# Πιθανοτική ανάλυση ευαισθησίας (PSA)

Η PSA αναθέτει κατανομή πιθανότητας σε κάθε αβέβαιη παράμετρο, τις δειγματοληπτεί όλες ταυτόχρονα χιλιάδες φορές (Monte Carlo) και αναφέρει την *πιθανότητα* μια επιλογή να είναι η καλύτερη — αντί για μία σημειακή εκτίμηση.

## Γιατί έχει σημασία

Η περίπτωση αναφοράς του NICE *απαιτεί* PSA. Η ντετερμινιστική ανάλυση απαντά στο «τι γίνεται αν μία είσοδος είναι λάθος;»· η PSA απαντά στο «δεδομένων όλων όσων δεν γνωρίζουμε ταυτόχρονα, πόσο πιθανό είναι να παίρνουμε τη σωστή απόφαση;». Το χαρακτηριστικό της αποτέλεσμα, η **καμπύλη αποδοχής κόστος-αποτελεσματικότητας (CEAC)**, σχεδιάζει την πιθανότητα μια επιλογή να είναι κόστος-αποτελεσματική έναντι του κατωφλίου προθυμίας πληρωμής — μετατρέποντας το «το ICER είναι £24.000/QALY» σε «υπάρχει 78% πιθανότητα να είναι η σωστή επιλογή στα £30.000/QALY».

## Τα μαθηματικά

```
For each of N draws (N ≈ 10,000):
  sample every parameter θ from its distribution
    (costs ~ Gamma, probabilities ~ Beta, utilities ~ Beta, effects ~ Normal/logNormal)
  compute NMB_j(θ) = λ × Effect_j(θ) − Cost_j(θ) for each option j

CEAC_j(λ) = fraction of draws in which option j has the highest NMB at threshold λ
```

Βλ. [καθαρό νομισματικό όφελος](../καθαρό-νομισματικό-όφελος/) για το NMB και [κατώφλια προθυμίας πληρωμής](../κατώφλια-προθυμίας-πληρωμής/) για το λ.

## Αναλυτικό παράδειγμα

Επιχειρηματική περίπτωση μετάβασης πλατφόρμας. Τρεις αβέβαιες είσοδοι:

```
Migration cost      ~ Gamma,  mean £800k, sd £200k
Annual benefit      ~ Normal, mean £350k, sd £150k
Benefit duration    ~ Uniform, 3–6 years
```

Για καθεμία από τις 10.000 κληρώσεις υπολογίστε καθαρό όφελος = διάρκεια × ετήσιο − κόστος (η προεξόφληση παραλείπεται για σαφήνεια). Ενδεικτικά αποτελέσματα:

```
Mean net benefit:      £775k
Probability net > 0:   0.86
5th–95th percentile:  −£180k … +£1.9M
```

Η σημειακή εκτίμηση έλεγε «προφανώς ναι». Η PSA λέει «86% ναι, με πραγματική ουρά όπου χάνουμε £180k+» — που είναι αυτό που πράγματι χρειάζεται ένας κάτοχος χαρτοφυλακίου, και τιμολογεί την περίπτωση για την εκτέλεση ενός discovery spike πρώτα (βλ. [EVPI](../αναμενόμενη-αξία-τέλειας-πληροφορίας/)).

## Σύνδεση με τη μηχανική λογισμικού

Οι μηχανικοί ήδη εμπιστεύονται το Monte Carlo για την πρόβλεψη παράδοσης (η δειγματοληψία διακίνησης υπερτερεί των σημειακών εκτιμήσεων). Επεκτείνετε τον ίδιο μηχανισμό στο χρήμα: κατανομές στην υιοθέτηση, τον χρόνο που εξοικονομείται και τον μισθό, και αναφέρετε «πιθανότητα αυτή η επένδυση πλατφόρμας να είναι καθαρά θετική» αντί για ψευδοακριβές ROI. Μια καμπύλη τύπου CEAC — πιθανότητα να είναι η καλύτερη επιλογή ως συνάρτηση του πώς ο οργανισμός αποτιμά μια ώρα μηχανικού — είναι πραγματικά καλύτερο τεκμήριο για μια επιτροπή χρηματοδότησης από οποιονδήποτε μεμονωμένο αριθμό.

## Παγίδες

- **Κατανομές σκουπίδια**: η PSA με επινοημένες τυπικές αποκλίσεις είναι ντετερμινιστική ανάλυση με άσπρη ποδιά. Βασίστε τα εύρη σε δεδομένα ή δομημένη εμπειρογνωμονική άντληση.
- **Αγνόηση συσχέτισης** μεταξύ παραμέτρων (η υψηλή υιοθέτηση συνήθως συσχετίζεται με υψηλό χρόνο που εξοικονομείται)· η ανεξάρτητη δειγματοληψία υποεκτιμά τον κίνδυνο ουράς.
- **Αναφορά μόνο του μέσου όρου** της προσομοίωσης — όλο το νόημα είναι η κατανομή και η πιθανότητα απόφασης.
