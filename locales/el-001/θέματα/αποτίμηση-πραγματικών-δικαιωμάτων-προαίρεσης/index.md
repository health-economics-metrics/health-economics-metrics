# Αποτίμηση πραγματικών δικαιωμάτων προαίρεσης

Η αποτίμηση πραγματικών δικαιωμάτων προαίρεσης (real options) εφαρμόζει τη λογική τιμολόγησης χρηματοοικονομικών δικαιωμάτων προαίρεσης σε πραγματικές (μη χρηματοπιστωτικές) επενδυτικές αποφάσεις — συγκεκριμένα, στο *δικαίωμα επέκτασης* ενός έργου αργότερα αν πετύχει, χωρίς υποχρέωση. Ένα απλοποιημένο διωνυμικό μοντέλο μίας περιόδου (Cox, Ross, Rubinstein, 1979) αποτιμά άμεσα αυτή την ευελιξία, μετατρέποντας το «ας κυκλοφορήσουμε μικρά και ας δούμε» από διαίσθηση σε τιμολογημένο αριθμό.

## Γιατί έχει σημασία

Ένας στατικός υπολογισμός NPV τιμολογεί ένα έργο ως στοίχημα όλα-ή-τίποτα: χρηματοδοτήστε το ή όχι, στη σημερινή κλίμακα, για πάντα. Τα πραγματικά έργα — και ειδικά οι σταδιακές εκτυλίξεις ψηφιακής υγείας — σπάνια στοιχηματίζονται έτσι: ένα σύστημα υγείας μπορεί να χρηματοδοτήσει ένα μικρό πιλοτικό, να παρατηρήσει τι συμβαίνει και να δεσμεύσει περισσότερα χρήματα μόνο αν λειτουργήσει. Αυτή η ευελιξία έχει πραγματική αξία, και η αγνόησή της υποτιμά συστηματικά τις σταδιακές επενδύσεις σε σχέση με τις εφάπαξ, κάτι που είναι ακριβώς ανάποδο για διαδικασίες προμηθειών που επιβραβεύουν την ασφαλέστερη φαινομενικά σταδιακή πρόταση. Η αποτίμηση πραγματικών δικαιωμάτων προαίρεσης τιμολογεί την ίδια την ευελιξία, ώστε μια σταδιακή πρόταση να συγκρίνεται δίκαια με εναλλακτική πλήρους δέσμευσης αντί να τιμωρείται επειδή φαίνεται μικρότερη σε μια αφελή γραμμή NPV.

## Τα μαθηματικά

```
Risk-neutral probability of the "up" state:
  p = ((1 + risk_free_rate) − down_factor) / (up_factor − down_factor)

Expansion payoff in each state (floored at zero — expanding is optional):
  payoff_up   = max(project_value × up_factor   − expansion_cost, 0)
  payoff_down = max(project_value × down_factor − expansion_cost, 0)

Option value (discounted expected payoff):
  option_value = (p × payoff_up + (1 − p) × payoff_down) / (1 + risk_free_rate)

Expanded NPV = static_npv + option_value
```

Η αξία του έργου είτε ανεβαίνει (`up_factor`) είτε πέφτει (`down_factor`) έως το επόμενο σημείο απόφασης. Η επέκταση ασκείται μόνο αν είναι κερδοφόρα σε αυτή την κατάσταση — το κατώτατο όριο μηδέν της απολαβής είναι αυτό που το κάνει γνήσιο *δικαίωμα προαίρεσης* και όχι υποχρέωση. Για την τιμολόγηση του δικαιώματος συλλογής πληροφορίας πρώτα, αντί του δικαιώματος επέκτασης αργότερα, βλ. [αναμενόμενη αξία τέλειας πληροφορίας](../αναμενόμενη-αξία-τέλειας-πληροφορίας/). Για το κόστος της αναμονής για αυτή την απόφαση, βλ. [κόστος καθυστέρησης](../κόστος-καθυστέρησης/).

## Αναλυτικό παράδειγμα

Ένα πιλοτικό ψηφιακής υπηρεσίας με `project_value = £1.000.000`, πιθανή άνοδο στο 1,5× ή πτώση στο 0,5× έως το επόμενο σημείο απόφασης, ακίνδυνο επιτόκιο 8% και κόστος επέκτασης £600.000:

```
p = (1.08 − 0.5) / (1.5 − 0.5) = 0.58

payoff_up   = max(1,000,000 × 1.5 − 600,000, 0) =  900,000
payoff_down = max(1,000,000 × 0.5 − 600,000, 0) = max(−100,000, 0) = 0

The floor matters: the option would NOT be exercised if the market
disappoints — the £600,000 expansion cost exceeds the £500,000 the
project would be worth in the down state.

option_value = (0.58 × 900,000 + 0.42 × 0) / 1.08
             = 522,000 / 1.08
             ≈ £483,333.33
```

Προσθέτοντας την αξία του δικαιώματος σε στατική βάση NPV £200.000: διευρυμένο NPV = 200.000 + 483.333,33 ≈ **£683.333,33**. Η αναφορά μόνο του στατικού NPV των £200.000, χωρίς αυτή την αξία δικαιώματος, θα υποτιμούσε την πραγματική αξία του σταδιακού έργου περισσότερο από το διπλάσιο.

## Σύνδεση με τη μηχανική λογισμικού

Αυτή είναι η τυπική εκδοχή του «κυκλοφορήστε μια ελάχιστη έκδοση τώρα, κρατήστε το δικαίωμα να επενδύσετε περισσότερο αν πάρει μπρος» — άμεσα σχετική με μια σταδιακή εκτύλιξη προϊόντος ψηφιακής υγείας, δομικά παράλληλη με την πλαισίωση ακολουθίας-υπό-αβεβαιότητα του [κόστους καθυστέρησης](../κόστος-καθυστέρησης/) και του [WSJF/CD3](../wsjf-και-cd3/), και συμπληρωματική προς την [αναμενόμενη αξία τέλειας πληροφορίας](../αναμενόμενη-αξία-τέλειας-πληροφορίας/) και την [αναμενόμενη αξία δειγματικής πληροφορίας](../αναμενόμενη-αξία-πληροφορίας-δείγματος/) — και τα τρία τιμολογούν ευελιξία ή πληροφορία υπό αβεβαιότητα, από διαφορετικές οπτικές.

## Παγίδες

- **Δανεισμός τιμολόγησης ουδέτερης ως προς τον κίνδυνο χωρίς την παραδοχή εμπορεύσιμου περιουσιακού στοιχείου στην οποία βασίζεται**: τα μοντέλα πραγματικών δικαιωμάτων δανείζονται πιθανότητα ουδέτερη ως προς τον κίνδυνο από την τιμολόγηση χρηματοοικονομικών δικαιωμάτων, που υποθέτει ότι η υποκείμενη αξία είναι *εμπορεύσιμο* στοιχείο — για ένα πραγματικά μη εμπορεύσιμο έργο αυτό είναι μοντελοποιητική ευκολία, όχι κυριολεκτικό γεγονός αγοράς.
- **Αντιμετώπιση των `up_factor`/`down_factor` ως ελεύθερων παραμέτρων**: οι διωνυμικές είσοδοι ανόδου/πτώσης είναι οι ίδιες παραδοχές που απαιτούν αιτιολόγηση, όχι ελεύθερες παράμετροι επιλεγμένες ώστε να παράγουν επιθυμητή απάντηση.
- **Αναφορά της αξίας δικαιώματος μόνο**: η αξία πραγματικού δικαιώματος είναι *προσθετική* στο στατικό NPV ενός αυτόνομου έργου — συνηθισμένο σφάλμα είναι η αναφορά μόνο της αξίας δικαιώματος με παράλειψη της βασικής περίπτωσης, κάτι που υπερεκτιμά την περίπτωση αν το στατικό NPV είναι αρνητικό και την υποεκτιμά (όπως στο αναλυτικό παράδειγμα) όταν το στατικό NPV παραλείπεται εντελώς.
