# ການວິເຄາະການຕັດສິນໃຈຫຼາຍເກນ (MCDA)

ການວິເຄາະການຕັດສິນໃຈຫຼາຍເກນ (MCDA) ແມ່ນແບບຈຳລອງໃຫ້ຄະແນນຜົນລວມຖ່ວງນ້ຳໜັກທີ່ໃຊ້ໃນການປະເມີນເຕັກໂນໂລຢີສຸຂະພາບ ເມື່ອເກນ ICER/ຄວາມເຕັມໃຈທີ່ຈະຈ່າຍດຽວບໍ່ຄອບຄຸມທຸກຢ່າງທີ່ຜູ້ຕັດສິນໃຈໃສ່ໃຈ: ຄວາມເທົ່າທຽມ, ຄວາມຕ້ອງການທີ່ບໍ່ໄດ້ຮັບການຕອບສະໜອງ, ນະວັດຕະກຳ, ຜົນກະທົບຕໍ່ງົບປະມານ, ຄວາມຮຸນແຮງຂອງພະຍາດ. ແຕ່ລະເກນໄດ້ນ້ຳໜັກທີ່ສະທ້ອນຄວາມສຳຄັນ (ດຶງຈາກຜູ້ມີສ່ວນຮ່ວມ, ນ້ຳໜັກລວມເປັນ 1), ແຕ່ລະທາງເລືອກໄດ້ຄະແນນປັບມາດຕະຖານຕໍ່ເກນ (ປົກກະຕິ 0–1), ແລະ ຄະແນນລວມແມ່ນຜົນລວມຖ່ວງນ້ຳໜັກ — ຮູບຮ່າງຄະນິດສາດດຽວກັບບັດຄະແນນເລືອກຜູ້ຂາຍຊອບແວ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

MCDA ຖືກໃຊ້ໃນກອບເຊັ່ນ EVIDEM, ແລະ ໂດຍບາງອົງກອນ HTA ສຳລັບການປະເມີນພະຍາດກຳພ້າ/ພະຍາດຫາຍາກ ບ່ອນທີ່ວິທີເກນຕົ້ນທຶນຕໍ່ QALY ທີ່ເຄັ່ງຄັດຖືວ່າແຄບເກີນໄປທີ່ຈະຈັບທຸກຢ່າງທີ່ສຳຄັນຂອງການຕັດສິນໃຈ. ຄະນະທຳງານ ISPOR MCDA Emerging Good Practices ໄດ້ວາງຄຳແນະນຳການປະຕິບັດທີ່ດີສຳລັບການດຶງນ້ຳໜັກ ແລະ ຄະແນນຢ່າງປົກປ້ອງໄດ້ ກໍເພາະການຕັດສິນໃຈທີ່ຖ່ວງນ້ຳໜັກແບບບໍ່ເປັນທາງການສ້າງງ່າຍ ແລະ ຫຼິ້ນກົນງ່າຍ. ເມື່ອເຕັກໂນໂລຢີສຸຂະພາບມີມິຕິມູນຄ່າແທ້ໆ ທີ່ [ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ](../ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ/) ດຽວສະແດງບໍ່ໄດ້ — ຄວາມຮຸນແຮງ, ນະວັດຕະກຳ, ຄວາມເທົ່າທຽມ — MCDA ໃຫ້ຜູ້ຕັດສິນໃຈມີໂຄງສ້າງທີ່ຊັດເຈນ ແລະ ກວດສອບໄດ້ສຳລັບການລວມພວກມັນ, ແທນການຕັດສິນທີ່ບໍ່ໄດ້ກ່າວອອກ.

## ຄະນິດສາດ

```
MCDA score = Σ_i (weight_i × score_i)

weights should sum to 1 (elicited via stakeholder methods such as swing
weighting or the Analytic Hierarchy Process)
```

## ຕົວຢ່າງການຄິດໄລ່

ຄະນະກຳມະການ HTA ໃຫ້ຄະແນນຢາດິຈິຕອນຕາມສີ່ເກນ:

```
Criterion                          Weight   Score   Weight × Score
Clinical benefit                   0.4      0.8     0.32
Cost impact                        0.3      0.5     0.15
Disease severity / unmet need      0.2      0.9     0.18
Innovation                         0.1      0.6     0.06
                                    ─────                ─────
                                    1.0                  0.71
```

ນ້ຳໜັກລວມເປັນ 1.0 (0.4 + 0.3 + 0.2 + 0.1), ແລະ ຄະແນນ MCDA ແມ່ນ 0.71 (0.32 + 0.15 + 0.18 + 0.06). ຄະນະກຳມະການປຽບທຽບ 0.71 ກັບເກນທີ່ຕົກລົງລ່ວງໜ້າ, ຫຼື ຈັດອັນດັບມັນກັບເຕັກໂນໂລຢີຄູ່ແຂ່ງທີ່ໃຫ້ຄະແນນແບບດຽວກັນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ນີ້ແມ່ນຄະນິດສາດດຽວກັນກັບບັດຄະແນນເລືອກຜູ້ຂາຍຖ່ວງນ້ຳໜັກ, ມາຕຣິກການປະເມີນ RFP, ຫຼື ແບບຈຳລອງໃຫ້ຄະແນນການຈັດລຳດັບຄວາມສຳຄັນຄຸນສົມບັດ — ເບິ່ງ [ສ້າງເອງ ທຽບກັບ ຊື້](../ສ້າງເອງ-ທຽບກັບ-ຊື້/), ກໍລະນີໃຊ້ບັດຄະແນນຖ່ວງນ້ຳໜັກຄລາສສິກໃນການຈັດຊື້ຊອບແວ. ຍັງຄວນປຽບຕ່າງກັບ [WSJF ແລະ CD3](../wsjf-ແລະ-cd3/): WSJF/CD3 ເປັນວິທີຈັດລຳດັບຄວາມສຳຄັນແບບ *ອັດຕາສ່ວນ* (ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າຫານດ້ວຍຂະໜາດງານ ຫຼື ໄລຍະເວລາ), ໃນຂະນະທີ່ MCDA ແມ່ນ *ຜົນລວມ* ຖ່ວງນ້ຳໜັກ. MCDA ແລະ WSJF/CD3 ແມ່ນສອງຄຳຕອບທີ່ຕ່າງກັນໃນໂຄງສ້າງຕໍ່ "ເຮົາຈັດອັນດັບທາງເລືອກຄູ່ແຂ່ງແນວໃດ", ແລະ ການຮູ້ວ່າການຕັດສິນໃຈໃດຕ້ອງການອັນໃດ — ມູນຄ່າແບບບວກຂ້າມເກນເອກະລາດ ທຽບກັບ ຄວາມໜາແໜ້ນມູນຄ່າຕໍ່ຫົວໜ່ວຍຄວາມຈຸທີ່ຫາຍາກ — ສຳຄັນກວ່າວ່າສູດໃດເບິ່ງເຄັ່ງຄັດກວ່າ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ອະຄະຕິການດຶງນ້ຳໜັກ**: ຜູ້ທີ່ກຳນົດນ້ຳໜັກກຳນົດອັນດັບລ່ວງໜ້າໂດຍປະສິດທິຜົນ, ດັ່ງນັ້ນ "ສູດ" ສາມາດຟອກການຕັດສິນໃຈທາງການເມືອງ ຫຼື ການຄ້າເປັນການຄິດໄລ່ທີ່ເປັນວັດຖຸວິໄສ. ບັນທຶກວ່າໃຜກຳນົດນ້ຳໜັກ ແລະ ແນວໃດ.
- **ນັບເກນທີ່ຈັບໄດ້ແລ້ວຊ້ຳສອງຄັ້ງ**: ໃຫ້ຄະແນນ "ຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ" ເປັນໜຶ່ງເກນ ໃນຂະນະທີ່ *ຍັງ* ໃຫ້ຄະແນນ "ຜົນກະທົບດ້ານຕົ້ນທຶນ" ແຍກຕ່າງຫາກ ຖ່ວງນ້ຳໜັກເງິນເກີນເມື່ອທຽບກັບເກນອື່ນໂດຍບໍ່ມີໃຜຕັ້ງໃຈ.
- **ຄວາມແມ່ນຍຳປອມ**: ຄະແນນຖ່ວງນ້ຳໜັກສອງຕຳແໜ່ງທົດສະນິຍົມ (0.71) ບົ່ງບອກຄວາມເຄັ່ງຄັດຫຼາຍກວ່າທີ່ການໃຫ້ຄະແນນ 0–10 ຂອງຜູ້ມີສ່ວນຮ່ວມຮອງຮັບຈິງ, ແລະ ຄວາມແປຜັນລະຫວ່າງຜູ້ໃຫ້ຄະແນນມັກບໍ່ຖືກລາຍງານເລີຍ.
