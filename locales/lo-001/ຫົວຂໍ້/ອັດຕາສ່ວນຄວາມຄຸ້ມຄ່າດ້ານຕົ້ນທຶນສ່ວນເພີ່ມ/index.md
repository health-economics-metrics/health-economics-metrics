# ອັດຕາສ່ວນຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນສ່ວນເພີ່ມ (ICER)

ICER ແມ່ນຕົ້ນທຶນເພີ່ມເຕີມຕໍ່ໜຶ່ງຫົວໜ່ວຍຜົນດ້ານສຸຂະພາບທີ່ເພີ່ມຂຶ້ນ ເມື່ອທ່ານເລືອກທາງເລືອກໜຶ່ງແທນທາງເລືອກທີ່ດີທີ່ສຸດຖັດໄປ. ມັນເປັນຕົວເລກຫຼັກຂອງການປະເມີນເຕັກໂນໂລຢີສຸຂະພາບ. (ເມື່ອຫົວໜ່ວຍຜົນແມ່ນ QALY, ມັນຍັງເອີ້ນວ່າອັດຕາສ່ວນຕົ້ນທຶນ-ອຣະຖະປະໂຫຍດສ່ວນເພີ່ມ, ICUR.)

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ລະບົບສຸຂະພາບບໍ່ເຄີຍປະເມີນເຕັກໂນໂລຢີແບບໂດດດ່ຽວ — ສະເໝີ *ແບບສ່ວນເພີ່ມ*, ທຽບກັບສິ່ງທີ່ຈະເຮັດຖ້າບໍ່ມີມັນ. NICE ປຽບທຽບ ICER ຂອງເຕັກໂນໂລຢີກັບເກນ **£20,000–£30,000 ຕໍ່ QALY**; ສະຖາບັນ ICER ຂອງສະຫະລັດລາຍງານໃນຊ່ວງ $50,000–$200,000/QALY; ການາດາໃຊ້ປະມານ CAD$50,000/QALY. ການທີ່ຜະລິດຕະພັນຂອງທ່ານ "ຄຸ້ມຄ່າ" ສຳລັບບໍລິການສຸຂະພາບແຫ່ງຊາດຫຼືບໍ່ ຕາມທາງການຄືວ່າ ICER ຂອງມັນຜ່ານເກນທ້ອງຖິ່ນຫຼືບໍ່. ເບິ່ງ [ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ](../ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ/).

## ຄະນິດສາດ

```
ICER = (Cost_new − Cost_comparator) / (Effect_new − Effect_comparator)
     = ΔC / ΔE
```

ກົດການຕີຄວາມ:

- ΔC < 0, ΔE > 0: ທາງເລືອກໃໝ່ **ເໜືອກວ່າ** — ຖືກກວ່າ ແລະ ດີກວ່າ; ບໍ່ຕ້ອງໃຊ້ອັດຕາສ່ວນ.
- ΔC > 0, ΔE > 0: ຄິດໄລ່ ICER, ປຽບທຽບກັບເກນ λ; ຮັບເອົາຖ້າ ICER < λ.
- ΔC > 0, ΔE < 0: ທາງເລືອກໃໝ່ຖືກຄອບງຳ — ປະຕິເສດ.
- ອັດຕາສ່ວນມີພຶດຕິກຳບໍ່ດີໃກ້ ΔE = 0 — ໃຫ້ເລືອກ [ຜົນປະໂຫຍດເປັນເງິນສຸດທິ](../ຜົນປະໂຫຍດເປັນເງິນສຸດທິ/) ສຳລັບການຈັດອັນດັບ.

ຕົວປຽບທຽບຕ້ອງເປັນ *ທາງເລືອກທີ່ດີທີ່ສຸດຖັດໄປທີ່ບໍ່ຖືກຄອບງຳ*, ບໍ່ແມ່ນ "ບໍ່ເຮັດຫຍັງ" — ເບິ່ງ [ຄວາມເໜືອກວ່າ ແລະ ຂອບເຂດປະສິດທິພາບ](../ຄວາມເໜືອກວ່າ-ແລະ-ຂອບເຂດປະສິດທິພາບ/).

## ຕົວຢ່າງການຄິດໄລ່

ບໍລິການຕິດຕາມທາງໄກສຳລັບຜູ້ປ່ວຍຫົວໃຈລົ້ມເຫຼວ, ຕໍ່ຜູ້ປ່ວຍ 1,000 ຄົນ/ປີ, ທຽບກັບການດູແລປົກກະຕິ:

```
Costs:   service £900,000; admissions avoided save £600,000
         ΔC = 900,000 − 600,000 = £300,000
Effects: earlier intervention gains 25 QALYs
         ΔE = 25

ICER = 300,000 / 25 = £12,000 per QALY
```

£12,000/QALY ຕ່ຳກວ່າເກນ £20,000 ຂອງ NICE ຢ່າງສະບາຍ — ກໍລະນີທີ່ເຂັ້ມແຂງ. ສັງເກດວ່າຕົ້ນທຶນ *ສຸດທິ* ສຳຄັນແນວໃດ: ຖ້າບໍ່ມີການຫັກລົບ £600,000, ICER ຈະເປັນ £36,000/QALY ແລະ ກໍລະນີນີ້ຄົງຈະບໍ່ຜ່ານ. ການຫັກລົບຕົ້ນທຶນ ແລະ ຄຸນນະພາບຫຼັກຖານຂອງມັນແມ່ນບ່ອນທີ່ການວິເຄາະເຫຼົ່ານີ້ຊະນະ ຫຼື ແພ້ (ເບິ່ງ [ຕົ້ນທຶນຕໍ່ເນື່ອງທີ່ຫຼີກລ່ຽງໄດ້](../ຕົ້ນທຶນຕໍ່ເນື່ອງທີ່ຫຼີກລ່ຽງໄດ້/)).

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ວິໄນ ICER ໂອນໄປໃຊ້ກັບການຕັດສິນໃຈດ້ານວິສະວະກຳໄດ້ທັງໝົດ:

```
(cost of option B − cost of option A) / (outcome B − outcome A)
```

— ຕົ້ນທຶນສ່ວນເພີ່ມຕໍ່ການ deploy ທີ່ເພີ່ມ, ຕໍ່ຊົ່ວໂມງວິສະວະກອນທີ່ປະຢັດ, ຕໍ່ເຫດການທີ່ຫຼີກລ່ຽງໄດ້ — ສະເໝີທຽບກັບທາງເລືອກທີ່ດີທີ່ສຸດຖັດໄປ, ບໍ່ແມ່ນທຽບກັບການບໍ່ເຮັດຫຍັງ. ສອງນິໄສທີ່ຄວນລອກແບບ: (1) *ລະບຸຕົວປຽບທຽບຢ່າງຊັດເຈນ*; ການອ້າງ ROI ຂອງເຄື່ອງມືສ່ວນໃຫຍ່ແອບປຽບທຽບກັບຄູ່ແຂ່ງທີ່ອ່ອນແອ; (2) *ຫັກຕົ້ນທຶນສຸດທິກ່ອນ* — ເຄື່ອງມືທີ່ມີລາຄາ £100k ແຕ່ທົດແທນລາຍຈ່າຍເດີມ £80k ມີ ΔC = £20k.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ປຽບທຽບ ICER ຂ້າມສະກຸນເງິນໂດຍບໍ່ມີຂັ້ນຕອນແປງຢ່າງຊັດເຈນ**: ICER ທີ່ຄິດໄລ່ເປັນສະກຸນເງິນຂອງປະເທດໜຶ່ງຕ້ອງແປງດ້ວຍວິທີທີ່ລະບຸກ່ອນປຽບທຽບກັບເກນຂອງປະເທດອື່ນ — ເບິ່ງ [ການປຽບທຽບ ICER ຂ້າມສະກຸນເງິນ](../ການປຽບທຽບ-icer-ຂ້າມສະກຸນເງິນ/) ວ່າເປັນຫຍັງການເລືອກປັດໄຈແປງ (ຄວາມສະເໝີພາບຂອງອຳນາດຊື້ ທຽບກັບ ອັດຕາແລກປ່ຽນຕະຫຼາດ) ເອງສາມາດພິກການຕັດສິນໃຈຮັບເອົາໄດ້.
- **ການຫຼິ້ນກົນຕົວປຽບທຽບ**: ການປຽບທຽບກັບເສັ້ນຖານທີ່ລ້າສະໄໝ ຫຼື ຖືກເຮັດໃຫ້ແຍ່ຢ່າງຈົງໃຈເຮັດໃຫ້ ΔE ພອງຕົວ ແລະ ຍົກຍ້ອງ ICER.
- **ຄ່າສະເລ່ຍແທນສ່ວນເພີ່ມ**: ຕົ້ນທຶນຕໍ່ QALY ຂອງໂຄງການທັງໝົດບໍ່ແມ່ນ ICER ຂອງການຂະຫຍາຍ ຫຼື ການຮັບເອົາມັນ.
- **ການບູຊາຄ່າຈຸດດຽວ**: ICER ແມ່ນອັດຕາສ່ວນຂອງຄວາມແຕກຕ່າງສອງຢ່າງທີ່ບໍ່ແນ່ນອນ; ລາຍງານຄວາມບໍ່ແນ່ນອນຜ່ານ [PSA ແລະ CEAC](../ການວິເຄາະຄວາມອ່ອນໄຫວແບບຄວາມນ່າຈະເປັນ/).
- **ICER ຕິດລົບມີຄວາມກຳກວມ** (ຖືກກວ່າ-ແລະ-ດີກວ່າ ທຽບກັບ ແພງກວ່າ-ແລະ-ແຍ່ກວ່າ ໃຫ້ເຄື່ອງໝາຍດຽວກັນ) — ຢ່າລາຍງານ ICER ຕິດລົບໂດຍບໍ່ບອກວ່າມັນຢູ່ໃນຮ່ອງ (quadrant) ໃດ.
