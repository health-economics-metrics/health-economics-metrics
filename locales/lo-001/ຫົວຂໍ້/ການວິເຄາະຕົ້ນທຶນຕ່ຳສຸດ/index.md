# ການວິເຄາະຕົ້ນທຶນຕ່ຳສຸດ (CMA)

CMA ປຽບທຽບສະເພາະຕົ້ນທຶນ ແລະ ເລືອກທາງເລືອກທີ່ຖືກທີ່ສຸດ — ຖືກຕ້ອງ*ສະເພາະ*ເມື່ອຜົນລັບຂອງທາງເລືອກໄດ້ຖືກສະແດງວ່າທຽບເທົ່າກັນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

CMA ແມ່ນການວິເຄາະທີ່ງ່າຍທີ່ສຸດ ແລະ ຖືກໃຊ້ຜິດຫຼາຍທີ່ສຸດ. ຂໍ້ອ້າງຄວາມທຽບເທົ່າເຮັດວຽກທັງໝົດ: ຖ້າຜົນລັບບໍ່ແຕກຕ່າງແທ້ (ໄບໂອຊິມິລາ vs ຕົ້ນສະບັບ; ຜູ້ສະໜອງສອງລາຍຂອງບໍລິການດຽວກັນທີ່ຕອບສະໜອງສະເປກດຽວກັນ) ຕົ້ນທຶນກໍເປັນຄຳຖາມດຽວ ແລະ CMA ຖືກຕ້ອງ. ຄວາມເຂັ້ມງວດຢູ່ທີ່ການ*ພິສູດ*ຄວາມທຽບເທົ່າກ່ອນ — ປົກກະຕິຜ່ານການສຶກສາ non-inferiority ທີ່ມີຂອບເຂດກຳນົດລ່ວງໜ້າ — ເຊິ່ງແມ່ນຂັ້ນຕອນທີ່ຜູ້ຊື້ມັກຂ້າມ.

## ຄະນິດສາດ

```
Given evidence that Effect_A ≈ Effect_B (within a pre-specified margin δ):
Choose min(Cost_A, Cost_B)

Costs measured from the same perspective, over the same horizon,
including switching/transition costs.
```

ຖ້າບໍ່ສາມາດສະແດງຫຼັກຖານຄວາມທຽບເທົ່າ CMA ໃຊ້ບໍ່ໄດ້ — ໃຊ້[CEA](../ການວິເຄາະຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ/)/[CUA](../ການວິເຄາະຕົ້ນທຶນ-ອຣະຖະປະໂຫຍດ/)ແທນ.

## ຕົວຢ່າງການຄິດໄລ່

ໂຮງໝໍ trust ເລືອກລະຫວ່າງສອງແພລດຟອມປຶກສາຜ່ານວິດີໂອ. ການທົດລອງຂະໜານ 3 ເດືອນສະແດງອັດຕາສຳເລັດ 94.1% ທຽບ 93.8%, ຄວາມພໍໃຈຂອງຄົນເຈັບ 4.4 ທຽບ 4.4 — ຄວາມແຕກຕ່າງຢູ່ພາຍໃນ δ 2 ຈຸດເປີເຊັນທີ່ຕົກລົງລ່ວງໜ້າ. ຜົນລັບ: ທຽບເທົ່າ. ຕົ້ນທຶນ 3 ປີ:

```
                     Platform A     Platform B
Licences             £360,000       £210,000
Integration          £80,000        £150,000
Training/support     £60,000        £90,000
Total                £500,000       £450,000
```

ແພລດຟອມ B ຊະນະ £50,000 — *ລວມ*ຕົ້ນທຶນການເຊື່ອມປະສານທີ່ສູງກວ່າຂອງມັນ. ຖ້າບໍ່ມີການທົດລອງ ຂໍ້ອ້າງຄວາມທຽບເທົ່າຈະອີງໃສ່ເອກະສານໂຄສະນາຂອງຜູ້ຂາຍ, ແລະ ຄວາມແຕກຕ່າງອັດຕາສຳເລັດ 1 ຈຸດ (≈ ການປຶກສາທີ່ລົ້ມເຫຼວຫຼາຍພັນຄັ້ງ/ປີ) ຈະເກີນ £50,000 ຫຼາຍ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

CMA ແມ່ນຮູບຮ່າງທາງການຂອງການຈັດຊື້ສິນຄ້າທົ່ວໄປ: ຜູ້ໃຫ້ບໍລິການ CI ສອງລາຍທີ່ຕອບສະໜອງ SLO ດຽວກັນ, object store ສອງອັນທີ່ມີສະເປກຄວາມທົນທານດຽວກັນ. ບົດຮຽນເສດຖະສາດສຸຂະພາບແມ່ນ*ລຳດັບການດຳເນີນງານ*: ກ່ອນອື່ນສະແດງຫຼັກຖານຄວາມທຽບເທົ່າ (ເກນທຽບກັບປະລິມານງານຂອງທ່ານ, ທົດລອງກັບ SLO ຂອງທ່ານ, ດ້ວຍຂອບເຂດທີ່ຕົກລົງລ່ວງໜ້າ), ແລ້ວປຽບທຽບຕົ້ນທຶນທັງໝົດລວມການຍ້າຍ. "ພວກມັນຄືກັນໂດຍພື້ນຖານ, B ຖືກກວ່າ" ໂດຍບໍ່ມີຂັ້ນຕອນທຳອິດ ແມ່ນວິທີທີ່ອົງກອນຊື້ເຄື່ອງມືທີ່ຖືກກວ່າ 10% ແຕ່ແຍ່ກວ່າ 40%. ຂໍ້ສະຫຼຸບ: ເມື່ອຜູ້ຂາຍໂຕ້ແຍ້ງເລື່ອງລາຄາ ໃຫ້ເຂົາກຳນົດຄວາມທຽບເທົ່າ — ມັນຜູກມັດໃນທິດທາງອື່ນນຳ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຄວາມທຽບເທົ່າທີ່ສົມມຸດ** — ບາບທີ່ນິຍາມ; ການບໍ່ມີຫຼັກຖານຂອງຄວາມແຕກຕ່າງບໍ່ແມ່ນຫຼັກຖານຂອງຄວາມທຽບເທົ່າ (ການທົດລອງທີ່ກຳລັງຕ່ຳ "ສະແດງ" ຄວາມທຽບເທົ່າໂດຍບໍ່ເສຍຫຍັງ).
- **ຕົກຕົ້ນທຶນການສະຫຼັບ** — ການຍ້າຍ, ການຝຶກຄືນ, ແລະ ການດຳເນີນຂະໜານຢູ່ໃນດ້ານຕົ້ນທຶນ.
- **ຄວາມທຽບເທົ່າໃນຜົນລັບທີ່ຜິດ**: ທຽບເທົ່າໃນຕົວຊີ້ວັດທີ່ວັດ ແຕ່ຕ່າງໃນອັນທີ່ສຳຄັນ (ການເຂົ້າເຖິງ, tail latency, ຄ່າສົ່ງຂໍ້ມູນອອກ).
