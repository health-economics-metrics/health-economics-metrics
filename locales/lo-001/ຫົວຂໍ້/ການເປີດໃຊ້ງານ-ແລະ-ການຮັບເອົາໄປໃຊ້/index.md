# ການເປີດໃຊ້ງານ ແລະ ການຮັບເອົາໄປໃຊ້

ອັດຕາການເປີດໃຊ້ງານ (activation rate) ຄືສັດສ່ວນຂອງຜູ້ສະໝັກທີ່ໄປເຖິງຄຸນຄ່າທີ່ມີຄວາມໝາຍຄັ້ງທຳອິດ (ການກະທຳ "aha" — ບັນທຶກຄ່າອ່ານຄັ້ງທຳອິດ, ຮຽນບົດຮຽນທຳອິດສຳເລັດ). ການຮັບເອົາໄປໃຊ້ (uptake) ແມ່ນສະບັບຂອງປະຊາກອນ: ສັດສ່ວນຂອງປະຊາກອນທີ່*ມີສິດ*ທີ່ຮັບເອົາໄປໃຊ້ເລີຍ. ທັງສອງລວມກັນເປັນປະຕູດ່ານໜ້າຂອງທໍ່ຄຸນຄ່າ (value funnel): ການຫາຜູ້ໃຊ້ → ການຮັບເອົາໄປໃຊ້ → ການເປີດໃຊ້ງານ → [ການຮັກສາຜູ້ໃຊ້](../ການຮັກສາຜູ້ໃຊ້-ແລະ-ການຫຼຸດຫາຍ/) → ຜົນລັບ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຜູ້ໃຊ້ທີ່ບໍ່ໄດ້ເປີດໃຊ້ງານແມ່ນຕົ້ນທຶນລ້ວນໆ: ລາຍຈ່າຍໃນການຫາຜູ້ໃຊ້, ການຈັດຕຽມລະບົບ, ພາລະການສະໜັບສະໜູນ — ແຕ່ບໍ່ມີຄຸນຄ່າທາງຄລີນິກເລີຍ. ເກນທຽບມາດຕະຖານຊີ້ວ່າການເປີດໃຊ້ງານຂອງຊອບແວດ້ານສຸຂະພາບ*ຕ່ຳກວ່າ*ຄ່າສະເລ່ຍຂອງທຸກອຸດສາຫະກຳ (≈24% ທຽບກັບ ≈37% ສຳລັບການເປີດໃຊ້ງານຂອງຜູ້ໃຊ້ໃໝ່ໃນຊຸດເກນທຽບ SaaS ຊຸດໜຶ່ງ; ການເຮັດລາຍການກວດສອບການຝຶກໃຊ້ງານສຳເລັດ ~20%), ສະທ້ອນເຖິງຂັ້ນຕອນຝຶກໃຊ້ງານທີ່ໜັກກວ່າ (ການຢືນຢັນຕົວຕົນ, ການຍິນຍອມ, ຄວາມປອດໄພທາງຄລີນິກ). ການຮັບເອົາໄປໃຊ້ແບກຮັບສິ່ງທີ່ມີຜົນຕໍ່ປະຊາກອນ: ໃນ[ກອບ RE-AIM](../ການເຂົ້າເຖິງ-ແລະ-ຄວາມເທົ່າທຽມ/), ຜົນກະທົບດ້ານສາທາລະນະສຸກ ≈ ການເຂົ້າເຖິງ × ປະສິດທິຜົນ — ແອັບທີ່ດີເລີດແຕ່ມີປະຊາກອນທີ່ມີສິດຮັບເອົາໄປໃຊ້ພຽງ 3% ກໍເຮັດໃຫ້ຕົວຊີ້ວັດຂອງປະຊາກອນຂະຍັບໄດ້ພຽງ 3%. ສຳລັບການປິ່ນປົວດິຈິຕອນທີ່ມີໃບສັ່ງແພດ ດ່ານການຮັບເອົາໄປໃຊ້ເຫັນໄດ້ຊັດໃນຂໍ້ມູນລະດັບຊາດ: **ໃບສັ່ງ DiGA ຂອງເຢຍລະມັນ ~81% ຖືກເປີດໃຊ້ງານ** — ການປິ່ນປົວທີ່ສັ່ງແລ້ວແລະຈ່າຍເງິນແລ້ວ 1 ໃນ 5 ບໍ່ເຄີຍເລີ່ມຕົ້ນ (ເບິ່ງ [ເສັ້ນທາງລັດ DiGA](../ເສັ້ນທາງລັດ-diga-ຂອງເຢຍລະມັນ/)).

## ຄະນິດສາດ

```
Activation rate = users completing key action within window / sign-ups × 100
Uptake rate     = adopters / eligible population × 100
DTx fill rate   = activated prescription codes / issued prescriptions × 100

Funnel value model:
  eligible × uptake × activation × retention-weighted benefit = population value
  — four multiplications; improving the smallest factor usually
  dominates (theory-of-constraints for funnels)
```

## ຕົວຢ່າງການຄິດໄລ່

ຜູ້ຊື້ບໍລິການ (commissioner) ສະເໜີແອັບປ້ອງກັນໂລກເບົາຫວານໃຫ້ຜູ້ອາໄສທີ່ມີສິດ 80,000 ຄົນ:

```
Invited → registered:  80,000 → 12,000  (uptake 15%)
Registered → activated (first session + goal set, 7 days): 12,000 → 5,400 (45%)
Activated → completed 6-month programme: 5,400 → 1,600 (30%)

Programme effect (trial, completers): 0.03 QALYs + £180 avoided costs
Population value = 1,600 × (0.03 × £20,000 + £180) ≈ £1.25M
Per-eligible-person value = £15.6 — versus £780 if every eligible person completed.

Where to invest? Doubling uptake (15→30%) doubles value; raising
activation 45→65% adds ~44%; both beat further polishing the programme
content the 1,600 already complete.
```

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ການເປີດໃຊ້ງານແມ່ນຂັ້ນຕອນຂອງທໍ່ຄຸນຄ່າທີ່ວິສະວະກຳແກ້ໄຂໄດ້ງ່າຍທີ່ສຸດ: ແຮງຕ້ານຈາກການຢືນຢັນຕົວຕົນ, ຂັ້ນຕອນການຍິນຍອມ, ການອອກແບບໜ້າຈໍເປົ່າ, ແລະ ເວລາຈົນເຖິງຄຸນຄ່າຄັ້ງທຳອິດ ລ້ວນແຕ່ເປັນໂຄດ ບໍ່ແມ່ນນະໂຍບາຍ (ຄ່າມັດທະຍະຖານເວລາຈົນເຖິງຄຸນຄ່າຂອງຊອບແວສຸຂະພາບ ≈ 1 ມື້ 7 ຊົ່ວໂມງໃນຂໍ້ມູນເກນທຽບ — ທຸກຊົ່ວໂມງຄືຄວາມສ່ຽງທີ່ຜູ້ໃຊ້ຈະເລີກໃຊ້). ການຮັບເອົາໄປໃຊ້ແມ່ນບັນຫາຂອງລະບົບການແຈກຈ່າຍ: ການເຊື່ອມເຂົ້າກັບເສັ້ນທາງການສົ່ງຕໍ່ (ຈຸດທີ່ສັ່ງຢາ), ຄຳເຊີນທີ່ແພດທົ່ວໄປ (GP) ແນະນຳ (ຄວາມໄວ້ວາງໃຈຖືກຖ່າຍທອດ), ແລະ ການເຂົ້າເຖິງໄດ້ (ພາສາ, ທັກສະດິຈິຕອນ — ເບິ່ງ [ການເຂົ້າເຖິງ ແລະ ຄວາມເທົ່າທຽມ](../ການເຂົ້າເຖິງ-ແລະ-ຄວາມເທົ່າທຽມ/)). ແບບຈຳລອງຄຸນຄ່າຂອງທໍ່ຂ້າງເທິງແມ່ນຕົວສ້າງເຫດຜົນທາງທຸລະກິດສຳລັບທັງສອງ: ຄູນປັດໄຈຕ່າງໆ, ຫາຂໍ້ຈຳກັດ, ແລ້ວຕີລາຄາການແກ້ໄຂທຽບກັບຄຸນຄ່າຂອງປະຊາກອນທີ່ມັນປົດປ່ອຍອອກມາ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ນິຍາມການເປີດໃຊ້ງານຕາມຄວາມສະດວກ** (ຢືນຢັນອີເມວແລ້ວ) ແທນທີ່ຈະຕາມຄວາມໝາຍທາງຄລີນິກ (ການກະທຳເພື່ອການປິ່ນປົວຄັ້ງທຳອິດ) — ເຮັດໃຫ້ຕົວຊີ້ວັດສູງເກີນຈິງ ແລະ ທຳລາຍຕ່ອງໂສ້ຄຸນຄ່າ.
- **ການຫຼິ້ນກົນກັບຕົວຫານຂອງການຮັບເອົາໄປໃຊ້**: "ຈາກຜູ້ທີ່ເຂົ້າເບິ່ງເວັບໄຊ" ທຽບກັບປະຊາກອນທີ່ມີສິດຈິງໆ — ຜູ້ຊື້ບໍລິການໃສ່ໃຈຕົວຫຼັງ.
- **ຜົນຈາກການຄັດເລືອກ**: ຜູ້ໃຊ້ທີ່ເປີດໃຊ້ງານງ່າຍແມ່ນຜູ້ທີ່ເຈັບປ່ວຍໜ້ອຍທີ່ສຸດ ແລະ ຂາດແຄນໜ້ອຍທີ່ສຸດ; ການປັບປຸງທໍ່ອາດເຮັດໃຫ້ຊ່ອງຫວ່າງຄວາມເທົ່າທຽມກວ້າງຂຶ້ນ ໃນຂະນະທີ່ຄ່າສະເລ່ຍດີຂຶ້ນ.
