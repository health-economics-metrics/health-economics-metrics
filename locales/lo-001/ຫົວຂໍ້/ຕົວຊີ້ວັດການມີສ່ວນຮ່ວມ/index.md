# ຕົວຊີ້ວັດການມີສ່ວນຮ່ວມ

ຕົວຊີ້ວັດການມີສ່ວນຮ່ວມວັດວ່າຜູ້ໃຊ້ໃຊ້ແອັບສຸຂະພາບແທ້ໆຫຼາຍປານໃດ: ຄວາມຕິດໃຊ້ DAU/MAU, ຄວາມຖີ່ແລະໄລຍະເວລາຂອງເຊດຊັນ, ການໃຊ້ຄຸນສົມບັດ. ໃນສຸຂະພາບດິຈິຕອນ ການມີສ່ວນຮ່ວມບໍ່ແມ່ນເພື່ອຄວາມງາມ — ມັນແມ່ນ**ປະລິມານ (dose)**: ການໄດ້ຮັບທີ່ຜົນທາງຄລີນິກໃດໆຕ້ອງໄຫຼຜ່ານ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຢາທີ່ຢູ່ໃນຂວດບໍ່ປິ່ນປົວໃຜ; ແອັບທີ່ບໍ່ຖືກຕິດຕັ້ງຫຼືບໍ່ເປີດແມ່ນຮູບແບບຄວາມລົ້ມເຫຼວດຽວກັນ. ທຸກຂໍ້ອ້າງດ້ານເສດຖະສາດສຸຂະພາບຂອງຜະລິດຕະພັນສຸຂະພາບຜູ້ບໍລິໂພກຄູນຜ່ານການມີສ່ວນຮ່ວມ — ປະສິດທິຜົນ (efficacy) ທີ່ສະແດງໃນການທົດລອງຖືກວັດທີ່ລະດັບການໃຊ້ໃດໜຶ່ງ ແລະ ຄຸນຄ່າໃນໂລກຈິງຂະຫຍາຍຕາມວ່າການໃຊ້ໃນການນຳໃຊ້ໃກ້ລະດັບນັ້ນເທົ່າໃດ. ເກນທຽບຜະລິດຕະພັນມາດຕະຖານ: DAU/MAU ປະມານ **20% ຖືວ່າດີ** ສຳລັບແອັບມືຖືທົ່ວໄປ, >25% ໂດດເດັ່ນ; ແອັບສຸຂະພາບມັກຕ່ຳກວ່າ.

## ຄະນິດສາດ

```
Stickiness (DAU/MAU) = daily active users / monthly active users × 100
Session metrics      = sessions/user/period; avg duration = total time / sessions
Feature engagement   = users performing key action / active users

Dose-response framing (the health-economics upgrade):
  realized effect ≈ trial effect × f(actual usage / trial usage)
  where f comes from dose-response analysis — see the "effective
  engagement" concept in adherence-and-persistence.md: enough usage
  to achieve the intended outcome, which may be modest and finite
```

## ຕົວຢ່າງການຄິດໄລ່

ການສຶກສາສຳຄັນຂອງແອັບຄວາມດັນເລືອດສະແດງການຫຼຸດຄວາມດັນ systolic 6 mmHg ໃນບັນດາຜູ້ໃຊ້ທີ່ບັນທຶກຄ່າອ່ານ ≥4 ຄັ້ງ/ອາທິດ. ໃນການນຳໃຊ້ກັບຜູ້ໃຊ້ທີ່ລົງທະບຽນ 50,000 ຄົນ:

```
MAU 20,000 (40%); of those, logging ≥4×/week: 7,000
Effective-dose users = 7,000 / 50,000 = 14% of the registered base

Population-level effect ≈ trial effect delivered to 14%, not 100%:
any economic model quoting "50,000 users × 6 mmHg" overstates ~7×.
Honest model: 7,000 × full effect + partial credit (from dose-response
data, if any) for the 13,000 sub-threshold users.
```

ການຄູນນີ້ — ຜ່ານທໍ່ການມີສ່ວນຮ່ວມໄປຫາປະລິມານທີ່ມີປະສິດທິຜົນ — ແມ່ນບ່ອນດຽວທີ່ພົບທົ່ວໄປທີ່ສຸດທີ່ເສດຖະສາດສຸຂະພາບດິຈິຕອນສູງເກີນຈິງ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ວິສະວະກອນເປັນເຈົ້າຂອງທໍ່ການມີສ່ວນຮ່ວມ ເຊິ່ງເຮັດໃຫ້ພວກເຂົາເປັນເຈົ້າຂອງຕົວແປ*ທາງຄລີນິກ*: ແຮງຕ້ານຕອນເລີ່ມໃຊ້, ຍຸດທະສາດການແຈ້ງເຕືອນ, ເວລາໂຫຼດ, ແລະ ຄວາມທົນທານຕອນອອບລາຍ ລ້ວນເຄື່ອນປະລິມານທີ່ສົ່ງມອບ. ສອງຜົນຕໍ່ການອອກແບບ: ຕິດຕັ້ງການວັດ**ການກະທຳທີ່ມີຄວາມໝາຍທາງຄລີນິກ** (ຄ່າອ່ານທີ່ບັນທຶກ, ບົດຮຽນທີ່ຈົບ) ບໍ່ແມ່ນການເປີດ — DAU ທີ່ສ້າງຈາກເຊດຊັນທີ່ເດັ້ງຈາກການແຈ້ງເຕືອນແມ່ນການສໍ້ໂກງປະລິມານ; ແລະ ຖືເປົ້າໝາຍການມີສ່ວນຮ່ວມເປັນເປົ້າໝາຍ*ຄວາມພຽງພໍ* ບໍ່ແມ່ນການເພີ່ມສູງສຸດ — ແອັບທີ່ບັນລຸຜົນລັບໃນ 5 ນາທີ/ອາທິດແລະຖອຍອອກຈາກທາງແມ່ນດີເລີດທາງຄລີນິກແຕ່ "ຕ່ຳ" ທາງຕົວຊີ້ວັດ (ເບິ່ງການມີສ່ວນຮ່ວມທີ່ມີປະສິດທິຜົນໃນ[ການປະຕິບັດຕາມ ແລະ ຄວາມຕໍ່ເນື່ອງ](../ການປະຕິບັດຕາມ-ແລະ-ຄວາມຕໍ່ເນື່ອງ/)). ຕີມູນຄ່າວຽກການມີສ່ວນຮ່ວມເອງດ້ວຍແບບຈຳລອງຜົນຕໍ່ປະຊາກອນຂ້າງເທິງ: ກຳໄລ 2 ຈຸດໃນສ່ວນແບ່ງປະລິມານທີ່ມີປະສິດທິຜົນແມ່ນແຖວ QALY ທີ່ວັດໄດ້.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການມີສ່ວນຮ່ວມເປັນຜົນລັບ**: ການໃຊ້ແມ່ນວິທີ; ຜົນລັບແມ່ນ[PROM](../ຜົນລັບທີ່ຜູ້ປ່ວຍລາຍງານ/) ຫຼື ຈຸດສິ້ນສຸດທາງຄລີນິກ.
- **ຄ່າສະເລ່ຍຂອງການໃຊ້ແບບສອງຍອດ**: ປະຊາກອນແອັບສຸຂະພາບແບ່ງເປັນຜູ້ໃຊ້ທີ່ອຸທິດຕົນແລະຜີ; ຄ່າສະເລ່ຍບັນຍາຍບໍ່ແມ່ນໃຜ — ແຍກເປັນກຸ່ມ.
- **ການເພີ່ມປະລິມານດ້ວຍ dark-pattern**: streaks ແລະ ການແຈ້ງເຕືອນສ້າງຄວາມຮູ້ສຶກຜິດເພີ່ມຕົວຊີ້ວັດແລະອາດເປັນອັນຕະລາຍຕໍ່ປະຊາກອນທີ່ກັງວົນທີ່ແອັບສຸຂະພາບຮັບໃຊ້; ຜະລິດຕະພັນທາງຄລີນິກມີຈັນຍາບັນທາງຄລີນິກ.
- **ທີ່ມາຂອງເກນທຽບຂອງຜູ້ຂາຍ**: ເກນທຽບການມີສ່ວນຮ່ວມທີ່ເຜີຍແຜ່ສ່ວນໃຫຍ່ມາຈາກຜູ້ຂາຍການວິເຄາະ ບໍ່ແມ່ນການທົບທວນໂດຍເພື່ອນຮ່ວມວິຊາຊີບ; ປັບທຽບກັບການທົດລອງຂອງທ່ານເອງ.
