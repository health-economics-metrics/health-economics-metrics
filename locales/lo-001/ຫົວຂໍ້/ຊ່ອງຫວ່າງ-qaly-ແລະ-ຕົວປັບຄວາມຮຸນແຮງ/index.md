# ຊ່ອງຫວ່າງ QALY ແລະ ຕົວປັບຄວາມຮຸນແຮງ

ຊ່ອງຫວ່າງ QALY ວັດວ່າພະຍາດເອົາສຸຂະພາບໃນອະນາຄົດຈາກຜູ້ປ່ວຍຫຼາຍປານໃດທຽບກັບປະຊາກອນທົ່ວໄປ. NICE ໃຊ້ມັນເພື່ອນຳໃຊ້ **ຕົວປັບຄວາມຮຸນແຮງ**: ປະຊາກອນຍິ່ງເຈັບປ່ວຍຫຼາຍ, ແຕ່ລະ QALY ທີ່ໄດ້ຍິ່ງມີຄ່າຫຼາຍ — ສູງສຸດ 1.7× ຂອງເກນມາດຕະຖານ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ນັບແຕ່ຄູ່ມື NICE ປີ 2022, ຄວາມຮຸນແຮງເປັນຕົວຄູນຊັດເຈນຕໍ່ມູນຄ່າຂອງຜົນໄດ້ຮັບດ້ານສຸຂະພາບ, ແທນທີ່ສ່ວນເພີ່ມທ້າຍຊີວິດເກົ່າ. ເຕັກໂນໂລຢີສຳລັບສະພາບຮຸນແຮງຖືກຕັດສິນທຽບກັບເກນປະສິດທິຜົນສູງເຖິງ ~£51,000/QALY ແທນ £30,000. ຖ້າຊອບແວຂອງທ່ານໃຫ້ບໍລິການປະຊາກອນທີ່ໄດ້ຮັບຜົນກະທົບຮຸນແຮງ (ຫົວໃຈລົ້ມເຫຼວຂັ້ນສູງ, ພະຍາດຈິດຮຸນແຮງ), ຕົວປັບຄວາມຮຸນແຮງສາມາດເປັນຄວາມແຕກຕ່າງລະຫວ່າງກໍລະນີເສດຖະກິດທີ່ໄດ້ທຶນ ແລະ ບໍ່ໄດ້ທຶນ — ແລະ ທ່ານຕ້ອງການເລກຊ່ອງຫວ່າງເພື່ອອ້າງມັນ.

## ຄະນິດສາດ

ສອງມາດຕະການ, ຄິດໄລ່ຕະຫຼອດອາຍຸທີ່ເຫຼືອດ້ວຍມາດຕະຖານການດູແລປັດຈຸບັນ:

```
Absolute shortfall     = QALYs_general_population − QALYs_with_condition
Proportional shortfall = Absolute shortfall / QALYs_general_population
```

ນ້ຳໜັກ NICE 2022 (ມາດຕະການໃດໃຫ້ນ້ຳໜັກສູງກວ່າຈະນຳໃຊ້):

```
Weight ×1.0: absolute < 12 and proportional < 0.85
Weight ×1.2: absolute ≥ 12 or proportional ≥ 0.85
Weight ×1.7: absolute ≥ 18 or proportional ≥ 0.95
```

ນ້ຳໜັກຄູນ ΔE (ຫຼື ເທົ່າກັນຄືຄູນເກນ): λ ປະສິດທິຜົນກາຍເປັນ £24k–£36k ທີ່ ×1.2 ແລະ £34k–£51k ທີ່ ×1.7.

## ຕົວຢ່າງການຄິດໄລ່

ຜູ້ປ່ວຍທີ່ມີພະຍາດຮຸກຮານ, ອາຍຸສະເລ່ຍ 60 ປີ. ປະຊາກອນທົ່ວໄປທີ່ອາຍຸ 60 ຄາດ 14.2 QALY ຫຼຸດມູນຄ່າ; ມີພະຍາດພາຍໃຕ້ການດູແລປັດຈຸບັນ, 2.1.

```
Absolute shortfall     = 14.2 − 2.1 = 12.1  (≥ 12 → qualifies for ×1.2)
Proportional shortfall = 12.1 / 14.2 = 0.852 (≥ 0.85 → also ×1.2)
```

ICER ຂອງແພລດຟອມຕິດຕາມຂອງທ່ານແມ່ນ £26,000/QALY — ສູງກວ່າຈຸດກາງ £20k–£30k ມາດຕະຖານ, ຢູ່ຂອບ. ດ້ວຍນ້ຳໜັກ ×1.2: ICER ປະສິດທິຜົນ = 26,000 / 1.2 ≈ **£21,700/QALY** — ໄດ້ທຶນຢ່າງສະບາຍ. ການຄິດໄລ່ຊ່ອງຫວ່າງຍ້າຍການຕັດສິນໃຈ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ການຖ່ວງນ້ຳໜັກຄວາມຮຸນແຮງແມ່ນຮຸ່ນທາງການຂອງສິ່ງທີ່ອົງກອນວິສະວະກຳເຮັດຕາມສະຕິປັນຍາ: ໃຊ້ຈ່າຍຫຼາຍຂຶ້ນຕໍ່ຫົວໜ່ວຍການປັບປຸງໃນລະບົບທີ່ແຍ່ທີ່ສຸດ. ແບບແຜນທີ່ໂອນໄດ້ — ຄິດໄລ່ "ຊ່ອງຫວ່າງ SLO" ຂອງແຕ່ລະບໍລິການ (ມັນດຳເນີນຕ່ຳກວ່າເສັ້ນຖານທີ່ຄາດໄວ້ຢ່າງສຸຂະພາບດີເທົ່າໃດ, ທັງສົມບູນ ແລະ ສັດສ່ວນ), ແລະ ຖ່ວງນ້ຳໜັກມູນຄ່າການແກ້ໄຂຕາມນັ້ນ. ນີ້ຊອບທຳ, ດ້ວຍເລກຄະນິດແທນການໂຕ້ຖຽງ, ວ່າເປັນຫຍັງລະບົບເກົ່າທີ່ກຳລັງໄໝ້ໄດ້ຮັບການລົງທຶນຕໍ່ຊົ່ວໂມງທີ່ປະຢັດຫຼາຍກວ່າລະບົບທີ່ສຸຂະພາບດີ. ມັນຍັງມີບົດຮຽນການກຳກັບດູແລດຽວກັນ: ເຜີຍແຜ່ນ້ຳໜັກ *ກ່ອນ* ກອງປະຊຸມຈັດລຳດັບຄວາມສຳຄັນ, ບໍ່ດັ່ງນັ້ນທຸກທີມອ້າງຄວາມຮຸນແຮງ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຄິດໄລ່ຊ່ອງຫວ່າງທຽບກັບເສັ້ນຖານທີ່ຜິດ**: ມັນວັດພາຍໃຕ້ *ມາດຕະຖານການດູແລປັດຈຸບັນ*, ບໍ່ແມ່ນປະຫວັດທຳມະຊາດທີ່ບໍ່ໄດ້ຮັບການຮັກສາ.
- **ຄວາມອ່ອນໄຫວຕໍ່ອາຍຸ**: ຊ່ອງຫວ່າງຂຶ້ນກັບອາຍຸປະຊາກອນຢ່າງຫຼາຍ (ຜູ້ປ່ວຍໜຸ່ມມີ QALY ຫຼາຍກວ່າທີ່ຈະສູນເສຍ → ຊ່ອງຫວ່າງສົມບູນສູງກວ່າ); ໃຊ້ການແຈກຢາຍອາຍຸຂອງປະຊາກອນທີ່ຖືກຮັກສາຈິງ.
- **ສົມມຸດວ່າຕົວປັບນຳໃຊ້ບ່ອນອື່ນ** — ມັນເປັນກົນໄກຂອງ NICE (ອັງກິດ); ອົງກອນ HTA ອື່ນຈັດການຄວາມຮຸນແຮງແຕກຕ່າງ (ຫຼື ບໍ່ເລີຍ).
