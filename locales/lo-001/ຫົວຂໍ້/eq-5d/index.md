# EQ-5D

EQ-5D ແມ່ນແບບສອບຖາມມາດຕະຖານຂອງກຸ່ມ EuroQol ສຳລັບວັດຄຸນນະພາບຊີວິດທີ່ກ່ຽວຂ້ອງກັບສຸຂະພາບ. ມັນແມ່ນເຄື່ອງມືທີ່ສ້າງນ້ຳໜັກອຣະຖະປະໂຫຍດພາຍໃນການຄິດໄລ່[QALY](../ປີຊີວິດທີ່ປັບດ້ວຍຄຸນນະພາບ/)ສ່ວນໃຫຍ່ — ກໍລະນີອ້າງອີງຂອງ NICE ລະບຸມັນເປັນມາດຕະການທີ່ຕ້ອງການສຳລັບຜູ້ໃຫຍ່.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຜະລິດຕະພັນສຸຂະພາບດິຈິຕອນໃດທີ່ຢາກອ້າງ QALY ຕ້ອງການອຣະຖະປະໂຫຍດຈາກເຄື່ອງມືທີ່ຢືນຢັນແລ້ວ ແລະ EQ-5D ເປັນຄ່າເລີ່ມຕົ້ນໃນອັງກິດແລະຢູໂຣບສ່ວນໃຫຍ່. ມັນສັ້ນພໍທີ່ຝັງໃນແອັບໄດ້ (5 ຄຳຖາມ + ມາດຕາພາບ) ໝາຍຄວາມວ່າຜະລິດຕະພັນຊອບແວສາມາດເກັບຂໍ້ມູນຜົນລັບລະດັບ HTA ເປັນຜົນຂ້າງຄຽງຂອງການໃຊ້ປົກກະຕິ — ຂໍ້ໄດ້ປຽບດ້ານໂຄງສ້າງເໜືອຢາ ທີ່ຕ້ອງການການສຶກສາສະເພາະ.

## ຄະນິດສາດ

EQ-5D-5L ຖາມໜຶ່ງຄຳຖາມໃນແຕ່ລະ **5 ມິຕິ** — ການເຄື່ອນໄຫວ, ການດູແລຕົນເອງ, ກິດຈະກຳປົກກະຕິ, ຄວາມເຈັບປວດ/ບໍ່ສະບາຍ, ຄວາມກັງວົນ/ຊຶມເສົ້າ — ແຕ່ລະອັນຕອບໃນ **5 ລະດັບ** (ບໍ່ມີບັນຫາ … ບັນຫາຮ້າຍແຮງທີ່ສຸດ), ບວກມາດຕາພາບ 0–100 (EQ VAS).

```
Health state = 5-digit profile, e.g. "21221"
Utility index = value_set(profile)

The value set is country-specific, derived from time-trade-off /
discrete-choice surveys of the general public. Anchors: 1 = full health,
0 = dead; states worse than death are negative (UK 3L set floor: −0.594).
```

ຈາກນັ້ນເລກ QALY ດຳເນີນເປັນ `duration × utility`.

## ຕົວຢ່າງການຄິດໄລ່

ແອັບຟື້ນຟູກະດູກກ້າມເນື້ອວັດ EQ-5D-5L ຕອນເລີ່ມແລະທີ 6 ເດືອນສຳລັບຜູ້ໃຊ້ທີ່ຈົບ 1,000 ຄົນ.

```
Mean utility at baseline:  0.62
Mean utility at 6 months:  0.71
Gain sustained (assume) 1 year: (0.71 − 0.62) × 1.0 = 0.09 QALYs per user
```

ທຽບກັບການປ່ຽນແປງຂອງກຸ່ມຄວບຄຸມ 0.03 (ການຟື້ນຕົວຕາມທຳມະຊາດ) ກຳໄລທີ່ເຊື່ອມໂຍງໄດ້ແມ່ນ 0.06 QALY/ຜູ້ໃຊ້. ແປງເປັນເງິນທີ່ £20,000–£30,000/QALY: **£1,200–£1,800 ຂອງມູນຄ່າສຸຂະພາບຕໍ່ຜູ້ໃຊ້ທີ່ຈົບ** — ຕົວເລກທີ່ຢຶດການເຈລະຈາລາຄາຂອງແອັບກັບຜູ້ຈ່າຍເງິນ. (ຄວາມແຕກຕ່າງທີ່ສຳຄັນທາງຄລີນິກຕ່ຳສຸດສຳລັບດັດຊະນີ EQ-5D ມັກຢູ່ໃນຊ່ວງ 0.03–0.08 ດັ່ງນັ້ນ 0.06 ເປັນໄປໄດ້ແຕ່ຕ້ອງຜ່ານການປຽບທຽບກຸ່ມຄວບຄຸມ; ເບິ່ງ[ຜົນລັບທີ່ລາຍງານໂດຍຄົນເຈັບ](../ຜົນລັບທີ່ຜູ້ປ່ວຍລາຍງານ/).)

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

- **ຕິດຕັ້ງການວັດ.** EQ-5D ຕອນສະໝັກແລະຊ່ວງຕິດຕາມແມ່ນສອງສາມໜ້າຈໍ UI; ຜົນຕອບແທນແມ່ນຫຼັກຖານລະດັບ HTA. ຂໍໃບອະນຸຍາດຈາກ EuroQol (ຈຳເປັນ, ຟຣີສຳລັບບາງການນຳໃຊ້).
- **ໃຊ້ຊຸດມູນຄ່າທີ່ຖືກຕ້ອງ** ສຳລັບປະເທດທີ່ນຳໃຊ້ — ຄຳຕອບດຽວກັນໃຫ້ຄະແນນຕ່າງກັນໃນອັງກິດ ທຽບເຢຍລະມັນ ທຽບຍີ່ປຸ່ນ.
- **ບົດຮຽນການອອກແບບ**: EQ-5D ສະແດງວ່າການສຳຫຼວດມາດຕະຖານນ້ອຍໆບວກຟັງຊັນໃຫ້ຄະແນນທີ່ເຜີຍແຜ່ ໃຫ້ດັດຊະນີດຽວທີ່ປຽບທຽບໄດ້. ນັ້ນແມ່ນແບບແຜນສຳລັບດັດຊະນີປະສົບການນັກພັດທະນາທີ່ໜ້າເຊື່ອຖືເຊັ່ນກັນ — ເຄື່ອງມືມາດຕະຖານ, ນ້ຳໜັກທີ່ເຜີຍແຜ່ ບໍ່ແມ່ນຄວາມຮູ້ສຶກແບບ ad hoc. ເບິ່ງ[SPACE ແລະ DevEx](../space-ແລະ-devex/).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ກ່ອນ/ຫຼັງໂດຍບໍ່ມີຕົວປຽບທຽບ** — ການຖອຍເຂົ້າຫາຄ່າສະເລ່ຍແລະການຟື້ນຕົວຕາມທຳມະຊາດເຮັດໃຫ້ກຳໄລແບບງ່າຍສູງເກີນຈິງ.
- **ຄວາມລຳອຽງຜູ້ລອດຊີວິດ**: ວັດສະເພາະຜູ້ໃຊ້ທີ່ຍັງມີສ່ວນຮ່ວມ (ເບິ່ງ[ການຮັກສາຜູ້ໃຊ້ ແລະ ການເລີກໃຊ້](../ການຮັກສາຜູ້ໃຊ້-ແລະ-ການຫຼຸດຫາຍ/)).
- **ປົນເວີຊັນ 3L ແລະ 5L ຫຼື ຊຸດມູນຄ່າ** ຂ້າມການສຶກສາ — ຕົວເລກຕ່າງກັນຢ່າງເປັນລະບົບ.
- **ຜົນເພດານ** ໃນປະຊາກອນທີ່ໄດ້ຮັບຜົນກະທົບເບົາ: ຜູ້ໃຊ້ຫຼາຍຄົນໄດ້ຄະແນນໃກ້ 1.0 ຕອນເລີ່ມ ບໍ່ເຫຼືອບ່ອນສະແດງກຳໄລ.
- **ຖືຊຸດມູນຄ່າວ່າຮັບປະກັນຕົນເອງ**: ຕົວເລກອຣະຖະປະໂຫຍດທີ່ຊຸດມູນຄ່າສົ່ງຄືນເອງຖືກສະກັດຈາກສາທາລະນະຜ່ານການສຳຫຼວດ time-trade-off (ຫຼືການເລືອກທີ່ກ່ຽວຂ້ອງ) — ເບິ່ງ[ການສະກັດອຣະຖະປະໂຫຍດດ້ວຍການແລກປ່ຽນເວລາ (TTO)](../ການດຶງຄ່າປະໂຫຍດດ້ວຍການແລກປ່ຽນເວລາ/) ສຳລັບວິທີ.
