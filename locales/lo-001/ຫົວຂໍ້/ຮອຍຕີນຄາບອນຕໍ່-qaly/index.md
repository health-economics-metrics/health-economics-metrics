# ຮອຍຕີນຄາບອນຕໍ່ QALY

ຄາບອນຕໍ່ QALY ແມ່ນອັດຕາສ່ວນປະສິດທິພາບ — ການປ່ອຍຄາບອນຂອງການແຊກແຊງ (ຫຼື ການປ່ອຍທີ່ຫຼີກລ່ຽງໄດ້) ຫານດ້ວຍ QALY ທີ່ມັນສົ່ງມອບ — ຄ້າຍຄືກັບຕົ້ນທຶນຕໍ່ QALY ໂດຍກົງ ເຮັດໃຫ້ປະເມີນປະສິດທິພາບດ້ານຄາບອນຂອງການແຊກແຊງຄຽງຄູ່ປະສິດທິພາບດ້ານຕົ້ນທຶນ. "ຜົນປະໂຫຍດສຸດທິເປັນເງິນທີ່ປັບຄາບອນ" ກ້າວໄປອີກຂັ້ນ ໂດຍແປງຜົນກະທົບຄາບອນເປັນເງິນດ້ວຍຄ່າຄາບອນທີ່ບໍ່ຊື້ຂາຍຢ່າງເປັນທາງການຂອງ UK Green Book ແລ້ວຫັກລົບກັບ[ຜົນປະໂຫຍດສຸດທິເປັນເງິນ](../ຜົນປະໂຫຍດເປັນເງິນສຸດທິ/)ມາດຕະຖານ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ປັດຈຸບັນ NICE ແລະ NHS England ຄາດຫວັງໃຫ້ພິຈາລະນາຜົນກະທົບດ້ານສິ່ງແວດລ້ອມຄຽງຄູ່ຕົ້ນທຶນແລະ QALY. NHS ມີຄຳໝັ້ນສັນຍາສາທາລະນະເລື່ອງ net-zero: net zero ສຳລັບການປ່ອຍໂດຍກົງພາຍໃນປີ 2040, ແລະ net zero ສຳລັບຮອຍຕີນຂອງຕ່ອງໂສ້ອຸປະທານທັງໝົດພາຍໃນປີ 2045. ຄູ່ມືການປະເມີນເຕັກໂນໂລຢີສຸຂະພາບຂອງ NICE (PMG36) ອ້າງເຖິງຄວາມຍືນຍົງດ້ານສິ່ງແວດລ້ອມເປັນການພິຈາລະນາທີ່ກຳລັງເກີດຂຶ້ນໃນການປະເມີນເຕັກໂນໂລຢີ. ສຳລັບຜະລິດຕະພັນສຸຂະພາບດິຈິຕອນ ນີ້ໝາຍຄວາມວ່າຄາບອນກຳລັງກາຍເປັນເສົາຫຼັກທີສີ່ຂອງກໍລະນີຄຸນຄ່າ ຄຽງຄູ່ຕົ້ນທຶນ, QALY, ແລະ [ຄວາມເໜືອກວ່າເທິງຂອບເຂດປະສິດທິພາບ](../ຄວາມເໜືອກວ່າ-ແລະ-ຂອບເຂດປະສິດທິພາບ/) — ບໍ່ແມ່ນການແທນທີ່ອັນໃດ ແຕ່ເປັນມິຕິທີ່ກໍລະນີທຸລະກິດທີ່ສ້າງດີຕ້ອງລາຍງານຫຼາຍຂຶ້ນ.

## ຄະນິດສາດ

```
Carbon per QALY = total_emissions_tonnes_co2e / total_qalys
  (a negative value means net emissions AVOIDED per QALY gained — a
  double win: better health and lower carbon)

Monetized carbon impact = emissions_tonnes_co2e × carbon_value_per_tonne
  (negative emissions × positive value = a negative cost, i.e. a benefit)

Carbon-adjusted NMB = net_monetary_benefit − monetized_carbon_impact
```

ນີ້ຂະຫຍາຍແນວຄິດຂອບເຂດປະສິດທິພາບຕົ້ນທຶນ/QALY ດ້ວຍແກນທີສອງ — ຄາບອນຕໍ່ QALY — ເຫດຜົນ "ພລອດທຸກທາງເລືອກແລ້ວເບິ່ງວ່າອັນໃດຖືກເໜືອກວ່າ" ດຽວກັນກັບ[ຄວາມເໜືອກວ່າ ແລະ ຂອບເຂດປະສິດທິພາບ](../ຄວາມເໜືອກວ່າ-ແລະ-ຂອບເຂດປະສິດທິພາບ/) ແຕ່ນຳໃຊ້ກັບຄາບອນແທນຕົ້ນທຶນ.

## ຕົວຢ່າງການຄິດໄລ່

ບໍລິການສຸຂະພາບທາງໄກທົດແທນການມາພົບໜ້າ ຫຼີກລ່ຽງການເດີນທາງດ້ວຍລົດ 5,000 ເທື່ອ/ປີ ປະມານ 8kg CO2e ຕໍ່ເທື່ອ — ຫຼີກລ່ຽງ CO2e 40 ໂຕນ, ສະແດງເປັນຕົວເລກການປ່ອຍຕິດລົບ (−40.0 ໂຕນ), ແລະ ສົ່ງມອບ 25 QALY/ປີ:

```
Carbon per QALY = −40.0 / 25.0 = −1.6 tonnes CO2e avoided per QALY gained
```

ໃຊ້ຄ່າຄາບອນທີ່ບໍ່ຊື້ຂາຍຂອງ Green Book (ຕົວເລກປະກອບ, ຄ່າກາງທີ່ບໍ່ຊື້ຂາຍປີ 2023 ≈ £269/ໂຕນ CO2e — Green Book ອັບເດດຄ່າຄາບອນທຸກປີ, ກວດສອບໃໝ່ກ່ອນອ້າງໃນການວິເຄາະຈິງ):

```
Monetized carbon impact = −40.0 × £269 = −£10,760
```

"ຕົ້ນທຶນ" −£10,760 ຄືຜົນປະໂຫຍດ £10,760. ຖ້າຜົນປະໂຫຍດສຸດທິເປັນເງິນດ່ຽວຂອງການແຊກແຊງແມ່ນ £500,000:

```
Carbon-adjusted NMB = £500,000 − (−£10,760) = £510,760
```

ການປະຢັດຄາບອນເພີ່ມເຂົ້າກໍລະນີ ແທນທີ່ຈະຫຼຸດ — ຊະນະສອງຕໍ່ ທີ່ການກຳນົດກອບການປ່ອຍຕິດລົບຕັ້ງໃຈໃຫ້ເຫັນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ນີ້ແມ່ນຈຸດຕັດກັນທີ່ເປັນປັດຈຸບັນກັບເສດຖະສາດ AI/ຄລາວ: ຮອຍຕີນຄາບອນຂອງການຄຳນວນໃນການຝຶກແລະເປີດໃຊ້ແບບຈຳລອງ AI ຕອນນີ້ເປັນລາຍການຈິງໃນການຈັດຊື້ຂອງ NHS ເນື່ອງຈາກສັນຍາຜູ້ສະໜອງ NHS ເໜືອເກນໃດໜຶ່ງຕ້ອງມີ Carbon Reduction Plan. [ເສດຖະສາດຫົວໜ່ວຍຂອງຄລາວ](../ເສດຖະສາດຫົວໜ່ວຍຂອງຄລາວ/)ຕິດຕາມຕົ້ນທຶນຕໍ່ຫົວໜ່ວຍຜົນຜະລິດການຄຳນວນຢູ່ແລ້ວ; ຄາບອນຕໍ່ QALY ແມ່ນແມ່ແບບທຳມະຊາດສຳລັບຕົວຊີ້ວັດ "ຕົ້ນທຶນຄາບອນຕໍ່ການອະນຸມານ" ໃນອະນາຄົດທີ່ຂະຫຍາຍໂມດູນນັ້ນແລະເສດຖະສາດຫົວໜ່ວຍຂອງການອະນຸມານໄປສູ່ມິຕິດ້ານສິ່ງແວດລ້ອມ ແຕ່ຕົວຊີ້ວັດນັ້ນຍັງບໍ່ມີ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການຫຼິ້ນກົນກັບຂອບເຂດ**: ນັບສະເພາະການປ່ອຍໂດຍກົງ (Scope 1) ແລະ ຍົກເວັ້ນການປ່ອຍຂອງຕ່ອງໂສ້ອຸປະທານ (Scope 3) ເຊິ່ງມັກເປັນສ່ວນໃຫຍ່ຂອງຮອຍຕີນຈິງຂອງຜະລິດຕະພັນສຸຂະພາບດິຈິຕອນ.
- **ໃຊ້ຄ່າຄາບອນທີ່ລ້າສະໄໝ**: Green Book ອັບເດດຄ່າຄາບອນທີ່ບໍ່ຊື້ຂາຍທຸກປີ ດັ່ງນັ້ນຕົວເລກ £/ໂຕນໃດໆທີ່ອ້າງຕ້ອງລະບຸວັນທີ່ ບໍ່ແມ່ນອ້າງເປັນຄ່າຄົງທີ່.
- **ຖື "ປະສິດທິພາບຄາບອນ" ເປັນຕົວແທນຂອງ "ຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ"**: ການແຊກແຊງທີ່ຄາບອນຕ່ຳ ຄຸນຄ່າຕ່ຳ ຍັງເປັນການໃຊ້ຊັບພະຍາກອນ NHS ທີ່ບໍ່ດີ. ຄາບອນເປັນເສົາຫຼັກທີສີ່ຄຽງຄູ່ຕົ້ນທຶນແລະ QALY ບໍ່ແມ່ນການແທນທີ່ອັນໃດ.
