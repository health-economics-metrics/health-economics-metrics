# ຄວາມຈຸໃນການສ້າງມູນຄ່າ (ການຫັນປ່ຽນການດຳເນີນງານ)

ຄວາມຈຸໃນການສ້າງມູນຄ່າແມ່ນ "ຜົນປະໂຫຍດຈາກໂອກາດ" ຂອງເວລາທີ່ປົດປ່ອຍ: ສິ່ງທີ່ໂຮງໝໍສາມາດ *ບັນລຸ* ໄດ້ດຽວນີ້ດ້ວຍຊົ່ວໂມງທີ່ຊອບແວຂອງທ່ານປົດປ່ອຍ. ນີ້ແມ່ນຕົວຊີ້ວັດທີ່ສຳຄັນທີ່ສຸດຕໍ່ຜູ້ອຳນວຍການດ້ານການດຳເນີນງານ (COO) ແລະ ຜູ້ອຳນວຍການການແພດ, ເພາະມັນເວົ້າໃນສະກຸນເງິນທີ່ພວກເຂົາຖືກບໍລິຫານ — ກິດຈະກຳ, ເປົ້າໝາຍ ແລະ ເວລາຫັນປ່ຽນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

NHS ປະເຊີນກັບການຄ້າງການສົ່ງຕໍ່ເຖິງການຮັກສາຢ່າງມະຫາສານ, ແລະ ທຣັສທີ່ພາດມາດຕະຖານເວລາລໍຖ້າແຫ່ງຊາດປະເຊີນການກວດກາ ແລະ ການແຊກແຊງຂອງຜູ້ຄວບຄຸມ (ເບິ່ງ [ການສົ່ງຕໍ່ເຖິງການຮັກສາ](../ການສົ່ງຕໍ່ເຖິງການຮັກສາ/)). ການຈ້າງຊ້າ ແລະ ຖືກຈຳກັດ; ສະຖານທີ່ຄົງທີ່. ຄັນໂຍກດຽວທີ່ໄວແມ່ນການໄດ້ກິດຈະກຳສ້າງມູນຄ່າຫຼາຍຂຶ້ນຈາກພະນັກງານ ແລະ ພື້ນທີ່ທີ່ມີຢູ່. ຊອບແວທີ່ເອົາເວລາແພດຊ່ຽວຊານຄືນບໍ່ພຽງແຕ່ "ປະຢັດເງິນ" — ມັນ *ຜະລິດຄວາມຈຸ*: ຄລີນິກທີ່ບໍ່ສາມາດມີໄດ້, ການປະເມີນທີ່ບໍ່ສາມາດຈັດຕາຕະລາງໄດ້, ໂດຍບໍ່ຈ້າງ ຫຼື ສ້າງ.

## ຄະນິດສາດ

```
Hidden capacity created = time released → activity units enabled × scheme value

Activity units: outpatient attendances, pre-op assessments, monitoring reviews
Scheme value:   national tariff / NHS Payment Scheme prices
                (see national-tariff-and-unit-costs.md)
```

ນີ້ແມ່ນການປະເມີນຕາມຜົນຜະລິດຂອງ [ເວລາຂອງຜູ້ປະຕິບັດວິຊາຊີບ](../ເວລາຂອງຜູ້ປະຕິບັດວິຊາຊີບ/), ຂະຫຍາຍເປັນສາຍບໍລິການ ແລະ ສະແດງເປັນຫົວໜ່ວຍກິດຈະກຳທີ່ທີມການດຳເນີນງານວາງແຜນຢູ່ແລ້ວ.

## ຕົວຢ່າງການຄິດໄລ່

ພະຍາບານຊ່ຽວຊານ Band 6 ດຳເນີນຄລີນິກປະເມີນກ່ອນຜ່າຕັດ. ການອັດຕະໂນມັດເອກະສານເອົາຄືນ 1 ຊົ່ວໂມງ/ວັນສຳລັບແຕ່ລະພະຍາບານ 25 ຄົນ; ແຕ່ລະຊົ່ວໂມງໃສ່ໄດ້ 2 ການປະເມີນ.

```
Extra assessments = 25 nurses × 2/day × 250 days = 12,500/year
At ~£120 scheme value per pre-op assessment:
  12,500 × £120 = £1.5M/year of care capacity created
```

— ໂດຍບໍ່ຈ້າງພະຍາບານຄົນດຽວ ຫຼື ສ້າງຫ້ອງດຽວ. (ແບບຈຳລອງທີ່ອ້າງຢ່າງກວ້າງຂວາງທີ່ stub ນີ້ອ້າງອີງແຕ່ເດີມໃຫ້ຕົວເລກ £766,920/ປີສຳລັບກຸ່ມນ້ອຍກວ່າ; ແບບແຜນເລກຄະນິດດຽວກັນ — ຕົວເລກຂະຫຍາຍຕາມພະຍາບານ × ຊ່ວງ × ອັດຕາ.) ກອບການດຳເນີນງານສຳລັບ COO: ການປະເມີນກ່ອນຜ່າຕັດຢຸດເປັນຂໍ້ຈຳກັດຂອງລາຍການຫ້ອງຜ່າຕັດ — ການຍົກເລີກການຜ່າຕັດໃນມື້ນັ້ນຫຼຸດລົງ, ແລະ ການນຳໃຊ້ຫ້ອງຜ່າຕັດເພີ່ມຂຶ້ນ, ເຊິ່ງເປັນບ່ອນທີ່ເສັ້ນຜົນປະໂຫຍດ *ຖັດໄປ* ເລີ່ມ (ເບິ່ງ [ການເພີ່ມປະສິດທິພາບຊັບພະຍາກອນຕໍ່ເນື່ອງ](../ການເພີ່ມປະສິດທິພາບຊັບພະຍາກອນຕໍ່ເນື່ອງ/)).

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ການຈັດກອບໃໝ່ດຽວກັນຊ່ວຍຊີວິດການອ້າງຜະລິດຕະພາບນັກພັດທະນາຈາກເລກຄ່າຈ້າງ: ເວລາວິສະວະກຳທີ່ປົດປ່ອຍ, ສະແດງເປັນ *ຄວາມສາມາດທີ່ສົ່ງມອບທີ່ອົງກອນບໍ່ສາມາດຈ່າຍໄດ້ຖ້າບໍ່ດັ່ງນັ້ນ* — ຄຸນສົມບັດ, ການຍ້າຍ, ງານຄວາມໜ້າເຊື່ອຖື — ປະເມີນດ້ວຍສິ່ງທີ່ອົງກອນຈ່າຍສຳລັບຄວາມສາມາດແບບນັ້ນທີ່ຂອບ (ອັດຕາຜູ້ຮັບເໝົາ, ຫຼື ທຽບເທົ່າການຈ້າງທີ່ເລື່ອນ). ກອບ COO ຍັງສອນບາງສິ່ງກ່ຽວກັບການນຳສະເໜີງານແພລດຟອມ: ສະແດງຜົນປະໂຫຍດໃນຫົວໜ່ວຍທີ່ຜູ້ຊົມຖືກບໍລິຫານ. ຜູ້ນຳດ້ານການດຳເນີນງານຄິດເປັນກິດຈະກຳ ແລະ ເປົ້າໝາຍ, ບໍ່ແມ່ນຊົ່ວໂມງນາມມະທຳ; ຜູ້ນຳວິສະວະກຳຄິດເປັນລາຍການແຜນງານ ແລະ ຈຳນວນພະນັກງານ, ບໍ່ແມ່ນນາທີທີ່ປະຢັດ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ອ້າງຄວາມຈຸໂດຍບໍ່ມີຄວາມຕ້ອງການ**: 12,500 ຊ່ອງການປະເມີນເພີ່ມສຳຄັນກໍຕໍ່ເມື່ອທໍ່ການຜ່າຕັດເຕີມມັນ — ກວດຂໍ້ຈຳກັດຕໍ່ເນື່ອງ.
- **ມູນຄ່າອັດຕາໂດຍບໍ່ມີກົນໄກການຈ່າຍ**: ພາຍໃຕ້ການຈ່າຍແບບປະສົມ, ກິດຈະກຳເພີ່ມອາດບໍ່ນຳລາຍໄດ້ເພີ່ມ; ມູນຄ່າອາດເປັນການຫຼຸດລາຍຊື່ລໍຖ້າແທນ (ເບິ່ງ [ຜົນກະທົບຕໍ່ລາຍຊື່ລໍຖ້າ](../ຜົນກະທົບຕໍ່ລາຍຊື່ລໍຖ້າ/)).
- **ນຳສະເໜີຄວາມຈຸເປັນເງິນສົດ** — ນີ້ແມ່ນຜົນປະໂຫຍດທີ່ບໍ່ປົດປ່ອຍເງິນສົດທີ່ເປັນໂຕແທນ; ຕິດປ້າຍມັນ (ເບິ່ງ [ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດ ທຽບກັບ ທີ່ບໍ່ປົດປ່ອຍເງິນສົດ](../ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດ-ທຽບກັບ-ທີ່ບໍ່ປົດປ່ອຍເງິນສົດ/)).
