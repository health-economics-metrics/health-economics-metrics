# ການວິເຄາະຕົ້ນທຶນ-ອຣະຖະປະໂຫຍດ (CUA)

CUA ແມ່ນການວິເຄາະຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນທີ່ມີ**ຜົນລັບທົ່ວໄປທີ່ຖ່ວງນ້ຳໜັກດ້ວຍຄວາມມັກ** — ເກືອບສະເໝີແມ່ນ[QALY](../ປີຊີວິດທີ່ປັບດ້ວຍຄຸນນະພາບ/) (ຫຼື [DALY](../ປີຊີວິດທີ່ປັບດ້ວຍຄວາມພິການ/) ທີ່ຫຼີກລ່ຽງ). ເພາະຫົວໜ່ວຍຜົນລັບເປັນສາກົນ CUA ຈຶ່ງປຽບທຽບການແຊກແຊງຂ້າມພະຍາດທີ່ແຕກຕ່າງກັນທັງໝົດໄດ້.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ບໍລິການສຸຂະພາບແຫ່ງຊາດຕ້ອງເລືອກລະຫວ່າງຢາມະເຮັງ, ແອັບສຸຂະພາບຈິດ, ແລະ ຫຸ່ນຍົນຜ່າຕັດຈາກງົບປະມານດຽວ. ຫົວໜ່ວຍທຳມະຊາດປຽບທຽບພວກມັນບໍ່ໄດ້; QALY ໄດ້. CUA ຈຶ່ງເປັນວິທີກໍລະນີອ້າງອີງຂອງ NICE ແລະ ອົງການ HTA ສ່ວນໃຫຍ່: ຜົນຜະລິດຂອງມັນ — ຕົ້ນທຶນຕໍ່ QALY ທີ່ຕັດສິນທຽບກັບ[ເກນ](../ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ/) — ແມ່ນສິ່ງທີ່ໃກ້ຄຽງທີ່ສຸດຂອງນະໂຍບາຍສຸຂະພາບຕໍ່ອັດຕາແລກປ່ຽນສາກົນ. ຖ້າທ່ານຢາກໃຫ້ຊອບແວຂອງທ່ານໄດ້ຮັບທຶນ*ແທນສິ່ງອື່ນ* CUA ແມ່ນສະໜາມ.

## ຄະນິດສາດ

```
ICUR = ΔCost / ΔQALYs      (the ICER with QALYs as the effect unit)

ΔQALYs = Σ (duration_i × utility_i)_new − Σ (duration_i × utility_i)_old
```

ອຣະຖະປະໂຫຍດຈາກເຄື່ອງມືທີ່ຢືນຢັນແລ້ວ ([EQ-5D](../eq-5d/)); ຕົ້ນທຶນແລະ QALY ທັງສອງ[ຫຼຸດມູນຄ່າ](../ການຫຼຸດມູນຄ່າ-ແລະ-ຄວາມມັກດ້ານເວລາ/)ທີ່ 3.5% (ກໍລະນີອ້າງອີງຂອງ NICE); ຄວາມບໍ່ແນ່ນອນຜ່ານ[PSA](../ການວິເຄາະຄວາມອ່ອນໄຫວແບບຄວາມນ່າຈະເປັນ/).

## ຕົວຢ່າງການຄິດໄລ່

ແອັບ CBT ສຳລັບຄວາມກັງວົນລະດັບປານກາງ ທຽບກັບລາຍຊື່ລໍຖ້າການປິ່ນປົວແບບພົບໜ້າ, ຕໍ່ຄົນເຈັບ:

```
Costs:  app licence + support        £250
        therapy displaced            −£680   (40% of users no longer need it)
        ΔC = 250 − 680 = −£430 (saves money)

QALYs:  6 months at utility 0.76 instead of 0.68 while waiting
        ΔE = 0.5 × (0.76 − 0.68) = +0.04 QALYs
```

ΔC < 0 ແລະ ΔE > 0: ແອັບ**ເໜືອກວ່າ** — ດີກວ່າແລະຖືກກວ່າ ບໍ່ຕ້ອງການອັດຕາສ່ວນ. ຖ້າສົມມຸດຕິຖານການແທນທີ່ການປິ່ນປົວມີພຽງ 10% ΔC = 250 − 170 = +£80, ແລະ ICUR = 80 / 0.04 = **£2,000/QALY** — ຍັງຕ່ຳກວ່າ £20,000 ຫຼາຍ. ກໍລະນີຢູ່ລອດເຖິງແມ່ນຕັດສົມມຸດຕິຖານຫຼັກຢ່າງຫຼວງຫຼາຍ: ນັ້ນຄື CUA ທີ່ແຂງແຮງ (ແລະ[ແຜນວາດ tornado](../ການວິເຄາະຄວາມອ່ອນໄຫວ/)ພິສູດມັນ).

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ແນວຄິດເລິກຂອງ CUA — *ໜຶ່ງຫົວໜ່ວຍປະສົມທີ່ຖ່ວງນ້ຳໜັກດ້ວຍຄວາມມັກເພື່ອປຽບທຽບສິ່ງທີ່ບໍ່ຄືກັນ* — ແມ່ນແບບແຜນສຳລັບການປຽບທຽບການລົງທຶນດ້ານວິສະວະກຳທີ່ບໍ່ຄືກັນ (ຄວາມປອດໄພ vs ປະສົບການນັກພັດທະນາ vs ຄວາມນ່າເຊື່ອຖື). ທາງເລືອກທີ່ຊື່ສັດແມ່ນຫົວໜ່ວຍປະສົມທີ່ປ້ອງກັນໄດ້ (ຫາຍາກ) ຫຼື[ຕາຕະລາງຕົ້ນທຶນ-ຜົນທີ່ຕາມມາ](../ການວິເຄາະຕົ້ນທຶນ-ຜົນທີ່ຕາມມາ/)ທີ່ຊັດເຈນ (ທົ່ວໄປ). ສິ່ງທີ່ CUA ເຕືອນບໍ່ໃຫ້ເຮັດແມ່ນການປະສົມປອມ: "ຄະແນນຜົນກະທົບ" ຖ່ວງນ້ຳໜັກທີ່ນ້ຳໜັກຖືກປັບຫຼັງຈາກເຫດການເພື່ອໃຫ້ທາງເລືອກທີ່ມັກຊະນະ. ເສດຖະສາດສຸຂະພາບໃຊ້ເວລາຫຼາຍທົດສະວັດໃນການມາດຕະຖານການສະກັດອຣະຖະປະໂຫຍດ ເພື່ອໃຫ້ນ້ຳໜັກມາກ່ອນການປຽບທຽບ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ກຳໄລອຣະຖະປະໂຫຍດຕ່ຳກວ່າຄວາມອ່ອນໄຫວຂອງເຄື່ອງມື** (ເບິ່ງຄວາມແຕກຕ່າງທີ່ສຳຄັນທາງຄລີນິກຕ່ຳສຸດໃນ[ຜົນລັບທີ່ລາຍງານໂດຍຄົນເຈັບ](../ຜົນລັບທີ່ຜູ້ປ່ວຍລາຍງານ/)) — ΔE ນ້ອຍໆ ຄູນປະຊາກອນໃຫຍ່ແມ່ນກົນລະຍຸດຟອກຂໍ້ມູນຄລາສສິກ.
- **ຕົກການແທນທີ່ການດູແລຂອງຕົວປຽບທຽບ** — ຕົ້ນທຶນໃຫຍ່ທີ່ສຸດສຳລັບຜະລິດຕະພັນດິຈິຕອນມັກແມ່ນສິ່ງທີ່ມັນແທນທີ່.
- **ການແຜນທີ່ຄະແນນທີ່ບໍ່ແມ່ນຄວາມມັກໄປເປັນອຣະຖະປະໂຫຍດ** ດ້ວຍຕາຕະລາງຂ້າມທີ່ບໍ່ຢືນຢັນ.
