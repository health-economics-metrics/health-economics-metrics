# ການຈຳລອງກຸ່ມ Markov

ແບບຈຳລອງກຸ່ມ Markov ແມ່ນເຕັກນິກການສ້າງແບບຈຳລອງ HTA ມາດຕະຖານສຳລັບການແຊກແຊງທີ່ຜົນຄ່ອຍໆເກີດຂຶ້ນຕະຫຼອດຫຼາຍໄລຍະເວລາ (ຮອບ), ບໍ່ແມ່ນຄັ້ງດຽວ. ກຸ່ມສົມມຸດເລີ່ມຕົ້ນທັງໝົດໃນສະຖານະສຸຂະພາບໜຶ່ງ, ແລະ ແຕ່ລະຮອບຊຸດຄວາມນ່າຈະເປັນການປ່ຽນຄົງທີ່ຍ້າຍເສດສ່ວນຂອງກຸ່ມລະຫວ່າງສະຖານະ; ຕົ້ນທຶນ ແລະ QALY ສະສົມໃນແຕ່ລະຮອບຕາມສັດສ່ວນຂອງກຸ່ມທີ່ຢູ່ແຕ່ລະສະຖານະ, ແລ້ວຫຼຸດມູນຄ່າກັບຄືນເປັນມູນຄ່າປັດຈຸບັນ. ວິສະວະກອນຊອບແວທີ່ສ້າງແບບຈຳລອງ business case ສຸຂະພາບດິຈິຕອນຫຼາຍປີ — ບ່ອນທີ່ຜູ້ໃຊ້ ຫຼື ຜູ້ປ່ວຍເຄື່ອນລະຫວ່າງສະຖານະເຊັ່ນ "ມີສ່ວນຮ່ວມ", "ຫຼຸດໄປ" ຫຼື "ເລີກໃຊ້" ຕາມເວລາ — ກຳລັງສ້າງໂຄງສ້າງດຽວກັນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ການຕັດສິນໃຈເຕັກໂນໂລຢີສຸຂະພາບຈິງສ່ວນໃຫຍ່ບໍ່ແມ່ນການປຽບທຽບຄັ້ງດຽວຂອງຕົ້ນທຶນ ແລະ ຜົນລັບຂອງໄລຍະດຽວ. ພະຍາດຊຳເຮື້ອຄວາມຄືບໜ້າ, ກັບຄືນ, ຕອບສະໜອງຕໍ່ການຮັກສາ ຫຼື ເຮັດໃຫ້ເສຍຊີວິດ ຕະຫຼອດຫຼາຍປີ — ແລະ [ການວິເຄາະຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ](../ການວິເຄາະຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ/) ໄລຍະດຽວບໍ່ສາມາດສະແດງມັນໄດ້. ການສົ່ງຄຳຮ້ອງ NICE, ICER ແລະ CADTH ສຳລັບການແຊກແຊງພະຍາດຊຳເຮື້ອ, ປະເມີນຜ່ານ [ການປະເມີນເຕັກໂນໂລຢີສຸຂະພາບ](../ການປະເມີນເຕັກໂນໂລຢີສຸຂະພາບ/), ເກືອບສະເໝີຖືກສ້າງເປັນແບບຈຳລອງກຸ່ມ Markov ດ້ວຍຂອບເຂດເວລາຕະຫຼອດຊີວິດ, ເພາະທາງເລືອກ — ການສ້າງແບບຈຳລອງທຸກເສັ້ນທາງຜູ້ປ່ວຍລາຍບຸກຄົນ — ບໍ່ສາມາດຈັດການໄດ້ໃນຂະໜາດໃຫຍ່. ແບບຈຳລອງ Markov ລະດັບກຸ່ມແລກຄວາມສົມຈິງລະດັບບຸກຄົນບາງສ່ວນ (ມັນບໍ່ສາມາດສະແດງຄວາມຈຳຂອງສະຖານະໃນອະດີດໄດ້ງ່າຍ, ຈຶ່ງເອີ້ນວ່າ "Markov": ອະນາຄົດຂຶ້ນກັບສະຖານະປັດຈຸບັນເທົ່ານັ້ນ) ເພື່ອໄດ້ແບບຈຳລອງທີ່ໂປ່ງໃສ, ກວດສອບໄດ້ ແລະ ໄວພໍທີ່ຈະຣັນຫຼາຍພັນຄັ້ງໃນ [ການວິເຄາະຄວາມອ່ອນໄຫວແບບຄວາມນ່າຈະເປັນ](../ການວິເຄາະຄວາມອ່ອນໄຫວແບບຄວາມນ່າຈະເປັນ/).

## ຄະນິດສາດ

```
One cycle's cohort update (row-vector x transition matrix):
  new_state[j] = sum_i state[i] * transition_matrix[i][j]

One cycle's cost:
  cycle_cost = sum_s state[s] * cost_per_cycle[s]

One cycle's QALYs:
  cycle_qalys = sum_s state[s] * utility[s] * cycle_length_years

Full simulation over `cycles` cycles, discounted at `discount_rate`:
  total_discounted_cost  = sum_{t=0}^{cycles-1} cycle_cost(state_t)  / (1 + discount_rate)^t
  total_discounted_qalys = sum_{t=0}^{cycles-1} cycle_qalys(state_t) / (1 + discount_rate)^t
  where state_0 = initial_distribution, state_{t+1} = advance_cohort(state_t, transition_matrix)
```

ການຫຼຸດມູນຄ່າແຕ່ລະຮອບກັບຄືນເປັນມູນຄ່າປັດຈຸບັນໃຊ້ສູດ [ການຫຼຸດມູນຄ່າ ແລະ ຄວາມມັກດ້ານເວລາ](../ການຫຼຸດມູນຄ່າ-ແລະ-ຄວາມມັກດ້ານເວລາ/) ຢ່າງແນ່ນອນ, ນຳໃຊ້ຕໍ່ຮອບແທນຕໍ່ປີ.

## ຕົວຢ່າງການຄິດໄລ່

**ທາງຄລີນິກ**: ແບບຈຳລອງ 2 ສະຖານະ — `Well` ແລະ `Dead` — ບ່ອນທີ່ກຸ່ມ 10% ເສຍຊີວິດໃນແຕ່ລະຮອບ ແລະ `Dead` ເປັນສະຖານະດູດຊຶມ (ຄວາມນ່າຈະເປັນການປ່ຽນຕົວເອງແມ່ນ 1.0; ຖ້າລະເວັ້ນວົງຕົວເອງນັ້ນ ມວນຂອງກຸ່ມຈະຫາຍໄປຫຼັງໜຶ່ງຮອບໃນ `Dead`). ກຸ່ມເລີ່ມຕົ້ນທັງໝົດ `Well`, ມີຕົ້ນທຶນ £1,000 ຕໍ່ຮອບໃນຂະນະ `Well` (£0 ເມື່ອ `Dead`), ແລະ ໄດ້ 0.8 QALY ຕໍ່ປີໃນຂະນະ `Well`. ຈຳລອງ 3 ຮອບລາຍປີທີ່ອັດຕາຫຼຸດມູນຄ່າ 3.5% ຂອງ NICE:

```
Cycle 0: state = [1.00, 0.00] (100% Well)
  cost = £1,000.00, qalys = 0.800, discount factor = 1.000000
  discounted: cost = £1,000.00, qalys = 0.8000

Cycle 1: state = [0.90, 0.10] (90% Well, 10% Dead)
  cost = £900.00, qalys = 0.720, discount factor = 0.966184
  discounted: cost = £869.57, qalys = 0.6957

Cycle 2: state = [0.81, 0.19] (81% Well, 19% Dead)
  cost = £810.00, qalys = 0.648, discount factor = 0.933511
  discounted: cost = £756.14, qalys = 0.6049

Total discounted cost  ≈ £2,625.71
Total discounted QALYs ≈ 2.1006
```

ສະຖານະຂອງແຕ່ລະຮອບແມ່ນສະຖານະຮອບກ່ອນທີ່ຖືກສົ່ງຜ່ານມາຕຣິກການປ່ຽນ — 90% ຂອງ 90% ທີ່ຍັງ `Well` ໃນຮອບ 1 ຍັງ `Well` ໃນຮອບ 2 (0.9 × 0.9 = 0.81), ໃນຂະນະທີ່ອີກ 19% ເສຍຊີວິດແລ້ວ (0.9 × 0.1 + 0.1 × 1.0 = 0.19). ສັງເກດວ່າກຸ່ມບໍ່ເຄີຍຫຼຸດ `Well` ເປັນສູນຢ່າງສົມບູນ: ດ້ວຍອັດຕາການຕາຍຄົງທີ່ 10% ຕໍ່ຮອບ ແລະ ບໍ່ມີການເຂົ້າກັບ, ສ່ວນ `Well` ຫຼຸດລົງແບບເລຂາຄະນິດ ແທນທີ່ຈະເຖິງສູນໃນຈຳນວນຮອບຈຳກັດໃດໜຶ່ງ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ສຳລັບວິທີທີ່ແບບຈຳລອງ HTA ຫຼາຍຮອບຖືກໃຊ້ໃນການປະເມີນຈິງ, ເບິ່ງ [ການປະເມີນເຕັກໂນໂລຢີສຸຂະພາບ](../ການປະເມີນເຕັກໂນໂລຢີສຸຂະພາບ/) — reference case ທີ່ກຳນົດວ່າແບບຈຳລອງ Markov ທີ່ສົ່ງຕ້ອງໃຊ້ອັດຕາຫຼຸດມູນຄ່າ, ແຫຼ່ງຄ່າປະໂຫຍດ ແລະ ຂອບເຂດເວລາໃດ.

ແບບຈຳລອງກຸ່ມ Markov ໃນໂຄງສ້າງແມ່ນເຄື່ອງຈັກສະຖານະທີ່ມີການປ່ຽນແບບຄວາມນ່າຈະເປັນ, ຣັນຈຳນວນ tick ຄົງທີ່, ຫຼຸດມູນຄ່າມູນຄ່າຂອງແຕ່ລະ tick. ຮູບຮ່າງດຽວກັນຈຳລອງການຮັກສາຜູ້ໃຊ້/ການປ່ຽນສະຖານະຂອງກຸ່ມຜູ້ໃຊ້ຕາມເວລາ — ເບິ່ງ [ຕົວຊີ້ວັດ DORA](../ຕົວຊີ້ວັດ-dora/) ສຳລັບຮຸ່ນຄວາມໜ້າເຊື່ອຖືໃນການດຳເນີນງານຂອງ "ສ່ວນໃດຂອງລະບົບຢູ່ໃນສະຖານະເສື່ອມໃນໄລຍະນີ້, ແລະ ມັນມີຕົ້ນທຶນເທົ່າໃດ". ໂດຍສະເພາະ:

- **ການສ້າງແບບຈຳລອງການຮັກສາຜູ້ໃຊ້/ການຫຼຸດຫາຍ** ແມ່ນແບບຈຳລອງກຸ່ມ Markov ທີ່ມີສະຖານະເຊັ່ນ "ໃຊ້ງານຢູ່", "ມີຄວາມສ່ຽງ", "ເລີກໃຊ້": ມາຕຣິກການປ່ຽນລາຍເດືອນຄົງທີ່, ຣັນ 12 ຫຼື 24 ຮອບລາຍເດືອນ, ບອກຈຳນວນຜູ້ໃຊ້ທີ່ຄາດໄວ້ (ແລະ ລາຍຮັບ) ໃນເດືອນອະນາຄົດໃດກໍໄດ້, ແບບດຽວກັບທີ່ `Well`/`Dead` ບອກຜູ້ລອດຊີວິດທີ່ຄາດໄວ້.
- **ຄວາມໜ້າເຊື່ອຖື ແລະ ເສດຖະສາດເຫດການ**: ສະຖານະຂອງລະບົບ (ປົກກະຕິ, ເສື່ອມ, ລົ້ມ) ສາມາດສ້າງແບບຈຳລອງແບບດຽວກັນ, ດ້ວຍ "ຕົ້ນທຶນຕໍ່ຮອບ" ຂອງຄວາມເສຍຫາຍຈາກການຢຸດສະສົມໃນຂະນະລະບົບຢູ່ສະຖານະເສື່ອມ/ລົ້ມ — ປ່ຽນຂໍ້ໂຕ້ແຍ້ງຄວາມຖີ່ຂອງເຫດການເປັນຂໍ້ໂຕ້ແຍ້ງຕົ້ນທຶນທີ່ຫຼຸດມູນຄ່າ ທີ່ປຽບທຽບໄດ້ກັບຕົ້ນທຶນຂອງວຽກຄວາມໜ້າເຊື່ອຖືທີ່ຈະປ່ຽນຄວາມນ່າຈະເປັນການປ່ຽນ.
- **ສະຖານະດູດຊຶມເປັນສະຖານະສຸດທ້າຍ**: `Dead` ໃນແບບຈຳລອງຄລີນິກແມ່ນ "ຍົກເລີກການສະໝັກ" ຫຼື "ອອບໄລນ໌ຖາວອນ" ໃນແບບຈຳລອງຊອບແວຢ່າງແນ່ນອນ — ທັງສອງຕ້ອງການຄວາມນ່າຈະເປັນການປ່ຽນຕົວເອງ 1.0 ຢ່າງຊັດເຈນ, ຖ້າບໍ່ດັ່ງນັ້ນການຈຳລອງຈະເສຍມວນຢ່າງງຽບໆ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຄວາມນ່າຈະເປັນການປ່ຽນທີ່ລວມແຖວບໍ່ເປັນ 1.** ແຖວທີ່ລວມຫຼາຍ ຫຼື ໜ້ອຍກວ່າ 1 ເຮັດໃຫ້ກຸ່ມ "ຮົ່ວ" ຫຼື "ເພີ່ມ" ມວນໃນແຕ່ລະຮອບຢ່າງງຽບໆ — ກວດຜົນລວມແຖວສະເໝີກ່ອນເຊື່ອຜົນຂອງແບບຈຳລອງ, ເພາະບໍ່ມີຫຍັງໃນໂຄງສ້າງແບບຈຳລອງທີ່ແຈ້ງເຕືອນຂໍ້ຜິດພາດ.
- **ຄວາມຍາວຮອບຫຍາບເກີນໄປສຳລັບພະລະວັດຈິງຂອງພະຍາດ.** ຮອບລາຍປີສຳລັບພະຍາດທີ່ປ່ຽນສະຖານະຢ່າງມີນັຍພາຍໃນສອງສາມອາທິດຄາດການປ່ຽນກາງຮອບຕ່ຳເກີນໄປ; ເລືອກຄວາມຍາວຮອບທີ່ສັ້ນເມື່ອທຽບກັບຄວາມໄວທີ່ຂະບວນການທີ່ສ້າງແບບຈຳລອງເຄື່ອນຈິງ.
- **ລືມວົງຕົວເອງຂອງສະຖານະດູດຊຶມ.** ສະຖານະດູດຊຶມ (ການເສຍຊີວິດ, ການຢຸດຖາວອນ) ຕ້ອງມີຄວາມນ່າຈະເປັນການປ່ຽນຕົວເອງ 1.0 ພໍດີ. ຖ້າລະເວັ້ນ ມວນຂອງກຸ່ມໃນສະຖານະນັ້ນຫາຍໄປຫຼັງໜຶ່ງຮອບ, ຄາດຕົ້ນທຶນສະສົມ ຫຼື ການສູນເສຍ QALY ຕ່ຳເກີນໄປ.
- **ຖືວ່າແບບຈຳລອງຖືກຢືນຢັນແລ້ວເພາະມັນຣັນໄດ້.** ແບບຈຳລອງກຸ່ມ Markov ທີ່ມີຄວາມນ່າຈະເປັນການປ່ຽນທີ່ເບິ່ງສົມເຫດສົມຜົນຍັງອາດຜິດໃນໂຄງສ້າງ (ຂາດສະຖານະ, ພຶດຕິກຳດູດຊຶມຜິດ); ຢືນຢັນກັບເກນປຽບທຽບທາງລະບາດວິທະຍາທີ່ຮູ້ແລ້ວ (ເຊັ່ນ ການລອດຊີວິດທີ່ແບບຈຳລອງໄດ້ທີ່ 5 ປີກົງກັບເສັ້ນໂຄ້ງການລອດຊີວິດທີ່ເຜີຍແຜ່ຫຼືບໍ່) ກ່ອນເຊື່ອຜົນ.
