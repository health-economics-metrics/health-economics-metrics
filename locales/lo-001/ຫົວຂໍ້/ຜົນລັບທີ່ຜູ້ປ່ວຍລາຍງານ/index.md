# ຜົນລັບທີ່ຜູ້ປ່ວຍລາຍງານ (PROMs, PREMs, MCID)

PROM ແມ່ນເຄື່ອງມືມາດຕະຖານທີ່ຜູ້ປ່ວຍລາຍງານສະຖານະສຸຂະພາບຂອງຕົນເອງ (ອາການ, ໜ້າທີ່, ຄຸນນະພາບຊີວິດ); PREM ຈັບ *ປະສົບການ* ການດູແລ. **MCID** — ຄວາມແຕກຕ່າງນ້ອຍທີ່ສຸດທີ່ສຳຄັນທາງຄລີນິກ — ແມ່ນການປ່ຽນແປງຄະແນນນ້ອຍທີ່ສຸດທີ່ຜູ້ປ່ວຍຮັບຮູ້ຈິງວ່າເປັນປະໂຫຍດ: ເກນທີ່ການອ້າງການປັບປຸງໃດກໍຕ້ອງຜ່ານ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

PROM ແມ່ນສະກຸນເງິນປະສິດທິຜົນຫຼັກຂອງສຸຂະພາບດິຈິຕອນ: ແອັບບໍ່ຄ່ອຍເຄື່ອນອັດຕາການຕາຍ, ແຕ່ມັນສາມາດເຄື່ອນຄະແນນອາການທີ່ຢືນຢັນແລ້ວໄດ້ຢ່າງໜ້າເຊື່ອຖື. ເຄື່ອງມືທີ່ສຳຄັນມີໜ້ອຍ ແລະ ເປັນມາດຕະຖານ — **PHQ-9** (ໂລກຊຶມເສົ້າ, 0–27; ແຖບຄວາມຮຸນແຮງທີ່ 5/10/15/20), **GAD-7** (ຄວາມກັງວົນ, 0–21; ແຖບທີ່ 5/10/15), **EQ-5D** (ຄ່າປະໂຫຍດສຳລັບ [QALY](../ປີຊີວິດທີ່ປັບດ້ວຍຄຸນນະພາບ/)) — ແລະ ຜູ້ຄວບຄຸມ, ອົງກອນ HTA ແລະ ຜູ້ຈ່າຍເງິນຍອມຮັບພວກມັນກໍເພາະປຽບທຽບກັນໄດ້ຂ້າມຜະລິດຕະພັນ ແລະ ການທົດລອງ. MCID ແມ່ນປະຕູແຫ່ງຄວາມຊື່ສັດ: MCID ຂອງ PHQ-9 ≈ 5 ຄະແນນ, GAD-7 ≈ 4, ດັດຊະນີ EQ-5D ໂດຍທົ່ວໄປ ~0.03–0.08 — ການປ່ຽນ PHQ-9 1.5 ຄະແນນທີ່ມີນັຍສຳຄັນທາງສະຖິຕິໃນຕົວຢ່າງໃຫຍ່ແມ່ນ *ເປັນຈິງແຕ່ບໍ່ມີຄວາມໝາຍທາງຄລີນິກ*, ແລະ ຜູ້ທົບທວນຫຼັກຖານຈະເວົ້າແນວນັ້ນ.

## ຄະນິດສາດ

```
PROM scoring: instrument-specific sums (e.g., PHQ-9 = Σ 9 items × 0–3)

MCID estimation:
  anchor-based:      score change among patients who report "somewhat better"
  distribution-based: ≈ 0.5 × SD of baseline scores (rough heuristic)

Response rate framing (for trials and dossiers):
  responder = patient improving ≥ MCID (or ≥50% for PHQ-9 convention)
  NNT = 1 / (responder rate_treatment − responder rate_control)
  — see number-needed-to-treat.md
```

## ຕົວຢ່າງການຄິດໄລ່

ແອັບສະໜັບສະໜູນໂລກຊຶມເສົ້າ, RCT ທຽບກັບລາຍຊື່ລໍຖ້າ, 12 ອາທິດ:

```
PHQ-9 change: app −6.2 points, control −2.1 → adjusted difference −4.1
MCID check: 4.1 < 5 → mean difference below MCID; report responders instead:
  responders (≥5-point drop): app 48%, control 22% → ARR 26%
  NNT = 1/0.26 ≈ 4 — four users treated per additional clinical response

Economic bridge: responders' EQ-5D gain 0.06 sustained 6 months
  = 0.03 QALYs; per 1,000 users: 260 extra responders × 0.03 = 7.8 QALYs
  ≈ £156,000–£234,000 of health value at NICE thresholds
```

ກອບຜູ້ຕອບສະໜອງ/NNT ຜ່ານການທົບທວນ ໃນຂະນະທີ່ຄວາມແຕກຕ່າງສະເລ່ຍທີ່ຕ່ຳກວ່າ MCID ຈະຖືກປະຕິເສດ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

PROM ແມ່ນບັນຫາການເກັບຂໍ້ມູນທີ່ຊອບແວຢູ່ໃນຕຳແໜ່ງພິເສດທີ່ຈະແກ້: ເຄື່ອງມືໃນແອັບໄດ້ອັດຕາການເຮັດສຳເລັດ ແລະ ຄວາມໜາແໜ້ນຕາມລຳດັບເວລາທີ່ເຈ້ຍບໍ່ເຄີຍເຮັດໄດ້, ປ່ຽນ telemetry ຜະລິດຕະພັນປົກກະຕິເປັນຫຼັກຖານລະດັບ HTA ([EQ-5D](../eq-5d/) ແມ່ນຫ້າໜ້າຈໍ). ກົດວິສະວະກຳ: ໃຊ້ເຄື່ອງມືທີ່ຢືນຢັນແລ້ວ *ຕາມຕົວອັກສອນ* (ການຂຽນຄືນເຮັດໃຫ້ມັນໃຊ້ບໍ່ໄດ້ — ມີການອະນຸຍາດໃຊ້ງານ); ກຳນົດເວລາວັດຕາມໂປຣໂຕຄອນ, ບໍ່ແມ່ນຕາມຄວາມສະດວກຂອງການມີສ່ວນຮ່ວມ (ວັດສະເພາະຜູ້ໃຊ້ທີ່ຍັງໃຊ້ງານແມ່ນອະຄະຕິຜູ້ລອດຊີວິດ — ເບິ່ງ [ການຮັກສາຜູ້ໃຊ້](../ການຮັກສາຜູ້ໃຊ້-ແລະ-ການຫຼຸດຫາຍ/)); ແລະ ລັອກເວີຊັນຂໍ້ມູນເຄື່ອງມືຄືກັບ schema ໃດໆ — ການປ່ຽນຖ້ອຍຄຳກາງການສຶກສາແມ່ນຄວາມເສຍຫາຍຂອງຂໍ້ມູນ. PREM ແມ່ນກົງກັບເຄື່ອງມືແບບ CSAT/NPS, ແລະ ບົດຮຽນດຽວກັນໃຊ້ໄດ້: ມາດຕະຖານຊະນະສິ່ງທີ່ສ້າງເອງ ເມື່ອຜູ້ຊົມແມ່ນຜູ້ຈ່າຍເງິນ. ສຳລັບເຄື່ອງມືສະເພາະຜະລິດຕະພາບການເຮັດວຽກ, ເບິ່ງ [WPAI](../ຜະລິດຕະພາບການເຮັດວຽກ-ແລະ-ຄວາມບົກພ່ອງຂອງກິດຈະກຳ/).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ນັຍສຳຄັນທາງສະຖິຕິທີ່ຕ່ຳກວ່າ MCID** ທີ່ນຳສະເໜີເປັນປະໂຫຍດທາງຄລີນິກ — ການເວົ້າເກີນຈິງທີ່ພົບທົ່ວໄປທີ່ສຸດໃນສາຂານີ້.
- **ການຖອຍຫາຄ່າສະເລ່ຍ**: ຜູ້ໃຊ້ລົງທະບຽນໃນຈຸດສູງສຸດຂອງອາການ; ກ່ອນ/ຫຼັງແຂນດຽວຄາດເກີນຫຼາຍ — ຕົວປຽບທຽບແມ່ນຕໍ່ລອງບໍ່ໄດ້.
- **ການເລືອກເຄື່ອງມື**: ຣັນ PHQ-9, GAD-7 ແລະ WHO-5 ແລ້ວລາຍງານອັນໃດທີ່ເຄື່ອນ — ລົງທະບຽນລ່ວງໜ້າຕົວຫຼັກ.
- **ແຮງກົດດັນແບບສຳຫຼວດດິຈິຕອນ**: ການຊັກນຳຜູ້ໃຊ້ໄປຫາຄຳຕອບທີ່ເປັນປະໂຫຍດທຳລາຍເຄື່ອງມື (ແລະ ຜູ້ທົບທວນຮູ້ອັດຕາພື້ນຖານ).
