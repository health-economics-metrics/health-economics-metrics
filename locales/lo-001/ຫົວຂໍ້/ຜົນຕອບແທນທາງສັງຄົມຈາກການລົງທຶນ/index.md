# ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ (SROI)

SROI ຂະຫຍາຍ [ROI](../ຜົນຕອບແທນຈາກການລົງທຶນ/) ໄປສູ່ຜົນລັບທີ່ຕະຫຼາດບໍ່ຕັ້ງລາຄາ — ສຸຂະພາບດີ, ການເຊື່ອມໂຍງທາງສັງຄົມ, ຜົນກະທົບຕໍ່ສິ່ງແວດລ້ອມ — ໂດຍແປງເປັນເງິນດ້ວຍຕົວແທນທາງການເງິນ, ສຳລັບຜູ້ມີສ່ວນຮ່ວມ *ທຸກຄົນ* ທີ່ໄດ້ຮັບຜົນກະທົບ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ສິ່ງທີ່ການແຊກແຊງດ້ານສຸຂະພາບ ແລະ ຊຸມຊົນຜະລິດສ່ວນໃຫຍ່ບໍ່ເຄີຍແຕະລາຍການງົບ: ຄວາມໂດດດ່ຽວຫຼຸດລົງ, ການບັນເທົາຜູ້ດູແລ, ການມີວຽກເພີ່ມ, ກຽດສັກສີ. SROI, ຄວບຄຸມໂດຍເຈັດຫຼັກການຂອງ Social Value International (ມີສ່ວນຮ່ວມກັບຜູ້ມີສ່ວນຮ່ວມ, ປະເມີນສິ່ງທີ່ສຳຄັນ, ຢ່າອ້າງເກີນ, ໂປ່ງໃສ, ຢືນຢັນ…), ຜະລິດຄຳກ່າວເຊັ່ນ "ມູນຄ່າທາງສັງຄົມ £3.20 ຕໍ່ການລົງທຶນ £1." ຄວາມຕ້ອງການມູນຄ່າທາງສັງຄົມໃນການຈັດຊື້ພາກລັດຂອງສະຫະລາຊະອານາຈັກເຮັດໃຫ້ຫຼັກຖານແບບ SROI ກ່ຽວຂ້ອງດ້ານການຄ້າ: ການປະມູນສັນຍາພາກລັດ (ລວມທັງ NHS) ໄດ້ຄະແນນສຳລັບມູນຄ່າທາງສັງຄົມທີ່ສາທິດ.

## ຄະນິດສາດ

```
SROI ratio = PV(monetized social outcomes) / PV(investment)

For each outcome:
  value = quantity × financial proxy × attribution × (1 − deadweight) × (1 − displacement)

deadweight   = would have happened anyway
attribution  = share caused by others
displacement = benefit moved from elsewhere rather than created
drop-off     = decay of the outcome over years
```

ປັດໄຈປັບແມ່ນຄວາມສົມບູນຂອງວິທີການ: ຖ້າບໍ່ມີ, SROI ແມ່ນນິຍາຍທີ່ມີເຄື່ອງໝາຍສະກຸນເງິນ.

## ຕົວຢ່າງການຄິດໄລ່

ແອັບເພື່ອນທີ່ເຊື່ອມຜູ້ສູງອາຍຸທີ່ໂດດດ່ຽວກັບອາສາສະໝັກ; ຕົ້ນທຶນໂຄງການ £200,000/ປີ; 1,500 ຄູ່ທີ່ໃຊ້ງານ.

```
Outcome: reduced loneliness for 1,500 people
  proxy: wellbeing valuation of "relief from loneliness" ≈ £1,800/person/yr
  deadweight 25% (some would have found connection anyway)
  attribution 80% (some credit to other services)

Value = 1,500 × 1,800 × 0.80 × 0.75 = £1,620,000

Outcome: reduced GP visits, 1,500 × 1.2 visits × £42 = £75,600 (payer-real)

SROI = (1,620,000 + 75,600) / 200,000 ≈ 8.5 : 1
```

ສັງເກດວ່າອັດຕາສ່ວນແມ່ນ 96% ສຸຂະພາບດີທີ່ປະເມີນດ້ວຍຕົວແທນ ແລະ 4% ເງິນສົດແທ້. ນັ້ນເປັນ SROI ທີ່ຊອບທຳ — ແຕ່ຕ້ອງນຳສະເໜີເປັນມູນຄ່າທາງສັງຄົມ, ຢ່າປ່ອຍໃຫ້ບົ່ງບອກວ່າ £1.7M ເກັບເງິນໄດ້.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

SROI ແມ່ນກອບທີ່ຊື່ສັດສຳລັບງານວິສະວະກຳທີ່ຜູ້ໄດ້ຮັບປະໂຫຍດຢູ່ນອກທີມທີ່ຈ່າຍ: ການບຳລຸງຮັກສາໂອເພນຊອດ, ການປັບປຸງການເຂົ້າເຖິງໄດ້, ງານແພລດຟອມທີ່ທີມອື່ນໃຊ້, ການລົງທຶນຊຸມຊົນນັກພັດທະນາ. ກົນໄກທີ່ໂອນໄດ້: ລະບຸຜູ້ມີສ່ວນຮ່ວມທັງໝົດ, ແປງເປັນເງິນດ້ວຍຕົວແທນທີ່ລະບຸ, ແລະ ນຳໃຊ້ສ່ວນຫຼຸດ deadweight/ການຖືກຖືວ່າເກີດຈາກ (ການແກ້ OSS ນັ້ນຈະເກີດຂຶ້ນຢູ່ແລ້ວບໍ? ຜົນໄດ້ສ່ວນໃດແມ່ນງານຂອງທ່ານ ທຽບກັບລະບົບນິເວດ?). ວິໄນຂອງ *ການຫຼຸດການອ້າງຜົນກະທົບຂອງຕົນເອງ* ແມ່ນສິ່ງທີ່ແຍກ SROI ຈາກຕົວເລກການຕະຫຼາດ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການເລືອກຕົວແທນ**: ເລືອກການປະເມີນສຸຂະພາບດີທີ່ໃຈກວ້າງທີ່ສຸດທີ່ມີ.
- **ຂ້າມ deadweight/attribution** — ການເວົ້າເກີນທີ່ພົບທົ່ວໄປທີ່ສຸດ, ມັກເຮັດໃຫ້ອັດຕາສ່ວນເພີ່ມສອງເທົ່າ.
- **ປຽບທຽບອັດຕາສ່ວນຂ້າມການສຶກສາ**: ອັດຕາສ່ວນ SROI ອ່ອນໄຫວຕໍ່ວິທີການ; ປຽບທຽບສະເພາະພາຍໃນກອບທີ່ສອດຄ່ອງ.
- **ນຳສະເໜີມູນຄ່າທາງສັງຄົມເປັນການປະຢັດທີ່ເກັບເງິນໄດ້** ໃຫ້ຜູ້ຖືງົບ.
