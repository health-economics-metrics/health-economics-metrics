# Seachaint freastail éigeandála

Comhaireamhann seachaint freastail éigeandála cuairteanna ED (A&E) agus glactha isteach éigeandála a chuirtear cosc orthu trí idirghabháil suas an sruth — aipeanna triaiste, monatóireacht chianda, barda fíorúla, atreorú cúraim phráinní. Aistríonn sé “rug muid air níos luaithe” ina éileamh costáilte.

## Cén fáth a bhfuil tábhacht leis

Is é cúram éigeandála an suíomh rialta is costasaí sa chóras (costais aonaid freastail ED sa raon £250–£400 de réir figiúirí Bailiúchán Náisiúnta Costais / PSSRU; is mílte é glacadh éigeandála), agus tá plódú ED ina chúis le moilleanna otharchairr agus roghanna cealaithe. Ceannaíonn aon rud a réitíonn éileamh go sábháilte suas an sruth — comhairle féinchúraim, príomhchúram an lae chéanna, freagairt phobail — cumas don chóras ag a phointe is faoi strus. Is é seo an líne sochair chaighdeánach d’fhíorcheistiúcháin siomptóm, seirbhísí triaiste de stíl 111, agus [monatóireacht chianda othar](../eacnamaíocht-monatóireachta-othar-iargúlta/).

## An mhatamaitic

```
Freastail seachanta = daonra × (ráta bonnlíne − ráta idirghabhála)
Coigilteas comhlán  = freastail seachanta × costas aonaid in aghaidh an fhreastail
                      (+ glactha isteach seachanta × costas glactha isteach, comhaireamh ar leithligh)

Coigilteas glan     = coigilteas comhlán − costas idirghabhála − costas úsáide bealaigh nua
                      (níl éileamh atreoraithe saor: tá costais aonaid ag glao 111, sliotán dochtúra
                       teaghlaigh, lá barda fíorúil)
```

Teastaíonn comparadóir ón éileamh cúiseach: bíonn treochtaí agus athruithe séasúracha ar rátaí freastail, mar sin ní chruthaíonn roimh/tar éis amháin aon rud.

## Sampla oibrithe

Seirbhís monatóireachta cianda COPD do 3,000 othar ard-riosca. Léiríonn meastóireacht rialuithe meaitseáilte go dtiteann freastal ED a bhaineann le géarú ó 0.9 go 0.7 in aghaidh na bliana-othair, agus glacadh isteach éigeandála ó 0.5 go 0.42.

```
Freastail seachanta = 3,000 × 0.2  = 600 × £300   = £180,000
Glacadh isteach seachanta = 3,000 × 0.08 = 240 × £3,800 = £912,000
Comhlán                                            £1,092,000/bliain

Costais: seirbhís monatóireachta £600,000; freagairtí breise altra pobail £150,000
Glan ≈ +£342,000/bliain — móide gnóthachain QALY ó ghéaruithe a chóireáiltear níos luaithe.
```

Tabhair faoi deara gurb é líne an ghlactha isteach is mó: is annamh a íocann seachaint freastail amháin as seirbhís monatóireachta; is i seachaint *glactha isteach* atá an t-airgead.

## An nasc le hinnealtóireacht bogearraí

Is é seo **eacnamaíocht seachaint teagmhais**. Is é luach breathnaitheachta, imlonnuithe canary, agus córais luathrabhaidh “freastail éigeandála” seachanta — leathanaigh, seomraí cogaidh, sev-1anna — gach ceann le costas lódáilte (uaireanta innealtóra × ráta + tionchar custaiméara). Baineann na rialacha samhaltaithe céanna: glan costas an bhealaigh nua suas an sruth (ní saor é triaiste rabhaidh), bí aireach faoi ionadú (is imní sláinte iad rabhaidh a chruthaíonn obair gan teagmhais a chosc, ní sláinte), agus cruthaigh an contrafhíoras le rialú (bíonn treochtaí agus aischéimniú go dtí an meán ag rátaí teagmhas foirne, díreach cosúil le freastal ED).

## Gaistí

- **Aischéimniú go dtí an meán**: feabhsaíonn cohóirtí ard-riosca a roghnaítear ar bhliain dhona gan chóireáil; tá rialuithe meaitseáilte nó dearaí céimdhuilleoige riachtanach.
- **Éileamh spreagtha ag soláthar**: is féidir le triaiste dhigiteach éasca teagmhálacha iomlána a *mhéadú* (tairseach níos ísle chun cabhair a lorg) agus sciar ED a laghdú — comhaireamh costas iomlán an chórais.
- **Freastail a luacháil ar mheáncostas** nuair nach dtiteann costais sheasta ED — féach [costas imeallach vs meán](../costas-imeallach-vs-meánchostas/).
