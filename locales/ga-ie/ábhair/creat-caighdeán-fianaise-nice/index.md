# Creat Caighdeán Fianaise NICE (ESF)

Is é an ESF creat NICE a shonraíonn **cé mhéad fianaise a theastaíonn ó theicneolaíocht sláinte dhigiteach, i gcomhréir lena riosca**. Is é an rud is gaire do fhreagra oifigiúil ar “cad atá le cruthú againn sula gceannaíonn an NHS ár n-aip?”.

## Cén fáth a bhfuil tábhacht leis

Aicmíonn an ESF (a eisíodh den chéad uair in 2019, nuashonraithe in 2022 chun AI agus algartaim oiriúnaitheacha a chuimsiú) teicneolaíochtaí sláinte digiteacha i leibhéil de réir feidhm chliniciúil, le caighdeáin fianaise **charnacha** — 21 chaighdeán thar 5 ghrúpa (fachtóirí dearaidh, luach, feidhmíocht/éifeachtacht, tionchar eacnamaíoch, imscaradh):

```
Tier A — system services, no direct patient outcome (e.g., e-rostering)
         → basic standards: credibility, data protection, technical assurance
Tier B — inform, simple monitoring, communication (e.g., symptom diary)
         → + evidence of user benefit, appropriate reliability
Tier C — treat, diagnose, or actively guide clinical management
         → + high-quality comparative effectiveness evidence (ideally RCT)
           and economic analysis
```

Maidir le fianaise eacnamaíoch, is inghlactha é [anailís costais-iarmhairtí](../anailís-costais-iarmhairtí/) do fhormhór na leibhéal; táthar ag súil le [anailís costais-úsáidíochta](../anailís-costais-fóntais/) ag an riosca is airde. Sainmhíníonn an ESF do **chostas fianaise iontrála margaidh** — déan buiséadú dó cosúil le haon chostas tógála eile.

## An mhatamaitic

Gan fhoirmlí — tábla cinnidh. Is tráchtála an ríomh oibríochtúil:

```
Evidence investment required = f(tier)
  Tier A: documentation + assurance ≈ £10k–50k
  Tier B: observational/comparative user-benefit study ≈ £50k–250k
  Tier C: RCT-grade comparative study + economic model ≈ £250k–£2M+

Position your product's claims deliberately: claiming "supports clinical
decisions" instead of "informs patients" moves you a tier and can 10× the bill.
```

## Sampla oibrithe

Smaoiníonn déantóir aipe meabhrúcháin cógais ar ghné moladh coigeartaithe dáileoige a chur leis.

- Mar aip mheabhrúcháin: **Leibhéal B** — is leor staidéar cohórt a thaispeánann feabhas ar chomhlíonadh.
- Le moltaí dáileoige: **Leibhéal C** — fianaise éifeachtachta chomparáidí (RCT i gcoinne gnáthchúraim is dócha) móide anailís eacnamaíoch.

Má chosnaíonn an RCT £600k agus is é £200k/bliain ioncam breise na gné dáileoige, caithfidh an ghné luach a choinneáil ar feadh 3+ bliana sula mbriseann costais fianaise cothrom — cinneadh táirge a bhfuil cuma go hiomlán difriúil air nuair atá leibhéal ESF praghsáilte isteach. Seolann go leor foirne an táirge Leibhéal B agus cuireann siad an t-éileamh Leibhéal C ar chéimeanna taobh thiar de mhaoiniú.

## An nasc le hinnealtóireacht bogearraí

Is é an ESF an patrún rialachais is inaistrithe sa stór seo: **riachtanais fianaise a bhfuil leibhéil riosca acu d’ghlacadh uirlisí**. Leagan inmheánach: teastaíonn taispeántas ó fhormáidire cód (Leibhéal A); teastaíonn píolótach tomhaiste ó uirlis tháirgiúlachta a éilíonn uaireanta sábháilte (Leibhéal B); teastaíonn fianaise ar chaighdeán trialach rialaithe ó gheata AI a bhlocálann imscarthaí go huathoibríoch nó a scríobhann cód cliniciúil go huathoibríoch sula scaoiltear é eagraíocht-leathan (Leibhéal C). Stopann fianaise chomhréireach an dá mhodh teip — maorlathas ag plúchadh uirlisí tríviúla, agus vibes ag seoladh cinn thábhachtacha. Féach freisin [lamháil mhear DiGA](../bealach-tapa-diga-na-gearmáine/) mar fhorlíonadh “glacadh sealadach le sprioc ama fianaise”.

## Gaistí

- **Mífhoirmliú leibhéil de bharr smaointeoireacht inmhianaithe** — aicmíonn rialtóirí agus ceannaitheoirí de réir an méid a dhéanann an táirge, ní de réir an mhargaíochta.
- **Fianaise a thógtar tar éis an táirge**: tá RCT a athchóiriú ar tháirge seolta gan ionstraimiú ná cothromaíocht mall agus dodhéanta go minic.
- **An ESF a chomhlíonadh agus dearmad a dhéanamh ar an gcuid eile**: seasann an ESF taobh le DTAC (sábháilteacht chliniciúil, cosaint sonraí, idir-inoibritheacht) agus, don AI, imréiteach rialála — féach [meastóireacht rialála AI](../meastóireacht-rialála-ai/).
