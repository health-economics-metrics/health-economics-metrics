# Measúnú teicneolaíochta sláinte (HTA)

Is é HTA an próiseas foirmiúil, institiúidithe trínar chinneann córais sláinte an fiú íoc as teicneolaíocht — druga, feiste, nó bogearraí. Cuimsíonn sé fianaise éifeachtachta cliniciúla le meastóireacht eacnamaíoch faoi mhodheolaíocht fhoilsithe, éigeantach.

## Cén fáth a bhfuil tábhacht leis

Má dhíolann tú isteach i seirbhís sláinte náisiúnta, féadfaidh comhlacht HTA rochtain ar do mhargadh a chinneadh go litriúil. Is é eolas ar an bpróiseas áitiúil eolas ar do fhíor-rialálaí luacha:

- **NICE (Sasana)**: measúnuithe reachtúla faoi *chás tagartha* sainithe — QALYanna ó [EQ-5D](../eq-5d/), [peirspictíocht](../peirspictíocht-anailíse/) NHS+PSS, [lascainiú](../lascainiú-agus-rogha-ama/) 3.5%, [PSA](../anailís-íogaireachta-dóchúlachta/) riachtanach — breithnithe i gcoinne £20k–£30k/QALY le [modhnóirí déine](../easnamh-qaly-agus-modhnóirí-déine/); teicneolaíochtaí an-speisialaithe suas go £100k+ le hualú.
- **ICER (SAM, neamhrialtasach)**: tuarascálacha fianaise le *tagarmharc praghais sochair sláinte* — an praghas a mbeadh táirge costéifeachtúil ag $100k–$150k in aghaidh QALY/evLYG — a úsáidtear mar luamhán caibidlíochta; móide “rabhaidh inacmhainneachta” tionchair buiséid.
- **Ceanada (CADTH → CDA-AMC)**: athbhreithnithe aisíoca ag ≈CAD$50k/QALY; d’iarr siad go stairiúil laghduithe praghais i ~95% d’aighneachtaí.

## An mhatamaitic

Ní foirmle é cumhacht HTA ach **modh sainordaithe**: ríomhann gach aighneacht an [ICER](../cóimheas-incriminteach-costéifeachtúlachta/) céanna faoi na rialacha cáis-tagartha céanna, ionas go bhfuil torthaí inchomparáide thar tháirgí agus blianta. Sonraíonn an cás tagartha beart toraidh, ionstraim fóntais, peirspictíocht, roghnú comparadóra, ráta lascaine, spriocam, agus anailís éiginnteachta — ag baint gach céim saoirse a d’fhéadfadh urraí a chluiche.

## Sampla oibrithe

Cuireann teiripe dhigiteach isteach ar mheastóireacht de stíl NICE:

```
Samhail: ΔC = +£450/othar, ΔE = +0.03 QALY → ICER = £15,000/QALY ✓ faoi £20k
Seiceálacha cáis tagartha:
  fóntais ó EQ-5D-5L le tacar luacha RA                   ✓
  comparadóir = bealach cúraim reatha (ní “gan cóireáil”) ✓
  PSA: 71% dóchúlachta costéifeachtúil ag £20k           ✓ (tuairiscithe)
  modhnóir déine: bearna faoi bhun teorainneacha ×1.2     — níor éileamh aon cheann
Moladh: coimisiúnú gnáth, le bailiú sonraí fíor-domhanda.
```

Léirigh anailís is fearr leis an urraí féin £9,000/QALY; bhrúigh an cás tagartha go £15,000 é trí iallach a chur ar an gcomparadóir macánta. Is é an bhearna sin *an fáth* go bhfuil cásanna tagartha ann.

## An nasc le hinnealtóireacht bogearraí

Is é an déantán inaistrithe an **cás tagartha inmheánach**: modh sainordaithe amháin do gach cás gnó uirlisí/ardáin — comparadóir dearbhaithe, costais aonaid chaighdeánacha (féach [taraif náisiúnta agus costais aonaid](../taraif-náisiúnta-agus-costais-aonaid/) don phatrún), ráta lascaine seasta, anailís íogaireachta riachtanach, teimpléad caighdeánach. Cuireann “dosaen AMCP d’uirlisí” a chuirtear faoi bhráid comhairle ardáin tograí inchomparáide agus cluichí infheicthe, díreach mar a dhéanann HTA don leigheas. Tosaigh níos lú ná mar a thosaigh NICE: is fearr teimpléad dhá leathanach móide leabhar praghais foilsithe ná gan aon chaighdeán.

Chun a fheiceáil conas a insamhlaítear samhail HTA il-timthriall cohóirt-ar-chohóirt i ndáiríre, féach [insamhladh cohóirt Markov](../insamhalta-cohórt-markov/).

## Gaistí

- **HTA a chaitheamh mar fhoirmiúlacht tar éis glanadh rialála** — deir glanadh CE/UKCA/FDA go bhfuil táirge sábháilte; cinneann HTA an fiú *é a cheannach*. Bacainn dhifriúil, fianaise dhifriúil.
- **An tsamhail eacnamaíoch a thógáil tar éis na trialach** — ba chóir giniúint fianaise a dhearadh siar ó riachtanais an cháis tagartha.
- **Difríochtaí dlínse a neamhaird**: teipeann ICER inmhaoinithe sna SA ag $120k/QALY ag NICE ag £30k; pleanáil fianaise agus praghsáil in aghaidh an mhargaidh.
