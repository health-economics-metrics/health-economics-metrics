# כלכלת סקירה

כלכלת סקירה שולטת בערך של בדיקת אוכלוסיות א-סימפטומטיות. העובדה המתמטית המרכזית: **בשכיחות מחלה נמוכה, אפילו בדיקות מצוינות מייצרות בעיקר תוצאות חיוביות שגויות** — ועלות המעקב אחריהן במורד הזרם יכולה להטביע את תועלת המציאות האמיתיות.

## למה זה חשוב

מאז 1968 קריטריוני Wilson–Jungner של WHO קובעים את הרף לסקירת אוכלוסייה: המצב חייב להיות חשוב, הבדיקה מקובלת ומדויקת, טיפול יעיל חייב להתקיים, והכלכלה חייבת להתאזן. הוועדה הלאומית לסקירה בבריטניה מיישמת ניתוח עלות-אפקטיביות פורמלי לפני אישור כל תוכנית לאומית — ודוחה את רוב ההצעות. כל פיץ' של "בינה מלאכותית תסרוק את כולם לכל דבר" נתקל במכונה הזו, ובדרך כלל מפסיד לחשבון שלהלן.

## המתמטיקה

ערך חזוי חיובי (PPV) — ההסתברות שתוצאה חיובית אמיתית — קורס בשכיחות נמוכה:

```
PPV = (sens × prev) / [sens × prev + (1 − spec) × (1 − prev)]

Example: sensitivity 90%, specificity 95%, prevalence 0.5%:
PPV = (0.9 × 0.005) / (0.9 × 0.005 + 0.05 × 0.995)
    = 0.0045 / (0.0045 + 0.04975) ≈ 8.3%
```

אחד-עשר מתוך שנים-עשר חיוביים שגויים. כלכלת התוכנית המלאה:

```
Cost per true case found = (screening cost + workup cost × all positives) / true positives
Then: is finding a case worth that? (earlier-intervention value per case,
      minus overdiagnosis harm — cases found that would never have mattered)
```

## דוגמה מחושבת

סקירת רשתית בבינה מלאכותית למצב נדיר, 100,000 איש, שכיחות 0.5%, רגישות 90%, סגוליות 95%, סריקה £15, בירור מאשש £400:

```
True positives:  100,000 × 0.005 × 0.90 = 450
False positives: 100,000 × 0.995 × 0.05 = 4,975
Cost = 100,000 × 15 + (450 + 4,975) × 400 = 1.5M + 2.17M = £3.67M
Cost per true case ≈ £8,156
```

אם טיפול מוקדם חוסך £20,000 + QALY אחד למקרה, התוכנית עוברת בקלות. העלו סגוליות ל-99% (פחות אזעקות שווא): עלות הבירור יורדת ל-(450 + 995) × 400 = £0.58M, סך הכל £2.08M, עלות למקרה ≈ **£4,622** — סגוליות, לא רגישות, היא המקום שבו כלכלת סקירה נוצחת בשכיחות נמוכה.

## הקשר להנדסת תוכנה

ניתוח סטטי, סריקת אבטחה וזיהוי חריגות הם תוכניות סקירה על בסיסי קוד וטלמטריה, עם שכיחות פגמים אמיתית לרוב הרבה מתחת ל-1% לכל הזדמנות התראה. אותה מתמטיקה מסבירה עייפות התראות: סורק בסגוליות 95% על קוד בשכיחות נמוכה מטביע צוותים בחיוביים שגויים, וכל חיובי שגוי עולה בתשומת לב ושוחק אמון עד שהתראות אמיתיות מתעלמות (המונח הקליני הוא *נזק סקירה*; המונח ההנדסי הוא *קהות דפדוף*). התרופות עוברות מהבריאות: העלו סגוליות לפני רגישות, סרקו תת-אוכלוסיות בשכיחות גבוהה יותר (מיקוד מבוסס סיכון ↔ סריקת קוד שהשתנה בלבד), וספרו עלות מיון בכלכלת הכלי — ראו [NNT](../המספר-הנדרש-לטיפול/) ו[הערכת בינה מלאכותית קלינית](../הערכת-בינה-מלאכותית-קלינית/). לגודל תוכנית סקירה שלמה ולא בדיקה אחת, ראו [המספר הנדרש לסקירה](../המספר-הנדרש-לסקירה/) — כמה אנשים חייבים לעבור את מסלול הסקירה-והטיפול כולו כדי למנוע תוצאה אחת.

## מלכודות נפוצות

- **ציטוט רגישות/סגוליות בלי שכיחות** — דיוק בלי PPV הוא שיווק.
- **התעלמות מאבחון-יתר**: מציאת "מחלה" אינדולנטית שלעולם לא הייתה פוגעת מפעילה עלויות ונזקי טיפול אמיתיים.
- **הטיית זמן הובלה**: גילוי מוקדם יותר בלי שינוי תוצאות מנפח הישרדות לכאורה — ראו [התערבות מוקדמת יותר](../התערבות-מוקדמת-יותר/).
