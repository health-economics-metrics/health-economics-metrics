# WSJF ו-CD3

CD3 (עלות עיכוב חלקי משך) ו-WSJF (Weighted Shortest Job First) הם כללי תעדוף שמתזמנים עבודה לפי **צפיפות ערך**: כמה עלות עיכוב מוסרת ליחידת קיבולת נדירה שנצרכת. תחת קיבולת משותפת וקבועה, הגבוה ביותר ב-CD3 ראשון הוא הרצף האופטימלי מתמטית למזעור עלות העיכוב הכוללת.

## למה זה חשוב

כל צבר הוא בעיית קיצוב: פריטים ראויים רבים, צינור אחד. כלכלת הבריאות פתרה את אותה בעיה לתקציבי בריאות בעזרת טבלאות ליגה של עלות-תועלת — דרגו התערבויות לפי בריאות שהושגה לכל פאונד, מממנים במורד הרשימה עד שהתקציב אוזל. CD3 הוא אותה לוגיקה לקיבולת אספקה: תועלת ליחידת *המשאב המוגבל*, ממומנת לפי סדר דירוג. סידור נכון הוא כסף חינם — אותה עבודה, אותה קיבולת, פחות עלות עיכוב כוללת.

## המתמטיקה

```
CD3  = Cost of Delay (£/week) / Duration (weeks)      — real units (Black Swan Farming)

WSJF = (user-business value + time criticality + risk reduction/opportunity
        enablement) / job size                         — SAFe's relative-scale proxy,
                                                        modified-Fibonacci scores
```

CD3 עם מטבע אמיתי ([עלות עיכוב](../עלות-עיכוב/)) חזק יותר בהחלט מנקודות ללא יחידות של WSJF — WSJF הוא ל-CD3 מה שניקוד רב-קריטריוני הוא ל[ניתוח עלות-תועלתנות](../ניתוח-עלות-תועלתנות/) מלא: שמיש כשכימות כספי אינו מעשי, ניתן לעיוות כשלציונים אין עוגן.

## דוגמה מחושבת

שלושה פיצ'רים, צוות אחד:

```
Feature   CoD (£/wk)   Duration   CD3
A         30,000       10 wks     3,000
B         12,000       2 wks      6,000
C         5,000        1 wk       5,000
```

סדר CD3: B, C, A. השוו את עלות העיכוב הכוללת מול "CoD הגדול ביותר ראשון" (A, B, C):

```
CD3 order  (B,C,A): A waits 3 wks, C waits 2 → 30k×3 + 5k×2  = £100k delay cost
CoD order  (A,B,C): B waits 10, C waits 12   → 12k×10 + 5k×12 = £180k
```

אותם פיצ'רים, אותו צוות — הסידור לבדו חוסך £80,000. האינטואיציה: פריטים קטנים ודחופים הולכים ראשונים כי הם משחררים את עלות העיכוב שלהם בזול; הפריט הגדול מפסיד מעט בהמתנה קצרה.

## הקשר להנדסת תוכנה

לתיקי תוכנה לבריאות, בטאו את CoD ביחידות שהמאגר הזה מלמד: QALY/שבוע × סף + £ תפעולי/שבוע, והצבר נעשה בר-השוואה ישירה לאופן שבו מערכת הבריאות מדרגת כל דבר אחר שהיא קונה. שתי הערות מעשיות: (1) משך פירושו *זמן לוח שנה שתופס את האילוץ*, לא מאמץ — פריט של שבועיים חלוף שדורש יומיים מהצוות שהוא צוואר הבקבוק זול ממה שהוא נראה (ראו [אופטימיזציית משאבים במורד הזרם](../אופטימיזציה-של-משאבים-במורד-הזרם/)); (2) בתי חולים מפעילים את אותו כלל במובלע כשהם מסדרים רשימות חדרי ניתוח לפי תפוקה משוקללת דחיפות — קטגוריות תעדוף קליניות הן CD3 משוקלל חומרה (ראו [חסר QALY ומתאמי חומרה](../חסר-qaly-ומתקני-חומרה/)).

## מלכודות נפוצות

- **תיאטרון ציוני WSJF**: ויכוחי פיבונאצ'י ללא יחידות מתכנסים למי שטוען בקול הרם ביותר; עגנו לפחות את פריטי ראש הצבר ב-CoD אמיתי.
- **עיוות משך**: פיצול פריטים כדי לנפח דירוג CD3 — בסדר כשהפיצולים מספקים ערך באופן עצמאי, הונאה כשלא.
- **התעלמות מפרופילי דחיפות**: CoD בצורת מועד אחרון (תאריכים רגולטוריים) שובר את הנחת הקצב היציב; תזמנו אותם לפי היתכנות תאריך, ואז CD3 לשאר.
- **תנודות דירוג מחדש**: CD3 מיועד להחלטות סידור בזמן ההתחייבות, לא לערבוב יומיומי של עבודה בביצוע (ראו [מדדי זרימה](../מדדי-זרימה/) על WIP).
