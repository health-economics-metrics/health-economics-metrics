# כלכלת יחידה של הסקה

כלכלת יחידה של הסקה מתמחרת תכונות בינה מלאכותית לפי המחשוב השולי שלהן: **עלות לטוקן**, מגולגלת לעלות לעסקה, למשתמש, לאפיזודה קלינית. הדינמיקה המגדירה: מחירי LLM ירדו בערך **בסדר גודל כל 1–2 שנים** ביכולת קבועה — קצב דפלציה חסר תקדים בתמחור טכנולוגיות בריאות.

## למה זה חשוב

שתי השלכות נובעות מקריסת המחירים. מסחרית, תכונת בינה מלאכותית שהיא שולית היום עשויה להיות רווחית בקלות בעוד 18 חודשים — ומתחרה שתומחר על עלויות היום יקוצץ. להערכה כלכלית, כל מודל עלות-אפקטיביות לשירות קליני מבוסס בינה מלאכותית שמקפיא מחירי הסקה של 2024 **מעריך ביתר באופן מהותי את העלות השוטפת** — הניתוח צריך תרחישי ירידת מחירים כפי שמודלי תרופות מטפלים בפקיעת פטנט וכניסת גנריות. (נקודות ייחוס מהמחקר: טוקני פלט חזיתיים ~$15–75/M באמצע 2026, מודלי ביניים זולים בסדר גודל, יכולת ברמת GPT-4 ירדה מ-~$20/M ב-2022 ל-~$0.40/M; Epoch AI מדדה ירידות של פי 9–900 בשנה בהתאם לאבן הדרך ביכולת.)

## המתמטיקה

```
Cost per call     = input tokens × input rate + output tokens × output rate
Cost per unit     = Σ calls per unit of business output (per triage episode,
                    per drafted letter, per consultation summary)

Blended reality   = base call + retries + RAG context (input-heavy)
                    + evaluation/guardrail calls (often 20–50% overhead)

Price-decline scenario for multi-year models:
  cost_t = cost_0 × d^t, test d ∈ {0.3, 0.5, 0.7}/year in sensitivity analysis
```

## דוגמה מחושבת

שירות סיכומי שחרור בבינה מלאכותית: סיכום ממוצע משתמש ב-12,000 טוקני קלט (הקשר רשומה) + 1,200 פלט, בתוספת מעבר אימות (6,000 קלט / 300 פלט). ב-$3/M קלט, $15/M פלט:

```
Draft:   12,000 × 3/1M + 1,200 × 15/1M  = $0.036 + $0.018 = $0.054
Verify:   6,000 × 3/1M +   300 × 15/1M  = $0.018 + $0.0045 ≈ $0.023
Per summary ≈ $0.077 → per 100,000 summaries/year ≈ $7,700

Against ~20 clinician-minutes saved per summary (≈ £25), inference is
0.25% of the value created — the economics are dominated by everything
EXCEPT the tokens: integration, evaluation, governance, adoption.
```

המסקנה הזו — עלות ההסקה היא לעיתים רחוקות האילוץ המחייב, במחירים הנוכחיים, למשימות קליניות בעלות ערך גבוה — היא בעצמה הממצא ששווה לשאת לפגישות תמחור.

## הקשר להנדסת תוכנה

זוהי [כלכלת יחידה בענן](../כלכלת-יחידה-בענן/) מותאמת לבינה מלאכותית, עם שלוש הערות פרקטיקה: **מדדו לכל יחידה עסקית**, לא לכל קריאת API, כך שהמספר מתחבר ישירות למודלי [ICER](../יחס-עלות-אפקטיביות-מצטבר/)/[השפעה תקציבית](../ניתוח-השפעה-תקציבית/); **שימו לב לאסימטריית קלט/פלט** (פלט לרוב ~פי 4 ממחיר הקלט; ארכיטקטורות RAG כבדות-קלט — בחירות ארכיטקטורה הן בחירות תמחור); ו**נתבו לפי דרגת משימה** — התאמת יכולת מודל לקושי משימה (מודלים זולים לסיווג, חזיתיים לסינתזה) מקצצת באופן שגרתי עלות משולבת פי 5–10 באיכות שווה, גרסת התוכנה לשימוש בהתערבות היעילה הזולה ביותר ([מזעור עלויות](../ניתוח-מזעור-עלויות/), שקילות מוכחת).

## מלכודות נפוצות

- **מודלים רב-שנתיים במחיר קפוא** — מעריכים ביתר עלות; אך גם **מודלי הכנסה מניחי-דפלציה** — מלחמת מחירים אינה חוזה; תרחשו את שניהם.
- **התעלמות מתקורת הערכה**: מעקות בטיחות, שופטים וניסיונות חוזרים הם טוקנים אמיתיים, לעיתים הרוב בסביבות מוסדרות.
- **קוצר-ראייה לטוקן**: השהיה, מגבלות קצב ואילוצי חלון הקשר נושאים עלויות שאף מחיר טוקן אינו לוכד.
