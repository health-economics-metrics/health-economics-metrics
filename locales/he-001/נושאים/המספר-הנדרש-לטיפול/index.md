# המספר הנדרש לטיפול (NNT)

NNT הוא מספר המטופלים שחייבים לקבל התערבות כדי ש**מטופל נוסף אחד** ייהנה, בתוך מסגרת זמן מוצהרת. הוא ממיר הפחתות סיכון באחוזים — שמטעות — ליחידות מאמץ-לתועלת שכל אחד יכול לנמק.

## למה זה חשוב

"מפחית התקפי לב ב-25%!" נשמע מכריע. אם הסיכון הבסיסי הוא 4% על פני 5 שנים, ההפחתה המוחלטת היא נקודת אחוז אחת, כך ש**100 אנשים חייבים לקחת את התרופה 5 שנים כדי שאחד ייהנה** — וכל ה-100 משלמים את העלויות ותופעות הלוואי. NNT הוא הנוגדן לשיווק בסיכון יחסי, ולכן רפואה מבוססת ראיות פותחת בו. סטטינים למניעה ראשונית: NNT ≈ 50–100 על פני 5 שנים לכל התקף לב שנמנע. הראי שלו, **NNH** (המספר הנדרש לנזק), סופר כמה מטופלים לכל אדם שניזוק.

## המתמטיקה

```
ARR = control event rate − treatment event rate   (absolute risk reduction)
NNT = 1 / ARR

NNH = 1 / (harm rate_treatment − harm rate_control)

Economic bridge:
cost per event prevented = NNT × cost per treatment course
```

ציינו תמיד את מסגרת הזמן ואת אוכלוסיית הבסיס — NNT חסר משמעות בלי שניהם.

## דוגמה מחושבת

מערכת חיזוי נפילות בבית חולים מסמנת מטופלים בסיכון גבוה להתערבות (חיישני מיטה, סקירה, השגחה). ניסוי: נפילות עם פציעה יורדות מ-3.2% ל-2.4% מהקבלות.

```
ARR = 0.8 percentage points → NNT = 1/0.008 = 125
   (125 patients must get the intervention bundle to prevent 1 injurious fall)

Intervention cost ≈ £40/patient → cost per fall prevented = 125 × 40 = £5,000
Cost of an injurious inpatient fall (extra stay, imaging, litigation) ≈ £12,000
Net: prevention pays ~2.4:1 — and the QALY gain is on top.
```

שימו לב כיצד NNT שומר על כנות הטענה: "מפחית נפילות ב-25%" ו"מונע נפילה אחת לכל 125 מטופלים שטופלו" הם אותה תוצאה, משכנעים באופן שונה.

## הקשר להנדסת תוכנה

NNT הוא היחידה הנכונה לכל שער או בדיקה שפועלים על פריטים רבים כדי לתפוס מעטים: **"מספר ה-PR שחייבים לעבור דרך שער הסקירה של הבינה המלאכותית כדי לתפוס פגם אחד שמיועד לייצור."** אם השער סוקר 400 PR לכל תפיסה אמיתית (NNT = 400) ב-4 דקות תשומת לב של מפתח כל אחד, תפיסה אחת עולה ~27 שעות מפתח — כעת השוו זאת לעלות התקרית שהיא מונעת. NNH ממפה לחיוביים שגויים: כמה PR לכל דגל *שגוי*, וכמה כל אחד עולה בתשומת לב ובאמון? כלים בסגנון סקירה (linters, סורקי אבטחה, זיהוי חריגות) צריכים להישלח עם חשבון NNT/NNH — ראו [כלכלת סקירה](../כלכלת-סקירה/) לכך שנפיצות נמוכה הופכת את המספרים האלה לאכזריים. [המספר הנדרש לסקירה](../המספר-הנדרש-לסקירה/) הוא הנתון המקביל רמה אחת למעלה, לתוכנית שלמה של סקירה-ואז-טיפול ולא לטיפול בלבד.

## מלכודות נפוצות

- **אין מסגרת זמן**: "NNT = 50" אינו אומר דבר; "NNT = 50 על פני 5 שנים" היא טענה.
- **השתלת סיכון בסיסי**: NNT שחושב באוכלוסיית ניסוי בסיכון גבוה קורס באוכלוסיית פריסה בסיכון נמוך.
- **התעלמות מ-NNH** — שער עם NNT 400 ו-NNH 3 הוא מחולל מטרד, לא מערכת בטיחות.
