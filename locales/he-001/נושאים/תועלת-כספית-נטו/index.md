# תועלת כספית נטו (NMB)

NMB ממיר תוצאת עלות-אפקטיביות לערך כספי יחיד: רווח בריאותי מתומחר בסף נכונות הלשלם, פחות עלות. תאומו, תועלת בריאותית נטו (NHB), מבטא את אותו כלל ביחידות בריאות.

## למה זה חשוב

יחסים ([ICER](../יחס-עלות-אפקטיביות-מצטבר/)) מביכים: הם מתפוצצים ליד אפקט אפס, לא ניתן לעשות להם ממוצע על פני הגרלות אי-ודאות, ולא ניתן לדרג בהם בנקיות שלוש אפשרויות ויותר. NMB מתקן את כל זה — הוא ליניארי, כך שאפשר לדרג אפשרויות, לעשות ממוצע להגרלות Monte Carlo ולפרק תרומות. הוא גם צורת המתמטיקה הכלכלית-בריאותית שכל מהנדס כבר מכיר: *ערך פחות עלות*.

## המתמטיקה

```
NMB = (ΔE × λ) − ΔC
NHB = ΔE − (ΔC / λ)

ΔE = incremental effect (e.g., QALYs)
ΔC = incremental cost
λ  = willingness-to-pay threshold (see willingness-to-pay-thresholds.md)

Decision rule: adopt if NMB > 0 (equivalently NHB > 0).
Among alternatives: choose the highest NMB.
```

NMB > 0 ⇔ ICER < λ (כש-ΔE > 0), כך ששני הכללים מסכימים — NMB פשוט מתנהג טוב יותר.

## דוגמה מחושבת

שלוש אפשרויות לשירות סוכרת, לכל 1,000 מטופלים, λ = £20,000/QALY:

```
Option           ΔC          ΔE (QALYs)   NMB = 20,000×ΔE − ΔC
App + coaching   £400,000    30           600,000 − 400,000 = £200,000
App only         £150,000    12           240,000 − 150,000 = £90,000
Extra clinics    £700,000    32           640,000 − 700,000 = −£60,000
```

מרפאות נוספות מרוויחות הכי הרבה QALY אך הורסות ערך בסף הזה (NMB < 0). אפליקציה + אימון מנצחים. שימו לב ש-NMB מאפשר לכם *לדרג את כל השלוש בבת אחת* — ICER זוגיים היו דורשים את הליך הגבול ב[דומיננטיות וגבול היעילות](../דומיננטיות-וגבול-היעילות/), ומגיעים לאותה תשובה.

מבט NHB על המנצח: 30 − 400,000/20,000 = 30 − 20 = **10 QALY נטו** — הבריאות שנרווחה מעבר למה שאותו כסף היה מייצר במקום אחר.

## הקשר להנדסת תוכנה

`(hours saved × loaded hourly rate) − tool cost` — התיק העסקי היומיומי של כלים — הוא ממש חישוב NMB עם λ = עלות מהנדס עמוסה. שני שדרוגים שכלכלת הבריאות מוסיפה:

- **הפכו את λ למשתנה, לא לקבוע.** שרטטו NMB מול λ ("ערך שעת מהנדס") והראו היכן ההחלטה מתהפכת; בעלי עניין שונים יכולים אז ליישם את ההערכה שלהם בלי לעשות מחדש את המתמטיקה שלכם.
- **חשיבת NHB**: "הפלטפורמה חוסכת 5,000 שעות מהנדס אך צורכת תקציב שהיה קונה 3,000 שעות קיבולת קבלנית — נטו 2,000 שעות" כופה את השוואת עלות ההזדמנות ביחידות קיבולת. ראו [עלות הזדמנות](../עלות-הזדמנות/).

## מלכודות נפוצות

- **הסתרת הסף**: NMB חסר משמעות בלי ציון λ; דווחו NMB ב-£20k וב-£30k, או שרטטו את העקומה.
- **שימוש ב-NMB להלבנת אפקטים זעירים**: אוכלוסייה עצומה כפול אפקט זניח לאדם יכולים לייצר NMB גדול — דווחו אפקטים לאדם לצד.
- **שכחה ש-NMB יורש כל אי-ודאות** ב-ΔC ו-ΔE — צרפו [ניתוח רגישות הסתברותי](../ניתוח-רגישות-הסתברותי/).
