# NICE ಸಾಕ್ಷ್ಯ ಮಾನದಂಡಗಳ ಚೌಕಟ್ಟು (ESF)

ESF ಎಂಬುದು ಡಿಜಿಟಲ್ ಆರೋಗ್ಯ ತಂತ್ರಜ್ಞಾನಕ್ಕೆ ಅದರ ಅಪಾಯಕ್ಕೆ ಅನುಪಾತದಲ್ಲಿ **ಎಷ್ಟು ಸಾಕ್ಷ್ಯ ಬೇಕು** ಎಂದು ನಿರ್ದಿಷ್ಟಪಡಿಸುವ NICEಯ ಚೌಕಟ್ಟು. "NHS ನಮ್ಮ ಆ್ಯಪ್ ಖರೀದಿಸುವ ಮೊದಲು ನಾವು ಏನನ್ನು ಸಾಬೀತುಪಡಿಸಬೇಕು?" ಎಂಬುದಕ್ಕೆ ಅಧಿಕೃತ ಉತ್ತರಕ್ಕೆ ಹತ್ತಿರದ ವಸ್ತು ಇದು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ESF (ಮೊದಲು 2019ರಲ್ಲಿ ಬಿಡುಗಡೆ, AI ಮತ್ತು ಹೊಂದಿಕೊಳ್ಳುವ ಅಲ್ಗಾರಿದಮ್‌ಗಳನ್ನು ಒಳಗೊಳ್ಳಲು 2022ರಲ್ಲಿ ನವೀಕರಿಸಲಾಗಿದೆ) ಡಿಜಿಟಲ್ ಆರೋಗ್ಯ ತಂತ್ರಜ್ಞಾನಗಳನ್ನು ಕ್ಲಿನಿಕಲ್ ಕಾರ್ಯದ ಪ್ರಕಾರ ಹಂತಗಳಾಗಿ ವರ್ಗೀಕರಿಸುತ್ತದೆ, **ಸಂಚಿತ** ಸಾಕ್ಷ್ಯ ಮಾನದಂಡಗಳೊಂದಿಗೆ — 5 ಗುಂಪುಗಳಲ್ಲಿ 21 ಮಾನದಂಡಗಳು (ವಿನ್ಯಾಸ ಅಂಶಗಳು, ಮೌಲ್ಯ, ಕಾರ್ಯಕ್ಷಮತೆ/ಪರಿಣಾಮಕಾರಿತ್ವ, ಆರ್ಥಿಕ ಪ್ರಭಾವ, ನಿಯೋಜನೆ):

```
Tier A — system services, no direct patient outcome (e.g., e-rostering)
         → basic standards: credibility, data protection, technical assurance
Tier B — inform, simple monitoring, communication (e.g., symptom diary)
         → + evidence of user benefit, appropriate reliability
Tier C — treat, diagnose, or actively guide clinical management
         → + high-quality comparative effectiveness evidence (ideally RCT)
           and economic analysis
```

ಆರ್ಥಿಕ ಸಾಕ್ಷ್ಯಕ್ಕೆ, ಹೆಚ್ಚಿನ ಹಂತಗಳಿಗೆ [ವೆಚ್ಚ-ಪರಿಣಾಮ ವಿಶ್ಲೇಷಣೆ](../ವೆಚ್ಚ-ಪರಿಣಾಮ-ವಿಶ್ಲೇಷಣೆ/) ಸ್ವೀಕಾರಾರ್ಹ; ಅತಿ ಹೆಚ್ಚು ಅಪಾಯದಲ್ಲಿ [ವೆಚ್ಚ-ಉಪಯುಕ್ತತಾ ವಿಶ್ಲೇಷಣೆ](../ವೆಚ್ಚ-ಉಪಯುಕ್ತತಾ-ವಿಶ್ಲೇಷಣೆ/) ನಿರೀಕ್ಷಿತ. ESF ನಿಮ್ಮ **ಮಾರುಕಟ್ಟೆ-ಪ್ರವೇಶದ ಸಾಕ್ಷ್ಯ ವೆಚ್ಚ**ವನ್ನು ವ್ಯಾಖ್ಯಾನಿಸುತ್ತದೆ — ಇತರ ಯಾವುದೇ ನಿರ್ಮಾಣ ವೆಚ್ಚದಂತೆ ಅದಕ್ಕೆ ಬಜೆಟ್ ಮಾಡಿ.

## ಗಣಿತ

ಸೂತ್ರಗಳಿಲ್ಲ — ನಿರ್ಧಾರ ಕೋಷ್ಟಕ. ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಲೆಕ್ಕ ವಾಣಿಜ್ಯ:

```
Evidence investment required = f(tier)
  Tier A: documentation + assurance ≈ £10k–50k
  Tier B: observational/comparative user-benefit study ≈ £50k–250k
  Tier C: RCT-grade comparative study + economic model ≈ £250k–£2M+

Position your product's claims deliberately: claiming "supports clinical
decisions" instead of "informs patients" moves you a tier and can 10× the bill.
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಔಷಧ-ಜ್ಞಾಪನೆ ಆ್ಯಪ್ ತಯಾರಕ ಮಾತ್ರೆ-ಹೊಂದಾಣಿಕೆ ಶಿಫಾರಸು ವೈಶಿಷ್ಟ್ಯವನ್ನು ಸೇರಿಸುವುದನ್ನು ಪರಿಗಣಿಸುತ್ತಾನೆ.

- ಜ್ಞಾಪನೆ ಆ್ಯಪ್ ಆಗಿ: **ಹಂತ B** — ಅನುಸರಣೆ ಸುಧಾರಣೆಯನ್ನು ತೋರಿಸುವ ಸಮೂಹ ಅಧ್ಯಯನ ಸಾಕು.
- ಮಾತ್ರೆ ಶಿಫಾರಸುಗಳೊಂದಿಗೆ: **ಹಂತ C** — ತುಲನಾತ್ಮಕ ಪರಿಣಾಮಕಾರಿತ್ವ ಸಾಕ್ಷ್ಯ (ಸಾಮಾನ್ಯ ಆರೈಕೆ ವಿರುದ್ಧ ಬಹುಶಃ RCT) ಜೊತೆಗೆ ಆರ್ಥಿಕ ವಿಶ್ಲೇಷಣೆ.

RCT £600k ವೆಚ್ಚವಾಗಿ ಮತ್ತು ಮಾತ್ರೆ ವೈಶಿಷ್ಟ್ಯದ ಹೆಚ್ಚುವರಿ ಆದಾಯ ವರ್ಷಕ್ಕೆ £200k ಆದರೆ, ಸಾಕ್ಷ್ಯ ವೆಚ್ಚಗಳು ಸರಿದೂಗುವ ಮೊದಲು ವೈಶಿಷ್ಟ್ಯ 3+ ವರ್ಷ ಮೌಲ್ಯ ಉಳಿಸಿಕೊಳ್ಳಬೇಕು — ESF ಹಂತಕ್ಕೆ ಬೆಲೆ ಕಟ್ಟಿದ ನಂತರ ಸಂಪೂರ್ಣ ಭಿನ್ನವಾಗಿ ಕಾಣುವ ಉತ್ಪನ್ನ ನಿರ್ಧಾರ. ಅನೇಕ ತಂಡಗಳು ಹಂತ B ಉತ್ಪನ್ನವನ್ನು ಬಿಡುಗಡೆ ಮಾಡಿ ಹಂತ C ಹಕ್ಕನ್ನು ಹಣಕಾಸಿನ ಹಿಂದೆ ಹಂತಹಂತವಾಗಿ ಇಡುತ್ತವೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ESF ಈ ರೆಪೊಸಿಟರಿಯಲ್ಲಿ ಅತ್ಯಂತ ವರ್ಗಾಯಿಸಬಹುದಾದ ಆಡಳಿತ ಮಾದರಿ: **ಸಾಧನ ಅಳವಡಿಕೆಗೆ ಅಪಾಯ-ಹಂತದ ಸಾಕ್ಷ್ಯ ಅವಶ್ಯಕತೆಗಳು**. ಆಂತರಿಕ ಆವೃತ್ತಿ: ಕೋಡ್ ಫಾರ್ಮ್ಯಾಟರ್‌ಗೆ ಡೆಮೊ ಬೇಕು (ಹಂತ A); ಉಳಿಸಿದ ಗಂಟೆಗಳನ್ನು ಹಕ್ಕು ಸಾಧಿಸುವ ಉತ್ಪಾದಕತೆ ಸಾಧನಕ್ಕೆ ಅಳೆದ ಪ್ರಾಯೋಗಿಕ ಯೋಜನೆ ಬೇಕು (ಹಂತ B); ನಿಯೋಜನೆಗಳನ್ನು ಸ್ವಯಂ-ತಡೆಯುವ ಅಥವಾ ಕ್ಲಿನಿಕಲ್ ಕೋಡ್ ಸ್ವಯಂ-ಬರೆಯುವ AI ದ್ವಾರಕ್ಕೆ ಸಂಸ್ಥೆ-ವ್ಯಾಪಿ ವಿಸ್ತರಣೆಯ ಮೊದಲು ನಿಯಂತ್ರಿತ-ಪ್ರಯೋಗ-ದರ್ಜೆ ಸಾಕ್ಷ್ಯ ಬೇಕು (ಹಂತ C). ಅನುಪಾತದ ಸಾಕ್ಷ್ಯ ಎರಡೂ ವೈಫಲ್ಯ ವಿಧಾನಗಳನ್ನು ತಡೆಯುತ್ತದೆ — ಕ್ಷುಲ್ಲಕ ಸಾಧನಗಳನ್ನು ಉಸಿರುಗಟ್ಟಿಸುವ ಅಧಿಕಾರಶಾಹಿ, ಮತ್ತು ಪರಿಣಾಮಕಾರಿ ಸಾಧನಗಳನ್ನು ಬಿಡುಗಡೆ ಮಾಡುವ ಭಾವನೆಗಳು. "ಸಾಕ್ಷ್ಯ ಗಡುವಿನೊಂದಿಗೆ ತಾತ್ಕಾಲಿಕ ಅಳವಡಿಕೆ" ಪೂರಕಕ್ಕೆ [DiGA ತ್ವರಿತ ಮಾರ್ಗ](../ಜರ್ಮನಿಯ-diga-ತ್ವರಿತ-ಮಾರ್ಗ/) ಸಹ ನೋಡಿ.

## ಎಡವಟ್ಟುಗಳು

- **ಆಸೆಯ ಚಿಂತನೆಯಿಂದ ಹಂತ ತಪ್ಪು ವರ್ಗೀಕರಣ** — ನಿಯಂತ್ರಕರು ಮತ್ತು ಖರೀದಿದಾರರು ಉತ್ಪನ್ನ *ಏನು ಮಾಡುತ್ತದೆ* ಎಂಬುದರ ಮೇಲೆ ವರ್ಗೀಕರಿಸುತ್ತಾರೆ, ಮಾರುಕಟ್ಟೆ ಹೇಳುವುದರ ಮೇಲಲ್ಲ.
- **ಉತ್ಪನ್ನದ ನಂತರ ನಿರ್ಮಿಸಿದ ಸಾಕ್ಷ್ಯ**: ಉಪಕರಣ ಅಥವಾ ಸಮತೋಲನವಿಲ್ಲದೆ ಬಿಡುಗಡೆಯಾದ ಉತ್ಪನ್ನಕ್ಕೆ RCT ಅನ್ನು ನಂತರ ಜೋಡಿಸುವುದು ನಿಧಾನ ಮತ್ತು ಹೆಚ್ಚಾಗಿ ಅಸಾಧ್ಯ.
- **ESF ಪೂರೈಸಿ ಉಳಿದದ್ದನ್ನು ಮರೆಯುವುದು**: ESF DTAC (ಕ್ಲಿನಿಕಲ್ ಸುರಕ್ಷತೆ, ದತ್ತಾಂಶ ರಕ್ಷಣೆ, ಅಂತರಕಾರ್ಯಸಾಧ್ಯತೆ) ಮತ್ತು, AIಗೆ, ನಿಯಂತ್ರಕ ಅನುಮತಿಯ ಜೊತೆಗೆ ಇದೆ — [AI ನಿಯಂತ್ರಕ ಮೌಲ್ಯಮಾಪನ](../ai-ನಿಯಂತ್ರಕ-ಮೌಲ್ಯಮಾಪನ/) ನೋಡಿ.
