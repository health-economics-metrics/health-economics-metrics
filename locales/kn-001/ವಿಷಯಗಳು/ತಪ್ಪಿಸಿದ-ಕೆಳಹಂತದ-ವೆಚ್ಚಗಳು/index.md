# ತಪ್ಪಿಸಿದ ಕೆಳಹಂತದ ವೆಚ್ಚಗಳು

ತಪ್ಪಿಸಿದ ಕೆಳಹಂತದ ವೆಚ್ಚಗಳು (ವೆಚ್ಚ ಸರಿದೂಗಿಸುವಿಕೆ, cost offsets) ಎಂದರೆ ಬೇಗನೆ ಅಥವಾ ಉತ್ತಮ ಕ್ರಮದಿಂದ ತಡೆಯಲಾದ ಭವಿಷ್ಯದ ಚಿಕಿತ್ಸಾ ವೆಚ್ಚಗಳು, ಮಧ್ಯಸ್ಥಿಕೆಯ ಸ್ವಂತ ವೆಚ್ಚದ ವಿರುದ್ಧ ಲೆಕ್ಕ ಹಾಕಿದ್ದು. ಒಂದು ಮಧ್ಯಸ್ಥಿಕೆ *ಪ್ರಾಬಲ್ಯ* (dominant) ಪಡೆಯುವ — ಅಗ್ಗ **ಮತ್ತು** ಉತ್ತಮ — ಕಾರ್ಯವಿಧಾನವೇ ಈ ಸರಿದೂಗಿಸುವಿಕೆಗಳು; ಅವು ಆರೋಗ್ಯ ಅರ್ಥಶಾಸ್ತ್ರದಲ್ಲಿ ಅತಿ ಹೆಚ್ಚು ದ್ವಿಗುಣ-ಎಣಿಕೆ ಮತ್ತು ಅತಿ ಹೆಚ್ಚು ಉತ್ಪ್ರೇಕ್ಷಿತ ಸಾಲು ಕೂಡ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಬಹುತೇಕ ಪ್ರತಿ ಡಿಜಿಟಲ್ ಆರೋಗ್ಯ ಮೌಲ್ಯ ಪ್ರತಿಪಾದನೆಯಲ್ಲಿ ಸರಿದೂಗಿಸುವ ಹಕ್ಕು ಇರುತ್ತದೆ: "ನಮ್ಮ ಆ್ಯಪ್ ದಾಖಲಾತಿಗಳನ್ನು ತಡೆಯುತ್ತದೆ," "ನಮ್ಮ ಎಚ್ಚರಿಕೆಗಳು ಹದಗೆಡುವಿಕೆಯನ್ನು ತಡೆಯುತ್ತವೆ," "ನಮ್ಮ ವೇದಿಕೆ ನಕಲಿ ಪರೀಕ್ಷೆಗಳನ್ನು ತಪ್ಪಿಸುತ್ತದೆ." ಸರಿದೂಗಿಸುವಿಕೆಗಳು ನಿಜವಾದಾಗ ಅರ್ಥಶಾಸ್ತ್ರವನ್ನೇ ಪರಿವರ್ತಿಸುತ್ತವೆ ([ICER](../ಹೆಚ್ಚುವರಿ-ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ಅನುಪಾತ/) ಬಿಡಿಸಿದ ಉದಾಹರಣೆ ನೋಡಿ, ಅಲ್ಲಿ £600k ಸರಿದೂಗಿಸುವಿಕೆ ಪ್ರಕರಣವನ್ನು ಗೆಲ್ಲಿಸುತ್ತದೆ). ಪಾವತಿದಾರರಿಗೆ ಇದು ಗೊತ್ತು — ಹೀಗಾಗಿ ಸರಿದೂಗಿಸುವ ಹಕ್ಕುಗಳು ಯಾವುದೇ ಮೌಲ್ಯಮಾಪನದಲ್ಲಿ ಅತ್ಯಂತ ಕಠಿಣ ಪರಿಶೀಲನೆಗೆ ಒಳಗಾಗುತ್ತವೆ. ಕೆಳಗಿನ ವಿಶ್ವಾಸಾರ್ಹತೆ ನಿಯಮಗಳು ಹಣ ನೀಡಲರ್ಹ ಮಾದರಿಯನ್ನು ಮಾರುಕಟ್ಟೆ ಪ್ರಚಾರದಿಂದ ಬೇರ್ಪಡಿಸುತ್ತವೆ.

## ಗಣಿತ

```
Net cost = intervention cost − Σ offsets

A valid offset must be:
  Attributable — causally linked to the intervention (comparator evidence)
  Marginal     — the money actually stops being spent, at marginal not
                 average cost (see marginal-vs-average-cost.md)
  Probability- — weighted by P(the downstream event would have occurred)
  weighted
  Discounted   — future avoided costs at present value
  Unique       — counted once, in one benefit line
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

"ಈ ವಲಸೆ-ಅಪಾಯದ ಹಕ್ಕು, ಸರಿಯಾಗಿ ಮಾಡಿದರೆ": 5,000 ಶಸ್ತ್ರಚಿಕಿತ್ಸೆ-ನಂತರದ ರೋಗಿಗಳಿಗೆ ಗಾಯ-ಮೇಲ್ವಿಚಾರಣೆ ಆ್ಯಪ್ ಸೋಂಕು-ಸಂಬಂಧಿತ ಮರು-ದಾಖಲಾತಿಗಳನ್ನು ತಪ್ಪಿಸುತ್ತದೆ ಎಂದು ಹೇಳುತ್ತದೆ.

```
Baseline readmission for infection: 4.0% ; with app (RCT): 3.1%
Attributable events avoided = 5,000 × 0.009 = 45/year
Cost per readmission spell (marginal, this trust): £3,200
Offset = 45 × 3,200 = £144,000/year
App cost = 5,000 × £20 = £100,000/year
Net cost = −£44,000 → genuinely cost-saving, with:
  attribution from an RCT ✓  marginal costing ✓  probability from trial data ✓
```

"ಮರು-ದಾಖಲಾತಿ ಸರಾಸರಿ £5,800 ವೆಚ್ಚ, ನಾವು ಬಹಳಷ್ಟನ್ನು ತಡೆಯುತ್ತೇವೆ" ಎಂದು ಕಟ್ಟಿದ ಅದೇ ಹಕ್ಕು ನಾಲ್ಕೂ ಪರೀಕ್ಷೆಗಳಲ್ಲಿ ವಿಫಲವಾಗುತ್ತದೆ ಮತ್ತು ಅದಕ್ಕೆ ಸಿಗುವ ತಿರಸ್ಕಾರಕ್ಕೆ ಅರ್ಹ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

"ಈ ವಲಸೆ ಭವಿಷ್ಯದ ಮರುಬರವಣಿಗೆಯನ್ನು ತಪ್ಪಿಸುತ್ತದೆ" ಒಂದು ಸರಿದೂಗಿಸುವ ಹಕ್ಕು, ಮತ್ತು ಆರೋಗ್ಯ-ಅರ್ಥಶಾಸ್ತ್ರ ನಿಯಮಗಳು ಅದನ್ನು ಪ್ರಾಮಾಣಿಕಗೊಳಿಸುತ್ತವೆ:

- **ಪ್ರತಿ-ವಾಸ್ತವಿಕ ವೆಚ್ಚ**: ಮರುಬರವಣಿಗೆ ನಿಜವಾಗಿ ಎಷ್ಟು ವೆಚ್ಚವಾಗುತ್ತದೆ, ಯಾವ ಸಾಕ್ಷ್ಯದೊಂದಿಗೆ?
- **ಸಂಭವನೀಯತೆ**: ಆ ಭವಿಷ್ಯ ಎಷ್ಟು ಸಂಭಾವ್ಯ? (100% ಅಲ್ಲ — ಉತ್ಪನ್ನಗಳು ಕೊಲ್ಲಲ್ಪಡುತ್ತವೆ, ಆದ್ಯತೆಗಳು ಬದಲಾಗುತ್ತವೆ.)
- **ರಿಯಾಯಿತಿ**: 4ನೇ ವರ್ಷದಲ್ಲಿ ತಪ್ಪಿಸಿದ ಮರುಬರವಣಿಗೆ 3.5–10% ರಿಯಾಯಿತಿಯಲ್ಲಿ ಮುಖಬೆಲೆಗಿಂತ ಬಹಳ ಕಡಿಮೆ ಮೌಲ್ಯದ್ದು.
- **ಅನನ್ಯತೆ**: ಅದೇ ತಪ್ಪಿಸಿದ ಮರುಬರವಣಿಗೆಯನ್ನು ತಾಂತ್ರಿಕ-ಸಾಲದ ಸಾಲಿನಲ್ಲೂ ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ ಸಾಲಿನಲ್ಲೂ ಹಕ್ಕು ಸಾಧಿಸಬೇಡಿ.

`Offset value = P(future event) × counterfactual cost × discount factor` — ಆ ಸಾಲನ್ನು ಪ್ರಸ್ತಾವನೆಯಲ್ಲಿ ಬರೆಯಿರಿ, ಅಂದಾಜು ಚರ್ಚಾಸ್ಪದವಾಗುವುದನ್ನು ನೋಡಿ — ಅದೇ ಉದ್ದೇಶ.

## ಎಡವಟ್ಟುಗಳು

- **ದ್ವಿಗುಣ ಎಣಿಕೆ** — ಅದೇ ತಪ್ಪಿಸಿದ ದಾಖಲಾತಿಯನ್ನು ಸರಿದೂಗಿಸುವಿಕೆ, ಹಾಸಿಗೆ-ದಿನಗಳು ಮತ್ತು ವೆಚ್ಚ-ಜೋಡಿಸಿದ QALYಗಳಾಗಿ ಹಕ್ಕು ಸಾಧಿಸುವುದು.
- ನಿಗದಿತ ವೆಚ್ಚಗಳು ಹೇಗಿದ್ದರೂ ಮುಂದುವರಿಯುವ ಘಟನೆಗಳಿಗೆ **ಸರಾಸರಿ-ವೆಚ್ಚದ ಸರಿದೂಗಿಸುವಿಕೆಗಳು**.
- ಕೇವಲ ಸಾಧ್ಯವಿದ್ದ ಕೆಳಹಂತದ ಘಟನೆಗಳ ಮೇಲೆ **ಮೌನ 100% ಸಂಭವನೀಯತೆ**.
- ಪಾವತಿಸಲು ಕೇಳಲಾಗುವ ಪಾವತಿದಾರನಿಗೆ ಉಳಿತಾಯವೆಂದು ಪ್ರಸ್ತುತಪಡಿಸಿದ **ಇತರ ಬಜೆಟ್‌ಗಳಿಗೆ ಸರಿದೂಗಿಸುವಿಕೆ** — [ವಿಶ್ಲೇಷಣಾ ದೃಷ್ಟಿಕೋನ](../ವಿಶ್ಲೇಷಣಾ-ದೃಷ್ಟಿಕೋನ/) ನೋಡಿ.
