# ವೆಚ್ಚ-ಕನಿಷ್ಠೀಕರಣ ವಿಶ್ಲೇಷಣೆ (CMA)

CMA ವೆಚ್ಚಗಳನ್ನು ಮಾತ್ರ ಹೋಲಿಸಿ ಅತ್ಯಂತ ಅಗ್ಗದ ಆಯ್ಕೆಯನ್ನು ಆರಿಸುತ್ತದೆ — ಪರ್ಯಾಯಗಳ ಫಲಿತಾಂಶಗಳು ಸಮಾನವೆಂದು ಪ್ರದರ್ಶಿಸಲ್ಪಟ್ಟಿದ್ದರೆ *ಮಾತ್ರ* ಮಾನ್ಯ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

CMA ಅತ್ಯಂತ ಸರಳ ವಿಶ್ಲೇಷಣೆ ಮತ್ತು ಅತ್ಯಂತ ದುರುಪಯೋಗಿತ. ಸಮಾನತೆಯ ಹೇಳಿಕೆಯೇ ಎಲ್ಲ ಕೆಲಸ ಮಾಡುತ್ತದೆ: ಫಲಿತಾಂಶಗಳು ನಿಜವಾಗಿ ಭಿನ್ನವಾಗಿಲ್ಲದಿದ್ದರೆ (ಜೈವಿಕ-ಸಮಾನ ಔಷಧ vs ಅದರ ಮೂಲ; ಒಂದೇ ವಿಶೇಷಣವನ್ನು ಪೂರೈಸುವ ಒಂದೇ ಸೇವೆಯ ಇಬ್ಬರು ಪೂರೈಕೆದಾರರು), ವೆಚ್ಚವೇ ಏಕೈಕ ಪ್ರಶ್ನೆ ಮತ್ತು CMA ಸರಿ. ಕಟ್ಟುನಿಟ್ಟು ಇರುವುದು ಮೊದಲು ಸಮಾನತೆಯನ್ನು *ಸಾಬೀತುಪಡಿಸುವುದರಲ್ಲಿ* — ಸಾಮಾನ್ಯವಾಗಿ ಪೂರ್ವ-ನಿರ್ದಿಷ್ಟ ಅಂಚಿನೊಂದಿಗೆ ಕೀಳರಿಮೆರಹಿತ ಅಧ್ಯಯನದ ಮೂಲಕ — ಖರೀದಿದಾರರು ಸಾಮಾನ್ಯವಾಗಿ ಬಿಟ್ಟುಬಿಡುವ ಹೆಜ್ಜೆ ಅದೇ.

## ಗಣಿತ

```
Given evidence that Effect_A ≈ Effect_B (within a pre-specified margin δ):
Choose min(Cost_A, Cost_B)

Costs measured from the same perspective, over the same horizon,
including switching/transition costs.
```

ಸಮಾನತೆಯನ್ನು ಸಾಕ್ಷ್ಯೀಕರಿಸಲಾಗದಿದ್ದರೆ, CMA ಅಮಾನ್ಯ — ಬದಲಿಗೆ [CEA](../ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ವಿಶ್ಲೇಷಣೆ/)/[CUA](../ವೆಚ್ಚ-ಉಪಯುಕ್ತತಾ-ವಿಶ್ಲೇಷಣೆ/) ಬಳಸಿ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಒಂದು ಟ್ರಸ್ಟ್ ಎರಡು ವೀಡಿಯೊ-ಸಮಾಲೋಚನೆ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ಗಳ ನಡುವೆ ಆರಿಸುತ್ತದೆ. 3-ತಿಂಗಳ ಸಮಾನಾಂತರ ಪೈಲಟ್ ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ ದರಗಳು 94.1% vs 93.8%, ರೋಗಿ ತೃಪ್ತಿ 4.4 vs 4.4 ಎಂದು ತೋರಿಸುತ್ತದೆ — ವ್ಯತ್ಯಾಸಗಳು ಪೂರ್ವ-ಒಪ್ಪಿದ 2 ಶೇಕಡಾವಾರು ಅಂಕಗಳ δ ಒಳಗೆ. ಫಲಿತಾಂಶಗಳು: ಸಮಾನ. 3 ವರ್ಷಗಳ ವೆಚ್ಚಗಳು:

```
                     Platform A     Platform B
Licences             £360,000       £210,000
Integration          £80,000        £150,000
Training/support     £60,000        £90,000
Total                £500,000       £450,000
```

ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ B £50,000ರಿಂದ ಗೆಲ್ಲುತ್ತದೆ — ಅದರ ಹೆಚ್ಚಿನ ಏಕೀಕರಣ ವೆಚ್ಚ *ಸೇರಿಸಿ*. ಪೈಲಟ್ ಇಲ್ಲದಿದ್ದರೆ, ಸಮಾನತೆಯ ಹೇಳಿಕೆ ಮಾರಾಟಗಾರರ ಕರಪತ್ರಗಳ ಮೇಲೆ ನಿಲ್ಲುತ್ತಿತ್ತು, ಮತ್ತು 1-ಅಂಕದ ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ-ದರ ವ್ಯತ್ಯಾಸ (≈ ವರ್ಷಕ್ಕೆ ಸಾವಿರಾರು ವಿಫಲ ಸಮಾಲೋಚನೆಗಳು) £50,000ವನ್ನು ಕುಬ್ಜಗೊಳಿಸುತ್ತಿತ್ತು.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

CMA ಸರಕು ಖರೀದಿಯ ಔಪಚಾರಿಕ ಆಕಾರ: ಒಂದೇ SLO ಪೂರೈಸುವ ಇಬ್ಬರು CI ಪೂರೈಕೆದಾರರು, ಒಂದೇ ಬಾಳಿಕೆ ವಿಶೇಷಣ ಇರುವ ಎರಡು ಆಬ್ಜೆಕ್ಟ್ ಸ್ಟೋರ್‌ಗಳು. ಆರೋಗ್ಯ-ಅರ್ಥಶಾಸ್ತ್ರದ ಪಾಠ *ಕಾರ್ಯಾಚರಣೆಗಳ ಕ್ರಮ*: ಮೊದಲು ಸಮಾನತೆಯನ್ನು ಸಾಕ್ಷ್ಯೀಕರಿಸಿ (ನಿಮ್ಮ ವರ್ಕ್‌ಲೋಡ್ ವಿರುದ್ಧ ಬೆಂಚ್‌ಮಾರ್ಕ್, ನಿಮ್ಮ SLOಗಳ ವಿರುದ್ಧ ಪೈಲಟ್, ಅಂಚನ್ನು ಮುಂಚಿತವಾಗಿ ಒಪ್ಪಿ), ನಂತರ ಸ್ಥಳಾಂತರ ಸೇರಿದ ಒಟ್ಟು ವೆಚ್ಚಗಳನ್ನು ಹೋಲಿಸಿ. ಮೊದಲ ಹೆಜ್ಜೆ ಇಲ್ಲದೆ "ಅವು ಬಹುತೇಕ ಒಂದೇ, B ಅಗ್ಗ" ಎಂಬುದು ಸಂಸ್ಥೆಗಳು 10% ಅಗ್ಗದ ಮತ್ತು 40% ಕೆಟ್ಟ ಟೂಲ್ ಖರೀದಿಸುವ ವಿಧಾನ. ಉಪಪ್ರಮೇಯ: ಮಾರಾಟಗಾರರು ಬೆಲೆ ವಾದಿಸಿದಾಗ, ಸಮಾನತೆಯನ್ನು ಅವರೇ ನಿಗದಿಪಡಿಸುವಂತೆ ಮಾಡಿ — ಅದು ಇನ್ನೊಂದು ದಿಕ್ಕಿನಲ್ಲೂ ಬದ್ಧಗೊಳಿಸುತ್ತದೆ.

## ಎಡವಟ್ಟುಗಳು

- **ಊಹಿಸಿದ ಸಮಾನತೆ** — ವ್ಯಾಖ್ಯಾನಾತ್ಮಕ ಪಾಪ; ವ್ಯತ್ಯಾಸದ ಸಾಕ್ಷ್ಯದ ಅನುಪಸ್ಥಿತಿ ಸಮಾನತೆಯ ಸಾಕ್ಷ್ಯವಲ್ಲ (ಕಡಿಮೆ-ಶಕ್ತಿಯ ಪೈಲಟ್‌ಗಳು ಉಚಿತವಾಗಿ ಸಮಾನತೆ "ತೋರಿಸುತ್ತವೆ").
- **ಸ್ಥಳಾಂತರ ವೆಚ್ಚಗಳನ್ನು ಬಿಡುವುದು** — ಸ್ಥಳಾಂತರ, ಮರುತರಬೇತಿ ಮತ್ತು ಸಮಾನಾಂತರ ಚಾಲನೆ ವೆಚ್ಚ ಭಾಗಕ್ಕೆ ಸೇರುತ್ತವೆ.
- **ತಪ್ಪು ಫಲಿತಾಂಶಗಳ ಮೇಲೆ ಸಮಾನತೆ**: ಅಳೆದ ಮೆಟ್ರಿಕ್‌ನಲ್ಲಿ ಸಮಾನ, ಮುಖ್ಯವಾದ ಒಂದರಲ್ಲಿ (ಪ್ರವೇಶಾರ್ಹತೆ, ಬಾಲ ಲೇಟೆನ್ಸಿ, ಡೇಟಾ ಎಗ್ರೆಸ್) ಭಿನ್ನ.
