# ಮೌಲ್ಯ-ಉತ್ಪಾದಕ ಸಾಮರ್ಥ್ಯ (ಕಾರ್ಯಾಚರಣೆ ಪರಿವರ್ತನೆ)

ಮೌಲ್ಯ-ಉತ್ಪಾದಕ ಸಾಮರ್ಥ್ಯ ಎಂದರೆ ಮುಕ್ತಗೊಂಡ ಸಮಯದ "ಅವಕಾಶ ಲಾಭ": ನಿಮ್ಮ ಸಾಫ್ಟ್‌ವೇರ್ ಬಿಡುಗಡೆ ಮಾಡುವ ಗಂಟೆಗಳೊಂದಿಗೆ ಆಸ್ಪತ್ರೆ ಈಗ ಏನನ್ನು *ಸಾಧಿಸಬಹುದು*. ಮುಖ್ಯ ಕಾರ್ಯಾಚರಣೆ ಅಧಿಕಾರಿಗಳು ಮತ್ತು ವೈದ್ಯಕೀಯ ನಿರ್ದೇಶಕರಿಗೆ ಇದು ಅತ್ಯಂತ ಮುಖ್ಯವಾದ ಮಾಪನ, ಏಕೆಂದರೆ ಅದು ಅವರನ್ನು ನಿರ್ವಹಿಸುವ ಕರೆನ್ಸಿಯಲ್ಲಿ ಮಾತನಾಡುತ್ತದೆ — ಚಟುವಟಿಕೆ, ಗುರಿಗಳು ಮತ್ತು ಪರಿವರ್ತನೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

NHS ಬೃಹತ್ ಚಿಕಿತ್ಸೆಗೆ-ಉಲ್ಲೇಖ ಬಾಕಿಗಳನ್ನು ಎದುರಿಸುತ್ತದೆ, ಮತ್ತು ರಾಷ್ಟ್ರೀಯ ಕಾಯುವ-ಸಮಯ ಮಾನದಂಡಗಳನ್ನು ತಪ್ಪಿಸುವ ಟ್ರಸ್ಟ್‌ಗಳು ನಿಯಂತ್ರಕ ಪರಿಶೀಲನೆ ಮತ್ತು ಮಧ್ಯಪ್ರವೇಶ ಎದುರಿಸುತ್ತವೆ ([ಚಿಕಿತ್ಸೆಗೆ ಉಲ್ಲೇಖ](../ಚಿಕಿತ್ಸೆಗೆ-ಉಲ್ಲೇಖ/) ನೋಡಿ). ನೇಮಕಾತಿ ನಿಧಾನ ಮತ್ತು ನಿರ್ಬಂಧಿತ; ಕಟ್ಟಡಗಳು ನಿಗದಿತ. ಏಕೈಕ ವೇಗದ ಸನ್ನೆಗೋಲು ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ಸಿಬ್ಬಂದಿ ಮತ್ತು ಸ್ಥಳದಿಂದ ಹೆಚ್ಚು ಮೌಲ್ಯ-ಉತ್ಪಾದಕ ಚಟುವಟಿಕೆ ಪಡೆಯುವುದು. ತಜ್ಞರ ಸಮಯವನ್ನು ಮರಳಿ ಪಡೆಯುವ ಸಾಫ್ಟ್‌ವೇರ್ ಕೇವಲ "ಹಣ ಉಳಿಸುವುದಿಲ್ಲ" — ಅದು *ಸಾಮರ್ಥ್ಯವನ್ನು ಮುದ್ರಿಸುತ್ತದೆ*: ನೇಮಕಾತಿ ಅಥವಾ ನಿರ್ಮಾಣವಿಲ್ಲದೆ ಅಸ್ತಿತ್ವದಲ್ಲಿರಲಾಗದ ಕ್ಲಿನಿಕ್‌ಗಳು, ನಿಗದಿಪಡಿಸಲಾಗದ ಮೌಲ್ಯಮಾಪನಗಳು.

## ಗಣಿತ

```
Hidden capacity created = time released → activity units enabled × scheme value

Activity units: outpatient attendances, pre-op assessments, monitoring reviews
Scheme value:   national tariff / NHS Payment Scheme prices
                (see national-tariff-and-unit-costs.md)
```

ಇದು [ವೈದ್ಯರ ಸಮಯ](../ವೈದ್ಯರ-ಸಮಯ/)ದ ಉತ್ಪಾದನೆ-ಆಧಾರಿತ ಮೌಲ್ಯಮಾಪನ, ಸೇವಾ ಸಾಲಿಗೆ ವಿಸ್ತರಿಸಿ ಕಾರ್ಯಾಚರಣೆ ತಂಡ ಈಗಾಗಲೇ ಯೋಜಿಸುವ ಚಟುವಟಿಕೆ ಘಟಕಗಳಲ್ಲಿ ವ್ಯಕ್ತಪಡಿಸಿದ್ದು.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

Band 6 ತಜ್ಞ ದಾದಿಯರು ಶಸ್ತ್ರಚಿಕಿತ್ಸೆ-ಪೂರ್ವ ಮೌಲ್ಯಮಾಪನ ಕ್ಲಿನಿಕ್‌ಗಳನ್ನು ನಡೆಸುತ್ತಾರೆ. ದಾಖಲೀಕರಣ ಸ್ವಯಂಚಾಲನ 25 ದಾದಿಯರಲ್ಲಿ ಪ್ರತಿಯೊಬ್ಬರಿಗೆ ದಿನಕ್ಕೆ 1 ಗಂಟೆ ಮರಳಿ ನೀಡುತ್ತದೆ; ಪ್ರತಿ ಗಂಟೆಗೆ 2 ಮೌಲ್ಯಮಾಪನಗಳು ಹೊಂದುತ್ತವೆ.

```
Extra assessments = 25 nurses × 2/day × 250 days = 12,500/year
At ~£120 scheme value per pre-op assessment:
  12,500 × £120 = £1.5M/year of care capacity created
```

— ಒಬ್ಬ ದಾದಿಯನ್ನೂ ನೇಮಿಸದೆ ಅಥವಾ ಒಂದು ಕೋಣೆಯನ್ನೂ ಕಟ್ಟದೆ. (ಈ ಕರಡು ಮೂಲತಃ ಉಲ್ಲೇಖಿಸಿದ ವ್ಯಾಪಕವಾಗಿ ಉಲ್ಲೇಖಿತ ಮಾದರಿ ಚಿಕ್ಕ ಸಮೂಹಕ್ಕೆ ವರ್ಷಕ್ಕೆ £766,920 ಎಂದು ಹೇಳಿತ್ತು; ಅಂಕಗಣಿತ ಮಾದರಿ ಒಂದೇ — ಸಂಖ್ಯೆ ದಾದಿಯರು × ಅವಧಿಗಳು × ದರಪಟ್ಟಿಯೊಂದಿಗೆ ಮಾಪನಗೊಳ್ಳುತ್ತದೆ.) COOಗೆ ಕಾರ್ಯಾಚರಣೆ ಚೌಕಟ್ಟು: ಶಸ್ತ್ರಚಿಕಿತ್ಸೆ-ಪೂರ್ವ ಮೌಲ್ಯಮಾಪನ ಶಸ್ತ್ರಚಿಕಿತ್ಸಾ ಪಟ್ಟಿಗಳ ಮೇಲೆ ನಿರ್ಬಂಧವಾಗುವುದನ್ನು ನಿಲ್ಲಿಸುತ್ತದೆ — ಅದೇ-ದಿನ ರದ್ದಾದ ಶಸ್ತ್ರಚಿಕಿತ್ಸೆಗಳು ಇಳಿಯುತ್ತವೆ, ಮತ್ತು ಶಸ್ತ್ರಚಿಕಿತ್ಸಾ-ಕೊಠಡಿ ಬಳಕೆ ಏರುತ್ತದೆ, *ಮುಂದಿನ* ಲಾಭ ಸಾಲು ಅಲ್ಲಿ ಆರಂಭವಾಗುತ್ತದೆ ([ಕೆಳಹಂತದ ಸಂಪನ್ಮೂಲ ಅತ್ಯುತ್ತಮೀಕರಣ](../ಕೆಳಹಂತದ-ಸಂಪನ್ಮೂಲ-ಅತ್ಯುತ್ತಮೀಕರಣ/) ನೋಡಿ).

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಅದೇ ಮರುಚೌಕಟ್ಟು ಡೆವಲಪರ್-ಉತ್ಪಾದಕತೆ ಹಕ್ಕುಗಳನ್ನು ವೇತನ ಗಣಿತದಿಂದ ರಕ್ಷಿಸುತ್ತದೆ: ಮುಕ್ತಗೊಂಡ ಎಂಜಿನಿಯರಿಂಗ್ ಸಮಯ, ಸಂಸ್ಥೆ ಬೇರೆ ರೀತಿ ಭರಿಸಲಾಗದ *ತಲುಪಿಸಿದ ಸಾಮರ್ಥ್ಯ* — ವೈಶಿಷ್ಟ್ಯಗಳು, ವಲಸೆಗಳು, ವಿಶ್ವಾಸಾರ್ಹತೆ ಕೆಲಸ — ಎಂದು ವ್ಯಕ್ತಪಡಿಸಿ, ಸಂಸ್ಥೆ ಅಂತಹ ಸಾಮರ್ಥ್ಯಕ್ಕೆ ಸೀಮಾಂತದಲ್ಲಿ ಪಾವತಿಸುವುದರಲ್ಲಿ (ಗುತ್ತಿಗೆದಾರ ದರಗಳು, ಅಥವಾ ಮುಂದೂಡಿದ-ನೇಮಕಾತಿ ಸಮಾನಗಳು) ಮೌಲ್ಯ ಕಟ್ಟಿ. COO ಚೌಕಟ್ಟು ವೇದಿಕೆ ಕೆಲಸವನ್ನು ಮಂಡಿಸುವ ಬಗ್ಗೆಯೂ ಏನನ್ನೋ ಕಲಿಸುತ್ತದೆ: ಲಾಭವನ್ನು ಪ್ರೇಕ್ಷಕರನ್ನು ನಿರ್ವಹಿಸುವ ಘಟಕಗಳಲ್ಲಿ ವ್ಯಕ್ತಪಡಿಸಿ. ಕಾರ್ಯಾಚರಣೆ ನಾಯಕರು ಅಮೂರ್ತ ಗಂಟೆಗಳಲ್ಲಿ ಅಲ್ಲ, ಚಟುವಟಿಕೆ ಮತ್ತು ಗುರಿಗಳಲ್ಲಿ ಯೋಚಿಸುತ್ತಾರೆ; ಎಂಜಿನಿಯರಿಂಗ್ ನಾಯಕರು ಉಳಿಸಿದ ನಿಮಿಷಗಳಲ್ಲಿ ಅಲ್ಲ, ಮಾರ್ಗಸೂಚಿ ಅಂಶಗಳು ಮತ್ತು ತಲೆಗಣತಿಯಲ್ಲಿ ಯೋಚಿಸುತ್ತಾರೆ.

## ಎಡವಟ್ಟುಗಳು

- **ಬೇಡಿಕೆಯಿಲ್ಲದ ಸಾಮರ್ಥ್ಯ ಹಕ್ಕುಗಳು**: 12,500 ಹೆಚ್ಚುವರಿ ಮೌಲ್ಯಮಾಪನ ಸ್ಲಾಟ್‌ಗಳು ಶಸ್ತ್ರಚಿಕಿತ್ಸಾ ಕೊಳವೆ ಅವನ್ನು ತುಂಬಿದರೆ ಮಾತ್ರ ಮುಖ್ಯ — ಕೆಳಹಂತದ ನಿರ್ಬಂಧವನ್ನು ಪರಿಶೀಲಿಸಿ.
- **ಪಾವತಿ ಕಾರ್ಯವಿಧಾನವಿಲ್ಲದ ದರಪಟ್ಟಿ ಮೌಲ್ಯ**: ಮಿಶ್ರ ಪಾವತಿಯಡಿ, ಹೆಚ್ಚುವರಿ ಚಟುವಟಿಕೆ ಹೆಚ್ಚುವರಿ ಆದಾಯ ತರದಿರಬಹುದು; ಮೌಲ್ಯ ಬದಲಿಗೆ ಕಾಯುವ-ಪಟ್ಟಿ ಇಳಿಕೆಯಾಗಿರಬಹುದು ([ಕಾಯುವ ಪಟ್ಟಿ ಪ್ರಭಾವ](../ಕಾಯುವ-ಪಟ್ಟಿಯ-ಪರಿಣಾಮ/) ನೋಡಿ).
- **ಸಾಮರ್ಥ್ಯವನ್ನು ನಗದಾಗಿ ಪ್ರಸ್ತುತಪಡಿಸುವುದು** — ಇದು ಪ್ರಮುಖ ನಗದು-ರಹಿತ ಲಾಭ; ಲೇಬಲ್ ಮಾಡಿ ([ನಗದು-ಬಿಡುಗಡೆ vs ನಗದು-ರಹಿತ](../ನಗದು-ಬಿಡುಗಡೆ-vs-ನಗದು-ರಹಿತ-ಉಳಿತಾಯ/) ನೋಡಿ).
