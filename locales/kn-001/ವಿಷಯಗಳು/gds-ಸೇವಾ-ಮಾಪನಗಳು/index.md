# GDS ಸೇವಾ ಮಾಪನಗಳು

ಯುಕೆ ಸರ್ಕಾರಿ ಡಿಜಿಟಲ್ ಸೇವೆ (GDS) ಸೇವಾ ಕೈಪಿಡಿ ಪ್ರತಿ ಸರ್ಕಾರಿ ಡಿಜಿಟಲ್ ಸೇವೆಗೆ ನಾಲ್ಕು KPIಗಳನ್ನು ಕಡ್ಡಾಯಗೊಳಿಸುತ್ತದೆ: **ಪ್ರತಿ ವಹಿವಾಟಿಗೆ ವೆಚ್ಚ, ಬಳಕೆದಾರ ತೃಪ್ತಿ, ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ ದರ, ಮತ್ತು ಡಿಜಿಟಲ್ ಸ್ವೀಕಾರ**. ಒಟ್ಟಾಗಿ ಅವು ಸಾರ್ವಜನಿಕ ಡಿಜಿಟಲ್ ಸೇವೆಯ ಕನಿಷ್ಠ ಅರ್ಥಶಾಸ್ತ್ರ — ಮತ್ತು NHS ಡಿಜಿಟಲ್ ಸೇವೆಗಳು ಪಡೆಯುವ ಮಾದರಿ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

GDS ಮಾಪನಗಳು ಸರ್ಕಾರದ ಒಂದು ದಶಕದ ಡಿಜಿಟಲೀಕರಣಕ್ಕೆ ಹಣ ನೀಡಿದ ಚಾನೆಲ್-ಬದಲಾವಣೆ ವ್ಯಾಪಾರ ಸಮರ್ಥನೆಯನ್ನು ಸಂಕೇತಿಸುತ್ತವೆ: ಡಿಜಿಟಲ್ ದಕ್ಷತೆ ವರದಿ ಡಿಜಿಟಲ್ ವಹಿವಾಟುಗಳು ಫೋನ್‌ಗಿಂತ ~20× ಮತ್ತು ಮುಖಾಮುಖಿಗಿಂತ ~50× ಅಗ್ಗ ಎಂದು ಕಂಡುಕೊಂಡಿತು (ಸ್ಥಳೀಯ-ಸರ್ಕಾರ ಅಂಕಿಗಳು: ವೆಬ್ £0.15, ಫೋನ್ £2.83, ಮುಖಾಮುಖಿ £8.62). ಆದರೆ ಜನರು ದುಬಾರಿ ಚಾನೆಲ್‌ನ *ಬದಲು* (ಸ್ವೀಕಾರ) ಡಿಜಿಟಲ್ ಪ್ರಯಾಣವನ್ನು *ಪೂರ್ಣಗೊಳಿಸಿದಾಗ* (ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ ದರ) ಮಾತ್ರ ಉಳಿತಾಯ ಸಾಕಾರಗೊಳ್ಳುತ್ತದೆ — ನಾಲ್ಕು KPIಗಳು ಒಂದೇ ಆರ್ಥಿಕ ಮಾದರಿ, ನಾಲ್ಕು ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ಗಳಲ್ಲ.

## ಗಣಿತ

```
Cost per transaction = total service cost / completed transactions
Completion rate      = completed / started transactions × 100
Digital take-up      = digital transactions / all-channel transactions × 100
User satisfaction    = % satisfied+very satisfied (5-point, in-service survey)

Channel-shift saving = volume × take-up shift × (cost_old_channel − cost_digital)
… minus failure demand: (1 − completion rate) × fallback channel cost
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

NHS ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್-ನಿರ್ವಹಣೆ ಸೇವೆ: ವರ್ಷಕ್ಕೆ 2M ವಹಿವಾಟುಗಳು, ಪ್ರಸ್ತುತ 70% ಫೋನ್ (£3.20/ಕರೆ) / 30% ಡಿಜಿಟಲ್ (£0.25). ಮರುವಿನ್ಯಾಸ ಡಿಜಿಟಲ್ ಸ್ವೀಕಾರವನ್ನು 55%ಕ್ಕೆ ಮತ್ತು ಪೂರ್ಣಗೊಳಿಸುವಿಕೆಯನ್ನು 84%ರಿಂದ 93%ಕ್ಕೆ ಏರಿಸುತ್ತದೆ:

```
Take-up shift saving = 2M × 0.25 × (3.20 − 0.25) = £1,475,000/year

Failure-demand saving: failed digital journeys fall back to phone
  before: 2M × 0.30 × 0.16 × £3.20 = £307,200
  after:  2M × 0.55 × 0.07 × £3.20 = £246,400
  net £60,800/year — completion improvements protect the take-up gains

Satisfaction is the leading indicator: dissatisfied users revert to phone,
so a satisfaction drop forecasts take-up decay before it appears.
```

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಈ ನಾಲ್ಕು KPIಗಳು [ವೆಚ್ಚ-ಪರಿಣಾಮ ಕೋಷ್ಟಕ](../ವೆಚ್ಚ-ಪರಿಣಾಮ-ವಿಶ್ಲೇಷಣೆ/)ದ ಉತ್ಪಾದನಾ-ದರ್ಜೆ ಉದಾಹರಣೆ: ಒಂದು ವೆಚ್ಚ ಮಾಪನ, ಮೂರು ಫಲಿತಾಂಶ ಮಾಪನಗಳು, ಎಂದಿಗೂ ಅಂಕಕ್ಕೆ ಕುಸಿಯುವುದಿಲ್ಲ. ಉತ್ಪನ್ನ ಎಂಜಿನಿಯರ್‌ಗಳಿಗೆ ಕಾರ್ಯಾಚರಣೆ ಪಾಠಗಳು: **ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ ದರ ಕೊಳವೆ-ಉಪಕರಣ ಸಮಸ್ಯೆ** (ಪ್ರತಿ ಕೈಬಿಡುವ ಬಿಂದುವನ್ನು ಕಂಡುಹಿಡಿದು ಸರಿಪಡಿಸಬಹುದು); **ಪ್ರತಿ ವಹಿವಾಟಿಗೆ ವೆಚ್ಚ [ಕ್ಲೌಡ್ ಘಟಕ ಅರ್ಥಶಾಸ್ತ್ರ](../ಕ್ಲೌಡ್-ಘಟಕ-ಅರ್ಥಶಾಸ್ತ್ರ/)** ಜೊತೆಗೆ ಸಿಬ್ಬಂದಿ-ಸಹಾಯಿತ ಚಾನೆಲ್ ವೆಚ್ಚಗಳು; **ಸ್ವೀಕಾರ ಮರೆಮಾಚಿದ ಸಮಾನತೆ ಮಾಪನ** — ಚಾನೆಲ್ ಬದಲಿಸಲಾಗದ ಅಥವಾ ಬದಲಿಸದ ಬಳಕೆದಾರರು ಅಸಮಾನವಾಗಿ ವೃದ್ಧರು, ಅಂಗವಿಕಲರು ಮತ್ತು ವಂಚಿತರು, ಆದ್ದರಿಂದ ಆಕ್ರಮಣಕಾರಿ ಚಾನೆಲ್ ಮುಚ್ಚುವಿಕೆ "ಉಳಿತಾಯ"ಗಳನ್ನು ಪ್ರವೇಶ ಹಾನಿಯಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ ([ವ್ಯಾಪ್ತಿ ಮತ್ತು ಸಮಾನತೆ](../ವ್ಯಾಪ್ತಿ-ಮತ್ತು-ಸಮಾನತೆ/) ನೋಡಿ). KPIಗಳನ್ನು ಪ್ರಕಟಿಸುವುದೂ (GOV.UK ಪ್ರತಿ ಸೇವೆಗೆ ಮಾಡುತ್ತದೆ) ಒಂದು ಕಾರ್ಯವಿಧಾನ: [ಲಾಭ ಸಾಕ್ಷಾತ್ಕಾರ](../ಲಾಭ-ಸಾಕ್ಷಾತ್ಕಾರ/) ಲೆಕ್ಕಪರಿಶೋಧನೆಗಳಂತೆ ಪಾರದರ್ಶಕತೆ ಮುನ್ಸೂಚನೆಗಳನ್ನು ಶಿಸ್ತುಗೊಳಿಸುತ್ತದೆ.

## ಎಡವಟ್ಟುಗಳು

- **ಬಲವಂತದ ಸ್ವೀಕಾರ**: ಫೋನ್ ಲೈನ್ ಮುಚ್ಚುವುದು ಸ್ವೀಕಾರವನ್ನು ಏರಿಸುತ್ತದೆ ಮತ್ತು ವೈಫಲ್ಯ ಬೇಡಿಕೆಯನ್ನು ಮುಂಚೂಣಿ ಸಿಬ್ಬಂದಿಯ ಮೇಲೆ ಎಸೆಯುತ್ತದೆ; ಒಟ್ಟು-ವ್ಯವಸ್ಥೆ ವೆಚ್ಚವನ್ನು ಅಳೆಯಿರಿ.
- **ಪುಟ-2ರಿಂದ ಅಳೆದ ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ**: ಕೈಬಿಡುವ ಬಿಂದುವಿನ ನಂತರ ಕೊಳವೆಯನ್ನು ಆರಂಭಿಸುವುದು ದರಕ್ಕೆ ಮುಖಸ್ತುತಿ ಮಾಡುತ್ತದೆ.
- **ಸಹಾಯಿತ-ಡಿಜಿಟಲ್ ಬೆಂಬಲ ಮತ್ತು ವೈಫಲ್ಯ-ಬೇಡಿಕೆ ನಿರ್ವಹಣೆಯನ್ನು ನಿರ್ಲಕ್ಷಿಸುವ ಪ್ರತಿ-ವಹಿವಾಟು ವೆಚ್ಚ**.
- **ಯಶಸ್ವಿ ಪೂರ್ಣಗೊಳಿಸುವಿಕೆಯಲ್ಲಿ ಮಾತ್ರ ತೃಪ್ತಿ ಸಮೀಕ್ಷೆಗಳು** — ಅತೃಪ್ತರು ಹೆಚ್ಚಾಗಿ ಸಮೀಕ್ಷೆಯನ್ನು ತಲುಪುವುದೇ ಇಲ್ಲ.
