# ತಪ್ಪಿಸಬಹುದಾದ ಹೊರಗುತ್ತಿಗೆ ವೆಚ್ಚಗಳು

ಒಂದು ಟ್ರಸ್ಟ್ ಆಂತರಿಕ ಸಾಮರ್ಥ್ಯದಿಂದ ಗುರಿಗಳನ್ನು ಸಾಧಿಸಲಾಗದಾಗ, ಅದು ಪ್ರೀಮಿಯಂ ದರಗಳಲ್ಲಿ ಸಾಮರ್ಥ್ಯವನ್ನು ಖರೀದಿಸುತ್ತದೆ: ತನ್ನ ಸಿಬ್ಬಂದಿಗೇ ವಾರಾಂತ್ಯದ ಅಧಿಕಾವಧಿ, ಅಥವಾ ಖಾಸಗಿ ಒದಗಿಸುವವರಿಗೆ ಕಾರ್ಯವಿಧಾನಗಳ ಹೊರಗುತ್ತಿಗೆ. ಸಾಮರ್ಥ್ಯ-ಬಿಡುಗಡೆ ಸಾಫ್ಟ್‌ವೇರ್‌ನ ಆರ್ಥಿಕ ಮೌಲ್ಯದಲ್ಲಿ ಆ ಪ್ರೀಮಿಯಂ-ದರ ಕೆಲಸದ **ತಪ್ಪಿಸಬಹುದಾದ ವೆಚ್ಚ** ಸೇರಿದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಐಚ್ಛಿಕ-ಚೇತರಿಕೆ ಒತ್ತಡದಲ್ಲಿ ಟ್ರಸ್ಟ್‌ಗಳು ನಿಯಮಿತವಾಗಿ ಖಾಸಗಿ-ವಲಯದ ತಕ್ಷಣದ ಬೆಲೆಗಳನ್ನು (ಹೆಚ್ಚಾಗಿ NHS ಯೋಜನಾ ಬೆಲೆಯ 1.2–1.5×) ಅಥವಾ ವಾರಾಂತ್ಯದ ಪಟ್ಟಿಗಳಿಗೆ ತಮ್ಮ ಸಲಹೆಗಾರರಿಗೇ ಪ್ರೀಮಿಯಂ ಕಾಯುವ-ಪಟ್ಟಿ-ಉಪಕ್ರಮ ದರಗಳನ್ನು ಪಾವತಿಸುತ್ತವೆ. ಸಾಮಾನ್ಯ ಸಾಮರ್ಥ್ಯ ಹೇಳಿಕೆಗಳಂತಲ್ಲದೆ, ತಪ್ಪಿಸಿದ ಹೊರಗುತ್ತಿಗೆ **ನಗದು-ಬಿಡುಗಡೆ**: ಖಾಸಗಿ ಒದಗಿಸುವವರಿಗೆ ಇನ್‌ವಾಯ್ಸ್ ನಿಜವಾಗಿಯೂ ಏರುವುದಿಲ್ಲ. ಇದು ಆಂತರಿಕ ಥ್ರೂಪುಟ್ ಹೆಚ್ಚಿಸುವ ಸಾಫ್ಟ್‌ವೇರ್‌ಗೆ ಲಭ್ಯವಿರುವ ಅತ್ಯಂತ ಬಲವಾದ ಲಾಭ ಸಾಲುಗಳಲ್ಲಿ ಒಂದು — ಮತ್ತು ಸಾಕ್ಷ್ಯ ನೀಡಲು ಸುಲಭವಾದದ್ದು, ಏಕೆಂದರೆ ಹೊರಗುತ್ತಿಗೆ ಖರ್ಚು ಈಗಾಗಲೇ ಕಾಣುವ ಬಜೆಟ್ ಸಾಲು.

## ಗಣಿತ

```
Avoidable outsourcing cost = activity moved in-house × (outsourced unit price
                             − internal marginal cost per case)

Internal marginal cost: consumables + variable staffing for the extra activity
— the fixed estate is already paid for (see marginal-vs-average-cost.md).
```

ಹಕ್ಕು ಸಾಧಿಸಲು ಬಿಡುಗಡೆಯಾದ ಆಂತರಿಕ ಸಾಮರ್ಥ್ಯ ನಿಜವಾಗಿ ಆ ಚಟುವಟಿಕೆಯನ್ನು ಹೀರಿಕೊಳ್ಳಬೇಕು: ಶಸ್ತ್ರಚಿಕಿತ್ಸಾ ಕೊಠಡಿ ಅವಧಿಗಳು, ಹಾಸಿಗೆಗಳು ಮತ್ತು ಸಿಬ್ಬಂದಿ ಎಲ್ಲವೂ ಲಭ್ಯವಿರಬೇಕು (ಬಂಧಿಸುವ ನಿರ್ಬಂಧ ನಿಯಂತ್ರಿಸುತ್ತದೆ — ಮತ್ತೆ ನಿರ್ಬಂಧಗಳ ಸಿದ್ಧಾಂತ).

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಒಂದು ಟ್ರಸ್ಟ್ ವರ್ಷಕ್ಕೆ 800 ಕಣ್ಣಿನ ಪೊರೆ ಕಾರ್ಯವಿಧಾನಗಳನ್ನು ತಲಾ £900ಕ್ಕೆ ಹೊರಗುತ್ತಿಗೆ ನೀಡುತ್ತದೆ: ವರ್ಷಕ್ಕೆ £720,000 ಬಾಹ್ಯ ಖರ್ಚು, ಯೋಜನಾ ಬೆಲೆ ~£750ಕ್ಕೆ ಹೋಲಿಸಿದರೆ.

ಶಸ್ತ್ರಚಿಕಿತ್ಸಾ-ಕೊಠಡಿ ವೇಳಾಪಟ್ಟಿ ಸಾಫ್ಟ್‌ವೇರ್ (ಪಟ್ಟಿ ಅತ್ಯುತ್ತಮೀಕರಣ, ರದ್ದತಿಗಳಿಂದ ಅಂತರ ಭರ್ತಿ, ತಿರುವು-ಸಮಯ ಟ್ರ್ಯಾಕಿಂಗ್) ಆಂತರಿಕ ಶಸ್ತ್ರಚಿಕಿತ್ಸಾ-ಕೊಠಡಿ ಬಳಕೆಯನ್ನು ಸಾಕಷ್ಟು ಹೆಚ್ಚಿಸಿ 500 ಕಾರ್ಯವಿಧಾನಗಳನ್ನು ಮರಳಿ ತರುತ್ತದೆ:

```
Internal marginal cost per case ≈ £350 (consumables + sessional staffing)
Saving = 500 × (900 − 350) = £275,000/year — cash-releasing
Remaining outsourcing: 300 × £900 = £270,000 (was £720,000)
```

ಸಾಫ್ಟ್‌ವೇರ್ ವೆಚ್ಚ ವರ್ಷಕ್ಕೆ £90,000 → ನಿವ್ವಳ ≈ **ವರ್ಷಕ್ಕೆ +£185,000 ಬ್ಯಾಂಕ್ ಮಾಡಬಹುದಾದ ನಗದು**, ಜೊತೆಗೆ ಕೆಲಸವನ್ನು ಆಂತರಿಕವಾಗಿ ಉಳಿಸಿಕೊಳ್ಳುವ ಗುಣಮಟ್ಟ ಮತ್ತು ತರಬೇತಿ ಲಾಭಗಳು.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ನೇರ ಸಮಾನಾಂತರ **ಗುತ್ತಿಗೆದಾರ ಮತ್ತು ಸಲಹಾ ಸಂಸ್ಥೆ ಪ್ರೀಮಿಯಂ**: ಆಂತರಿಕ ಎಂಜಿನಿಯರಿಂಗ್ ಸಾಮರ್ಥ್ಯ ಬದ್ಧತೆಗಳನ್ನು ಪೂರೈಸಲಾಗದಾಗ, ಸಂಸ್ಥೆಗಳು ಆಂತರಿಕ ಲೋಡ್ ಮಾಡಿದ ದರಗಳ 1.5–3× ದರದಲ್ಲಿ ಬಾಹ್ಯ ಸಾಮರ್ಥ್ಯ ಖರೀದಿಸುತ್ತವೆ. ಆಂತರಿಕ ಥ್ರೂಪುಟ್ ಹೆಚ್ಚಿಸುವ ವೇದಿಕೆ ಮತ್ತು ಉತ್ಪಾದಕತೆ ಹೂಡಿಕೆಗಳು ತಪ್ಪಿಸಿದ ಗುತ್ತಿಗೆದಾರ ಖರ್ಚನ್ನು ಮೇಲಿನಂತೆಯೇ ಹಕ್ಕು ಸಾಧಿಸಬೇಕು — ಬಾಹ್ಯ ದಿನ-ದರ ಮೈನಸ್ ಆಂತರಿಕ ಸೀಮಾಂತ ವೆಚ್ಚ, ಗುಣಿಸಿ ಮರಳಿ ತಂದ ಕೆಲಸ — ಏಕೆಂದರೆ ಡೆವಲಪರ್-ಉತ್ಪಾದಕತೆ ವ್ಯಾಪಾರ ಸಮರ್ಥನೆಯಲ್ಲಿ ನಿಜವಾಗಿ ನಗದು-ಬಿಡುಗಡೆ ಮಾಡುವ ಕೆಲವೇ ಸಾಲುಗಳಲ್ಲಿ ಇದೂ ಒಂದು. ಅದೇ ಎಚ್ಚರಿಕೆ ಇಲ್ಲೂ ಅನ್ವಯಿಸುತ್ತದೆ: ಆಂತರಿಕ ಸಾಮರ್ಥ್ಯ ನಿಜವಾಗಿ ಇರಬೇಕು ಮತ್ತು ಮರಳಿ ತಂದ ಕೆಲಸಕ್ಕೆ ನಿಗದಿಯಾಗಿರಬೇಕು, ಇಲ್ಲದಿದ್ದರೆ ಹಕ್ಕು ಕಲ್ಪನೆ.

## ಎಡವಟ್ಟುಗಳು

- **ಪೂರ್ಣ ಸಾಮರ್ಥ್ಯ ಸರಪಳಿ ಇಲ್ಲದೆ ಮರಳಿ ತರುವ ಹಕ್ಕು** — ಶಸ್ತ್ರಚಿಕಿತ್ಸಕರು ಮುಕ್ತರಾದರೂ ಶಸ್ತ್ರಚಿಕಿತ್ಸಾ-ಕೊಠಡಿ ಸ್ಲಾಟ್‌ಗಳಿಲ್ಲ (ಅಥವಾ ಎಂಜಿನಿಯರ್‌ಗಳು ಮುಕ್ತರಾದರೂ ಉತ್ಪನ್ನ-ನಿರ್ವಹಣೆ ಸಾಮರ್ಥ್ಯವಿಲ್ಲ) ಎಂದರೆ ಏನನ್ನೂ ಮರಳಿ ತರಲಾಗದು.
- **ಹೊರಗುತ್ತಿಗೆ ಬೆಲೆಯನ್ನು ಸೀಮಾಂತ ವೆಚ್ಚದ ಬದಲು ಆಂತರಿಕ ಸರಾಸರಿ ವೆಚ್ಚದೊಂದಿಗೆ ಹೋಲಿಸುವುದು** — ವಿಚಿತ್ರವೆಂದರೆ ಉಳಿತಾಯವನ್ನು ಕಡಿಮೆ ಹೇಳುತ್ತದೆ; ನಿಗದಿತ ವೆಚ್ಚಗಳು ಎರಡೂ ರೀತಿ ನಡೆಯುತ್ತವೆ.
- **ಗುಣಮಟ್ಟ/ಸಂಕೀರ್ಣತೆಯ ಅಸಮಮಿತಿ**: ಹೊರಗುತ್ತಿಗೆ ನೀಡಿದ ಪ್ರಕರಣಗಳು ಹೆಚ್ಚಾಗಿ ಸರಳವಾದವು; ಅವನ್ನು ಮರಳಿ ತರುವುದು ಆಂತರಿಕ ಪ್ರಕರಣ ಮಿಶ್ರಣ ಮತ್ತು ಘಟಕ ವೆಚ್ಚಗಳನ್ನು ಬದಲಿಸುತ್ತದೆ.
