# ಪ್ರಾಬಲ್ಯ ಮತ್ತು ದಕ್ಷತಾ ಗಡಿ

ಇನ್ನೊಂದು ಆಯ್ಕೆ ಕಡಿಮೆ ವೆಚ್ಚದಲ್ಲಿ *ಮತ್ತು* ಹೆಚ್ಚು ಫಲಿತಾಂಶ ನೀಡಿದರೆ ಒಂದು ಆಯ್ಕೆ **ಪ್ರಾಬಲ್ಯಕ್ಕೊಳಗಾಗಿದೆ**. **ದಕ್ಷತಾ ಗಡಿ** ಎಂದರೆ ಪ್ರಾಬಲ್ಯಕ್ಕೊಳಗಾದ ಆಯ್ಕೆಗಳನ್ನು ತೆಗೆದುಹಾಕಿದ ನಂತರ ಉಳಿಯುವುದು: ಹೆಚ್ಚು ಪಡೆಯಲು ಹೆಚ್ಚು ಪಾವತಿಸಬೇಕಾದ ಆಯ್ಕೆಗಳ ಗುಂಪು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಮಿತಿಗಳು ಅಥವಾ ಬಜೆಟ್‌ಗಳ ಬಗ್ಗೆ ಯಾವುದೇ ಚರ್ಚೆಯ ಮೊದಲು, ಆರೋಗ್ಯ ತಂತ್ರಜ್ಞಾನ ಮೌಲ್ಯಮಾಪನವು ಮೊದಲು ಯಾರೂ ಎಂದಿಗೂ ಆರಿಸಬಾರದ ಆಯ್ಕೆಗಳನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ. ಪ್ರತಿ ಆಯ್ಕೆಯನ್ನು ವೆಚ್ಚ-ವಿರುದ್ಧ-ಪರಿಣಾಮ ಸಮತಲದಲ್ಲಿ ಚಿತ್ರಿಸಿ ಗಡಿಯನ್ನು ಎಳೆಯುವುದು ಐದು ನಿಮಿಷದ ಕೆಲಸ, ಮತ್ತು ಅದು ನಿಯಮಿತವಾಗಿ ಶಾರ್ಟ್‌ಲಿಸ್ಟ್‌ನ ಅರ್ಧವನ್ನು ಕೊಲ್ಲುತ್ತದೆ. ನಂತರ ಹೆಚ್ಚುವರಿ ಹೋಲಿಕೆಗಳನ್ನು ([ICERಗಳು](../ಹೆಚ್ಚುವರಿ-ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ಅನುಪಾತ/)) ಗಡಿಯ *ಉದ್ದಕ್ಕೆ* ಮಾತ್ರ ಲೆಕ್ಕಿಸಲಾಗುತ್ತದೆ, ಪ್ರತಿ ಆಯ್ಕೆಯನ್ನು ಮುಂದಿನ-ಅಗ್ಗದ ಪ್ರಾಬಲ್ಯರಹಿತ ಆಯ್ಕೆಯ ವಿರುದ್ಧ — ಉತ್ತಮ ಮಧ್ಯಂತರ ಆಯ್ಕೆಗಳಿರುವಾಗ ಎಂದಿಗೂ "ಏನೂ ಮಾಡದಿರುವುದರ" ವಿರುದ್ಧ ಅಲ್ಲ.

## ಗಣಿತ

```
Strict dominance:   A dominates B if Cost_A ≤ Cost_B and Effect_A ≥ Effect_B
                    (with at least one strict inequality)

Extended dominance: B is ruled out if a mix of A and C achieves more effect
                    per pound — detected when ICERs decrease as you move up
                    the frontier. Valid frontier ICERs must be increasing.
```

ವಿಧಾನ: ಆಯ್ಕೆಗಳನ್ನು ಪರಿಣಾಮದ ಪ್ರಕಾರ ವಿಂಗಡಿಸಿ; ಕಟ್ಟುನಿಟ್ಟಾಗಿ ಪ್ರಾಬಲ್ಯಕ್ಕೊಳಗಾದವನ್ನು ತೆಗೆಯಿರಿ; ನೆರೆಯವರ ನಡುವಿನ ಜೋಡಿ ICERಗಳನ್ನು ಲೆಕ್ಕಿಸಿ; ICER ಮುಂದಿನ ಹೆಚ್ಚು-ಪರಿಣಾಮಕಾರಿ ಆಯ್ಕೆಗಿಂತ ಹೆಚ್ಚಿರುವ ಯಾವುದೇ ಆಯ್ಕೆಯನ್ನು ತೆಗೆಯಿರಿ (ವಿಸ್ತೃತ ಪ್ರಾಬಲ್ಯ); ICERಗಳು ಏಕತಾನವಾಗಿ ಏರುವವರೆಗೆ ಪುನರಾವರ್ತಿಸಿ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ತಪ್ಪಿದ ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್‌ಗಳನ್ನು ಕಡಿಮೆ ಮಾಡಲು ನಾಲ್ಕು ಆಯ್ಕೆಗಳು (ಪರಿಣಾಮ = ವರ್ಷಕ್ಕೆ ಮರುಪಡೆದ ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್‌ಗಳು):

```
Option          Cost/yr    Recovered
Do nothing      £0         0
SMS reminders   £20,000    2,000
Phone calls     £120,000   2,200
SMS + AI triage £90,000    3,500
```

ಫೋನ್ ಕರೆಗಳು SMS + AI ಟ್ರಯಾಜ್‌ನಿಂದ **ಕಟ್ಟುನಿಟ್ಟಾಗಿ ಪ್ರಾಬಲ್ಯಕ್ಕೊಳಗಾಗಿವೆ** (ಹೆಚ್ಚು ವೆಚ್ಚ, ಕಡಿಮೆ ಮರುಪಡೆಯುವಿಕೆ). ಗಡಿ: ಏನೂ ಇಲ್ಲ → SMS → SMS + AI.

```
ICER(SMS vs nothing)   = 20,000 / 2,000  = £10 per appointment recovered
ICER(SMS+AI vs SMS)    = (90,000 − 20,000) / (3,500 − 2,000) = £46.67 per appointment
```

ಏರುತ್ತಿರುವ ICERಗಳು → ಮಾನ್ಯ ಗಡಿ. ಮರುಪಡೆದ ಪ್ರತಿ ಆಸ್ಪತ್ರೆ ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್‌ಗೆ ~£160 ಉಳಿತಾಯದಲ್ಲಿ ([ಹಾಜರಾಗದ ದರ](../ಹಾಜರಾಗದ-dna-ದರ/) ನೋಡಿ), ಗಡಿಯ ಎರಡೂ ಹಂತಗಳು ತೆಗೆದುಕೊಳ್ಳಲು ಯೋಗ್ಯ; ಫೋನ್-ಬ್ಯಾಂಕ್ ಪ್ರಸ್ತಾವನೆ ಸಮಿತಿಯನ್ನು ಎಂದಿಗೂ ತಲುಪಬಾರದು.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಯಾವುದೇ ಟೂಲಿಂಗ್ ನಿರ್ಧಾರಕ್ಕೆ ಅದೇ ಚಾರ್ಟ್ ನಿರ್ಮಿಸಿ: ಒಂದು ಅಕ್ಷದಲ್ಲಿ ವರ್ಷಕ್ಕೆ ವೆಚ್ಚ, ಇನ್ನೊಂದರಲ್ಲಿ ಅಳೆದ ಫಲಿತಾಂಶ (ಉಳಿತಾಯವಾದ ಗಂಟೆಗಳು, ತಪ್ಪಿಸಿದ ಘಟನೆಗಳು, ಸಾಧ್ಯವಾದ ಡಿಪ್ಲಾಯ್‌ಗಳು). ಗಡಿಯ ಮೇಲ್-ಎಡಕ್ಕಿರುವ ಬಿಂದುಗಳನ್ನು ಬಜೆಟ್ ಬಗ್ಗೆ ಯಾರಾದರೂ ವಾದಿಸುವ ಮೊದಲೇ ತೆಗೆದುಹಾಕಲಾಗುತ್ತದೆ. ಇದು ಮಾರಾಟಗಾರರ ಆಯ್ಕೆಯನ್ನು ವೈಶಿಷ್ಟ್ಯ-ಪರಿಶೀಲನಾಪಟ್ಟಿ ಚರ್ಚೆಗಳಿಂದ "ನೀವು ಪ್ರಾಬಲ್ಯಕ್ಕೊಳಗಾಗಿದ್ದೀರಿ; ಸಭೆ ಮುಗಿಯಿತು" ಎಂಬುದಕ್ಕೆ ಮರುರೂಪಿಸುತ್ತದೆ. ಕನಿಷ್ಠ ಲಾಭಕ್ಕಾಗಿ ಅತ್ಯಂತ ದುಬಾರಿ ಆಯ್ಕೆಯನ್ನು ಖರೀದಿಸುವ ಸಾಮಾನ್ಯ ಉದ್ಯಮ ಮಾದರಿಯನ್ನೂ ಇದು ಬಯಲು ಮಾಡುತ್ತದೆ — ಹೆಚ್ಚುವರಿ ಘಟಕದ ಹೆಚ್ಚುವರಿ ಬೆಲೆ ಸಂಸ್ಥೆಯು ತಿಳಿದೂ ಪಾವತಿಸುವಂಥದ್ದಾದರೆ ಮಾತ್ರ ಅದು ನ್ಯಾಯಸಮ್ಮತ.

## ಎಡವಟ್ಟುಗಳು

- ಗಡಿಯ ಮುಂದಿನ ಆಯ್ಕೆಯ ಬದಲು **ಎಲ್ಲವನ್ನೂ ಮೂಲರೇಖೆಗೆ ಹೋಲಿಸುವುದು** — ಇದು ಅಗ್ಗದ ಬಹುತೇಕ-ಸಮಾನ ಆಯ್ಕೆಗಳನ್ನು ಅಡಗಿಸಿ ದುಬಾರಿ ಆಯ್ಕೆಗಳನ್ನು ಹೊಗಳುತ್ತದೆ.
- ಮುಖ್ಯವಾದುದನ್ನು ಅಡಗಿಸುವ **ಏಕ-ಆಯಾಮದ ಪರಿಣಾಮ ಅಂಕಗಳು**; ಎರಡು ಫಲಿತಾಂಶಗಳು ಮುಖ್ಯವಾದರೆ, ಅವನ್ನು ಸಮರ್ಥನೀಯವಾಗಿ ಸಂಯೋಜಿಸಿ ([ವೆಚ್ಚ-ಉಪಯುಕ್ತತಾ ವಿಶ್ಲೇಷಣೆ](../ವೆಚ್ಚ-ಉಪಯುಕ್ತತಾ-ವಿಶ್ಲೇಷಣೆ/) ನೋಡಿ) ಅಥವಾ ಎರಡು ಗಡಿಗಳನ್ನು ತೋರಿಸಿ.
- **ಅನಿಶ್ಚಿತತೆಯನ್ನು ಮರೆಯುವುದು**: ಗಡಿಯ ಹತ್ತಿರದ ಆಯ್ಕೆಗಳು [ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ](../ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/)ಯಡಿ ಸ್ಥಾನ ಬದಲಿಸಬಹುದು.
