# ಪಾವತಿಸಲು ಇಚ್ಛೆಯ ಮಿತಿಗಳು

ಪಾವತಿಸಲು ಇಚ್ಛೆಯ (WTP) ಮಿತಿ ಎಂದರೆ ಆರೋಗ್ಯ ಲಾಭದ ಪ್ರತಿ ಘಟಕಕ್ಕೆ ನಿರ್ಧಾರಕರು ಪಾವತಿಸಲು ಸಿದ್ಧರಿರುವ ಗರಿಷ್ಠ ಮೊತ್ತ — [ICER](../ಹೆಚ್ಚುವರಿ-ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ಅನುಪಾತ/) ಅನ್ನು ಅಳವಡಿಸು/ತಿರಸ್ಕರಿಸು ನಿರ್ಧಾರವನ್ನಾಗಿ ಪರಿವರ್ತಿಸುವ ಗೆರೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಆರೋಗ್ಯ ಅರ್ಥಶಾಸ್ತ್ರವು ಮಾಪನವನ್ನು ನಿಲ್ಲಿಸಿ ನೀತಿಯಾಗುವ ಸ್ಥಳ ಮಿತಿ. ಪ್ರತಿ ರಾಷ್ಟ್ರೀಯ ವ್ಯವಸ್ಥೆಗೂ ಒಂದು ಇರುತ್ತದೆ, ಸ್ಪಷ್ಟ ಅಥವಾ ಪರೋಕ್ಷ, ಮತ್ತು ಸ್ಥಳೀಯ ಸಂಖ್ಯೆ ತಿಳಿದರೆ ಆರೋಗ್ಯ-ಮೌಲ್ಯದ ಹೇಳಿಕೆಗೆ ಹೇಗೆ ಬೆಲೆ ಕಟ್ಟಬೇಕು ಎಂದು ನಿಖರವಾಗಿ ತಿಳಿಯುತ್ತದೆ:

| ಸಂಸ್ಥೆ | ಮಿತಿ (ಸಂಶೋಧಿಸಿದಂತೆ, 2024–2025) |
|---|---|
| NICE (ಇಂಗ್ಲೆಂಡ್) | ಪ್ರತಿ QALYಗೆ £20,000–£30,000; ಅನುಭವಾಧಾರಿತ ಸರಾಸರಿ ನಿರ್ಧಾರ ಮಿತಿ ≈ £24,400 (2022–24); ತೀವ್ರತಾ ಮಾರ್ಪಾಡುಗಳು ಪರಿಣಾಮಕಾರಿ ಮೇಲ್ಮಿತಿಯನ್ನು ~£36k–£51kಗೆ ಏರಿಸುತ್ತವೆ; ಅತಿ-ವಿಶೇಷ ತಂತ್ರಜ್ಞಾನಗಳಿಗೆ £100k+ ವರೆಗೆ |
| ICER (ಅಮೆರಿಕ, ಸರ್ಕಾರೇತರ) | ಪ್ರತಿ QALY/evLYGಗೆ $100,000–$150,000 ಬೆಲೆ ಮಾನದಂಡಗಳು; $50k–$200k ವ್ಯಾಪ್ತಿ ವರದಿ ಮಾಡುತ್ತದೆ |
| ಕೆನಡಾ (CADTH / CDA-AMC) | ≈ ಪ್ರತಿ QALYಗೆ CAD$50,000 ಕಾರ್ಯನಿರ್ವಹಣಾ ಮಿತಿ |
| WHO-CHOICE (ಐತಿಹಾಸಿಕ, ಜಾಗತಿಕ) | ತಪ್ಪಿಸಿದ ಪ್ರತಿ DALYಗೆ ತಲಾ GDPಯ 1–3× (ಈಗ ತೀರಾ ಒರಟು ಎಂದು ನಿರುತ್ಸಾಹಗೊಳಿಸಲಾಗಿದೆ) |
| ಅನುಭವಾಧಾರಿತ ಯುಕೆ ಪೂರೈಕೆ ಕಡೆ (Claxton ಮತ್ತು ಇತರರು) | NHS ಅಂಚಿನಲ್ಲಿ ವಾಸ್ತವವಾಗಿ ಸ್ಥಾನಪಲ್ಲಟಗೊಂಡ ≈ ಪ್ರತಿ QALYಗೆ £13,000 |

## ಗಣಿತ

ಮಿತಿ λ ಪ್ರತಿ ನಿರ್ಧಾರ ನಿಯಮದಲ್ಲೂ ಪ್ರವೇಶಿಸುತ್ತದೆ:

```
Adopt if ICER = ΔC/ΔE < λ
Equivalently: adopt if NMB = λ×ΔE − ΔC > 0
```

λ *ಎಂದರೇನು* ಎಂಬ ಬಗ್ಗೆ ಎರಡು ಸಿದ್ಧಾಂತಗಳು:

- **ಬೇಡಿಕೆಯ ಕಡೆ**: ಆರೋಗ್ಯಕ್ಕಾಗಿ ಸಮಾಜ ಪಾವತಿಸಲು ಸಿದ್ಧವಿರುವುದು (ಮೌಲ್ಯ ನಿರ್ಣಯ).
- **ಪೂರೈಕೆಯ ಕಡೆ**: ಬಜೆಟ್ ಪ್ರಸ್ತುತ ಅಂಚಿನಲ್ಲಿ ಉತ್ಪಾದಿಸುವ ಆರೋಗ್ಯ (ಅನುಭವಾಧಾರಿತ ಪ್ರಮಾಣ — Claxtonರ ~£13k/QALY). ನಿರ್ಧಾರಗಳಿಗೆ ಬಳಸಿದ λ ಪೂರೈಕೆ-ಕಡೆಯ ದರವನ್ನು ಮೀರಿದರೆ, ಹೊಸ ತಂತ್ರಜ್ಞಾನ ಅನುಮೋದಿಸುವುದು ಅದು ಸೇರಿಸುವುದಕ್ಕಿಂತ ಹೆಚ್ಚು ಆರೋಗ್ಯವನ್ನು ಸ್ಥಾನಪಲ್ಲಟಗೊಳಿಸುತ್ತದೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ನಿಮ್ಮ ಡಿಜಿಟಲ್ ಚಿಕಿತ್ಸಕ ಪ್ರತಿ ಚಿಕಿತ್ಸೆ ಪಡೆದ ರೋಗಿಗೆ £800 ನಿವ್ವಳ ವೆಚ್ಚದಲ್ಲಿ (ಬೆಲೆ ಮೈನಸ್ ಸರಿದೂಗಿಕೆಗಳು) 0.05 QALY ನೀಡುತ್ತದೆ.

```
ICER = 800 / 0.05 = £16,000 per QALY
```

- ಇಂಗ್ಲೆಂಡ್: £20kಗಿಂತ ಕೆಳಗೆ → ಹಣ ನೀಡಬಹುದು. ಸಮರ್ಥನೀಯ ಗರಿಷ್ಠ ಬೆಲೆ: λ = £20,000ದಲ್ಲಿ, price_max = 0.05 × 20,000 + ಸರಿದೂಗಿಕೆಗಳು = £1,000 + ಸರಿದೂಗಿಕೆಗಳು.
- $150k/QALYಯಲ್ಲಿ ಅಮೆರಿಕದ ವಾಣಿಜ್ಯ ಚೌಕಟ್ಟು: ಮೌಲ್ಯ-ಆಧಾರಿತ ಬೆಲೆ ಬಹಳ ಹೆಚ್ಚು.
- ತಲಾ GDP ಮಿತಿ $4,000 ಇರುವ ದೇಶ: ಅದೇ ಉತ್ಪನ್ನದ ನಿವ್ವಳ ವೆಚ್ಚ ಸುಮಾರು $200ಕ್ಕಿಂತ ಕಡಿಮೆ ಇರಬೇಕು.

ಅದೇ ಉತ್ಪನ್ನ, ಮೂರು ಮಾರುಕಟ್ಟೆಗಳು, ಮೂರು ಬೆಲೆಗಳು — ಮಿತಿಯೇ ಬೆಲೆ ಮಾದರಿ. ಇದು λ ನಿಂದ ಹಿಮ್ಮುಖವಾಗಿ ನಡೆಸಿದ ಮೌಲ್ಯ-ಆಧಾರಿತ ಬೆಲೆ ನಿಗದಿ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಪ್ರತಿ ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಸ್ಥೆಗೂ ಪರೋಕ್ಷ λ ಇದೆ: ಉಳಿತಾಯವಾದ ಎಂಜಿನಿಯರ್-ಗಂಟೆಗೆ ಟೂಲಿಂಗ್‌ಗೆ ಹಣ ನೀಡುವ ಅಡ್ಡಗೋಡೆ. ಅದನ್ನು ಸ್ಪಷ್ಟಪಡಿಸುವುದು — "ನಂಬಲರ್ಹವಾಗಿ ಉಳಿತಾಯವಾದ ಪ್ರತಿ ಎಂಜಿನಿಯರ್-ಗಂಟೆಗೆ £40ಕ್ಕಿಂತ ಕಡಿಮೆಯದಕ್ಕೆ ನಾವು ಹಣ ನೀಡುತ್ತೇವೆ" — ಪ್ರತಿ-QALY ವೆಚ್ಚದ ಲೀಗ್ ಕೋಷ್ಟಕಗಳು ಆರೋಗ್ಯ ವೆಚ್ಚವನ್ನು ಶ್ರೇಣೀಕರಿಸುವಂತೆಯೇ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಹೂಡಿಕೆಗಳ ಲೀಗ್-ಕೋಷ್ಟಕ ಹೋಲಿಕೆಯನ್ನು ಸಾಧ್ಯವಾಗಿಸುತ್ತದೆ. ಪೂರೈಕೆ-ಕಡೆಯ ಪಾಠವೂ ವರ್ಗಾವಣೆಯಾಗುತ್ತದೆ: ನಿಮ್ಮ ನಿಜವಾದ ಆಂತರಿಕ λ ಎಂದರೆ ನಿಮ್ಮ *ಪ್ರಸ್ತುತ* ಬ್ಯಾಕ್‌ಲಾಗ್ ಅಂಚಿನಲ್ಲಿ ಉತ್ಪಾದಿಸುವುದು, ನಾಯಕತ್ವ ಸಮಯಕ್ಕೆ ಇದೆ ಎಂದು ಹೇಳುವ ಮೌಲ್ಯವಲ್ಲ.

## ಎಡವಟ್ಟುಗಳು

- ನ್ಯಾಯವ್ಯಾಪ್ತಿಗಳಾದ್ಯಂತ **ಮಿತಿ ಶಾಪಿಂಗ್**, ಅಥವಾ ಸಾಮಾನ್ಯ ಉತ್ಪನ್ನಕ್ಕೆ HST ಮೇಲ್ಮಿತಿಯನ್ನು ಉಲ್ಲೇಖಿಸುವುದು.
- **λ ಅನ್ನು ಬೆಲೆ ತಳಮಟ್ಟ ಎಂದು ಪರಿಗಣಿಸುವುದು**: ಮಿತಿಯನ್ನು ದಾಟುವುದು ಅಗತ್ಯ, ಸಾಕಾಗದು — ಪ್ರತಿ-ಘಟಕಕ್ಕೆ ಭರಿಸಬಲ್ಲ ಉತ್ಪನ್ನವನ್ನೂ [ಬಜೆಟ್ ಪರಿಣಾಮ](../ಬಜೆಟ್-ಪರಿಣಾಮ-ವಿಶ್ಲೇಷಣೆ/) ಮುಳುಗಿಸಬಹುದು.
- **ಮಿತಿಗಳು ಚಲಿಸುತ್ತವೆ ಎಂಬುದನ್ನು ಕಡೆಗಣಿಸುವುದು**: NICEಯ ತೀವ್ರತಾ ಮಾರ್ಪಾಡುಗಳು (2022) ಮತ್ತು ಆವರ್ತಕ ವಿಮರ್ಶೆಗಳು ಪರಿಣಾಮಕಾರಿ λ ಬದಲಿಸುತ್ತವೆ; ನಿಮ್ಮ ಹೇಳಿಕೆಗಳಿಗೆ ದಿನಾಂಕ ಹಾಕಿ.
- **ಪರಿವರ್ತಿಸದೆ ಬೇರೆ ಕರೆನ್ಸಿಯ ಮಿತಿಗೆ ICER ಹೋಲಿಸುವುದು**: [ಅಡ್ಡ-ಕರೆನ್ಸಿ ICER ಹೋಲಿಕೆ](../ಅಡ್ಡ-ಕರೆನ್ಸಿ-icer-ಹೋಲಿಕೆ/) ನೋಡಿ — ಪರಿವರ್ತನಾ ವಿಧಾನ (ಖರೀದಿ ಸಾಮರ್ಥ್ಯ ಸಮಾನತೆ vs ಮಾರುಕಟ್ಟೆ ವಿನಿಮಯ ದರ) ವಿಧಾನಶಾಸ್ತ್ರೀಯವಾಗಿ ಪರಿಣಾಮಕಾರಿ, ಪೂರ್ಣಾಂಕದ ವಿವರವಲ್ಲ.
- **λ-ಆಧಾರಿತ ಮೌಲ್ಯಮಾಪನವನ್ನು ಕಾರ್ಮಿಕ-ಮಾರುಕಟ್ಟೆ VSL/VPF ಸಂಪ್ರದಾಯದೊಂದಿಗೆ ಗೊಂದಲಗೊಳಿಸುವುದು**: ಇವು ಬೇರೆ ಬೇರೆ ಸೈದ್ಧಾಂತಿಕ ಸಂಪ್ರದಾಯಗಳಿಂದ ಬರುತ್ತವೆ (ಆರೋಗ್ಯ-ಬಜೆಟ್-ನಿರ್ಬಂಧಿತ ವಿಧಾನಶಾಸ್ತ್ರ vs ವೇತನ-ಅಪಾಯ ವಿನಿಮಯಗಳಿಂದ ಬಹಿರಂಗ ಆದ್ಯತೆ) ಮತ್ತು ಯಾವಾಗಲೂ ಹೊಂದಾಣಿಕೆಯಾಗುವುದಿಲ್ಲ — ಜೀವಕ್ಕೆ ಬೆಲೆ ಕಟ್ಟುವ ಪರ್ಯಾಯ ಬಹಿರಂಗ-ಆದ್ಯತೆ ವಿಧಾನಕ್ಕಾಗಿ [ಸಾಂಖ್ಯಿಕ ಜೀವದ ಮೌಲ್ಯ](../ಸಾಂಖ್ಯಿಕ-ಜೀವದ-ಮೌಲ್ಯ/) ನೋಡಿ.
