# ಪರಿಪೂರ್ಣ ಮಾಹಿತಿಯ ನಿರೀಕ್ಷಿತ ಮೌಲ್ಯ (EVPI)

EVPI ಎಂದರೆ ನಿರ್ಧರಿಸುವ ಮೊದಲು ಅನಿಶ್ಚಿತತೆಯನ್ನು ತೊಡೆದುಹಾಕಲು ನಿರ್ಧಾರಕರು ಪಾವತಿಸಬೇಕಾದ ಗರಿಷ್ಠ ಮೊತ್ತ — "ಮೊದಲು ಒಂದು ಅಧ್ಯಯನ ನಡೆಸೋಣ" ಎಂಬುದರ ಔಪಚಾರಿಕ ಬೆಲೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಆರೋಗ್ಯ ವ್ಯವಸ್ಥೆಗಳು ನಿರಂತರವಾಗಿ ಈ ಆಯ್ಕೆ ಎದುರಿಸುತ್ತವೆ: ಅಪೂರ್ಣ ಸಾಕ್ಷ್ಯದ ಮೇಲೆ ಈಗಲೇ ಅಳವಡಿಸಿಕೊಳ್ಳುವುದು, ಅಥವಾ ಮೊದಲು ಹೆಚ್ಚಿನ ಸಂಶೋಧನೆಗೆ ಹಣ ನೀಡುವುದು. EVPI ಎರಡನೇ ಆಯ್ಕೆಗೆ ಒಂದು ಸಂಖ್ಯೆ ಕೊಡುತ್ತದೆ. EVPI £50,000 ಮತ್ತು ಪ್ರಸ್ತಾವಿತ ಪ್ರಯೋಗಕ್ಕೆ £2 ಮಿಲಿಯನ್ ವೆಚ್ಚವಾದರೆ, ಈಗಲೇ ಅಳವಡಿಸಿ. EVPI £20 ಮಿಲಿಯನ್ ಆದರೆ, ಪ್ರಯೋಗ ಚೌಕಾಸಿ. ಅದೇ ಪ್ರಶ್ನೆ — "ಹೊರತರುವ ಮೊದಲು ಇದನ್ನು ಪೈಲಟ್ ಮಾಡಬೇಕೇ?" — ಪ್ರತಿ ಉದ್ಯಮ ಟೂಲ್ ನಿರ್ಧಾರದಲ್ಲೂ ಎದುರಾಗುತ್ತದೆ, ಮತ್ತು ಬಹುತೇಕ ಯಾರೂ ಅದಕ್ಕೆ ಬೆಲೆ ಕಟ್ಟುವುದಿಲ್ಲ. ಮೊದಲು ಮಾಹಿತಿ ಸಂಗ್ರಹಿಸುವ ಆಯ್ಕೆಯಲ್ಲ, ಯೋಜನೆಯನ್ನು ನಂತರ ವಿಸ್ತರಿಸುವ ಆಯ್ಕೆಗೆ ಬೆಲೆ ಕಟ್ಟಲು [ರಿಯಲ್ ಆಪ್ಷನ್ಸ್ ಮೌಲ್ಯಮಾಪನ](../ರಿಯಲ್-ಆಪ್ಷನ್ಸ್-ಮೌಲ್ಯಮಾಪನ/) ನೋಡಿ.

## ಗಣಿತ

EVPI ಎಂದರೆ ಪರಿಪೂರ್ಣ ದೂರದೃಷ್ಟಿಯೊಂದಿಗೆ ನಿರ್ಧರಿಸುವುದು ಮತ್ತು ನಿರೀಕ್ಷೆಗಳ ಮೇಲೆ ಈಗಲೇ ನಿರ್ಧರಿಸುವುದರ ನಡುವಿನ ಅಂತರ:

```
EVPI = E_θ[ max_j NMB(j, θ) ]  −  max_j E_θ[ NMB(j, θ) ]

θ        = uncertain parameters (with their joint distribution)
NMB(j,θ) = net monetary benefit of option j given θ
```

ಮೊದಲ ಪದ: ಸಂಭವನೀಯ ಪ್ರತಿ ಜಗತ್ತಿನಲ್ಲಿ ಅತ್ಯುತ್ತಮ-ಆಯ್ಕೆಯ ಪ್ರತಿಫಲದ ಸರಾಸರಿ (ನೀವು ಯಾವಾಗಲೂ ಸರಿಯಾದದನ್ನೇ ಆರಿಸುತ್ತೀರಿ). ಎರಡನೇ ಪದ: ಸರಾಸರಿಯಲ್ಲಿ ಅತ್ಯುತ್ತಮವಾದ ಏಕೈಕ ಆಯ್ಕೆಯ ಪ್ರತಿಫಲ (ನೀವು ಈಗಲೇ ಬದ್ಧರಾಗಬೇಕು). EVPI ≥ 0 ಯಾವಾಗಲೂ. ಜನಸಂಖ್ಯಾ EVPI ಬಾಧಿತ ನಿರ್ಧಾರಗಳ ಸಂಖ್ಯೆಯಿಂದ ಗುಣಿಸುತ್ತದೆ. [PSA](../ಸಂಭಾವ್ಯತಾ-ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/) ಮಾದರಿಗಳಿಂದ ನೇರವಾಗಿ ಲೆಕ್ಕಿಸಲಾಗುತ್ತದೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

5,000 ವೈದ್ಯರಿಗೆ AI ದಾಖಲೆ ಸಹಾಯಕವನ್ನು ಹೊರತರುವುದು, ಅಥವಾ ಇಲ್ಲ. ಎರಡು ಜಗತ್ತುಗಳು:

```
World A (p = 0.6): assistant saves 20 min/day → NMB of rollout = +£8M
World B (p = 0.4): assistant saves ~0 (workflow friction) → NMB of rollout = −£3M
NMB of "don't roll out" = £0 in both worlds.
```

ಈಗಲೇ ನಿರ್ಧರಿಸಿ: E[ಹೊರತರುವಿಕೆಯ NMB] = 0.6 × 8 − 0.4 × 3 = **+£3.6M** → ಹೊರತನ್ನಿ.

ಪರಿಪೂರ್ಣ ಮಾಹಿತಿಯೊಂದಿಗೆ: ಜಗತ್ತು A ಯಲ್ಲಿ ಹೊರತರುವುದನ್ನು ಆರಿಸಿ (+£8M), ಜಗತ್ತು B ಯಲ್ಲಿ ಏನೂ ಮಾಡದಿರುವುದನ್ನು (£0). ನಿರೀಕ್ಷಿತ ಮೌಲ್ಯ = 0.6 × 8 + 0.4 × 0 = **£4.8M**.

```
EVPI = 4.8M − 3.6M = £1.2M
```

ನೀವು ಯಾವ ಜಗತ್ತಿನಲ್ಲಿದ್ದೀರಿ ಎಂಬುದನ್ನು ಗಣನೀಯವಾಗಿ ಬಗೆಹರಿಸುವ £150,000 ವೆಚ್ಚದ ಕಠಿಣ 3-ತಿಂಗಳ ಪೈಲಟ್ ನಿಸ್ಸಂದೇಹವಾಗಿ ಯೋಗ್ಯ — ಮತ್ತು £1.2M ಗಿಂತ ಹೆಚ್ಚು ವೆಚ್ಚವಾಗುವ ಯಾವುದೇ ಪೈಲಟ್ ಎಷ್ಟೇ ಸಮಗ್ರವಾಗಿದ್ದರೂ ಯೋಗ್ಯವಲ್ಲ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

EVPI ಎಂದರೆ ಸ್ಪೈಕ್, ಪೈಲಟ್, A/B ಪರೀಕ್ಷೆ ಮತ್ತು ಪ್ರೂಫ್-ಆಫ್-ಕಾನ್ಸೆಪ್ಟ್‌ನ ಅರ್ಥಶಾಸ್ತ್ರ. ಇದು ಎರಡು ಪ್ರಾಯೋಗಿಕ ನಿಯಮಗಳನ್ನು ನೀಡುತ್ತದೆ:

- **ನಿರ್ಧಾರ ನಿಜವಾಗಿ ಬದಲಾಗಬಲ್ಲದಾದರೆ ಮಾತ್ರ ಪೈಲಟ್‌ಗೆ ಹಣ ನೀಡುವುದು ಯೋಗ್ಯ.** ಪೈಲಟ್ ಫಲಿತಾಂಶ ಏನೇ ಇದ್ದರೂ ನೀವು ಹೊರತರುವುದಾದರೆ, EVPI = 0 ಮತ್ತು ಪೈಲಟ್ ನಾಟಕ.
- **ಪೈಲಟ್ ವೆಚ್ಚವನ್ನು EVPIಗೆ ಮಿತಿಗೊಳಿಸಿ.** ಮಾಹಿತಿಯ ಮೌಲ್ಯವು ಅದು ತಿಳಿಸುವ ನಿರ್ಧಾರದ ಮೌಲ್ಯದಿಂದ ಮಿತಿಗೊಂಡಿದೆ.

ಭಾಗಶಃ EVPI (EVPPI) ಇದನ್ನು ಏಕ ನಿಯತಾಂಕಗಳಿಗೆ ವಿಸ್ತರಿಸುತ್ತದೆ: "ಉಳಿತಾಯವಾದ-ಸಮಯದ ಸಂಖ್ಯೆಯನ್ನು ನಿರ್ದಿಷ್ಟವಾಗಿ ಖಚಿತಪಡಿಸುವುದರ ಮೌಲ್ಯವೇನು?" — ಪೈಲಟ್ ಏನನ್ನು ಅಳೆಯಬೇಕು ಎಂದು ಇದು ತಿಳಿಸುತ್ತದೆ. ಎಲ್ಲ ಅನಿಶ್ಚಿತತೆಯನ್ನು ತೊಡೆಯುವ ಬದಲು *ನಿರ್ದಿಷ್ಟ* ಪ್ರಸ್ತಾವಿತ ಅಧ್ಯಯನಕ್ಕೆ ಬೆಲೆ ಕಟ್ಟಲು [EVSI](../ಮಾದರಿ-ಮಾಹಿತಿಯ-ನಿರೀಕ್ಷಿತ-ಮೌಲ್ಯ/) ನೋಡಿ.

## ಎಡವಟ್ಟುಗಳು

- **ನಿರ್ಧಾರ ನಿಯಮ ಜೋಡಿಸದೆ ಪೈಲಟ್‌ಗಳನ್ನು ನಡೆಸುವುದು** — ಆಯ್ಕೆಯನ್ನು ಬದಲಿಸಲಾಗದ ಮಾಹಿತಿ ವ್ಯಾಖ್ಯಾನದಿಂದಲೇ ಮೌಲ್ಯರಹಿತ.
- **ಮಾಹಿತಿ ಸಂಗ್ರಹಿಸುವ ವಿಳಂಬ ವೆಚ್ಚವನ್ನು ಕಡೆಗಣಿಸುವುದು**: 6-ತಿಂಗಳ ಪೈಲಟ್ 6 ತಿಂಗಳ ಲಾಭವನ್ನು ವಿಳಂಬಗೊಳಿಸುತ್ತದೆ ([ವಿಳಂಬದ ವೆಚ್ಚ](../ವಿಳಂಬದ-ವೆಚ್ಚ/)); ಪೈಲಟ್‌ನ ನಿವ್ವಳ ಮೌಲ್ಯ = ಬಗೆಹರಿದ EVPI − ವಿಳಂಬ ವೆಚ್ಚ − ಪೈಲಟ್ ವೆಚ್ಚ.
- **EVPI ಅನ್ನು ಮುನ್ಸೂಚನೆ ಎಂದು ಪರಿಗಣಿಸುವುದು.** ಅದು ಮಾಹಿತಿ ಮೌಲ್ಯದ ಮೇಲಿನ ಮಿತಿ, ನಿರ್ದಿಷ್ಟ ಅಧ್ಯಯನ ಏನು ನೀಡುತ್ತದೆ ಎಂಬುದರ ಅಂದಾಜಲ್ಲ.
