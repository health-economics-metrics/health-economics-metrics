# ಮಾರ್ಕೊವ್ ಸಮೂಹ ಅನುಕರಣೆ

ಮಾರ್ಕೊವ್ ಸಮೂಹ ಮಾದರಿ ಒಂದೇ ಬಾರಿಯಲ್ಲಿ ಅಲ್ಲ, ಬಹು ಕಾಲಾವಧಿಗಳಲ್ಲಿ (ಚಕ್ರಗಳು) ಪರಿಣಾಮಗಳು ತೆರೆದುಕೊಳ್ಳುವ ಮಧ್ಯಸ್ಥಿಕೆಗಳಿಗೆ ಪ್ರಮಾಣಿತ HTA ಮಾದರಿ ತಂತ್ರ. ಊಹಾತ್ಮಕ ಸಮೂಹ ಸಂಪೂರ್ಣವಾಗಿ ಒಂದು ಆರೋಗ್ಯ ಸ್ಥಿತಿಯಲ್ಲಿ ಆರಂಭವಾಗುತ್ತದೆ, ಮತ್ತು ಪ್ರತಿ ಚಕ್ರದಲ್ಲಿ ನಿಗದಿತ ಪರಿವರ್ತನೆ ಸಂಭವನೀಯತೆಗಳ ಸಮೂಹ ಸಮೂಹದ ಭಿನ್ನರಾಶಿಗಳನ್ನು ಸ್ಥಿತಿಗಳ ನಡುವೆ ಚಲಿಸುತ್ತದೆ; ವೆಚ್ಚಗಳು ಮತ್ತು QALYಗಳು ಪ್ರತಿ ಚಕ್ರ ಪ್ರತಿ ಸ್ಥಿತಿಯನ್ನು ಸಮೂಹದ ಎಷ್ಟು ಭಾಗ ಆಕ್ರಮಿಸಿದೆ ಎಂಬುದರ ಅನುಪಾತದಲ್ಲಿ ಸಂಚಯವಾಗುತ್ತವೆ, ಮತ್ತು ವರ್ತಮಾನ ಮೌಲ್ಯಕ್ಕೆ ರಿಯಾಯಿತಿ ಮಾಡಲ್ಪಡುತ್ತವೆ. ಬಹು-ವರ್ಷದ ಡಿಜಿಟಲ್-ಆರೋಗ್ಯ ವ್ಯಾಪಾರ ಸಮರ್ಥನೆಯನ್ನು ಮಾದರಿ ಮಾಡುವ ಯಾವುದೇ ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರ್ — ಅಲ್ಲಿ ಬಳಕೆದಾರರು ಅಥವಾ ರೋಗಿಗಳು ಕಾಲಾನಂತರ "ತೊಡಗಿದ", "ನಿಷ್ಕ್ರಿಯ" ಅಥವಾ "ಬಿಟ್ಟುಹೋದ" ಸ್ಥಿತಿಗಳ ನಡುವೆ ಚಲಿಸುತ್ತಾರೆ — ಇದೇ ರಚನೆಯನ್ನು ನಿರ್ಮಿಸುತ್ತಿದ್ದಾನೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಹೆಚ್ಚಿನ ನೈಜ ಆರೋಗ್ಯ-ತಂತ್ರಜ್ಞಾನ ನಿರ್ಧಾರಗಳು ಒಂದು ಅವಧಿಯ ವೆಚ್ಚ ಮತ್ತು ಫಲಿತಾಂಶದ ಒಂದು-ಬಾರಿ ಹೋಲಿಕೆಗಳಲ್ಲ. ದೀರ್ಘಕಾಲಿಕ ಸ್ಥಿತಿ ವರ್ಷಗಳಲ್ಲಿ ಪ್ರಗತಿಸುತ್ತದೆ, ಮರುಕಳಿಸುತ್ತದೆ, ಚಿಕಿತ್ಸೆಗೆ ಸ್ಪಂದಿಸುತ್ತದೆ ಅಥವಾ ಕೊಲ್ಲುತ್ತದೆ — ಮತ್ತು ಒಂದು-ಅವಧಿಯ [ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ವಿಶ್ಲೇಷಣೆ](../ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ವಿಶ್ಲೇಷಣೆ/) ಅದನ್ನು ಪ್ರತಿನಿಧಿಸಲಾರದು. [ಆರೋಗ್ಯ ತಂತ್ರಜ್ಞಾನ ಮೌಲ್ಯಮಾಪನ](../ಆರೋಗ್ಯ-ತಂತ್ರಜ್ಞಾನ-ಮೌಲ್ಯಮಾಪನ/)ದ ಮೂಲಕ ಮೌಲ್ಯಮಾಪನಗೊಳ್ಳುವ ದೀರ್ಘಕಾಲಿಕ-ರೋಗ ಮಧ್ಯಸ್ಥಿಕೆಗಳಿಗೆ NICE, ICER ಮತ್ತು CADTH ಸಲ್ಲಿಕೆಗಳು ಬಹುತೇಕ ಯಾವಾಗಲೂ ಜೀವಿತಾವಧಿ ಕಾಲದ ಗಡಿಯೊಂದಿಗೆ ಮಾರ್ಕೊವ್ ಸಮೂಹ ಮಾದರಿಗಳಾಗಿ ನಿರ್ಮಿಸಲ್ಪಡುತ್ತವೆ, ಏಕೆಂದರೆ ಪರ್ಯಾಯ — ಪ್ರತಿ ಸಂಭಾವ್ಯ ವೈಯಕ್ತಿಕ ರೋಗಿ ಮಾರ್ಗವನ್ನು ಮಾದರಿ ಮಾಡುವುದು — ಪ್ರಮಾಣದಲ್ಲಿ ನಿರ್ವಹಿಸಲಾಗದು. ಸಮೂಹ-ಮಟ್ಟದ ಮಾರ್ಕೊವ್ ಮಾದರಿ ಕೆಲವು ವೈಯಕ್ತಿಕ-ಮಟ್ಟದ ವಾಸ್ತವತೆಯನ್ನು ಬಿಟ್ಟುಕೊಡುತ್ತದೆ (ಹಿಂದಿನ ಸ್ಥಿತಿಗಳ ನೆನಪನ್ನು ಸುಲಭವಾಗಿ ಪ್ರತಿನಿಧಿಸಲಾಗದು, ಆದ್ದರಿಂದ "ಮಾರ್ಕೊವ್": ಭವಿಷ್ಯ ಪ್ರಸ್ತುತ ಸ್ಥಿತಿಯನ್ನು ಮಾತ್ರ ಅವಲಂಬಿಸುತ್ತದೆ) ಮತ್ತು ಪ್ರತಿಯಾಗಿ ಪಾರದರ್ಶಕ, ಲೆಕ್ಕಪರಿಶೋಧನೆಗೆ ಯೋಗ್ಯ, ಮತ್ತು [ಸಂಭಾವ್ಯತಾ ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ](../ಸಂಭಾವ್ಯತಾ-ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/)ಯಲ್ಲಿ ಸಾವಿರಾರು ಬಾರಿ ನಡೆಸುವಷ್ಟು ವೇಗದ ಮಾದರಿಯನ್ನು ಪಡೆಯುತ್ತದೆ.

## ಗಣಿತ

```
One cycle's cohort update (row-vector x transition matrix):
  new_state[j] = sum_i state[i] * transition_matrix[i][j]

One cycle's cost:
  cycle_cost = sum_s state[s] * cost_per_cycle[s]

One cycle's QALYs:
  cycle_qalys = sum_s state[s] * utility[s] * cycle_length_years

Full simulation over `cycles` cycles, discounted at `discount_rate`:
  total_discounted_cost  = sum_{t=0}^{cycles-1} cycle_cost(state_t)  / (1 + discount_rate)^t
  total_discounted_qalys = sum_{t=0}^{cycles-1} cycle_qalys(state_t) / (1 + discount_rate)^t
  where state_0 = initial_distribution, state_{t+1} = advance_cohort(state_t, transition_matrix)
```

ಪ್ರತಿ ಚಕ್ರವನ್ನು ವರ್ತಮಾನ ಮೌಲ್ಯಕ್ಕೆ ರಿಯಾಯಿತಿ ಮಾಡುವುದು ನಿಖರವಾಗಿ [ರಿಯಾಯಿತಿ ಮತ್ತು ಕಾಲ ಆದ್ಯತೆ](../ರಿಯಾಯಿತಿ-ಮತ್ತು-ಕಾಲ-ಆದ್ಯತೆ/) ಸೂತ್ರವನ್ನೇ ಬಳಸುತ್ತದೆ, ವರ್ಷದಿಂದ-ವರ್ಷದ ಬದಲು ಚಕ್ರದಿಂದ-ಚಕ್ರಕ್ಕೆ ಅನ್ವಯಿಸಿ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

**ಕ್ಲಿನಿಕಲ್**: 2-ಸ್ಥಿತಿ ಮಾದರಿ — `Well` ಮತ್ತು `Dead` — ಪ್ರತಿ ಚಕ್ರದಲ್ಲಿ ಸಮೂಹದ 10% ಸಾಯುತ್ತದೆ ಮತ್ತು `Dead` ಹೀರಿಕೊಳ್ಳುವ ಸ್ಥಿತಿ (ಅದರ ಸ್ವ-ಪರಿವರ್ತನೆ ಸಂಭವನೀಯತೆ 1.0; ಆ ಸ್ವ-ಲೂಪ್ ಬಿಟ್ಟರೆ `Dead`ನಲ್ಲಿ ಒಂದು ಚಕ್ರದ ನಂತರ ಸಮೂಹ ರಾಶಿ ಮಾಯವಾಗುತ್ತದೆ). ಸಮೂಹ ಸಂಪೂರ್ಣವಾಗಿ `Well` ಆಗಿ ಆರಂಭವಾಗುತ್ತದೆ, `Well` ಇರುವಾಗ ಪ್ರತಿ ಚಕ್ರಕ್ಕೆ £1,000 ವೆಚ್ಚ (`Dead` ಆದ ನಂತರ £0), ಮತ್ತು `Well` ಇರುವಾಗ ವರ್ಷಕ್ಕೆ 0.8 QALY ಗಳಿಸುತ್ತದೆ. NICEಯ 3.5% ರಿಯಾಯಿತಿ ದರದಲ್ಲಿ 3 ವಾರ್ಷಿಕ ಚಕ್ರಗಳಿಗೆ ಅನುಕರಿಸಿದ್ದು:

```
Cycle 0: state = [1.00, 0.00] (100% Well)
  cost = £1,000.00, qalys = 0.800, discount factor = 1.000000
  discounted: cost = £1,000.00, qalys = 0.8000

Cycle 1: state = [0.90, 0.10] (90% Well, 10% Dead)
  cost = £900.00, qalys = 0.720, discount factor = 0.966184
  discounted: cost = £869.57, qalys = 0.6957

Cycle 2: state = [0.81, 0.19] (81% Well, 19% Dead)
  cost = £810.00, qalys = 0.648, discount factor = 0.933511
  discounted: cost = £756.14, qalys = 0.6049

Total discounted cost  ≈ £2,625.71
Total discounted QALYs ≈ 2.1006
```

ಪ್ರತಿ ಚಕ್ರದ ಸ್ಥಿತಿ ಹಿಂದಿನ ಚಕ್ರದ ಸ್ಥಿತಿಯನ್ನು ಪರಿವರ್ತನೆ ಮ್ಯಾಟ್ರಿಕ್ಸ್ ಮೂಲಕ ಒಯ್ದದ್ದು — ಚಕ್ರ 1ರಲ್ಲಿ ಇನ್ನೂ `Well` ಇರುವ 90%ರಲ್ಲಿ 90% ಚಕ್ರ 2ರಲ್ಲಿ `Well` ಆಗಿ ಉಳಿಯುತ್ತದೆ (0.9 × 0.9 = 0.81), ಉಳಿದ 19% ಈಗ ಸತ್ತಿದೆ (0.9 × 0.1 + 0.1 × 1.0 = 0.19). ಸಮೂಹ `Well` ಅನ್ನು ಎಂದಿಗೂ ಸಂಪೂರ್ಣವಾಗಿ ಖಾಲಿ ಮಾಡುವುದಿಲ್ಲ ಎಂಬುದನ್ನು ಗಮನಿಸಿ: ಸ್ಥಿರ 10% ಪ್ರತಿ-ಚಕ್ರ ಮರಣ ಮತ್ತು ಮರು-ಪ್ರವೇಶವಿಲ್ಲದೆ, `Well` ಭಿನ್ನರಾಶಿ ಯಾವುದೇ ಸೀಮಿತ ಚಕ್ರ ಸಂಖ್ಯೆಯಲ್ಲಿ ಶೂನ್ಯ ತಲುಪದೆ ಜ್ಯಾಮಿತೀಯವಾಗಿ ಕ್ಷೀಣಿಸುತ್ತದೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಬಹು-ಚಕ್ರ HTA ಮಾದರಿಯನ್ನು ನೈಜ ಮೌಲ್ಯಮಾಪನದೊಳಗೆ ಹೇಗೆ ಬಳಸಲಾಗುತ್ತದೆ ಎಂಬುದಕ್ಕೆ [ಆರೋಗ್ಯ ತಂತ್ರಜ್ಞಾನ ಮೌಲ್ಯಮಾಪನ](../ಆರೋಗ್ಯ-ತಂತ್ರಜ್ಞಾನ-ಮೌಲ್ಯಮಾಪನ/) ನೋಡಿ — ಸಲ್ಲಿಸಿದ ಮಾರ್ಕೊವ್ ಮಾದರಿ ಯಾವ ರಿಯಾಯಿತಿ ದರ, ಉಪಯುಕ್ತತೆ ಮೂಲ ಮತ್ತು ಕಾಲದ ಗಡಿ ಬಳಸಬೇಕೆಂದು ನಿಯಂತ್ರಿಸುವ ಉಲ್ಲೇಖ ಪ್ರಕರಣ.

ಮಾರ್ಕೊವ್ ಸಮೂಹ ಮಾದರಿ ರಚನಾತ್ಮಕವಾಗಿ ಸಂಭಾವ್ಯ ಪರಿವರ್ತನೆಗಳಿರುವ ಸ್ಥಿತಿ ಯಂತ್ರ, ನಿಗದಿತ ಸಂಖ್ಯೆಯ ಟಿಕ್‌ಗಳಿಗೆ ನಡೆಸಿ, ಪ್ರತಿ ಟಿಕ್‌ನ ಮೌಲ್ಯವನ್ನು ರಿಯಾಯಿತಿ ಮಾಡುತ್ತದೆ. ಅದೇ ಆಕಾರ ಬಳಕೆದಾರ ಸಮೂಹದ ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ/ಸ್ಥಿತಿ ಪರಿವರ್ತನೆಗಳನ್ನು ಕಾಲಾನಂತರ ಅನುಕರಿಸುತ್ತದೆ — "ಈ ಅವಧಿಯಲ್ಲಿ ವ್ಯವಸ್ಥೆಯ ಯಾವ ಭಾಗ ಕುಸಿದ ಸ್ಥಿತಿಯಲ್ಲಿದೆ, ಮತ್ತು ಅದಕ್ಕೆ ಎಷ್ಟು ವೆಚ್ಚ" ಎಂಬುದರ ಕಾರ್ಯಾಚರಣೆ-ವಿಶ್ವಾಸಾರ್ಹತೆ ಆವೃತ್ತಿಗೆ [DORA ಮಾಪನಗಳು](../dora-ಮಾಪನಗಳು/) ನೋಡಿ. ನಿರ್ದಿಷ್ಟವಾಗಿ:

- **ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ/ಬಿಟ್ಟುಹೋಗುವಿಕೆ ಮಾದರಿ** "ಸಕ್ರಿಯ", "ಅಪಾಯದಲ್ಲಿ", "ಬಿಟ್ಟುಹೋದ" ಸ್ಥಿತಿಗಳಿರುವ ಮಾರ್ಕೊವ್ ಸಮೂಹ ಮಾದರಿ: ನಿಗದಿತ ಮಾಸಿಕ ಪರಿವರ್ತನೆ ಮ್ಯಾಟ್ರಿಕ್ಸ್, 12 ಅಥವಾ 24 ಮಾಸಿಕ ಚಕ್ರಗಳಿಗೆ ನಡೆಸಿದ್ದು, ಯಾವುದೇ ಭವಿಷ್ಯದ ತಿಂಗಳಲ್ಲಿ ನಿರೀಕ್ಷಿತ ಸಕ್ರಿಯ-ಬಳಕೆದಾರ ಎಣಿಕೆ (ಮತ್ತು ಆದಾಯ) ತಿಳಿಸುತ್ತದೆ, `Well`/`Dead` ನಿರೀಕ್ಷಿತ ಉಳಿದವರನ್ನು ತಿಳಿಸುವಂತೆ.
- **ವಿಶ್ವಾಸಾರ್ಹತೆ ಮತ್ತು ಘಟನೆ ಅರ್ಥಶಾಸ್ತ್ರ**: ವ್ಯವಸ್ಥೆಯ ಸ್ಥಿತಿಗಳನ್ನು (ಆರೋಗ್ಯಕರ, ಕುಸಿದ, ಸ್ಥಗಿತ) ಅದೇ ರೀತಿ ಮಾದರಿ ಮಾಡಬಹುದು, ವ್ಯವಸ್ಥೆ ಕುಸಿದ/ಸ್ಥಗಿತ ಸ್ಥಿತಿಗಳಲ್ಲಿರುವಾಗ ಡೌನ್‌ಟೈಮ್ ಹಾನಿಯ "ಪ್ರತಿ ಚಕ್ರ ವೆಚ್ಚ" ಸಂಚಯವಾಗುತ್ತದೆ — ಘಟನೆ-ಆವರ್ತನ ವಾದವನ್ನು ಪರಿವರ್ತನೆ ಸಂಭವನೀಯತೆಗಳನ್ನು ಬದಲಿಸುವ ವಿಶ್ವಾಸಾರ್ಹತೆ ಕೆಲಸದ ವೆಚ್ಚದ ವಿರುದ್ಧ ಹೋಲಿಸಬಹುದಾದ ರಿಯಾಯಿತಿ-ವೆಚ್ಚ ವಾದವಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ.
- **ಹೀರಿಕೊಳ್ಳುವ ಸ್ಥಿತಿಗಳು ಅಂತಿಮ ಸ್ಥಿತಿಗಳಾಗಿ**: ಕ್ಲಿನಿಕಲ್ ಮಾದರಿಯಲ್ಲಿ `Dead` ಸಾಫ್ಟ್‌ವೇರ್ ಮಾದರಿಯಲ್ಲಿ ನಿಖರವಾಗಿ "ರದ್ದುಪಡಿಸಿದ ಚಂದಾ" ಅಥವಾ "ಶಾಶ್ವತವಾಗಿ ಆಫ್‌ಲೈನ್" ಸ್ಥಿತಿ — ಎರಡಕ್ಕೂ 1.0 ಸ್ಪಷ್ಟ ಸ್ವ-ಪರಿವರ್ತನೆ ಸಂಭವನೀಯತೆ ಬೇಕು, ಇಲ್ಲದಿದ್ದರೆ ಅನುಕರಣೆ ಮೌನವಾಗಿ ರಾಶಿ ಕಳೆದುಕೊಳ್ಳುತ್ತದೆ.

## ಎಡವಟ್ಟುಗಳು

- **ಪ್ರತಿ ಸಾಲಿಗೆ 1ಕ್ಕೆ ಕೂಡದ ಪರಿವರ್ತನೆ ಸಂಭವನೀಯತೆಗಳು.** 1ಕ್ಕಿಂತ ಹೆಚ್ಚು ಅಥವಾ ಕಡಿಮೆ ಕೂಡುವ ಸಾಲು ಪ್ರತಿ ಚಕ್ರ ಸಮೂಹ ರಾಶಿಯನ್ನು ಮೌನವಾಗಿ "ಸೋರಿಸುತ್ತದೆ" ಅಥವಾ "ಬೆಳೆಸುತ್ತದೆ" — ಮಾದರಿಯ ಫಲಿತಾಂಶವನ್ನು ನಂಬುವ ಮೊದಲು ಯಾವಾಗಲೂ ಸಾಲು ಮೊತ್ತಗಳನ್ನು ಪರಿಶೀಲಿಸಿ, ಏಕೆಂದರೆ ಮಾದರಿ ರಚನೆಯೇ ದೋಷವನ್ನು ಗುರುತಿಸುವುದಿಲ್ಲ.
- **ರೋಗದ ನಿಜ ಚಲನಶೀಲತೆಗೆ ತುಂಬಾ ಒರಟು ಚಕ್ರ ಉದ್ದ.** ವಾರಗಳಲ್ಲಿ ಅರ್ಥಪೂರ್ಣವಾಗಿ ಸ್ಥಿತಿ ಬದಲಿಸುವ ಸ್ಥಿತಿಗೆ ವಾರ್ಷಿಕ ಚಕ್ರ ಚಕ್ರದ ಮಧ್ಯದಲ್ಲಿ ಸಂಭವಿಸುವ ಪರಿವರ್ತನೆಗಳನ್ನು ಕಡಿಮೆ ಹೇಳುತ್ತದೆ; ಮಾದರಿ ಮಾಡಿದ ಪ್ರಕ್ರಿಯೆ ನಿಜವಾಗಿ ಎಷ್ಟು ವೇಗವಾಗಿ ಚಲಿಸುತ್ತದೆ ಎಂಬುದಕ್ಕೆ ಹೋಲಿಸಿದರೆ ಚಿಕ್ಕ ಚಕ್ರ ಉದ್ದವನ್ನು ಆರಿಸಿ.
- **ಹೀರಿಕೊಳ್ಳುವ ಸ್ಥಿತಿಯ ಸ್ವ-ಲೂಪ್ ಮರೆಯುವುದು.** ಹೀರಿಕೊಳ್ಳುವ ಸ್ಥಿತಿಗೆ (ಮರಣ, ಶಾಶ್ವತ ನಿಲ್ಲಿಸುವಿಕೆ) ನಿಖರವಾಗಿ 1.0 ಸ್ವ-ಪರಿವರ್ತನೆ ಸಂಭವನೀಯತೆ ಬೇಕು. ಬಿಟ್ಟರೆ ಆ ಸ್ಥಿತಿಯಲ್ಲಿನ ಸಮೂಹ ರಾಶಿ ಒಂದು ಚಕ್ರದ ನಂತರ ಆವಿಯಾಗುತ್ತದೆ, ಸಂಚಿತ ವೆಚ್ಚಗಳು ಅಥವಾ QALY ನಷ್ಟವನ್ನು ಕಡಿಮೆ ಹೇಳುತ್ತದೆ.
- **ಓಡುತ್ತದೆ ಎಂಬ ಕಾರಣಕ್ಕೆ ಮಾದರಿ ಮೌಲ್ಯೀಕರಿಸಲ್ಪಟ್ಟಿದೆ ಎಂದು ಪರಿಗಣಿಸುವುದು.** ತೋರಿಕೆಯಲ್ಲಿ ಸಮಂಜಸ ಪರಿವರ್ತನೆ ಸಂಭವನೀಯತೆಗಳಿರುವ ಮಾರ್ಕೊವ್ ಸಮೂಹ ಮಾದರಿ ಇನ್ನೂ ರಚನಾತ್ಮಕವಾಗಿ ತಪ್ಪಿರಬಹುದು (ಕಾಣೆಯಾದ ಸ್ಥಿತಿಗಳು, ತಪ್ಪಾದ ಹೀರಿಕೊಳ್ಳುವ ವರ್ತನೆ); ಫಲಿತಾಂಶವನ್ನು ನಂಬುವ ಮೊದಲು ತಿಳಿದ ಸಾಂಕ್ರಾಮಿಕ ರೋಗಶಾಸ್ತ್ರ ಮಾನದಂಡಗಳ ವಿರುದ್ಧ ಮೌಲ್ಯೀಕರಿಸಿ (ಉದಾ. 5 ವರ್ಷಗಳಲ್ಲಿ ಮಾದರಿ ಮಾಡಿದ ಬದುಕುಳಿಯುವಿಕೆ ಪ್ರಕಟಿತ ಬದುಕುಳಿಯುವಿಕೆ ವಕ್ರರೇಖೆಗಳಿಗೆ ಹೊಂದುತ್ತದೆಯೇ).
