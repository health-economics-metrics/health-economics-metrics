# ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ವಿಶ್ಲೇಷಣೆ (CEA)

CEA ಪರ್ಯಾಯ ಮಧ್ಯಸ್ಥಿಕೆಗಳ ವೆಚ್ಚಗಳನ್ನು **ನೈಸರ್ಗಿಕ ಘಟಕಗಳಲ್ಲಿ** ಅಳೆದ ಒಂದೇ ಫಲಿತಾಂಶದ ವಿರುದ್ಧ ಹೋಲಿಸುತ್ತದೆ — ಜೀವ ವರ್ಷಗಳು, ಪತ್ತೆಯಾದ ಪ್ರಕರಣಗಳು, ತಪ್ಪಿಸಿದ ದಾಖಲಾತಿಗಳು, ಕಡಿಮೆಯಾದ ರಕ್ತದೊತ್ತಡದ mmHg. ಇದರ ಫಲಿತಾಂಶ ಫಲಿತಾಂಶದ ಪ್ರತಿ ಘಟಕಕ್ಕೆ ವೆಚ್ಚ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಎಲ್ಲ ಆಯ್ಕೆಗಳು ಒಂದೇ ಫಲಿತಾಂಶವನ್ನು ಗುರಿಯಾಗಿಸಿದಾಗ CEA ಮುಖ್ಯ ಹೋಲಿಕೆ ಸಾಧನ. ಇದು "X ಸಾಧಿಸುವ ಈ ವಿಧಾನಗಳಲ್ಲಿ ಹಣದ ಅತ್ಯುತ್ತಮ ಬಳಕೆ ಯಾವುದು?" ಎಂದು ಉತ್ತರಿಸುತ್ತದೆ — ಆದರೆ "X ಸಾಧಿಸುವುದು ಯೋಗ್ಯವೇ?" ಅಲ್ಲ (ಅದಕ್ಕೆ [ವೆಚ್ಚ-ಲಾಭ ವಿಶ್ಲೇಷಣೆ](../ವೆಚ್ಚ-ಲಾಭ-ವಿಶ್ಲೇಷಣೆ/) ಬೇಕು) ಮತ್ತು "X ಸಂಬಂಧವಿಲ್ಲದ ಆದ್ಯತೆಗಳೊಂದಿಗೆ ಹೇಗೆ ಹೋಲುತ್ತದೆ?" ಅಲ್ಲ (ಅದಕ್ಕೆ [ವೆಚ್ಚ-ಉಪಯುಕ್ತತಾ ವಿಶ್ಲೇಷಣೆ](../ವೆಚ್ಚ-ಉಪಯುಕ್ತತಾ-ವಿಶ್ಲೇಷಣೆ/) ಮತ್ತು QALY ನಂತಹ ಸಾಮಾನ್ಯ ಫಲಿತಾಂಶ ಬೇಕು).

## ಗಣಿತ

ಹೋಲಿಕೆಯ ಅಂಕಿಅಂಶ ನೈಸರ್ಗಿಕ ಘಟಕಗಳಲ್ಲಿನ [ICER](../ಹೆಚ್ಚುವರಿ-ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ಅನುಪಾತ/):

```
ICER = (Cost_A − Cost_B) / (Effect_A − Effect_B)
     = £ per additional case detected / admission avoided / etc.
```

ವಿಧಾನ: ಫಲಿತಾಂಶ ಘಟಕವನ್ನು ವ್ಯಾಖ್ಯಾನಿಸಿ; ಪ್ರತಿ ಆಯ್ಕೆಯ ವೆಚ್ಚವನ್ನು ಅದೇ [ದೃಷ್ಟಿಕೋನ](../ವಿಶ್ಲೇಷಣಾ-ದೃಷ್ಟಿಕೋನ/)ದಿಂದ ಅದೇ [ಕಾಲದ ಗಡಿ](../ಕಾಲದ-ಗಡಿ/)ಯ ಮೇಲೆ ಲೆಕ್ಕಿಸಿ; ಪ್ರಾಬಲ್ಯಕ್ಕೊಳಗಾದ ಆಯ್ಕೆಗಳನ್ನು ತೆಗೆಯಿರಿ ([ದಕ್ಷತಾ ಗಡಿ](../ಪ್ರಾಬಲ್ಯ-ಮತ್ತು-ದಕ್ಷತಾ-ಗಡಿ/)); ಗಡಿಯ ಉದ್ದಕ್ಕೆ ಹೆಚ್ಚುವರಿ ಅನುಪಾತಗಳನ್ನು ಲೆಕ್ಕಿಸಿ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

100,000 ಜನಸಂಖ್ಯೆಯಲ್ಲಿ ಪತ್ತೆಯಾಗದ ಹೃತ್ಕರ್ಣ ಕಂಪನವನ್ನು ಕಂಡುಹಿಡಿಯುವ ಮೂರು ವಿಧಾನಗಳು:

```
Option                    Cost        Cases found
Opportunistic pulse checks £150,000       300
Pharmacy screening events  £400,000       520
Wearable-based screening   £900,000       610

ICER pharmacy vs pulse:  (400k−150k)/(520−300) = £1,136 per additional case
ICER wearable vs pharmacy:(900k−400k)/(610−520) = £5,556 per additional case
```

ಪ್ರತಿ ಹೆಚ್ಚುವರಿ ಪ್ರಕರಣಕ್ಕೆ £5,556 "ಯೋಗ್ಯ"ವೇ ಎಂಬುದು ಪತ್ತೆಯಾದ ಪ್ರಕರಣದ ಮೌಲ್ಯದ (ಕೆಳಹರಿವಿನ ಸ್ಟ್ರೋಕ್ ತಡೆಗಟ್ಟುವಿಕೆ) ಮೇಲೆ ಅವಲಂಬಿತ — CEA ಆಯ್ಕೆಗಳನ್ನು ಶ್ರೇಣೀಕರಿಸುತ್ತದೆ ಆದರೆ ಅಳವಡಿಕೆ ನಿರ್ಧಾರಕ್ಕೆ ಆ ಬಾಹ್ಯ ಮೌಲ್ಯಮಾಪನ ಬೇಕು. ಧರಿಸಬಹುದಾದ ಆಯ್ಕೆಯ *ಸರಾಸರಿ* ಪ್ರತಿ-ಪ್ರಕರಣ ವೆಚ್ಚ (900k/610 = £1,475) ಚೆನ್ನಾಗಿ ಕಾಣುತ್ತದೆ; ವಿಸ್ತರಣಾ ನಿರ್ಧಾರಕ್ಕೆ ಪ್ರಾಮಾಣಿಕ ಸಂಖ್ಯೆ *ಹೆಚ್ಚುವರಿ* £5,556.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಆಯ್ಕೆಗಳು ಒಂದೇ ಫಲಿತಾಂಶ ಹಂಚಿಕೊಂಡಾಗಲೆಲ್ಲ CEA ಸರಿಯಾದ ಟೆಂಪ್ಲೇಟ್: ಮೂರು ಪರಿಹಾರ ವಿಧಾನಗಳಾದ್ಯಂತ ತೆಗೆದುಹಾಕಿದ ಪ್ರತಿ ಅಸ್ಥಿರ ಪರೀಕ್ಷೆಗೆ ವೆಚ್ಚ; ಅವಲೋಕನಶೀಲತಾ ಮಾರಾಟಗಾರರಾದ್ಯಂತ ತಪ್ಪಿಸಿದ ಪ್ರತಿ ಘಟನೆಗೆ ವೆಚ್ಚ; CI ವಾಸ್ತುಶಿಲ್ಪಗಳಾದ್ಯಂತ ಪ್ರತಿ ಯಶಸ್ವಿ ಡಿಪ್ಲಾಯ್‌ಮೆಂಟ್‌ಗೆ ವೆಚ್ಚ. ಅದು ಜಾರಿಗೊಳಿಸುವ ಶಿಸ್ತು — ಒಂದು ಘೋಷಿತ ಫಲಿತಾಂಶ ಘಟಕ, ಹೆಚ್ಚುವರಿ (ಸರಾಸರಿಯಲ್ಲ) ಅನುಪಾತಗಳು, ಮೊದಲು ಪ್ರಾಬಲ್ಯಕ್ಕೊಳಗಾದ ಆಯ್ಕೆಗಳ ನಿವಾರಣೆ — ಬೆಲೆ ಚರ್ಚೆ ಪ್ರಾರಂಭವಾಗುವ ಮೊದಲೇ ಹೆಚ್ಚಿನ ಕೆಟ್ಟ ಮಾರಾಟಗಾರ ಹೋಲಿಕೆಗಳನ್ನು ಕೊಲ್ಲುತ್ತದೆ.

## ಎಡವಟ್ಟುಗಳು

- **ಒಂದೇ CEAಯಲ್ಲಿ ಭಿನ್ನ ಫಲಿತಾಂಶಗಳಿರುವ ಆಯ್ಕೆಗಳನ್ನು** ("ಪತ್ತೆಯಾದ ಪ್ರಕರಣಗಳು" vs "ತೃಪ್ತಿ") ಹೋಲಿಸುವುದು — ಅದಕ್ಕೆ [ವೆಚ್ಚ-ಪರಿಣಾಮ ವಿಶ್ಲೇಷಣೆ](../ವೆಚ್ಚ-ಪರಿಣಾಮ-ವಿಶ್ಲೇಷಣೆ/) ಅಥವಾ ಸಾಮಾನ್ಯ ಫಲಿತಾಂಶ ಬೇಕು.
- ಹೆಚ್ಚುವರಿ ಅನುಪಾತಗಳು ಬೇಕಾದಲ್ಲಿ **ಸರಾಸರಿ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ಅನುಪಾತಗಳನ್ನು** ಪ್ರಸ್ತುತಪಡಿಸುವುದು (ಮೇಲಿನ ಧರಿಸಬಹುದಾದ ಉದಾಹರಣೆ).
- **ಮುಖಸ್ತುತಿಗಾಗಿ ಆರಿಸಿದ ಫಲಿತಾಂಶ ಘಟಕಗಳು**: "ಉತ್ಪಾದಿಸಿದ ಎಚ್ಚರಿಕೆಗಳು" ಒಂದು ಔಟ್‌ಪುಟ್, ಫಲಿತಾಂಶವಲ್ಲ; ಮೌಲ್ಯ ಹೊತ್ತ ಘಟಕಗಳಿಗೆ ಒತ್ತಾಯಿಸಿ.
