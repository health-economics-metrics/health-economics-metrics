# ಸ್ಕ್ರೀನಿಂಗ್ ಅರ್ಥಶಾಸ್ತ್ರ

ಸ್ಕ್ರೀನಿಂಗ್ ಅರ್ಥಶಾಸ್ತ್ರ ಲಕ್ಷಣರಹಿತ ಜನಸಂಖ್ಯೆಗಳನ್ನು ಪರೀಕ್ಷಿಸುವ ಮೌಲ್ಯವನ್ನು ನಿಯಂತ್ರಿಸುತ್ತದೆ. ಮೂಲ ಗಣಿತ ಸತ್ಯ: **ಕಡಿಮೆ ರೋಗ ಹರಡುವಿಕೆಯಲ್ಲಿ, ಅತ್ಯುತ್ತಮ ಪರೀಕ್ಷೆಗಳೂ ಹೆಚ್ಚಾಗಿ ಸುಳ್ಳು ಧನಾತ್ಮಕಗಳನ್ನು ಉತ್ಪಾದಿಸುತ್ತವೆ** — ಮತ್ತು ಅವುಗಳನ್ನು ಬೆನ್ನಟ್ಟುವ ಕೆಳಹಂತದ ವೆಚ್ಚ ನಿಜ ಪತ್ತೆಗಳ ಲಾಭವನ್ನು ಮುಳುಗಿಸಬಹುದು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

1968ರಿಂದ, WHOಯ Wilson–Jungner ಮಾನದಂಡಗಳು ಜನಸಂಖ್ಯಾ ಸ್ಕ್ರೀನಿಂಗ್‌ಗೆ ಮಟ್ಟವನ್ನು ನಿಗದಿಪಡಿಸಿವೆ: ಸ್ಥಿತಿ ಮುಖ್ಯವಾಗಿರಬೇಕು, ಪರೀಕ್ಷೆ ಸ್ವೀಕಾರಾರ್ಹ ಮತ್ತು ನಿಖರವಾಗಿರಬೇಕು, ಪರಿಣಾಮಕಾರಿ ಚಿಕಿತ್ಸೆ ಅಸ್ತಿತ್ವದಲ್ಲಿರಬೇಕು, ಮತ್ತು ಅರ್ಥಶಾಸ್ತ್ರ ಸಮತೋಲನದಲ್ಲಿರಬೇಕು. ಯುಕೆ ರಾಷ್ಟ್ರೀಯ ಸ್ಕ್ರೀನಿಂಗ್ ಸಮಿತಿ ಯಾವುದೇ ರಾಷ್ಟ್ರೀಯ ಕಾರ್ಯಕ್ರಮವನ್ನು ಅನುಮೋದಿಸುವ ಮೊದಲು ಔಪಚಾರಿಕ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ವಿಶ್ಲೇಷಣೆ ಅನ್ವಯಿಸುತ್ತದೆ — ಮತ್ತು ಹೆಚ್ಚಿನ ಪ್ರಸ್ತಾವನೆಗಳನ್ನು ತಿರಸ್ಕರಿಸುತ್ತದೆ. ಪ್ರತಿ "AI ಎಲ್ಲರನ್ನೂ ಎಲ್ಲದಕ್ಕೂ ಸ್ಕ್ರೀನ್ ಮಾಡುತ್ತದೆ" ಪ್ರಸ್ತಾವನೆ ಈ ವ್ಯವಸ್ಥೆಗೆ ಎದುರಾಗುತ್ತದೆ ಮತ್ತು ಸಾಮಾನ್ಯವಾಗಿ ಕೆಳಗಿನ ಅಂಕಗಣಿತಕ್ಕೆ ಸೋಲುತ್ತದೆ.

## ಗಣಿತ

ಧನಾತ್ಮಕ ಭವಿಷ್ಯಸೂಚಕ ಮೌಲ್ಯ (PPV) — ಧನಾತ್ಮಕ ಫಲಿತಾಂಶ ನಿಜವಾಗಿರುವ ಸಂಭವನೀಯತೆ — ಕಡಿಮೆ ಹರಡುವಿಕೆಯಲ್ಲಿ ಕುಸಿಯುತ್ತದೆ:

```
PPV = (sens × prev) / [sens × prev + (1 − spec) × (1 − prev)]

Example: sensitivity 90%, specificity 95%, prevalence 0.5%:
PPV = (0.9 × 0.005) / (0.9 × 0.005 + 0.05 × 0.995)
    = 0.0045 / (0.0045 + 0.04975) ≈ 8.3%
```

ಹನ್ನೆರಡು ಧನಾತ್ಮಕಗಳಲ್ಲಿ ಹನ್ನೊಂದು ಸುಳ್ಳು. ಪೂರ್ಣ ಕಾರ್ಯಕ್ರಮ ಅರ್ಥಶಾಸ್ತ್ರ:

```
Cost per true case found = (screening cost + workup cost × all positives) / true positives
Then: is finding a case worth that? (earlier-intervention value per case,
      minus overdiagnosis harm — cases found that would never have mattered)
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಅಪರೂಪದ ಸ್ಥಿತಿಗೆ AI ರೆಟಿನಲ್ ಸ್ಕ್ರೀನಿಂಗ್, 100,000 ಜನರು, ಹರಡುವಿಕೆ 0.5%, ಸೂಕ್ಷ್ಮತೆ 90%, ವಿಶಿಷ್ಟತೆ 95%, ಸ್ಕ್ಯಾನ್ £15, ದೃಢೀಕರಣ ಅನುಸರಣೆ £400:

```
True positives:  100,000 × 0.005 × 0.90 = 450
False positives: 100,000 × 0.995 × 0.05 = 4,975
Cost = 100,000 × 15 + (450 + 4,975) × 400 = 1.5M + 2.17M = £3.67M
Cost per true case ≈ £8,156
```

ಮುಂಚಿನ ಚಿಕಿತ್ಸೆ ಪ್ರತಿ ಪ್ರಕರಣಕ್ಕೆ £20,000 + 1 QALY ಉಳಿಸಿದರೆ, ಕಾರ್ಯಕ್ರಮ ಸುಲಭವಾಗಿ ದಾಟುತ್ತದೆ. ವಿಶಿಷ್ಟತೆಯನ್ನು 99%ಗೆ ಏರಿಸಿ (ಕಡಿಮೆ ಸುಳ್ಳು ಎಚ್ಚರಿಕೆಗಳು): ಅನುಸರಣೆ ವೆಚ್ಚ (450 + 995) × 400 = £0.58Mಗೆ ಇಳಿಯುತ್ತದೆ, ಒಟ್ಟು £2.08M, ಪ್ರತಿ ಪ್ರಕರಣ ವೆಚ್ಚ ≈ **£4,622** — ಕಡಿಮೆ ಹರಡುವಿಕೆಯಲ್ಲಿ ಸ್ಕ್ರೀನಿಂಗ್ ಅರ್ಥಶಾಸ್ತ್ರ ಗೆಲ್ಲುವುದು ಸೂಕ್ಷ್ಮತೆಯಲ್ಲಿ ಅಲ್ಲ, ವಿಶಿಷ್ಟತೆಯಲ್ಲಿ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಸ್ಥಿರ ವಿಶ್ಲೇಷಣೆ, ಭದ್ರತಾ ಸ್ಕ್ಯಾನಿಂಗ್ ಮತ್ತು ಅಸಂಗತಿ ಪತ್ತೆ ಕೋಡ್‌ಬೇಸ್‌ಗಳು ಮತ್ತು ಟೆಲಿಮೆಟ್ರಿಯ ಮೇಲಿನ ಸ್ಕ್ರೀನಿಂಗ್ ಕಾರ್ಯಕ್ರಮಗಳು, ನಿಜ-ದೋಷ ಹರಡುವಿಕೆ ಹೆಚ್ಚಾಗಿ ಪ್ರತಿ ಎಚ್ಚರಿಕೆ-ಅವಕಾಶಕ್ಕೆ 1%ಕ್ಕಿಂತ ಬಹಳ ಕಡಿಮೆ. ಅದೇ ಗಣಿತ ಎಚ್ಚರಿಕೆ ಆಯಾಸವನ್ನು ವಿವರಿಸುತ್ತದೆ: ಕಡಿಮೆ-ಹರಡುವಿಕೆ ಕೋಡ್‌ನಲ್ಲಿ 95%-ವಿಶಿಷ್ಟ ಸ್ಕ್ಯಾನರ್ ತಂಡಗಳನ್ನು ಸುಳ್ಳು ಧನಾತ್ಮಕಗಳಲ್ಲಿ ಮುಳುಗಿಸುತ್ತದೆ, ಮತ್ತು ಪ್ರತಿ ಸುಳ್ಳು ಧನಾತ್ಮಕ ಗಮನವನ್ನು ವೆಚ್ಚ ಮಾಡುತ್ತದೆ ಮತ್ತು ನಿಜ ಎಚ್ಚರಿಕೆಗಳು ನಿರ್ಲಕ್ಷಿಸಲ್ಪಡುವವರೆಗೆ ನಂಬಿಕೆಯನ್ನು ಸವೆಸುತ್ತದೆ (ಕ್ಲಿನಿಕಲ್ ಪದ *ಸ್ಕ್ರೀನಿಂಗ್ ಹಾನಿ*; ಎಂಜಿನಿಯರಿಂಗ್ ಪದ *ಪೇಜರ್ ಮರಗಟ್ಟುವಿಕೆ*). ಪರಿಹಾರಗಳು ಆರೋಗ್ಯದಿಂದ ವರ್ಗಾವಣೆಯಾಗುತ್ತವೆ: ಸೂಕ್ಷ್ಮತೆಯ ಮೊದಲು ವಿಶಿಷ್ಟತೆಯನ್ನು ಏರಿಸಿ, ಹೆಚ್ಚು-ಹರಡುವಿಕೆಯ ಉಪ-ಜನಸಂಖ್ಯೆಗಳನ್ನು ಸ್ಕ್ರೀನ್ ಮಾಡಿ (ಅಪಾಯ-ಆಧಾರಿತ ಗುರಿ ↔ ಬದಲಾದ-ಕೋಡ್-ಮಾತ್ರ ಸ್ಕ್ಯಾನಿಂಗ್), ಮತ್ತು ಸಾಧನದ ಅರ್ಥಶಾಸ್ತ್ರದಲ್ಲಿ ಟ್ರಯಾಜ್ ವೆಚ್ಚವನ್ನು ಎಣಿಸಿ — [NNT](../ಚಿಕಿತ್ಸೆ-ನೀಡಬೇಕಾದ-ಸಂಖ್ಯೆ/) ಮತ್ತು [ಕ್ಲಿನಿಕಲ್ AI ಮೌಲ್ಯಮಾಪನ](../ಕ್ಲಿನಿಕಲ್-ai-ಮೌಲ್ಯಮಾಪನ/) ನೋಡಿ. ಒಂದು ಪರೀಕ್ಷೆಯ ಬದಲು ಇಡೀ ಸ್ಕ್ರೀನಿಂಗ್ ಕಾರ್ಯಕ್ರಮದ ಗಾತ್ರಕ್ಕೆ [ಸ್ಕ್ರೀನ್ ಮಾಡಬೇಕಾದ ಸಂಖ್ಯೆ](../ಸ್ಕ್ರೀನ್-ಮಾಡಬೇಕಾದ-ಸಂಖ್ಯೆ/) ನೋಡಿ — ಒಂದು ಫಲಿತಾಂಶ ತಡೆಯಲು ಎಷ್ಟು ಜನ ಇಡೀ ಸ್ಕ್ರೀನ್-ಮತ್ತು-ಚಿಕಿತ್ಸೆ ಮಾರ್ಗದ ಮೂಲಕ ಹೋಗಬೇಕು.

## ಎಡವಟ್ಟುಗಳು

- **ಹರಡುವಿಕೆ ಇಲ್ಲದೆ ಸೂಕ್ಷ್ಮತೆ/ವಿಶಿಷ್ಟತೆ ಉಲ್ಲೇಖಿಸುವುದು** — PPV ಇಲ್ಲದ ನಿಖರತೆ ಮಾರುಕಟ್ಟೆ ಪ್ರಚಾರ.
- **ಅತಿರೋಗನಿರ್ಣಯದ ನಿರ್ಲಕ್ಷ್ಯ**: ಎಂದಿಗೂ ಹಾನಿ ಮಾಡದ ನಿಧಾನ "ರೋಗ"ವನ್ನು ಕಂಡುಹಿಡಿಯುವುದು ನಿಜ ಚಿಕಿತ್ಸಾ ವೆಚ್ಚ ಮತ್ತು ಹಾನಿಗಳನ್ನು ಪ್ರಚೋದಿಸುತ್ತದೆ.
- **ಲೀಡ್-ಟೈಮ್ ಪಕ್ಷಪಾತ**: ಫಲಿತಾಂಶಗಳನ್ನು ಬದಲಿಸದ ಮುಂಚಿನ ಪತ್ತೆ ಸ್ಪಷ್ಟ ಬದುಕುಳಿಯುವಿಕೆಯನ್ನು ಉಬ್ಬಿಸುತ್ತದೆ — [ಮುಂಚಿನ ಮಧ್ಯಸ್ಥಿಕೆ](../ಮುಂಚಿನ-ಮಧ್ಯಸ್ಥಿಕೆ/) ನೋಡಿ.
