# ಹೆಚ್ಚುವರಿ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ಅನುಪಾತ (ICER)

ICER ಎಂದರೆ ಮುಂದಿನ-ಅತ್ಯುತ್ತಮ ಪರ್ಯಾಯದ ಬದಲು ಒಂದು ಆಯ್ಕೆಯನ್ನು ಆರಿಸಿದಾಗ ಆರೋಗ್ಯ ಪರಿಣಾಮದ ಪ್ರತಿ ಹೆಚ್ಚುವರಿ ಘಟಕಕ್ಕೆ ಹೆಚ್ಚುವರಿ ವೆಚ್ಚ. ಇದು ಆರೋಗ್ಯ ತಂತ್ರಜ್ಞಾನ ಮೌಲ್ಯಮಾಪನದ ಶೀರ್ಷಿಕೆ ಸಂಖ್ಯೆ. (ಪರಿಣಾಮದ ಘಟಕ QALYಗಳಾದಾಗ, ಇದನ್ನು ಹೆಚ್ಚುವರಿ ವೆಚ್ಚ-ಉಪಯುಕ್ತತಾ ಅನುಪಾತ, ICUR, ಎಂದೂ ಕರೆಯುತ್ತಾರೆ.)

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಆರೋಗ್ಯ ವ್ಯವಸ್ಥೆಗಳು ಎಂದಿಗೂ ತಂತ್ರಜ್ಞಾನವನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ಮೌಲ್ಯಮಾಪನ ಮಾಡುವುದಿಲ್ಲ — ಯಾವಾಗಲೂ *ಹೆಚ್ಚುವರಿಯಾಗಿ*, ಇಲ್ಲದಿದ್ದರೆ ಏನು ಮಾಡಲಾಗುತ್ತಿತ್ತೋ ಅದರ ವಿರುದ್ಧ. NICE ತಂತ್ರಜ್ಞಾನದ ICER ಅನ್ನು ಅದರ **ಪ್ರತಿ QALYಗೆ £20,000–£30,000** ಮಿತಿಗೆ ಹೋಲಿಸುತ್ತದೆ; ಅಮೆರಿಕದ ICER ಸಂಸ್ಥೆ $50,000–$200,000/QALY ವ್ಯಾಪ್ತಿಯಲ್ಲಿ ವರದಿ ಮಾಡುತ್ತದೆ; ಕೆನಡಾ ಸುಮಾರು CAD$50,000/QALYಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ನಿಮ್ಮ ಉತ್ಪನ್ನ ರಾಷ್ಟ್ರೀಯ ಆರೋಗ್ಯ ಸೇವೆಗೆ "ಯೋಗ್ಯ"ವೇ ಎಂಬುದು ಔಪಚಾರಿಕವಾಗಿ ಅದರ ICER ಸ್ಥಳೀಯ ಮಿತಿಯನ್ನು ದಾಟುತ್ತದೆಯೇ ಎಂಬುದು. [ಪಾವತಿಸಲು ಇಚ್ಛೆಯ ಮಿತಿಗಳು](../ಪಾವತಿಸಲು-ಇಚ್ಛೆಯ-ಮಿತಿಗಳು/) ನೋಡಿ.

## ಗಣಿತ

```
ICER = (Cost_new − Cost_comparator) / (Effect_new − Effect_comparator)
     = ΔC / ΔE
```

ವ್ಯಾಖ್ಯಾನದ ನಿಯಮಗಳು:

- ΔC < 0, ΔE > 0: ಹೊಸ ಆಯ್ಕೆ **ಪ್ರಾಬಲ್ಯ ಹೊಂದಿದೆ** — ಅಗ್ಗ ಮತ್ತು ಉತ್ತಮ; ಅನುಪಾತ ಬೇಕಿಲ್ಲ.
- ΔC > 0, ΔE > 0: ICER ಲೆಕ್ಕಿಸಿ, ಮಿತಿ λಗೆ ಹೋಲಿಸಿ; ICER < λ ಆದರೆ ಅಳವಡಿಸಿ.
- ΔC > 0, ΔE < 0: ಹೊಸ ಆಯ್ಕೆ ಪ್ರಾಬಲ್ಯಕ್ಕೊಳಗಾಗಿದೆ — ತಿರಸ್ಕರಿಸಿ.
- ΔE = 0 ಹತ್ತಿರ ಅನುಪಾತಗಳು ಕೆಟ್ಟದಾಗಿ ವರ್ತಿಸುತ್ತವೆ — ಶ್ರೇಣೀಕರಣಕ್ಕೆ [ನಿವ್ವಳ ಹಣಕಾಸು ಲಾಭ](../ನಿವ್ವಳ-ಹಣಕಾಸು-ಲಾಭ/) ಆದ್ಯತೆ ನೀಡಿ.

ಹೋಲಿಕೆ ಆಧಾರ *ಮುಂದಿನ-ಅತ್ಯುತ್ತಮ ಪ್ರಾಬಲ್ಯರಹಿತ ಆಯ್ಕೆ* ಆಗಿರಬೇಕು, "ಏನೂ ಮಾಡದಿರುವುದು" ಅಲ್ಲ — [ಪ್ರಾಬಲ್ಯ ಮತ್ತು ದಕ್ಷತಾ ಗಡಿ](../ಪ್ರಾಬಲ್ಯ-ಮತ್ತು-ದಕ್ಷತಾ-ಗಡಿ/) ನೋಡಿ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಹೃದಯ ವೈಫಲ್ಯ ರೋಗಿಗಳಿಗೆ ದೂರಸ್ಥ-ಮೇಲ್ವಿಚಾರಣಾ ಸೇವೆ, ಪ್ರತಿ 1,000 ರೋಗಿ/ವರ್ಷಕ್ಕೆ, ಸಾಮಾನ್ಯ ಆರೈಕೆಯ ವಿರುದ್ಧ:

```
Costs:   service £900,000; admissions avoided save £600,000
         ΔC = 900,000 − 600,000 = £300,000
Effects: earlier intervention gains 25 QALYs
         ΔE = 25

ICER = 300,000 / 25 = £12,000 per QALY
```

ಪ್ರತಿ QALYಗೆ £12,000, NICEಯ £20,000 ಮಿತಿಗಿಂತ ಆರಾಮವಾಗಿ ಕೆಳಗೆ — ಬಲವಾದ ಪ್ರಕರಣ. *ನಿವ್ವಳ* ವೆಚ್ಚ ಹೇಗೆ ಮುಖ್ಯ ಎಂಬುದನ್ನು ಗಮನಿಸಿ: £600,000 ಸರಿದೂಗಿಕೆ ಇಲ್ಲದಿದ್ದರೆ ICER ಪ್ರತಿ QALYಗೆ £36,000 ಆಗುತ್ತಿತ್ತು ಮತ್ತು ಪ್ರಕರಣ ಬಹುಶಃ ವಿಫಲವಾಗುತ್ತಿತ್ತು. ವೆಚ್ಚ ಸರಿದೂಗಿಕೆಗಳು ಮತ್ತು ಅವುಗಳ ಸಾಕ್ಷ್ಯದ ಗುಣಮಟ್ಟದಲ್ಲಿ ಈ ವಿಶ್ಲೇಷಣೆಗಳು ಗೆಲ್ಲುತ್ತವೆ ಅಥವಾ ಸೋಲುತ್ತವೆ ([ತಪ್ಪಿಸಲಾದ ಕೆಳಹರಿವಿನ ವೆಚ್ಚಗಳು](../ತಪ್ಪಿಸಿದ-ಕೆಳಹಂತದ-ವೆಚ್ಚಗಳು/) ನೋಡಿ).

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ICER ಶಿಸ್ತು ಎಂಜಿನಿಯರಿಂಗ್ ನಿರ್ಧಾರಗಳಿಗೆ ಸಂಪೂರ್ಣವಾಗಿ ವರ್ಗಾವಣೆಯಾಗುತ್ತದೆ:

```
(cost of option B − cost of option A) / (outcome B − outcome A)
```

— ಪ್ರತಿ ಹೆಚ್ಚುವರಿ ಡಿಪ್ಲಾಯ್‌ಗೆ, ಉಳಿತಾಯವಾದ ಪ್ರತಿ ಎಂಜಿನಿಯರ್-ಗಂಟೆಗೆ, ತಪ್ಪಿಸಿದ ಪ್ರತಿ ಘಟನೆಗೆ ಹೆಚ್ಚುವರಿ ವೆಚ್ಚ — ಯಾವಾಗಲೂ ಮುಂದಿನ-ಅತ್ಯುತ್ತಮ ಪರ್ಯಾಯದ ವಿರುದ್ಧ, ಏನೂ ಮಾಡದಿರುವುದರ ವಿರುದ್ಧ ಅಲ್ಲ. ಕದಿಯಲು ಯೋಗ್ಯ ಎರಡು ಅಭ್ಯಾಸಗಳು: (1) *ಹೋಲಿಕೆ ಆಧಾರವನ್ನು ಸ್ಪಷ್ಟವಾಗಿ ಹೆಸರಿಸಿ*; ಹೆಚ್ಚಿನ ಟೂಲ್ ROI ಹೇಳಿಕೆಗಳು ರಹಸ್ಯವಾಗಿ ಹುಲ್ಲಿನ ಬೊಂಬೆಯೊಂದಿಗೆ ಹೋಲಿಸುತ್ತವೆ; (2) *ಮೊದಲು ವೆಚ್ಚಗಳನ್ನು ನಿವ್ವಳಗೊಳಿಸಿ* — £100k ವೆಚ್ಚದ ಆದರೆ £80k ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ ವೆಚ್ಚವನ್ನು ಸ್ಥಾನಪಲ್ಲಟಗೊಳಿಸುವ ಟೂಲ್‌ನ ΔC = £20k.

## ಎಡವಟ್ಟುಗಳು

- **ಸ್ಪಷ್ಟ ಪರಿವರ್ತನಾ ಹೆಜ್ಜೆ ಇಲ್ಲದೆ ಕರೆನ್ಸಿಗಳಾದ್ಯಂತ ICER ಹೋಲಿಸುವುದು**: ಒಂದು ದೇಶದ ಕರೆನ್ಸಿಯಲ್ಲಿ ಲೆಕ್ಕಿಸಿದ ICER ಅನ್ನು ಇನ್ನೊಂದು ದೇಶದ ಮಿತಿಗೆ ಹೋಲಿಸುವ ಮೊದಲು ಹೇಳಿದ ವಿಧಾನದಿಂದ ಪರಿವರ್ತಿಸಬೇಕು — ಪರಿವರ್ತನಾ ಅಂಶದ ಆಯ್ಕೆ (ಖರೀದಿ ಸಾಮರ್ಥ್ಯ ಸಮಾನತೆ vs ಮಾರುಕಟ್ಟೆ ವಿನಿಮಯ ದರ) ಸ್ವತಃ ಅಳವಡಿಕೆ ನಿರ್ಧಾರವನ್ನು ಏಕೆ ತಿರುಗಿಸಬಹುದು ಎಂಬುದಕ್ಕೆ [ಅಡ್ಡ-ಕರೆನ್ಸಿ ICER ಹೋಲಿಕೆ](../ಅಡ್ಡ-ಕರೆನ್ಸಿ-icer-ಹೋಲಿಕೆ/) ನೋಡಿ.
- **ಹೋಲಿಕೆ ಆಧಾರದ ತಿರುಚುವಿಕೆ**: ಹಳೆಯ ಅಥವಾ ಕೃತಕವಾಗಿ ಕೆಟ್ಟ ಮೂಲರೇಖೆಯೊಂದಿಗೆ ಹೋಲಿಸುವುದು ΔE ಅನ್ನು ಉಬ್ಬಿಸಿ ICERಗೆ ಮುಖಸ್ತುತಿ ಮಾಡುತ್ತದೆ.
- **ಹೆಚ್ಚುವರಿಗಳ ಬದಲು ಸರಾಸರಿಗಳು**: ಇಡೀ ಕಾರ್ಯಕ್ರಮದ ಪ್ರತಿ QALY ವೆಚ್ಚ, ಅದನ್ನು ವಿಸ್ತರಿಸುವ ಅಥವಾ ಅಳವಡಿಸುವ ICER ಅಲ್ಲ.
- **ಬಿಂದು-ಅಂದಾಜಿನ ಆರಾಧನೆ**: ICERಗಳು ಎರಡು ಅನಿಶ್ಚಿತ ವ್ಯತ್ಯಾಸಗಳ ಅನುಪಾತಗಳು; ಅನಿಶ್ಚಿತತೆಯನ್ನು [PSA ಮತ್ತು CEACಗಳ](../ಸಂಭಾವ್ಯತಾ-ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/) ಮೂಲಕ ವರದಿ ಮಾಡಿ.
- **ಋಣಾತ್ಮಕ ICERಗಳು ಅಸ್ಪಷ್ಟ** (ಅಗ್ಗ-ಮತ್ತು-ಉತ್ತಮ vs ದುಬಾರಿ-ಮತ್ತು-ಕೆಟ್ಟದ್ದು ಒಂದೇ ಚಿಹ್ನೆ ನೀಡುತ್ತವೆ) — ಯಾವ ಚತುರ್ಥಾಂಶ ಎಂದು ಹೇಳದೆ ಋಣಾತ್ಮಕ ICER ಅನ್ನು ಎಂದಿಗೂ ವರದಿ ಮಾಡಬೇಡಿ.
