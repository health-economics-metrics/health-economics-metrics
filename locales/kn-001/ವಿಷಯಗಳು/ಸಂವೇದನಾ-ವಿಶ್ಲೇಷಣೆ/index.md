# ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ

ನಿರ್ಧಾರಾತ್ಮಕ ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ (DSA) ಒಂದು ಸಮಯದಲ್ಲಿ ಒಂದು ಊಹೆಯನ್ನು ಸಂಭಾವ್ಯ ವ್ಯಾಪ್ತಿಯಲ್ಲಿ ಬದಲಿಸಿ, ನಿರ್ಣಯ ಉಳಿಯುತ್ತದೆಯೇ ಎಂದು ನೋಡುತ್ತದೆ. ಪ್ರಮಾಣಿತ ದೃಶ್ಯೀಕರಣ ಟೊರ್ನೇಡೊ ಆಕೃತಿ: ನಿಯತಾಂಕಗಳು ಫಲಿತಾಂಶವನ್ನು ಎಷ್ಟು ಅಲುಗಾಡಿಸುತ್ತವೆ ಎಂಬುದರ ಆಧಾರದಲ್ಲಿ ಶ್ರೇಣೀಕೃತವಾಗುತ್ತವೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಪ್ರತಿಯೊಂದು ಆರ್ಥಿಕ ಮಾದರಿಯೂ ಅಂದಾಜುಗಳ ಮೇಲೆ ನಿರ್ಮಿತ — ಉಳಿತಾಯವಾದ ಸಮಯ, ಸ್ವೀಕಾರ, ಘಟಕ ವೆಚ್ಚಗಳು. ಆರೋಗ್ಯ ತಂತ್ರಜ್ಞಾನ ಮೌಲ್ಯಮಾಪನವು ಇನ್‌ಪುಟ್‌ಗಳ ಬಗ್ಗೆ ಸಮಂಜಸ ಭಿನ್ನಾಭಿಪ್ರಾಯಕ್ಕೆ ನಿರ್ಣಯ ದೃಢವಾಗಿದೆ ಎಂಬ ಸಾಕ್ಷ್ಯವಿಲ್ಲದೆ ಬಿಂದು ಅಂದಾಜನ್ನು ("ROI 340%") ಒಪ್ಪಿಕೊಳ್ಳಲು ನಿರಾಕರಿಸುತ್ತದೆ. ಟೊರ್ನೇಡೊ ಆಕೃತಿಯು ನಿರ್ಧಾರಕರಿಗೆ *ಯಾವ ಊಹೆಯನ್ನು ಪ್ರಶ್ನಿಸಬೇಕು* ಎಂದು ಹೇಳುತ್ತದೆ: ಅತ್ಯಂತ ವಿವಾದಾಸ್ಪದ ನಿಯತಾಂಕ ಅದರ ಆಶಾವಾದಿ ತುದಿಯಲ್ಲಿದ್ದಾಗ ಮಾತ್ರ ಪ್ರಕರಣ ಕೆಲಸ ಮಾಡುವುದಾದರೆ, ಎಲ್ಲರಿಗೂ ಅದು ತಕ್ಷಣ ಕಾಣುತ್ತದೆ.

ಆರೋಗ್ಯ ಅರ್ಥಶಾಸ್ತ್ರದಿಂದ ಸಾಫ್ಟ್‌ವೇರ್ ವ್ಯವಹಾರ ಪ್ರಕರಣಗಳಿಗೆ ವರ್ಗಾಯಿಸಬಹುದಾದ ಅತ್ಯಂತ ಉಪಯುಕ್ತ ಏಕೈಕ ಅಭ್ಯಾಸ ಇದು.

## ಗಣಿತ

ಸಂಭಾವ್ಯ ವ್ಯಾಪ್ತಿ [p_low, p_high] ಇರುವ ಪ್ರತಿ ನಿಯತಾಂಕ p ಗೆ:

```
Result_low  = model(p = p_low,  all others at base case)
Result_high = model(p = p_high, all others at base case)
Swing(p)    = |Result_high − Result_low|
```

ನಿಯತಾಂಕಗಳನ್ನು ಅಲುಗಾಟದ ಪ್ರಕಾರ ಶ್ರೇಣೀಕರಿಸಿ; ಮೂಲ-ಪ್ರಕರಣದ ಫಲಿತಾಂಶದ ಸುತ್ತ ಅಡ್ಡ ಪಟ್ಟಿಗಳನ್ನು ಚಿತ್ರಿಸಿ. ರೂಪಾಂತರಗಳು: ದ್ವಿಮುಖ DSA (ಎರಡು ನಿಯತಾಂಕಗಳನ್ನು ಗ್ರಿಡ್‌ನಲ್ಲಿ ಬದಲಿಸುವುದು), ಮಿತಿ ವಿಶ್ಲೇಷಣೆ (ನಿರ್ಧಾರ ಬದಲಾಗುವ ನಿಯತಾಂಕ ಮೌಲ್ಯವನ್ನು ಕಂಡುಹಿಡಿಯುವುದು).

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

200 ಡೆವಲಪರ್‌ಗಳಿಗೆ AI ಕೋಡಿಂಗ್ ಸಹಾಯಕ. ಮೂಲ ಪ್ರಕರಣ: ಪ್ರತಿ ಡೆವಲಪರ್‌ಗೆ ತಿಂಗಳಿಗೆ £39 ಪರವಾನಗಿ; ಡೆವಲಪರ್‌ಗೆ ದಿನಕ್ಕೆ 30 ನಿಮಿಷ ಉಳಿತಾಯ; ಲೋಡ್ ವೆಚ್ಚ ಗಂಟೆಗೆ £60; 220 ಕೆಲಸದ ದಿನಗಳು.

```
Base-case annual benefit = 200 × 0.5h × 220 × £60 = £1,320,000
Annual cost              = 200 × £39 × 12         = £93,600
Base-case net            = £1,226,400
```

ಟೊರ್ನೇಡೊ (ಒಂದು ಸಮಯದಲ್ಲಿ ಒಂದು ನಿಯತಾಂಕ):

```
Time saved 0.1–1.0 h/day: net = £170,400 … £2,546,400   (swing £2.38M) ← dominates
Loaded cost £40–£80/h:    net = £786,400 … £1,666,400   (swing £0.88M)
Working days 200–240:     net = £1,106,400 … £1,346,400 (swing £0.24M)
Licence £30–£50/mo:       net = £1,248,000 … £1,200,000 (swing £48k)
```

ಮಿತಿ ವಿಶ್ಲೇಷಣೆ: ದಿನಕ್ಕೆ ಸುಮಾರು **2.1 ನಿಮಿಷ** ಉಳಿತಾಯವಾದಾಗ ನಿವ್ವಳ ಲಾಭ ಸೊನ್ನೆಯಾಗುತ್ತದೆ. ನಿರ್ಧಾರವು ಪರವಾನಗಿ ಬೆಲೆಗೆ ಸಂವೇದನಾಶೀಲವಲ್ಲ ಮತ್ತು ಸಂಪೂರ್ಣವಾಗಿ ಉಳಿತಾಯವಾದ-ಸಮಯದ ಅಂದಾಜಿನ ಮೇಲೆ ನಿಂತಿದೆ — ಆದ್ದರಿಂದ ಉಳಿದದ್ದನ್ನಲ್ಲ, ಅದನ್ನು ಅಳೆಯಿರಿ. (ಮತ್ತು ಫಲಿತಾಂಶವು ನಗದಲ್ಲ, ಸಾಮರ್ಥ್ಯ ಎಂಬುದನ್ನು ನೆನಪಿಡಿ — [ನಗದು-ಬಿಡುಗಡೆ vs ನಗದು-ರಹಿತ](../ನಗದು-ಬಿಡುಗಡೆ-vs-ನಗದು-ರಹಿತ-ಉಳಿತಾಯ/) ನೋಡಿ.)

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಎಂಜಿನಿಯರ್‌ಗಳು ಈಗಾಗಲೇ ಇದನ್ನು "X ಬಗ್ಗೆ ನಾವು ತಪ್ಪಾಗಿದ್ದರೆ?" ಎಂಬ ಸಹಜ ಪ್ರವೃತ್ತಿಯಾಗಿ ಮಾಡುತ್ತಾರೆ — DSA ಅದನ್ನು ವ್ಯವಸ್ಥಿತ ಮತ್ತು ಗೋಚರವಾಗಿಸುತ್ತದೆ ಅಷ್ಟೆ. ಪ್ರತಿ ಟೂಲಿಂಗ್ ಪ್ರಸ್ತಾವನೆ, ಸಾಮರ್ಥ್ಯ ಯೋಜನೆ ಮತ್ತು ನಿರ್ಮಿಸಿ-vs-ಖರೀದಿಸಿ ವಿಶ್ಲೇಷಣೆಯಲ್ಲಿ ಟೊರ್ನೇಡೊ ಆಕೃತಿ ಇರಿಸಿ. ಯಾರ ಒಳಮನಸ್ಸು ಸರಿ ಎಂಬ ವಾದಗಳನ್ನು ಯಾವ ನಿಯತಾಂಕವನ್ನು ಅಳೆಯಬೇಕು ಎಂಬ ಒಪ್ಪಂದಗಳಾಗಿ ಅದು ಪರಿವರ್ತಿಸುತ್ತದೆ — ಆಗಾಗ ಪೈಲಟ್ ಮೂಲಕ, ಅದರ ಮೌಲ್ಯಕ್ಕೂ ಬೆಲೆ ಕಟ್ಟಬಹುದು ([ಪರಿಪೂರ್ಣ ಮಾಹಿತಿಯ ನಿರೀಕ್ಷಿತ ಮೌಲ್ಯ](../ಪರಿಪೂರ್ಣ-ಮಾಹಿತಿಯ-ನಿರೀಕ್ಷಿತ-ಮೌಲ್ಯ/) ನೋಡಿ).

## ಎಡವಟ್ಟುಗಳು

- **ಮುಖಸ್ತುತಿಗೆ ಆರಿಸಿದ ವ್ಯಾಪ್ತಿಗಳು**: ನಿಜವಾದ ಅನಿಶ್ಚಿತತೆಯ ಪರಿವೆ ಇಲ್ಲದೆ ಪ್ರತಿ ಇನ್‌ಪುಟ್ ಸುತ್ತ ±10%. ಉಳಿತಾಯವಾದ-ಸಮಯದ ಅಂದಾಜುಗಳಿಗೆ ±80% ಬೇಕು; ಪರವಾನಗಿ ಬೆಲೆಗಳಿಗೆ ±10%.
- **ಒಂದು-ಸಮಯದಲ್ಲಿ-ಒಂದು ವಿಧಾನ ಪರಸ್ಪರ ಕ್ರಿಯೆಗಳನ್ನು ತಪ್ಪಿಸುತ್ತದೆ** — ಸಹಸಂಬಂಧಿತ ನಿಯತಾಂಕಗಳಿಗೆ (ಸ್ವೀಕಾರ ಮತ್ತು ಉಳಿತಾಯವಾದ ಸಮಯ) ದ್ವಿಮುಖ ವಿಶ್ಲೇಷಣೆ ಅಥವಾ ಪೂರ್ಣ [ಸಂಭಾವ್ಯತಾ ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ](../ಸಂಭಾವ್ಯತಾ-ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/) ಬೇಕು.
- **ವಿಶ್ಲೇಷಣೆ ಮಾಡಿ ಅದನ್ನು ನಿರ್ಲಕ್ಷಿಸುವುದು**: ಪ್ರಕರಣವು ಒಂದು ಮೃದು ಸಂಖ್ಯೆಯ ಮೇಲೆ ನಿಂತಿದೆ ಎಂದು ಟೊರ್ನೇಡೊ ಹೇಳಿದರೆ, ಮುಂದಿನ ಹೆಜ್ಜೆ ಅಳತೆ, ಸಹಿ ಅಲ್ಲ.
