# ಡಿಜಿಟಲ್ ಅಂತಿಮ ಬಿಂದುಗಳು ಮತ್ತು ಜೈವಿಕ ಗುರುತುಗಳು

ಡಿಜಿಟಲ್ ಜೈವಿಕ ಗುರುತು (digital biomarker) ಎಂದರೆ ಸಂವೇದಕಗಳ ಮೂಲಕ ಸಂಗ್ರಹಿಸಿದ ವಸ್ತುನಿಷ್ಠ ಶಾರೀರಿಕ ಅಥವಾ ವರ್ತನಾ ಮಾಪನ (ಫೋನ್‌ನಿಂದ ನಡಿಗೆ ವೇಗ, ಧರಿಸುವ ಸಾಧನದಿಂದ ನಿದ್ರೆ, ವೇಗವರ್ಧಕಮಾಪನದಿಂದ ನಡುಕ). ಡಿಜಿಟಲ್ ಅಂತಿಮ ಬಿಂದು (digital endpoint) ಎಂದರೆ ಅಂತಹ ಮಾಪನವನ್ನು ಚಿಕಿತ್ಸಾ ಪರಿಣಾಮ ತೋರಿಸಲು ಬಳಸುವ **ಪ್ರಯೋಗ ಫಲಿತಾಂಶ**ಕ್ಕೆ ಉನ್ನತೀಕರಿಸಿದ್ದು. "ಸಾಧನ ಹೊರಸೂಸುವ ದತ್ತಾಂಶ"ದಿಂದ "ನಿಯಂತ್ರಕ ಒಪ್ಪುವ ಸಾಕ್ಷ್ಯ"ಕ್ಕೆ ಬಡ್ತಿ ನಿರ್ದಿಷ್ಟ ಮೌಲ್ಯೀಕರಣ ಏಣಿಯ ಮೂಲಕ ಹೋಗುತ್ತದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಸಾಂಪ್ರದಾಯಿಕ ಪ್ರಯೋಗ ಅಂತಿಮ ಬಿಂದುಗಳು ಆವರ್ತಕ (ಪ್ರತಿ 3 ತಿಂಗಳಿಗೆ ಕ್ಲಿನಿಕ್ ಭೇಟಿಗಳು) ಮತ್ತು ದುಬಾರಿ; ಡಿಜಿಟಲ್ ಅಂತಿಮ ಬಿಂದುಗಳು ನಿರಂತರ, ಪರಿಸರೀಯ (ನಿಜ ಜೀವನ, ಕ್ಲಿನಿಕ್ ಕಾರ್ಯಕ್ಷಮತೆಯಲ್ಲ), ಮತ್ತು ಪ್ರತಿ ವೀಕ್ಷಣೆಗೆ ಅಗ್ಗ — ಅವು ಪ್ರಯೋಗಗಳನ್ನು ಕುಗ್ಗಿಸಬಹುದು, ಪರಿಣಾಮಗಳನ್ನು ಬೇಗ ಪತ್ತೆಹಚ್ಚಬಹುದು ಮತ್ತು ವಿಕೇಂದ್ರೀಕೃತ ಅಧ್ಯಯನಗಳನ್ನು ಸಾಧ್ಯವಾಗಿಸಬಹುದು. ಸಿಕ್ಕಿಹಾಕಿಕೊಳ್ಳುವ ಅಂಶ ಮೌಲ್ಯೀಕರಣ: ಒಪ್ಪಿತ ಚೌಕಟ್ಟಿಗೆ (FDA-ಹೊಂದಾಣಿಕೆಯ, ಮೂರು ಸ್ತಂಭಗಳು) **ಪರಿಶೀಲನೆ/ವಿಶ್ಲೇಷಣಾತ್ಮಕ ಮೌಲ್ಯೀಕರಣ** (ಸಂವೇದಕ ಭೌತಿಕ ಪ್ರಮಾಣವನ್ನು ನಿಖರವಾಗಿ ಅಳೆಯುತ್ತದೆ), **ಕ್ಲಿನಿಕಲ್ ಮೌಲ್ಯೀಕರಣ** (ಮಾಪನ ತಾನು ಹೇಳುವ ಕ್ಲಿನಿಕಲ್ ಸ್ಥಿತಿಯನ್ನು ಪ್ರತಿಬಿಂಬಿಸುತ್ತದೆ), ಮತ್ತು ಪ್ರದರ್ಶಿತ **ಆರೋಗ್ಯದ ಅರ್ಥಪೂರ್ಣ ಅಂಶ** (ಅದು ಸೆರೆಹಿಡಿಯುವುದರ ಬಗ್ಗೆ ರೋಗಿಗಳು ಕಾಳಜಿ ವಹಿಸುತ್ತಾರೆ) ಬೇಕು. ಮೂರೂ ಇಲ್ಲದ ಅಂತಿಮ ಬಿಂದು ಟೆಲಿಮೆಟ್ರಿ, ಸಾಕ್ಷ್ಯವಲ್ಲ.

## ಗಣಿತ

```
Analytical validation: agreement with reference (see wearable-validation.md —
                       MAPE, CCC, Bland-Altman)
Clinical validation:   correlation/discrimination against clinical anchors
                       (known-groups validity, responsiveness to change)
Endpoint economics:
  events detected per patient-year (continuous) vs per-visit sampling
  trial power: continuous measures cut sample size when between-visit
  variance dominates — N ∝ σ²/Δ², and σ² falls with dense sampling
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಪಾರ್ಕಿನ್ಸನ್ ಪ್ರಯೋಗ ತ್ರೈಮಾಸಿಕ ಕ್ಲಿನಿಕ್-ರೇಟ್ ಮಾಡಿದ ಅಂಕಗಳ ವಿರುದ್ಧ ಮಣಿಕಟ್ಟು ಸಂವೇದಕದಿಂದ ನಡಿಗೆ ವೇಗವನ್ನು ಪರಿಗಣಿಸುತ್ತದೆ:

```
Clinic endpoint:  4 measurements/patient/year, high day-to-day noise
Digital endpoint: ~200 passive measurements/patient/year

Variance of the annual-change estimate falls ~5× with dense sampling →
detectable effect size at fixed power improves ~√5 ≈ 2.2×, or
equivalently sample size shrinks ~40–60% for the same hypothesis.
At £25,000 per enrolled patient, cutting 200 patients ≈ £5M saved
per trial — the commercial case for the validation investment
(itself perhaps £1–2M) across a sponsor's pipeline.
```

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಡಿಜಿಟಲ್ ಅಂತಿಮ ಬಿಂದುಗಳು ಕ್ಲಿನಿಕಲ್ ಉಡುಪು ಧರಿಸಿದ ದತ್ತಾಂಶ-ಎಂಜಿನಿಯರಿಂಗ್ ಶಿಸ್ತು: **ಮೂಲ ಮತ್ತು ಆವೃತ್ತೀಕರಣ** (ಅಧ್ಯಯನದ ಮಧ್ಯದ ಅಲ್ಗಾರಿದಮ್ ನವೀಕರಣಗಳು ಹೋಲಿಕೆಗೆ ಬೆದರಿಕೆ — ಪ್ರಯೋಗ ರೂಪದಲ್ಲಿ [PCCP](../ai-ನಿಯಂತ್ರಕ-ಮೌಲ್ಯಮಾಪನ/) ಸಮಸ್ಯೆ; ಆವೃತ್ತಿ-ಲಾಕ್ ಮತ್ತು ಸೇತುವೆ-ಮೌಲ್ಯೀಕರಣ); **ಕಾಣೆಯಾದ-ದತ್ತಾಂಶ ವಿನ್ಯಾಸ** (ಧರಿಸಿದ-ಸಮಯದ ಅಂತರಗಳು ಮಾಹಿತಿಪೂರ್ಣ, ಯಾದೃಚ್ಛಿಕವಲ್ಲ — [ಧರಿಸುವ ಸಾಧನ ಮೌಲ್ಯೀಕರಣ](../ಧರಿಸುವ-ಸಾಧನ-ಮೌಲ್ಯೀಕರಣ/) ನೋಡಿ; ಅಭಿಕಲನ ಆಯ್ಕೆಗಳು ವೈಜ್ಞಾನಿಕ ಹೇಳಿಕೆಗಳು); ಮತ್ತು ನಂತರ ಯಾವ ಕಚ್ಚಾ ಸಂಕೇತ ಮರುಪಡೆಯಬಹುದು ಎಂಬುದನ್ನೇ ಬದಲಿಸುವ **ಅಂಚು/ಕ್ಲೌಡ್ ವಿಭಜನೆ ನಿರ್ಧಾರಗಳು**. ಮಾಪನ ಪೈಪ್‌ಲೈನ್ ಅನ್ನು ಮೊದಲ ದಿನದಿಂದಲೇ ನಿಯಂತ್ರಿತ ಸಾಫ್ಟ್‌ವೇರ್ ಆಗಿ — ಪರೀಕ್ಷಿಸಿ, ಆವೃತ್ತಿ ಮಾಡಿ, ದಾಖಲಿಸಿ — ಪರಿಗಣಿಸುವ ತಂಡಗಳು ತಮ್ಮ ಅಂತಿಮ ಬಿಂದುಗಳ ವಿಶ್ವಾಸಾರ್ಹತೆಯನ್ನು ಅಗ್ಗವಾಗಿ ಖರೀದಿಸುತ್ತವೆ; ವೇಗವಾಗಿ ಚಲಿಸಿದ ಪೈಪ್‌ಲೈನ್‌ಗೆ ಮೌಲ್ಯೀಕರಣವನ್ನು ನಂತರ ಜೋಡಿಸುವಲ್ಲಿ ಡಿಜಿಟಲ್-ಅಂತಿಮ-ಬಿಂದು ಕಾರ್ಯಕ್ರಮಗಳು ಸಾಯುತ್ತವೆ.

## ಎಡವಟ್ಟುಗಳು

- **ಕ್ಲಿನಿಕ್‌ನೊಂದಿಗೆ ಸಹಸಂಬಂಧವೇ ಪೂರ್ಣ ಮೌಲ್ಯೀಕರಣ**: ದೋಷಪೂರ್ಣ ಕ್ಲಿನಿಕ್ ಮಾಪನಕ್ಕೆ ಹೊಂದಿಸುವುದು ಸತ್ಯವಲ್ಲ, ಉತ್ತರಾಧಿಕಾರವನ್ನು ಸಾಬೀತುಪಡಿಸುತ್ತದೆ; ಅರ್ಥಪೂರ್ಣ ಆರೋಗ್ಯ ಅಂಶದ ವಿರುದ್ಧ ಮೌಲ್ಯೀಕರಿಸಿ.
- **ನೂತನ-ಅಂತಿಮ-ಬಿಂದು ನಿಯಂತ್ರಕ ಅಪಾಯ**: ಅಭೂತಪೂರ್ವ ಅಂತಿಮ ಬಿಂದು ವೈಜ್ಞಾನಿಕವಾಗಿ ಶ್ರೇಷ್ಠವಾಗಿದ್ದರೂ ಸಲ್ಲಿಕೆಯನ್ನು ಮುಳುಗಿಸಬಹುದು — ನಿಯಂತ್ರಕರನ್ನು ಬೇಗನೆ ತೊಡಗಿಸಿ (ಅರ್ಹತಾ ಕಾರ್ಯಕ್ರಮಗಳಿವೆ).
- **ಸಂವೇದಕ-ಜನಸಂಖ್ಯೆ ಹೊಂದಾಣಿಕೆಯಿಲ್ಲದಿರುವುದು**: ಯುವ ಆರೋಗ್ಯವಂತ ಮಣಿಕಟ್ಟುಗಳಲ್ಲಿ ಮೌಲ್ಯೀಕರಣ, ನಡುಕ ಮತ್ತು PPG ಎಂದೂ ಕಾಣದ ವರ್ಣದ್ರವ್ಯ ವ್ಯತ್ಯಾಸಗಳಿರುವ ವೃದ್ಧ ರೋಗಿಗಳಲ್ಲಿ ನಿಯೋಜನೆ.
- **ವೈಶಿಷ್ಟ್ಯ ವಿಚಲನೆ**: ಹೊಸ ದತ್ತಾಂಶದ ಮೇಲೆ ನಡಿಗೆ ಅಲ್ಗಾರಿದಮ್ ಮರು-ತರಬೇತಿ ಅಧ್ಯಯನದ ಮಧ್ಯದಲ್ಲಿ ಅಂತಿಮ ಬಿಂದುವನ್ನೇ ಮೌನವಾಗಿ ಮರು-ವ್ಯಾಖ್ಯಾನಿಸುತ್ತದೆ.
