# ನಿವ್ವಳ ಹಣಕಾಸು ಲಾಭ (NMB)

NMB ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ಫಲಿತಾಂಶವನ್ನು ಒಂದೇ ಹಣದ ಮೌಲ್ಯಕ್ಕೆ ಪರಿವರ್ತಿಸುತ್ತದೆ: ಪಾವತಿಸಲು ಇಚ್ಛೆಯ ಮಿತಿಯಲ್ಲಿ ಬೆಲೆ ಕಟ್ಟಿದ ಆರೋಗ್ಯ ಲಾಭ, ಮೈನಸ್ ವೆಚ್ಚ. ಅದರ ಅವಳಿ, ನಿವ್ವಳ ಆರೋಗ್ಯ ಲಾಭ (NHB), ಅದೇ ನಿಯಮವನ್ನು ಆರೋಗ್ಯ ಘಟಕಗಳಲ್ಲಿ ವ್ಯಕ್ತಪಡಿಸುತ್ತದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಅನುಪಾತಗಳು ([ICERಗಳು](../ಹೆಚ್ಚುವರಿ-ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ಅನುಪಾತ/)) ಅಸಹಜ: ಅವು ಶೂನ್ಯ ಪರಿಣಾಮದ ಹತ್ತಿರ ಸ್ಫೋಟಿಸುತ್ತವೆ, ಅನಿಶ್ಚಿತತೆ ಮಾದರಿಗಳಾದ್ಯಂತ ಸರಾಸರಿ ತೆಗೆಯಲಾಗದು, ಮತ್ತು ಮೂರು ಅಥವಾ ಹೆಚ್ಚು ಆಯ್ಕೆಗಳನ್ನು ಸ್ವಚ್ಛವಾಗಿ ಶ್ರೇಣೀಕರಿಸಲಾಗದು. NMB ಅದೆಲ್ಲವನ್ನೂ ಸರಿಪಡಿಸುತ್ತದೆ — ಅದು ರೇಖೀಯ, ಆದ್ದರಿಂದ ಆಯ್ಕೆಗಳನ್ನು ಶ್ರೇಣೀಕರಿಸಬಹುದು, ಮಾಂಟೆ ಕಾರ್ಲೊ ಮಾದರಿಗಳ ಸರಾಸರಿ ತೆಗೆಯಬಹುದು ಮತ್ತು ಕೊಡುಗೆಗಳನ್ನು ವಿಭಜಿಸಬಹುದು. ಪ್ರತಿ ಎಂಜಿನಿಯರ್ ಈಗಾಗಲೇ ತಿಳಿದಿರುವ ಆರೋಗ್ಯ-ಆರ್ಥಿಕ ಗಣಿತದ ರೂಪವೂ ಇದೇ: *ಮೌಲ್ಯ ಮೈನಸ್ ವೆಚ್ಚ*.

## ಗಣಿತ

```
NMB = (ΔE × λ) − ΔC
NHB = ΔE − (ΔC / λ)

ΔE = incremental effect (e.g., QALYs)
ΔC = incremental cost
λ  = willingness-to-pay threshold (see willingness-to-pay-thresholds.md)

Decision rule: adopt if NMB > 0 (equivalently NHB > 0).
Among alternatives: choose the highest NMB.
```

NMB > 0 ⇔ ICER < λ (ΔE > 0 ಆದಾಗ), ಆದ್ದರಿಂದ ಎರಡು ನಿಯಮಗಳು ಒಪ್ಪುತ್ತವೆ — NMB ಹೆಚ್ಚು ಸುವ್ಯವಸ್ಥಿತ ವರ್ತನೆ ಹೊಂದಿದೆ ಅಷ್ಟೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಮಧುಮೇಹ ಸೇವೆಗೆ ಮೂರು ಆಯ್ಕೆಗಳು, ಪ್ರತಿ 1,000 ರೋಗಿಗಳಿಗೆ, λ = £20,000/QALY:

```
Option           ΔC          ΔE (QALYs)   NMB = 20,000×ΔE − ΔC
App + coaching   £400,000    30           600,000 − 400,000 = £200,000
App only         £150,000    12           240,000 − 150,000 = £90,000
Extra clinics    £700,000    32           640,000 − 700,000 = −£60,000
```

ಹೆಚ್ಚುವರಿ ಕ್ಲಿನಿಕ್‌ಗಳು ಅತಿ ಹೆಚ್ಚು QALY ಗಳಿಸುತ್ತವೆ ಆದರೆ ಈ ಮಿತಿಯಲ್ಲಿ ಮೌಲ್ಯವನ್ನು ನಾಶಮಾಡುತ್ತವೆ (NMB < 0). ಆ್ಯಪ್ + ತರಬೇತಿ ಗೆಲ್ಲುತ್ತದೆ. NMB ನಿಮಗೆ *ಮೂರನ್ನೂ ಒಮ್ಮೆಗೇ ಶ್ರೇಣೀಕರಿಸಲು* ಅವಕಾಶ ನೀಡುತ್ತದೆ ಎಂಬುದನ್ನು ಗಮನಿಸಿ — ಜೋಡಿ ICERಗಳಿಗೆ [ಪ್ರಾಬಲ್ಯ ಮತ್ತು ದಕ್ಷತಾ ಗಡಿ](../ಪ್ರಾಬಲ್ಯ-ಮತ್ತು-ದಕ್ಷತಾ-ಗಡಿ/)ಯ ಗಡಿ ವಿಧಾನ ಬೇಕು, ಮತ್ತು ಅದೇ ಉತ್ತರ ತಲುಪುತ್ತದೆ.

ವಿಜೇತನ NHB ನೋಟ: 30 − 400,000/20,000 = 30 − 20 = **10 QALY ನಿವ್ವಳ** — ಅದೇ ಹಣ ಬೇರೆಡೆ ಉತ್ಪಾದಿಸುತ್ತಿದ್ದುದಕ್ಕಿಂತ ಹೆಚ್ಚು ಗಳಿಸಿದ ಆರೋಗ್ಯ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

`(ಉಳಿತಾಯವಾದ ಗಂಟೆಗಳು × ಲೋಡ್ ಗಂಟೆ ದರ) − ಟೂಲ್ ವೆಚ್ಚ` — ದೈನಂದಿನ ಟೂಲಿಂಗ್ ವ್ಯವಹಾರ ಪ್ರಕರಣ — ಅಕ್ಷರಶಃ λ = ಲೋಡ್ ಎಂಜಿನಿಯರ್ ವೆಚ್ಚ ಇರುವ NMB ಲೆಕ್ಕಾಚಾರ. ಆರೋಗ್ಯ ಅರ್ಥಶಾಸ್ತ್ರ ಸೇರಿಸುವ ಎರಡು ಉನ್ನತೀಕರಣಗಳು:

- **λ ಅನ್ನು ಸ್ಥಿರಾಂಕವಲ್ಲ, ಚರಾಂಕವನ್ನಾಗಿಸಿ.** NMB ಅನ್ನು λ ವಿರುದ್ಧ ("ಎಂಜಿನಿಯರ್-ಗಂಟೆಯ ಮೌಲ್ಯ") ಚಿತ್ರಿಸಿ ಮತ್ತು ನಿರ್ಧಾರ ಎಲ್ಲಿ ತಿರುಗುತ್ತದೆ ಎಂದು ತೋರಿಸಿ; ಆಗ ವಿಭಿನ್ನ ಪಾಲುದಾರರು ನಿಮ್ಮ ಗಣಿತವನ್ನು ಮತ್ತೆ ಮಾಡದೆ ತಮ್ಮದೇ ಮೌಲ್ಯಮಾಪನ ಅನ್ವಯಿಸಬಹುದು.
- **NHB ಚಿಂತನೆ**: "ಈ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ 5,000 ಎಂಜಿನಿಯರ್-ಗಂಟೆಗಳನ್ನು ಉಳಿಸುತ್ತದೆ ಆದರೆ 3,000 ಎಂಜಿನಿಯರ್-ಗಂಟೆಗಳ ಗುತ್ತಿಗೆದಾರ ಸಾಮರ್ಥ್ಯವನ್ನು ಖರೀದಿಸುತ್ತಿದ್ದ ಬಜೆಟ್ ಬಳಸುತ್ತದೆ — ನಿವ್ವಳ 2,000 ಗಂಟೆಗಳು" ಎನ್ನುವುದು ಸಾಮರ್ಥ್ಯ ಘಟಕಗಳಲ್ಲಿ ಅವಕಾಶ-ವೆಚ್ಚ ಹೋಲಿಕೆಯನ್ನು ಒತ್ತಾಯಿಸುತ್ತದೆ. [ಅವಕಾಶ ವೆಚ್ಚ](../ಅವಕಾಶ-ವೆಚ್ಚ/) ನೋಡಿ.

## ಎಡವಟ್ಟುಗಳು

- **ಮಿತಿಯನ್ನು ಅಡಗಿಸುವುದು**: λ ಹೇಳದೆ NMB ಅರ್ಥಹೀನ; NMB ಅನ್ನು £20k ಮತ್ತು £30kಯಲ್ಲಿ ವರದಿ ಮಾಡಿ, ಅಥವಾ ವಕ್ರರೇಖೆಯನ್ನು ಚಿತ್ರಿಸಿ.
- **ಸಣ್ಣ ಪರಿಣಾಮಗಳನ್ನು ಶುದ್ಧೀಕರಿಸಲು NMB ಬಳಸುವುದು**: ದೊಡ್ಡ ಜನಸಂಖ್ಯೆ ಗುಣಿಸಿದ ನಗಣ್ಯ ಪ್ರತಿ-ವ್ಯಕ್ತಿ ಪರಿಣಾಮ ದೊಡ್ಡ NMB ನೀಡಬಹುದು — ಪ್ರತಿ-ವ್ಯಕ್ತಿ ಪರಿಣಾಮಗಳನ್ನೂ ಜೊತೆಗೆ ವರದಿ ಮಾಡಿ.
- **NMB, ΔC ಮತ್ತು ΔEಯ ಪ್ರತಿ ಅನಿಶ್ಚಿತತೆಯನ್ನು ಬಳುವಳಿಯಾಗಿ ಪಡೆಯುತ್ತದೆ ಎಂಬುದನ್ನು ಮರೆಯುವುದು** — [ಸಂಭಾವ್ಯತಾ ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ](../ಸಂಭಾವ್ಯತಾ-ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/)ಯೊಂದಿಗೆ ಜೋಡಿಸಿ.
