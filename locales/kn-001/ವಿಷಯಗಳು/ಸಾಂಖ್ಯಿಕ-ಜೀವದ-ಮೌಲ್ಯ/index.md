# ಸಾಂಖ್ಯಿಕ ಜೀವದ ಮೌಲ್ಯ (VSL)

ಸಾಂಖ್ಯಿಕ ಜೀವದ ಮೌಲ್ಯ (VSL) — ಯುಕೆ ಬಳಕೆಯಲ್ಲಿ "ತಡೆಯಲಾದ ಮರಣದ ಮೌಲ್ಯ" (VPF) ಎನ್ನುತ್ತಾರೆ — ಒಂದು ಸಾಂಖ್ಯಿಕ ಸಾವಿನ ಅಪಾಯವನ್ನು ಕಡಿಮೆ ಮಾಡಲು *ಜನಸಂಖ್ಯೆ* ಸಾಮೂಹಿಕವಾಗಿ ಪಾವತಿಸಲು ಸಿದ್ಧವಿರುವ ಮೊತ್ತ, ಇದನ್ನು ವೇತನ-ಅಪಾಯ ವಿನಿಮಯ ಅಧ್ಯಯನಗಳಿಂದ (ಅಪಾಯಕಾರಿ ಕೆಲಸಗಳಿಗೆ ಕಾರ್ಮಿಕರು ಎಷ್ಟು ಹೆಚ್ಚುವರಿ ವೇತನ ಕೇಳುತ್ತಾರೆ) ಮತ್ತು ಘೋಷಿತ-ಆದ್ಯತೆ ಸಮೀಕ್ಷೆಗಳಿಂದ ಪಡೆಯಲಾಗುತ್ತದೆ. ಇದು ಗುರುತಿಸಲಾದ ಯಾವುದೇ ವ್ಯಕ್ತಿಯ ಜೀವದ ಬೆಲೆಯಲ್ಲ; ಇದು ಜನಸಂಖ್ಯಾ-ಅಪಾಯ ರಚನೆ, ಮತ್ತು ಅಪಾಯ-ಕಡಿಮೆ ಮಾಡುವ ವ್ಯವಸ್ಥೆಗಳನ್ನು — ಟ್ರಯಾಜ್ ಅಲ್ಗಾರಿದಮ್‌ಗಳು, ಆಂಬ್ಯುಲೆನ್ಸ್ ರವಾನೆ, ಸುರಕ್ಷತಾ ಮೇಲ್ವಿಚಾರಣೆ — ನಿರ್ಮಿಸುವ ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರ್, ಇದು [ಪಾವತಿಸಲು ಇಚ್ಛೆಯ ಮಿತಿಗಳಿಗಿಂತ](../ಪಾವತಿಸಲು-ಇಚ್ಛೆಯ-ಮಿತಿಗಳು/) ಭಿನ್ನ ಸೈದ್ಧಾಂತಿಕ ಸಂಪ್ರದಾಯದಿಂದ ಬರುತ್ತದೆ ಎಂದು ತಿಳಿಯಬೇಕು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

VSL/VPF ನಿಯಂತ್ರಕ ವೆಚ್ಚ-ಲಾಭ ವಿಶ್ಲೇಷಣೆಯಲ್ಲಿ ಮರಣ-ಅಪಾಯ ಕಡಿತಗಳನ್ನು ಹಣದ ರೂಪಕ್ಕೆ ಪರಿವರ್ತಿಸುವ ಪ್ರಮಾಣಿತ ಸಾಧನ: ಸಾರಿಗೆ ಸುರಕ್ಷತೆ, ಪರಿಸರ ನಿಯಂತ್ರಣ ಮತ್ತು ಕೆಲವು ಸಾರ್ವಜನಿಕ-ಆರೋಗ್ಯ ಮಧ್ಯಸ್ಥಿಕೆಗಳು ತಮ್ಮ ವ್ಯವಹಾರ ಪ್ರಕರಣಗಳನ್ನು ಇದರ ಮೂಲಕ ನಡೆಸುತ್ತವೆ. HM ಖಜಾನೆಯ ಗ್ರೀನ್ ಬುಕ್ ಯುಕೆ ಕಾರ್ಮಿಕ-ಮಾರುಕಟ್ಟೆ ಮತ್ತು ಸಮೀಕ್ಷೆ ಸಾಕ್ಷ್ಯದಿಂದ ಪಡೆದ VPF ಅಂಕಿಯನ್ನು ಪ್ರಕಟಿಸುತ್ತದೆ, ಮತ್ತು ಸಾರಿಗೆ ಇಲಾಖೆ ರಸ್ತೆ-ಸುರಕ್ಷತಾ ಮೌಲ್ಯಮಾಪನದಲ್ಲಿ ಅದನ್ನು ನೇರವಾಗಿ ಬಳಸುತ್ತದೆ. ಇದು QALY × ಪಾವತಿಸಲು ಇಚ್ಛೆಯ ಮಿತಿ ವಿಧಾನಶಾಸ್ತ್ರಕ್ಕಿಂತ ನಿಜವಾಗಿಯೂ ಭಿನ್ನ ಮೌಲ್ಯಮಾಪನ ಸಂಪ್ರದಾಯ: ಮಿತಿ ವಿಧಾನವು ಆರೋಗ್ಯ ಲಾಭಗಳನ್ನು ಆರೋಗ್ಯ *ಬಜೆಟ್* ಪ್ರಸ್ತುತ ಅಂಚಿನಲ್ಲಿ ಉತ್ಪಾದಿಸುವುದರ ವಿರುದ್ಧ ಮೌಲ್ಯೀಕರಿಸುತ್ತದೆ, ಆದರೆ VSL/VPF ಅಪಾಯ ಕಡಿತವನ್ನು ಕಾರ್ಮಿಕ ಮಾರುಕಟ್ಟೆಯ ಅಥವಾ ಸಮೀಕ್ಷೆಯ ಜನರು ಅದಕ್ಕಾಗಿ ಪಾವತಿಸುತ್ತೇವೆಂದು ಬಹಿರಂಗಪಡಿಸುವುದರ ವಿರುದ್ಧ ಮೌಲ್ಯೀಕರಿಸುತ್ತದೆ. ಈ ಎರಡು ಚೌಕಟ್ಟುಗಳು ಯಾವಾಗಲೂ ಹೊಂದಾಣಿಕೆಯಾಗುವುದಿಲ್ಲ, ಮತ್ತು ಅದನ್ನು ಒಪ್ಪಿಕೊಳ್ಳದೆ ಒಂದೇ ಪ್ರಕರಣದಲ್ಲಿ ಎರಡನ್ನೂ ಬಳಸುವುದು ಸಾಮಾನ್ಯ ವಿಶ್ಲೇಷಣಾ ತಪ್ಪು.

## ಗಣಿತ

```
Deaths averted = population × risk_reduction_per_person
  (risk_reduction_per_person is a probability, e.g. 0.000001 = 1-in-a-million
   reduction in annual mortality risk)

Monetized mortality benefit = deaths_averted × value_of_prevented_fatality
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

800,000 ಜನರ ಪ್ರದೇಶವು ರಸ್ತೆ-ಸುರಕ್ಷತಾ ಡಿಜಿಟಲ್ ರವಾನೆ/ಟ್ರಯಾಜ್ ಮಧ್ಯಸ್ಥಿಕೆಯಿಂದ ಪ್ರಯೋಜನ ಪಡೆಯುತ್ತದೆ, ಅದು ಪ್ರತಿ ವ್ಯಕ್ತಿಯ ವಾರ್ಷಿಕ ಮರಣ ಅಪಾಯವನ್ನು ಮಿಲಿಯನ್‌ನಲ್ಲಿ 1ರಷ್ಟು (0.000001) ಕಡಿಮೆ ಮಾಡುತ್ತದೆ:

```
Deaths averted = 800,000 × 0.000001 = 0.8
```

ಯುಕೆಯ ತಡೆಯಲಾದ ಮರಣದ ಮೌಲ್ಯ £2,180,000 ಬಳಸಿ (HM ಖಜಾನೆ/DfT ಅಂಕಿ, 2023/24 ಬೆಲೆಗಳು — ಗ್ರೀನ್ ಬುಕ್ ಇದನ್ನು ವಾರ್ಷಿಕವಾಗಿ ನವೀಕರಿಸುತ್ತದೆ, ಜೀವಂತ ವಿಶ್ಲೇಷಣೆಯಲ್ಲಿ ಉಲ್ಲೇಖಿಸುವ ಮೊದಲು ಮರುಪರಿಶೀಲಿಸಿ):

```
Monetized mortality benefit = 0.8 × £2,180,000 = £1,744,000/year
```

ವರ್ಷಕ್ಕೆ £1.75 ಮಿಲಿಯನ್‌ಗಿಂತ ಸ್ವಲ್ಪ ಕಡಿಮೆ ಹಣದ-ರೂಪದ ಮರಣ ಲಾಭ, ಬಾಧಿತ ಜನಸಂಖ್ಯೆಯ ಬಹುತೇಕರು ವೈಯಕ್ತಿಕವಾಗಿ ಎಂದಿಗೂ ಗಮನಿಸದ ಅಪಾಯ ಕಡಿತದಿಂದ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಸುರಕ್ಷತೆ-ನಿರ್ಣಾಯಕ ಸಾಫ್ಟ್‌ವೇರ್ ತಂಡಗಳು — ವೈದ್ಯಕೀಯ ಸಾಧನ ಫರ್ಮ್‌ವೇರ್, ಸ್ವಾಯತ್ತ ವಾಹನ ಸಾಫ್ಟ್‌ವೇರ್, ಕೈಗಾರಿಕಾ ನಿಯಂತ್ರಣ ವ್ಯವಸ್ಥೆಗಳು — ಸುರಕ್ಷತಾ ಹೂಡಿಕೆಗೆ ವೆಚ್ಚ-ಲಾಭ ಪ್ರಕರಣ ನಿರ್ಮಿಸುವಾಗ ನಿಖರವಾಗಿ ಈ ಬೆಲೆ ನಿಗದಿ ಸಮಸ್ಯೆಯನ್ನು ಎದುರಿಸುತ್ತವೆ: ವೈಫಲ್ಯ ಅಪರೂಪ, ತೀವ್ರ ಮತ್ತು ಬಳಕೆದಾರರ ದೊಡ್ಡ ಜನಸಂಖ್ಯೆಯಾದ್ಯಂತ ಹರಡಿರುವಾಗ "ಒಂದು ದುರಂತ ವೈಫಲ್ಯವನ್ನು ತಡೆಯುವುದಕ್ಕೆ" ಹೇಗೆ ಬೆಲೆ ಕಟ್ಟುತ್ತೀರಿ? ಅಪರೂಪದ, ತೀವ್ರ, ಜನಸಂಖ್ಯಾ-ಮಟ್ಟದ ಅಪಾಯ ಕಡಿತಕ್ಕೆ ಸಂಖ್ಯೆ ಹಾಕುವ ದಶಕಗಳ ಹಳೆಯ, ಸಾರ್ವಜನಿಕವಾಗಿ ದಾಖಲಿತ ನೈಜ-ಜಗತ್ತಿನ ಪೂರ್ವನಿದರ್ಶನ VSL/VPF — ಅಪರೂಪದ ದುರಂತ ಸ್ಥಗಿತದ ವಿರುದ್ಧ SRE ಹೂಡಿಕೆಗೆ ಬೆಲೆ ಕಟ್ಟುವುದರ ಅದೇ ಆಕಾರದ ವಾದ, ಕೇವಲ ಡೌನ್‌ಟೈಮ್ ಫಲಿತಾಂಶದ ಬದಲು ಮರಣ ಫಲಿತಾಂಶದೊಂದಿಗೆ.

## ಎಡವಟ್ಟುಗಳು

- **VSL ಅನ್ನು "ಗುರುತಿಸಲಾದ ಜೀವದ ಬೆಲೆ" ಎಂದು ಪರಿಗಣಿಸುವುದು**: ಅದು ಅಲ್ಲ. VSL/VPF ಅನೇಕ ಜನರಾದ್ಯಂತ ಅಪಾಯ-ಕಡಿತ ವಿನಿಮಯಗಳಿಂದ ಪಡೆದ ಜನಸಂಖ್ಯಾ ಸಾಂಖ್ಯಿಕ ರಚನೆ, ಯಾವುದೇ ನಿರ್ದಿಷ್ಟ ವ್ಯಕ್ತಿಯ ಜೀವ ಅಥವಾ ಸಾವಿನ ಮೌಲ್ಯಮಾಪನವಲ್ಲ.
- **QALY-ಆಧಾರಿತ ನಿವ್ವಳ ಹಣಕಾಸು ಲಾಭ ಲೆಕ್ಕಾಚಾರದ ವಿರುದ್ಧ ದ್ವಿ-ಎಣಿಕೆ**: ಒಂದೇ ಪ್ರಕರಣದಲ್ಲಿ VSL/VPF ಅಂಕಿ ಮತ್ತು ಪ್ರತ್ಯೇಕ QALY × ಮಿತಿ ಲೆಕ್ಕಾಚಾರವನ್ನು ಸಮನ್ವಯಗೊಳಿಸದೆ ಬಳಸುವುದು ಅದೇ ತಪ್ಪಿಸಿದ ಸಾವುಗಳ ಮೌಲ್ಯವನ್ನು ಮೌನವಾಗಿ ಎರಡು ಬಾರಿ ಎಣಿಸುತ್ತದೆ. ನಿರ್ದಿಷ್ಟ ಪ್ರಕರಣಕ್ಕೆ ಒಂದು ಚೌಕಟ್ಟನ್ನು ಆರಿಸಿ.
- **ಹೊಂದಾಣಿಕೆ ಇಲ್ಲದೆ VSL ಅಂದಾಜನ್ನು ಸಂದರ್ಭಗಳಾದ್ಯಂತ ವರ್ಗಾಯಿಸುವುದು**: ಒಂದು ದೇಶದ ಕಾರ್ಮಿಕ ಮಾರುಕಟ್ಟೆಯಿಂದ ಅಥವಾ ಕೆಲಸದ-ವಯಸ್ಸಿನ ವೇತನ-ಅಪಾಯ ದತ್ತಾಂಶದಿಂದ ಪಡೆದ VSL ಅನ್ನು ಬೇರೆ ಆದಾಯ ಸಂದರ್ಭಕ್ಕೆ ಅಥವಾ ಬೇರೆ ಜನಸಂಖ್ಯೆಗೆ (ಮಕ್ಕಳು, ನಿವೃತ್ತರು) ಹೊಂದಾಣಿಕೆ ಇಲ್ಲದೆ ಅನ್ವಯಿಸುವುದು ದೀರ್ಘಕಾಲದ, ನಿಜವಾಗಿ ವಿವಾದಾಸ್ಪದ ವಿಧಾನಶಾಸ್ತ್ರೀಯ ಸಮಸ್ಯೆ — ಬಗೆಹರಿದ ಸಮಸ್ಯೆಯಲ್ಲ.
