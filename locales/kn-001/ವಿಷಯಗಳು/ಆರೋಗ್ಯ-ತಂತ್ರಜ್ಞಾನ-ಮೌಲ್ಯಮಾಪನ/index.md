# ಆರೋಗ್ಯ ತಂತ್ರಜ್ಞಾನ ಮೌಲ್ಯಮಾಪನ (HTA)

HTA ಎಂದರೆ ಒಂದು ತಂತ್ರಜ್ಞಾನ — ಔಷಧ, ಸಾಧನ ಅಥವಾ ಸಾಫ್ಟ್‌ವೇರ್ — ಪಾವತಿಸಲು ಯೋಗ್ಯವೇ ಎಂದು ಆರೋಗ್ಯ ವ್ಯವಸ್ಥೆಗಳು ನಿರ್ಧರಿಸುವ ಔಪಚಾರಿಕ, ಸಂಸ್ಥೀಕೃತ ಪ್ರಕ್ರಿಯೆ. ಇದು ಪ್ರಕಟಿತ, ಕಡ್ಡಾಯ ವಿಧಾನದ ಅಡಿಯಲ್ಲಿ ಕ್ಲಿನಿಕಲ್-ಪರಿಣಾಮಕಾರಿತ್ವ ಸಾಕ್ಷ್ಯವನ್ನು ಆರ್ಥಿಕ ಮೌಲ್ಯಮಾಪನದೊಂದಿಗೆ ಸಂಯೋಜಿಸುತ್ತದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ನೀವು ರಾಷ್ಟ್ರೀಯ ಆರೋಗ್ಯ ಸೇವೆಗೆ ಮಾರಾಟ ಮಾಡಿದರೆ, HTA ಸಂಸ್ಥೆ ಅಕ್ಷರಶಃ ನಿಮ್ಮ ಮಾರುಕಟ್ಟೆ ಪ್ರವೇಶವನ್ನು ನಿರ್ಧರಿಸಬಹುದು. ಸ್ಥಳೀಯ ಪ್ರಕ್ರಿಯೆ ತಿಳಿದಿರುವುದು ನಿಮ್ಮ ನಿಜವಾದ ಮೌಲ್ಯ-ನಿಯಂತ್ರಕನನ್ನು ತಿಳಿದಿರುವುದು:

- **NICE (ಇಂಗ್ಲೆಂಡ್)**: ನಿರ್ದಿಷ್ಟ *ಉಲ್ಲೇಖ ಪ್ರಕರಣ*ದ ಅಡಿಯಲ್ಲಿ ಶಾಸನಬದ್ಧ ಮೌಲ್ಯಮಾಪನಗಳು — [EQ-5D](../eq-5d/)ಯಿಂದ QALYಗಳು, NHS+PSS [ದೃಷ್ಟಿಕೋನ](../ವಿಶ್ಲೇಷಣಾ-ದೃಷ್ಟಿಕೋನ/), 3.5% [ರಿಯಾಯಿತಿ](../ರಿಯಾಯಿತಿ-ಮತ್ತು-ಕಾಲ-ಆದ್ಯತೆ/), [PSA](../ಸಂಭಾವ್ಯತಾ-ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/) ಅಗತ್ಯ — [ತೀವ್ರತೆ ಮಾರ್ಪಡಿಸುವವುಗಳೊಂದಿಗೆ](../qaly-ಕೊರತೆ-ಮತ್ತು-ತೀವ್ರತಾ-ಮಾರ್ಪಾಡುಗಳು/) £20k–£30k/QALY ವಿರುದ್ಧ ನಿರ್ಣಯ; ಹೆಚ್ಚು ವಿಶೇಷ ತಂತ್ರಜ್ಞಾನಗಳಿಗೆ ತೂಕದೊಂದಿಗೆ £100k+ ವರೆಗೆ.
- **ICER (ಅಮೆರಿಕ, ಸರ್ಕಾರೇತರ)**: *ಆರೋಗ್ಯ-ಲಾಭ ಬೆಲೆ ಮಾನದಂಡ*ದೊಂದಿಗೆ ಸಾಕ್ಷ್ಯ ವರದಿಗಳು — ಉತ್ಪನ್ನ ಪ್ರತಿ QALY/evLYGಗೆ $100k–$150k ನಲ್ಲಿ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿಯಾಗುವ ಬೆಲೆ — ಮಾತುಕತೆ ಲಾಭವಾಗಿ ಬಳಕೆ; ಜೊತೆಗೆ ಬಜೆಟ್-ಪ್ರಭಾವ "ಕೈಗೆಟುಕುವಿಕೆ ಎಚ್ಚರಿಕೆಗಳು."
- **ಕೆನಡಾ (CADTH → CDA-AMC)**: ≈CAD$50k/QALYಯಲ್ಲಿ ಮರುಪಾವತಿ ವಿಮರ್ಶೆಗಳು; ಐತಿಹಾಸಿಕವಾಗಿ ~95% ಸಲ್ಲಿಕೆಗಳಲ್ಲಿ ಬೆಲೆ ಕಡಿತ ಕೋರಿದೆ.

## ಗಣಿತ

HTAಯ ಶಕ್ತಿ ಸೂತ್ರವಲ್ಲ, **ಕಡ್ಡಾಯ ವಿಧಾನ**: ಪ್ರತಿ ಸಲ್ಲಿಕೆ ಅದೇ ಉಲ್ಲೇಖ-ಪ್ರಕರಣ ನಿಯಮಗಳ ಅಡಿಯಲ್ಲಿ ಅದೇ [ICER](../ಹೆಚ್ಚುವರಿ-ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ಅನುಪಾತ/) ಅನ್ನು ಲೆಕ್ಕ ಹಾಕುತ್ತದೆ, ಆದ್ದರಿಂದ ಫಲಿತಾಂಶಗಳು ಉತ್ಪನ್ನಗಳು ಮತ್ತು ವರ್ಷಗಳಾದ್ಯಂತ ಹೋಲಿಸಬಹುದು. ಉಲ್ಲೇಖ ಪ್ರಕರಣ ಫಲಿತಾಂಶ ಮಾಪನ, ಉಪಯುಕ್ತತೆ ಸಾಧನ, ದೃಷ್ಟಿಕೋನ, ಹೋಲಿಕೆದಾರ ಆಯ್ಕೆ, ರಿಯಾಯಿತಿ ದರ, ಕಾಲದ ಗಡಿ ಮತ್ತು ಅನಿಶ್ಚಿತತೆ ವಿಶ್ಲೇಷಣೆಯನ್ನು ನಿರ್ದಿಷ್ಟಪಡಿಸುತ್ತದೆ — ಪ್ರಾಯೋಜಕ ತಿರುಚಬಹುದಾದ ಪ್ರತಿ ಸ್ವಾತಂತ್ರ್ಯ ಮಟ್ಟವನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಡಿಜಿಟಲ್ ಚಿಕಿತ್ಸೆ NICE-ಶೈಲಿಯ ಮೌಲ್ಯಮಾಪನಕ್ಕೆ ಸಲ್ಲಿಸುತ್ತದೆ:

```
Model: ΔC = +£450/patient, ΔE = +0.03 QALYs → ICER = £15,000/QALY ✓ under £20k
Reference-case checks:
  utilities from EQ-5D-5L with UK value set              ✓
  comparator = current care pathway (not "no treatment") ✓
  PSA: 71% probability cost-effective at £20k            ✓ (reported)
  severity modifier: shortfall below ×1.2 bounds         — none claimed
Recommendation: routine commissioning, with real-world data collection.
```

ಪ್ರಾಯೋಜಕನ ಸ್ವಂತ ಆದ್ಯತೆಯ ವಿಶ್ಲೇಷಣೆ £9,000/QALY ತೋರಿಸಿತ್ತು; ಉಲ್ಲೇಖ ಪ್ರಕರಣ ಪ್ರಾಮಾಣಿಕ ಹೋಲಿಕೆದಾರನನ್ನು ಒತ್ತಾಯಿಸುವ ಮೂಲಕ ಅದನ್ನು £15,000ಕ್ಕೆ ತಳ್ಳಿತು. ಆ ಅಂತರವೇ ಉಲ್ಲೇಖ ಪ್ರಕರಣಗಳು ಅಸ್ತಿತ್ವದಲ್ಲಿರುವ *ಕಾರಣ*.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ವರ್ಗಾಯಿಸಬಹುದಾದ ಕಲಾಕೃತಿ **ಆಂತರಿಕ ಉಲ್ಲೇಖ ಪ್ರಕರಣ**: ಎಲ್ಲಾ ಸಾಧನ/ವೇದಿಕೆ ವ್ಯಾಪಾರ ಸಮರ್ಥನೆಗಳಿಗೆ ಒಂದು ಕಡ್ಡಾಯ ವಿಧಾನ — ಘೋಷಿತ ಹೋಲಿಕೆದಾರ, ಪ್ರಮಾಣಿತ ಘಟಕ ವೆಚ್ಚಗಳು (ಮಾದರಿಗೆ [ರಾಷ್ಟ್ರೀಯ ದರಪಟ್ಟಿ ಮತ್ತು ಘಟಕ ವೆಚ್ಚಗಳು](../ರಾಷ್ಟ್ರೀಯ-ಸುಂಕ-ಮತ್ತು-ಘಟಕ-ವೆಚ್ಚಗಳು/) ನೋಡಿ), ನಿಗದಿತ ರಿಯಾಯಿತಿ ದರ, ಅಗತ್ಯ ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ, ಪ್ರಮಾಣಿತ ಟೆಂಪ್ಲೇಟ್. ವೇದಿಕೆ ಮಂಡಳಿಗೆ ಸಲ್ಲಿಸುವ "ಸಾಧನಗಳಿಗೆ AMCP-ದಾಖಲೆ" ಪ್ರಸ್ತಾವನೆಗಳನ್ನು ಹೋಲಿಸಬಹುದಾದವನ್ನಾಗಿ ಮತ್ತು ತಿರುಚುವಿಕೆಯನ್ನು ಗೋಚರವಾಗಿಸುತ್ತದೆ, HTA ಔಷಧಕ್ಕೆ ಮಾಡುವಂತೆ. NICE ಆರಂಭಿಸಿದ್ದಕ್ಕಿಂತ ಚಿಕ್ಕದಾಗಿ ಆರಂಭಿಸಿ: ಎರಡು-ಪುಟದ ಟೆಂಪ್ಲೇಟ್ ಜೊತೆಗೆ ಪ್ರಕಟಿತ ಬೆಲೆ ಪುಸ್ತಕ ಯಾವುದೇ ಮಾನದಂಡ ಇಲ್ಲದ್ದಕ್ಕಿಂತ ಉತ್ತಮ.

ಬಹು-ಚಕ್ರ HTA ಮಾದರಿಯನ್ನು ವಾಸ್ತವದಲ್ಲಿ ಸಮೂಹ-ಚಕ್ರದ ಮೂಲಕ ಹೇಗೆ ಅನುಕರಿಸಲಾಗುತ್ತದೆ ಎಂಬುದಕ್ಕೆ [ಮಾರ್ಕೊವ್ ಸಮೂಹ ಅನುಕರಣೆ](../ಮಾರ್ಕೊವ್-ಸಮೂಹ-ಅನುಕರಣೆ/) ನೋಡಿ.

## ಎಡವಟ್ಟುಗಳು

- **ನಿಯಂತ್ರಕ ಅನುಮತಿಯ ನಂತರ HTAಯನ್ನು ಔಪಚಾರಿಕತೆ ಎಂದು ಪರಿಗಣಿಸುವುದು** — CE/UKCA/FDA ಅನುಮತಿ ಉತ್ಪನ್ನ ಸುರಕ್ಷಿತ ಎನ್ನುತ್ತದೆ; HTA ಅದು *ಖರೀದಿಸಲು ಯೋಗ್ಯವೇ* ಎಂದು ನಿರ್ಧರಿಸುತ್ತದೆ. ಬೇರೆ ಅಡಚಣೆ, ಬೇರೆ ಸಾಕ್ಷ್ಯ.
- **ಪ್ರಯೋಗದ ನಂತರ ಆರ್ಥಿಕ ಮಾದರಿ ನಿರ್ಮಿಸುವುದು** — ಸಾಕ್ಷ್ಯ ಉತ್ಪಾದನೆಯನ್ನು ಉಲ್ಲೇಖ ಪ್ರಕರಣದ ಅವಶ್ಯಕತೆಗಳಿಂದ ಹಿಂದಕ್ಕೆ ವಿನ್ಯಾಸಗೊಳಿಸಬೇಕು.
- **ನ್ಯಾಯವ್ಯಾಪ್ತಿ ವ್ಯತ್ಯಾಸಗಳ ನಿರ್ಲಕ್ಷ್ಯ**: ಅಮೆರಿಕದಲ್ಲಿ $120k/QALYಗೆ ಹಣ ನೀಡಬಹುದಾದ ICER NICE £30kಯಲ್ಲಿ ವಿಫಲ; ಪ್ರತಿ ಮಾರುಕಟ್ಟೆಗೆ ಸಾಕ್ಷ್ಯ ಮತ್ತು ಬೆಲೆಯನ್ನು ಯೋಜಿಸಿ.
