# Gweythresans ha Degemeryans

Ratyo gweythresans yw an radh a'n re a wra skrifa aga hanow neb a dheu bys y'n kensa talvos poesek (an gwrians "aha" — an kensa musur skrifys, an kensa dyskans gwrys). Degemeryans yw an versyon a'n pobel: an radh a'n pobel *ankwithys* a wra degemeres an gwrians hag oll. Warbarth, yth yns an yetow a-dheves a'n kanel talvos: kevrenn → degemeryans → gweythresans → [synsyans](../synsyans-ha-kellys-devnydhyoryon/) → sewyans.

## Perag yth yw posek

Devnydhyoryon na vo gweythresys yw kost pur: spena kevrenn, provysyon ha skoodhyans — talvos klinikel vyth. Skoodhyow gwerthjy a dhiskwedh bos gweythresans medhelweyth yeghes *ysella* ages an keworrans a-dro dhe'n bys (≈24% erbynn ≈37% rag gweythresans devnydhyoryon nowydh y'n unn set SaaS; kowlwrians rol-wolok ≈20%), drefen bos an dallethva moy poesek (hanow, kensentyans, sawder klinikel). Degemeryans a dhegh an gwodhow a'n pobel: y'n [framya RE-AIM](../hedhes-hag-ekwita/), efekt yeghes poblek ≈ pewas × effeythusnans — app splann degemerys gans 3% a'n pobel ankwithys a gews an pobel 3% yn unnik. Rag terapiow nombrek erviresys, an yet degemeryans yw gwelys yn data kenedhlek: **~81% a erviryow DiGA yw gweythresys** — unn a bymp tretyans erviresys ha paydhys na dhallath bythkweth (gwelewgh [fast-track DiGA](../fast-track-diga-almayn/)).

## An Matematik

```
Reyt gweythresans = devnydhyoryon a gowlwrug an gwrians bownder y'n termyn / kevrennow × 100
Reyt degemeryans  = degemerysi / pobel ankwithys × 100
Reyt lenwi DTx    = kodhow ervir gweythresys / erviryow res-ys × 100

Patrom talvos an kanel:
  ankwithys × degemeryans × gweythresans × prow poesys-synsyans = talvos an pobel
  — peswar multiplikans; gwellhe an faktour byghanna
  yw an moyha nebes (teori an strishyansow rag kanelyow)
```

## Ensampel gwrys

Kommyssyoner a re app lettya diabetes dhe 80,000 trigys ankwithys:

```
Gelwys → kovskrifys:  80,000 → 12,000  (degemeryans 15%)
Kovskrifys → gweythresys (kensa session + gol settys, 7 dydh): 12,000 → 5,400 (45%)
Gweythresys → kowlwrys an kerdh 6-mis: 5,400 → 1,600 (30%)

Efekt an kerdh (previans, an re a gowlwrug): 0.03 QALY + £180 kostow evitys
Talvos an pobel = 1,600 × (0.03 × £20,000 + £180) ≈ £1.25M
Talvos rag pubonan ankwithys = £15.6 — erbynn £780 mar kowlwrav kenyver unn.

Ple investya? Dewblya degemeryans (15→30%) a dhewblas an talvos; derevel
gweythresans 45→65% a gressa ~44%; an dew a dhefsa orth gwellhe pella
an dalgh kerdh a'n 1,600 re gowlwrug seulabrys.
```

## Kolm gans ynjynnyans medhelweyth

Gweythresans yw an gradh an moyha hweth rag ynjynnoryon: fros bostyans hanow, fluryow kensentyans, dyssynyans an stat gwag ha termyn-bys-an-kensa-talvos yw kod, na ny yw polici (an kesrenans a dermyn-dhe-dalvos yeghes yw ≈ 1 dydh 7 eur — pub eur anodho yw danjer a lesta). Degemeryans yw kudyn a sistemow dasparth: kesstrivyans y'n fordhow kuntelles (prys an erviras), galwansow skoodhys gans medhygyon teylu (fydhyans a dremena) ha kavadowder (tavas, skians nombrek — gwelewgh [hedhyans ha kehaval](../hedhes-hag-ekwita/)). An patrom talvos kanel a-ugh yw jenerator an kas besneth rag an dew: multiplya an faktours, kavos an strishyans, ha pris an gwellhe erbynn an talvos a'n pobel a dhelivrer.

## Fowtys Kemmyn

- **Gweythresans diskwedhys avel es** (post-el gwrys fydh) lemmyn ages styr klinikel (an kensa gwrians terapek) — hy a bompya an musur ha dorr an chayn talvos.
- **Gamys a dhelergh degemeryans**: "a'n re a wylas an gwiasva" erbynn an pobel ankwithys yn gwir — kommyssyoners a bryder a'n diwettha.
- **Efektys dewisyans**: devnydhyoryon es dhe weythresa yw an re lyha klav ha lyha diwesek; gwellhesow an kanel a yll ledha an bylyow kehaval hag y wellhe an kesre.
