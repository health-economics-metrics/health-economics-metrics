# WSJF και CD3

Τα CD3 (Cost of Delay Divided by Duration — Κόστος καθυστέρησης διαιρεμένο με τη διάρκεια) και WSJF (Weighted Shortest Job First) είναι κανόνες ιεράρχησης που προγραμματίζουν την εργασία βάσει **πυκνότητας αξίας**: πόσο κόστος καθυστέρησης αφαιρείται ανά μονάδα σπάνιας δυναμικότητας που καταναλώνεται. Υπό κοινή, σταθερή δυναμικότητα, η σειρά «πρώτα το υψηλότερο CD3» είναι η μαθηματικά βέλτιστη ακολουθία για την ελαχιστοποίηση του συνολικού κόστους καθυστέρησης.

## Γιατί έχει σημασία

Κάθε backlog είναι πρόβλημα δελτίου: πολλά άξια αντικείμενα, ένας αγωγός. Η οικονομική της υγείας έλυσε το ίδιο πρόβλημα για τους προϋπολογισμούς υγείας με πίνακες κατάταξης κόστους-αποτελεσματικότητας — κατατάξτε τις παρεμβάσεις βάσει υγείας που κερδίζεται ανά λίρα, χρηματοδοτήστε προς τα κάτω στη λίστα έως ότου εξαντληθεί ο προϋπολογισμός. Το CD3 είναι η ίδια λογική για τη δυναμικότητα παράδοσης: όφελος ανά μονάδα του *περιορισμένου πόρου*, χρηματοδοτούμενο κατά σειρά κατάταξης. Η σωστή ακολουθία είναι δωρεάν χρήμα — ίδια εργασία, ίδια δυναμικότητα, λιγότερο συνολικό κόστος καθυστέρησης.

## Τα μαθηματικά

```
CD3  = Cost of Delay (£/week) / Duration (weeks)      — real units (Black Swan Farming)

WSJF = (user-business value + time criticality + risk reduction/opportunity
        enablement) / job size                         — SAFe's relative-scale proxy,
                                                        modified-Fibonacci scores
```

Το CD3 με γνήσιο νόμισμα ([κόστος καθυστέρησης](../κόστος-καθυστέρησης/)) είναι αυστηρά ισχυρότερο από τους άνευ μονάδων πόντους του WSJF — το WSJF είναι για το CD3 ό,τι η βαθμολόγηση πολλαπλών κριτηρίων για την πλήρη [ανάλυση κόστους-χρησιμότητας](../ανάλυση-κόστους-χρησιμότητας/): χρησιμοποιήσιμο όταν η νομισματοποίηση είναι ανέφικτη, παραποιήσιμο όταν οι βαθμολογίες δεν έχουν άγκυρα.

## Αναλυτικό παράδειγμα

Τρεις λειτουργίες, μία ομάδα:

```
Feature   CoD (£/wk)   Duration   CD3
A         30,000       10 wks     3,000
B         12,000       2 wks      6,000
C         5,000        1 wk       5,000
```

Σειρά CD3: B, C, A. Συγκρίνετε το συνολικό κόστος καθυστέρησης με το «πρώτα το μεγαλύτερο CoD» (A, B, C):

```
CD3 order  (B,C,A): A waits 3 wks, C waits 2 → 30k×3 + 5k×2  = £100k delay cost
CoD order  (A,B,C): B waits 10, C waits 12   → 12k×10 + 5k×12 = £180k
```

Ίδιες λειτουργίες, ίδια ομάδα — η ακολουθία από μόνη της εξοικονομεί £80.000. Η διαίσθηση: τα μικρά, επείγοντα αντικείμενα πάνε πρώτα επειδή απελευθερώνουν φθηνά το κόστος καθυστέρησής τους· το μεγάλο αντικείμενο χάνει λίγα περιμένοντας για λίγο.

## Σύνδεση με τη μηχανική λογισμικού

Για χαρτοφυλάκια λογισμικού υγείας, εκφράστε το CoD στις μονάδες που διδάσκει αυτό το αποθετήριο: QALY/εβδομάδα × κατώφλι + λειτουργικά £/εβδομάδα, και το backlog γίνεται άμεσα σύμμετρο με τον τρόπο που το σύστημα υγείας κατατάσσει όλα τα άλλα που αγοράζει. Δύο πρακτικές σημειώσεις: (1) η διάρκεια σημαίνει *ημερολογιακός χρόνος που καταλαμβάνει τον περιορισμό*, όχι προσπάθεια — ένα αντικείμενο 2 εβδομάδων που χρειάζεται 2 ημέρες της ομάδας-σημείου συμφόρησης είναι φθηνότερο απ' ό,τι φαίνεται (βλ. [βελτιστοποίηση κατάντη πόρων](../βελτιστοποίηση-πόρων-κατάντη/))· (2) τα νοσοκομεία τρέχουν σιωπηρά τον ίδιο κανόνα όταν ταξινομούν τις λίστες χειρουργείου κατά διακίνηση σταθμισμένη με επείγον — οι κατηγορίες κλινικής ιεράρχησης είναι CD3 σταθμισμένο κατά σοβαρότητα (βλ. [έλλειμμα QALY και τροποποιητές σοβαρότητας](../έλλειμμα-qaly-και-τροποποιητές-σοβαρότητας/)).

## Παγίδες

- **Θέατρο βαθμολογιών WSJF**: οι άνευ μονάδων συζητήσεις Fibonacci συγκλίνουν σε όποιον φωνάζει δυνατότερα· αγκυρώστε τουλάχιστον τα αντικείμενα κορυφής του backlog σε πραγματικό CoD.
- **Παραπλάνηση διάρκειας**: διάσπαση αντικειμένων για να φουσκώσει η κατάταξη CD3 — εντάξει όταν οι διασπάσεις παραδίδουν αξία ανεξάρτητα, απάτη όταν όχι.
- **Αγνόηση προφίλ επείγοντος**: το CoD σχήματος προθεσμίας (ρυθμιστικές ημερομηνίες) σπάει την παραδοχή σταθερού ρυθμού· προγραμματίστε αυτά βάσει εφικτότητας ημερομηνίας, και μετά CD3 τα υπόλοιπα.
- **Αναταραχή επανακατάταξης**: το CD3 είναι για αποφάσεις ακολουθίας κατά τη δέσμευση, όχι για καθημερινή αναδιάταξη εργασίας σε εξέλιξη (βλ. [δείκτες ροής](../μετρικές-ροής/) για το WIP).
