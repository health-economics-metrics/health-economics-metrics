# Αξία μιας στατιστικής ζωής (VSL)

Η αξία μιας στατιστικής ζωής (VSL) — που στη βρετανική χρήση ονομάζεται «αξία αποτραπέντος θανάτου» (VPF) — είναι το ποσό που ένας *πληθυσμός* είναι συλλογικά διατεθειμένος να πληρώσει για να μειώσει τον κίνδυνο ενός στατιστικού θανάτου, και προκύπτει από μελέτες ανταλλαγής μισθού-κινδύνου (πόση επιπλέον αμοιβή απαιτούν οι εργαζόμενοι για πιο επικίνδυνες δουλειές) και από έρευνες δηλωμένων προτιμήσεων. Δεν είναι η τιμή της ζωής κάποιου προσδιορισμένου ατόμου· είναι κατασκεύασμα πληθυσμιακού κινδύνου, και ένας μηχανικός λογισμικού που χτίζει συστήματα μείωσης κινδύνου — αλγορίθμους διαλογής, κατανομή ασθενοφόρων, παρακολούθηση ασφάλειας — πρέπει να ξέρει ότι προέρχεται από διαφορετική θεωρητική παράδοση από τα [κατώφλια προθυμίας πληρωμής](../κατώφλια-προθυμίας-πληρωμής/).

## Γιατί έχει σημασία

Η VSL/VPF είναι το τυπικό εργαλείο για τη νομισματοποίηση μειώσεων του κινδύνου θνησιμότητας στην ρυθμιστική ανάλυση κόστους-οφέλους: η ασφάλεια των μεταφορών, η περιβαλλοντική ρύθμιση και ορισμένες παρεμβάσεις δημόσιας υγείας περνούν όλες τις επιχειρηματικές τους περιπτώσεις μέσα από αυτήν. Το Green Book του HM Treasury δημοσιεύει ένα μέγεθος VPF που προκύπτει από στοιχεία της βρετανικής αγοράς εργασίας και ερευνών, και το Υπουργείο Μεταφορών το χρησιμοποιεί απευθείας στην αξιολόγηση οδικής ασφάλειας. Πρόκειται για πραγματικά διαφορετική παράδοση αποτίμησης από τη μεθοδολογία QALY × κατώφλι προθυμίας πληρωμής: η προσέγγιση του κατωφλίου αποτιμά τα οφέλη υγείας έναντι αυτού που παράγει σήμερα στο περιθώριο ένας *προϋπολογισμός* υγείας, ενώ η VSL/VPF αποτιμά τη μείωση κινδύνου έναντι αυτού που αποκαλύπτουν ότι θα πλήρωναν οι άνθρωποι σε μια αγορά εργασίας ή έρευνα. Τα δύο πλαίσια δεν συμβιβάζονται πάντα, και η χρήση και των δύο στην ίδια περίπτωση χωρίς αναγνώριση αυτού είναι συνηθισμένο αναλυτικό σφάλμα.

## Τα μαθηματικά

```
Deaths averted = population × risk_reduction_per_person
  (risk_reduction_per_person is a probability, e.g. 0.000001 = 1-in-a-million
   reduction in annual mortality risk)

Monetized mortality benefit = deaths_averted × value_of_prevented_fatality
```

## Αναλυτικό παράδειγμα

Μια περιοχή 800.000 ατόμων ωφελείται από μια ψηφιακή παρέμβαση κατανομής/διαλογής οδικής ασφάλειας που μειώνει τον ετήσιο κίνδυνο θνησιμότητας κάθε ατόμου κατά 1 στο εκατομμύριο (0,000001):

```
Deaths averted = 800,000 × 0.000001 = 0.8
```

Με χρήση της Value of a Prevented Fatality του ΗΒ, £2.180.000 (μέγεθος HM Treasury/DfT, τιμές 2023/24 — το Green Book το ενημερώνει ετησίως, επαληθεύστε ξανά πριν από παραπομπή σε ζωντανή ανάλυση):

```
Monetized mortality benefit = 0.8 × £2,180,000 = £1,744,000/year
```

Λίγο κάτω από £1,75 εκατ. ετησίως νομισματοποιημένου οφέλους θνησιμότητας, από μια μείωση κινδύνου που οι περισσότεροι του επηρεαζόμενου πληθυσμού δεν θα πρόσεχαν ατομικά.

## Σύνδεση με τη μηχανική λογισμικού

Οι ομάδες λογισμικού κρίσιμης ασφάλειας — υλικολογισμικό ιατροτεχνολογικών προϊόντων, λογισμικό αυτόνομων οχημάτων, βιομηχανικά συστήματα ελέγχου — αντιμετωπίζουν ακριβώς αυτό το πρόβλημα τιμολόγησης όταν χτίζουν την περίπτωση κόστους-οφέλους για μια επένδυση ασφάλειας: πώς τιμολογείτε το «αποτρέψτε μία καταστροφική αστοχία» όταν η αστοχία είναι σπάνια, σοβαρή και διασπαρμένη σε μεγάλο πληθυσμό χρηστών; Η VSL/VPF είναι ένα δεκαετιών, δημόσια τεκμηριωμένο προηγούμενο πραγματικού κόσμου για να δοθεί αριθμός σε μια σπάνια, σοβαρή, πληθυσμιακού επιπέδου μείωση κινδύνου — το ίδιο σχήμα επιχειρήματος με την τιμολόγηση μιας επένδυσης SRE έναντι μιας σπάνιας καταστροφικής διακοπής, απλώς με έκβαση θνησιμότητας αντί για έκβαση διακοπής λειτουργίας.

## Παγίδες

- **Αντιμετώπιση της VSL ως «τιμής μιας προσδιορισμένης ζωής»**: δεν είναι. Η VSL/VPF είναι στατιστικό κατασκεύασμα πληθυσμού που προκύπτει από ανταλλαγές μείωσης κινδύνου σε πολλούς ανθρώπους, όχι αποτίμηση της ζωής ή του θανάτου κάποιου συγκεκριμένου ατόμου.
- **Διπλή καταμέτρηση έναντι υπολογισμού καθαρού νομισματικού οφέλους βάσει QALY**: η χρήση ενός μεγέθους VSL/VPF και ενός χωριστού υπολογισμού QALY × κατώφλι στην ίδια περίπτωση, χωρίς συμβιβασμό, διπλομετρά σιωπηλά την αξία των ίδιων αποτραπέντων θανάτων. Επιλέξτε ένα πλαίσιο για μια δεδομένη περίπτωση.
- **Μεταφύτευση εκτίμησης VSL μεταξύ πλαισίων χωρίς προσαρμογή**: μια VSL που προκύπτει από την αγορά εργασίας μιας χώρας, ή από δεδομένα μισθού-κινδύνου εργάσιμης ηλικίας, εφαρμοσμένη χωρίς προσαρμογή σε διαφορετικό εισοδηματικό πλαίσιο ή διαφορετικό πληθυσμό (παιδιά, συνταξιούχοι) είναι διαχρονικό, πραγματικά αμφισβητούμενο μεθοδολογικό ζήτημα — όχι λυμένο.
