# Πολυκριτηριακή Ανάλυση Αποφάσεων (MCDA)

Η πολυκριτηριακή ανάλυση αποφάσεων (MCDA) είναι ένα μοντέλο βαθμολόγησης σταθμισμένου αθροίσματος που χρησιμοποιείται στην αξιολόγηση τεχνολογιών υγείας όταν ένα μεμονωμένο ICER/όριο προθυμίας πληρωμής δεν αποτυπώνει όλα όσα ενδιαφέρουν τον φορέα απόφασης: ισότητα, ανεκπλήρωτη ανάγκη, καινοτομία, επίπτωση στον προϋπολογισμό, σοβαρότητα νόσου. Κάθε κριτήριο παίρνει ένα βάρος που αντανακλά τη σημασία του (εξαγόμενο από ενδιαφερόμενους, με βάρη που αθροίζουν στο 1), κάθε επιλογή παίρνει κανονικοποιημένη βαθμολογία ανά κριτήριο (συνήθως 0–1), και η συνολική βαθμολογία είναι το σταθμισμένο άθροισμα — το ίδιο μαθηματικό σχήμα με μια κάρτα βαθμολόγησης επιλογής προμηθευτή λογισμικού.

## Γιατί έχει σημασία

Η MCDA χρησιμοποιείται σε πλαίσια όπως το EVIDEM, και από ορισμένους φορείς HTA για αξιολογήσεις ορφανών/σπάνιων νόσων όπου μια αυστηρή προσέγγιση ορίου κόστους-ανά-QALY θεωρείται πολύ στενή για να αποτυπώσει όλα όσα μετράνε σε μια απόφαση. Η ομάδα εργασίας ISPOR MCDA Emerging Good Practices Task Force τυποποίησε καθοδήγηση καλών πρακτικών για την υπερασπίσιμη εξαγωγή βαρών και βαθμολογιών, ακριβώς επειδή μια ανεπίσημα σταθμισμένη απόφαση είναι εύκολο να κατασκευαστεί και εύκολο να χειραγωγηθεί. Όταν μια τεχνολογία υγείας έχει πράγματι διαστάσεις αξίας που ένα μεμονωμένο [όριο προθυμίας πληρωμής](../κατώφλια-προθυμίας-πληρωμής/) δεν μπορεί να αναπαραστήσει — σοβαρότητα, καινοτομία, ισότητα — η MCDA δίνει στους φορείς απόφασης μια ρητή, ελέγξιμη δομή για να τα συνδυάσουν, αντί για άρρητη κρίση.

## Τα μαθηματικά

```
Βαθμολογία MCDA = Σ_i (weight_i × score_i)

τα βάρη πρέπει να αθροίζουν στο 1 (εξαγόμενα με μεθόδους ενδιαφερομένων όπως
swing weighting ή Analytic Hierarchy Process)
```

## Αναλυτικό παράδειγμα

Μια επιτροπή HTA βαθμολογεί ένα ψηφιακό θεραπευτικό με τέσσερα κριτήρια:

```
Κριτήριο                           Βάρος    Βαθμός  Βάρος × Βαθμός
Κλινικό όφελος                     0.4      0.8     0.32
Επίπτωση κόστους                   0.3      0.5     0.15
Σοβαρότητα νόσου / ανεκπλήρωτη ανάγκη 0.2   0.9     0.18
Καινοτομία                         0.1      0.6     0.06
                                    ─────                ─────
                                    1.0                  0.71
```

Τα βάρη αθροίζουν στο 1.0 (0.4 + 0.3 + 0.2 + 0.1), και η βαθμολογία MCDA είναι 0.71 (0.32 + 0.15 + 0.18 + 0.06). Η επιτροπή συγκρίνει το 0.71 με ένα προσυμφωνημένο όριο, ή το κατατάσσει έναντι ανταγωνιστικών τεχνολογιών που βαθμολογήθηκαν με τον ίδιο τρόπο.

## Σύνδεση με τη μηχανική λογισμικού

Αυτά είναι ακριβώς τα ίδια μαθηματικά με μια σταθμισμένη κάρτα επιλογής προμηθευτή, ένα μητρώο αξιολόγησης RFP ή ένα μοντέλο βαθμολόγησης προτεραιοποίησης χαρακτηριστικών — βλ. [κατασκευή έναντι αγοράς](../κατασκευή-ή-αγορά/), κλασική περίπτωση χρήσης σταθμισμένης κάρτας στις προμήθειες λογισμικού. Αξίζει επίσης αντιπαραβολή με το [WSJF και CD3](../wsjf-και-cd3/): το WSJF/CD3 είναι μέθοδος ιεράρχησης βασισμένη σε *λόγο* (κόστος καθυστέρησης διά μέγεθος εργασίας ή διάρκεια), ενώ η MCDA είναι σταθμισμένο *άθροισμα*. Η MCDA και το WSJF/CD3 είναι δύο δομικά διαφορετικές απαντήσεις στο «πώς κατατάσσουμε ανταγωνιστικές επιλογές», και το να ξέρετε ποια χρειάζεται πράγματι μια απόφαση — προσθετική αξία σε ανεξάρτητα κριτήρια, έναντι πυκνότητας αξίας ανά μονάδα σπάνιας χωρητικότητας — μετράει περισσότερο από το ποιος τύπος μοιάζει πιο αυστηρός.

## Παγίδες

- **Μεροληψία εξαγωγής βαρών**: όποιος ορίζει τα βάρη προκαθορίζει ουσιαστικά την κατάταξη, οπότε ένας «τύπος» μπορεί να νομιμοποιήσει μια πολιτική ή εμπορική απόφαση ως αντικειμενικό υπολογισμό. Τεκμηριώστε ποιος όρισε τα βάρη και πώς.
- **Διπλή καταμέτρηση κριτηρίου που ήδη αποτυπώνεται αλλού**: η βαθμολόγηση της «οικονομικής αποδοτικότητας» ως ενός κριτηρίου *και* χωριστά της «επίπτωσης κόστους» υπερσταθμίζει το χρήμα σε σχέση με τα άλλα κριτήρια χωρίς να το σκοπεύει κανείς.
- **Ψευδής ακρίβεια**: μια σταθμισμένη βαθμολογία δύο δεκαδικών (0.71) υπονοεί περισσότερη αυστηρότητα από όση στηρίζουν οι υποκείμενες αξιολογήσεις 0–10 των ενδιαφερομένων, και η μεταβλητότητα μεταξύ αξιολογητών σε αυτές συχνά δεν αναφέρεται καθόλου.
