# Κυριαρχία και Μέτωπο Αποδοτικότητας

Μια επιλογή **κυριαρχείται** αν μια άλλη επιλογή κοστίζει λιγότερο *και* αποδίδει περισσότερο. Το **μέτωπο αποδοτικότητας** είναι ό,τι απομένει μετά την εξάλειψη των κυριαρχούμενων επιλογών: το σύνολο των επιλογών όπου για να πάρετε περισσότερα πρέπει να πληρώσετε περισσότερα.

## Γιατί έχει σημασία

Πριν από οποιαδήποτε συζήτηση για όρια ή προϋπολογισμούς, η αξιολόγηση τεχνολογιών υγείας εξαλείφει πρώτα επιλογές που κανείς δεν πρέπει να επιλέξει ποτέ. Η απεικόνιση κάθε επιλογής σε επίπεδο κόστους-αποτελέσματος και η χάραξη του μετώπου είναι άσκηση πέντε λεπτών που συστηματικά σκοτώνει τη μισή βραχεία λίστα. Οι αυξητικές συγκρίσεις ([ICER](../αυξητικός-λόγος-κόστους-αποτελεσματικότητας/)) υπολογίζονται έπειτα μόνο *κατά μήκος του μετώπου*, κάθε επιλογή έναντι της επόμενης φθηνότερης μη κυριαρχούμενης — ποτέ έναντι του «μην κάνουμε τίποτα» όταν υπάρχουν καλύτερες ενδιάμεσες επιλογές.

## Τα μαθηματικά

```
Αυστηρή κυριαρχία:   το A κυριαρχεί του B αν Cost_A ≤ Cost_B και Effect_A ≥ Effect_B
                     (με τουλάχιστον μία αυστηρή ανισότητα)

Εκτεταμένη κυριαρχία: το B αποκλείεται αν ένα μείγμα των A και C επιτυγχάνει περισσότερο
                      αποτέλεσμα ανά λίρα — ανιχνεύεται όταν τα ICER μειώνονται καθώς
                      ανεβαίνετε στο μέτωπο. Τα έγκυρα ICER του μετώπου πρέπει να αυξάνονται.
```

Διαδικασία: ταξινομήστε τις επιλογές κατά αποτέλεσμα· αφαιρέστε τις αυστηρά κυριαρχούμενες· υπολογίστε ζευγαρωτά ICER μεταξύ γειτόνων· αφαιρέστε κάθε επιλογή της οποίας το ICER υπερβαίνει αυτό της επόμενης πιο αποτελεσματικής (εκτεταμένη κυριαρχία)· επαναλάβετε μέχρι τα ICER να αυξάνονται μονότονα.

## Αναλυτικό παράδειγμα

Τέσσερις επιλογές για τη μείωση των χαμένων ραντεβού (αποτέλεσμα = ραντεβού που ανακτώνται/έτος):

```
Επιλογή            Κόστος/έτος  Ανακτημένα
Καμία ενέργεια     £0           0
Υπενθυμίσεις SMS   £20,000      2,000
Τηλεφωνήματα       £120,000     2,200
SMS + AI triage    £90,000      3,500
```

Τα τηλεφωνήματα **κυριαρχούνται αυστηρά** από το SMS + AI triage (κοστίζουν περισσότερο, ανακτούν λιγότερα). Μέτωπο: τίποτα → SMS → SMS + AI.

```
ICER(SMS έναντι τίποτα)  = 20,000 / 2,000  = £10 ανά ανακτημένο ραντεβού
ICER(SMS+AI έναντι SMS)  = (90,000 − 20,000) / (3,500 − 2,000) = £46.67 ανά ραντεβού
```

Αυξανόμενα ICER → έγκυρο μέτωπο. Με ~£160 εξοικονόμηση ανά ανακτημένο ραντεβού νοσοκομείου (βλ. [ποσοστό μη προσέλευσης](../ποσοστό-μη-προσέλευσης/)), και τα δύο βήματα του μετώπου αξίζουν· η πρόταση τηλεφωνικού κέντρου δεν θα έπρεπε ποτέ να φτάσει στην επιτροπή.

## Σύνδεση με τη μηχανική λογισμικού

Φτιάξτε το ίδιο διάγραμμα για κάθε απόφαση εργαλείων: κόστος ανά έτος στον έναν άξονα, μετρούμενο αποτέλεσμα (ώρες που εξοικονομήθηκαν, περιστατικά που αποφεύχθηκαν, διαθέσεις που κατέστησε δυνατές) στον άλλο. Τα σημεία πάνω-αριστερά από το μέτωπο εξαλείφονται πριν κανείς διαφωνήσει για τον προϋπολογισμό. Αυτό αναδιατυπώνει την επιλογή προμηθευτή από συζητήσεις λίστας χαρακτηριστικών σε «κυριαρχείστε· η σύσκεψη τελείωσε.» Αποκαλύπτει επίσης το συνηθισμένο εταιρικό μοτίβο αγοράς της ακριβότερης επιλογής για οριακό κέρδος — θεμιτό μόνο αν η αυξητική τιμή ανά αυξητική μονάδα είναι αυτή που ο οργανισμός θα πλήρωνε εν γνώσει του.

## Παγίδες

- **Σύγκριση όλων με τη βάση** αντί με την επόμενη επιλογή στο μέτωπο — κολακεύει τις ακριβές επιλογές κρύβοντας φθηνότερα σχεδόν ισοδύναμα.
- **Βαθμολογίες αποτελέσματος μίας διάστασης** που κρύβουν ό,τι μετράει· αν μετρούν δύο αποτελέσματα, είτε συνδυάστε τα υπερασπίσιμα (βλ. [ανάλυση κόστους-χρησιμότητας](../ανάλυση-κόστους-χρησιμότητας/)) είτε δείξτε δύο μέτωπα.
- **Λησμονιά της αβεβαιότητας**: οι επιλογές κοντά στο μέτωπο μπορεί να ανταλλάξουν θέσεις υπό [ανάλυση ευαισθησίας](../ανάλυση-ευαισθησίας/).
