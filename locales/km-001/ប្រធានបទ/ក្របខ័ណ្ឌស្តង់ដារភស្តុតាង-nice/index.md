# ក្របខ័ណ្ឌស្តង់ដារភស្តុតាង NICE (ESF)

ESF គឺជាក្របខ័ណ្ឌរបស់ NICE ដែលបញ្ជាក់ថា **បច្ចេកវិទ្យាសុខភាពឌីជីថលត្រូវការភស្តុតាងប៉ុន្មាន សមាមាត្រនឹងហានិភ័យរបស់វា**។ វាជាអ្វីដែលជិតបំផុតនឹងចម្លើយផ្លូវការចំពោះ "តើយើងត្រូវបង្ហាញអ្វីមុន NHS ទិញកម្មវិធីរបស់យើង?"

## ហេតុអ្វីបានជាសំខាន់

ESF (ចេញលើកដំបូងឆ្នាំ 2019 ធ្វើបច្ចុប្បន្នភាពឆ្នាំ 2022 ដើម្បីគ្របដណ្តប់ AI និងក្បួនដោះស្រាយបត់បែន) ចាត់ថ្នាក់បច្ចេកវិទ្យាសុខភាពឌីជីថលជាថ្នាក់តាមមុខងារគ្លីនិក ជាមួយស្តង់ដារភស្តុតាង **បន្ថែមគ្នា** — 21 ស្តង់ដារ ក្នុង 5 ក្រុម (កត្តារចនា តម្លៃ ប្រតិបត្តិការ/ប្រសិទ្ធភាព ផលប៉ះពាល់សេដ្ឋកិច្ច ការដាក់ពង្រាយ)៖

```
Tier A — system services, no direct patient outcome (e.g., e-rostering)
         → basic standards: credibility, data protection, technical assurance
Tier B — inform, simple monitoring, communication (e.g., symptom diary)
         → + evidence of user benefit, appropriate reliability
Tier C — treat, diagnose, or actively guide clinical management
         → + high-quality comparative effectiveness evidence (ideally RCT)
           and economic analysis
```

សម្រាប់ភស្តុតាងសេដ្ឋកិច្ច [ការវិភាគថ្លៃដើម-ផលវិបាក](../ការវិភាគថ្លៃដើម-លទ្ធផល/) អាចទទួលយកបានសម្រាប់ថ្នាក់ភាគច្រើន; [ការវិភាគថ្លៃដើម-ឧបយោគ](../ការវិភាគថ្លៃដើម-ឧបយោគ/) ត្រូវបានរំពឹងនៅហានិភ័យខ្ពស់បំផុត។ ESF កំណត់ **ថ្លៃដើមភស្តុតាងនៃការចូលទីផ្សារ** របស់អ្នក — ធ្វើថវិកាសម្រាប់វាដូចថ្លៃដើមសាងសង់ផ្សេងទៀត។

## គណិតវិទ្យា

គ្មានរូបមន្តទេ — តារាងការសម្រេចចិត្ត។ ការគណនាប្រតិបត្តិគឺពាណិជ្ជកម្ម៖

```
Evidence investment required = f(tier)
  Tier A: documentation + assurance ≈ £10k–50k
  Tier B: observational/comparative user-benefit study ≈ £50k–250k
  Tier C: RCT-grade comparative study + economic model ≈ £250k–£2M+

Position your product's claims deliberately: claiming "supports clinical
decisions" instead of "informs patients" moves you a tier and can 10× the bill.
```

## ឧទាហរណ៍ដែលបានគណនា

អ្នកផលិតកម្មវិធីរំលឹកថ្នាំពិចារណាបន្ថែមមុខងារណែនាំកែតម្រូវកម្រិតថ្នាំ។

- ជាកម្មវិធីរំលឹក៖ **ថ្នាក់ B** — ការសិក្សាក្រុមដែលបង្ហាញការកែលម្អការប្រកាន់ខ្ជាប់គ្រប់គ្រាន់។
- ជាមួយការណែនាំកម្រិតថ្នាំ៖ **ថ្នាក់ C** — ភស្តុតាងប្រសិទ្ធភាពប្រៀបធៀប (ទំនងជា RCT ធៀបនឹងការថែទាំធម្មតា) បូកការវិភាគសេដ្ឋកិច្ច។

ប្រសិនបើ RCT ថ្លៃ £600k ហើយចំណូលបន្ថែមរបស់មុខងារកម្រិតថ្នាំគឺ £200k/ឆ្នាំ មុខងារត្រូវរក្សាតម្លៃ 3+ ឆ្នាំមុនថ្លៃដើមភស្តុតាងស្មើនឹងចំណូល — ការសម្រេចចិត្តផលិតផលដែលមើលទៅខុសគ្នាទាំងស្រុងនៅពេលថ្នាក់ ESF ត្រូវបានគិតថ្លៃ។ ក្រុមជាច្រើនបញ្ចេញផលិតផលថ្នាក់ B ហើយដាក់ការអះអាងថ្នាក់ C នៅពីក្រោយការផ្តល់មូលនិធិ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ESF គឺជាលំនាំអភិបាលកិច្ចដែលអាចផ្ទេរបានបំផុតតែមួយក្នុងឃ្លាំងនេះ៖ **តម្រូវការភស្តុតាងតាមថ្នាក់ហានិភ័យសម្រាប់ការទទួលយកឧបករណ៍**។ កំណែផ្ទៃក្នុង៖ ឧបករណ៍ធ្វើទ្រង់ទ្រាយកូដត្រូវការ demo (ថ្នាក់ A); ឧបករណ៍ផលិតភាពដែលអះអាងម៉ោងសន្សំត្រូវការគម្រោងសាកល្បងដែលបានវាស់ (ថ្នាក់ B); AI gate ដែលទប់ស្កាត់ការដាក់ឱ្យប្រើដោយស្វ័យប្រវត្តិ ឬសរសេរកូដគ្លីនិកដោយស្វ័យប្រវត្តិ ត្រូវការភស្តុតាងកម្រិតការសាកល្បងមានការគ្រប់គ្រងមុនដាក់ពង្រាយទូទាំងអង្គការ (ថ្នាក់ C)។ ភស្តុតាងសមាមាត្រទប់ស្កាត់របៀបបរាជ័យទាំងពីរ — អាជ្ញាធរការិយាធិបតេយ្យច្របាច់ឧបករណ៍តូចតាច និងអារម្មណ៍បញ្ចេញរឿងសំខាន់។ សូមមើលផងដែរ [DiGA ផ្លូវរហ័ស](../ផ្លូវរហ័ស-diga-របស់អាល្លឺម៉ង់/) សម្រាប់ការបំពេញបន្ថែម "ការទទួលយកបណ្តោះអាសន្នជាមួយកាលកំណត់ភស្តុតាង"។

## កំហុសដែលត្រូវជៀសវាង

- **ការចាត់ថ្នាក់ខុសដោយបំណងប្រាថ្នា** — និយតករ និងអ្នកទិញចាត់ថ្នាក់តាមអ្វីដែលផលិតផល *ធ្វើ* មិនមែនអ្វីដែលទីផ្សារនិយាយទេ។
- **ភស្តុតាងសាងសង់បន្ទាប់ពីផលិតផល**: ការដាក់ RCT ឡើងវិញលើផលិតផលដែលបានបញ្ចេញដោយគ្មានឧបករណ៍វាស់ ឬ equipoise យឺត ហើយជារឿយៗមិនអាចធ្វើបាន។
- **បំពេញ ESF ហើយភ្លេចអ្វីផ្សេងទៀត**: ESF ស្ថិតនៅជាមួយ DTAC (សុវត្ថិភាពគ្លីនិក ការការពារទិន្នន័យ អន្តរប្រតិបត្តិការ) ហើយសម្រាប់ AI ការអនុម័តបទប្បញ្ញត្តិ — សូមមើល [ការវាយតម្លៃបទប្បញ្ញត្តិ AI](../ការវាយតម្លៃបទប្បញ្ញត្តិ-ai/)។
