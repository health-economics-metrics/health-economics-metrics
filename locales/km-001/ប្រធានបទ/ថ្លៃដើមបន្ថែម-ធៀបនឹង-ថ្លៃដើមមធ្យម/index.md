# ថ្លៃដើមបន្ថែម ធៀបនឹង ថ្លៃដើមមធ្យម

ថ្លៃដើមមធ្យម (average cost) គឺជាថ្លៃដើមសរុបចែកនឹងចំនួនឯកតាដែលផលិត។ ថ្លៃដើមបន្ថែម (marginal cost) គឺជាថ្លៃដើមនៃការផលិតឯកតា *មួយបន្ថែម*។ ការសម្រេចចិត្តគួរធ្វើលើថ្លៃដើមបន្ថែម — ប៉ុន្តែថ្លៃឯកតាដែលបានបោះពុម្ពស្ទើរតែជានិច្ចជាមធ្យមភាគ។

## ហេតុអ្វីបានជាសំខាន់

កំហុសទូទៅបំផុតតែមួយក្នុងករណីអាជីវកម្មសុខភាពឌីជីថល គឺការវាយតម្លៃធនធានដែលបានសន្សំនៅថ្លៃដើម **មធ្យម** របស់វា ខណៈដែលការសន្សំពិតគឺថ្លៃដើម **បន្ថែម**។ ថ្ងៃគ្រែមន្ទីរពេទ្យមួយមានថ្លៃដើមមធ្យម (ស្រូបពេញលេញ) £400+ ប៉ុន្តែការដោះលែងថ្ងៃគ្រែមួយមិនសន្សំ £400 ទេ — អគារ ការកំដៅ និងថ្លៃបុគ្គលិកភាគច្រើនបន្តកើតមាន។ សាច់ប្រាក់ដែលដោះលែងពិតប្រាកដអាចជា £50–£150 លើកលែងតែគ្រែគ្រប់គ្រាន់ត្រូវបានដោះលែងដើម្បីបិទបន្ទប់ពេទ្យមួយ។

## គណិតវិទ្យា

```
Average cost:  AC = TC / Q
Marginal cost: MC = dTC/dQ   (cost of one more/one fewer unit)

TC = total cost, Q = quantity
```

ថ្លៃដើមថេរធ្វើឱ្យ MC < AC សម្រាប់ការកាត់បន្ថយសមត្ថភាព ហើយ MC អាចខិតជិតសូន្យនៅពេលមានសមត្ថភាពបម្រុង។ ការអះអាងសន្សំគួរប្រើ៖

```
True saving = ΔQ × MC          (small changes)
True saving = step change in TC (large changes that cross a capacity threshold, e.g. closing a ward)
```

## ឧទាហរណ៍ដែលបានគណនា

កម្មវិធីរបស់អ្នកកាត់បន្ថយរយៈពេលស្នាក់នៅមធ្យម ដោះលែង 1,000 ថ្ងៃគ្រែ/ឆ្នាំនៅត្រឹស្តីមួយ។

- **ការអះអាងឆោតល្ងង់**: 1,000 × £400 ថ្លៃដើមមធ្យម = **£400,000 សន្សំ**។ ខុស។
- **ការអះអាងបន្ថែម**: ថ្លៃដើមអថេរក្នុងមួយថ្ងៃគ្រែ (អាហារ បោកគក់ សម្ភារៈប្រើប្រាស់ ភាពបត់បែនគិលានុបដ្ឋាយិកាខ្លះ) ≈ £120។ ការសន្សំ = 1,000 × £120 = **£120,000** *បូក* តម្លៃនៃសមត្ថភាពដែលដោះលែង ប្រសិនបើគ្រែត្រូវបានបំពេញឡើងវិញដោយអ្នកជំងឺវះកាត់តាមកាលវិភាគដែលកំពុងរង់ចាំ (ចំណូលក្រោមការទូទាត់ផ្អែកលើសកម្មភាព ឬការកាត់បន្ថយបញ្ជីរង់ចាំ)។
- **ការអះអាងការផ្លាស់ប្តូរជំហាន**: ប្រសិនបើត្រឹស្តីដោះលែង 7,300 ថ្ងៃគ្រែ/ឆ្នាំ (បន្ទប់ 20 គ្រែ) វាអាចបិទបន្ទប់ពិតប្រាកដ៖ បុគ្គលិក + ថ្លៃដំណើរការ ≈ £1.5 លាន/ឆ្នាំនៃសាច់ប្រាក់ពិត។ ឥឡូវនេះគណិតវិទ្យាថ្លៃដើមមធ្យមកាន់តែជិតការពិត។

អន្តរាគមន៍ដូចគ្នា លេខការពារបានបីផ្សេងគ្នា អាស្រ័យលើថាតើការផ្លាស់ប្តូរឆ្លងជំហានសមត្ថភាពឬអត់។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

សេដ្ឋកិច្ចពពកជាទឹកដីថ្លៃដើមបន្ថែមដោយធម្មជាតិ៖

- ថ្លៃដើមបន្ថែមនៃការរត់ CI មួយបន្ថែមលើសមត្ថភាពដែលបានកក់រួច ≈ £0 ខណៈថ្លៃដើមមធ្យមក្នុងមួយការរត់ (ការចំណាយវេទិកាសរុប ÷ ការរត់) អាចជាប៉ុន្មានផោន។ ប្រព័ន្ធ chargeback ដែលគិតថ្លៃដើមមធ្យមជំរុញក្រុមឱ្យប្រើសមត្ថភាពរួមតិចពេក ដែលពិតជាឥតគិតថ្លៃនៅរឹម។
- ផ្ទុយទៅវិញ "យើងបានសន្សំ 30% នៃការគណនា" ដោះលែងសាច់ប្រាក់តែនៅពេលឧទាហរណ៍ត្រូវបានបិទពិតប្រាកដ ឬការកក់ត្រូវបានកាត់បន្ថយ — កំណែកម្មវិធីនៃអន្ទាក់ថ្ងៃគ្រែ។ សូមមើល [ការសន្សំដោះលែងសាច់ប្រាក់ ធៀបនឹង មិនដោះលែងសាច់ប្រាក់](../ការសន្សំដែលបញ្ចេញសាច់ប្រាក់-ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់/)។

## កំហុសដែលត្រូវជៀសវាង

- **ការវាយតម្លៃសមត្ថភាពនៅថ្លៃដើមមធ្យម** ហើយបង្ហាញជាសាច់ប្រាក់ (បុរាណ)។
- **ការសន្មតថាថ្លៃដើមបន្ថែមថេរ**។ វាឡើងជំហាននៅព្រំដែនសមត្ថភាព (ការបិទបន្ទប់ពេទ្យ កម្រិតអាជ្ញាប័ណ្ណ ការប្តេជ្ញាឧទាហរណ៍កក់ទុក)។
- **ការប្រើថ្លៃដើមបន្ថែមសម្រាប់ការសម្រេចចិត្តពង្រីក ប៉ុន្តែមធ្យមសម្រាប់ការរួញ** ក្នុងករណីតែមួយ — ជ្រើសរើសតាមការសម្រេចចិត្តពិតប្រាកដ។
