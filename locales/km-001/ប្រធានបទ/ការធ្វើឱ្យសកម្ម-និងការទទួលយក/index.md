# ការធ្វើឱ្យសកម្ម និងការទទួលយក

អត្រាធ្វើឱ្យសកម្ម (activation rate) គឺជាចំណែកនៃអ្នកចុះឈ្មោះដែលឈានដល់តម្លៃដ៏មានន័យដំបូង (សកម្មភាព "aha" — ការកត់ត្រាតម្លៃវាស់ដំបូង ឬមេរៀនដំបូងដែលបានបញ្ចប់)។ ការទទួលយក (uptake) គឺជាកំណែនៅកម្រិតប្រជាជន៖ ចំណែកនៃប្រជាជន *ដែលមានសិទ្ធិ* ដែលទទួលយកសោះ។ ទាំងពីរជាមួយគ្នាជាច្រកខាងមុខនៃចីវលោតម្លៃ (value funnel)៖ ការទាញយកអ្នកប្រើ → ការទទួលយក → ការធ្វើឱ្យសកម្ម → [ការរក្សា](../ការរក្សា-និងការបោះបង់/) → លទ្ធផល។

## ហេតុអ្វីបានជាសំខាន់

អ្នកប្រើដែលមិនទាន់សកម្មគឺជាថ្លៃដើមសុទ្ធ៖ ការចំណាយលើការទាញយក ការរៀបចំប្រព័ន្ធ និងផ្ទៃគាំទ្រ — ដោយគ្មានតម្លៃគ្លីនិកសោះ។ ស្តង់ដារប្រៀបធៀបបង្ហាញថា ការធ្វើឱ្យសកម្មរបស់កម្មវិធីសុខាភិបាល *ទាបជាង* មធ្យមភាគនៃឧស្សាហកម្មផ្សេងៗ (≈24% ធៀបនឹង ≈37% សម្រាប់ការធ្វើឱ្យអ្នកប្រើថ្មីសកម្មក្នុងសំណុំស្តង់ដារ SaaS មួយ; ការបំពេញបញ្ជីត្រួតពិនិត្យការចូលប្រើ ~20%) ដែលឆ្លុះបញ្ចាំងពីដំណើរការចូលប្រើដែលធ្ងន់ជាង (អត្តសញ្ញាណ ការយល់ព្រម សុវត្ថិភាពគ្លីនិក)។ ការទទួលយកផ្ទុកភាគហ៊ុនកម្រិតប្រជាជន៖ ក្នុង[ក្របខ័ណ្ឌ RE-AIM](../ការឈានដល់-និងសមធម៌/) ផលប៉ះពាល់សុខភាពសាធារណៈ ≈ ការឈានដល់ × ប្រសិទ្ធភាព — កម្មវិធីដ៏ល្អឥតខ្ចោះដែលប្រជាជនមានសិទ្ធិត្រឹម 3% ទទួលយក ផ្លាស់ប្តូរសូចនាករប្រជាជនបានត្រឹម 3%។ សម្រាប់ការព្យាបាលឌីជីថលដែលមានវេជ្ជបញ្ជា ច្រកទទួលយកអាចមើលឃើញក្នុងទិន្នន័យថ្នាក់ជាតិ៖ **~81% នៃវេជ្ជបញ្ជា DiGA របស់អាល្លឺម៉ង់ត្រូវបានធ្វើឱ្យសកម្ម** — ការព្យាបាលមួយក្នុងប្រាំដែលបានចេញវេជ្ជបញ្ជា និងបានបង់ប្រាក់ មិនដែលចាប់ផ្តើមឡើយ (សូមមើល[ផ្លូវរហ័ស DiGA](../ផ្លូវរហ័ស-diga-របស់អាល្លឺម៉ង់/))។

## គណិតវិទ្យា

```
Activation rate = users completing key action within window / sign-ups × 100
Uptake rate     = adopters / eligible population × 100
DTx fill rate   = activated prescription codes / issued prescriptions × 100

Funnel value model:
  eligible × uptake × activation × retention-weighted benefit = population value
  — four multiplications; improving the smallest factor usually
  dominates (theory-of-constraints for funnels)
```

## ឧទាហរណ៍ដែលបានគណនា

អ្នកកម្មវិធីសុខាភិបាល (commissioner) ផ្តល់កម្មវិធីបង្ការជំងឺទឹកនោមផ្អែមដល់អ្នករស់នៅដែលមានសិទ្ធិ 80,000 នាក់៖

```
Invited → registered:  80,000 → 12,000  (uptake 15%)
Registered → activated (first session + goal set, 7 days): 12,000 → 5,400 (45%)
Activated → completed 6-month programme: 5,400 → 1,600 (30%)

Programme effect (trial, completers): 0.03 QALYs + £180 avoided costs
Population value = 1,600 × (0.03 × £20,000 + £180) ≈ £1.25M
Per-eligible-person value = £15.6 — versus £780 if every eligible person completed.

Where to invest? Doubling uptake (15→30%) doubles value; raising
activation 45→65% adds ~44%; both beat further polishing the programme
content the 1,600 already complete.
```

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ការធ្វើឱ្យសកម្មគឺជាដំណាក់កាលនៃចីវលោដែលវិស្វកម្មអាចដោះស្រាយបានងាយបំផុត៖ ការកកស្ទះនៃការផ្ទៀងផ្ទាត់អត្តសញ្ញាណ លំហូរនៃការយល់ព្រម ការរចនាស្ថានភាពទទេ និងពេលវេលាទៅកាន់តម្លៃដំបូង គឺជាកូដ មិនមែននយោបាយទេ (មធ្យមភាគពេលវេលាទៅកាន់តម្លៃរបស់វិស័យសុខាភិបាល ≈ 1 ថ្ងៃ 7 ម៉ោងក្នុងទិន្នន័យស្តង់ដារ — រាល់ម៉ោងនីមួយៗគឺជាហានិភ័យនៃការបោះបង់)។ ការទទួលយកគឺជាបញ្ហាប្រព័ន្ធចែកចាយ៖ ការរួមបញ្ចូលក្នុងផ្លូវបញ្ជូនអ្នកជំងឺ (ពេលចេញវេជ្ជបញ្ជា) ការអញ្ជើញដែលវេជ្ជបណ្ឌិតទូទៅគាំទ្រ (ការផ្ទេរទំនុកចិត្ត) និងភាពងាយស្រួលប្រើ (ភាសា ជំនាញឌីជីថល — សូមមើល[ការឈានដល់ និងសមធម៌](../ការឈានដល់-និងសមធម៌/))។ គំរូតម្លៃនៃចីវលោខាងលើគឺជាម៉ាស៊ីនបង្កើតករណីអាជីវកម្មសម្រាប់ទាំងពីរ៖ គុណកត្តាទាំងនោះ រកឧបសគ្គ ហើយកំណត់តម្លៃនៃការជួសជុលធៀបនឹងតម្លៃប្រជាជនដែលវាបញ្ចេញ។

## កំហុសដែលត្រូវជៀសវាង

- **និយមន័យការធ្វើឱ្យសកម្មតាមភាពងាយស្រួល** (អ៊ីមែលបានផ្ទៀងផ្ទាត់) ជំនួសឱ្យអត្ថន័យគ្លីនិក (សកម្មភាពព្យាបាលដំបូង) — ធ្វើឱ្យសូចនាករប៉ោង ហើយបំបែកខ្សែច្រវាក់តម្លៃ។
- **ល្បិចភាគបែងនៃការទទួលយក**៖ "ក្នុងចំណោមអ្នកដែលបានចូលមើលគេហទំព័រ" ធៀបនឹងប្រជាជនដែលមានសិទ្ធិពិតប្រាកដ — អ្នកកម្មវិធីសុខាភិបាលយកចិត្តទុកដាក់ចំពោះក្រោយ។
- **ឥទ្ធិពលនៃការជ្រើសរើស**៖ អ្នកដែលងាយធ្វើឱ្យសកម្មគឺជាអ្នកឈឺតិចបំផុត និងខ្វះខាតតិចបំផុត; ការកែលម្អចីវលោអាចពង្រីកគម្លាតសមធម៌ ខណៈពេលដែលកែលម្អមធ្យមភាគ។
