# ការប្រៀបធៀប ICER ឆ្លងរូបិយប័ណ្ណ

ការប្រៀបធៀប [ICER](../សមាមាត្រប្រសិទ្ធភាពថ្លៃដើមបន្ថែម/) ដែលគណនាក្នុងរូបិយប័ណ្ណរបស់ប្រទេសមួយ ទល់នឹង[កម្រិតឆន្ទៈបង់ប្រាក់](../កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់/)របស់ប្រទេសមួយទៀត — ឬការបូកទិន្នន័យថ្លៃដើមដែលប្រមូលក្នុងការសាកល្បងពហុជាតិ — តម្រូវឱ្យមានជំហានបម្លែងរូបិយប័ណ្ណដែលច្បាស់លាស់ និងអាចធ្វើសវនកម្មបាន។ ប្រសិនបើវិធីសាស្ត្របម្លែងខុស ភស្តុតាងមូលដ្ឋានដូចគ្នាអាចបង្វិលការសម្រេចចិត្តទទួលយក ទោះបីគ្មានអ្វីអំពីទិន្នន័យគ្លីនិក ឬថ្លៃដើមផ្លាស់ប្តូរក៏ដោយ។

## ហេតុអ្វីបានជាសំខាន់

ការណែនាំវិធីសាស្ត្ររបស់ ISPOR សម្រាប់ការសាកល្បងគ្លីនិកពហុជាតិ (Willke et al., *Health Economics*, 1998) ណែនាំឱ្យបម្លែងថ្លៃធនធានដោយប្រើ **សមភាពអំណាចទិញ (PPP)** — មិនមែនអត្រាប្តូរប្រាក់ទីផ្សារទេ — នៅពេលប្រៀបធៀបតម្លៃសេដ្ឋកិច្ចពិតនៃធនធានឆ្លងប្រទេស ហើយបម្រុងអត្រាប្តូរប្រាក់ទីផ្សារសម្រាប់អ្វីដែលវាពិតជាសម្រាប់៖ ការធ្វើគំរូលំហូរការបង់សាច់ប្រាក់ឆ្លងព្រំដែនពិតប្រាកដ។ ការច្រឡំទាំងពីរគឺជាកំហុសវិធីសាស្ត្រ HTA ពហុជាតិទូទៅបំផុតមួយ ព្រោះទាំងពីរមើលទៅដូច "អត្រាប្តូរប្រាក់" ចំពោះអ្នកដែលមិនបានអានការណែនាំ ហើយស្ព្រេតសីតមិនបញ្ឈប់អ្នកពីការធ្វើខុសទេ។

## គណិតវិទ្យា

```
icer_in_local_currency = convert(icer_in_source_currency, conversion_factor)

conversion_factor should be:
  PPP conversion factor  — for comparing real economic value of resources
                            across countries (ISPOR-recommended for
                            multinational CEA)
  market FX rate         — only for actual cross-border cash payments

adopt if icer_in_local_currency < local_threshold
```

ច្បាប់ការសម្រេចចិត្តខ្លួនឯងគឺ[ច្បាប់កម្រិត ICER](../កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់/)ធម្មតា — `adopt if ICER < λ` — សំណួរវិធីសាស្ត្រដែលប្រធានបទនេះដោះស្រាយគឺទាំងស្រុងអំពី *កត្តាបម្លែងណា* ដែលបង្កើតតួលេខ `icer_in_local_currency` ដែលច្បាប់នោះត្រូវបានអនុវត្ត។

## ឧទាហរណ៍ដែលបានគណនា

ICER របស់ថ្នាំពីការសាកល្បងអាមេរិកគឺ $45,000/QALY។ ប្រទេសនាំចូលសម្មតិកម្មកំណត់កម្រិតបង្ហាញរបស់ខ្លួន £34,000/QALY (តួលេខជាក់លាក់ប្រទេសសម្មតិកម្មសម្រាប់ឧទាហរណ៍នេះតែប៉ុណ្ណោះ — កម្រិតពិតប្រែប្រួលតាមប្រទេស និងផ្លាស់ប្តូរតាមពេលវេលា ហើយត្រូវតែមានប្រភព និងកាលបរិច្ឆេទជានិច្ច)។

**ការប្រើកត្តាបម្លែង PPP 0.72** (បង្ហាញ សម្រាប់ឧទាហរណ៍នេះតែប៉ុណ្ណោះ)៖ $45,000 × 0.72 = £32,400/QALY។ £32,400 < £34,000 → **ទទួលយក**។

**ការប្រើអត្រាប្តូរប្រាក់ទីផ្សារ 0.79** ជំនួស (បង្ហាញ)៖ $45,000 × 0.79 = £35,550/QALY។ £35,550 > £34,000 → **បដិសេធ**។

ICER $45,000/QALY មូលដ្ឋានដូចគ្នាបង្កើតការសម្រេចចិត្តទទួលយកក្រោមការបម្លែង PPP និងការសម្រេចចិត្តបដិសេធក្រោមការបម្លែងអត្រាប្តូរប្រាក់ទីផ្សារ។ នេះគឺជាឧទាហរណ៍ជាក់ស្តែងអំពីមូលហេតុដែលការណែនាំ ISPOR ចាត់ទុកជម្រើសកត្តាបម្លែងថាមានផលវិបាកខាងវិធីសាស្ត្រ — មិនមែនព័ត៌មានលម្អិតនៃការបង្គត់ទេ ហើយមិនមែនអ្វីដែលត្រូវទុកដោយប្រយោលក្នុងរូបមន្តស្ព្រេតសីតដែលគ្មាននរណាពិនិត្យទ្វេដង។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

នេះគឺជាកញ្ចក់សេដ្ឋកិច្ចសុខាភិបាលនៃដែនវិស្វកម្មដែលស្គាល់ច្បាស់៖ ភាពត្រឹមត្រូវនៃការកំណត់តម្លៃច្រើនរូបិយប័ណ្ណ i18n/l10n ក្នុងកម្មវិធីពាណិជ្ជកម្ម ដែលទំព័រតម្លៃ SaaS មិនត្រូវប្រៀបធៀបចំនួន `$` ទៅនឹងតម្លៃ `£` ដោយស្ងាត់ៗទេ។ ការធានាកម្រិតប្រភេទដែលប្រភេទ `Money` ដែលបង្កើតល្អផ្តល់ — វិធីសាស្ត្រប្រៀបធៀបដែលបដិសេធប្រៀបធៀបរូបិយប័ណ្ណមិនត្រូវគ្នា បង្ខំជំហានបម្លែងច្បាស់លាស់មុន — គឺជាភាពស្រដៀងវិស្វកម្មកម្មវិធីដោយផ្ទាល់នៃចំណុចវិធីសាស្ត្រសេដ្ឋកិច្ចសុខាភិបាលនៅទីនេះ៖ កុំប្រៀបធៀបតួលេខដែលមិនទាន់បម្លែងឆ្លងរូបិយប័ណ្ណ ហើយកុំឱ្យជំហានបម្លែងប្រយោល ឬគ្មានឯកសារ។

## កំហុសដែលត្រូវជៀសវាង

- **ការប្រៀបធៀបចំនួនក្នុងរូបិយប័ណ្ណខុសគ្នាដោយស្ងាត់ៗ**៖ ការងារ HTA ស្ព្រេតសីតមិនទៀងទាត់ដែលដក ឬប្រៀបធៀបតួលេខដុល្លារ និងផោនដោយគ្មានជំហានបម្លែងមុន — ថ្នាក់កំហុសដែលប្រភេទ `Money` ដែលដឹងរូបិយប័ណ្ណពិតចាប់បានតាមរចនាសម្ព័ន្ធ ជំនួសឱ្យទុកជាកំហុសស្ងាត់។
- **ការច្រឡំអត្រាប្តូរប្រាក់ទីផ្សារជាមួយ PPP**៖ កំហុសវិធីសាស្ត្រ HTA ពហុជាតិទូទៅបំផុតតាមការណែនាំ ISPOR — លេខទាំងពីរអាចខុសគ្នាច្រើន ហើយឆ្លើយសំណួរខុសគ្នា (តម្លៃសេដ្ឋកិច្ចពិត ធៀបនឹងលំហូរសាច់ប្រាក់ពិត)។
- **មិនដាក់កាលបរិច្ឆេទអត្រាប្តូរប្រាក់ ឬសន្ទស្សន៍ PPP ដែលបានប្រើ**៖ ទាំងពីរផ្លាស់ប្តូរតាមពេលវេលា ដូច្នេះកត្តាបម្លែងដែលបានដកស្រង់ណាមួយត្រូវតែមានកាលបរិច្ឆេទតាមរបៀបដូចគ្នាដែលឃ្លាំងនេះដាក់កាលបរិច្ឆេទតួលេខស្តង់ដារផ្សេងទៀត (តម្លៃកាបូន Green Book តម្លៃនៃការស្លាប់ដែលបានបង្ការ ។ល។)។
