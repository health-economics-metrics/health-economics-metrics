# សមត្ថភាពបង្កើតតម្លៃ (ការបង្វិលប្រតិបត្តិការ)

សមត្ថភាពបង្កើតតម្លៃគឺជា "អត្ថប្រយោជន៍ឱកាស" នៃពេលវេលាដែលបានដោះលែង៖ អ្វីដែលមន្ទីរពេទ្យឥឡូវអាច *សម្រេច* ជាមួយម៉ោងដែលកម្មវិធីរបស់អ្នកបញ្ចេញ។ នេះគឺជារង្វាស់ដែលសំខាន់បំផុតចំពោះនាយកប្រតិបត្តិការ និងនាយកវេជ្ជសាស្ត្រ ពីព្រោះវានិយាយជារូបិយប័ណ្ណដែលពួកគេត្រូវបានគ្រប់គ្រងតាម — សកម្មភាព គោលដៅ និងការបង្វិល។

## ហេតុអ្វីបានជាសំខាន់

NHS ប្រឈមមុខនឹងការជាប់គាំងការបញ្ជូនទៅការព្យាបាលដ៏ធំ ហើយ trusts ដែលខកខានស្តង់ដារពេលរង់ចាំជាតិប្រឈមការត្រួតពិនិត្យនិយតកម្ម និងអន្តរាគមន៍ (សូមមើល[ការបញ្ជូនទៅការព្យាបាល](../ពីការបញ្ជូនទៅការព្យាបាល/))។ ការជួលយឺត និងមានដែនកំណត់; អចលនទ្រព្យថេរ។ ដំណោះស្រាយលឿនតែមួយគឺទទួលបានសកម្មភាពបង្កើតតម្លៃច្រើនជាងពីបុគ្គលិក និងលំហដែលមាន។ កម្មវិធីដែលទាមទារពេលវេលាអ្នកឯកទេសមកវិញ មិនត្រឹមតែ "សន្សំប្រាក់" ទេ — វា *បង្កើតសមត្ថភាព*៖ គ្លីនិកដែលមិនអាចមាន ការវាយតម្លៃដែលមិនអាចកំណត់ពេល ដោយមិនជួល ឬសាងសង់។

## គណិតវិទ្យា

```
Hidden capacity created = time released → activity units enabled × scheme value

Activity units: outpatient attendances, pre-op assessments, monitoring reviews
Scheme value:   national tariff / NHS Payment Scheme prices
                (see national-tariff-and-unit-costs.md)
```

នេះគឺជាការកំណត់តម្លៃតាមលទ្ធផលនៃ[ពេលវេលាអ្នកអនុវត្តវិជ្ជាជីវៈ](../ពេលវេលាអ្នកអនុវត្តវិជ្ជាជីវៈ/) ដែលពង្រីកទៅខ្សែសេវា និងបង្ហាញជាឯកតាសកម្មភាពដែលក្រុមប្រតិបត្តិការធ្វើផែនការរួចហើយ។

## ឧទាហរណ៍ដែលបានគណនា

គិលានុបដ្ឋាយិកាឯកទេស Band 6 ដំណើរការគ្លីនិកវាយតម្លៃមុនវះកាត់។ ស្វ័យប្រវត្តិកម្មឯកសារទាមទារ 1 ម៉ោង/ថ្ងៃមកវិញសម្រាប់គិលានុបដ្ឋាយិកា 25 នាក់; ម៉ោងនីមួយៗស្ថិតនៅក្នុងការវាយតម្លៃ 2។

```
Extra assessments = 25 nurses × 2/day × 250 days = 12,500/year
At ~£120 scheme value per pre-op assessment:
  12,500 × £120 = £1.5M/year of care capacity created
```

— ដោយមិនជួលគិលានុបដ្ឋាយិកាម្នាក់ ឬសាងសង់បន្ទប់តែមួយ។ (ម៉ូដែលដែលបានដកស្រង់ជាទូទៅដែលសេចក្តីព្រាងនេះដំបូងដកស្រង់ដាក់តួលេខ £766,920/ឆ្នាំសម្រាប់ក្រុមតូចជាង; គំរូនព្វន្ធដូចគ្នា — លេខធំឡើងតាមគិលានុបដ្ឋាយិកា × វគ្គ × តម្លៃ។) ក្របខ័ណ្ឌប្រតិបត្តិការសម្រាប់ COO៖ ការវាយតម្លៃមុនវះកាត់លែងជាឧបសគ្គលើបញ្ជីបន្ទប់វះកាត់ — ការវះកាត់ដែលលុបចោលនៅថ្ងៃដែលធ្លាក់ចុះ ហើយការប្រើបន្ទប់វះកាត់កើនឡើង ដែលជាកន្លែងដែលបន្ទាត់អត្ថប្រយោជន៍ *បន្ទាប់* ចាប់ផ្តើម (សូមមើល[ការបង្កើនប្រសិទ្ធភាពធនធានផ្នែកខាងក្រោម](../ការបង្កើនប្រសិទ្ធភាពធនធានផ្នែកខាងក្រោម/))។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ការកំណត់ក្របខ័ណ្ឌឡើងវិញដដែលជួយសង្គ្រោះការអះអាងផលិតភាពអ្នកអភិវឌ្ឍន៍ពីគណិតវិទ្យាប្រាក់ឈ្នួល៖ ពេលវេលាវិស្វកម្មដែលបានដោះលែង បង្ហាញជា *សមត្ថភាពដែលបានបញ្ជូនដែលអង្គការមិនអាចបង់បានបើមិនដូច្នោះ* — លក្ខណៈពិសេស ការផ្លាស់ប្តូរ ការងារភាពជឿជាក់ — កំណត់តម្លៃតាមអ្វីដែលអង្គការបង់សម្រាប់សមត្ថភាពបែបនោះនៅគែម (អត្រាអ្នកម៉ៅការ ឬសមមូលការជួលពន្យារ)។ ក្របខ័ណ្ឌ COO ក៏បង្រៀនអ្វីមួយអំពីការស្នើការងារវេទិកា៖ បង្ហាញអត្ថប្រយោជន៍ក្នុងឯកតាដែលទស្សនិកជនត្រូវបានគ្រប់គ្រង។ មេដឹកនាំប្រតិបត្តិការគិតជាសកម្មភាព និងគោលដៅ មិនមែនម៉ោងអរូបីទេ; មេដឹកនាំវិស្វកម្មគិតជាធាតុផែនទីបង្ហាញផ្លូវ និងចំនួនបុគ្គលិក មិនមែននាទីដែលបានសន្សំទេ។

## ចំណុចងាយធ្លាក់

- **ការអះអាងសមត្ថភាពដោយគ្មានតម្រូវការ**៖ ចន្លោះវាយតម្លៃបន្ថែម 12,500 សំខាន់តែនៅពេលបំពង់វះកាត់បំពេញវា — ពិនិត្យឧបសគ្គផ្នែកខាងក្រោម។
- **តម្លៃតារាងតម្លៃដោយគ្មានយន្តការទូទាត់**៖ ក្រោមការទូទាត់លាយ សកម្មភាពបន្ថែមប្រហែលមិននាំចំណូលបន្ថែមទេ; តម្លៃអាចជាការកាត់បន្ថយបញ្ជីរង់ចាំជំនួស (សូមមើល[ផលប៉ះពាល់បញ្ជីរង់ចាំ](../ផលប៉ះពាល់បញ្ជីរង់ចាំ/))។
- **ការបង្ហាញសមត្ថភាពជាសាច់ប្រាក់** — នេះគឺជាអត្ថប្រយោជន៍មិនបញ្ចេញសាច់ប្រាក់ឈានមុខ; ដាក់ស្លាកវា (សូមមើល[ការសន្សំបញ្ចេញសាច់ប្រាក់ ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់](../ការសន្សំដែលបញ្ចេញសាច់ប្រាក់-ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់/))។
