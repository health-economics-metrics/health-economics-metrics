# តម្លៃនៃជីវិតស្ថិតិ (VSL)

តម្លៃនៃជីវិតស្ថិតិ (VSL) — ហៅថា "តម្លៃនៃការស្លាប់ដែលបានការពារ" (VPF) ក្នុងការប្រើប្រាស់របស់ចក្រភពអង់គ្លេស — គឺជាចំនួនដែល *ប្រជាជន* ក្នុងសមូហភាពមានឆន្ទៈបង់ ដើម្បីកាត់បន្ថយហានិភ័យនៃការស្លាប់ស្ថិតិមួយ ដែលទាញយកពីការសិក្សាដោះដូរប្រាក់ឈ្នួល-ហានិភ័យ (កម្មករទាមទារប្រាក់ឈ្នួលបន្ថែមប៉ុន្មានសម្រាប់ការងារហានិភ័យជាង) និងការស្ទង់មតិចំណូលចិត្តដែលបានបញ្ជាក់។ វាមិនមែនជាតម្លៃនៃជីវិតបុគ្គលដែលបានកំណត់អត្តសញ្ញាណណាមួយទេ; វាជាសំណង់ហានិភ័យប្រជាជន ហើយវិស្វករកម្មវិធីដែលសាងសង់ប្រព័ន្ធកាត់បន្ថយហានិភ័យ — ក្បួនដោះស្រាយចាត់ថ្នាក់ ការបញ្ជូនរថយន្តសង្គ្រោះ ការត្រួតពិនិត្យសុវត្ថិភាព — ត្រូវដឹងថាវាមកពីប្រពៃណីទ្រឹស្តីខុសពី[កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់](../កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់/)។

## ហេតុអ្វីបានជាសំខាន់

VSL/VPF គឺជាឧបករណ៍ស្តង់ដារសម្រាប់ធ្វើឱ្យការកាត់បន្ថយហានិភ័យមរណភាពទៅជាប្រាក់ ក្នុងការវិភាគថ្លៃដើម-អត្ថប្រយោជន៍និយតកម្ម៖ សុវត្ថិភាពដឹកជញ្ជូន បទប្បញ្ញត្តិបរិស្ថាន និងអន្តរាគមន៍សុខភាពសាធារណៈមួយចំនួន ដំណើរការករណីអាជីវកម្មរបស់ពួកគេតាមវា។ Green Book របស់ HM Treasury បោះពុម្ពតួលេខ VPF ដែលទាញយកពីភស្តុតាងទីផ្សារពលកម្ម និងការស្ទង់មតិរបស់ចក្រភពអង់គ្លេស ហើយក្រសួងដឹកជញ្ជូនប្រើវាដោយផ្ទាល់ក្នុងការវាយតម្លៃសុវត្ថិភាពផ្លូវ។ នេះគឺជាប្រពៃណីកំណត់តម្លៃខុសគ្នាពិតប្រាកដពីវិធីសាស្ត្រ QALY × កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់៖ វិធីសាស្ត្រកម្រិតកំណត់វាយតម្លៃការទទួលបានសុខភាពធៀបនឹងអ្វីដែល *ថវិកា* សុខភាពផលិតនៅគែមបច្ចុប្បន្ន ចំណែក VSL/VPF វាយតម្លៃការកាត់បន្ថយហានិភ័យធៀបនឹងអ្វីដែលមនុស្សក្នុងទីផ្សារពលកម្ម ឬការស្ទង់មតិបង្ហាញថាពួកគេនឹងបង់។ ក្របខ័ណ្ឌទាំងពីរមិនតែងតែផ្សះផ្សាបានទេ ហើយការប្រើទាំងពីរក្នុងករណីតែមួយដោយមិនទទួលស្គាល់នេះ គឺជាកំហុសវិភាគទូទៅ។

## គណិតវិទ្យា

```
Deaths averted = population × risk_reduction_per_person
  (risk_reduction_per_person is a probability, e.g. 0.000001 = 1-in-a-million
   reduction in annual mortality risk)

Monetized mortality benefit = deaths_averted × value_of_prevented_fatality
```

## ឧទាហរណ៍ដែលបានគណនា

តំបន់មួយដែលមានប្រជាជន 800,000 នាក់ទទួលអត្ថប្រយោជន៍ពីអន្តរាគមន៍ចាត់ថ្នាក់/បញ្ជូនឌីជីថលសុវត្ថិភាពផ្លូវ ដែលកាត់បន្ថយហានិភ័យមរណភាពប្រចាំឆ្នាំរបស់មនុស្សម្នាក់ៗ 1 ក្នុងមួយលាន (0.000001)៖

```
Deaths averted = 800,000 × 0.000001 = 0.8
```

ដោយប្រើតម្លៃនៃការស្លាប់ដែលបានការពាររបស់ចក្រភពអង់គ្លេស £2,180,000 (តួលេខ HM Treasury/DfT តម្លៃ 2023/24 — Green Book ធ្វើបច្ចុប្បន្នភាពរាល់ឆ្នាំ ផ្ទៀងផ្ទាត់ឡើងវិញមុនដកស្រង់ក្នុងការវិភាគផ្ទាល់)៖

```
Monetized mortality benefit = 0.8 × £2,180,000 = £1,744,000/year
```

តិចជាង £1.75 លានក្នុងមួយឆ្នាំនៃអត្ថប្រយោជន៍មរណភាពជាប្រាក់ ពីការកាត់បន្ថយហានិភ័យដែលប្រជាជនរងផលប៉ះពាល់ភាគច្រើនមិនដែលកត់សម្គាល់ជាបុគ្គល។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ក្រុមកម្មវិធីសុវត្ថិភាពសំខាន់ — កម្មវិធីបង្កប់ឧបករណ៍វេជ្ជសាស្ត្រ កម្មវិធីយានយន្តស្វយ័ត ប្រព័ន្ធត្រួតពិនិត្យឧស្សាហកម្ម — ប្រឈមនឹងបញ្ហាកំណត់តម្លៃនេះពិតប្រាកដ ពេលសាងសង់ករណីថ្លៃដើម-អត្ថប្រយោជន៍សម្រាប់ការវិនិយោគសុវត្ថិភាព៖ តើអ្នកកំណត់តម្លៃ "ការពារការបរាជ័យមហន្តរាយមួយ" យ៉ាងដូចម្តេច នៅពេលការបរាជ័យកម្រ ធ្ងន់ធ្ងរ និងរាលដាលឆ្លងអ្នកប្រើច្រើន? VSL/VPF គឺជាមុខវិជ្ជាក្នុងពិភពពិតដែលមានឯកសារសាធារណៈជាច្រើនទសវត្សរ៍ សម្រាប់ដាក់លេខលើការកាត់បន្ថយហានិភ័យកម្រ ធ្ងន់ធ្ងរ កម្រិតប្រជាជន — ទម្រង់អំណះអំណាងដូចគ្នានឹងការកំណត់តម្លៃការវិនិយោគ SRE ធៀបនឹងការដាច់អគ្គិសនីមហន្តរាយកម្រ គ្រាន់តែជាមួយលទ្ធផលមរណភាពជំនួសឱ្យលទ្ធផលពេលវេលាដាច់។

## ចំណុចងាយធ្លាក់

- **ការចាត់ទុក VSL ជា "តម្លៃនៃជីវិតដែលបានកំណត់អត្តសញ្ញាណ"**៖ វាមិនមែនទេ។ VSL/VPF គឺជាសំណង់ស្ថិតិប្រជាជនដែលទាញយកពីការដោះដូរការកាត់បន្ថយហានិភ័យឆ្លងមនុស្សច្រើន មិនមែនការវាយតម្លៃជីវិត ឬមរណភាពរបស់មនុស្សជាក់លាក់ណាមួយទេ។
- **ការរាប់ស្ទួនជាមួយការគណនាអត្ថប្រយោជន៍ជាប្រាក់សុទ្ធផ្អែកលើ QALY**៖ ការប្រើតួលេខ VSL/VPF និងការគណនា QALY × កម្រិតកំណត់ដាច់ដោយឡែកក្នុងករណីតែមួយ ដោយមិនផ្សះផ្សា រាប់ស្ទួនដោយស្ងាត់ស្ងាត់នូវតម្លៃនៃការស្លាប់ដែលបានជៀសវាងដូចគ្នា។ ជ្រើសក្របខ័ណ្ឌមួយសម្រាប់ករណីមួយ។
- **ការផ្ទេរការប៉ាន់ស្មាន VSL ឆ្លងបរិបទដោយគ្មានការកែតម្រូវ**៖ VSL ដែលទាញយកពីទីផ្សារពលកម្មប្រទេសមួយ ឬពីទិន្នន័យប្រាក់ឈ្នួល-ហានិភ័យវ័យធ្វើការ អនុវត្តដោយមិនកែតម្រូវលើបរិបទចំណូលផ្សេង ឬប្រជាជនផ្សេង (កុមារ អ្នកចូលនិវត្តន៍) គឺជាបញ្ហាវិធីសាស្ត្រដែលមានជម្លោះយូរមកហើយ — មិនមែនបញ្ហាដែលដោះស្រាយរួចទេ។
