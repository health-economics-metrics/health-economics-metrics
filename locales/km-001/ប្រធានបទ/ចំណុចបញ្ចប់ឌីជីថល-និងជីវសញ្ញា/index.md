# ចំណុចបញ្ចប់ឌីជីថល និងជីវសញ្ញា

ជីវសញ្ញាឌីជីថល (digital biomarker) គឺជារង្វាស់សរីរវិទ្យា ឬអាកប្បកិរិយាវត្ថុវិស័យដែលប្រមូលតាមឧបករណ៍ចាប់សញ្ញា (ល្បឿនដើរពីទូរស័ព្ទ ការគេងពីឧបករណ៍ពាក់ ការញ័រពីឧបករណ៍វាស់ល្បឿនបង្កើន)។ ចំណុចបញ្ចប់ឌីជីថល (digital endpoint) គឺជារង្វាស់បែបនេះដែលត្រូវបានលើកឡើងជា **លទ្ធផលនៃការសាកល្បង** — ប្រើដើម្បីបង្ហាញឥទ្ធិពលនៃការព្យាបាល។ ការដំឡើងឋានៈពី "ទិន្នន័យដែលឧបករណ៍បញ្ចេញ" ទៅ "ភស្តុតាងដែលអ្នកគ្រប់គ្រងទទួលយក" ដំណើរការតាមជណ្តើរផ្ទៀងផ្ទាត់ដែលបានកំណត់។

## ហេតុអ្វីបានជាសំខាន់

ចំណុចបញ្ចប់នៃការសាកល្បងប្រពៃណីមានលក្ខណៈមិនទៀងទាត់ (ទស្សនកិច្ចគ្លីនិករាល់ 3 ខែ) និងថ្លៃ; ចំណុចបញ្ចប់ឌីជីថលបន្តបន្ទាប់ មានបរិស្ថានវិទ្យា (ជីវិតពិត មិនមែនសមត្ថភាពក្នុងគ្លីនិកទេ) និងថោកក្នុងមួយការសង្កេត — ពួកវាអាចបង្រួមការសាកល្បង រកឃើញឥទ្ធិពលឆាប់ជាង និងអនុញ្ញាតការសិក្សាវិមជ្ឈការ។ ចំណុចចាប់គឺការផ្ទៀងផ្ទាត់៖ ក្របខ័ណ្ឌដែលទទួលយក (តម្រឹមតាម FDA បីសសរស្តម្ភ) តម្រូវឱ្យមាន **ការផ្ទៀងផ្ទាត់/ការវិភាគ** (ឧបករណ៍ចាប់សញ្ញាវាស់បរិមាណរូបវន្តបានត្រឹមត្រូវ) **ការផ្ទៀងផ្ទាត់គ្លីនិក** (រង្វាស់ឆ្លុះបញ្ចាំងស្ថានភាពគ្លីនិកដែលវាអះអាង) និង **ទិដ្ឋភាពសុខភាពដែលមានអត្ថន័យ** ដែលបានបង្ហាញ (អ្នកជំងឺយកចិត្តទុកដាក់ចំពោះអ្វីដែលវាចាប់យក)។ ចំណុចបញ្ចប់ដែលគ្មានទាំងបីគឺជាទូរមាត្រ មិនមែនភស្តុតាងទេ។

## គណិតវិទ្យា

```
Analytical validation: agreement with reference (see wearable-validation.md —
                       MAPE, CCC, Bland-Altman)
Clinical validation:   correlation/discrimination against clinical anchors
                       (known-groups validity, responsiveness to change)
Endpoint economics:
  events detected per patient-year (continuous) vs per-visit sampling
  trial power: continuous measures cut sample size when between-visit
  variance dominates — N ∝ σ²/Δ², and σ² falls with dense sampling
```

## ឧទាហរណ៍ដែលបានគណនា

ការសាកល្បងជំងឺប៉ាកឃីនសុនពិចារណាល្បឿនដើរពីឧបករណ៍ចាប់សញ្ញាកដៃ ធៀបនឹងពិន្ទុវាយតម្លៃដោយគ្លីនិករាល់ត្រីមាស៖

```
Clinic endpoint:  4 measurements/patient/year, high day-to-day noise
Digital endpoint: ~200 passive measurements/patient/year

Variance of the annual-change estimate falls ~5× with dense sampling →
detectable effect size at fixed power improves ~√5 ≈ 2.2×, or
equivalently sample size shrinks ~40–60% for the same hypothesis.
At £25,000 per enrolled patient, cutting 200 patients ≈ £5M saved
per trial — the commercial case for the validation investment
(itself perhaps £1–2M) across a sponsor's pipeline.
```

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ចំណុចបញ្ចប់ឌីជីថលគឺជាវិន័យវិស្វកម្មទិន្នន័យស្លៀកពាក់គ្លីនិក៖ **ប្រភពដើម និងការគ្រប់គ្រងកំណែ** (ការធ្វើបច្ចុប្បន្នភាពក្បួនដោះស្រាយកណ្តាលការសិក្សាគំរាមកំហែងភាពអាចប្រៀបធៀប — បញ្ហា [PCCP](../ការវាយតម្លៃបទប្បញ្ញត្តិ-ai/) ក្នុងទម្រង់ការសាកល្បង; ចាក់សោកំណែ និងផ្ទៀងផ្ទាត់ស្ពាន); **ការរចនាទិន្នន័យបាត់** (គម្លាតពេលពាក់ផ្តល់ព័ត៌មាន មិនចៃដន្យទេ — សូមមើល[ការផ្ទៀងផ្ទាត់ឧបករណ៍ពាក់](../ការផ្ទៀងផ្ទាត់ឧបករណ៍ពាក់/); ជម្រើសបំពេញគឺជាការអះអាងវិទ្យាសាស្ត្រ); និង **ការសម្រេចចិត្តបំបែក edge/ពពក** ដែលផ្លាស់ប្តូរអ្វីដែលសញ្ញាឆៅអាចទាញយកបានក្រោយ។ ក្រុមដែលចាត់ទុកបំពង់វាស់ជាកម្មវិធីមានបទប្បញ្ញត្តិតាំងពីថ្ងៃដំបូង — បានសាកល្បង មានកំណែ មានឯកសារ — ទិញភាពជឿជាក់នៃចំណុចបញ្ចប់របស់ពួកគេក្នុងតម្លៃថោក; ការបន្ថែមការផ្ទៀងផ្ទាត់ទៅបំពង់ដែលបានផ្លាស់ទីលឿនគឺជាកន្លែងដែលកម្មវិធីចំណុចបញ្ចប់ឌីជីថលស្លាប់។

## កំហុសដែលត្រូវជៀសវាង

- **ការជាប់ទាក់ទងជាមួយគ្លីនិកជាការផ្ទៀងផ្ទាត់ពេញលេញ**៖ ការផ្គូផ្គងរង្វាស់គ្លីនិកមានកំហុសបង្ហាញមរតក មិនមែនការពិតទេ; ផ្ទៀងផ្ទាត់ធៀបនឹងទិដ្ឋភាពសុខភាពដែលមានអត្ថន័យ។
- **ហានិភ័យបទប្បញ្ញត្តិនៃចំណុចបញ្ចប់ថ្មី**៖ ចំណុចបញ្ចប់ដែលមិនធ្លាប់មានអាចល្អជាងខាងវិទ្យាសាស្ត្រ ហើយនៅតែបំផ្លាញការដាក់ពាក្យ — ចូលរួមជាមួយអ្នកគ្រប់គ្រងឱ្យឆាប់ (មានកម្មវិធីបញ្ជាក់គុណវុឌ្ឍិ)។
- **ភាពមិនត្រូវគ្នារវាងឧបករណ៍ចាប់សញ្ញា និងប្រជាជន**៖ ការផ្ទៀងផ្ទាត់លើកដៃមនុស្សវ័យក្មេងមានសុខភាពល្អ ការដាក់ឱ្យប្រើក្នុងអ្នកជំងឺវ័យចាស់ដែលមានការញ័រ និងភាពខុសគ្នានៃសារធាតុពណ៌ដែល PPG មិនដែលឃើញ។
- **ការរសាត់លក្ខណៈពិសេស**៖ ការបណ្តុះបណ្តាលក្បួនដោះស្រាយល្បឿនដើរឡើងវិញលើទិន្នន័យថ្មីកំណត់ចំណុចបញ្ចប់ឡើងវិញស្ងាត់ៗកណ្តាលការសិក្សា។
