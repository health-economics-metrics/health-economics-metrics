# សមាមាត្រប្រសិទ្ធភាពថ្លៃដើមបន្ថែម (ICER)

ICER គឺជាថ្លៃដើមបន្ថែមក្នុងមួយឯកតាបន្ថែមនៃផលសុខភាព នៅពេលអ្នកជ្រើសរើសជម្រើសមួយជាជាងជម្រើសជំនួសដែលល្អបំផុតបន្ទាប់។ វាជាលេខចម្បងនៃការវាយតម្លៃបច្ចេកវិទ្យាសុខភាព។ (នៅពេលឯកតាផលជា QALY វាត្រូវបានគេហៅថា សមាមាត្រថ្លៃដើម-ឧបយោគបន្ថែម ឬ ICUR ផងដែរ។)

## ហេតុអ្វីបានជាសំខាន់

ប្រព័ន្ធសុខាភិបាលមិនដែលវាយតម្លៃបច្ចេកវិទ្យាមួយដាច់ដោយឡែកឡើយ — ជានិច្ចកាលវាយតម្លៃ *បន្ថែម* ធៀបនឹងអ្វីដែលនឹងត្រូវធ្វើបើមិនដូច្នោះ។ NICE ប្រៀបធៀប ICER របស់បច្ចេកវិទ្យាមួយនឹងកម្រិតកំណត់ **£20,000–£30,000 ក្នុងមួយ QALY** របស់ខ្លួន; វិទ្យាស្ថាន ICER របស់សហរដ្ឋអាមេរិករាយការណ៍ក្នុងចន្លោះ $50,000–$200,000/QALY; កាណាដាធ្វើការជាមួយប្រហែល CAD$50,000/QALY។ ថាតើផលិតផលរបស់អ្នក "ស័ក្តិសម" សម្រាប់សេវាសុខភាពជាតិឬអត់ ជាផ្លូវការគឺថា តើ ICER របស់វាស្ថិតក្រោមកម្រិតកំណត់ក្នុងតំបន់ឬអត់។ សូមមើល [កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់](../កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់/)។

## គណិតវិទ្យា

```
ICER = (Cost_new − Cost_comparator) / (Effect_new − Effect_comparator)
     = ΔC / ΔE
```

ច្បាប់បកស្រាយ៖

- ΔC < 0, ΔE > 0: ជម្រើសថ្មី **ឈ្នះដាច់** — ថោកជាង និងល្អជាង; មិនចាំបាច់មានសមាមាត្រទេ។
- ΔC > 0, ΔE > 0: គណនា ICER ប្រៀបធៀបនឹងកម្រិតកំណត់ λ; ទទួលយកប្រសិនបើ ICER < λ។
- ΔC > 0, ΔE < 0: ជម្រើសថ្មីត្រូវបានឈ្នះដាច់ — បដិសេធ។
- សមាមាត្រមានអាកប្បកិរិយាមិនល្អនៅជិត ΔE = 0 — ចូលចិត្ត[អត្ថប្រយោជន៍រូបិយវត្ថុសុទ្ធ](../អត្ថប្រយោជន៍រូបិយវត្ថុសុទ្ធ/)សម្រាប់ការតម្រៀបចំណាត់ថ្នាក់។

ជម្រើសប្រៀបធៀបត្រូវតែជា *ជម្រើសល្អបំផុតបន្ទាប់ដែលមិនត្រូវបានឈ្នះដាច់* មិនមែន "មិនធ្វើអ្វីសោះ" ទេ — សូមមើល [ការឈ្នះដាច់ និងព្រំដែនប្រសិទ្ធភាព](../ភាពលេចធ្លោ-និងព្រំដែនប្រសិទ្ធភាព/)។

## ឧទាហរណ៍ដែលបានគណនា

សេវាត្រួតពិនិត្យពីចម្ងាយសម្រាប់អ្នកជំងឺបរាជ័យបេះដូង ក្នុង 1,000 នាក់/ឆ្នាំ ធៀបនឹងការថែទាំធម្មតា៖

```
Costs:   service £900,000; admissions avoided save £600,000
         ΔC = 900,000 − 600,000 = £300,000
Effects: earlier intervention gains 25 QALYs
         ΔE = 25

ICER = 300,000 / 25 = £12,000 per QALY
```

£12,000/QALY ទាបជាងកម្រិត £20,000 របស់ NICE ច្រើន — ជាករណីដ៏រឹងមាំ។ សូមកត់សម្គាល់ថា ថ្លៃដើម *សុទ្ធ* សំខាន់យ៉ាងណា៖ បើគ្មានការទូទាត់ £600,000 នោះ ICER នឹងស្មើ £36,000/QALY ហើយករណីនេះប្រហែលជាបរាជ័យ។ ការទូទាត់ថ្លៃដើម និងគុណភាពភស្តុតាងរបស់វា គឺជាកន្លែងដែលការវិភាគទាំងនេះឈ្នះ ឬចាញ់ (សូមមើល [ថ្លៃដើមខាងក្រោមដែលបានជៀសវាង](../ថ្លៃដើមបន្ទាប់ដែលបានជៀសវាង/))។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

វិន័យ ICER ផ្ទេរទៅការសម្រេចចិត្តផ្នែកវិស្វកម្មបានទាំងស្រុង៖

```
(cost of option B − cost of option A) / (outcome B − outcome A)
```

— ថ្លៃដើមបន្ថែមក្នុងមួយការដាក់ឱ្យប្រើបន្ថែម ក្នុងមួយម៉ោងវិស្វករដែលសន្សំបាន ក្នុងមួយឧប្បត្តិហេតុដែលបានជៀសវាង — ធៀបនឹងជម្រើសល្អបំផុតបន្ទាប់ជានិច្ច មិនមែនធៀបនឹងការមិនធ្វើអ្វីសោះទេ។ ទម្លាប់ពីរដែលគួរយកតាម៖ (1) *ដាក់ឈ្មោះជម្រើសប្រៀបធៀបឱ្យច្បាស់លាស់*; ការអះអាង ROI របស់ឧបករណ៍ភាគច្រើនប្រៀបធៀបជាមួយបុរសចំបើងដោយសម្ងាត់; (2) *ដកថ្លៃដើមសុទ្ធជាមុនសិន* — ឧបករណ៍ដែលតម្លៃ £100k ប៉ុន្តែជំនួសការចំណាយដែលមានស្រាប់ £80k មាន ΔC = £20k។

## កំហុសដែលត្រូវជៀសវាង

- **ការប្រៀបធៀប ICER ឆ្លងរូបិយប័ណ្ណ ដោយគ្មានជំហានបម្លែងច្បាស់លាស់**: ICER ដែលគណនាជារូបិយប័ណ្ណរបស់ប្រទេសមួយ ត្រូវតែបម្លែងដោយវិធីសាស្ត្រដែលបានបញ្ជាក់ មុនប្រៀបធៀបនឹងកម្រិតកំណត់របស់ប្រទេសមួយទៀត — សូមមើល [ការប្រៀបធៀប ICER ឆ្លងរូបិយប័ណ្ណ](../ការប្រៀបធៀប-icer-ឆ្លងរូបិយប័ណ្ណ/) ដើម្បីដឹងមូលហេតុដែលការជ្រើសរើសកត្តាបម្លែង (សមភាពអំណាចទិញ ធៀបនឹងអត្រាប្តូរប្រាក់ទីផ្សារ) អាចត្រឡប់ការសម្រេចចិត្តទទួលយកបាន។
- **ការលេងល្បិចជម្រើសប្រៀបធៀប**: ការប្រៀបធៀបនឹងមូលដ្ឋានដែលហួសសម័យ ឬអាក្រក់ដោយសិប្បនិម្មិត ធ្វើឱ្យ ΔE ប៉ោង និងធ្វើឱ្យ ICER មើលទៅល្អ។
- **មធ្យមភាគជំនួសឱ្យការបន្ថែម**: ថ្លៃដើមក្នុងមួយ QALY នៃកម្មវិធីទាំងមូល មិនមែនជា ICER នៃការពង្រីក ឬទទួលយកវាទេ។
- **ការគោរពប៉ាន់ស្មានចំណុចតែមួយ**: ICER គឺជាសមាមាត្រនៃភាពខុសគ្នាមិនប្រាកដពីរ; ត្រូវរាយការណ៍ភាពមិនប្រាកដប្រជាតាមរយៈ [PSA និង CEAC](../ការវិភាគភាពរសើបប្រូបាប៊ីលីស្ទិក/)។
- **ICER អវិជ្ជមានមានភាពមិនច្បាស់លាស់** (ថោកជាង-និងល្អជាង ធៀបនឹង ថ្លៃជាង-និងអាក្រក់ជាង ផ្តល់សញ្ញាដូចគ្នា) — កុំរាយការណ៍ ICER អវិជ្ជមានដោយមិនប្រាប់ថាវាស្ថិតក្នុងចតុកោណណា។
