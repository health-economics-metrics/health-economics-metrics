# ថ្លៃដើមសរុបនៃភាពជាម្ចាស់ (TCO)

TCO គឺជាថ្លៃដើមទាំងមូលនៃប្រព័ន្ធមួយក្នុងអាយុកាលរបស់វា៖ ការទិញ ឬសាងសង់ ការធ្វើសមាហរណកម្ម ប្រតិបត្តិការ ការថែទាំ ជំនួយ ការបណ្តុះបណ្តាល និងការឈប់ប្រើ។ មូលដ្ឋានមិនស្រណោះ៖ **ការថែទាំគឺ 50–80% នៃ TCO កម្មវិធី** — ប្រហែលបីភាគបួននៃថ្លៃដើមពេញមួយអាយុកាលកើតឡើង *បន្ទាប់ពី* ការចាប់ផ្តើម។

## ហេតុអ្វីបានជាសំខាន់

ការវាយតម្លៃបច្ចេកវិទ្យាសុខភាពបានរៀនតាំងពីយូរមកហើយថា តម្លៃថ្នាំមិនមែនជាថ្លៃដើមរបស់វាទេ — ការគ្រប់គ្រង ការត្រួតពិនិត្យ និងការគ្រប់គ្រងផលរំខានទាំងអស់ត្រូវដាក់ក្នុងម៉ូដែល។ ករណីអាជីវកម្មកម្មវិធីដែលរាប់តែថ្លៃសាងសង់/អាជ្ញាប័ណ្ណ ធ្វើកំហុសតម្លៃថ្នាំស្រើបស្រាលដដែល ហើយប៉ាន់ស្មានចំហៀងថ្លៃដើមទាបជាប្រព័ន្ធ នៃរាល់ [ICER](../សមាមាត្រប្រសិទ្ធភាពថ្លៃដើមបន្ថែម/) និង[ផលប៉ះពាល់ថវិកា](../ការវិភាគផលប៉ះពាល់ថវិកា/) ដែលវាផ្តល់ទិន្នន័យ។ សម្រាប់ការទិញរបស់ NHS វិន័យ TCO គឺជាអ្វីដែលធ្វើឱ្យការអះអាងប្រសិទ្ធភាពថ្លៃដើមរបស់ផលិតផលឌីជីថលស្មោះត្រង់ — ហើយជាកន្លែងដែលជម្រើសមើលទៅថោកចាញ់។

## គណិតវិទ្យា

```
TCO = initial cost (build/licence + integration + data migration + training)
    + Σ_t [operations + maintenance + support + infrastructure + upgrades
           + compliance/assurance]_t / (1 + r)^t
    + decommissioning cost (exit, data extraction, parallel running)

Horizon: 3–5 years commercial, system-lifetime for clinical infrastructure
r: 3.5% public sector (Green Book), 8–12% commercial
Benchmarks: annual maintenance ≈ 15–20% of build cost; ~78% of lifetime
TCO post-launch; ignore decommissioning and vendor lock-in prices itself.
```

## ឧទាហរណ៍ដែលបានគណនា

ជម្រើសពីរសម្រាប់ប្រព័ន្ធ e-observations ផ្តោតលើ 5 ឆ្នាំ៖

```
                        Vendor SaaS     In-house build
Year 0 (licence/build)  £250,000        £900,000
Integration + training  £180,000        £150,000
Annual run (yrs 1–5)    £120,000/yr     £190,000/yr  (hosting + 1.5 FTE maint.)
Exit/decommission       £60,000         £30,000

Undiscounted TCO        £1,090,000      £2,030,000
```

ការប៉ាន់ស្មានវិស្វកម្មនៃជម្រើសសាងសង់ (£900k) គឺត្រឹមតែ 44% នៃ TCO ពិតរបស់វា — ហើយការប៉ាន់ស្មានសាងសង់ជាធម្មតាលើសថវិកា 30–40% (សូមមើល[បង្កើត ឬទិញ](../បង្កើត-ឬទិញ/))។ លុះត្រាតែជម្រើសក្នុងផ្ទះផ្តល់ *លទ្ធផល* ខុសគ្នាគួរឱ្យកត់សម្គាល់ តក្កវិជ្ជា[ការកាត់បន្ថយថ្លៃដើម](../ការវិភាគកាត់បន្ថយថ្លៃដើម/) អនុវត្ត ហើយ SaaS ឈ្នះប្រហែល £940k។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

វិស្វករលើកទម្ងន់ទិន្នន័យថែទាំនៃវិស័យខ្លួនទាបពេលតស៊ូមតិការសាងសង់៖ ច្បាប់ថែទាំប្រចាំឆ្នាំ 15–20% នៃថ្លៃសាងសង់មានន័យថារាល់ប្រព័ន្ធ £1M ប្តេជ្ញាស្ងាត់ស្ងាត់សមត្ថភាពអនាគត £150–200k/ឆ្នាំ — បំណុលដែលជាកម្មសិទ្ធិនៃតារាងតុល្យការផ្លូវចិត្តដូចគ្នាជាមួយ[បំណុលបច្ចេកទេស](../បំណុលបច្ចេកទេស/)។ TCO ក៏ជាផ្នែកថ្លៃដើមនៃរាល់រង្វាស់ក្នុងឃ្លាំងនេះ៖ ថ្លៃដើមក្នុងមួយការដាក់ពង្រាយ [សេដ្ឋកិច្ចឯកតាពពក](../សេដ្ឋកិច្ចឯកតាពពក/) និងវិន័យភាគបែងដែល HTA បង្ខំលើអ្នកឧបត្ថម្ភថ្នាំ។ នៅពេលតម្លៃផលិតផលរបស់អ្នកត្រូវបានប្រកួតប្រជែង ការប្រៀបធៀប TCO រួមទាំងថ្លៃដើមដំណើរការពិតរបស់អ្នកកាន់តំណែងជាធម្មតាជាការកំណត់ក្របខ័ណ្ឌឡើងវិញដ៏ខ្លាំងបំផុត។ តួលេខ TCO ច្រើនឆ្នាំដូចខាងលើគឺជាផលបូកនៃបន្ទាត់ថ្លៃដើមច្រើនតាមពេលវេលា — សូមមើល[ការបូកសរុបថ្លៃដើមសុវត្ថិភាពរូបិយប័ណ្ណ](../ការបូកសរុបថ្លៃដើមសុវត្ថិភាពរូបិយប័ណ្ណ/) ដើម្បីដឹងថាហេតុអ្វីផលបូកនោះគួរជាទសភាគពិតប្រាកដជាជាងចំណុចអណ្តែត នៅពេលម៉ូដែលត្រូវផ្គូផ្គងដល់សេន និង[ការបែងចែកថ្លៃដើមត្រឹមសេនពិតប្រាកដ](../ការបែងចែកថ្លៃដើមត្រឹមសេនពិតប្រាកដ/) សម្រាប់បែងចែកសរុប TCO ឆ្លងមជ្ឈមណ្ឌលថ្លៃដើមដោយមិនបាត់សេន។

## ចំណុចងាយធ្លាក់

- **ការយកថ្លៃដើមចាប់ផ្តើមជាយុថ្កា**៖ ប្រៀបធៀបជម្រើសនៅថ្លៃដើមឆ្នាំ 0 នៅពេលចំណាត់ថ្នាក់ត្រឡប់ដល់ឆ្នាំទី 3។
- **ក្តីស្រមៃពលកម្មផ្ទៃក្នុងឥតគិតថ្លៃ**៖ ការថែទាំក្នុងផ្ទះគិតថ្លៃសូន្យ ពីព្រោះ "ក្រុមត្រូវបានបង់រួចហើយ" — សូមមើល[ថ្លៃដើមឱកាស](../ថ្លៃដើមឱកាស/)។
- **ការមិនអើពើថ្លៃដើមចាកចេញ**៖ ការទាញទិន្នន័យចេញ ការបញ្ចប់កិច្ចសន្យា និងការដំណើរការស្របគ្នា គឺជាកន្លែងដែល SaaS "ថោក" ក្លាយជាថ្លៃ។
- **ការរំលោភរយៈពេលដូចគ្នា**៖ ប្រៀបធៀប TCO SaaS 3 ឆ្នាំនឹងការរំលស់ការសាងសង់ 10 ឆ្នាំ (សូមមើល[កម្រិតពេលវេលា](../ព្រំដែនពេលវេលា/))។
