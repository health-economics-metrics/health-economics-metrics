# EQ-5D

EQ-5D គឺជាកម្រងសំណួរស្តង់ដាររបស់ក្រុម EuroQol សម្រាប់វាស់គុណភាពជីវិតទាក់ទងនឹងសុខភាព។ វាគឺជាឧបករណ៍ដែលបង្កើតទម្ងន់ឧបយោគក្នុងការគណនា[QALY](../ឆ្នាំជីវិតដែលកែតម្រូវតាមគុណភាព/)ភាគច្រើន — ករណីយោងរបស់ NICE ដាក់ឈ្មោះវាថាជារង្វាស់ដែលពេញចិត្តសម្រាប់មនុស្សពេញវ័យ។

## ហេតុអ្វីបានជាសំខាន់

ផលិតផលសុខភាពឌីជីថលណាដែលចង់អះអាង QALYs ត្រូវការឧបយោគពីឧបករណ៍ដែលបានផ្ទៀងផ្ទាត់ ហើយ EQ-5D គឺជាលំនាំដើមនៅចក្រភពអង់គ្លេស និងអឺរ៉ុបភាគច្រើន។ វាខ្លីល្មមបង្កប់ក្នុងកម្មវិធី (5 សំណួរ + មាត្រដ្ឋានមើលឃើញ) មានន័យថាផលិតផលកម្មវិធីអាចប្រមូលទិន្នន័យលទ្ធផលកម្រិត HTA ជាផលរំខាននៃការប្រើប្រាស់ធម្មតា — អត្ថប្រយោជន៍រចនាសម្ព័ន្ធលើថ្នាំ ដែលត្រូវការការសិក្សាឯកទេស។

## គណិតវិទ្យា

EQ-5D-5L សួរសំណួរមួយក្នុង **5 វិមាត្រ** — ការធ្វើចលនា ការថែទាំខ្លួន សកម្មភាពធម្មតា ការឈឺចាប់/មិនស្រួល ការថប់បារម្ភ/ធ្លាក់ទឹកចិត្ត — ឆ្លើយនៅ **5 កម្រិត** (គ្មានបញ្ហា … បញ្ហាខ្លាំង) បូកមាត្រដ្ឋានអាណាឡូកមើលឃើញ 0–100 (EQ VAS)។

```
Health state = 5-digit profile, e.g. "21221"
Utility index = value_set(profile)

The value set is country-specific, derived from time-trade-off /
discrete-choice surveys of the general public. Anchors: 1 = full health,
0 = dead; states worse than death are negative (UK 3L set floor: −0.594).
```

បន្ទាប់មកនព្វន្ធ QALY ដំណើរការជា `duration × utility`។

## ឧទាហរណ៍ដែលបានគណនា

កម្មវិធីស្តារសាច់ដុំ និងឆ្អឹងវាស់ EQ-5D-5L នៅពេលចូលប្រើ និងនៅ 6 ខែសម្រាប់អ្នកប្រើបញ្ចប់ 1,000 នាក់។

```
Mean utility at baseline:  0.62
Mean utility at 6 months:  0.71
Gain sustained (assume) 1 year: (0.71 − 0.62) × 1.0 = 0.09 QALYs per user
```

ធៀបនឹងការផ្លាស់ប្តូរក្រុមត្រួតពិនិត្យ 0.03 (ការជាសះស្បើយធម្មជាតិ) ផលចំណេញដែលអាចសន្មតបានគឺ 0.06 QALYs/អ្នកប្រើ។ បំប្លែងជារូបិយវត្ថុក្នុង £20,000–£30,000/QALY៖ **£1,200–£1,800 នៃតម្លៃសុខភាពក្នុងមួយអ្នកប្រើបញ្ចប់** — លេខដែលជាយុថ្កានៃការចរចាតម្លៃរបស់កម្មវិធីជាមួយអ្នកបង់ប្រាក់។ (ភាពខុសគ្នាគ្លីនិកសំខាន់អប្បបរមាសម្រាប់សន្ទស្សន៍ EQ-5D ជាទូទៅនៅក្នុងចន្លោះ 0.03–0.08 ដូច្នេះ 0.06 អាចជឿបាន ប៉ុន្តែត្រូវតែឆ្លងការប្រៀបធៀបក្រុមត្រួតពិនិត្យ; សូមមើល[លទ្ធផលរាយការណ៍ដោយអ្នកជំងឺ](../លទ្ធផលដែលអ្នកជំងឺរាយការណ៍/)។)

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

- **ដាក់ឧបករណ៍វាស់វា។** EQ-5D នៅពេលចុះឈ្មោះ និងចន្លោះតាមដានគឺជាអេក្រង់ UI ពីរបី; ផលចំណេញគឺភស្តុតាងកម្រិត HTA។ ទទួលអាជ្ញាប័ណ្ណពី EuroQol (តម្រូវ ឥតគិតថ្លៃសម្រាប់ការប្រើប្រាស់មួយចំនួន)។
- **ប្រើសំណុំតម្លៃត្រឹមត្រូវ** សម្រាប់ប្រទេសដាក់ឱ្យប្រើ — ចម្លើយដូចគ្នាមានពិន្ទុខុសគ្នានៅចក្រភពអង់គ្លេសធៀបនឹងអាល្លឺម៉ង់ធៀបនឹងជប៉ុន។
- **មេរៀនរចនា**៖ EQ-5D បង្ហាញពីរបៀបដែលការស្ទង់មតិស្តង់ដារតូចមួយបូកមុខងារដាក់ពិន្ទុដែលបានបោះពុម្ពផ្តល់សន្ទស្សន៍តែមួយអាចប្រៀបធៀបបាន។ នោះគឺជាគំរូសម្រាប់សន្ទស្សន៍បទពិសោធន៍អ្នកអភិវឌ្ឍន៍ដែលអាចជឿបាន — ឧបករណ៍ស្តង់ដារ ទម្ងន់ដែលបានបោះពុម្ព មិនមែនអារម្មណ៍តាមអំពើចិត្តទេ។ សូមមើល[SPACE និង DevEx](../space-និង-devex/)។

## កំហុសដែលត្រូវជៀសវាង

- **មុន/ក្រោយដោយគ្មានអ្នកប្រៀបធៀប** — ការវិលទៅរកមធ្យម និងការជាសះស្បើយធម្មជាតិបំប៉ោងការទទួលបានដោយងាយ។
- **ភាពលំអៀងអ្នករួចជីវិត**៖ ការវាស់តែអ្នកប្រើដែលនៅតែចូលរួម (សូមមើល[ការរក្សា និងការបោះបង់](../ការរក្សា-និងការបោះបង់/))។
- **ការលាយកំណែ 3L និង 5L ឬសំណុំតម្លៃ** ឆ្លងការសិក្សា — លេខខុសគ្នាជាប្រព័ន្ធ។
- **ឥទ្ធិពលពិដាន** ក្នុងប្រជាជនរងផលប៉ះពាល់ស្រាល៖ អ្នកប្រើជាច្រើនពិន្ទុជិត 1.0 នៅមូលដ្ឋាន ទុកគ្មានចន្លោះបង្ហាញការទទួលបាន។
- **ចាត់ទុកសំណុំតម្លៃថាបញ្ជាក់ខ្លួនឯង**៖ លេខឧបយោគដែលសំណុំតម្លៃត្រឡប់ខ្លួនឯងត្រូវបានទាញយកពីសាធារណជនតាមការស្ទង់មតិ time trade-off (ឬផ្អែកលើជម្រើសពាក់ព័ន្ធ) — សូមមើល[ការទាញយកឧបយោគ Time Trade-Off (TTO)](../ការទាញយកឧបយោគតាមការដោះដូរពេលវេលា/)សម្រាប់របៀប។
