# ការវិភាគភាពរសើបប្រូបាប៊ីលីស្ទិក (PSA)

PSA កំណត់ការចែកចាយប្រូបាប៊ីលីតេដល់រាល់ប៉ារ៉ាម៉ែត្រមិនប្រាកដ យកគំរូពួកវាទាំងអស់ក្នុងពេលតែមួយរាប់ពាន់ដង (Monte Carlo) ហើយរាយការណ៍ *ប្រូបាប៊ីលីតេ* ដែលជម្រើសមួយជាជម្រើសល្អបំផុត — ជំនួសឱ្យការប៉ាន់ស្មានចំណុចតែមួយ។

## ហេតុអ្វីបានជាសំខាន់

ករណីយោងរបស់ NICE *តម្រូវ* PSA។ ការវិភាគកំណត់ឆ្លើយ "ចុះបើធាតុចូលមួយខុស?"; PSA ឆ្លើយ "ដោយផ្តល់នូវអ្វីៗទាំងអស់ដែលយើងមិនដឹងក្នុងពេលតែមួយ តើមានប្រូបាប៊ីលីតេប៉ុន្មានដែលយើងធ្វើការសម្រេចចិត្តត្រឹមត្រូវ?" លទ្ធផលសញ្ញាសម្គាល់របស់វា **ខ្សែកោងអាចទទួលយកបានប្រសិទ្ធភាពថ្លៃដើម (CEAC)** គូសប្រូបាប៊ីលីតេដែលជម្រើសមួយមានប្រសិទ្ធភាពថ្លៃដើម ធៀបនឹងកម្រិតកំណត់ឆន្ទៈបង់ប្រាក់ — បម្លែង "ICER គឺ £24,000/QALY" ទៅជា "មានឱកាស 78% ដែលនេះជាជម្រើសត្រឹមត្រូវនៅ £30,000/QALY។"

## គណិតវិទ្យា

```
For each of N draws (N ≈ 10,000):
  sample every parameter θ from its distribution
    (costs ~ Gamma, probabilities ~ Beta, utilities ~ Beta, effects ~ Normal/logNormal)
  compute NMB_j(θ) = λ × Effect_j(θ) − Cost_j(θ) for each option j

CEAC_j(λ) = fraction of draws in which option j has the highest NMB at threshold λ
```

សូមមើល[អត្ថប្រយោជន៍ជាប្រាក់សុទ្ធ](../អត្ថប្រយោជន៍រូបិយវត្ថុសុទ្ធ/) សម្រាប់ NMB និង[កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់](../កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់/) សម្រាប់ λ។

## ឧទាហរណ៍ដែលបានគណនា

ករណីអាជីវកម្មការផ្លាស់ប្តូរវេទិកា។ ធាតុចូលមិនប្រាកដបី៖

```
Migration cost      ~ Gamma,  mean £800k, sd £200k
Annual benefit      ~ Normal, mean £350k, sd £150k
Benefit duration    ~ Uniform, 3–6 years
```

សម្រាប់រាល់ 10,000 ការគូស គណនាអត្ថប្រយោជន៍សុទ្ធ = រយៈពេល × ប្រចាំឆ្នាំ − ថ្លៃដើម (មិនរាប់ការបញ្ចុះតម្លៃដើម្បីភាពច្បាស់)។ លទ្ធផលបង្ហាញ៖

```
Mean net benefit:      £775k
Probability net > 0:   0.86
5th–95th percentile:  −£180k … +£1.9M
```

ការប៉ាន់ស្មានចំណុចនិយាយថា "ច្បាស់ជាបាទ/ចាស។" PSA និយាយថា "86% បាទ/ចាស ជាមួយកន្ទុយពិតដែលយើងបាត់បង់ £180k+" — ដែលជាអ្វីដែលម្ចាស់ផលប័ត្រត្រូវការពិតប្រាកដ ហើយវាកំណត់តម្លៃសម្រាប់ដំណើរការ discovery spike មុន (សូមមើល [EVPI](../តម្លៃរំពឹងទុកនៃព័ត៌មានល្អឥតខ្ចោះ/))។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

វិស្វករទុកចិត្ត Monte Carlo រួចហើយសម្រាប់ការព្យាករណ៍ការបញ្ជូន (ការយកគំរូទិន្នផលឈ្នះការប៉ាន់ស្មានចំណុច)។ ពង្រីកយន្តការដូចគ្នាទៅលើប្រាក់៖ ការចែកចាយលើការទទួលយក ពេលវេលាដែលសន្សំ និងប្រាក់ខែ បន្ទាប់មករាយការណ៍ "ប្រូបាប៊ីលីតេដែលការវិនិយោគវេទិកានេះមានជាវិជ្ជមានសុទ្ធ" ជំនួសឱ្យ ROI ភាពជាក់លាក់មិនពិត។ ខ្សែកោងប្រភេទ CEAC — ប្រូបាប៊ីលីតេនៃការជាជម្រើសល្អបំផុតជាអនុគមន៍នៃរបៀបដែលអង្គការកំណត់តម្លៃម៉ោងវិស្វករ — គឺជាសិល្បៈវត្ថុល្អប្រសើរពិតប្រាកដសម្រាប់គណៈកម្មាធិការផ្តល់មូលនិធិ ជាងលេខតែមួយណាមួយ។

## ចំណុចងាយធ្លាក់

- **ការចែកចាយសំរាម**៖ PSA ជាមួយគម្លាតស្តង់ដារប្រឌិតគឺជាការវិភាគកំណត់ពាក់អាវក្រៅមន្ទីរពិសោធន៍។ ផ្អែកការរាលដាលលើទិន្នន័យ ឬការទាញយកអ្នកជំនាញដែលមានរចនាសម្ព័ន្ធ។
- **ការមិនអើពើការជាប់ទាក់ទង** រវាងប៉ារ៉ាម៉ែត្រ (ការទទួលយកខ្ពស់ជាធម្មតាជាប់ទាក់ទងនឹងពេលវេលាសន្សំខ្ពស់); ការយកគំរូឯករាជ្យប៉ាន់ស្មានហានិភ័យកន្ទុយទាបពេក។
- **ការរាយការណ៍តែមធ្យម** នៃការក្លែងធ្វើ — ចំណុចទាំងមូលគឺការចែកចាយ និងប្រូបាប៊ីលីតេការសម្រេចចិត្ត។
