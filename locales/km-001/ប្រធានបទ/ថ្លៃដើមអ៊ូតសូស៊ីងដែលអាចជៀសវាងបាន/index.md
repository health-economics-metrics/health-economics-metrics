# ថ្លៃដើមអ៊ូតសូស៊ីងដែលអាចជៀសវាងបាន

នៅពេលទុន (trust) មិនអាចសម្រេចគោលដៅដោយសមត្ថភាពផ្ទៃក្នុង វាទិញសមត្ថភាពក្នុងអត្រាបុព្វលាភ៖ ម៉ោងបន្ថែមចុងសប្តាហ៍សម្រាប់បុគ្គលិកខ្លួនឯង ឬអ៊ូតសូស៊ីងនីតិវិធីទៅអ្នកផ្តល់សេវាឯកជន។ តម្លៃសេដ្ឋកិច្ចនៃកម្មវិធីដែលបញ្ចេញសមត្ថភាពរួមបញ្ចូល **ថ្លៃដើមដែលអាចជៀសវាងបាននៃការងារអត្រាបុព្វលាភនោះ**។

## ហេតុអ្វីបានជាសំខាន់

ក្រោមសម្ពាធនៃការស្តារឡើងវិញនៃការព្យាបាលតាមគម្រោង ទុនជាទូទៅបង់តម្លៃទីផ្សារភ្លាមៗវិស័យឯកជន (ជារឿយៗ 1.2–1.5× តម្លៃគ្រោងការណ៍ NHS) ឬអត្រាគំនិតផ្តួចផ្តើមបញ្ជីរង់ចាំបុព្វលាភដល់អ្នកជំនាញផ្ទាល់ខ្លួនសម្រាប់បញ្ជីចុងសប្តាហ៍។ មិនដូចការអះអាងសមត្ថភាពធម្មតា ការជៀសវាងអ៊ូតសូស៊ីងគឺ **បញ្ចេញសាច់ប្រាក់**៖ វិក្កយបត្រទៅអ្នកផ្តល់សេវាឯកជនពិតជាមិនត្រូវបានចេញ។ នោះធ្វើឱ្យវាក្លាយជាបន្ទាត់អត្ថប្រយោជន៍ខ្លាំងបំផុតមួយសម្រាប់កម្មវិធីដែលបង្កើនទិន្នផលផ្ទៃក្នុង — និងងាយបង្ហាញភស្តុតាងបំផុត ព្រោះការចំណាយអ៊ូតសូស៊ីងជាបន្ទាត់ថវិកាដែលអាចមើលឃើញរួចហើយ។

## គណិតវិទ្យា

```
Avoidable outsourcing cost = activity moved in-house × (outsourced unit price
                             − internal marginal cost per case)

Internal marginal cost: consumables + variable staffing for the extra activity
— the fixed estate is already paid for (see marginal-vs-average-cost.md).
```

ការអះអាងតម្រូវឱ្យសមត្ថភាពផ្ទៃក្នុងដែលបានបញ្ចេញស្រូបយកសកម្មភាពពិតប្រាកដ៖ វគ្គវះកាត់ គ្រែ និងបុគ្គលិកត្រូវតែមានទាំងអស់ (ឧបសគ្គចងចាំគ្រប់គ្រង — ទ្រឹស្តីឧបសគ្គម្តងទៀត)។

## ឧទាហរណ៍ដែលបានគណនា

ទុនមួយអ៊ូតសូស៊ីងនីតិវិធីវះកាត់ជំងឺឡើងបាយភ្នែក 800 ក្នុងមួយឆ្នាំ ក្នុងតម្លៃ £900 ក្នុងមួយ៖ ការចំណាយខាងក្រៅ £720,000/ឆ្នាំ ធៀបនឹងតម្លៃគ្រោងការណ៍ ~£750។

កម្មវិធីកំណត់ពេលវេលាបន្ទប់វះកាត់ (បង្កើនប្រសិទ្ធភាពបញ្ជី បំពេញគម្លាតពីការលុបចោល តាមដានពេលផ្លាស់ប្តូរ) បង្កើនការប្រើប្រាស់បន្ទប់វះកាត់ផ្ទៃក្នុងគ្រប់គ្រាន់ដើម្បីនាំត្រឡប់ 500 នីតិវិធី៖

```
Internal marginal cost per case ≈ £350 (consumables + sessional staffing)
Saving = 500 × (900 − 350) = £275,000/year — cash-releasing
Remaining outsourcing: 300 × £900 = £270,000 (was £720,000)
```

ថ្លៃកម្មវិធី £90,000/ឆ្នាំ → សុទ្ធ ≈ **+£185,000/ឆ្នាំជាសាច់ប្រាក់ដែលអាចដាក់ធនាគារបាន** បូករួមទាំងអត្ថប្រយោជន៍គុណភាពផ្ទៃក្នុង និងការបណ្តុះបណ្តាលពីការរក្សាការងារក្នុងផ្ទះ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ភាពស្រដៀងដោយផ្ទាល់គឺ **បុព្វលាភអ្នកម៉ៅការ និងទីប្រឹក្សា**៖ នៅពេលសមត្ថភាពវិស្វកម្មផ្ទៃក្នុងមិនអាចបំពេញកាតព្វកិច្ច អង្គការទិញសមត្ថភាពខាងក្រៅក្នុង 1.5–3× អត្រាផ្ទៃក្នុងដែលបានផ្ទុក។ ការវិនិយោគវេទិកា និងផលិតភាពដែលបង្កើនទិន្នផលផ្ទៃក្នុងគួរអះអាងការចំណាយអ្នកម៉ៅការដែលបានជៀសវាងដូចខាងលើ — អត្រាថ្ងៃខាងក្រៅដកថ្លៃដើមរឹតបន្តឹងផ្ទៃក្នុង គុណនឹងការងារដែលបាននាំត្រឡប់ — ព្រោះវាជាបន្ទាត់បញ្ចេញសាច់ប្រាក់ពិតប្រាកដតិចតួចមួយក្នុងករណីអាជីវកម្មផលិតភាពអ្នកអភិវឌ្ឍន៍។ ការព្រមានដូចគ្នាអនុវត្ត៖ សមត្ថភាពផ្ទៃក្នុងត្រូវតែមានពិតប្រាកដ និងត្រូវបានកំណត់ពេលលើការងារដែលបាននាំត្រឡប់ បើមិនដូច្នោះទេការអះអាងគឺជាប្រឌិត។

## កំហុសដែលត្រូវជៀសវាង

- **អះអាងការនាំត្រឡប់ដោយគ្មានខ្សែច្រវាក់សមត្ថភាពពេញលេញ** — គ្រូពេទ្យវះកាត់ត្រូវបានដោះលែងប៉ុន្តែគ្មានម៉ោងបន្ទប់វះកាត់ (ឬវិស្វករត្រូវបានដោះលែងប៉ុន្តែគ្មានកម្រិតបញ្ជូនគ្រប់គ្រងផលិតផល) នាំត្រឡប់អ្វីសោះ។
- **ការប្រៀបធៀបតម្លៃអ៊ូតសូស៊ីងនឹងថ្លៃដើមមធ្យមផ្ទៃក្នុង** ជំនួសឱ្យថ្លៃដើមរឹតបន្តឹង — ធ្វើឱ្យការសន្សំតិចជាងការពិត ចម្លែកណាស់; ថ្លៃដើមថេរដំណើរការទាំងពីរផ្លូវ។
- **ភាពមិនស៊ីមេទ្រីគុណភាព/ភាពស្មុគស្មាញ**៖ ករណីអ៊ូតសូស៊ីងជារឿយៗជាករណីសាមញ្ញ; ការនាំត្រឡប់ពួកវាផ្លាស់ប្តូរការលាយករណីផ្ទៃក្នុង និងថ្លៃដើមឯកតា។
