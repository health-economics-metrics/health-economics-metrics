# ការវិភាគការសម្រេចចិត្តពហុលក្ខណៈវិនិច្ឆ័យ (MCDA)

ការវិភាគការសម្រេចចិត្តពហុលក្ខណៈវិនិច្ឆ័យ (MCDA) គឺជាគំរូដាក់ពិន្ទុផលបូកថ្លឹងទម្ងន់ ប្រើក្នុងការវាយតម្លៃបច្ចេកវិទ្យាសុខភាព នៅពេលកម្រិតកំណត់ ICER/ឆន្ទៈបង់ប្រាក់តែមួយមិនចាប់យកអ្វីៗទាំងអស់ដែលអ្នកសម្រេចចិត្តខ្វល់ខ្វាយ៖ សមធម៌ តម្រូវការមិនទាន់បំពេញ ការច្នៃប្រឌិត ផលប៉ះពាល់ថវិកា ភាពធ្ងន់ធ្ងរនៃជំងឺ។ លក្ខណៈវិនិច្ឆ័យនីមួយៗទទួលបានទម្ងន់ឆ្លុះបញ្ចាំងពីសារៈសំខាន់របស់វា (ទាញយកពីអ្នកពាក់ព័ន្ធ ទម្ងន់បូកស្មើ 1) ជម្រើសនីមួយៗទទួលបានពិន្ទុធ្វើឱ្យប្រក្រតីក្នុងមួយលក្ខណៈវិនិច្ឆ័យ (ជាទូទៅ 0–1) ហើយពិន្ទុរួមគឺជាផលបូកថ្លឹងទម្ងន់ — រូបរាងគណិតវិទ្យាដូចគ្នានឹងបញ្ជីពិន្ទុជ្រើសរើសអ្នកលក់កម្មវិធី។

## ហេតុអ្វីបានជាសំខាន់

MCDA ត្រូវបានប្រើក្នុងក្របខ័ណ្ឌដូចជា EVIDEM និងដោយស្ថាប័ន HTA ខ្លះសម្រាប់ការវាយតម្លៃជំងឺកម្រ/ជំងឺ orphan ដែលវិធីសាស្ត្រកម្រិតកំណត់ថ្លៃដើមក្នុងមួយ QALY តឹងរ៉ឹងត្រូវបានចាត់ទុកថាតូចចង្អៀតពេកមិនអាចចាប់យកអ្វីៗទាំងអស់ដែលសំខាន់អំពីការសម្រេចចិត្ត។ ក្រុមការងារ ISPOR MCDA Emerging Good Practices បានបង្កើតការណែនាំអនុវត្តល្អសម្រាប់ការទាញយកទម្ងន់ និងពិន្ទុដោយអាចការពារបាន ពិតជាព្រោះការសម្រេចចិត្តដែលថ្លឹងទម្ងន់ដោយមិនផ្លូវការងាយសាងសង់ និងងាយលេងល្បិច។ នៅពេលបច្ចេកវិទ្យាសុខភាពមានវិមាត្រតម្លៃពិតប្រាកដដែល[កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់](../កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់/)តែមួយមិនអាចតំណាងបាន — ភាពធ្ងន់ធ្ងរ ការច្នៃប្រឌិត សមធម៌ — MCDA ផ្តល់ឱ្យអ្នកសម្រេចចិត្តនូវរចនាសម្ព័ន្ធច្បាស់លាស់ និងអាចសវនកម្មបានសម្រាប់ការបញ្ចូលគ្នា ជាជាងការវិនិច្ឆ័យមិនបានបញ្ជាក់។

## គណិតវិទ្យា

```
MCDA score = Σ_i (weight_i × score_i)

weights should sum to 1 (elicited via stakeholder methods such as swing
weighting or the Analytic Hierarchy Process)
```

## ឧទាហរណ៍ដែលបានគណនា

គណៈកម្មាធិការ HTA ដាក់ពិន្ទុការព្យាបាលឌីជីថលលើលក្ខណៈវិនិច្ឆ័យបួន៖

```
Criterion                          Weight   Score   Weight × Score
Clinical benefit                   0.4      0.8     0.32
Cost impact                        0.3      0.5     0.15
Disease severity / unmet need      0.2      0.9     0.18
Innovation                         0.1      0.6     0.06
                                    ─────                ─────
                                    1.0                  0.71
```

ទម្ងន់បូកស្មើ 1.0 (0.4 + 0.3 + 0.2 + 0.1) ហើយពិន្ទុ MCDA គឺ 0.71 (0.32 + 0.15 + 0.18 + 0.06)។ គណៈកម្មាធិការប្រៀបធៀប 0.71 នឹងកម្រិតកំណត់ដែលបានយល់ព្រមជាមុន ឬចាត់ចំណាត់ថ្នាក់ធៀបនឹងបច្ចេកវិទ្យាប្រកួតប្រជែងដែលបានដាក់ពិន្ទុដូចគ្នា។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

នេះគឺជាគណិតវិទ្យាដូចគ្នាបេះបិទនឹងបញ្ជីពិន្ទុជ្រើសរើសអ្នកលក់ថ្លឹងទម្ងន់ ម៉ាទ្រីសវាយតម្លៃ RFP ឬគំរូដាក់ពិន្ទុអាទិភាពមុខងារ — សូមមើល [សាងសង់ ធៀបនឹង ទិញ](../បង្កើត-ឬទិញ/) ករណីប្រើបញ្ជីពិន្ទុថ្លឹងទម្ងន់បុរាណក្នុងការទិញកម្មវិធី។ វាក៏គួរប្រៀបធៀបជាមួយ [WSJF និង CD3](../wsjf-និង-cd3/)៖ WSJF/CD3 គឺជាវិធីសាស្ត្រអាទិភាពផ្អែកលើ *សមាមាត្រ* (ថ្លៃដើមនៃការពន្យារចែកនឹងទំហំការងារ ឬរយៈពេល) ខណៈ MCDA ជា *ផលបូក* ថ្លឹងទម្ងន់។ MCDA និង WSJF/CD3 គឺជាចម្លើយខុសគ្នាខាងរចនាសម្ព័ន្ធពីរចំពោះ "តើយើងចាត់ចំណាត់ថ្នាក់ជម្រើសប្រកួតប្រជែងដូចម្តេច" ហើយការដឹងថាការសម្រេចចិត្តណាមួយត្រូវការមួយណា — តម្លៃបូកលើលក្ខណៈវិនិច្ឆ័យឯករាជ្យ ធៀបនឹងដង់ស៊ីតេតម្លៃក្នុងមួយឯកតាសមត្ថភាពខ្វះខាត — សំខាន់ជាងរូបមន្តណាមើលទៅតឹងរ៉ឹងជាង។

## កំហុសដែលត្រូវជៀសវាង

- **ភាពលំអៀងក្នុងការទាញយកទម្ងន់**: អ្នកកំណត់ទម្ងន់ជាក់ស្តែងកំណត់ចំណាត់ថ្នាក់ជាមុន ដូច្នេះ "រូបមន្ត" អាចលាងសម្អាតការសម្រេចចិត្តនយោបាយ ឬពាណិជ្ជកម្មឱ្យជាការគណនាគោលបំណង។ ចងក្រងឯកសារថាអ្នកណាកំណត់ទម្ងន់ និងដោយរបៀបណា។
- **ការរាប់ស្ទួនលក្ខណៈវិនិច្ឆ័យដែលបានចាប់យកក្នុងកន្លែងផ្សេងរួចហើយ**: ការដាក់ពិន្ទុ "ប្រសិទ្ធភាពថ្លៃដើម" ជាលក្ខណៈវិនិច្ឆ័យមួយ ខណៈ *ក៏* ដាក់ពិន្ទុ "ផលប៉ះពាល់ថ្លៃដើម" ដាច់ដោយឡែក ថ្លឹងទម្ងន់ប្រាក់លើសលក្ខណៈវិនិច្ឆ័យផ្សេងទៀតដោយគ្មានអ្នកណាចេតនា។
- **ភាពជាក់លាក់មិនពិត**: ពិន្ទុថ្លឹងទម្ងន់ពីរខ្ទង់ទសភាគ (0.71) បង្កប់ន័យភាពតឹងរ៉ឹងច្រើនជាងអ្វីដែលការវាយតម្លៃអ្នកពាក់ព័ន្ធ 0–10 ពិតប្រាកដគាំទ្រ ហើយភាពប្រែប្រួលរវាងអ្នកវាយតម្លៃក្នុងការវាយតម្លៃទាំងនោះជារឿយៗមិនត្រូវបានរាយការណ៍សោះ។
