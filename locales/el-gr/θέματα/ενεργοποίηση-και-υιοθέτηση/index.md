# Ενεργοποίηση και υιοθέτηση

Το ποσοστό ενεργοποίησης είναι το μερίδιο των χρηστών που εγγράφονται και φτάνουν στην πρώτη ουσιαστική αξία (η ενέργεια «aha» — πρώτη καταγραφή μέτρησης, πρώτο ολοκληρωμένο μάθημα). Η υιοθέτηση είναι η εκδοχή σε επίπεδο πληθυσμού: το μερίδιο του *επιλέξιμου* πληθυσμού που υιοθετεί καθόλου το προϊόν. Μαζί αποτελούν τις πρώτες πύλες του χωνιού αξίας: απόκτηση → υιοθέτηση → ενεργοποίηση → [διατήρηση](../διατήρηση-και-αποχώρηση/) → έκβαση.

## Γιατί έχει σημασία

Οι μη ενεργοποιημένοι χρήστες είναι καθαρό κόστος: δαπάνη απόκτησης, παροχή πόρων, επιφάνεια υποστήριξης — μηδενική κλινική αξία. Τα συγκριτικά στοιχεία δείχνουν ότι η ενεργοποίηση στο λογισμικό υγείας είναι *χαμηλότερη* από τον διαβιομηχανικό μέσο όρο (≈24% έναντι ≈37% για την ενεργοποίηση νέων χρηστών σε ένα σύνολο συγκριτικών στοιχείων SaaS· ολοκλήρωση λίστας ένταξης ~20%), λόγω βαρύτερης ένταξης (ταυτότητα, συναίνεση, κλινική ασφάλεια). Η υιοθέτηση φέρει το διακύβευμα σε επίπεδο πληθυσμού: στο [πλαίσιο RE-AIM](../προσέγγιση-και-ισότητα/), ο αντίκτυπος στη δημόσια υγεία ≈ προσέγγιση × αποτελεσματικότητα — μια εξαιρετική εφαρμογή που υιοθετείται από το 3% του επιλέξιμου πληθυσμού κινεί τον πληθυσμιακό δείκτη μόλις κατά 3%. Για τις συνταγογραφούμενες ψηφιακές θεραπευτικές παρεμβάσεις η πύλη της υιοθέτησης φαίνεται στα εθνικά δεδομένα: **~81% των συνταγών DiGA στη Γερμανία ενεργοποιείται** — μία στις πέντε συνταγογραφημένες και πληρωμένες θεραπείες δεν ξεκινά ποτέ (βλ. [DiGA fast-track](../η-ταχεία-διαδικασία-diga-της-γερμανίας/)).

## Τα μαθηματικά

```
Activation rate = users completing key action within window / sign-ups × 100
Uptake rate     = adopters / eligible population × 100
DTx fill rate   = activated prescription codes / issued prescriptions × 100

Funnel value model:
  eligible × uptake × activation × retention-weighted benefit = population value
  — four multiplications; improving the smallest factor usually
  dominates (theory-of-constraints for funnels)
```

## Αναλυτικό παράδειγμα

Ένας φορέας ανάθεσης προσφέρει μια εφαρμογή πρόληψης του διαβήτη σε 80.000 επιλέξιμους κατοίκους:

```
Invited → registered:  80,000 → 12,000  (uptake 15%)
Registered → activated (first session + goal set, 7 days): 12,000 → 5,400 (45%)
Activated → completed 6-month programme: 5,400 → 1,600 (30%)

Programme effect (trial, completers): 0.03 QALYs + £180 avoided costs
Population value = 1,600 × (0.03 × £20,000 + £180) ≈ £1.25M
Per-eligible-person value = £15.6 — versus £780 if every eligible person completed.

Where to invest? Doubling uptake (15→30%) doubles value; raising
activation 45→65% adds ~44%; both beat further polishing the programme
content the 1,600 already complete.
```

## Σύνδεση με τη μηχανική λογισμικού

Η ενεργοποίηση είναι το πιο προσιτό στη μηχανική στάδιο του χωνιού: η τριβή στην επαλήθευση ταυτότητας, οι ροές συναίνεσης, ο σχεδιασμός κενών καταστάσεων και ο χρόνος έως την πρώτη αξία είναι κώδικας, όχι πολιτική (ο διάμεσος χρόνος έως την αξία στην υγεία ≈ 1 ημέρα και 7 ώρες στα συγκριτικά δεδομένα — κάθε ώρα του είναι έκθεση σε απώλεια χρηστών). Η υιοθέτηση είναι πρόβλημα συστημάτων διανομής: ενσωμάτωση στις διαδρομές παραπομπής (η στιγμή της συνταγογράφησης), προσκλήσεις με την έγκριση του γενικού ιατρού (η εμπιστοσύνη μεταφέρεται) και προσβασιμότητα (γλώσσα, ψηφιακές δεξιότητες — βλ. [προσέγγιση και ισότητα](../προσέγγιση-και-ισότητα/)). Το παραπάνω μοντέλο αξίας του χωνιού παράγει την επιχειρηματική τεκμηρίωση και για τα δύο: πολλαπλασιάστε τους παράγοντες, εντοπίστε τον περιορισμό, τιμολογήστε τη διόρθωση έναντι της πληθυσμιακής αξίας που απελευθερώνει.

## Παγίδες

- **Ενεργοποίηση ορισμένη ως ευκολία** (επαληθευμένο email) αντί για κλινικό νόημα (πρώτη θεραπευτική ενέργεια) — φουσκώνει τον δείκτη και σπάει την αλυσίδα αξίας.
- **Παιχνίδια με τον παρονομαστή της υιοθέτησης**: «από όσους επισκέφθηκαν τον ιστότοπο» έναντι του πραγματικά επιλέξιμου πληθυσμού — οι φορείς ανάθεσης ενδιαφέρονται για το δεύτερο.
- **Φαινόμενα επιλογής**: οι χρήστες που ενεργοποιούνται εύκολα είναι οι λιγότερο άρρωστοι και οι λιγότερο στερημένοι· οι βελτιώσεις του χωνιού μπορούν να διευρύνουν τα χάσματα ισότητας ενώ βελτιώνουν τους μέσους όρους.
