# Αξιολόγηση κλινικού AI

Τα βασικά στατιστικά για την αξιολόγηση ενός κλινικού ή διαγνωστικού μοντέλου AI: ευαισθησία, ειδικότητα, AUROC, προγνωστικές αξίες και αριθμός προς έλεγχο (number needed to screen). Το κεντρικό οικονομικό δίδαγμα: **ένα εξαιρετικό AUROC δεν κάνει μια ανάπτυξη κόστος-αποτελεσματική** — η αξία εξαρτάται από το σημείο λειτουργίας, τη συχνότητα (prevalence) και τι συμβαίνει κατάντη κάθε θετικού αποτελέσματος.

## Γιατί έχει σημασία

Οι ρυθμιστικές αρχές (FDA, MHRA) εγκρίνουν το κλινικό AI σε **κλειδωμένο σημείο λειτουργίας** — ένα συγκεκριμένο ζεύγος ευαισθησίας/ειδικότητας (π.χ. το πρώτο εγκεκριμένο από τον FDA αυτόνομο σύστημα διαβητικής αμφιβληστροειδοπάθειας: ευαισθησία 87,2%, ειδικότητα 90,7% στην κρίσιμη δοκιμή του). Οι οικονομολόγοι υγείας ρωτούν τότε το ερώτημα που οι δείκτες ακρίβειας δεν μπορούν να απαντήσουν: στη συχνότητα του πληθυσμού ανάπτυξής σας, πόσο *κοστίζει* κάθε ανίχνευση και αξίζει η δράση βάσει αυτής; Μια οικονομική αξιολόγηση του AI προσυμπτωματικού ελέγχου αμφιβληστροειδοπάθειας (npj Digital Medicine 2024) έδειξε ότι η υψηλότερη ακρίβεια από μόνη της δεν εγγυόταν κόστος-αποτελεσματικότητα όταν υπολογίστηκαν τα κόστη παραπομπής.

## Τα μαθηματικά

```
Sensitivity = TP / (TP + FN)        — of the truly positive, share caught
Specificity = TN / (TN + FP)        — of the truly negative, share cleared
AUROC       = P(model ranks a random positive above a random negative)
              0.5 chance … 1.0 perfect; threshold-independent — and therefore
              deployment-decision-insufficient

PPV = TP / (TP + FP)   ← prevalence-dependent (Bayes); collapses when rare
NPV = TN / (TN + FN)

NNS  ≈ 1 / (prevalence × sensitivity)       — screened per true case found
Cost per true case = programme cost / TP      — the economic bottom line
```

## Αναλυτικό παράδειγμα

Το ίδιο μοντέλο, δύο περιβάλλοντα — ευαισθησία 90%, ειδικότητα 93%:

```
Specialist clinic (prevalence 20%):
  PPV = (0.9×0.2)/(0.9×0.2 + 0.07×0.8) = 0.18/0.236 ≈ 76%  → 3 in 4 alerts real

Primary care (prevalence 1%):
  PPV = (0.9×0.01)/(0.9×0.01 + 0.07×0.99) = 0.009/0.0783 ≈ 11.5%
  → 8 in 9 alerts false; workup at £350 each:
  cost per true case = (0.009 + 0.0693) × 350 / 0.009 ≈ £3,045 per case found
```

Ίδιο μοντέλο, ριζικά διαφορετική οικονομική — γι' αυτό η αξιολόγηση ανά χώρο είναι ρυθμιστικό θέμα και γι' αυτό το «το μοντέλο μας έχει 0,95 AUROC» είναι η αρχή μιας οικονομικής περίπτωσης, όχι το τέλος. Βλ. [οικονομική του προσυμπτωματικού ελέγχου](../οικονομία-προληπτικού-ελέγχου/) για τα πλήρη μαθηματικά προγράμματος.

## Σύνδεση με τη μηχανική λογισμικού

Για μηχανικούς που κατασκευάζουν ή αγοράζουν κλινικό AI: **παραδώστε τον πίνακα σύγχυσης στη συχνότητα ανάπτυξης**, όχι μόνο την καμπύλη ROC· **αφήστε το όριο να είναι οικονομική απόφαση** — ο συμβιβασμός ευαισθησίας/ειδικότητας πρέπει να ελαχιστοποιεί το αναμενόμενο κόστος (χαμένα περιστατικά × κόστος παράλειψης έναντι ψευδών συναγερμών × κόστος διερεύνησης), όχι να μεγιστοποιεί ένα στατιστικό συγκριτικής δοκιμής· και αναγνωρίστε τα ίδια μαθηματικά στα δικά σας εργαλεία — τα συστήματα ειδοποιήσεων, οι ανιχνευτές ανωμαλιών και οι σαρωτές ασφάλειας είναι διαγνωστικές εξετάσεις πάνω σε ροές συμβάντων χαμηλής συχνότητας, με την κόπωση ειδοποιήσεων ως [NNH](../αριθμός-προς-θεραπεία/). Οι ενημερώσεις μοντέλου που μετατοπίζουν το σημείο λειτουργίας ανοίγουν ξανά την οικονομική (και την ρυθμιστική έγκριση — βλ. [ρυθμιστική αξιολόγηση του AI](../ρυθμιστική-αξιολόγηση-του-ai/)).

## Παγίδες

- **Αγορά AUROC**: σύγκριση μοντέλων με AUROC ενώ θα τρέχουν σε ένα όριο — συγκρίνετε στο σημείο λειτουργίας.
- **PPV συχνότητας δοκιμής που παρατίθεται για ανάπτυξη στον πραγματικό κόσμο** — το κλασικό· υπολογίστε πάντα ξανά με την τοπική συχνότητα.
- **Μεροληψία φάσματος**: μοντέλα που επικυρώθηκαν σε προφανή περιστατικά έναντι υγιών μαρτύρων αποδίδουν υπερβολικά καλά στη διφορούμενη μέση που κυριαρχεί στην πράξη.
- **Καμία κοστολόγηση της κατάντη διαδρομής**: κάθε θετικό πυροδοτεί διερεύνηση· ένα μοντέλο είναι παρέμβαση στην οικονομική *ολόκληρης της διαδρομής*.
