# ເສດຖະສາດການຄັດກອງ

ເສດຖະສາດການຄັດກອງຄວບຄຸມມູນຄ່າຂອງການທົດສອບປະຊາກອນທີ່ບໍ່ມີອາການ. ຂໍ້ເທັດຈິງທາງຄະນິດສາດຫຼັກ: **ທີ່ຄວາມຊຸກຊຸມຂອງພະຍາດຕ່ຳ, ແມ້ແຕ່ການທົດສອບທີ່ດີເລີດກໍສ້າງຜົນບວກປອມເປັນສ່ວນໃຫຍ່** — ແລະ ຕົ້ນທຶນຕໍ່ເນື່ອງຂອງການໄລ່ຕາມພວກມັນສາມາດຖ້ວມປະໂຫຍດຂອງການພົບຈິງ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ນັບແຕ່ປີ 1968, ເກນ Wilson–Jungner ຂອງ WHO ກຳນົດມາດຕະຖານສຳລັບການຄັດກອງປະຊາກອນ: ສະພາບຕ້ອງສຳຄັນ, ການທົດສອບຕ້ອງຍອມຮັບໄດ້ ແລະ ຖືກຕ້ອງ, ຕ້ອງມີການຮັກສາທີ່ມີປະສິດທິຜົນ, ແລະ ເສດຖະສາດຕ້ອງດຸ່ນດ່ຽງ. ຄະນະກຳມະການຄັດກອງແຫ່ງຊາດຂອງສະຫະລາຊະອານາຈັກນຳໃຊ້ການວິເຄາະຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນແບບທາງການກ່ອນອະນຸມັດໂຄງການແຫ່ງຊາດ — ແລະ ປະຕິເສດຂໍ້ສະເໜີສ່ວນໃຫຍ່. ທຸກການນຳສະເໜີ "AI ຈະຄັດກອງທຸກຄົນສຳລັບທຸກຢ່າງ" ຕຳກັບກົນໄກນີ້, ແລະ ປົກກະຕິແພ້ໃຫ້ເລກຄະນິດຂ້າງລຸ່ມ.

## ຄະນິດສາດ

ຄ່າທຳນາຍບວກ (PPV) — ຄວາມນ່າຈະເປັນທີ່ຜົນບວກເປັນຈິງ — ລົ້ມລົງທີ່ຄວາມຊຸກຊຸມຕ່ຳ:

```
PPV = (sens × prev) / [sens × prev + (1 − spec) × (1 − prev)]

Example: sensitivity 90%, specificity 95%, prevalence 0.5%:
PPV = (0.9 × 0.005) / (0.9 × 0.005 + 0.05 × 0.995)
    = 0.0045 / (0.0045 + 0.04975) ≈ 8.3%
```

ສິບເອັດຈາກສິບສອງຜົນບວກແມ່ນປອມ. ເສດຖະສາດໂຄງການເຕັມ:

```
Cost per true case found = (screening cost + workup cost × all positives) / true positives
Then: is finding a case worth that? (earlier-intervention value per case,
      minus overdiagnosis harm — cases found that would never have mattered)
```

## ຕົວຢ່າງການຄິດໄລ່

ການຄັດກອງຈໍແສງຕາດ້ວຍ AI ສຳລັບສະພາບຫາຍາກ, 100,000 ຄົນ, ຄວາມຊຸກຊຸມ 0.5%, sens 90%, spec 95%, ສະແກນ £15, ການກວດຢືນຢັນ £400:

```
True positives:  100,000 × 0.005 × 0.90 = 450
False positives: 100,000 × 0.995 × 0.05 = 4,975
Cost = 100,000 × 15 + (450 + 4,975) × 400 = 1.5M + 2.17M = £3.67M
Cost per true case ≈ £8,156
```

ຖ້າການຮັກສາແຕ່ເນີ່ນໆປະຢັດ £20,000 + 1 QALY ຕໍ່ກໍລະນີ, ໂຄງການຜ່ານງ່າຍ. ເພີ່ມຄວາມຈຳເພາະເປັນ 99% (ສັນຍານເຕືອນປອມໜ້ອຍລົງ): ຕົ້ນທຶນການກວດຢືນຢັນຫຼຸດເປັນ (450 + 995) × 400 = £0.58M, ລວມ £2.08M, ຕົ້ນທຶນຕໍ່ກໍລະນີ ≈ **£4,622** — ຄວາມຈຳເພາະ, ບໍ່ແມ່ນຄວາມໄວ, ແມ່ນບ່ອນທີ່ເສດຖະສາດການຄັດກອງຊະນະທີ່ຄວາມຊຸກຊຸມຕ່ຳ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ການວິເຄາະສະຖິດ, ການສະແກນຄວາມປອດໄພ ແລະ ການກວດຈັບຄວາມຜິດປົກກະຕິແມ່ນໂຄງການຄັດກອງເທິງໂຄ້ດເບດ ແລະ telemetry, ດ້ວຍຄວາມຊຸກຊຸມຂໍ້ບົກພ່ອງແທ້ມັກຕ່ຳກວ່າ 1% ຫຼາຍຕໍ່ໂອກາດແຈ້ງເຕືອນ. ເລກຄະນິດດຽວກັນອະທິບາຍຄວາມເມື່ອຍລ້າຈາກການແຈ້ງເຕືອນ: ເຄື່ອງສະແກນທີ່ຈຳເພາະ 95% ເທິງໂຄ້ດທີ່ມີຄວາມຊຸກຊຸມຕ່ຳຈົມທີມໃນຜົນບວກປອມ, ແລະ ທຸກຜົນບວກປອມໃຊ້ຄວາມສົນໃຈ ແລະ ກັດກ່ອນຄວາມໄວ້ວາງໃຈຈົນການແຈ້ງເຕືອນຈິງຖືກເມີນ (ສັບທາງຄລີນິກແມ່ນ *ອັນຕະລາຍຈາກການຄັດກອງ*; ສັບວິສະວະກຳແມ່ນ *ຄວາມຊາຂອງ pager*). ວິທີແກ້ຖືກໂອນຈາກສຸຂະພາບ: ເພີ່ມຄວາມຈຳເພາະກ່ອນຄວາມໄວ, ຄັດກອງກຸ່ມຍ່ອຍທີ່ມີຄວາມຊຸກຊຸມສູງກວ່າ (ການເປົ້າໝາຍຕາມຄວາມສ່ຽງ ↔ ສະແກນສະເພາະໂຄ້ດທີ່ປ່ຽນ), ແລະ ນັບຕົ້ນທຶນການຄັດແຍກໃນເສດຖະສາດຂອງເຄື່ອງມື — ເບິ່ງ [NNT](../ຈຳນວນທີ່ຕ້ອງຮັກສາ/) ແລະ [ການປະເມີນ AI ທາງຄລີນິກ](../ການປະເມີນ-ai-ທາງຄລີນິກ/). ສຳລັບການກຳນົດຂະໜາດໂຄງການຄັດກອງທັງໝົດແທນການທົດສອບດຽວ, ເບິ່ງ [ຈຳນວນທີ່ຕ້ອງຄັດກອງ](../ຈຳນວນທີ່ຕ້ອງຄັດກອງ/) — ຈຳນວນຄົນທີ່ຕ້ອງຜ່ານເສັ້ນທາງຄັດກອງແລ້ວຮັກສາທັງໝົດເພື່ອປ້ອງກັນໜຶ່ງຜົນລັບ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ອ້າງ sensitivity/specificity ໂດຍບໍ່ມີຄວາມຊຸກຊຸມ** — ຄວາມຖືກຕ້ອງໂດຍບໍ່ມີ PPV ແມ່ນການຕະຫຼາດ.
- **ເມີນເສີຍການວິນິດໄສເກີນ**: ການພົບ "ພະຍາດ" ທີ່ເຕີບໂຕຊ້າທີ່ຈະບໍ່ເຄີຍເປັນອັນຕະລາຍກະຕຸ້ນຕົ້ນທຶນ ແລະ ອັນຕະລາຍການຮັກສາຈິງ.
- **ອະຄະຕິເວລານຳ (lead-time)**: ການກວດພົບແຕ່ເນີ່ນໆໂດຍບໍ່ປ່ຽນຜົນລັບເຮັດໃຫ້ການລອດຊີວິດທີ່ປາກົດພອງຕົວ — ເບິ່ງ [ການແຊກແຊງແຕ່ເນີ່ນໆ](../ການແຊກແຊງແຕ່ເນີ່ນໆ/).
