# ການຫຼຸດມູນຄ່າ ແລະ ຄວາມມັກດ້ານເວລາ

ການຫຼຸດມູນຄ່າ (discounting) ແປງຕົ້ນທຶນແລະຜົນປະໂຫຍດໃນອະນາຄົດເປັນມູນຄ່າປັດຈຸບັນ ເພາະຜົນປະໂຫຍດໃນມື້ນີ້ມີຄ່າຫຼາຍກວ່າຜົນປະໂຫຍດດຽວກັນໃນຫ້າປີຂ້າງໜ້າ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ທຸກການປະເມີນເສດຖະສາດສຸຂະພາບ ແລະ ທຸກກໍລະນີທຸລະກິດຂອງພາກລັດທີ່ຈິງຈັງຫຼຸດມູນຄ່າກະແສຫຼາຍປີ. Green Book ຂອງ HM Treasury ອັງກິດບັງຄັບອັດຕາຄວາມມັກດ້ານເວລາຂອງສັງຄົມ 3.5% ຕໍ່ປີ; ກໍລະນີອ້າງອີງຂອງ NICE ຫຼຸດມູນຄ່າທັງຕົ້ນທຶນແລະຜົນທາງສຸຂະພາບທີ່ 3.5% ຕໍ່ປີ (ດ້ວຍອັດຕາ 1.5% ທີ່ບໍ່ແມ່ນກໍລະນີອ້າງອີງສຳລັບການປິ່ນປົວທີ່ເກືອບຫາຍຂາດທີ່ມີຜົນປະໂຫຍດ 30+ ປີ). ຖ້າກໍລະນີທຸລະກິດຊອບແວຂອງທ່ານອ້າງ "ປະຢັດ £5 ລ້ານໃນ 10 ປີ" ຜູ້ທົບທວນການເງິນຈະຖາມຕົວເລກທີ່ຫຼຸດມູນຄ່າທັນທີ.

## ຄະນິດສາດ

ມູນຄ່າປັດຈຸບັນຂອງຈຳນວນໃນອະນາຄົດ:

```
PV = FV / (1 + r)^t

PV = present value
FV = future value in year t
r  = discount rate (NICE/Green Book: 0.035)
t  = years from now
```

ສຳລັບຜົນປະໂຫຍດປະຈຳປີຄົງທີ່ B ໃນ n ປີ (ເງິນງວດ):

```
PV = B × [1 − (1 + r)^(−n)] / r
```

## ຕົວຢ່າງການຄິດໄລ່

ຊອບແວຂອງທ່ານປະຢັດໂຮງໝໍ NHS trust £100,000 ຕໍ່ປີ ເປັນເວລາ 5 ປີ ເລີ່ມໜຶ່ງປີຫຼັງເປີດໃຊ້.

ຍອດລວມທີ່ບໍ່ຫຼຸດມູນຄ່າ: £500,000.

ຫຼຸດມູນຄ່າທີ່ 3.5%:

```
Year 1: 100,000 / 1.035^1 = £96,618
Year 2: 100,000 / 1.035^2 = £93,351
Year 3: 100,000 / 1.035^3 = £90,194
Year 4: 100,000 / 1.035^4 = £87,144
Year 5: 100,000 / 1.035^5 = £84,197

Total PV ≈ £451,505
```

ຫົວຂໍ້ທີ່ຊື່ສັດແມ່ນປະມານ £451,000 ໜ້ອຍກວ່າຜົນລວມແບບງ່າຍໆປະມານ 10%. ສົມມຸດວ່າການສົ່ງມອບເລື່ອນໜຶ່ງປີ: ທຸກພົດເລື່ອນຊ້າລົງໜຶ່ງປີ ແລະ PV ຫຼຸດເປັນປະມານ £436,000 — ມຸມມອງການຫຼຸດມູນຄ່າຂອງ[ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ](../ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ/).

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

- **ການຊຳລະໜີ້ທາງເຕັກນິກ ແລະ ການຍ້າຍແພລດຟອມ** ສັນຍາກະແສຜົນປະໂຫຍດຫຼາຍປີຂ້າງໜ້າ; ຫຼຸດມູນຄ່າກ່ອນປຽບທຽບກັບງານທີ່ຄືນທຶນໃນໄຕມາດນີ້.
- **ຕົ້ນທຶນຢູ່ໜ້າ, ຜົນປະໂຫຍດຢູ່ຫຼັງ** ແມ່ນຮູບຮ່າງມາດຕະຖານຂອງການຍ້າຍລະບົບ. ການຫຼຸດມູນຄ່າລົງໂທດຮູບຮ່າງນັ້ນຢ່າງຖືກຕ້ອງ: ມັນຕີລາຄາມູນຄ່າເວລາທີ່ປາສະຈາກຄວາມສ່ຽງຂອງການຜູກມັດຄວາມສາມາດຕອນນີ້ເພື່ອຄຸນຄ່າໃນພາຍຫຼັງ.
- **ຂໍ້ອ້າງ "ປະຢັດໃນປີທີ 5"** ສົມຄວນຖືກສົງໄສສອງເທື່ອ — ທັງຖືກຫຼຸດມູນຄ່າຫຼາຍ ແລະ ບໍ່ແນ່ນອນສູງ (ເບິ່ງ[ການວິເຄາະຄວາມອ່ອນໄຫວ](../ການວິເຄາະຄວາມອ່ອນໄຫວ/)).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຫຼຸດມູນຄ່າຕົ້ນທຶນແຕ່ບໍ່ຫຼຸດຜົນປະໂຫຍດ** (ຫຼື ກົງກັນຂ້າມ) — ກໍລະນີອ້າງອີງຫຼຸດມູນຄ່າທັງສອງດ້ວຍອັດຕາດຽວກັນ.
- **ໃຊ້ອັດຕາການຄ້າ (8–12%) ໃນກໍລະນີພາກລັດ** ຫຼື 3.5% ໃນກໍລະນີທີ່ມີທຶນສ່ຽງ. ໃຫ້ອັດຕາກົງກັບຜູ້ຕັດສິນໃຈ.
- **ສັບສົນການຫຼຸດມູນຄ່າກັບເງິນເຟີ້.** ການຫຼຸດມູນຄ່າໃຊ້ກັບມູນຄ່າ*ແທ້ຈິງ* (ປັບເງິນເຟີ້ແລ້ວ); ຢ່າເຮັດທັງສອງແບບແອບແຝງ.
