# ມູນຄ່າທີ່ຄາດໄວ້ຂອງຂໍ້ມູນສົມບູນແບບ (EVPI)

EVPI ແມ່ນຈຳນວນສູງສຸດທີ່ຜູ້ຕັດສິນໃຈຄວນຈ່າຍເພື່ອກຳຈັດຄວາມບໍ່ແນ່ນອນກ່ອນຕັດສິນໃຈ — ລາຄາທາງການຂອງ "ເຮົາມາເຮັດການສຶກສາກ່ອນ."

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ລະບົບສຸຂະພາບປະເຊີນທາງເລືອກຢູ່ສະເໝີ: ນຳໃຊ້ຕອນນີ້ດ້ວຍຫຼັກຖານທີ່ບໍ່ສົມບູນ ຫຼື ໃຫ້ທຶນການຄົ້ນຄວ້າເພີ່ມກ່ອນ. EVPI ໃສ່ຕົວເລກໃຫ້ທາງເລືອກທີສອງ. ຖ້າ EVPI ແມ່ນ £50,000 ແລະ ການທົດລອງທີ່ສະເໜີມີຕົ້ນທຶນ £2 ລ້ານ ໃຫ້ນຳໃຊ້ເລີຍ. ຖ້າ EVPI ແມ່ນ £20 ລ້ານ ການທົດລອງແມ່ນຂໍ້ຕໍ່ລອງ. ຄຳຖາມດຽວກັນ — "ເຮົາຄວນທົດລອງສິ່ງນີ້ກ່ອນເປີດໃຊ້ບໍ?" — ເກີດຂຶ້ນກັບທຸກການຕັດສິນໃຈເຄື່ອງມືວິສາຫະກິດ ແລະ ເກືອບບໍ່ມີໃຜຕີລາຄາມັນ. ສຳລັບການຕີລາຄາທາງເລືອກໃນການຂະຫຍາຍໂຄງການໃນພາຍຫຼັງ ແທນທີ່ຈະເປັນທາງເລືອກໃນການເກັບຂໍ້ມູນກ່ອນ ເບິ່ງ[ການປະເມີນມູນຄ່າທາງເລືອກຕົວຈິງ](../ການປະເມີນມູນຄ່າຕົວເລືອກຈິງ/).

## ຄະນິດສາດ

EVPI ແມ່ນຊ່ອງຫວ່າງລະຫວ່າງການຕັດສິນໃຈດ້ວຍການຫຍັບໄກທີ່ສົມບູນ ກັບການຕັດສິນໃຈຕອນນີ້ຕາມຄ່າຄາດໄວ້:

```
EVPI = E_θ[ max_j NMB(j, θ) ]  −  max_j E_θ[ NMB(j, θ) ]

θ        = uncertain parameters (with their joint distribution)
NMB(j,θ) = net monetary benefit of option j given θ
```

ພົດທຳອິດ: ຄ່າສະເລ່ຍຂອງຜົນຕອບແທນຂອງທາງເລືອກທີ່ດີທີ່ສຸດຂ້າມແຕ່ລະໂລກທີ່ເປັນໄປໄດ້ (ທ່ານເລືອກຖືກສະເໝີ). ພົດທີສອງ: ຜົນຕອບແທນຂອງທາງເລືອກດຽວທີ່ດີທີ່ສຸດໂດຍສະເລ່ຍ (ທ່ານຕ້ອງຜູກມັດຕອນນີ້). EVPI ≥ 0 ສະເໝີ. EVPI ລະດັບປະຊາກອນຄູນດ້ວຍຈຳນວນການຕັດສິນໃຈທີ່ໄດ້ຮັບຜົນກະທົບ. ຄິດໄລ່ໂດຍກົງຈາກການສຸ່ມຂອງ[PSA](../ການວິເຄາະຄວາມອ່ອນໄຫວແບບຄວາມນ່າຈະເປັນ/).

## ຕົວຢ່າງການຄິດໄລ່

ເປີດໃຊ້ຜູ້ຊ່ວຍບັນທຶກເອກະສານດ້ວຍ AI ໃຫ້ແພດ 5,000 ຄົນ ຫຼື ບໍ່. ສອງໂລກ:

```
World A (p = 0.6): assistant saves 20 min/day → NMB of rollout = +£8M
World B (p = 0.4): assistant saves ~0 (workflow friction) → NMB of rollout = −£3M
NMB of "don't roll out" = £0 in both worlds.
```

ຕັດສິນຕອນນີ້: E[NMB ເປີດໃຊ້] = 0.6 × 8 − 0.4 × 3 = **+£3.6M** → ເປີດໃຊ້.

ດ້ວຍຂໍ້ມູນສົມບູນ: ໃນໂລກ A ເລືອກເປີດໃຊ້ (+£8M), ໃນໂລກ B ເລືອກບໍ່ເຮັດຫຍັງ (£0). ມູນຄ່າທີ່ຄາດໄວ້ = 0.6 × 8 + 0.4 × 0 = **£4.8M**.

```
EVPI = 4.8M − 3.6M = £1.2M
```

ການທົດລອງ 3 ເດືອນທີ່ເຄັ່ງຄັດ ມີຕົ້ນທຶນ £150,000 ທີ່ແກ້ໄດ້ຢ່າງສຳຄັນວ່າເຮົາຢູ່ໂລກໃດ ຄຸ້ມຄ່າແນ່ນອນ — ແລະ ການທົດລອງໃດທີ່ມີຕົ້ນທຶນເກີນ £1.2M ບໍ່ຄຸ້ມ ບໍ່ວ່າຈະລະອຽດປານໃດ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

EVPI ແມ່ນເສດຖະສາດຂອງ spike, ການທົດລອງ, A/B test, ແລະ proof-of-concept. ມັນໃຫ້ສອງກົດທີ່ປະຕິບັດໄດ້:

- **ການທົດລອງຄຸ້ມຄ່າທີ່ຈະໃຫ້ທຶນສະເພາະເມື່ອການຕັດສິນໃຈສາມາດປ່ຽນໄດ້ແທ້.** ຖ້າທ່ານຈະເປີດໃຊ້ບໍ່ວ່າຜົນທົດລອງຈະເປັນແນວໃດ EVPI = 0 ແລະ ການທົດລອງເປັນລະຄອນ.
- **ຈຳກັດລາຍຈ່າຍການທົດລອງທີ່ EVPI.** ມູນຄ່າຂອງຂໍ້ມູນຖືກຈຳກັດດ້ວຍມູນຄ່າຂອງການຕັດສິນໃຈທີ່ມັນໃຫ້ຂໍ້ມູນ.

EVPI ບາງສ່ວນ (EVPPI) ຂະຫຍາຍນີ້ໄປຫາພາຣາມິເຕີດຽວ: "ການກຳນົດຕົວເລກເວລາທີ່ປະຢັດໃຫ້ແນ່ນອນມີຄ່າເທົ່າໃດ?" — ເຊິ່ງບອກວ່າການທົດລອງຄວນວັດຫຍັງ. ສຳລັບການຕີລາຄາການສຶກສາທີ່ສະເໜີ*ສະເພາະ* ແທນການກຳຈັດຄວາມບໍ່ແນ່ນອນທັງໝົດ ເບິ່ງ[EVSI](../ມູນຄ່າທີ່ຄາດໄວ້ຂອງຂໍ້ມູນຕົວຢ່າງ/).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ດຳເນີນການທົດລອງໂດຍບໍ່ມີກົດການຕັດສິນໃຈ** — ຂໍ້ມູນທີ່ປ່ຽນການເລືອກບໍ່ໄດ້ບໍ່ມີຄ່າໂດຍນິຍາມ.
- **ລະເລີຍຕົ້ນທຶນຄວາມລ່າຊ້າຂອງການເກັບຂໍ້ມູນ**: ການທົດລອງ 6 ເດືອນຊັກຊ້າຜົນປະໂຫຍດ 6 ເດືອນ ([ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ](../ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ/)); ມູນຄ່າສຸດທິຂອງການທົດລອງ = EVPI ທີ່ແກ້ໄດ້ − ຕົ້ນທຶນຄວາມລ່າຊ້າ − ຕົ້ນທຶນການທົດລອງ.
- **ຖື EVPI ເປັນການພະຍາກອນ.** ມັນແມ່ນຂອບເຂດເທິງຂອງມູນຄ່າຂໍ້ມູນ ບໍ່ແມ່ນການຄາດຄະເນສິ່ງທີ່ການສຶກສາສະເພາະຈະສົ່ງມອບ.
