# ການປຽບທຽບ ICER ຂ້າມສະກຸນເງິນ

ການປຽບທຽບ [ICER](../ອັດຕາສ່ວນຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນສ່ວນເພີ່ມ/) ທີ່ຄິດໄລ່ເປັນສະກຸນເງິນຂອງປະເທດໜຶ່ງ ກັບ[ເກນຄວາມເຕັມໃຈຈ່າຍ](../ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ/)ຂອງອີກປະເທດໜຶ່ງ — ຫຼື ການລວມຂໍ້ມູນຕົ້ນທຶນທີ່ເກັບຂ້າມການທົດລອງຫຼາຍຊາດ — ຕ້ອງການຂັ້ນຕອນການແປງສະກຸນເງິນທີ່ຊັດເຈນແລະກວດສອບໄດ້. ຖ້າວິທີການແປງຜິດ ຫຼັກຖານພື້ນຖານດຽວກັນກໍສາມາດພິກການຕັດສິນໃຈນຳໃຊ້ໄດ້ ທັງທີ່ຂໍ້ມູນທາງຄລີນິກຫຼືຕົ້ນທຶນບໍ່ປ່ຽນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຄຳແນະນຳວິທີການຂອງ ISPOR ສຳລັບການທົດລອງທາງຄລີນິກຫຼາຍຊາດ (Willke et al., *Health Economics*, 1998) ແນະນຳການແປງຕົ້ນທຶນຊັບພະຍາກອນດ້ວຍ**ຄວາມສະເໝີພາບດ້ານກຳລັງຊື້ (PPP)** — ບໍ່ແມ່ນອັດຕາແລກປ່ຽນຕະຫຼາດ — ເມື່ອປຽບທຽບມູນຄ່າເສດຖະກິດທີ່ແທ້ຈິງຂອງຊັບພະຍາກອນຂ້າມປະເທດ, ແລະ ສະຫງວນອັດຕາແລກປ່ຽນຕະຫຼາດໄວ້ສຳລັບຈຸດປະສົງຂອງມັນ: ການສ້າງແບບຈຳລອງກະແສການຈ່າຍເງິນສົດຂ້າມແດນຈິງ. ການສັບສົນສອງຢ່າງນີ້ແມ່ນໜຶ່ງໃນຂໍ້ຜິດພາດວິທີການ HTA ຫຼາຍຊາດທີ່ພົບເລື້ອຍທີ່ສຸດ ເພາະທັງສອງເບິ່ງຄື "ອັດຕາແລກປ່ຽນ" ສຳລັບຄົນທີ່ບໍ່ໄດ້ອ່ານຄຳແນະນຳ ແລະ ສະເປຣດຊີດບໍ່ຢຸດທ່ານຈາກການເຮັດຜິດ.

## ຄະນິດສາດ

```
icer_in_local_currency = convert(icer_in_source_currency, conversion_factor)

conversion_factor should be:
  PPP conversion factor  — for comparing real economic value of resources
                            across countries (ISPOR-recommended for
                            multinational CEA)
  market FX rate         — only for actual cross-border cash payments

adopt if icer_in_local_currency < local_threshold
```

ກົດການຕັດສິນໃຈເອງແມ່ນ[ກົດເກນ ICER](../ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ/)ທຳມະດາ — `adopt if ICER < λ` — ຄຳຖາມວິທີການທີ່ຫົວຂໍ້ນີ້ແກ້ແມ່ນກ່ຽວກັບ*ປັດໄຈແປງ*ໃດທີ່ສ້າງຕົວເລກ `icer_in_local_currency` ທີ່ກົດນັ້ນນຳໃຊ້ທັງໝົດ.

## ຕົວຢ່າງການຄິດໄລ່

ICER ຂອງຢາຈາກການທົດລອງສະຫະລັດແມ່ນ $45,000/QALY. ປະເທດນຳເຂົ້າສົມມຸດຕັ້ງເກນປະກອບຂອງຕົນທີ່ £34,000/QALY (ຕົວເລກສະເພາະປະເທດສົມມຸດສຳລັບຕົວຢ່າງນີ້ເທົ່ານັ້ນ — ເກນຈິງແຕກຕ່າງຕາມປະເທດ ແລະ ປ່ຽນຕາມເວລາ ແລະ ຕ້ອງມີແຫຼ່ງແລະວັນທີສະເໝີ).

**ໃຊ້ປັດໄຈແປງ PPP 0.72** (ປະກອບ, ສຳລັບຕົວຢ່າງນີ້ເທົ່ານັ້ນ): $45,000 × 0.72 = £32,400/QALY. £32,400 < £34,000 → **ນຳໃຊ້**.

**ໃຊ້ອັດຕາແລກປ່ຽນຕະຫຼາດ 0.79** ແທນ (ປະກອບ): $45,000 × 0.79 = £35,550/QALY. £35,550 > £34,000 → **ປະຕິເສດ**.

ICER $45,000/QALY ດຽວກັນໃຫ້ການຕັດສິນນຳໃຊ້ພາຍໃຕ້ການແປງ PPP ແລະ ການຕັດສິນປະຕິເສດພາຍໃຕ້ການແປງອັດຕາຕະຫຼາດ. ນີ້ແມ່ນຕົວຢ່າງທີ່ຊັດເຈນວ່າເປັນຫຍັງຄຳແນະນຳ ISPOR ຖືການເລືອກປັດໄຈແປງເປັນເລື່ອງສຳຄັນທາງວິທີການ — ບໍ່ແມ່ນລາຍລະອຽດການປັດເສດ ແລະ ບໍ່ແມ່ນສິ່ງທີ່ປະໃຫ້ແອບແຝງຢູ່ໃນສູດສະເປຣດຊີດທີ່ບໍ່ມີໃຜກວດຄືນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ນີ້ແມ່ນກະຈົກເສດຖະສາດສຸຂະພາບຂອງໂດເມນວິສະວະກຳທີ່ຮູ້ຈັກດີ: ຄວາມຖືກຕ້ອງຂອງການກຳນົດລາຄາຫຼາຍສະກຸນເງິນ i18n/l10n ໃນຊອບແວການຄ້າ ບ່ອນທີ່ໜ້າລາຄາ SaaS ຕ້ອງບໍ່ປຽບທຽບຈຳນວນ `$` ກັບລາຄາ `£` ແບບງຽບໆ. ການຮັບປະກັນລະດັບປະເພດທີ່ປະເພດ `Money` ທີ່ສ້າງດີໃຫ້ — ເມທອດປຽບທຽບທີ່ປະຕິເສດການປຽບທຽບສະກຸນເງິນທີ່ບໍ່ກົງກັນ ບັງຄັບຂັ້ນຕອນການແປງທີ່ຊັດເຈນກ່ອນ — ແມ່ນຄູ່ຂະໜານດ້ານວິສະວະກຳຊອບແວໂດຍກົງຂອງຈຸດວິທີການເສດຖະສາດສຸຂະພາບນີ້: ຢ່າປຽບທຽບຕົວເລກທີ່ບໍ່ໄດ້ແປງຂ້າມສະກຸນເງິນ, ແລະ ຢ່າປ່ອຍໃຫ້ຂັ້ນຕອນການແປງແອບແຝງ ຫຼື ບໍ່ມີເອກະສານ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ປຽບທຽບຈຳນວນຕ່າງສະກຸນເງິນແບບງຽບໆ**: ວຽກ HTA ໃນສະເປຣດຊີດແບບ ad hoc ທີ່ລົບ ຫຼື ປຽບທຽບຕົວເລກໂດລາກັບຕົວເລກປອນໂດຍບໍ່ມີຂັ້ນຕອນແປງກ່ອນ — ຊັ້ນບັກທີ່ປະເພດ `Money` ທີ່ຮັບຮູ້ສະກຸນເງິນຈິງຈັບໄດ້ໂດຍການສ້າງ ແທນທີ່ຈະປະເປັນຂໍ້ຜິດພາດງຽບໆ.
- **ສັບສົນອັດຕາແລກປ່ຽນຕະຫຼາດກັບ PPP**: ຂໍ້ຜິດພາດວິທີການ HTA ຫຼາຍຊາດທີ່ພົບທົ່ວໄປທີ່ສຸດຕາມຄຳແນະນຳ ISPOR — ສອງຕົວເລກອາດແຕກຕ່າງຫຼາຍແລະຕອບຄຳຖາມຕ່າງກັນ (ມູນຄ່າເສດຖະກິດທີ່ແທ້ຈິງ vs ກະແສເງິນສົດຈິງ).
- **ບໍ່ລະບຸວັນທີຂອງອັດຕາແລກປ່ຽນ ຫຼື ດັດຊະນີ PPP ທີ່ໃຊ້**: ທັງສອງເຄື່ອນໄຫວຕາມເວລາ ດັ່ງນັ້ນປັດໄຈແປງໃດໆທີ່ອ້າງຕ້ອງລະບຸວັນທີແບບດຽວກັບທີ່ຄັງນີ້ລະບຸວັນທີຕົວເລກເກນທຽບອື່ນ (ຄ່າຄາບອນຂອງ Green Book, ມູນຄ່າຂອງການເສຍຊີວິດທີ່ປ້ອງກັນ, ແລະ ອື່ນໆ).
