# ການວິເຄາະຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ (CEA)

CEA ປຽບທຽບຕົ້ນທຶນຂອງການແຊກແຊງທາງເລືອກຕ່າງໆກັບຜົນລັບດຽວທີ່ວັດເປັນ**ຫົວໜ່ວຍທຳມະຊາດ** — ປີຊີວິດ, ກໍລະນີທີ່ກວດພົບ, ການຮັບເຂົ້າທີ່ຫຼີກລ່ຽງ, mmHg ຂອງຄວາມດັນເລືອດທີ່ຫຼຸດ. ຜົນຜະລິດແມ່ນຕົ້ນທຶນຕໍ່ຫົວໜ່ວຍຜົນລັບ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

CEA ແມ່ນການປຽບທຽບຫຼັກເມື່ອທຸກທາງເລືອກມຸ່ງໄປຜົນລັບດຽວກັນ. ມັນຕອບ "ວິທີໃດໃນບັນດາວິທີບັນລຸ X ເຫຼົ່ານີ້ແມ່ນການໃຊ້ເງິນທີ່ດີທີ່ສຸດ?" — ແຕ່*ບໍ່*ຕອບ "X ຄຸ້ມຄ່າທີ່ຈະບັນລຸເລີຍບໍ?" (ນັ້ນຕ້ອງໃຊ້[ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດ](../ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດ/)) ແລະ*ບໍ່*ຕອບ "X ປຽບທຽບກັບບູລິມະສິດທີ່ບໍ່ກ່ຽວຂ້ອງໄດ້ແນວໃດ?" (ນັ້ນຕ້ອງໃຊ້[ການວິເຄາະຕົ້ນທຶນ-ອຣະຖະປະໂຫຍດ](../ການວິເຄາະຕົ້ນທຶນ-ອຣະຖະປະໂຫຍດ/) ແລະ ຜົນລັບທົ່ວໄປເຊັ່ນ QALY).

## ຄະນິດສາດ

ສະຖິຕິປຽບທຽບແມ່ນ[ICER](../ອັດຕາສ່ວນຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນສ່ວນເພີ່ມ/)ໃນຫົວໜ່ວຍທຳມະຊາດ:

```
ICER = (Cost_A − Cost_B) / (Effect_A − Effect_B)
     = £ per additional case detected / admission avoided / etc.
```

ຂັ້ນຕອນ: ກຳນົດຫົວໜ່ວຍຜົນລັບ; ຄິດຕົ້ນທຶນທຸກທາງເລືອກຈາກ[ມຸມມອງ](../ມຸມມອງຂອງການວິເຄາະ/)ດຽວກັນໃນ[ຂອບເຂດເວລາ](../ຂອບເຂດເວລາ/)ດຽວກັນ; ຕັດທາງເລືອກທີ່ຖືກເໜືອກວ່າອອກ ([ຂອບເຂດປະສິດທິພາບ](../ຄວາມເໜືອກວ່າ-ແລະ-ຂອບເຂດປະສິດທິພາບ/)); ຄິດໄລ່ອັດຕາສ່ວນສ່ວນເພີ່ມຕາມຂອບເຂດ.

## ຕົວຢ່າງການຄິດໄລ່

ສາມວິທີຫາໂຣກຫົວໃຈເຕັ້ນຜິດຈັງຫວະ (atrial fibrillation) ທີ່ຍັງບໍ່ໄດ້ວິນິດໄສໃນປະຊາກອນ 100,000 ຄົນ:

```
Option                    Cost        Cases found
Opportunistic pulse checks £150,000       300
Pharmacy screening events  £400,000       520
Wearable-based screening   £900,000       610

ICER pharmacy vs pulse:  (400k−150k)/(520−300) = £1,136 per additional case
ICER wearable vs pharmacy:(900k−400k)/(610−520) = £5,556 per additional case
```

ວ່າ £5,556 ຕໍ່ກໍລະນີເພີ່ມ "ຄຸ້ມຄ່າ" ຫຼືບໍ່ ຂຶ້ນກັບຄຸນຄ່າຂອງກໍລະນີທີ່ພົບ (ການປ້ອງກັນເສັ້ນເລືອດໃນສະໝອງຕໍ່ເນື່ອງ) — CEA ຈັດອັນດັບທາງເລືອກ ແຕ່ການຕັດສິນໃຈນຳໃຊ້ຕ້ອງການການຕີມູນຄ່າພາຍນອກນັ້ນ. ໃຫ້ສັງເກດວ່າຕົ້ນທຶນ*ສະເລ່ຍ*ຕໍ່ກໍລະນີຂອງທາງເລືອກອຸປະກອນສວມໃສ່ (900k/610 = £1,475) ເບິ່ງດີ; £5,556 *ສ່ວນເພີ່ມ*ແມ່ນຕົວເລກທີ່ຊື່ສັດສຳລັບການຕັດສິນໃຈຂະຫຍາຍ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

CEA ແມ່ນແມ່ແບບທີ່ຖືກຕ້ອງເມື່ອທາງເລືອກມີຜົນລັບດຽວກັນ: ຕົ້ນທຶນຕໍ່ flaky test ທີ່ກຳຈັດໄດ້ຂ້າມສາມວິທີແກ້ໄຂ; ຕົ້ນທຶນຕໍ່ເຫດການທີ່ຫຼີກລ່ຽງຂ້າມຜູ້ຂາຍ observability; ຕົ້ນທຶນຕໍ່ການນຳໃຊ້ທີ່ສຳເລັດຂ້າມສະຖາປັດຕະຍະກຳ CI. ລະບຽບວິໄນທີ່ມັນບັງຄັບ — ຫົວໜ່ວຍຜົນລັບດຽວທີ່ປະກາດ, ອັດຕາສ່ວນສ່ວນເພີ່ມ (ບໍ່ແມ່ນສະເລ່ຍ), ກຳຈັດທາງເລືອກທີ່ຖືກເໜືອກວ່າກ່ອນ — ຂ້າການປຽບທຽບຜູ້ຂາຍທີ່ບໍ່ດີສ່ວນໃຫຍ່ກ່ອນການສົນທະນາລາຄາເລີ່ມ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ປຽບທຽບທາງເລືອກທີ່ມີຜົນລັບຕ່າງກັນ** ("ກໍລະນີທີ່ພົບ" ທຽບກັບ "ຄວາມພໍໃຈ") ໃນ CEA ດຽວ — ນັ້ນຕ້ອງໃຊ້[ການວິເຄາະຕົ້ນທຶນ-ຜົນທີ່ຕາມມາ](../ການວິເຄາະຕົ້ນທຶນ-ຜົນທີ່ຕາມມາ/) ຫຼື ຜົນລັບທົ່ວໄປ.
- **ອັດຕາສ່ວນຄວາມຄຸ້ມຄ່າສະເລ່ຍ** ທີ່ນຳສະເໜີບ່ອນທີ່ຕ້ອງການສ່ວນເພີ່ມ (ຕົວຢ່າງອຸປະກອນສວມໃສ່ຂ້າງເທິງ).
- **ຫົວໜ່ວຍຜົນລັບທີ່ເລືອກເພື່ອຄວາມງາມ**: "ການແຈ້ງເຕືອນທີ່ສ້າງ" ເປັນຜົນຜະລິດ ບໍ່ແມ່ນຜົນລັບ; ຢືນຢັນຫົວໜ່ວຍທີ່ມີຄຸນຄ່າ.
