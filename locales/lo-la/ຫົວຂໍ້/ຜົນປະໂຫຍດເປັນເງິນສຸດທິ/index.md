# ຜົນປະໂຫຍດເປັນເງິນສຸດທິ (NMB)

NMB ແປງຜົນຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນເປັນມູນຄ່າເງິນດຽວ: ຜົນໄດ້ຮັບດ້ານສຸຂະພາບທີ່ຕັ້ງລາຄາຕາມເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ ລົບດ້ວຍຕົ້ນທຶນ. ຄູ່ແຝດຂອງມັນ, ຜົນປະໂຫຍດດ້ານສຸຂະພາບສຸດທິ (NHB), ສະແດງກົດດຽວກັນເປັນຫົວໜ່ວຍສຸຂະພາບ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ອັດຕາສ່ວນ ([ICER](../ອັດຕາສ່ວນຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນສ່ວນເພີ່ມ/)) ໃຊ້ຍາກ: ມັນລະເບີດໃກ້ຜົນເປັນສູນ, ເອົາຄ່າສະເລ່ຍຂ້າມການສຸ່ມຕົວຢ່າງຄວາມບໍ່ແນ່ນອນບໍ່ໄດ້, ແລະ ຈັດອັນດັບສາມທາງເລືອກຂຶ້ນໄປຢ່າງສະອາດບໍ່ໄດ້. NMB ແກ້ທັງໝົດນັ້ນ — ມັນເປັນເສັ້ນຊື່, ຈຶ່ງຈັດອັນດັບທາງເລືອກ, ເອົາຄ່າສະເລ່ຍການສຸ່ມ Monte Carlo, ແລະ ແຍກສ່ວນປະກອບໄດ້. ມັນຍັງເປັນຮູບແບບຂອງເລກເສດຖະສາດສຸຂະພາບທີ່ວິສະວະກອນທຸກຄົນຮູ້ແລ້ວ: *ມູນຄ່າລົບຕົ້ນທຶນ*.

## ຄະນິດສາດ

```
NMB = (ΔE × λ) − ΔC
NHB = ΔE − (ΔC / λ)

ΔE = incremental effect (e.g., QALYs)
ΔC = incremental cost
λ  = willingness-to-pay threshold (see willingness-to-pay-thresholds.md)

Decision rule: adopt if NMB > 0 (equivalently NHB > 0).
Among alternatives: choose the highest NMB.
```

NMB > 0 ⇔ ICER < λ (ເມື່ອ ΔE > 0), ສອງກົດຈຶ່ງລົງຮອຍກັນ — NMB ພຽງແຕ່ມີພຶດຕິກຳດີກວ່າ.

## ຕົວຢ່າງການຄິດໄລ່

ສາມທາງເລືອກສຳລັບບໍລິການເບົາຫວານ, ຕໍ່ຜູ້ປ່ວຍ 1,000 ຄົນ, λ = £20,000/QALY:

```
Option           ΔC          ΔE (QALYs)   NMB = 20,000×ΔE − ΔC
App + coaching   £400,000    30           600,000 − 400,000 = £200,000
App only         £150,000    12           240,000 − 150,000 = £90,000
Extra clinics    £700,000    32           640,000 − 700,000 = −£60,000
```

ຄລີນິກເພີ່ມໄດ້ QALY ຫຼາຍທີ່ສຸດ ແຕ່ທຳລາຍມູນຄ່າທີ່ເກນນີ້ (NMB < 0). ແອັບ + ການໂຄສ໌ຊະນະ. ສັງເກດວ່າ NMB ໃຫ້ *ຈັດອັນດັບທັງສາມພ້ອມກັນ* — ICER ແບບຄູ່ຕ້ອງໃຊ້ຂັ້ນຕອນຂອບເຂດໃນ [ຄວາມເໜືອກວ່າ ແລະ ຂອບເຂດປະສິດທິພາບ](../ຄວາມເໜືອກວ່າ-ແລະ-ຂອບເຂດປະສິດທິພາບ/), ແລະ ໄດ້ຄຳຕອບດຽວກັນ.

ມຸມມອງ NHB ຂອງຜູ້ຊະນະ: 30 − 400,000/20,000 = 30 − 20 = **ສຸດທິ 10 QALY** — ສຸຂະພາບທີ່ໄດ້ເກີນກວ່າທີ່ເງິນຈຳນວນດຽວກັນຈະສ້າງຢູ່ບ່ອນອື່ນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

`(hours saved × loaded hourly rate) − tool cost` — business case ເຄື່ອງມືປະຈຳວັນ — ແມ່ນການຄິດໄລ່ NMB ແທ້ໆ ດ້ວຍ λ = ຕົ້ນທຶນເຕັມຂອງວິສະວະກອນ. ສອງການຍົກລະດັບທີ່ເສດຖະສາດສຸຂະພາບເພີ່ມ:

- **ເຮັດໃຫ້ λ ເປັນຕົວແປ, ບໍ່ແມ່ນຄ່າຄົງທີ່.** ພລັອດ NMB ທຽບກັບ λ ("ມູນຄ່າຂອງຊົ່ວໂມງວິສະວະກອນ") ແລະ ສະແດງວ່າການຕັດສິນໃຈພິກຢູ່ໃສ; ຜູ້ມີສ່ວນຮ່ວມແຕ່ລະຄົນຈຶ່ງໃຊ້ການປະເມີນຂອງຕົນເອງໄດ້ໂດຍບໍ່ຕ້ອງຄິດໄລ່ຄືນ.
- **ການຄິດແບບ NHB**: "ແພລດຟອມນີ້ປະຢັດ 5,000 ຊົ່ວໂມງວິສະວະກອນ ແຕ່ໃຊ້ງົບທີ່ຈະຊື້ຄວາມຈຸຜູ້ຮັບເໝົາ 3,000 ຊົ່ວໂມງ — ສຸດທິ 2,000 ຊົ່ວໂມງ" ບັງຄັບການປຽບທຽບຕົ້ນທຶນຄວາມເສຍໂອກາດເປັນຫົວໜ່ວຍຄວາມຈຸ. ເບິ່ງ [ຕົ້ນທຶນຄວາມເສຍໂອກາດ](../ຕົ້ນທຶນຄວາມເສຍໂອກາດ/).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ເຊື່ອງເກນ**: NMB ບໍ່ມີຄວາມໝາຍຖ້າບໍ່ລະບຸ λ; ລາຍງານ NMB ທີ່ £20k ແລະ £30k, ຫຼື ພລັອດເສັ້ນໂຄ້ງ.
- **ໃຊ້ NMB ຟອກຜົນນ້ອຍໆ**: ປະຊາກອນໃຫຍ່ຄູນຜົນຕໍ່ຄົນທີ່ນ້ອຍຫຼາຍສາມາດໃຫ້ NMB ໃຫຍ່ — ລາຍງານຜົນຕໍ່ຄົນຄຽງຄູ່.
- **ລືມວ່າ NMB ສືບທອດທຸກຄວາມບໍ່ແນ່ນອນ** ໃນ ΔC ແລະ ΔE — ຈັບຄູ່ກັບ [ການວິເຄາະຄວາມອ່ອນໄຫວແບບຄວາມນ່າຈະເປັນ](../ການວິເຄາະຄວາມອ່ອນໄຫວແບບຄວາມນ່າຈະເປັນ/).
