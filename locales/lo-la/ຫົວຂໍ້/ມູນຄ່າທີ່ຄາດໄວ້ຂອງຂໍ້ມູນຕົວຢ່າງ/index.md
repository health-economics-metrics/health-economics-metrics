# ມູນຄ່າທີ່ຄາດໄວ້ຂອງຂໍ້ມູນຕົວຢ່າງ (EVSI)

EVSI ແມ່ນມູນຄ່າຂອງ*ການສຶກສາທີ່ສະເໜີສະເພາະ* — ການອອກແບບໜຶ່ງ, ຂະໜາດຕົວຢ່າງໜຶ່ງ — ກ່ອນທີ່ມັນຈະຖືກດຳເນີນ ກົງກັນຂ້າມກັບ[EVPI](../ມູນຄ່າທີ່ຄາດໄວ້ຂອງຂໍ້ມູນສົມບູນແບບ/) ທີ່ຕີລາຄາການກຳຈັດຄວາມບໍ່ແນ່ນອນທັງໝົດ. EVSI ຕອບຄຳຖາມທີ່ຜູ້ໃຫ້ທຶນການຄົ້ນຄວ້າປະເຊີນຈິງ: "ການທົດລອງ*ນີ້* ທີ່ຂະໜາດ*ນີ້* ຄຸ້ມຄ່າກັບຕົ້ນທຶນຂອງມັນບໍ?"

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

EVPI ບອກເພດານຂອງສິ່ງທີ່ການຄົ້ນຄວ້າໃດໆອາດມີຄ່າ; ມັນບໍ່ບອກວ່າການທົດລອງທີ່ຢູ່ຕໍ່ໜ້າທ່ານຜ່ານເກນຫຼືບໍ່. ຜູ້ໃຫ້ທຶນການຄົ້ນຄວ້າແຫ່ງຊາດທີ່ເລືອກລະຫວ່າງການທົດລອງນຳຮ່ອງ 50 ຄົນເຈັບ ແລະ ການທົດລອງສຸດທ້າຍ 500 ຄົນເຈັບ ຕ້ອງຮູ້ວ່າ*ແຕ່ລະການອອກແບບສະເພາະ*ມີຄ່າເທົ່າໃດ ບໍ່ແມ່ນພຽງມູນຄ່າຂອງການຮູ້ທຸກຢ່າງ. EVSI ສະໜອງຕົວເລກນັ້ນ ແລະ ເພາະມັນຂະຫຍາຍຕາມຂະໜາດຕົວຢ່າງ ມັນຊ່ວຍໃຫ້ຜູ້ໃຫ້ທຶນຫາຂະໜາດຕົວຢ່າງທີ່ເພີ່ມຜົນປະໂຫຍດສຸດທິທີ່ຄາດໄວ້ໃຫ້ສູງສຸດ ແທນທີ່ຈະເດົາ.

ນີ້ຍັງເປັນເຫດຜົນທີ່ EVSI ນ້ອຍກວ່າຫຼືເທົ່າ EVPI ສະເໝີ: ຕົວຢ່າງຈຳກັດແກ້ຄວາມບໍ່ແນ່ນອນໄດ້ບາງສ່ວນ ແລະ ການສຶກສາທີ່ເບິ່ງຄືມີຄ່າເກີນຂໍ້ມູນສົມບູນແບບແມ່ນສັນຍານວ່າການຄິດໄລ່ຜິດ ບໍ່ແມ່ນຜົນຈິງ.

## ຄະນິດສາດ

```
General:
EVSI(n) = E_data[ max_d E_θ|data[NB(d,θ)] ]  −  max_d E_θ[NB(d,θ)]
  (nested expectation: outer over possible study results, inner over the
  posterior belief about θ after seeing that result — usually estimated by
  nested Monte Carlo / Bayesian updating over probabilistic sensitivity
  analysis draws)

Closed-form normal approximation (single uncertain parameter, conjugate
normal-normal model — a standard shortcut, not exact for every model):
EVSI(n) = EVPI × n / (n + n0)

n  = proposed study's sample size
n0 = "prior-equivalent sample size" — the size of an imaginary sample that
     would carry the same information as the current prior, derived from
     the ratio of data variance to prior variance
ENBS(n) = EVSI(n) − Cost(n)
Population EVSI = per-decision EVSI × decisions affected
```

ຮູບແບບທົ່ວໄປແມ່ນຄ່າຄາດໄວ້ຊ້ອນກັນ ເພາະຜົນໃນອະນາຄົດຂອງການສຶກສາເອງບໍ່ແນ່ນອນ: ທ່ານຕ້ອງສະເລ່ຍຂ້າມທຸກຊຸດຂໍ້ມູນທີ່ການສຶກສາອາດສ້າງ ແລະ ສຳລັບແຕ່ລະອັນຄິດໄລ່ການຕັດສິນໃຈທີ່ດີທີ່ສຸດໃໝ່ທີ່ໃຫ້ຄວາມເຊື່ອທີ່ອັບເດດ (posterior). ການປະມານປົກກະຕິແບບປິດແລກຕົ້ນທຶນການຄຳນວນນັ້ນເປັນອັດຕາສ່ວນດຽວ ໃຊ້ໄດ້ເມື່ອພາຣາມິເຕີທີ່ບໍ່ແນ່ນອນແລະຂໍ້ມູນ (ໂດຍປະມານ) ເປັນປົກກະຕິແລະ conjugate — ຄວາມສະດວກ ບໍ່ແມ່ນກົດສາກົນ. Monte Carlo ຊ້ອນເຕັມຮູບແມ່ນວິທີທົ່ວໄປເມື່ອສົມມຸດຕິຖານນັ້ນບໍ່ຖືກ. ເບິ່ງ[ການວິເຄາະຄວາມອ່ອນໄຫວແບບຄວາມນ່າຈະເປັນ](../ການວິເຄາະຄວາມອ່ອນໄຫວແບບຄວາມນ່າຈະເປັນ/) ສຳລັບການສຸ່ມ PSA ທີ່ EVSI ມັກຖືກຄາດຄະເນຈາກ.

## ຕົວຢ່າງການຄິດໄລ່

ຕໍ່ຍອດຈາກຕົວຢ່າງ[EVPI](../ມູນຄ່າທີ່ຄາດໄວ້ຂອງຂໍ້ມູນສົມບູນແບບ/) — ການເປີດໃຊ້ຜູ້ຊ່ວຍບັນທຶກເອກະສານດ້ວຍ AI ໃຫ້ແພດ 5,000 ຄົນ ທີ່ EVPI ພົບວ່າ £1.2M — ສະແດງ EVPI ດຽວກັນເປັນປອນເຕັມ: **EVPI = £1,200,000**.

ການສຶກສານຳຮ່ອງທີ່ສະເໜີກັບແພດ 50 ຄົນຢູ່ເທິງໂຕະ. ຈາກອັດຕາສ່ວນຂອງຄວາມແປຜັນຂອງຄວາມເຊື່ອກ່ອນຕໍ່ຄວາມແມ່ນຍຳຂອງການວັດຂອງການນຳຮ່ອງ ຂະໜາດຕົວຢ່າງທຽບເທົ່າກ່ອນແມ່ນ `n0 = 75`:

```
EVSI(50) = 1,200,000 × 50 / (50 + 75)
         = 1,200,000 × 50 / 125
         = 1,200,000 × 0.4
         = £480,000
```

ການນຳຮ່ອງມີຕົ້ນທຶນ £120,000:

```
ENBS = EVSI − Cost = 480,000 − 120,000 = £360,000
```

ENBS ເປັນບວກຢ່າງຊັດເຈນ: ໃຫ້ທຶນການນຳຮ່ອງ. ຖ້າການຕັດສິນໃຈຈັດຊື້ດຽວກັນເກີດຂຶ້ນຊ້ຳໃນ 3 ໂຮງໝໍ trust ພາກພື້ນທີ່ຄ້າຍກັນ ມູນຄ່າຂອງການນຳຮ່ອງຂະຫຍາຍ:

```
Population EVSI = 480,000 × 3 = £1,440,000
```

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

EVSI ແມ່ນເສດຖະສາດຂອງການເລືອກ*ຂະໜາດ*ຂອງການນຳຮ່ອງ ຫຼື A/B test ບໍ່ແມ່ນພຽງວ່າຈະເຮັດຫຼືບໍ່:

- **ການຕັດສິນໃຈຂະໜາດຕົວຢ່າງເປັນການລົງທຶນ.** beta 50 ຜູ້ໃຊ້ ແລະ ການເປີດໃຊ້ເປັນຂັ້ນ 5,000 ຜູ້ໃຊ້ແມ່ນ "ການສຶກສາ" ທີ່ແຕກຕ່າງກັນ ດ້ວຍ EVSI ແລະ ຕົ້ນທຶນຕ່າງກັນ — EVSI ຊ່ວຍໃຫ້ປຽບທຽບໃນພື້ນຖານດຽວກັນ ແທນການຕັ້ງຄ່າເລີ່ມຕົ້ນເປັນ "ຂໍ້ມູນຫຼາຍກວ່າດີກວ່າສະເໝີ."
- **ENBS ບໍ່ແມ່ນ EVSI ພຽງຢ່າງດຽວຄືການທົດສອບການມອບໝາຍ.** ການສຶກສາທີ່ມີ EVSI ສູງແຕ່ຕົ້ນທຶນກິນສ່ວນໃຫຍ່ຂອງມັນແມ່ນຂໍ້ສະເໜີທີ່ອ່ອນ; ກົດການຕັດສິນໃຈແມ່ນຜົນປະໂຫຍດສຸດທິທີ່ຄາດໄວ້ຂອງການເກັບຕົວຢ່າງ ຄືກັບທີ່ກໍລະນີທຸລະກິດຫັກຜົນປະໂຫຍດກັບຕົ້ນທຶນ ແທນທີ່ຈະລາຍງານຜົນປະໂຫຍດຢ່າງດຽວ.
- **ຜົນຕອບແທນຫຼຸດລົງຊັດເຈນ.** ເພາະ EVSI(n) ເພີ່ມຕາມ `n/(n+n0)` ການເພີ່ມຂະໜາດການນຳຮ່ອງເປັນສອງເທົ່າບໍ່ເຄີຍເພີ່ມມູນຄ່າສອງເທົ່າ — ສະບັບທາງການຂອງສະຕິສະຫຼຸດດ້ານວິສະວະກຳວ່າການທົດລອງໃຫຍ່ຂຶ້ນມີມູນຄ່າຂໍ້ມູນສ່ວນເພີ່ມຫຼຸດລົງ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ໃຊ້ການປະມານປົກກະຕິນອກສົມມຸດຕິຖານຂອງມັນ.** ມັນໃຊ້ໄດ້ສະເພາະຄວາມບໍ່ແນ່ນອນພາຣາມິເຕີດຽວທີ່ເກືອບ conjugate; ແບບຈຳລອງການຕັດສິນໃຈທີ່ບໍ່ເປັນເສັ້ນຫຼືຫຼາຍພາຣາມິເຕີຕ້ອງການ Monte Carlo ຊ້ອນເຕັມຮູບ ບໍ່ແມ່ນທາງລັດນີ້.
- **ປຽບທຽບ EVSI ກັບຕົ້ນທຶນເງິນສົດຢ່າງດຽວ.** EVSI ຕ້ອງຖືກຊັ່ງທຽບກັບຕົ້ນທຶນ*ເຕັມ*ຂອງການສຶກສາ ລວມຕົ້ນທຶນຄວາມລ່າຊ້າໃນການຕັດສິນໃຈຂອງມັນເອງ — ເບິ່ງ[ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ](../ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ/) — ບໍ່ແມ່ນພຽງໃບແຈ້ງໜີ້ຂອງການສຶກສາ.
- **ຖື EVSI > EVPI ເປັນຜົນຄົ້ນພົບຈິງ.** EVSI ບໍ່ສາມາດເກີນ EVPI ໄດ້ໂດຍການສ້າງ; ການຄິດໄລ່ທີ່ໄດ້ຜົນດັ່ງກ່າວແມ່ນບັກຂອງການສ້າງແບບຈຳລອງ ບໍ່ແມ່ນການຄົ້ນພົບ.
