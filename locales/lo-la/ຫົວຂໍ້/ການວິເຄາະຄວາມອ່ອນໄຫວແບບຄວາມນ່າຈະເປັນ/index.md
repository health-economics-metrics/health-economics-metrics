# ການວິເຄາະຄວາມອ່ອນໄຫວແບບຄວາມນ່າຈະເປັນ (PSA)

PSA ກຳນົດການແຈກຢາຍຄວາມນ່າຈະເປັນໃຫ້ທຸກພາຣາມິເຕີທີ່ບໍ່ແນ່ນອນ, ສຸ່ມທັງໝົດພ້ອມກັນຫຼາຍພັນຄັ້ງ (Monte Carlo), ແລະ ລາຍງານ *ຄວາມນ່າຈະເປັນ* ທີ່ທາງເລືອກໜຶ່ງເປັນທາງເລືອກທີ່ດີທີ່ສຸດ — ແທນຄ່າຈຸດດຽວ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

reference case ຂອງ NICE *ຕ້ອງການ* PSA. ການວິເຄາະແບບກຳນົດຕອບ "ຈະເປັນແນວໃດຖ້າຂໍ້ມູນເຂົ້າອັນໜຶ່ງຜິດ?"; PSA ຕອບ "ເມື່ອພິຈາລະນາທຸກສິ່ງທີ່ເຮົາບໍ່ຮູ້ພ້ອມກັນ, ເຮົາມີໂອກາດເທົ່າໃດທີ່ຕັດສິນໃຈຖືກ?" ຜົນອອກລາຍເຊັນຂອງມັນ, **ເສັ້ນໂຄ້ງການຍອມຮັບຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ (CEAC)**, ພລັອດຄວາມນ່າຈະເປັນທີ່ທາງເລືອກຄຸ້ມຄ່າດ້ານຕົ້ນທຶນທຽບກັບເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ — ປ່ຽນ "ICER ແມ່ນ £24,000/QALY" ເປັນ "ມີໂອກາດ 78% ທີ່ນີ້ແມ່ນທາງເລືອກທີ່ຖືກຕ້ອງທີ່ £30,000/QALY."

## ຄະນິດສາດ

```
For each of N draws (N ≈ 10,000):
  sample every parameter θ from its distribution
    (costs ~ Gamma, probabilities ~ Beta, utilities ~ Beta, effects ~ Normal/logNormal)
  compute NMB_j(θ) = λ × Effect_j(θ) − Cost_j(θ) for each option j

CEAC_j(λ) = fraction of draws in which option j has the highest NMB at threshold λ
```

ເບິ່ງ [ຜົນປະໂຫຍດເປັນເງິນສຸດທິ](../ຜົນປະໂຫຍດເປັນເງິນສຸດທິ/) ສຳລັບ NMB ແລະ [ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ](../ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ/) ສຳລັບ λ.

## ຕົວຢ່າງການຄິດໄລ່

business case ການຍ້າຍແພລດຟອມ. ສາມຂໍ້ມູນເຂົ້າທີ່ບໍ່ແນ່ນອນ:

```
Migration cost      ~ Gamma,  mean £800k, sd £200k
Annual benefit      ~ Normal, mean £350k, sd £150k
Benefit duration    ~ Uniform, 3–6 years
```

ສຳລັບແຕ່ລະ 10,000 ການສຸ່ມ ຄິດໄລ່ຜົນປະໂຫຍດສຸດທິ = ໄລຍະ × ລາຍປີ − ຕົ້ນທຶນ (ຕັດການຫຼຸດມູນຄ່າອອກເພື່ອຄວາມຊັດເຈນ). ຜົນຕົວຢ່າງ:

```
Mean net benefit:      £775k
Probability net > 0:   0.86
5th–95th percentile:  −£180k … +£1.9M
```

ຄ່າຈຸດເວົ້າວ່າ "ແນ່ນອນວ່າແມ່ນ." PSA ເວົ້າວ່າ "86% ແມ່ນ, ມີຫາງຈິງທີ່ເຮົາສູນເສຍ £180k+" — ເຊິ່ງເປັນສິ່ງທີ່ເຈົ້າຂອງພອດໂຟລິໂອຕ້ອງການຈິງ, ແລະ ມັນຕັ້ງລາຄາກໍລະນີສຳລັບການຣັນ discovery spike ກ່ອນ (ເບິ່ງ [EVPI](../ມູນຄ່າທີ່ຄາດໄວ້ຂອງຂໍ້ມູນສົມບູນແບບ/)).

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ວິສະວະກອນເຊື່ອ Monte Carlo ສຳລັບການພະຍາກອນການສົ່ງມອບແລ້ວ (ການສຸ່ມ throughput ດີກວ່າຄ່າຈຸດ). ຂະຫຍາຍກົນໄກດຽວກັນໄປຫາເງິນ: ການແຈກຢາຍໃນການຮັບເອົາ, ເວລາທີ່ປະຢັດ ແລະ ເງິນເດືອນ, ແລ້ວລາຍງານ "ຄວາມນ່າຈະເປັນທີ່ການລົງທຶນແພລດຟອມນີ້ເປັນບວກສຸດທິ" ແທນ ROI ທີ່ແມ່ນຍຳປອມ. ເສັ້ນໂຄ້ງແບບ CEAC — ຄວາມນ່າຈະເປັນຂອງການເປັນທາງເລືອກທີ່ດີທີ່ສຸດເປັນຟັງຊັນຂອງວິທີທີ່ອົງກອນປະເມີນຊົ່ວໂມງວິສະວະກອນ — ເປັນຜົນງານທີ່ດີກວ່າແທ້ສຳລັບຄະນະກຳມະການທຶນກວ່າຕົວເລກດຽວໃດໆ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການແຈກຢາຍຂີ້ເຫຍື້ອ**: PSA ທີ່ມີຄ່າບ່ຽງເບນມາດຕະຖານປະດິດແມ່ນການວິເຄາະແບບກຳນົດທີ່ໃສ່ເສື້ອກາວຫ້ອງທົດລອງ. ອີງການກະຈາຍຕາມຂໍ້ມູນ ຫຼື ການດຶງຄວາມຄິດເຫັນຜູ້ຊ່ຽວຊານທີ່ມີໂຄງສ້າງ.
- **ເມີນເສີຍສະຫະສຳພັນ** ລະຫວ່າງພາຣາມິເຕີ (ການຮັບເອົາສູງມັກສຳພັນກັບເວລາທີ່ປະຢັດສູງ); ການສຸ່ມເອກະລາດຄາດຄວາມສ່ຽງຫາງຕ່ຳເກີນໄປ.
- **ລາຍງານສະເພາະຄ່າສະເລ່ຍ** ຂອງການຈຳລອງ — ຈຸດປະສົງທັງໝົດແມ່ນການແຈກຢາຍ ແລະ ຄວາມນ່າຈະເປັນຂອງການຕັດສິນໃຈ.
