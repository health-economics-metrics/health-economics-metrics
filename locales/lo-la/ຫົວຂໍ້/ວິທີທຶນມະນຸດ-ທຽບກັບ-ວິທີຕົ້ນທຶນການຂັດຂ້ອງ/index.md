# ວິທີທຶນມະນຸດ ທຽບກັບ ວິທີຕົ້ນທຶນການຂັດຂ້ອງ

ສອງວິທີທີ່ແຂ່ງຂັນກັນໃນການປະເມີນມູນຄ່າຜະລິດຕະພາບທີ່ສູນເສຍ — ຈາກການເຈັບປ່ວຍ, ຄວາມພິການ ຫຼື ການເສຍຊີວິດ — ໃນການສຶກສາຕົ້ນທຶນຂອງພະຍາດ ແລະ ຕົ້ນທຶນ-ຜົນປະໂຫຍດ. ວິທີທຶນມະນຸດ (HCA) ປະເມີນຜົນຜະລິດທີ່ສູນເສຍທັງໝົດຕະຫຼອດໄລຍະຂາດງານດ້ວຍອັດຕາຄ່າຈ້າງ; ວິທີຕົ້ນທຶນການຂັດຂ້ອງ (FCM) ປະເມີນມັນສະເພາະໄລຍະເວລາທີ່ສັ້ນກວ່າທີ່ນາຍຈ້າງຕ້ອງການເພື່ອຟື້ນຟູການຜະລິດ. ການເລືອກລະຫວ່າງສອງວິທີນີ້ປ່ຽນການຄາດຄະເນຕົ້ນທຶນທາງອ້ອມໄດ້ສອງເທົ່າ ຫຼືຫຼາຍກວ່າ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຕົ້ນທຶນທາງອ້ອມ (ຜະລິດຕະພາບ) ແມ່ນລາຍການທີ່ຖົກຖຽງກັນຫຼາຍທີ່ສຸດໃນເສດຖະສາດສຸຂະພາບ ກໍຍ້ອນສອງວິທີມາດຕະຖານບໍ່ລົງຮອຍກັນຢ່າງຮຸນແຮງ. HCA ຖືວ່າທຸກວັນຂາດງານແມ່ນວັນຜົນຜະລິດທີ່ເສດຖະກິດສູນເສຍແທ້ ໂດຍປະເມີນດ້ວຍຄ່າຈ້າງເຕັມຕະຫຼອດໄລຍະ — ຫຼື ສຳລັບການເສຍຊີວິດ ຫຼື ຄວາມພິການຖາວອນ, ຕະຫຼອດອາຍຸການເຮັດວຽກທີ່ເຫຼືອ. FCM ໂຕ້ແຍ້ງວ່າໃນເສດຖະກິດທີ່ມີການຫວ່າງງານ ແລະ ຕະຫຼາດແຮງງານຫຼວມ, ການຂາດງານສ່ວນໃຫຍ່ບໍ່ໄດ້ຫຼຸດຜົນຜະລິດລວມຂອງຊາດຈິງ ເມື່ອນາຍຈ້າງໄດ້ຝຶກຄົນແທນ ຫຼື ແບ່ງງານໃໝ່; ມີແຕ່ "ໄລຍະການຂັດຂ້ອງ" — ເວລາເພື່ອຟື້ນຟູການຜະລິດໃຫ້ກັບຄືນລະດັບເດີມ — ທີ່ເປັນຄວາມສູນເສຍແທ້. FCM ຈຶ່ງໃຫ້ການຄາດຄະເນຕົ້ນທຶນທາງອ້ອມທີ່ຕ່ຳກວ່າ ແລະ ລະມັດລະວັງກວ່າ HCA ຢ່າງເປັນລະບົບ, ແລະ ສອງວິທີບໍ່ແມ່ນໝາຍເຫດທີ່ແລກປ່ຽນກັນໄດ້: ມັນແມ່ນທິດສະດີເສດຖະກິດທີ່ແຕກຕ່າງກັນກ່ຽວກັບຄວາມໝາຍຂອງ "ຜະລິດຕະພາບທີ່ສູນເສຍ". ນີ້ກໍເປັນເຫດຜົນທີ່ [reference case ຂອງ NICE](../ການປະເມີນເຕັກໂນໂລຢີສຸຂະພາບ/) ຍົກເວັ້ນຕົ້ນທຶນຜະລິດຕະພາບເປັນຄ່າເລີ່ມຕົ້ນ, ລາຍງານມັນ (ຖ້າລາຍງານ) ເປັນການວິເຄາະຄວາມອ່ອນໄຫວແຍກຕ່າງຫາກຂອງມຸມມອງສັງຄົມ ແທນທີ່ຈະປະສົມເຂົ້າໃນ ICER ຂອງ reference case — ເບິ່ງ [ມຸມມອງຂອງການວິເຄາະ](../ມຸມມອງຂອງການວິເຄາະ/).

## ຄະນິດສາດ

```
Human Capital Approach:
HCA_cost = daily_wage × days_lost

Friction Cost Method (simplified, capped-at-friction-period form):
FCM_cost = daily_wage × min(days_lost, friction_period_days)

friction_period_days = country/sector-specific estimate of time-to-restore
                        production (historically ~85 days in Dutch iMTA
                        costing guidance; varies by country and is
                        periodically re-estimated)
```

ຄວາມຂັດແຍ້ງທັງໝົດລະຫວ່າງສອງວິທີຢູ່ໃນ `min()`: HCA ບໍ່ເຄີຍຈຳກັດ `days_lost`, ດັ່ງນັ້ນຕົ້ນທຶນເພີ່ມຂຶ້ນຕະຫຼອດການຂາດງານ, ໃນຂະນະທີ່ FCM ຈຳກັດຈຳນວນວັນທີ່ນັບໄວ້ທີ່ໄລຍະການຂັດຂ້ອງ ບໍ່ວ່າການຂາດງານຈິງຈະຍາວປານໃດ.

## ຕົວຢ່າງການຄິດໄລ່

ພະນັກງານຂາດງານ `days_lost = 180` ວັນ, ມີລາຍໄດ້ `daily_wage = £150`.

**ວິທີທຶນມະນຸດ**:

```
HCA_cost = 150 × 180 = £27,000
```

**ວິທີຕົ້ນທຶນການຂັດຂ້ອງ**, ໃຊ້ໄລຍະການຂັດຂ້ອງ `friction_period_days = 85` (ເກນປຽບທຽບ iMTA ຂອງເນເທີແລນໃນອະດີດ, ຕາມການຄາດຄະເນຄືນໃໝ່ເປັນໄລຍະຂອງຄຳແນະນຳ):

```
FCM_cost = 150 × min(180, 85) = 150 × 85 = £12,750
```

£12,750 ຂອງ FCM ຕ່ຳກວ່າເຄິ່ງໜຶ່ງຂອງ £27,000 ຂອງ HCA ສຳລັບການຂາດງານ *ດຽວກັນ* — ການເລືອກວິທີພຽງຢ່າງດຽວປ່ຽນກໍລະນີຕົ້ນທຶນຂອງພະຍາດຢ່າງມີນັຍສຳຄັນ, ກ່ອນຈະແຕະຕ້ອງສົມມຸດຕິຖານອື່ນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ນີ້ສອດຄ່ອງໂດຍກົງກັບວິທີທີມງານປະເມີນມູນຄ່າຂອງວິສະວະກອນທີ່ລາອອກ:

- **ການຄິດຕົ້ນທຶນການລາອອກແບບ HCA**: ປະເມີນຄວາມສູນເສຍເປັນເງິນເດືອນເຕັມຂອງວິສະວະກອນທີ່ອອກໄປ ຕະຫຼອດເວລາທີ່ຕຳແໜ່ງຍັງວ່າງ. ນີ້ແມ່ນລຸ້ນທີ່ໄຮ້ດຽງສາຂອງແບບຈຳລອງຕົ້ນທຶນການລາອອກສ່ວນໃຫຍ່, ແລະ ມັນຄາດເກີນຄວາມສູນເສຍດ້ວຍເຫດຜົນດຽວກັບທີ່ HCA ຄາດເກີນການສູນເສຍຜະລິດຕະພາບ — ມັນສົມມຸດວ່າກຳລັງທີ່ວ່າງເຄີຍມີຜະລິດຕະພາບເຕັມຕະຫຼອດ ແລະ ບໍ່ມີຫຍັງອື່ນມາດູດຊຶມສ່ວນເກີນ. ເບິ່ງ [ການຮັກສາກຳລັງແຮງງານ](../ການຮັກສາກຳລັງແຮງງານ/), ເຊິ່ງກຳນົດປະລິມານລະບົບຕ່ອງໂສ້ການຮັບສະໝັກ/ການປະຖົມນິເທດ/ການຄຸ້ມຄອງຕຳແໜ່ງວ່າງທີ່ວິທີນີ້ປ້ອນເຂົ້າ.
- **ການຄິດຕົ້ນທຶນການລາອອກແບບ FCM**: ປະເມີນຄວາມສູນເສຍສະເພາະເວລາຕົວຈິງໃນການຫາຄົນມາແທນ ແລະ ໃຫ້ເຂົາປັບຕົວ — "ໄລຍະການຂັດຂ້ອງ" ດ້ານວິສະວະກຳ. ນີ້ແມ່ນຕົວເລກທີ່ປົກປ້ອງໄດ້ຫຼາຍກວ່າສຳລັບ business case, ຄືກັນກັບທີ່ FCM ເປັນທາງເລືອກທີ່ລະມັດລະວັງກວ່າໃນການສຶກສາຕົ້ນທຶນຂອງພະຍາດ.
- ວິໄນພື້ນຖານແມ່ນອັນດຽວກັນໃນ [ຕົ້ນທຶນຄວາມເສຍໂອກາດ](../ຕົ້ນທຶນຄວາມເສຍໂອກາດ/): ປະເມີນຊັບພະຍາກອນທີ່ຖືກແທນທີ່ດ້ວຍສິ່ງທີ່ສູນເສຍຈິງ, ບໍ່ແມ່ນໄລຍະເວລາຫົວຂ່າວຄູນດ້ວຍອັດຕາ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ປະສົມ HCA ແລະ FCM ໃນການວິເຄາະດຽວ, ຫຼື ລາຍງານພຽງອັນດຽວໂດຍບໍ່ເປີດເຜີຍການເລືອກ.** ຂໍ້ມູນການຂາດງານດຽວກັນສາມາດໃຫ້ຕົ້ນທຶນທີ່ລາຍງານແຕກຕ່າງກັນ 2 ເທົ່າຂຶ້ນໄປຕາມວິທີ; ການເລືອກຕ້ອງລະບຸໄວ້, ບໍ່ແມ່ນຝັງໄວ້.
- **ໃຊ້ HCA ສຳລັບກໍລະນີມຸມມອງສັງຄົມໂດຍບໍ່ໝາຍວ່າເປັນການວິເຄາະຄວາມອ່ອນໄຫວ.** reference case ຂອງ NICE ຍົກເວັ້ນຕົ້ນທຶນຜະລິດຕະພາບຢ່າງຊັດເຈນ; ການຄາດຄະເນ HCA ຂອງມຸມມອງສັງຄົມຄວນຢູ່ໃນການວິເຄາະສະຖານະການ, ບໍ່ແມ່ນ ICER ຫຼັກ.
- **ໃຊ້ວິທີໃດວິທີໜຶ່ງກັບງານທີ່ບໍ່ມີຄ່າຈ້າງ ຫຼື ນອກຕະຫຼາດ (ເຊັ່ນ ການດູແລຜູ້ປ່ວຍ) ໂດຍບໍ່ປັບ.** ທັງສອງວິທີສົມມຸດໃຊ້ອັດຕາຄ່າຈ້າງແທນມູນຄ່າ, ເຊິ່ງບໍ່ໂອນໄປໃຊ້ກັບງານທີ່ບໍ່ມີຄ່າຈ້າງຕະຫຼາດໄດ້ຢ່າງສະອາດ.
