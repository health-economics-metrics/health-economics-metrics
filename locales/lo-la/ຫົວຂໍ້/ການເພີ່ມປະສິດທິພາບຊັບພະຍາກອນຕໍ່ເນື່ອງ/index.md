# ການເພີ່ມປະສິດທິພາບຊັບພະຍາກອນຕໍ່ເນື່ອງ

ການປະຢັດໜຶ່ງຊົ່ວໂມງຂອງຜູ້ປະຕິບັດວິຊາຊີບອາວຸໂສ — ແພດທົ່ວໄປ, ແພດລົງທະບຽນອາວຸໂສ, ແພດທີ່ປຶກສາ — ມັກປ້ອງກັນຄວາມຊັກຊ້າຈາກຂໍ້ຄອດຂອງທັງທີມຫຼາຍສາຂາວິຊາຊີບ (MDT) ຂອງພະຍາບານ, ເສມຽນບໍລິຫານ, ແລະ ນັກບຳບັດທີ່ລໍຖ້າການລົງນາມທາງຄລີນິກ. ຄຸນຄ່າຂອງການປົດຂໍ້ຄອດແມ່ນປະລິມານງານຂອງທຸກຄົນຕໍ່ເນື່ອງຈາກມັນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ການດູແລສຸຂະພາບດຳເນີນດ້ວຍຕ່ອງໂສ້ການອະນຸມັດ: ການອອກໂຮງໝໍລໍຖ້າການລົງນາມຂອງແພດທີ່ປຶກສາ, ແຜນການປິ່ນປົວລໍຖ້າການທົບທວນ MDT, ການສົ່ງຕໍ່ລໍຖ້າການຄັດແຍກ. ເມື່ອບົດບາດທີ່ເປັນປະຕູຊັກຊ້າ ຕົ້ນທຶນບໍ່ແມ່ນຊົ່ວໂມງຂອງຄົນດຽວ — ແຕ່ແມ່ນເວລາວ່າງຫຼືຖືກບລັອກໃນທຸກບົດບາດທີ່ຂຶ້ນກັບ ບວກເວລາຂອງຄົນເຈັບທີ່ຄ້າງຄາ ([ວັນນອນໂຮງໝໍ](../ວັນນອນໂຮງໝໍທີ່ປະຢັດໄດ້/)ເພີ່ມ, [ການລໍຖ້າ RTT](../ການສົ່ງຕໍ່ເຖິງການຮັກສາ/)ດົນຂຶ້ນ). ນີ້ແມ່ນທິດສະດີຂໍ້ຈຳກັດທີ່ນຳໃຊ້ກັບເສັ້ນທາງຄລີນິກ: ຊົ່ວໂມງທີ່ປະຢັດ*ທີ່ຂໍ້ຈຳກັດ*ມີຄ່າເທົ່າປະລິມານງານສ່ວນເພີ່ມຂອງທັງລະບົບ; ຊົ່ວໂມງທີ່ປະຢັດບ່ອນອື່ນມີຄ່າໜ້ອຍກວ່າຫຼາຍ.

## ຄະນິດສາດ

```
Value of unblocking = Σ over downstream roles (blocked hours released × unit cost)
                    + pathway throughput gain × value per pathway completion

Contrast: value of the same hour saved at a non-gating role ≈ that role's
capacity value alone (see practitioner-time.md).
```

ກຳນົດຂໍ້ຈຳກັດຈາກຂໍ້ມູນຕົວຈິງ: ງານຕໍ່ຄິວດົນທີ່ສຸດຢູ່ໃສ? ຄວາມຊັກຊ້າຕິດຕາມຫາກ່ອງຈົດໝາຍຂອງໃຜ?

## ຕົວຢ່າງການຄິດໄລ່

ການອອກໂຮງໝໍຂອງຫວອດຕ້ອງການການທົບທວນຂອງແພດທີ່ປຶກສາທຸກເຊົ້າ. ແພດໃຊ້ເວລາ 90 ນາທີ/ມື້ໃນການລວບລວມຂໍ້ມູນທີ່ກະຈາຍໃນຫຼາຍລະບົບ; ການທົບທວນສຳເລັດຮອດ 14:00, ແລະ ການອອກໂຮງໝໍ 6 ຄົນ/ມື້ສຳເລັດຊ້າເກີນສຳລັບມື້ນັ້ນ — ແຕ່ລະຄົນເສຍວັນນອນໂຮງໝໍທີ່ຫຼີກລ່ຽງໄດ້.

ແດຊບອດສະຫຼຸບການອອກໂຮງໝໍ (ແລັບ, ຢາ, ທຸງໃນມຸມມອງດຽວ) ຕັດການລວບລວມເປັນ 20 ນາທີ; ການທົບທວນສຳເລັດຮອດ 11:30:

```
Bed days avoided     = 4 of the 6 late discharges × 365 ≈ 1,460 bed days/year
Downstream unblocking: 2 discharge coordinators + pharmacy + transport
                       previously idle-then-crunched each afternoon —
                       ~3 staff-hours/day of blocked time released ≈ 1,100 hrs/yr
```

70 ນາທີຂອງແພດທີ່ປຶກສາເອງແມ່ນສ່ວນ*ນ້ອຍທີ່ສຸດ*ຂອງຄຸນຄ່າ — ຈຸດຂອງຕົວຊີ້ວັດນີ້. ຕີມູນຄ່າວັນນອນໂຮງໝໍຕາມກົນໄກ (ເບິ່ງ[ວັນນອນໂຮງໝໍທີ່ປະຢັດໄດ້](../ວັນນອນໂຮງໝໍທີ່ປະຢັດໄດ້/)) ແລະ ຊົ່ວໂມງບຸກຄະລາກອນເປັນຄວາມສາມາດ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ນີ້ແມ່ນການທົບທວນໂຄດ, ການລົງນາມສະຖາປັດຕະຍະກຳ, ແລະ ກ່ອງຈົດໝາຍຂອງວິສະວະກອນອາວຸໂສ. ເມື່ອວິສະວະກອນຫ້າຄົນລໍຖ້າໜຶ່ງມື້ສຳລັບຄົນດຽວທີ່ອະນຸມັດການອອກແບບໄດ້ ຕົ້ນທຶນແມ່ນຫ້າວັນວິສະວະກອນ ບວກໜຶ່ງມື້ຂອງ[ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ](../ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ/)ຂອງງານນັ້ນ — ບໍ່ແມ່ນໜຶ່ງຊົ່ວໂມງຂອງຜູ້ທົບທວນ. ເຄື່ອງມືທີ່ບີບອັດໜ້າວຽກຂອງບົດບາດທີ່ເປັນປະຕູ (ບໍລິບົດການທົບທວນທີ່ດີກວ່າ, ການກວດລ່ວງໜ້າອັດຕະໂນມັດ, ແດຊບອດທີ່ລວບລວມສິ່ງທີ່ຜູ້ອະນຸມັດຕ້ອງການ) ຊື້ປະລິມານງານຂອງລະບົບ ບໍ່ແມ່ນຄວາມສະດວກສ່ວນຕົວ. ວັດເວລາຮັບ/ລໍຖ້າທີ່ຂໍ້ຈຳກັດ (ເບິ່ງ[ຕົວຊີ້ວັດການໄຫຼ](../ຕົວຊີ້ວັດການໄຫຼ/)) — ມັນແມ່ນສິ່ງທຽບເທົ່າຂອງຊອບແວຕໍ່ໜ້າຜາການອອກໂຮງໝໍເວລາ 14:00.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ປັບສິ່ງທີ່ບໍ່ແມ່ນຂໍ້ຈຳກັດ**: ເຄື່ອງມືງາມສຳລັບບົດບາດທີ່ບໍ່ມີອັນໃດຕໍ່ຄິວຢູ່ຫຼັງ ສ້າງຄຸນຄ່າໃຫ້ລະບົບເກືອບສູນ.
- **ການຍ້າຍຂໍ້ຈຳກັດ**: ປົດແພດທີ່ປຶກສາແລ້ວຂໍ້ຈຳກັດຍ້າຍ (ໄປຫາຮ້ານຢາ, ການຂົນສົ່ງ) — ສ້າງແບບຈຳລອງຂໍ້ຈຳກັດ*ຖັດໄປ*ກ່ອນອ້າງກຳໄລປະລິມານງານເຕັມ.
- **ນັບຊົ່ວໂມງຕໍ່ເນື່ອງເປັນເງິນສົດ**: ການປົດເວລາທີ່ຖືກບລັອກແມ່ນຄວາມສາມາດ ຂຶ້ນກັບ[ການທົດສອບການຍ້າຍໃຊ້ງານ](../ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດ-ທຽບກັບ-ທີ່ບໍ່ປົດປ່ອຍເງິນສົດ/)ປົກກະຕິ.
