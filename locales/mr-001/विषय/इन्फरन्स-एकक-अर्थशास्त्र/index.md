# इन्फरन्स एकक अर्थशास्त्र

इन्फरन्स एकक अर्थशास्त्र AI वैशिष्ट्यांची किंमत त्यांच्या सीमान्त कंप्यूटने ठरवते: **प्रति टोकन खर्च**, जो प्रति व्यवहार, प्रति वापरकर्ता, प्रति क्लिनिकल प्रसंग खर्चात एकत्र होतो. परिभाषित गतिशीलता: समान क्षमतेवर LLM किमती अंदाजे **दर 1–2 वर्षांनी एका परिमाण-क्रमाने** घसरल्या आहेत — आरोग्य-तंत्रज्ञान खर्च-निर्धारणात ज्याला उदाहरण नाही असा अपस्फीती दर.

## हे का महत्त्वाचे आहे

किंमत घसरणीचे दोन परिणाम होतात. व्यावसायिकदृष्ट्या, आज सीमारेषेवर असलेले AI वैशिष्ट्य 18 महिन्यांत सहज नफादायी होऊ शकते — आणि आजच्या खर्चावर किंमत ठरवणाऱ्या स्पर्धकाला कमी किमतीने मागे टाकले जाईल. आर्थिक मूल्यमापनासाठी, AI-सक्षम क्लिनिकल सेवेचे कोणतेही खर्च-परिणामकारकता मॉडेल जे 2024 इन्फरन्स किमती गोठवते ते **चालू खर्च ठळकपणे अतिरंजित करते** — औषध मॉडेल पेटंट समाप्ती आणि जेनेरिक प्रवेश जसे हाताळतात तसे विश्लेषणाला किंमत-घट परिस्थिती हव्या. (संशोधनातील संदर्भ बिंदू: 2026 मध्यावर फ्रंटियर आउटपुट टोकन ~$15–75/M, मध्यम-स्तरीय मॉडेल्स एक परिमाण-क्रम स्वस्त, GPT-4-स्तर क्षमता 2022 मधील ~$20/M वरून ~$0.40/M; Epoch AI ने क्षमता टप्प्यानुसार दरवर्षी 9×–900× घट मोजली.)

## गणित

```
Cost per call     = input tokens × input rate + output tokens × output rate
Cost per unit     = Σ calls per unit of business output (per triage episode,
                    per drafted letter, per consultation summary)

Blended reality   = base call + retries + RAG context (input-heavy)
                    + evaluation/guardrail calls (often 20–50% overhead)

Price-decline scenario for multi-year models:
  cost_t = cost_0 × d^t, test d ∈ {0.3, 0.5, 0.7}/year in sensitivity analysis
```

## सोडवलेले उदाहरण

एक AI सुट्टी-सारांश सेवा: सरासरी सारांश 12,000 इनपुट टोकन (नोंद संदर्भ) + 1,200 आउटपुट वापरतो, अधिक एक पडताळणी फेरी (6,000 इन / 300 आउट). $3/M इन, $15/M आउट वर:

```
Draft:   12,000 × 3/1M + 1,200 × 15/1M  = $0.036 + $0.018 = $0.054
Verify:   6,000 × 3/1M +   300 × 15/1M  = $0.018 + $0.0045 ≈ $0.023
Per summary ≈ $0.077 → per 100,000 summaries/year ≈ $7,700

Against ~20 clinician-minutes saved per summary (≈ £25), inference is
0.25% of the value created — the economics are dominated by everything
EXCEPT the tokens: integration, evaluation, governance, adoption.
```

तो निष्कर्ष — उच्च-मूल्य क्लिनिकल कामांसाठी, सध्याच्या किमतींवर, इन्फरन्स खर्च क्वचितच बंधनकारक अडथळा आहे — हेच किंमत बैठकींमध्ये घेऊन जाण्यासारखे निष्कर्ष आहे.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

हे AI साठी विशेषीकृत [क्लाउड एकक अर्थशास्त्र](../क्लाउड-एकक-अर्थशास्त्र/) आहे, तीन सराव टिपांसह: **प्रति API कॉल नव्हे, प्रति व्यवसाय एकक मोजा**, म्हणजे आकडा थेट [ICER](../वाढीव-खर्च-परिणामकारकता-गुणोत्तर/)/[अंदाजपत्रक प्रभाव](../अंदाजपत्रक-प्रभाव-विश्लेषण/) मॉडेल्समध्ये जोडता येतो; **इनपुट/आउटपुट असममिती पहा** (आउटपुट सहसा इनपुट किमतीच्या ~4×; RAG आर्किटेक्चर इनपुट-जड असतात — आर्किटेक्चर निवडी म्हणजे किंमत निवडी); आणि **कार्य स्तरानुसार मार्ग ठरवा** — मॉडेल क्षमता कामाच्या अडचणीशी जुळवणे (वर्गीकरणासाठी स्वस्त मॉडेल, संश्लेषणासाठी फ्रंटियर) समान गुणवत्तेवर मिश्र खर्च नियमितपणे 5–10× कमी करते, सर्वात स्वस्त प्रभावी हस्तक्षेप वापरण्याची सॉफ्टवेअर आवृत्ती ([खर्च-किमानीकरण](../खर्च-किमानीकरण-विश्लेषण/), समतुल्यता पुराव्यासह).

## सामान्य चुका

- **गोठवलेल्या-किमतीची बहु-वर्षीय मॉडेल्स** — खर्च अतिरंजित करतात; पण **गृहीत-अपस्फीती महसूल मॉडेल्स** देखील — किंमत युद्ध म्हणजे करार नाही; दोन्हींची परिस्थिती तपासा.
- **मूल्यमापन ओव्हरहेडकडे दुर्लक्ष**: गार्डरेल्स, जजेस आणि पुन्हा प्रयत्न हे खरे टोकन आहेत, नियंत्रित स्थितीत अनेकदा बहुसंख्य.
- **प्रति-टोकन अदूरदर्शीपणा**: लेटन्सी, दर मर्यादा आणि संदर्भ-खिडकी बंधनांना असा खर्च असतो जो कोणतीही टोकन किंमत टिपत नाही.
