# EQ-5D

EQ-5D हे आरोग्य-संबंधित जीवन गुणवत्ता मोजण्यासाठी EuroQol गटाचे प्रमाणित प्रश्नावली आहे. बहुतेक [QALY](../गुणवत्ता-समायोजित-आयुर्वर्ष/) गणनांमधील उपयुक्तता भार हेच साधन निर्माण करते — NICE चे संदर्भ प्रकरण प्रौढांसाठी ते पसंतीचे मापन म्हणून नमूद करते.

## हे का महत्त्वाचे आहे

QALY चा दावा करू इच्छिणाऱ्या कोणत्याही डिजिटल आरोग्य उत्पादनाला प्रमाणित साधनातून उपयुक्तता हवी असते, आणि UK आणि बहुतेक युरोपमध्ये EQ-5D हे डीफॉल्ट आहे. ते अ‍ॅपमध्ये एम्बेड करण्याइतके लहान आहे (5 प्रश्न + दृश्य मापनी), म्हणजे सॉफ्टवेअर उत्पादने सामान्य वापराचा उपपरिणाम म्हणून HTA-दर्जाचा परिणाम डेटा गोळा करू शकतात — औषधांपेक्षा संरचनात्मक फायदा, ज्यांना समर्पित अभ्यास लागतात.

## गणित

EQ-5D-5L **5 परिमाणांपैकी** प्रत्येकात एक प्रश्न विचारते — हालचाल, स्वतःची काळजी, नेहमीच्या क्रिया, वेदना/अस्वस्थता, चिंता/नैराश्य — प्रत्येकाचे उत्तर **5 स्तरांवर** (कोणतीही अडचण नाही … अत्यंत अडचणी), तसेच 0–100 दृश्य analogue मापनी (EQ VAS).

```
Health state = 5-digit profile, e.g. "21221"
Utility index = value_set(profile)

The value set is country-specific, derived from time-trade-off /
discrete-choice surveys of the general public. Anchors: 1 = full health,
0 = dead; states worse than death are negative (UK 3L set floor: −0.594).
```

QALY गणित मग `कालावधी × उपयुक्तता` असे पुढे जाते.

## सोडवलेले उदाहरण

एक स्नायू-कंकाल पुनर्वसन अ‍ॅप 1,000 पूर्ण करणाऱ्या वापरकर्त्यांसाठी ऑनबोर्डिंगवेळी आणि 6 महिन्यांनी EQ-5D-5L मोजते.

```
Mean utility at baseline:  0.62
Mean utility at 6 months:  0.71
Gain sustained (assume) 1 year: (0.71 − 0.62) × 1.0 = 0.09 QALYs per user
```

0.03 च्या नियंत्रण-गट बदलाविरुद्ध (नैसर्गिक पुनर्प्राप्ती), श्रेय देण्याजोगा लाभ 0.06 QALY/वापरकर्ता आहे. £20,000–£30,000/QALY वर मूल्य ठरवल्यास: **प्रति पूर्ण करणाऱ्या वापरकर्त्यासाठी £1,200–£1,800 आरोग्य मूल्य** — देय देणाऱ्याशी अ‍ॅपच्या किंमत वाटाघाटीचा आधार ठरणारा आकडा. (EQ-5D निर्देशांकासाठी किमान क्लिनिकली महत्त्वाचे फरक सामान्यतः 0.03–0.08 श्रेणीत असतात, म्हणून 0.06 विश्वासार्ह आहे पण नियंत्रण तुलनेतून पार पडला पाहिजे; [रुग्ण-नोंदवलेले परिणाम](../रुग्ण-नोंदवलेले-परिणाम/) पहा.)

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

- **इन्स्ट्रुमेंट करा.** साइनअपवर आणि फॉलो-अप अंतरांवर EQ-5D हे UI च्या काही स्क्रीन आहेत; फायदा म्हणजे HTA-दर्जाचा पुरावा. EuroQol कडून परवाना मिळवा (आवश्यक, काही वापरांसाठी मोफत).
- तैनाती देशासाठी **योग्य value set वापरा** — तीच उत्तरे UK, जर्मनी आणि जपानमध्ये वेगळी गुणांकित होतात.
- **रचना धडा**: EQ-5D दाखवते की लहान प्रमाणित सर्वेक्षण आणि प्रकाशित गुणांकन फलन तुलनीय एकल निर्देशांक कसे देते. कोणत्याही विश्वासार्ह डेव्हलपर-अनुभव निर्देशांकाचा हाच नमुना आहे — प्रमाणित साधन, प्रकाशित भार, तदर्थ भावना नव्हे. [SPACE आणि DevEx](../space-आणि-devex/) पहा.

## सामान्य चुका

- **तुलनात्मक गटाशिवाय आधी/नंतर** — सरासरीकडे परतणे आणि नैसर्गिक पुनर्प्राप्ती भोळे लाभ फुगवतात.
- **वाचलेल्यांचा पक्षपात**: फक्त गुंतलेल्या राहिलेल्या वापरकर्त्यांचे मोजमाप ([टिकवणूक आणि गळती](../टिकवणूक-आणि-गळती/) पहा).
- अभ्यासांमध्ये **3L आणि 5L आवृत्त्या किंवा value sets मिसळणे** — पद्धतशीरपणे वेगळे आकडे.
- सौम्य बाधित लोकसंख्येत **कमाल-मर्यादा परिणाम**: अनेक वापरकर्ते मूलरेषेवर 1.0 जवळ गुण मिळवतात, लाभ दाखवायला जागा उरत नाही.
- **value set ला स्वयं-समर्थक मानणे**: value set जे उपयुक्तता आकडे देतो ते स्वतः जनतेकडून time-trade-off (किंवा संबंधित निवड-आधारित) सर्वेक्षणांद्वारे मिळवले होते — कसे ते [टाइम-ट्रेड-ऑफ (TTO) उपयुक्तता निश्चिती](../टाइम-ट्रेड-ऑफ-tto-उपयुक्तता-निश्चिती/) मध्ये पहा.
