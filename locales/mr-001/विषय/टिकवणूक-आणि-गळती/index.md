# टिकवणूक आणि गळती

टिकवणूक मोजते की वापरकर्ता कोहॉर्टचा किती अंश सुरुवातीनंतर N दिवसांनी अजूनही सक्रिय आहे (D1/D7/D30 वक्र); गळती हा त्याचा पूरक आहे. क्रूर डिजिटल-आरोग्य मूलरेषा: **सुमारे 90% आरोग्य-अ‍ॅप वापरकर्ते 30 दिवसांत सोडून देतात** — सर्व-अ‍ॅप सरासरी ~6% च्या तुलनेत डिजिटल आरोग्य D30 टिकवणूक ~3–4% आहे.

## हे का महत्त्वाचे आहे

Eysenbach यांनी 2005 मध्ये याला नाव दिले: **गळतीचा नियम** — वापरकर्ते उच्च दराने गमावणे हा eHealth हस्तक्षेपांचा अंतर्गत, संरचनात्मक गुणधर्म आहे, अंमलबजावणी बग नाही, eHealth चाचण्यांमध्ये गळती नियमितपणे 50% पेक्षा जास्त. आर्थिक परिणाम पूर्ण आहे: टिकवणूक *उपचार खिडकी* ठरवते ज्यात कोणताही लाभ पोहोचवता येतो, आणि [एकक अर्थशास्त्र](../आरोग्य-अ-ॅप-एकक-अर्थशास्त्र/) — 12 दिवस टिकणाऱ्या प्रति वापरकर्त्यासाठी दिलेला CAC ना LTV देतो ना QALY. टिकवणूक वक्राने लाभ भारित न करणारे ग्राहक आरोग्य उत्पादनाचे कोणतेही आर्थिक मॉडेल अस्तित्वात नसलेल्या उत्पादनाचे वर्णन करत आहे.

## गणित

```
Retention_Dn = users active on day n / cohort size × 100
Churn rate   = users lost in period / users at period start × 100

Benefit weighting (the health-economics move):
  expected benefit per acquired user = Σ_t retention(t) × benefit rate(t)
  ≈ area under the retention curve × per-time benefit
  — NOT trial benefit × 100% of acquired users

Cost per retained-at-D30 user = CAC / D30 retention
  (at 4% D30, a £5 CAC is really £125 per retained user)
```

## सोडवलेले उदाहरण

एक मानसिक-आरोग्य अ‍ॅप: चाचणीत 8 आठवडे पूर्ण करणाऱ्या प्रति वापरकर्त्याला 0.02 QALY लाभ दिसला. 100,000 डाउनलोडचा तैनाती कोहॉर्ट, टिकवणूक D7 25%, D30 8%, आठवडा-8 4%:

```
Completers          = 100,000 × 0.04 = 4,000
QALYs delivered     = 4,000 × 0.02 = 80  (not 100,000 × 0.02 = 2,000)
At £20,000/QALY     = £1.6M of health value (not £40M)

Per-download health value = £16 — the number that should set what a
payer will pay per download, and it is 4% of the naive claim.
Retention improvement case: moving week-8 completion 4% → 6% adds
40 QALYs/year ≈ £800k — retention engineering IS health production.
```

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

टिकवणूक हे मेट्रिक आहे जिथे उत्पादन अभियांत्रिकी वरील गणितानुसार सर्वात थेट आरोग्य मूल्य निर्माण करते. ते हलवणारे सराव सामान्य आहेत: ऑनबोर्डिंग पहिल्या-मूल्यापर्यंतचा वेळ, पुन्हा-एंगेजमेंट रचना, कामगिरी, आणि निर्णायकपणे **नियोजित मात्रा पूर्णत्व** — परिभाषित शेवट असलेला कार्यक्रम (8 आठवडे, मग पदवी) *पूर्णत्व* मोजला पाहिजे, शाश्वत DAU नाही, मेट्रिकला जाहिरात-निधीकृत लक्ष मॉडेलऐवजी क्लिनिकल मॉडेलशी संरेखित करून. जगणे-विश्लेषण हा योग्य साधनसंच आहे ([मिळवलेली आयुर्वर्षे](../मिळवलेली-आयुर्वर्षे/) मधील तेच Kaplan-Meier गणित); वक्र संपादन चॅनेलनुसार विभागा, कारण चॅनेल मिश्रण बहुतेक वैशिष्ट्यांपेक्षा जास्त टिकवणूक बदलते.

## सामान्य चुका

- **उलट दिशेने intention-to-treat धुलाई**: चाचण्या पूर्ण करणाऱ्यांना नोंदवतात; तैनाती अर्थशास्त्राने संपादित केलेल्या प्रत्येकाला मोजले पाहिजे (Eysenbach यांचा मूळ इशारा).
- **टिकवणूक नाटक**: उपचारात्मक कृती कधीही न करणारे सूचना-चालित "सक्रिय" वापरकर्ते ([एंगेजमेंट मेट्रिक्स](../एंगेजमेंट-मेट्रिक्स/) पहा).
- **व्याख्यांमध्ये वक्रांची तुलना**: "सक्रिय" म्हणजे उघडणे विरुद्ध अर्थपूर्ण कृती हे D30 अनेक पटींनी बदलते.
- **कोण गळते याकडे दुर्लक्ष**: सर्वात आजारी सर्वात वेगाने गळत असतील, तर निरोगी लोकांमध्ये टिकवणूक सुधारत जाते तसे प्रति-वापरकर्ता लाभ घसरतात — वक्र केस-मिक्ससोबत जोडा ([पोहोच आणि समानता](../पोहोच-आणि-समानता/) पहा).
