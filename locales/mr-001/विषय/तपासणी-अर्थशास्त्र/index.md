# तपासणी अर्थशास्त्र

तपासणी अर्थशास्त्र लक्षणहीन लोकसंख्येच्या चाचणीचे मूल्य नियंत्रित करते. मूलभूत गणिती तथ्य: **कमी रोग प्रसारावर, उत्कृष्ट चाचण्याही बहुतेक खोटे सकारात्मक निकाल निर्माण करतात** — आणि त्यांचा पाठलाग करण्याचा खालचा खर्च खऱ्या शोधांच्या लाभाला झाकून टाकू शकतो.

## हे का महत्त्वाचे आहे

1968 पासून WHO चे Wilson–Jungner निकष लोकसंख्या तपासणीसाठी पट्टी ठरवतात: स्थिती महत्त्वाची असावी, चाचणी स्वीकार्य आणि अचूक असावी, प्रभावी उपचार अस्तित्वात असावा, आणि अर्थशास्त्र समतोल असावे. UK National Screening Committee कोणताही राष्ट्रीय कार्यक्रम मंजूर करण्यापूर्वी औपचारिक खर्च-परिणामकारकता विश्लेषण लावते — आणि बहुतेक प्रस्ताव नाकारते. प्रत्येक "AI प्रत्येकाची प्रत्येक गोष्टीसाठी तपासणी करेल" मांडणी या यंत्रणेला भिडते, आणि सहसा खालील गणितासमोर हरते.

## गणित

सकारात्मक भविष्यसूचक मूल्य (PPV) — सकारात्मक निकाल खरा असण्याची संभाव्यता — कमी प्रसारावर कोसळते:

```
PPV = (sens × prev) / [sens × prev + (1 − spec) × (1 − prev)]

Example: sensitivity 90%, specificity 95%, prevalence 0.5%:
PPV = (0.9 × 0.005) / (0.9 × 0.005 + 0.05 × 0.995)
    = 0.0045 / (0.0045 + 0.04975) ≈ 8.3%
```

बारापैकी अकरा सकारात्मक खोटे आहेत. पूर्ण कार्यक्रम अर्थशास्त्र:

```
Cost per true case found = (screening cost + workup cost × all positives) / true positives
Then: is finding a case worth that? (earlier-intervention value per case,
      minus overdiagnosis harm — cases found that would never have mattered)
```

## सोडवलेले उदाहरण

दुर्मिळ स्थितीसाठी AI रेटिना तपासणी, 100,000 लोक, प्रसार 0.5%, संवेदनशीलता 90%, विशिष्टता 95%, स्कॅन £15, पुष्टीकारक तपासणी £400:

```
True positives:  100,000 × 0.005 × 0.90 = 450
False positives: 100,000 × 0.995 × 0.05 = 4,975
Cost = 100,000 × 15 + (450 + 4,975) × 400 = 1.5M + 2.17M = £3.67M
Cost per true case ≈ £8,156
```

लवकर उपचाराने प्रति प्रकरण £20,000 + 1 QALY वाचत असेल, तर कार्यक्रम सहज उत्तीर्ण होतो. विशिष्टता 99% पर्यंत वाढवा (कमी खोटे गजर): तपासणी खर्च (450 + 995) × 400 = £0.58M पर्यंत घटतो, एकूण £2.08M, प्रति प्रकरण खर्च ≈ **£4,622** — कमी प्रसारावर तपासणी अर्थशास्त्र संवेदनशीलतेत नव्हे, तर विशिष्टतेत जिंकले जाते.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

स्थिर विश्लेषण, सुरक्षा स्कॅनिंग आणि विसंगती शोध हे कोडबेस आणि टेलिमेट्रीवरील तपासणी कार्यक्रम आहेत, ज्यात खऱ्या-दोषाचा प्रसार प्रति अलर्ट-संधी अनेकदा 1% पेक्षा खूप कमी असतो. तेच गणित अलर्ट थकवा स्पष्ट करते: कमी-प्रसार कोडवरील 95%-विशिष्ट स्कॅनर संघांना खोट्या सकारात्मकांमध्ये बुडवतो, आणि प्रत्येक खोटा सकारात्मक लक्ष खातो आणि खरे अलर्ट दुर्लक्षित होईपर्यंत विश्वास खोडतो (क्लिनिकल संज्ञा *तपासणी हानी*; अभियांत्रिकी संज्ञा *पेजर बधिरता*). उपाय आरोग्यातून हस्तांतरित होतात: संवेदनशीलतेपूर्वी विशिष्टता वाढवा, उच्च-प्रसार उप-लोकसंख्या तपासा (जोखीम-आधारित लक्ष्यीकरण ↔ फक्त-बदललेल्या-कोडचे स्कॅनिंग), आणि टूलच्या अर्थशास्त्रात ट्रायाज खर्च मोजा — [NNT](../उपचारासाठी-आवश्यक-संख्या/) आणि [क्लिनिकल AI मूल्यमापन](../क्लिनिकल-ai-मूल्यमापन/) पहा. एका चाचणीऐवजी संपूर्ण तपासणी कार्यक्रमाच्या आकारमानासाठी [तपासणीसाठी आवश्यक संख्या](../तपासणीसाठी-आवश्यक-संख्या/) पहा — एक परिणाम टाळण्यासाठी किती लोकांना संपूर्ण तपासणी-आणि-उपचार मार्गातून जावे लागते.

## सामान्य चुका

- **प्रसाराशिवाय संवेदनशीलता/विशिष्टता उद्धृत करणे** — PPV शिवाय अचूकता म्हणजे विपणन.
- **अतिनिदानाकडे दुर्लक्ष**: कधीही हानी न करणारा सुप्त "रोग" शोधल्याने खरे उपचार खर्च आणि हानी निर्माण होते.
- **लीड-टाइम पक्षपात**: परिणाम न बदलता लवकर शोध दिसणारे जगणे फुगवतो — [लवकर हस्तक्षेप](../लवकर-हस्तक्षेप/) पहा.
