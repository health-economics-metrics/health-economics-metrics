# सक्रियता आणि स्वीकार

सक्रियता दर म्हणजे नोंदणी करणाऱ्यांपैकी पहिल्या अर्थपूर्ण मूल्यापर्यंत पोहोचणाऱ्यांचा वाटा ("अहा" क्रिया — पहिली नोंद केलेली मोजणी, पहिला पूर्ण केलेला धडा). स्वीकार ही त्याची लोकसंख्या-स्तरावरील आवृत्ती आहे: *पात्र* लोकसंख्येपैकी मुळात अंगीकार करणाऱ्यांचा वाटा. दोन्ही मिळून मूल्य-फनेलची पुढची दारे ठरतात: संपादन → स्वीकार → सक्रियता → [टिकवणूक](../टिकवणूक-आणि-गळती/) → परिणाम.

## हे का महत्त्वाचे आहे

सक्रिय न झालेले वापरकर्ते म्हणजे निव्वळ खर्च: संपादनावरील खर्च, तरतूद, सपोर्टचा भार — पण क्लिनिकल मूल्य शून्य. बेंचमार्क दर्शवतात की आरोग्यसेवा सॉफ्टवेअरची सक्रियता सर्व उद्योगांच्या सरासरीपेक्षा *कमी* असते (एका SaaS बेंचमार्क संचात नवीन वापरकर्त्यांच्या सक्रियतेसाठी ≈24% विरुद्ध ≈37%; ऑनबोर्डिंग चेकलिस्ट पूर्ण होण्याचे प्रमाण ~20%), कारण ऑनबोर्डिंग अधिक जड असते (ओळख, संमती, क्लिनिकल सुरक्षा). स्वीकारावर लोकसंख्येचे हित अवलंबून असते: [RE-AIM मांडणीनुसार](../पोहोच-आणि-समानता/) सार्वजनिक आरोग्यावरील परिणाम ≈ पोहोच × परिणामकारकता — पात्र लोकसंख्येच्या 3% लोकांनी स्वीकारलेले उत्कृष्ट अ‍ॅप लोकसंख्येचा काटा फक्त 3% इतकाच हलवते. प्रिस्क्रिप्शनवर दिल्या जाणाऱ्या डिजिटल उपचारांसाठी स्वीकाराचे दार राष्ट्रीय आकडेवारीत दिसते: **जर्मन DiGA प्रिस्क्रिप्शनपैकी ~81% सक्रिय होतात** — लिहून दिलेल्या आणि पैसे भरलेल्या उपचारांपैकी पाचातील एक कधीच सुरू होत नाही ([DiGA फास्ट-ट्रॅक](../जर्मनीचा-diga-फास्ट-ट्रॅक/) पहा).

## गणित

```
Activation rate = users completing key action within window / sign-ups × 100
Uptake rate     = adopters / eligible population × 100
DTx fill rate   = activated prescription codes / issued prescriptions × 100

Funnel value model:
  eligible × uptake × activation × retention-weighted benefit = population value
  — four multiplications; improving the smallest factor usually
  dominates (theory-of-constraints for funnels)
```

## सोडवलेले उदाहरण

एक कमिशनर 80,000 पात्र रहिवाशांना मधुमेह-प्रतिबंध अ‍ॅप देऊ करतो:

```
Invited → registered:  80,000 → 12,000  (uptake 15%)
Registered → activated (first session + goal set, 7 days): 12,000 → 5,400 (45%)
Activated → completed 6-month programme: 5,400 → 1,600 (30%)

Programme effect (trial, completers): 0.03 QALYs + £180 avoided costs
Population value = 1,600 × (0.03 × £20,000 + £180) ≈ £1.25M
Per-eligible-person value = £15.6 — versus £780 if every eligible person completed.

Where to invest? Doubling uptake (15→30%) doubles value; raising
activation 45→65% adds ~44%; both beat further polishing the programme
content the 1,600 already complete.
```

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

सक्रियता ही फनेलमधील अभियांत्रिकीच्या दृष्टीने सर्वात हाताळण्यायोग्य पायरी आहे: ओळख-पडताळणीतील अडथळे, संमती प्रवाह, रिकाम्या स्थितीची रचना आणि पहिल्या मूल्यापर्यंतचा वेळ हे धोरण नव्हे तर कोड आहे (बेंचमार्क डेटामध्ये आरोग्यसेवेत पहिल्या मूल्यापर्यंतचा मध्यक वेळ ≈ 1 दिवस 7 तास — त्यातील प्रत्येक तास गळतीचा धोका आहे). स्वीकार ही वितरण-प्रणालींची समस्या आहे: रेफरल मार्गांमध्ये एकात्मता (प्रिस्क्रिप्शनचा क्षण), GP ने दिलेली आमंत्रणे (विश्वास हस्तांतरित होतो) आणि सुलभता (भाषा, डिजिटल कौशल्ये — [पोहोच आणि समानता](../पोहोच-आणि-समानता/) पहा). वरील फनेल-मूल्य मॉडेल दोन्हींसाठी व्यवसाय-प्रकरण तयार करणारे साधन आहे: घटक गुणा, अडथळा शोधा आणि तो दूर करण्याची किंमत त्यातून सुटणाऱ्या लोकसंख्या-मूल्याशी ताडून पहा.

## सामान्य चुका

- **सक्रियतेची व्याख्या सोयीनुसार करणे** (ईमेल पडताळला) — क्लिनिकल अर्थाऐवजी (पहिली उपचारात्मक कृती) — यामुळे मेट्रिक फुगते आणि मूल्य-साखळी तुटते.
- **स्वीकाराच्या छेदातील खेळ**: "साइटला भेट दिलेल्यांपैकी" विरुद्ध खऱ्या पात्र लोकसंख्येपैकी — कमिशनरांना दुसऱ्याची काळजी असते.
- **निवड परिणाम**: सक्रिय करायला सोपे वापरकर्ते सर्वात कमी आजारी आणि सर्वात कमी वंचित असतात; फनेल सुधारणांमुळे सरासरी सुधारत असताना समानतेतील दरी वाढू शकते.
