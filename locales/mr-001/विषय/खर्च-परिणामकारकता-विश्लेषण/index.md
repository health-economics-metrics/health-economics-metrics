# खर्च-परिणामकारकता विश्लेषण (CEA)

CEA पर्यायी हस्तक्षेपांच्या खर्चाची तुलना **नैसर्गिक एककांत** मोजलेल्या एका परिणामाशी करते — आयुर्वर्षे, शोधलेली प्रकरणे, टाळलेले दाखले, कमी झालेले रक्तदाबाचे mmHg. त्याचा आउटपुट म्हणजे प्रति एकक परिणाम खर्च.

## हे का महत्त्वाचे आहे

सर्व पर्याय एकाच परिणामाला लक्ष्य करतात तेव्हा CEA हे कामाचे तुलनात्मक साधन आहे. "X साध्य करण्याच्या या मार्गांपैकी पैशाचा सर्वोत्तम वापर कोणता?" याचे ते उत्तर देते — पण "X साध्य करणे अजिबात योग्य आहे का?" याचे नाही (त्यासाठी [खर्च-लाभ विश्लेषण](../खर्च-लाभ-विश्लेषण/) लागते) आणि "X ची असंबंधित प्राधान्यांशी तुलना कशी होते?" याचेही नाही (त्यासाठी [खर्च-उपयुक्तता विश्लेषण](../खर्च-उपयुक्तता-विश्लेषण/) आणि QALY सारखा सामान्य परिणाम लागतो).

## गणित

तुलनात्मक सांख्यिकी म्हणजे नैसर्गिक एककांतील [ICER](../वाढीव-खर्च-परिणामकारकता-गुणोत्तर/):

```
ICER = (Cost_A − Cost_B) / (Effect_A − Effect_B)
     = £ per additional case detected / admission avoided / etc.
```

प्रक्रिया: परिणाम एकक निश्चित करा; प्रत्येक पर्यायाचा खर्च एकाच [दृष्टिकोनातून](../विश्लेषण-दृष्टिकोन/) एकाच [कालावधी क्षितिजावर](../कालावधी-क्षितिज/) मोजा; वर्चस्वित पर्याय काढून टाका ([कार्यक्षमता सीमा](../वर्चस्व-आणि-कार्यक्षमता-सीमा/)); सीमेवरील वाढीव गुणोत्तरे काढा.

## सोडवलेले उदाहरण

100,000 लोकसंख्येत निदान न झालेले अॅट्रियल फिब्रिलेशन शोधण्याचे तीन मार्ग:

```
Option                    Cost        Cases found
Opportunistic pulse checks £150,000       300
Pharmacy screening events  £400,000       520
Wearable-based screening   £900,000       610

ICER pharmacy vs pulse:  (400k−150k)/(520−300) = £1,136 per additional case
ICER wearable vs pharmacy:(900k−400k)/(610−520) = £5,556 per additional case
```

प्रति अतिरिक्त प्रकरण £5,556 "योग्य" आहे का हे सापडलेल्या प्रकरणाच्या मूल्यावर (खालच्या पातळीवरील पक्षाघात प्रतिबंध) अवलंबून असते — CEA पर्यायांना क्रम देते, पण स्वीकाराच्या निर्णयासाठी ते बाह्य मूल्यमापन लागते. लक्षात घ्या की वेअरेबल पर्यायाचा *सरासरी* प्रति प्रकरण खर्च (900k/610 = £1,475) ठीक दिसतो; विस्ताराच्या निर्णयासाठी प्रामाणिक संख्या *वाढीव* £5,556 आहे.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

पर्याय एकच परिणाम सामायिक करतात तेव्हा CEA हा योग्य आराखडा आहे: तीन उपाय पद्धतींमध्ये दूर केलेल्या प्रति अस्थिर चाचणी खर्च; निरीक्षणक्षमता विक्रेत्यांमध्ये टाळलेल्या प्रति घटना खर्च; CI रचनांमध्ये प्रति यशस्वी तैनाती खर्च. तो लादत असलेली शिस्त — एक जाहीर परिणाम एकक, वाढीव (सरासरी नव्हे) गुणोत्तरे, वर्चस्वित पर्याय आधी काढणे — किंमतीची चर्चा सुरू होण्यापूर्वीच बहुतेक वाईट विक्रेता तुलना संपवते.

## सामान्य चुका

- **वेगवेगळे परिणाम असलेल्या पर्यायांची** ("शोधलेली प्रकरणे" विरुद्ध "समाधान") एकाच CEA मध्ये तुलना — त्यासाठी [खर्च-परिणाम विश्लेषण](../खर्च-परिणाम-विश्लेषण/) किंवा सामान्य परिणाम लागतो.
- **वाढीव गुणोत्तरांची गरज असताना सरासरी खर्च-परिणामकारकता गुणोत्तरे** मांडणे (वरील वेअरेबल उदाहरण).
- **खुशामतीसाठी निवडलेली परिणाम एकके**: "निर्माण झालेले अलर्ट" हे आउटपुट आहे, परिणाम नाही; मूल्य वाहणाऱ्या एककांचा आग्रह धरा.
