# आरोग्य तंत्रज्ञान मूल्यमापन (HTA)

HTA ही औपचारिक, संस्थात्मक प्रक्रिया आहे ज्याद्वारे आरोग्य प्रणाली ठरवतात की तंत्रज्ञान — औषध, उपकरण किंवा सॉफ्टवेअर — पैसे देण्यासारखे आहे का. ती प्रकाशित, अनिवार्य पद्धतीखाली क्लिनिकल-परिणामकारकता पुराव्याला आर्थिक मूल्यमापनाशी जोडते.

## हे का महत्त्वाचे आहे

तुम्ही राष्ट्रीय आरोग्य सेवेला विकत असाल, तर HTA संस्था शब्दशः तुमचा बाजार प्रवेश ठरवू शकते. स्थानिक प्रक्रिया जाणणे म्हणजे तुमचा खरा मूल्य-नियामक जाणणे:

- **NICE (इंग्लंड)**: परिभाषित *संदर्भ प्रकरणाखाली* वैधानिक मूल्यमापने — [EQ-5D](../eq-5d/) मधून QALY, NHS+PSS [दृष्टिकोन](../विश्लेषण-दृष्टिकोन/), 3.5% [सवलत](../सवलत-आणि-काळाबद्दलचे-प्राधान्य/), [PSA](../संभाव्यताधारित-संवेदनशीलता-विश्लेषण/) आवश्यक — £20k–£30k/QALY विरुद्ध [तीव्रता सुधारकांसह](../qaly-तूट-आणि-तीव्रता-सुधारक/) तपासणी; अत्यंत विशेष तंत्रज्ञान भारणासह £100k+ पर्यंत.
- **ICER (US, अ-सरकारी)**: *आरोग्य-लाभ किंमत बेंचमार्क* असलेले पुरावा अहवाल — $100k–$150k प्रति QALY/evLYG वर उत्पादन खर्च-परिणामकारक ठरेल अशी किंमत — वाटाघाटी लीव्हरेज म्हणून वापरली जाते; तसेच अंदाजपत्रक-प्रभाव "परवडण्याचे इशारे."
- **कॅनडा (CADTH → CDA-AMC)**: ≈CAD$50k/QALY वर परतफेड पुनरावलोकने; ऐतिहासिकदृष्ट्या ~95% सादरीकरणांमध्ये किंमत कपात मागितली.

## गणित

HTA ची ताकद सूत्र नसून **अनिवार्य पद्धत** आहे: प्रत्येक सादरीकरण त्याच संदर्भ-प्रकरण नियमांखाली तोच [ICER](../वाढीव-खर्च-परिणामकारकता-गुणोत्तर/) मोजते, म्हणून निकाल उत्पादने आणि वर्षांमध्ये तुलनीय असतात. संदर्भ प्रकरण परिणाम मापन, उपयुक्तता साधन, दृष्टिकोन, तुलनात्मक निवड, सवलत दर, कालावधी क्षितिज आणि अनिश्चितता विश्लेषण निर्दिष्ट करते — प्रायोजक हेराफेरी करू शकेल अशी प्रत्येक स्वातंत्र्याची पातळी काढून टाकते.

## सोडवलेले उदाहरण

एक डिजिटल उपचार पद्धती NICE-शैलीच्या मूल्यमापनात सादर होते:

```
Model: ΔC = +£450/patient, ΔE = +0.03 QALYs → ICER = £15,000/QALY ✓ under £20k
Reference-case checks:
  utilities from EQ-5D-5L with UK value set              ✓
  comparator = current care pathway (not "no treatment") ✓
  PSA: 71% probability cost-effective at £20k            ✓ (reported)
  severity modifier: shortfall below ×1.2 bounds         — none claimed
Recommendation: routine commissioning, with real-world data collection.
```

प्रायोजकाच्या स्वतःच्या पसंतीच्या विश्लेषणात £9,000/QALY दिसले; संदर्भ प्रकरणाने प्रामाणिक तुलनात्मक लादून ते £15,000 वर ढकलले. ती तफावत हेच संदर्भ प्रकरणे *का* अस्तित्वात आहेत याचे कारण.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

हस्तांतरणीय कलाकृती म्हणजे **अंतर्गत संदर्भ प्रकरण**: सर्व टूलिंग/प्लॅटफॉर्म व्यवसाय प्रकरणांसाठी एक अनिवार्य पद्धत — घोषित तुलनात्मक, प्रमाणित एकक खर्च (नमुन्यासाठी [राष्ट्रीय दरपत्रक आणि एकक खर्च](../राष्ट्रीय-दरपत्रक-आणि-एकक-खर्च/) पहा), निश्चित सवलत दर, आवश्यक संवेदनशीलता विश्लेषण, प्रमाणित साचा. प्लॅटफॉर्म परिषदेला सादर केलेला "टूल्ससाठी AMCP-dossier" प्रस्ताव तुलनीय आणि हेराफेरी दृश्य करतो, जसे HTA औषधासाठी करते. NICE ने केले त्यापेक्षा लहान सुरुवात करा: दोन-पानी साचा आणि प्रकाशित किंमत पुस्तक हे कोणत्याही मानकाशिवाय असण्यापेक्षा चांगले.

बहु-चक्र HTA मॉडेल प्रत्यक्षात कोहॉर्ट-दर-चक्र कसे सिम्युलेट केले जाते त्यासाठी [मार्कोव्ह कोहॉर्ट सिम्युलेशन](../मार्कोव्ह-कोहॉर्ट-सिम्युलेशन/) पहा.

## सामान्य चुका

- **नियामक मंजुरीनंतर HTA ला औपचारिकता मानणे** — CE/UKCA/FDA मंजुरी सांगते की उत्पादन सुरक्षित आहे; HTA ठरवते की ते *विकत घेण्यासारखे* आहे का. वेगळा अडथळा, वेगळा पुरावा.
- **चाचणीनंतर आर्थिक मॉडेल बांधणे** — पुरावा निर्मिती संदर्भ प्रकरणाच्या आवश्यकतांपासून मागे रचली पाहिजे.
- **अधिकारक्षेत्र फरकांकडे दुर्लक्ष**: US मध्ये $120k/QALY वर निधीयोग्य ICER NICE मध्ये £30k वर अपयशी ठरतो; प्रत्येक बाजारासाठी पुरावा आणि किंमत नियोजित करा.
