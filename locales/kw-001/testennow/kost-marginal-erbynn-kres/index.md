# Kost Marginal erbynn Kres

Kost kres yw kost oll rannys dre unnysow gwrys. Kost marginal yw kost gwil unn unnys *ekstra*. Dewisyansow a res bos gwrys war kost marginal — mes kostow unys dyllys yw peub-prys kresow.

## Perag yth yw posek

An fowt unn moyha kemmyn yn kasow besneth yeghes nombrek yw talvosya kanasow sawys orth aga host **kres** pan yw an sawyans gwir an kost **marginal**. Dydh gweli klavji a'n jeves kost kres (kowl-absorbys) a £400+, mes relasya unn dydh gweli ny sav £400 — an chi, tomm ha moyha kostow staffya a bes. An arghans relasys yn gwir a yll bos £50–£150 marnas lowr gwelyow a vo rydh dhe dhegya ward.

## An Matematik

```
Kost kres:     AC = TC / Q
Kost marginal: MC = dTC/dQ   (kost unn unnys moy/le)

TC = kost oll, Q = kyfrol
```

Kostow fast a wra MC < AC rag leha kanasow, ha MC a yll dos ogas dhe nul pan eus kanasow spar. Klaymow sawyans a res devnydhya:

```
Sawyans gwir = ΔQ × MC          (chanjow byghan)
Sawyans gwir = step-chanj yn TC (chanjow bras a dreuss harth kanasow, rag ensampel degya ward)
```

## Ensampel gwrys

Dha vedhelweyth a leha hys gortos kres, ow kul 1,000 dydh gweli/bledhen rydh orth trest.

- **Klaym sempel**: 1,000 × £400 kost kres = **£400,000 sawys**. Kamm.
- **Klaym marginal**: kost kewar rag dydh gweli (boes, golghi, devnydhyow, nebes flex nors) ≈ £120. Sawyans = 1,000 × £120 = **£120,000**, *ha* talvos an kanasow rydh mar kwrer dasglenwi gwelyow gans klevyon dewisyek ow kortos (mona yn dann pewas diwar gwrians, po leha rol-gortos).
- **Klaym step-chanj**: mar kwra an trest rydhya 7,300 dydh gweli/bledhen (ward 20-gwely) hi a yll degya an ward yn gwir: staffya + oberya ≈ £1.5 milyon/bledhen a arghans gwir. Lemmyn matematik kost kres yw nes dhe wir.

An keth ynkleth, tri niver defendyek, herwydh mar tresa an chanj step kanasow.

## Kolm gans ynjynnyans medhelweyth

Ekonomek skeul yw tir kost marginal naturel:

- Kost marginal unn ober CI moy war kanasow ervirys seulabrys yw ≈ £0, hag an kost kres rag pub ober (spena platform oll ÷ oberow) a yll bos pownds. Systemow dyllans-war-gwyl a chargya kost kres a dhrif tymow dhe dhiwarth devnydh kanasow rynnys na vo rydh orth an marja.
- Yn kontrari, "ni a sawyas 30% a gompoutya" a re arghans yn unnik pan veu enstansow dhiwysyes po ervirans le gwarthekys — an versyon medhelweyth a'n trap dydh-gweli. Gwelewgh [sawyansow relasya arghans erbynn heb relasya arghans](../sawyansow-relasya-arghans-erbynn-heb-relasya-arghans/).

## Fowtys Kemmyn

- **Talvosya kanasow orth kost kres** ha'y dhiskwedhes avel arghans (an klassek).
- **Tybya bos kost marginal fast.** Hi a step orth harthow kanasow (degyans ward, gradhow lisens, ervirow enstans ervirys).
- **Devnydhya kost marginal rag ystynnans mes kres rag leha yn an keth kas** — dewisewgh herwydh an dewisyans gwir.
