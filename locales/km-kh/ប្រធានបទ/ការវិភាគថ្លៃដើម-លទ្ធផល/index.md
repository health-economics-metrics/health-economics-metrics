# ការវិភាគថ្លៃដើម-លទ្ធផល (CCA)

CCA បង្ហាញថ្លៃដើមរួមជាមួយ **តារាងលទ្ធផលទាំងអស់ដែលបានបំបែក** — គ្លីនិក ប្រតិបត្តិការ បទពិសោធន៍ — ដោយមិនបង្រួមទៅជាសមាមាត្រ ឬពិន្ទុតែមួយ។ អ្នកសម្រេចចិត្តថ្លឹងថ្លែងការដោះដូរដោយបើកចំហ។

## ហេតុអ្វីបានជាសំខាន់

CCA គឺជា **ទម្រង់សេដ្ឋកិច្ចដែល NICE ពេញចិត្តសម្រាប់បច្ចេកវិទ្យាសុខភាពឌីជីថលភាគច្រើន** ក្រោមក្របខ័ណ្ឌស្តង់ដារភស្តុតាង។ ផលិតផលឌីជីថលបង្កើតឥទ្ធិពលខុសគ្នា (ពេលវេលាសន្សំ ការពេញចិត្ត ការកាត់បន្ថយ DNA ផលចំណេញគ្លីនិកតូចៗ) ដែលតទល់នឹងការបូកសរុបស្មោះត្រង់ទៅជាលេខ QALY តែមួយ។ ជំនួសឱ្យការបង្ខំឱ្យមានសមាសធាតុងាយបែក CCA បង្ហាញសៀវភៅគណនេយ្យពេញលេញ។ សម្រាប់ករណីអាជីវកម្មកម្មវិធីភាគច្រើន វាជាទម្រង់ស្មោះត្រង់បំផុត និងបញ្ចុះបញ្ចូលបំផុត ព្រោះអ្នកពាក់ព័ន្ធគ្រប់រូបអាចរកឃើញជួរពាក់ព័ន្ធនឹងការសម្រេចចិត្តរបស់ខ្លួន។

## គណិតវិទ្យា

មិនមានរូបមន្តបូកសរុបដោយចេតនា។ លទ្ធផលគឺជាតារាង៖

```
                          Intervention   Comparator   Difference
Costs (annual)            £X             £Y           ΔC
Outcome 1 (natural units) …              …            Δ1
Outcome 2                 …              …            Δ2
Qualitative outcomes      described, not scored
```

ជួរនីមួយៗរក្សាឯកតារបស់ខ្លួន។ ច្បាប់៖ រាល់ផលវិបាកកំណត់ជាមុន (គ្មានការជ្រើសរើសបន្ទាប់ពីលទ្ធផល); [ទស្សនៈ](../ទស្សនៈនៃការវិភាគ/)ដូចគ្នា និង[ជើងមេឃ](../ព្រំដែនពេលវេលា/)ពេញមួយ; ភាពមិនប្រាកដប្រជាក្នុងមួយជួរ។

## ឧទាហរណ៍ដែលបានគណនា

វេទិកាវាយតម្លៃមុនវះកាត់ឌីជីថល ធៀបនឹងដំណើរការតាមទូរស័ព្ទ ក្នុងមួយឆ្នាំ ទុនមួយ៖

```
                              Digital      Phone       Difference
Running cost                  £180,000     £95,000     +£85,000
Nurse hours on assessments    6,200        11,800      −5,600 hrs
On-day surgery cancellations  92           174         −82
Patient satisfaction (CSAT)   4.5/5        3.9/5       +0.6
Assessments lost/incomplete   1.2%         4.8%        −3.6 pp
```

គ្មានពិន្ទុតែមួយ — ប៉ុន្តែការសម្រេចចិត្តងាយវែកញែក៖ £85,000 ទិញបាន 5,600 ម៉ោងគិលានុបដ្ឋាយិកា (≈ £15/ម៉ោង ទាបជាងថ្លៃបុគ្គលិកណាមួយឆ្ងាយ) ការលុបចោល 82 ដងដែលបានជៀសវាង (ម្នាក់ៗខ្ជះខ្ជាយម៉ោងវះកាត់ដែលមានតម្លៃ ~£1,200) និងបទពិសោធន៍ប្រសើរជាង។ គណៈកម្មការក៏អាចឃើញច្បាស់ពីអ្វីដែលវា *មិនទទួលបាន*៖ គ្មានឥទ្ធិពល QALY ឬមរណភាពដែលបានអះអាង។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

CCA គឺជាកំណែផ្លូវការនៃកាតពិន្ទុតុល្យភាពដែលសំណើវេទិកាល្អប្រើរួចហើយ៖ ថ្លៃដើមជាប់នឹងរង្វាស់ DORA ពិន្ទុ DevEx ចំនួនឧប្បត្តិហេតុ — មិនបូកសរុប។ វិន័យសេដ្ឋកិច្ចសុខាភិបាលដែលត្រូវបន្ថែម៖ **កំណត់ជួរជាមុន** (សម្រេចថាអ្វីរាប់មុនការសាកល្បង ដូច្នេះអ្នកមិនអាចលុបរង្វាស់ដែលកាន់តែអាក្រក់ស្ងាត់ៗ) និង **បង្ហាញជួរមិនអំណោយផល** — CCA ដែលមានតែព័ត៌មានល្អគឺជាទីផ្សារ។ ប្រើ CCA នៅពេលគ្មានសមាសធាតុការពារបាន ដែលសម្រាប់ឧបករណ៍អ្នកអភិវឌ្ឍន៍ស្ទើរតែជានិច្ច។

## កំហុសដែលត្រូវជៀសវាង

- **ផលវិបាកដែលជ្រើសរើស** — សុចរិតភាពនៃទម្រង់អាស្រ័យលើការកំណត់ជាមុន។
- **ការបូកសរុបលួចចូល**៖ ការដាក់ពណ៌ ឬ "ពិន្ទុរួម" នាំចូលម៉ាសុីនទម្ងន់តាមអំពើចិត្តឡើងវិញ ដែល CCA មានដើម្បីជៀសវាង។
- **ភាពស្តូកស្តឹកនៃការសម្រេចចិត្ត**៖ CCA ត្រូវការអ្នកសម្រេចចិត្តដែលចង់ថ្លឹងថ្លែងការដោះដូរ; ផ្គូផ្គងវាជាមួយអនុសាសន៍ និងហេតុផល។
