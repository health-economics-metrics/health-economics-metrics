# សន្ទស្សន៍កំហាប់

សន្ទស្សន៍កំហាប់ (Concentration Index) (Wagstaff, Paci, van Doorslaer, 1991) គឺជារង្វាស់ស្ថិតិស្តង់ដារនៃវិសមភាពទាក់ទងនឹងស្ថានភាពសេដ្ឋកិច្ចសង្គមក្នុងអថេរសុខភាពមួយ ដែលមានចន្លោះពី -1 ដល់ 1។ អវិជ្ជមានមានន័យថាអថេរសុខភាពប្រមូលផ្តុំក្នុងចំណោមអ្នកខ្វះខាតខាងសេដ្ឋកិច្ចសង្គម វិជ្ជមានមានន័យថាប្រមូលផ្តុំក្នុងចំណោមអ្នកមាន ហើយសូន្យមានន័យថាគ្មានជម្រាលសេដ្ឋកិច្ចសង្គមស្របគ្នា — វាបំប្លែងការសង្ស័យអំពីការចែកចាយមិនស្មើទៅជាលេខតែមួយដែលអាចប្រៀបធៀបបាន។

## ហេតុអ្វីបានជាសំខាន់

កម្មវិធីអាចមើលទៅមានប្រសិទ្ធភាពក្នុងសរុប ហើយនៅតែផ្តល់អត្ថប្រយោជន៍ស្ទើរតែទាំងស្រុងដល់មនុស្សដែលមានជីវភាពល្អរួចហើយ។ ក្តីបារម្ភការចែកចាយបែបនេះគឺជាអ្វីដែល[ការឈានដល់ និងសមធម៌](../ការឈានដល់-និងសមធម៌/)តាមដានតាមបែបពិពណ៌នា — ការឈានដល់ដែលបែងចែកតាមប្រាក់ចំណូលខ្វះខាត គម្លាតសមធម៌រវាងក្រុមកំពូល និងបាត — ប៉ុន្តែតារាងបែងចែកមិនបង្រួមទៅជាខ្សែនិន្នាការតែមួយទេ ហើយមិនងាយប្រៀបធៀបឆ្លងអន្តរាគមន៍ពីរខុសគ្នាទាំងស្រុងដែលវាស់លើមាត្រដ្ឋានខុសគ្នា។ សន្ទស្សន៍កំហាប់ដោះស្រាយទាំងពីរបញ្ហា៖ វាត្រូវបានគណនាតាមរបៀបដូចគ្នាសម្រាប់អថេរសុខភាពណាមួយធៀបនឹងចំណាត់ថ្នាក់សេដ្ឋកិច្ចសង្គមណាមួយ ដូច្នេះសេវាសុខាភិបាលជាតិអាចតាមដានថាតើវិសមភាពនៃសេវាឌីជីថលជាក់លាក់មួយកំពុងកើនឡើង ឬថយចុះពីការចេញផ្សាយមួយទៅមួយទៀត ហើយអាចប្រៀបធៀបភាពយុត្តិធម៌ចែកចាយនៃការដាក់ឱ្យប្រើកម្មវិធីធៀបនឹង ឧទាហរណ៍ កម្មវិធីត្រួតពិនិត្យ លើមាត្រដ្ឋានធម្មតាដូចគ្នា។

## គណិតវិទ្យា

```
CI = (2 / mean(health_values)) × Cov(health_values, socioeconomic_ranks)

Cov(X, Y) = mean(X × Y) − mean(X) × mean(Y)   (population covariance)

socioeconomic_ranks: each person's fractional rank in the socioeconomic
distribution, in [0, 1] (0 = most disadvantaged, 1 = most advantaged;
for grouped/banded data, conventionally the midpoint rank of each group)
```

នេះគឺជា "រូបមន្តកូវ៉ារ្យ៉ង់ងាយស្រួល" (O'Donnell, van Doorslaer, Wagstaff, Lindelow, World Bank 2008) — ផ្លូវកាត់អ្នកអនុវត្តស្តង់ដារសម្រាប់គណនាសន្ទស្សន៍កំហាប់ដោយផ្ទាល់ពីការសង្កេតជាគូ ដោយមិនចាំបាច់គូស និងធ្វើអាំងតេក្រាលក្រោមខ្សែកោងកំហាប់មុនឡើយ។

## ឧទាហរណ៍ដែលបានគណនា

ពិន្ទុសុខភាពល្អដែលរាយការណ៍ដោយខ្លួនឯង (1 = អាក្រក់បំផុត 4 = ល្អបំផុត) សង្កេតឆ្លងក្រុមសេដ្ឋកិច្ចសង្គមបួនស្មើគ្នា ដែលនីមួយៗតំណាងដោយចំណាត់ថ្នាក់ចំណុចកណ្តាលក្វាទីល៖

```
health_values        = [1.0, 2.0, 3.0, 4.0]
socioeconomic_ranks  = [0.125, 0.375, 0.625, 0.875]

mean(health_values)        = 2.5
mean(health × rank)        = mean([0.125, 0.75, 1.875, 3.5]) = 1.5625
mean(socioeconomic_ranks)  = 0.5

Cov = 1.5625 − 2.5 × 0.5 = 0.3125

CI = 2 × 0.3125 / 2.5 = 0.25
```

`0.25` វិជ្ជមានមានន័យថាពិន្ទុសុខភាពនេះប្រមូលផ្តុំក្នុងចំណោមក្រុមមានអត្ថប្រយោជន៍សេដ្ឋកិច្ចសង្គម — អ្នកឆ្លើយដែលមានពិន្ទុខ្ពស់ទំនោរទៅចុងមានជីវភាពល្អនៃចំណាត់ថ្នាក់។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

នេះគឺជាការវាស់វិសមភាពផ្អែកលើកូវ៉ារ្យ៉ង់ដូចគ្នាដែលប្រើក្នុងសេដ្ឋកិច្ចទូទៅ (ញាតិនៃមេគុណ Gini) ហើយវាគូសផែនទីលើការវាស់ថាតើអត្ថប្រយោជន៍ផលិតផលកម្មវិធីប្រមូលផ្តុំក្នុងចំណោមផ្នែកអ្នកប្រើដែលមានអត្ថប្រយោជន៍រួចហើយ ជាជាងរាលដាលស្មើភាព — ជាផ្នែកបន្ថែមដោយផ្ទាល់នៃ[ការឈានដល់ និងសមធម៌](../ការឈានដល់-និងសមធម៌/) (វិមាត្រ "ការឈានដល់" នៃ RE-AIM) ទៅជារង្វាស់ស្ថិតិផ្លូវការ ជាជាងគម្លាតដែលបានពិពណ៌នា។ ដែល reach-and-equity រាយការណ៍ផលប៉ះពាល់ក្នុងមួយស្រទាប់ សន្ទស្សន៍កំហាប់បង្រួមការចែកចាយទាំងមូលទៅជាលេខមានសញ្ញាតែមួយ សមស្របជា KPI តាមដានតែមួយឆ្លងការចេញផ្សាយ — ជាក់ស្តែងសម្រាប់ផ្ទាំងគ្រប់គ្រង ដែលការបែងចែកពេញលេញមិនសមស្រប។

## កំហុសដែលត្រូវជៀសវាង

- **ការរសាត់អនុសញ្ញាសញ្ញា**៖ សញ្ញាអាស្រ័យលើរបៀបកំណត់ទាំងអថេរសុខភាព និងចំណាត់ថ្នាក់ — ការត្រឡប់ណាមួយត្រឡប់សញ្ញា ដូច្នេះអនុសញ្ញាដែលបានប្រើត្រូវតែបញ្ជាក់ជានិច្ចជាមួយតម្លៃដែលបានរាយការណ៍។
- **ចំណាត់ថ្នាក់ព្រំដែនជំនួសចំណាត់ថ្នាក់ចំណុចកណ្តាល**៖ ទិន្នន័យសេដ្ឋកិច្ចសង្គមដែលបែងចែកជាក្រុម (ឧទាហរណ៍ ក្វីនទីល) តម្រូវឱ្យប្រើចំណាត់ថ្នាក់ប្រភាគនៃក្រុមនីមួយៗនៅ *ចំណុចកណ្តាល* មិនមែនព្រំដែនទេ បើមិនដូច្នោះទេសន្ទស្សន៍លំអៀង។
- **អានថា "ជិតសូន្យ" ជា "គ្មានវិសមភាព"**៖ សន្ទស្សន៍កំហាប់ជិតសូន្យមានន័យថា "គ្មានជម្រាលសេដ្ឋកិច្ចសង្គមស្របគ្នា" មិនមែន "គ្មានវិសមភាព" ក្នុងន័យដាច់ខាតទេ — វិសមភាពដែលជំនួសគ្នាក្នុងទិសដៅផ្សេងគ្នាអាចលុបគ្នា។
