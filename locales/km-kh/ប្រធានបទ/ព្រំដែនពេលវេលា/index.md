# ព្រំដែនពេលវេលា

ព្រំដែនពេលវេលាគឺជារយៈពេលដែលការវិភាគរាប់ថ្លៃដើម និងផល។ វាត្រូវតែវែងគ្រប់គ្រាន់ដើម្បីចាប់យកភាពខុសគ្នាមានន័យទាំងអស់រវាងជម្រើសដែលកំពុងប្រៀបធៀប។

## ហេតុអ្វីបានជាសំខាន់

ជ្រើសព្រំដែនខ្លី អ្នកនឹងខកខានអត្ថប្រយោជន៍ចុងក្រោយ (ការបង្ការ) និងថ្លៃដើមចុងក្រោយ (ការថែទាំ)។ ជ្រើសព្រំដែនវែងពេក អ្វីៗលង់ក្នុងភាពមិនប្រាកដ។ ការវាយតម្លៃបច្ចេកវិទ្យាសុខភាពជារឿយៗប្រើព្រំដែន **មួយជីវិត** សម្រាប់ការព្យាបាលដែលមានផលប៉ះពាល់មរណភាព; [ការវិភាគផលប៉ះពាល់ថវិកា](../ការវិភាគផលប៉ះពាល់ថវិកា/) ប្រើព្រំដែនខ្លី **1–5 ឆ្នាំ** ដោយចេតនា ពីព្រោះសំណួររបស់វាគឺលទ្ធភាពទទួលបាន មិនមែនតម្លៃទេ។ ព្រំដែនគឺជាជម្រើសគំរូដែលបានប្រកាស ហើយព្រំដែនមិនស៊ីគ្នាគឺជាវិធីបុរាណក្នុងការបន្លំការប្រៀបធៀប។

## គណិតវិទ្យា

ព្រំដែនគឺជាដែនកំណត់ខាងលើនៃផលបូកក្នុងរាល់ការវាយតម្លៃ៖

```
Net present value = Σ (t = 0 … T) [ (Benefits_t − Costs_t) / (1 + r)^t ]

T = time horizon (years)
r = discount rate (see discounting-and-time-preference.md)
```

លទ្ធផលគួររាយការណ៍ជាមួយព្រំដែនដែលបានបញ្ជាក់ ហើយល្អបំផុតបង្ហាញនៅព្រំដែនច្រើន។

## ឧទាហរណ៍ដែលបានគណនា

ប្រព័ន្ធចេញវេជ្ជបញ្ជាអេឡិចត្រូនិកមានថ្លៃអនុវត្ត £2 លាន និង £200,000/ឆ្នាំដើម្បីដំណើរការ។ វាការពារកំហុសថ្នាំតម្លៃ £600,000/ឆ្នាំ (ថ្លៃព្យាបាលនៃគ្រោះថ្នាក់ដែលបានជៀសវាង)។

អត្ថប្រយោជន៍សុទ្ធតាមព្រំដែន (មិនបានបញ្ចុះតម្លៃ ដើម្បីភាពច្បាស់)៖

```
Horizon 1 year:  −2,000,000 − 200,000 + 600,000  = −£1,600,000
Horizon 3 years: −2,000,000 + 3 × 400,000        = −£800,000
Horizon 5 years: −2,000,000 + 5 × 400,000        =  £0
Horizon 10 years:−2,000,000 + 10 × 400,000       = +£2,000,000
```

ប្រព័ន្ធ "បរាជ័យ" នៅព្រំដែនណាក៏ដោយក្រោម 5 ឆ្នាំ ហើយ "ជោគជ័យ" នៅ 10។ មិនមួយណាជាចម្លើយពិតទេ; របាយការណ៍ស្មោះត្រង់ចែងចំណុចតុល្យភាព និងបញ្ជាក់ព្រំដែនតាមអាយុកាលប្រព័ន្ធ (តើយូរប៉ុនណាមុនពេលជំនួស?)។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

- **ការវាយតម្លៃឧបករណ៍ដែលវាស់លើ sprint តែមួយ** ខកខានជាប្រព័ន្ធនូវការធ្លាក់ខ្សែកោងរៀន (ថ្លៃដើមផ្ទុកខាងមុខ) និងការថែទាំរយៈពេលវែង (ថ្លៃដើមផ្ទុកខាងក្រោយ)។ គម្រោងសាកល្បងជំនួយការសរសេរកូដ AI ដែលវាស់នៅសប្តាហ៍ទី 2 ចាប់យកភាពថ្មីថ្មោងកំពូល មិនមែនស្ថានភាពស្ថិរភាពទេ។
- **រយៈពេលកិច្ចសន្យា ≠ ព្រំដែនអត្ថប្រយោជន៍។** កិច្ចសន្យា SaaS 1 ឆ្នាំនៅតែអាចវាយតម្លៃលើ 5 ឆ្នាំ ប្រសិនបើអ្នករំពឹងការបន្តជាក់ស្តែង — ប៉ុន្តែត្រូវនិយាយដូច្នេះ។
- **ករណីជំនួសមរតក** គួរដំណើរការដល់ចុងអាយុកាលគួរឱ្យជឿនៃប្រព័ន្ធចាស់ មិនមែនលេខមូលតាមអំពើចិត្តទេ។

## ចំណុចងាយធ្លាក់

- **ការជ្រើសព្រំដែន**៖ ជ្រើសព្រំដែនណាដែលធ្វើឱ្យជម្រើសរបស់អ្នកឈ្នះ។ ចុះបញ្ជីព្រំដែនជាមុនមុនគណនាលទ្ធផល។
- **ព្រំដែនខុសគ្នាសម្រាប់ជម្រើសខុសគ្នា** ក្នុងការប្រៀបធៀបតែមួយ។
- **ព្រំដែនមួយជីវិតដោយគ្មានការបញ្ចុះតម្លៃ ឬការវិភាគភាពមិនប្រាកដ** — អត្ថប្រយោជន៍ឆ្នាំទី 30 តាមតម្លៃមុខគឺជាប្រលោមលោក។ ផ្គូផ្គងព្រំដែនវែងជាមួយ[ការវិភាគភាពរសើប](../ការវិភាគភាពរសើប/)។
