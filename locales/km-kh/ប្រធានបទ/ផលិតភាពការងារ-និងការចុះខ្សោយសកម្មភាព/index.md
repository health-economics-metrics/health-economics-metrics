# ផលិតភាពការងារ និងការចុះខ្សោយសកម្មភាព (WPAI)

WPAI គឺជាកម្រងសំណួរដោយខ្លួនឯងដែលបានបញ្ជាក់ត្រឹមត្រូវ (Reilly, Zbrozek, Dasbach, 1993) វាស់ថាបញ្ហាសុខភាពប៉ះពាល់ការងារមានប្រាក់ឈ្នួល និងសកម្មភាពប្រចាំថ្ងៃប៉ុន្មាន ជាធម្មតាក្នុង 7 ថ្ងៃកន្លងមក។ វាបំបែកការបាត់បង់ជា *អវត្តមាន* — ពេលវេលាធ្វើការដែលបាត់ពិតប្រាកដ — និង *វត្តមានដែលគ្មានផលិតភាព* — ផលិតភាពថយចុះខណៈពេលនៅកន្លែងធ្វើការ — ហើយទីពីរជាធម្មតាជាសមាសធាតុថ្លៃដើមធំជាង និងលាក់កំបាំងជាង។

## ហេតុអ្វីបានជាសំខាន់

ការរាប់ថ្ងៃឈឺធម្មតាឃើញតែអវត្តមាន។ គ្លីនីសីយាំ ឬអ្នកធ្វើការចំណេះដឹងដែលមិនដែលឈប់មួយថ្ងៃ ប៉ុន្តែធ្វើការនៅសមត្ថភាព 60% ដោយសារស្ថានភាពរ៉ាំរ៉ៃ រួមចំណែកសូន្យចំពោះបញ្ជីអវត្តមាន ខណៈនៅបង្កើតការបាត់បង់ផលិតភាពដ៏ធំពិត — WPAI ត្រូវបានរចនាជាពិសេសដើម្បីលាតត្រដាងថ្លៃដើមមើលមិនឃើញនោះ។ ដោយសារវាជាឧបករណ៍ដែលបានបញ្ជាក់ត្រឹមត្រូវ មិនមែនការស្ទង់មតិផ្ទាល់ខ្លួន ពិន្ទុរបស់វាអាចប្រើបានក្នុងកញ្ចប់ភស្តុតាង[លទ្ធផលដែលអ្នកជំងឺរាយការណ៍](../លទ្ធផលដែលអ្នកជំងឺរាយការណ៍/) និងការសិក្សាថ្លៃដើមជំងឺ ដោយអ្នកពិនិត្យមិនចាំបាច់ផ្ទៀងផ្ទាត់រង្វាស់ឡើងវិញ។ ជាឧបករណ៍រាយការណ៍ដោយខ្លួនឯង វាផ្ទាល់ជាទម្រង់ PROM ខុសគ្នាភាគច្រើនដោយការផ្តោតលើការងារ និងសកម្មភាព ជាជាងរោគសញ្ញា ឬគុណភាពជីវិត។

## គណិតវិទ្យា

```
Absenteeism % = hours_missed_due_to_health / (hours_missed_due_to_health + hours_worked) × 100

Presenteeism %  = self-rated 0–10 impairment while working, × 10
                  (elicited directly via questionnaire, not derived here)

Overall Work Impairment % =
    Absenteeism% + (1 − Absenteeism%/100) × Presenteeism%
    (combines the two so the total can never exceed 100%)

Productivity cost = Overall Work Impairment% / 100 × period_earnings
```

រូបមន្តការចុះខ្សោយសរុបមិនមែនជាផលបូកសាមញ្ញដោយចេតនា៖ ការបូកភាគរយទាំងពីរដោយផ្ទាល់អាចលើស 100% ដូច្នេះវត្តមានដែលគ្មានផលិតភាពត្រូវបានអនុវត្តតែលើចំណែក *ដែលនៅសល់* (មិនអវត្តមាន) នៃពេលវេលាធ្វើការ។

## ឧទាហរណ៍ដែលបានគណនា

និយោជិតម្នាក់ដែលមានជំងឺឈឺក្បាលម្ខាងរាយការណ៍ថាមានកាលវិភាគសប្តាហ៍ 40 ម៉ោង ប៉ុន្តែខកខាន 4 ម៉ោង៖

```
hours_missed = 4, hours_worked = 36
Absenteeism% = 4 / (4 + 36) × 100 = 10%
```

ពួកគេដាក់ពិន្ទុផលប៉ះពាល់ផលិតភាពខណៈធ្វើការដោយខ្លួនឯងដាច់ដោយឡែកថា 3 ក្នុង 10 លើកម្រងសំណួរ WPAI គឺ `Presenteeism% = 30%` (ជំហាននេះគឺជាចម្លើយកម្រងសំណួរឆៅ មិនមែនទាញយកពីលេខផ្សេងទេ)៖

```
Overall Work Impairment% = 10 + (1 − 10/100) × 30
                          = 10 + 0.9 × 30
                          = 10 + 27
                          = 37%
```

ក្នុងសប្តាហ៍ 5 ថ្ងៃដែលរកបាន £800 (£160/ថ្ងៃ)៖

```
Productivity cost = 37/100 × 800 = £296
```

សូមកត់សម្គាល់ថាការរាប់ថ្ងៃឈឺធម្មតានឹងកត់ត្រាតែ 4 ម៉ោង (10%) ដែលខកខាន — សមាសធាតុវត្តមានដែលគ្មានផលិតភាពបង្កើនការចុះខ្សោយពិតជិតបីដងនៅពេលរាប់។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

នេះផ្គូផ្គងដោយផ្ទាល់ទៅនឹងរង្វាស់សុខភាពក្រុមវិស្វកម្ម៖

- **អវត្តមាន** គឺការឈប់សម្រាកឈឺ និង PTO — មើលឃើញ តាមដានរួចហើយ និងជាផ្នែកងាយ។
- **វត្តមានដែលគ្មានផលិតភាព** គឺវិស្វករអស់កម្លាំង ឬផ្ទុកលើសដោយការប្តូរបរិបទ ដែលមានវត្តមានក្នុងរាល់ stand-up ខណៈដំណើរការនៅសមត្ថភាពថយចុះ — ជាធម្មតាថ្លៃដើមធំជាង និងលាក់កំបាំងជាង ហើយមើលមិនឃើញក្នុងទិន្នន័យចំនួនបុគ្គលិក ឬវត្តមាន។ វាបង្ហាញជំនួសជាទិន្នផលថយចុះក្នុង [DORA](../រង្វាស់-dora/) និង[រង្វាស់លំហូរ](../រង្វាស់លំហូរ/) ឬការដោះស្រាយយឺតនៃ[បំណុលបច្ចេកទេស](../បំណុលបច្ចេកទេស/) ដែល "ការប្រាក់" របស់វាបង្កើនការចុះខ្សោយបន្ថែមទៀត។
- មេរៀនវិស្វកម្មដូចគ្នានឹងគ្លីនិក៖ ការវាស់តែអវត្តមាន ហើយហៅវាថា "ការបាត់បង់ផលិតភាព" ប៉ាន់ស្មានថ្លៃដើមពិតទាបជាប្រព័ន្ធ ពីព្រោះវាខកខានអ្នកគ្រប់គ្នាដែលមានវត្តមាន ប៉ុន្តែចុះខ្សោយ។

## ចំណុចងាយធ្លាក់

- **ភាពលំអៀងការចងចាំនៃការរាយការណ៍ដោយខ្លួនឯង។** បង្អួចចងចាំ 7 ថ្ងៃរងការបំភ្លៃការរាយការណ៍ដូចរាល់ការរាយការណ៍ដោយខ្លួនឯងក្រោយ។
- **ការចាត់ទុកមាត្រដ្ឋាន 0–10 វត្តមានដែលគ្មានផលិតភាពជាការវាស់ផ្លូវកាយពិត។** វាជាលំដាប់ ទាញយកដោយការដាក់ពិន្ទុខ្លួនឯង មិនមែនបរិមាណផ្លូវកាយដែលបានបញ្ជាក់ត្រឹមត្រូវទេ — ការចាត់ទុកភាពខុសគ្នាលើវាជាលីនេអ៊ែរ ឬចន្លោះយ៉ាងតឹងរឹង គឺជាភាពងាយស្រួលនៃការធ្វើគំរូ មិនមែនជាអង្គហេតុផ្លូវកាយដែលបានបញ្ជាក់ត្រឹមត្រូវទេ។
- **ការបូកពិន្ទុឆ្លងកំណែ WPAI។** WPAI មានកំណែជាក់លាក់ស្ថានភាពជាច្រើន — WPAI:GH (សុខភាពទូទៅ), WPAI:SHP (បញ្ហាសុខភាពជាក់លាក់) និងកំណែជាក់លាក់ជំងឺ — ហើយពិន្ទុពីកំណែផ្សេងគ្នាមិនគួរបូក ឬប្រៀបធៀបដោយមិនពិនិត្យថាវាជាកំណែឧបករណ៍ដូចគ្នាទេ។
