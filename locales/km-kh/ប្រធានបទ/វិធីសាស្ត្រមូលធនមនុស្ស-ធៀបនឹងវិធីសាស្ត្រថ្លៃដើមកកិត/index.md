# វិធីសាស្ត្រមូលធនមនុស្ស ធៀបនឹងវិធីសាស្ត្រថ្លៃដើមកកិត

ទាំងនេះគឺជាវិធីសាស្ត្រប្រកួតប្រជែងពីរសម្រាប់វាយតម្លៃផលិតភាពដែលបាត់បង់ — ពីជំងឺ ពិការភាព ឬមរណភាព — ក្នុងការសិក្សាថ្លៃដើមនៃជំងឺ និងថ្លៃដើម-អត្ថប្រយោជន៍។ វិធីសាស្ត្រមូលធនមនុស្ស (HCA) វាយតម្លៃលទ្ធផលដែលបាត់បង់ទាំងអស់សម្រាប់រយៈពេលអវត្តមានទាំងមូលតាមអត្រាប្រាក់ឈ្នួល; វិធីសាស្ត្រថ្លៃដើមកកិត (FCM) វាយតម្លៃវាតែសម្រាប់រយៈពេលខ្លីជាងដែលនិយោជកត្រូវការពិតប្រាកដដើម្បីស្តារផលិតកម្ម។ ការជ្រើសរវាងពួកវាផ្លាស់ប្តូរការប៉ាន់ស្មានថ្លៃដើមប្រយោលពីរដង ឬច្រើនជាង។

## ហេតុអ្វីបានជាសំខាន់

ថ្លៃដើមប្រយោល (ផលិតភាព) គឺជាធាតុបន្ទាត់ដែលជជែកគ្នាច្រើនបំផុតមួយក្នុងសេដ្ឋកិច្ចសុខាភិបាល ពិតជាព្រោះវិធីសាស្ត្រស្តង់ដារទាំងពីរមិនយល់ស្របគ្នាយ៉ាងខ្លាំង។ HCA ចាត់ទុករាល់ថ្ងៃអវត្តមានជាថ្ងៃនៃលទ្ធផលដែលសេដ្ឋកិច្ចបាត់បង់ពិតប្រាកដ វាយតម្លៃតាមប្រាក់ឈ្នួលពេញលេញសម្រាប់រយៈពេលពេញលេញ — ឬសម្រាប់មរណភាព ឬពិការភាពអចិន្ត្រៃយ៍ សម្រាប់អាយុការងារដែលនៅសល់។ FCM អះអាងថាក្នុងសេដ្ឋកិច្ចដែលមានការគ្មានការងារធ្វើ និងភាពធូររលុងទីផ្សារការងារ អវត្តមានយូរភាគច្រើនមិនកាត់បន្ថយលទ្ធផលជាតិពិតប្រាកដទេនៅពេលនិយោជកបានបណ្តុះបណ្តាលអ្នកជំនួស ឬចែកចាយការងារឡើងវិញ; មានតែ "រយៈពេលកកិត" — ពេលវេលាស្តារផលិតកម្មទៅកម្រិតមុន — តំណាងការបាត់បង់ពិតប្រាកដ។ ដូច្នេះ FCM បង្កើតការប៉ាន់ស្មានថ្លៃដើមប្រយោលទាបជាង និងអភិរក្សជាងជាប្រព័ន្ធជាង HCA ហើយវិធីសាស្ត្រទាំងពីរមិនមែនជាកំណត់ចំណាំបាតទំព័រដែលអាចជំនួសគ្នាបានទេ៖ ពួកវាជាទ្រឹស្តីសេដ្ឋកិច្ចខុសគ្នាអំពីអត្ថន័យនៃ "ផលិតភាពដែលបាត់បង់"។ នេះក៏ជាមូលហេតុដែល[ករណីយោងរបស់ NICE](../ការវាយតម្លៃបច្ចេកវិទ្យាសុខភាព/)ដកថ្លៃផលិតភាពចេញតាមលំនាំដើម រាយការណ៍ពួកវា ប្រសិនបើសោះ ជាការវិភាគភាពប្រកាន់អារម្មណ៍ទស្សនៈសង្គមដោយឡែក ជាជាងលាយចូល ICER ករណីយោង — សូមមើល[ទស្សនៈនៃការវិភាគ](../ទស្សនៈនៃការវិភាគ/)។

## គណិតវិទ្យា

```
Human Capital Approach:
HCA_cost = daily_wage × days_lost

Friction Cost Method (simplified, capped-at-friction-period form):
FCM_cost = daily_wage × min(days_lost, friction_period_days)

friction_period_days = country/sector-specific estimate of time-to-restore
                        production (historically ~85 days in Dutch iMTA
                        costing guidance; varies by country and is
                        periodically re-estimated)
```

ភាពមិនយល់ស្របទាំងមូលរវាងវិធីសាស្ត្រទាំងពីររស់នៅក្នុង `min()`៖ HCA មិនដែលកំណត់ពិដាន `days_lost` ដូច្នេះថ្លៃដើមបន្តកើនសម្រាប់អវត្តមានទាំងមូល ខណៈ FCM កំណត់ពិដានថ្ងៃដែលបានរាប់នៅរយៈពេលកកិត មិនថាអវត្តមានជាក់ស្តែងវែងប៉ុណ្ណា។

## ឧទាហរណ៍ដែលបានគណនា

និយោជិតមិនបានធ្វើការ `days_lost = 180` ថ្ងៃ ទទួល `daily_wage = £150`។

**វិធីសាស្ត្រមូលធនមនុស្ស**៖

```
HCA_cost = 150 × 180 = £27,000
```

**វិធីសាស្ត្រថ្លៃដើមកកិត** ដោយប្រើរយៈពេលកកិត `friction_period_days = 85` (ស្តង់ដារ iMTA ហូឡង់ប្រវត្តិសាស្ត្រ ដូចការប៉ាន់ស្មានឡើងវិញតាមកាលកំណត់នៃការណែនាំ)៖

```
FCM_cost = 150 × min(180, 85) = 150 × 85 = £12,750
```

£12,750 របស់ FCM គឺតិចជាងពាក់កណ្តាលនៃ £27,000 របស់ HCA សម្រាប់អវត្តមានដូចគ្នា — ជម្រើសវិធីសាស្ត្រតែឯងផ្លាស់ប្តូរករណីថ្លៃដើមនៃជំងឺយ៉ាងសំខាន់ មុនពេលការសន្មតផ្សេងទៀតត្រូវបានប៉ះពាល់។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

នេះគូសផែនទីដោយផ្ទាល់លើរបៀបដែលក្រុមវាយតម្លៃវិស្វករចាកចេញ៖

- **ការគិតថ្លៃអត្រាចាកចេញបែប HCA**៖ វាយតម្លៃការបាត់បង់ជាប្រាក់ខែពេញលេញរបស់វិស្វករដែលបានចាកចេញ សម្រាប់រយៈពេលណាដែលតួនាទីនៅទំនេរ។ នេះគឺជាកំណែអយុត្តិធម៌នៃគំរូថ្លៃអត្រាចាកចេញភាគច្រើន ហើយវាបំប៉ោងការបាត់បង់ដោយហេតុផលដូចគ្នាដែល HCA បំប៉ោងការបាត់បង់ផលិតភាព — វាសន្មតថាសមត្ថភាពទំនេរមានផលិតភាពពេញលេញគ្រប់ពេលវេលា ហើយគ្មានអ្វីផ្សេងស្រូបយកភាពធូររលុង។ សូមមើល[ការរក្សាកម្លាំងពលកម្ម](../ការរក្សាកម្លាំងពលកម្ម/) ដែលកំណត់បរិមាណខ្សែសង្វាក់ជួល/ចូលប្រើ/គ្របដណ្តប់ទំនេរដែលវិធីសាស្ត្រនេះផ្តល់ឱ្យ។
- **ការគិតថ្លៃអត្រាចាកចេញបែប FCM**៖ វាយតម្លៃការបាត់បង់តែសម្រាប់ពេលវេលាពិតប្រាកដទៅបំពេញ-និងឡើងល្បឿននៃអ្នកជំនួស — "រយៈពេលកកិត" វិស្វកម្ម។ នេះគឺជាលេខដែលអាចការពារបានជាងសម្រាប់ករណីអាជីវកម្ម ដូច FCM ជាជម្រើសអភិរក្សជាងក្នុងការសិក្សាថ្លៃដើមនៃជំងឺ។
- វិន័យមូលដ្ឋានដូចគ្នានៅក្នុង[ថ្លៃដើមឱកាស](../ថ្លៃដើមឱកាស/)៖ វាយតម្លៃធនធានដែលត្រូវបានផ្លាស់ទីដោយអ្វីដែលបាត់បង់ពិតប្រាកដ មិនមែនរយៈពេលក្បាលរឿងគុណនឹងអត្រាទេ។

## កំហុសដែលត្រូវជៀសវាង

- **ការលាយ HCA និង FCM ក្នុងការវិភាគតែមួយ ឬរាយការណ៍តែមួយដោយមិនបង្ហាញជម្រើស។** ទិន្នន័យអវត្តមានដូចគ្នាអាចបង្កើតភាពខុសគ្នា 2x+ ក្នុងថ្លៃដើមដែលបានរាយការណ៍តាមវិធីសាស្ត្រ; ជម្រើសត្រូវតែបញ្ជាក់ មិនកប់ទេ។
- **ការប្រើ HCA សម្រាប់ករណីទស្សនៈសង្គមដោយមិនកត់សម្គាល់វាជាការវិភាគភាពប្រកាន់អារម្មណ៍។** ករណីយោងរបស់ NICE ដកថ្លៃផលិតភាពចេញយ៉ាងច្បាស់; ការប៉ាន់ស្មាន HCA ទស្សនៈសង្គមជារបស់ក្នុងការវិភាគសេណារីយ៉ូ មិនមែន ICER ចំណងជើងទេ។
- **ការអនុវត្តវិធីសាស្ត្រទាំងពីរលើការងារគ្មានប្រាក់ឈ្នួល ឬមិនមែនទីផ្សារ (ឧទាហរណ៍ ការថែទាំ) ដោយគ្មានការកែតម្រូវ។** វិធីសាស្ត្រទាំងពីរសន្មតប្រូកស៊ីអត្រាប្រាក់ឈ្នួលសម្រាប់តម្លៃ ដែលមិនផ្ទេរស្អាតទៅការងារគ្មានប្រាក់ឈ្នួលទីផ្សារ។
