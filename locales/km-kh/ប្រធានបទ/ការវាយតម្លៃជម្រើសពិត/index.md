# ការវាយតម្លៃជម្រើសពិត

ការវាយតម្លៃជម្រើសពិតអនុវត្តតក្កវិជ្ជាកំណត់តម្លៃជម្រើសហិរញ្ញវត្ថុចំពោះការសម្រេចចិត្តវិនិយោគពិត (មិនមែនទីផ្សារហិរញ្ញវត្ថុ) — ជាពិសេស *ជម្រើសក្នុងការពង្រីក* គម្រោងមួយនៅពេលក្រោយ ប្រសិនបើវាជោគជ័យ ដោយមិនមានកាតព្វកិច្ច។ គំរូ binomial មួយរយៈសាមញ្ញ (Cox, Ross, Rubinstein, 1979) កំណត់តម្លៃភាពបត់បែននេះដោយផ្ទាល់ ដោយបម្លែង "ចូរបញ្ជូនតូចហើយមើល" ពីការស្មានទៅជាលេខដែលបានកំណត់តម្លៃ។

## ហេតុអ្វីបានជាសំខាន់

ការគណនា NPV ឋិតិវន្តកំណត់តម្លៃគម្រោងជាការភ្នាល់ទាំងអស់ ឬគ្មាន៖ ផ្តល់មូលនិធិ ឬមិនផ្តល់ នៅមាត្រដ្ឋានថ្ងៃនេះ រហូតតទៅ។ គម្រោងពិត — ជាពិសេសការដាក់ពង្រាយសុខភាពឌីជីថលជាដំណាក់កាល — កម្រត្រូវបានភ្នាល់តាមវិធីនោះ៖ ប្រព័ន្ធសុខាភិបាលអាចផ្តល់មូលនិធិគម្រោងសាកល្បងតូចមួយ មើលអ្វីដែលកើតឡើង ហើយប្តេជ្ញាប្រាក់បន្ថែមតែប្រសិនបើវាដំណើរការ។ ភាពបត់បែននោះមានតម្លៃពិត ហើយការមិនអើពើវាធ្វើឱ្យការវិនិយោគជាដំណាក់កាលមានតម្លៃទាបជាងប្រព័ន្ធមួយដងជាប្រព័ន្ធ ដែលផ្ទុយទាំងស្រុងសម្រាប់ដំណើរការទិញដែលផ្តល់រង្វាន់សំណើជាដំណាក់កាលដែលមើលទៅមានសុវត្ថិភាពជាង។ ការវាយតម្លៃជម្រើសពិតកំណត់តម្លៃភាពបត់បែនខ្លួនឯង ដូច្នេះសំណើជាដំណាក់កាលអាចត្រូវបានប្រៀបធៀបយ៉ាងយុត្តិធម៌ជាមួយជម្រើសប្តេជ្ញាពេញលេញ ជាជាងត្រូវបានពិន័យដោយសារមើលទៅតូចជាងលើបន្ទាត់ NPV ឆោតល្ងង់។

## គណិតវិទ្យា

```
Risk-neutral probability of the "up" state:
  p = ((1 + risk_free_rate) − down_factor) / (up_factor − down_factor)

Expansion payoff in each state (floored at zero — expanding is optional):
  payoff_up   = max(project_value × up_factor   − expansion_cost, 0)
  payoff_down = max(project_value × down_factor − expansion_cost, 0)

Option value (discounted expected payoff):
  option_value = (p × payoff_up + (1 − p) × payoff_down) / (1 + risk_free_rate)

Expanded NPV = static_npv + option_value
```

តម្លៃគម្រោងឡើង (`up_factor`) ឬធ្លាក់ (`down_factor`) ត្រឹមចំណុចការសម្រេចចិត្តបន្ទាប់។ ការពង្រីកត្រូវបានអនុវត្តតែប្រសិនបើវាមានប្រាក់ចំណេញក្នុងស្ថានភាពនោះ — ជាន់សូន្យនៃផលតបស្នងគឺជាអ្វីដែលធ្វើឱ្យនេះជា *ជម្រើស* ពិតប្រាកដ ជាជាងកាតព្វកិច្ច។ សម្រាប់កំណត់តម្លៃជម្រើសក្នុងការប្រមូលព័ត៌មានជាមុន ជាជាងជម្រើសក្នុងការពង្រីកនៅពេលក្រោយ សូមមើល[តម្លៃរំពឹងទុកនៃព័ត៌មានល្អឥតខ្ចោះ](../តម្លៃរំពឹងទុកនៃព័ត៌មានល្អឥតខ្ចោះ/)។ សម្រាប់ថ្លៃដើមនៃការរង់ចាំធ្វើការសម្រេចចិត្តនោះ សូមមើល[ថ្លៃដើមនៃការពន្យារ](../ថ្លៃដើមនៃការពន្យារ/)។

## ឧទាហរណ៍ដែលបានគណនា

គម្រោងសាកល្បងសេវាឌីជីថលដែលមាន `project_value = £1,000,000` អាចឡើងដល់ 1.5× ឬធ្លាក់ដល់ 0.5× ត្រឹមចំណុចការសម្រេចចិត្តបន្ទាប់ អត្រាគ្មានហានិភ័យ 8% និងថ្លៃដើមពង្រីក £600,000៖

```
p = (1.08 − 0.5) / (1.5 − 0.5) = 0.58

payoff_up   = max(1,000,000 × 1.5 − 600,000, 0) =  900,000
payoff_down = max(1,000,000 × 0.5 − 600,000, 0) = max(−100,000, 0) = 0

The floor matters: the option would NOT be exercised if the market
disappoints — the £600,000 expansion cost exceeds the £500,000 the
project would be worth in the down state.

option_value = (0.58 × 900,000 + 0.42 × 0) / 1.08
             = 522,000 / 1.08
             ≈ £483,333.33
```

ការបន្ថែមតម្លៃជម្រើសទៅមូលដ្ឋាន NPV ឋិតិវន្ត £200,000៖ NPV ពង្រីក = 200,000 + 483,333.33 ≈ **£683,333.33**។ ការរាយការណ៍ NPV ឋិតិវន្ត £200,000 តែម្យ៉ាង ដោយគ្មានតម្លៃជម្រើសនេះ នឹងប៉ាន់ស្មានតម្លៃពិតនៃគម្រោងជាដំណាក់កាលទាបជាងពាក់កណ្តាល។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

នេះគឺជាកំណែផ្លូវការនៃ "បញ្ជូនកំណែអប្បបរមាឥឡូវនេះ រក្សាជម្រើសវិនិយោគបន្ថែមប្រសិនបើវាចាប់ផ្តើម" — ពាក់ព័ន្ធដោយផ្ទាល់នឹងការដាក់ពង្រាយផលិតផលសុខភាពឌីជីថលជាដំណាក់កាល ស្របតាមរចនាសម្ព័ន្ធជាមួយ[ថ្លៃដើមនៃការពន្យារ](../ថ្លៃដើមនៃការពន្យារ/) និងការដាក់ស៊ុមលំដាប់ក្រោមភាពមិនប្រាកដរបស់ [WSJF/CD3](../wsjf-និង-cd3/) ហើយបំពេញបន្ថែម[តម្លៃរំពឹងទុកនៃព័ត៌មានល្អឥតខ្ចោះ](../តម្លៃរំពឹងទុកនៃព័ត៌មានល្អឥតខ្ចោះ/) និង[តម្លៃរំពឹងទុកនៃព័ត៌មានគំរូ](../តម្លៃរំពឹងទុកនៃព័ត៌មានគំរូ/) — ទាំងបីកំណត់តម្លៃភាពបត់បែន ឬព័ត៌មានក្រោមភាពមិនប្រាកដ ពីមុំផ្សេងគ្នា។

## ចំណុចងាយធ្លាក់

- **ការខ្ចីការកំណត់តម្លៃអព្យាក្រឹតហានិភ័យ ដោយគ្មានការសន្មត់ទ្រព្យសកម្មដែលជួញដូរ ដែលវាពឹងផ្អែក**៖ គំរូជម្រើសពិតខ្ចីប្រូបាប៊ីលីតេអព្យាក្រឹតហានិភ័យពីការកំណត់តម្លៃជម្រើសហិរញ្ញវត្ថុ ដែលសន្មត់ថាតម្លៃមូលដ្ឋានជាទ្រព្យសកម្ម *ដែលជួញដូរ* — សម្រាប់គម្រោងពិតដែលមិនជួញដូរជាក់ស្តែង នេះគឺជាភាពងាយស្រួលនៃការធ្វើគំរូ មិនមែនអង្គហេតុទីផ្សារតាមព្យញ្ជនៈទេ។
- **ការចាត់ទុក `up_factor`/`down_factor` ជាប៉ារ៉ាម៉ែត្រសេរី**៖ ធាតុចូលឡើង/ចុះ binomial ខ្លួនឯងជាការសន្មត់ដែលត្រូវការហេតុផល មិនមែនប៉ារ៉ាម៉ែត្រសេរីដែលជ្រើសដើម្បីផលិតចម្លើយដែលចង់បានទេ។
- **ការរាយការណ៍តម្លៃជម្រើសតែឯង**៖ តម្លៃជម្រើសពិត *បន្ថែម* លើ NPV ឋិតិវន្តនៃគម្រោងឯករាជ្យ — កំហុសទូទៅគឺរាយការណ៍តែតម្លៃជម្រើស ហើយទម្លាក់ករណីមូលដ្ឋាន ដែលបំផ្លើសករណីប្រសិនបើ NPV ឋិតិវន្តអវិជ្ជមាន ហើយប៉ាន់ស្មានទាប (ដូចក្នុងឧទាហរណ៍ខាងលើ) នៅពេល NPV ឋិតិវន្តត្រូវបានទុកចោលទាំងស្រុង។
