# ការបញ្ចុះតម្លៃ និងចំណូលចិត្តពេលវេលា

ការបញ្ចុះតម្លៃ (discounting) បម្លែងថ្លៃដើម និងអត្ថប្រយោជន៍អនាគតទៅជាតម្លៃបច្ចុប្បន្ន ព្រោះអត្ថប្រយោជន៍ថ្ងៃនេះមានតម្លៃជាងអត្ថប្រយោជន៍ដូចគ្នាក្នុងរយៈពេលប្រាំឆ្នាំ។

## ហេតុអ្វីបានជាសំខាន់

រាល់ការវាយតម្លៃសេដ្ឋកិច្ចសុខាភិបាល និងរាល់ករណីអាជីវកម្មវិស័យសាធារណៈធ្ងន់ធ្ងរបញ្ចុះតម្លៃលំហូរច្រើនឆ្នាំ។ Green Book របស់ HM Treasury ចក្រភពអង់គ្លេសតម្រូវអត្រាចំណូលចិត្តពេលវេលាសង្គម 3.5% ក្នុងមួយឆ្នាំ; ករណីយោងរបស់ NICE បញ្ចុះតម្លៃទាំងថ្លៃដើម និងផលប៉ះពាល់សុខភាពក្នុង 3.5% ក្នុងមួយឆ្នាំ (ជាមួយអត្រាករណីមិនយោង 1.5% សម្រាប់ការព្យាបាលជិតជាសះស្បើយដែលមានអត្ថប្រយោជន៍ 30+ ឆ្នាំ)។ ប្រសិនបើករណីអាជីវកម្មកម្មវិធីរបស់អ្នកអះអាង "សន្សំ £5 លានក្នុងរយៈពេល 10 ឆ្នាំ" អ្នកពិនិត្យហិរញ្ញវត្ថុនឹងសុំតួលេខដែលបានបញ្ចុះតម្លៃភ្លាមៗ។

## គណិតវិទ្យា

តម្លៃបច្ចុប្បន្ននៃចំនួនអនាគត៖

```
PV = FV / (1 + r)^t

PV = present value
FV = future value in year t
r  = discount rate (NICE/Green Book: 0.035)
t  = years from now
```

សម្រាប់អត្ថប្រយោជន៍ប្រចាំឆ្នាំថេរ B លើ n ឆ្នាំ (annuity)៖

```
PV = B × [1 − (1 + r)^(−n)] / r
```

## ឧទាហរណ៍ដែលបានគណនា

កម្មវិធីរបស់អ្នកសន្សំទុន NHS £100,000 ក្នុងមួយឆ្នាំរយៈពេល 5 ឆ្នាំ ចាប់ផ្តើមមួយឆ្នាំបន្ទាប់ពីដាក់ឱ្យប្រើ។

សរុបមិនបញ្ចុះតម្លៃ៖ £500,000។

បញ្ចុះតម្លៃក្នុង 3.5%៖

```
Year 1: 100,000 / 1.035^1 = £96,618
Year 2: 100,000 / 1.035^2 = £93,351
Year 3: 100,000 / 1.035^3 = £90,194
Year 4: 100,000 / 1.035^4 = £87,144
Year 5: 100,000 / 1.035^5 = £84,197

Total PV ≈ £451,505
```

ចំណងជើងស្មោះត្រង់គឺប្រហែល £451,000 តិចជាងផលបូកដោយអស់កល្ប ~10%។ ឥឡូវនេះសន្មតថាការផ្តល់ជូនយឺតមួយឆ្នាំ៖ រាល់ពាក្យផ្លាស់ទៅក្រោយមួយឆ្នាំ ហើយ PV ធ្លាក់ទៅប្រហែល £436,000 — ទិដ្ឋភាពបញ្ចុះតម្លៃនៃ[ថ្លៃដើមនៃការពន្យារ](../ថ្លៃដើមនៃការពន្យារ/)។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

- **ការសងបំណុលបច្ចេកទេស និងការធ្វើចំណាកស្រុកវេទិកា** សន្យាលំហូរអត្ថប្រយោជន៍នៅឆ្នាំខាងមុខ; បញ្ចុះតម្លៃវាមុនប្រៀបធៀបនឹងការងារដែលសងត្រឡប់ត្រីមាសនេះ។
- **ថ្លៃដើមមុខ អត្ថប្រយោជន៍ក្រោយ** គឺជារូបរាងស្តង់ដារនៃការធ្វើចំណាកស្រុក។ ការបញ្ចុះតម្លៃដាក់ទណ្ឌកម្មរូបរាងនោះ ដោយត្រឹមត្រូវ៖ វាកំណត់តម្លៃពេលវេលាគ្មានហានិភ័យនៃការបញ្ចូលសមត្ថភាពឥឡូវសម្រាប់តម្លៃក្រោយ។
- **ការអះអាង "សន្សំក្នុងឆ្នាំទី 5"** សមនឹងការសង្ស័យពីរដង — ពួកវាទាំងត្រូវបានបញ្ចុះតម្លៃខ្លាំង និងមិនប្រាកដប្រជាខ្ពស់ (សូមមើល[ការវិភាគភាពប្រកាន់អារម្មណ៍](../ការវិភាគភាពរសើប/))។

## កំហុសដែលត្រូវជៀសវាង

- **បញ្ចុះតម្លៃថ្លៃដើមប៉ុន្តែមិនបញ្ចុះអត្ថប្រយោជន៍** (ឬច្រាស់មកវិញ) — ករណីយោងបញ្ចុះតម្លៃទាំងពីរ ក្នុងអត្រាដូចគ្នា។
- **ការប្រើអត្រាពាណិជ្ជកម្ម (8–12%) ក្នុងករណីវិស័យសាធារណៈ** ឬ 3.5% ក្នុងករណីដែលមានមូលនិធិវិនិយោគ។ ផ្គូផ្គងអត្រាទៅនឹងអ្នកសម្រេចចិត្ត។
- **ការច្រឡំការបញ្ចុះតម្លៃជាមួយអតិផរណា។** ការបញ្ចុះតម្លៃអនុវត្តលើតម្លៃ *ពិត* (កែតម្រូវអតិផរណា); កុំធ្វើទាំងពីរដោយប្រយោល។
