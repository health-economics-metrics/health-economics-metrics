# ការវិភាគថ្លៃដើម-ឧបយោគ (CUA)

CUA គឺជាការវិភាគប្រសិទ្ធភាពថ្លៃដើមជាមួយ **លទ្ធផលទូទៅដែលថ្លឹងតាមចំណូលចិត្ត** — ស្ទើរតែជានិច្ចជា [QALY](../ឆ្នាំជីវិតដែលកែតម្រូវតាមគុណភាព/) (ឬ [DALY](../ឆ្នាំជីវិតដែលកែតម្រូវតាមពិការភាព/) ដែលបានជៀសវាង)។ ដោយសារឯកតាលទ្ធផលជាសកល CUA អាចប្រៀបធៀបអន្តរាគមន៍ឆ្លងជំងឺខុសគ្នាទាំងស្រុង។

## ហេតុអ្វីបានជាសំខាន់

សេវាសុខាភិបាលជាតិត្រូវជ្រើសរវាងថ្នាំមហារីក កម្មវិធីសុខភាពផ្លូវចិត្ត និងរ៉ូបូតវះកាត់ ពីថវិកាតែមួយ។ ឯកតាធម្មជាតិមិនអាចប្រៀបធៀបពួកវាបាន; QALYs អាច។ ដូច្នេះ CUA គឺជាវិធីសាស្ត្រករណីយោងនៅ NICE និងស្ថាប័ន HTA ភាគច្រើន៖ លទ្ធផលរបស់វា — ថ្លៃដើមក្នុងមួយ QALY ដែលវិនិច្ឆ័យធៀបនឹង[កម្រិត](../កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់/) — គឺជាអ្វីដែលជិតបំផុតនឹងអត្រាប្តូរប្រាក់សកលដែលគោលនយោបាយសុខភាពមាន។ ប្រសិនបើអ្នកចង់ឱ្យកម្មវិធីរបស់អ្នកទទួលមូលនិធិ *ជំនួសឱ្យអ្វីផ្សេង* CUA គឺជាសង្វៀន។

## គណិតវិទ្យា

```
ICUR = ΔCost / ΔQALYs      (the ICER with QALYs as the effect unit)

ΔQALYs = Σ (duration_i × utility_i)_new − Σ (duration_i × utility_i)_old
```

ឧបយោគមកពីឧបករណ៍ដែលបានផ្ទៀងផ្ទាត់ ([EQ-5D](../eq-5d/)); ទាំងថ្លៃដើម និង QALYs ត្រូវ[បញ្ចុះតម្លៃ](../ការបញ្ចុះតម្លៃ-និងចំណូលចិត្តពេលវេលា/)ក្នុង 3.5% (ករណីយោង NICE); ភាពមិនប្រាកដប្រជាតាម [PSA](../ការវិភាគភាពរសើបប្រូបាប៊ីលីស្ទិក/)។

## ឧទាហរណ៍ដែលបានគណនា

កម្មវិធី CBT សម្រាប់ការថប់បារម្ភកម្រិតមធ្យម ធៀបនឹងបញ្ជីរង់ចាំព្យាបាលជាមុខ ក្នុងមួយអ្នកជំងឺ៖

```
Costs:  app licence + support        £250
        therapy displaced            −£680   (40% of users no longer need it)
        ΔC = 250 − 680 = −£430 (saves money)

QALYs:  6 months at utility 0.76 instead of 0.68 while waiting
        ΔE = 0.5 × (0.76 − 0.68) = +0.04 QALYs
```

ΔC < 0 និង ΔE > 0៖ កម្មវិធី **លេចធ្លោ** — ល្អជាង និងថោកជាង មិនត្រូវការសមាមាត្រទេ។ ប្រសិនបើការសន្មតជំនួសការព្យាបាលមានត្រឹម 10% ΔC = 250 − 170 = +£80 ហើយ ICUR = 80 / 0.04 = **£2,000/QALY** — នៅតែទាបជាង £20,000 ឆ្ងាយ។ ករណីរស់រានមានជីវិតសូម្បីតែការសន្មតសំខាន់ត្រូវបានកាត់បន្ថយ៖ នោះគឺជាអ្វីដែល CUA រឹងមាំមើលទៅដូច (ហើយ[ដ្យាក្រាមព្យុះកំបុតត្បូង](../ការវិភាគភាពរសើប/)បញ្ជាក់វា)។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

គំនិតជ្រៅរបស់ CUA — *ឯកតាសមាសធាតុមួយ ថ្លឹងតាមចំណូលចិត្ត ដើម្បីប្រៀបធៀបរបស់មិនដូចគ្នា* — គឺជាគំរូសម្រាប់ប្រៀបធៀបការវិនិយោគវិស្វកម្មមិនដូចគ្នា (សុវត្ថិភាព ធៀបនឹងបទពិសោធន៍អ្នកអភិវឌ្ឍន៍ ធៀបនឹងភាពអាចទុកចិត្តបាន)។ ជម្រើសស្មោះត្រង់គឺឯកតាសមាសធាតុការពារបាន (កម្រ) ឬ[តារាងថ្លៃដើម-លទ្ធផល](../ការវិភាគថ្លៃដើម-លទ្ធផល/)ច្បាស់លាស់ (ធម្មតា)។ អ្វីដែល CUA ព្រមានប្រឆាំងគឺសមាសធាតុក្លែងក្លាយ៖ "ពិន្ទុផលប៉ះពាល់" ថ្លឹងដែលទម្ងន់ត្រូវបានលៃតម្រូវក្រោយការពិតដើម្បីឱ្យជម្រើសដែលពេញចិត្តឈ្នះ។ សេដ្ឋកិច្ចសុខាភិបាលបានចំណាយទសវត្សរ៍ធ្វើស្តង់ដារការទាញយកឧបយោគ ពិតជាដើម្បីឱ្យទម្ងន់មកមុនការប្រៀបធៀប។

## កំហុសដែលត្រូវជៀសវាង

- **ផលចំណេញឧបយោគក្រោមភាពប្រកាន់អារម្មណ៍របស់ឧបករណ៍** (សូមមើលភាពខុសគ្នាគ្លីនិកសំខាន់អប្បបរមាក្នុង[លទ្ធផលរាយការណ៍ដោយអ្នកជំងឺ](../លទ្ធផលដែលអ្នកជំងឺរាយការណ៍/)) — ΔE តូចគុណប្រជាជនធំគឺជាល្បិចលាងស្អាតបុរាណ។
- **ខ្វះការជំនួសការថែទាំអ្នកប្រៀបធៀប** — ពាក្យថ្លៃដើមធំបំផុតសម្រាប់ផលិតផលឌីជីថលជារឿយៗគឺអ្វីដែលវាជំនួស។
- **ការគូសផែនទីពិន្ទុមិនមែនចំណូលចិត្តទៅឧបយោគ** ជាមួយតារាងប្តូរដែលមិនបានផ្ទៀងផ្ទាត់។
