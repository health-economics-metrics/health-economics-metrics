# សេដ្ឋកិច្ចនៃការពិនិត្យ

សេដ្ឋកិច្ចនៃការពិនិត្យគ្រប់គ្រងតម្លៃនៃការធ្វើតេស្តលើប្រជាជនដែលគ្មានរោគសញ្ញា។ អង្គហេតុគណិតវិទ្យាស្នូល៖ **នៅប្រេវ៉ាឡង់ជំងឺទាប សូម្បីតេស្តល្អឥតខ្ចោះក៏បង្កើតវិជ្ជមានមិនពិតភាគច្រើន** — ហើយថ្លៃដើមខាងក្រោមនៃការដេញតាមវាអាចលើសអត្ថប្រយោជន៍នៃការរកឃើញពិត។

## ហេតុអ្វីបានជាសំខាន់

តាំងពីឆ្នាំ 1968 លក្ខណៈវិនិច្ឆ័យ Wilson–Jungner របស់ WHO បានកំណត់របារសម្រាប់ការពិនិត្យប្រជាជន៖ ស្ថានភាពត្រូវសំខាន់ តេស្តត្រូវអាចទទួលយកបាន និងត្រឹមត្រូវ ត្រូវមានការព្យាបាលមានប្រសិទ្ធភាព ហើយសេដ្ឋកិច្ចត្រូវស្មើគ្នា។ គណៈកម្មាធិការពិនិត្យជាតិអង់គ្លេសអនុវត្តការវិភាគប្រសិទ្ធភាពថ្លៃដើមផ្លូវការ មុនអនុម័តកម្មវិធីជាតិណាមួយ — ហើយបដិសេធសំណើភាគច្រើន។ រាល់ការផ្តល់ជូន "AI នឹងពិនិត្យអ្នកគ្រប់គ្នាសម្រាប់អ្វីៗទាំងអស់" ប៉ះនឹងយន្តការនេះ ហើយជាធម្មតាចាញ់នព្វន្ធខាងក្រោម។

## គណិតវិទ្យា

តម្លៃព្យាករណ៍វិជ្ជមាន (PPV) — ប្រូបាប៊ីលីតេដែលលទ្ធផលវិជ្ជមានជាការពិត — ធ្លាក់ចុះនៅប្រេវ៉ាឡង់ទាប៖

```
PPV = (sens × prev) / [sens × prev + (1 − spec) × (1 − prev)]

Example: sensitivity 90%, specificity 95%, prevalence 0.5%:
PPV = (0.9 × 0.005) / (0.9 × 0.005 + 0.05 × 0.995)
    = 0.0045 / (0.0045 + 0.04975) ≈ 8.3%
```

វិជ្ជមានដប់មួយក្នុងដប់ពីរគឺមិនពិត។ សេដ្ឋកិច្ចកម្មវិធីពេញលេញ៖

```
Cost per true case found = (screening cost + workup cost × all positives) / true positives
Then: is finding a case worth that? (earlier-intervention value per case,
      minus overdiagnosis harm — cases found that would never have mattered)
```

## ឧទាហរណ៍ដែលបានគណនា

ការពិនិត្យរីទីណា AI សម្រាប់ស្ថានភាពកម្រ 100,000 នាក់ ប្រេវ៉ាឡង់ 0.5% sens 90% spec 95% ការស្កេន £15 ការត្រួតពិនិត្យបញ្ជាក់ £400៖

```
True positives:  100,000 × 0.005 × 0.90 = 450
False positives: 100,000 × 0.995 × 0.05 = 4,975
Cost = 100,000 × 15 + (450 + 4,975) × 400 = 1.5M + 2.17M = £3.67M
Cost per true case ≈ £8,156
```

ប្រសិនបើការព្យាបាលឆាប់សន្សំ £20,000 + 1 QALY ក្នុងមួយករណី កម្មវិធីឆ្លងកាត់យ៉ាងងាយ។ បង្កើនភាពជាក់លាក់ទៅ 99% (ការជូនដំណឹងមិនពិតតិចជាង)៖ ថ្លៃដើមត្រួតពិនិត្យធ្លាក់ទៅ (450 + 995) × 400 = £0.58M សរុប £2.08M ថ្លៃដើមក្នុងមួយករណី ≈ **£4,622** — ភាពជាក់លាក់ មិនមែនភាពប្រែប្រួលទេ គឺជាកន្លែងដែលសេដ្ឋកិច្ចការពិនិត្យត្រូវបានឈ្នះនៅប្រេវ៉ាឡង់ទាប។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ការវិភាគឋិតិវន្ត ការស្កេនសុវត្ថិភាព និងការរកឃើញភាពមិនប្រក្រតី គឺជាកម្មវិធីពិនិត្យលើមូលដ្ឋានកូដ និងតេឡេមេទ្រី ជាមួយប្រេវ៉ាឡង់កំហុសពិតជាញឹកញាប់ក្រោម 1% ក្នុងមួយឱកាសជូនដំណឹង។ គណិតវិទ្យាដូចគ្នាពន្យល់ភាពអស់កម្លាំងពីការជូនដំណឹង៖ ម៉ាស៊ីនស្កេនភាពជាក់លាក់ 95% លើកូដប្រេវ៉ាឡង់ទាបលិចលង់ក្រុមក្នុងវិជ្ជមានមិនពិត ហើយរាល់វិជ្ជមានមិនពិតចំណាយការយកចិត្តទុកដាក់ និងបំផ្លាញទំនុកចិត្តរហូតការជូនដំណឹងពិតត្រូវបានមិនអើពើ (ពាក្យគ្លីនិកគឺ *គ្រោះថ្នាក់ពីការពិនិត្យ*; ពាក្យវិស្វកម្មគឺ *ភាពស្ពឹកនៃ pager*)។ ការព្យាបាលផ្ទេរពីសុខភាព៖ បង្កើនភាពជាក់លាក់មុនភាពប្រែប្រួល ពិនិត្យប្រជាជនរងប្រេវ៉ាឡង់ខ្ពស់ជាង (ការកំណត់គោលដៅផ្អែកលើហានិភ័យ ↔ ការស្កេនតែកូដដែលបានផ្លាស់ប្តូរ) និងរាប់ថ្លៃដើមចាត់ថ្នាក់ក្នុងសេដ្ឋកិច្ចឧបករណ៍ — សូមមើល [NNT](../ចំនួនដែលត្រូវព្យាបាល/) និង[ការវាយតម្លៃ AI គ្លីនិក](../ការវាយតម្លៃ-ai-គ្លីនិក/)។ សម្រាប់កំណត់ទំហំកម្មវិធីពិនិត្យទាំងមូល ជាជាងតេស្តមួយ សូមមើល[ចំនួនដែលត្រូវពិនិត្យ](../ចំនួនដែលត្រូវពិនិត្យ/) — មនុស្សប៉ុន្មាននាក់ត្រូវឆ្លងកាត់ផ្លូវពិនិត្យរួចព្យាបាលទាំងមូល ដើម្បីការពារលទ្ធផលមួយ។

## ចំណុចងាយធ្លាក់

- **ការដកស្រង់ភាពប្រែប្រួល/ភាពជាក់លាក់ដោយគ្មានប្រេវ៉ាឡង់** — ភាពត្រឹមត្រូវដោយគ្មាន PPV គឺជាការទីផ្សារ។
- **ការមិនអើពើការធ្វើរោគវិនិច្ឆ័យលើស**៖ ការរកឃើញ "ជំងឺ" ដែលមិនរីកចម្រើនដែលមិនដែលបង្កគ្រោះថ្នាក់ បង្កថ្លៃដើមការព្យាបាល និងគ្រោះថ្នាក់ពិត។
- **ភាពលំអៀងពេលវេលាដឹកនាំ**៖ ការរកឃើញឆាប់ជាងដោយគ្មានលទ្ធផលផ្លាស់ប្តូរ បំផ្លើសការរស់រានជាក់ស្តែង — សូមមើល[អន្តរាគមន៍ឆាប់ជាង](../អន្តរាគមន៍ឆាប់ជាង/)។
