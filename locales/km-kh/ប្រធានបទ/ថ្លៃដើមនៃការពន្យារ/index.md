# ថ្លៃដើមនៃការពន្យារ (CoD)

ថ្លៃដើមនៃការពន្យារ (Cost of Delay) គឺជាតម្លៃសេដ្ឋកិច្ចដែលបាត់បង់ក្នុងមួយឯកតាពេលវេលា ដែលមុខងារ ផលិតផល ឬសេវា *មិន* ត្រូវបានផ្តល់ជូន។ វាជាស្ពានខ្លាំងបំផុតតែមួយរវាងរង្វាស់ផ្តល់ជូនកម្មវិធី និងសេដ្ឋកិច្ចសុខាភិបាល៖ វាបំប្លែង "យើងបានចេញយឺត" ទៅជារូបិយប័ណ្ណ — ឬ QALYs។

## ហេតុអ្វីបានជាសំខាន់

ច្បាប់របស់ Reinertsen៖ "បើអ្នកកំណត់បរិមាណតែរឿងមួយ ចូរកំណត់បរិមាណថ្លៃដើមនៃការពន្យារ។" អង្គការភាគច្រើនដឹងថាគម្រោងមួយចំណាយប៉ុន្មាន ប៉ុន្តែមិនដឹងថាការពន្យារមួយខែចំណាយប៉ុន្មាន ដូច្នេះពួកគេបង្កើនប្រសិទ្ធភាពថវិកាខណៈហូរឈាមតម្លៃពេលវេលា។ សម្រាប់កម្មវិធីសុខាភិបាល ភាគហ៊ុនគឺព្យញ្ជនៈ៖ រាល់សប្តាហ៍ដែលការកែលម្អផ្លូវត្រូវបានពន្យារ អ្នកជំងឺរង់ចាំយូរជាងក្នុងស្ថានភាពសុខភាពអាក្រក់ជាង។ CoD គឺជាក្របខ័ណ្ឌគណិតវិទ្យាខ្លាំងបំផុតដើម្បីបង្ហាញដល់អ្នកពាក់ព័ន្ធ NHS ព្រោះវាកំណត់តម្លៃ *អវត្តមាន* នៃកម្មវិធីរបស់អ្នក។

## គណិតវិទ្យា

```
CoD = benefit per unit time forgone while undelivered   (£/week or QALYs/week)

Total delay loss = CoD × delay duration

For prioritization, see wsjf-and-cd3.md: CD3 = CoD / duration.
```

សម្រាប់កម្មវិធីគ្លីនិក កំណត់ជាសុខភាពក៏ដូចជារូបិយវត្ថុ៖

```
CoD_health = patients affected per week × QALY gain per patient
CoD_money  = CoD_health × λ (willingness-to-pay threshold, £20k–30k/QALY)
             + operational savings per week forgone
```

## ឧទាហរណ៍ដែលបានគណនា

**ប្រតិបត្តិការ**៖ កម្មវិធីសន្សំ £200 ក្នុងមួយអ្នកជំងឺលើផ្លូវ; ទុនដំណើរការអ្នកជំងឺបែបនេះ 50 នាក់/សប្តាហ៍។

```
CoD = 200 × 50 = £10,000/week
A 10-week procurement delay costs 200 × 50 × 10 = £100,000 in avoidable waste.
```

**គ្លីនិក**៖ ការកែលម្អការចាត់ថ្នាក់ដកការរង់ចាំ 5 សប្តាហ៍ (ឧបយោគ 0.68 → 0.80 លឿនជាង) សម្រាប់អ្នកជំងឺ 100 នាក់/សប្តាហ៍៖

```
QALY gain per patient = (5/52) × 0.12 ≈ 0.0115
CoD_health = 100 × 0.0115 = 1.15 QALYs/week
CoD_money  = 1.15 × £20,000 ≈ £23,000/week of health value
```

ការពន្យារការដាក់ឱ្យប្រើ 6 ខែ "ចំណាយ" ~30 QALYs — អាគុយម៉ង់ដែលកំណត់ការរអិលនៃការចេញ IT ឡើងវិញជាព្រឹត្តិការណ៍គ្លីនិក។ (ស្តង់ដារសម្រាប់មាត្រដ្ឋាន៖ ការវិភាគ Maersk ដ៏ល្បីរបស់ Black Swan Farming បានរកឃើញមុខងារតែមួយដែលមាន CoD ≈ $200k/សប្តាហ៍ ដែលបានរង់ចាំ 38 សប្តាហ៍។)

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

CoD គឺជារង្វាស់ដែលធ្វើឱ្យ[ពេលវេលាដឹកនាំ DORA](../រង្វាស់-dora/) និង[ប្រសិទ្ធភាពលំហូរ](../រង្វាស់លំហូរ/)អាចអានបានផ្នែកហិរញ្ញវត្ថុ៖ ពេលវេលាដឹកនាំ × CoD = ប្រាក់ (ឬសុខភាព) ដែលឆេះក្នុងជួរ។ ការប្រើប្រាស់៖

- **ការកំណត់អាទិភាព**៖ ចំណាត់ថ្នាក់ការងារតាម CoD/រយៈពេល ([WSJF/CD3](../wsjf-និង-cd3/)) ជំនួសឱ្យអ្នកពាក់ព័ន្ធដែលខ្លាំងបំផុត។
- **សេដ្ឋកិច្ចដំណើរការ**៖ ចង្វាក់ចេញផ្សាយ 2 សប្តាហ៍មានថ្លៃដើមពន្យារដែលរំពឹងទុក ~1 សប្តាហ៍ × CoD ក្នុងមួយមុខងារ ធៀបនឹងការផ្តល់ជូនបន្តបន្ទាប់ — កំណត់តម្លៃបាច់។
- **ការទិញ**៖ វដ្តទិញរបស់ NHS 6–18 ខែមាន CoD; ការបង្ហាញវាផ្លាស់ប្តូរការសន្ទនាអំពីភាពបន្ទាន់ (សូមមើល[ការវិភាគផលប៉ះពាល់ថវិកា](../ការវិភាគផលប៉ះពាល់ថវិកា/)សម្រាប់ដៃគូសមត្ថភាពទិញបាន)។

## កំហុសដែលត្រូវជៀសវាង

- **ការសន្មត CoD លីនេអ៊ែរ**៖ ការងារខ្លះមានតម្លៃរាងកាលកំណត់ (កាលបរិច្ឆេទបទប្បញ្ញត្តិ — CoD គ្មានកំណត់បន្ទាប់ពីកាលបរិច្ឆេទ សូន្យមុន) ឬតម្លៃរលួយ (បង្អួចអ្នកដំបូង)។ ចាត់ថ្នាក់ទម្រង់ភាពបន្ទាន់មុនគុណ។
- **CoD លើលទ្ធផលដែលគ្មាននរណាចង់បាន**៖ ការពន្យារមានថ្លៃតែបើវត្ថុនោះមានតម្លៃ; សំរាមដែលពន្យារគឺឥតគិតថ្លៃ។
- **ការរាប់ការពន្យារ និងការបញ្ចុះតម្លៃស្ទួន**៖ [ការបញ្ចុះតម្លៃ](../ការបញ្ចុះតម្លៃ-និងចំណូលចិត្តពេលវេលា/)កំណត់តម្លៃពេលវេលារួចហើយលើជើងមេឃច្រើនឆ្នាំ; CoD គឺជាកំណែប្រតិបត្តិការក្នុងជើងមេឃ។ ប្រើ CoD សម្រាប់សប្តាហ៍/ខែ ការផ្លាស់ប្តូរ NPV សម្រាប់ឆ្នាំ។
