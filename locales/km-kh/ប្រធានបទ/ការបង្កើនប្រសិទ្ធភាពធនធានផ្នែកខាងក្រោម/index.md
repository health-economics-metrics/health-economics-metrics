# ការបង្កើនប្រសិទ្ធភាពធនធានផ្នែកខាងក្រោម

ការសន្សំមួយម៉ោងសម្រាប់អ្នកជំនាញជាន់ខ្ពស់ — វេជ្ជបណ្ឌិតទូទៅ ឬអ្នកចុះឈ្មោះជាន់ខ្ពស់ ឬអ្នកជំនាញ — ជារឿយៗការពារការពន្យារឧបសគ្គសម្រាប់ក្រុមពហុវិញ្ញាសា (MDT) ទាំងមូលនៃគិលានុបដ្ឋាយិកា ស្មៀនរដ្ឋបាល និងអ្នកព្យាបាលដែលកំពុងរង់ចាំការចុះហត្ថលេខាគ្លីនិក។ តម្លៃនៃការដោះសោឧបសគ្គគឺជាទិន្នផលរបស់អ្នកគ្រប់គ្នានៅផ្នែកខាងក្រោមរបស់វា។

## ហេតុអ្វីបានជាសំខាន់

ការថែទាំសុខភាពដំណើរការលើខ្សែសង្វាក់ការអនុញ្ញាត៖ ការចេញពីមន្ទីរពេទ្យរង់ចាំការចុះហត្ថលេខាអ្នកជំនាញ ផែនការព្យាបាលរង់ចាំការពិនិត្យ MDT ការបញ្ជូនរង់ចាំការចាត់ថ្នាក់។ នៅពេលតួនាទីច្រកត្រូវបានពន្យារ ថ្លៃដើមមិនមែនជាម៉ោងរបស់មនុស្សម្នាក់ទេ — វាគឺជាពេលទំនេរ ឬត្រូវបានរារាំងឆ្លងគ្រប់តួនាទីពឹងផ្អែក បូកពេលវេលាអ្នកជំងឺក្នុងភាពមិនប្រាកដប្រជា (បន្ថែម[ថ្ងៃគ្រែ](../ថ្ងៃគ្រែដែលបានសន្សំ/) [ការរង់ចាំ RTT](../ពីការបញ្ជូនទៅការព្យាបាល/) យូរជាង)។ នេះគឺជាទ្រឹស្តីឧបសគ្គអនុវត្តលើផ្លូវគ្លីនិក៖ មួយម៉ោងដែលបានសន្សំ *នៅឧបសគ្គ* មានតម្លៃស្មើនឹងទិន្នផលរឹតបន្តឹងនៃប្រព័ន្ធទាំងមូល; មួយម៉ោងដែលបានសន្សំកន្លែងផ្សេងមានតម្លៃតិចជាងច្រើន។

## គណិតវិទ្យា

```
Value of unblocking = Σ over downstream roles (blocked hours released × unit cost)
                    + pathway throughput gain × value per pathway completion

Contrast: value of the same hour saved at a non-gating role ≈ that role's
capacity value alone (see practitioner-time.md).
```

កំណត់ឧបសគ្គតាមបទពិសោធន៍៖ តើការងារតម្រង់ជួរយូរបំផុតនៅឯណា? ការពន្យារតាមដានត្រឡប់ទៅប្រអប់សំបុត្ររបស់នរណា?

## ឧទាហរណ៍ដែលបានគណនា

ការចេញពីមន្ទីរពេទ្យរបស់វួដតម្រូវការពិនិត្យអ្នកជំនាញរាល់ព្រឹក។ អ្នកជំនាញចំណាយ 90 នាទី/ថ្ងៃប្រមូលព័ត៌មានដែលរាយប៉ាយក្នុងប្រព័ន្ធ; ការពិនិត្យបញ្ចប់នៅ 14:00 ហើយការចេញ 6/ថ្ងៃបញ្ចប់យឺតពេកសម្រាប់ថ្ងៃនោះ — ម្នាក់ៗចំណាយថ្ងៃគ្រែដែលអាចជៀសវាងបាន។

ផ្ទាំងគ្រប់គ្រងសេចក្តីសង្ខេបការចេញ (មន្ទីរពិសោធន៍ ថ្នាំ ទង់ក្នុងទិដ្ឋភាពតែមួយ) កាត់បន្ថយការប្រមូលទៅ 20 នាទី; ការពិនិត្យបញ្ចប់នៅ 11:30៖

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

នេះគឺជាការពិនិត្យកូដ ការចុះហត្ថលេខាស្ថាបត្យកម្ម និងប្រអប់សំបុត្ររបស់វិស្វករជាន់ខ្ពស់។ នៅពេលវិស្វករប្រាំនាក់រង់ចាំមួយថ្ងៃសម្រាប់មនុស្សម្នាក់ដែលអាចអនុម័តការរចនា ថ្លៃដើមគឺប្រាំថ្ងៃវិស្វករ បូកមួយថ្ងៃនៃ[ថ្លៃដើមនៃការពន្យារ](../ថ្លៃដើមនៃការពន្យារ/)លើការងារខ្លួនឯង — មិនមែនមួយម៉ោងអ្នកពិនិត្យទេ។ ឧបករណ៍ដែលបង្រួមកិច្ចការរបស់តួនាទីច្រក (បរិបទពិនិត្យល្អជាង ការត្រួតពិនិត្យមុនស្វ័យប្រវត្តិ ផ្ទាំងគ្រប់គ្រងដែលប្រមូលអ្វីដែលអ្នកអនុម័តត្រូវការ) ទិញទិន្នផលប្រព័ន្ធ មិនមែនភាពងាយស្រួលបុគ្គលទេ។ វាស់ពេលរើស/ពេលរង់ចាំនៅឧបសគ្គ (សូមមើល[រង្វាស់លំហូរ](../រង្វាស់លំហូរ/)) — វាគឺជាសមមូលកម្មវិធីនៃច្រាំងការចេញនៅ 14:00។

## កំហុសដែលត្រូវជៀសវាង

- **ការបង្កើនប្រសិទ្ធភាពមិនមែនឧបសគ្គ**៖ ឧបករណ៍ស្អាតសម្រាប់តួនាទីដែលគ្មានអ្វីតម្រង់ជួរនៅពីក្រោយ បង្កើតតម្លៃប្រព័ន្ធជិតសូន្យ។
- **ការធ្វើចំណាកឧបសគ្គ**៖ ដោះសោអ្នកជំនាញ ហើយឧបសគ្គផ្លាស់ទី (ទៅឱសថស្ថាន ទៅដឹកជញ្ជូន) — ធ្វើគំរូឧបសគ្គ *បន្ទាប់* មុនអះអាងការកើនឡើងទិន្នផលពេញលេញ។
- **រាប់ម៉ោងខាងក្រោមជាសាច់ប្រាក់**៖ ការបញ្ចេញពេលរារាំងគឺជាសមត្ថភាព ស្ថិតក្រោម[តេស្តផ្លាស់ប្តូរទីតាំង](../ការសន្សំដែលបញ្ចេញសាច់ប្រាក់-ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់/)ធម្មតា។
