# រង្វាស់ការចូលរួម

រង្វាស់ការចូលរួមវាស់ថាតើអ្នកប្រើប្រាស់កម្មវិធីសុខភាពប៉ុណ្ណា៖ ភាពស្អិត DAU/MAU ភាពញឹកញាប់ និងរយៈពេលសម័យប្រជុំ ការប្រើប្រាស់មុខងារ។ ក្នុងសុខភាពឌីជីថល ការចូលរួមមិនមែនជាឥតន័យទេ — វាគឺជា **កម្រិតថ្នាំ**៖ ការប៉ះពាល់ដែលឥទ្ធិពលគ្លីនិកណាមួយត្រូវតែហូរកាត់។

## ហេតុអ្វីបានជាសំខាន់

ថ្នាំដែលនៅក្នុងដបមិនព្យាបាលនរណាម្នាក់ទេ; កម្មវិធីដែលនៅមិនបានដំឡើង ឬមិនបានបើកគឺជារបៀបបរាជ័យដូចគ្នា។ រាល់ការអះអាងសេដ្ឋកិច្ចសុខាភិបាលសម្រាប់ផលិតផលសុខភាពអ្នកប្រើប្រាស់គុណតាមការចូលរួម — ប្រសិទ្ធភាពដែលបង្ហាញក្នុងការសាកល្បងត្រូវបានវាស់នៅកម្រិតប្រើប្រាស់មួយចំនួន ហើយតម្លៃពិភពពិតកើនឡើងតាមរបៀបដែលការប្រើប្រាស់ដាក់ឱ្យប្រើទៅជិតកម្រិតនោះ។ ស្តង់ដារផលិតផលស្តង់ដារ៖ DAU/MAU ប្រហែល **20% ត្រូវបានចាត់ទុកថាមានសុខភាពល្អ** សម្រាប់កម្មវិធីចល័តជាទូទៅ >25% ពិសេស; កម្មវិធីសុខភាពជារឿយៗទាបជាង។

## គណិតវិទ្យា

```
Stickiness (DAU/MAU) = daily active users / monthly active users × 100
Session metrics      = sessions/user/period; avg duration = total time / sessions
Feature engagement   = users performing key action / active users

Dose-response framing (the health-economics upgrade):
  realized effect ≈ trial effect × f(actual usage / trial usage)
  where f comes from dose-response analysis — see the "effective
  engagement" concept in adherence-and-persistence.md: enough usage
  to achieve the intended outcome, which may be modest and finite
```

## ឧទាហរណ៍ដែលបានគណនា

ការសិក្សាសំខាន់នៃកម្មវិធីសម្ពាធឈាមបង្ហាញការថយចុះ systolic 6 mmHg ក្នុងចំណោមអ្នកប្រើដែលកត់ត្រា ≥4 ការអាន/សប្តាហ៍។ ក្នុងការដាក់ឱ្យប្រើឆ្លងអ្នកប្រើចុះឈ្មោះ 50,000 នាក់៖

```
MAU 20,000 (40%); of those, logging ≥4×/week: 7,000
Effective-dose users = 7,000 / 50,000 = 14% of the registered base

Population-level effect ≈ trial effect delivered to 14%, not 100%:
any economic model quoting "50,000 users × 6 mmHg" overstates ~7×.
Honest model: 7,000 × full effect + partial credit (from dose-response
data, if any) for the 13,000 sub-threshold users.
```

ការគុណនេះ — តាមចីវលោការចូលរួមទៅកម្រិតថ្នាំមានប្រសិទ្ធភាព — គឺជាកន្លែងតែមួយទូទៅបំផុតដែលសេដ្ឋកិច្ចសុខភាពឌីជីថលបំប៉ោង។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

វិស្វករជាម្ចាស់ចីវលោការចូលរួម ដែលធ្វើឱ្យពួកគេជាម្ចាស់អថេរ *គ្លីនិក*៖ ការកកស្ទះការចូលប្រើ យុទ្ធសាស្ត្រការជូនដំណឹង ពេលផ្ទុក និងភាពធន់ក្រៅបណ្តាញ សុទ្ធតែផ្លាស់ប្តូរកម្រិតថ្នាំដែលបានផ្តល់។ ផលប៉ះពាល់រចនាពីរ៖ ដាក់ឧបករណ៍វាស់ **សកម្មភាពគ្លីនិកមានអត្ថន័យ** (ការអានដែលបានកត់ត្រា មេរៀនដែលបានបញ្ចប់) មិនមែនការបើកទេ — DAU ដែលបង្កើតលើសម័យលោតការជូនដំណឹងគឺជាការក្លែងកម្រិតថ្នាំ; ហើយចាត់ទុកគោលដៅការចូលរួមជាគោលដៅ *គ្រប់គ្រាន់* មិនមែនអតិបរមាទេ — កម្មវិធីដែលសម្រេចលទ្ធផលក្នុង 5 នាទី/សប្តាហ៍ ហើយចេញពីផ្លូវគឺល្អបំផុតខាងគ្លីនិក និង "ខ្សោយ" ខាងរង្វាស់ (សូមមើលការចូលរួមមានប្រសិទ្ធភាពក្នុង[ការប្រកាន់ខ្ជាប់ និងការបន្តប្រើប្រាស់](../ការប្រកាន់ខ្ជាប់-និងការបន្តប្រើប្រាស់/))។ វាយតម្លៃការងារចូលរួមខ្លួនឯងតាមគំរូឥទ្ធិពលប្រជាជនខាងលើ៖ ការកើនឡើង 2 ចំណុចនៃភាគកម្រិតថ្នាំមានប្រសិទ្ធភាពគឺជាបន្ទាត់ QALY ដែលអាចវាស់បាន។

## កំហុសដែលត្រូវជៀសវាង

- **ការចូលរួមជាលទ្ធផល**៖ ការប្រើប្រាស់គឺជាមធ្យោបាយ; លទ្ធផលគឺ [PROM](../លទ្ធផលដែលអ្នកជំងឺរាយការណ៍/) ឬចំណុចបញ្ចប់គ្លីនិក។
- **មធ្យមលើការប្រើពីរកំពូល**៖ ប្រជាជនកម្មវិធីសុខភាពបែងចែកជាអ្នកប្រើឧស្សាហ៍ និងខ្មោច; មធ្យមពិពណ៌នានរណាក៏មិនបាន — បែងចែកជាក្រុម។
- **ការបំប៉ោងកម្រិតថ្នាំតាមគំរូងងឹត**៖ ស្ទ្រីក និងការជូនដំណឹងបន្ទោសលើករង្វាស់ ហើយអាចប៉ះពាល់ប្រជាជនថប់បារម្ភដែលកម្មវិធីសុខភាពបម្រើ; ផលិតផលគ្លីនិកមានក្រមសីលធម៌គ្លីនិក។
- **ប្រភពដើមស្តង់ដារអ្នកលក់**៖ ស្តង់ដារការចូលរួមដែលបានបោះពុម្ពភាគច្រើនមកពីអ្នកលក់ការវិភាគ មិនមែនការត្រួតពិនិត្យដោយមិត្តភ័ក្តិទេ; ក្រិតធៀបនឹងការសាកល្បងរបស់អ្នកផ្ទាល់។
