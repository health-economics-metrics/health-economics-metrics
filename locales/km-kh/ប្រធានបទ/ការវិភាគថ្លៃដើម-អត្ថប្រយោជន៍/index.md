# ការវិភាគថ្លៃដើម-អត្ថប្រយោជន៍ (CBA)

CBA វាយតម្លៃទាំងថ្លៃដើម *និង* លទ្ធផលជារូបិយវត្ថុ។ វាជាប្រភេទការវិភាគតែមួយគត់ដែលអាចឆ្លើយថា "តើនេះគួរធ្វើទេ?" — មិនមែនត្រឹមតែ "ជម្រើសណាល្អបំផុត?" ទេ — ព្រោះអត្ថប្រយោជន៍ដែលបានបំប្លែងជារូបិយវត្ថុអាចប្រៀបធៀបដោយផ្ទាល់នឹងថ្លៃដើម។

## ហេតុអ្វីបានជាសំខាន់

CBA គឺជាស្តង់ដារនៃ **Green Book** របស់ HM Treasury ចក្រភពអង់គ្លេស សម្រាប់ការវាយតម្លៃចំណាយសាធារណៈទាំងអស់ រួមទាំងសុខភាព នៅពេលលទ្ធផលអាចបំប្លែងជារូបិយវត្ថុបាន។ ដែល [CEA](../ការវិភាគប្រសិទ្ធភាពថ្លៃដើម/)/[CUA](../ការវិភាគថ្លៃដើម-ឧបយោគ/) ឈប់នៅ "ថ្លៃដើមក្នុងមួយឯកតាសុខភាព" CBA កំណត់តម្លៃសុខភាពខ្លួនឯង (QALY × តម្លៃកម្រិត) និងអ្វីៗផ្សេងទៀត — ពេលវេលា ការធ្វើដំណើរ កាបូន — ហើយរាយការណ៍តួលេខសុទ្ធតែមួយ។ រាល់ករណីអាជីវកម្មឌីជីថល NHS ពេញលេញមានករណីសេដ្ឋកិច្ចរូបរាង CBA។

## គណិតវិទ្យា

```
NPV (net present social value) = Σ_t [ (Benefits_t − Costs_t) / (1 + r)^t ]
BCR (benefit-cost ratio)       = PV(benefits) / PV(costs)

Adopt if NPV > 0 (equivalently BCR > 1); rank by NPV, not BCR.
r = 3.5% (Green Book social time preference rate)
```

ផលប៉ះពាល់សុខភាពអាចចូលជារូបិយវត្ថុជា QALYs × λ (សូមមើល[កម្រិតឆន្ទៈបង់ប្រាក់](../កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់/))។ Green Book ក៏តម្រូវឱ្យ **កែតម្រូវភាពលំអៀងសុទិដ្ឋិនិយម** — បន្ថែមការប៉ាន់ស្មានថ្លៃដើម និងកាត់បន្ថយអត្ថប្រយោជន៍តាមភាគរយផ្អែកលើភស្តុតាង ព្រោះការវាយតម្លៃមានភាពរីករាយជាប្រព័ន្ធ។

## ឧទាហរណ៍ដែលបានគណនា

ប្រព័ន្ធបញ្ជូនអេឡិចត្រូនិក ជើងមេឃ 5 ឆ្នាំ បញ្ចុះតម្លៃ 3.5%៖

```
Costs:    build £1.2M (year 0), run £300k/yr (years 1–5)
Benefits: admin savings £250k/yr, avoided duplicate diagnostics £280k/yr,
          patient time saved 40,000 hrs/yr × £15 = £600k/yr → £1,130k/yr

PV costs    = 1,200k + 300k × 4.515 (annuity factor) = £2,555k
PV benefits = 1,130k × 4.515                          = £5,102k

NPV = 5,102 − 2,555 = +£2,547k     BCR = 2.0
```

អនុវត្តភាពលំអៀងសុទិដ្ឋិនិយម Green Book (និយាយថា +40% លើថ្លៃបង្កើត −20% លើអត្ថប្រយោជន៍)៖ PV ថ្លៃដើម ≈ £3,035k, PV អត្ថប្រយោជន៍ ≈ £4,082k, NPV ≈ **+£1,047k** — នៅតែវិជ្ជមាន ដែលជាចំណុចនៃការកែតម្រូវ៖ ករណីគួររស់រានមានជីវិតពីសុទិដ្ឋិនិយមរបស់ខ្លួន។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ករណីអាជីវកម្មវិស្វកម្មគឺជា CBA ក្រៅផ្លូវការ។ ការលើកកម្រិតរបស់ Green Book ដែលគួរលួច៖

- **ភាពលំអៀងសុទិដ្ឋិនិយមជាការបន្ថែមស្តង់ដារ** — វិស្វករប៉ាន់ស្មានទាបថ្លៃការធ្វើចំណាកស្រុកដូចក្រសួងប៉ាន់ស្មានទាបថ្លៃហេដ្ឋារចនាសម្ព័ន្ធ; អនុវត្តការបន្ថែមដែលបានកំណត់ ជំនួសឱ្យការធ្វើពុតថាលើកនេះខុស។
- **បំប្លែងអត្ថប្រយោជន៍គ្របដណ្តប់ជារូបិយវត្ថុដោយស្មោះត្រង់ ឬមិនធ្វើសោះ** — ពេលវេលាអ្នកជំងឺ/អ្នកប្រើត្រូវបានបំប្លែងតាមអត្រាការពារបាន; "តម្លៃម៉ាក" មិនមែនទេ។
- **NPV ចំណាត់ថ្នាក់ BCR មិនចំណាត់ថ្នាក់**៖ គម្រោងតូចដែលមាន BCR 5 អាចសំខាន់តិចជាងគម្រោងធំដែលមាន BCR 1.6។

## កំហុសដែលត្រូវជៀសវាង

- **បំប្លែងអ្វីដែលមិនអាចបំប្លែងជារូបិយវត្ថុ** ដើម្បីបំប៉ោងអត្ថប្រយោជន៍ (ស្មារតី "ការតម្រឹមយុទ្ធសាស្ត្រ") — រក្សាទាំងនោះជាគុណភាព តាម[ការវិភាគថ្លៃដើម-លទ្ធផល](../ការវិភាគថ្លៃដើម-លទ្ធផល/)។
- **រាប់ការផ្ទេរជាអត្ថប្រយោជន៍**៖ ប្រាក់ផ្លាស់ទីរវាងស្ថាប័នសាធារណៈ ស្មើសូន្យនៅ[ទស្សនៈ](../ទស្សនៈនៃការវិភាគ/)សង្គម។
- **គ្មានប្រឆាំងការពិត**៖ អត្ថប្រយោជន៍ត្រូវបានវាស់ធៀបនឹងជម្រើសធ្វើអប្បបរមា មិនមែនធៀបនឹងសូន្យទេ។
