# ការរក្សាកម្លាំងពលកម្ម

សេដ្ឋកិច្ចនៃការរក្សាកម្លាំងពលកម្មបរិមាណថ្លៃដើមដែលការផ្លាស់ប្តូរបុគ្គលិកធ្វើឱ្យប្រព័ន្ធសុខាភិបាល — ការជួល ការណែនាំចូលបំពេញការងារ ការគ្របដណ្តប់មុខតំណែងទំនេរ — ហើយដូច្នេះតម្លៃនៃកម្មវិធីដែលកាត់បន្ថយការអស់កម្លាំងរដ្ឋបាល។ ការអស់កម្លាំងពីកិច្ចការទិន្នន័យរដ្ឋបាលដដែលៗគឺជាកត្តាជំរុញចម្បងនៃការផ្លាស់ប្តូរបុគ្គលិក និងអវត្តមានជំងឺក្នុង NHS។

## ហេតុអ្វីបានជាសំខាន់

នៅពេលគ្លីនីសីយាំចាកចេញ trust បង់បីដង៖ ដើម្បីជួលអ្នកជំនួស (ការផ្សាយពាណិជ្ជកម្ម ថ្លៃភ្នាក់ងារ ការសម្ភាសន៍) ដើម្បីណែនាំពួកគេ (ជាច្រើនខែនៃផលិតភាពថយចុះ ការត្រួតពិនិត្យ) និងគ្របដណ្តប់មុខតំណែងទំនេរក្នុងពេលនោះ — ជាធម្មតាជាមួយបុគ្គលិកភ្នាក់ងារ ឬ locum ក្នុងអត្រា 2–3× នៃអត្រា Agenda for Change ជាប់ប្រាក់ខែ (សូមមើល[ថ្លៃដើមអ៊ូតសូស៊ីងដែលអាចជៀសវាងបាន](../ថ្លៃដើមអ៊ូតសូស៊ីងដែលអាចជៀសវាងបាន/) និង[ការសន្សំរឹងដែលបញ្ចេញសាច់ប្រាក់](../ការសន្សំរឹងដែលបញ្ចេញសាច់ប្រាក់/))។ ដោយសារថ្លៃដើមការផ្លាស់ប្តូរជាសាច់ប្រាក់ពិត ការកែលម្អការរក្សាគឺជាអត្ថប្រយោជន៍កម្លាំងពលកម្មតិចតួចដែលនាយកហិរញ្ញវត្ថុអាចដាក់ធនាគារបាន។ ការកកិតរដ្ឋបាលជាប់ជាកត្តាជំរុញកំពូលដែលបានដកស្រង់នៃការអស់កម្លាំងគ្លីនិកជានិច្ច ដែលធ្វើឱ្យវាជាថ្លៃដើមដែលកម្មវិធីអាចដោះស្រាយបាន។

## គណិតវិទ្យា

```
Cost per leaver = recruitment cost + onboarding/productivity-ramp cost
                + vacancy cover premium × vacancy duration

Annual turnover cost = headcount × turnover rate × cost per leaver

Value of software  = headcount × Δturnover rate × cost per leaver
                   + sickness-absence reduction × cover cost/day
```

ខ្សែសង្វាក់មូលហេតុមានតំណប៉ាន់ស្មានពីរ — កម្មវិធី → ការអស់កម្លាំង/ការកកិត និងការអស់កម្លាំង → ការផ្លាស់ប្តូរ — ដូច្នេះផ្តល់ភស្តុតាងទាំងពីរ (ការស្ទង់មតិបុគ្គលិកមុន/ក្រោយ; ទំនាក់ទំនងការអស់កម្លាំង-ការចាកចេញដែលបានបោះពុម្ព) ហើយរក្សា Δ ដែលអះអាងឱ្យមានកម្រិត។

## ឧទាហរណ៍ដែលបានគណនា

trust មួយជួលគិលានុបដ្ឋាយិកា 1,200 នាក់; ការផ្លាស់ប្តូរ 11%/ឆ្នាំ។ ថ្លៃដើមក្នុងមួយអ្នកចាកចេញ៖

```
Recruitment ≈ £4,500;  onboarding/ramp ≈ £6,000
Vacancy cover: 4 months × 0.6 WTE covered by agency premium ≈ £8,000
Total ≈ £18,500 per leaver
Baseline turnover cost = 1,200 × 0.11 × 18,500 ≈ £2.44M/year
```

កម្មវិធីកាត់បន្ថយបន្ទុកឯកសារ (ការវាយតម្លៃបំពេញស្វ័យប្រវត្តិ ចូលតែមួយ ការសរសេរតាមអាន) ប្រហែលជាផ្លាស់ប្តូរការផ្លាស់ប្តូរបុគ្គលិក 1 ពិន្ទុភាគរយ៖

```
Value = 1,200 × 0.01 × 18,500 = £222,000/year cash-relevant
```

ការអះអាង 1 ពិន្ទុដែលគាំទ្រដោយពិន្ទុកកិតការស្ទង់មតិបុគ្គលិកគឺគួរឱ្យជឿ; ការអះអាង 4 ពិន្ទុមិនមែនទេ។ ដំណើរការ[ដ្យាក្រាមខ្យល់ព្យុះ](../ការវិភាគភាពរសើប/) លើ Δturnover៖ វាគ្រប់គ្រងអ្វីៗផ្សេងទៀតក្នុងម៉ូដែល។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

គណិតវិទ្យារក្សាវិស្វកម្មដូចគ្នា ហើយមានឯកសារអន់ជាង៖ ការជំនួសវិស្វករជាន់ខ្ពស់មានតម្លៃប្រាក់ខែពេញ 6–12 ខែ (ការជួល ការណែនាំ បរិបទបាត់បង់) ដូច្នេះអង្គការ 200 នាក់ដែលមានអត្រាចាកចេញ 15% ដុតលាននាក់ប្រចាំឆ្នាំលើការផ្លាស់ប្តូរ។ ការវិនិយោគបទពិសោធន៍អ្នកអភិវឌ្ឍន៍ ([SPACE និង DevEx](../space-និង-devex/)) គឺជាភាពស្រដៀងដោយផ្ទាល់នៃការបន្ធូរបន្ថយបន្ទុកឯកសារសម្រាប់គិលានុបដ្ឋាយិកា — ហើយគួរត្រូវបានបញ្ជាក់តាមរបៀបដូចគ្នា៖ ពិន្ទុកកិតដែលបានវាស់ ផលប៉ះពាល់ដែលអះអាងមានកម្រិតលើការចាកចេញ ថ្លៃដើមក្នុងមួយអ្នកចាកចេញពីទិន្នន័យហិរញ្ញវត្ថុរបស់អ្នកផ្ទាល់។ វិន័យសេដ្ឋកិច្ចសុខភាពដែលត្រូវចម្លងគឺ *ការគិតថ្លៃអ្នកចាកចេញដោយស្មោះត្រង់* ជាជាងការជជែកថាតើមនុស្ស "ពិត" ចាកចេញដោយសារឧបករណ៍ឬអត់។

## ចំណុចងាយធ្លាក់

- **ការកំណត់គុណលក្ខណៈចលនាការផ្លាស់ប្តូរទាំងអស់ទៅអន្តរាគមន៍របស់អ្នក** — ទីផ្សារពលកម្មផ្លាស់ប្តូរការចាកចេញច្រើនជាងកម្មវិធី; ប្រើក្រុមត្រួតពិនិត្យ ឬយ៉ាងហោចណាស់ការកែតម្រូវនិន្នាការវិស័យ។
- **ការរាប់ស្ទួន**៖ ការសន្សំការរក្សា និងការសន្សំការចំណាយភ្នាក់ងារត្រួតគ្នា (ការគ្របដណ្តប់មុខតំណែងទំនេរ *គឺជា* ការចំណាយភ្នាក់ងារ); ផ្សះផ្សាបន្ទាត់ទាំងនោះ។
- **ការមិនអើពើពេលយឺត**៖ ការចាកចេញដែលជំរុញដោយការអស់កម្លាំងឆ្លើយតបនឹងការផ្លាស់ប្តូរការកកិតក្នុងរយៈពេល 1–2 ឆ្នាំ មិនមែនត្រីមាសបន្ទាប់ទេ។
