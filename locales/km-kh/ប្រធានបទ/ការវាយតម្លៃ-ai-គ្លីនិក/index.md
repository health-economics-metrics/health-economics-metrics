# ការវាយតម្លៃ AI គ្លីនិក

ស្ថិតិស្នូលសម្រាប់វាយតម្លៃ AI គ្លីនិក ឬម៉ូដែលរោគវិនិច្ឆ័យ៖ ភាពប្រកាន់អារម្មណ៍ (sensitivity) ភាពជាក់លាក់ (specificity) AUROC តម្លៃព្យាករណ៍ និងចំនួនដែលត្រូវត្រួតពិនិត្យ (number needed to screen)។ មេរៀនសេដ្ឋកិច្ចស្នូល៖ **AUROC ល្អមិនធ្វើឱ្យការដាក់ឱ្យប្រើមានប្រសិទ្ធភាពថ្លៃដើមទេ** — តម្លៃអាស្រ័យលើចំណុចប្រតិបត្តិការ ប្រេវ៉ាឡង់ និងអ្វីដែលកើតឡើងបន្ទាប់ពីរាល់លទ្ធផលវិជ្ជមាន។

## ហេតុអ្វីបានជាសំខាន់

អ្នកគ្រប់គ្រង (FDA, MHRA) អនុញ្ញាត AI គ្លីនិកនៅ **ចំណុចប្រតិបត្តិការចាក់សោ** — គូភាពប្រកាន់អារម្មណ៍/ភាពជាក់លាក់ជាក់លាក់ (ឧទាហរណ៍ ប្រព័ន្ធឯករាជ្យដំបូងដែល FDA អនុម័តសម្រាប់ជំងឺរីទីណូប៉ាទីទឹកនោមផ្អែម៖ ភាពប្រកាន់អារម្មណ៍ 87.2% ភាពជាក់លាក់ 90.7% ក្នុងការសាកល្បងសំខាន់របស់វា)។ បន្ទាប់មកអ្នកសេដ្ឋកិច្ចសុខាភិបាលសួរសំណួរដែលរង្វាស់ភាពត្រឹមត្រូវមិនអាចឆ្លើយ៖ នៅប្រេវ៉ាឡង់ប្រជាជនដាក់ឱ្យប្រើរបស់អ្នក តើរាល់ការរកឃើញ *ថ្លៃប៉ុន្មាន* ហើយតើការធ្វើសកម្មភាពលើវាមានតម្លៃឬទេ? ការវាយតម្លៃសេដ្ឋកិច្ចនៃ AI ត្រួតពិនិត្យរីទីណូប៉ាទី (npj Digital Medicine 2024) បានបង្ហាញថាភាពត្រឹមត្រូវខ្ពស់ជាងតែឯងមិនធានាប្រសិទ្ធភាពថ្លៃដើមទេ នៅពេលថ្លៃបញ្ជូនត្រូវបានរាប់។

## គណិតវិទ្យា

```
Sensitivity = TP / (TP + FN)        — of the truly positive, share caught
Specificity = TN / (TN + FP)        — of the truly negative, share cleared
AUROC       = P(model ranks a random positive above a random negative)
              0.5 chance … 1.0 perfect; threshold-independent — and therefore
              deployment-decision-insufficient

PPV = TP / (TP + FP)   ← prevalence-dependent (Bayes); collapses when rare
NPV = TN / (TN + FN)

NNS  ≈ 1 / (prevalence × sensitivity)       — screened per true case found
Cost per true case = programme cost / TP      — the economic bottom line
```

## ឧទាហរណ៍ដែលបានគណនា

ម៉ូដែលដូចគ្នា បរិបទពីរ — ភាពប្រកាន់អារម្មណ៍ 90% ភាពជាក់លាក់ 93%៖

```
Specialist clinic (prevalence 20%):
  PPV = (0.9×0.2)/(0.9×0.2 + 0.07×0.8) = 0.18/0.236 ≈ 76%  → 3 in 4 alerts real

Primary care (prevalence 1%):
  PPV = (0.9×0.01)/(0.9×0.01 + 0.07×0.99) = 0.009/0.0783 ≈ 11.5%
  → 8 in 9 alerts false; workup at £350 each:
  cost per true case = (0.009 + 0.0693) × 350 / 0.009 ≈ £3,045 per case found
```

ម៉ូដែលដូចគ្នា សេដ្ឋកិច្ចខុសគ្នាខ្លាំង — ជាមូលហេតុដែលការវាយតម្លៃជាក់លាក់តាមទីតាំងជាប្រធានបទបទប្បញ្ញត្តិ ហើយជាមូលហេតុដែល "ម៉ូដែលរបស់យើងមាន AUROC 0.95" គឺជាការចាប់ផ្តើមនៃករណីសេដ្ឋកិច្ច មិនមែនចុងបញ្ចប់ទេ។ សូមមើល[សេដ្ឋកិច្ចការត្រួតពិនិត្យ](../សេដ្ឋកិច្ចនៃការពិនិត្យ/)សម្រាប់គណិតវិទ្យាកម្មវិធីពេញលេញ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

សម្រាប់វិស្វករដែលកំពុងបង្កើត ឬទិញ AI គ្លីនិក៖ **ផ្តល់ម៉ាទ្រីសភាពច្រឡំនៅប្រេវ៉ាឡង់ដាក់ឱ្យប្រើ** មិនមែនតែខ្សែកោង ROC ទេ; **ឱ្យកម្រិតជាការសម្រេចចិត្តសេដ្ឋកិច្ច** — ការដោះដូរ sens/spec គួរបង្រួមថ្លៃដើមរំពឹងទុកអប្បបរមា (ករណីខកខាន × ថ្លៃខកខាន ធៀបនឹងសញ្ញាព្រមានមិនពិត × ថ្លៃពិនិត្យបន្ត) មិនមែនបង្កើនស្ថិតិស្តង់ដារអតិបរមាទេ; ហើយទទួលស្គាល់គណិតវិទ្យាដូចគ្នាក្នុងឧបករណ៍ផ្ទាល់ខ្លួនរបស់អ្នក — ប្រព័ន្ធជូនដំណឹង ឧបករណ៍រកភាពមិនប្រក្រតី និងម៉ាស៊ីនស្កេនសុវត្ថិភាព គឺជាតេស្តរោគវិនិច្ឆ័យលើស្ទ្រីមព្រឹត្តិការណ៍ប្រេវ៉ាឡង់ទាប ដោយភាពហត់នឿយនៃការជូនដំណឹងជា [NNH](../ចំនួនដែលត្រូវព្យាបាល/)។ ការធ្វើបច្ចុប្បន្នភាពម៉ូដែលដែលផ្លាស់ប្តូរចំណុចប្រតិបត្តិការបើកសេដ្ឋកិច្ចឡើងវិញ (និងការអនុម័តតាមបទប្បញ្ញត្តិ — សូមមើល[ការវាយតម្លៃបទប្បញ្ញត្តិ AI](../ការវាយតម្លៃបទប្បញ្ញត្តិ-ai/))។

## កំហុសដែលត្រូវជៀសវាង

- **ការទិញ AUROC**៖ ប្រៀបធៀបម៉ូដែលលើ AUROC នៅពេលពួកវានឹងដំណើរការនៅកម្រិតតែមួយ — ប្រៀបធៀបនៅចំណុចប្រតិបត្តិការ។
- **PPV ប្រេវ៉ាឡង់ការសាកល្បងដែលបានដកស្រង់សម្រាប់ការដាក់ឱ្យប្រើក្នុងពិភពពិត** — បុរាណ; គណនាឡើងវិញជានិច្ចនៅប្រេវ៉ាឡង់មូលដ្ឋាន។
- **ភាពលំអៀងវិសាលគម**៖ ម៉ូដែលដែលបានផ្ទៀងផ្ទាត់លើករណីជាក់ស្តែងធៀបនឹងក្រុមត្រួតពិនិត្យមានសុខភាព ដំណើរការលើសលើកណ្តាលមិនច្បាស់ដែលគ្របដណ្តប់ការអនុវត្ត។
- **គ្មានការកំណត់តម្លៃផ្លូវបន្ទាប់**៖ រាល់វិជ្ជមានបង្កការពិនិត្យបន្ត; ម៉ូដែលគឺជាអន្តរាគមន៍លើសេដ្ឋកិច្ច *ផ្លូវទាំងមូល*។
