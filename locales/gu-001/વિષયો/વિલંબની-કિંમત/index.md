# વિલંબની કિંમત (CoD)

વિલંબની કિંમત એ સુવિધા, ઉત્પાદન કે સેવા *ન* પહોંચાડાય ત્યારે સમયના એકમ દીઠ ગુમાવાતું આર્થિક મૂલ્ય છે. તે સૉફ્ટવેર ડિલિવરી મેટ્રિક્સ અને આરોગ્ય અર્થશાસ્ત્ર વચ્ચેનો સૌથી મજબૂત સેતુ છે: તે "અમે મોડું મોકલ્યું" ને ચલણમાં — અથવા QALY માં — ફેરવે છે.

## આ શા માટે મહત્ત્વનું છે

Reinertsen નો નિયમ: "જો તમે એક જ વસ્તુ માપો, તો વિલંબની કિંમત માપો." મોટાભાગની સંસ્થાઓ જાણે છે કે પ્રોજેક્ટનો ખર્ચ કેટલો છે પણ એક મહિનાના વિલંબનો ખર્ચ નહીં, તેથી તેઓ સમય-મૂલ્ય વહાવતા બજેટ ઑપ્ટિમાઇઝ કરે છે. આરોગ્ય સૉફ્ટવેર માટે દાવ શાબ્દિક છે: માર્ગ સુધારામાં થતા દરેક સપ્તાહના વિલંબે દર્દીઓ ખરાબ આરોગ્ય અવસ્થામાં વધુ રાહ જુએ છે. CoD NHS હિતધારકોને રજૂ કરવા માટે સૌથી મજબૂત ગાણિતિક માળખું છે કારણ કે તે તમારા સૉફ્ટવેરની *ગેરહાજરી*ની કિંમત આંકે છે.

## ગણિત

```
CoD = benefit per unit time forgone while undelivered   (£/week or QALYs/week)

Total delay loss = CoD × delay duration

For prioritization, see wsjf-and-cd3.md: CD3 = CoD / duration.
```

ક્લિનિકલ સૉફ્ટવેર માટે, નાણાં ઉપરાંત આરોગ્યમાં પણ દર્શાવો:

```
CoD_health = patients affected per week × QALY gain per patient
CoD_money  = CoD_health × λ (willingness-to-pay threshold, £20k–30k/QALY)
             + operational savings per week forgone
```

## ઉકેલેલું ઉદાહરણ

**સંચાલન**: સૉફ્ટવેર માર્ગ પર દર્દી દીઠ £200 બચાવે છે; ટ્રસ્ટ સપ્તાહે 50 આવા દર્દીઓ પ્રક્રિયા કરે છે.

```
CoD = 200 × 50 = £10,000/week
A 10-week procurement delay costs 200 × 50 × 10 = £100,000 in avoidable waste.
```

**ક્લિનિકલ**: ટ્રાયેજ સુધારો સપ્તાહે 100 દર્દીઓ માટે 5 સપ્તાહની પ્રતીક્ષા દૂર કરે છે (ઉપયોગિતા 0.68 → 0.80 વહેલી):

```
QALY gain per patient = (5/52) × 0.12 ≈ 0.0115
CoD_health = 100 × 0.0115 = 1.15 QALYs/week
CoD_money  = 1.15 × £20,000 ≈ £23,000/week of health value
```

6-મહિનાનો ડિપ્લોયમેન્ટ વિલંબ ~30 QALY "ખર્ચે" છે — IT ગો-લાઇવ સરકવાને ક્લિનિકલ ઘટના તરીકે ફરી ઘડતી દલીલ. (સ્કેલ માટે બેન્ચમાર્ક: Black Swan Farming ના પ્રસિદ્ધ Maersk વિશ્લેષણમાં એકલ સુવિધાઓ મળી જેમની CoD ≈ $200k/સપ્તાહ હતી અને 38 સપ્તાહ રાહ જોઈ હતી.)

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

CoD એ મેટ્રિક છે જે [DORA લીડ ટાઇમ](../dora-મેટ્રિક્સ/) અને [ફ્લો કાર્યક્ષમતા](../ફ્લો-મેટ્રિક્સ/) ને નાણાકીય રીતે વાંચી શકાય તેવી બનાવે છે: લીડ ટાઇમ × CoD = કતારોમાં બળેલા નાણાં (અથવા આરોગ્ય). ઉપયોગો:

- **પ્રાથમિકતા**: સૌથી મોટા અવાજવાળા હિતધારકને બદલે CoD/સમયગાળા ([WSJF/CD3](../wsjf-અને-cd3/)) દ્વારા કામને ક્રમ આપો.
- **પ્રક્રિયા અર્થશાસ્ત્ર**: 2-સપ્તાહની રિલીઝ કેડન્સમાં સતત ડિલિવરી સામે સુવિધા દીઠ ~1 સપ્તાહ × CoD અપેક્ષિત વિલંબ ખર્ચ છે — બેચની કિંમત આંકો.
- **પ્રાપ્તિ**: NHS પ્રાપ્તિ ચક્રો 6–18 મહિનાના હોય છે જેની CoD છે; તે બતાવવાથી તાત્કાલિકતાની વાતચીત બદલાય છે (પોસાણક્ષમતા પ્રતિરૂપ માટે [બજેટ અસર વિશ્લેષણ](../બજેટ-અસર-વિશ્લેષણ/) જુઓ).

## સામાન્ય ભૂલો

- **રેખીય CoD માની લેવી**: કેટલાક કામનું મૂલ્ય સમયમર્યાદા-આકારનું હોય છે (નિયામક તારીખો — તારીખ પછી અનંત CoD, પહેલાં શૂન્ય) અથવા ક્ષીણ થતું (પ્રથમ-ચાલક બારીઓ). ગુણતા પહેલાં તાત્કાલિકતા પ્રોફાઇલ વર્ગીકૃત કરો.
- **કોઈને ન જોઈતા આઉટપુટ પર CoD**: વિલંબ ત્યારે જ ખર્ચ કરે છે જ્યારે વસ્તુનું મૂલ્ય હોય; વિલંબિત કચરો મફત છે.
- **વિલંબ અને ડિસ્કાઉન્ટિંગની બેવડી ગણતરી**: [ડિસ્કાઉન્ટિંગ](../ડિસ્કાઉન્ટિંગ-અને-સમય-પસંદગી/) બહુ-વર્ષીય ક્ષિતિજ પર સમયની કિંમત પહેલેથી આંકે છે; CoD ક્ષિતિજ-અંદરનું સંચાલન સંસ્કરણ છે. અઠવાડિયા/મહિનાઓ માટે CoD, વર્ષો માટે NPV શિફ્ટ વાપરો.
