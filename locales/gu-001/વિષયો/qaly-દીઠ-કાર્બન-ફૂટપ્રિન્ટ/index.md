# QALY દીઠ કાર્બન ફૂટપ્રિન્ટ

QALY દીઠ કાર્બન એ કાર્યક્ષમતા ગુણોત્તર છે — હસ્તક્ષેપના કાર્બન ઉત્સર્જન (અથવા ટાળેલા ઉત્સર્જન)ને તે જે QALY આપે છે તેનાથી ભાગવું — જે QALY દીઠ ખર્ચ સાથે સીધું સમાન છે, અને હસ્તક્ષેપની કાર્બન કાર્યક્ષમતાને તેની ખર્ચ કાર્યક્ષમતા સાથે આંકવા દે છે. "કાર્બન-સમાયોજિત ચોખ્ખો નાણાકીય લાભ" એક પગલું આગળ જાય છે, UK Green Book ના સત્તાવાર બિન-વેપારી કાર્બન મૂલ્યોથી કાર્બન અસરનું નાણાંકીય મૂલ્યાંકન કરી તેને પ્રમાણભૂત [ચોખ્ખા નાણાકીય લાભ](../ચોખ્ખો-નાણાકીય-લાભ/) સામે ચોખ્ખું કરે છે.

## આ શા માટે મહત્ત્વનું છે

NICE અને NHS England હવે ખર્ચ અને QALY સાથે પર્યાવરણીય અસર ધ્યાનમાં લેવાની અપેક્ષા રાખે છે. NHS ની જાહેર નેટ-ઝીરો પ્રતિબદ્ધતા છે: તેના પ્રત્યક્ષ ઉત્સર્જન માટે 2040 સુધીમાં નેટ ઝીરો, અને સંપૂર્ણ સપ્લાય-ચેઇન ફૂટપ્રિન્ટ માટે 2045 સુધીમાં નેટ ઝીરો. NICE ની આરોગ્ય ટેકનોલોજી મૂલ્યાંકન માર્ગદર્શિકા (PMG36) ટેકનોલોજી મૂલ્યાંકનમાં પર્યાવરણીય ટકાઉપણાને ઉભરતી વિચારણા તરીકે ઉલ્લેખે છે. ડિજિટલ આરોગ્ય ઉત્પાદન માટે, એનો અર્થ છે કે કાર્બન ખર્ચ, QALY અને [કાર્યક્ષમતા સીમા પર પ્રભુત્વ](../પ્રભુત્વ-અને-કાર્યક્ષમતા-સીમા/) સાથે મૂલ્ય કેસનો ચોથો સ્તંભ બની રહ્યો છે — કોઈનો વિકલ્પ નહીં, પણ સારી રીતે બનાવેલા બિઝનેસ કેસે વધુને વધુ અહેવાલ કરવો પડે તેવો પરિમાણ.

## ગણિત

```
Carbon per QALY = total_emissions_tonnes_co2e / total_qalys
  (a negative value means net emissions AVOIDED per QALY gained — a
  double win: better health and lower carbon)

Monetized carbon impact = emissions_tonnes_co2e × carbon_value_per_tonne
  (negative emissions × positive value = a negative cost, i.e. a benefit)

Carbon-adjusted NMB = net_monetary_benefit − monetized_carbon_impact
```

આ ખર્ચ/QALY કાર્યક્ષમતા-સીમાના વિચારને બીજા અક્ષ — QALY દીઠ કાર્બન — સાથે વિસ્તારે છે, એ જ "દરેક વિકલ્પ આલેખો અને જુઓ કયા પ્રભાવિત છે" તર્ક જે [પ્રભુત્વ અને કાર્યક્ષમતા સીમા](../પ્રભુત્વ-અને-કાર્યક્ષમતા-સીમા/) માં છે, ખર્ચને બદલે કાર્બન પર લાગુ.

## ઉકેલેલું ઉદાહરણ

એક ટેલિહેલ્થ સેવા રૂબરૂ મુલાકાતોને બદલે છે, વર્ષે 5,000 કાર મુસાફરીઓ ટાળે છે, દરેક આશરે 8kg CO2e — 40 ટન CO2e ટળ્યું, ઋણ ઉત્સર્જન આંકડા તરીકે રજૂ (−40.0 ટન), અને તે વર્ષે 25 QALY આપે છે:

```
Carbon per QALY = −40.0 / 25.0 = −1.6 tonnes CO2e avoided per QALY gained
```

Green Book ના બિન-વેપારી કાર્બન મૂલ્યનો ઉપયોગ કરીને (સચિત્ર આંકડો, 2023 બિન-વેપારી કેન્દ્રીય મૂલ્ય ≈ £269/ટન CO2e — Green Book કાર્બન મૂલ્યો વાર્ષિક અપડેટ કરે છે, જીવંત વિશ્લેષણમાં ટાંકતા પહેલાં ફરી ચકાસો):

```
Monetized carbon impact = −40.0 × £269 = −£10,760
```

−£10,760 "ખર્ચ" એ £10,760 લાભ છે. જો હસ્તક્ષેપનો સ્વતંત્ર ચોખ્ખો નાણાકીય લાભ £500,000 હોય:

```
Carbon-adjusted NMB = £500,000 − (−£10,760) = £510,760
```

કાર્બન બચત કેસમાંથી ઘટાડવાને બદલે ઉમેરો કરે છે — ઋણ-ઉત્સર્જન ફ્રેમિંગ જે બેવડી જીત ઉજાગર કરવા માટે છે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

આ AI/ક્લાઉડ અર્થશાસ્ત્ર સાથેનું જીવંત, વર્તમાન છેદન છે: AI મૉડેલને તાલીમ આપવાનો અને ચલાવવાનો કમ્પ્યુટ કાર્બન ફૂટપ્રિન્ટ હવે NHS પ્રાપ્તિમાં વાસ્તવિક લાઇન આઇટમ છે, કારણ કે ચોક્કસ સીમાથી ઉપરના NHS સપ્લાયર કરારો માટે Carbon Reduction Plan જરૂરી છે. [ક્લાઉડ યુનિટ ઇકોનોમિક્સ](../ક્લાઉડ-યુનિટ-ઇકોનોમિક્સ/) પહેલેથી કમ્પ્યુટ આઉટપુટના એકમ દીઠ ખર્ચ ટ્રૅક કરે છે; QALY દીઠ કાર્બન ભવિષ્યના "અનુમાન દીઠ કાર્બન ખર્ચ" મેટ્રિક માટે કુદરતી નમૂનો છે, જે એ મૉડ્યુલ અને અનુમાન એકમ અર્થશાસ્ત્રને પર્યાવરણીય પરિમાણમાં વિસ્તારશે, જોકે તે મેટ્રિક હજુ અસ્તિત્વમાં નથી.

## સામાન્ય ભૂલો

- **અવકાશ-સીમા સાથે રમત**: ફક્ત પ્રત્યક્ષ (Scope 1) ઉત્સર્જન ગણવું અને સપ્લાય-ચેઇન (Scope 3) ઉત્સર્જન બાકાત રાખવું, જે ડિજિટલ આરોગ્ય ઉત્પાદનના વાસ્તવિક ફૂટપ્રિન્ટનો સામાન્ય રીતે મોટો ભાગ છે.
- **જૂનું કાર્બન મૂલ્ય વાપરવું**: Green Book તેના બિન-વેપારી કાર્બન મૂલ્યો વાર્ષિક અપડેટ કરે છે, તેથી કોઈપણ ટાંકેલો £/ટન આંકડો તારીખ સાથે હોવો જોઈએ, સ્થિર અચળાંક તરીકે નહીં.
- **"કાર્બન-કાર્યક્ષમ"ને "ખર્ચ-અસરકારક"નો વિકલ્પ ગણવો**: ઓછા-કાર્બન, ઓછા-મૂલ્યનો હસ્તક્ષેપ હજુ NHS સંસાધનોનો નબળો ઉપયોગ છે. કાર્બન ખર્ચ અને QALY સાથે ચોથો સ્તંભ છે, કોઈનો વિકલ્પ નથી.
