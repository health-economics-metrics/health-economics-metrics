# સ્ક્રીનિંગ અર્થશાસ્ત્ર

સ્ક્રીનિંગ અર્થશાસ્ત્ર લક્ષણ-રહિત વસ્તીના પરીક્ષણનું મૂલ્ય નક્કી કરે છે. મુખ્ય ગાણિતિક હકીકત: **રોગના નીચા વ્યાપે, ઉત્તમ પરીક્ષણો પણ મોટેભાગે ખોટા-ધન પરિણામો આપે છે** — અને તેમનો પીછો કરવાનો ડાઉનસ્ટ્રીમ ખર્ચ સાચા શોધોના લાભને ડુબાડી શકે છે.

## આ શા માટે મહત્ત્વનું છે

1968 થી WHO ના Wilson–Jungner માપદંડ વસ્તી સ્ક્રીનિંગ માટેનું ધોરણ નક્કી કરે છે: સ્થિતિ મહત્ત્વની હોવી જોઈએ, પરીક્ષણ સ્વીકાર્ય અને સચોટ, અસરકારક સારવાર ઉપલબ્ધ, અને અર્થશાસ્ત્ર સંતુલિત. UK National Screening Committee કોઈ પણ રાષ્ટ્રીય કાર્યક્રમ મંજૂર કરતાં પહેલાં ઔપચારિક ખર્ચ-અસરકારકતા વિશ્લેષણ લાગુ કરે છે — અને મોટાભાગની દરખાસ્તો નકારે છે. દરેક "AI બધા માટે બધું સ્ક્રીન કરશે" પિચ આ તંત્ર સાથે અથડાય છે, અને સામાન્ય રીતે નીચેના ગણિત સામે હારે છે.

## ગણિત

પૉઝિટિવ પ્રેડિક્ટિવ વૅલ્યુ (PPV) — પૉઝિટિવ પરિણામ સાચું હોવાની સંભાવના — નીચા વ્યાપે તૂટી પડે છે:

```
PPV = (sens × prev) / [sens × prev + (1 − spec) × (1 − prev)]

Example: sensitivity 90%, specificity 95%, prevalence 0.5%:
PPV = (0.9 × 0.005) / (0.9 × 0.005 + 0.05 × 0.995)
    = 0.0045 / (0.0045 + 0.04975) ≈ 8.3%
```

બાર પૉઝિટિવમાંથી અગિયાર ખોટા છે. સંપૂર્ણ કાર્યક્રમ અર્થશાસ્ત્ર:

```
Cost per true case found = (screening cost + workup cost × all positives) / true positives
Then: is finding a case worth that? (earlier-intervention value per case,
      minus overdiagnosis harm — cases found that would never have mattered)
```

## ઉકેલેલું ઉદાહરણ

દુર્લભ સ્થિતિ માટે AI રેટિનલ સ્ક્રીનિંગ, 100,000 લોકો, વ્યાપ 0.5%, sens 90%, spec 95%, સ્કૅન £15, પુષ્ટિકારક વર્કઅપ £400:

```
True positives:  100,000 × 0.005 × 0.90 = 450
False positives: 100,000 × 0.995 × 0.05 = 4,975
Cost = 100,000 × 15 + (450 + 4,975) × 400 = 1.5M + 2.17M = £3.67M
Cost per true case ≈ £8,156
```

જો વહેલી સારવાર દરેક કેસ દીઠ £20,000 + 1 QALY બચાવે, તો કાર્યક્રમ સહેલાઈથી પાસ થાય છે. વિશિષ્ટતા 99% સુધી વધારો (ઓછા ખોટા એલાર્મ): વર્કઅપ ખર્ચ ઘટીને (450 + 995) × 400 = £0.58M, કુલ £2.08M, કેસ દીઠ ખર્ચ ≈ **£4,622** — નીચા વ્યાપે સ્ક્રીનિંગ અર્થશાસ્ત્ર સંવેદનશીલતાથી નહીં, વિશિષ્ટતાથી જીતાય છે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

સ્ટૅટિક વિશ્લેષણ, સુરક્ષા સ્કૅનિંગ અને અસંગતિ શોધ કોડબેઝ અને ટેલિમેટ્રી પરના સ્ક્રીનિંગ કાર્યક્રમો છે, જેમાં સાચી-ખામીનો વ્યાપ પ્રતિ ચેતવણી-તક ઘણીવાર 1% થી ઘણો ઓછો હોય છે. આ જ ગણિત ચેતવણી થાક સમજાવે છે: નીચા વ્યાપવાળા કોડ પર 95%-વિશિષ્ટ સ્કૅનર ટીમોને ખોટા-ધનમાં ડુબાડે છે, અને દરેક ખોટું-ધન ધ્યાન ખર્ચે છે અને વિશ્વાસ ઘટાડે છે, જ્યાં સુધી સાચી ચેતવણીઓ અવગણાય નહીં (ક્લિનિકલ શબ્દ *સ્ક્રીનિંગ નુકસાન*; એન્જિનિયરિંગ શબ્દ *pager numbness*). ઉપાયો આરોગ્યમાંથી ટ્રાન્સફર થાય છે: સંવેદનશીલતા પહેલાં વિશિષ્ટતા વધારો, ઊંચા-વ્યાપવાળા ઉપ-વસ્તીને સ્ક્રીન કરો (જોખમ-આધારિત લક્ષ્યીકરણ ↔ ફક્ત-બદલાયેલ-કોડ સ્કૅનિંગ), અને ટૂલના અર્થશાસ્ત્રમાં ટ્રાયેજ ખર્ચ ગણો — [NNT](../સારવાર-માટે-જરૂરી-સંખ્યા/) અને [ક્લિનિકલ AI મૂલ્યાંકન](../ક્લિનિકલ-ai-મૂલ્યાંકન/) જુઓ. એક પરીક્ષણને બદલે આખા સ્ક્રીનિંગ કાર્યક્રમનું કદ નક્કી કરવા [સ્ક્રીન કરવા જરૂરી સંખ્યા](../સ્ક્રીનિંગ-માટે-જરૂરી-સંખ્યા/) જુઓ — એક પરિણામ અટકાવવા કેટલા લોકોએ સંપૂર્ણ સ્ક્રીન-અને-સારવાર માર્ગમાંથી પસાર થવું પડે.

## સામાન્ય ભૂલો

- **વ્યાપ વગર સંવેદનશીલતા/વિશિષ્ટતા ટાંકવી** — PPV વગરની ચોકસાઈ માર્કેટિંગ છે.
- **અતિ-નિદાન અવગણવું**: ધીમા "રોગ" શોધવા જે ક્યારેય નુકસાન ન કરત, તે વાસ્તવિક સારવાર ખર્ચ અને નુકસાન ઊભા કરે છે.
- **લીડ-ટાઇમ પક્ષપાત**: પરિણામ બદલાયા વગર વહેલી શોધ દેખીતા સર્વાઇવલને ફુલાવે છે — [વહેલો હસ્તક્ષેપ](../વહેલો-હસ્તક્ષેપ/) જુઓ.
