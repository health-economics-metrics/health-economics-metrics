# ખર્ચ-લાભ વિશ્લેષણ (CBA)

CBA ખર્ચ *અને* પરિણામો બંનેનું નાણાંમાં મૂલ્યાંકન કરે છે. તે એકમાત્ર વિશ્લેષણ પ્રકાર છે જે "આ કરવા જેવું છે જ?" નો જવાબ આપી શકે — માત્ર "કયો વિકલ્પ શ્રેષ્ઠ છે?" નહીં — કારણ કે નાણાંકીય રીતે મૂલ્યાંકિત લાભોની સીધી ખર્ચ સાથે સરખામણી થઈ શકે.

## આ શા માટે મહત્ત્વનું છે

CBA એ UK ના HM Treasury **Green Book** નું બધા જાહેર ખર્ચ મૂલ્યાંકન માટેનું ધોરણ છે, જેમાં પરિણામો નાણાંમાં મૂલ્યાંકિત થઈ શકે ત્યારે આરોગ્ય પણ આવે છે. જ્યાં [CEA](../ખર્ચ-અસરકારકતા-વિશ્લેષણ/)/[CUA](../ખર્ચ-ઉપયોગિતા-વિશ્લેષણ/) "આરોગ્યના એકમ દીઠ ખર્ચ" પર અટકે છે, ત્યાં CBA આરોગ્યની જ કિંમત (QALY × સીમા મૂલ્ય) અને બીજું બધું — સમય, મુસાફરી, કાર્બન — આંકે છે અને એક ચોખ્ખો આંકડો અહેવાલ કરે છે. દરેક સંપૂર્ણ NHS ડિજિટલ બિઝનેસ કેસમાં CBA-આકારનો આર્થિક કેસ હોય છે.

## ગણિત

```
NPV (net present social value) = Σ_t [ (Benefits_t − Costs_t) / (1 + r)^t ]
BCR (benefit-cost ratio)       = PV(benefits) / PV(costs)

Adopt if NPV > 0 (equivalently BCR > 1); rank by NPV, not BCR.
r = 3.5% (Green Book social time preference rate)
```

આરોગ્ય અસરો QALY × λ તરીકે નાણાંકીય રૂપે દાખલ થઈ શકે ([ચૂકવવાની તૈયારીની સીમાઓ](../ચૂકવવાની-તૈયારીની-સીમાઓ/) જુઓ). Green Book **આશાવાદ-પૂર્વગ્રહ સમાયોજનો** પણ ફરજિયાત કરે છે — ખર્ચ અંદાજો વધારવા અને લાભોને પુરાવા-આધારિત ટકાવારીથી ઘટાડવા, કારણ કે મૂલ્યાંકનો વ્યવસ્થિત રીતે ગુલાબી હોય છે.

## ઉકેલેલું ઉદાહરણ

એક ઇ-રેફરલ સિસ્ટમ, 5-વર્ષ ક્ષિતિજ, 3.5% ડિસ્કાઉન્ટ:

```
Costs:    build £1.2M (year 0), run £300k/yr (years 1–5)
Benefits: admin savings £250k/yr, avoided duplicate diagnostics £280k/yr,
          patient time saved 40,000 hrs/yr × £15 = £600k/yr → £1,130k/yr

PV costs    = 1,200k + 300k × 4.515 (annuity factor) = £2,555k
PV benefits = 1,130k × 4.515                          = £5,102k

NPV = 5,102 − 2,555 = +£2,547k     BCR = 2.0
```

Green Book આશાવાદ પૂર્વગ્રહ લાગુ કરો (ધારો કે બિલ્ડ ખર્ચ પર +40%, લાભ પર −20%): PV ખર્ચ ≈ £3,035k, PV લાભ ≈ £4,082k, NPV ≈ **+£1,047k** — હજુ હકારાત્મક, જે સમાયોજનનો હેતુ છે: કેસ તેમના પોતાના આશાવાદથી બચવા જોઈએ.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

એન્જિનિયરિંગ બિઝનેસ કેસ અનૌપચારિક CBA છે. Green Book ના ચોરવા જેવા સુધારા:

- **પ્રમાણભૂત વધારા તરીકે આશાવાદ પૂર્વગ્રહ** — એન્જિનિયરો માઇગ્રેશન ખર્ચને એટલી જ નિયમિતતાથી ઓછો આંકે છે જેટલી મંત્રાલયો માળખાકીય ખર્ચ; આ વખતે અલગ છે એવો ડોળ કરવાને બદલે જણાવેલો વધારો લાગુ કરો.
- **પ્રભાવી લાભનું પ્રામાણિકપણે નાણાંકીય મૂલ્યાંકન કરો અથવા બિલકુલ નહીં** — દર્દી/વપરાશકર્તા સમયનું બચાવી શકાય તેવા દરે નાણાંકીય મૂલ્યાંકન થાય છે; "બ્રાન્ડ મૂલ્ય" નહીં.
- **NPV ક્રમ આપે છે, BCR નહીં**: BCR 5 વાળો નાનો પ્રોજેક્ટ BCR 1.6 વાળા મોટા પ્રોજેક્ટ કરતાં ઓછો મહત્ત્વનો હોઈ શકે.

## સામાન્ય ભૂલો

- **લાભ ફુલાવવા અમાપ્યનું નાણાંકીય મૂલ્યાંકન** (મનોબળ, "વ્યૂહાત્મક સંરેખણ") — [ખર્ચ-પરિણામ વિશ્લેષણ](../ખર્ચ-પરિણામ-વિશ્લેષણ/) અનુસાર તેને ગુણાત્મક રાખો.
- **સ્થાનાંતરણોને લાભ ગણવા**: જાહેર સંસ્થાઓ વચ્ચે ખસતા નાણાં સામાજિક [દૃષ્ટિકોણ](../વિશ્લેષણ-દૃષ્ટિકોણ/) એ શૂન્ય થાય છે.
- **પ્રતિતથ્ય નહીં**: લાભ ન્યૂનતમ-કાર્ય વિકલ્પ સામે માપવા, શૂન્ય સામે નહીં.
