# હાજર ન રહેવાનો (DNA) દર

DNA દર એ બુક કરેલી એપૉઇન્ટમેન્ટનો ટકાવારી છે જ્યાં દર્દી ન તો હાજર રહે છે ન રદ કરે છે. ક્લિનિશિયન, રૂમ અને સ્લોટ માટે ચુકવણી થાય છે; કંઈ થતું નથી. તે આરોગ્ય સંભાળનું સૌથી શુદ્ધ બગાડ મેટ્રિક છે — અને સૉફ્ટવેરથી સુધારી શકાય તેવા મેટ્રિકમાંનું એક.

## આ શા માટે મહત્ત્વનું છે

NHS England ના આંકડા (2019): ચૂકેલી GP એપૉઇન્ટમેન્ટ વર્ષે 1.5 કરોડથી વધુ, દરેક ~£30 — **£216M/વર્ષ** થી વધુ — અને હૉસ્પિટલ આઉટપેશન્ટ DNA વર્ષે ~80 લાખ (~6.4% એપૉઇન્ટમેન્ટ), ચૂકેલા સ્લોટ દીઠ સરેરાશ ~**£160**. કારણ કે રિમાઇન્ડરનો સીમાંત ખર્ચ પૈસા છે અને પાછું મળેલું મૂલ્ય સંપૂર્ણ સ્ટાફવાળો ક્લિનિકલ સ્લોટ છે, DNA ઘટાડામાં ડિજિટલ આરોગ્યનું સૌથી સારું ROI અંકગણિત છે, એટલે જ SMS રિમાઇન્ડર, સરળ ફરી-બુકિંગ અને આગાહી ઓવરબુકિંગ પ્રથમ સાબિત ડિજિટલ આરોગ્ય જીતોમાં હતા.

## ગણિત

```
DNA rate = DNAs / booked appointments × 100

Value of reduction = appointments × ΔDNA rate × value per recovered slot

value per recovered slot: the slot is refilled (activity value / waiting-list
reduction) or it is not (staff time partially reusable) — mechanism matters,
as with bed-days-saved.md.
```

## ઉકેલેલું ઉદાહરણ

એક આઉટપેશન્ટ વિભાગ: વર્ષે 2,00,000 એપૉઇન્ટમેન્ટ, DNA દર 8%. રિમાઇન્ડર-વત્તા-ફરી-બુકિંગ સેવા (એક-ટૅપ રીબુક સાથે SMS, પરિવહન માહિતી, સુલભ ફૉર્મેટ) DNA ને 5.5% સુધી ઘટાડે છે.

```
Recovered slots = 200,000 × 0.025 = 5,000/year
Refilled from the waiting list at ~£160 average outpatient value:
  5,000 × £160 = £800,000/year of recovered activity
Service cost: 200,000 × £0.40 = £80,000/year

Return ≈ 10:1, plus 5,000 waiting-list patients seen sooner
(see waiting-list-impact.md and referral-to-treatment.md).
```

અસરનું કદ (2.5 બિંદુ) વાસ્તવિક છે: રિમાઇન્ડર RCT સતત 25–40% સાપેક્ષ DNA ઘટાડો બતાવે છે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

- **આ શેડ્યુલિંગ-સિસ્ટમ્સની સમસ્યા છે**: રિમાઇન્ડર, સ્વ-સેવા ફરી-બુકિંગ, રદ થયેલા સ્લોટમાંથી પ્રતીક્ષા-યાદી ઑટો-બૅકફિલ, અને લક્ષિત ડબલ-બુકિંગ ચલાવતા ન-આવવાના આગાહી મૉડેલ્સ. દરેક અસામાન્ય રીતે સ્પષ્ટ આર્થિક કેસ સાથેનું સામાન્ય સૉફ્ટવેર એન્જિનિયરિંગ છે.
- **એન્જિનિયરિંગ સમકક્ષ**: રિઝર્વ કરેલી ક્ષમતા માટે ન-આવવું — બુક કરેલા-પણ-નિષ્ક્રિય CI સ્લોટ, રિઝર્વ્ડ ક્લાઉડ ક્ષમતા, મીટિંગ રૂમ, ઇન્ટરવ્યૂ પૅનલ. અર્થશાસ્ત્ર સ્થાનાંતરિત થાય છે: સસ્તી સ્વચાલિત નજ (અથવા ન વપરાયેલા રિઝર્વેશનનું ઑટો-રિલીઝ) મોંઘી પ્રતિબદ્ધ ક્ષમતા પાછી મેળવે છે.
- **આગાહી નીતિશાસ્ત્ર પૂર્વાવલોકન**: હાજરી ડેટા પર તાલીમ પામેલા ન-આવવાના મૉડેલ્સ વંચિતતા અને પહોંચ અવરોધોને કોડ કરે છે; ન-આવવાની સંભાવના ધરાવતાઓને *ઓછી પ્રાથમિકતા* આપવા તેનો ઉપયોગ અસમાનતા વધારે છે, હાજરી *સહાય* (પરિવહન મદદ, ટેલિફોન વિકલ્પ) માટે ઉપયોગ તેને ઘટાડે છે. જુઓ [પહોંચ અને સમાનતા](../પહોંચ-અને-સમાનતા/).

## સામાન્ય ભૂલો

- **રદ-અને-ફરી-બુક કરેલાને પાછા મળેલા મૂલ્ય તરીકે બે વાર ગણવું.**
- **ફરી ન ભરાયેલા પાછા મળેલા સ્લોટનું મૂલ્યાંકન** — રિમાઇન્ડર મોકલાયું હોવા છતાં ખાલી સ્લોટ ખાલી જ છે.
- **DNA ને શૂન્ય સુધી પીછો કરવો**: DNA ના છેલ્લા બિંદુઓ વાસ્તવિક અવરોધોનો સામનો કરતા દર્દીઓ છે; દંડાત્મક અભિગમ (N DNA પછી રજા) દર્દીઓને છોડી દઈને મેટ્રિક ઘટાડે છે.
