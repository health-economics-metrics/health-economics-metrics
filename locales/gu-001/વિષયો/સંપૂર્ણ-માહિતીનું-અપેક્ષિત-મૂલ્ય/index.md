# સંપૂર્ણ માહિતીનું અપેક્ષિત મૂલ્ય (EVPI)

EVPI એ મહત્તમ રકમ છે જે નિર્ણયકર્તાએ નિર્ણય લેતાં પહેલાં અનિશ્ચિતતા દૂર કરવા ચૂકવવી જોઈએ — "ચાલો પહેલાં અભ્યાસ ચલાવીએ" ની ઔપચારિક કિંમત.

## આ શા માટે મહત્ત્વનું છે

આરોગ્ય પ્રણાલીઓ સતત પસંદગીનો સામનો કરે છે: અપૂર્ણ પુરાવા પર હમણાં અપનાવો, કે પહેલાં વધુ સંશોધનને ભંડોળ આપો. EVPI બીજા વિકલ્પ પર સંખ્યા મૂકે છે. જો EVPI £50,000 હોય અને સૂચિત ટ્રાયલનો ખર્ચ £2 મિલિયન હોય, તો હમણાં અપનાવો. જો EVPI £20 મિલિયન હોય, તો ટ્રાયલ સોદો છે. એ જ પ્રશ્ન — "રોલઆઉટ પહેલાં આનું પાયલટ કરવું જોઈએ?" — દરેક એન્ટરપ્રાઇઝ ટૂલ નિર્ણય માટે ઊભો થાય છે, અને લગભગ કોઈ તેની કિંમત આંકતું નથી. પહેલાં માહિતી એકત્ર કરવાના વિકલ્પને બદલે પ્રોજેક્ટને પછીથી વિસ્તારવાના વિકલ્પની કિંમત માટે, [રિયલ ઑપ્શન્સ મૂલ્યાંકન](../રિયલ-ઑપ્શન્સ-મૂલ્યાંકન/) જુઓ.

## ગણિત

EVPI એ સંપૂર્ણ દૂરદર્શિતા સાથે નિર્ણય અને અપેક્ષાઓ પર હમણાં નિર્ણય વચ્ચેનું અંતર છે:

```
EVPI = E_θ[ max_j NMB(j, θ) ]  −  max_j E_θ[ NMB(j, θ) ]

θ        = uncertain parameters (with their joint distribution)
NMB(j,θ) = net monetary benefit of option j given θ
```

પ્રથમ પદ: દરેક સંભવિત વિશ્વમાં શ્રેષ્ઠ-પસંદગી વળતરની સરેરાશ (તમે હંમેશા સાચું પસંદ કરો છો). બીજું પદ: સરેરાશ રીતે શ્રેષ્ઠ એકમાત્ર વિકલ્પનું વળતર (તમારે હમણાં પ્રતિબદ્ધ થવું પડે). EVPI ≥ 0 હંમેશા. વસ્તી EVPI અસરગ્રસ્ત નિર્ણયોની સંખ્યાથી ગુણે છે. [PSA](../સંભાવનાત્મક-સંવેદનશીલતા-વિશ્લેષણ/) ડ્રૉ પરથી સીધું ગણાય છે.

## ઉકેલેલું ઉદાહરણ

5,000 ક્લિનિશિયનો માટે AI દસ્તાવેજીકરણ સહાયક રોલઆઉટ કરવું, કે નહીં. બે વિશ્વો:

```
World A (p = 0.6): assistant saves 20 min/day → NMB of rollout = +£8M
World B (p = 0.4): assistant saves ~0 (workflow friction) → NMB of rollout = −£3M
NMB of "don't roll out" = £0 in both worlds.
```

હમણાં નિર્ણય: E[NMB rollout] = 0.6 × 8 − 0.4 × 3 = **+£3.6M** → રોલઆઉટ કરો.

સંપૂર્ણ માહિતી સાથે: વિશ્વ A માં રોલઆઉટ પસંદ કરો (+£8M), વિશ્વ B માં કંઈ નહીં (£0). અપેક્ષિત મૂલ્ય = 0.6 × 8 + 0.4 × 0 = **£4.8M**.

```
EVPI = 4.8M − 3.6M = £1.2M
```

£150,000 ના ખર્ચવાળો કડક 3-મહિનાનો પાયલટ જે તમે કયા વિશ્વમાં છો તે નોંધપાત્ર રીતે ઉકેલે તે નિઃશંક રીતે યોગ્ય છે — અને £1.2M થી વધુ ખર્ચવાળો કોઈપણ પાયલટ નથી, ભલે ગમે તેટલો સંપૂર્ણ.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

EVPI એ સ્પાઇક, પાયલટ, A/B ટેસ્ટ અને પ્રૂફ-ઑફ-કોન્સેપ્ટનું અર્થશાસ્ત્ર છે. તે બે વ્યવહારુ નિયમો આપે છે:

- **પાયલટને ભંડોળ આપવું ત્યારે જ યોગ્ય છે જ્યારે નિર્ણય ખરેખર બદલાઈ શકે.** જો પાયલટ પરિણામ ગમે તે હોય તમે રોલઆઉટ કરશો, તો EVPI = 0 અને પાયલટ નાટક છે.
- **પાયલટ ખર્ચને EVPI પર મર્યાદિત કરો.** માહિતીનું મૂલ્ય તે જે નિર્ણયને માહિતગાર કરે તેના મૂલ્યથી બંધાયેલું છે.

આંશિક EVPI (EVPPI) આને એકલ પરિમાણો સુધી વિસ્તારે છે: "ખાસ કરીને બચેલા-સમયની સંખ્યા નક્કી કરવાનું શું મૂલ્ય છે?" — જે કહે છે કે પાયલટે શું માપવું જોઈએ. બધી અનિશ્ચિતતા દૂર કરવાને બદલે *ચોક્કસ સૂચિત અભ્યાસ*ની કિંમત માટે, [EVSI](../નમૂના-માહિતીનું-અપેક્ષિત-મૂલ્ય/) જુઓ.

## સામાન્ય ભૂલો

- **કોઈ નિર્ણય નિયમ જોડ્યા વિના પાયલટ ચલાવવા** — જે માહિતી પસંદગી બદલી ન શકે તે વ્યાખ્યા મુજબ નકામી છે.
- **માહિતી એકત્ર કરવાના વિલંબ ખર્ચની અવગણના**: 6-મહિનાનો પાયલટ 6 મહિનાના લાભને વિલંબિત કરે છે ([વિલંબની કિંમત](../વિલંબની-કિંમત/)); પાયલટનું ચોખ્ખું મૂલ્ય = ઉકેલાયેલું EVPI − વિલંબ ખર્ચ − પાયલટ ખર્ચ.
- **EVPI ને આગાહી ગણવી.** તે માહિતી મૂલ્યની ઉપલી સીમા છે, ચોક્કસ અભ્યાસ શું આપશે તેનો અંદાજ નથી.
