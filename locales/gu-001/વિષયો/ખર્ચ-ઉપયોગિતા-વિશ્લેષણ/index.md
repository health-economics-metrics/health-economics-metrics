# ખર્ચ-ઉપયોગિતા વિશ્લેષણ (CUA)

CUA એ **સામાન્ય, પસંદગી-ભારિત પરિણામ** સાથેનું ખર્ચ-અસરકારકતા વિશ્લેષણ છે — લગભગ હંમેશા [QALY](../ગુણવત્તા-સમાયોજિત-જીવન-વર્ષ/) (અથવા ટાળેલ [DALY](../અપંગતા-સમાયોજિત-જીવન-વર્ષ/)). પરિણામ એકમ સાર્વત્રિક હોવાથી, CUA સંપૂર્ણપણે અલગ રોગો વચ્ચે હસ્તક્ષેપોની સરખામણી કરી શકે છે.

## આ શા માટે મહત્ત્વનું છે

રાષ્ટ્રીય આરોગ્ય સેવાએ એક જ બજેટમાંથી કૅન્સર દવા, માનસિક-આરોગ્ય ઍપ અને સર્જિકલ રોબોટ વચ્ચે પસંદગી કરવી પડે છે. કુદરતી એકમો તેમની સરખામણી કરી શકતા નથી; QALY કરી શકે છે. તેથી CUA એ NICE અને મોટાભાગની HTA સંસ્થાઓની સંદર્ભ-કેસ પદ્ધતિ છે: તેનું આઉટપુટ — QALY દીઠ ખર્ચ, [સીમા](../ચૂકવવાની-તૈયારીની-સીમાઓ/) સામે નક્કી — આરોગ્ય નીતિ પાસે સાર્વત્રિક વિનિમય દરની સૌથી નજીકની વસ્તુ છે. જો તમે ઇચ્છો કે તમારા સૉફ્ટવેરને *બીજા કશાની જગ્યાએ* ભંડોળ મળે, તો CUA એ અખાડો છે.

## ગણિત

```
ICUR = ΔCost / ΔQALYs      (the ICER with QALYs as the effect unit)

ΔQALYs = Σ (duration_i × utility_i)_new − Σ (duration_i × utility_i)_old
```

માન્ય સાધનો ([EQ-5D](../eq-5d/)) માંથી ઉપયોગિતાઓ; ખર્ચ અને QALY બંને 3.5% પર [ડિસ્કાઉન્ટ](../ડિસ્કાઉન્ટિંગ-અને-સમય-પસંદગી/) (NICE સંદર્ભ કેસ); અનિશ્ચિતતા [PSA](../સંભાવનાત્મક-સંવેદનશીલતા-વિશ્લેષણ/) દ્વારા.

## ઉકેલેલું ઉદાહરણ

મધ્યમ ચિંતા માટે CBT ઍપ વિરુદ્ધ રૂબરૂ થેરાપીની પ્રતીક્ષા યાદી, દર્દી દીઠ:

```
Costs:  app licence + support        £250
        therapy displaced            −£680   (40% of users no longer need it)
        ΔC = 250 − 680 = −£430 (saves money)

QALYs:  6 months at utility 0.76 instead of 0.68 while waiting
        ΔE = 0.5 × (0.76 − 0.68) = +0.04 QALYs
```

ΔC < 0 અને ΔE > 0: ઍપ **પ્રભાવી** છે — વધુ સારી અને સસ્તી, ગુણોત્તરની જરૂર નથી. જો થેરાપી-વિસ્થાપન ધારણા ફક્ત 10% હોત, તો ΔC = 250 − 170 = +£80, અને ICUR = 80 / 0.04 = **£2,000/QALY** — હજુ £20,000 થી ઘણું નીચે. મુખ્ય ધારણા કાપી નાખ્યા છતાં કેસ ટકી રહે છે: મજબૂત CUA આવું દેખાય છે (અને [ટૉર્નેડો આકૃતિ](../સંવેદનશીલતા-વિશ્લેષણ/) તે સાબિત કરે છે).

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

CUA નો ઊંડો વિચાર — *અસમાન વસ્તુઓની સરખામણી માટે એક સંયુક્ત, પસંદગી-ભારિત એકમ* — અસમાન એન્જિનિયરિંગ રોકાણો (સુરક્ષા વિરુદ્ધ ડેવલપર અનુભવ વિરુદ્ધ વિશ્વસનીયતા) ની સરખામણીનો નમૂનો છે. પ્રામાણિક વિકલ્પો કાં તો બચાવી શકાય તેવો સંયુક્ત એકમ (દુર્લભ) અથવા સ્પષ્ટ [ખર્ચ-પરિણામ કોષ્ટક](../ખર્ચ-પરિણામ-વિશ્લેષણ/) (સામાન્ય) છે. CUA જેની સામે ચેતવે છે તે નકલી સંયુક્ત છે: ભારિત "અસર ગુણાંક" જેના ભાર પસંદગીનો વિકલ્પ જીતે તે માટે પછીથી ગોઠવાયા હોય. આરોગ્ય અર્થશાસ્ત્રે દાયકાઓ ઉપયોગિતા નિષ્કર્ષણ પ્રમાણિત કરવામાં વિતાવ્યા ચોક્કસ એટલા માટે કે ભાર સરખામણી પહેલાં આવે.

## સામાન્ય ભૂલો

- **સાધનની સંવેદનશીલતાથી નીચેના ઉપયોગિતા લાભ** ([દર્દી-નોંધિત પરિણામો](../દર્દી-નોંધિત-પરિણામો/) માં લઘુતમ ક્લિનિકલી મહત્ત્વનો તફાવત જુઓ) — નાનું ΔE ગુણ મોટી વસ્તી એ ક્લાસિક લૉન્ડરિંગ યુક્તિ છે.
- **તુલનાકાર સંભાળ વિસ્થાપન ચૂકવું** — ડિજિટલ ઉત્પાદનો માટે સૌથી મોટો ખર્ચ પદ ઘણી વાર તેઓ શું બદલે છે તે છે.
- **બિન-પસંદગી ગુણાંકને ઉપયોગિતામાં મેપ કરવા** અમાન્ય ક્રોસવૉક્સ સાથે.
