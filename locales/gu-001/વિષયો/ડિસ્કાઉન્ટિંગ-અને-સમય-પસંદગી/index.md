# ડિસ્કાઉન્ટિંગ અને સમય-પસંદગી

ડિસ્કાઉન્ટિંગ ભવિષ્યના ખર્ચ અને લાભોને વર્તમાન મૂલ્યોમાં ફેરવે છે, કારણ કે આજનો લાભ પાંચ વર્ષ પછીના એ જ લાભ કરતાં વધુ મૂલ્યવાન છે.

## આ શા માટે મહત્ત્વનું છે

દરેક આરોગ્ય-અર્થશાસ્ત્ર મૂલ્યાંકન અને દરેક ગંભીર જાહેર-ક્ષેત્ર બિઝનેસ કેસ બહુ-વર્ષીય પ્રવાહોને ડિસ્કાઉન્ટ કરે છે. UK ના HM Treasury Green Book 3.5% વાર્ષિક સામાજિક સમય-પસંદગી દર ફરજિયાત કરે છે; NICE નો સંદર્ભ કેસ ખર્ચ અને આરોગ્ય અસરો બંનેને વર્ષે 3.5% પર ડિસ્કાઉન્ટ કરે છે (30+ વર્ષ સુધી લાભવાળી લગભગ-ઇલાજ થેરાપી માટે 1.5% નો બિન-સંદર્ભ-કેસ દર). જો તમારો સૉફ્ટવેર બિઝનેસ કેસ "10 વર્ષમાં £5 મિલિયન બચત" નો દાવો કરે, તો નાણાકીય સમીક્ષક તરત ડિસ્કાઉન્ટેડ આંકડો માંગશે.

## ગણિત

ભવિષ્યની રકમનું વર્તમાન મૂલ્ય:

```
PV = FV / (1 + r)^t

PV = present value
FV = future value in year t
r  = discount rate (NICE/Green Book: 0.035)
t  = years from now
```

n વર્ષ માટે સ્થિર વાર્ષિક લાભ B (annuity) માટે:

```
PV = B × [1 − (1 + r)^(−n)] / r
```

## ઉકેલેલું ઉદાહરણ

તમારું સૉફ્ટવેર NHS ટ્રસ્ટને ગો-લાઇવ પછી એક વર્ષે શરૂ કરીને 5 વર્ષ માટે વર્ષે £100,000 બચાવે છે.

ડિસ્કાઉન્ટ વગરનો કુલ: £500,000.

3.5% પર ડિસ્કાઉન્ટેડ:

```
Year 1: 100,000 / 1.035^1 = £96,618
Year 2: 100,000 / 1.035^2 = £93,351
Year 3: 100,000 / 1.035^3 = £90,194
Year 4: 100,000 / 1.035^4 = £87,144
Year 5: 100,000 / 1.035^5 = £84,197

Total PV ≈ £451,505
```

પ્રામાણિક હેડલાઇન લગભગ £451,000 છે, ભોળા સરવાળા કરતાં આશરે 10% ઓછી. હવે ધારો કે ડિલિવરી એક વર્ષ સરકે છે: દરેક પદ એક વર્ષ પછી ખસે છે, અને PV લગભગ £436,000 સુધી ઘટે છે — [વિલંબની કિંમત](../વિલંબની-કિંમત/) નું ડિસ્કાઉન્ટિંગ દૃશ્ય.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

- **ટેક-ડેટ ચૂકવણી અને પ્લૅટફૉર્મ માઇગ્રેશન** વર્ષો દૂરના લાભ પ્રવાહોનું વચન આપે છે; આ ત્રિમાસિકમાં વળતર આપતા કામ સામે સરખાવતા પહેલાં તેમને ડિસ્કાઉન્ટ કરો.
- **આગળ-ભારિત ખર્ચ, પાછળ-ભારિત લાભ** માઇગ્રેશનનો પ્રમાણભૂત આકાર છે. ડિસ્કાઉન્ટિંગ તે આકારને દંડ કરે છે, યોગ્ય રીતે: તે પછીના મૂલ્ય માટે હમણાં ક્ષમતા પ્રતિબદ્ધ કરવાની જોખમ-મુક્ત સમય કિંમત આંકે છે.
- **"પાંચમા વર્ષે બચત" દાવાઓ** બે વાર સંશયને પાત્ર છે — તે ભારે ડિસ્કાઉન્ટેડ અને અત્યંત અનિશ્ચિત બંને છે (જુઓ [સંવેદનશીલતા વિશ્લેષણ](../સંવેદનશીલતા-વિશ્લેષણ/)).

## સામાન્ય ભૂલો

- **ખર્ચ ડિસ્કાઉન્ટ કરવા પણ લાભ નહીં** (અથવા ઊલટું) — સંદર્ભ કેસ બંનેને એ જ દરે ડિસ્કાઉન્ટ કરે છે.
- **જાહેર-ક્ષેત્ર કેસમાં વાણિજ્યિક દર (8–12%) વાપરવો**, અથવા વેન્ચર-બૅક્ડ કેસમાં 3.5%. દર નિર્ણયકર્તા સાથે મેળવો.
- **ડિસ્કાઉન્ટિંગ અને ફુગાવાની ભેળસેળ.** ડિસ્કાઉન્ટિંગ *વાસ્તવિક* (ફુગાવા-સમાયોજિત) મૂલ્યો પર લાગુ થાય છે; બંને ગર્ભિત રીતે ન કરો.
