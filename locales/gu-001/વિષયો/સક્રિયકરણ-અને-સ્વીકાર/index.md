# સક્રિયકરણ અને સ્વીકાર

સક્રિયકરણ દર એટલે સાઇન-અપ કરનારાઓનો તે હિસ્સો જે પ્રથમ અર્થપૂર્ણ મૂલ્ય સુધી પહોંચે છે ("aha" ક્રિયા — પ્રથમ રીડિંગ નોંધાયું, પ્રથમ પાઠ પૂરો થયો). સ્વીકાર (uptake) તેનું વસ્તી-સ્તરનું સ્વરૂપ છે: *પાત્ર* વસ્તીનો તે હિસ્સો જે મૂળભૂત રીતે અપનાવે છે. સાથે મળીને તે મૂલ્ય ફનલના આગળના દરવાજા છે: પ્રાપ્તિ → સ્વીકાર → સક્રિયકરણ → [જાળવણી](../જાળવણી-અને-છોડી-જવું/) → પરિણામ.

## આ શા માટે મહત્ત્વનું છે

સક્રિય ન થયેલા વપરાશકર્તાઓ શુદ્ધ ખર્ચ છે: પ્રાપ્તિ ખર્ચ, પ્રોવિઝનિંગ, સપોર્ટ સપાટી — ક્લિનિકલ મૂલ્ય શૂન્ય. બેન્ચમાર્ક મુજબ આરોગ્ય સૉફ્ટવેરનું સક્રિયકરણ ઉદ્યોગોની સરેરાશ *કરતાં નીચું* છે (એક SaaS બેન્ચમાર્ક સમૂહમાં નવા-વપરાશકર્તા સક્રિયકરણ ≈24% વિરુદ્ધ ≈37%; ઑનબોર્ડિંગ ચેકલિસ્ટ પૂર્ણતા ~20%), જે વધુ ભારે ઑનબોર્ડિંગ (ઓળખ, સંમતિ, ક્લિનિકલ સલામતી) દર્શાવે છે. સ્વીકાર વસ્તીનો દાવ વહન કરે છે: [RE-AIM માળખા](../પહોંચ-અને-સમાનતા/)માં જાહેર-આરોગ્ય અસર ≈ પહોંચ × અસરકારકતા — પાત્ર વસ્તીના 3% દ્વારા અપનાવાયેલી ઉત્તમ ઍપ વસ્તી પર માત્ર 3% જેટલો જ ફેરફાર લાવે છે. સૂચવેલી ડિજિટલ થેરાપ્યુટિક્સ માટે સ્વીકારનો દરવાજો રાષ્ટ્રીય માહિતીમાં દેખાય છે: **~81% જર્મન DiGA પ્રિસ્ક્રિપ્શન સક્રિય થાય છે** — દર પાંચમાંથી એક સૂચવેલી-અને-ચૂકવેલી સારવાર ક્યારેય શરૂ થતી નથી (જુઓ [DiGA ફાસ્ટ-ટ્રૅક](../જર્મનીનો-diga-ફાસ્ટ-ટ્રૅક/)).

## ગણિત

```
Activation rate = users completing key action within window / sign-ups × 100
Uptake rate     = adopters / eligible population × 100
DTx fill rate   = activated prescription codes / issued prescriptions × 100

Funnel value model:
  eligible × uptake × activation × retention-weighted benefit = population value
  — four multiplications; improving the smallest factor usually
  dominates (theory-of-constraints for funnels)
```

## ઉકેલેલું ઉદાહરણ

એક કમિશનર 80,000 પાત્ર રહેવાસીઓને ડાયાબિટીસ-નિવારણ ઍપ ઑફર કરે છે:

```
Invited → registered:  80,000 → 12,000  (uptake 15%)
Registered → activated (first session + goal set, 7 days): 12,000 → 5,400 (45%)
Activated → completed 6-month programme: 5,400 → 1,600 (30%)

Programme effect (trial, completers): 0.03 QALYs + £180 avoided costs
Population value = 1,600 × (0.03 × £20,000 + £180) ≈ £1.25M
Per-eligible-person value = £15.6 — versus £780 if every eligible person completed.

Where to invest? Doubling uptake (15→30%) doubles value; raising
activation 45→65% adds ~44%; both beat further polishing the programme
content the 1,600 already complete.
```

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

સક્રિયકરણ ફનલનો સૌથી વધુ એન્જિનિયરિંગ-સાધ્ય તબક્કો છે: ઓળખ-ચકાસણીનું ઘર્ષણ, સંમતિ પ્રવાહો, ખાલી-સ્થિતિ ડિઝાઇન અને પ્રથમ-મૂલ્ય સુધીનો સમય એ કોડ છે, નીતિ નહીં (બેન્ચમાર્ક માહિતીમાં આરોગ્ય સેવાનો મધ્યક પ્રથમ-મૂલ્ય સમય ≈ 1 દિવસ 7 કલાક — તેનો દરેક કલાક છોડી જવાનું જોખમ છે). સ્વીકાર વિતરણ-પ્રણાલીઓની સમસ્યા છે: રેફરલ માર્ગોમાં સંકલન (પ્રિસ્ક્રિપ્શનની ક્ષણ), GP-સમર્થિત આમંત્રણો (વિશ્વાસનું સ્થાનાંતરણ), અને સુલભતા (ભાષા, ડિજિટલ કૌશલ્ય — જુઓ [પહોંચ અને સમાનતા](../પહોંચ-અને-સમાનતા/)). ઉપરનું ફનલ-મૂલ્ય મૉડેલ બંને માટે બિઝનેસ કેસ જનરેટર છે: પરિબળોને ગુણો, અવરોધ શોધો, અને તે જે વસ્તી-મૂલ્ય મુક્ત કરે છે તેની સામે ઉકેલની કિંમત આંકો.

## સામાન્ય ભૂલો

- **સક્રિયકરણની વ્યાખ્યા સગવડ તરીકે** (ઇમેઇલ ચકાસાયો) ક્લિનિકલ અર્થ (પ્રથમ ઉપચારાત્મક ક્રિયા)ને બદલે — મેટ્રિક ફુલાવે છે, મૂલ્ય શૃંખલા તોડે છે.
- **સ્વીકારના છેદ સાથે રમત**: "સાઇટની મુલાકાત લેનારાઓમાંથી" વિરુદ્ધ ખરેખર પાત્ર વસ્તી — કમિશનરો બીજાની કાળજી રાખે છે.
- **પસંદગી અસરો**: સક્રિય કરવામાં સરળ વપરાશકર્તાઓ સૌથી ઓછા બીમાર અને સૌથી ઓછા વંચિત હોય છે; ફનલ સુધારા સરેરાશ સુધારતી વખતે સમાનતાનું અંતર વધારી શકે છે.
