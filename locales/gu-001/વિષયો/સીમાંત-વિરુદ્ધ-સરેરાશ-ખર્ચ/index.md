# સીમાંત વિરુદ્ધ સરેરાશ ખર્ચ

સરેરાશ ખર્ચ એટલે કુલ ખર્ચ ભાગ્યા ઉત્પન્ન થયેલા એકમો. સીમાંત ખર્ચ એટલે એક *વધારાનો* એકમ ઉત્પન્ન કરવાનો ખર્ચ. નિર્ણયો સીમાંત ખર્ચ પર લેવા જોઈએ — પણ પ્રકાશિત એકમ ખર્ચ લગભગ હંમેશા સરેરાશ હોય છે.

## આ શા માટે મહત્ત્વનું છે

ડિજિટલ આરોગ્ય બિઝનેસ કેસમાં સૌથી સામાન્ય ભૂલ છે બચાવેલા સંસાધનનું **સરેરાશ** ખર્ચે મૂલ્યાંકન કરવું જ્યારે વાસ્તવિક બચત **સીમાંત** ખર્ચ છે. હૉસ્પિટલ પથારી-દિવસનો સરેરાશ (સંપૂર્ણ-શોષિત) ખર્ચ £400+ છે, પણ એક પથારી-દિવસ મુક્ત કરવાથી £400 બચતા નથી — મકાન, ગરમી અને મોટાભાગનો સ્ટાફિંગ ખર્ચ ચાલુ રહે છે. વાસ્તવમાં મુક્ત થતી રોકડ £50–£150 હોઈ શકે, સિવાય કે વૉર્ડ બંધ કરવા જેટલી પથારીઓ મુક્ત થાય.

## ગણિત

```
Average cost:  AC = TC / Q
Marginal cost: MC = dTC/dQ   (cost of one more/one fewer unit)

TC = total cost, Q = quantity
```

સ્થિર ખર્ચ ક્ષમતા ઘટાડા માટે MC < AC બનાવે છે, અને જ્યારે વધારાની ક્ષમતા હોય ત્યારે MC શૂન્યની નજીક પહોંચી શકે. બચત દાવાઓએ વાપરવું જોઈએ:

```
True saving = ΔQ × MC          (small changes)
True saving = step change in TC (large changes that cross a capacity threshold, e.g. closing a ward)
```

## ઉકેલેલું ઉદાહરણ

તમારું સૉફ્ટવેર સરેરાશ દાખલ રહેવાનો સમય ઘટાડે છે, ટ્રસ્ટમાં વર્ષે 1,000 પથારી-દિવસો મુક્ત કરે છે.

- **ભોળો દાવો**: 1,000 × £400 સરેરાશ ખર્ચ = **£400,000 બચ્યા**. ખોટો.
- **સીમાંત દાવો**: પથારી-દિવસ દીઠ ચલ ખર્ચ (ખોરાક, લૉન્ડ્રી, ઉપભોગ્ય વસ્તુઓ, થોડું નર્સિંગ ફ્લેક્સ) ≈ £120. બચત = 1,000 × £120 = **£120,000**, *ઉપરાંત* જો પથારીઓ રાહ જોતા વૈકલ્પિક દર્દીઓથી ફરી ભરાય તો મુક્ત ક્ષમતાનું મૂલ્ય (પ્રવૃત્તિ-આધારિત ચુકવણી હેઠળ આવક, અથવા પ્રતીક્ષા-યાદી ઘટાડો).
- **પગથિયું-ફેરફાર દાવો**: જો ટ્રસ્ટ વર્ષે 7,300 પથારી-દિવસો (20-પથારીનો વૉર્ડ) મુક્ત કરે, તો તે ખરેખર વૉર્ડ બંધ કરી શકે: સ્ટાફિંગ + ચાલુ ખર્ચ ≈ £1.5 મિલિયન/વર્ષ વાસ્તવિક રોકડ. હવે સરેરાશ-ખર્ચ ગણિત સત્યની વધુ નજીક છે.

એ જ હસ્તક્ષેપ, ત્રણ બચાવી શકાય તેવી સંખ્યાઓ, ફેરફાર ક્ષમતા પગથિયું પાર કરે છે કે નહીં તેના આધારે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

ક્લાઉડ અર્થશાસ્ત્ર મૂળભૂત સીમાંત-ખર્ચ પ્રદેશ છે:

- પહેલેથી-રિઝર્વ કરેલી ક્ષમતા પર એક વધુ CI રનનો સીમાંત ખર્ચ ≈ £0 છે, જ્યારે રન દીઠ સરેરાશ ખર્ચ (કુલ પ્લૅટફૉર્મ ખર્ચ ÷ રન) પાઉન્ડમાં હોઈ શકે. સરેરાશ ખર્ચ વસૂલતી ચાર્જબૅક પ્રણાલીઓ ટીમોને વહેંચાયેલ ક્ષમતાનો ઓછો ઉપયોગ કરવા પ્રેરે છે જે સીમા પર ખરેખર મફત છે.
- વિપરીત રીતે, "અમે 30% કમ્પ્યુટ બચાવ્યું" ત્યારે જ રોકડ મુક્ત કરે છે જ્યારે ઇન્સ્ટન્સ ખરેખર સમાપ્ત થાય કે રિઝર્વેશન ઘટે — પથારી-દિવસ જાળનું સૉફ્ટવેર સંસ્કરણ. જુઓ [રોકડ-મુક્તિકારક વિરુદ્ધ બિન-રોકડ-મુક્તિકારક બચત](../રોકડ-મુક્તિકારક-વિરુદ્ધ-બિન-રોકડ-મુક્તિકારક-બચત/).

## સામાન્ય ભૂલો

- **ક્ષમતાનું સરેરાશ ખર્ચે મૂલ્યાંકન** અને તેને રોકડ તરીકે રજૂ કરવું (ક્લાસિક).
- **સીમાંત ખર્ચ સ્થિર છે એમ માનવું.** તે ક્ષમતા સીમાઓ પર પગથિયાં બનાવે છે (વૉર્ડ બંધ, લાઇસન્સ સ્તરો, રિઝર્વ્ડ-ઇન્સ્ટન્સ પ્રતિબદ્ધતા).
- **એ જ કેસમાં વિસ્તરણ નિર્ણયો માટે સીમાંત પણ સંકોચન માટે સરેરાશ વાપરવું** — વાસ્તવિક નિર્ણય અનુસાર પસંદ કરો.
