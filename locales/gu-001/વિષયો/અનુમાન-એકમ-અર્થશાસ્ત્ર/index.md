# અનુમાન એકમ અર્થશાસ્ત્ર

અનુમાન (inference) એકમ અર્થશાસ્ત્ર AI સુવિધાઓની કિંમત તેમના સીમાંત કમ્પ્યુટથી આંકે છે: **ટોકન દીઠ ખર્ચ**, જે વ્યવહાર દીઠ, વપરાશકર્તા દીઠ, ક્લિનિકલ એપિસોડ દીઠ ખર્ચમાં ભેગો થાય છે. નિર્ણાયક ગતિશીલતા: LLM ભાવ સ્થિર ક્ષમતા પર લગભગ **દર 1–2 વર્ષે એક ગણા ક્રમથી** ઘટ્યા છે — આરોગ્ય-ટેકનોલોજી ખર્ચ આંકણીમાં અભૂતપૂર્વ ડિફ્લેશન દર.

## આ શા માટે મહત્ત્વનું છે

ભાવ પતનથી બે પરિણામો આવે છે. વાણિજ્યિક રીતે, આજે સીમાંત AI સુવિધા 18 મહિનામાં તુચ્છ રીતે નફાકારક હોઈ શકે — અને આજના ખર્ચ પર ભાવ નક્કી કરનાર સ્પર્ધકને નીચે પાડવામાં આવશે. આર્થિક મૂલ્યાંકન માટે, AI-સક્ષમ ક્લિનિકલ સેવા માટેનું કોઈપણ ખર્ચ-અસરકારકતા મૉડેલ જે 2024 અનુમાન ભાવ સ્થિર કરે છે તે **ચાલુ ખર્ચને ભૌતિક રીતે વધુ આંકે છે** — વિશ્લેષણને ભાવ-ઘટાડા દૃશ્યો જોઈએ, જેમ દવા મૉડેલો પેટન્ટ સમાપ્તિ અને જેનરિક પ્રવેશ સંભાળે છે. (સંશોધનમાંથી સંદર્ભ બિંદુઓ: 2026 ના મધ્યમાં ફ્રન્ટિયર આઉટપુટ ટોકન ~$15–75/M, મધ્યમ-સ્તરના મૉડેલ એક ક્રમ સસ્તા, GPT-4-સ્તરની ક્ષમતા 2022 માં ~$20/M થી ~$0.40/M; Epoch AI એ ક્ષમતા માઇલસ્ટોન મુજબ 9×–900×/વર્ષ ઘટાડા માપ્યા.)

## ગણિત

```
Cost per call     = input tokens × input rate + output tokens × output rate
Cost per unit     = Σ calls per unit of business output (per triage episode,
                    per drafted letter, per consultation summary)

Blended reality   = base call + retries + RAG context (input-heavy)
                    + evaluation/guardrail calls (often 20–50% overhead)

Price-decline scenario for multi-year models:
  cost_t = cost_0 × d^t, test d ∈ {0.3, 0.5, 0.7}/year in sensitivity analysis
```

## ઉકેલેલું ઉદાહરણ

AI રજા-સારાંશ સેવા: સરેરાશ સારાંશ 12,000 ઇનપુટ ટોકન (રેકોર્ડ સંદર્ભ) + 1,200 આઉટપુટ વાપરે છે, ઉપરાંત ચકાસણી પાસ (6,000 in / 300 out). $3/M in, $15/M out પર:

```
Draft:   12,000 × 3/1M + 1,200 × 15/1M  = $0.036 + $0.018 = $0.054
Verify:   6,000 × 3/1M +   300 × 15/1M  = $0.018 + $0.0045 ≈ $0.023
Per summary ≈ $0.077 → per 100,000 summaries/year ≈ $7,700

Against ~20 clinician-minutes saved per summary (≈ £25), inference is
0.25% of the value created — the economics are dominated by everything
EXCEPT the tokens: integration, evaluation, governance, adoption.
```

એ નિષ્કર્ષ — ઉચ્ચ-મૂલ્ય ક્લિનિકલ કાર્યો માટે, વર્તમાન ભાવે, અનુમાન ખર્ચ ભાગ્યે જ બંધનકર્તા અવરોધ છે — તે જ ભાવ બેઠકોમાં સાથે લઈ જવા યોગ્ય તારણ છે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

આ AI માટે વિશિષ્ટ [ક્લાઉડ યુનિટ ઇકોનોમિક્સ](../ક્લાઉડ-યુનિટ-ઇકોનોમિક્સ/) છે, ત્રણ પ્રથા નોંધ સાથે: **API કૉલ નહીં, બિઝનેસ એકમ દીઠ મીટર કરો**, જેથી સંખ્યા સીધી [ICER](../વૃદ્ધિશીલ-ખર્ચ-અસરકારકતા-ગુણોત્તર/)/[બજેટ અસર](../બજેટ-અસર-વિશ્લેષણ/) મૉડેલોમાં બેસે; **ઇનપુટ/આઉટપુટ અસમપ્રમાણતા પર નજર રાખો** (આઉટપુટ સામાન્ય રીતે ઇનપુટ ભાવના ~4×; RAG આર્કિટેક્ચર ઇનપુટ-ભારે છે — આર્કિટેક્ચર પસંદગીઓ ભાવ પસંદગીઓ છે); અને **કાર્ય સ્તર દ્વારા રૂટ કરો** — મૉડેલ ક્ષમતાને કાર્ય મુશ્કેલી સાથે મેળવવું (વર્ગીકરણ માટે સસ્તા મૉડેલ, સંશ્લેષણ માટે ફ્રન્ટિયર) નિયમિતપણે સમાન ગુણવત્તાએ મિશ્ર ખર્ચ 5–10× ઘટાડે છે, સૌથી સસ્તા અસરકારક હસ્તક્ષેપના ઉપયોગનું સૉફ્ટવેર સંસ્કરણ ([ખર્ચ-લઘુતમીકરણ](../ખર્ચ-લઘુતમીકરણ-વિશ્લેષણ/), સમતુલ્યતા પુરવાર).

## સામાન્ય ભૂલો

- **સ્થિર-ભાવ બહુ-વર્ષીય મૉડેલ** — ખર્ચ વધુ આંકે છે; પણ **ધારેલ-ડિફ્લેશન આવક મૉડેલ** — ભાવ યુદ્ધ કરાર નથી; બંનેનું દૃશ્ય બનાવો.
- **મૂલ્યાંકન ઓવરહેડની અવગણના**: ગાર્ડરેઇલ, જજ અને રિટ્રાય વાસ્તવિક ટોકન છે, નિયંત્રિત સેટિંગ્સમાં ઘણી વાર બહુમતી.
- **ટોકન-દીઠ દ્રષ્ટિદોષ**: લેટન્સી, રેટ મર્યાદા અને કૉન્ટેક્સ્ટ-વિન્ડો અવરોધો કોઈ ટોકન ભાવ પકડતો નથી તેવા ખર્ચ વહન કરે છે.
