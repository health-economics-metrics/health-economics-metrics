# માનવ મૂડી અભિગમ વિરુદ્ધ ઘર્ષણ ખર્ચ પદ્ધતિ

આ બીમારી, અપંગતા કે મૃત્યુથી ગુમાવેલી ઉત્પાદકતાનું રોગ-ખર્ચ અને ખર્ચ-લાભ અભ્યાસોમાં મૂલ્યાંકન કરવાની બે સ્પર્ધક પદ્ધતિઓ છે. માનવ મૂડી અભિગમ (HCA) ગેરહાજરીના સંપૂર્ણ સમયગાળા માટે ગુમાવેલા બધા આઉટપુટનું વેતન દરે મૂલ્ય આંકે છે; ઘર્ષણ ખર્ચ પદ્ધતિ (FCM) ફક્ત નોકરીદાતાને ઉત્પાદન પુનઃસ્થાપિત કરવા જોઈએ તે ટૂંકા સમયગાળા માટે મૂલ્ય આંકે છે. બંને વચ્ચે પસંદગી પરોક્ષ-ખર્ચ અંદાજને બે ગણો કે વધુ બદલે છે.

## આ શા માટે મહત્ત્વનું છે

પરોક્ષ (ઉત્પાદકતા) ખર્ચ આરોગ્ય અર્થશાસ્ત્રની સૌથી વિવાદિત લાઇન આઇટમ્સમાંની એક છે ચોક્કસ કારણ કે બે પ્રમાણભૂત પદ્ધતિઓ આટલી તીવ્ર રીતે અસંમત છે. HCA ગેરહાજરીના દરેક દિવસને અર્થતંત્ર ખરેખર ગુમાવતા આઉટપુટનો દિવસ ગણે છે, સંપૂર્ણ સમયગાળા માટે પૂરા વેતન પર મૂલ્ય — અથવા મૃત્યુ કે કાયમી અપંગતા માટે બાકીના કામના જીવન માટે. FCM દલીલ કરે છે કે બેરોજગારી અને શ્રમ-બજાર ઢીલાશ ધરાવતા અર્થતંત્રમાં, નોકરીદાતાએ બદલી તૈયાર કર્યા પછી કે કામ ફરી વહેંચ્યા પછી લાંબી ગેરહાજરીનો મોટાભાગ ખરેખર રાષ્ટ્રીય આઉટપુટ ઘટાડતો નથી; ફક્ત "ઘર્ષણ સમયગાળો" — ઉત્પાદનને અગાઉના સ્તરે પાછું લાવવાનો સમય — વાસ્તવિક નુકસાન છે. FCM તેથી HCA કરતાં વ્યવસ્થિત રીતે ઓછા, વધુ રૂઢિચુસ્ત પરોક્ષ-ખર્ચ અંદાજો આપે છે, અને બંને પદ્ધતિઓ અદલાબદલી કરી શકાય તેવી ટૂંકનોંધ નથી: તે "ગુમાવેલી ઉત્પાદકતા" નો અર્થ શું તે અંગેના અલગ આર્થિક સિદ્ધાંતો છે. એટલે જ [NICE નો સંદર્ભ કેસ](../આરોગ્ય-ટેકનોલોજી-મૂલ્યાંકન/) ડિફૉલ્ટ રૂપે ઉત્પાદકતા ખર્ચ બાકાત રાખે છે, તેમને સંદર્ભ-કેસ ICER માં ભેળવવાને બદલે, જો કરે તો, અલગ સામાજિક-દૃષ્ટિકોણ સંવેદનશીલતા વિશ્લેષણ તરીકે અહેવાલ કરે છે — જુઓ [વિશ્લેષણ દૃષ્ટિકોણ](../વિશ્લેષણ-દૃષ્ટિકોણ/).

## ગણિત

```
Human Capital Approach:
HCA_cost = daily_wage × days_lost

Friction Cost Method (simplified, capped-at-friction-period form):
FCM_cost = daily_wage × min(days_lost, friction_period_days)

friction_period_days = country/sector-specific estimate of time-to-restore
                        production (historically ~85 days in Dutch iMTA
                        costing guidance; varies by country and is
                        periodically re-estimated)
```

બંને પદ્ધતિઓ વચ્ચેની સંપૂર્ણ અસંમતિ `min()` માં રહે છે: HCA ક્યારેય `days_lost` ને મર્યાદિત કરતી નથી, તેથી ખર્ચ આખી ગેરહાજરી દરમ્યાન વધતો રહે છે, જ્યારે FCM વાસ્તવિક ગેરહાજરી ગમે તેટલી લાંબી ચાલે, ગણાતા દિવસોને ઘર્ષણ સમયગાળા સુધી મર્યાદિત કરે છે.

## ઉકેલેલું ઉદાહરણ

એક કર્મચારી `days_lost = 180` દિવસ કામથી દૂર છે, `daily_wage = £150` કમાય છે.

**માનવ મૂડી અભિગમ**:

```
HCA_cost = 150 × 180 = £27,000
```

**ઘર્ષણ ખર્ચ પદ્ધતિ**, `friction_period_days = 85` ના ઘર્ષણ સમયગાળા સાથે (ઐતિહાસિક Dutch iMTA બેન્ચમાર્ક, માર્ગદર્શનના સમયાંતરે પુનઃઅંદાજ મુજબ):

```
FCM_cost = 150 × min(180, 85) = 150 × 85 = £12,750
```

FCM ના £12,750 એ *એ જ* ગેરહાજરી માટે HCA ના £27,000 ના અડધાથી ઓછા છે — ફક્ત પદ્ધતિની પસંદગી રોગ-ખર્ચ કેસને ભૌતિક રીતે બદલે છે, અન્ય કોઈ ધારણાને સ્પર્શ્યા પહેલાં.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

આ ટીમ એન્જિનિયર જતાં તેનું મૂલ્ય કેવી રીતે આંકે છે તેની સાથે સીધું મેપ થાય છે:

- **HCA-શૈલી અટ્રિશન ખર્ચ**: ભૂમિકા ખાલી રહે ત્યાં સુધી ગયેલા એન્જિનિયરના સંપૂર્ણ પગાર તરીકે નુકસાનનું મૂલ્ય. આ મોટાભાગના અટ્રિશન-ખર્ચ મૉડેલોનું ભોળું સંસ્કરણ છે, અને તે HCA ઉત્પાદકતા નુકસાનને વધુ આંકે છે તે જ કારણે નુકસાનને વધુ આંકે છે — તે માને છે કે ખાલી ક્ષમતા આખો સમય સંપૂર્ણ ઉત્પાદક હતી અને બીજા કંઈએ ઢીલાશ શોષી નહીં. આ પદ્ધતિ જે ભરતી/ઑનબોર્ડિંગ/ખાલી-જગ્યા-કવર સાંકળને ફીડ કરે છે તેને માપતા [કાર્યબળ જાળવણી](../કાર્યબળ-જાળવણી/) જુઓ.
- **FCM-શૈલી અટ્રિશન ખર્ચ**: બદલીને બૅકફિલ અને રૅમ્પ કરવાના વાસ્તવિક સમય — એન્જિનિયરિંગ "ઘર્ષણ સમયગાળો" — માટે જ નુકસાનનું મૂલ્ય. બિઝનેસ કેસ માટે આ વધુ બચાવી શકાય તેવો આંકડો છે, બરાબર જેમ FCM રોગ-ખર્ચ અભ્યાસમાં વધુ રૂઢિચુસ્ત પસંદગી છે.
- અંતર્ગત શિસ્ત [તકની કિંમત](../તકની-કિંમત/) માં છે તે જ છે: વિસ્થાપિત સંસાધનનું મૂલ્ય ખરેખર શું ગુમાવાયું તેના આધારે આંકો, દર વડે ગુણેલા હેડલાઇન સમયગાળા દ્વારા નહીં.

## સામાન્ય ભૂલો

- **એક જ વિશ્લેષણમાં HCA અને FCM ભેળવવા, અથવા પસંદગી જાહેર કર્યા વિના ફક્ત એક અહેવાલ કરવો.** એ જ ગેરહાજરી ડેટા પદ્ધતિ મુજબ અહેવાલિત ખર્ચમાં 2x+ તફાવત પેદા કરી શકે; પસંદગી જણાવવી જોઈએ, દાટી ન દેવી.
- **સામાજિક-દૃષ્ટિકોણ કેસ માટે HCA ને સંવેદનશીલતા વિશ્લેષણ તરીકે ચિહ્નિત કર્યા વિના વાપરવું.** NICE નો સંદર્ભ કેસ સ્પષ્ટપણે ઉત્પાદકતા ખર્ચ બાકાત રાખે છે; સામાજિક-દૃષ્ટિકોણ HCA અંદાજ દૃશ્ય વિશ્લેષણમાં આવે છે, હેડલાઇન ICER માં નહીં.
- **અવેતન કે બિન-બજાર કામ (દા.ત. સંભાળકાર્ય) પર સમાયોજન વિના કોઈપણ પદ્ધતિ લાગુ કરવી.** બંને પદ્ધતિઓ મૂલ્ય માટે વેતન-દર પ્રોક્સી ધારે છે, જે બજાર વેતન વિનાના કામ પર સ્વચ્છ રીતે સ્થાનાંતરિત થતું નથી.
