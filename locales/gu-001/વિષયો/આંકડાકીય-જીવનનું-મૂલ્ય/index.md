# આંકડાકીય જીવનનું મૂલ્ય (VSL)

આંકડાકીય જીવનનું મૂલ્ય (VSL) — UK ઉપયોગમાં "અટકાવેલ મૃત્યુનું મૂલ્ય" (VPF) કહેવાય છે — એ રકમ છે જે *વસ્તી* એક આંકડાકીય મૃત્યુનું જોખમ ઘટાડવા સામૂહિક રીતે ચૂકવવા તૈયાર છે, જે વેતન-જોખમ વિનિમય અભ્યાસો (જોખમી નોકરીઓ માટે કામદારો કેટલો વધારાનો પગાર માગે છે) અને જણાવેલ-પસંદગી સર્વેમાંથી મેળવાય છે. તે કોઈ ઓળખાયેલ વ્યક્તિના જીવનની કિંમત નથી; તે વસ્તી-જોખમ રચના છે, અને જોખમ-ઘટાડતી સિસ્ટમો — ટ્રાયેજ ઍલ્ગોરિધમ, ઍમ્બ્યુલન્સ ડિસ્પૅચ, સલામતી નિરીક્ષણ — બનાવતા સૉફ્ટવેર એન્જિનિયરે જાણવું જોઈએ કે તે [ચૂકવવાની તૈયારીની સીમાઓ](../ચૂકવવાની-તૈયારીની-સીમાઓ/) કરતાં જુદી સૈદ્ધાંતિક પરંપરામાંથી આવે છે.

## આ શા માટે મહત્ત્વનું છે

VSL/VPF નિયમનકારી ખર્ચ-લાભ વિશ્લેષણમાં મૃત્યુ-જોખમ ઘટાડાને નાણાંમાં ફેરવવાનું પ્રમાણભૂત સાધન છે: પરિવહન સલામતી, પર્યાવરણીય નિયમન, અને કેટલાક જાહેર-આરોગ્ય હસ્તક્ષેપો બધા તેમના બિઝનેસ કેસ તેમાંથી ચલાવે છે. HM Treasury નું Green Book UK શ્રમ-બજાર અને સર્વે પુરાવામાંથી મેળવેલો VPF આંકડો પ્રકાશિત કરે છે, અને પરિવહન વિભાગ તેને માર્ગ-સલામતી મૂલ્યાંકનમાં સીધો વાપરે છે. આ QALY × ચૂકવવાની-તૈયારી-સીમા પદ્ધતિથી ખરેખર જુદી મૂલ્યાંકન પરંપરા છે: સીમા અભિગમ આરોગ્ય લાભને આરોગ્ય *બજેટ* હાલમાં સીમાંત પર જે ઉત્પન્ન કરે છે તેની સામે મૂલવે છે, જ્યારે VSL/VPF જોખમ ઘટાડાને શ્રમ બજાર કે સર્વેમાં લોકો તેના માટે જે ચૂકવવાનું પ્રગટ કરે છે તેની સામે મૂલવે છે. બંને માળખાં હંમેશાં સમાધાનપાત્ર નથી, અને તે સ્વીકાર્યા વગર એક જ કેસમાં બંને વાપરવું સામાન્ય વિશ્લેષણાત્મક ભૂલ છે.

## ગણિત

```
Deaths averted = population × risk_reduction_per_person
  (risk_reduction_per_person is a probability, e.g. 0.000001 = 1-in-a-million
   reduction in annual mortality risk)

Monetized mortality benefit = deaths_averted × value_of_prevented_fatality
```

## ઉકેલેલું ઉદાહરણ

800,000 લોકોનો એક પ્રદેશ માર્ગ-સલામતી ડિજિટલ ડિસ્પૅચ/ટ્રાયેજ હસ્તક્ષેપથી લાભ મેળવે છે જે દરેક વ્યક્તિનું વાર્ષિક મૃત્યુ જોખમ દસ લાખમાં 1 (0.000001) ઘટાડે છે:

```
Deaths averted = 800,000 × 0.000001 = 0.8
```

UK ના અટકાવેલ મૃત્યુ મૂલ્ય, £2,180,000 (HM Treasury/DfT આંકડો, 2023/24 ભાવ — Green Book તેને વાર્ષિક અપડેટ કરે છે, જીવંત વિશ્લેષણમાં ટાંકતા પહેલાં ફરી ચકાસો) નો ઉપયોગ કરતાં:

```
Monetized mortality benefit = 0.8 × £2,180,000 = £1,744,000/year
```

વર્ષ દીઠ £1.75 મિલિયનથી થોડો ઓછો નાણાંકીય મૃત્યુ લાભ, એવા જોખમ ઘટાડામાંથી જે અસરગ્રસ્ત મોટાભાગની વસ્તી વ્યક્તિગત રીતે ક્યારેય નોંધે નહીં.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

સલામતી-નિર્ણાયક સૉફ્ટવેર ટીમો — મેડિકલ ઉપકરણ ફર્મવેર, સ્વાયત્ત વાહન સૉફ્ટવેર, ઔદ્યોગિક નિયંત્રણ સિસ્ટમો — સલામતી રોકાણ માટે ખર્ચ-લાભ કેસ બનાવતી વખતે બરાબર આ જ ભાવ-નિર્ધારણ સમસ્યાનો સામનો કરે છે: જ્યારે નિષ્ફળતા દુર્લભ, ગંભીર અને વપરાશકર્તાઓની મોટી વસ્તીમાં ફેલાયેલી હોય ત્યારે "એક વિનાશક નિષ્ફળતા અટકાવો" નો ભાવ કેવી રીતે નક્કી કરશો? VSL/VPF એ દુર્લભ, ગંભીર, વસ્તી-સ્તરના જોખમ ઘટાડા પર આંકડો મૂકવાનો દાયકાઓ જૂનો, જાહેરમાં દસ્તાવેજીકૃત વાસ્તવિક-વિશ્વ દાખલો છે — દુર્લભ વિનાશક આઉટેજ સામે SRE રોકાણનો ભાવ નક્કી કરવાની દલીલનો જ આકાર, ફક્ત ડાઉનટાઇમ પરિણામને બદલે મૃત્યુ પરિણામ સાથે.

## સામાન્ય ભૂલો

- **VSL ને "ઓળખાયેલ જીવનની કિંમત" ગણવી**: તે નથી. VSL/VPF ઘણા લોકો વચ્ચેના જોખમ-ઘટાડા વિનિમયમાંથી મેળવેલી વસ્તી આંકડાકીય રચના છે, કોઈ ચોક્કસ વ્યક્તિના જીવન કે મૃત્યુનું મૂલ્યાંકન નથી.
- **QALY-આધારિત ચોખ્ખા નાણાકીય લાભ ગણતરી સામે બેવડી ગણતરી**: એક જ કેસમાં VSL/VPF આંકડો અને અલગ QALY × સીમા ગણતરી, સમાધાન કર્યા વગર વાપરવાથી એ જ ટાળેલા મૃત્યુનું મૂલ્ય શાંતિથી બે વાર ગણાય છે. આપેલા કેસ માટે એક માળખું પસંદ કરો.
- **સમાયોજન વગર સંદર્ભો વચ્ચે VSL અંદાજ ફેરવવો**: એક દેશના શ્રમ બજાર અથવા કાર્ય-વયના વેતન-જોખમ ડેટામાંથી મેળવેલું VSL, સમાયોજન વગર જુદા આવક સંદર્ભ કે જુદી વસ્તી (બાળકો, નિવૃત્તો) પર લાગુ કરવું લાંબા સમયથી ચાલતો, ખરેખર વિવાદિત પદ્ધતિગત મુદ્દો છે — ઉકેલાયેલો નહીં.
