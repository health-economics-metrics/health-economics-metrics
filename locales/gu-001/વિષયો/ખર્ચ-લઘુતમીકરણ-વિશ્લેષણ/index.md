# ખર્ચ-લઘુતમીકરણ વિશ્લેષણ (CMA)

CMA ફક્ત ખર્ચની સરખામણી કરે છે અને સૌથી સસ્તો વિકલ્પ પસંદ કરે છે — *ફક્ત* ત્યારે જ યોગ્ય છે જ્યારે વિકલ્પોના પરિણામો સમતુલ્ય હોવાનું દર્શાવાયું હોય.

## આ શા માટે મહત્ત્વનું છે

CMA સૌથી સરળ વિશ્લેષણ છે અને સૌથી વધુ દુરુપયોગ થતું પણ. સમતુલ્યતાનો દાવો બધું કામ કરે છે: જો પરિણામો ખરેખર અલગ ન હોય (બાયોસિમિલર વિરુદ્ધ તેના મૂળ; એ જ સ્પેક પૂરું કરતા એ જ સેવાના બે સપ્લાયર્સ), તો ખર્ચ જ એકમાત્ર પ્રશ્ન છે અને CMA સાચું છે. ચોકસાઈ સમતુલ્યતા પહેલાં *સાબિત* કરવામાં રહેલી છે — સામાન્ય રીતે પૂર્વ-નિર્દિષ્ટ માર્જિન સાથે નૉન-ઇન્ફીરિયોરિટી અભ્યાસ દ્વારા — જે પગલું ખરીદદારો સામાન્ય રીતે છોડી દે છે.

## ગણિત

```
Given evidence that Effect_A ≈ Effect_B (within a pre-specified margin δ):
Choose min(Cost_A, Cost_B)

Costs measured from the same perspective, over the same horizon,
including switching/transition costs.
```

જો સમતુલ્યતા સાબિત ન કરી શકાય, તો CMA અમાન્ય છે — તેના બદલે [CEA](../ખર્ચ-અસરકારકતા-વિશ્લેષણ/)/[CUA](../ખર્ચ-ઉપયોગિતા-વિશ્લેષણ/) વાપરો.

## ઉકેલેલું ઉદાહરણ

એક ટ્રસ્ટ બે વિડિયો-પરામર્શ પ્લૅટફૉર્મ વચ્ચે પસંદગી કરે છે. 3-મહિનાનો સમાંતર પાયલટ પૂર્ણતા દર 94.1% વિરુદ્ધ 93.8%, દર્દી સંતોષ 4.4 વિરુદ્ધ 4.4 દર્શાવે છે — તફાવતો 2 ટકા-બિંદુના પૂર્વ-સંમત δ ની અંદર. પરિણામો: સમતુલ્ય. 3 વર્ષ પરનો ખર્ચ:

```
                     Platform A     Platform B
Licences             £360,000       £210,000
Integration          £80,000        £150,000
Training/support     £60,000        £90,000
Total                £500,000       £450,000
```

પ્લૅટફૉર્મ B £50,000 થી જીતે છે — તેના ઊંચા સંકલન ખર્ચ *સહિત*. પાયલટ વિના, સમતુલ્યતાનો દાવો વેન્ડર બ્રોશર પર ટકેલો હોત, અને 1-બિંદુનો પૂર્ણતા-દર તફાવત (≈ વર્ષે હજારો નિષ્ફળ પરામર્શ) £50,000 ને વામણું બનાવી દેત.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

CMA કોમોડિટી પ્રાપ્તિનું ઔપચારિક સ્વરૂપ છે: સમાન SLO પૂરા કરતા બે CI પ્રદાતાઓ, સમાન ટકાઉપણું સ્પેક ધરાવતા બે ઑબ્જેક્ટ સ્ટોર્સ. આરોગ્ય-અર્થશાસ્ત્રનો પાઠ *કામગીરીનો ક્રમ* છે: પહેલાં સમતુલ્યતા સાબિત કરો (તમારા વર્કલોડ સામે બેન્ચમાર્ક, તમારા SLO સામે પાયલટ, માર્જિન અગાઉથી સંમત), પછી માઇગ્રેશન સહિતના કુલ ખર્ચની સરખામણી કરો. પ્રથમ પગલા વિના "તેઓ મૂળભૂત રીતે સમાન છે, B સસ્તું છે" એ રીતે સંસ્થાઓ 10% સસ્તું અને 40% ખરાબ સાધન ખરીદે છે. અનુસિદ્ધાંત: જ્યારે વેન્ડર ભાવ પર દલીલ કરે, ત્યારે તેમને સમતુલ્યતા સ્વીકારવા કહો — તે બીજી દિશામાં પણ બંધનકર્તા છે.

## સામાન્ય ભૂલો

- **માની લીધેલી સમતુલ્યતા** — વ્યાખ્યાયિત પાપ; તફાવતના પુરાવાનો અભાવ સમતુલ્યતાનો પુરાવો નથી (અલ્પ-શક્તિવાળા પાયલટ્સ મફતમાં સમતુલ્યતા "બતાવે" છે).
- **સ્વિચિંગ ખર્ચ છોડી દેવો** — માઇગ્રેશન, પુનઃતાલીમ અને સમાંતર ચાલવું ખર્ચ બાજુમાં આવે છે.
- **ખોટા પરિણામો પર સમતુલ્યતા**: માપેલા મેટ્રિક પર સમતુલ્ય, પણ મહત્ત્વના મેટ્રિક પર અલગ (સુલભતા, ટેઇલ લેટન્સી, ડેટા એગ્રેસ).
