# ટાળેલા ડાઉનસ્ટ્રીમ ખર્ચ

ટાળેલા ડાઉનસ્ટ્રીમ ખર્ચ (ખર્ચ ઑફસેટ) એ વહેલા અથવા વધુ સારા પગલાંથી અટકાવાયેલા ભવિષ્યના સારવાર ખર્ચ છે, જે હસ્તક્ષેપના પોતાના ખર્ચ સામે ચોખ્ખા કરાય છે. ઑફસેટ્સ એ પદ્ધતિ છે જેના દ્વારા હસ્તક્ષેપ *પ્રભાવી* (dominant) — સસ્તો **અને** વધુ સારો — બની શકે છે, અને તે આરોગ્ય અર્થશાસ્ત્રમાં સૌથી વધુ બેવડી ગણાતી, અતિ-દાવો કરાતી પંક્તિ પણ છે.

## આ શા માટે મહત્ત્વનું છે

લગભગ દરેક ડિજિટલ આરોગ્ય મૂલ્ય દરખાસ્તમાં ઑફસેટ દાવો હોય છે: "અમારી ઍપ દાખલ થવાનું અટકાવે છે," "અમારી ચેતવણીઓ બગાડ અટકાવે છે," "અમારું પ્લૅટફૉર્મ બેવડા ટેસ્ટ ટાળે છે." જ્યારે ઑફસેટ્સ વાસ્તવિક હોય, ત્યારે તે અર્થશાસ્ત્ર બદલી નાખે છે ([ICER](../વૃદ્ધિશીલ-ખર્ચ-અસરકારકતા-ગુણોત્તર/) નું ઉકેલેલું ઉદાહરણ જુઓ, જ્યાં £600k ઑફસેટ કેસ બનાવે છે). ચુકવણીકારો આ જાણે છે — તેથી ઑફસેટ દાવાઓ કોઈપણ મૂલ્યાંકનમાં સૌથી કઠોર ચકાસણી આકર્ષે છે. નીચેના વિશ્વસનીયતા નિયમો જ ભંડોળ-યોગ્ય મૉડેલને માર્કેટિંગથી અલગ પાડે છે.

## ગણિત

```
Net cost = intervention cost − Σ offsets

A valid offset must be:
  Attributable — causally linked to the intervention (comparator evidence)
  Marginal     — the money actually stops being spent, at marginal not
                 average cost (see marginal-vs-average-cost.md)
  Probability- — weighted by P(the downstream event would have occurred)
  weighted
  Discounted   — future avoided costs at present value
  Unique       — counted once, in one benefit line
```

## ઉકેલેલું ઉદાહરણ

"આ માઇગ્રેશન-જોખમ દાવો, સાચી રીતે કરેલો": 5,000 શસ્ત્રક્રિયા-પછીના દર્દીઓ માટેની ઘા-નિરીક્ષણ ઍપ ચેપ-સંબંધિત પુનઃદાખલ ટાળવાનો દાવો કરે છે.

```
Baseline readmission for infection: 4.0% ; with app (RCT): 3.1%
Attributable events avoided = 5,000 × 0.009 = 45/year
Cost per readmission spell (marginal, this trust): £3,200
Offset = 45 × 3,200 = £144,000/year
App cost = 5,000 × £20 = £100,000/year
Net cost = −£44,000 → genuinely cost-saving, with:
  attribution from an RCT ✓  marginal costing ✓  probability from trial data ✓
```

"પુનઃદાખલનો સરેરાશ ખર્ચ £5,800 છે, અમે ઘણા અટકાવીશું" પર બનેલો એ જ દાવો ચારેય કસોટીમાં નિષ્ફળ જાય છે અને તેને મળતો અસ્વીકાર લાયક છે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

"આ માઇગ્રેશન ભવિષ્યનું પુનઃલેખન ટાળે છે" એ ઑફસેટ દાવો છે, અને આરોગ્ય-અર્થશાસ્ત્રના નિયમો તેને પ્રામાણિક બનાવે છે:

- **પ્રતિતથ્યાત્મક ખર્ચ**: પુનઃલેખનનો ખરેખર કેટલો ખર્ચ થશે, કેવા પુરાવાથી?
- **સંભાવના**: તે ભવિષ્ય કેટલું સંભવિત છે? (100% નહીં — ઉત્પાદનો બંધ થાય છે, પ્રાથમિકતાઓ બદલાય છે.)
- **ડિસ્કાઉન્ટિંગ**: 3.5–10% ડિસ્કાઉન્ટ પર ચોથા વર્ષે ટાળેલા પુનઃલેખનનું મૂલ્ય મૂળ કિંમત કરતાં ઘણું ઓછું છે.
- **અનન્યતા**: ટેક-ડેટ પંક્તિ અને જાળવણી પંક્તિ બંનેમાં એ જ ટાળેલા પુનઃલેખનનો દાવો ન કરો.

`Offset value = P(future event) × counterfactual cost × discount factor` — દરખાસ્તમાં આ પંક્તિ લખો અને અંદાજ ચર્ચાસ્પદ બનતો જુઓ, જે જ હેતુ છે.

## સામાન્ય ભૂલો

- **બેવડી ગણતરી** — એ જ ટાળેલું દાખલ થવું ઑફસેટ, પથારી-દિવસો અને ખર્ચ-સંલગ્ન QALY તરીકે દાવો કરાય.
- **સરેરાશ-ખર્ચ ઑફસેટ્સ** એવી ઘટનાઓ માટે જેમના સ્થિર ખર્ચ ગમે તે રીતે ચાલુ રહે છે.
- **શાંત 100% સંભાવના** એવી ડાઉનસ્ટ્રીમ ઘટનાઓ પર જે ફક્ત સંભવ હતી.
- **અન્ય બજેટ્સ પરના ઑફસેટ્સ** જે ચૂકવવા કહેવાતા ચુકવણીકારને બચત તરીકે રજૂ થાય — જુઓ [વિશ્લેષણ દૃષ્ટિકોણ](../વિશ્લેષણ-દૃષ્ટિકોણ/).
