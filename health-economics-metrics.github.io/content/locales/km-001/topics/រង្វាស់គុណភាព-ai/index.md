# រង្វាស់គុណភាព AI

រង្វាស់នៃភាពត្រឹមត្រូវនៃលទ្ធផលដែលបង្កើតដោយ AI៖ ភាពត្រឹមត្រូវធៀបនឹងការពិតមូលដ្ឋាន **ភាពស្មោះត្រង់/ការផ្អែកលើមូលដ្ឋាន** (faithfulness/groundedness) (តើគ្រប់ការអះអាងត្រូវបានគាំទ្រដោយបរិបទដែលបានផ្តល់ឬទេ?) និង **អត្រាភាពស្រមើស្រមៃ** (hallucination rate) (តើលទ្ធផលប៉ុន្មានភាគរយមានមាតិកាគ្មានមូលដ្ឋាន ឬមិនពិត?)។ ក្នុងបរិបទសុខាភិបាល ទាំងនេះមិនមែនជាភាពល្អប្រសើរបន្ថែមទេ — ពួកវាគឺជាអត្រាគ្រោះថ្នាក់។

## ហេតុអ្វីបានជាសំខាន់

ស្តង់ដារផ្នែកវេជ្ជសាស្ត្របានវាស់អត្រាស្រមើស្រមៃ **លើសពី 60% សម្រាប់ LLM ដែលមិនមានមូលដ្ឋាន** លើកិច្ចការវេជ្ជសាស្ត្រ (ម៉ូដែលបើកចំហមួយចំនួន >80%) ខណៈដែលការផ្អែកមូលដ្ឋាន ការទាញយក និងរបៀបវែកញែក កាត់បន្ថយអត្រាយ៉ាងខ្លាំង (ឧទាហរណ៍ របៀបគិតរបស់ GPT-5 កាត់បន្ថយការស្រមើស្រមៃ HealthBench ពី 3.6% ទៅ 1.6% លើស្តង់ដារមួយ)។ កម្រិតថ្នាំស្រមើស្រមៃ ឬការដកស្រង់ប្រឌិតក្នុងលំហូរការងារគ្លីនិក គឺជា **ព្រឹត្តិការណ៍ព័ត៌មានមិនពិតដែលមានផ្លូវគ្រោះថ្នាក់** — វាជារបស់ដៃគ្រោះថ្នាក់នៃគំរូសេដ្ឋកិច្ចណាមួយ ដែលកំណត់តម្លៃដូចវិជ្ជមានមិនពិតនៃ[សេដ្ឋកិច្ចការត្រួតពិនិត្យ](../សេដ្ឋកិច្ចនៃការពិនិត្យ/)៖ រាល់មួយបង្កឱ្យមានថ្លៃដើមបន្ទាប់ (ធ្វើតាមព័ត៌មានខុស កម្លាំងពលកម្មផ្ទៀងផ្ទាត់ ហានិភ័យផ្លូវច្បាប់វេជ្ជសាស្ត្រ ទំនុកចិត្តថយចុះ)។

## គណិតវិទ្យា

```
Hallucination rate = outputs containing unsupported/false content / total outputs
  intrinsic:  contradicts the provided context
  extrinsic:  unverifiable fabrication beyond the context

Faithfulness (RAGAS-style) = supported claims in answer / total claims in answer
Context precision/recall   = retrieval quality feeding the generator

Economic weighting — not all hallucinations cost alike:
  expected harm cost = Σ over error types (rate × P(undetected) ×
                       P(acted upon) × cost per acted-upon error)
  The human-review layer sets P(undetected) — and its cost belongs
  in the model too (reviewer minutes × volume).
```

## ឧទាហរណ៍ដែលបានគណនា

ជំនួយ AI សម្រាប់កូដគ្លីនិកដំណើរការ 200,000 ករណី/ឆ្នាំ; សវនកម្មបង្ហាញថា 2% នៃលទ្ធផលមានកំហុសកូដសំខាន់ ហើយអ្នកដាក់កូដមនុស្សចាប់បាន 85% នៃកំហុសទាំងនោះ៖

```
Errors reaching submission = 200,000 × 0.02 × 0.15 = 600/year
Cost per uncaught error (mis-billing avg + audit exposure) ≈ £250
Expected error cost         = 600 × 250 = £150,000/year
Review cost (2 min × 200k × £0.50/min)  = £200,000/year

Improvement case: retrieval grounding cuts error rate to 0.8%
→ uncaught errors 240, error cost £60,000 (−£90k/yr); review time
  can also drop (sampling instead of full review) — the quality
  investment pays before any speed claim.
```

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ចាត់ទុកគុណភាពម៉ូដែលដូចសេដ្ឋកិច្ចគ្របដណ្តប់តេស្ត ជាមួយវិន័យកម្រិតសុខាភិបាល៖ **សំណុំវាយតម្លៃគឺជាការសាកល្បងគ្លីនិករបស់អ្នក** — ចុះឈ្មោះជាមុន តំណាងឱ្យការលាយករណីរបស់ *អ្នក* ធ្វើបច្ចុប្បន្នភាពទល់នឹងការរសាត់; **ការផ្អែកមូលដ្ឋានឈ្នះទំហំ** សម្រាប់កិច្ចការអត្ថន័យការពិត (ការទាញយក + ការជំរុញដែលតម្រូវឱ្យដកស្រង់ជាធម្មតាជាការកាត់បន្ថយការស្រមើស្រមៃថោកបំផុត — សូមប្រៀបធៀប[សេដ្ឋកិច្ចឯកតាអនុមាន](../សេដ្ឋកិច្ចឯកតានៃការអនុមាន/)សម្រាប់ថ្លៃតូខឹនបន្ថែម); ហើយ**បោះពុម្ពចំណុចប្រតិបត្តិការ**៖ ដូច[ភាពប្រកាន់អារម្មណ៍/ភាពជាក់លាក់](../ការវាយតម្លៃ-ai-គ្លីនិក/) "ស្មោះត្រង់ 97%" គ្មានន័យ ប្រសិនបើគ្មានការចែកចាយកិច្ចការ និងកម្រិតរកឃើញ។ គណិតវិទ្យាស្រទាប់ពិនិត្យខាងលើ គឺជាក្បួនគណនា [NNT/NNH](../ចំនួនដែលត្រូវព្យាបាល/) ដូចគ្នានឹងច្រកត្រួតពិនិត្យណាមួយ។

## កំហុសដែលត្រូវជៀសវាង

- **ការផ្សាំពីស្តង់ដារទៅផលិតកម្ម**៖ អត្រាស្រមើស្រមៃប្រែប្រួលខ្លាំងតាមកិច្ចការ; ការលាយករណីរបស់អ្នកគឺជាស្តង់ដារតែមួយគត់ដែលរាប់។
- **ការត្រួតពិនិត្យដោយមនុស្សដែលមិនគិតថ្លៃ**៖ "គ្លីនិកករត្រួតពិនិត្យអ្វីៗទាំងអស់" កាត់បន្ថយអត្ថប្រយោជន៍ពាក់កណ្តាល ហើយត្រូវតែលេចក្នុងបន្ទាត់ថ្លៃដើម — ហើយការប្រុងប្រយ័ត្នថយចុះ (ការស្កប់ស្កល់នឹងស្វ័យប្រវត្តិកម្ម) ដូច្នេះ P(មិនរកឃើញ) កើនឡើងតាមទំនុកចិត្ត។
- **ការបង្កើនប្រសិទ្ធភាពគុណភាពមធ្យម ខណៈដែលហានិភ័យកន្ទុយផ្ទុកគ្រោះថ្នាក់**៖ កំណត់ត្រាអាឡែរហ្សីប្រឌិតមួយ មានទម្ងន់លើសពីការបញ្ចេញសំដីអាក្រក់មួយពាន់; ថ្លឹងកំហុសតាមផលវិបាក តាមរូបមន្តគ្រោះថ្នាក់រំពឹងទុក។
