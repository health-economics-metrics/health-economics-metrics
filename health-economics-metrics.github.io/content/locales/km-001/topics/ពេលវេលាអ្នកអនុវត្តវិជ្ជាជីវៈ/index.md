# ពេលវេលាអ្នកអនុវត្តវិជ្ជាជីវៈ

ពេលវេលាអ្នកអនុវត្តវិជ្ជាជីវៈគឺជាធនធានដែលខ្វះខាតបំផុតក្នុងប្រព័ន្ធសុខាភិបាលភាគច្រើន។ ការវាស់តម្លៃនៃការសន្សំនាទីរបស់គ្លីនីសីយាំក្នុងមួយថ្ងៃ ទាមទារការផ្លាស់ប្តូរពីគណិតវិទ្យាប្រាក់ឈ្នួលសាមញ្ញ ទៅ **ថ្លៃដើមឱកាស និងសមត្ថភាពប្រព័ន្ធ**៖ ក្នុងសេវាសុខភាពជាតិ ពេលវេលារបស់អ្នកអនុវត្តគឺជាចំណុចស្ទះប្រតិបត្តិការរឹង មិនមែនជាបន្ទាត់ថ្លៃដើមដែលបត់បែនបានទេ។

## ហេតុអ្វីបានជាសំខាន់

អ្នកមិនអាចបង្កើតគ្រូពេទ្យទូទៅ អ្នកប្រឹក្សា ឬគិលានុបដ្ឋាយិកាឯកទេសបន្ថែមបានលឿនទេ — បំពង់បណ្តុះបណ្តាលចំណាយពេល 5–15 ឆ្នាំ ហើយមុខតំណែងទំនេរជាបញ្ហារ៉ាំរ៉ៃ។ ដូច្នេះមួយម៉ោងនៃពេលវេលាអ្នកអនុវត្តដែលបានសន្សំ មិនមែន "ប្រាក់ឈ្នួលដែលបានជៀសវាង" ទេ (អ្នកអនុវត្តនៅតែទទួលប្រាក់ឈ្នួល); វាគឺជា *សមត្ថភាពចំណុចស្ទះដែលបានដោះលែង* ហើយសមត្ថភាពចំណុចស្ទះមានតម្លៃស្មើនឹងអ្វីដែលចំណុចស្ទះផលិត។ នេះជាមូលហេតុដែលការអះអាង "សន្សំ 10 នាទីក្នុងមួយការពិគ្រោះ" គឺជាបន្ទាត់ទូទៅបំផុត និងកំណត់តម្លៃខុសបំផុតក្នុងសុខភាពឌីជីថលក្នុងពេលតែមួយ។

## គណិតវិទ្យា

កម្រិតកំណត់តម្លៃបី ពីស្មោះត្រង់តិចទៅស្មោះត្រង់ច្រើន៖

```
1. Wage basis:        hours × loaded salary rate (PSSRU unit costs)
                      — what the time costs, not what it produces
2. Output basis:      hours → appointments/procedures enabled × scheme value
                      (see national-tariff-and-unit-costs.md)
3. Bottleneck basis:  if this role gates a whole pathway, hours × value of
                      pathway throughput released (theory of constraints)
```

ការបញ្ចុះតម្លៃការបែងចែក៖ ពេលវេលាដែលសន្សំជាបំណែកតូចៗក្រោមបរិមាណប្រើបាន (ឧទាហរណ៍ 3 នាទីខ្ចាត់ខ្ចាយក្នុងគ្លីនិក) ត្រូវបានប្រើឡើងវិញមិនល្អ; អនុវត្តកត្តាប្រើប្រាស់ដែលបានបញ្ជាក់។

## ឧទាហរណ៍ដែលបានគណនា

ការកត់ត្រាជុំវិញខ្លួនសន្សំពេលវេលាគ្រូពេទ្យទូទៅ 2 នាទីក្នុងមួយការពិគ្រោះ 30 ការពិគ្រោះ/ថ្ងៃ៖ 60 នាទី/ថ្ងៃ ឬ **220 ម៉ោង/ឆ្នាំក្នុងមួយគ្រូពេទ្យទូទៅ** ក្នុង 220 ថ្ងៃធ្វើការ។

```
Wage basis:   220 × £80 (loaded GP hour, PSSRU-region) ≈ £17,600/GP/year
Output basis: 60 min/day = 5 extra 12-min consultations/day
              = 1,100 extra appointments/GP/year × £42 ≈ £46,200/GP/year
              — or the same appointments absorbed as reduced overtime and
              safer, unhurried consultations (qualitative line)
```

ឆ្លងកាត់សហព័ន្ធគ្រូពេទ្យទូទៅ 50 នាក់ សមត្ថភាពតាមមូលដ្ឋានលទ្ធផលមានតម្លៃ ~£2.3M/ឆ្នាំ — លុះត្រាតែនាទីទាំងនោះជាការពិត (បានវាស់ មិនមែនអ្នកលក់អះអាងទេ) បានបូកបញ្ចូលគ្នា (ការពិគ្រោះទាំងមូល មិនមែនបំណែកទេ) និងបានប្រើឡើងវិញ (សូមមើល[ការសន្សំដែលបញ្ចេញសាច់ប្រាក់ ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់](../ការសន្សំដែលបញ្ចេញសាច់ប្រាក់-ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់/))។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ពេលវេលាវិស្វករជាន់ខ្ពស់ប្រព្រឹត្តដូចគ្នា៖ វាគឺជាចំណុចស្ទះដែលការរចនា ការពិនិត្យ និងឧប្បត្តិហេតុហូរកាត់ ដូច្នេះកំណត់តម្លៃវាតាមអ្វីដែលចំណុចស្ទះគ្រប់គ្រង មិនមែនតាមប្រាក់ខែទេ។ ការកំណត់តម្លៃបីកម្រិតដដែលអនុវត្តចំពោះការអះអាង "AI សន្សំអ្នកអភិវឌ្ឍន៍ម្នាក់ៗ X នាទី" — គណិតវិទ្យាប្រាក់ឈ្នួលបញ្ជាក់លេខតូចៗ; សំណួរស្មោះត្រង់គឺថាតើនាទីបូកបញ្ចូលគ្នាជាប្លុកដែលអាចប្រើបានឬទេ និងអ្វីដែលសមត្ថភាពដែលបានដោះលែងផលិតពិតប្រាកដ។ សូមមើល[ការបង្កើនប្រសិទ្ធភាពធនធានផ្នែកខាងក្រោម](../ការបង្កើនប្រសិទ្ធភាពធនធានផ្នែកខាងក្រោម/) សម្រាប់មេគុណនៅពេលដែលម៉ោងដែលសន្សំជារបស់អ្នកដែលអ្នកគ្រប់គ្នារង់ចាំ។

## ចំណុចងាយធ្លាក់

- **នាទី × ប្រាក់ខែ = ការសន្សំ** — ការបំផ្លើសបុរាណ; វាគឺជាសមត្ថភាព ហើយត្រឹមតែនៅកម្រិតប្រើប្រាស់ដែលបានបញ្ជាក់ប៉ុណ្ណោះ។
- **ការមិនអើពើបញ្ហាបរិមាណ**៖ ការសន្សំ 5 នាទី 12 ដង ≠ មួយម៉ោងទំនេរ។
- **ការកំណត់តម្លៃតួនាទីទាំងអស់ដូចគ្នា**៖ មួយម៉ោងនៃចំណុចស្ទះផ្លូវព្យាបាលមានតម្លៃច្រើនដងជាងមួយម៉ោងនៃតួនាទីដែលមិនគ្រប់គ្រង។
