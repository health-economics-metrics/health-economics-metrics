# ថ្ងៃគ្រែដែលបានសន្សំ

ថ្ងៃគ្រែ (bed day) គឺអ្នកជំងឺម្នាក់កាន់កាប់គ្រែមន្ទីរពេទ្យមួយក្នុងមួយថ្ងៃ។ "ថ្ងៃគ្រែដែលបានសន្សំ" — តាមរយៈការចេញពីមន្ទីរពេទ្យលឿន ការជៀសវាងការចូលសម្រាក ឬវួដនិម្មិត — គឺជាអត្ថប្រយោជន៍សំខាន់បំផុតនៃករណីអាជីវកម្មឌីជីថលរបស់ NHS ហើយជាអត្ថប្រយោជន៍ដែលត្រូវបានវាយតម្លៃហួសហេតុជាទូទៅបំផុត។

## ហេតុអ្វីបានជាសំខាន់

គ្រែគឺជាឧបសគ្គកំណត់នៃការថែទាំស្រួចស្រាវ៖ នៅពេលគ្រែពេញ ការវះកាត់តាមគម្រោងត្រូវបានលុបចោល រថយន្តសង្គ្រោះតម្រង់ជួរ ហើយផ្នែកសង្គ្រោះបន្ទាន់កកស្ទះ។ ដូច្នេះអន្តរាគមន៍ដែលដោះលែងថ្ងៃគ្រែមានតម្លៃពិតប្រាកដ — ប៉ុន្តែ *ប្រភេទ* នៃតម្លៃអាស្រ័យទាំងស្រុងលើអ្វីដែលកើតឡើងចំពោះគ្រែដែលបានដោះលែង។ នាយកហិរញ្ញវត្ថុបានរៀនបញ្ចុះការអះអាងថ្ងៃគ្រែងាយៗយ៉ាងខ្លាំង; ការគណនាឱ្យត្រឹមត្រូវគឺជាការសាកល្បងភាពជឿជាក់។

## គណិតវិទ្យា

```
Bed days saved = patients affected × Δ length of stay (or admissions avoided × avg LOS)

Value depends on the use of the freed capacity:
  refilled with elective activity → value = activity income or waiting-list benefit
  ward closed / flexed down      → value = staffing + running cost released (cash)
  absorbed as slack              → value ≈ marginal (hotel) cost only, £50–£150/day
```

ថ្លៃដើមមធ្យមដែលស្រូបយកពេញលេញនៃថ្ងៃគ្រែស្រួចស្រាវ ជារឿយៗត្រូវបានដកស្រង់ជា £400+ (National Cost Collection ជាប្រវត្តិសាស្ត្រ ~£350 សម្រាប់ថ្ងៃគ្រែលើស) — ប៉ុន្តែសូមមើល[ថ្លៃដើមរឹតបន្តឹង ធៀបនឹងថ្លៃដើមមធ្យម](../ថ្លៃដើមបន្ថែម-ធៀបនឹង-ថ្លៃដើមមធ្យម/)៖ មធ្យមស្ទើរតែមិនដែលជាការសន្សំទេ។

## ឧទាហរណ៍ដែលបានគណនា

"វួដនិម្មិត" ត្រួតពិនិត្យពីចម្ងាយអនុញ្ញាតឱ្យអ្នកជំងឺ 600 នាក់/ឆ្នាំទៅផ្ទះមុន 2 ថ្ងៃ៖ សន្សំបាន 1,200 ថ្ងៃគ្រែ។

- **ការអះអាងងាយៗ**៖ 1,200 × £400 = £480,000។ ខុស លើកលែងតែវួដបិទ។
- **ការអះអាងស្មោះត្រង់**៖ ទុនបំពេញគ្រែដោយអ្នកជំងឺឆ្អឹងតាមគម្រោង។ 1,200 ថ្ងៃគ្រែ ÷ ការស្នាក់នៅមធ្យម 3 ថ្ងៃ = 400 វគ្គតាមគម្រោងបន្ថែម ក្នុងប្រហែល £6,000 ចំណូលក្នុងមួយវគ្គ ក្រោមការបង់ប្រាក់តាមសកម្មភាព = **£2.4M នៃសកម្មភាពដែលមានមូលនិធិបន្ថែម** (ដកថ្លៃដើមរឹតបន្តឹងនៃការព្យាបាលអ្នកជំងឺទាំងនោះ) *បូករួម* អ្នកជំងឺ 400 នាក់ចេញពីបញ្ជីរង់ចាំ។ ថ្លៃដំណើរការវួដនិម្មិត (£350,000) ដកពីនេះ។

សមត្ថភាពដែលបានដោះលែង ដែល *ប្រើឡើងវិញ* ជារឿយៗមានតម្លៃច្រើនជាងការអះអាងសាច់ប្រាក់ងាយៗ — ប៉ុន្តែវាជាប្រភេទតម្លៃផ្សេង ហើយត្រូវតែដាក់ស្លាកដូច្នេះ ([ការសន្សំបញ្ចេញសាច់ប្រាក់ ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់](../ការសន្សំដែលបញ្ចេញសាច់ប្រាក់-ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់/))។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

"ថ្ងៃម៉ាស៊ីនមេដែលបានសន្សំ" មានឥរិយាបថដូចគ្នា។ ការបិទបរិស្ថានបើកជានិច្ចបញ្ចេញសាច់ប្រាក់តែនៅពេលឧទាហរណ៍ត្រូវបានបញ្ចប់ ឬការកក់ផុតកំណត់; សមត្ថភាពដែលស្រូបត្រឡប់ទៅក្នុងអាងមានតម្លៃស្មើនឹងថ្លៃដើមរឹតបន្តឹងរបស់វា (~0 លើការចំណាយដែលបានសន្យា)។ វិន័យស្របគ្នា៖ សម្រាប់រាល់ការអះអាងការសន្សំ ចូរដាក់ឈ្មោះ *យន្តការ* — បានបញ្ចប់ បំពេញឡើងវិញដោយការងារមានតម្លៃ ឬបាត់បង់។ កម្មវិធីដែលកាត់បន្ថយរយៈពេលស្នាក់នៅមន្ទីរពេទ្យ (ការសម្របសម្រួលការចេញ ការត្រួតពិនិត្យពីចម្ងាយ ពេលវេលាឆ្លើយតបរោគវិនិច្ឆ័យ) គួរធ្វើគំរូទាំងបីសេណារីយ៉ូ ហើយឱ្យទុនជ្រើសក្នុងមួយវួដ។

## កំហុសដែលត្រូវជៀសវាង

- **ការវាយតម្លៃតាមថ្លៃដើមមធ្យម** នៃសមត្ថភាពរឹតបន្តឹង — កំហុសបុរាណ។
- **ការរាប់ស្ទួន**៖ ថ្ងៃគ្រែសន្សំ *និង* ការចូលសម្រាកជៀសវាង *និង* ការកាត់បន្ថយបញ្ជីរង់ចាំពីគ្រែដែលបានដោះលែងដូចគ្នា។
- **ការសន្មតថាថ្ងៃដែលសន្សំជាថ្ងៃថ្លៃ**៖ ថ្ងៃដែលសន្សំនៅចុងបញ្ចប់នៃការស្នាក់នៅគឺជាថ្ងៃថោកបំផុត (ភាពធ្ងន់ធ្ងរទាប)។
