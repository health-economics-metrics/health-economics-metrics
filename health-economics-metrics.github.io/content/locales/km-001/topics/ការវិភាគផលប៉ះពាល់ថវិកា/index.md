# ការវិភាគផលប៉ះពាល់ថវិកា (BIA)

BIA ប៉ាន់ស្មានអ្វីដែលការទទួលយកអន្តរាគមន៍មួយធ្វើចំពោះ **ថវិកា** របស់អ្នកបង់ប្រាក់ជាក់លាក់មួយក្នុងរយៈពេល 1–5 ឆ្នាំខាងមុខ។ វាឆ្លើយ *សមត្ថភាពទិញបាន*; ប្រសិទ្ធភាពថ្លៃដើមឆ្លើយ *តម្លៃ*។ បច្ចេកវិទ្យាអាចមានតម្លៃល្អឥតខ្ចោះ ប៉ុន្តែមិនអាចទិញបាន — ឬអាចទិញបាន ប៉ុន្តែតម្លៃអន់។ ការវាយតម្លៃធ្ងន់ធ្ងរតម្រូវឱ្យមានទាំងពីរ។

## ហេតុអ្វីបានជាសំខាន់

សំណួររបស់នាយកហិរញ្ញវត្ថុមិនដែលជា "ICER ជាអ្វី?" ទេ — វាគឺ "តើនេះធ្វើអ្វីចំពោះថវិកាឆ្នាំក្រោយ?" ការណែនាំការអនុវត្តល្អរបស់ ISPOR (ស្តង់ដារវិស័យ) បញ្ជាក់៖ ទស្សនៈផ្ទាល់ខ្លួនរបស់អ្នកបង់ប្រាក់ ជើងមេឃ 1–5 ឆ្នាំ លំហូរសាច់ប្រាក់ប្រចាំឆ្នាំ *មិនបញ្ចុះតម្លៃ* ខ្សែកោងទទួលយកប្រកបដោយភាពប្រាកដនិយម និងភាពមិនប្រាកដប្រជាតាមសេណារីយ៉ូ (មិនមែនប្រូបាប៊ីលីស្ទិក)។ NICE តម្រូវឱ្យមានព័ត៌មានផលប៉ះពាល់ថវិកាជាមួយប្រសិទ្ធភាពថ្លៃដើម; ផលិតផលដែលមានផលប៉ះពាល់ថវិកាថ្នាក់ជាតិលើស ~£20M/ឆ្នាំក្នុងប្រទេសអង់គ្លេស បង្កការចរចាពាណិជ្ជកម្មដោយមិនគិតពី ICER របស់វា។

## គណិតវិទ្យា

```
BI_year_t = Cost_scenario_with_new(t) − Cost_scenario_current(t)

Cost_scenario(t) = Σ over patient groups:
   eligible population(t) × uptake(t) × net cost per patient(t)

net cost per patient = intervention cost − displaced care cost + induced care cost
```

ជម្រើសគំរូសំខាន់ៗ៖ កំណើនប្រជាជនមានសិទ្ធិ ខ្សែកោងទទួលយក (ការទទួលយកមិនដែលភ្លាមៗ) អ្វីដែលជម្រើសថ្មីជំនួស និងតម្រូវការណាដែលវា *បង្កើត* (ការចូលប្រើកាន់តែងាយ → អ្នកប្រើច្រើនជាង)។

## ឧទាហរណ៍ដែលបានគណនា

អ្នកបង់ប្រាក់គ្របដណ្តប់មនុស្ស 2M នាក់ ពិចារណាការព្យាបាលឌីជីថលក្នុងតម្លៃ £300/អ្នកជំងឺ/ឆ្នាំ; សមាជិក 1.5% មានសិទ្ធិ (30,000); ការទទួលយក 20% → 40% → 60% ក្នុងរយៈពេល 3 ឆ្នាំ; អ្នកប្រើម្នាក់ៗជំនួសការថែទាំផ្សេង £120/ឆ្នាំ។

```
Net cost per user = 300 − 120 = £180

Year 1: 30,000 × 0.20 × 180 = £1.08M
Year 2: 30,000 × 0.40 × 180 = £2.16M
Year 3: 30,000 × 0.60 × 180 = £3.24M
```

ទោះបីជា ICER របស់ផលិតផលអស្ចារ្យ £8,000/QALY ក៏ដោយ អ្នកបង់ប្រាក់ត្រូវតែរក *ប្រាក់ថ្មី* £3.24M ត្រឹមឆ្នាំទី 3 — £120 ដែលជំនួសរាលដាលស្តើងលើបន្ទាត់ថវិកាផ្សេងទៀត ហើយនឹងមិនត្រូវបានបញ្ចេញជាសាច់ប្រាក់ទេ (សូមមើល[បញ្ចេញសាច់ប្រាក់ ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់](../ការសន្សំដែលបញ្ចេញសាច់ប្រាក់-ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់/))។ នេះជាមូលហេតុដែលតម្លៃក្នុងមួយឯកតា និងសមត្ថភាពទិញបាន គឺជាឧបសគ្គដាច់ដោយឡែក។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

BIA គឺជាបំពេញបន្ថែមប្រឈមមុខនឹង CFO ចំពោះការអះអាង ROI ក្នុងមួយកៅអី៖ "វាមានប្រសិទ្ធភាពថ្លៃដើមក្នុងមួយអ្នកអភិវឌ្ឍន៍ ប៉ុន្តែតើយើងអាចទិញការដាក់ឱ្យប្រើទូទាំងអង្គការក្នុងឆ្នាំសារពើពន្ធនេះទេ?" ធ្វើគំរូកម្រិតអាជ្ញាប័ណ្ណ ខ្សែកោង S នៃការទទួលយក ថ្លៃឧបករណ៍ដែលជំនួសដែលបញ្ចេញសាច់ប្រាក់តែនៅពេលកិច្ចសន្យាចាស់ត្រូវបានបញ្ចប់ និងការប្រើប្រាស់បង្កើត (CI ថោកជាង → CI ច្រើនជាង)។ ការបង្ហាញតារាងផលប៉ះពាល់ថវិកា 3 ឆ្នាំរួមជាមួយ ROI គឺជាអ្វីដែលធ្វើឱ្យសំណើឧបករណ៍សហគ្រាសមានភាពជឿជាក់ផ្នែកហិរញ្ញវត្ថុ។ ការបំបែកផលបូកផលប៉ះពាល់ថវិកាដែលបានបោះពុម្ពទៅតាមទីតាំង ក្រុម ឬឆ្នាំសារពើពន្ធ — ហើយឱ្យផ្នែកទាំងនោះស៊ីគ្នាយ៉ាងត្រឹមត្រូវទៅនឹងតួលេខដែលបានបោះពុម្ព — គឺពិតជា[ការបែងចែកថ្លៃដើមត្រឹមសេនពិតប្រាកដ](../ការបែងចែកថ្លៃដើមត្រឹមសេនពិតប្រាកដ/); ការបូកបន្ទាត់ធាតុជាច្រើនដែលចូលក្នុងផលបូកតាំងពីដំបូងគឺជា[ការបូកសរុបថ្លៃដើមសុវត្ថិភាពរូបិយប័ណ្ណ](../ការបូកសរុបថ្លៃដើមសុវត្ថិភាពរូបិយប័ណ្ណ/)។

## កំហុសដែលត្រូវជៀសវាង

- **ក្តីសុបិន្តទទួលយកភ្លាមៗ**៖ ផលប៉ះពាល់ឆ្នាំទី 1 គណនានៅការទទួលយកស្ថិរភាព។
- **រាប់ថ្លៃដើមជំនួសជាសាច់ប្រាក់** នៅពេលវាជាសមត្ថភាពរាយប៉ាយ។
- **មិនយកចិត្តទុកដាក់ចំពោះតម្រូវការបង្កើត** — ការកែលម្អការចូលប្រើបង្កើនការប្រើប្រាស់របស់ប្រជាជនមានសិទ្ធិ។
- **ការច្រឡំជើងមេឃ/ការបញ្ចុះតម្លៃរវាង BIA និង CEA**៖ BIA មានជើងមេឃខ្លី មិនបញ្ចុះតម្លៃ ជាក់លាក់ចំពោះអ្នកបង់ប្រាក់ តាមការរចនា។
