# ចំនួនដែលត្រូវព្យាបាល (NNT)

NNT គឺជាចំនួនអ្នកជំងឺដែលត្រូវទទួលអន្តរាគមន៍ ដើម្បីឱ្យអ្នកជំងឺបន្ថែម **មួយនាក់** ទទួលបានអត្ថប្រយោជន៍ ក្នុងរយៈពេលដែលបានកំណត់។ វាបម្លែងភាគរយនៃការកាត់បន្ថយហានិភ័យ — ដែលធ្វើឱ្យយល់ច្រឡំ — ទៅជាឯកតាការខំប្រឹងក្នុងមួយអត្ថប្រយោជន៍ ដែលអ្នកណាក៏អាចវែកញែកបាន។

## ហេតុអ្វីបានជាសំខាន់

"កាត់បន្ថយជំងឺឆ្កួតជ្រូក 25%!" ស្តាប់ទៅដូចជាច្បាស់លាស់។ ប្រសិនបើហានិភ័យមូលដ្ឋានគឺ 4% ក្នុងរយៈពេល 5 ឆ្នាំ ការកាត់បន្ថយដាច់ខាតគឺ 1 ពិន្ទុភាគរយ ដូច្នេះ **មនុស្ស 100 នាក់ត្រូវប្រើថ្នាំ 5 ឆ្នាំ ដើម្បីឱ្យ 1 នាក់ទទួលបានអត្ថប្រយោជន៍** — ហើយទាំង 100 នាក់ទទួលរងថ្លៃដើម និងផលរំខាន។ NNT គឺជាថ្នាំប្រឆាំងនឹងការផ្សព្វផ្សាយហានិភ័យទាក់ទង ដែលជាមូលហេតុដែលវេជ្ជសាស្ត្រផ្អែកលើភស្តុតាងចាប់ផ្តើមជាមួយវា។ ស្តាទីនសម្រាប់ការបង្ការបឋម៖ NNT ≈ 50–100 ក្នុងរយៈពេល 5 ឆ្នាំ ក្នុងមួយការគ្រោះថ្នាក់បេះដូងដែលបានជៀសវាង។ កញ្ចក់ឆ្លុះរបស់វា **NNH** (ចំនួនដែលត្រូវបង្កគ្រោះថ្នាក់) រាប់ថាមានអ្នកទទួលការព្យាបាលប៉ុន្មាននាក់ក្នុងមួយអ្នកទទួលរងគ្រោះថ្នាក់។

## គណិតវិទ្យា

```
ARR = control event rate − treatment event rate   (absolute risk reduction)
NNT = 1 / ARR

NNH = 1 / (harm rate_treatment − harm rate_control)

Economic bridge:
cost per event prevented = NNT × cost per treatment course
```

ត្រូវបញ្ជាក់រយៈពេល និងប្រជាជនមូលដ្ឋានជានិច្ច — NNT គ្មានន័យទេបើគ្មានទាំងពីរ។

## ឧទាហរណ៍ដែលបានគណនា

ប្រព័ន្ធព្យាករណ៍ការដួលក្នុងមន្ទីរពេទ្យសម្គាល់អ្នកជំងឺហានិភ័យខ្ពស់ សម្រាប់អន្តរាគមន៍ (ឧបករណ៍ចាប់សញ្ញាគ្រែ ការពិនិត្យ ការត្រួតពិនិត្យ)។ ការសាកល្បង៖ ការដួលដែលមានរបួសថយចុះពី 3.2% ទៅ 2.4% នៃការចូលសម្រាក។

```
ARR = 0.8 percentage points → NNT = 1/0.008 = 125
   (125 patients must get the intervention bundle to prevent 1 injurious fall)

Intervention cost ≈ £40/patient → cost per fall prevented = 125 × 40 = £5,000
Cost of an injurious inpatient fall (extra stay, imaging, litigation) ≈ £12,000
Net: prevention pays ~2.4:1 — and the QALY gain is on top.
```

សូមកត់សម្គាល់ថា NNT រក្សាការអះអាងឱ្យស្មោះត្រង់យ៉ាងណា៖ "កាត់បន្ថយការដួល 25%" និង "ការពារការដួលមួយក្នុងអ្នកជំងឺ 125 នាក់ដែលបានព្យាបាល" គឺជាលទ្ធផលតែមួយ ប៉ុន្តែមានសមត្ថភាពបញ្ចុះបញ្ចូលខុសគ្នា។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

NNT គឺជាឯកតាត្រឹមត្រូវសម្រាប់ច្រក ឬការត្រួតពិនិត្យណាមួយដែលធ្វើសកម្មភាពលើធាតុជាច្រើន ដើម្បីចាប់បានតិចតួច៖ **"ចំនួន PR ដែលត្រូវឆ្លងកាត់ច្រកពិនិត្យ AI ដើម្បីចាប់បានបញ្ហាមួយដែលកំពុងឆ្ពោះទៅផលិតកម្ម។"** ប្រសិនបើច្រកពិនិត្យ PR 400 ក្នុងមួយការចាប់បានពិត (NNT = 400) ដោយប្រើការយកចិត្តទុកដាក់របស់អ្នកអភិវឌ្ឍន៍ 4 នាទីក្នុងមួយ PR នោះការចាប់បានមួយមានថ្លៃដើមប្រហែល 27 ម៉ោងអ្នកអភិវឌ្ឍន៍ — ឥឡូវប្រៀបធៀបនឹងថ្លៃដើមឧប្បត្តិហេតុដែលវាការពារ។ NNH ត្រូវនឹងវិជ្ជមានមិនពិត៖ តើ PR ប៉ុន្មានក្នុងមួយការសម្គាល់ *មិនពិត* ហើយការសម្គាល់នីមួយៗមានថ្លៃដើមអ្វីខ្លះក្នុងការយកចិត្តទុកដាក់ និងទំនុកចិត្ត? ឧបករណ៍ប្រភេទពិនិត្យ (linters កម្មវិធីស្កេនសុវត្ថិភាព ការរកឃើញភាពមិនប្រក្រតី) គួរមកជាមួយនឹងការគណនា NNT/NNH — សូមមើល[សេដ្ឋកិច្ចនៃការពិនិត្យ](../សេដ្ឋកិច្ចនៃការពិនិត្យ/) ដើម្បីដឹងថាហេតុអ្វីប្រេវ៉ាឡង់ទាបធ្វើឱ្យលេខទាំងនេះអាក្រក់។ [ចំនួនដែលត្រូវពិនិត្យ](../ចំនួនដែលត្រូវពិនិត្យ/) គឺជាតួលេខស្រដៀងគ្នាមួយកម្រិតខាងលើ សម្រាប់កម្មវិធីពិនិត្យរួចព្យាបាលទាំងមូល ជាជាងការព្យាបាលតែឯង។

## ចំណុចងាយធ្លាក់

- **គ្មានរយៈពេល**៖ "NNT = 50" គ្មានន័យអ្វី; "NNT = 50 ក្នុងរយៈពេល 5 ឆ្នាំ" ទើបជាការអះអាង។
- **ការផ្ទេរហានិភ័យមូលដ្ឋាន**៖ NNT ដែលគណនាក្នុងប្រជាជនសាកល្បងហានិភ័យខ្ពស់ ធ្លាក់ចុះនៅពេលអនុវត្តក្នុងប្រជាជនហានិភ័យទាប។
- **ការមិនអើពើ NNH** — ច្រកដែលមាន NNT 400 និង NNH 3 គឺជាម៉ាស៊ីនបង្កការរំខាន មិនមែនប្រព័ន្ធសុវត្ថិភាពទេ។
