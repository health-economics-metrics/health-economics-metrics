# WSJF និង CD3

CD3 (ថ្លៃដើមនៃការពន្យារចែកនឹងរយៈពេល) និង WSJF (ការងារខ្លីបំផុតដែលថ្លឹងទម្ងន់មុន) គឺជាច្បាប់ផ្តល់អាទិភាពដែលកំណត់ពេលការងារតាម **ដង់ស៊ីតេតម្លៃ**៖ ថ្លៃដើមនៃការពន្យារប៉ុន្មានត្រូវបានលុបក្នុងមួយឯកតានៃសមត្ថភាពខ្វះខាតដែលបានប្រើ។ ក្រោមសមត្ថភាពរួម និងថេរ CD3 ខ្ពស់បំផុតមុនគឺជាលំដាប់ល្អបំផុតតាមគណិតវិទ្យាសម្រាប់កាត់បន្ថយថ្លៃដើមពន្យារសរុប។

## ហេតុអ្វីបានជាសំខាន់

រាល់បញ្ជីការងារជាប់គាំងគឺជាបញ្ហាបែងចែក៖ ធាតុសមនឹងទទួលបានជាច្រើន បំពង់តែមួយ។ សេដ្ឋកិច្ចសុខភាពបានដោះស្រាយបញ្ហាដូចគ្នាសម្រាប់ថវិកាសុខភាពដោយតារាងចំណាត់ថ្នាក់ប្រសិទ្ធភាពថ្លៃដើម — ចាត់ថ្នាក់អន្តរាគមន៍តាមសុខភាពដែលទទួលបានក្នុងមួយផោន ផ្តល់មូលនិធិចុះក្រោមបញ្ជីរហូតដល់ថវិកាអស់។ CD3 គឺជាតក្កវិជ្ជាដូចគ្នាសម្រាប់សមត្ថភាពបញ្ជូន៖ អត្ថប្រយោជន៍ក្នុងមួយឯកតានៃ *ធនធានដែលមានដែនកំណត់* ផ្តល់មូលនិធិតាមលំដាប់ចំណាត់ថ្នាក់។ ការរៀបលំដាប់ត្រឹមត្រូវគឺជាប្រាក់ឥតគិតថ្លៃ — ការងារដដែល សមត្ថភាពដដែល ថ្លៃដើមពន្យារសរុបតិចជាង។

## គណិតវិទ្យា

```
CD3  = Cost of Delay (£/week) / Duration (weeks)      — real units (Black Swan Farming)

WSJF = (user-business value + time criticality + risk reduction/opportunity
        enablement) / job size                         — SAFe's relative-scale proxy,
                                                        modified-Fibonacci scores
```

CD3 ជាមួយរូបិយប័ណ្ណពិត ([ថ្លៃដើមនៃការពន្យារ](../ថ្លៃដើមនៃការពន្យារ/)) ខ្លាំងជាងពិន្ទុគ្មានឯកតារបស់ WSJF យ៉ាងតឹងរឹង — WSJF ចំពោះ CD3 ដូចការដាក់ពិន្ទុច្រើនលក្ខណៈវិនិច្ឆ័យចំពោះ[ការវិភាគថ្លៃដើម-ឧបយោគ](../ការវិភាគថ្លៃដើម-ឧបយោគ/) ពេញលេញ៖ អាចប្រើបានពេលការធ្វើជាប្រាក់មិនអាចធ្វើទៅរួច អាចបន្លំបានពេលពិន្ទុគ្មានយុថ្កា។

## ឧទាហរណ៍ដែលបានគណនា

លក្ខណៈពិសេសបី ក្រុមមួយ៖

```
Feature   CoD (£/wk)   Duration   CD3
A         30,000       10 wks     3,000
B         12,000       2 wks      6,000
C         5,000        1 wk       5,000
```

លំដាប់ CD3៖ B, C, A។ ប្រៀបធៀបថ្លៃដើមពន្យារសរុបជាមួយ "CoD ធំបំផុតមុន" (A, B, C)៖

```
CD3 order  (B,C,A): A waits 3 wks, C waits 2 → 30k×3 + 5k×2  = £100k delay cost
CoD order  (A,B,C): B waits 10, C waits 12   → 12k×10 + 5k×12 = £180k
```

លក្ខណៈពិសេសដដែល ក្រុមដដែល — ការរៀបលំដាប់តែឯងសន្សំ £80,000។ វិចារណញាណ៖ ធាតុតូច និងបន្ទាន់ទៅមុនពីព្រោះវាបញ្ចេញថ្លៃដើមពន្យារយ៉ាងថោក; ធាតុធំបាត់បង់តិចពីការរង់ចាំខ្លី។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

សម្រាប់ផលប័ត្រកម្មវិធីសុខាភិបាល កំណត់ CoD ក្នុងឯកតាដែលឃ្លាំងនេះបង្រៀន៖ QALY/សប្តាហ៍ × កម្រិតកំណត់ + £/សប្តាហ៍ប្រតិបត្តិការ ហើយបញ្ជីការងារជាប់គាំងក្លាយជាអាចប្រៀបធៀបដោយផ្ទាល់ជាមួយរបៀបដែលប្រព័ន្ធសុខាភិបាលចាត់ថ្នាក់អ្វីៗផ្សេងទៀតដែលវាទិញ។ កំណត់ចំណាំអនុវត្តពីរ៖ (1) រយៈពេលមានន័យថា *ពេលវេលាប្រតិទិនដែលកាន់កាប់ឧបសគ្គ* មិនមែនកិច្ចខំប្រឹងទេ — ធាតុដែលបានកន្លងផុត 2 សប្តាហ៍ ដែលត្រូវការ 2 ថ្ងៃនៃក្រុមចំណុចស្ទះ គឺថោកជាងដែលមើលទៅ (សូមមើល[ការបង្កើនប្រសិទ្ធភាពធនធានផ្នែកខាងក្រោម](../ការបង្កើនប្រសិទ្ធភាពធនធានផ្នែកខាងក្រោម/)); (2) មន្ទីរពេទ្យដំណើរការច្បាប់ដូចគ្នាដោយបង្កប់ នៅពេលរៀបបញ្ជីបន្ទប់វះកាត់តាមទិន្នផលដែលថ្លឹងតាមភាពបន្ទាន់ — ប្រភេទអាទិភាពគ្លីនិកគឺ CD3 ដែលថ្លឹងតាមភាពធ្ងន់ធ្ងរ (សូមមើល[ការខ្វះខាត QALY និងកត្តាកែតម្រូវភាពធ្ងន់ធ្ងរ](../ការខ្វះខាត-qaly-និងកត្តាកែតម្រូវភាពធ្ងន់ធ្ងរ/))។

## ចំណុចងាយធ្លាក់

- **ល្ខោនពិន្ទុ WSJF**៖ ការជជែក Fibonacci គ្មានឯកតាបញ្ចប់នឹងអ្នកដែលជជែកខ្លាំងបំផុត; ចងយ៉ាងហោចណាស់ធាតុកំពូលនៃបញ្ជីការងារជាប់គាំងក្នុង CoD ពិត។
- **ការបន្លំរយៈពេល**៖ ការបំបែកធាតុដើម្បីបំផ្លើសចំណាត់ថ្នាក់ CD3 — មិនអីទេពេលការបំបែកផ្តល់តម្លៃដោយឯករាជ្យ ជាការក្លែងបន្លំពេលមិនផ្តល់។
- **ការមិនអើពើទម្រង់បន្ទាន់**៖ CoD រាងកាលកំណត់ (កាលបរិច្ឆេទបទប្បញ្ញត្តិ) បំបែកការសន្មត់អត្រាថេរ; កំណត់ពេលទាំងនោះតាមលទ្ធភាពកាលបរិច្ឆេទ បន្ទាប់មក CD3 ដែលនៅសល់។
- **ការរៀបចំចំណាត់ថ្នាក់ឡើងវិញញឹកញាប់**៖ CD3 គឺសម្រាប់ការសម្រេចចិត្តរៀបលំដាប់នៅពេលប្តេជ្ញា មិនមែនសម្រាប់ការលាយឡើងវិញប្រចាំថ្ងៃនៃការងារកំពុងដំណើរការទេ (សូមមើល[រង្វាស់លំហូរ](../រង្វាស់លំហូរ/) លើ WIP)។
