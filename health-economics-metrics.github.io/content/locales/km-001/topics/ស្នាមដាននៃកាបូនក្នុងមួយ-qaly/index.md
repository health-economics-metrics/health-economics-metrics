# ស្នាមដាននៃកាបូនក្នុងមួយ QALY

កាបូនក្នុងមួយ QALY គឺជាសមាមាត្រប្រសិទ្ធភាព — ការបញ្ចេញកាបូនរបស់អន្តរាគមន៍ (ឬការបញ្ចេញដែលបានជៀសវាង) ចែកនឹង QALYs ដែលវាផ្តល់ — ប្រៀបធៀបដោយផ្ទាល់នឹងថ្លៃដើមក្នុងមួយ QALY ដែលអនុញ្ញាតឱ្យវាយតម្លៃប្រសិទ្ធភាពកាបូនរបស់អន្តរាគមន៍រួមជាមួយប្រសិទ្ធភាពថ្លៃដើមរបស់វា។ "អត្ថប្រយោជន៍រូបិយវត្ថុសុទ្ធដែលកែតម្រូវកាបូន" ទៅជំហានមួយទៀត៖ បំប្លែងផលប៉ះពាល់កាបូនជារូបិយវត្ថុដោយប្រើតម្លៃកាបូនមិនជួញដូររបស់ UK Green Book ហើយដកវាពី[អត្ថប្រយោជន៍រូបិយវត្ថុសុទ្ធ](../អត្ថប្រយោជន៍រូបិយវត្ថុសុទ្ធ/)ស្តង់ដារ។

## ហេតុអ្វីបានជាសំខាន់

ឥឡូវនេះ NICE និង NHS England រំពឹងថាផលប៉ះពាល់បរិស្ថានត្រូវបានពិចារណារួមជាមួយថ្លៃដើម និង QALYs។ NHS មានការប្តេជ្ញាចិត្ត net-zero ជាសាធារណៈ៖ net zero សម្រាប់ការបញ្ចេញដោយផ្ទាល់ត្រឹមឆ្នាំ 2040 និង net zero សម្រាប់ស្នាមដានខ្សែផ្គត់ផ្គង់ពេញលេញត្រឹមឆ្នាំ 2045។ សៀវភៅដៃការវាយតម្លៃបច្ចេកវិទ្យាសុខភាពរបស់ NICE (PMG36) យោងនិរន្តរភាពបរិស្ថានជាការពិចារណាកំពុងលេចឡើងក្នុងការវាយតម្លៃបច្ចេកវិទ្យា។ សម្រាប់ផលិតផលសុខភាពឌីជីថល នេះមានន័យថាកាបូនកំពុងក្លាយជាសសរស្តម្ភទីបួននៃករណីតម្លៃ រួមជាមួយថ្លៃដើម QALYs និង[ភាពលេចធ្លោលើព្រំដែនប្រសិទ្ធភាព](../ភាពលេចធ្លោ-និងព្រំដែនប្រសិទ្ធភាព/) — មិនមែនជាការជំនួសណាមួយទេ ប៉ុន្តែជាវិមាត្រដែលករណីអាជីវកម្មដែលបានបង្កើតល្អត្រូវការរាយការណ៍កាន់តែច្រើន។

## គណិតវិទ្យា

```
Carbon per QALY = total_emissions_tonnes_co2e / total_qalys
  (a negative value means net emissions AVOIDED per QALY gained — a
  double win: better health and lower carbon)

Monetized carbon impact = emissions_tonnes_co2e × carbon_value_per_tonne
  (negative emissions × positive value = a negative cost, i.e. a benefit)

Carbon-adjusted NMB = net_monetary_benefit − monetized_carbon_impact
```

នេះពង្រីកគំនិតព្រំដែនប្រសិទ្ធភាពថ្លៃដើម/QALY ដោយអ័ក្សទីពីរ — កាបូនក្នុងមួយ QALY — តក្កវិជ្ជា "គូសរាល់ជម្រើស ហើយមើលអ្វីដែលត្រូវបានលេចធ្លោ" ដូចគ្នានឹង[ភាពលេចធ្លោ និងព្រំដែនប្រសិទ្ធភាព](../ភាពលេចធ្លោ-និងព្រំដែនប្រសិទ្ធភាព/) អនុវត្តលើកាបូនជំនួសថ្លៃដើម។

## ឧទាហរណ៍ដែលបានគណនា

សេវាសុខភាពពីចម្ងាយជំនួសការចូលជួបផ្ទាល់ ជៀសវាងដំណើរឡាន 5,000 ដង/ឆ្នាំ ក្នុងប្រហែល 8kg CO2e ម្តង — 40 តោននៃ CO2e ដែលបានជៀសវាង តំណាងជាតួលេខបញ្ចេញអវិជ្ជមាន (−40.0 តោន) ហើយវាផ្តល់ 25 QALYs/ឆ្នាំ៖

```
Carbon per QALY = −40.0 / 25.0 = −1.6 tonnes CO2e avoided per QALY gained
```

ការប្រើតម្លៃកាបូនមិនជួញដូររបស់ Green Book (តួលេខបង្ហាញ តម្លៃកណ្តាលមិនជួញដូរឆ្នាំ 2023 ≈ £269/តោន CO2e — Green Book ធ្វើបច្ចុប្បន្នភាពតម្លៃកាបូនជារៀងរាល់ឆ្នាំ ផ្ទៀងផ្ទាត់ឡើងវិញមុនដកស្រង់ក្នុងការវិភាគផ្ទាល់)៖

```
Monetized carbon impact = −40.0 × £269 = −£10,760
```

"ថ្លៃដើម" −£10,760 គឺជាអត្ថប្រយោជន៍ £10,760។ ប្រសិនបើអត្ថប្រយោជន៍រូបិយវត្ថុសុទ្ធតែឯងរបស់អន្តរាគមន៍គឺ £500,000៖

```
Carbon-adjusted NMB = £500,000 − (−£10,760) = £510,760
```

ការសន្សំកាបូនបន្ថែមទៅករណីជាជាងកាត់បន្ថយវា — ជ័យជម្នះទ្វេដងដែលការកំណត់ក្របខ័ណ្ឌការបញ្ចេញអវិជ្ជមានមានបំណងបង្ហាញ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

នេះគឺជាចំណុចប្រសព្វបច្ចុប្បន្នដែលនៅរស់ជាមួយសេដ្ឋកិច្ច AI/ពពក៖ ស្នាមដានកាបូនគណនានៃការបណ្តុះបណ្តាល និងដំណើរការម៉ូដែល AI ឥឡូវនេះជាបន្ទាត់ធាតុពិតក្នុងការទិញរបស់ NHS ព្រោះកិច្ចសន្យាអ្នកផ្គត់ផ្គង់ NHS លើសកម្រិតជាក់លាក់តម្រូវឱ្យមានផែនការកាត់បន្ថយកាបូន។ [សេដ្ឋកិច្ចឯកតាពពក](../សេដ្ឋកិច្ចឯកតាពពក/)តាមដានថ្លៃដើមក្នុងមួយឯកតានៃលទ្ធផលគណនារួចហើយ; កាបូនក្នុងមួយ QALY គឺជាគំរូធម្មជាតិសម្រាប់រង្វាស់ "ថ្លៃកាបូនក្នុងមួយការអនុមាន" នាពេលអនាគត ដែលពង្រីកម៉ូឌុលនោះ និងសេដ្ឋកិច្ចឯកតាអនុមានទៅក្នុងវិមាត្របរិស្ថាន ទោះបីរង្វាស់នោះមិនទាន់មានក៏ដោយ។

## កំហុសដែលត្រូវជៀសវាង

- **ល្បិចព្រំដែនវិសាលភាព**៖ រាប់តែការបញ្ចេញដោយផ្ទាល់ (Scope 1) ហើយដកការបញ្ចេញខ្សែផ្គត់ផ្គង់ (Scope 3) ដែលជាធម្មតាជាភាគច្រើនសម្រាប់ស្នាមដានពិតរបស់ផលិតផលសុខភាពឌីជីថល។
- **ការប្រើតម្លៃកាបូនហួសសម័យ**៖ Green Book ធ្វើបច្ចុប្បន្នភាពតម្លៃកាបូនមិនជួញដូរជារៀងរាល់ឆ្នាំ ដូច្នេះតួលេខ £/តោនណាមួយដែលបានដកស្រង់ត្រូវតែមានកាលបរិច្ឆេទ មិនមែនដកស្រង់ជាថេរទេ។
- **ចាត់ទុក "ប្រសិទ្ធភាពកាបូន" ជាការជំនួស "ប្រសិទ្ធភាពថ្លៃដើម"**៖ អន្តរាគមន៍កាបូនទាប តម្លៃទាប នៅតែជាការប្រើប្រាស់ធនធាន NHS មិនល្អ។ កាបូនគឺជាសសរស្តម្ភទីបួនរួមជាមួយថ្លៃដើម និង QALYs មិនមែនជាការជំនួសណាមួយទេ។
