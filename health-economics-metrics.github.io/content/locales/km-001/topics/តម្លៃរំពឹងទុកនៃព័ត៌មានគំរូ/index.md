# តម្លៃរំពឹងទុកនៃព័ត៌មានគំរូ (EVSI)

EVSI គឺជាតម្លៃនៃ *ការសិក្សាជាក់លាក់ដែលបានស្នើ* — ការរចនាដែលបានផ្តល់ ទំហំគំរូដែលបានផ្តល់ — មុនពេលវាត្រូវបានដំណើរការ ផ្ទុយពី [EVPI](../តម្លៃរំពឹងទុកនៃព័ត៌មានល្អឥតខ្ចោះ/) ដែលកំណត់តម្លៃការលុបបំបាត់ភាពមិនប្រាកដប្រជាទាំងអស់ដោយផ្ទាល់។ EVSI ឆ្លើយសំណួរដែលអ្នកផ្តល់មូលនិធិស្រាវជ្រាវប្រឈមពិតប្រាកដ៖ "តើការសាកល្បង *នេះ* នៅទំហំ *នេះ* មានតម្លៃជាងថ្លៃដើមរបស់វាទេ?"

## ហេតុអ្វីបានជាសំខាន់

EVPI ប្រាប់អ្នកពីពិដានលើអ្វីដែលការស្រាវជ្រាវណាមួយអាចមានតម្លៃ; វាមិនដែលប្រាប់ថាតើការសាកល្បងនៅមុខអ្នកឆ្លងកាត់របារឬអត់។ អ្នកផ្តល់មូលនិធិស្រាវជ្រាវជាតិដែលជ្រើសរវាងការសាកល្បងអ្នកជំងឺ 50 នាក់ និងការសាកល្បងកំណត់ 500 នាក់ត្រូវដឹងថាតើ *ការរចនាជាក់លាក់នីមួយៗ* មានតម្លៃប៉ុន្មាន មិនមែនគ្រាន់តែតម្លៃនៃភាពអ្វីៗទាំងអស់ដឹងទេ។ EVSI ផ្តល់លេខនោះ ហើយព្រោះវាកើនតាមទំហំគំរូ វាអនុញ្ញាតឱ្យអ្នកផ្តល់មូលនិធិរកទំហំគំរូដែលបង្កើនអត្ថប្រយោជន៍សុទ្ធរំពឹងទុកអតិបរមា ជំនួសឱ្យការស្មាន។

នេះក៏ជាមូលហេតុដែល EVSI តែងតែតិចជាង ឬស្មើ EVPI៖ គំរូកំណត់អាចដោះស្រាយភាពមិនប្រាកដប្រជាបានតែមួយផ្នែក ហើយការសិក្សាដែលហាក់ដូចជាមានតម្លៃជាងព័ត៌មានល្អឥតខ្ចោះគឺជាសញ្ញាថាការគណនាខុស មិនមែនលទ្ធផលពិតទេ។

## គណិតវិទ្យា

```
General:
EVSI(n) = E_data[ max_d E_θ|data[NB(d,θ)] ]  −  max_d E_θ[NB(d,θ)]
  (nested expectation: outer over possible study results, inner over the
  posterior belief about θ after seeing that result — usually estimated by
  nested Monte Carlo / Bayesian updating over probabilistic sensitivity
  analysis draws)

Closed-form normal approximation (single uncertain parameter, conjugate
normal-normal model — a standard shortcut, not exact for every model):
EVSI(n) = EVPI × n / (n + n0)

n  = proposed study's sample size
n0 = "prior-equivalent sample size" — the size of an imaginary sample that
     would carry the same information as the current prior, derived from
     the ratio of data variance to prior variance
ENBS(n) = EVSI(n) − Cost(n)
Population EVSI = per-decision EVSI × decisions affected
```

ទម្រង់ទូទៅគឺជាការរំពឹងទុកជាប់គ្នា ព្រោះលទ្ធផលអនាគតនៃការសិក្សាខ្លួនឯងមិនប្រាកដ៖ អ្នកត្រូវតែគិតមធ្យមលើរាល់សំណុំទិន្នន័យដែលការសិក្សាអាចបង្កើត ហើយសម្រាប់នីមួយៗគណនាការសម្រេចចិត្តល្អបំផុតឡើងវិញដែលបានធ្វើបច្ចុប្បន្នភាព (posterior)។ ការប៉ាន់ស្មានធម្មតាទម្រង់បិទដោះដូរថ្លៃគណនានោះសម្រាប់សមាមាត្រតែមួយ មានសុពលភាពនៅពេលប៉ារ៉ាម៉ែត្រមិនប្រាកដ និងទិន្នន័យ (ប្រហែល) ធម្មតា និង conjugate — ភាពងាយស្រួល មិនមែនច្បាប់សកលទេ។ Monte Carlo ជាប់គ្នាពេញលេញគឺជាវិធីសាស្ត្រគោលបំណងទូទៅនៅពេលការសន្មតនោះមិនកាន់។ សូមមើល[ការវិភាគភាពប្រកាន់អារម្មណ៍ប្រូបាប៊ីលីស្ទិក](../ការវិភាគភាពរសើបប្រូបាប៊ីលីស្ទិក/)សម្រាប់ការដកយក PSA ដែល EVSI ជាធម្មតាត្រូវបានប៉ាន់ស្មាន។

## ឧទាហរណ៍ដែលបានគណនា

ដោយផ្អែកលើឧទាហរណ៍គណនា [EVPI](../តម្លៃរំពឹងទុកនៃព័ត៌មានល្អឥតខ្ចោះ/) — ដាក់ជំនួយឯកសារ AI ឱ្យប្រើដល់គ្លីនិកករ 5,000 នាក់ ដែល EVPI ត្រូវបានរកឃើញជា £1.2M — បង្ហាញ EVPI ដូចគ្នានៅទីនេះជាផោនទាំងមូល៖ **EVPI = £1,200,000**។

ការសិក្សាសាកល្បងដែលបានស្នើនៃគ្លីនិកករ 50 នាក់នៅលើតុ។ ពីសមាមាត្រនៃវ៉ារ្យ៉ង់នៃជំនឿមុនទៅភាពជាក់លាក់នៃការវាស់របស់ការសាកល្បង ទំហំគំរូស្មើនឹងមុនដំណើរការគឺ `n0 = 75`៖

```
EVSI(50) = 1,200,000 × 50 / (50 + 75)
         = 1,200,000 × 50 / 125
         = 1,200,000 × 0.4
         = £480,000
```

ការសាកល្បងចំណាយ £120,000៖

```
ENBS = EVSI − Cost = 480,000 − 120,000 = £360,000
```

ENBS វិជ្ជមានយ៉ាងច្បាស់៖ ផ្តល់មូលនិធិការសាកល្បង។ ប្រសិនបើការសម្រេចចិត្តទិញដូចគ្នាកើតឡើងម្តងទៀតឆ្លងទុនតំបន់ស្រដៀងគ្នា 3 តម្លៃរបស់ការសាកល្បងធំឡើង៖

```
Population EVSI = 480,000 × 3 = £1,440,000
```

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

EVSI គឺជាសេដ្ឋកិច្ចនៃការជ្រើសរើស *ទំហំប៉ុន្មាន* នៃការសាកល្បង ឬតេស្ត A/B មិនមែនគ្រាន់តែថាតើត្រូវដំណើរការវាសោះទេ៖

- **ការសម្រេចចិត្តទំហំគំរូជាការវិនិយោគ។** បេតា 50 អ្នកប្រើ និងការដាក់ឱ្យប្រើជាដំណាក់កាល 5,000 អ្នកប្រើគឺជា "ការសិក្សា" ខុសគ្នាដែលមាន EVSI ខុសគ្នា និងថ្លៃដើមខុសគ្នា — EVSI អនុញ្ញាតឱ្យអ្នកប្រៀបធៀបពួកវាលើមូលដ្ឋានដូចគ្នា ជំនួសឱ្យលំនាំដើម "ទិន្នន័យច្រើនជាងតែងតែល្អជាង"។
- **ENBS មិនមែន EVSI តែឯងទេ គឺជាតេស្តបញ្ជាទិញ។** ការសិក្សាដែលមាន EVSI ខ្ពស់ ប៉ុន្តែថ្លៃដើមស៊ីភាគច្រើនរបស់វាគឺជាសំណើខ្សោយ; ច្បាប់សម្រេចចិត្តគឺអត្ថប្រយោជន៍សុទ្ធរំពឹងទុកនៃការយកគំរូ ដូចករណីអាជីវកម្មដកអត្ថប្រយោជន៍ពីថ្លៃដើម ជាជាងរាយការណ៍អត្ថប្រយោជន៍តែឯង។
- **ផលចំណេញថយចុះគឺច្បាស់លាស់។** ដោយសារ EVSI(n) កើនតាម `n/(n+n0)` ការបង្កើនទំហំការសាកល្បងទ្វេដងមិនដែលបង្កើនតម្លៃវាទ្វេដងទេ — កំណែផ្លូវការនៃសភាវគតិវិស្វកម្មថាការពិសោធន៍ធំជាងមានតម្លៃព័ត៌មានរឹតបន្តឹងថយចុះ។

## កំហុសដែលត្រូវជៀសវាង

- **ការអនុវត្តការប៉ាន់ស្មានធម្មតានៅក្រៅការសន្មតរបស់វា។** វាកាន់តែទៅលើភាពមិនប្រាកដប្រជា conjugate ប្រហែល ប៉ារ៉ាម៉ែត្រតែមួយ; ម៉ូដែលសម្រេចចិត្តមិនលីនេអ៊ែរ ឬច្រើនប៉ារ៉ាម៉ែត្រពិតប្រាកដត្រូវការ Monte Carlo ជាប់គ្នាពេញលេញ មិនមែនផ្លូវកាត់នេះទេ។
- **ការប្រៀបធៀប EVSI ទៅនឹងថ្លៃសាច់ប្រាក់តែឯង។** EVSI ត្រូវតែថ្លឹងធៀបនឹងថ្លៃ *ពេញលេញ* នៃការសិក្សា រួមទាំងថ្លៃពន្យារការសម្រេចចិត្តរបស់ខ្លួន — សូមមើល[ថ្លៃដើមនៃការពន្យារ](../ថ្លៃដើមនៃការពន្យារ/) — មិនមែនគ្រាន់តែវិក្កយបត្រការសិក្សាទេ។
- **ចាត់ទុក EVSI > EVPI ជាការរកឃើញពិត។** EVSI មិនអាចលើស EVPI តាមរចនាសម្ព័ន្ធ; ការគណនាដែលបង្កើតនេះគឺជាកំហុសគំរូ មិនមែនការរកឃើញទេ។
