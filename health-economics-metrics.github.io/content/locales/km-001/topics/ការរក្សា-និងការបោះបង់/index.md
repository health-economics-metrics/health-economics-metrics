# ការរក្សា និងការបោះបង់

ការរក្សារង្វាស់ថាចំណែកនៃក្រុមអ្នកប្រើនៅតែសកម្ម N ថ្ងៃបន្ទាប់ពីចាប់ផ្តើម (ខ្សែកោង D1/D7/D30); ការបោះបង់គឺជាបំពេញបន្ថែមរបស់វា។ មូលដ្ឋានឃោរឃៅនៃសុខភាពឌីជីថល៖ **ប្រហែល 90% នៃអ្នកប្រើកម្មវិធីសុខភាពបោះបង់ក្នុងរយៈពេល 30 ថ្ងៃ** — ការរក្សា D30 នៃសុខភាពឌីជីថលស្ថិតនៅ ~3–4% ធៀបនឹងមធ្យមកម្មវិធីទាំងអស់ ~6%។

## ហេតុអ្វីបានជាសំខាន់

Eysenbach បានដាក់ឈ្មោះនេះក្នុងឆ្នាំ 2005៖ **ច្បាប់នៃការធ្លាក់ចុះ** — ការបាត់បង់អ្នកប្រើក្នុងអត្រាខ្ពស់ គឺជាលក្ខណៈសម្បត្តិខាងក្នុង និងរចនាសម្ព័ន្ធនៃអន្តរាគមន៍ eHealth មិនមែនកំហុសអនុវត្តទេ ដោយការធ្លាក់ចុះក្នុងការសាកល្បង eHealth ជាប្រចាំលើសពី 50%។ ផលវិបាកសេដ្ឋកិច្ចគឺសរុប៖ ការរក្សាកំណត់ *បង្អួចព្យាបាល* ដែលអត្ថប្រយោជន៍ណាមួយអាចត្រូវបានផ្តល់ និង[សេដ្ឋកិច្ចឯកតា](../សេដ្ឋកិច្ចឯកតានៃកម្មវិធីសុខភាព/) — CAC ដែលបង់ក្នុងមួយអ្នកប្រើដែលនៅ 12 ថ្ងៃ មិនផ្តល់ទាំង LTV ឬ QALY។ គំរូសេដ្ឋកិច្ចណាមួយសម្រាប់ផលិតផលសុខភាពអ្នកប្រើប្រាស់ដែលមិនថ្លឹងអត្ថប្រយោជន៍តាមខ្សែកោងរក្សា កំពុងពិពណ៌នាផលិតផលដែលមិនមាន។

## គណិតវិទ្យា

```
Retention_Dn = users active on day n / cohort size × 100
Churn rate   = users lost in period / users at period start × 100

Benefit weighting (the health-economics move):
  expected benefit per acquired user = Σ_t retention(t) × benefit rate(t)
  ≈ area under the retention curve × per-time benefit
  — NOT trial benefit × 100% of acquired users

Cost per retained-at-D30 user = CAC / D30 retention
  (at 4% D30, a £5 CAC is really £125 per retained user)
```

## ឧទាហរណ៍ដែលបានគណនា

កម្មវិធីសុខភាពផ្លូវចិត្ត៖ ការសាកល្បងបង្ហាញ 0.02 QALY ដែលទទួលបានក្នុងមួយអ្នកប្រើបញ្ចប់ 8 សប្តាហ៍។ ក្រុមដាក់ពង្រាយ 100,000 ដោនឡូដ ការរក្សា D7 25% D30 8% សប្តាហ៍ទី 8 4%៖

```
Completers          = 100,000 × 0.04 = 4,000
QALYs delivered     = 4,000 × 0.02 = 80  (not 100,000 × 0.02 = 2,000)
At £20,000/QALY     = £1.6M of health value (not £40M)

Per-download health value = £16 — the number that should set what a
payer will pay per download, and it is 4% of the naive claim.
Retention improvement case: moving week-8 completion 4% → 6% adds
40 QALYs/year ≈ £800k — retention engineering IS health production.
```

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ការរក្សាគឺជារង្វាស់ដែលវិស្វកម្មផលិតផលផលិតតម្លៃសុខភាពដោយផ្ទាល់បំផុត តាមនព្វន្ធខាងលើ។ ការអនុវត្តដែលផ្លាស់ប្តូរវាជារឿងធម្មតា៖ ពេលវេលាចាប់ផ្តើមទៅតម្លៃដំបូង ការរចនាការចូលរួមឡើងវិញ ដំណើរការ និងសំខាន់ **ការបញ្ចប់កម្រិតថ្នាំដែលបានគ្រោង** — កម្មវិធីដែលមានចុងបញ្ចប់កំណត់ (8 សប្តាហ៍ បន្ទាប់មកបញ្ចប់ការសិក្សា) គួរវាស់ *ការបញ្ចប់* មិនមែន DAU ជាប់រហូតទេ ដោយតម្រឹមរង្វាស់នឹងគំរូគ្លីនិក ជំនួសឱ្យគំរូការយកចិត្តទុកដាក់ដែលផ្តល់មូលនិធិដោយការផ្សាយពាណិជ្ជកម្ម។ ការវិភាគការរស់រានគឺជាឧបករណ៍ត្រឹមត្រូវ (គណិតវិទ្យា Kaplan-Meier ដូចគ្នានឹង[ឆ្នាំជីវិតដែលទទួលបាន](../ឆ្នាំជីវិតដែលទទួលបាន/)); បំបែកខ្សែកោងតាមឆានែលទទួលបាន ពីព្រោះការលាយឆានែលផ្លាស់ប្តូរការរក្សាច្រើនជាងលក្ខណៈពិសេសភាគច្រើន។

## ចំណុចងាយធ្លាក់

- **ការលាងសម្អាត intention-to-treat បញ្ច្រាស**៖ ការសាកល្បងរាយការណ៍អ្នកបញ្ចប់; សេដ្ឋកិច្ចដាក់ពង្រាយត្រូវតែរាប់អ្នកទាំងអស់ដែលបានទទួល (ការព្រមានស្នូលរបស់ Eysenbach)។
- **ល្ខោនការរក្សា**៖ អ្នកប្រើ "សកម្ម" ដែលជំរុញដោយការជូនដំណឹង ដែលមិនដែលធ្វើសកម្មភាពព្យាបាល (សូមមើល[រង្វាស់ការចូលរួម](../រង្វាស់ការចូលរួម/))។
- **ការប្រៀបធៀបខ្សែកោងឆ្លងនិយមន័យ**៖ "សកម្ម" ដែលកំណត់ជាការបើក ធៀបនឹងសកម្មភាពមានន័យ ផ្លាស់ប្តូរ D30 ច្រើនដង។
- **ការមិនអើពើអ្នកណាបោះបង់**៖ ប្រសិនបើអ្នកឈឺបំផុតបោះបង់លឿនបំផុត អត្ថប្រយោជន៍ក្នុងមួយអ្នកប្រើធ្លាក់ចុះនៅពេលការរក្សាប្រសើរក្នុងចំណោមអ្នកមានសុខភាពល្អ — ផ្គូផ្គងខ្សែកោងជាមួយសមាសភាពករណី (សូមមើល[ការឈានដល់ និងសមធម៌](../ការឈានដល់-និងសមធម៌/))។
