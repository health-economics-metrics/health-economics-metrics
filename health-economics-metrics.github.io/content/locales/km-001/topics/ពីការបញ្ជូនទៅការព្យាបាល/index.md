# ពីការបញ្ជូនទៅការព្យាបាល (RTT)

ពីការបញ្ជូនទៅការព្យាបាលគឺជាពេលវេលាដែលកន្លងផុតពីការបញ្ជូនរបស់គ្រូពេទ្យទូទៅ រហូតដល់ការចាប់ផ្តើមព្យាបាលដែលដឹកនាំដោយអ្នកប្រឹក្សា។ ធម្មនុញ្ញ NHS កំណត់ស្តង់ដារ៖ **92% នៃអ្នកជំងឺគួរចាប់ផ្តើមព្យាបាលក្នុងរយៈពេល 18 សប្តាហ៍**។ RTT គឺជារង្វាស់ប្រតិបត្តិការដែលមើលឃើញខាងនយោបាយបំផុតតែមួយគត់ក្នុង NHS អង់គ្លេស។

## ហេតុអ្វីបានជាសំខាន់

Trust ដែលខកខានគោលដៅ RTT ប្រឈមនឹងការត្រួតពិនិត្យនិយតកម្ម អន្តរាគមន៍ និងការខូចកេរ្តិ៍ឈ្មោះ; បញ្ជីរង់ចាំជាតិគឺជាលេខនៅទំព័រមុខ។ រាល់សប្តាហ៍ដែលអ្នកជំងឺរង់ចាំគឺជាសុខភាពដែលបាត់បង់ (រង់ចាំក្នុងស្ថានភាពសុខភាពអាក្រក់ជាង — សូមមើលគណិតវិទ្យា QALY ខាងក្រោម) ហើយជាញឹកញាប់ជាថ្លៃដើមដែលបានទទួល (ស្ថានភាពអន់ថយ; សូមមើល[អន្តរាគមន៍ឆាប់ជាង](../អន្តរាគមន៍ឆាប់ជាង/))។ កម្មវិធីដែលសន្សំពេលវេលានៅកន្លែងណាក៏ដោយក្នុងផ្លូវពីការបញ្ជូនទៅការព្យាបាល — ការចាត់ថ្នាក់ ការឆ្លើយតបធ្វើរោគវិនិច្ឆ័យ សមត្ថភាពគ្លីនិក ការកំណត់ពេល — កាត់បន្ថយដោយផ្ទាល់នូវផលវិបាកប្រតិបត្តិការ និងហិរញ្ញវត្ថុនៃការបរាជ័យស្តង់ដារ ដែលជាមូលហេតុដែលផលប៉ះពាល់ RTT ជាបន្ទាត់អត្ថប្រយោជន៍ថ្នាក់ទីមួយក្នុងករណីអាជីវកម្មឌីជីថល NHS។

## គណិតវិទ្យា

```
RTT performance = patients treated within 18 weeks / total treated × 100
Waiting-time health cost per patient = wait duration × (utility_treated − utility_waiting)

Pathway view: RTT = Σ stage durations (referral triage → first appointment →
diagnostics → decision → treatment) — improve the longest queue, not the
busiest stage (see flow-metrics.md).
```

## ឧទាហរណ៍ដែលបានគណនា

ឯកទេសមួយព្យាបាលអ្នកជំងឺផ្លូវ 5,000 នាក់/ឆ្នាំ; ការរង់ចាំមធ្យម 24 សប្តាហ៍; ឧបយោគពេលរង់ចាំ 0.68 ធៀបនឹងបានព្យាបាល 0.80។

ការចាត់ថ្នាក់ឌីជីថល បូកពិធីការត្រង់ទៅតេស្ត លុប 5 សប្តាហ៍នៃការរង់ចាំជួរសុទ្ធ៖

```
QALY gain = 5,000 × (5/52) × (0.80 − 0.68) = 57.7 QALYs/year
Monetized at £20,000–£30,000/QALY (see willingness-to-pay-thresholds.md):
  ≈ £1.15M–£1.73M/year of health value
```

— បូកនឹង trust ផ្លាស់ពីការរំលោភទៅបំពេញស្តង់ដារ 18 សប្តាហ៍ ដែលមានតម្លៃអភិបាលកិច្ចដែលតារាងគណនាមិនចាប់យកពេញលេញ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

RTT គឺជា **រង្វាស់ពេលវេលាដឹកនាំលើជួរច្រើនដំណាក់កាល** — កំណែមន្ទីរពេទ្យនៃពេលវេលាដឹកនាំពីការបញ្ជូនទៅផលិតកម្ម (សូមមើល[រង្វាស់ DORA](../រង្វាស់-dora/))។ វិធីសាស្ត្រកែលម្អដូចគ្នា៖ ដាក់ឧបករណ៍វាស់ដំណាក់កាលនីមួយៗ រកកន្លែងដែលពេលវេលាប្រមូលផ្តុំ (ស្ទើរតែជានិច្ចជាការប្រគល់ និងជួរ មិនមែនការងារគ្លីនិកទេ) ហើយលុបស្ថានភាពរង់ចាំ។ ជ័យជម្នះកម្មវិធីធម្មតា៖ ការចាត់ថ្នាក់អេឡិចត្រូនិកដែលបញ្ជូនការបញ្ជូនក្នុងរយៈពេលជាម៉ោង ជំនួសបាច់ប្រចាំសប្តាហ៍ ការរុញលទ្ធផលធ្វើរោគវិនិច្ឆ័យជំនួសការណាត់ជួបតាមដាន និងលក្ខណៈវិនិច្ឆ័យត្រង់ទៅតេស្តស្វ័យប្រវត្តិ។ វាយតម្លៃការកែលម្អជាមួយ[ថ្លៃដើមនៃការពន្យារ](../ថ្លៃដើមនៃការពន្យារ/) ជាឯកតា QALY/សប្តាហ៍។

## ចំណុចងាយធ្លាក់

- **ការកែលម្អដំណាក់កាលដែលមិនមែនជាឧបសគ្គ** — កាត់បន្ថយការរង់ចាំណាត់ជួបដំបូង ខណៈជួរធ្វើរោគវិនិច្ឆ័យកើនឡើង គ្រាន់តែផ្លាស់ទីអាងប៉ុណ្ណោះ។
- **ការបន្លំ**៖ ការកំណត់ផ្លូវឡើងវិញ និងការផ្អាកនាឡិកាអាចកែលម្អ RTT ដែលបានរាយការណ៍ ដោយមិនព្យាបាលអ្នកណាលឿនជាងមុន; ធ្វើសវនកម្មការចែកចាយមូលដ្ឋាន។
- **ការអះអាងការកែលម្អផ្លូវទាំងមូល** សម្រាប់ឧបករណ៍មួយ នៅពេលការផ្លាស់ប្តូរជាច្រើនបានមកដល់រួមគ្នា — ការបង្កប់គុណលក្ខណៈត្រូវការអ្នកប្រៀបធៀប។
