# ការវិភាគភាពរសើប

ការវិភាគភាពរសើបកំណត់ (DSA) ផ្លាស់ប្តូរការសន្មត់មួយម្តងៗក្នុងចន្លោះសមហេតុផល ដើម្បីមើលថាតើការសន្និដ្ឋានបន្តពិតឬអត់។ ការបង្ហាញស្តង់ដារគឺដ្យាក្រាមខ្យល់ព្យុះ (tornado)៖ ប៉ារ៉ាម៉ែត្រត្រូវបានតម្រៀបតាមកម្រិតដែលវាធ្វើឱ្យលទ្ធផលប្រែប្រួល។

## ហេតុអ្វីបានជាសំខាន់

រាល់ម៉ូដែលសេដ្ឋកិច្ចត្រូវបានសាងសង់លើការប៉ាន់ស្មាន — ពេលវេលាដែលសន្សំ ការទទួលយក ថ្លៃដើមឯកតា។ ការវាយតម្លៃបច្ចេកវិទ្យាសុខភាពបដិសេធមិនទទួលយកការប៉ាន់ស្មានចំណុចតែមួយ ("ROI គឺ 340%") ដោយគ្មានភស្តុតាងថាការសន្និដ្ឋានរឹងមាំចំពោះការមិនយល់ស្របសមហេតុផលលើធាតុចូល។ ដ្យាក្រាមខ្យល់ព្យុះប្រាប់អ្នកសម្រេចចិត្តថា *ការសន្មត់ណាត្រូវសាកសួរ*៖ ប្រសិនបើករណីដំណើរការតែនៅពេលប៉ារ៉ាម៉ែត្រដែលចរចាបំផុតនៅចុងសុទិដ្ឋិនិយម អ្នកគ្រប់គ្នាអាចឃើញភ្លាមៗ។

នេះគឺជាទម្លាប់ដែលអាចផ្ទេរបានច្រើនបំផុតតែមួយពីសេដ្ឋកិច្ចសុខភាពទៅករណីអាជីវកម្មកម្មវិធី។

## គណិតវិទ្យា

សម្រាប់ប៉ារ៉ាម៉ែត្រ p នីមួយៗដែលមានចន្លោះសមហេតុផល [p_low, p_high]៖

```
Result_low  = model(p = p_low,  all others at base case)
Result_high = model(p = p_high, all others at base case)
Swing(p)    = |Result_high − Result_low|
```

តម្រៀបប៉ារ៉ាម៉ែត្រតាមកម្រិតប្រែប្រួល; គូសរបារផ្ដេកជុំវិញលទ្ធផលករណីមូលដ្ឋាន។ ទម្រង់ផ្សេង៖ DSA ពីរផ្លូវ (ផ្លាស់ប្តូរប៉ារ៉ាម៉ែត្រពីរលើក្រឡាចត្រង្គ) ការវិភាគកម្រិតកំណត់ (រកតម្លៃប៉ារ៉ាម៉ែត្រដែលការសម្រេចចិត្តត្រឡប់)។

## ឧទាហរណ៍ដែលបានគណនា

ជំនួយការសរសេរកូដ AI សម្រាប់អ្នកអភិវឌ្ឍន៍ 200 នាក់។ ករណីមូលដ្ឋាន៖ អាជ្ញាប័ណ្ណ £39/អ្នកអភិវឌ្ឍន៍/ខែ; សន្សំ 30 នាទី/អ្នកអភិវឌ្ឍន៍/ថ្ងៃ; ថ្លៃដើមពេញលេញ £60/ម៉ោង; 220 ថ្ងៃធ្វើការ។

```
Base-case annual benefit = 200 × 0.5h × 220 × £60 = £1,320,000
Annual cost              = 200 × £39 × 12         = £93,600
Base-case net            = £1,226,400
```

ខ្យល់ព្យុះ (ប៉ារ៉ាម៉ែត្រមួយម្តងៗ)៖

```
Time saved 0.1–1.0 h/day: net = £170,400 … £2,546,400   (swing £2.38M) ← dominates
Loaded cost £40–£80/h:    net = £786,400 … £1,666,400   (swing £0.88M)
Working days 200–240:     net = £1,106,400 … £1,346,400 (swing £0.24M)
Licence £30–£50/mo:       net = £1,248,000 … £1,200,000 (swing £48k)
```

ការវិភាគកម្រិតកំណត់៖ អត្ថប្រយោជន៍សុទ្ធស្មើសូន្យនៅពេលសន្សំបានប្រហែល **2.1 នាទី/ថ្ងៃ**។ ការសម្រេចចិត្តមិនរសើបចំពោះតម្លៃអាជ្ញាប័ណ្ណ ហើយអាស្រ័យទាំងស្រុងលើការប៉ាន់ស្មានពេលវេលាដែលសន្សំ — ដូច្នេះត្រូវវាស់វា មិនមែនអ្វីផ្សេងទៀតទេ។ (ហើយចងចាំថាលទ្ធផលគឺសមត្ថភាព មិនមែនសាច់ប្រាក់ — សូមមើល[ការសន្សំដែលបញ្ចេញសាច់ប្រាក់ ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់](../ការសន្សំដែលបញ្ចេញសាច់ប្រាក់-ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់/)។)

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

វិស្វករធ្វើវិចារណញាណនេះរួចហើយជា "ចុះបើយើងខុសអំពី X?" — DSA គ្រាន់តែធ្វើឱ្យវាមានប្រព័ន្ធ និងមើលឃើញ។ ដាក់ដ្យាក្រាមខ្យល់ព្យុះក្នុងរាល់សំណើឧបករណ៍ ផែនការសមត្ថភាព និងការវិភាគបង្កើត ឬទិញ។ វាបម្លែងអំណះអំណាងអំពីអារម្មណ៍របស់អ្នកណាត្រឹមត្រូវ ទៅជាកិច្ចព្រមព្រៀងអំពីប៉ារ៉ាម៉ែត្រណាត្រូវទៅវាស់ — ជារឿយៗតាមរយៈគម្រោងសាកល្បង ដែលតម្លៃរបស់វាអាចត្រូវបានកំណត់ (សូមមើល[តម្លៃរំពឹងទុកនៃព័ត៌មានល្អឥតខ្ចោះ](../តម្លៃរំពឹងទុកនៃព័ត៌មានល្អឥតខ្ចោះ/))។

## ចំណុចងាយធ្លាក់

- **ចន្លោះដែលជ្រើសដើម្បីបញ្ជាក់ត្រូវ**៖ ±10% ជុំវិញរាល់ធាតុចូលដោយមិនគិតពីភាពមិនប្រាកដពិត។ ការប៉ាន់ស្មានពេលវេលាដែលសន្សំសមនឹង ±80%; តម្លៃអាជ្ញាប័ណ្ណ ±10%។
- **មួយម្តងៗខកខានអន្តរកម្ម** — ប៉ារ៉ាម៉ែត្រជាប់ទាក់ទង (ការទទួលយក និងពេលវេលាដែលសន្សំ) ត្រូវការការវិភាគពីរផ្លូវ ឬ[ការវិភាគភាពរសើបប្រូបាប៊ីលីស្ទិក](../ការវិភាគភាពរសើបប្រូបាប៊ីលីស្ទិក/)ពេញលេញ។
- **ធ្វើការវិភាគ ហើយមិនអើពើវា**៖ ប្រសិនបើខ្យល់ព្យុះនិយាយថាករណីអាស្រ័យលើលេខទន់តែមួយ ជំហានបន្ទាប់គឺការវាស់ មិនមែនការអនុម័តទេ។
