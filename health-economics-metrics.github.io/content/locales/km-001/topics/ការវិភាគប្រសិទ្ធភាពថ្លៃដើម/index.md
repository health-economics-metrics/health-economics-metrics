# ការវិភាគប្រសិទ្ធភាពថ្លៃដើម (CEA)

CEA ប្រៀបធៀបថ្លៃដើមនៃអន្តរាគមន៍ជម្រើសទល់នឹងលទ្ធផលតែមួយដែលវាស់ជា **ឯកតាធម្មជាតិ** — ឆ្នាំជីវិត ករណីដែលបានរកឃើញ ការចូលសម្រាកដែលបានជៀសវាង mmHg នៃការបន្ថយសម្ពាធឈាម។ លទ្ធផលរបស់វាគឺថ្លៃដើមក្នុងមួយឯកតានៃលទ្ធផល។

## ហេតុអ្វីបានជាសំខាន់

CEA គឺជាការប្រៀបធៀបការងារសំខាន់នៅពេលជម្រើសទាំងអស់ផ្តោតលើលទ្ធផលតែមួយ។ វាឆ្លើយ "ក្នុងចំណោមវិធីទាំងនេះដើម្បីសម្រេច X តើវិធីណាជាការប្រើប្រាស់ប្រាក់ល្អបំផុត?" — ប៉ុន្តែ *មិនមែន* "តើ X គួរសម្រេចទេ?" (ត្រូវការ[ការវិភាគថ្លៃដើម-អត្ថប្រយោជន៍](../ការវិភាគថ្លៃដើម-អត្ថប្រយោជន៍/)) និង *មិនមែន* "តើ X ប្រៀបធៀបនឹងអាទិភាពមិនទាក់ទងយ៉ាងដូចម្តេច?" (ត្រូវការ[ការវិភាគថ្លៃដើម-ឧបយោគ](../ការវិភាគថ្លៃដើម-ឧបយោគ/) និងលទ្ធផលទូទៅដូចជា QALY)។

## គណិតវិទ្យា

ស្ថិតិប្រៀបធៀបគឺ[ICER](../សមាមាត្រប្រសិទ្ធភាពថ្លៃដើមបន្ថែម/)ក្នុងឯកតាធម្មជាតិ៖

```
ICER = (Cost_A − Cost_B) / (Effect_A − Effect_B)
     = £ per additional case detected / admission avoided / etc.
```

នីតិវិធី៖ កំណត់ឯកតាលទ្ធផល; គិតថ្លៃរាល់ជម្រើសពី[ទស្សនៈ](../ទស្សនៈនៃការវិភាគ/)ដូចគ្នា លើ[ជើងមេឃពេលវេលា](../ព្រំដែនពេលវេលា/)ដូចគ្នា; លុបជម្រើសដែលត្រូវបានលេចធ្លោ ([ព្រំដែនប្រសិទ្ធភាព](../ភាពលេចធ្លោ-និងព្រំដែនប្រសិទ្ធភាព/)); គណនាសមាមាត្របន្ថែមតាមព្រំដែន។

## ឧទាហរណ៍ដែលបានគណនា

បីវិធីដើម្បីរកឃើញការញ័របេះដូងបន្ទប់មិនទាន់រកឃើញក្នុងប្រជាជន 100,000 នាក់៖

```
Option                    Cost        Cases found
Opportunistic pulse checks £150,000       300
Pharmacy screening events  £400,000       520
Wearable-based screening   £900,000       610

ICER pharmacy vs pulse:  (400k−150k)/(520−300) = £1,136 per additional case
ICER wearable vs pharmacy:(900k−400k)/(610−520) = £5,556 per additional case
```

ថាតើ £5,556 ក្នុងមួយករណីបន្ថែម "មានតម្លៃ" ឬអត់ អាស្រ័យលើតម្លៃនៃករណីដែលបានរកឃើញ (ការបង្ការជំងឺដាច់សរសៃឈាមខួរក្បាលបន្ទាប់) — CEA ចំណាត់ថ្នាក់ជម្រើស ប៉ុន្តែការសម្រេចចិត្តទទួលយកត្រូវការការវាយតម្លៃខាងក្រៅនោះ។ ចំណាំថាថ្លៃដើម *មធ្យម* ក្នុងមួយករណីរបស់ជម្រើសពាក់ត្រូវ (900k/610 = £1,475) មើលទៅល្អ; £5,556 *បន្ថែម* គឺជាលេខស្មោះត្រង់សម្រាប់ការសម្រេចចិត្តពង្រីក។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

CEA គឺជាគំរូត្រឹមត្រូវនៅពេលជម្រើសចែករំលែកលទ្ធផលតែមួយ៖ ថ្លៃដើមក្នុងមួយតេស្តមិនស្ថិរភាពដែលបានលុបបំបាត់ឆ្លងវិធីជួសជុលបី; ថ្លៃក្នុងមួយឧប្បត្តិហេតុដែលបានជៀសវាងឆ្លងអ្នកលក់ការសង្កេត; ថ្លៃក្នុងមួយការដាក់ឱ្យប្រើជោគជ័យឆ្លងស្ថាបត្យកម្ម CI។ វិន័យដែលវាបង្ខំ — ឯកតាលទ្ធផលកំណត់មួយ សមាមាត្របន្ថែម (មិនមែនមធ្យម) ជម្រើសដែលត្រូវបានលេចធ្លោលុបមុនសិន — សម្លាប់ការប្រៀបធៀបអ្នកលក់អាក្រក់ភាគច្រើនមុនការពិភាក្សាតម្លៃចាប់ផ្តើម។

## កំហុសដែលត្រូវជៀសវាង

- **ការប្រៀបធៀបជម្រើសដែលមានលទ្ធផលខុសគ្នា** ("ករណីដែលបានរកឃើញ" ធៀបនឹង "ការពេញចិត្ត") ក្នុង CEA មួយ — នោះត្រូវការ[ការវិភាគថ្លៃដើម-លទ្ធផល](../ការវិភាគថ្លៃដើម-លទ្ធផល/) ឬលទ្ធផលទូទៅ។
- **សមាមាត្រប្រសិទ្ធភាពថ្លៃដើមមធ្យម** បង្ហាញនៅកន្លែងដែលត្រូវការសមាមាត្របន្ថែម (ឧទាហរណ៍ឧបករណ៍ពាក់ខាងលើ)។
- **ឯកតាលទ្ធផលជ្រើសរើសដើម្បីបញ្ជោរ**៖ "ការជូនដំណឹងដែលបានបង្កើត" គឺជាលទ្ធផលចេញ មិនមែនលទ្ធផលប្រកបដោយអត្ថន័យទេ; ទទូចលើឯកតាដែលផ្ទុកតម្លៃ។
