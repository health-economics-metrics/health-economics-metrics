# អត្ថប្រយោជន៍រូបិយវត្ថុសុទ្ធ (NMB)

NMB បំប្លែងលទ្ធផលប្រសិទ្ធភាពថ្លៃដើមទៅជាតម្លៃប្រាក់តែមួយ៖ ផលសុខភាពដែលកំណត់តម្លៃនៅកម្រិតកំណត់ឆន្ទៈបង់ប្រាក់ ដកថ្លៃដើម។ ភ្លោះរបស់វា អត្ថប្រយោជន៍សុខភាពសុទ្ធ (NHB) បង្ហាញច្បាប់ដូចគ្នាជាឯកតាសុខភាព។

## ហេតុអ្វីបានជាសំខាន់

សមាមាត្រ ([ICER](../សមាមាត្រប្រសិទ្ធភាពថ្លៃដើមបន្ថែម/)) ពិបាកប្រើ៖ វាផ្ទុះនៅជិតផលសូន្យ មិនអាចយកមធ្យមឆ្លងការទាញយកភាពមិនប្រាកដប្រជា ហើយមិនអាចតម្រៀបជម្រើសបីឬច្រើនបានស្អាត។ NMB ដោះស្រាយទាំងអស់នោះ — វាមានលក្ខណៈលីនេអ៊ែរ ដូច្នេះអ្នកអាចតម្រៀបជម្រើស យកមធ្យមការទាញយក Monte Carlo និងបំបែកការរួមចំណែក។ វាក៏ជាទម្រង់គណិតវិទ្យាសេដ្ឋកិច្ចសុខភាពដែលវិស្វករគ្រប់រូបស្គាល់រួចហើយ៖ *តម្លៃ ដកថ្លៃដើម*។

## គណិតវិទ្យា

```
NMB = (ΔE × λ) − ΔC
NHB = ΔE − (ΔC / λ)

ΔE = incremental effect (e.g., QALYs)
ΔC = incremental cost
λ  = willingness-to-pay threshold (see willingness-to-pay-thresholds.md)

Decision rule: adopt if NMB > 0 (equivalently NHB > 0).
Among alternatives: choose the highest NMB.
```

NMB > 0 ⇔ ICER < λ (នៅពេល ΔE > 0) ដូច្នេះច្បាប់ទាំងពីរស្របគ្នា — NMB គ្រាន់តែមានអាកប្បកិរិយាល្អជាង។

## ឧទាហរណ៍ដែលបានគណនា

ជម្រើសបីសម្រាប់សេវាទឹកនោមផ្អែម ក្នុង 1,000 អ្នកជំងឺ λ = £20,000/QALY៖

```
Option           ΔC          ΔE (QALYs)   NMB = 20,000×ΔE − ΔC
App + coaching   £400,000    30           600,000 − 400,000 = £200,000
App only         £150,000    12           240,000 − 150,000 = £90,000
Extra clinics    £700,000    32           640,000 − 700,000 = −£60,000
```

គ្លីនិកបន្ថែមទទួលបាន QALY ច្រើនបំផុត ប៉ុន្តែបំផ្លាញតម្លៃនៅកម្រិតកំណត់នេះ (NMB < 0)។ App + coaching ឈ្នះ។ សូមកត់សម្គាល់ថា NMB អនុញ្ញាតឱ្យអ្នក *តម្រៀបទាំងបីក្នុងពេលតែមួយ* — ICER ជាគូនឹងត្រូវការនីតិវិធីព្រំដែនក្នុង [ការឈ្នះដាច់ និងព្រំដែនប្រសិទ្ធភាព](../ភាពលេចធ្លោ-និងព្រំដែនប្រសិទ្ធភាព/) ហើយទទួលបានចម្លើយដូចគ្នា។

ទិដ្ឋភាព NHB របស់អ្នកឈ្នះ៖ 30 − 400,000/20,000 = 30 − 20 = **10 QALY សុទ្ធ** — សុខភាពដែលទទួលបានលើសពីអ្វីដែលប្រាក់ដូចគ្នានឹងផលិតនៅកន្លែងផ្សេង។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

`(hours saved × loaded hourly rate) − tool cost` — ករណីអាជីវកម្មឧបករណ៍ប្រចាំថ្ងៃ — ពិតជាការគណនា NMB ដែល λ = ថ្លៃដើមវិស្វករផ្ទុក។ ការដំឡើងពីរដែលសេដ្ឋកិច្ចសុខភាពបន្ថែម៖

- **ធ្វើឱ្យ λ ជាអថេរ មិនមែនថេរ។** គូស NMB ធៀបនឹង λ ("តម្លៃនៃម៉ោងវិស្វករ") ហើយបង្ហាញកន្លែងដែលការសម្រេចចិត្តត្រឡប់; អ្នកពាក់ព័ន្ធផ្សេងគ្នាអាចអនុវត្តការវាយតម្លៃផ្ទាល់ខ្លួនដោយមិនធ្វើគណិតវិទ្យារបស់អ្នកឡើងវិញ។
- **ការគិត NHB**: "វេទិកានេះសន្សំ 5,000 ម៉ោងវិស្វករ ប៉ុន្តែប្រើថវិកាដែលអាចទិញសមត្ថភាពអ្នកម៉ៅការ 3,000 ម៉ោង — សុទ្ធ 2,000 ម៉ោង" បង្ខំការប្រៀបធៀបថ្លៃដើមឱកាសជាឯកតាសមត្ថភាព។ សូមមើល [ថ្លៃដើមឱកាស](../ថ្លៃដើមឱកាស/)។

## កំហុសដែលត្រូវជៀសវាង

- **លាក់កម្រិតកំណត់**: NMB គ្មានន័យបើមិនបញ្ជាក់ λ; រាយការណ៍ NMB នៅ £20k និង £30k ឬគូសខ្សែកោង។
- **ការប្រើ NMB លាងសម្អាតផលតូចតាច**: ប្រជាជនធំគុណផលតូចតាចក្នុងមនុស្សម្នាក់ អាចផលិត NMB ធំ — រាយការណ៍ផលក្នុងមនុស្សម្នាក់ជាមួយគ្នា។
- **ភ្លេចថា NMB ទទួលមរតកភាពមិនប្រាកដប្រជាទាំងអស់** ក្នុង ΔC និង ΔE — ផ្គូផ្គងជាមួយ[ការវិភាគភាពរសើបប្រូបាប៊ីលីស្ទិក](../ការវិភាគភាពរសើបប្រូបាប៊ីលីស្ទិក/)។
