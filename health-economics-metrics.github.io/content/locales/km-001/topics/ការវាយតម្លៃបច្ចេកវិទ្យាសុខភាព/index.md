# ការវាយតម្លៃបច្ចេកវិទ្យាសុខភាព (HTA)

HTA គឺជាដំណើរការផ្លូវការ និងស្ថាប័នដែលប្រព័ន្ធសុខាភិបាលសម្រេចថាតើបច្ចេកវិទ្យា — ថ្នាំ ឧបករណ៍ ឬកម្មវិធី — មានតម្លៃបង់ប្រាក់ឬអត់។ វារួមបញ្ចូលភស្តុតាងប្រសិទ្ធភាពគ្លីនិកជាមួយការវាយតម្លៃសេដ្ឋកិច្ចក្រោមវិធីសាស្ត្រដែលបានបោះពុម្ព និងតម្រូវ។

## ហេតុអ្វីបានជាសំខាន់

ប្រសិនបើអ្នកលក់ទៅសេវាសុខាភិបាលជាតិ ស្ថាប័ន HTA អាចសម្រេចការចូលទីផ្សាររបស់អ្នកព្យញ្ជនៈ។ ការស្គាល់ដំណើរការមូលដ្ឋានគឺការស្គាល់អ្នកគ្រប់គ្រងតម្លៃពិតរបស់អ្នក៖

- **NICE (អង់គ្លេស)**៖ ការវាយតម្លៃតាមច្បាប់ក្រោម *ករណីយោង* កំណត់ — QALYs ពី [EQ-5D](../eq-5d/) [ទស្សនៈ](../ទស្សនៈនៃការវិភាគ/) NHS+PSS [ការបញ្ចុះតម្លៃ](../ការបញ្ចុះតម្លៃ-និងចំណូលចិត្តពេលវេលា/) 3.5% តម្រូវ [PSA](../ការវិភាគភាពរសើបប្រូបាប៊ីលីស្ទិក/) — វិនិច្ឆ័យធៀបនឹង £20k–£30k/QALY ជាមួយ[ការកែប្រែភាពធ្ងន់ធ្ងរ](../ការខ្វះខាត-qaly-និងកត្តាកែតម្រូវភាពធ្ងន់ធ្ងរ/); បច្ចេកវិទ្យាឯកទេសខ្ពស់ដល់ £100k+ ជាមួយការថ្លឹង។
- **ICER (សហរដ្ឋអាមេរិក មិនមែនរដ្ឋាភិបាល)**៖ របាយការណ៍ភស្តុតាងជាមួយ *ស្តង់ដារតម្លៃអត្ថប្រយោជន៍សុខភាព* — តម្លៃដែលផលិតផលនឹងមានប្រសិទ្ធភាពថ្លៃដើមនៅ $100k–$150k ក្នុងមួយ QALY/evLYG — ប្រើជាអំណាចចរចា; បូក "ការជូនដំណឹងសមត្ថភាពទិញបាន" ផលប៉ះពាល់ថវិកា។
- **កាណាដា (CADTH → CDA-AMC)**៖ ការពិនិត្យសងប្រាក់នៅ ≈CAD$50k/QALY; ជាប្រវត្តិសាស្ត្របានស្នើកាត់បន្ថយតម្លៃក្នុង ~95% នៃការដាក់ពាក្យ។

## គណិតវិទ្យា

អំណាចរបស់ HTA មិនមែនជារូបមន្តទេ ប៉ុន្តែជា **វិធីសាស្ត្រតម្រូវ**៖ រាល់ការដាក់ពាក្យគណនា [ICER](../សមាមាត្រប្រសិទ្ធភាពថ្លៃដើមបន្ថែម/) ដូចគ្នាក្រោមច្បាប់ករណីយោងដូចគ្នា ដូច្នេះលទ្ធផលអាចប្រៀបធៀបបានឆ្លងផលិតផល និងឆ្នាំ។ ករណីយោងកំណត់រង្វាស់លទ្ធផល ឧបករណ៍ឧបយោគ ទស្សនៈ ការជ្រើសអ្នកប្រៀបធៀប អត្រាបញ្ចុះតម្លៃ ជើងមេឃពេលវេលា និងការវិភាគភាពមិនប្រាកដប្រជា — លុបរាល់កម្រិតសេរីភាពដែលអ្នកឧបត្ថម្ភអាចលេងល្បិច។

## ឧទាហរណ៍ដែលបានគណនា

ការព្យាបាលឌីជីថលដាក់ពាក្យទៅការវាយតម្លៃបែប NICE៖

```
Model: ΔC = +£450/patient, ΔE = +0.03 QALYs → ICER = £15,000/QALY ✓ under £20k
Reference-case checks:
  utilities from EQ-5D-5L with UK value set              ✓
  comparator = current care pathway (not "no treatment") ✓
  PSA: 71% probability cost-effective at £20k            ✓ (reported)
  severity modifier: shortfall below ×1.2 bounds         — none claimed
Recommendation: routine commissioning, with real-world data collection.
```

ការវិភាគដែលអ្នកឧបត្ថម្ភពេញចិត្តផ្ទាល់ខ្លួនបង្ហាញ £9,000/QALY; ករណីយោងរុញវាទៅ £15,000 ដោយបង្ខំអ្នកប្រៀបធៀបស្មោះត្រង់។ គម្លាតនោះគឺជា *មូលហេតុ* ដែលករណីយោងមាន។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

វត្ថុដែលអាចផ្ទេរបានគឺ **ករណីយោងផ្ទៃក្នុង**៖ វិធីសាស្ត្រតម្រូវមួយសម្រាប់រាល់ករណីអាជីវកម្មឧបករណ៍/វេទិកា — អ្នកប្រៀបធៀបដែលបានប្រកាស ថ្លៃដើមឯកតាស្តង់ដារ (សូមមើល[តារាងតម្លៃជាតិ និងថ្លៃដើមឯកតា](../តម្លៃសេវាជាតិ-និងថ្លៃដើមឯកតា/)សម្រាប់គំរូ) អត្រាបញ្ចុះតម្លៃថេរ ការវិភាគភាពប្រកាន់អារម្មណ៍តម្រូវ គំរូស្តង់ដារ។ "AMCP-dossier សម្រាប់ឧបករណ៍" ដាក់ជូនក្រុមប្រឹក្សាវេទិកាធ្វើឱ្យសំណើអាចប្រៀបធៀបបាន និងការលេងល្បិចអាចមើលឃើញ ដូច HTA ធ្វើសម្រាប់វេជ្ជសាស្ត្រ។ ចាប់ផ្តើមតូចជាង NICE៖ គំរូពីរទំព័របូកបញ្ជីតម្លៃដែលបានបោះពុម្ពប្រសើរជាងគ្មានស្តង់ដារ។

សម្រាប់របៀបដែលម៉ូដែល HTA ច្រើនវដ្តត្រូវបានក្លែងធ្វើពិតប្រាកដតាមក្រុម-ទៅតាមវដ្ត សូមមើល[ការក្លែងធ្វើក្រុម Markov](../ការក្លែងធ្វើក្រុម-markov/)។

## កំហុសដែលត្រូវជៀសវាង

- **ចាត់ទុក HTA ជាទម្រង់ភាពក្រោយការអនុម័តតាមបទប្បញ្ញត្តិ** — ការអនុម័ត CE/UKCA/FDA ប្រាប់ថាផលិតផលមានសុវត្ថិភាព; HTA សម្រេចថាតើវា *មានតម្លៃទិញ*។ ឧបសគ្គខុសគ្នា ភស្តុតាងខុសគ្នា។
- **ការសាងសង់ម៉ូដែលសេដ្ឋកិច្ចក្រោយការសាកល្បង** — ការបង្កើតភស្តុតាងគួររចនាថយក្រោយពីតម្រូវការរបស់ករណីយោង។
- **ការមិនយកចិត្តទុកដាក់ចំពោះភាពខុសគ្នាយុត្តាធិការ**៖ ICER ដែលអាចផ្តល់មូលនិធិក្នុងសហរដ្ឋអាមេរិកនៅ $120k/QALY បរាជ័យ NICE នៅ £30k; រៀបចំផែនការភស្តុតាង និងតម្លៃតាមទីផ្សារ។
