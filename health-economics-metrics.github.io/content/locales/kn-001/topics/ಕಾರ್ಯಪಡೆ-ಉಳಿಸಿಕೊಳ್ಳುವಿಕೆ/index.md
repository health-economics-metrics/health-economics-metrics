# ಕಾರ್ಯಪಡೆ ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ

ಕಾರ್ಯಪಡೆ ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ ಅರ್ಥಶಾಸ್ತ್ರ ಸಿಬ್ಬಂದಿ ವಹಿವಾಟು ಆರೋಗ್ಯ ವ್ಯವಸ್ಥೆಗೆ ಏನು ವೆಚ್ಚ ಮಾಡುತ್ತದೆ — ನೇಮಕಾತಿ, ಆನ್‌ಬೋರ್ಡಿಂಗ್, ಖಾಲಿ ಹುದ್ದೆ ಕವರ್ — ಮತ್ತು ಆದ್ದರಿಂದ ಆಡಳಿತಾತ್ಮಕ ದಣಿವನ್ನು ಕಡಿಮೆ ಮಾಡುವ ಸಾಫ್ಟ್‌ವೇರ್ ಎಷ್ಟು ಮೌಲ್ಯದ್ದು ಎಂದು ಪರಿಮಾಣೀಕರಿಸುತ್ತದೆ. ಪುನರಾವರ್ತಿತ ಆಡಳಿತಾತ್ಮಕ ದತ್ತಾಂಶ ಕಾರ್ಯಗಳಿಂದ ಉಂಟಾಗುವ ದಣಿವು NHSನಲ್ಲಿ ಸಿಬ್ಬಂದಿ ವಹಿವಾಟು ಮತ್ತು ಅನಾರೋಗ್ಯ ಗೈರುಹಾಜರಿಯ ಪ್ರಾಥಮಿಕ ಚಾಲಕ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ವೈದ್ಯ ಬಿಟ್ಟುಹೋದಾಗ, ಟ್ರಸ್ಟ್ ಮೂರು ಬಾರಿ ಪಾವತಿಸುತ್ತದೆ: ಬದಲಿ ನೇಮಕಕ್ಕೆ (ಜಾಹೀರಾತು, ಏಜೆನ್ಸಿ ಶುಲ್ಕ, ಸಂದರ್ಶನಗಳು), ಅವರನ್ನು ಆನ್‌ಬೋರ್ಡ್ ಮಾಡಲು (ಕಡಿಮೆ ಉತ್ಪಾದಕತೆಯ ತಿಂಗಳುಗಳು, ಮೇಲ್ವಿಚಾರಣೆ), ಮತ್ತು ಈ ನಡುವೆ ಖಾಲಿ ಹುದ್ದೆಯನ್ನು ತುಂಬಲು — ಸಾಮಾನ್ಯವಾಗಿ ಮೂಲ Agenda for Change ದರಗಳ 2–3× ಏಜೆನ್ಸಿ ಅಥವಾ ಲೊಕಮ್ ಸಿಬ್ಬಂದಿಯೊಂದಿಗೆ ([ತಪ್ಪಿಸಬಹುದಾದ ಹೊರಗುತ್ತಿಗೆ ವೆಚ್ಚಗಳು](../ತಪ್ಪಿಸಬಹುದಾದ-ಹೊರಗುತ್ತಿಗೆ-ವೆಚ್ಚಗಳು/) ಮತ್ತು [ಕಠಿಣ ನಗದು-ಬಿಡುಗಡೆ ಉಳಿತಾಯ](../ಕಠಿಣ-ನಗದು-ಬಿಡುಗಡೆ-ಉಳಿತಾಯ/) ನೋಡಿ). ವಹಿವಾಟು ವೆಚ್ಚಗಳು ನಿಜ ನಗದಾದ್ದರಿಂದ, ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ ಸುಧಾರಣೆಗಳು ಹಣಕಾಸು ನಿರ್ದೇಶಕ ಬ್ಯಾಂಕ್ ಮಾಡಬಹುದಾದ ಕೆಲವೇ ಕಾರ್ಯಪಡೆ ಲಾಭಗಳಲ್ಲಿ ಸೇರಿವೆ. ಆಡಳಿತಾತ್ಮಕ ಘರ್ಷಣೆ ಕ್ಲಿನಿಕಲ್ ದಣಿವಿನ ಉಲ್ಲೇಖಿತ ಅಗ್ರ ಚಾಲಕರಲ್ಲಿ ಸ್ಥಿರವಾಗಿದೆ, ಇದು ಅದನ್ನು ಸಾಫ್ಟ್‌ವೇರ್-ಪರಿಹರಿಸಬಹುದಾದ ವೆಚ್ಚವಾಗಿಸುತ್ತದೆ.

## ಗಣಿತ

```
Cost per leaver = recruitment cost + onboarding/productivity-ramp cost
                + vacancy cover premium × vacancy duration

Annual turnover cost = headcount × turnover rate × cost per leaver

Value of software  = headcount × Δturnover rate × cost per leaver
                   + sickness-absence reduction × cover cost/day
```

ಕಾರಣ ಸರಪಳಿಯಲ್ಲಿ ಎರಡು ಅಂದಾಜಿಸಿದ ಕೊಂಡಿಗಳಿವೆ — ಸಾಫ್ಟ್‌ವೇರ್ → ದಣಿವು/ಘರ್ಷಣೆ, ಮತ್ತು ದಣಿವು → ವಹಿವಾಟು — ಆದ್ದರಿಂದ ಎರಡಕ್ಕೂ ಸಾಕ್ಷ್ಯ ನೀಡಿ (ಮೊದಲು/ನಂತರ ಸಿಬ್ಬಂದಿ ಸಮೀಕ್ಷೆಗಳು; ಪ್ರಕಟಿತ ದಣಿವು-ಕ್ಷೀಣತೆ ಸಂಬಂಧಗಳು) ಮತ್ತು ಹೇಳಿದ Δ ಅನ್ನು ಸಾಧಾರಣವಾಗಿಡಿ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಒಂದು ಟ್ರಸ್ಟ್ 1,200 ದಾದಿಯರನ್ನು ನೇಮಿಸಿಕೊಂಡಿದೆ; ವಹಿವಾಟು ವರ್ಷಕ್ಕೆ 11%. ಬಿಟ್ಟುಹೋಗುವವರ ಪ್ರತಿ ವೆಚ್ಚ:

```
Recruitment ≈ £4,500;  onboarding/ramp ≈ £6,000
Vacancy cover: 4 months × 0.6 WTE covered by agency premium ≈ £8,000
Total ≈ £18,500 per leaver
Baseline turnover cost = 1,200 × 0.11 × 18,500 ≈ £2.44M/year
```

ದಾಖಲೀಕರಣ-ಹೊರೆ ಸಾಫ್ಟ್‌ವೇರ್ (ಸ್ವಯಂ-ತುಂಬಿದ ಮೌಲ್ಯಮಾಪನಗಳು, ಏಕ ಸೈನ್-ಆನ್, ಡಿಕ್ಟೇಶನ್) ವಹಿವಾಟನ್ನು 1 ಶೇಕಡಾ-ಅಂಕ ಚಲಿಸುವುದು ಸಮಂಜಸ:

```
Value = 1,200 × 0.01 × 18,500 = £222,000/year cash-relevant
```

ಸಿಬ್ಬಂದಿ-ಸಮೀಕ್ಷೆ ಘರ್ಷಣೆ ಅಂಕಗಳಿಂದ ಬೆಂಬಲಿತ 1-ಅಂಕ ಹಕ್ಕು ನಂಬಲರ್ಹ; 4-ಅಂಕ ಹಕ್ಕು ಅಲ್ಲ. Δವಹಿವಾಟಿನ ಮೇಲೆ [ಟೊರ್ನೇಡೊ](../ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/) ನಡೆಸಿ: ಅದು ಮಾದರಿಯ ಉಳಿದೆಲ್ಲದರ ಮೇಲೆ ಪ್ರಾಬಲ್ಯ ಹೊಂದುತ್ತದೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಎಂಜಿನಿಯರಿಂಗ್ ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ ಗಣಿತ ಅದೇ ಮತ್ತು ಕಡಿಮೆ-ದಾಖಲಾಗಿದೆ: ಹಿರಿಯ ಎಂಜಿನಿಯರ್ ಅನ್ನು ಬದಲಿಸಲು 6–12 ತಿಂಗಳ ಲೋಡ್ ಮಾಡಿದ ಸಂಬಳ ವೆಚ್ಚ (ನೇಮಕಾತಿ, ಕಲಿಕೆ, ಕಳೆದುಹೋದ ಸಂದರ್ಭ), ಆದ್ದರಿಂದ 15% ಕ್ಷೀಣತೆಯಲ್ಲಿರುವ 200-ವ್ಯಕ್ತಿಯ ಸಂಸ್ಥೆ ವಾರ್ಷಿಕವಾಗಿ ಬಿಟ್ಟುಹೋಗುವಿಕೆಯ ಮೇಲೆ ಲಕ್ಷಾಂತರ ಸುಡುತ್ತದೆ. ಡೆವಲಪರ್-ಅನುಭವ ಹೂಡಿಕೆ ([SPACE ಮತ್ತು DevEx](../space-ಮತ್ತು-devex/)) ದಾದಿಯರ ದಾಖಲೀಕರಣ-ಹೊರೆ ನಿವಾರಣೆಯ ನೇರ ಸಮಾನ — ಮತ್ತು ಅದೇ ರೀತಿ ಸಮರ್ಥಿಸಬೇಕು: ಅಳೆದ ಘರ್ಷಣೆ ಅಂಕಗಳು, ಕ್ಷೀಣತೆಯ ಮೇಲೆ ಸಾಧಾರಣ ಹೇಳಿದ ಪರಿಣಾಮ, ನಿಮ್ಮ ಸ್ವಂತ ಹಣಕಾಸು ದತ್ತಾಂಶದಿಂದ ಪ್ರತಿ ಬಿಟ್ಟುಹೋಗುವವರ ವೆಚ್ಚ. ನಕಲು ಮಾಡಬೇಕಾದ ಆರೋಗ್ಯ-ಅರ್ಥಶಾಸ್ತ್ರ ಶಿಸ್ತು ಜನರು ಸಾಧನಗಳಿಗಾಗಿ "ನಿಜವಾಗಿ" ಬಿಡುತ್ತಾರೆಯೇ ಎಂದು ವಾದಿಸುವ ಬದಲು *ಬಿಟ್ಟುಹೋಗುವವರಿಗೆ ಪ್ರಾಮಾಣಿಕವಾಗಿ ವೆಚ್ಚ ಲೆಕ್ಕಿಸುವುದು*.

## ಎಡವಟ್ಟುಗಳು

- **ವಹಿವಾಟು ಚಲನೆಯನ್ನೆಲ್ಲ ನಿಮ್ಮ ಮಧ್ಯಸ್ಥಿಕೆಗೆ ಆರೋಪಿಸುವುದು** — ಕಾರ್ಮಿಕ ಮಾರುಕಟ್ಟೆಗಳು ಸಾಫ್ಟ್‌ವೇರ್‌ಗಿಂತ ಬಹಳ ಹೆಚ್ಚು ವಹಿವಾಟನ್ನು ಚಲಿಸುತ್ತವೆ; ನಿಯಂತ್ರಣ ಗುಂಪುಗಳನ್ನು ಅಥವಾ ಕನಿಷ್ಠ ವಲಯ ಪ್ರವೃತ್ತಿ ಹೊಂದಾಣಿಕೆಯನ್ನು ಬಳಸಿ.
- **ದ್ವಿಗುಣ ಎಣಿಕೆ**: ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ ಉಳಿತಾಯ ಮತ್ತು ಏಜೆನ್ಸಿ-ಖರ್ಚು ಉಳಿತಾಯ ಅತಿಕ್ರಮಿಸುತ್ತವೆ (ಖಾಲಿ ಹುದ್ದೆ ಕವರ್ *ಅದೇ* ಏಜೆನ್ಸಿ ಖರ್ಚು); ಸಾಲುಗಳನ್ನು ಹೊಂದಿಸಿ.
- **ವಿಳಂಬದ ನಿರ್ಲಕ್ಷ್ಯ**: ದಣಿವು-ಚಾಲಿತ ಕ್ಷೀಣತೆ ಘರ್ಷಣೆ ಬದಲಾವಣೆಗಳಿಗೆ 1–2 ವರ್ಷಗಳಲ್ಲಿ ಪ್ರತಿಕ್ರಿಯಿಸುತ್ತದೆ, ಮುಂದಿನ ತ್ರೈಮಾಸಿಕದಲ್ಲಲ್ಲ.
