# ಸಾಮಾಜಿಕ ಹೂಡಿಕೆಯ ಮೇಲಿನ ಪ್ರತಿಫಲ (SROI)

SROI [ROI](../ಹೂಡಿಕೆಯ-ಮೇಲಿನ-ಪ್ರತಿಫಲ/)ಯನ್ನು ಮಾರುಕಟ್ಟೆಗಳು ಬೆಲೆ ಕಟ್ಟದ ಫಲಿತಾಂಶಗಳಿಗೆ — ಯೋಗಕ್ಷೇಮ, ಸಾಮಾಜಿಕ ಸಂಪರ್ಕ, ಪರಿಸರ ಪರಿಣಾಮ — ವಿಸ್ತರಿಸುತ್ತದೆ, ಹಣಕಾಸು ಪ್ರತಿನಿಧಿಗಳೊಂದಿಗೆ ಅವನ್ನು ಹಣದ ರೂಪಕ್ಕೆ ಪರಿವರ್ತಿಸಿ, ಬಾಧಿತ *ಎಲ್ಲ* ಪಾಲುದಾರರಿಗಾಗಿ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಆರೋಗ್ಯ ಮತ್ತು ಸಮುದಾಯ ಮಧ್ಯಸ್ಥಿಕೆಗಳು ಉತ್ಪಾದಿಸುವ ಬಹುಪಾಲು ಬಜೆಟ್ ಸಾಲನ್ನು ಎಂದಿಗೂ ಮುಟ್ಟುವುದಿಲ್ಲ: ಕಡಿಮೆಯಾದ ಒಂಟಿತನ, ಆರೈಕೆದಾರರ ಉಪಶಮನ, ಉದ್ಯೋಗ ಲಾಭಗಳು, ಘನತೆ. ಸೋಶಿಯಲ್ ವ್ಯಾಲ್ಯೂ ಇಂಟರ್ನ್ಯಾಷನಲ್‌ನ ಏಳು ತತ್ವಗಳಿಂದ ನಿಯಂತ್ರಿತವಾದ SROI (ಪಾಲುದಾರರನ್ನು ಒಳಗೊಳ್ಳಿ, ಮುಖ್ಯವಾದುದಕ್ಕೆ ಮೌಲ್ಯ ಕೊಡಿ, ಅತಿ-ಹೇಳಿಕೆ ಮಾಡಬೇಡಿ, ಪಾರದರ್ಶಕರಾಗಿರಿ, ಪರಿಶೀಲಿಸಿ…) "ಹೂಡಿದ ಪ್ರತಿ £1ಕ್ಕೆ £3.20 ಸಾಮಾಜಿಕ ಮೌಲ್ಯ" ಎಂಬಂತಹ ಹೇಳಿಕೆಗಳನ್ನು ಉತ್ಪಾದಿಸುತ್ತದೆ. ಯುಕೆ ಸಾರ್ವಜನಿಕ ಖರೀದಿಯ ಸಾಮಾಜಿಕ-ಮೌಲ್ಯ ಅಗತ್ಯಗಳು SROI-ಶೈಲಿಯ ಸಾಕ್ಷ್ಯವನ್ನು ವಾಣಿಜ್ಯಿಕವಾಗಿ ಪ್ರಸ್ತುತವಾಗಿಸುತ್ತವೆ: ಸಾರ್ವಜನಿಕ ಗುತ್ತಿಗೆಗಳಿಗೆ (NHS ಸೇರಿ) ಬಿಡ್‌ಗಳು ಪ್ರದರ್ಶಿತ ಸಾಮಾಜಿಕ ಮೌಲ್ಯಕ್ಕೆ ಅಂಕ ಪಡೆಯುತ್ತವೆ.

## ಗಣಿತ

```
SROI ratio = PV(monetized social outcomes) / PV(investment)

For each outcome:
  value = quantity × financial proxy × attribution × (1 − deadweight) × (1 − displacement)

deadweight   = would have happened anyway
attribution  = share caused by others
displacement = benefit moved from elsewhere rather than created
drop-off     = decay of the outcome over years
```

ಹೊಂದಾಣಿಕೆ ಅಂಶಗಳು ವಿಧಾನದ ಪ್ರಾಮಾಣಿಕತೆ: ಅವಿಲ್ಲದೆ, SROI ಕರೆನ್ಸಿ ಚಿಹ್ನೆಯಿರುವ ಕಾಲ್ಪನಿಕ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಒಂಟಿಯಾದ ಹಿರಿಯರನ್ನು ಸ್ವಯಂಸೇವಕರೊಂದಿಗೆ ಸಂಪರ್ಕಿಸುವ ಸ್ನೇಹ ಆ್ಯಪ್; ಕಾರ್ಯಕ್ರಮ ವೆಚ್ಚ ವರ್ಷಕ್ಕೆ £200,000; 1,500 ಸಕ್ರಿಯ ಜೋಡಿಗಳು.

```
Outcome: reduced loneliness for 1,500 people
  proxy: wellbeing valuation of "relief from loneliness" ≈ £1,800/person/yr
  deadweight 25% (some would have found connection anyway)
  attribution 80% (some credit to other services)

Value = 1,500 × 1,800 × 0.80 × 0.75 = £1,620,000

Outcome: reduced GP visits, 1,500 × 1.2 visits × £42 = £75,600 (payer-real)

SROI = (1,620,000 + 75,600) / 200,000 ≈ 8.5 : 1
```

ಅನುಪಾತ 96% ಪ್ರತಿನಿಧಿ-ಮೌಲ್ಯದ ಯೋಗಕ್ಷೇಮ ಮತ್ತು 4% ನಿಜವಾದ ನಗದು ಎಂಬುದನ್ನು ಗಮನಿಸಿ. ಅದು ನ್ಯಾಯಸಮ್ಮತ SROI — ಆದರೆ ಅದನ್ನು ಸಾಮಾಜಿಕ ಮೌಲ್ಯವಾಗಿ ಪ್ರಸ್ತುತಪಡಿಸಬೇಕು, £1.7M ಬ್ಯಾಂಕ್ ಮಾಡಬಹುದು ಎಂದು ಸೂಚಿಸಲು ಎಂದಿಗೂ ಬಿಡಬಾರದು.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಫಲಾನುಭವಿಗಳು ಪಾವತಿಸುವ ತಂಡದ ಹೊರಗಿರುವ ಎಂಜಿನಿಯರಿಂಗ್ ಕೆಲಸಕ್ಕೆ SROI ಪ್ರಾಮಾಣಿಕ ಚೌಕಟ್ಟು: ಓಪನ್-ಸೋರ್ಸ್ ನಿರ್ವಹಣೆ, ಪ್ರವೇಶಾರ್ಹತೆ ಸುಧಾರಣೆಗಳು, ಇತರ ತಂಡಗಳು ಬಳಸುವ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಕೆಲಸ, ಡೆವಲಪರ್-ಸಮುದಾಯ ಹೂಡಿಕೆ. ವರ್ಗಾವಣೆಯಾಗುವ ಕಾರ್ಯವಿಧಾನ: ಎಲ್ಲ ಪಾಲುದಾರರನ್ನು ಗುರುತಿಸಿ, ಹೇಳಿದ ಪ್ರತಿನಿಧಿಗಳೊಂದಿಗೆ ಹಣದ ರೂಪಕ್ಕೆ ಪರಿವರ್ತಿಸಿ, ಮತ್ತು ಡೆಡ್‌ವೇಟ್/ಆರೋಪಣೆ ರಿಯಾಯಿತಿಗಳನ್ನು ಅನ್ವಯಿಸಿ (ಆ OSS ಸರಿಪಡಿಸುವಿಕೆ ಹೇಗಿದ್ದರೂ ಆಗುತ್ತಿತ್ತೇ? ಲಾಭದ ಎಷ್ಟು ಭಾಗ ನಿಮ್ಮ ಕೆಲಸ vs ಪರಿಸರ ವ್ಯವಸ್ಥೆಯದು?). *ನಿಮ್ಮ ಸ್ವಂತ ಪರಿಣಾಮ ಹೇಳಿಕೆಗಳಿಗೆ ರಿಯಾಯಿತಿ ನೀಡುವ* ಶಿಸ್ತು SROI ಅನ್ನು ಮಾರ್ಕೆಟಿಂಗ್ ಸಂಖ್ಯೆಯಿಂದ ಬೇರ್ಪಡಿಸುತ್ತದೆ.

## ಎಡವಟ್ಟುಗಳು

- **ಪ್ರತಿನಿಧಿ ಶಾಪಿಂಗ್**: ಲಭ್ಯವಿರುವ ಅತ್ಯಂತ ಉದಾರ ಯೋಗಕ್ಷೇಮ ಮೌಲ್ಯಮಾಪನವನ್ನು ಆರಿಸುವುದು.
- **ಡೆಡ್‌ವೇಟ್/ಆರೋಪಣೆ ಬಿಡುವುದು** — ಅತ್ಯಂತ ಸಾಮಾನ್ಯ ಉಬ್ಬಿಸುವಿಕೆ, ಆಗಾಗ ಅನುಪಾತವನ್ನು ದ್ವಿಗುಣಗೊಳಿಸುತ್ತದೆ.
- **ಅಧ್ಯಯನಗಳಾದ್ಯಂತ ಅನುಪಾತ ಹೋಲಿಕೆ**: SROI ಅನುಪಾತಗಳು ವಿಧಾನ-ಸಂವೇದನಾಶೀಲ; ಸ್ಥಿರ ಚೌಕಟ್ಟಿನೊಳಗೆ ಮಾತ್ರ ಹೋಲಿಸಿ.
- ಬಜೆಟ್ ಹೊಂದಿರುವವರಿಗೆ **ಸಾಮಾಜಿಕ ಮೌಲ್ಯವನ್ನು ನಗದಾಗಿಸಬಹುದಾದ ಉಳಿತಾಯವಾಗಿ ಪ್ರಸ್ತುತಪಡಿಸುವುದು**.
