# ಗುಣಮಟ್ಟ-ಹೊಂದಾಣಿಕೆಯ ಜೀವ ವರ್ಷ (QALY)

QALY ಎಂದರೆ ಪರಿಪೂರ್ಣ ಆರೋಗ್ಯದಲ್ಲಿ ಬದುಕಿದ ಒಂದು ವರ್ಷ. ಇದು ಜನರು *ಎಷ್ಟು ಕಾಲ* ಬದುಕುತ್ತಾರೆ ಮತ್ತು *ಎಷ್ಟು ಚೆನ್ನಾಗಿ* ಬದುಕುತ್ತಾರೆ ಎಂಬುದನ್ನು ಸಂಯೋಜಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಕೆಟ್ಟ ಆರೋಗ್ಯದ ಒಂದು ವರ್ಷ ಒಂದು QALYಗಿಂತ ಕಡಿಮೆ ಎಂದು ಲೆಕ್ಕಕ್ಕೆ ಬರುತ್ತದೆ — ಸಂಪೂರ್ಣ ಭಿನ್ನ ಆರೋಗ್ಯ ಮಧ್ಯಸ್ಥಿಕೆಗಳನ್ನು ಒಂದೇ ಮಾಪಕದಲ್ಲಿ ಹೋಲಿಸಬಲ್ಲವನ್ನಾಗಿ ಮಾಡುತ್ತದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

QALY ಆರೋಗ್ಯ ತಂತ್ರಜ್ಞಾನ ಮೌಲ್ಯಮಾಪನದ ಸಾಮಾನ್ಯ ಕರೆನ್ಸಿ. NICE (ಇಂಗ್ಲೆಂಡ್) ಆರೋಗ್ಯ ಲಾಭಗಳನ್ನು **ಪ್ರತಿ QALYಗೆ £20,000–£30,000** ದರದಲ್ಲಿ ಮೌಲ್ಯೀಕರಿಸುತ್ತದೆ: ಆ ಮಿತಿಗಿಂತ ಅಗ್ಗವಾಗಿ QALYಗಳನ್ನು ಖರೀದಿಸುವ ಮಧ್ಯಸ್ಥಿಕೆಯನ್ನು ಸಾಮಾನ್ಯವಾಗಿ ಶಿಫಾರಸು ಮಾಡಲಾಗುತ್ತದೆ; ದುಬಾರಿಯಾಗಿ ಖರೀದಿಸುವುದನ್ನು ಸಾಮಾನ್ಯವಾಗಿ ತಿರಸ್ಕರಿಸಲಾಗುತ್ತದೆ. ಈ ಒಂದು ಸಂಖ್ಯೆಯ ಮೂಲಕವೇ ರಾಷ್ಟ್ರೀಯ ಆರೋಗ್ಯ ಸೇವೆಯು ಕ್ಯಾನ್ಸರ್ ಔಷಧ, ಸೊಂಟ ಬದಲಿ ಮತ್ತು ಟ್ರಯಾಜ್ ಆ್ಯಪ್ ಅನ್ನು ಒಂದೇ ಅಕ್ಷದಲ್ಲಿ ಹೋಲಿಸುತ್ತದೆ. ನಿಮ್ಮ ಸಾಫ್ಟ್‌ವೇರ್ ಕ್ಷೀಣತೆಯನ್ನು ತಡೆಯುವ, ಚಿಕಿತ್ಸೆಯನ್ನು ವೇಗಗೊಳಿಸುವ ಅಥವಾ ಸುರಕ್ಷತೆಯನ್ನು ಸುಧಾರಿಸುವ ಮೂಲಕ QALYಗಳನ್ನು ನಂಬಲರ್ಹವಾಗಿ ಹೇಳಿಕೊಳ್ಳಬಲ್ಲದಾದರೆ, ಅದರ ಆರೋಗ್ಯ ಮೌಲ್ಯಕ್ಕೆ ಔಷಧದ ಅದೇ ಕರೆನ್ಸಿಯಲ್ಲಿ ಬೆಲೆ ಕಟ್ಟಬಹುದು.

## ಗಣಿತ

```
QALYs = Σ_i (duration_i × utility_i)

duration_i = years spent in health state i
utility_i  = quality weight of state i, anchored at 1 = perfect health, 0 = dead
             (negative values allowed for states worse than death)
```

ಉಪಯುಕ್ತತಾ ತೂಕಗಳು ಮಾನ್ಯತೆ ಪಡೆದ ಸಾಧನಗಳಿಂದ ಬರುತ್ತವೆ, ಹೆಚ್ಚಾಗಿ [EQ-5D](../eq-5d/). ಮಧ್ಯಸ್ಥಿಕೆಯಿಂದ QALY *ಲಾಭ* ಎಂದರೆ ಅದರೊಂದಿಗೆ ಮತ್ತು ಅದಿಲ್ಲದ QALY ಹರಿವುಗಳ ವ್ಯತ್ಯಾಸ, NICE ಉಲ್ಲೇಖ ಪ್ರಕರಣದಲ್ಲಿ ವರ್ಷಕ್ಕೆ 3.5% [ರಿಯಾಯಿತಿ](../ರಿಯಾಯಿತಿ-ಮತ್ತು-ಕಾಲ-ಆದ್ಯತೆ/) ನೀಡಲಾಗುತ್ತದೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ರೋಗಿಯೊಬ್ಬರು ಹೃದಯ ಚಿಕಿತ್ಸೆಗಾಗಿ ಉಪಯುಕ್ತತೆ 0.6 ಇರುವ ಸ್ಥಿತಿಯಲ್ಲಿ ಕಾಯುತ್ತಿದ್ದಾರೆ. ಚಿಕಿತ್ಸೆ ಅವರನ್ನು ಉಪಯುಕ್ತತೆ 0.85ಕ್ಕೆ ಮರುಸ್ಥಾಪಿಸುತ್ತದೆ.

- **ಈಗಲೇ ಚಿಕಿತ್ಸೆ**: 0.85ರಲ್ಲಿ 1 ವರ್ಷ = ಈ ವರ್ಷ 0.85 QALY.
- **6-ತಿಂಗಳ ವಿಳಂಬದ ನಂತರ ಚಿಕಿತ್ಸೆ**: 0.5 × 0.6 + 0.5 × 0.85 = 0.725 QALY.
- **ವಿಳಂಬದಿಂದ ಪ್ರತಿ ರೋಗಿಗೆ QALY ನಷ್ಟ**: 0.85 − 0.725 = **0.125 QALY**.

NICEಯ ಮಿತಿಯಲ್ಲಿ ಹಣದ ರೂಪಕ್ಕೆ: 0.125 × £20,000–£30,000 = **ಪ್ರತಿ ರೋಗಿಗೆ ಪ್ರತಿ 6-ತಿಂಗಳ ವಿಳಂಬಕ್ಕೆ £2,500–£3,750 ಆರೋಗ್ಯ ಮೌಲ್ಯ ನಷ್ಟ**. ಮಾರ್ಗವನ್ನು ವೇಗಗೊಳಿಸುವ ಸಾಫ್ಟ್‌ವೇರ್ ವರ್ಷಕ್ಕೆ 400 ರೋಗಿಗಳಿಗೆ ಆ ವಿಳಂಬವನ್ನು ತೆಗೆದುಹಾಕಿದರೆ, ಆರೋಗ್ಯ ಮೌಲ್ಯ 50 QALY ≈ **ವರ್ಷಕ್ಕೆ £1.0–£1.5 ಮಿಲಿಯನ್** — ಯಾವುದೇ ಕಾರ್ಯಾಚರಣೆಯ ಉಳಿತಾಯಗಳನ್ನು ಲೆಕ್ಕಿಸುವ ಮೊದಲೇ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

- **ವೇಗದ ಮಾರ್ಗಗಳು = ಬೇಗನೆ QALYಗಳು.** [ಚಿಕಿತ್ಸೆಗೆ ಉಲ್ಲೇಖ](../ಚಿಕಿತ್ಸೆಗೆ-ಉಲ್ಲೇಖ/)ವನ್ನು ಕಡಿಮೆ ಮಾಡುವ ಯಾವುದಾದರೂ ಕಾಯುವ-ಸಮಯದ ಅನುಪಯುಕ್ತತೆಯನ್ನು ಆರೋಗ್ಯ ಲಾಭವಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ, ಮೇಲಿನಂತೆ ಮೌಲ್ಯೀಕರಿಸಲಾಗುತ್ತದೆ.
- **ಸುರಕ್ಷತೆ = ಸಂರಕ್ಷಿತ QALYಗಳು.** ತಡೆಯಲಾದ ಔಷಧ ತಪ್ಪುಗಳು ಮತ್ತು ತಪ್ಪಿದ ರೋಗನಿರ್ಣಯಗಳು ತಪ್ಪಿಸಿದ QALY ನಷ್ಟಗಳು.
- **QALY ಮೆಟ್ರಿಕ್-ವಿನ್ಯಾಸದ ಟೆಂಪ್ಲೇಟ್ ಕೂಡ**: ಪ್ರಮಾಣ × ಗುಣಮಟ್ಟದ ಸಂಯೋಜನೆ, ಗುಣಮಟ್ಟದ ತೂಕಗಳು ಪ್ರಮಾಣೀಕೃತ ಸಾಧನದಿಂದ ಪಡೆದವು. "ಗುಣಮಟ್ಟ-ಹೊಂದಾಣಿಕೆಯ ಎಂಜಿನಿಯರ್ ವರ್ಷ" (ಸಮಯ × DevEx-ಸಮೀಕ್ಷೆ ತೂಕ) ಅದೇ ರಚನೆ — [SPACE ಮತ್ತು DevEx](../space-ಮತ್ತು-devex/) ನೋಡಿ.
- QALYಗಳನ್ನು ವ್ಯವಹಾರ ಪ್ರಕರಣಕ್ಕಾಗಿ ಹಣವಾಗಿ ಪರಿವರ್ತಿಸಲು [ನಿವ್ವಳ ಹಣಕಾಸು ಲಾಭ](../ನಿವ್ವಳ-ಹಣಕಾಸು-ಲಾಭ/) ಬಳಸಿ; ನಿರ್ಧಾರವಾಗಿ ಪರಿವರ್ತಿಸಲು [ಪಾವತಿಸಲು ಇಚ್ಛೆಯ ಮಿತಿಗಳು](../ಪಾವತಿಸಲು-ಇಚ್ಛೆಯ-ಮಿತಿಗಳು/).

## ಎಡವಟ್ಟುಗಳು

- **ಉಪಯುಕ್ತತಾ ತೂಕಗಳನ್ನು ಸೃಷ್ಟಿಸುವುದು.** ತೂಕಗಳು ಮಾನ್ಯತೆ ಪಡೆದ ಸಾಧನಗಳಿಂದ (EQ-5D) ಮತ್ತು ಪ್ರಕಟಿತ ಮೌಲ್ಯ ಗುಚ್ಛಗಳಿಂದ ಬರಬೇಕು, ಅಂತಃಪ್ರಜ್ಞೆಯಿಂದಲ್ಲ.
- **ಕಾರಣ ಮಾರ್ಗವಿಲ್ಲದೆ QALYಗಳನ್ನು ಹೇಳಿಕೊಳ್ಳುವುದು.** "ನಮ್ಮ ಆ್ಯಪ್ ಯೋಗಕ್ಷೇಮವನ್ನು ಸುಧಾರಿಸುತ್ತದೆ" QALY ಹೇಳಿಕೆಯಲ್ಲ; "ಉಪಯುಕ್ತತೆ 0.6 ಸ್ಥಿತಿಯಲ್ಲಿ X ವಾರಗಳ ಕಾಯುವಿಕೆಯನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ" ಹೌದು.
- **ದ್ವಿ-ಎಣಿಕೆ**: ತಪ್ಪಿಸಿದ ಒಂದೇ ಕ್ಷೀಣತೆಯ QALY ಲಾಭ ಮತ್ತು ವೆಚ್ಚ ಉಳಿತಾಯ ಎರಡನ್ನೂ ಹೇಳಿಕೊಳ್ಳಲು ಅವು ನಿಜವಾಗಿ ಪ್ರತ್ಯೇಕವೆಂಬ ಎಚ್ಚರಿಕೆ ಬೇಕು.
- **ಸಮಾನತೆಯ ಕುರುಡು ಸ್ಥಳಗಳು**: QALYಗಳು ಜೀವ ವಿಸ್ತರಣೆಯ ಒಂದು ವರ್ಷಕ್ಕೆ ಆರಂಭಿಕ ಉಪಯುಕ್ತತೆಯ ಆಧಾರದಲ್ಲಿ ಮೌಲ್ಯ ಕೊಡುತ್ತವೆ, ಇದು ಅಂಗವೈಕಲ್ಯವಿರುವವರಿಗೆ ಅನನುಕೂಲವಾಗಬಹುದು — ICER (ಅಮೆರಿಕ) evLYG ಅನ್ನೂ ವರದಿ ಮಾಡಲು ಇದೇ ಕಾರಣ ([ಗಳಿಸಿದ ಜೀವ ವರ್ಷಗಳು](../ಗಳಿಸಿದ-ಜೀವ-ವರ್ಷಗಳು/) ನೋಡಿ).
