# ಮಾದರಿ ಮಾಹಿತಿಯ ನಿರೀಕ್ಷಿತ ಮೌಲ್ಯ (EVSI)

EVSI ಎಂದರೆ ನಡೆಸುವ ಮೊದಲೇ *ನಿರ್ದಿಷ್ಟ ಪ್ರಸ್ತಾವಿತ ಅಧ್ಯಯನ*ದ — ನಿರ್ದಿಷ್ಟ ವಿನ್ಯಾಸ, ನಿರ್ದಿಷ್ಟ ಮಾದರಿ ಗಾತ್ರ — ಮೌಲ್ಯ; ಎಲ್ಲ ಅನಿಶ್ಚಿತತೆಯನ್ನು ಸಂಪೂರ್ಣವಾಗಿ ತೊಡೆಯುವುದಕ್ಕೆ ಬೆಲೆ ಕಟ್ಟುವ [EVPI](../ಪರಿಪೂರ್ಣ-ಮಾಹಿತಿಯ-ನಿರೀಕ್ಷಿತ-ಮೌಲ್ಯ/)ಗಿಂತ ಭಿನ್ನ. ಸಂಶೋಧನಾ ಹಣಕಾಸುದಾರರು ನಿಜವಾಗಿ ಎದುರಿಸುವ ಪ್ರಶ್ನೆಗೆ EVSI ಉತ್ತರಿಸುತ್ತದೆ: "*ಈ* ಗಾತ್ರದ *ಈ* ಪ್ರಯೋಗ ಅದರ ವೆಚ್ಚಕ್ಕೆ ಯೋಗ್ಯವೇ?"

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಯಾವುದೇ ಸಂಶೋಧನೆಯ ಮೌಲ್ಯದ ಮೇಲ್ಮಿತಿಯನ್ನು EVPI ಹೇಳುತ್ತದೆ; ನಿಮ್ಮ ಮುಂದಿರುವ ಪ್ರಯೋಗ ಆ ಮಟ್ಟವನ್ನು ದಾಟುತ್ತದೆಯೇ ಎಂದು ಅದು ಎಂದಿಗೂ ಹೇಳುವುದಿಲ್ಲ. 50-ರೋಗಿ ಪೈಲಟ್ ಮತ್ತು 500-ರೋಗಿ ನಿರ್ಣಾಯಕ ಪ್ರಯೋಗದ ನಡುವೆ ಆರಿಸುವ ರಾಷ್ಟ್ರೀಯ ಸಂಶೋಧನಾ ಹಣಕಾಸುದಾರರಿಗೆ ಸರ್ವಜ್ಞತೆಯ ಮೌಲ್ಯ ಮಾತ್ರವಲ್ಲ, *ಪ್ರತಿ ನಿರ್ದಿಷ್ಟ ವಿನ್ಯಾಸ* ಎಷ್ಟು ಮೌಲ್ಯಯುತ ಎಂಬುದು ತಿಳಿಯಬೇಕು. EVSI ಆ ಸಂಖ್ಯೆಯನ್ನು ಒದಗಿಸುತ್ತದೆ, ಮತ್ತು ಅದು ಮಾದರಿ ಗಾತ್ರದೊಂದಿಗೆ ಅಳೆಯುವುದರಿಂದ, ಊಹಿಸುವ ಬದಲು ನಿರೀಕ್ಷಿತ ನಿವ್ವಳ ಲಾಭವನ್ನು ಗರಿಷ್ಠಗೊಳಿಸುವ ಮಾದರಿ ಗಾತ್ರವನ್ನು ಹಣಕಾಸುದಾರರು ಕಂಡುಹಿಡಿಯಬಹುದು.

ಇದೇ ಕಾರಣಕ್ಕೆ EVSI ಯಾವಾಗಲೂ EVPIಗೆ ಸಮ ಅಥವಾ ಕಡಿಮೆ: ಸೀಮಿತ ಮಾದರಿ ಅನಿಶ್ಚಿತತೆಯನ್ನು ಭಾಗಶಃ ಮಾತ್ರ ಬಗೆಹರಿಸಬಲ್ಲದು, ಮತ್ತು ಪರಿಪೂರ್ಣ ಮಾಹಿತಿಗಿಂತ ಹೆಚ್ಚು ಮೌಲ್ಯಯುತವಾಗಿ ಕಾಣುವ ಅಧ್ಯಯನವು ಲೆಕ್ಕಾಚಾರ ತಪ್ಪು ಎಂಬುದರ ಸಂಕೇತ, ನಿಜವಾದ ಫಲಿತಾಂಶವಲ್ಲ.

## ಗಣಿತ

```
General:
EVSI(n) = E_data[ max_d E_θ|data[NB(d,θ)] ]  −  max_d E_θ[NB(d,θ)]
  (nested expectation: outer over possible study results, inner over the
  posterior belief about θ after seeing that result — usually estimated by
  nested Monte Carlo / Bayesian updating over probabilistic sensitivity
  analysis draws)

Closed-form normal approximation (single uncertain parameter, conjugate
normal-normal model — a standard shortcut, not exact for every model):
EVSI(n) = EVPI × n / (n + n0)

n  = proposed study's sample size
n0 = "prior-equivalent sample size" — the size of an imaginary sample that
     would carry the same information as the current prior, derived from
     the ratio of data variance to prior variance
ENBS(n) = EVSI(n) − Cost(n)
Population EVSI = per-decision EVSI × decisions affected
```

ಸಾಮಾನ್ಯ ರೂಪವು ಗೂಡುಕಟ್ಟಿದ ನಿರೀಕ್ಷೆ, ಏಕೆಂದರೆ ಅಧ್ಯಯನದ ಭವಿಷ್ಯದ ಫಲಿತಾಂಶವೇ ಅನಿಶ್ಚಿತ: ಅಧ್ಯಯನ ಉತ್ಪಾದಿಸಬಹುದಾದ ಪ್ರತಿ ಸಂಭವನೀಯ ದತ್ತಾಂಶಗುಚ್ಛದ ಮೇಲೆ ಸರಾಸರಿ ತೆಗೆಯಬೇಕು, ಮತ್ತು ಪ್ರತಿಯೊಂದಕ್ಕೂ ನವೀಕೃತ (ಪಶ್ಚಾತ್) ನಂಬಿಕೆ ನೀಡಿದ ಅತ್ಯುತ್ತಮ ನಿರ್ಧಾರವನ್ನು ಮರುಲೆಕ್ಕಿಸಬೇಕು. ಮುಚ್ಚಿದ-ರೂಪದ ಸಾಮಾನ್ಯ ಅಂದಾಜು ಆ ಗಣನಾ ವೆಚ್ಚವನ್ನು ಒಂದೇ ಅನುಪಾತಕ್ಕೆ ವಿನಿಮಯ ಮಾಡುತ್ತದೆ, ಅನಿಶ್ಚಿತ ನಿಯತಾಂಕ ಮತ್ತು ದತ್ತಾಂಶ (ಸುಮಾರು) ಸಾಮಾನ್ಯ ಮತ್ತು ಸಂಯುಗ್ಮಿಯಾಗಿದ್ದಾಗ ಮಾತ್ರ ಮಾನ್ಯ — ಅದೊಂದು ಅನುಕೂಲ, ಸಾರ್ವತ್ರಿಕ ನಿಯಮವಲ್ಲ. ಆ ಊಹೆ ಹೊಂದದಿದ್ದಾಗ ಪೂರ್ಣ ಗೂಡುಕಟ್ಟಿದ ಮಾಂಟೆ ಕಾರ್ಲೊ ಸಾರ್ವತ್ರಿಕ ವಿಧಾನ. EVSI ಅನ್ನು ಸಾಮಾನ್ಯವಾಗಿ ಅಂದಾಜಿಸುವ PSA ಮಾದರಿಗಳಿಗಾಗಿ [ಸಂಭಾವ್ಯತಾ ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ](../ಸಂಭಾವ್ಯತಾ-ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/) ನೋಡಿ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

[EVPI](../ಪರಿಪೂರ್ಣ-ಮಾಹಿತಿಯ-ನಿರೀಕ್ಷಿತ-ಮೌಲ್ಯ/) ಬಿಡಿಸಿದ ಉದಾಹರಣೆಯ ಮೇಲೆ ನಿರ್ಮಿಸುತ್ತಾ — 5,000 ವೈದ್ಯರಿಗೆ AI ದಾಖಲೆ ಸಹಾಯಕವನ್ನು ಹೊರತರುವುದು, ಅಲ್ಲಿ EVPI £1.2M ಎಂದು ಕಂಡುಬಂತು — ಅದೇ EVPI ಅನ್ನು ಇಲ್ಲಿ ಪೂರ್ಣ ಪೌಂಡ್‌ಗಳಲ್ಲಿ ವ್ಯಕ್ತಪಡಿಸಿ: **EVPI = £1,200,000**.

50 ವೈದ್ಯರ ಪ್ರಸ್ತಾವಿತ ಪೈಲಟ್ ಅಧ್ಯಯನ ಮುಂದಿದೆ. ಪೂರ್ವ ನಂಬಿಕೆಯ ಭಿನ್ನತೆ ಮತ್ತು ಪೈಲಟ್‌ನ ಮಾಪನ ನಿಖರತೆಯ ಅನುಪಾತದಿಂದ, ಪೂರ್ವ-ಸಮಾನ ಮಾದರಿ ಗಾತ್ರ `n0 = 75` ಆಗುತ್ತದೆ:

```
EVSI(50) = 1,200,000 × 50 / (50 + 75)
         = 1,200,000 × 50 / 125
         = 1,200,000 × 0.4
         = £480,000
```

ಪೈಲಟ್‌ಗೆ £120,000 ವೆಚ್ಚ:

```
ENBS = EVSI − Cost = 480,000 − 120,000 = £360,000
```

ಸ್ಪಷ್ಟವಾಗಿ ಧನಾತ್ಮಕ ENBS: ಪೈಲಟ್‌ಗೆ ಹಣ ನೀಡಿ. ಅದೇ ಖರೀದಿ ನಿರ್ಧಾರ 3 ಇದೇ ರೀತಿಯ ಪ್ರಾದೇಶಿಕ ಟ್ರಸ್ಟ್‌ಗಳಲ್ಲಿ ಪುನರಾವರ್ತಿತವಾದರೆ, ಪೈಲಟ್‌ನ ಮೌಲ್ಯ ಅಳೆಯುತ್ತದೆ:

```
Population EVSI = 480,000 × 3 = £1,440,000
```

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

EVSI ಎಂದರೆ ಪೈಲಟ್ ಅಥವಾ A/B ಪರೀಕ್ಷೆ ನಡೆಸಬೇಕೇ ಎಂಬುದಲ್ಲ, ಅದು *ಎಷ್ಟು ದೊಡ್ಡದಿರಬೇಕು* ಎಂದು ಆರಿಸುವ ಅರ್ಥಶಾಸ್ತ್ರ:

- **ಮಾದರಿ-ಗಾತ್ರ-ಹೂಡಿಕೆ ನಿರ್ಧಾರ.** 50-ಬಳಕೆದಾರರ ಬೀಟಾ ಮತ್ತು 5,000-ಬಳಕೆದಾರರ ಹಂತ ಹಂತದ ಹೊರತರುವಿಕೆ ವಿಭಿನ್ನ EVSI ಮತ್ತು ವಿಭಿನ್ನ ವೆಚ್ಚಗಳಿರುವ ವಿಭಿನ್ನ "ಅಧ್ಯಯನಗಳು" — "ಹೆಚ್ಚು ದತ್ತಾಂಶ ಯಾವಾಗಲೂ ಉತ್ತಮ" ಎಂಬ ಡೀಫಾಲ್ಟ್‌ನ ಬದಲು ಅವನ್ನು ಒಂದೇ ಆಧಾರದಲ್ಲಿ ಹೋಲಿಸಲು EVSI ಅವಕಾಶ ಕೊಡುತ್ತದೆ.
- **ನಿಯೋಜನಾ ಪರೀಕ್ಷೆ EVSI ಮಾತ್ರವಲ್ಲ, ENBS.** ಹೆಚ್ಚಿನ EVSI ಆದರೆ ಅದರ ಬಹುಪಾಲನ್ನು ತಿನ್ನುವ ವೆಚ್ಚವಿರುವ ಅಧ್ಯಯನ ದುರ್ಬಲ ಪ್ರಸ್ತಾವನೆ; ನಿರ್ಧಾರ ನಿಯಮ ಮಾದರಿ ತೆಗೆಯುವಿಕೆಯ ನಿರೀಕ್ಷಿತ ನಿವ್ವಳ ಲಾಭ, ವ್ಯವಹಾರ ಪ್ರಕರಣ ಲಾಭವನ್ನು ಮಾತ್ರ ವರದಿ ಮಾಡದೆ ವೆಚ್ಚದೊಂದಿಗೆ ನಿವ್ವಳಗೊಳಿಸುವಂತೆಯೇ.
- **ಕ್ಷೀಣಿಸುವ ಪ್ರತಿಫಲಗಳು ಸ್ಪಷ್ಟ.** EVSI(n) `n/(n+n0)` ನೊಂದಿಗೆ ಏರುವುದರಿಂದ, ಪೈಲಟ್‌ನ ಗಾತ್ರವನ್ನು ದ್ವಿಗುಣಗೊಳಿಸಿದರೆ ಅದರ ಮೌಲ್ಯ ಎಂದಿಗೂ ದ್ವಿಗುಣವಾಗುವುದಿಲ್ಲ — ದೊಡ್ಡ ಪ್ರಯೋಗದ ಸೀಮಾಂತ ಮಾಹಿತಿ ಮೌಲ್ಯ ಕ್ಷೀಣಿಸುತ್ತದೆ ಎಂಬ ಎಂಜಿನಿಯರಿಂಗ್ ಸಹಜಜ್ಞಾನದ ಔಪಚಾರಿಕ ರೂಪ.

## ಎಡವಟ್ಟುಗಳು

- **ಸಾಮಾನ್ಯ ಅಂದಾಜನ್ನು ಅದರ ಊಹೆಗಳ ಹೊರಗೆ ಅನ್ವಯಿಸುವುದು.** ಇದು ಸುಮಾರು-ಸಂಯುಗ್ಮಿ, ಏಕ-ನಿಯತಾಂಕ ಅನಿಶ್ಚಿತತೆಗೆ ಮಾತ್ರ ಹೊಂದುತ್ತದೆ; ನಿಜವಾಗಿ ರೇಖೀಯವಲ್ಲದ ಅಥವಾ ಬಹು-ನಿಯತಾಂಕ ನಿರ್ಧಾರ ಮಾದರಿಗೆ ಈ ಶಾರ್ಟ್‌ಕಟ್ ಅಲ್ಲ, ಪೂರ್ಣ ಗೂಡುಕಟ್ಟಿದ ಮಾಂಟೆ ಕಾರ್ಲೊ ಬೇಕು.
- **EVSI ಅನ್ನು ನಗದು ವೆಚ್ಚದೊಂದಿಗೆ ಮಾತ್ರ ಹೋಲಿಸುವುದು.** EVSI ಅನ್ನು ಅಧ್ಯಯನದ *ಪೂರ್ಣ* ವೆಚ್ಚದೊಂದಿಗೆ — ಅದರದೇ ನಿರ್ಧಾರ-ವಿಳಂಬ ವೆಚ್ಚ ಸೇರಿ, [ವಿಳಂಬದ ವೆಚ್ಚ](../ವಿಳಂಬದ-ವೆಚ್ಚ/) ನೋಡಿ — ತೂಗಬೇಕು, ಅಧ್ಯಯನದ ಇನ್‌ವಾಯ್ಸ್ ಮಾತ್ರವಲ್ಲ.
- **EVSI > EVPI ಅನ್ನು ನಿಜವಾದ ಸಂಶೋಧನೆ ಎಂದು ಪರಿಗಣಿಸುವುದು.** ರಚನೆಯಿಂದಲೇ EVSI ಎಂದಿಗೂ EVPI ಮೀರಲಾಗದು; ಇದನ್ನು ಉತ್ಪಾದಿಸುವ ಲೆಕ್ಕಾಚಾರ ಮಾದರಿ ಬಗ್, ಆವಿಷ್ಕಾರವಲ್ಲ.
