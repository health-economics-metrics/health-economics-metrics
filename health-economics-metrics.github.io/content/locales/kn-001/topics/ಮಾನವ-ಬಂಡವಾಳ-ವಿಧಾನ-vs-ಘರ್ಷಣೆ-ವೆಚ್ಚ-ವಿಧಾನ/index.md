# ಮಾನವ ಬಂಡವಾಳ ವಿಧಾನ vs ಘರ್ಷಣೆ ವೆಚ್ಚ ವಿಧಾನ

ಅನಾರೋಗ್ಯ-ವೆಚ್ಚ ಮತ್ತು ವೆಚ್ಚ-ಲಾಭ ಅಧ್ಯಯನಗಳಲ್ಲಿ ಅನಾರೋಗ್ಯ, ಅಂಗವೈಕಲ್ಯ ಅಥವಾ ಸಾವಿನಿಂದ ಕಳೆದುಹೋದ ಉತ್ಪಾದಕತೆಗೆ ಬೆಲೆ ಕಟ್ಟುವ ಎರಡು ಸ್ಪರ್ಧಾತ್ಮಕ ವಿಧಾನಗಳು ಇವು. ಮಾನವ ಬಂಡವಾಳ ವಿಧಾನ (HCA) ಗೈರುಹಾಜರಿಯ ಪೂರ್ಣ ಅವಧಿಯ ಎಲ್ಲ ಕಳೆದುಹೋದ ಉತ್ಪಾದನೆಗೆ ವೇತನ ದರದಲ್ಲಿ ಬೆಲೆ ಕಟ್ಟುತ್ತದೆ; ಘರ್ಷಣೆ ವೆಚ್ಚ ವಿಧಾನ (FCM) ಉದ್ಯೋಗದಾತನು ಉತ್ಪಾದನೆಯನ್ನು ಮರುಸ್ಥಾಪಿಸಲು ನಿಜವಾಗಿ ಬೇಕಾದ ಚಿಕ್ಕ ಅವಧಿಗೆ ಮಾತ್ರ ಬೆಲೆ ಕಟ್ಟುತ್ತದೆ. ಇವೆರಡರ ನಡುವಿನ ಆಯ್ಕೆ ಪರೋಕ್ಷ-ವೆಚ್ಚ ಅಂದಾಜನ್ನು ಎರಡು ಪಟ್ಟು ಅಥವಾ ಹೆಚ್ಚು ಬದಲಿಸುತ್ತದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಪರೋಕ್ಷ (ಉತ್ಪಾದಕತೆ) ವೆಚ್ಚಗಳು ಆರೋಗ್ಯ ಅರ್ಥಶಾಸ್ತ್ರದ ಅತ್ಯಂತ ವಿವಾದಾಸ್ಪದ ಸಾಲು ವಸ್ತುಗಳಲ್ಲಿ ಒಂದು, ಏಕೆಂದರೆ ಎರಡು ಪ್ರಮಾಣಿತ ವಿಧಾನಗಳು ಅಷ್ಟು ತೀವ್ರವಾಗಿ ಭಿನ್ನವಾಗುತ್ತವೆ. HCA ಗೈರುಹಾಜರಿಯ ಪ್ರತಿ ದಿನವನ್ನೂ ಆರ್ಥಿಕತೆ ನಿಜವಾಗಿ ಕಳೆದುಕೊಳ್ಳುವ ಒಂದು ದಿನದ ಉತ್ಪಾದನೆ ಎಂದು ಪರಿಗಣಿಸುತ್ತದೆ, ಪೂರ್ಣ ಅವಧಿಗೆ ಪೂರ್ಣ ವೇತನದಲ್ಲಿ — ಅಥವಾ ಸಾವು ಅಥವಾ ಶಾಶ್ವತ ಅಂಗವೈಕಲ್ಯದ ಸಂದರ್ಭದಲ್ಲಿ ಉಳಿದ ಕೆಲಸದ ಜೀವನಕ್ಕೆ. ನಿರುದ್ಯೋಗ ಮತ್ತು ಕಾರ್ಮಿಕ-ಮಾರುಕಟ್ಟೆ ಸಡಿಲತೆ ಇರುವ ಆರ್ಥಿಕತೆಯಲ್ಲಿ, ಉದ್ಯೋಗದಾತನು ಬದಲಿಯವರಿಗೆ ತರಬೇತಿ ನೀಡಿದ ಅಥವಾ ಕೆಲಸವನ್ನು ಮರುಹಂಚಿದ ನಂತರ ದೀರ್ಘ ಗೈರುಹಾಜರಿಯ ಹೆಚ್ಚಿನ ಭಾಗ ರಾಷ್ಟ್ರೀಯ ಉತ್ಪಾದನೆಯನ್ನು ನಿಜವಾಗಿ ಕಡಿಮೆ ಮಾಡುವುದಿಲ್ಲ ಎಂದು FCM ವಾದಿಸುತ್ತದೆ; "ಘರ್ಷಣೆ ಅವಧಿ" ಮಾತ್ರ — ಉತ್ಪಾದನೆಯನ್ನು ಹಿಂದಿನ ಮಟ್ಟಕ್ಕೆ ಮರುಸ್ಥಾಪಿಸುವ ಸಮಯ — ನಿಜವಾದ ನಷ್ಟ. ಆದ್ದರಿಂದ FCM ವ್ಯವಸ್ಥಿತವಾಗಿ HCAಗಿಂತ ಕಡಿಮೆ, ಹೆಚ್ಚು ಸಂಪ್ರದಾಯಶೀಲ ಪರೋಕ್ಷ-ವೆಚ್ಚ ಅಂದಾಜುಗಳನ್ನು ನೀಡುತ್ತದೆ, ಮತ್ತು ಈ ಎರಡು ವಿಧಾನಗಳು ಪರಸ್ಪರ ಬದಲಾಯಿಸಬಹುದಾದ ಅಡಿಟಿಪ್ಪಣಿಗಳಲ್ಲ: ಅವು "ಕಳೆದುಹೋದ ಉತ್ಪಾದಕತೆ" ಎಂದರೇನು ಎಂಬ ಬಗ್ಗೆ ಭಿನ್ನ ಆರ್ಥಿಕ ಸಿದ್ಧಾಂತಗಳು. ಇದೇ ಕಾರಣಕ್ಕೆ [NICEಯ ಉಲ್ಲೇಖ ಪ್ರಕರಣ](../ಆರೋಗ್ಯ-ತಂತ್ರಜ್ಞಾನ-ಮೌಲ್ಯಮಾಪನ/) ಉತ್ಪಾದಕತಾ ವೆಚ್ಚಗಳನ್ನು ಡೀಫಾಲ್ಟ್ ಆಗಿ ಹೊರಗಿಡುತ್ತದೆ, ಅವುಗಳನ್ನು ಉಲ್ಲೇಖ-ಪ್ರಕರಣದ ICERಗೆ ಬೆರೆಸದೆ, ವರದಿ ಮಾಡುವುದಾದರೆ ಪ್ರತ್ಯೇಕ ಸಾಮಾಜಿಕ-ದೃಷ್ಟಿಕೋನ ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆಯಾಗಿ ಮಾತ್ರ — [ವಿಶ್ಲೇಷಣಾ ದೃಷ್ಟಿಕೋನ](../ವಿಶ್ಲೇಷಣಾ-ದೃಷ್ಟಿಕೋನ/) ನೋಡಿ.

## ಗಣಿತ

```
Human Capital Approach:
HCA_cost = daily_wage × days_lost

Friction Cost Method (simplified, capped-at-friction-period form):
FCM_cost = daily_wage × min(days_lost, friction_period_days)

friction_period_days = country/sector-specific estimate of time-to-restore
                        production (historically ~85 days in Dutch iMTA
                        costing guidance; varies by country and is
                        periodically re-estimated)
```

ಎರಡು ವಿಧಾನಗಳ ನಡುವಿನ ಇಡೀ ಭಿನ್ನಾಭಿಪ್ರಾಯ `min()` ನಲ್ಲಿದೆ: HCA ಎಂದಿಗೂ `days_lost` ಗೆ ಮಿತಿ ಹಾಕುವುದಿಲ್ಲ, ಆದ್ದರಿಂದ ಇಡೀ ಗೈರುಹಾಜರಿಗೆ ವೆಚ್ಚ ಬೆಳೆಯುತ್ತಲೇ ಇರುತ್ತದೆ; FCM ನಿಜವಾದ ಗೈರುಹಾಜರಿ ಎಷ್ಟೇ ಕಾಲ ನಡೆದರೂ ಲೆಕ್ಕಿಸುವ ದಿನಗಳನ್ನು ಘರ್ಷಣೆ ಅವಧಿಗೆ ಮಿತಿಗೊಳಿಸುತ್ತದೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಒಬ್ಬ ಉದ್ಯೋಗಿ `days_lost = 180` ದಿನ ಕೆಲಸದಿಂದ ದೂರವಿದ್ದಾರೆ, `daily_wage = £150` ಗಳಿಸುತ್ತಾರೆ.

**ಮಾನವ ಬಂಡವಾಳ ವಿಧಾನ**:

```
HCA_cost = 150 × 180 = £27,000
```

**ಘರ್ಷಣೆ ವೆಚ್ಚ ವಿಧಾನ**, `friction_period_days = 85` ಘರ್ಷಣೆ ಅವಧಿಯೊಂದಿಗೆ (ಮಾರ್ಗದರ್ಶನದ ಆವರ್ತಕ ಮರು-ಅಂದಾಜಿನ ಪ್ರಕಾರ ಐತಿಹಾಸಿಕ ಡಚ್ iMTA ಮಾನದಂಡ):

```
FCM_cost = 150 × min(180, 85) = 150 × 85 = £12,750
```

FCMನ £12,750 *ಅದೇ* ಗೈರುಹಾಜರಿಗೆ HCAಯ £27,000ದ ಅರ್ಧಕ್ಕಿಂತ ಕಡಿಮೆ — ಬೇರೆ ಯಾವುದೇ ಊಹೆಯನ್ನು ಮುಟ್ಟುವ ಮೊದಲೇ, ವಿಧಾನದ ಆಯ್ಕೆಯೊಂದೇ ಅನಾರೋಗ್ಯ-ವೆಚ್ಚ ಪ್ರಕರಣವನ್ನು ಗಣನೀಯವಾಗಿ ಬದಲಿಸುತ್ತದೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಇದು ತಂಡವೊಂದು ಹೊರಹೋಗುವ ಎಂಜಿನಿಯರ್‌ಗೆ ಹೇಗೆ ಬೆಲೆ ಕಟ್ಟುತ್ತದೆ ಎಂಬುದಕ್ಕೆ ನೇರವಾಗಿ ಹೊಂದುತ್ತದೆ:

- **HCA-ಶೈಲಿಯ ನಿರ್ಗಮನ ವೆಚ್ಚ ಲೆಕ್ಕಾಚಾರ**: ಹುದ್ದೆ ಖಾಲಿ ಇರುವಷ್ಟು ಕಾಲ ಹೊರಹೋದ ಎಂಜಿನಿಯರ್‌ನ ಪೂರ್ಣ ವೇತನವನ್ನು ನಷ್ಟವೆಂದು ಮೌಲ್ಯೀಕರಿಸುವುದು. ಹೆಚ್ಚಿನ ನಿರ್ಗಮನ-ವೆಚ್ಚ ಮಾದರಿಗಳ ಮುಗ್ಧ ಆವೃತ್ತಿ ಇದು, ಮತ್ತು HCA ಉತ್ಪಾದಕತಾ ನಷ್ಟವನ್ನು ಉತ್ಪ್ರೇಕ್ಷಿಸುವ ಅದೇ ಕಾರಣಕ್ಕೆ ಇದು ನಷ್ಟವನ್ನು ಉತ್ಪ್ರೇಕ್ಷಿಸುತ್ತದೆ — ಖಾಲಿ ಸಾಮರ್ಥ್ಯ ಇಡೀ ಕಾಲ ಸಂಪೂರ್ಣ ಉತ್ಪಾದಕವಾಗಿತ್ತು ಮತ್ತು ಬೇರೇನೂ ಸಡಿಲತೆಯನ್ನು ಹೀರಿಕೊಳ್ಳಲಿಲ್ಲ ಎಂದು ಅದು ಊಹಿಸುತ್ತದೆ. ಈ ವಿಧಾನ ಪೂರೈಸುವ ನೇಮಕಾತಿ/ಆನ್‌ಬೋರ್ಡಿಂಗ್/ಖಾಲಿ-ಹುದ್ದೆ-ಸರಿದೂಗಿಕೆ ಸರಪಳಿಯನ್ನು ಪರಿಮಾಣಗೊಳಿಸುವ [ಕಾರ್ಯಪಡೆ ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ](../ಕಾರ್ಯಪಡೆ-ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ/) ನೋಡಿ.
- **FCM-ಶೈಲಿಯ ನಿರ್ಗಮನ ವೆಚ್ಚ ಲೆಕ್ಕಾಚಾರ**: ಬದಲಿಯವರನ್ನು ಭರ್ತಿ ಮಾಡಿ ಪರಿಣತಿಗೆ ತರಲು ನಿಜವಾಗಿ ಬೇಕಾದ ಸಮಯಕ್ಕೆ ಮಾತ್ರ — ಎಂಜಿನಿಯರಿಂಗ್ "ಘರ್ಷಣೆ ಅವಧಿ" — ನಷ್ಟಕ್ಕೆ ಬೆಲೆ ಕಟ್ಟುವುದು. ಅನಾರೋಗ್ಯ-ವೆಚ್ಚ ಅಧ್ಯಯನದಲ್ಲಿ FCM ಹೆಚ್ಚು ಸಂಪ್ರದಾಯಶೀಲ ಆಯ್ಕೆಯಾಗಿರುವಂತೆಯೇ, ವ್ಯವಹಾರ ಪ್ರಕರಣಕ್ಕೆ ಇದು ಹೆಚ್ಚು ಸಮರ್ಥನೀಯ ಸಂಖ್ಯೆ.
- ಆಧಾರವಾಗಿರುವ ಶಿಸ್ತು [ಅವಕಾಶ ವೆಚ್ಚ](../ಅವಕಾಶ-ವೆಚ್ಚ/)ದಲ್ಲಿರುವುದೇ: ಸ್ಥಾನಪಲ್ಲಟಗೊಂಡ ಸಂಪನ್ಮೂಲಕ್ಕೆ ನಿಜವಾಗಿ ಕಳೆದುಹೋದದ್ದರ ಆಧಾರದಲ್ಲಿ ಬೆಲೆ ಕಟ್ಟಿ, ಪ್ರಧಾನ ಅವಧಿಯನ್ನು ದರದಿಂದ ಗುಣಿಸಿದ್ದರ ಆಧಾರದಲ್ಲಿ ಅಲ್ಲ.

## ಎಡವಟ್ಟುಗಳು

- **ಒಂದೇ ವಿಶ್ಲೇಷಣೆಯಲ್ಲಿ HCA ಮತ್ತು FCM ಅನ್ನು ಬೆರೆಸುವುದು, ಅಥವಾ ಆಯ್ಕೆಯನ್ನು ಬಹಿರಂಗಪಡಿಸದೆ ಒಂದನ್ನೇ ವರದಿ ಮಾಡುವುದು.** ಅದೇ ಗೈರುಹಾಜರಿ ದತ್ತಾಂಶ ವಿಧಾನದ ಆಧಾರದಲ್ಲಿ ವರದಿಯಾದ ವೆಚ್ಚದಲ್ಲಿ 2x+ ವ್ಯತ್ಯಾಸ ಉಂಟುಮಾಡಬಹುದು; ಆಯ್ಕೆಯನ್ನು ಹೇಳಬೇಕು, ಹೂತಿಡಬಾರದು.
- **ಸಾಮಾಜಿಕ-ದೃಷ್ಟಿಕೋನ ಪ್ರಕರಣಕ್ಕೆ HCA ಬಳಸಿ ಅದನ್ನು ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ ಎಂದು ಗುರುತಿಸದಿರುವುದು.** NICEಯ ಉಲ್ಲೇಖ ಪ್ರಕರಣ ಉತ್ಪಾದಕತಾ ವೆಚ್ಚಗಳನ್ನು ಸ್ಪಷ್ಟವಾಗಿ ಹೊರಗಿಡುತ್ತದೆ; ಸಾಮಾಜಿಕ-ದೃಷ್ಟಿಕೋನ HCA ಅಂದಾಜು ಸನ್ನಿವೇಶ ವಿಶ್ಲೇಷಣೆಗೆ ಸೇರಿದ್ದು, ಶೀರ್ಷಿಕೆ ICERಗೆ ಅಲ್ಲ.
- **ವೇತನರಹಿತ ಅಥವಾ ಮಾರುಕಟ್ಟೆಯಲ್ಲದ ಕೆಲಸಕ್ಕೆ (ಉದಾ., ಆರೈಕೆ ನೀಡುವಿಕೆ) ಹೊಂದಾಣಿಕೆ ಇಲ್ಲದೆ ಯಾವುದೇ ವಿಧಾನವನ್ನು ಅನ್ವಯಿಸುವುದು.** ಎರಡೂ ವಿಧಾನಗಳು ಮೌಲ್ಯಕ್ಕೆ ವೇತನ-ದರದ ಪ್ರತಿನಿಧಿಯನ್ನು ಊಹಿಸುತ್ತವೆ, ಮಾರುಕಟ್ಟೆ ವೇತನವಿಲ್ಲದ ಕೆಲಸಕ್ಕೆ ಅದು ಸ್ವಚ್ಛವಾಗಿ ವರ್ಗಾವಣೆಯಾಗುವುದಿಲ್ಲ.
