# ಸಕ್ರಿಯಗೊಳಿಸುವಿಕೆ ಮತ್ತು ಸ್ವೀಕಾರ

ಸಕ್ರಿಯಗೊಳಿಸುವಿಕೆ ದರ (activation rate) ಎಂದರೆ ಸೈನ್-ಅಪ್ ಮಾಡಿದವರಲ್ಲಿ ಮೊದಲ ಅರ್ಥಪೂರ್ಣ ಮೌಲ್ಯವನ್ನು ತಲುಪುವವರ ಪಾಲು ("ಆಹಾ" ಕ್ರಿಯೆ — ಮೊದಲ ಓದಿನ ದಾಖಲೆ, ಮೊದಲ ಪಾಠ ಪೂರ್ಣ). ಸ್ವೀಕಾರ (uptake) ಅದರ ಜನಸಂಖ್ಯಾ ರೂಪ: *ಅರ್ಹ* ಜನಸಂಖ್ಯೆಯಲ್ಲಿ ಅದನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳುವವರ ಪಾಲು. ಎರಡೂ ಸೇರಿ ಮೌಲ್ಯ-ಕೊಳವೆಯ (value funnel) ಮುಂಬಾಗಿಲುಗಳು: ಸ್ವಾಧೀನ → ಸ್ವೀಕಾರ → ಸಕ್ರಿಯಗೊಳಿಸುವಿಕೆ → [ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ](../ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ-ಮತ್ತು-ಬಿಟ್ಟುಹೋಗುವಿಕೆ/) → ಫಲಿತಾಂಶ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಸಕ್ರಿಯಗೊಳ್ಳದ ಬಳಕೆದಾರರು ಕೇವಲ ವೆಚ್ಚ: ಸ್ವಾಧೀನ ಖರ್ಚು, ಒದಗಣೆ, ಬೆಂಬಲದ ವ್ಯಾಪ್ತಿ — ಆದರೆ ಕ್ಲಿನಿಕಲ್ ಮೌಲ್ಯ ಶೂನ್ಯ. ಮಾನದಂಡಗಳ ಪ್ರಕಾರ ಆರೋಗ್ಯ ಸಾಫ್ಟ್‌ವೇರ್‌ನ ಸಕ್ರಿಯಗೊಳಿಸುವಿಕೆ ಎಲ್ಲ ಉದ್ಯಮಗಳ ಸರಾಸರಿಗಿಂತ *ಕಡಿಮೆ* (ಒಂದು SaaS ಮಾನದಂಡ ಸಮೂಹದಲ್ಲಿ ಹೊಸ-ಬಳಕೆದಾರ ಸಕ್ರಿಯಗೊಳಿಸುವಿಕೆ ≈24% vs ≈37%; ಆನ್‌ಬೋರ್ಡಿಂಗ್ ಚೆಕ್‌ಲಿಸ್ಟ್ ಪೂರ್ಣತೆ ~20%), ಇದಕ್ಕೆ ಕಾರಣ ಭಾರವಾದ ಆನ್‌ಬೋರ್ಡಿಂಗ್ (ಗುರುತು, ಸಮ್ಮತಿ, ಕ್ಲಿನಿಕಲ್ ಸುರಕ್ಷತೆ). ಸ್ವೀಕಾರಕ್ಕೆ ಜನಸಂಖ್ಯಾ ಪಣವಿದೆ: [RE-AIM ಚೌಕಟ್ಟಿನಲ್ಲಿ](../ವ್ಯಾಪ್ತಿ-ಮತ್ತು-ಸಮಾನತೆ/) ಸಾರ್ವಜನಿಕ-ಆರೋಗ್ಯ ಪ್ರಭಾವ ≈ ವ್ಯಾಪ್ತಿ × ಪರಿಣಾಮಕಾರಿತ್ವ — ಅರ್ಹ ಜನಸಂಖ್ಯೆಯ 3% ಜನ ಅಳವಡಿಸಿಕೊಂಡ ಅತ್ಯುತ್ತಮ ಆ್ಯಪ್ ಜನಸಂಖ್ಯಾ ಸೂಚಿಯನ್ನು 3%ರಷ್ಟು ಮಾತ್ರ ಕದಲಿಸುತ್ತದೆ. ಶಿಫಾರಸು ಮಾಡಿದ ಡಿಜಿಟಲ್ ಚಿಕಿತ್ಸೆಗಳಿಗೆ ಸ್ವೀಕಾರ ದ್ವಾರ ರಾಷ್ಟ್ರೀಯ ದತ್ತಾಂಶದಲ್ಲಿ ಕಾಣುತ್ತದೆ: **ಜರ್ಮನ್ DiGA ಶಿಫಾರಸುಗಳಲ್ಲಿ ~81% ಮಾತ್ರ ಸಕ್ರಿಯಗೊಳ್ಳುತ್ತವೆ** — ಶಿಫಾರಸು ಮಾಡಿ ಹಣ ಪಾವತಿಸಿದ ಐದರಲ್ಲಿ ಒಂದು ಚಿಕಿತ್ಸೆ ಎಂದಿಗೂ ಆರಂಭವಾಗುವುದಿಲ್ಲ ([DiGA ತ್ವರಿತ ಮಾರ್ಗ](../ಜರ್ಮನಿಯ-diga-ತ್ವರಿತ-ಮಾರ್ಗ/) ನೋಡಿ).

## ಗಣಿತ

```
Activation rate = users completing key action within window / sign-ups × 100
Uptake rate     = adopters / eligible population × 100
DTx fill rate   = activated prescription codes / issued prescriptions × 100

Funnel value model:
  eligible × uptake × activation × retention-weighted benefit = population value
  — four multiplications; improving the smallest factor usually
  dominates (theory-of-constraints for funnels)
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಒಬ್ಬ ಆಯೋಗದಾರ (commissioner) 80,000 ಅರ್ಹ ನಿವಾಸಿಗಳಿಗೆ ಮಧುಮೇಹ-ತಡೆ ಆ್ಯಪ್ ನೀಡುತ್ತಾನೆ:

```
Invited → registered:  80,000 → 12,000  (uptake 15%)
Registered → activated (first session + goal set, 7 days): 12,000 → 5,400 (45%)
Activated → completed 6-month programme: 5,400 → 1,600 (30%)

Programme effect (trial, completers): 0.03 QALYs + £180 avoided costs
Population value = 1,600 × (0.03 × £20,000 + £180) ≈ £1.25M
Per-eligible-person value = £15.6 — versus £780 if every eligible person completed.

Where to invest? Doubling uptake (15→30%) doubles value; raising
activation 45→65% adds ~44%; both beat further polishing the programme
content the 1,600 already complete.
```

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಸಕ್ರಿಯಗೊಳಿಸುವಿಕೆ ಕೊಳವೆಯ ಅತ್ಯಂತ ಎಂಜಿನಿಯರಿಂಗ್-ಸಾಧ್ಯ ಹಂತ: ಗುರುತು-ಪರಿಶೀಲನೆಯ ಘರ್ಷಣೆ, ಸಮ್ಮತಿ ಹರಿವುಗಳು, ಖಾಲಿ-ಸ್ಥಿತಿ ವಿನ್ಯಾಸ ಮತ್ತು ಮೊದಲ-ಮೌಲ್ಯಕ್ಕೆ ಬೇಕಾದ ಸಮಯ ಇವೆಲ್ಲ ಕೋಡ್, ನೀತಿಯಲ್ಲ (ಮಾನದಂಡ ದತ್ತಾಂಶದಲ್ಲಿ ಆರೋಗ್ಯ ವಲಯದ ಸರಾಸರಿ ಮೌಲ್ಯ-ಪಡೆಯುವ ಸಮಯ ≈ 1 ದಿನ 7 ಗಂಟೆ — ಅದರ ಪ್ರತಿ ಗಂಟೆಯೂ ಬಳಕೆದಾರ ಕೈಬಿಡುವ ಅಪಾಯ). ಸ್ವೀಕಾರ ಒಂದು ವಿತರಣಾ-ವ್ಯವಸ್ಥೆಯ ಸಮಸ್ಯೆ: ಶಿಫಾರಸು ಮಾರ್ಗಗಳಲ್ಲಿ ಏಕೀಕರಣ (ಔಷಧಿ ಚೀಟಿ ನೀಡುವ ಕ್ಷಣ), GP ಅನುಮೋದಿತ ಆಹ್ವಾನಗಳು (ನಂಬಿಕೆ ವರ್ಗಾವಣೆಯಾಗುತ್ತದೆ) ಮತ್ತು ಪ್ರವೇಶಸಾಧ್ಯತೆ (ಭಾಷೆ, ಡಿಜಿಟಲ್ ಕೌಶಲ — [ವ್ಯಾಪ್ತಿ ಮತ್ತು ಸಮಾನತೆ](../ವ್ಯಾಪ್ತಿ-ಮತ್ತು-ಸಮಾನತೆ/) ನೋಡಿ). ಮೇಲಿನ ಕೊಳವೆ-ಮೌಲ್ಯ ಮಾದರಿ ಇವೆರಡಕ್ಕೂ ವ್ಯಾಪಾರ-ಸಮರ್ಥನೆ ರೂಪಿಸುವ ಸಾಧನ: ಅಂಶಗಳನ್ನು ಗುಣಿಸಿ, ಅಡಚಣೆಯನ್ನು ಕಂಡುಹಿಡಿದು, ಅದನ್ನು ಸರಿಪಡಿಸುವ ವೆಚ್ಚವನ್ನು ಅದು ಬಿಡುಗಡೆ ಮಾಡುವ ಜನಸಂಖ್ಯಾ ಮೌಲ್ಯದೊಂದಿಗೆ ತೂಗಿ.

## ಎಡವಟ್ಟುಗಳು

- **ಸಕ್ರಿಯಗೊಳಿಸುವಿಕೆಯನ್ನು ಅನುಕೂಲದ ರೂಪದಲ್ಲಿ ವ್ಯಾಖ್ಯಾನಿಸುವುದು** (ಇಮೇಲ್ ಪರಿಶೀಲಿಸಲಾಗಿದೆ) — ಕ್ಲಿನಿಕಲ್ ಅರ್ಥದ (ಮೊದಲ ಚಿಕಿತ್ಸಕ ಕ್ರಿಯೆ) ಬದಲು — ಮಾಪನವನ್ನು ಉಬ್ಬಿಸುತ್ತದೆ, ಮೌಲ್ಯ ಸರಪಳಿಯನ್ನು ಮುರಿಯುತ್ತದೆ.
- **ಸ್ವೀಕಾರ ಛೇದದ ಆಟಗಳು**: "ಸೈಟ್‌ಗೆ ಭೇಟಿ ನೀಡಿದವರಲ್ಲಿ" vs ನಿಜವಾದ ಅರ್ಹ ಜನಸಂಖ್ಯೆ — ಆಯೋಗದಾರರು ಎರಡನೆಯದನ್ನು ಗಮನಿಸುತ್ತಾರೆ.
- **ಆಯ್ಕೆ ಪರಿಣಾಮಗಳು**: ಸುಲಭವಾಗಿ ಸಕ್ರಿಯಗೊಳ್ಳುವ ಬಳಕೆದಾರರು ಅತಿ ಕಡಿಮೆ ಅನಾರೋಗ್ಯದವರು ಮತ್ತು ಅತಿ ಕಡಿಮೆ ವಂಚಿತರು; ಕೊಳವೆ ಸುಧಾರಣೆಗಳು ಸರಾಸರಿಗಳನ್ನು ಸುಧಾರಿಸುತ್ತಲೇ ಸಮಾನತೆಯ ಅಂತರವನ್ನು ಹೆಚ್ಚಿಸಬಹುದು.
