# ಸಂಭಾವ್ಯತಾ ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ (PSA)

PSA ಪ್ರತಿ ಅನಿಶ್ಚಿತ ನಿಯತಾಂಕಕ್ಕೂ ಸಂಭಾವ್ಯತಾ ವಿತರಣೆಯನ್ನು ನಿಗದಿಪಡಿಸುತ್ತದೆ, ಅವೆಲ್ಲವನ್ನೂ ಏಕಕಾಲದಲ್ಲಿ ಸಾವಿರಾರು ಬಾರಿ ಮಾದರಿ ತೆಗೆಯುತ್ತದೆ (ಮಾಂಟೆ ಕಾರ್ಲೊ), ಮತ್ತು ಒಂದೇ ಬಿಂದು ಅಂದಾಜಿನ ಬದಲು ಒಂದು ಆಯ್ಕೆಯು ಅತ್ಯುತ್ತಮ ಎಂಬುದರ *ಸಂಭವನೀಯತೆ*ಯನ್ನು ವರದಿ ಮಾಡುತ್ತದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

NICEಯ ಉಲ್ಲೇಖ ಪ್ರಕರಣಕ್ಕೆ PSA *ಅಗತ್ಯ*. ನಿರ್ಧಾರಾತ್ಮಕ ವಿಶ್ಲೇಷಣೆ "ಒಂದು ಇನ್‌ಪುಟ್ ತಪ್ಪಾಗಿದ್ದರೆ?" ಎಂದು ಉತ್ತರಿಸುತ್ತದೆ; PSA "ನಮಗೆ ತಿಳಿಯದ ಎಲ್ಲವನ್ನೂ ಒಟ್ಟಿಗೆ ಪರಿಗಣಿಸಿದರೆ, ನಾವು ಸರಿಯಾದ ನಿರ್ಧಾರ ಕೈಗೊಳ್ಳುತ್ತಿರುವ ಸಂಭವನೀಯತೆ ಎಷ್ಟು?" ಎಂದು ಉತ್ತರಿಸುತ್ತದೆ. ಇದರ ವಿಶಿಷ್ಟ ಫಲಿತಾಂಶವಾದ **ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ಸ್ವೀಕಾರಾರ್ಹತಾ ವಕ್ರರೇಖೆ (CEAC)**, ಪಾವತಿಸಲು ಇಚ್ಛೆಯ ಮಿತಿಯ ಎದುರು ಒಂದು ಆಯ್ಕೆ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿಯಾಗಿರುವ ಸಂಭವನೀಯತೆಯನ್ನು ಚಿತ್ರಿಸುತ್ತದೆ — "ICER ಪ್ರತಿ QALYಗೆ £24,000" ಎಂಬುದನ್ನು "£30,000/QALY ಮಿತಿಯಲ್ಲಿ ಇದು ಸರಿಯಾದ ಆಯ್ಕೆಯಾಗಿರುವ 78% ಸಂಭವನೀಯತೆ ಇದೆ" ಎಂದು ಪರಿವರ್ತಿಸುತ್ತದೆ.

## ಗಣಿತ

```
For each of N draws (N ≈ 10,000):
  sample every parameter θ from its distribution
    (costs ~ Gamma, probabilities ~ Beta, utilities ~ Beta, effects ~ Normal/logNormal)
  compute NMB_j(θ) = λ × Effect_j(θ) − Cost_j(θ) for each option j

CEAC_j(λ) = fraction of draws in which option j has the highest NMB at threshold λ
```

NMBಗಾಗಿ [ನಿವ್ವಳ ಹಣಕಾಸು ಲಾಭ](../ನಿವ್ವಳ-ಹಣಕಾಸು-ಲಾಭ/) ಮತ್ತು λ ಗಾಗಿ [ಪಾವತಿಸಲು ಇಚ್ಛೆಯ ಮಿತಿಗಳು](../ಪಾವತಿಸಲು-ಇಚ್ಛೆಯ-ಮಿತಿಗಳು/) ನೋಡಿ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಸ್ಥಳಾಂತರ ವ್ಯವಹಾರ ಪ್ರಕರಣ. ಮೂರು ಅನಿಶ್ಚಿತ ಇನ್‌ಪುಟ್‌ಗಳು:

```
Migration cost      ~ Gamma,  mean £800k, sd £200k
Annual benefit      ~ Normal, mean £350k, sd £150k
Benefit duration    ~ Uniform, 3–6 years
```

10,000 ಮಾದರಿಗಳ ಪ್ರತಿಯೊಂದಕ್ಕೂ ನಿವ್ವಳ ಲಾಭ = ಅವಧಿ × ವಾರ್ಷಿಕ − ವೆಚ್ಚ ಲೆಕ್ಕಿಸಿ (ಸ್ಪಷ್ಟತೆಗಾಗಿ ರಿಯಾಯಿತಿ ಬಿಟ್ಟಿದೆ). ವಿವರಣಾತ್ಮಕ ಫಲಿತಾಂಶಗಳು:

```
Mean net benefit:      £775k
Probability net > 0:   0.86
5th–95th percentile:  −£180k … +£1.9M
```

ಬಿಂದು ಅಂದಾಜು "ಸ್ಪಷ್ಟವಾಗಿ ಹೌದು" ಎಂದಿತು. PSA "86% ಹೌದು, ಆದರೆ £180k+ ನಷ್ಟವಾಗುವ ನಿಜವಾದ ಬಾಲ ಇದೆ" ಎನ್ನುತ್ತದೆ — ಪೋರ್ಟ್‌ಫೋಲಿಯೊ ಮಾಲೀಕರಿಗೆ ನಿಜವಾಗಿ ಬೇಕಾದದ್ದು ಇದೇ, ಮತ್ತು ಮೊದಲು ಡಿಸ್ಕವರಿ ಸ್ಪೈಕ್ ನಡೆಸುವ ಪ್ರಕರಣಕ್ಕೂ ಇದು ಬೆಲೆ ಕಟ್ಟುತ್ತದೆ ([EVPI](../ಪರಿಪೂರ್ಣ-ಮಾಹಿತಿಯ-ನಿರೀಕ್ಷಿತ-ಮೌಲ್ಯ/) ನೋಡಿ).

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಎಂಜಿನಿಯರ್‌ಗಳು ಈಗಾಗಲೇ ಪೂರೈಕೆ ಮುನ್ಸೂಚನೆಗೆ ಮಾಂಟೆ ಕಾರ್ಲೊವನ್ನು ನಂಬುತ್ತಾರೆ (ಥ್ರೂಪುಟ್ ಮಾದರಿ ಬಿಂದು ಅಂದಾಜುಗಳನ್ನು ಮೀರಿಸುತ್ತದೆ). ಅದೇ ಯಂತ್ರವನ್ನು ಹಣಕ್ಕೆ ವಿಸ್ತರಿಸಿ: ಸ್ವೀಕಾರ, ಉಳಿತಾಯವಾದ ಸಮಯ ಮತ್ತು ವೇತನದ ಮೇಲೆ ವಿತರಣೆಗಳನ್ನು ಹಾಕಿ, ನಂತರ ಸುಳ್ಳು-ನಿಖರತೆಯ ROIಯ ಬದಲು "ಈ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಹೂಡಿಕೆ ನಿವ್ವಳ-ಧನಾತ್ಮಕವಾಗಿರುವ ಸಂಭವನೀಯತೆ" ವರದಿ ಮಾಡಿ. ಸಂಸ್ಥೆಯು ಎಂಜಿನಿಯರ್-ಗಂಟೆಗೆ ಎಷ್ಟು ಮೌಲ್ಯ ಕೊಡುತ್ತದೆ ಎಂಬುದರ ಕಾರ್ಯವಾಗಿ ಅತ್ಯುತ್ತಮ ಆಯ್ಕೆಯಾಗುವ ಸಂಭವನೀಯತೆಯ CEAC-ಶೈಲಿಯ ವಕ್ರರೇಖೆ, ನಿಧಿ ಸಮಿತಿಗೆ ಯಾವುದೇ ಒಂದೇ ಸಂಖ್ಯೆಗಿಂತ ನಿಜವಾಗಿಯೂ ಉತ್ತಮ ಸಾಧನ.

## ಎಡವಟ್ಟುಗಳು

- **ಕಸ ವಿತರಣೆಗಳು**: ಕಲ್ಪಿತ ಪ್ರಮಾಣಿತ ವಿಚಲನಗಳಿರುವ PSA ಲ್ಯಾಬ್ ಕೋಟ್ ಧರಿಸಿದ ನಿರ್ಧಾರಾತ್ಮಕ ವಿಶ್ಲೇಷಣೆ. ಹರಡುವಿಕೆಗಳನ್ನು ದತ್ತಾಂಶ ಅಥವಾ ರಚನಾತ್ಮಕ ತಜ್ಞ ನಿರ್ಧಾರಣೆಯ ಮೇಲೆ ಆಧರಿಸಿ.
- ನಿಯತಾಂಕಗಳ ನಡುವಿನ **ಸಹಸಂಬಂಧವನ್ನು ಕಡೆಗಣಿಸುವುದು** (ಹೆಚ್ಚಿನ ಸ್ವೀಕಾರ ಸಾಮಾನ್ಯವಾಗಿ ಹೆಚ್ಚಿನ ಉಳಿತಾಯವಾದ ಸಮಯದೊಂದಿಗೆ ಸಂಬಂಧಿಸಿದೆ); ಸ್ವತಂತ್ರ ಮಾದರಿ ಬಾಲ ಅಪಾಯವನ್ನು ಕಡಿಮೆ ಅಂದಾಜಿಸುತ್ತದೆ.
- ಅನುಕರಣೆಯ **ಸರಾಸರಿಯನ್ನು ಮಾತ್ರ ವರದಿ ಮಾಡುವುದು** — ವಿತರಣೆ ಮತ್ತು ನಿರ್ಧಾರ ಸಂಭವನೀಯತೆಯೇ ಇಡೀ ಉದ್ದೇಶ.
