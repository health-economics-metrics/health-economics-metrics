# ಉಳಿತಾಯವಾದ ಹಾಸಿಗೆ ದಿನಗಳು

ಹಾಸಿಗೆ ದಿನ ಎಂದರೆ ಒಬ್ಬ ರೋಗಿ ಒಂದು ಆಸ್ಪತ್ರೆ ಹಾಸಿಗೆಯನ್ನು ಒಂದು ದಿನ ಆಕ್ರಮಿಸುವುದು. ಬೇಗ ಡಿಸ್ಚಾರ್ಜ್, ದಾಖಲಾತಿ ತಪ್ಪಿಸುವಿಕೆ ಅಥವಾ ವರ್ಚುವಲ್ ವಾರ್ಡ್‌ಗಳ ಮೂಲಕ "ಉಳಿತಾಯವಾದ ಹಾಸಿಗೆ ದಿನಗಳು" NHS ಡಿಜಿಟಲ್ ವ್ಯವಹಾರ ಪ್ರಕರಣಗಳ ಮುಖ್ಯ ಲಾಭ, ಮತ್ತು ಅತ್ಯಂತ ಹೆಚ್ಚಾಗಿ ಅತಿಯಾಗಿ ಮೌಲ್ಯೀಕರಿಸಲ್ಪಡುವುದು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಹಾಸಿಗೆಗಳು ತೀವ್ರ ಆರೈಕೆಯ ಬದ್ಧ ನಿರ್ಬಂಧ: ಹಾಸಿಗೆಗಳು ತುಂಬಿದಾಗ, ಯೋಜಿತ ಶಸ್ತ್ರಚಿಕಿತ್ಸೆಗಳು ರದ್ದಾಗುತ್ತವೆ, ಆಂಬ್ಯುಲೆನ್ಸ್‌ಗಳು ಸರತಿಯಲ್ಲಿ ನಿಲ್ಲುತ್ತವೆ, ತುರ್ತು ವಿಭಾಗ ಹಿಂದೆ ಸಂಗ್ರಹವಾಗುತ್ತದೆ. ಹಾಸಿಗೆ ದಿನಗಳನ್ನು ಖಾಲಿ ಮಾಡುವ ಮಧ್ಯಸ್ಥಿಕೆಗಳು ಆದ್ದರಿಂದ ನಿಜವಾದ ಮೌಲ್ಯ ಹೊಂದಿವೆ — ಆದರೆ ಆ ಮೌಲ್ಯದ *ಸ್ವರೂಪ* ಖಾಲಿಯಾದ ಹಾಸಿಗೆಗೆ ಏನಾಗುತ್ತದೆ ಎಂಬುದರ ಮೇಲೆ ಸಂಪೂರ್ಣ ಅವಲಂಬಿತ. ಹಣಕಾಸು ನಿರ್ದೇಶಕರು ಮುಗ್ಧ ಹಾಸಿಗೆ-ದಿನ ಹೇಳಿಕೆಗಳಿಗೆ ಭಾರೀ ರಿಯಾಯಿತಿ ನೀಡಲು ಕಲಿತಿದ್ದಾರೆ; ಈ ಅಂಕಗಣಿತವನ್ನು ಸರಿಯಾಗಿ ಮಾಡುವುದು ವಿಶ್ವಾಸಾರ್ಹತೆಯ ಪರೀಕ್ಷೆ.

## ಗಣಿತ

```
Bed days saved = patients affected × Δ length of stay (or admissions avoided × avg LOS)

Value depends on the use of the freed capacity:
  refilled with elective activity → value = activity income or waiting-list benefit
  ward closed / flexed down      → value = staffing + running cost released (cash)
  absorbed as slack              → value ≈ marginal (hotel) cost only, £50–£150/day
```

ತೀವ್ರ ಆರೈಕೆ ಹಾಸಿಗೆ ದಿನದ ಸರಾಸರಿ ಸಂಪೂರ್ಣ-ಹೀರಲ್ಪಟ್ಟ ವೆಚ್ಚ ಹೆಚ್ಚಾಗಿ £400+ ಎಂದು ಉಲ್ಲೇಖಿಸಲ್ಪಡುತ್ತದೆ (ಅಧಿಕ ಹಾಸಿಗೆ ದಿನಗಳಿಗೆ ರಾಷ್ಟ್ರೀಯ ವೆಚ್ಚ ಸಂಗ್ರಹ ಐತಿಹಾಸಿಕವಾಗಿ ~£350) — ಆದರೆ [ಸೀಮಾಂತ vs ಸರಾಸರಿ ವೆಚ್ಚ](../ಸೀಮಾಂತ-vs-ಸರಾಸರಿ-ವೆಚ್ಚ/) ನೋಡಿ: ಸರಾಸರಿ ಬಹುತೇಕ ಎಂದಿಗೂ ಉಳಿತಾಯವಲ್ಲ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ದೂರಸ್ಥ-ಮೇಲ್ವಿಚಾರಣೆಯ "ವರ್ಚುವಲ್ ವಾರ್ಡ್" ವರ್ಷಕ್ಕೆ 600 ರೋಗಿಗಳನ್ನು 2 ದಿನ ಬೇಗ ಮನೆಗೆ ಹೋಗಲು ಅನುಮತಿಸುತ್ತದೆ: 1,200 ಹಾಸಿಗೆ ದಿನಗಳು ಉಳಿತಾಯ.

- **ಮುಗ್ಧ ಹೇಳಿಕೆ**: 1,200 × £400 = £480,000. ವಾರ್ಡ್ ಮುಚ್ಚದ ಹೊರತು ತಪ್ಪು.
- **ಪ್ರಾಮಾಣಿಕ ಹೇಳಿಕೆ**: ಟ್ರಸ್ಟ್ ಹಾಸಿಗೆಗಳನ್ನು ಯೋಜಿತ ಮೂಳೆ ರೋಗಿಗಳಿಂದ ಮರುತುಂಬುತ್ತದೆ. 1,200 ಹಾಸಿಗೆ ದಿನಗಳು ÷ 3-ದಿನ ಸರಾಸರಿ ವಾಸ = ಚಟುವಟಿಕೆ-ಆಧಾರಿತ ಪಾವತಿಯಡಿ ಪ್ರತಿಯೊಂದಕ್ಕೂ ~£6,000 ಆದಾಯದ 400 ಹೆಚ್ಚುವರಿ ಯೋಜಿತ ಅವಧಿಗಳು = **£2.4M ಹೆಚ್ಚುವರಿ ಹಣ ನೀಡಿದ ಚಟುವಟಿಕೆ** (ಆ ರೋಗಿಗಳಿಗೆ ಚಿಕಿತ್ಸೆ ನೀಡುವ ಸೀಮಾಂತ ವೆಚ್ಚ ಕಳೆದು), *ಜೊತೆಗೆ* ಕಾಯುವ ಪಟ್ಟಿಯಿಂದ 400 ರೋಗಿಗಳು ಹೊರಗೆ. ವರ್ಚುವಲ್ ವಾರ್ಡ್‌ನ ನಿರ್ವಹಣಾ ವೆಚ್ಚ (£350,000) ಇದರ ವಿರುದ್ಧ ನಿವ್ವಳವಾಗುತ್ತದೆ.

*ಮರುಬಳಕೆ*ಯಾದ ಖಾಲಿ ಸಾಮರ್ಥ್ಯ ಆಗಾಗ ಮುಗ್ಧ ನಗದು ಹೇಳಿಕೆಗಿಂತ ಹೆಚ್ಚು ಮೌಲ್ಯಯುತ — ಆದರೆ ಅದು ಬೇರೆ ಸ್ವರೂಪದ ಮೌಲ್ಯ ಮತ್ತು ಅದಕ್ಕೆ ಹಾಗೆಯೇ ಲೇಬಲ್ ಹಾಕಬೇಕು ([ನಗದು-ಬಿಡುಗಡೆ vs ನಗದು-ರಹಿತ](../ನಗದು-ಬಿಡುಗಡೆ-vs-ನಗದು-ರಹಿತ-ಉಳಿತಾಯ/)).

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

"ಉಳಿತಾಯವಾದ ಸರ್ವರ್ ದಿನಗಳು" ಅದೇ ರೀತಿ ವರ್ತಿಸುತ್ತವೆ. ಯಾವಾಗಲೂ-ಚಾಲನೆಯಲ್ಲಿರುವ ಪರಿಸರಗಳನ್ನು ಸ್ಥಗಿತಗೊಳಿಸುವುದು ಇನ್‌ಸ್ಟೆನ್ಸ್‌ಗಳು ಕೊನೆಗೊಂಡಾಗ ಅಥವಾ ಕಾದಿರಿಸುವಿಕೆಗಳು ಮುಗಿದಾಗ ಮಾತ್ರ ನಗದು ಬಿಡುಗಡೆ ಮಾಡುತ್ತದೆ; ಪೂಲ್‌ಗೆ ಮರಳಿ ಹೀರಲ್ಪಟ್ಟ ಸಾಮರ್ಥ್ಯ ಅದರ ಸೀಮಾಂತ ವೆಚ್ಚಕ್ಕೆ (ಬದ್ಧ ವೆಚ್ಚದಲ್ಲಿ ~0) ಯೋಗ್ಯ. ಸಮಾನಾಂತರ ಶಿಸ್ತು: ಹೇಳಿಕೊಂಡ ಪ್ರತಿ ಉಳಿತಾಯಕ್ಕೂ *ಕಾರ್ಯವಿಧಾನವನ್ನು* ಹೆಸರಿಸಿ — ಕೊನೆಗೊಳಿಸಲಾಗಿದೆ, ಮೌಲ್ಯಯುತ ಕೆಲಸದಿಂದ ಮರುತುಂಬಲಾಗಿದೆ, ಅಥವಾ ಆವಿಯಾಗಿದೆ. ಆಸ್ಪತ್ರೆ ವಾಸದ ಅವಧಿಯನ್ನು ಕಡಿಮೆ ಮಾಡುವ ಸಾಫ್ಟ್‌ವೇರ್ (ಡಿಸ್ಚಾರ್ಜ್ ಸಮನ್ವಯ, ದೂರಸ್ಥ ಮೇಲ್ವಿಚಾರಣೆ, ರೋಗನಿರ್ಣಯ ತಿರುಗುವ ಸಮಯ) ಮೂರೂ ಸನ್ನಿವೇಶಗಳನ್ನು ಮಾದರಿ ಮಾಡಬೇಕು ಮತ್ತು ಟ್ರಸ್ಟ್ ಪ್ರತಿ ವಾರ್ಡ್‌ಗೆ ಆರಿಸಲು ಬಿಡಬೇಕು.

## ಎಡವಟ್ಟುಗಳು

- ಸೀಮಾಂತ ಸಾಮರ್ಥ್ಯಕ್ಕೆ **ಸರಾಸರಿ-ವೆಚ್ಚ ಮೌಲ್ಯಮಾಪನ** — ಶ್ರೇಷ್ಠ ತಪ್ಪು.
- **ದ್ವಿ-ಎಣಿಕೆ**: ಅದೇ ಖಾಲಿ ಹಾಸಿಗೆಯಿಂದ ಉಳಿತಾಯವಾದ ಹಾಸಿಗೆ ದಿನಗಳು *ಮತ್ತು* ತಪ್ಪಿಸಿದ ದಾಖಲಾತಿಗಳು *ಮತ್ತು* ಕಾಯುವ ಪಟ್ಟಿ ಕಡಿತ.
- **ಉಳಿತಾಯವಾದ ದಿನಗಳು ದುಬಾರಿ ದಿನಗಳು ಎಂದು ಭಾವಿಸುವುದು**: ವಾಸದ ಕೊನೆಯಲ್ಲಿ ಉಳಿತಾಯವಾದ ದಿನಗಳು ಅತ್ಯಂತ ಅಗ್ಗ (ಕಡಿಮೆ-ತೀವ್ರತೆಯ) ದಿನಗಳು.
