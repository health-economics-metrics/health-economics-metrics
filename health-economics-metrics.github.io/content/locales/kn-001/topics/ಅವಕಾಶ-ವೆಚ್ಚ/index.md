# ಅವಕಾಶ ವೆಚ್ಚ

ಅವಕಾಶ ವೆಚ್ಚ ಎಂದರೆ ನೀವು ಒಂದು ಸಂಪನ್ಮೂಲವನ್ನು ಬದ್ಧಗೊಳಿಸಿದಾಗ ಬಿಟ್ಟುಕೊಡುವ ಅತ್ಯುತ್ತಮ ಪರ್ಯಾಯದ ಮೌಲ್ಯ. ನಿಗದಿತ ಬಜೆಟ್ ಇರುವ ಆರೋಗ್ಯ ವ್ಯವಸ್ಥೆಯಲ್ಲಿ, ಒಂದು ವಿಷಯದ ಮೇಲೆ £1 ಮಿಲಿಯನ್ ಖರ್ಚು ಮಾಡುವುದೆಂದರೆ ಬೇರೆಲ್ಲೋ £1 ಮಿಲಿಯನ್ ಮೌಲ್ಯದ ಆರೋಗ್ಯ *ಉತ್ಪಾದನೆಯಾಗದೆ* ಹೋಗುವುದು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಅವಕಾಶ ವೆಚ್ಚವು ಆರೋಗ್ಯ ಅರ್ಥಶಾಸ್ತ್ರದ ಅತ್ಯಂತ ಆಳವಾದ ಆಲೋಚನೆ, ಮತ್ತು ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರ್‌ಗಳು ಹೆಚ್ಚಾಗಿ ಬಿಟ್ಟುಬಿಡುವುದು ಇದನ್ನೇ. ಆರೋಗ್ಯ ಬಜೆಟ್‌ಗಳು ಯಾವುದೇ ವರ್ಷದಲ್ಲಿ ನಿಗದಿತವಾಗಿರುತ್ತವೆ, ಆದ್ದರಿಂದ ಹೊಸ ತಂತ್ರಜ್ಞಾನಕ್ಕೆ "ಹೆಚ್ಚುವರಿ" ಹಣದಿಂದ ಎಂದಿಗೂ ಹಣ ಒದಗುವುದಿಲ್ಲ — ಅದು ಬೇರೊಂದನ್ನು ಸ್ಥಾನಪಲ್ಲಟಗೊಳಿಸುತ್ತದೆ. ಪಾವತಿದಾರರು ನಿಜವಾಗಿ ಕೇಳುವ ಪ್ರಶ್ನೆ "ಇದು ಒಳ್ಳೆಯದೇ?" ಅಲ್ಲ, "ಅದೇ ಹಣ ಈಗ ಖರೀದಿಸುತ್ತಿರುವುದಕ್ಕಿಂತ ಇದು ಉತ್ತಮವೇ?" ಎಂಬುದು.

ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ಮಿತಿಗಳು ಅಸ್ತಿತ್ವದಲ್ಲಿರಲು ಇದೇ ಕಾರಣ: ಮಿತಿಯು ಪ್ರಸ್ತುತ ವ್ಯವಸ್ಥೆಯ ಅಂಚಿನಲ್ಲಿ ಆ ಹಣ ಖರೀದಿಸುವ ಆರೋಗ್ಯದ ಅಂದಾಜು. [ಪಾವತಿಸಲು ಇಚ್ಛೆಯ ಮಿತಿಗಳು](../ಪಾವತಿಸಲು-ಇಚ್ಛೆಯ-ಮಿತಿಗಳು/) ನೋಡಿ.

## ಗಣಿತ

ಯಾವುದೇ ಒಂದು ಸೂತ್ರವಿಲ್ಲ; ಅವಕಾಶ ವೆಚ್ಚವು ಹೋಲಿಕೆಯ ಶಿಸ್ತು:

```
Opportunity cost of choosing A = value of best forgone alternative B
Net gain from A = value(A) − value(B)
```

ಅನುಭವಾಧಾರಿತ ಮಾನದಂಡ: Claxton ಮತ್ತು ಇತರರು (2015) NHS ಅಂಚಿನಲ್ಲಿ ಸುಮಾರು **£13,000**ಗೆ ಒಂದು QALY ಉತ್ಪಾದಿಸುತ್ತದೆ ಎಂದು ಅಂದಾಜಿಸಿದರು. ಆದ್ದರಿಂದ ಒಂದು QALYಗಿಂತ ಕಡಿಮೆ ಉತ್ಪಾದಿಸುವ ತಂತ್ರಜ್ಞಾನದ ಮೇಲೆ £13,000 ಖರ್ಚು ಮಾಡಿದರೆ, ಆ ತಂತ್ರಜ್ಞಾನ "ಕೆಲಸ ಮಾಡಿದರೂ" ರಾಷ್ಟ್ರವು *ಕಡಿಮೆ* ಆರೋಗ್ಯವಂತವಾಗುತ್ತದೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಒಂದು NHS ಟ್ರಸ್ಟ್‌ನ ಪರಿವರ್ತನಾ ಬಜೆಟ್ ಈ ಕೆಳಗಿನವುಗಳಲ್ಲಿ ಕೇವಲ ಒಂದನ್ನು ಮಾತ್ರ ಭರಿಸಬಲ್ಲದು:

- **ಆಯ್ಕೆ A**: ಇ-ರೋಸ್ಟರಿಂಗ್ ಸಾಫ್ಟ್‌ವೇರ್ — ಏಜೆನ್ಸಿ ಸಿಬ್ಬಂದಿ ವೆಚ್ಚದಲ್ಲಿ ವರ್ಷಕ್ಕೆ £400,000 ಉಳಿಸುತ್ತದೆ.
- **ಆಯ್ಕೆ B**: ಡಿಸ್ಚಾರ್ಜ್-ಸಮನ್ವಯ ಸಾಫ್ಟ್‌ವೇರ್ — ವರ್ಷಕ್ಕೆ 2,000 ಹಾಸಿಗೆ ದಿನಗಳನ್ನು ಉಳಿಸುತ್ತದೆ. ನಿಜವಾಗಿ ಖಾಲಿಯಾದ ಪ್ರತಿ ಹಾಸಿಗೆ ದಿನಕ್ಕೆ ಸುಮಾರು £150 ಸೀಮಾಂತ ವೆಚ್ಚದಲ್ಲಿ, ಅದು ವರ್ಷಕ್ಕೆ £300,000, ಜೊತೆಗೆ ಕಾಯುತ್ತಿರುವ ರೋಗಿಗಳಿಗೆ ಬೇಗನೆ ಚಿಕಿತ್ಸೆ.

A ಗೆ ಹಣ ನೀಡುವುದೆಂದರೆ B ಅನ್ನು ಬಿಟ್ಟುಕೊಡುವುದು. A ಯ ಅವಕಾಶ ವೆಚ್ಚ B ಯ £300,000 + ರೋಗಿಯ ಲಾಭ; A ಪರವಾದ *ನಿವ್ವಳ* ವಾದ ಕೇವಲ ವ್ಯತ್ಯಾಸ, A ಯ ಪ್ರಧಾನ ಅಂಕಿ £400,000 ಅಲ್ಲ. ಪ್ರಸ್ತಾವನೆಯನ್ನು ಅತ್ಯುತ್ತಮ ಪರ್ಯಾಯದ ಬದಲು "ಏನೂ ಮಾಡದಿರುವುದರ" ಜೊತೆ ಹೋಲಿಸುವ ಯಾವುದೇ ವ್ಯವಹಾರ ಪ್ರಕರಣವು ಅದರ ಮೌಲ್ಯವನ್ನು ಉತ್ಪ್ರೇಕ್ಷಿಸುತ್ತದೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಎಂಜಿನಿಯರಿಂಗ್ ಸಾಮರ್ಥ್ಯವೂ ನಿಗದಿತ ಬಜೆಟ್ ಆಗಿದೆ — ಪೌಂಡ್‌ಗಳಲ್ಲ, ರೋಡ್‌ಮ್ಯಾಪ್ ಸ್ಲಾಟ್‌ಗಳು. ಟೂಲ್ B ಅದೇ ಕೆಲಸವನ್ನು ಗಂಟೆಗೆ £200ಕ್ಕೆ ಮಾಡುವಾಗ, ಎಂಜಿನಿಯರ್-ಗಂಟೆಗಳನ್ನು ಗಂಟೆಗೆ £500ಕ್ಕೆ ಉಳಿಸುವ ಟೂಲ್ A ಗೆ ಹಣ ನೀಡುವ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ತಂಡವು, ಪ್ರತಿ QALYಗೆ £40,000 ವೆಚ್ಚದ ಔಷಧಕ್ಕೆ ಹಣ ನೀಡಿ ಪ್ರತಿ QALYಗೆ £13,000 ಆರೈಕೆಯನ್ನು ಸ್ಥಾನಪಲ್ಲಟಗೊಳಿಸುವ ಆರೋಗ್ಯ ವ್ಯವಸ್ಥೆಯಂತೆಯೇ ಸಾಮರ್ಥ್ಯವನ್ನು ನಾಶಮಾಡುತ್ತದೆ. ಈ ಶಿಸ್ತು ನೇರವಾಗಿ ವರ್ಗಾವಣೆಯಾಗುತ್ತದೆ:

- ಯಾವಾಗಲೂ ಹೋಲಿಕೆಯ ಆಧಾರವನ್ನು ಹೆಸರಿಸಿ ("ಯಾವುದರ ವಿರುದ್ಧ?").
- ಎಂಜಿನಿಯರ್ ಸಮಯಕ್ಕೆ ವೇತನದ ಮೇಲೆ ಮಾತ್ರವಲ್ಲ, ಅದು ಇಲ್ಲದಿದ್ದರೆ ಉತ್ಪಾದಿಸುತ್ತಿದ್ದ ಮೌಲ್ಯದ ಆಧಾರದಲ್ಲಿ ಬೆಲೆ ಕಟ್ಟಿ.
- "ನಮ್ಮ ಬಳಿ ಬಜೆಟ್ ಉಳಿದಿದೆ" ಎಂಬುದನ್ನು ವಿಶ್ಲೇಷಣೆಯ ಅಂತ್ಯವಲ್ಲ, ಆರಂಭ ಎಂದು ಪರಿಗಣಿಸಿ.

## ಎಡವಟ್ಟುಗಳು

- **ಏನೂ ಇಲ್ಲದ್ದರ ವಿರುದ್ಧ ಹೋಲಿಸುವುದು.** ಸರಿಯಾದ ಹೋಲಿಕೆ ಆಧಾರ ಹಣದ ಮುಂದಿನ-ಅತ್ಯುತ್ತಮ ಬಳಕೆ, ಅದು ಅಪರೂಪವಾಗಿ "ಏನೂ ಮಾಡದಿರುವುದು".
- **ಉಳಿತಾಯವಾದ ಸಮಯಕ್ಕೆ ಶೂನ್ಯ ಅವಕಾಶ ವೆಚ್ಚ ಎಂದು ಭಾವಿಸುವುದು.** ಉಳಿತಾಯವಾದ ಸಮಯವು ಮೌಲ್ಯಯುತವಾದುದಕ್ಕೆ ಮರುಬಳಕೆಯಾದರೆ ಮಾತ್ರ ಮೌಲ್ಯಯುತ — [ನಗದು-ಬಿಡುಗಡೆ vs ನಗದು-ರಹಿತ ಉಳಿತಾಯ](../ನಗದು-ಬಿಡುಗಡೆ-vs-ನಗದು-ರಹಿತ-ಉಳಿತಾಯ/) ನೋಡಿ.
- **ಸ್ಥಾನಪಲ್ಲಟವನ್ನು ಕಡೆಗಣಿಸುವುದು.** "ಬಜೆಟ್ ಹೊಂದಿಕೊಳ್ಳುವಂತೆ ವಿಸ್ತರಿಸುತ್ತದೆ" ಎಂಬುದು ರಾಷ್ಟ್ರೀಯ ಆರೋಗ್ಯ ಸೇವೆಯಲ್ಲಿ ವರ್ಷದೊಳಗೆ ಬಹುತೇಕ ಎಂದಿಗೂ ನಿಜವಲ್ಲ.
- **ಸ್ಥಾನಪಲ್ಲಟಗೊಂಡ ಸಂಪನ್ಮೂಲಕ್ಕೆ ಯಾವ ವಿಧಾನ ಬೆಲೆ ಕಟ್ಟುತ್ತದೆ ಎಂಬುದನ್ನು ಕಡೆಗಣಿಸುವುದು.** ವಿಶೇಷವಾಗಿ ಅನಾರೋಗ್ಯ, ಅಂಗವೈಕಲ್ಯ ಅಥವಾ ಹೊರಹೋಗುವ ಉದ್ಯೋಗಿಯಿಂದ ಕಳೆದುಹೋದ ಉತ್ಪಾದಕತೆಗೆ — ಈ ಆಲೋಚನೆಯ ಉತ್ಪಾದಕತಾ-ವೆಚ್ಚ-ನಿರ್ದಿಷ್ಟ ಆವೃತ್ತಿಯಾದ [ಮಾನವ ಬಂಡವಾಳ ವಿಧಾನ vs ಘರ್ಷಣೆ ವೆಚ್ಚ ವಿಧಾನ](../ಮಾನವ-ಬಂಡವಾಳ-ವಿಧಾನ-vs-ಘರ್ಷಣೆ-ವೆಚ್ಚ-ವಿಧಾನ/) ನೋಡಿ.
