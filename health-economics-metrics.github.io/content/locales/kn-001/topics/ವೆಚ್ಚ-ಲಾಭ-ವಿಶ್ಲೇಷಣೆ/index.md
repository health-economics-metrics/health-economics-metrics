# ವೆಚ್ಚ-ಲಾಭ ವಿಶ್ಲೇಷಣೆ (CBA)

CBA ವೆಚ್ಚಗಳು *ಮತ್ತು* ಫಲಿತಾಂಶಗಳೆರಡಕ್ಕೂ ಹಣದಲ್ಲಿ ಬೆಲೆ ಕಟ್ಟುತ್ತದೆ. "ಯಾವ ಆಯ್ಕೆ ಉತ್ತಮ?" ಎಂದು ಮಾತ್ರವಲ್ಲ, "ಇದನ್ನು ಮಾಡುವುದು ಯೋಗ್ಯವೇ?" ಎಂದು ಉತ್ತರಿಸಬಲ್ಲ ಏಕೈಕ ವಿಶ್ಲೇಷಣಾ ವಿಧ ಇದು, ಏಕೆಂದರೆ ಹಣದ ರೂಪಕ್ಕೆ ಪರಿವರ್ತಿಸಿದ ಲಾಭಗಳನ್ನು ವೆಚ್ಚಗಳ ವಿರುದ್ಧ ನೇರವಾಗಿ ಹೋಲಿಸಬಹುದು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಫಲಿತಾಂಶಗಳನ್ನು ಹಣದ ರೂಪಕ್ಕೆ ಪರಿವರ್ತಿಸಲು ಸಾಧ್ಯವಾದಾಗ ಆರೋಗ್ಯ ಸೇರಿದಂತೆ ಎಲ್ಲ ಸಾರ್ವಜನಿಕ ವೆಚ್ಚ ಮೌಲ್ಯಮಾಪನಕ್ಕೆ CBA ಯುಕೆಯ HM ಖಜಾನೆ **ಗ್ರೀನ್ ಬುಕ್**ನ ಮಾನದಂಡ. [CEA](../ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ವಿಶ್ಲೇಷಣೆ/)/[CUA](../ವೆಚ್ಚ-ಉಪಯುಕ್ತತಾ-ವಿಶ್ಲೇಷಣೆ/) "ಆರೋಗ್ಯದ ಪ್ರತಿ ಘಟಕಕ್ಕೆ ವೆಚ್ಚ"ದಲ್ಲಿ ನಿಲ್ಲುವಲ್ಲಿ, CBA ಆರೋಗ್ಯಕ್ಕೇ (QALY × ಮಿತಿ ಮೌಲ್ಯ) ಮತ್ತು ಇತರ ಎಲ್ಲದಕ್ಕೂ — ಸಮಯ, ಪ್ರಯಾಣ, ಕಾರ್ಬನ್ — ಬೆಲೆ ಕಟ್ಟಿ ಒಂದು ನಿವ್ವಳ ಅಂಕಿಯನ್ನು ವರದಿ ಮಾಡುತ್ತದೆ. ಪ್ರತಿ ಪೂರ್ಣ NHS ಡಿಜಿಟಲ್ ವ್ಯವಹಾರ ಪ್ರಕರಣವೂ CBA-ಆಕಾರದ ಆರ್ಥಿಕ ಪ್ರಕರಣವನ್ನು ಒಳಗೊಂಡಿರುತ್ತದೆ.

## ಗಣಿತ

```
NPV (net present social value) = Σ_t [ (Benefits_t − Costs_t) / (1 + r)^t ]
BCR (benefit-cost ratio)       = PV(benefits) / PV(costs)

Adopt if NPV > 0 (equivalently BCR > 1); rank by NPV, not BCR.
r = 3.5% (Green Book social time preference rate)
```

ಆರೋಗ್ಯ ಪರಿಣಾಮಗಳು QALYs × λ ಆಗಿ ಹಣದ ರೂಪದಲ್ಲಿ ಪ್ರವೇಶಿಸಬಹುದು ([ಪಾವತಿಸಲು ಇಚ್ಛೆಯ ಮಿತಿಗಳು](../ಪಾವತಿಸಲು-ಇಚ್ಛೆಯ-ಮಿತಿಗಳು/) ನೋಡಿ). ಗ್ರೀನ್ ಬುಕ್ **ಆಶಾವಾದ-ಪಕ್ಷಪಾತ ಹೊಂದಾಣಿಕೆಗಳನ್ನೂ** ಕಡ್ಡಾಯಗೊಳಿಸುತ್ತದೆ — ವೆಚ್ಚ ಅಂದಾಜುಗಳನ್ನು ಹೆಚ್ಚಿಸುವುದು ಮತ್ತು ಲಾಭಗಳನ್ನು ಸಾಕ್ಷ್ಯ-ಆಧಾರಿತ ಶೇಕಡಾವಾರುಗಳಲ್ಲಿ ಕತ್ತರಿಸುವುದು, ಏಕೆಂದರೆ ಮೌಲ್ಯಮಾಪನಗಳು ವ್ಯವಸ್ಥಿತವಾಗಿ ಗುಲಾಬಿ ಬಣ್ಣದವು.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಇ-ರೆಫರಲ್ ವ್ಯವಸ್ಥೆ, 5-ವರ್ಷದ ಗಡಿ, 3.5% ರಿಯಾಯಿತಿ:

```
Costs:    build £1.2M (year 0), run £300k/yr (years 1–5)
Benefits: admin savings £250k/yr, avoided duplicate diagnostics £280k/yr,
          patient time saved 40,000 hrs/yr × £15 = £600k/yr → £1,130k/yr

PV costs    = 1,200k + 300k × 4.515 (annuity factor) = £2,555k
PV benefits = 1,130k × 4.515                          = £5,102k

NPV = 5,102 − 2,555 = +£2,547k     BCR = 2.0
```

ಗ್ರೀನ್ ಬುಕ್ ಆಶಾವಾದ ಪಕ್ಷಪಾತ ಅನ್ವಯಿಸಿ (ಉದಾ., ನಿರ್ಮಾಣ ವೆಚ್ಚದ ಮೇಲೆ +40%, ಲಾಭಗಳ ಮೇಲೆ −20%): PV ವೆಚ್ಚಗಳು ≈ £3,035k, PV ಲಾಭಗಳು ≈ £4,082k, NPV ≈ **+£1,047k** — ಇನ್ನೂ ಧನಾತ್ಮಕ, ಇದೇ ಹೊಂದಾಣಿಕೆಯ ಉದ್ದೇಶ: ಪ್ರಕರಣಗಳು ತಮ್ಮದೇ ಆಶಾವಾದವನ್ನು ಮೀರಿ ಉಳಿಯಬೇಕು.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಎಂಜಿನಿಯರಿಂಗ್ ವ್ಯವಹಾರ ಪ್ರಕರಣಗಳು ಅನೌಪಚಾರಿಕ CBAಗಳು. ಕದಿಯಲು ಯೋಗ್ಯ ಗ್ರೀನ್ ಬುಕ್ ಉನ್ನತೀಕರಣಗಳು:

- **ಪ್ರಮಾಣಿತ ಹೆಚ್ಚಳವಾಗಿ ಆಶಾವಾದ ಪಕ್ಷಪಾತ** — ಸಚಿವಾಲಯಗಳು ಮೂಲಸೌಕರ್ಯ ವೆಚ್ಚವನ್ನು ಕಡಿಮೆ ಅಂದಾಜಿಸುವಷ್ಟೇ ವಿಶ್ವಾಸಾರ್ಹವಾಗಿ ಎಂಜಿನಿಯರ್‌ಗಳು ಸ್ಥಳಾಂತರ ವೆಚ್ಚವನ್ನು ಕಡಿಮೆ ಅಂದಾಜಿಸುತ್ತಾರೆ; ಈ ಬಾರಿ ಬೇರೆ ಎಂದು ನಟಿಸುವ ಬದಲು ಹೇಳಿದ ಹೆಚ್ಚಳ ಅನ್ವಯಿಸಿ.
- **ಪ್ರಮುಖ ಲಾಭಕ್ಕೆ ಪ್ರಾಮಾಣಿಕವಾಗಿ ಹಣದ ಮೌಲ್ಯ ಕಟ್ಟಿ, ಅಥವಾ ಬೇಡ** — ರೋಗಿ/ಬಳಕೆದಾರರ ಸಮಯಕ್ಕೆ ಸಮರ್ಥನೀಯ ದರಗಳಲ್ಲಿ ಬೆಲೆ ಕಟ್ಟಲಾಗುತ್ತದೆ; "ಬ್ರಾಂಡ್ ಮೌಲ್ಯ" ಅಲ್ಲ.
- **NPV ಶ್ರೇಣೀಕರಿಸುತ್ತದೆ, BCR ಅಲ್ಲ**: BCR 5 ಇರುವ ಚಿಕ್ಕ ಯೋಜನೆ BCR 1.6 ಇರುವ ದೊಡ್ಡದಕ್ಕಿಂತ ಕಡಿಮೆ ಮುಖ್ಯವಾಗಬಹುದು.

## ಎಡವಟ್ಟುಗಳು

- ಲಾಭಗಳನ್ನು ಉಬ್ಬಿಸಲು **ಹಣದ ರೂಪಕ್ಕೆ ಪರಿವರ್ತಿಸಲಾಗದ್ದನ್ನು ಪರಿವರ್ತಿಸುವುದು** (ಮನೋಬಲ, "ಕಾರ್ಯತಂತ್ರದ ಹೊಂದಾಣಿಕೆ") — [ವೆಚ್ಚ-ಪರಿಣಾಮ ವಿಶ್ಲೇಷಣೆ](../ವೆಚ್ಚ-ಪರಿಣಾಮ-ವಿಶ್ಲೇಷಣೆ/) ಪ್ರಕಾರ ಅವನ್ನು ಗುಣಾತ್ಮಕವಾಗಿಡಿ.
- **ವರ್ಗಾವಣೆಗಳನ್ನು ಲಾಭಗಳೆಂದು ಲೆಕ್ಕಿಸುವುದು**: ಸಾರ್ವಜನಿಕ ಸಂಸ್ಥೆಗಳ ನಡುವೆ ಚಲಿಸುವ ಹಣ ಸಾಮಾಜಿಕ [ದೃಷ್ಟಿಕೋನ](../ವಿಶ್ಲೇಷಣಾ-ದೃಷ್ಟಿಕೋನ/)ದಲ್ಲಿ ಶೂನ್ಯಕ್ಕೆ ನಿವ್ವಳವಾಗುತ್ತದೆ.
- **ಪ್ರತಿವಾಸ್ತವ ಇಲ್ಲದಿರುವುದು**: ಲಾಭಗಳನ್ನು ಕನಿಷ್ಠ-ಮಾಡುವ ಆಯ್ಕೆಯ ವಿರುದ್ಧ ಅಳೆಯಲಾಗುತ್ತದೆ, ಶೂನ್ಯದ ವಿರುದ್ಧವಲ್ಲ.
