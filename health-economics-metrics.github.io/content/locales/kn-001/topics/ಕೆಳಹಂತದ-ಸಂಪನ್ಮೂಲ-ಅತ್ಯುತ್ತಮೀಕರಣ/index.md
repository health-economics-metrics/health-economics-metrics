# ಕೆಳಹಂತದ ಸಂಪನ್ಮೂಲ ಅತ್ಯುತ್ತಮೀಕರಣ

ಹಿರಿಯ ವೈದ್ಯನಿಗೆ — GP, ಹಿರಿಯ ರೆಜಿಸ್ಟ್ರಾರ್, ಸಲಹೆಗಾರ — ಒಂದು ಗಂಟೆ ಉಳಿಸುವುದು ಕ್ಲಿನಿಕಲ್ ಸಹಿಗಾಗಿ ಕಾಯುವ ದಾದಿಯರು, ಆಡಳಿತ ಗುಮಾಸ್ತರು ಮತ್ತು ಚಿಕಿತ್ಸಕರ ಇಡೀ ಬಹು-ವಿಭಾಗೀಯ ತಂಡದ (MDT) ಅಡಚಣೆ ವಿಳಂಬಗಳನ್ನು ಹೆಚ್ಚಾಗಿ ತಡೆಯುತ್ತದೆ. ಅಡಚಣೆಯನ್ನು ತೆರವುಗೊಳಿಸುವ ಮೌಲ್ಯ ಅದರ ಕೆಳಹಂತದ ಎಲ್ಲರ ಥ್ರೂಪುಟ್.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಆರೋಗ್ಯ ಸೇವೆ ಅಧಿಕಾರ ಸರಪಳಿಗಳ ಮೇಲೆ ನಡೆಯುತ್ತದೆ: ಬಿಡುಗಡೆಗಳು ಸಲಹೆಗಾರರ ಸಹಿಗಾಗಿ ಕಾಯುತ್ತವೆ, ಚಿಕಿತ್ಸಾ ಯೋಜನೆಗಳು MDT ವಿಮರ್ಶೆಗಾಗಿ ಕಾಯುತ್ತವೆ, ಉಲ್ಲೇಖಗಳು ಟ್ರಯಾಜ್‌ಗಾಗಿ ಕಾಯುತ್ತವೆ. ದ್ವಾರಪಾಲಕ ಪಾತ್ರ ವಿಳಂಬವಾದಾಗ, ವೆಚ್ಚ ಒಬ್ಬರ ಗಂಟೆಯಲ್ಲ — ಪ್ರತಿ ಅವಲಂಬಿತ ಪಾತ್ರದಾದ್ಯಂತ ನಿಷ್ಕ್ರಿಯ ಅಥವಾ ತಡೆಹಿಡಿದ ಸಮಯ, ಜೊತೆಗೆ ಅಂತರ್ಮುಖಿ ರೋಗಿ ಸಮಯ (ಹೆಚ್ಚುವರಿ [ಹಾಸಿಗೆ ದಿನಗಳು](../ಉಳಿತಾಯವಾದ-ಹಾಸಿಗೆ-ದಿನಗಳು/), ದೀರ್ಘ [RTT ಕಾಯುವಿಕೆ](../ಚಿಕಿತ್ಸೆಗೆ-ಉಲ್ಲೇಖ/)). ಇದು ಕ್ಲಿನಿಕಲ್ ಮಾರ್ಗಗಳಿಗೆ ಅನ್ವಯಿಸಿದ ನಿರ್ಬಂಧಗಳ ಸಿದ್ಧಾಂತ: *ನಿರ್ಬಂಧದಲ್ಲಿ* ಉಳಿಸಿದ ಒಂದು ಗಂಟೆ ಇಡೀ ವ್ಯವಸ್ಥೆಯ ಸೀಮಾಂತ ಥ್ರೂಪುಟ್‌ಗೆ ಯೋಗ್ಯ; ಬೇರೆಡೆ ಉಳಿಸಿದ ಗಂಟೆ ಬಹಳ ಕಡಿಮೆ.

## ಗಣಿತ

```
Value of unblocking = Σ over downstream roles (blocked hours released × unit cost)
                    + pathway throughput gain × value per pathway completion

Contrast: value of the same hour saved at a non-gating role ≈ that role's
capacity value alone (see practitioner-time.md).
```

ನಿರ್ಬಂಧವನ್ನು ಪ್ರಾಯೋಗಿಕವಾಗಿ ಗುರುತಿಸಿ: ಕೆಲಸ ಎಲ್ಲಿ ಅತಿ ದೀರ್ಘ ಸರತಿಯಲ್ಲಿರುತ್ತದೆ? ವಿಳಂಬಗಳು ಯಾರ ಇನ್‌ಬಾಕ್ಸ್‌ಗೆ ಹಿಂತಿರುಗುತ್ತವೆ?

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ವಾರ್ಡ್‌ನ ಬಿಡುಗಡೆಗಳಿಗೆ ಪ್ರತಿ ಬೆಳಿಗ್ಗೆ ಸಲಹೆಗಾರರ ವಿಮರ್ಶೆ ಬೇಕು. ಸಲಹೆಗಾರ ವ್ಯವಸ್ಥೆಗಳಲ್ಲಿ ಹರಡಿದ ಮಾಹಿತಿಯನ್ನು ಸಂಗ್ರಹಿಸಲು ದಿನಕ್ಕೆ 90 ನಿಮಿಷ ಕಳೆಯುತ್ತಾರೆ; ವಿಮರ್ಶೆಗಳು 14:00ಕ್ಕೆ ಮುಗಿಯುತ್ತವೆ, ಮತ್ತು ದಿನಕ್ಕೆ 6 ಬಿಡುಗಡೆಗಳು ಆ ದಿನಕ್ಕೆ ತುಂಬಾ ತಡವಾಗಿ ಪೂರ್ಣಗೊಳ್ಳುತ್ತವೆ — ಪ್ರತಿಯೊಂದೂ ತಪ್ಪಿಸಬಹುದಾದ ಹಾಸಿಗೆ ದಿನದ ವೆಚ್ಚ.

ಬಿಡುಗಡೆ-ಸಾರಾಂಶ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ (ಪ್ರಯೋಗಾಲಯ, ಔಷಧಿಗಳು, ಎಚ್ಚರಿಕೆಗಳು ಒಂದೇ ನೋಟದಲ್ಲಿ) ಸಂಗ್ರಹಣೆಯನ್ನು 20 ನಿಮಿಷಕ್ಕೆ ಇಳಿಸುತ್ತದೆ; ವಿಮರ್ಶೆಗಳು 11:30ಕ್ಕೆ ಮುಗಿಯುತ್ತವೆ:

```
Bed days avoided     = 4 of the 6 late discharges × 365 ≈ 1,460 bed days/year
Downstream unblocking: 2 discharge coordinators + pharmacy + transport
                       previously idle-then-crunched each afternoon —
                       ~3 staff-hours/day of blocked time released ≈ 1,100 hrs/yr
```

ಸಲಹೆಗಾರರ ಸ್ವಂತ 70 ನಿಮಿಷಗಳು ಮೌಲ್ಯದ *ಅತಿ ಚಿಕ್ಕ* ಭಾಗ — ಈ ಮಾಪನದ ತಿರುಳು. ಹಾಸಿಗೆ ದಿನಗಳಿಗೆ ಕಾರ್ಯವಿಧಾನದ ಮೂಲಕ ಮೌಲ್ಯ ಕಟ್ಟಿ ([ಉಳಿಸಿದ ಹಾಸಿಗೆ ದಿನಗಳು](../ಉಳಿತಾಯವಾದ-ಹಾಸಿಗೆ-ದಿನಗಳು/) ನೋಡಿ) ಮತ್ತು ಸಿಬ್ಬಂದಿ ಗಂಟೆಗಳನ್ನು ಸಾಮರ್ಥ್ಯವಾಗಿ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಇದು ಕೋಡ್ ವಿಮರ್ಶೆ, ವಾಸ್ತುಶಿಲ್ಪ ಸಹಿ, ಮತ್ತು ಸಿಬ್ಬಂದಿ ಎಂಜಿನಿಯರ್‌ನ ಇನ್‌ಬಾಕ್ಸ್. ವಿನ್ಯಾಸವನ್ನು ಅನುಮೋದಿಸಬಲ್ಲ ಒಬ್ಬ ವ್ಯಕ್ತಿಗಾಗಿ ಐವರು ಎಂಜಿನಿಯರ್‌ಗಳು ಒಂದು ದಿನ ಕಾದರೆ, ವೆಚ್ಚ ಒಬ್ಬ ವಿಮರ್ಶಕನ ಗಂಟೆಯಲ್ಲ — ಐದು ಎಂಜಿನಿಯರ್-ದಿನಗಳು ಜೊತೆಗೆ ಕೆಲಸದ ಮೇಲೆಯೇ ಒಂದು ದಿನದ [ವಿಳಂಬದ ವೆಚ್ಚ](../ವಿಳಂಬದ-ವೆಚ್ಚ/). ದ್ವಾರಪಾಲಕ ಪಾತ್ರದ ಕಾರ್ಯವನ್ನು ಸಂಕುಚಿತಗೊಳಿಸುವ ಸಾಧನಗಳು (ಉತ್ತಮ ವಿಮರ್ಶೆ ಸಂದರ್ಭ, ಸ್ವಯಂಚಾಲಿತ ಪೂರ್ವ-ಪರಿಶೀಲನೆಗಳು, ಅನುಮೋದಕನಿಗೆ ಬೇಕಾದದ್ದನ್ನು ಜೋಡಿಸುವ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ಗಳು) ವ್ಯವಸ್ಥೆಯ ಥ್ರೂಪುಟ್ ಖರೀದಿಸುತ್ತವೆ, ವೈಯಕ್ತಿಕ ಅನುಕೂಲವನ್ನಲ್ಲ. ನಿರ್ಬಂಧದಲ್ಲಿ ತೆಗೆದುಕೊಳ್ಳುವ/ಕಾಯುವ ಸಮಯವನ್ನು ಅಳೆಯಿರಿ ([ಹರಿವಿನ ಮಾಪನಗಳು](../ಹರಿವಿನ-ಮಾಪನಗಳು/) ನೋಡಿ) — ಇದು 14:00 ಬಿಡುಗಡೆ ಬಂಡೆಯ ಸಾಫ್ಟ್‌ವೇರ್ ಸಮಾನ.

## ಎಡವಟ್ಟುಗಳು

- **ನಿರ್ಬಂಧವಲ್ಲದ್ದನ್ನು ಅತ್ಯುತ್ತಮಗೊಳಿಸುವುದು**: ಯಾವುದೂ ಹಿಂದೆ ಸರತಿಯಲ್ಲಿ ನಿಲ್ಲದ ಪಾತ್ರಕ್ಕೆ ಸುಂದರ ಸಾಧನ ಸುಮಾರು ಶೂನ್ಯ ವ್ಯವಸ್ಥಾ ಮೌಲ್ಯ ನೀಡುತ್ತದೆ.
- **ನಿರ್ಬಂಧ ವಲಸೆ**: ಸಲಹೆಗಾರರನ್ನು ಮುಕ್ತಗೊಳಿಸಿದರೆ ನಿರ್ಬಂಧ ಚಲಿಸುತ್ತದೆ (ಔಷಧಾಲಯಕ್ಕೆ, ಸಾರಿಗೆಗೆ) — ಪೂರ್ಣ ಥ್ರೂಪುಟ್ ಲಾಭ ಹೇಳುವ ಮೊದಲು *ಮುಂದಿನ* ನಿರ್ಬಂಧವನ್ನು ಮಾದರಿ ಮಾಡಿ.
- **ಕೆಳಹಂತದ ಗಂಟೆಗಳನ್ನು ನಗದೆಂದು ಎಣಿಸುವುದು**: ತಡೆಹಿಡಿದ-ಸಮಯದ ಬಿಡುಗಡೆ ಸಾಮರ್ಥ್ಯ, ಸಾಮಾನ್ಯ [ಮರುನಿಯೋಜನೆ ಪರೀಕ್ಷೆ](../ನಗದು-ಬಿಡುಗಡೆ-vs-ನಗದು-ರಹಿತ-ಉಳಿತಾಯ/)ಗೆ ಒಳಪಟ್ಟಿದೆ.
