# ಒಟ್ಟು ಮಾಲೀಕತ್ವ ವೆಚ್ಚ (TCO)

TCO ಎಂದರೆ ವ್ಯವಸ್ಥೆಯ ಜೀವಿತಾವಧಿಯ ಪೂರ್ಣ ವೆಚ್ಚ: ಸ್ವಾಧೀನ ಅಥವಾ ನಿರ್ಮಾಣ, ಏಕೀಕರಣ, ಕಾರ್ಯಾಚರಣೆ, ನಿರ್ವಹಣೆ, ಬೆಂಬಲ, ತರಬೇತಿ ಮತ್ತು ಸೇವೆಯಿಂದ ತೆಗೆದುಹಾಕುವಿಕೆ. ಅಹಿತಕರ ಮೂಲರೇಖೆ: **ನಿರ್ವಹಣೆ ಸಾಫ್ಟ್‌ವೇರ್ TCOಯ 50–80%** — ಜೀವಿತಾವಧಿ ವೆಚ್ಚದ ಸುಮಾರು ಮುಕ್ಕಾಲು ಭಾಗ ಬಿಡುಗಡೆಯ *ನಂತರ* ಬರುತ್ತದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಔಷಧದ ಬೆಲೆ ಅದರ ವೆಚ್ಚವಲ್ಲ ಎಂದು ಆರೋಗ್ಯ ತಂತ್ರಜ್ಞಾನ ಮೌಲ್ಯಮಾಪನ ಬಹಳ ಹಿಂದೆಯೇ ಕಲಿತಿತು — ಆಡಳಿತ, ಮೇಲ್ವಿಚಾರಣೆ ಮತ್ತು ಅಡ್ಡ ಪರಿಣಾಮಗಳ ನಿರ್ವಹಣೆ ಎಲ್ಲವೂ ಮಾದರಿಯಲ್ಲಿ ಸೇರಬೇಕು. ನಿರ್ಮಾಣ/ಪರವಾನಗಿ ವೆಚ್ಚವನ್ನು ಮಾತ್ರ ಎಣಿಸುವ ಸಾಫ್ಟ್‌ವೇರ್ ವ್ಯಾಪಾರ ಸಮರ್ಥನೆಗಳು ಸರಳ-ಔಷಧ-ಬೆಲೆ ತಪ್ಪನ್ನು ಪುನರಾವರ್ತಿಸುತ್ತವೆ ಮತ್ತು ಅವು ಪೋಷಿಸುವ ಪ್ರತಿ [ICER](../ಹೆಚ್ಚುವರಿ-ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ಅನುಪಾತ/) ಮತ್ತು [ಬಜೆಟ್ ಪ್ರಭಾವ](../ಬಜೆಟ್-ಪರಿಣಾಮ-ವಿಶ್ಲೇಷಣೆ/)ದ ವೆಚ್ಚ ಬದಿಯನ್ನು ವ್ಯವಸ್ಥಿತವಾಗಿ ಕಡಿಮೆ ಹೇಳುತ್ತವೆ. NHS ಖರೀದಿಗೆ, TCO ಶಿಸ್ತು ಡಿಜಿಟಲ್ ಉತ್ಪನ್ನದ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ಹಕ್ಕನ್ನು ಪ್ರಾಮಾಣಿಕವಾಗಿಸುತ್ತದೆ — ಮತ್ತು ಅಗ್ಗವಾಗಿ ಕಾಣುವ ಆಯ್ಕೆಗಳು ಇಲ್ಲಿ ಸೋಲುತ್ತವೆ.

## ಗಣಿತ

```
TCO = initial cost (build/licence + integration + data migration + training)
    + Σ_t [operations + maintenance + support + infrastructure + upgrades
           + compliance/assurance]_t / (1 + r)^t
    + decommissioning cost (exit, data extraction, parallel running)

Horizon: 3–5 years commercial, system-lifetime for clinical infrastructure
r: 3.5% public sector (Green Book), 8–12% commercial
Benchmarks: annual maintenance ≈ 15–20% of build cost; ~78% of lifetime
TCO post-launch; ignore decommissioning and vendor lock-in prices itself.
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಇ-ವೀಕ್ಷಣೆ ವ್ಯವಸ್ಥೆಗೆ ಎರಡು ಆಯ್ಕೆಗಳು, 5-ವರ್ಷದ ಅವಧಿ:

```
                        Vendor SaaS     In-house build
Year 0 (licence/build)  £250,000        £900,000
Integration + training  £180,000        £150,000
Annual run (yrs 1–5)    £120,000/yr     £190,000/yr  (hosting + 1.5 FTE maint.)
Exit/decommission       £60,000         £30,000

Undiscounted TCO        £1,090,000      £2,030,000
```

ನಿರ್ಮಾಣ ಆಯ್ಕೆಯ ಎಂಜಿನಿಯರಿಂಗ್ ಅಂದಾಜು (£900k) ಅದರ ನಿಜ TCOಯ ಕೇವಲ 44% — ಮತ್ತು ನಿರ್ಮಾಣ ಅಂದಾಜುಗಳೇ ಸಾಮಾನ್ಯವಾಗಿ 30–40% ಮೀರುತ್ತವೆ ([ನಿರ್ಮಿಸು vs ಖರೀದಿಸು](../ನಿರ್ಮಿಸು-vs-ಖರೀದಿಸು/) ನೋಡಿ). ಆಂತರಿಕ ಆಯ್ಕೆ ಭೌತಿಕವಾಗಿ ಭಿನ್ನ *ಫಲಿತಾಂಶಗಳನ್ನು* ನೀಡದಿದ್ದರೆ, [ವೆಚ್ಚ-ಕನಿಷ್ಠೀಕರಣ](../ವೆಚ್ಚ-ಕನಿಷ್ಠೀಕರಣ-ವಿಶ್ಲೇಷಣೆ/) ತರ್ಕ ಅನ್ವಯಿಸುತ್ತದೆ ಮತ್ತು SaaS ~£940k ಅಂತರದಲ್ಲಿ ಗೆಲ್ಲುತ್ತದೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ನಿರ್ಮಾಣಗಳಿಗೆ ವಾದಿಸುವಾಗ ಎಂಜಿನಿಯರ್‌ಗಳು ತಮ್ಮದೇ ಕ್ಷೇತ್ರದ ನಿರ್ವಹಣೆ ದತ್ತಾಂಶಕ್ಕೆ ಕಡಿಮೆ ತೂಕ ನೀಡುತ್ತಾರೆ: ನಿರ್ಮಾಣ ವೆಚ್ಚದ 15–20% ವಾರ್ಷಿಕ ನಿರ್ವಹಣೆ ನಿಯಮ ಎಂದರೆ ಪ್ರತಿ £1M ವ್ಯವಸ್ಥೆ ಮೌನವಾಗಿ ವರ್ಷಕ್ಕೆ £150–200k ಭವಿಷ್ಯದ ಸಾಮರ್ಥ್ಯವನ್ನು ಬದ್ಧಗೊಳಿಸುತ್ತದೆ — [ತಾಂತ್ರಿಕ ಸಾಲ](../ತಾಂತ್ರಿಕ-ಸಾಲ/)ದ ಅದೇ ಮಾನಸಿಕ ಬ್ಯಾಲೆನ್ಸ್ ಶೀಟ್‌ಗೆ ಸೇರಬೇಕಾದ ಹೊಣೆಗಾರಿಕೆ. TCO ಈ ರೆಪೊಸಿಟರಿಯ ಪ್ರತಿ ಮಾಪನದ ವೆಚ್ಚ ಅರ್ಧವೂ ಹೌದು: ಪ್ರತಿ ನಿಯೋಜನೆಗೆ ವೆಚ್ಚ, [ಕ್ಲೌಡ್ ಘಟಕ ಅರ್ಥಶಾಸ್ತ್ರ](../ಕ್ಲೌಡ್-ಘಟಕ-ಅರ್ಥಶಾಸ್ತ್ರ/), ಮತ್ತು HTA ಔಷಧ ಪ್ರಾಯೋಜಕರ ಮೇಲೆ ಜಾರಿಗೊಳಿಸುವ ಛೇದ ಶಿಸ್ತು. ನಿಮ್ಮ ಉತ್ಪನ್ನದ ಬೆಲೆಯನ್ನು ಪ್ರಶ್ನಿಸಿದಾಗ, ಹಳೆಯ ವ್ಯವಸ್ಥೆಯ ನಿಜ ನಡೆಸುವ ವೆಚ್ಚಗಳನ್ನು ಒಳಗೊಂಡ TCO ಹೋಲಿಕೆ ಸಾಮಾನ್ಯವಾಗಿ ಲಭ್ಯ ಬಲಿಷ್ಠ ಮರುಚೌಕಟ್ಟು. ಮೇಲಿನಂತಹ ಬಹು-ವರ್ಷದ TCO ಅಂಕಿ ಕಾಲಾನಂತರ ಅನೇಕ ವೆಚ್ಚ ಸಾಲು ಅಂಶಗಳ ಮೊತ್ತ — ಮಾದರಿ ಪೈಸೆಗೆ ಹೊಂದಿಕೆಯಾಗಬೇಕಾದಾಗ ಆ ಮೊತ್ತ ಫ್ಲೋಟಿಂಗ್ ಪಾಯಿಂಟ್ ಬದಲು ನಿಖರ-ದಶಮಾಂಶ ಏಕೆ ಆಗಿರಬೇಕು ಎಂಬುದಕ್ಕೆ [ಕರೆನ್ಸಿ-ಸುರಕ್ಷಿತ ವೆಚ್ಚ ಸಂಕಲನ](../ಕರೆನ್ಸಿ-ಸುರಕ್ಷಿತ-ವೆಚ್ಚ-ಸಂಕಲನ/), ಮತ್ತು ಪೈಸೆಗಳನ್ನು ಕಳೆದುಕೊಳ್ಳದೆ TCO ಒಟ್ಟನ್ನು ವೆಚ್ಚ ಕೇಂದ್ರಗಳ ನಡುವೆ ವಿಭಜಿಸಲು [ನಿಖರ-ಸೆಂಟ್ ವೆಚ್ಚ ಹಂಚಿಕೆ](../ನಿಖರ-ಸೆಂಟ್-ವೆಚ್ಚ-ಹಂಚಿಕೆ/) ನೋಡಿ.

## ಎಡವಟ್ಟುಗಳು

- **ಬಿಡುಗಡೆ-ವೆಚ್ಚ ಆಧಾರ**: ವರ್ಷ 3ರ ವೇಳೆಗೆ ಶ್ರೇಣಿ ತಿರುಗುವಾಗ ಆಯ್ಕೆಗಳನ್ನು ವರ್ಷ-0 ವೆಚ್ಚದಲ್ಲಿ ಹೋಲಿಸುವುದು.
- **ಉಚಿತ-ಆಂತರಿಕ-ಶ್ರಮ ತಪ್ಪುಕಲ್ಪನೆ**: "ತಂಡಕ್ಕೆ ಈಗಾಗಲೇ ಪಾವತಿಸಲಾಗಿದೆ" ಎಂಬ ಕಾರಣಕ್ಕೆ ಆಂತರಿಕ ನಿರ್ವಹಣೆಯನ್ನು ಶೂನ್ಯಕ್ಕೆ ವೆಚ್ಚ ಲೆಕ್ಕಿಸುವುದು — [ಅವಕಾಶ ವೆಚ್ಚ](../ಅವಕಾಶ-ವೆಚ್ಚ/) ನೋಡಿ.
- **ನಿರ್ಗಮನ ವೆಚ್ಚಗಳ ನಿರ್ಲಕ್ಷ್ಯ**: ದತ್ತಾಂಶ ಹೊರಹರಿವು, ಒಪ್ಪಂದ ಮುಕ್ತಾಯ ಮತ್ತು ಸಮಾನಾಂತರ ಚಾಲನೆ — "ಅಗ್ಗ" SaaS ದುಬಾರಿಯಾಗುವ ಸ್ಥಳ.
- **ಒಂದೇ-ಅವಧಿ ಉಲ್ಲಂಘನೆಗಳು**: 3-ವರ್ಷದ SaaS TCOಯನ್ನು 10-ವರ್ಷದ ನಿರ್ಮಾಣ ವಿಭಜನೆಯೊಂದಿಗೆ ಹೋಲಿಸುವುದು ([ಕಾಲದ ಗಡಿ](../ಕಾಲದ-ಗಡಿ/) ನೋಡಿ).
