# ಅನುಮಾನ ಘಟಕ ಅರ್ಥಶಾಸ್ತ್ರ

ಅನುಮಾನ (inference) ಘಟಕ ಅರ್ಥಶಾಸ್ತ್ರ AI ವೈಶಿಷ್ಟ್ಯಗಳಿಗೆ ಅವುಗಳ ಸೀಮಾಂತ ಕಂಪ್ಯೂಟ್‌ನ ಮೂಲಕ ಬೆಲೆ ಕಟ್ಟುತ್ತದೆ: **ಪ್ರತಿ ಟೋಕನ್‌ಗೆ ವೆಚ್ಚ**, ಪ್ರತಿ ವಹಿವಾಟು, ಪ್ರತಿ ಬಳಕೆದಾರ, ಪ್ರತಿ ಕ್ಲಿನಿಕಲ್ ಪ್ರಕರಣಕ್ಕೆ ಸಂಕಲಿಸಿದ್ದು. ವ್ಯಾಖ್ಯಾನಿಸುವ ಚಲನಶೀಲತೆ: LLM ಬೆಲೆಗಳು ಸ್ಥಿರ ಸಾಮರ್ಥ್ಯದಲ್ಲಿ ಸುಮಾರು **ಪ್ರತಿ 1–2 ವರ್ಷಗಳಿಗೆ ಒಂದು ಪರಿಮಾಣ ಕ್ರಮದಷ್ಟು** ಇಳಿದಿವೆ — ಆರೋಗ್ಯ-ತಂತ್ರಜ್ಞಾನ ವೆಚ್ಚ ಲೆಕ್ಕದಲ್ಲಿ ಪೂರ್ವನಿದರ್ಶನವಿಲ್ಲದ ಹಣದುಬ್ಬರ-ಇಳಿಕೆ ದರ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಬೆಲೆ ಕುಸಿತದಿಂದ ಎರಡು ಪರಿಣಾಮಗಳು. ವಾಣಿಜ್ಯವಾಗಿ, ಇಂದು ಅಂಚಿನಲ್ಲಿರುವ AI ವೈಶಿಷ್ಟ್ಯ 18 ತಿಂಗಳಲ್ಲಿ ಕ್ಷುಲ್ಲಕವಾಗಿ ಲಾಭದಾಯಕವಾಗಬಹುದು — ಮತ್ತು ಇಂದಿನ ವೆಚ್ಚಗಳ ಮೇಲೆ ಬೆಲೆ ನಿಗದಿಪಡಿಸಿದ ಪ್ರತಿಸ್ಪರ್ಧಿಯನ್ನು ಕಡಿಮೆ ಬೆಲೆಯಿಂದ ಮೀರಿಸಲಾಗುತ್ತದೆ. ಆರ್ಥಿಕ ಮೌಲ್ಯಮಾಪನಕ್ಕೆ, 2024 ಅನುಮಾನ ಬೆಲೆಗಳನ್ನು ಹೆಪ್ಪುಗಟ್ಟಿಸುವ AI-ಸಕ್ರಿಯ ಕ್ಲಿನಿಕಲ್ ಸೇವೆಯ ಯಾವುದೇ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ಮಾದರಿ **ನಡೆಯುತ್ತಿರುವ ವೆಚ್ಚವನ್ನು ಗಮನಾರ್ಹವಾಗಿ ಉತ್ಪ್ರೇಕ್ಷಿಸುತ್ತದೆ** — ಔಷಧ ಮಾದರಿಗಳು ಪೇಟೆಂಟ್ ಮುಕ್ತಾಯ ಮತ್ತು ಜೆನೆರಿಕ್ ಪ್ರವೇಶವನ್ನು ನಿಭಾಯಿಸುವಂತೆ ವಿಶ್ಲೇಷಣೆಗೆ ಬೆಲೆ-ಇಳಿಕೆ ಸನ್ನಿವೇಶಗಳು ಬೇಕು. (ಸಂಶೋಧನೆಯ ಉಲ್ಲೇಖ ಬಿಂದುಗಳು: 2026ರ ಮಧ್ಯದಲ್ಲಿ ಮುಂಚೂಣಿ ಔಟ್‌ಪುಟ್ ಟೋಕನ್‌ಗಳು ~$15–75/M, ಮಧ್ಯಮ-ಶ್ರೇಣಿ ಮಾದರಿಗಳು ಒಂದು ಕ್ರಮ ಅಗ್ಗ, GPT-4-ಮಟ್ಟದ ಸಾಮರ್ಥ್ಯ 2022ರ ~$20/Mನಿಂದ ~$0.40/Mಗೆ; Epoch AI ಸಾಮರ್ಥ್ಯ ಮೈಲಿಗಲ್ಲನ್ನು ಅವಲಂಬಿಸಿ ವರ್ಷಕ್ಕೆ 9×–900× ಇಳಿಕೆ ಅಳೆದಿದೆ.)

## ಗಣಿತ

```
Cost per call     = input tokens × input rate + output tokens × output rate
Cost per unit     = Σ calls per unit of business output (per triage episode,
                    per drafted letter, per consultation summary)

Blended reality   = base call + retries + RAG context (input-heavy)
                    + evaluation/guardrail calls (often 20–50% overhead)

Price-decline scenario for multi-year models:
  cost_t = cost_0 × d^t, test d ∈ {0.3, 0.5, 0.7}/year in sensitivity analysis
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

AI ಬಿಡುಗಡೆ-ಸಾರಾಂಶ ಸೇವೆ: ಸರಾಸರಿ ಸಾರಾಂಶ 12,000 ಇನ್‌ಪುಟ್ ಟೋಕನ್‌ಗಳು (ದಾಖಲೆ ಸಂದರ್ಭ) + 1,200 ಔಟ್‌ಪುಟ್ ಬಳಸುತ್ತದೆ, ಜೊತೆಗೆ ಪರಿಶೀಲನಾ ಪಾಸ್ (6,000 ಇನ್ / 300 ಔಟ್). $3/M ಇನ್, $15/M ಔಟ್‌ನಲ್ಲಿ:

```
Draft:   12,000 × 3/1M + 1,200 × 15/1M  = $0.036 + $0.018 = $0.054
Verify:   6,000 × 3/1M +   300 × 15/1M  = $0.018 + $0.0045 ≈ $0.023
Per summary ≈ $0.077 → per 100,000 summaries/year ≈ $7,700

Against ~20 clinician-minutes saved per summary (≈ £25), inference is
0.25% of the value created — the economics are dominated by everything
EXCEPT the tokens: integration, evaluation, governance, adoption.
```

ಆ ತೀರ್ಮಾನ — ಹೆಚ್ಚಿನ-ಮೌಲ್ಯದ ಕ್ಲಿನಿಕಲ್ ಕಾರ್ಯಗಳಿಗೆ, ಪ್ರಸ್ತುತ ಬೆಲೆಗಳಲ್ಲಿ, ಅನುಮಾನ ವೆಚ್ಚ ಅಪರೂಪವಾಗಿ ಬಂಧಿಸುವ ನಿರ್ಬಂಧ — ಬೆಲೆ ಸಭೆಗಳಿಗೆ ಒಯ್ಯಬೇಕಾದ ಸಂಶೋಧನೆಯೇ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಇದು AIಗಾಗಿ ವಿಶೇಷಗೊಳಿಸಿದ [ಕ್ಲೌಡ್ ಘಟಕ ಅರ್ಥಶಾಸ್ತ್ರ](../ಕ್ಲೌಡ್-ಘಟಕ-ಅರ್ಥಶಾಸ್ತ್ರ/), ಮೂರು ಅಭ್ಯಾಸ ಟಿಪ್ಪಣಿಗಳೊಂದಿಗೆ: ಪ್ರತಿ API ಕರೆಗಲ್ಲ, **ಪ್ರತಿ ವ್ಯಾಪಾರ ಘಟಕಕ್ಕೆ ಮೀಟರ್ ಮಾಡಿ**, ಇದರಿಂದ ಸಂಖ್ಯೆ [ICER](../ಹೆಚ್ಚುವರಿ-ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ಅನುಪಾತ/)/[ಬಜೆಟ್ ಪ್ರಭಾವ](../ಬಜೆಟ್-ಪರಿಣಾಮ-ವಿಶ್ಲೇಷಣೆ/) ಮಾದರಿಗಳಿಗೆ ನೇರವಾಗಿ ಹೊಂದುತ್ತದೆ; **ಇನ್‌ಪುಟ್/ಔಟ್‌ಪುಟ್ ಅಸಮಮಿತಿಯನ್ನು ಗಮನಿಸಿ** (ಔಟ್‌ಪುಟ್ ಸಾಮಾನ್ಯವಾಗಿ ಇನ್‌ಪುಟ್ ಬೆಲೆಯ ~4×; RAG ವಾಸ್ತುಶಿಲ್ಪಗಳು ಇನ್‌ಪುಟ್-ಭಾರ — ವಾಸ್ತುಶಿಲ್ಪ ಆಯ್ಕೆಗಳು ಬೆಲೆ ಆಯ್ಕೆಗಳು); ಮತ್ತು **ಕಾರ್ಯ ಹಂತದ ಮೂಲಕ ರೂಟ್ ಮಾಡಿ** — ಮಾದರಿ ಸಾಮರ್ಥ್ಯವನ್ನು ಕಾರ್ಯ ಕಷ್ಟಕ್ಕೆ ಹೊಂದಿಸುವುದು (ವರ್ಗೀಕರಣಕ್ಕೆ ಅಗ್ಗ ಮಾದರಿಗಳು, ಸಂಶ್ಲೇಷಣೆಗೆ ಮುಂಚೂಣಿ) ಸಮಾನ ಗುಣಮಟ್ಟದಲ್ಲಿ ಮಿಶ್ರ ವೆಚ್ಚವನ್ನು ನಿಯಮಿತವಾಗಿ 5–10× ಕಡಿತಗೊಳಿಸುತ್ತದೆ, ಅತಿ ಅಗ್ಗದ ಪರಿಣಾಮಕಾರಿ ಮಧ್ಯಸ್ಥಿಕೆ ಬಳಸುವುದರ ಸಾಫ್ಟ್‌ವೇರ್ ಆವೃತ್ತಿ ([ವೆಚ್ಚ-ಕನಿಷ್ಠೀಕರಣ](../ವೆಚ್ಚ-ಕನಿಷ್ಠೀಕರಣ-ವಿಶ್ಲೇಷಣೆ/), ಸಮಾನತೆಗೆ ಸಾಕ್ಷ್ಯ).

## ಎಡವಟ್ಟುಗಳು

- **ಹೆಪ್ಪುಗಟ್ಟಿದ-ಬೆಲೆ ಬಹು-ವರ್ಷ ಮಾದರಿಗಳು** — ವೆಚ್ಚವನ್ನು ಉತ್ಪ್ರೇಕ್ಷಿಸುತ್ತವೆ; ಆದರೆ **ಊಹಿಸಿದ-ಬೆಲೆ-ಇಳಿಕೆ ಆದಾಯ ಮಾದರಿಗಳೂ** — ಬೆಲೆ ಯುದ್ಧ ಒಪ್ಪಂದವಲ್ಲ; ಎರಡನ್ನೂ ಸನ್ನಿವೇಶ ಮಾಡಿ.
- **ಮೌಲ್ಯಮಾಪನ ಹೆಚ್ಚುವರಿ ಭಾರದ ನಿರ್ಲಕ್ಷ್ಯ**: ರಕ್ಷಣಾ ಕಟ್ಟಳೆಗಳು, ನ್ಯಾಯಾಧೀಶರು ಮತ್ತು ಮರುಪ್ರಯತ್ನಗಳು ನಿಜವಾದ ಟೋಕನ್‌ಗಳು, ನಿಯಂತ್ರಿತ ಸೆಟ್ಟಿಂಗ್‌ಗಳಲ್ಲಿ ಹೆಚ್ಚಾಗಿ ಬಹುಪಾಲು.
- **ಪ್ರತಿ-ಟೋಕನ್ ಸೀಮಿತ ದೃಷ್ಟಿ**: ಲೇಟೆನ್ಸಿ, ದರ ಮಿತಿಗಳು ಮತ್ತು ಸಂದರ್ಭ-ಕಿಟಕಿ ನಿರ್ಬಂಧಗಳು ಯಾವುದೇ ಟೋಕನ್ ಬೆಲೆ ಸೆರೆಹಿಡಿಯದ ವೆಚ್ಚಗಳನ್ನು ಹೊತ್ತಿರುತ್ತವೆ.
