# ಸೀಮಾಂತ vs ಸರಾಸರಿ ವೆಚ್ಚ

ಸರಾಸರಿ ವೆಚ್ಚ ಎಂದರೆ ಒಟ್ಟು ವೆಚ್ಚವನ್ನು ಉತ್ಪಾದಿಸಿದ ಘಟಕಗಳಿಂದ ಭಾಗಿಸಿದ್ದು. ಸೀಮಾಂತ ವೆಚ್ಚ ಎಂದರೆ ಒಂದು *ಹೆಚ್ಚುವರಿ* ಘಟಕವನ್ನು ಉತ್ಪಾದಿಸುವ ವೆಚ್ಚ. ನಿರ್ಧಾರಗಳನ್ನು ಸೀಮಾಂತ ವೆಚ್ಚದ ಆಧಾರದಲ್ಲಿ ಕೈಗೊಳ್ಳಬೇಕು — ಆದರೆ ಪ್ರಕಟಿತ ಘಟಕ ವೆಚ್ಚಗಳು ಬಹುತೇಕ ಯಾವಾಗಲೂ ಸರಾಸರಿಗಳು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಡಿಜಿಟಲ್ ಆರೋಗ್ಯ ವ್ಯವಹಾರ ಪ್ರಕರಣಗಳಲ್ಲಿ ಅತ್ಯಂತ ಸಾಮಾನ್ಯ ತಪ್ಪು: ನಿಜವಾದ ಉಳಿತಾಯ **ಸೀಮಾಂತ** ವೆಚ್ಚವಾಗಿರುವಾಗ, ಉಳಿತಾಯವಾದ ಸಂಪನ್ಮೂಲಕ್ಕೆ ಅದರ **ಸರಾಸರಿ** ವೆಚ್ಚದಲ್ಲಿ ಬೆಲೆ ಕಟ್ಟುವುದು. ಆಸ್ಪತ್ರೆ ಹಾಸಿಗೆ ದಿನದ ಸರಾಸರಿ (ಸಂಪೂರ್ಣ ಹೀರಲ್ಪಟ್ಟ) ವೆಚ್ಚ £400+, ಆದರೆ ಒಂದು ಹಾಸಿಗೆ ದಿನವನ್ನು ಖಾಲಿ ಮಾಡುವುದು £400 ಉಳಿಸುವುದಿಲ್ಲ — ಕಟ್ಟಡ, ತಾಪನ ಮತ್ತು ಹೆಚ್ಚಿನ ಸಿಬ್ಬಂದಿ ವೆಚ್ಚಗಳು ಮುಂದುವರಿಯುತ್ತವೆ. ವಾರ್ಡ್ ಮುಚ್ಚುವಷ್ಟು ಹಾಸಿಗೆಗಳನ್ನು ಖಾಲಿ ಮಾಡದ ಹೊರತು, ನಿಜವಾಗಿ ಬಿಡುಗಡೆಯಾಗುವ ನಗದು £50–£150 ಆಗಿರಬಹುದು.

## ಗಣಿತ

```
Average cost:  AC = TC / Q
Marginal cost: MC = dTC/dQ   (cost of one more/one fewer unit)

TC = total cost, Q = quantity
```

ಸ್ಥಿರ ವೆಚ್ಚಗಳು ಸಾಮರ್ಥ್ಯ ಕಡಿತಗಳಿಗೆ MC < AC ಆಗಿಸುತ್ತವೆ, ಮತ್ತು ಬಿಡಿ ಸಾಮರ್ಥ್ಯ ಇದ್ದಾಗ MC ಸೊನ್ನೆಯ ಹತ್ತಿರ ಹೋಗಬಹುದು. ಉಳಿತಾಯದ ಹೇಳಿಕೆಗಳು ಇದನ್ನು ಬಳಸಬೇಕು:

```
True saving = ΔQ × MC          (small changes)
True saving = step change in TC (large changes that cross a capacity threshold, e.g. closing a ward)
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ನಿಮ್ಮ ಸಾಫ್ಟ್‌ವೇರ್ ಸರಾಸರಿ ಆಸ್ಪತ್ರೆ ವಾಸದ ಅವಧಿಯನ್ನು ಕಡಿಮೆ ಮಾಡಿ, ಒಂದು ಟ್ರಸ್ಟ್‌ನಲ್ಲಿ ವರ್ಷಕ್ಕೆ 1,000 ಹಾಸಿಗೆ ದಿನಗಳನ್ನು ಖಾಲಿ ಮಾಡುತ್ತದೆ.

- **ಮುಗ್ಧ ಹೇಳಿಕೆ**: 1,000 × £400 ಸರಾಸರಿ ವೆಚ್ಚ = **£400,000 ಉಳಿತಾಯ**. ತಪ್ಪು.
- **ಸೀಮಾಂತ ಹೇಳಿಕೆ**: ಪ್ರತಿ ಹಾಸಿಗೆ ದಿನದ ವೇರಿಯಬಲ್ ವೆಚ್ಚ (ಆಹಾರ, ಲಾಂಡ್ರಿ, ಬಳಕೆ ವಸ್ತುಗಳು, ಸ್ವಲ್ಪ ಶುಶ್ರೂಷಾ ಹೊಂದಾಣಿಕೆ) ≈ £120. ಉಳಿತಾಯ = 1,000 × £120 = **£120,000**, *ಜೊತೆಗೆ* ಖಾಲಿಯಾದ ಹಾಸಿಗೆಗಳನ್ನು ಕಾಯುತ್ತಿರುವ ಯೋಜಿತ ರೋಗಿಗಳಿಂದ ಮರುತುಂಬಿದರೆ ಆ ಸಾಮರ್ಥ್ಯದ ಮೌಲ್ಯ (ಚಟುವಟಿಕೆ-ಆಧಾರಿತ ಪಾವತಿಯಡಿ ಆದಾಯ, ಅಥವಾ ಕಾಯುವ ಪಟ್ಟಿ ಕಡಿತ).
- **ಹಂತ-ಬದಲಾವಣೆ ಹೇಳಿಕೆ**: ಟ್ರಸ್ಟ್ ವರ್ಷಕ್ಕೆ 7,300 ಹಾಸಿಗೆ ದಿನಗಳನ್ನು (20-ಹಾಸಿಗೆ ವಾರ್ಡ್) ಖಾಲಿ ಮಾಡಿದರೆ ವಾರ್ಡ್ ಅನ್ನು ನಿಜವಾಗಿ ಮುಚ್ಚಬಹುದು: ಸಿಬ್ಬಂದಿ + ನಿರ್ವಹಣೆ ≈ ವರ್ಷಕ್ಕೆ £1.5 ಮಿಲಿಯನ್ ನಿಜವಾದ ನಗದು. ಈಗ ಸರಾಸರಿ-ವೆಚ್ಚದ ಗಣಿತ ಸತ್ಯಕ್ಕೆ ಹತ್ತಿರ.

ಒಂದೇ ಮಧ್ಯಸ್ಥಿಕೆ, ಮೂರು ಸಮರ್ಥನೀಯ ಸಂಖ್ಯೆಗಳು — ಬದಲಾವಣೆ ಸಾಮರ್ಥ್ಯದ ಹಂತವನ್ನು ದಾಟುತ್ತದೆಯೇ ಎಂಬುದರ ಮೇಲೆ ಅವಲಂಬಿತ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಕ್ಲೌಡ್ ಅರ್ಥಶಾಸ್ತ್ರವು ಸೀಮಾಂತ-ವೆಚ್ಚದ ಸ್ವಂತ ನೆಲ:

- ಈಗಾಗಲೇ ಕಾದಿರಿಸಿದ ಸಾಮರ್ಥ್ಯದಲ್ಲಿ ಇನ್ನೊಂದು CI ರನ್‌ನ ಸೀಮಾಂತ ವೆಚ್ಚ ≈ £0, ಆದರೆ ಪ್ರತಿ ರನ್‌ನ ಸರಾಸರಿ ವೆಚ್ಚ (ಒಟ್ಟು ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ವೆಚ್ಚ ÷ ರನ್‌ಗಳು) ಹಲವು ಪೌಂಡ್‌ಗಳಾಗಿರಬಹುದು. ಸರಾಸರಿ ವೆಚ್ಚವನ್ನು ಬಿಲ್ ಮಾಡುವ ಚಾರ್ಜ್‌ಬ್ಯಾಕ್ ವ್ಯವಸ್ಥೆಗಳು, ಅಂಚಿನಲ್ಲಿ ವಾಸ್ತವವಾಗಿ ಉಚಿತವಾದ ಹಂಚಿಕೆಯ ಸಾಮರ್ಥ್ಯವನ್ನು ತಂಡಗಳು ಕಡಿಮೆ ಬಳಸುವಂತೆ ಮಾಡುತ್ತವೆ.
- ಅದಕ್ಕೆ ವಿರುದ್ಧವಾಗಿ, "ನಾವು 30% ಕಂಪ್ಯೂಟ್ ಉಳಿಸಿದೆವು" ಎಂಬುದು ಇನ್‌ಸ್ಟೆನ್ಸ್‌ಗಳನ್ನು ನಿಜವಾಗಿ ಕೊನೆಗೊಳಿಸಿದರೆ ಅಥವಾ ಕಾದಿರಿಸುವಿಕೆಗಳನ್ನು ಕಡಿಮೆ ಮಾಡಿದರೆ ಮಾತ್ರ ನಗದು ಬಿಡುಗಡೆ ಮಾಡುತ್ತದೆ — ಇದು ಹಾಸಿಗೆ-ದಿನದ ಬಲೆಯ ಸಾಫ್ಟ್‌ವೇರ್ ರೂಪ. [ನಗದು-ಬಿಡುಗಡೆ vs ನಗದು-ರಹಿತ ಉಳಿತಾಯ](../ನಗದು-ಬಿಡುಗಡೆ-vs-ನಗದು-ರಹಿತ-ಉಳಿತಾಯ/) ನೋಡಿ.

## ಎಡವಟ್ಟುಗಳು

- **ಸಾಮರ್ಥ್ಯಕ್ಕೆ ಸರಾಸರಿ ವೆಚ್ಚದಲ್ಲಿ ಬೆಲೆ ಕಟ್ಟಿ** ಅದನ್ನು ನಗದು ಎಂದು ಪ್ರಸ್ತುತಪಡಿಸುವುದು (ಶ್ರೇಷ್ಠ ತಪ್ಪು).
- **ಸೀಮಾಂತ ವೆಚ್ಚ ಸ್ಥಿರ ಎಂದು ಭಾವಿಸುವುದು.** ಅದು ಸಾಮರ್ಥ್ಯ ಗಡಿಗಳಲ್ಲಿ (ವಾರ್ಡ್ ಮುಚ್ಚುವಿಕೆ, ಪರವಾನಗಿ ಹಂತಗಳು, ಕಾದಿರಿಸಿದ-ಇನ್‌ಸ್ಟೆನ್ಸ್ ಬದ್ಧತೆಗಳು) ಹಂತ ಹಂತವಾಗಿ ಏರುತ್ತದೆ.
- ಒಂದೇ ಪ್ರಕರಣದಲ್ಲಿ **ವಿಸ್ತರಣಾ ನಿರ್ಧಾರಗಳಿಗೆ ಸೀಮಾಂತ ಆದರೆ ಕುಗ್ಗುವಿಕೆಗೆ ಸರಾಸರಿ ವೆಚ್ಚ ಬಳಸುವುದು** — ನಿಜವಾದ ನಿರ್ಧಾರಕ್ಕೆ ಅನುಗುಣವಾಗಿ ಆರಿಸಿ.
