# ರಿಯಾಯಿತಿ ಮತ್ತು ಕಾಲ ಆದ್ಯತೆ

ರಿಯಾಯಿತಿ (ಡಿಸ್ಕೌಂಟಿಂಗ್) ಭವಿಷ್ಯದ ವೆಚ್ಚಗಳು ಮತ್ತು ಲಾಭಗಳನ್ನು ವರ್ತಮಾನ ಮೌಲ್ಯಗಳನ್ನಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ, ಏಕೆಂದರೆ ಇಂದಿನ ಲಾಭವು ಐದು ವರ್ಷಗಳ ನಂತರದ ಅದೇ ಲಾಭಕ್ಕಿಂತ ಹೆಚ್ಚು ಮೌಲ್ಯಯುತ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಪ್ರತಿಯೊಂದು ಆರೋಗ್ಯ-ಅರ್ಥಶಾಸ್ತ್ರ ಮೌಲ್ಯಮಾಪನವೂ ಮತ್ತು ಪ್ರತಿಯೊಂದು ಗಂಭೀರ ಸಾರ್ವಜನಿಕ-ವಲಯ ವ್ಯವಹಾರ ಪ್ರಕರಣವೂ ಬಹು-ವರ್ಷದ ಹರಿವುಗಳಿಗೆ ರಿಯಾಯಿತಿ ಅನ್ವಯಿಸುತ್ತದೆ. ಯುಕೆಯ HM ಖಜಾನೆಯ ಗ್ರೀನ್ ಬುಕ್ ವಾರ್ಷಿಕ 3.5% ಸಾಮಾಜಿಕ ಕಾಲ ಆದ್ಯತಾ ದರವನ್ನು ಕಡ್ಡಾಯಗೊಳಿಸುತ್ತದೆ; NICEಯ ಉಲ್ಲೇಖ ಪ್ರಕರಣವು ವೆಚ್ಚಗಳು ಮತ್ತು ಆರೋಗ್ಯ ಪರಿಣಾಮಗಳೆರಡಕ್ಕೂ ವರ್ಷಕ್ಕೆ 3.5% ರಿಯಾಯಿತಿ ನೀಡುತ್ತದೆ (30+ ವರ್ಷಗಳ ಲಾಭವಿರುವ ಬಹುತೇಕ-ಗುಣಪಡಿಸುವ ಚಿಕಿತ್ಸೆಗಳಿಗೆ ಉಲ್ಲೇಖ-ಅಲ್ಲದ ಪ್ರಕರಣದಲ್ಲಿ 1.5% ದರ). ನಿಮ್ಮ ಸಾಫ್ಟ್‌ವೇರ್ ವ್ಯವಹಾರ ಪ್ರಕರಣ "10 ವರ್ಷಗಳಲ್ಲಿ £5 ಮಿಲಿಯನ್ ಉಳಿತಾಯ" ಎಂದು ಹೇಳಿದರೆ, ಹಣಕಾಸು ಪರಿಶೀಲಕರು ತಕ್ಷಣ ರಿಯಾಯಿತಿ ನೀಡಿದ ಅಂಕಿಯನ್ನು ಕೇಳುತ್ತಾರೆ.

## ಗಣಿತ

ಭವಿಷ್ಯದ ಮೊತ್ತದ ವರ್ತಮಾನ ಮೌಲ್ಯ:

```
PV = FV / (1 + r)^t

PV = present value
FV = future value in year t
r  = discount rate (NICE/Green Book: 0.035)
t  = years from now
```

n ವರ್ಷಗಳ ಕಾಲ ಸ್ಥಿರ ವಾರ್ಷಿಕ ಲಾಭ B ಗೆ (ವಾರ್ಷಿಕ ಕಂತು):

```
PV = B × [1 − (1 + r)^(−n)] / r
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ನಿಮ್ಮ ಸಾಫ್ಟ್‌ವೇರ್ ಗೋ-ಲೈವ್ ಆದ ಒಂದು ವರ್ಷದ ನಂತರದಿಂದ ಪ್ರಾರಂಭಿಸಿ, 5 ವರ್ಷ ಪ್ರತಿ ವರ್ಷ ಒಂದು NHS ಟ್ರಸ್ಟ್‌ಗೆ £100,000 ಉಳಿಸುತ್ತದೆ.

ರಿಯಾಯಿತಿ ಇಲ್ಲದ ಒಟ್ಟು: £500,000.

3.5% ರಿಯಾಯಿತಿಯೊಂದಿಗೆ:

```
Year 1: 100,000 / 1.035^1 = £96,618
Year 2: 100,000 / 1.035^2 = £93,351
Year 3: 100,000 / 1.035^3 = £90,194
Year 4: 100,000 / 1.035^4 = £87,144
Year 5: 100,000 / 1.035^5 = £84,197

Total PV ≈ £451,505
```

ಪ್ರಾಮಾಣಿಕ ಶೀರ್ಷಿಕೆ ಅಂಕಿ ಸುಮಾರು £451,000, ಮುಗ್ಧ ಮೊತ್ತಕ್ಕಿಂತ ಸುಮಾರು 10% ಕಡಿಮೆ. ಈಗ ಪೂರೈಕೆ ಒಂದು ವರ್ಷ ಮುಂದೂಡಲ್ಪಟ್ಟರೆ: ಪ್ರತಿ ಪದವೂ ಒಂದು ವರ್ಷ ತಡವಾಗುತ್ತದೆ, ಮತ್ತು PV ಸುಮಾರು £436,000ಕ್ಕೆ ಇಳಿಯುತ್ತದೆ — ಇದು [ವಿಳಂಬದ ವೆಚ್ಚ](../ವಿಳಂಬದ-ವೆಚ್ಚ/)ದ ರಿಯಾಯಿತಿ ದೃಷ್ಟಿಕೋನ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

- **ತಾಂತ್ರಿಕ ಸಾಲ ತೀರಿಸುವಿಕೆ ಮತ್ತು ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಸ್ಥಳಾಂತರಗಳು** ವರ್ಷಗಳ ನಂತರದ ಲಾಭ ಹರಿವುಗಳನ್ನು ಭರವಸೆ ನೀಡುತ್ತವೆ; ಈ ತ್ರೈಮಾಸಿಕದಲ್ಲೇ ಫಲ ನೀಡುವ ಕೆಲಸದೊಂದಿಗೆ ಹೋಲಿಸುವ ಮೊದಲು ಅವುಗಳಿಗೆ ರಿಯಾಯಿತಿ ನೀಡಿ.
- **ಮುಂಗಡ ವೆಚ್ಚಗಳು, ಹಿಂಗಡೆ ಲಾಭಗಳು** ಸ್ಥಳಾಂತರದ ಪ್ರಮಾಣಿತ ಆಕಾರ. ರಿಯಾಯಿತಿಯು ಆ ಆಕಾರವನ್ನು ಸರಿಯಾಗಿಯೇ ದಂಡಿಸುತ್ತದೆ: ಈಗ ಸಾಮರ್ಥ್ಯವನ್ನು ಬದ್ಧಗೊಳಿಸಿ ನಂತರ ಮೌಲ್ಯ ಪಡೆಯುವುದರ ಅಪಾಯ-ರಹಿತ ಕಾಲ ಮೌಲ್ಯಕ್ಕೆ ಅದು ಬೆಲೆ ಕಟ್ಟುತ್ತದೆ.
- **"5ನೇ ವರ್ಷದ ಉಳಿತಾಯ" ಹೇಳಿಕೆಗಳು** ಎರಡು ಪಟ್ಟು ಸಂದೇಹಕ್ಕೆ ಅರ್ಹ — ಅವು ಭಾರೀ ರಿಯಾಯಿತಿಗೆ ಒಳಪಟ್ಟಿವೆ ಮತ್ತು ಅತ್ಯಂತ ಅನಿಶ್ಚಿತವೂ ಹೌದು ([ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ](../ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/) ನೋಡಿ).

## ಎಡವಟ್ಟುಗಳು

- **ವೆಚ್ಚಗಳಿಗೆ ರಿಯಾಯಿತಿ ನೀಡಿ ಲಾಭಗಳಿಗೆ ನೀಡದಿರುವುದು** (ಅಥವಾ ವಿರುದ್ಧ) — ಉಲ್ಲೇಖ ಪ್ರಕರಣವು ಎರಡಕ್ಕೂ ಒಂದೇ ದರದಲ್ಲಿ ರಿಯಾಯಿತಿ ನೀಡುತ್ತದೆ.
- **ಸಾರ್ವಜನಿಕ-ವಲಯ ಪ್ರಕರಣದಲ್ಲಿ ವಾಣಿಜ್ಯ ದರ (8–12%) ಬಳಸುವುದು**, ಅಥವಾ ವೆಂಚರ್-ಬೆಂಬಲಿತ ಪ್ರಕರಣದಲ್ಲಿ 3.5%. ದರವನ್ನು ನಿರ್ಧಾರ ಕೈಗೊಳ್ಳುವವರಿಗೆ ಹೊಂದಿಸಿ.
- **ರಿಯಾಯಿತಿಯನ್ನು ಹಣದುಬ್ಬರದೊಂದಿಗೆ ಗೊಂದಲಗೊಳಿಸುವುದು.** ರಿಯಾಯಿತಿಯು *ನೈಜ* (ಹಣದುಬ್ಬರ-ಹೊಂದಾಣಿಕೆಯ) ಮೌಲ್ಯಗಳಿಗೆ ಅನ್ವಯಿಸುತ್ತದೆ; ಎರಡನ್ನೂ ಪರೋಕ್ಷವಾಗಿ ಮಾಡಬೇಡಿ.
