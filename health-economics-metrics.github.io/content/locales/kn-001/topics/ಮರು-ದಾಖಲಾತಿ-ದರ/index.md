# ಮರು-ದಾಖಲಾತಿ ದರ

30-ದಿನದ ಮರು-ದಾಖಲಾತಿ ದರ ಎಂದರೆ ಡಿಸ್ಚಾರ್ಜ್ ಆದ ರೋಗಿಗಳಲ್ಲಿ 30 ದಿನಗಳೊಳಗೆ ತುರ್ತಾಗಿ ಮರಳಿ ಬರುವವರ ಶೇಕಡಾವಾರು. ಇದು ಆರೋಗ್ಯ ವ್ಯವಸ್ಥೆಯ ಶ್ರೇಷ್ಠ *ಡಿಸ್ಚಾರ್ಜ್-ಗುಣಮಟ್ಟ* ಮೆಟ್ರಿಕ್ — ಮತ್ತು ಇದಕ್ಕೆ ನೇರ ಹಣಕಾಸು ದಂಡಗಳಿವೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಮರು-ದಾಖಲಾತಿ ಎಂದರೆ ಮೊದಲ ಡಿಸ್ಚಾರ್ಜ್ ನಿಲ್ಲಲಿಲ್ಲ: ಅಕಾಲಿಕ ಡಿಸ್ಚಾರ್ಜ್, ವಿಫಲ ಔಷಧ ಹಸ್ತಾಂತರ, ಅನುಸರಣೆ ಇಲ್ಲ, ಅಥವಾ ಸಾಮಾಜಿಕ ಬೆಂಬಲ ಕೊರತೆ. ಪಾವತಿದಾರರು ಇದನ್ನು ಸ್ಪಷ್ಟವಾಗಿ ದಂಡಿಸುತ್ತಾರೆ — ಅಮೆರಿಕದ ಹಾಸ್ಪಿಟಲ್ ರೀಅಡ್ಮಿಷನ್ಸ್ ರಿಡಕ್ಷನ್ ಪ್ರೋಗ್ರಾಂ ಆಸ್ಪತ್ರೆಯ ಮೆಡಿಕೇರ್ ಪಾವತಿಗಳ 3% ವರೆಗೆ ಕಡಿತಗೊಳಿಸುತ್ತದೆ; NHS ಐತಿಹಾಸಿಕವಾಗಿ ತಪ್ಪಿಸಬಹುದಾದ 30-ದಿನದ ತುರ್ತು ಮರು-ದಾಖಲಾತಿಗಳಿಗೆ ಪಾವತಿಸಿಲ್ಲ. ಆದ್ದರಿಂದ ಮರು-ದಾಖಲಾತಿ ತಪ್ಪಿಸುವಿಕೆ ಒದಗಿಸುವವರಿಗೆ ಕೇವಲ ಸಾಮರ್ಥ್ಯವಲ್ಲ, *ನೇರವಾಗಿ* ನಗದು-ಸಂಬಂಧಿತವಾದ ಕೆಲವೇ ಲಾಭ ವರ್ಗಗಳಲ್ಲಿ ಒಂದು.

## ಗಣಿತ

```
Readmission rate = emergency readmissions within 30 days / index discharges × 100

Risk-standardized comparisons adjust for case mix; penalty programmes
compare observed vs expected for like hospitals.

Value of avoidance = avoided readmissions × (cost per readmission spell
                     + penalty exposure per readmission)
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಹೃದಯ ವೈಫಲ್ಯ ಡಿಸ್ಚಾರ್ಜ್-ಬೆಂಬಲ ಆ್ಯಪ್ (ಲಕ್ಷಣ ಟ್ರ್ಯಾಕಿಂಗ್, ತೂಕ ಎಚ್ಚರಿಕೆಗಳು, ಔಷಧ ಜ್ಞಾಪಕಗಳು, ದಾದಿ ಉಲ್ಬಣ): ವರ್ಷಕ್ಕೆ 2,000 ಡಿಸ್ಚಾರ್ಜ್‌ಗಳು, ಮೂಲ ಮರು-ದಾಖಲಾತಿ ದರ 18%, ಆ್ಯಪ್‌ನೊಂದಿಗೆ ಪ್ರಯೋಗ 14% ತೋರಿಸುತ್ತದೆ.

```
Avoided readmissions = 2,000 × (0.18 − 0.14) = 80/year
Cost per readmission spell ≈ £3,500 → £280,000/year avoided treatment cost
Plus penalty/non-payment exposure on those spells.
App cost: 2,000 × £60 = £120,000/year

Net ≈ +£160,000/year, before any QALY claim for avoided deterioration.
```

ಸಮರ್ಥಿಸಬೇಕಾದ ಸಂಖ್ಯೆ 4-ಶೇಕಡಾವಾರು-ಅಂಕದ ಪರಿಣಾಮ: ಅದು ನಿಯಂತ್ರಿತ ಹೋಲಿಕೆಯಿಂದ ಬರಬೇಕು, ಏಕೆಂದರೆ ಮರು-ದಾಖಲಾತಿ ದರಗಳು ಕೇಸ್ ಮಿಶ್ರಣ ಮತ್ತು ಋತುವಿನೊಂದಿಗೆ ತೂಗಾಡುತ್ತವೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಮರು-ದಾಖಲಾತಿ ಆರೋಗ್ಯ ವ್ಯವಸ್ಥೆಯ **ಬದಲಾವಣೆ ವೈಫಲ್ಯ ದರ** ([DORA ಮೆಟ್ರಿಕ್ಸ್](../dora-ಮಾಪನಗಳು/) ನೋಡಿ): "ಹೊರತಂದ" ಆದರೆ 30 ದಿನಗಳೊಳಗೆ ಮರಳಿ ಬಂದ ಕೆಲಸ. ಸಾದೃಶ್ಯಗಳು ಆಳವಾಗಿವೆ — ಮರು-ತೆರೆದ ಟಿಕೆಟ್‌ಗಳು ಮತ್ತು ರಿಗ್ರೆಶನ್ ಘಟನೆಗಳು ಕಳಪೆ "ಡಿಸ್ಚಾರ್ಜ್ ಗುಣಮಟ್ಟ"ವನ್ನು (ದುರ್ಬಲ ಪರಿಶೀಲನೆ, ಅಕಾಲಿಕ ಮುಕ್ತಾಯ, ಕಾಣೆಯಾದ ಹಸ್ತಾಂತರ ದಾಖಲೆಗಳು) ಸೂಚಿಸುತ್ತವೆ; ದಂಡ-ಶೈಲಿಯ ಲೆಕ್ಕಾಚಾರ (ಸ್ವೀಕರಿಸುವ ತಂಡವಲ್ಲ, ಸರಿಪಡಿಸುವ ತಂಡ ಪಾವತಿಸುತ್ತದೆ) ವರ್ತನೆಯನ್ನು ಬದಲಿಸುತ್ತದೆ; ಮತ್ತು ಎರಡೂ ಕ್ಷೇತ್ರಗಳು ಒಂದೇ ಪಾಠ ಕಲಿತಿವೆ: ಹಸ್ತಾಂತರದಲ್ಲಿ ಹೂಡಿಕೆ ಮಾಡದೆ ಕಚ್ಚಾ ಥ್ರೂಪುಟ್ ಅನ್ನು (ವೇಗವಾದ ಡಿಸ್ಚಾರ್ಜ್, ವೇಗವಾದ ಶಿಪ್ಪಿಂಗ್) ತಳ್ಳುವುದು ಗೋಚರ ಸರತಿಗಳನ್ನು ಅದೃಶ್ಯ ಮರುಕೆಲಸವಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ ಅಷ್ಟೆ. ಚಕ್ರ ಸಮಯವನ್ನು ಆಚರಿಸುವ ಯಾವುದೇ ತಂಡದ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ನಲ್ಲಿ "30-ದಿನದ ಮರು-ತೆರೆಯುವಿಕೆ ದರ" ಇರಬೇಕು.

## ಎಡವಟ್ಟುಗಳು

- **ಮರು-ಲೇಬಲ್ ಮೂಲಕ ತಿರುಚುವಿಕೆ**: ಮರು-ದಾಖಲಾತಿಗಳನ್ನು ವೀಕ್ಷಣಾ ವಾಸಗಳು ಅಥವಾ ಹೊಸ ಸ್ಥಿತಿಗಳೆಂದು ಕೋಡ್ ಮಾಡುವುದು; ವ್ಯಾಖ್ಯಾನವನ್ನು ಲೆಕ್ಕಪರಿಶೋಧಿಸಿ.
- **ಎಲ್ಲ-ಕಾರಣ vs ಸಂಬಂಧಿತ-ಕಾರಣ**: 30-ದಿನದ ಎಲ್ಲ-ಕಾರಣವು ನಿಜವಾಗಿ ಸಂಬಂಧವಿಲ್ಲದ ಘಟನೆಗಳನ್ನು ಒಳಗೊಂಡಿದೆ; "ಸಂಬಂಧಿತ" ತಿರುಚಬಹುದಾದ್ದರಿಂದಲೇ ದಂಡಗಳು ಸಾಮಾನ್ಯವಾಗಿ ಎಲ್ಲ-ಕಾರಣ ಬಳಸುತ್ತವೆ.
- **ಕೇಸ್-ಮಿಶ್ರಣ ಕುರುಡುತನ**: ಹೆಚ್ಚು ಅಸ್ವಸ್ಥ, ಬಡ ಜನಸಂಖ್ಯೆಗೆ ಸೇವೆ ನೀಡುವ ಆಸ್ಪತ್ರೆ ಯಾವ ಆ್ಯಪ್ ಸರಿಪಡಿಸದ ಕಾರಣಗಳಿಗಾಗಿ ಹೆಚ್ಚು ಮರು-ದಾಖಲಿಸುತ್ತದೆ — ಹೋಲಿಸುವ ಮೊದಲು ಅಪಾಯ-ಹೊಂದಾಣಿಕೆ ಮಾಡಿ.
