# ಪ್ರತಿ QALYಗೆ ಇಂಗಾಲ ಹೆಜ್ಜೆಗುರುತು

ಪ್ರತಿ QALYಗೆ ಇಂಗಾಲ ಒಂದು ದಕ್ಷತೆ ಅನುಪಾತ — ಮಧ್ಯಸ್ಥಿಕೆಯ ಇಂಗಾಲ ಹೊರಸೂಸುವಿಕೆ (ಅಥವಾ ತಪ್ಪಿಸಿದ ಹೊರಸೂಸುವಿಕೆ) ಅದು ನೀಡುವ QALYಗಳಿಂದ ಭಾಗಿಸಿದ್ದು — ಪ್ರತಿ QALYಗೆ ವೆಚ್ಚಕ್ಕೆ ನೇರ ಸಮಾನ, ಇದು ಮಧ್ಯಸ್ಥಿಕೆಯ ಇಂಗಾಲ ದಕ್ಷತೆಯನ್ನು ಅದರ ವೆಚ್ಚ ದಕ್ಷತೆಯ ಜೊತೆಗೆ ನಿರ್ಣಯಿಸಲು ಅವಕಾಶ ನೀಡುತ್ತದೆ. "ಇಂಗಾಲ-ಹೊಂದಾಣಿಕೆಯ ನಿವ್ವಳ ವಿತ್ತೀಯ ಲಾಭ" ಒಂದು ಹೆಜ್ಜೆ ಮುಂದೆ ಹೋಗುತ್ತದೆ: ಯುಕೆ Green Bookನ ಅಧಿಕೃತ ವ್ಯಾಪಾರೇತರ ಇಂಗಾಲ ಮೌಲ್ಯಗಳನ್ನು ಬಳಸಿ ಇಂಗಾಲ ಪ್ರಭಾವವನ್ನು ಹಣಕ್ಕೆ ಪರಿವರ್ತಿಸಿ, ಅದನ್ನು ಪ್ರಮಾಣಿತ [ನಿವ್ವಳ ವಿತ್ತೀಯ ಲಾಭ](../ನಿವ್ವಳ-ಹಣಕಾಸು-ಲಾಭ/)ದ ವಿರುದ್ಧ ಲೆಕ್ಕ ಹಾಕುತ್ತದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

NICE ಮತ್ತು NHS England ಈಗ ವೆಚ್ಚ ಮತ್ತು QALYಗಳ ಜೊತೆಗೆ ಪರಿಸರ ಪರಿಣಾಮವನ್ನು ಪರಿಗಣಿಸಲು ನಿರೀಕ್ಷಿಸುತ್ತವೆ. NHSಗೆ ಸಾರ್ವಜನಿಕ ನಿವ್ವಳ-ಶೂನ್ಯ ಬದ್ಧತೆ ಇದೆ: ತನ್ನ ನೇರ ಹೊರಸೂಸುವಿಕೆಗೆ 2040ರೊಳಗೆ ನಿವ್ವಳ ಶೂನ್ಯ, ಮತ್ತು ಪೂರ್ಣ ಪೂರೈಕೆ-ಸರಪಳಿ ಹೆಜ್ಜೆಗುರುತಿಗೆ 2045ರೊಳಗೆ ನಿವ್ವಳ ಶೂನ್ಯ. NICEಯ ಆರೋಗ್ಯ ತಂತ್ರಜ್ಞಾನ ಮೌಲ್ಯಮಾಪನ ಕೈಪಿಡಿ (PMG36) ತಂತ್ರಜ್ಞಾನ ಮೌಲ್ಯಮಾಪನದಲ್ಲಿ ಪರಿಸರ ಸುಸ್ಥಿರತೆಯನ್ನು ಉದಯೋನ್ಮುಖ ಪರಿಗಣನೆಯಾಗಿ ಉಲ್ಲೇಖಿಸುತ್ತದೆ. ಡಿಜಿಟಲ್ ಆರೋಗ್ಯ ಉತ್ಪನ್ನಕ್ಕೆ ಇದರ ಅರ್ಥ: ಇಂಗಾಲ ವೆಚ್ಚ, QALYಗಳು ಮತ್ತು [ದಕ್ಷತೆ ಗಡಿಯ ಪ್ರಾಬಲ್ಯ](../ಪ್ರಾಬಲ್ಯ-ಮತ್ತು-ದಕ್ಷತಾ-ಗಡಿ/)ದ ಜೊತೆಗೆ ಮೌಲ್ಯ ಪ್ರಕರಣದ ನಾಲ್ಕನೇ ಸ್ತಂಭವಾಗುತ್ತಿದೆ — ಯಾವುದಕ್ಕೂ ಬದಲಿಯಲ್ಲ, ಆದರೆ ಚೆನ್ನಾಗಿ ರೂಪಿಸಿದ ವ್ಯಾಪಾರ ಪ್ರಕರಣ ಹೆಚ್ಚಾಗಿ ವರದಿ ಮಾಡಬೇಕಾದ ಆಯಾಮ.

## ಗಣಿತ

```
Carbon per QALY = total_emissions_tonnes_co2e / total_qalys
  (a negative value means net emissions AVOIDED per QALY gained — a
  double win: better health and lower carbon)

Monetized carbon impact = emissions_tonnes_co2e × carbon_value_per_tonne
  (negative emissions × positive value = a negative cost, i.e. a benefit)

Carbon-adjusted NMB = net_monetary_benefit − monetized_carbon_impact
```

ಇದು ವೆಚ್ಚ/QALY ದಕ್ಷತೆ-ಗಡಿ ಕಲ್ಪನೆಯನ್ನು ಎರಡನೇ ಅಕ್ಷದೊಂದಿಗೆ ವಿಸ್ತರಿಸುತ್ತದೆ — ಪ್ರತಿ QALYಗೆ ಇಂಗಾಲ — ಅದೇ "ಪ್ರತಿ ಆಯ್ಕೆಯನ್ನು ಬಿಡಿಸಿ ಯಾವುದು ಪ್ರಾಬಲ್ಯಕ್ಕೊಳಗಾಗಿದೆ ಎಂದು ನೋಡಿ" ತರ್ಕ, [ಪ್ರಾಬಲ್ಯ ಮತ್ತು ದಕ್ಷತೆ ಗಡಿ](../ಪ್ರಾಬಲ್ಯ-ಮತ್ತು-ದಕ್ಷತಾ-ಗಡಿ/)ಯಂತೆ, ವೆಚ್ಚದ ಬದಲು ಇಂಗಾಲಕ್ಕೆ ಅನ್ವಯಿಸಿದ್ದು.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಟೆಲಿಹೆಲ್ತ್ ಸೇವೆ ಮುಖಾಮುಖಿ ಭೇಟಿಗಳನ್ನು ಬದಲಿಸಿ, ವರ್ಷಕ್ಕೆ 5,000 ಕಾರು ಪ್ರಯಾಣಗಳನ್ನು (ತಲಾ ಸುಮಾರು 8kg CO2e) ತಪ್ಪಿಸುತ್ತದೆ — 40 ಟನ್ CO2e ತಪ್ಪಿಸಲಾಗಿದೆ, ಋಣಾತ್ಮಕ ಹೊರಸೂಸುವಿಕೆ ಅಂಕಿಯಾಗಿ ಪ್ರತಿನಿಧಿಸಿದೆ (−40.0 ಟನ್), ಮತ್ತು ವರ್ಷಕ್ಕೆ 25 QALY ನೀಡುತ್ತದೆ:

```
Carbon per QALY = −40.0 / 25.0 = −1.6 tonnes CO2e avoided per QALY gained
```

Green Bookನ ವ್ಯಾಪಾರೇತರ ಇಂಗಾಲ ಮೌಲ್ಯವನ್ನು ಬಳಸಿ (ಉದಾಹರಣೆ ಅಂಕಿ, 2023 ವ್ಯಾಪಾರೇತರ ಕೇಂದ್ರ ಮೌಲ್ಯ ≈ £269/ಟನ್ CO2e — Green Book ಇಂಗಾಲ ಮೌಲ್ಯಗಳನ್ನು ವಾರ್ಷಿಕವಾಗಿ ನವೀಕರಿಸುತ್ತದೆ, ನೇರ ವಿಶ್ಲೇಷಣೆಯಲ್ಲಿ ಉಲ್ಲೇಖಿಸುವ ಮೊದಲು ಮರು-ಪರಿಶೀಲಿಸಿ):

```
Monetized carbon impact = −40.0 × £269 = −£10,760
```

−£10,760 "ವೆಚ್ಚ" ಎಂದರೆ £10,760 ಲಾಭ. ಮಧ್ಯಸ್ಥಿಕೆಯ ಸ್ವತಂತ್ರ ನಿವ್ವಳ ವಿತ್ತೀಯ ಲಾಭ £500,000 ಆಗಿದ್ದರೆ:

```
Carbon-adjusted NMB = £500,000 − (−£10,760) = £510,760
```

ಇಂಗಾಲ ಉಳಿತಾಯ ಪ್ರಕರಣಕ್ಕೆ ಕೊರತೆ ತರುವ ಬದಲು ಸೇರಿಸುತ್ತದೆ — ಋಣಾತ್ಮಕ-ಹೊರಸೂಸುವಿಕೆ ಚೌಕಟ್ಟು ಬಹಿರಂಗಪಡಿಸಲು ಉದ್ದೇಶಿಸಿದ ದ್ವಿಗುಣ ಗೆಲುವು.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಇದು AI/ಕ್ಲೌಡ್ ಅರ್ಥಶಾಸ್ತ್ರದೊಂದಿಗೆ ಜೀವಂತ, ಪ್ರಸ್ತುತ ಸಂಗಮ: AI ಮಾದರಿಯನ್ನು ತರಬೇತಿ ನೀಡಿ ನಡೆಸುವ ಕಂಪ್ಯೂಟ್ ಇಂಗಾಲ ಹೆಜ್ಜೆಗುರುತು ಈಗ NHS ಖರೀದಿಯಲ್ಲಿ ನಿಜವಾದ ಲೆಕ್ಕ ಸಾಲು, ಏಕೆಂದರೆ ನಿರ್ದಿಷ್ಟ ಮಿತಿಗಳ ಮೇಲಿನ NHS ಪೂರೈಕೆದಾರ ಒಪ್ಪಂದಗಳಿಗೆ ಇಂಗಾಲ ಕಡಿತ ಯೋಜನೆ ಬೇಕು. [ಕ್ಲೌಡ್ ಘಟಕ ಅರ್ಥಶಾಸ್ತ್ರ](../ಕ್ಲೌಡ್-ಘಟಕ-ಅರ್ಥಶಾಸ್ತ್ರ/) ಈಗಾಗಲೇ ಕಂಪ್ಯೂಟ್ ಉತ್ಪಾದನೆಯ ಪ್ರತಿ ಘಟಕದ ವೆಚ್ಚವನ್ನು ಟ್ರ್ಯಾಕ್ ಮಾಡುತ್ತದೆ; ಪ್ರತಿ QALYಗೆ ಇಂಗಾಲ ಭವಿಷ್ಯದ "ಪ್ರತಿ ಅನುಮಾನಕ್ಕೆ ಇಂಗಾಲ ವೆಚ್ಚ" ಮಾಪನಕ್ಕೆ ಸಹಜ ಮಾದರಿ, ಅದು ಆ ಘಟಕ ಮತ್ತು ಅನುಮಾನ ಘಟಕ ಅರ್ಥಶಾಸ್ತ್ರವನ್ನು ಪರಿಸರ ಆಯಾಮಕ್ಕೆ ವಿಸ್ತರಿಸುತ್ತದೆ, ಆದರೆ ಆ ಮಾಪನ ಇನ್ನೂ ಅಸ್ತಿತ್ವದಲ್ಲಿಲ್ಲ.

## ಎಡವಟ್ಟುಗಳು

- **ವ್ಯಾಪ್ತಿ-ಗಡಿ ಆಟ**: ನೇರ (Scope 1) ಹೊರಸೂಸುವಿಕೆಯನ್ನು ಮಾತ್ರ ಎಣಿಸಿ ಪೂರೈಕೆ-ಸರಪಳಿ (Scope 3) ಹೊರಸೂಸುವಿಕೆಯನ್ನು ಹೊರಗಿಡುವುದು, ಅದು ಡಿಜಿಟಲ್ ಆರೋಗ್ಯ ಉತ್ಪನ್ನದ ನಿಜವಾದ ಹೆಜ್ಜೆಗುರುತಿನ ಬಹುಪಾಲು.
- **ಹಳೆಯ ಇಂಗಾಲ ಮೌಲ್ಯದ ಬಳಕೆ**: Green Book ತನ್ನ ವ್ಯಾಪಾರೇತರ ಇಂಗಾಲ ಮೌಲ್ಯಗಳನ್ನು ವಾರ್ಷಿಕವಾಗಿ ನವೀಕರಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಉಲ್ಲೇಖಿಸಿದ ಯಾವುದೇ £/ಟನ್ ಅಂಕಿಗೆ ದಿನಾಂಕ ಇರಬೇಕು, ನಿಗದಿತ ಸ್ಥಿರಾಂಕವಾಗಿ ಉಲ್ಲೇಖಿಸಬಾರದು.
- **"ಇಂಗಾಲ-ದಕ್ಷ"ವನ್ನು "ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿ"ಗೆ ಬದಲಿಯಾಗಿ ಪರಿಗಣಿಸುವುದು**: ಕಡಿಮೆ-ಇಂಗಾಲ, ಕಡಿಮೆ-ಮೌಲ್ಯದ ಮಧ್ಯಸ್ಥಿಕೆ ಇನ್ನೂ NHS ಸಂಪನ್ಮೂಲಗಳ ಕಳಪೆ ಬಳಕೆ. ಇಂಗಾಲ ವೆಚ್ಚ ಮತ್ತು QALYಗಳ ಜೊತೆಗಿನ ನಾಲ್ಕನೇ ಸ್ತಂಭ, ಇವೆರಡರಲ್ಲಿ ಯಾವುದಕ್ಕೂ ಬದಲಿಯಲ್ಲ.
