# ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ ಮತ್ತು ಬಿಟ್ಟುಹೋಗುವಿಕೆ

ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ (retention) ಬಳಕೆದಾರ ಸಮೂಹದ ಯಾವ ಭಾಗ ಆರಂಭದ N ದಿನಗಳ ನಂತರವೂ ಸಕ್ರಿಯವಾಗಿದೆ ಎಂದು ಅಳೆಯುತ್ತದೆ (D1/D7/D30 ವಕ್ರರೇಖೆಗಳು); ಬಿಟ್ಟುಹೋಗುವಿಕೆ (churn) ಅದರ ಪೂರಕ. ಕ್ರೂರ ಡಿಜಿಟಲ್-ಆರೋಗ್ಯ ಮೂಲರೇಖೆ: **ಸುಮಾರು 90% ಆರೋಗ್ಯ-ಆ್ಯಪ್ ಬಳಕೆದಾರರು 30 ದಿನಗಳೊಳಗೆ ಕೈಬಿಡುತ್ತಾರೆ** — ಡಿಜಿಟಲ್ ಆರೋಗ್ಯ D30 ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ ಎಲ್ಲಾ-ಆ್ಯಪ್ ಸರಾಸರಿ ~6%ಗೆ ವಿರುದ್ಧ ~3–4%.

## ಇದು ಏಕೆ ಮುಖ್ಯ

Eysenbach 2005ರಲ್ಲಿ ಇದಕ್ಕೆ ಹೆಸರಿಟ್ಟರು: **ಕ್ಷೀಣತೆಯ ನಿಯಮ (law of attrition)** — ಹೆಚ್ಚಿನ ದರದಲ್ಲಿ ಬಳಕೆದಾರರನ್ನು ಕಳೆದುಕೊಳ್ಳುವುದು eHealth ಮಧ್ಯಸ್ಥಿಕೆಗಳ ಆಂತರಿಕ, ರಚನಾತ್ಮಕ ಗುಣ, ಅನುಷ್ಠಾನ ದೋಷವಲ್ಲ, eHealth ಪ್ರಯೋಗಗಳಲ್ಲಿ ಕ್ಷೀಣತೆ ನಿಯಮಿತವಾಗಿ 50% ಮೀರುತ್ತದೆ. ಆರ್ಥಿಕ ಪರಿಣಾಮ ಸಂಪೂರ್ಣ: ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ ಯಾವುದೇ ಲಾಭ ತಲುಪಿಸಬಹುದಾದ *ಚಿಕಿತ್ಸಾ ಕಿಟಕಿ*ಯನ್ನು ಮತ್ತು [ಘಟಕ ಅರ್ಥಶಾಸ್ತ್ರ](../ಆರೋಗ್ಯ-ಆ್ಯಪ್-ಘಟಕ-ಅರ್ಥಶಾಸ್ತ್ರ/)ವನ್ನು ವ್ಯಾಖ್ಯಾನಿಸುತ್ತದೆ — 12 ದಿನ ಉಳಿಯುವ ಬಳಕೆದಾರರಿಗೆ ಪಾವತಿಸಿದ CAC LTV ಅಥವಾ QALYಗಳನ್ನು ತಲುಪಿಸುವುದಿಲ್ಲ. ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ ವಕ್ರರೇಖೆಯಿಂದ ಲಾಭಗಳನ್ನು ತೂಕ ಮಾಡದ ಗ್ರಾಹಕ ಆರೋಗ್ಯ ಉತ್ಪನ್ನದ ಯಾವುದೇ ಆರ್ಥಿಕ ಮಾದರಿ ಅಸ್ತಿತ್ವದಲ್ಲಿಲ್ಲದ ಉತ್ಪನ್ನವನ್ನು ವಿವರಿಸುತ್ತಿದೆ.

## ಗಣಿತ

```
Retention_Dn = users active on day n / cohort size × 100
Churn rate   = users lost in period / users at period start × 100

Benefit weighting (the health-economics move):
  expected benefit per acquired user = Σ_t retention(t) × benefit rate(t)
  ≈ area under the retention curve × per-time benefit
  — NOT trial benefit × 100% of acquired users

Cost per retained-at-D30 user = CAC / D30 retention
  (at 4% D30, a £5 CAC is really £125 per retained user)
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಮಾನಸಿಕ-ಆರೋಗ್ಯ ಆ್ಯಪ್: 8 ವಾರಗಳನ್ನು ಪೂರ್ಣಗೊಳಿಸುವ ಪ್ರತಿ ಬಳಕೆದಾರರಿಗೆ 0.02 QALY ಲಾಭ ಎಂದು ಪ್ರಯೋಗ ತೋರಿಸಿತು. 100,000 ಡೌನ್‌ಲೋಡ್‌ಗಳ ನಿಯೋಜನೆ ಸಮೂಹ, ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ D7 25%, D30 8%, ವಾರ-8 4%:

```
Completers          = 100,000 × 0.04 = 4,000
QALYs delivered     = 4,000 × 0.02 = 80  (not 100,000 × 0.02 = 2,000)
At £20,000/QALY     = £1.6M of health value (not £40M)

Per-download health value = £16 — the number that should set what a
payer will pay per download, and it is 4% of the naive claim.
Retention improvement case: moving week-8 completion 4% → 6% adds
40 QALYs/year ≈ £800k — retention engineering IS health production.
```

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಉತ್ಪನ್ನ ಎಂಜಿನಿಯರಿಂಗ್ ಮೇಲಿನ ಅಂಕಗಣಿತದಂತೆ ಆರೋಗ್ಯ ಮೌಲ್ಯವನ್ನು ಅತ್ಯಂತ ನೇರವಾಗಿ ತಯಾರಿಸುವ ಮಾಪನ ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ. ಅದನ್ನು ಚಲಿಸುವ ಅಭ್ಯಾಸಗಳು ಸಾಮಾನ್ಯ: ಆನ್‌ಬೋರ್ಡಿಂಗ್ ಮೊದಲ-ಮೌಲ್ಯದ ಸಮಯ, ಮರು-ತೊಡಗಿಕೊಳ್ಳುವಿಕೆ ವಿನ್ಯಾಸ, ಕಾರ್ಯಕ್ಷಮತೆ, ಮತ್ತು ನಿರ್ಣಾಯಕವಾಗಿ **ಯೋಜಿತ ಮಾತ್ರೆ ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ** — ನಿರ್ದಿಷ್ಟ ಅಂತ್ಯವಿರುವ ಕಾರ್ಯಕ್ರಮ (8 ವಾರಗಳು, ನಂತರ ಪದವಿ) ಶಾಶ್ವತ DAU ಅಲ್ಲ, *ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ* ಅಳೆಯಬೇಕು, ಮಾಪನವನ್ನು ಜಾಹೀರಾತು-ಧನಸಹಾಯದ ಗಮನ ಮಾದರಿಯ ಬದಲು ಕ್ಲಿನಿಕಲ್ ಮಾದರಿಗೆ ಹೊಂದಿಸುತ್ತದೆ. ಬದುಕುಳಿಯುವಿಕೆ ವಿಶ್ಲೇಷಣೆ ಸರಿಯಾದ ಸಾಧನ ಪೆಟ್ಟಿಗೆ ([ಗಳಿಸಿದ ಜೀವ ವರ್ಷಗಳು](../ಗಳಿಸಿದ-ಜೀವ-ವರ್ಷಗಳು/)ಯ ಅದೇ Kaplan-Meier ಗಣಿತ); ವಕ್ರರೇಖೆಗಳನ್ನು ಸ್ವಾಧೀನ ಚಾನೆಲ್ ಮೂಲಕ ವಿಭಾಗಿಸಿ, ಏಕೆಂದರೆ ಚಾನೆಲ್ ಮಿಶ್ರಣ ಹೆಚ್ಚಿನ ವೈಶಿಷ್ಟ್ಯಗಳಿಗಿಂತ ಹೆಚ್ಚು ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆಯನ್ನು ಬದಲಿಸುತ್ತದೆ.

## ಎಡವಟ್ಟುಗಳು

- **ವಿರುದ್ಧ ದಿಕ್ಕಿನ ಉದ್ದೇಶ-ಚಿಕಿತ್ಸೆ ತೊಳೆಯುವಿಕೆ**: ಪ್ರಯೋಗಗಳು ಪೂರ್ಣಗೊಳಿಸಿದವರನ್ನು ವರದಿ ಮಾಡುತ್ತವೆ; ನಿಯೋಜನೆ ಅರ್ಥಶಾಸ್ತ್ರ ಸ್ವಾಧೀನಪಡಿಸಿಕೊಂಡ ಎಲ್ಲರನ್ನೂ ಎಣಿಸಬೇಕು (Eysenbachರ ಮುಖ್ಯ ಎಚ್ಚರಿಕೆ).
- **ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ ನಾಟಕ**: ಚಿಕಿತ್ಸಕ ಕ್ರಿಯೆಯನ್ನು ಎಂದಿಗೂ ನಿರ್ವಹಿಸದ ಅಧಿಸೂಚನೆ-ಚಾಲಿತ "ಸಕ್ರಿಯ" ಬಳಕೆದಾರರು ([ತೊಡಗಿಕೊಳ್ಳುವಿಕೆ ಮಾಪನಗಳು](../ತೊಡಗಿಕೊಳ್ಳುವಿಕೆ-ಮಾಪನಗಳು/) ನೋಡಿ).
- **ವ್ಯಾಖ್ಯಾನಗಳಾದ್ಯಂತ ವಕ್ರರೇಖೆ ಹೋಲಿಕೆ**: "ಸಕ್ರಿಯ" ಅನ್ನು ತೆರೆದಿದೆ vs ಅರ್ಥಪೂರ್ಣ ಕ್ರಿಯೆ ಎಂದು ವ್ಯಾಖ್ಯಾನಿಸುವುದು D30 ಅನ್ನು ಪಟ್ಟುಗಳಲ್ಲಿ ಬದಲಿಸುತ್ತದೆ.
- **ಯಾರು ಬಿಟ್ಟುಹೋಗುತ್ತಾರೆ ಎಂಬುದರ ನಿರ್ಲಕ್ಷ್ಯ**: ಅತಿ ಅನಾರೋಗ್ಯದವರು ಅತಿ ವೇಗವಾಗಿ ಬಿಟ್ಟುಹೋದರೆ, ಆರೋಗ್ಯವಂತರಲ್ಲಿ ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ ಸುಧಾರಿಸಿದಂತೆ ಪ್ರತಿ-ಬಳಕೆದಾರ ಲಾಭ ಇಳಿಯುತ್ತದೆ — ವಕ್ರರೇಖೆಗಳನ್ನು ಪ್ರಕರಣ-ಮಿಶ್ರಣದೊಂದಿಗೆ ಜೋಡಿಸಿ ([ವ್ಯಾಪ್ತಿ ಮತ್ತು ಸಮಾನತೆ](../ವ್ಯಾಪ್ತಿ-ಮತ್ತು-ಸಮಾನತೆ/) ನೋಡಿ).
