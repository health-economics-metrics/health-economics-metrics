# ತಾಂತ್ರಿಕ ಸಾಲ

ತಾಂತ್ರಿಕ ಸಾಲ (technical debt) ಎಂದರೆ ಕೋಡ್‌ಬೇಸ್‌ನಲ್ಲಿ ಹಿಂದಿನ ತಾತ್ಕಾಲಿಕ ನಿರ್ಧಾರಗಳ ಸೂಚ್ಯ ಭವಿಷ್ಯದ ವೆಚ್ಚ: ಬಾಕಿ ಇರುವ ಪರಿಹಾರ ಕೆಲಸ (**ಮೂಲಧನ**) ಮತ್ತು ಅದು ವಿತರಣೆಯ ಮೇಲೆ ಬೀರುವ ನಿರಂತರ ಎಳೆತ (**ಬಡ್ಡಿ**). SQALE ನಂತಹ ಪರಿಮಾಣೀಕರಣ ವಿಧಾನಗಳು ಅದನ್ನು ರೂಪಕದಿಂದ ವೆಚ್ಚ ಲೆಕ್ಕಿಸಿದ ಹೊಣೆಗಾರಿಕೆಯಾಗಿ ಪರಿವರ್ತಿಸುತ್ತವೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಪರಿಮಾಣೀಕರಿಸದ ತಾಂತ್ರಿಕ ಸಾಲ ಗೊಣಗಾಟ; ಪರಿಮಾಣೀಕರಿಸಿದರೆ ವ್ಯಾಪಾರ ಸಮರ್ಥನೆ. ಉದ್ಯಮ ಮೂಲರೇಖೆಗಳು (CAST Appmarq, 1,400 ಆ್ಯಪ್‌ಗಳು / 550M LOC): ಐತಿಹಾಸಿಕವಾಗಿ ಪ್ರತಿ ಕೋಡ್ ಸಾಲಿಗೆ ≈ **$3.61 ತಾಂತ್ರಿಕ-ಸಾಲ ಮೂಲಧನ**, ವಿಶಿಷ್ಟ ಕೋಡ್‌ಬೇಸ್‌ಗಳು ಮರುನಿರ್ಮಾಣ ವೆಚ್ಚದ 15–20% ಸಾಲ ಅನುಪಾತ ಹೊತ್ತಿರುತ್ತವೆ, ಸಾಮಾನ್ಯವಾಗಿ ಬಳಸುವ ಆರೋಗ್ಯ ಮಟ್ಟ ≤5% (SonarQubeನ "A" ದರ್ಜೆ) ವಿರುದ್ಧ. ಆರೋಗ್ಯ-ಅರ್ಥಶಾಸ್ತ್ರ ಚೌಕಟ್ಟು ನಿಖರವಾಗಿ ಹೊಂದುತ್ತದೆ: ಸಾಲ *ದೀರ್ಘಕಾಲಿಕ ಸ್ಥಿತಿ* — ಚಿಕಿತ್ಸೆಯಿಲ್ಲದಿದ್ದರೆ ಪ್ರಗತಿಸುತ್ತದೆ, ಅದರ "ಬಡ್ಡಿ" ನಿಧಾನ ವಿತರಣೆ ಮತ್ತು ಹೆಚ್ಚಿನ ದೋಷ ದರಗಳಾಗಿ ಚಕ್ರಬಡ್ಡಿ ಹೊಂದುತ್ತದೆ, ಮತ್ತು ತಡೆಗಟ್ಟುವಿಕೆ ಚಿಕಿತ್ಸೆಯೊಂದಿಗೆ ಸ್ಪರ್ಧಿಸುವಂತೆ ಪರಿಹಾರ ವೈಶಿಷ್ಟ್ಯ ಕೆಲಸದೊಂದಿಗೆ ಸಾಮರ್ಥ್ಯಕ್ಕಾಗಿ ಸ್ಪರ್ಧಿಸುತ್ತದೆ.

## ಗಣಿತ

```
SQALE principal   = Σ over violations (remediation time) × developer cost rate
Technical debt ratio (TDR) = remediation cost / redevelopment cost × 100
                    (SonarQube grades: A ≤ 5%, B ≤ 10%, C ≤ 20%, D ≤ 50%)

Interest (the number that justifies paydown):
  interest/year = Δ delivery velocity × value per unit velocity
                + Δ defect rate × cost per defect
Paydown case  = PV(interest avoided over horizon) − remediation cost
                (discounted — see discounting-and-time-preference.md)
```

ಮೂಲಧನ ಹೊಣೆಗಾರಿಕೆಯನ್ನು ತಿಳಿಸುತ್ತದೆ; **ಬಡ್ಡಿ** ಹೂಡಿಕೆ ಪ್ರಕರಣವನ್ನು ಮಾಡುತ್ತದೆ. ವರ್ಷಕ್ಕೆ £40k ಬಡ್ಡಿ ತಪ್ಪಿಸಲು £500k ಮೂಲಧನ ಪಾವತಿಸುವುದು ಕೆಟ್ಟ ವ್ಯಾಪಾರ; £400k/ವರ್ಷ ತಪ್ಪಿಸಲು, ಅತ್ಯುತ್ತಮ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

400k-LOC ಕ್ಲಿನಿಕಲ್-ದಾಖಲೆ ಏಕೀಕರಣ ಪದರ: SQALE ಮೂಲಧನ 3,800 ಗಂಟೆಗಳು × £75 = **£285k**; TDR ≈ 12% (ದರ್ಜೆ C). ಅಳೆದ ಬಡ್ಡಿ: ಈ ಪದರವನ್ನು ಮುಟ್ಟುವ ತಂಡಗಳು ಎಸ್ಟೇಟ್ ಮೂಲರೇಖೆಗೆ ಹೋಲಿಸಿದರೆ 40% ದೀರ್ಘ ಚಕ್ರ ಸಮಯ ಮತ್ತು 2× ಬದಲಾವಣೆ-ವೈಫಲ್ಯ ದರಗಳನ್ನು ತೋರಿಸುತ್ತವೆ. ಪದರ ವರ್ಷಕ್ಕೆ 6,000 ಡೆವ್-ಗಂಟೆಗಳನ್ನು ಹೀರಿಕೊಳ್ಳುತ್ತದೆ:

```
Interest ≈ 6,000 × 0.40 × £75      = £180,000/year (velocity drag)
         + 12 extra failures × £8,000 = £96,000/year (rework/incidents)
         ≈ £276,000/year

Remediate the worst 30% of principal (£85k) targeting hotspots → modelled
interest reduction 60%: saves ~£166k/year. Payback ≈ 6 months.
```

ಹಾಟ್‌ಸ್ಪಾಟ್ ಗುರಿ ಮುಖ್ಯ: ಸಾಲ ಬಡ್ಡಿ ಬದಲಾವಣೆ ಆವರ್ತನ × ಸಾಲ ಸಾಂದ್ರತೆ ಶಿಖರವಾಗುವಲ್ಲಿ ಕೇಂದ್ರೀಕರಿಸುತ್ತದೆ — ವಿರಳವಾಗಿ ಮುಟ್ಟುವ ಸಾಲವನ್ನು ಸರಿಪಡಿಸುವುದು ಏನನ್ನೂ ಖರೀದಿಸುವುದಿಲ್ಲ, ಎಂದಿಗೂ ಪ್ರಗತಿಸದ ಸ್ಥಿತಿಗೆ ಚಿಕಿತ್ಸೆ ನೀಡಿದಂತೆ ([ತಡೆಗಟ್ಟುವಿಕೆ ಅರ್ಥಶಾಸ್ತ್ರ](../ತಡೆಗಟ್ಟುವಿಕೆ-ಅರ್ಥಶಾಸ್ತ್ರ/)).

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ತಾಂತ್ರಿಕ-ಸಾಲ ವಾದಗಳನ್ನು ಉನ್ನತೀಕರಿಸುವ ಆರೋಗ್ಯ-ಅರ್ಥಶಾಸ್ತ್ರ ಆಮದುಗಳು: ಎಸ್ಟೇಟ್ ಅನ್ನು **ಹೊರೆ ದಾಸ್ತಾನು**ವಾಗಿ ವ್ಯಕ್ತಪಡಿಸಿ ([DALY](../ಅಂಗವೈಕಲ್ಯ-ಹೊಂದಾಣಿಕೆಯ-ಜೀವ-ವರ್ಷ/)-ಶೈಲಿ — ಕಳೆದುಹೋದ ಆರೋಗ್ಯಕರ ಎಂಜಿನಿಯರಿಂಗ್-ವರ್ಷಗಳು ಎಲ್ಲಿವೆ?); ಪರಿಹಾರವನ್ನು ಪ್ರಗತಿ ಗಣಿತದಿಂದ ಪ್ರಾಮಾಣಿಕವಾಗಿ ಸಮರ್ಥಿಸಿ (ಸಾಮಾನ್ಯವಾಗಿ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿ, ವೆಚ್ಚ-ಉಳಿತಾಯವಲ್ಲ); ಅತ್ಯಂತ ಕೆಟ್ಟ ವ್ಯವಸ್ಥೆಗಳ ಪರಿಹಾರಕ್ಕೆ [ತೀವ್ರತೆ ಕೊರತೆ](../qaly-ಕೊರತೆ-ಮತ್ತು-ತೀವ್ರತಾ-ಮಾರ್ಪಾಡುಗಳು/)ಯಿಂದ ತೂಕ ನೀಡಿ; ಮತ್ತು ದೊಡ್ಡ ಪರಿಹಾರ ಪ್ರಸ್ತಾವನೆಗಳನ್ನು [ತಪ್ಪಿಸಿದ ಕೆಳಹಂತದ ವೆಚ್ಚಗಳ](../ತಪ್ಪಿಸಿದ-ಕೆಳಹಂತದ-ವೆಚ್ಚಗಳು/) ನಿಯಮಗಳನ್ನು ಉಳಿಸಿಕೊಳ್ಳುವ ಸರಿದೂಗಿಸುವ ವಿಶ್ಲೇಷಣೆಯೊಂದಿಗೆ ಸಲ್ಲಿಸಿ — ಸಂಭವನೀಯತೆ-ತೂಕದ, ರಿಯಾಯಿತಿ ಮಾಡಿದ, ಒಮ್ಮೆ ಎಣಿಸಿದ.

## ಎಡವಟ್ಟುಗಳು

- **ಮೂಲಧನ-ಮಾತ್ರ ವರದಿ**: ಬಡ್ಡಿ ಅಂದಾಜಿಲ್ಲದ ದೊಡ್ಡ ಭಯಾನಕ ಸಂಖ್ಯೆ ಏನನ್ನೂ ಸಮರ್ಥಿಸುವುದಿಲ್ಲ.
- **ಸಾಧನ-ಉತ್ಪಾದಿತ ಸಾಲ ಅಂಕಿಗಳನ್ನು ಅಕ್ಷರಶಃ ತೆಗೆದುಕೊಳ್ಳುವುದು**: SQALE ನಿಯಮ ಉಲ್ಲಂಘನೆಗಳನ್ನು ಎಣಿಸುತ್ತದೆ; ವಾಸ್ತುಶಿಲ್ಪ ಸಾಲವನ್ನು (ದುಬಾರಿ ರೀತಿ) ತಪ್ಪಿಸುತ್ತದೆ ಮತ್ತು ಕ್ಷುಲ್ಲಕತೆಗಳನ್ನು ಎಣಿಸುತ್ತದೆ.
- **ಸಾಲ-ಶೂನ್ಯ ಆದರ್ಶವಾದ**: ಅತ್ಯುತ್ತಮ ಸಾಲ ಮಟ್ಟ ಶೂನ್ಯವಲ್ಲ — ಸಾಲ ಬಲ; ಪ್ರಶ್ನೆ ಬಡ್ಡಿ ದರ.
- **"ಮರುಬರವಣಿಗೆ ಎಲ್ಲವನ್ನೂ ತಪ್ಪಿಸುತ್ತದೆ"**: ಮರುಬರವಣಿಗೆ ಪ್ರಸ್ತಾವನೆಗಳು ಅದೇ ಸರಿದೂಗಿಸುವ ನಿಯಮಗಳನ್ನು ದಾಟಬೇಕು — ಪ್ರತಿ-ವಾಸ್ತವಿಕ ವೆಚ್ಚ, ಸಂಭವನೀಯತೆ, ರಿಯಾಯಿತಿ.
