# EQ-5D

EQ-5D ಎಂಬುದು ಆರೋಗ್ಯ-ಸಂಬಂಧಿತ ಜೀವನ ಗುಣಮಟ್ಟವನ್ನು ಅಳೆಯಲು EuroQol ಗುಂಪಿನ ಪ್ರಮಾಣೀಕೃತ ಪ್ರಶ್ನಾವಳಿ. ಹೆಚ್ಚಿನ [QALY](../ಗುಣಮಟ್ಟ-ಹೊಂದಾಣಿಕೆಯ-ಜೀವ-ವರ್ಷ/) ಲೆಕ್ಕಾಚಾರಗಳೊಳಗಿನ ಉಪಯುಕ್ತತಾ ತೂಕಗಳನ್ನು ಉತ್ಪಾದಿಸುವ ಸಾಧನ ಇದು — NICEಯ ಉಲ್ಲೇಖ ಪ್ರಕರಣ ವಯಸ್ಕರಿಗೆ ಇದನ್ನೇ ಆದ್ಯತೆಯ ಮಾಪನ ಎಂದು ಹೆಸರಿಸುತ್ತದೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

QALYಗಳನ್ನು ಹೇಳಿಕೊಳ್ಳಬಯಸುವ ಯಾವುದೇ ಡಿಜಿಟಲ್ ಆರೋಗ್ಯ ಉತ್ಪನ್ನಕ್ಕೆ ಮಾನ್ಯತೆ ಪಡೆದ ಸಾಧನದಿಂದ ಉಪಯುಕ್ತತೆಗಳು ಬೇಕು, ಮತ್ತು ಯುಕೆ ಹಾಗೂ ಯುರೋಪಿನ ಬಹುಭಾಗದಲ್ಲಿ EQ-5D ಡೀಫಾಲ್ಟ್. ಇದು ಆ್ಯಪ್‌ನಲ್ಲಿ ಅಳವಡಿಸಲು ಸಾಕಷ್ಟು ಚಿಕ್ಕದು (5 ಪ್ರಶ್ನೆಗಳು + ದೃಶ್ಯ ಮಾಪಕ), ಅಂದರೆ ಸಾಫ್ಟ್‌ವೇರ್ ಉತ್ಪನ್ನಗಳು ಸಾಮಾನ್ಯ ಬಳಕೆಯ ಅಡ್ಡ ಪರಿಣಾಮವಾಗಿ HTA-ದರ್ಜೆಯ ಫಲಿತಾಂಶ ದತ್ತಾಂಶವನ್ನು ಸಂಗ್ರಹಿಸಬಹುದು — ಮೀಸಲಾದ ಅಧ್ಯಯನಗಳು ಬೇಕಾಗುವ ಔಷಧಗಳ ಮೇಲೆ ರಚನಾತ್ಮಕ ಅನುಕೂಲ.

## ಗಣಿತ

EQ-5D-5L **5 ಆಯಾಮಗಳಲ್ಲಿ** ಪ್ರತಿಯೊಂದರಲ್ಲಿ ಒಂದು ಪ್ರಶ್ನೆ ಕೇಳುತ್ತದೆ — ಚಲನಶೀಲತೆ, ಸ್ವಯಂ-ಆರೈಕೆ, ಸಾಮಾನ್ಯ ಚಟುವಟಿಕೆಗಳು, ನೋವು/ಅಸ್ವಸ್ಥತೆ, ಆತಂಕ/ಖಿನ್ನತೆ — ಪ್ರತಿಯೊಂದಕ್ಕೂ **5 ಹಂತಗಳಲ್ಲಿ** ಉತ್ತರ (ಸಮಸ್ಯೆ ಇಲ್ಲ … ತೀವ್ರ ಸಮಸ್ಯೆಗಳು), ಜೊತೆಗೆ 0–100 ದೃಶ್ಯ ಸದೃಶ ಮಾಪಕ (EQ VAS).

```
Health state = 5-digit profile, e.g. "21221"
Utility index = value_set(profile)

The value set is country-specific, derived from time-trade-off /
discrete-choice surveys of the general public. Anchors: 1 = full health,
0 = dead; states worse than death are negative (UK 3L set floor: −0.594).
```

ನಂತರ QALY ಅಂಕಗಣಿತ `duration × utility` ಆಗಿ ಮುಂದುವರಿಯುತ್ತದೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಸ್ನಾಯು-ಅಸ್ಥಿ ಪುನರ್ವಸತಿ ಆ್ಯಪ್, ಪೂರ್ಣಗೊಳಿಸುವ 1,000 ಬಳಕೆದಾರರಿಗೆ ಆನ್‌ಬೋರ್ಡಿಂಗ್‌ನಲ್ಲಿ ಮತ್ತು 6 ತಿಂಗಳಲ್ಲಿ EQ-5D-5L ಅಳೆಯುತ್ತದೆ.

```
Mean utility at baseline:  0.62
Mean utility at 6 months:  0.71
Gain sustained (assume) 1 year: (0.71 − 0.62) × 1.0 = 0.09 QALYs per user
```

ನಿಯಂತ್ರಣ-ಗುಂಪಿನ ಬದಲಾವಣೆ 0.03 (ಸಹಜ ಚೇತರಿಕೆ) ವಿರುದ್ಧ, ಆರೋಪಿಸಬಹುದಾದ ಲಾಭ ಪ್ರತಿ ಬಳಕೆದಾರರಿಗೆ 0.06 QALY. ಪ್ರತಿ QALYಗೆ £20,000–£30,000ದಲ್ಲಿ ಹಣದ ರೂಪಕ್ಕೆ: **ಪೂರ್ಣಗೊಳಿಸುವ ಪ್ರತಿ ಬಳಕೆದಾರರಿಗೆ £1,200–£1,800 ಆರೋಗ್ಯ ಮೌಲ್ಯ** — ಪಾವತಿದಾರರೊಂದಿಗೆ ಆ್ಯಪ್‌ನ ಬೆಲೆ ಮಾತುಕತೆಗೆ ಆಧಾರವಾಗುವ ಸಂಖ್ಯೆ. (EQ-5D ಸೂಚ್ಯಂಕಕ್ಕೆ ಕನಿಷ್ಠ ವೈದ್ಯಕೀಯವಾಗಿ ಮುಖ್ಯ ವ್ಯತ್ಯಾಸಗಳು ಸಾಮಾನ್ಯವಾಗಿ 0.03–0.08 ವ್ಯಾಪ್ತಿಯಲ್ಲಿರುತ್ತವೆ, ಆದ್ದರಿಂದ 0.06 ಸಂಭಾವ್ಯ ಆದರೆ ನಿಯಂತ್ರಣ ಹೋಲಿಕೆಯನ್ನು ದಾಟಬೇಕು; [ರೋಗಿ-ವರದಿ ಫಲಿತಾಂಶಗಳು](../ರೋಗಿ-ವರದಿ-ಫಲಿತಾಂಶಗಳು/) ನೋಡಿ.)

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

- **ಇದನ್ನು ಅಳವಡಿಸಿ.** ಸೈನ್-ಅಪ್‌ನಲ್ಲಿ ಮತ್ತು ಅನುಸರಣಾ ಅಂತರಗಳಲ್ಲಿ EQ-5D ಕೆಲವೇ UI ಪರದೆಗಳು; ಫಲ HTA-ದರ್ಜೆಯ ಸಾಕ್ಷ್ಯ. EuroQolನಿಂದ ಪರವಾನಗಿ ಪಡೆಯಿರಿ (ಅಗತ್ಯ, ಕೆಲವು ಬಳಕೆಗಳಿಗೆ ಉಚಿತ).
- ನಿಯೋಜನಾ ದೇಶಕ್ಕೆ **ಸರಿಯಾದ ಮೌಲ್ಯ ಗುಚ್ಛ ಬಳಸಿ** — ಅದೇ ಉತ್ತರಗಳು ಯುಕೆ vs ಜರ್ಮನಿ vs ಜಪಾನ್‌ನಲ್ಲಿ ಬೇರೆ ಅಂಕ ಪಡೆಯುತ್ತವೆ.
- **ವಿನ್ಯಾಸ ಪಾಠ**: ಚಿಕ್ಕ ಪ್ರಮಾಣೀಕೃತ ಸಮೀಕ್ಷೆ ಜೊತೆಗೆ ಪ್ರಕಟಿತ ಅಂಕ ನೀಡುವ ಕಾರ್ಯವು ಹೋಲಿಸಬಲ್ಲ ಏಕ ಸೂಚ್ಯಂಕವನ್ನು ಹೇಗೆ ನೀಡುತ್ತದೆ ಎಂಬುದನ್ನು EQ-5D ತೋರಿಸುತ್ತದೆ. ಯಾವುದೇ ನಂಬಲರ್ಹ ಡೆವಲಪರ್-ಅನುಭವ ಸೂಚ್ಯಂಕಕ್ಕೂ ಅದೇ ಮಾದರಿ — ಪ್ರಮಾಣೀಕೃತ ಸಾಧನ, ಪ್ರಕಟಿತ ತೂಕಗಳು, ತಾತ್ಕಾಲಿಕ ಭಾವನೆಗಳಲ್ಲ. [SPACE ಮತ್ತು DevEx](../space-ಮತ್ತು-devex/) ನೋಡಿ.

## ಎಡವಟ್ಟುಗಳು

- **ಹೋಲಿಕೆ ಗುಂಪಿಲ್ಲದ ಮೊದಲು/ನಂತರ** — ಸರಾಸರಿಗೆ ಹಿಂಜರಿತ ಮತ್ತು ಸಹಜ ಚೇತರಿಕೆ ಮುಗ್ಧ ಲಾಭಗಳನ್ನು ಉಬ್ಬಿಸುತ್ತವೆ.
- **ಬದುಕುಳಿದವರ ಪಕ್ಷಪಾತ**: ತೊಡಗಿಸಿಕೊಂಡಿದ್ದ ಬಳಕೆದಾರರನ್ನು ಮಾತ್ರ ಅಳೆಯುವುದು ([ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ ಮತ್ತು ಬಿಟ್ಟುಹೋಗುವಿಕೆ](../ಉಳಿಸಿಕೊಳ್ಳುವಿಕೆ-ಮತ್ತು-ಬಿಟ್ಟುಹೋಗುವಿಕೆ/) ನೋಡಿ).
- ಅಧ್ಯಯನಗಳಾದ್ಯಂತ **3L ಮತ್ತು 5L ಆವೃತ್ತಿಗಳು ಅಥವಾ ಮೌಲ್ಯ ಗುಚ್ಛಗಳನ್ನು ಬೆರೆಸುವುದು** — ವ್ಯವಸ್ಥಿತವಾಗಿ ಭಿನ್ನ ಸಂಖ್ಯೆಗಳು.
- ಸೌಮ್ಯವಾಗಿ ಬಾಧಿತ ಜನಸಂಖ್ಯೆಗಳಲ್ಲಿ **ಮೇಲ್ಛಾವಣಿ ಪರಿಣಾಮಗಳು**: ಅನೇಕ ಬಳಕೆದಾರರು ಆರಂಭದಲ್ಲೇ 1.0ರ ಹತ್ತಿರ ಅಂಕ ಪಡೆಯುತ್ತಾರೆ, ಲಾಭ ತೋರಿಸಲು ಜಾಗ ಉಳಿಯುವುದಿಲ್ಲ.
- **ಮೌಲ್ಯ ಗುಚ್ಛವನ್ನು ಸ್ವಯಂ-ಸಮರ್ಥನೀಯ ಎಂದು ಪರಿಗಣಿಸುವುದು**: ಮೌಲ್ಯ ಗುಚ್ಛ ಹಿಂತಿರುಗಿಸುವ ಉಪಯುಕ್ತತಾ ಸಂಖ್ಯೆಗಳನ್ನು ಸ್ವತಃ ಕಾಲ ವಿನಿಮಯ (ಅಥವಾ ಸಂಬಂಧಿತ ಆಯ್ಕೆ-ಆಧಾರಿತ) ಸಮೀಕ್ಷೆಗಳ ಮೂಲಕ ಸಾರ್ವಜನಿಕರಿಂದ ಪಡೆಯಲಾಗಿದೆ — ಹೇಗೆ ಎಂದು ತಿಳಿಯಲು [ಕಾಲ ವಿನಿಮಯ (TTO) ಉಪಯುಕ್ತತಾ ನಿರ್ಧಾರಣೆ](../ಕಾಲ-ವಿನಿಮಯ-tto-ಉಪಯುಕ್ತತಾ-ನಿರ್ಧಾರಣೆ/) ನೋಡಿ.
