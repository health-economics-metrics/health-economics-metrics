# ಕ್ಲೌಡ್ ಘಟಕ ಅರ್ಥಶಾಸ್ತ್ರ (FinOps)

ಕ್ಲೌಡ್ ಘಟಕ ಅರ್ಥಶಾಸ್ತ್ರ ಕಚ್ಚಾ ಕ್ಲೌಡ್ ಖರ್ಚನ್ನು **ಉತ್ಪಾದನೆಯ ಪ್ರತಿ ಘಟಕಕ್ಕೆ ವೆಚ್ಚ**ವಾಗಿ ಪರಿವರ್ತಿಸುತ್ತದೆ — ಪ್ರತಿ ಗ್ರಾಹಕ, ಪ್ರತಿ ವಹಿವಾಟು, ಪ್ರತಿ ಬಗೆಹರಿದ ಪ್ರಕರಣ, ಪ್ರತಿ ಟೋಕನ್. "ನಮ್ಮ AWS ಬಿಲ್ ತಿಂಗಳಿಗೆ £400k" ಅನ್ನು "ಒಬ್ಬ ರೋಗಿಗೆ ಸೇವೆ ನೀಡಲು £0.83 ವೆಚ್ಚ" ಆಗಿ ಬದಲಿಸುವ FinOps ಸಾಮರ್ಥ್ಯ ಇದು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಒಟ್ಟು ಖರ್ಚಿನ ಅಂಕಿಗಳು ಮುಖ್ಯ ಪ್ರಶ್ನೆಗಳಿಗೆ ಉತ್ತರಿಸಲಾರವು: ಉತ್ಪನ್ನ ಹೆಚ್ಚು ದಕ್ಷವಾಗುತ್ತಿದೆಯೇ ಕಡಿಮೆಯೇ? ಬೆಳವಣಿಗೆ ಲಾಭಾಂಶವನ್ನು ಸುಧಾರಿಸುತ್ತದೆಯೇ ನಾಶಮಾಡುತ್ತದೆಯೇ? ನಾವು ಎಷ್ಟು ಶುಲ್ಕ ವಿಧಿಸಬೇಕು? ಘಟಕ ವೆಚ್ಚಗಳು ಮೂರಕ್ಕೂ ಉತ್ತರಿಸುತ್ತವೆ. ಡಿಜಿಟಲ್ ಆರೋಗ್ಯಕ್ಕೆ ನಿರ್ದಿಷ್ಟವಾಗಿ, "ಬಗೆಹರಿದ ಪ್ರಕರಣಕ್ಕೆ ವೆಚ್ಚ" ಒಂದು ಆರೋಗ್ಯ-ಸೇವಾ ಘಟಕ ವೆಚ್ಚವೇ — ಆಯೋಗದಾರ ಪ್ರತಿ ಇತರ ಸೇವೆಗೆ ಬಳಸುವ [ರಾಷ್ಟ್ರೀಯ ವೆಚ್ಚ ಸಂಗ್ರಹ](../ರಾಷ್ಟ್ರೀಯ-ಸುಂಕ-ಮತ್ತು-ಘಟಕ-ವೆಚ್ಚಗಳು/) ಅಂಕಿಗಳೊಂದಿಗೆ ನೇರವಾಗಿ ಹೋಲಿಸಬಹುದು, ಇದು ಡಿಜಿಟಲ್ ಮಾರ್ಗಗಳನ್ನು ಸಾಂಪ್ರದಾಯಿಕವಾದವುಗಳ ವಿರುದ್ಧ ಬೆಲೆ ನಿಗದಿಪಡಿಸಲು ಸಹಜ ಭಾಷೆ.

## ಗಣಿತ

```
Unit cost = total allocated cost (incl. shared/platform costs) / units delivered

Two families:
  resource-efficiency units: cost/GB stored, cost/vCPU-hour, cost/token,
                             cost/build-minute
  business units:            cost/customer, cost/transaction, cost/consultation,
                             cost/case-resolved

Marginal vs average discipline applies (marginal-vs-average-cost.md):
committed/reserved spend makes marginal unit cost ≈ 0 until the next
commitment step — price expansion decisions at marginal, efficiency
trends at average.
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಡಿಜಿಟಲ್ ಟ್ರಯಾಜ್ ಸೇವೆ: ಕ್ಲೌಡ್ ಖರ್ಚು ತಿಂಗಳಿಗೆ £62,000 (ಕಂಪ್ಯೂಟ್ £30k, ದತ್ತಾಂಶ £18k, ಹಂಚಿಕೆಯ ವೇದಿಕೆ ಹಂಚಿಕೆ £14k), ತಿಂಗಳಿಗೆ 380,000 ಟ್ರಯಾಜ್ ಪ್ರಕರಣಗಳನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ:

```
Average cost per episode = 62,000 / 380,000 ≈ £0.163

Commissioner comparison: telephone triage ≈ £8–12/call, GP consultation ≈ £42
→ digital episode runs at ~2% of the cheapest human alternative — the
channel-shift economics of gds-service-metrics.md, from the cost side.

Trend check: last year £0.21/episode at 240k episodes → improving scale
economics (fixed platform costs amortizing), worth a headline in the QBR.
```

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಘಟಕ ಅರ್ಥಶಾಸ್ತ್ರ ಎಂಜಿನಿಯರಿಂಗ್ ಆಯ್ಕೆಗಳು ಹಣಕಾಸಿಗೆ ಓದಬಲ್ಲದಾಗುವ ಸ್ಥಳ: ಪ್ರತಿ ಪ್ರಕರಣಕ್ಕೆ ವೆಚ್ಚವನ್ನು ಅರ್ಧಕ್ಕಿಳಿಸುವ ವಾಸ್ತುಶಿಲ್ಪ ಬೆಲೆ ಅನುಕೂಲ; ಅತಿ-ರೇಖೀಯವಾಗಿ ಬೆಳೆಯುವುದು ಈ ಮಾಪನದಲ್ಲಿ ಮಾತ್ರ ಕಾಣುವ ಟೈಮ್ ಬಾಂಬ್. ಆರೋಗ್ಯ ವೆಚ್ಚ ಲೆಕ್ಕದಿಂದ ವರ್ಗಾಯಿಸಬಹುದಾದ ಅಭ್ಯಾಸಗಳು: **ಹಂಚಿಕೆ ನಿಯಮಗಳನ್ನು ಪ್ರಕಟಿಸಿ** (PLICS ರೋಗಿ-ಮಟ್ಟದ ವೆಚ್ಚ ಲೆಕ್ಕವನ್ನು ಪ್ರಮಾಣೀಕರಿಸುವವರೆಗೆ ಹಂಚಿಕೆಯ ವೆಚ್ಚಗಳು ಪ್ರತಿ-ಘಟಕ ಅಂಕಿಗಳನ್ನು ವಿರೂಪಗೊಳಿಸುತ್ತಿದ್ದವು — ನಿಮ್ಮ ವೇದಿಕೆ-ವೆಚ್ಚ ಹಂಚಿಕೆಗೂ ಅದೇ ಕಟ್ಟುನಿಟ್ಟು ಬೇಕು); **ಖರೀದಿದಾರ ಯೋಚಿಸುವ ಘಟಕಗಳನ್ನು ಆರಿಸಿ** (ಆಯೋಗದಾರರು vCPU ಅಲ್ಲ, ಪ್ರಕರಣಗಳನ್ನು ಖರೀದಿಸುತ್ತಾರೆ); ಮತ್ತು ಘಟಕ ವೆಚ್ಚಗಳನ್ನು ಪ್ರತಿ [ICER](../ಹೆಚ್ಚುವರಿ-ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ-ಅನುಪಾತ/) ಮತ್ತು [ಬಜೆಟ್ ಪ್ರಭಾವ](../ಬಜೆಟ್-ಪರಿಣಾಮ-ವಿಶ್ಲೇಷಣೆ/) ಮಾದರಿಗೆ ಅಧಿಕೃತ ವೆಚ್ಚ ಛೇದವಾಗಿ ನೀಡಿ. AI ವೈಶಿಷ್ಟ್ಯಗಳಿಗೆ ಘಟಕ ಟೋಕನ್ — [ಅನುಮಾನ ಘಟಕ ಅರ್ಥಶಾಸ್ತ್ರ](../ಅನುಮಾನ-ಘಟಕ-ಅರ್ಥಶಾಸ್ತ್ರ/) ನೋಡಿ.

## ಎಡವಟ್ಟುಗಳು

- **ಹಂಚಿಕೆಯ ವೆಚ್ಚಗಳ ನಿರ್ಲಕ್ಷ್ಯ**: ವೇದಿಕೆ/ಭದ್ರತೆ/ಆನ್-ಕಾಲ್ ಹಂಚಿಕೆಗಳನ್ನು ಹೊರಗಿಡುವ ಘಟಕ ವೆಚ್ಚಗಳು 30–50% ಕಡಿಮೆ ಹೇಳುತ್ತವೆ ಮತ್ತು ಲೆಕ್ಕಪರಿಶೋಧನೆಯಲ್ಲಿ ಕುಸಿಯುತ್ತವೆ.
- **ವ್ಯರ್ಥ ಛೇದಗಳು**: "ಪ್ರತಿ API ಕರೆಗೆ ವೆಚ್ಚ" ಮುಖಸ್ತುತಿ ಮಾಡುತ್ತದೆ; "ಪೂರ್ಣಗೊಂಡ ಪ್ರತಿ ರೋಗಿ ಪ್ರಕರಣಕ್ಕೆ ವೆಚ್ಚ" ತಿಳಿಸುತ್ತದೆ.
- **ಸೀಮಾಂತ ನಿರ್ಧಾರಗಳಿಗೆ ಸರಾಸರಿ-ವೆಚ್ಚ ಬೆಲೆ**: ಸೀಮಾಂತವಾಗಿ ಉಚಿತವಾದ ಬಳಕೆಗೆ ತಂಡಗಳಿಂದ ಸರಾಸರಿ ಘಟಕ ವೆಚ್ಚ ವಿಧಿಸುವುದು ತ್ಯಾಜ್ಯ-ತಪ್ಪಿಸುವ ನಾಟಕಕ್ಕೆ ಕಾರಣವಾಗುತ್ತದೆ (ಈ ಪ್ರೋತ್ಸಾಹ ದೋಷದ NHS ಆವೃತ್ತಿಗೆ [ರಾಷ್ಟ್ರೀಯ ದರಪಟ್ಟಿ](../ರಾಷ್ಟ್ರೀಯ-ಸುಂಕ-ಮತ್ತು-ಘಟಕ-ವೆಚ್ಚಗಳು/) ನೋಡಿ).
