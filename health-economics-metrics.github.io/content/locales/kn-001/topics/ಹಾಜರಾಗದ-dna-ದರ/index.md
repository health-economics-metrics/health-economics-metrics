# ಹಾಜರಾಗದ (DNA) ದರ

DNA ದರ ಎಂದರೆ ರೋಗಿಯು ಹಾಜರಾಗದ ಮತ್ತು ರದ್ದುಪಡಿಸದ ಬುಕ್ ಮಾಡಿದ ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್‌ಗಳ ಶೇಕಡಾವಾರು. ವೈದ್ಯರು, ಕೋಣೆ ಮತ್ತು ಸ್ಲಾಟ್‌ಗೆ ಹಣ ಪಾವತಿಸಲಾಗಿದೆ; ಏನೂ ನಡೆಯುವುದಿಲ್ಲ. ಇದು ಆರೋಗ್ಯ ಸೇವೆಯ ಅತ್ಯಂತ ಶುದ್ಧ ವ್ಯರ್ಥ ಮೆಟ್ರಿಕ್ — ಮತ್ತು ಸಾಫ್ಟ್‌ವೇರ್‌ನಿಂದ ಸರಿಪಡಿಸಬಹುದಾದ ಅತ್ಯಂತ ಸುಲಭವಾದವುಗಳಲ್ಲಿ ಒಂದು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

NHS ಇಂಗ್ಲೆಂಡ್‌ನ ಅಂಕಿಅಂಶಗಳು (2019): ತಪ್ಪಿದ GP ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್‌ಗಳು ವರ್ಷಕ್ಕೆ 15 ಮಿಲಿಯನ್ ಮೀರುತ್ತವೆ, ತಲಾ ~£30 — ವರ್ಷಕ್ಕೆ **£216M**ಗಿಂತ ಹೆಚ್ಚು — ಮತ್ತು ಆಸ್ಪತ್ರೆ ಹೊರರೋಗಿ DNAಗಳು ವರ್ಷಕ್ಕೆ ~8M (ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್‌ಗಳ ~6.4%), ತಪ್ಪಿದ ಪ್ರತಿ ಸ್ಲಾಟ್‌ಗೆ ಸರಾಸರಿ ~**£160**. ಜ್ಞಾಪಕದ ಸೀಮಾಂತ ವೆಚ್ಚ ಕೆಲವೇ ಪೆನ್ನಿಗಳು ಮತ್ತು ಮರುಪಡೆದ ಮೌಲ್ಯ ಸಂಪೂರ್ಣ ಸಿಬ್ಬಂದಿ ಇರುವ ವೈದ್ಯಕೀಯ ಸ್ಲಾಟ್ ಆಗಿರುವುದರಿಂದ, DNA ಕಡಿತ ಡಿಜಿಟಲ್ ಆರೋಗ್ಯದ ಅತ್ಯುತ್ತಮ ROI ಅಂಕಗಣಿತಗಳಲ್ಲಿ ಕೆಲವನ್ನು ಹೊಂದಿದೆ — SMS ಜ್ಞಾಪಕಗಳು, ಸುಲಭ ಮರು-ಬುಕಿಂಗ್ ಮತ್ತು ಭವಿಷ್ಯಸೂಚಕ ಅತಿ-ಬುಕಿಂಗ್ ಮೊದಲ ಸಾಬೀತಾದ ಡಿಜಿಟಲ್ ಆರೋಗ್ಯ ಗೆಲುವುಗಳಲ್ಲಿ ಸೇರಿದ್ದದ್ದು ಇದೇ ಕಾರಣ.

## ಗಣಿತ

```
DNA rate = DNAs / booked appointments × 100

Value of reduction = appointments × ΔDNA rate × value per recovered slot

value per recovered slot: the slot is refilled (activity value / waiting-list
reduction) or it is not (staff time partially reusable) — mechanism matters,
as with bed-days-saved.md.
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಒಂದು ಹೊರರೋಗಿ ವಿಭಾಗ: ವರ್ಷಕ್ಕೆ 200,000 ಅಪಾಯಿಂಟ್‌ಮೆಂಟ್‌ಗಳು, DNA ದರ 8%. ಜ್ಞಾಪಕ-ಜೊತೆಗೆ-ಮರು-ಬುಕಿಂಗ್ ಸೇವೆ (ಒಂದು-ಟ್ಯಾಪ್ ಮರು-ಬುಕ್‌ನೊಂದಿಗೆ SMS, ಸಾರಿಗೆ ಮಾಹಿತಿ, ಪ್ರವೇಶಾರ್ಹ ಸ್ವರೂಪಗಳು) DNAಗಳನ್ನು 5.5%ಕ್ಕೆ ಇಳಿಸುತ್ತದೆ.

```
Recovered slots = 200,000 × 0.025 = 5,000/year
Refilled from the waiting list at ~£160 average outpatient value:
  5,000 × £160 = £800,000/year of recovered activity
Service cost: 200,000 × £0.40 = £80,000/year

Return ≈ 10:1, plus 5,000 waiting-list patients seen sooner
(see waiting-list-impact.md and referral-to-treatment.md).
```

ಪರಿಣಾಮದ ಗಾತ್ರ (2.5 ಅಂಕಗಳು) ವಾಸ್ತವಿಕ: ಜ್ಞಾಪಕ RCTಗಳು ಸ್ಥಿರವಾಗಿ 25–40% ಸಾಪೇಕ್ಷ DNA ಕಡಿತ ತೋರಿಸುತ್ತವೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

- **ಇದು ವೇಳಾಪಟ್ಟಿ-ವ್ಯವಸ್ಥೆಗಳ ಸಮಸ್ಯೆ**: ಜ್ಞಾಪಕಗಳು, ಸ್ವ-ಸೇವಾ ಮರು-ಬುಕಿಂಗ್, ರದ್ದತಿಗಳಿಂದ ಕಾಯುವ-ಪಟ್ಟಿ ಸ್ವಯಂ-ಬ್ಯಾಕ್‌ಫಿಲ್, ಮತ್ತು ಗುರಿಯಿಟ್ಟ ಡಬಲ್-ಬುಕಿಂಗ್ ಚಾಲನೆ ಮಾಡುವ ಗೈರುಹಾಜರಿ ಭವಿಷ್ಯ ಮಾದರಿಗಳು. ಪ್ರತಿಯೊಂದೂ ಅಸಾಧಾರಣವಾಗಿ ಸ್ಪಷ್ಟ ಆರ್ಥಿಕ ಪ್ರಕರಣವಿರುವ ಸಾಮಾನ್ಯ ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್.
- **ಎಂಜಿನಿಯರಿಂಗ್ ಸಮಾನ**: ಕಾದಿರಿಸಿದ ಸಾಮರ್ಥ್ಯಕ್ಕೆ ಗೈರುಹಾಜರಿಗಳು — ಬುಕ್ ಮಾಡಿದ ಆದರೆ ನಿಷ್ಕ್ರಿಯ CI ಸ್ಲಾಟ್‌ಗಳು, ಕಾದಿರಿಸಿದ ಕ್ಲೌಡ್ ಸಾಮರ್ಥ್ಯ, ಸಭೆ ಕೊಠಡಿಗಳು, ಸಂದರ್ಶನ ಪ್ಯಾನೆಲ್‌ಗಳು. ಅರ್ಥಶಾಸ್ತ್ರ ವರ್ಗಾವಣೆಯಾಗುತ್ತದೆ: ಅಗ್ಗದ ಸ್ವಯಂಚಾಲಿತ ಒತ್ತಾಸೆ (ಅಥವಾ ಬಳಸದ ಕಾದಿರಿಸುವಿಕೆಗಳ ಸ್ವಯಂ-ಬಿಡುಗಡೆ) ದುಬಾರಿ ಬದ್ಧ ಸಾಮರ್ಥ್ಯವನ್ನು ಮರುಪಡೆಯುತ್ತದೆ.
- **ಭವಿಷ್ಯ ನೈತಿಕತೆಯ ಮುನ್ನೋಟ**: ಹಾಜರಾತಿ ದತ್ತಾಂಶದ ಮೇಲೆ ತರಬೇತಿ ಪಡೆದ ಗೈರುಹಾಜರಿ ಮಾದರಿಗಳು ಬಡತನ ಮತ್ತು ಪ್ರವೇಶ ತಡೆಗಳನ್ನು ಸಂಕೇತಗೊಳಿಸುತ್ತವೆ; ಗೈರುಹಾಜರಾಗುವ ಸಾಧ್ಯತೆಯವರನ್ನು *ಆದ್ಯತೆ ಕಡಿಮೆ* ಮಾಡಲು ಬಳಸುವುದು ಅಸಮಾನತೆಯನ್ನು ವರ್ಧಿಸುತ್ತದೆ; ಹಾಜರಾತಿಯನ್ನು *ಬೆಂಬಲಿಸಲು* (ಸಾರಿಗೆ ಸಹಾಯ, ದೂರವಾಣಿ ಪರ್ಯಾಯಗಳು) ಬಳಸುವುದು ಅದನ್ನು ಕಡಿಮೆ ಮಾಡುತ್ತದೆ. [ತಲುಪುವಿಕೆ ಮತ್ತು ಸಮಾನತೆ](../ವ್ಯಾಪ್ತಿ-ಮತ್ತು-ಸಮಾನತೆ/) ನೋಡಿ.

## ಎಡವಟ್ಟುಗಳು

- **ರದ್ದು-ಮತ್ತು-ಮರು-ಬುಕ್ ಆದದ್ದನ್ನು ಮರುಪಡೆದ ಮೌಲ್ಯವಾಗಿ ಎರಡು ಬಾರಿ ಲೆಕ್ಕಿಸುವುದು.**
- **ಮರುತುಂಬದ ಮರುಪಡೆದ ಸ್ಲಾಟ್‌ಗಳಿಗೆ ಮೌಲ್ಯ ಕಟ್ಟುವುದು** — ಜ್ಞಾಪಕ ಕಳುಹಿಸಿದ ಖಾಲಿ ಸ್ಲಾಟ್ ಇನ್ನೂ ಖಾಲಿ.
- **DNAಯನ್ನು ಸೊನ್ನೆಗೆ ಬೆನ್ನಟ್ಟುವುದು**: DNAಯ ಕೊನೆಯ ಅಂಕಗಳು ನಿಜವಾದ ತಡೆಗಳನ್ನು ಎದುರಿಸುತ್ತಿರುವ ರೋಗಿಗಳು; ದಂಡನಾತ್ಮಕ ವಿಧಾನಗಳು (N DNAಗಳ ನಂತರ ಡಿಸ್ಚಾರ್ಜ್) ರೋಗಿಗಳನ್ನು ಕೈಬಿಡುವ ಮೂಲಕ ಮೆಟ್ರಿಕ್ ಅನ್ನು ಕಡಿತಗೊಳಿಸುತ್ತವೆ.
