# QALY ಕೊರತೆ ಮತ್ತು ತೀವ್ರತಾ ಮಾರ್ಪಾಡುಗಳು

QALY ಕೊರತೆಯು ಸಾಮಾನ್ಯ ಜನಸಂಖ್ಯೆಗೆ ಹೋಲಿಸಿದರೆ ರೋಗವು ರೋಗಿಗಳಿಂದ ಎಷ್ಟು ಭವಿಷ್ಯದ ಆರೋಗ್ಯವನ್ನು ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ ಎಂದು ಅಳೆಯುತ್ತದೆ. NICE ಇದನ್ನು **ತೀವ್ರತಾ ಮಾರ್ಪಾಡುಗಳನ್ನು** ಅನ್ವಯಿಸಲು ಬಳಸುತ್ತದೆ: ಜನಸಂಖ್ಯೆ ಹೆಚ್ಚು ಅಸ್ವಸ್ಥವಾದಷ್ಟೂ ಗಳಿಸಿದ ಪ್ರತಿ QALY ಹೆಚ್ಚು ಮೌಲ್ಯಯುತ — ಪ್ರಮಾಣಿತ ಮಿತಿಯ 1.7× ವರೆಗೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

NICEಯ 2022 ಕೈಪಿಡಿಯಿಂದ, ತೀವ್ರತೆ ಹಳೆಯ ಜೀವನಾಂತ್ಯ ಪ್ರೀಮಿಯಂ ಬದಲಿಗೆ ಆರೋಗ್ಯ ಲಾಭಗಳ ಮೌಲ್ಯದ ಮೇಲೆ ಸ್ಪಷ್ಟ ಗುಣಕ. ತೀವ್ರ ಸ್ಥಿತಿಯ ತಂತ್ರಜ್ಞಾನವನ್ನು £30,000ರ ಬದಲು ಪ್ರತಿ QALYಗೆ ~£51,000 ವರೆಗಿನ ಪರಿಣಾಮಕಾರಿ ಮಿತಿಯ ವಿರುದ್ಧ ನಿರ್ಣಯಿಸಲಾಗುತ್ತದೆ. ನಿಮ್ಮ ಸಾಫ್ಟ್‌ವೇರ್ ತೀವ್ರವಾಗಿ ಬಾಧಿತ ಜನಸಂಖ್ಯೆಗೆ (ಮುಂದುವರಿದ ಹೃದಯ ವೈಫಲ್ಯ, ತೀವ್ರ ಮಾನಸಿಕ ಅನಾರೋಗ್ಯ) ಸೇವೆ ನೀಡಿದರೆ, ತೀವ್ರತಾ ಮಾರ್ಪಾಡು ಹಣ ನೀಡಬಹುದಾದ ಮತ್ತು ಹಣ ನೀಡಲಾಗದ ಆರ್ಥಿಕ ಪ್ರಕರಣದ ನಡುವಿನ ವ್ಯತ್ಯಾಸವಾಗಬಹುದು — ಮತ್ತು ಅದನ್ನು ಹೇಳಿಕೊಳ್ಳಲು ನಿಮಗೆ ಕೊರತೆಯ ಗಣಿತ ಬೇಕು.

## ಗಣಿತ

ಪ್ರಸ್ತುತ ಪ್ರಮಾಣಿತ ಆರೈಕೆಯೊಂದಿಗೆ ಉಳಿದ ಜೀವಿತಾವಧಿಯ ಮೇಲೆ ಲೆಕ್ಕಿಸಿದ ಎರಡು ಮಾಪನಗಳು:

```
Absolute shortfall     = QALYs_general_population − QALYs_with_condition
Proportional shortfall = Absolute shortfall / QALYs_general_population
```

NICE 2022 ತೂಕಗಳು (ಹೆಚ್ಚಿನ ತೂಕ ನೀಡುವ ಮಾಪನ ಅನ್ವಯಿಸುತ್ತದೆ):

```
Weight ×1.0: absolute < 12 and proportional < 0.85
Weight ×1.2: absolute ≥ 12 or proportional ≥ 0.85
Weight ×1.7: absolute ≥ 18 or proportional ≥ 0.95
```

ತೂಕವು ΔE ಅನ್ನು (ಅಥವಾ ಸಮಾನವಾಗಿ ಮಿತಿಯನ್ನು) ಗುಣಿಸುತ್ತದೆ: ಪರಿಣಾಮಕಾರಿ λ ×1.2ರಲ್ಲಿ £24k–£36k ಮತ್ತು ×1.7ರಲ್ಲಿ £34k–£51k ಆಗುತ್ತದೆ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಸರಾಸರಿ ವಯಸ್ಸು 60 ಇರುವ ಆಕ್ರಮಣಕಾರಿ ಸ್ಥಿತಿಯ ರೋಗಿಗಳು. 60ರಲ್ಲಿ ಸಾಮಾನ್ಯ ಜನಸಂಖ್ಯೆ 14.2 ರಿಯಾಯಿತಿ QALY ನಿರೀಕ್ಷಿಸುತ್ತದೆ; ಪ್ರಸ್ತುತ ಆರೈಕೆಯಡಿ ಸ್ಥಿತಿಯೊಂದಿಗೆ, 2.1.

```
Absolute shortfall     = 14.2 − 2.1 = 12.1  (≥ 12 → qualifies for ×1.2)
Proportional shortfall = 12.1 / 14.2 = 0.852 (≥ 0.85 → also ×1.2)
```

ನಿಮ್ಮ ಮೇಲ್ವಿಚಾರಣಾ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ನ ICER ಪ್ರತಿ QALYಗೆ £26,000 — ಪ್ರಮಾಣಿತ £20k–£30k ಮಧ್ಯಬಿಂದು ನಿರ್ಣಯಕ್ಕಿಂತ ಮೇಲೆ, ಅಂಚಿನಲ್ಲಿ. ×1.2 ತೂಕದೊಂದಿಗೆ: ಪರಿಣಾಮಕಾರಿ ICER = 26,000 / 1.2 ≈ **ಪ್ರತಿ QALYಗೆ £21,700** — ಆರಾಮವಾಗಿ ಹಣ ನೀಡಬಹುದು. ಕೊರತೆ ಲೆಕ್ಕಾಚಾರವೇ ನಿರ್ಧಾರವನ್ನು ಚಲಿಸಿತು.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ತೀವ್ರತಾ ತೂಕೀಕರಣವು ಎಂಜಿನಿಯರಿಂಗ್ ಸಂಸ್ಥೆಗಳು ಸಹಜವಾಗಿ ಮಾಡುವ ಕೆಲಸದ ಔಪಚಾರಿಕ ರೂಪ: ಅತ್ಯಂತ ಹಿಂದುಳಿದ ವ್ಯವಸ್ಥೆಗಳ ಮೇಲೆ ಪ್ರತಿ ಘಟಕ ಸುಧಾರಣೆಗೆ ಹೆಚ್ಚು ಖರ್ಚು ಮಾಡುವುದು. ವರ್ಗಾವಣೆಯಾಗುವ ಮಾದರಿ — ಪ್ರತಿ ಸೇವೆಯ "SLO ಕೊರತೆ"ಯನ್ನು (ಅದು ತನ್ನ ನಿರೀಕ್ಷಿತ ಆರೋಗ್ಯಕರ ಮೂಲರೇಖೆಗಿಂತ ಎಷ್ಟು ಕೆಳಗೆ ಓಡುತ್ತದೆ, ಸಂಪೂರ್ಣವಾಗಿ ಮತ್ತು ಅನುಪಾತದಲ್ಲಿ) ಲೆಕ್ಕಿಸಿ, ಪರಿಹಾರ ಮೌಲ್ಯವನ್ನು ಅದಕ್ಕೆ ತಕ್ಕಂತೆ ತೂಗಿ. ಇದು ಉರಿಯುತ್ತಿರುವ ಹಳೆಯ ವ್ಯವಸ್ಥೆ ಆರೋಗ್ಯಕರವಾದದ್ದಕ್ಕಿಂತ ಉಳಿತಾಯವಾದ ಪ್ರತಿ ಗಂಟೆಗೆ ಹೆಚ್ಚು ಹೂಡಿಕೆ ಏಕೆ ಪಡೆಯುತ್ತದೆ ಎಂಬುದನ್ನು ವಾದಗಳ ಬದಲು ಅಂಕಗಣಿತದಿಂದ ಸಮರ್ಥಿಸುತ್ತದೆ. ಇದು ಅದೇ ಆಡಳಿತ ಪಾಠವನ್ನೂ ಹೊತ್ತಿದೆ: ಆದ್ಯತೀಕರಣ ಸಭೆಗೆ *ಮೊದಲು* ತೂಕಗಳನ್ನು ಪ್ರಕಟಿಸಿ, ಇಲ್ಲದಿದ್ದರೆ ಪ್ರತಿ ತಂಡವೂ ತೀವ್ರತೆಯನ್ನು ಹೇಳಿಕೊಳ್ಳುತ್ತದೆ.

## ಎಡವಟ್ಟುಗಳು

- **ತಪ್ಪು ಮೂಲರೇಖೆಯ ವಿರುದ್ಧ ಕೊರತೆ ಲೆಕ್ಕಿಸುವುದು**: ಅದನ್ನು *ಪ್ರಸ್ತುತ ಪ್ರಮಾಣಿತ ಆರೈಕೆ*ಯಡಿ ಅಳೆಯಲಾಗುತ್ತದೆ, ಚಿಕಿತ್ಸೆ ಇಲ್ಲದ ಸಹಜ ಇತಿಹಾಸದಲ್ಲಿ ಅಲ್ಲ.
- **ವಯಸ್ಸಿನ ಸಂವೇದನೆ**: ಕೊರತೆ ಜನಸಂಖ್ಯೆಯ ವಯಸ್ಸಿನ ಮೇಲೆ ಬಹಳ ಅವಲಂಬಿತ (ಕಿರಿಯ ರೋಗಿಗಳು ಕಳೆದುಕೊಳ್ಳಲು ಹೆಚ್ಚು QALY ಹೊಂದಿದ್ದಾರೆ → ಹೆಚ್ಚಿನ ಸಂಪೂರ್ಣ ಕೊರತೆ); ಚಿಕಿತ್ಸೆ ಪಡೆದ ನಿಜವಾದ ಜನಸಂಖ್ಯೆಯ ವಯಸ್ಸಿನ ವಿತರಣೆ ಬಳಸಿ.
- **ಮಾರ್ಪಾಡು ಬೇರೆಡೆಯೂ ಅನ್ವಯಿಸುತ್ತದೆ ಎಂದು ಭಾವಿಸುವುದು** — ಇದು NICE (ಇಂಗ್ಲೆಂಡ್) ಕಾರ್ಯವಿಧಾನ; ಇತರ HTA ಸಂಸ್ಥೆಗಳು ತೀವ್ರತೆಯನ್ನು ಬೇರೆ ರೀತಿ ನಿಭಾಯಿಸುತ್ತವೆ (ಅಥವಾ ಇಲ್ಲವೇ ಇಲ್ಲ).
