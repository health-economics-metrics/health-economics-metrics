# ಕ್ಲಿನಿಕಲ್ AI ಮೌಲ್ಯಮಾಪನ

ಕ್ಲಿನಿಕಲ್ AI ಅಥವಾ ರೋಗನಿರ್ಣಯ ಮಾದರಿಯನ್ನು ಮೌಲ್ಯಮಾಪನ ಮಾಡುವ ಮೂಲ ಅಂಕಿಅಂಶಗಳು: ಸೂಕ್ಷ್ಮತೆ, ವಿಶಿಷ್ಟತೆ, AUROC, ಭವಿಷ್ಯಸೂಚಕ ಮೌಲ್ಯಗಳು ಮತ್ತು ಸ್ಕ್ರೀನ್ ಮಾಡಬೇಕಾದ ಸಂಖ್ಯೆ. ಕೇಂದ್ರ ಆರ್ಥಿಕ ಪಾಠ: **ಉತ್ತಮ AUROC ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿ ನಿಯೋಜನೆಯನ್ನು ಮಾಡುವುದಿಲ್ಲ** — ಮೌಲ್ಯ ಕಾರ್ಯ ಬಿಂದು, ಹರಡುವಿಕೆ ಮತ್ತು ಪ್ರತಿ ಧನಾತ್ಮಕದ ಕೆಳಹಂತದಲ್ಲಿ ಏನಾಗುತ್ತದೆ ಎಂಬುದರ ಮೇಲೆ ಅವಲಂಬಿತ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ನಿಯಂತ್ರಕರು (FDA, MHRA) ಕ್ಲಿನಿಕಲ್ AIಗೆ **ಲಾಕ್ ಮಾಡಿದ ಕಾರ್ಯ ಬಿಂದು**ವಿನಲ್ಲಿ ಅನುಮತಿ ನೀಡುತ್ತಾರೆ — ನಿರ್ದಿಷ್ಟ ಸೂಕ್ಷ್ಮತೆ/ವಿಶಿಷ್ಟತೆ ಜೋಡಿ (ಉದಾ. FDA ಅನುಮೋದಿಸಿದ ಮೊದಲ ಸ್ವಾಯತ್ತ ಮಧುಮೇಹ-ರೆಟಿನೋಪತಿ ವ್ಯವಸ್ಥೆ: ಅದರ ನಿರ್ಣಾಯಕ ಪ್ರಯೋಗದಲ್ಲಿ ಸೂಕ್ಷ್ಮತೆ 87.2%, ವಿಶಿಷ್ಟತೆ 90.7%). ಆಗ ಆರೋಗ್ಯ ಅರ್ಥಶಾಸ್ತ್ರಜ್ಞರು ನಿಖರತೆ ಮಾಪನಗಳು ಉತ್ತರಿಸಲಾಗದ ಪ್ರಶ್ನೆ ಕೇಳುತ್ತಾರೆ: ನಿಮ್ಮ ನಿಯೋಜನೆ ಜನಸಂಖ್ಯೆಯ ಹರಡುವಿಕೆಯಲ್ಲಿ, ಪ್ರತಿ ಪತ್ತೆಗೆ ಎಷ್ಟು *ವೆಚ್ಚ*, ಮತ್ತು ಅದರ ಮೇಲೆ ಕ್ರಿಯೆ ಮಾಡುವುದು ಯೋಗ್ಯವೇ? ರೆಟಿನೋಪತಿ-ಸ್ಕ್ರೀನಿಂಗ್ AIಯ ಆರ್ಥಿಕ ಮೌಲ್ಯಮಾಪನ (npj Digital Medicine 2024) ರೆಫರಲ್ ವೆಚ್ಚಗಳನ್ನು ಲೆಕ್ಕಿಸಿದ ನಂತರ ಹೆಚ್ಚಿನ ನಿಖರತೆ ಮಾತ್ರ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವಕ್ಕೆ ಖಾತರಿ ನೀಡಲಿಲ್ಲ ಎಂದು ತೋರಿಸಿತು.

## ಗಣಿತ

```
Sensitivity = TP / (TP + FN)        — of the truly positive, share caught
Specificity = TN / (TN + FP)        — of the truly negative, share cleared
AUROC       = P(model ranks a random positive above a random negative)
              0.5 chance … 1.0 perfect; threshold-independent — and therefore
              deployment-decision-insufficient

PPV = TP / (TP + FP)   ← prevalence-dependent (Bayes); collapses when rare
NPV = TN / (TN + FN)

NNS  ≈ 1 / (prevalence × sensitivity)       — screened per true case found
Cost per true case = programme cost / TP      — the economic bottom line
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಅದೇ ಮಾದರಿ, ಎರಡು ಸನ್ನಿವೇಶಗಳು — ಸೂಕ್ಷ್ಮತೆ 90%, ವಿಶಿಷ್ಟತೆ 93%:

```
Specialist clinic (prevalence 20%):
  PPV = (0.9×0.2)/(0.9×0.2 + 0.07×0.8) = 0.18/0.236 ≈ 76%  → 3 in 4 alerts real

Primary care (prevalence 1%):
  PPV = (0.9×0.01)/(0.9×0.01 + 0.07×0.99) = 0.009/0.0783 ≈ 11.5%
  → 8 in 9 alerts false; workup at £350 each:
  cost per true case = (0.009 + 0.0693) × 350 / 0.009 ≈ £3,045 per case found
```

ಒಂದೇ ಮಾದರಿ, ಸಂಪೂರ್ಣ ಭಿನ್ನ ಅರ್ಥಶಾಸ್ತ್ರ — ಆದ್ದರಿಂದಲೇ ಸ್ಥಳ-ನಿರ್ದಿಷ್ಟ ಮೌಲ್ಯಮಾಪನ ನಿಯಂತ್ರಕ ವಿಷಯ, ಮತ್ತು "ನಮ್ಮ ಮಾದರಿಗೆ 0.95 AUROC ಇದೆ" ಆರ್ಥಿಕ ಪ್ರಕರಣದ ಆರಂಭ, ಅಂತ್ಯವಲ್ಲ. ಪೂರ್ಣ ಕಾರ್ಯಕ್ರಮ ಗಣಿತಕ್ಕೆ [ಸ್ಕ್ರೀನಿಂಗ್ ಅರ್ಥಶಾಸ್ತ್ರ](../ಸ್ಕ್ರೀನಿಂಗ್-ಅರ್ಥಶಾಸ್ತ್ರ/) ನೋಡಿ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಕ್ಲಿನಿಕಲ್ AI ನಿರ್ಮಿಸುವ ಅಥವಾ ಖರೀದಿಸುವ ಎಂಜಿನಿಯರ್‌ಗಳಿಗೆ: ROC ವಕ್ರರೇಖೆ ಮಾತ್ರವಲ್ಲ, **ನಿಯೋಜನೆ ಹರಡುವಿಕೆಯಲ್ಲಿ ಗೊಂದಲ ಮ್ಯಾಟ್ರಿಕ್ಸ್ ಅನ್ನು ಒದಗಿಸಿ**; **ಮಿತಿಯನ್ನು ಆರ್ಥಿಕ ನಿರ್ಧಾರವಾಗಲು ಬಿಡಿ** — ಸೂಕ್ಷ್ಮತೆ/ವಿಶಿಷ್ಟತೆ ವಿನಿಮಯ ನಿರೀಕ್ಷಿತ ವೆಚ್ಚವನ್ನು (ತಪ್ಪಿಹೋದ ಪ್ರಕರಣಗಳು × ತಪ್ಪಿಹೋಗುವ ವೆಚ್ಚ vs ಸುಳ್ಳು ಎಚ್ಚರಿಕೆಗಳು × ಅನುಸರಣಾ ವೆಚ್ಚ) ಕನಿಷ್ಠಗೊಳಿಸಬೇಕು, ಮಾನದಂಡ ಅಂಕಿಯನ್ನು ಗರಿಷ್ಠಗೊಳಿಸಬಾರದು; ಮತ್ತು ನಿಮ್ಮ ಸ್ವಂತ ಸಾಧನಗಳಲ್ಲೂ ಅದೇ ಗಣಿತವನ್ನು ಗುರುತಿಸಿ — ಎಚ್ಚರಿಕೆ ವ್ಯವಸ್ಥೆಗಳು, ಅಸಂಗತಿ ಪತ್ತೆಕಾರರು ಮತ್ತು ಭದ್ರತಾ ಸ್ಕ್ಯಾನರ್‌ಗಳು ಕಡಿಮೆ-ಹರಡುವಿಕೆಯ ಘಟನೆ ಪ್ರವಾಹಗಳ ಮೇಲಿನ ರೋಗನಿರ್ಣಯ ಪರೀಕ್ಷೆಗಳು, ಎಚ್ಚರಿಕೆ ಆಯಾಸ [NNH](../ಚಿಕಿತ್ಸೆ-ನೀಡಬೇಕಾದ-ಸಂಖ್ಯೆ/) ಆಗಿ. ಕಾರ್ಯ ಬಿಂದುವನ್ನು ಬದಲಿಸುವ ಮಾದರಿ ನವೀಕರಣಗಳು ಅರ್ಥಶಾಸ್ತ್ರವನ್ನು (ಮತ್ತು ನಿಯಂತ್ರಕ ಅನುಮತಿಯನ್ನು — [AI ನಿಯಂತ್ರಕ ಮೌಲ್ಯಮಾಪನ](../ai-ನಿಯಂತ್ರಕ-ಮೌಲ್ಯಮಾಪನ/) ನೋಡಿ) ಮತ್ತೆ ತೆರೆಯುತ್ತವೆ.

## ಎಡವಟ್ಟುಗಳು

- **AUROC ಶಾಪಿಂಗ್**: ಮಾದರಿಗಳು ಒಂದೇ ಮಿತಿಯಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುವಾಗ AUROCನಲ್ಲಿ ಹೋಲಿಸುವುದು — ಕಾರ್ಯ ಬಿಂದುವಿನಲ್ಲಿ ಹೋಲಿಸಿ.
- **ಪ್ರಯೋಗ-ಹರಡುವಿಕೆಯ PPVಯನ್ನು ನೈಜ-ಜಗತ್ತಿನ ನಿಯೋಜನೆಗೆ ಉಲ್ಲೇಖಿಸುವುದು** — ಶ್ರೇಷ್ಠ ತಪ್ಪು; ಯಾವಾಗಲೂ ಸ್ಥಳೀಯ ಹರಡುವಿಕೆಯಲ್ಲಿ ಮರು-ಲೆಕ್ಕ ಹಾಕಿ.
- **ವರ್ಣಪಟಲ ಪಕ್ಷಪಾತ**: ಸ್ಪಷ್ಟ ಪ್ರಕರಣಗಳು vs ಆರೋಗ್ಯವಂತ ನಿಯಂತ್ರಣಗಳ ಮೇಲೆ ಮೌಲ್ಯೀಕರಿಸಿದ ಮಾದರಿಗಳು ಅಭ್ಯಾಸದಲ್ಲಿ ಪ್ರಾಬಲ್ಯ ಹೊಂದಿರುವ ಅಸ್ಪಷ್ಟ ಮಧ್ಯಭಾಗದಲ್ಲಿ ಉತ್ತಮ ಪ್ರದರ್ಶನ ತೋರುತ್ತವೆ.
- **ಕೆಳಹಂತದ ಮಾರ್ಗದ ವೆಚ್ಚ ಲೆಕ್ಕವಿಲ್ಲದಿರುವುದು**: ಪ್ರತಿ ಧನಾತ್ಮಕ ಅನುಸರಣಾ ಪರೀಕ್ಷೆಯನ್ನು ಪ್ರಚೋದಿಸುತ್ತದೆ; ಮಾದರಿ ಎಂದರೆ *ಇಡೀ ಮಾರ್ಗದ* ಅರ್ಥಶಾಸ್ತ್ರದ ಮೇಲಿನ ಮಧ್ಯಸ್ಥಿಕೆ.
