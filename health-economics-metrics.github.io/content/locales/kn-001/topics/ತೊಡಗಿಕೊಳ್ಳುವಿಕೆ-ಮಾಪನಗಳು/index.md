# ತೊಡಗಿಕೊಳ್ಳುವಿಕೆ ಮಾಪನಗಳು

ತೊಡಗಿಕೊಳ್ಳುವಿಕೆ ಮಾಪನಗಳು ಬಳಕೆದಾರರು ಆರೋಗ್ಯ ಆ್ಯಪ್ ಅನ್ನು ನಿಜವಾಗಿ ಎಷ್ಟು ಬಳಸುತ್ತಾರೆ ಎಂದು ಅಳೆಯುತ್ತವೆ: DAU/MAU ಅಂಟಿಕೊಳ್ಳುವಿಕೆ, ಅಧಿವೇಶನ ಆವರ್ತನ ಮತ್ತು ಅವಧಿ, ವೈಶಿಷ್ಟ್ಯ ಬಳಕೆ. ಡಿಜಿಟಲ್ ಆರೋಗ್ಯದಲ್ಲಿ ತೊಡಗಿಕೊಳ್ಳುವಿಕೆ ವ್ಯರ್ಥ ಅಂಕಿಯಲ್ಲ — ಅದು **ಮಾತ್ರೆ (dose)**: ಯಾವುದೇ ಕ್ಲಿನಿಕಲ್ ಪರಿಣಾಮ ಹರಿಯಬೇಕಾದ ಒಡ್ಡಿಕೊಳ್ಳುವಿಕೆ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಬಾಟಲಿಯಲ್ಲೇ ಉಳಿದ ಔಷಧ ಯಾರನ್ನೂ ಗುಣಪಡಿಸುವುದಿಲ್ಲ; ಸ್ಥಾಪನೆಯಾಗದ ಅಥವಾ ತೆರೆಯದ ಆ್ಯಪ್ ಅದೇ ವೈಫಲ್ಯ ವಿಧಾನ. ಗ್ರಾಹಕ ಆರೋಗ್ಯ ಉತ್ಪನ್ನದ ಪ್ರತಿ ಆರೋಗ್ಯ-ಆರ್ಥಿಕ ಹಕ್ಕು ತೊಡಗಿಕೊಳ್ಳುವಿಕೆಯ ಮೂಲಕ ಗುಣಿಸಲ್ಪಡುತ್ತದೆ — ಪ್ರಯೋಗಗಳಲ್ಲಿ ತೋರಿಸಿದ ಪರಿಣಾಮಕಾರಿತ್ವವನ್ನು ಕೆಲವು ಬಳಕೆ ಮಟ್ಟದಲ್ಲಿ ಅಳೆಯಲಾಗಿತ್ತು, ಮತ್ತು ನೈಜ-ಜಗತ್ತಿನ ಮೌಲ್ಯ ನಿಯೋಜನೆ ಬಳಕೆ ಆ ಮಟ್ಟಕ್ಕೆ ಎಷ್ಟು ಹತ್ತಿರ ಬರುತ್ತದೆ ಎಂಬುದರೊಂದಿಗೆ ಮಾಪನಗೊಳ್ಳುತ್ತದೆ. ಪ್ರಮಾಣಿತ ಉತ್ಪನ್ನ ಮಾನದಂಡಗಳು: ಮೊಬೈಲ್ ಆ್ಯಪ್‌ಗಳಿಗೆ ಸಾಮಾನ್ಯವಾಗಿ DAU/MAU ಸುಮಾರು **20% ಆರೋಗ್ಯಕರ** ಎಂದು ಪರಿಗಣಿಸಲಾಗುತ್ತದೆ, >25% ಅಸಾಧಾರಣ; ಆರೋಗ್ಯ ಆ್ಯಪ್‌ಗಳು ಹೆಚ್ಚಾಗಿ ಕಡಿಮೆ ಇರುತ್ತವೆ.

## ಗಣಿತ

```
Stickiness (DAU/MAU) = daily active users / monthly active users × 100
Session metrics      = sessions/user/period; avg duration = total time / sessions
Feature engagement   = users performing key action / active users

Dose-response framing (the health-economics upgrade):
  realized effect ≈ trial effect × f(actual usage / trial usage)
  where f comes from dose-response analysis — see the "effective
  engagement" concept in adherence-and-persistence.md: enough usage
  to achieve the intended outcome, which may be modest and finite
```

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ರಕ್ತದೊತ್ತಡ ಆ್ಯಪ್‌ನ ನಿರ್ಣಾಯಕ ಅಧ್ಯಯನ ವಾರಕ್ಕೆ ≥4 ಓದುಗಳನ್ನು ದಾಖಲಿಸುವ ಬಳಕೆದಾರರಲ್ಲಿ 6 mmHg ಸಿಸ್ಟೋಲಿಕ್ ಇಳಿಕೆ ತೋರಿಸಿತು. 50,000 ನೋಂದಾಯಿತ ಬಳಕೆದಾರರಾದ್ಯಂತ ನಿಯೋಜನೆಯಲ್ಲಿ:

```
MAU 20,000 (40%); of those, logging ≥4×/week: 7,000
Effective-dose users = 7,000 / 50,000 = 14% of the registered base

Population-level effect ≈ trial effect delivered to 14%, not 100%:
any economic model quoting "50,000 users × 6 mmHg" overstates ~7×.
Honest model: 7,000 × full effect + partial credit (from dose-response
data, if any) for the 13,000 sub-threshold users.
```

ತೊಡಗಿಕೊಳ್ಳುವಿಕೆ ಕೊಳವೆಯ ಮೂಲಕ ಪರಿಣಾಮಕಾರಿ ಮಾತ್ರೆಗೆ ಈ ಗುಣಾಕಾರ — ಡಿಜಿಟಲ್-ಆರೋಗ್ಯ ಅರ್ಥಶಾಸ್ತ್ರ ಉಬ್ಬುವ ಅತಿ ಸಾಮಾನ್ಯ ಸ್ಥಳ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಎಂಜಿನಿಯರ್‌ಗಳು ತೊಡಗಿಕೊಳ್ಳುವಿಕೆ ಕೊಳವೆಯ ಮಾಲೀಕರು, ಇದು ಅವರನ್ನು *ಕ್ಲಿನಿಕಲ್* ಚರಾಂಶದ ಮಾಲೀಕರನ್ನಾಗಿಸುತ್ತದೆ: ಆನ್‌ಬೋರ್ಡಿಂಗ್ ಘರ್ಷಣೆ, ಅಧಿಸೂಚನೆ ತಂತ್ರ, ಲೋಡ್ ಸಮಯ ಮತ್ತು ಆಫ್‌ಲೈನ್ ಸ್ಥಿತಿಸ್ಥಾಪಕತ್ವ ಎಲ್ಲವೂ ನೀಡಿದ ಮಾತ್ರೆಯನ್ನು ಚಲಿಸುತ್ತವೆ. ಎರಡು ವಿನ್ಯಾಸ ಪರಿಣಾಮಗಳು: ತೆರೆಯುವಿಕೆಗಳನ್ನಲ್ಲ, **ಕ್ಲಿನಿಕಲ್ ಅರ್ಥಪೂರ್ಣ ಕ್ರಿಯೆಯನ್ನು** (ದಾಖಲಿಸಿದ ಓದುಗಳು, ಪೂರ್ಣಗೊಂಡ ಪಾಠಗಳು) ಉಪಕರಣಗೊಳಿಸಿ — ಅಧಿಸೂಚನೆ-ಪುಟಿತ ಅಧಿವೇಶನಗಳ ಮೇಲೆ ನಿರ್ಮಿಸಿದ DAU ಮಾತ್ರೆ-ವಂಚನೆ; ಮತ್ತು ತೊಡಗಿಕೊಳ್ಳುವಿಕೆ ಗುರಿಗಳನ್ನು ಗರಿಷ್ಠೀಕರಣವಲ್ಲ, *ಸಾಕಷ್ಟು* ಗುರಿಗಳಾಗಿ ಪರಿಗಣಿಸಿ — ವಾರಕ್ಕೆ 5 ನಿಮಿಷಗಳಲ್ಲಿ ತನ್ನ ಫಲಿತಾಂಶ ಸಾಧಿಸಿ ದಾರಿ ಬಿಡುವ ಆ್ಯಪ್ ಕ್ಲಿನಿಕಲ್ ಆಗಿ ಆದರ್ಶ ಮತ್ತು ಮಾಪನಾತ್ಮಕವಾಗಿ "ಕಳಪೆ" ([ಅನುಸರಣೆ ಮತ್ತು ಮುಂದುವರಿಕೆ](../ಅನುಸರಣೆ-ಮತ್ತು-ಮುಂದುವರಿಕೆ/)ಯಲ್ಲಿ ಪರಿಣಾಮಕಾರಿ ತೊಡಗಿಕೊಳ್ಳುವಿಕೆ ನೋಡಿ). ತೊಡಗಿಕೊಳ್ಳುವಿಕೆ ಕೆಲಸಕ್ಕೇ ಮೇಲಿನ ಜನಸಂಖ್ಯೆ-ಪರಿಣಾಮ ಮಾದರಿಯ ಮೂಲಕ ಮೌಲ್ಯ ಕಟ್ಟಿ: ಪರಿಣಾಮಕಾರಿ-ಮಾತ್ರೆ ಪಾಲಿನಲ್ಲಿ 2-ಅಂಕದ ಏರಿಕೆ ಪರಿಮಾಣೀಕರಿಸಬಹುದಾದ QALY ಸಾಲು.

## ಎಡವಟ್ಟುಗಳು

- **ತೊಡಗಿಕೊಳ್ಳುವಿಕೆಯೇ ಫಲಿತಾಂಶ**: ಬಳಕೆ ಸಾಧನ; ಫಲಿತಾಂಶ [PROM](../ರೋಗಿ-ವರದಿ-ಫಲಿತಾಂಶಗಳು/) ಅಥವಾ ಕ್ಲಿನಿಕಲ್ ಅಂತಿಮ ಬಿಂದು.
- **ದ್ವಿಮೋಡಲ್ ಬಳಕೆಯ ಮೇಲೆ ಸರಾಸರಿಗಳು**: ಆರೋಗ್ಯ-ಆ್ಯಪ್ ಜನಸಂಖ್ಯೆಗಳು ನಿಷ್ಠ ಬಳಕೆದಾರರು ಮತ್ತು ಭೂತಗಳಾಗಿ ವಿಭಜನೆಗೊಳ್ಳುತ್ತವೆ; ಸರಾಸರಿಗಳು ಯಾರನ್ನೂ ವಿವರಿಸುವುದಿಲ್ಲ — ಸಮೂಹ ಮಾಡಿ.
- **ಡಾರ್ಕ್-ಪ್ಯಾಟರ್ನ್ ಮಾತ್ರೆ ಉಬ್ಬರ**: ಸ್ಟ್ರೀಕ್‌ಗಳು ಮತ್ತು ಅಪರಾಧ-ಭಾವ ಅಧಿಸೂಚನೆಗಳು ಮಾಪನಗಳನ್ನು ಎತ್ತರಿಸುತ್ತವೆ ಮತ್ತು ಆರೋಗ್ಯ ಆ್ಯಪ್‌ಗಳು ಸೇವೆ ನೀಡುವ ಆತಂಕಿತ ಜನಸಂಖ್ಯೆಗಳಿಗೆ ಹಾನಿ ಮಾಡಬಹುದು; ಕ್ಲಿನಿಕಲ್ ಉತ್ಪನ್ನಗಳು ಕ್ಲಿನಿಕಲ್ ನೀತಿಶಾಸ್ತ್ರ ಹೊತ್ತಿರುತ್ತವೆ.
- **ಮಾರಾಟಗಾರ-ಮಾನದಂಡ ಮೂಲ**: ಪ್ರಕಟಿತ ತೊಡಗಿಕೊಳ್ಳುವಿಕೆ ಮಾನದಂಡಗಳಲ್ಲಿ ಹೆಚ್ಚಿನವು ವಿಶ್ಲೇಷಣಾ ಮಾರಾಟಗಾರರಿಂದ ಬರುತ್ತವೆ, ಪೀರ್ ವಿಮರ್ಶೆಯಿಂದಲ್ಲ; ನಿಮ್ಮ ಸ್ವಂತ ಪ್ರಯೋಗಗಳ ವಿರುದ್ಧ ಮಾಪನಾಂಕ ಮಾಡಿ.
