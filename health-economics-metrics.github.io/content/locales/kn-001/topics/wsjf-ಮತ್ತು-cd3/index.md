# WSJF ಮತ್ತು CD3

CD3 (ಅವಧಿಯಿಂದ ಭಾಗಿಸಿದ ವಿಳಂಬದ ವೆಚ್ಚ) ಮತ್ತು WSJF (ತೂಕದ ಅತಿ ಚಿಕ್ಕ ಕೆಲಸ ಮೊದಲು) ಕೆಲಸವನ್ನು **ಮೌಲ್ಯ ಸಾಂದ್ರತೆ**ಯ ಪ್ರಕಾರ ನಿಗದಿಪಡಿಸುವ ಆದ್ಯತೆ ನಿಯಮಗಳು: ಬಳಸಿದ ವಿರಳ ಸಾಮರ್ಥ್ಯದ ಪ್ರತಿ ಘಟಕಕ್ಕೆ ಎಷ್ಟು ವಿಳಂಬ ವೆಚ್ಚ ತೆಗೆದುಹಾಕಲ್ಪಡುತ್ತದೆ. ಹಂಚಿಕೆಯ, ನಿಗದಿತ ಸಾಮರ್ಥ್ಯದ ಅಡಿಯಲ್ಲಿ, ಅತಿ-ಹೆಚ್ಚು-CD3-ಮೊದಲು ಒಟ್ಟು ವಿಳಂಬ ವೆಚ್ಚವನ್ನು ಕನಿಷ್ಠಗೊಳಿಸುವ ಗಣಿತೀಯವಾಗಿ ಅತ್ಯುತ್ತಮ ಅನುಕ್ರಮ.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ಪ್ರತಿ ಬಾಕಿ ಪಟ್ಟಿ ಹಂಚಿಕೆ ಸಮಸ್ಯೆ: ಅನೇಕ ಯೋಗ್ಯ ವಸ್ತುಗಳು, ಒಂದು ಕೊಳವೆ. ಆರೋಗ್ಯ ಅರ್ಥಶಾಸ್ತ್ರ ಅದೇ ಸಮಸ್ಯೆಯನ್ನು ಆರೋಗ್ಯ ಬಜೆಟ್‌ಗಳಿಗೆ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ಲೀಗ್ ಕೋಷ್ಟಕಗಳಿಂದ ಪರಿಹರಿಸಿತು — ಪ್ರತಿ ಪೌಂಡ್‌ಗೆ ಗಳಿಸಿದ ಆರೋಗ್ಯದ ಪ್ರಕಾರ ಮಧ್ಯಸ್ಥಿಕೆಗಳನ್ನು ಶ್ರೇಣೀಕರಿಸಿ, ಬಜೆಟ್ ಮುಗಿಯುವವರೆಗೆ ಪಟ್ಟಿಯ ಕೆಳಗೆ ಹಣ ನೀಡಿ. CD3 ವಿತರಣಾ ಸಾಮರ್ಥ್ಯಕ್ಕೆ ಅದೇ ತರ್ಕ: *ನಿರ್ಬಂಧಿತ ಸಂಪನ್ಮೂಲದ* ಪ್ರತಿ ಘಟಕಕ್ಕೆ ಲಾಭ, ಶ್ರೇಣಿ ಕ್ರಮದಲ್ಲಿ ಹಣ ನೀಡಲಾಗುತ್ತದೆ. ಅನುಕ್ರಮವನ್ನು ಸರಿಯಾಗಿ ಮಾಡುವುದು ಉಚಿತ ಹಣ — ಅದೇ ಕೆಲಸ, ಅದೇ ಸಾಮರ್ಥ್ಯ, ಕಡಿಮೆ ಒಟ್ಟು ವಿಳಂಬ ವೆಚ್ಚ.

## ಗಣಿತ

```
CD3  = Cost of Delay (£/week) / Duration (weeks)      — real units (Black Swan Farming)

WSJF = (user-business value + time criticality + risk reduction/opportunity
        enablement) / job size                         — SAFe's relative-scale proxy,
                                                        modified-Fibonacci scores
```

ನಿಜ ಕರೆನ್ಸಿಯೊಂದಿಗೆ CD3 ([ವಿಳಂಬದ ವೆಚ್ಚ](../ವಿಳಂಬದ-ವೆಚ್ಚ/)) WSJFನ ಘಟಕರಹಿತ ಅಂಕಗಳಿಗಿಂತ ಕಟ್ಟುನಿಟ್ಟಾಗಿ ಬಲಿಷ್ಠ — WSJF CD3ಗೆ ಬಹು-ಮಾನದಂಡ ಅಂಕ ನಿಗದಿ ಪೂರ್ಣ [ವೆಚ್ಚ-ಉಪಯುಕ್ತತಾ ವಿಶ್ಲೇಷಣೆ](../ವೆಚ್ಚ-ಉಪಯುಕ್ತತಾ-ವಿಶ್ಲೇಷಣೆ/)ಗೆ ಇದ್ದಂತೆ: ಹಣಗಳಿಕೆ ಅಪ್ರಾಯೋಗಿಕವಾದಾಗ ಬಳಸಬಹುದಾದ, ಅಂಕಗಳಿಗೆ ಆಧಾರವಿಲ್ಲದಾಗ ತಿರುಚಬಹುದಾದ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಮೂರು ವೈಶಿಷ್ಟ್ಯಗಳು, ಒಂದು ತಂಡ:

```
Feature   CoD (£/wk)   Duration   CD3
A         30,000       10 wks     3,000
B         12,000       2 wks      6,000
C         5,000        1 wk       5,000
```

CD3 ಕ್ರಮ: B, C, A. ಒಟ್ಟು ವಿಳಂಬ ವೆಚ್ಚವನ್ನು "ದೊಡ್ಡ CoD ಮೊದಲು" (A, B, C) ಜೊತೆ ಹೋಲಿಸಿ:

```
CD3 order  (B,C,A): A waits 3 wks, C waits 2 → 30k×3 + 5k×2  = £100k delay cost
CoD order  (A,B,C): B waits 10, C waits 12   → 12k×10 + 5k×12 = £180k
```

ಅದೇ ವೈಶಿಷ್ಟ್ಯಗಳು, ಅದೇ ತಂಡ — ಅನುಕ್ರಮ ಮಾತ್ರ £80,000 ಉಳಿಸುತ್ತದೆ. ಸಹಜ ಜ್ಞಾನ: ಸಣ್ಣ, ತುರ್ತು ವಸ್ತುಗಳು ಮೊದಲು ಹೋಗುತ್ತವೆ ಏಕೆಂದರೆ ಅವು ತಮ್ಮ ವಿಳಂಬ ವೆಚ್ಚವನ್ನು ಅಗ್ಗವಾಗಿ ಬಿಡುಗಡೆ ಮಾಡುತ್ತವೆ; ದೊಡ್ಡ ವಸ್ತು ಸ್ವಲ್ಪ ಕಾಲ ಕಾಯುವುದರಿಂದ ಅಲ್ಪ ಕಳೆದುಕೊಳ್ಳುತ್ತದೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಆರೋಗ್ಯ ಸಾಫ್ಟ್‌ವೇರ್ ಪೋರ್ಟ್‌ಫೋಲಿಯೊಗಳಿಗೆ, CoDಯನ್ನು ಈ ರೆಪೊಸಿಟರಿ ಕಲಿಸುವ ಘಟಕಗಳಲ್ಲಿ ವ್ಯಕ್ತಪಡಿಸಿ: QALY/ವಾರ × ಮಿತಿ + ಕಾರ್ಯಾಚರಣೆ £/ವಾರ, ಮತ್ತು ಬಾಕಿ ಪಟ್ಟಿ ಆರೋಗ್ಯ ವ್ಯವಸ್ಥೆ ತಾನು ಖರೀದಿಸುವ ಇತರ ಎಲ್ಲವನ್ನೂ ಶ್ರೇಣೀಕರಿಸುವ ರೀತಿಗೆ ನೇರವಾಗಿ ಹೋಲಿಸಬಹುದಾಗುತ್ತದೆ. ಎರಡು ಅಭ್ಯಾಸ ಟಿಪ್ಪಣಿಗಳು: (1) ಅವಧಿ ಎಂದರೆ *ನಿರ್ಬಂಧವನ್ನು ಆಕ್ರಮಿಸುವ ಕ್ಯಾಲೆಂಡರ್ ಸಮಯ*, ಪ್ರಯತ್ನವಲ್ಲ — ಅಡಚಣೆ ತಂಡದ 2 ದಿನ ಬೇಕಾದ 2-ವಾರದ ಕಳೆದ-ಸಮಯದ ವಸ್ತು ಕಾಣುವುದಕ್ಕಿಂತ ಅಗ್ಗ ([ಕೆಳಹಂತದ ಸಂಪನ್ಮೂಲ ಅತ್ಯುತ್ತಮೀಕರಣ](../ಕೆಳಹಂತದ-ಸಂಪನ್ಮೂಲ-ಅತ್ಯುತ್ತಮೀಕರಣ/) ನೋಡಿ); (2) ಆಸ್ಪತ್ರೆಗಳು ಶಸ್ತ್ರಚಿಕಿತ್ಸಾ ಪಟ್ಟಿಗಳನ್ನು ತುರ್ತು-ತೂಕದ ಥ್ರೂಪುಟ್‌ನಿಂದ ಕ್ರಮಗೊಳಿಸುವಾಗ ಅದೇ ನಿಯಮವನ್ನು ಪರೋಕ್ಷವಾಗಿ ನಡೆಸುತ್ತವೆ — ಕ್ಲಿನಿಕಲ್ ಆದ್ಯತೆ ವರ್ಗಗಳು ತೀವ್ರತೆ-ತೂಕದ CD3 ([QALY ಕೊರತೆ ಮತ್ತು ತೀವ್ರತೆ ಮಾರ್ಪಡಿಸುವವುಗಳು](../qaly-ಕೊರತೆ-ಮತ್ತು-ತೀವ್ರತಾ-ಮಾರ್ಪಾಡುಗಳು/) ನೋಡಿ).

## ಎಡವಟ್ಟುಗಳು

- **WSJF ಅಂಕ ನಾಟಕ**: ಘಟಕರಹಿತ Fibonacci ಚರ್ಚೆಗಳು ಅತಿ ಜೋರಾಗಿ ವಾದಿಸುವವರತ್ತ ಒಮ್ಮುಖವಾಗುತ್ತವೆ; ಕನಿಷ್ಠ ಬಾಕಿ ಪಟ್ಟಿಯ ಮೇಲ್ಭಾಗದ ವಸ್ತುಗಳನ್ನು ನಿಜ CoDಯಲ್ಲಿ ಆಧರಿಸಿ.
- **ಅವಧಿ ತಿರುಚುವಿಕೆ**: CD3 ಶ್ರೇಣಿ ಉಬ್ಬಿಸಲು ವಸ್ತುಗಳನ್ನು ವಿಭಜಿಸುವುದು — ವಿಭಜನೆಗಳು ಸ್ವತಂತ್ರವಾಗಿ ಮೌಲ್ಯ ನೀಡುವಾಗ ಸರಿ, ನೀಡದಿದ್ದಾಗ ವಂಚನೆ.
- **ತುರ್ತು ಪ್ರೊಫೈಲ್‌ಗಳ ನಿರ್ಲಕ್ಷ್ಯ**: ಗಡುವು-ಆಕಾರದ CoD (ನಿಯಂತ್ರಕ ದಿನಾಂಕಗಳು) ಸ್ಥಿರ-ದರ ಊಹೆಯನ್ನು ಮುರಿಯುತ್ತದೆ; ಅವನ್ನು ದಿನಾಂಕ ಸಾಧ್ಯತೆಯಿಂದ ನಿಗದಿಪಡಿಸಿ, ನಂತರ ಉಳಿದದ್ದಕ್ಕೆ CD3.
- **ಮರು-ಶ್ರೇಣೀಕರಣ ಗೊಂದಲ**: CD3 ಬದ್ಧತೆಯ ಸಮಯದಲ್ಲಿ ಅನುಕ್ರಮ ನಿರ್ಧಾರಗಳಿಗೆ, ಪ್ರಗತಿಯಲ್ಲಿರುವ ಕೆಲಸದ ದೈನಂದಿನ ಮರುಹೊಂದಾಣಿಕೆಗಲ್ಲ (WIP ಕುರಿತು [ಹರಿವಿನ ಮಾಪನಗಳು](../ಹರಿವಿನ-ಮಾಪನಗಳು/) ನೋಡಿ).
