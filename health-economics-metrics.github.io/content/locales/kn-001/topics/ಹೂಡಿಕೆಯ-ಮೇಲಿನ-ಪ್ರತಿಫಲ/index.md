# ಹೂಡಿಕೆಯ ಮೇಲಿನ ಪ್ರತಿಫಲ (ROI)

ROI ಎಂದರೆ ನಿವ್ವಳ ಲಾಭ ಮತ್ತು ಹೂಡಿದ ಹಣದ ಅನುಪಾತ. ಎಂಜಿನಿಯರಿಂಗ್ ಮತ್ತು ಹಣಕಾಸು ಈಗಾಗಲೇ ಹಂಚಿಕೊಳ್ಳುವ ಮೆಟ್ರಿಕ್ ಇದು — ಆರೋಗ್ಯ ಅರ್ಥಶಾಸ್ತ್ರವು ROI ಹೇಳಿಕೆಯನ್ನು ಪರಿಶೀಲನೆಯಲ್ಲಿ ಉಳಿಸುವ ಶಿಸ್ತನ್ನು ಸೇರಿಸುತ್ತದೆ: ಘೋಷಿತ ದೃಷ್ಟಿಕೋನ, ಹೋಲಿಕೆ ಆಧಾರ, ಗಡಿ ಮತ್ತು ಲಾಭ ವರ್ಗಗಳು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ROI ಬಜೆಟ್ ಹೊಂದಿರುವವರ ಸಾಮಾನ್ಯ ಭಾಷೆ, ಮತ್ತು ಸಾರ್ವಜನಿಕ ಆರೋಗ್ಯವೂ ಇದನ್ನು ಬಳಸುತ್ತದೆ: ಮೈಲಿಗಲ್ಲು Masters ಮತ್ತು ಇತರರ ವಿಮರ್ಶೆ ಸಾರ್ವಜನಿಕ ಆರೋಗ್ಯ ಮಧ್ಯಸ್ಥಿಕೆಗಳಿಗೆ **14.3:1 ಮಧ್ಯಸ್ಥ ROI** ಕಂಡುಕೊಂಡಿತು (ಪ್ರತಿ £1 ವಿಶಾಲ ಆರ್ಥಿಕತೆ ಮತ್ತು ಆರೋಗ್ಯ ವ್ಯವಸ್ಥೆಗೆ ~£14 ಮರಳಿಸುತ್ತದೆ) — ತಡೆಗಟ್ಟುವಿಕೆ ವೆಚ್ಚವನ್ನು ಸಮರ್ಥಿಸಲು ವ್ಯಾಪಕವಾಗಿ ಬಳಸುವ ಸಂಖ್ಯೆ. ಆದರೆ ಆ 14:1 *ಸಾಮಾಜಿಕ, ದೀರ್ಘ-ಗಡಿ* ಅಂಕಿ; ಆಸ್ಪತ್ರೆ CFOಯ ROI ಪಾವತಿದಾರ-ದೃಷ್ಟಿಕೋನ ಮತ್ತು 1–3 ವರ್ಷಗಳದ್ದು. ಹೆಚ್ಚಿನ ROI ಜಗಳಗಳು ವಾಸ್ತವವಾಗಿ ಘೋಷಿಸದ-ದೃಷ್ಟಿಕೋನ ಜಗಳಗಳು.

## ಗಣಿತ

```
ROI = (Benefits − Costs) / Costs      (often × 100%)

Payback period = Costs / annual net benefit
```

ನಾಲ್ಕು ಘೋಷಣೆಗಳಿಲ್ಲದೆ ROI ಹೇಳಿಕೆ ಅಪೂರ್ಣ:

1. **ದೃಷ್ಟಿಕೋನ** — ಯಾರ ಲಾಭಗಳು ಲೆಕ್ಕಕ್ಕೆ? ([ವಿಶ್ಲೇಷಣಾ ದೃಷ್ಟಿಕೋನ](../ವಿಶ್ಲೇಷಣಾ-ದೃಷ್ಟಿಕೋನ/) ನೋಡಿ)
2. **ಹೋಲಿಕೆ ಆಧಾರ** — ಯಾವ ಪರ್ಯಾಯದ ವಿರುದ್ಧ? ([ಅವಕಾಶ ವೆಚ್ಚ](../ಅವಕಾಶ-ವೆಚ್ಚ/) ನೋಡಿ)
3. **ಗಡಿ** — ಎಷ್ಟು ಕಾಲ, ಮತ್ತು [ರಿಯಾಯಿತಿ](../ರಿಯಾಯಿತಿ-ಮತ್ತು-ಕಾಲ-ಆದ್ಯತೆ/) ನೀಡಲಾಗಿದೆಯೇ?
4. **ಲಾಭ ವರ್ಗ** — ನಗದು-ಬಿಡುಗಡೆ, ಸಾಮರ್ಥ್ಯ, ಅಥವಾ ಗುಣಾತ್ಮಕ? ([ನಗದು-ಬಿಡುಗಡೆ vs ನಗದು-ರಹಿತ](../ನಗದು-ಬಿಡುಗಡೆ-vs-ನಗದು-ರಹಿತ-ಉಳಿತಾಯ/) ನೋಡಿ)

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಇ-ರೋಸ್ಟರಿಂಗ್ ವ್ಯವಸ್ಥೆ, 3 ವರ್ಷಗಳಲ್ಲಿ £500,000 ವೆಚ್ಚ.

```
Cash-releasing:  agency shift reduction        £450,000
Capacity:        ward-manager admin time freed £600,000 (valued, not banked)
Qualitative:     staff satisfaction, safety    not monetized

Strict financial ROI  = (450,000 − 500,000)/500,000 = −10%
Economic ROI          = (1,050,000 − 500,000)/500,000 = +110%
```

ಎರಡೂ ಸಂಖ್ಯೆಗಳು ನಿಜ. £450k ಮಾತ್ರ ಬ್ಯಾಂಕ್ ಮಾಡಬಲ್ಲ CFOಗೆ "+110% ROI" ಎಂದು ಉಲ್ಲೇಖಿಸುವ ಮಾರಾಟಗಾರ ವಿಶ್ವಾಸ ಕಳೆದುಕೊಳ್ಳುತ್ತಾನೆ; ಎರಡನ್ನೂ ಲೇಬಲ್ ಮಾಡಿ ಪ್ರಸ್ತುತಪಡಿಸುವುದು ಅದನ್ನು ಗೆಲ್ಲುತ್ತದೆ. ಹಣಕಾಸು ವಿಭಾಗ ಎರಡು ವರ್ಷಗಳ ನಂತರ ಲಾಭಗಳನ್ನು ಲೆಕ್ಕಪರಿಶೋಧಿಸಿದಾಗ ಅದೇ ವಿಭಜನೆ ಆಂತರಿಕ ಪ್ರತಿಪಾದಕನನ್ನು ರಕ್ಷಿಸುತ್ತದೆ.

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

ಪ್ರತಿ ಟೂಲಿಂಗ್ ಪ್ರಸ್ತಾವನೆಗೂ ROI ಸ್ಲೈಡ್ ಇದೆ; ಬಹುತೇಕ ಯಾವುದೂ ನಾಲ್ಕು ನಿಯತಾಂಕಗಳನ್ನು ಘೋಷಿಸುವುದಿಲ್ಲ. ಅತ್ಯಂತ ಸಾಮಾನ್ಯ ವೈಫಲ್ಯ ವರ್ಗ-ಬೆರೆಸುವಿಕೆ: ಸಾಮರ್ಥ್ಯ ಲಾಭಗಳನ್ನು (ಡೆವಲಪರ್ ನಿಮಿಷಗಳು) ಹಣಕಾಸು ಪ್ರತಿಫಲವಾಗಿ ಪ್ರಸ್ತುತಪಡಿಸುವುದು. AI/ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ROI ಅನ್ನು ಮೇಲಿನ ಬಿಡಿಸಿದ ಉದಾಹರಣೆಯಂತೆ ರಚಿಸಿ — ನಗದು ಸಾಲು, ಸಾಮರ್ಥ್ಯ ಸಾಲು, ಗುಣಾತ್ಮಕ ಸಾಲು — ಮತ್ತು ಮೃದು ಸಂಖ್ಯೆಗಳ ಮೇಲೆ [ಸಂವೇದನಾ ವಿಶ್ಲೇಷಣೆ](../ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/) ಸೇರಿಸಿ. AI ROIಗೆ ವಿಶೇಷವಾಗಿ P&L ವಾಸ್ತವ ಪರಿಶೀಲನೆಗಾಗಿ [AI ಹೂಡಿಕೆಯ ಮೇಲಿನ ಪ್ರತಿಫಲ](../ai-ಹೂಡಿಕೆಯ-ಮೇಲಿನ-ಪ್ರತಿಫಲ/) ನೋಡಿ.

## ಎಡವಟ್ಟುಗಳು

- **ದೃಷ್ಟಿಕೋನ ಶುದ್ಧೀಕರಣ**: 12-ತಿಂಗಳ ಗಡಿ ಇರುವ ಬಜೆಟ್ ಹೊಂದಿರುವವರಿಗೆ ದಶಕದ ಸಾಮಾಜಿಕ ಲಾಭಗಳನ್ನು ಉಲ್ಲೇಖಿಸುವುದು.
- **ನಿವ್ವಳದ ಬದಲು ಒಟ್ಟು**: £2M ವೆಚ್ಚಕ್ಕೆ "£3M ಮರಳಿಸುತ್ತದೆ" ಎಂದರೆ 50% ROI, 300% ಅಲ್ಲ.
- **ಅನುಪಾತ ಗರಿಷ್ಠೀಕರಣ**: ಚಿಕ್ಕ ಛೇದಗಳು ಅತಿ ಸಣ್ಣ ಹೂಡಿಕೆಗಳಿಗೆ ಅದ್ಭುತ ROI ನೀಡುತ್ತವೆ; ಪೋರ್ಟ್‌ಫೋಲಿಯೊಗಳನ್ನು NPV ಅಥವಾ [ನಿವ್ವಳ ಹಣಕಾಸು ಲಾಭ](../ನಿವ್ವಳ-ಹಣಕಾಸು-ಲಾಭ/)ದಿಂದ ಶ್ರೇಣೀಕರಿಸಿ, ROI ಅನ್ನು ಜರಡಿಯಾಗಿ ಬಳಸಿ.
- **ಲಾಭ ಲೆಕ್ಕಪರಿಶೋಧನೆ ಇಲ್ಲ**: [ಲಾಭ ಸಾಕ್ಷಾತ್ಕಾರ](../ಲಾಭ-ಸಾಕ್ಷಾತ್ಕಾರ/) ಟ್ರ್ಯಾಕಿಂಗ್ ಇಲ್ಲದ ಮುನ್ಸೂಚಿತ ROI ಒಂದು ಭರವಸೆ, ಫಲಿತಾಂಶವಲ್ಲ.
