# ವೆಚ್ಚ-ಉಪಯುಕ್ತತಾ ವಿಶ್ಲೇಷಣೆ (CUA)

CUA ಎಂಬುದು **ಸಾಮಾನ್ಯ, ಆದ್ಯತೆ-ತೂಕದ ಫಲಿತಾಂಶ** ಇರುವ ವೆಚ್ಚ-ಪರಿಣಾಮಕಾರಿತ್ವ ವಿಶ್ಲೇಷಣೆ — ಬಹುತೇಕ ಯಾವಾಗಲೂ [QALY](../ಗುಣಮಟ್ಟ-ಹೊಂದಾಣಿಕೆಯ-ಜೀವ-ವರ್ಷ/) (ಅಥವಾ ತಪ್ಪಿಸಿದ [DALY](../ಅಂಗವೈಕಲ್ಯ-ಹೊಂದಾಣಿಕೆಯ-ಜೀವ-ವರ್ಷ/)). ಫಲಿತಾಂಶ ಘಟಕ ಸಾರ್ವತ್ರಿಕವಾದ್ದರಿಂದ, CUA ಸಂಪೂರ್ಣ ಭಿನ್ನ ರೋಗಗಳಾದ್ಯಂತ ಮಧ್ಯಸ್ಥಿಕೆಗಳನ್ನು ಹೋಲಿಸಬಲ್ಲದು.

## ಇದು ಏಕೆ ಮುಖ್ಯ

ರಾಷ್ಟ್ರೀಯ ಆರೋಗ್ಯ ಸೇವೆ ಒಂದೇ ಬಜೆಟ್‌ನಿಂದ ಕ್ಯಾನ್ಸರ್ ಔಷಧ, ಮಾನಸಿಕ-ಆರೋಗ್ಯ ಆ್ಯಪ್ ಮತ್ತು ಶಸ್ತ್ರಚಿಕಿತ್ಸಾ ರೋಬೋಟ್ ನಡುವೆ ಆರಿಸಬೇಕು. ನೈಸರ್ಗಿಕ ಘಟಕಗಳು ಅವನ್ನು ಹೋಲಿಸಲಾಗದು; QALYಗಳು ಹೋಲಿಸಬಲ್ಲವು. ಆದ್ದರಿಂದ CUA NICE ಮತ್ತು ಹೆಚ್ಚಿನ HTA ಸಂಸ್ಥೆಗಳಲ್ಲಿ ಉಲ್ಲೇಖ-ಪ್ರಕರಣ ವಿಧಾನ: ಅದರ ಫಲಿತಾಂಶ — ಪ್ರತಿ QALYಗೆ ವೆಚ್ಚ, [ಮಿತಿ](../ಪಾವತಿಸಲು-ಇಚ್ಛೆಯ-ಮಿತಿಗಳು/)ಯ ವಿರುದ್ಧ ನಿರ್ಣಯಿಸಲ್ಪಟ್ಟದ್ದು — ಆರೋಗ್ಯ ನೀತಿಗೆ ಸಾರ್ವತ್ರಿಕ ವಿನಿಮಯ ದರಕ್ಕೆ ಹತ್ತಿರದ ವಸ್ತು. ನಿಮ್ಮ ಸಾಫ್ಟ್‌ವೇರ್‌ಗೆ *ಬೇರೊಂದರ ಬದಲು* ಹಣ ಸಿಗಬೇಕಾದರೆ, CUA ಅಖಾಡ.

## ಗಣಿತ

```
ICUR = ΔCost / ΔQALYs      (the ICER with QALYs as the effect unit)

ΔQALYs = Σ (duration_i × utility_i)_new − Σ (duration_i × utility_i)_old
```

ಮಾನ್ಯತೆ ಪಡೆದ ಸಾಧನಗಳಿಂದ ([EQ-5D](../eq-5d/)) ಉಪಯುಕ್ತತೆಗಳು; ವೆಚ್ಚಗಳು ಮತ್ತು QALYಗಳೆರಡಕ್ಕೂ 3.5% [ರಿಯಾಯಿತಿ](../ರಿಯಾಯಿತಿ-ಮತ್ತು-ಕಾಲ-ಆದ್ಯತೆ/) (NICE ಉಲ್ಲೇಖ ಪ್ರಕರಣ); ಅನಿಶ್ಚಿತತೆ [PSA](../ಸಂಭಾವ್ಯತಾ-ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/) ಮೂಲಕ.

## ಬಿಡಿಸಿದ ಉದಾಹರಣೆ

ಮಧ್ಯಮ ಆತಂಕಕ್ಕೆ CBT ಆ್ಯಪ್ vs ಮುಖಾಮುಖಿ ಚಿಕಿತ್ಸೆಯ ಕಾಯುವ ಪಟ್ಟಿ, ಪ್ರತಿ ರೋಗಿಗೆ:

```
Costs:  app licence + support        £250
        therapy displaced            −£680   (40% of users no longer need it)
        ΔC = 250 − 680 = −£430 (saves money)

QALYs:  6 months at utility 0.76 instead of 0.68 while waiting
        ΔE = 0.5 × (0.76 − 0.68) = +0.04 QALYs
```

ΔC < 0 ಮತ್ತು ΔE > 0: ಆ್ಯಪ್ **ಪ್ರಾಬಲ್ಯ ಹೊಂದಿದೆ** — ಉತ್ತಮ ಮತ್ತು ಅಗ್ಗ, ಅನುಪಾತ ಬೇಕಿಲ್ಲ. ಚಿಕಿತ್ಸೆ-ಸ್ಥಾನಪಲ್ಲಟ ಊಹೆ ಕೇವಲ 10% ಆಗಿದ್ದರೆ, ΔC = 250 − 170 = +£80, ಮತ್ತು ICUR = 80 / 0.04 = **ಪ್ರತಿ QALYಗೆ £2,000** — ಇನ್ನೂ £20,000ಕ್ಕಿಂತ ಬಹಳ ಕೆಳಗೆ. ಪ್ರಮುಖ ಊಹೆಯನ್ನು ಕತ್ತರಿಸಿದರೂ ಪ್ರಕರಣ ಉಳಿಯುತ್ತದೆ: ದೃಢ CUA ಹೀಗೇ ಕಾಣುತ್ತದೆ (ಮತ್ತು [ಟೊರ್ನೇಡೊ ಆಕೃತಿ](../ಸಂವೇದನಾ-ವಿಶ್ಲೇಷಣೆ/) ಅದನ್ನು ಸಾಬೀತುಪಡಿಸುತ್ತದೆ).

## ಸಾಫ್ಟ್‌ವೇರ್ ಎಂಜಿನಿಯರಿಂಗ್‌ನೊಂದಿಗಿನ ಸಂಬಂಧ

CUAಯ ಆಳವಾದ ಆಲೋಚನೆ — *ಅಸಮಾನ ವಸ್ತುಗಳನ್ನು ಹೋಲಿಸಲು ಒಂದು ಸಂಯೋಜಿತ, ಆದ್ಯತೆ-ತೂಕದ ಘಟಕ* — ಅಸಮಾನ ಎಂಜಿನಿಯರಿಂಗ್ ಹೂಡಿಕೆಗಳನ್ನು (ಭದ್ರತೆ vs ಡೆವಲಪರ್ ಅನುಭವ vs ವಿಶ್ವಾಸಾರ್ಹತೆ) ಹೋಲಿಸುವ ಮಾದರಿ. ಪ್ರಾಮಾಣಿಕ ಆಯ್ಕೆಗಳು ಸಮರ್ಥನೀಯ ಸಂಯೋಜಿತ ಘಟಕ (ಅಪರೂಪ) ಅಥವಾ ಸ್ಪಷ್ಟ [ವೆಚ್ಚ-ಪರಿಣಾಮ ಕೋಷ್ಟಕ](../ವೆಚ್ಚ-ಪರಿಣಾಮ-ವಿಶ್ಲೇಷಣೆ/) (ಸಾಮಾನ್ಯ). CUA ಎಚ್ಚರಿಸುವುದು ನಕಲಿ ಸಂಯೋಜಿತದ ಬಗ್ಗೆ: ಆದ್ಯತೆಯ ಆಯ್ಕೆ ಗೆಲ್ಲುವಂತೆ ನಂತರ ಹೊಂದಿಸಿದ ತೂಕಗಳ "ಪರಿಣಾಮ ಅಂಕ". ತೂಕಗಳು ಹೋಲಿಕೆಗೆ ಮೊದಲೇ ಇರಲೆಂದೇ ಆರೋಗ್ಯ ಅರ್ಥಶಾಸ್ತ್ರವು ದಶಕಗಳ ಕಾಲ ಉಪಯುಕ್ತತಾ ನಿರ್ಧಾರಣೆಯನ್ನು ಪ್ರಮಾಣೀಕರಿಸಿತು.

## ಎಡವಟ್ಟುಗಳು

- **ಸಾಧನದ ಸಂವೇದನೆಗಿಂತ ಕೆಳಗಿನ ಉಪಯುಕ್ತತಾ ಲಾಭಗಳು** ([ರೋಗಿ-ವರದಿ ಫಲಿತಾಂಶಗಳು](../ರೋಗಿ-ವರದಿ-ಫಲಿತಾಂಶಗಳು/)ದಲ್ಲಿ ಕನಿಷ್ಠ ವೈದ್ಯಕೀಯವಾಗಿ ಮುಖ್ಯ ವ್ಯತ್ಯಾಸ ನೋಡಿ) — ದೊಡ್ಡ ಜನಸಂಖ್ಯೆ ಗುಣಿಸಿದ ಅತಿ ಚಿಕ್ಕ ΔE ಶ್ರೇಷ್ಠ ಶುದ್ಧೀಕರಣ ತಂತ್ರ.
- **ಹೋಲಿಕೆ ಆರೈಕೆ ಸ್ಥಾನಪಲ್ಲಟವನ್ನು ತಪ್ಪಿಸಿಕೊಳ್ಳುವುದು** — ಡಿಜಿಟಲ್ ಉತ್ಪನ್ನಗಳ ದೊಡ್ಡ ವೆಚ್ಚ ಪದ ಆಗಾಗ ಅವು ಏನನ್ನು ಬದಲಿಸುತ್ತವೆ ಎಂಬುದೇ.
- **ಮಾನ್ಯತೆ ಇಲ್ಲದ ಕ್ರಾಸ್‌ವಾಕ್‌ಗಳೊಂದಿಗೆ** ಆದ್ಯತೆ-ರಹಿತ ಅಂಕಗಳನ್ನು ಉಪಯುಕ್ತತೆಗಳಿಗೆ ಮ್ಯಾಪ್ ಮಾಡುವುದು.
