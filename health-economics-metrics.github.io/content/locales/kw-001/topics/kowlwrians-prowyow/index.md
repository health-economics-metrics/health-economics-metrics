# Kowlwrians Prowyow

Maynans kowlwrians prowyow (BRM) yw an dyskyplin a aswonn, dalleth-lenya, holya ha *dhiskwedhes* bos an prowyow a veu gwrys gwir dhelergh an delivrans. Yn invested poblek an Rewlm Unys, yma y'n **Modh Pymp Kas** a Green Book HM Treasury; y'n medhegieth, y gares yw gwithyans wosa an varghas.

## Perag yth yw posek

Kasow besneth yw gwrians; kowlwrians prowyow yw an awdit. Gwerthjyansow a bregowtha NHS nombrek a dhyskudhas prowyow ragwelys na dhrehedhas bythkweth — ha pan na veu prowyow relasya arghans, y ny wrug tra vyth rag diwedh an trest. Gorthyp an Green Book: pub kas spena a res tremena **pymp kas** (strategek, ekonomek, kenwerthek, arghansek, maynans), gans kowlwrians prowyow towlys y'n kas maynans *kyns a dhegemeres* — perghenogyon hanwys, dalleth-linennow kuntelles, dydhyow musur settys. Heb hemma, "an medhelweyth a sawyas 30 mynysenn dhe bub medhegesen" a bys fabel gwerther bys vyken.

## An Matematik

```
Ratyo kowlwrians = prowyow kowlwrys / prowyow ragwelys   (rag pub prow, rag pub termyn)

Mechanika a wra yth yw kowntadow:
  dalleth-linenn kuntelles KYNS an dallethans (po'n delta yw dhimusurys)
  rag pub prow: perghenek, metrik, fenten data, rol musur
  ragwel a vo kesys rag bias-owrowayans orth apprais (ordhenans Green Book)
  prowyow klasys arghans / heb-arghans / kwalita, ha holys dioberys
  (gwelewgh cash-releasing-vs-non-cash-releasing.md)
```

## Ensampel gwrys

Kas besneth e-rosteryans a bromisyas, pub bledhen: £450k mynnys spena kevarwydh (arghans), 8,000 eur mestrow-ward (kanasow), plesyans gwellhes lenwi-ratyo (kwalita). Dewdhek mis wosa an dallethans:

```
Prow              Ragwelys    Kowlwrys    Ratyo  Skoodhyans
Spena kevarwydh   £450,000    £287,000    64%    lyver-denewi erbynn bledhen dalleth
Eurow mestrow     8,000       5,100       64%    sampel termyn-gwrians
Plesyans lenwi    +10pp       +12pp       120%   data system rosteryans

Gwrians diwar an gwerthjyans (poynt BRM):
kamgovys kevarwydh dhe dhew ward na veu dalleth-gemerys → aga degemeres;
fowt owrowayans 30% an patrom ragwelys skrifys → devnydhys dhe'n kas nessa.
```

64% kowlwrians nyns yw fyll — yw *godhvos*. Kasow na veu musurys a glam 100% bys vyken.

## Kolm gans ynjynnyans medhelweyth

Kowethyansow ynjynnyans a dhegemer investyansow platform diwar prowyow ragwelys ha nebes pan awditya — an keth klevyd a wra BRM sawya. An port es: pub arghadow a-ugh threshold a henwi perghenogyon prow, metryks dalleth-linenn, ha dydh gwerthjyans T+6 mis; ratyow kowlwrians a re dhe'n kowethyans pygen moy dhe diskontya ragwel nessa an tim (po'n gwerther). Hemma yw ynwedh an gorthyp dhe skeptigyans ark AI: [kavans MIT bos ~95% a bregowthow GenAI heb dewlder P&L musurys](../dehweles-dhe-investyans-ai/) yw sewyans kowlwrians prowyow — an bregowthow a *dhelivras* a'n jeva linednow prow hwithradow ha perghenogys. Ragwel → musur → dasboyza yw an keth kelgh kepar ha previansow [EVPI](../talvos-ragwelys-a-wodhvos-perfydh/), ow ledya war skala portfolio.

## Fowtys Kemmyn

- **Heb dalleth-linenn kyns dallethans** — an gwall marow na yll bos sawys.
- **Diperghenegieth prow**: heb perghenek hanwys, nagonan ny gussul an data ha pub gwerthjyans a lever "yn tyller ewn."
- **Prowyow dewblys dres kesplansow** ow klamya an keth kanasow delivrys — gwithewgh rol prowyow dres an portfolio.
- **Gwari kowlwrians**: musura an gwainys kwalita es hag an linednow arghans a dhelyr heb gwerthjyans.
