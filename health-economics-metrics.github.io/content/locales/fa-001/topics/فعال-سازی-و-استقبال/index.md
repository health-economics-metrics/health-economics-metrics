# فعال‌سازی و استقبال

نرخ فعال‌سازی سهم ثبت‌نام‌کنندگانی است که به نخستین ارزش معنادار می‌رسند (اقدام «آها» — نخستین خوانش ثبت‌شده، نخستین درس انجام‌شده). استقبال (uptake) نسخه جمعیتی آن است: سهمی از جمعیت *واجد شرایط* که اصلاً می‌پذیرند. با هم دروازه‌های ورودی قیف ارزش‌اند: جذب ← استقبال ← فعال‌سازی ← [ماندگاری](../ماندگاری-و-ریزش/) ← پیامد.

## چرا اهمیت دارد

کاربران فعال‌نشده هزینه خالص‌اند: هزینه جذب، تدارک، سطح پشتیبانی — بدون هیچ ارزش بالینی. محک‌ها فعال‌سازی نرم‌افزارهای سلامت را *کمتر* از میانگین میان‌صنعتی نشان می‌دهند (حدود 24% در برابر حدود 37% برای فعال‌سازی کاربر جدید در یک مجموعه محک SaaS؛ تکمیل فهرست راه‌اندازی حدود 20%)، که بازتاب راه‌اندازی سنگین‌تر (هویت، رضایت، ایمنی بالینی) است. استقبال سهم جمعیتی را حمل می‌کند: در [چارچوب RE-AIM](../دسترسی-و-برابری/)، اثر سلامت عمومی ≈ دسترسی × اثربخشی — یک اپلیکیشن عالی که 3% جمعیت واجد شرایط می‌پذیرند، فقط به اندازه 3% عقربه جمعیت را حرکت می‌دهد. برای درمان‌های دیجیتال تجویزی، دروازه استقبال در داده‌های ملی دیده می‌شود: **حدود 81% نسخه‌های DiGA آلمان فعال می‌شوند** — از هر پنج درمان تجویزشده و پرداخت‌شده یکی هرگز آغاز نمی‌شود (به [مسیر سریع DiGA](../مسیر-سریع-diga-آلمان/) نگاه کنید).

## ریاضیات

```
Activation rate = users completing key action within window / sign-ups × 100
Uptake rate     = adopters / eligible population × 100
DTx fill rate   = activated prescription codes / issued prescriptions × 100

Funnel value model:
  eligible × uptake × activation × retention-weighted benefit = population value
  — four multiplications; improving the smallest factor usually
  dominates (theory-of-constraints for funnels)
```

## مثال حل‌شده

یک متولی خرید یک اپلیکیشن پیشگیری از دیابت را به 80,000 ساکن واجد شرایط پیشنهاد می‌کند:

```
Invited → registered:  80,000 → 12,000  (uptake 15%)
Registered → activated (first session + goal set, 7 days): 12,000 → 5,400 (45%)
Activated → completed 6-month programme: 5,400 → 1,600 (30%)

Programme effect (trial, completers): 0.03 QALYs + £180 avoided costs
Population value = 1,600 × (0.03 × £20,000 + £180) ≈ £1.25M
Per-eligible-person value = £15.6 — versus £780 if every eligible person completed.

Where to invest? Doubling uptake (15→30%) doubles value; raising
activation 45→65% adds ~44%; both beat further polishing the programme
content the 1,600 already complete.
```

## ارتباط با مهندسی نرم‌افزار

فعال‌سازی از نظر مهندسی قابل‌حل‌ترین مرحله قیف است: اصطکاک راستی‌آزمایی هویت، جریان‌های رضایت، طراحی حالت خالی و زمان رسیدن به نخستین ارزش کد هستند، نه سیاست (میانه زمان رسیدن به ارزش در سلامت ≈ 1 روز و 7 ساعت در داده‌های محک — هر ساعت از آن مواجهه با ریزش است). استقبال مسئله نظام‌های توزیع است: یکپارچگی در مسیرهای ارجاع (لحظه نسخه)، دعوت‌های مورد تأیید پزشک عمومی (انتقال اعتماد)، و دسترس‌پذیری (زبان، مهارت دیجیتال — به [دسترسی و برابری](../دسترسی-و-برابری/) نگاه کنید). مدل ارزش قیف بالا مولد پرونده کسب‌وکار برای هر دو است: عوامل را ضرب کنید، محدودیت را بیابید، رفع آن را در برابر ارزش جمعیتی که آزاد می‌کند قیمت‌گذاری کنید.

## تله‌ها و اشتباهات رایج

- **فعال‌سازی تعریف‌شده بر اساس سهولت** (ایمیل تأییدشده) نه معنای بالینی (نخستین اقدام درمانی) — معیار را باد می‌کند و زنجیره ارزش را می‌شکند.
- **بازی با مخرج استقبال**: «از میان کسانی که از سایت بازدید کردند» در برابر جمعیت واقعاً واجد شرایط — متولیان خرید به دومی اهمیت می‌دهند.
- **اثرات انتخاب**: کاربرانی که فعال‌سازی‌شان آسان است کم‌بیمارترین و کم‌محروم‌ترین‌اند؛ بهبود قیف می‌تواند شکاف‌های برابری را با بهتر شدن میانگین‌ها گسترده کند.
