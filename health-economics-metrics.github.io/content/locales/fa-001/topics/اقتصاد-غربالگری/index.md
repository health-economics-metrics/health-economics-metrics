# اقتصاد غربالگری

اقتصاد غربالگری بر ارزش آزمون جمعیت‌های بدون علامت حاکم است. واقعیت ریاضی اصلی: **در شیوع پایین بیماری، حتی آزمون‌های عالی عمدتاً مثبت کاذب تولید می‌کنند** — و هزینه پایین‌دست دنبال کردن آنها می‌تواند منفعت یافته‌های واقعی را بر باد دهد.

## چرا اهمیت دارد

از 1968، معیارهای ویلسون–یونگر WHO سطح غربالگری جمعیتی را تعیین کرده‌اند: وضعیت باید مهم باشد، آزمون پذیرفتنی و دقیق، درمان مؤثر موجود، و اقتصاد متوازن. کمیته ملی غربالگری بریتانیا پیش از تأیید هر برنامه ملی تحلیل هزینه-اثربخشی رسمی اعمال می‌کند — و بیشتر پیشنهادها را رد می‌کند. هر عرضه «هوش مصنوعی همه را برای همه‌چیز غربالگری می‌کند» با این ماشین برمی‌خورد و معمولاً در برابر حساب زیر می‌بازد.

## ریاضیات

ارزش پیش‌بینی مثبت (PPV) — احتمال واقعی بودن نتیجه مثبت — در شیوع پایین فرو می‌ریزد:

```
PPV = (sens × prev) / [sens × prev + (1 − spec) × (1 − prev)]

Example: sensitivity 90%, specificity 95%, prevalence 0.5%:
PPV = (0.9 × 0.005) / (0.9 × 0.005 + 0.05 × 0.995)
    = 0.0045 / (0.0045 + 0.04975) ≈ 8.3%
```

از هر دوازده مثبت یازده کاذب است. اقتصاد کامل برنامه:

```
Cost per true case found = (screening cost + workup cost × all positives) / true positives
Then: is finding a case worth that? (earlier-intervention value per case,
      minus overdiagnosis harm — cases found that would never have mattered)
```

## مثال حل‌شده

غربالگری شبکیه با هوش مصنوعی برای یک وضعیت نادر، 100,000 نفر، شیوع 0.5%، حساسیت 90%، ویژگی 95%، اسکن £15، پیگیری تأییدی £400:

```
True positives:  100,000 × 0.005 × 0.90 = 450
False positives: 100,000 × 0.995 × 0.05 = 4,975
Cost = 100,000 × 15 + (450 + 4,975) × 400 = 1.5M + 2.17M = £3.67M
Cost per true case ≈ £8,156
```

اگر درمان زودهنگام به ازای هر مورد £20,000 + 1 QALY صرفه‌جویی کند، برنامه به‌راحتی عبور می‌کند. ویژگی را به 99% بالا ببرید (هشدارهای کاذب کمتر): هزینه پیگیری به (450 + 995) × 400 = £0.58M می‌رسد، کل £2.08M، هزینه به ازای هر مورد ≈ **£4,622** — ویژگی، نه حساسیت، جایی است که اقتصاد غربالگری در شیوع پایین برده می‌شود.

## ارتباط با مهندسی نرم‌افزار

تحلیل ایستا، اسکن امنیتی و تشخیص ناهنجاری برنامه‌های غربالگری روی پایگاه‌های کد و تله‌متری‌اند، با شیوع نقص واقعی اغلب بسیار کمتر از 1% به ازای هر فرصت هشدار. همان ریاضیات خستگی از هشدار را توضیح می‌دهد: اسکنری با ویژگی 95% روی کد با شیوع پایین تیم‌ها را در مثبت‌های کاذب غرق می‌کند، و هر مثبت کاذب توجه را مصرف و اعتماد را فرسوده می‌کند تا هشدارهای واقعی نادیده گرفته شوند (اصطلاح بالینی *آسیب غربالگری* است؛ اصطلاح مهندسی *بی‌حسی پیجر*). راه‌حل‌ها از سلامت منتقل می‌شوند: پیش از حساسیت ویژگی را بالا ببرید، زیرجمعیت‌های با شیوع بالاتر را غربال کنید (هدف‌گیری مبتنی بر ریسک ↔ اسکن فقط کد تغییرکرده)، و هزینه تریاژ را در اقتصاد ابزار بشمارید — به [NNT](../تعداد-لازم-برای-درمان/) و [ارزیابی هوش مصنوعی بالینی](../ارزیابی-هوش-مصنوعی-بالینی/) نگاه کنید. برای اندازه‌گیری کل یک برنامه غربالگری به‌جای یک آزمون، به [تعداد لازم برای غربالگری](../تعداد-لازم-برای-غربالگری/) نگاه کنید — چند نفر باید از کل مسیر غربالگری-و-درمان بگذرند تا از یک پیامد پیشگیری شود.

## تله‌ها و اشتباهات رایج

- **نقل حساسیت/ویژگی بدون شیوع** — دقت بدون PPV بازاریابی است.
- **نادیده گرفتن بیش‌تشخیصی**: یافتن «بیماری» تنبل که هرگز آسیب نمی‌زد هزینه‌ها و آسیب‌های واقعی درمان را به راه می‌اندازد.
- **سوگیری زمان پیش‌برد**: تشخیص زودتر بدون تغییر پیامدها بقای ظاهری را باد می‌کند — به [مداخله زودتر](../مداخله-زودتر/) نگاه کنید.
