# ຕົວຊີ້ວັດເສດຖະສາດສຸຂະພາບ

ການແນະນຳຢ່າງຄົບຖ້ວນກ່ຽວກັບເລກຄະນິດ, ຕົວຢ່າງ ແລະ ການໃຫ້ເຫດຜົນຂອງເສດຖະສາດສຸຂະພາບ. ແຕ່ລະໄຟລ໌ຄຸມໜຶ່ງຕົວຊີ້ວັດ ຫຼື ແນວຄິດ: ນິຍາມ, ເປັນຫຍັງຈຶ່ງສຳຄັນ, ຄະນິດສາດ, ຕົວຢ່າງການຄິດໄລ່, ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ, ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ ແລະ ແຫຼ່ງອ້າງອີງ.

ເປັນຄັ້ງທຳອິດຂອງທ່ານບໍ? ເລີ່ມຈາກ [ຕົ້ນທຶນຄວາມເສຍໂອກາດ](locales/en-gb-oxendict/topics/opportunity-cost/), [ປີຊີວິດທີ່ປັບດ້ວຍຄຸນນະພາບ (QALY)](locales/en-gb-oxendict/topics/quality-adjusted-life-year/) ແລະ [ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ (CoD)](locales/en-gb-oxendict/topics/cost-of-delay/) — ສາມແນວຄິດທີ່ທຸກຢ່າງອື່ນສ້າງຂຶ້ນມາ.

## ພື້ນຖານການໃຫ້ເຫດຜົນທາງເສດຖະກິດ

- [ຕົ້ນທຶນຄວາມເສຍໂອກາດ](locales/en-gb-oxendict/topics/opportunity-cost/) — ມູນຄ່າຂອງທາງເລືອກທີ່ດີທີ່ສຸດທີ່ສະລະໄປ; ເປັນຫຍັງງົບຄົງທີ່ຈຶ່ງເຮັດໃຫ້ທຸກການເລືອກເປັນການແທນທີ່
- [ການຫຼຸດມູນຄ່າ ແລະ ຄວາມມັກດ້ານເວລາ](locales/en-gb-oxendict/topics/discounting-and-time-preference/) — ມູນຄ່າປັດຈຸບັນ, ອັດຕາ 3.5% ຂອງ Green Book/NICE
- [ມຸມມອງຂອງການວິເຄາະ](locales/en-gb-oxendict/topics/analysis-perspective/) — ຜູ້ຈ່າຍເງິນ ທຽບກັບ ຜູ້ໃຫ້ບໍລິການ ທຽບກັບ ສັງຄົມ: ຕົ້ນທຶນຂອງໃຜທີ່ນັບ
- [ຂອບເຂດເວລາ](locales/en-gb-oxendict/topics/time-horizon/) — ນັບຕົ້ນທຶນ ແລະ ຜົນດົນປານໃດ, ແລະ ການຫຼິ້ນກົນຂອບເຂດເວລາ
- [ຕົ້ນທຶນສ່ວນເພີ່ມ ທຽບກັບ ຕົ້ນທຶນສະເລ່ຍ](locales/en-gb-oxendict/topics/marginal-vs-average-cost/) — ເປັນຫຍັງການປົດປ່ອຍຕຽງໜຶ່ງຈຶ່ງບໍ່ປະຢັດຕົ້ນທຶນສະເລ່ຍຂອງມັນ
- [ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດ ທຽບກັບ ທີ່ບໍ່ປົດປ່ອຍເງິນສົດ](locales/en-gb-oxendict/topics/cash-releasing-vs-non-cash-releasing/) — ການທົດສອບຄວາມຊື່ສັດສຳລັບທຸກການອ້າງ "ປະຢັດເວລາ"
- [ການວິເຄາະຄວາມອ່ອນໄຫວ](locales/en-gb-oxendict/topics/sensitivity-analysis/) — ແຜນຜັງ tornado; ສົມມຸດຖານໃດຮັບກໍລະນີຂອງທ່ານ
- [ການວິເຄາະຄວາມອ່ອນໄຫວແບບຄວາມນ່າຈະເປັນ (PSA)](locales/en-gb-oxendict/topics/probabilistic-sensitivity-analysis/) — Monte Carlo, CEAC, ຄວາມນ່າຈະເປັນທີ່ຖືກຕ້ອງ
- [ມູນຄ່າທີ່ຄາດໄວ້ຂອງຂໍ້ມູນສົມບູນແບບ (EVPI)](locales/en-gb-oxendict/topics/expected-value-of-perfect-information/) — ຕັ້ງລາຄາໂຄງການນຳຮ່ອງກ່ອນທີ່ທ່ານຈະຣັນມັນ
- [ມູນຄ່າທີ່ຄາດໄວ້ຂອງຂໍ້ມູນຕົວຢ່າງ (EVSI)](locales/en-gb-oxendict/topics/expected-value-of-sample-information/) — ຕັ້ງລາຄາການສຶກສາທີ່ສະເໜີ *ສະເພາະ*, ບໍ່ແມ່ນການກຳຈັດຄວາມບໍ່ແນ່ນອນທັງໝົດ
- [ການປະເມີນມູນຄ່າຕົວເລືອກຈິງ](locales/en-gb-oxendict/topics/real-options-valuation/) — ຕັ້ງລາຄາຕົວເລືອກໃນການຂະຫຍາຍໂຄງການເປັນໄລຍະພາຍຫຼັງ, ແທນຕົວເລືອກໃນການເກັບຂໍ້ມູນກ່ອນ
- [ວິທີທຶນມະນຸດ ທຽບກັບ ວິທີຕົ້ນທຶນການຂັດຂ້ອງ](locales/en-gb-oxendict/topics/human-capital-and-friction-cost/) — ສອງວິທີປະເມີນຜະລິດຕະພາບທີ່ສູນເສຍ, ຕົ້ນທຶນທີ່ລາຍງານຕ່າງກັນ 2 ເທົ່າຂຶ້ນໄປ
- [ຄວາມເໜືອກວ່າ ແລະ ຂອບເຂດປະສິດທິພາບ](locales/en-gb-oxendict/topics/dominance-and-efficiency-frontier/) — ກຳຈັດທາງເລືອກທີ່ບໍ່ມີໃຜຄວນເລືອກ

## ມາດຕະການຜົນລັບ

- [ປີຊີວິດທີ່ປັບດ້ວຍຄຸນນະພາບ (QALY)](locales/en-gb-oxendict/topics/quality-adjusted-life-year/) — ສະກຸນເງິນຮ່ວມຂອງມູນຄ່າດ້ານສຸຂະພາບ
- [ປີຊີວິດທີ່ປັບດ້ວຍຄວາມພິການ (DALY)](locales/en-gb-oxendict/topics/disability-adjusted-life-year/) — ກະຈົກດ້ານພາລະ; ຕົວຊີ້ວັດຂອງສຸຂະພາບໂລກ
- [EQ-5D](locales/en-gb-oxendict/topics/eq-5d/) — ເຄື່ອງມືທີ່ຢູ່ເບື້ອງຫຼັງນ້ຳໜັກຄ່າປະໂຫຍດ QALY ສ່ວນໃຫຍ່
- [ການດຶງຄ່າປະໂຫຍດດ້ວຍການແລກປ່ຽນເວລາ (TTO)](locales/en-gb-oxendict/topics/time-trade-off-utility/) — ນ້ຳໜັກຄ່າປະໂຫຍດຖືກດຶງຈາກຜູ້ຕອບຈິງແນວໃດ
- [ອັດຕາສ່ວນຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນສ່ວນເພີ່ມ (ICER)](locales/en-gb-oxendict/topics/incremental-cost-effectiveness-ratio/) — ຕົ້ນທຶນເພີ່ມຕໍ່ໜຶ່ງຫົວໜ່ວຍສຸຂະພາບທີ່ເພີ່ມ
- [ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ](locales/en-gb-oxendict/topics/willingness-to-pay-thresholds/) — NICE £20–30k/QALY ແລະ ເສັ້ນອື່ນຂອງໂລກ
- [ມູນຄ່າຂອງຊີວິດທາງສະຖິຕິ (VSL)](locales/en-gb-oxendict/topics/value-of-a-statistical-life/) — ທາງເລືອກຈາກຕະຫຼາດແຮງງານແທນການປະເມີນອີງເກນ
- [ຜົນປະໂຫຍດເປັນເງິນສຸດທິ (NMB)](locales/en-gb-oxendict/topics/net-monetary-benefit/) — ມູນຄ່າລົບຕົ້ນທຶນ, ເຮັດໃຫ້ຖືກຕ້ອງ
- [ປີຊີວິດທີ່ໄດ້ເພີ່ມ (LYG)](locales/en-gb-oxendict/topics/life-years-gained/) — ເລກການລອດຊີວິດ, ແລະ ຮຸ່ນຄວາມເທົ່າທຽມ evLYG
- [ອາຍຸຂັ້ຍທີ່ປັບດ້ວຍສຸຂະພາບ (HALE)](locales/en-gb-oxendict/topics/health-adjusted-life-expectancy/) — ການບັນຊີປີສຸຂະພາບດີລະດັບປະຊາກອນ
- [ຊ່ອງຫວ່າງ QALY ແລະ ຕົວປັບຄວາມຮຸນແຮງ](locales/en-gb-oxendict/topics/qaly-shortfall-and-severity-modifiers/) — ເປັນຫຍັງ QALY ຂອງປະຊາກອນທີ່ເຈັບປ່ວຍກວ່າຈຶ່ງນັບຫຼາຍກວ່າ
- [ຜະລິດຕະພາບການເຮັດວຽກ ແລະ ຄວາມບົກພ່ອງຂອງກິດຈະກຳ (WPAI)](locales/en-gb-oxendict/topics/work-productivity-and-activity-impairment/) — ການຂາດງານ ທຽບກັບ presenteeism, ເຄິ່ງທີ່ເຊື່ອງຢູ່ຂອງຕົ້ນທຶນ

## ປະເພດການວິເຄາະທາງເສດຖະກິດ

- [ການວິເຄາະຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ (CEA)](locales/en-gb-oxendict/topics/cost-effectiveness-analysis/) — ຕົ້ນທຶນຕໍ່ຫົວໜ່ວຍທຳມະຊາດຂອງຜົນລັບ
- [ການວິເຄາະຕົ້ນທຶນ-ອຣະຖະປະໂຫຍດ (CUA)](locales/en-gb-oxendict/topics/cost-utility-analysis/) — ຕົ້ນທຶນຕໍ່ QALY; ປຽບທຽບການແຊກແຊງທີ່ບໍ່ຄືກັນ
- [ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດ (CBA)](locales/en-gb-oxendict/topics/cost-benefit-analysis/) — ທຸກຢ່າງເປັນເງິນ; NPV ຂອງ Green Book
- [ການວິເຄາະຕົ້ນທຶນຕ່ຳສຸດ (CMA)](locales/en-gb-oxendict/topics/cost-minimization-analysis/) — ທາງເລືອກຖືກທີ່ສຸດ, ຫຼັງພິສູດຄວາມເທົ່າທຽມ
- [ການວິເຄາະຕົ້ນທຶນ-ຜົນທີ່ຕາມມາ (CCA)](locales/en-gb-oxendict/topics/cost-consequence-analysis/) — ຕາຕະລາງແຍກສ່ວນ; ຄວາມມັກຂອງ NICE ສຳລັບສຸຂະພາບດິຈິຕອນ
- [ການວິເຄາະຜົນກະທົບຕໍ່ງົບປະມານ (BIA)](locales/en-gb-oxendict/topics/budget-impact-analysis/) — ຄວາມສາມາດໃນການຈ່າຍ, ແຕກຕ່າງຈາກມູນຄ່າ
- [ຜົນຕອບແທນຈາກການລົງທຶນ (ROI)](locales/en-gb-oxendict/topics/return-on-investment/) — ຕົວຊີ້ວັດຮ່ວມ, ພ້ອມພາຣາມິເຕີທີ່ປະກາດ
- [ຜົນຕອບແທນທາງສັງຄົມຈາກການລົງທຶນ (SROI)](locales/en-gb-oxendict/topics/social-return-on-investment/) — ແປງສິ່ງທີ່ຕະຫຼາດບໍ່ຕັ້ງລາຄາເປັນເງິນ
- [ການປຽບທຽບ ICER ຂ້າມສະກຸນເງິນ](locales/en-gb-oxendict/topics/cross-currency-icer-comparison/) — PPP ທຽບກັບ FX ຕະຫຼາດ; ການເລືອກການແປງທີ່ສາມາດພິກການຕັດສິນໃຈຮັບເອົາ

## ເສດຖະສາດການດຳເນີນງານຂອງລະບົບສຸຂະພາບ

- [ວັນນອນໂຮງໝໍທີ່ປະຢັດໄດ້](locales/en-gb-oxendict/topics/bed-days-saved/) — ຜົນປະໂຫຍດຫຼັກ, ແລະ ກັບດັກການປະເມີນມູນຄ່າ
- [ໄລຍະເວລານອນໂຮງໝໍ (LOS)](locales/en-gb-oxendict/topics/length-of-stay/) — ເວລາວົງຈອນຂອງໂຮງໝໍ
- [ອັດຕາການກັບມານອນຊ້ຳ](locales/en-gb-oxendict/topics/readmission-rate/) — ອັດຕາຄວາມລົ້ມເຫຼວຂອງການປ່ຽນແປງຂອງລະບົບສຸຂະພາບ
- [ອັດຕາການບໍ່ມາຕາມນັດ (DNA)](locales/en-gb-oxendict/topics/did-not-attend-rate/) — ນັດທີ່ພາດ; ຕົວຊີ້ວັດຂອງເສຍເປົ່າທີ່ບໍລິສຸດທີ່ສຸດ
- [ການຫຼີກລ່ຽງການມາຫ້ອງສຸກເສີນ](locales/en-gb-oxendict/topics/emergency-attendance-avoidance/) — ເສດຖະສາດການແຊກແຊງຕົ້ນນ້ຳ

## ກອບ HTA ແລະ ເສດຖະສາດການປ້ອງກັນ

- [ການປະເມີນເຕັກໂນໂລຢີສຸຂະພາບ (HTA)](locales/en-gb-oxendict/topics/health-technology-assessment/) — NICE, ICER (ສະຫະລັດ), CADTH: ໃຜຕັດສິນວ່າຄຸ້ມຄ່າທີ່ຈະຊື້ຫຍັງ

- [ກອບມາດຕະຖານຫຼັກຖານຂອງ NICE (ESF)](locales/en-gb-oxendict/topics/nice-evidence-standards-framework/) — ຄວາມຕ້ອງການຫຼັກຖານແບບແບ່ງລະດັບຕາມຄວາມສ່ຽງສຳລັບສຸຂະພາບດິຈິຕອນ
- [ເສັ້ນທາງລັດ DiGA ຂອງເຢຍລະມັນ](locales/en-gb-oxendict/topics/diga-fast-track/) — ແອັບຕາມໃບສັ່ງແພດ; ການຂຶ້ນບັນຊີຊົ່ວຄາວພ້ອມກຳນົດເວລາຫຼັກຖານ
- [ຈຳນວນທີ່ຕ້ອງຮັກສາ (NNT)](locales/en-gb-oxendict/topics/number-needed-to-treat/) — ຫົວໜ່ວຍຄວາມພະຍາຍາມຕໍ່ຜົນປະໂຫຍດທີ່ຮັກສາການອ້າງໃຫ້ຊື່ສັດ
- [ສ່ວນທີ່ຖືກຖືວ່າເກີດຈາກປັດໄຈໃນປະຊາກອນ (PAF)](locales/en-gb-oxendict/topics/population-attributable-fraction/) — ພາລະພະຍາດເທົ່າໃດທີ່ປັດໄຈສ່ຽງຄຸ້ມຄ່າທີ່ຈະໄລ່ຕາມແທ້
- [ເສດຖະສາດການປ້ອງກັນ](locales/en-gb-oxendict/topics/prevention-economics/) — ເປັນຫຍັງການປ້ອງກັນຄຸ້ມຄ່າດ້ານຕົ້ນທຶນແຕ່ບໍ່ຄ່ອຍປະຢັດຕົ້ນທຶນ
- [ເສດຖະສາດການຄັດກອງ](locales/en-gb-oxendict/topics/screening-economics/) — Wilson–Jungner, PPV ລົ້ມທີ່ຄວາມຊຸກຊຸມຕ່ຳ, ຄວາມເມື່ອຍລ້າຈາກການແຈ້ງເຕືອນ
- [ຈຳນວນທີ່ຕ້ອງຄັດກອງ (NNS)](locales/en-gb-oxendict/topics/number-needed-to-screen/) — ຕົວທຽບເທົ່າລະດັບໂຄງການຄັດກອງຂອງ NNT
- [ຕົ້ນທຶນຕໍ່ເນື່ອງທີ່ຫຼີກລ່ຽງໄດ້](locales/en-gb-oxendict/topics/avoided-downstream-costs/) — ການຫັກລົບຕົ້ນທຶນ ແລະ ກົດທີ່ເຮັດໃຫ້ມັນໜ້າເຊື່ອຖື
- [ການວິເຄາະການຕັດສິນໃຈຫຼາຍເກນ (MCDA)](locales/en-gb-oxendict/topics/multi-criteria-decision-analysis/) — ການໃຫ້ຄະແນນຖ່ວງນ້ຳໜັກເມື່ອເກນດຽວບໍ່ພໍ
