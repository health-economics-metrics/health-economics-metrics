# ຜົນຕອບແທນຈາກການລົງທຶນ (ROI)

ROI ແມ່ນອັດຕາສ່ວນຂອງກຳໄລສຸດທິຕໍ່ເງິນທີ່ລົງທຶນ. ມັນເປັນຕົວຊີ້ວັດທີ່ວິສະວະກຳ ແລະ ການເງິນໃຊ້ຮ່ວມກັນແລ້ວ — ເສດຖະສາດສຸຂະພາບເພີ່ມວິໄນທີ່ເຮັດໃຫ້ການອ້າງ ROI ທົນຕໍ່ການກວດສອບ: ມຸມມອງທີ່ປະກາດ, ຕົວປຽບທຽບ, ຂອບເຂດເວລາ ແລະ ປະເພດຜົນປະໂຫຍດ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ROI ແມ່ນພາສາກາງຂອງຜູ້ຖືງົບ, ແລະ ສາທາລະນະສຸກກໍໃຊ້ມັນ: ການທົບທວນຂອງ Masters et al. ພົບ **ROI ມັດທະຍະຖານ 14.3:1** ສຳລັບການແຊກແຊງສາທາລະນະສຸກ (ທຸກ £1 ສົ່ງຄືນ ~£14 ໃຫ້ເສດຖະກິດກວ້າງ ແລະ ລະບົບສຸຂະພາບ) — ຕົວເລກທີ່ໃຊ້ຢ່າງກວ້າງຂວາງເພື່ອໂຕ້ແຍ້ງການໃຊ້ຈ່າຍດ້ານການປ້ອງກັນ. ແຕ່ 14:1 ນັ້ນແມ່ນຕົວເລກ *ມຸມມອງສັງຄົມ, ຂອບເຂດເວລາຍາວ*; ROI ຂອງ CFO ໂຮງໝໍແມ່ນມຸມມອງຜູ້ຈ່າຍເງິນ ແລະ 1–3 ປີ. ການຕໍ່ສູ້ເລື່ອງ ROI ສ່ວນໃຫຍ່ແທ້ຈິງແລ້ວແມ່ນການຕໍ່ສູ້ມຸມມອງທີ່ບໍ່ໄດ້ປະກາດ.

## ຄະນິດສາດ

```
ROI = (Benefits − Costs) / Costs      (often × 100%)

Payback period = Costs / annual net benefit
```

ການອ້າງ ROI ບໍ່ສົມບູນຖ້າບໍ່ມີສີ່ການປະກາດ:

1. **ມຸມມອງ** — ຜົນປະໂຫຍດຂອງໃຜນັບ? (ເບິ່ງ [ມຸມມອງຂອງການວິເຄາະ](../ມຸມມອງຂອງການວິເຄາະ/))
2. **ຕົວປຽບທຽບ** — ທຽບກັບທາງເລືອກໃດ? (ເບິ່ງ [ຕົ້ນທຶນຄວາມເສຍໂອກາດ](../ຕົ້ນທຶນຄວາມເສຍໂອກາດ/))
3. **ຂອບເຂດເວລາ** — ເປັນເວລາດົນປານໃດ, ແລະ [ຫຼຸດມູນຄ່າ](../ການຫຼຸດມູນຄ່າ-ແລະ-ຄວາມມັກດ້ານເວລາ/) ບໍ?
4. **ຊັ້ນຜົນປະໂຫຍດ** — ປົດປ່ອຍເງິນສົດ, ຄວາມຈຸ, ຫຼື ເປັນຄຸນນະພາບ? (ເບິ່ງ [ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດ ທຽບກັບ ທີ່ບໍ່ປົດປ່ອຍເງິນສົດ](../ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດ-ທຽບກັບ-ທີ່ບໍ່ປົດປ່ອຍເງິນສົດ/))

## ຕົວຢ່າງການຄິດໄລ່

ລະບົບຈັດຕາຕະລາງພະນັກງານເອເລັກໂຕຣນິກ, ຕົ້ນທຶນ £500,000 ໃນ 3 ປີ.

```
Cash-releasing:  agency shift reduction        £450,000
Capacity:        ward-manager admin time freed £600,000 (valued, not banked)
Qualitative:     staff satisfaction, safety    not monetized

Strict financial ROI  = (450,000 − 500,000)/500,000 = −10%
Economic ROI          = (1,050,000 − 500,000)/500,000 = +110%
```

ທັງສອງຕົວເລກເປັນຈິງ. ຜູ້ຂາຍທີ່ອ້າງ "ROI +110%" ໃຫ້ CFO ທີ່ເກັບເງິນໄດ້ພຽງ £450k ຈະເສຍຄວາມໄວ້ວາງໃຈ; ການນຳສະເໜີທັງສອງພ້ອມປ້າຍຊະນະມັນ. ການແຍກດຽວກັນປົກປ້ອງຜູ້ສະໜັບສະໜູນພາຍໃນເມື່ອການເງິນກວດສອບຜົນປະໂຫຍດສອງປີຕໍ່ມາ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ທຸກຂໍ້ສະເໜີເຄື່ອງມືມີສະໄລດ໌ ROI; ເກືອບບໍ່ມີອັນໃດປະກາດສີ່ພາຣາມິເຕີ. ຄວາມລົ້ມເຫຼວທົ່ວໄປທີ່ສຸດແມ່ນການປະສົມໝວດ: ຜົນໄດ້ຄວາມຈຸ (ນາທີນັກພັດທະນາ) ທີ່ນຳສະເໜີເປັນຜົນຕອບແທນທາງການເງິນ. ຈັດໂຄງສ້າງ ROI ຂອງ AI/ແພລດຟອມຕາມຕົວຢ່າງການຄິດໄລ່ຂ້າງເທິງ — ເສັ້ນເງິນສົດ, ເສັ້ນຄວາມຈຸ, ເສັ້ນຄຸນນະພາບ — ແລະ ເພີ່ມ [ການວິເຄາະຄວາມອ່ອນໄຫວ](../ການວິເຄາະຄວາມອ່ອນໄຫວ/) ກັບຕົວເລກອ່ອນ. ສຳລັບການກວດຄວາມເປັນຈິງ P&L ຂອງ ROI ຂອງ AI ໂດຍສະເພາະ, ເບິ່ງ [ຜົນຕອບແທນຈາກການລົງທຶນໃນ AI](../ຜົນຕອບແທນຈາກການລົງທຶນໃນ-ai/).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການຟອກມຸມມອງ**: ຜົນປະໂຫຍດສັງຄົມໃນໜຶ່ງທົດສະວັດທີ່ອ້າງໃຫ້ຜູ້ຖືງົບທີ່ມີຂອບເຂດ 12 ເດືອນ.
- **ລວມແທນສຸດທິ**: "ສົ່ງຄືນ £3M" ຈາກການໃຊ້ຈ່າຍ £2M ແມ່ນ ROI 50%, ບໍ່ແມ່ນ 300%.
- **ການເພີ່ມອັດຕາສ່ວນໃຫ້ສູງສຸດ**: ຕົວຫານນ້ອຍໃຫ້ ROI ມະຫັດສະຈັນກັບການລົງທຶນເລັກນ້ອຍ; ຈັດອັນດັບພອດໂຟລິໂອດ້ວຍ NPV ຫຼື [ຜົນປະໂຫຍດເປັນເງິນສຸດທິ](../ຜົນປະໂຫຍດເປັນເງິນສຸດທິ/), ໃຊ້ ROI ເປັນຕົວກັ່ນຕອງ.
- **ບໍ່ມີການກວດສອບຜົນປະໂຫຍດ**: ROI ພະຍາກອນໂດຍບໍ່ມີການຕິດຕາມ [ການເຮັດໃຫ້ຜົນປະໂຫຍດເກີດຂຶ້ນຈິງ](../ການເຮັດໃຫ້ຜົນປະໂຫຍດເກີດຂຶ້ນຈິງ/) ແມ່ນຄຳສັນຍາ, ບໍ່ແມ່ນຜົນ.
