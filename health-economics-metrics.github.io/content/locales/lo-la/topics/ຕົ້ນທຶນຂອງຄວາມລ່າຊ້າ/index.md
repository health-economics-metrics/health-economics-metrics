# ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ (CoD)

ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ (Cost of Delay) ແມ່ນມູນຄ່າທາງເສດຖະກິດທີ່ສູນເສຍຕໍ່ຫົວໜ່ວຍເວລາທີ່ຄຸນສົມບັດ, ຜະລິດຕະພັນ, ຫຼື ບໍລິການ *ບໍ່*ໄດ້ຖືກສົ່ງມອບ. ມັນເປັນຂົວເຊື່ອມທີ່ແຂງແຮງທີ່ສຸດລະຫວ່າງຕົວຊີ້ວັດການສົ່ງມອບຊອບແວ ແລະ ເສດຖະສາດສຸຂະພາບ: ມັນແປງ "ພວກເຮົາສົ່ງຊ້າ" ເປັນເງິນຕາ — ຫຼື ເປັນ QALY.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ກົດຂອງ Reinertsen: "ຖ້າທ່ານຈະວັດປະລິມານສິ່ງດຽວ ໃຫ້ວັດປະລິມານຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ." ອົງກອນສ່ວນໃຫຍ່ຮູ້ວ່າໂຄງການມີຕົ້ນທຶນເທົ່າໃດ ແຕ່ບໍ່ຮູ້ວ່າຄວາມລ່າຊ້າໜຶ່ງເດືອນມີຕົ້ນທຶນເທົ່າໃດ ຈຶ່ງປັບງົບປະມານໃຫ້ດີ ໃນຂະນະທີ່ເລືອດໄຫຼອອກຈາກມູນຄ່າເວລາ. ສຳລັບຊອບແວສຸຂະພາບ ສິ່ງທີ່ມີຄວາມສ່ຽງເປັນຕົວຈິງ: ທຸກອາທິດທີ່ການປັບປຸງເສັ້ນທາງຖືກເລື່ອນ ຄົນເຈັບລໍຖ້າດົນຂຶ້ນໃນສະພາບສຸຂະພາບທີ່ແຍ່ກວ່າ. CoD ແມ່ນກອບຄະນິດສາດທີ່ແຂງແຮງທີ່ສຸດທີ່ຈະນຳສະເໜີຕໍ່ຜູ້ມີສ່ວນໄດ້ເສຍຂອງ NHS ເພາະມັນຕີລາຄາ*ການຂາດຫາຍ*ຂອງຊອບແວຂອງທ່ານ.

## ຄະນິດສາດ

```
CoD = benefit per unit time forgone while undelivered   (£/week or QALYs/week)

Total delay loss = CoD × delay duration

For prioritization, see wsjf-and-cd3.md: CD3 = CoD / duration.
```

ສຳລັບຊອບແວທາງຄລີນິກ ໃຫ້ກຳນົດເປັນສຸຂະພາບພ້ອມທັງເງິນ:

```
CoD_health = patients affected per week × QALY gain per patient
CoD_money  = CoD_health × λ (willingness-to-pay threshold, £20k–30k/QALY)
             + operational savings per week forgone
```

## ຕົວຢ່າງການຄິດໄລ່

**ດ້ານການດຳເນີນງານ**: ຊອບແວປະຢັດ £200 ຕໍ່ຄົນເຈັບໃນເສັ້ນທາງໜຶ່ງ; ໂຮງໝໍ trust ປະມວນຜົນຄົນເຈັບດັ່ງກ່າວ 50 ຄົນ/ອາທິດ.

```
CoD = 200 × 50 = £10,000/week
A 10-week procurement delay costs 200 × 50 × 10 = £100,000 in avoidable waste.
```

**ດ້ານຄລີນິກ**: ການປັບປຸງການຄັດແຍກລົບເວລາລໍຖ້າ 5 ອາທິດ (ອຣະຖະປະໂຫຍດ 0.68 → 0.80 ໄວຂຶ້ນ) ສຳລັບຄົນເຈັບ 100 ຄົນ/ອາທິດ:

```
QALY gain per patient = (5/52) × 0.12 ≈ 0.0115
CoD_health = 100 × 0.0115 = 1.15 QALYs/week
CoD_money  = 1.15 × £20,000 ≈ £23,000/week of health value
```

ຄວາມລ່າຊ້າໃນການນຳໃຊ້ 6 ເດືອນ "ມີຕົ້ນທຶນ" ~30 QALY — ຂໍ້ໂຕ້ແຍ້ງທີ່ປັບກອບການເລື່ອນເປີດໃຊ້ IT ໃຫ້ເປັນເຫດການທາງຄລີນິກ. (ເກນທຽບຂະໜາດ: ການວິເຄາະ Maersk ທີ່ມີຊື່ສຽງຂອງ Black Swan Farming ພົບຄຸນສົມບັດດຽວທີ່ມີ CoD ≈ $200k/ອາທິດ ທີ່ລໍຖ້າມາ 38 ອາທິດ.)

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

CoD ແມ່ນຕົວຊີ້ວັດທີ່ເຮັດໃຫ້[ເວລານຳ DORA](../ຕົວຊີ້ວັດ-dora/)ແລະ[ປະສິດທິພາບການໄຫຼ](../ຕົວຊີ້ວັດການໄຫຼ/)ການເງິນອ່ານອອກ: ເວລານຳ × CoD = ເງິນ (ຫຼື ສຸຂະພາບ) ທີ່ເຜົາໄໝ້ໃນຄິວ. ການນຳໃຊ້:

- **ການຈັດບູລິມະສິດ**: ຈັດອັນດັບວຽກຕາມ CoD/ໄລຍະເວລາ ([WSJF/CD3](../wsjf-ແລະ-cd3/)) ແທນຜູ້ມີສ່ວນໄດ້ເສຍທີ່ສຽງດັງທີ່ສຸດ.
- **ເສດຖະສາດຂອງຂະບວນການ**: ຈັງຫວະປ່ອຍທຸກ 2 ອາທິດມີຕົ້ນທຶນຄວາມລ່າຊ້າທີ່ຄາດໄວ້ ~1 ອາທິດ × CoD ຕໍ່ຄຸນສົມບັດ ທຽບກັບການສົ່ງມອບຢ່າງຕໍ່ເນື່ອງ — ຕີລາຄາຊຸດ.
- **ການຈັດຊື້**: ວົງຈອນການຈັດຊື້ NHS 6–18 ເດືອນມີ CoD; ການສະແດງມັນປ່ຽນການສົນທະນາເລື່ອງຄວາມເລັ່ງດ່ວນ (ເບິ່ງ[ການວິເຄາະຜົນກະທົບຕໍ່ງົບປະມານ](../ການວິເຄາະຜົນກະທົບຕໍ່ງົບປະມານ/) ສຳລັບສ່ວນທີ່ກົງກັນຂ້າມດ້ານຄວາມສາມາດໃນການຈ່າຍ).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ສົມມຸດ CoD ເປັນເສັ້ນຊື່**: ບາງວຽກມີຄຸນຄ່າຮູບກຳນົດເວລາ (ວັນທີກົດລະບຽບ — CoD ບໍ່ມີຂີດຈຳກັດຫຼັງວັນທີ, ສູນກ່ອນ) ຫຼື ຄຸນຄ່າເສື່ອມ (ໜ້າຕ່າງຜູ້ມາກ່ອນ). ຈັດປະເພດໂປຣໄຟລ໌ຄວາມເລັ່ງດ່ວນກ່ອນຄູນ.
- **CoD ຂອງຜົນຜະລິດທີ່ບໍ່ມີໃຜຕ້ອງການ**: ຄວາມລ່າຊ້າມີຕົ້ນທຶນສະເພາະເມື່ອສິ່ງນັ້ນມີຄຸນຄ່າ; ຂີ້ເຫຍື້ອທີ່ລ່າຊ້າແມ່ນຟຣີ.
- **ນັບຊ້ຳຄວາມລ່າຊ້າແລະການຫຼຸດມູນຄ່າ**: [ການຫຼຸດມູນຄ່າ](../ການຫຼຸດມູນຄ່າ-ແລະ-ຄວາມມັກດ້ານເວລາ/)ຕີລາຄາເວລາໃນຂອບເຂດຫຼາຍປີຢູ່ແລ້ວ; CoD ແມ່ນສະບັບດຳເນີນງານພາຍໃນຂອບເຂດ. ໃຊ້ CoD ສຳລັບອາທິດ/ເດືອນ, ການເລື່ອນ NPV ສຳລັບປີ.
