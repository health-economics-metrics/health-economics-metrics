# ຂອບເຂດເວລາ

ຂອບເຂດເວລາແມ່ນໄລຍະທີ່ການວິເຄາະນັບຕົ້ນທຶນ ແລະ ຜົນ. ມັນຕ້ອງຍາວພໍທີ່ຈະຈັບຄວາມແຕກຕ່າງທີ່ມີຄວາມໝາຍທັງໝົດລະຫວ່າງທາງເລືອກທີ່ປຽບທຽບ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ເລືອກຂອບເຂດສັ້ນ ແລ້ວທ່ານພາດປະໂຫຍດຊ້າ (ການປ້ອງກັນ) ແລະ ຕົ້ນທຶນຊ້າ (ການບຳລຸງຮັກສາ). ເລືອກຂອບເຂດຍາວເກີນໄປ ແລ້ວທຸກຢ່າງຈົມໃນຄວາມບໍ່ແນ່ນອນ. ການປະເມີນເຕັກໂນໂລຢີສຸຂະພາບມັກໃຊ້ຂອບເຂດ **ຕະຫຼອດຊີວິດ** ສຳລັບການຮັກສາທີ່ມີຜົນຕໍ່ອັດຕາການຕາຍ; [ການວິເຄາະຜົນກະທົບຕໍ່ງົບປະມານ](../ການວິເຄາະຜົນກະທົບຕໍ່ງົບປະມານ/) ໃຊ້ຂອບເຂດ **1–5 ປີ** ສັ້ນໂດຍເຈດຕະນາ ເພາະຄຳຖາມຂອງມັນແມ່ນຄວາມສາມາດໃນການຈ່າຍ, ບໍ່ແມ່ນມູນຄ່າ. ຂອບເຂດເປັນທາງເລືອກການສ້າງແບບຈຳລອງທີ່ປະກາດ, ແລະ ຂອບເຂດທີ່ບໍ່ກົງກັນແມ່ນວິທີຄລາສສິກຂອງການຫຼິ້ນກົນການປຽບທຽບ.

## ຄະນິດສາດ

ຂອບເຂດແມ່ນຂີດຈຳກັດເທິງຂອງຜົນລວມໃນທຸກການວິເຄາະ:

```
Net present value = Σ (t = 0 … T) [ (Benefits_t − Costs_t) / (1 + r)^t ]

T = time horizon (years)
r = discount rate (see discounting-and-time-preference.md)
```

ຄວນລາຍງານຜົນພ້ອມລະບຸຂອບເຂດ, ແລະ ດີທີ່ສຸດສະແດງຢູ່ຫຼາຍຂອບເຂດ.

## ຕົວຢ່າງການຄິດໄລ່

ລະບົບສັ່ງຢາເອເລັກໂຕຣນິກມີຕົ້ນທຶນການນຳໃຊ້ £2 ລ້ານ ແລະ £200,000/ປີເພື່ອດຳເນີນງານ. ມັນປ້ອງກັນຄວາມຜິດພາດຢາທີ່ມີຄ່າ £600,000/ປີ (ຕົ້ນທຶນການຮັກສາຂອງອັນຕະລາຍທີ່ຫຼີກລ່ຽງໄດ້).

ຜົນປະໂຫຍດສຸດທິຕາມຂອບເຂດ (ບໍ່ຫຼຸດມູນຄ່າ, ເພື່ອຄວາມຊັດເຈນ):

```
Horizon 1 year:  −2,000,000 − 200,000 + 600,000  = −£1,600,000
Horizon 3 years: −2,000,000 + 3 × 400,000        = −£800,000
Horizon 5 years: −2,000,000 + 5 × 400,000        =  £0
Horizon 10 years:−2,000,000 + 10 × 400,000       = +£2,000,000
```

ລະບົບ "ລົ້ມເຫຼວ" ທີ່ຂອບເຂດໃດກໍຕາມຕ່ຳກວ່າ 5 ປີ ແລະ "ສຳເລັດ" ທີ່ 10. ບໍ່ມີອັນໃດແມ່ນຄຳຕອບແທ້; ລາຍງານທີ່ຊື່ສັດລະບຸຈຸດຄຸ້ມທຶນ ແລະ ໃຫ້ເຫດຜົນຂອບເຂດດ້ວຍອາຍຸຂອງລະບົບ (ດົນປານໃດກ່ອນທົດແທນ?).

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

- **ການປະເມີນເຄື່ອງມືທີ່ວັດຕະຫຼອດໜຶ່ງ sprint** ພາດການຕົກຂອງເສັ້ນໂຄ້ງການຮຽນຮູ້ຢ່າງເປັນລະບົບ (ຕົ້ນທຶນຢູ່ໜ້າ) ແລະ ການບຳລຸງຮັກສາໄລຍະຍາວ (ຕົ້ນທຶນຢູ່ຫຼັງ). ໂຄງການນຳຮ່ອງຜູ້ຊ່ວຍຂຽນໂຄ້ດ AI ທີ່ວັດໃນອາທິດທີ 2 ຈັບຈຸດສູງສຸດຂອງຄວາມໃໝ່, ບໍ່ແມ່ນສະຖານະຄົງທີ່.
- **ຄວາມຍາວສັນຍາ ≠ ຂອບເຂດປະໂຫຍດ.** ສັນຍາ SaaS 1 ປີຍັງສາມາດປະເມີນໃນ 5 ປີຖ້າທ່ານຄາດຕໍ່ສັນຍາຢ່າງສົມເຫດສົມຜົນ — ແຕ່ຕ້ອງເວົ້າ.
- **ກໍລະນີທົດແທນລະບົບເກົ່າ** ຄວນຣັນຈົນເຖິງຈຸດສິ້ນສຸດອາຍຸທີ່ເຊື່ອຖືໄດ້ຂອງລະບົບເກົ່າ, ບໍ່ແມ່ນເລກກົມຕາມໃຈ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການເລືອກຂອບເຂດຕາມໃຈ**: ເລືອກຂອບເຂດໃດທີ່ເຮັດໃຫ້ທາງເລືອກຂອງທ່ານຊະນະ. ລົງທະບຽນຂອບເຂດລ່ວງໜ້າກ່ອນຄິດໄລ່ຜົນ.
- **ຂອບເຂດຕ່າງກັນສຳລັບທາງເລືອກຕ່າງກັນ** ໃນການປຽບທຽບດຽວກັນ.
- **ຂອບເຂດຕະຫຼອດຊີວິດໂດຍບໍ່ຫຼຸດມູນຄ່າ ຫຼື ວິເຄາະຄວາມບໍ່ແນ່ນອນ** — ປະໂຫຍດປີທີ 30 ທີ່ມູນຄ່າໜ້າຕາແມ່ນນິຍາຍ. ຈັບຄູ່ຂອບເຂດຍາວກັບ [ການວິເຄາະຄວາມອ່ອນໄຫວ](../ການວິເຄາະຄວາມອ່ອນໄຫວ/).
