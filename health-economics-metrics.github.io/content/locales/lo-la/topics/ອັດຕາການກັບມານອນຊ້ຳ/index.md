# ອັດຕາການກັບມານອນຊ້ຳ

ອັດຕາການກັບມານອນຊ້ຳພາຍໃນ 30 ວັນແມ່ນເປີເຊັນຂອງຜູ້ປ່ວຍທີ່ອອກໂຮງໝໍແລ້ວກັບມາແບບສຸກເສີນພາຍໃນ 30 ວັນ. ມັນເປັນຕົວຊີ້ວັດ *ຄຸນນະພາບຂອງການອອກໂຮງໝໍ* ມາດຕະຖານຂອງລະບົບສຸຂະພາບ — ແລະ ມີບົດລົງໂທດດ້ານການເງິນໂດຍກົງ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ການກັບມານອນຊ້ຳໝາຍຄວາມວ່າການອອກຄັ້ງທຳອິດບໍ່ຢູ່: ອອກກ່ອນເວລາ, ການສົ່ງຕໍ່ຢາລົ້ມເຫຼວ, ບໍ່ມີການຕິດຕາມ, ຫຼື ຂາດການສະໜັບສະໜູນທາງສັງຄົມ. ຜູ້ຈ່າຍເງິນລົງໂທດມັນຢ່າງຊັດເຈນ — ໂຄງການ Hospital Readmissions Reduction Program ຂອງສະຫະລັດຫັກເຖິງ 3% ຂອງການຈ່າຍ Medicare ຂອງໂຮງໝໍ; NHS ໃນອະດີດບໍ່ຈ່າຍສຳລັບການກັບມານອນສຸກເສີນພາຍໃນ 30 ວັນທີ່ຫຼີກລ່ຽງໄດ້. ດັ່ງນັ້ນການຫຼີກລ່ຽງການກັບມານອນຊ້ຳແມ່ນໜຶ່ງໃນປະເພດຜົນປະໂຫຍດໜ້ອຍອັນທີ່ກ່ຽວຂ້ອງກັບເງິນສົດ *ໂດຍກົງ* ສຳລັບຜູ້ໃຫ້ບໍລິການ, ບໍ່ແມ່ນພຽງຄວາມຈຸ.

## ຄະນິດສາດ

```
Readmission rate = emergency readmissions within 30 days / index discharges × 100

Risk-standardized comparisons adjust for case mix; penalty programmes
compare observed vs expected for like hospitals.

Value of avoidance = avoided readmissions × (cost per readmission spell
                     + penalty exposure per readmission)
```

## ຕົວຢ່າງການຄິດໄລ່

ແອັບສະໜັບສະໜູນການອອກໂຮງໝໍສຳລັບຫົວໃຈລົ້ມເຫຼວ (ຕິດຕາມອາການ, ເຕືອນນ້ຳໜັກ, ເຕືອນຢາ, ສົ່ງຕໍ່ພະຍາບານ): 2,000 ການອອກ/ປີ, ອັດຕາການກັບມານອນຊ້ຳພື້ນຖານ 18%, ການທົດລອງສະແດງ 14% ດ້ວຍແອັບ.

```
Avoided readmissions = 2,000 × (0.18 − 0.14) = 80/year
Cost per readmission spell ≈ £3,500 → £280,000/year avoided treatment cost
Plus penalty/non-payment exposure on those spells.
App cost: 2,000 × £60 = £120,000/year

Net ≈ +£160,000/year, before any QALY claim for avoided deterioration.
```

ຕົວເລກທີ່ຕ້ອງປົກປ້ອງແມ່ນຜົນ 4 ຈຸດເປີເຊັນ: ມັນຕ້ອງມາຈາກການປຽບທຽບທີ່ຄວບຄຸມ, ເພາະອັດຕາການກັບມານອນຊ້ຳແກວ່ງຕາມ case mix ແລະ ລະດູການ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ການກັບມານອນຊ້ຳແມ່ນ **ອັດຕາຄວາມລົ້ມເຫຼວຂອງການປ່ຽນແປງ** ຂອງລະບົບສຸຂະພາບ (ເບິ່ງ [ຕົວຊີ້ວັດ DORA](../ຕົວຊີ້ວັດ-dora/)): ງານທີ່ "ສົ່ງມອບ" ແລ້ວເດັ້ງກັບພາຍໃນ 30 ວັນ. ການທຽບເທົ່າເລິກເຊິ່ງ — ປີ້ທີ່ເປີດຄືນ ແລະ ເຫດການຖອຍຫຼັງສະແດງ "ຄຸນນະພາບການອອກ" ທີ່ບໍ່ດີ (ການຢືນຢັນອ່ອນ, ປິດກ່ອນເວລາ, ຂາດເອກະສານສົ່ງຕໍ່); ການບັນຊີແບບລົງໂທດ (ທີມທີ່ແກ້ຈ່າຍ, ບໍ່ແມ່ນທີມທີ່ຮັບ) ປ່ຽນພຶດຕິກຳ; ແລະ ທັງສອງຂົງເຂດໄດ້ຮຽນບົດຮຽນດຽວກັນ ວ່າການຍູ້ throughput ດິບ (ອອກໄວຂຶ້ນ, ສົ່ງມອບໄວຂຶ້ນ) ໂດຍບໍ່ລົງທຶນໃນການສົ່ງຕໍ່ພຽງແຕ່ປ່ຽນຄິວທີ່ເຫັນເປັນງານແກ້ໄຂຄືນທີ່ເບິ່ງບໍ່ເຫັນ. "ອັດຕາການເປີດຄືນພາຍໃນ 30 ວັນ" ຄວນຢູ່ໃນແດຊບອດຂອງທີມໃດກໍຕາມທີ່ສະເຫຼີມສະຫຼອງເວລາວົງຈອນ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການຫຼິ້ນກົນດ້ວຍການຕິດປ້າຍໃໝ່**: ການກັບມານອນຊ້ຳທີ່ລະຫັດເປັນການພັກສັງເກດການ ຫຼື ສະພາບໃໝ່; ກວດສອບນິຍາມ.
- **ທຸກສາເຫດ ທຽບກັບ ສາເຫດທີ່ກ່ຽວຂ້ອງ**: ທຸກສາເຫດໃນ 30 ວັນລວມເຫດການທີ່ບໍ່ກ່ຽວຂ້ອງແທ້; ບົດລົງໂທດປົກກະຕິໃຊ້ທຸກສາເຫດກໍເພາະ "ກ່ຽວຂ້ອງ" ຫຼິ້ນກົນໄດ້.
- **ຕາບອດ case-mix**: ໂຮງໝໍທີ່ໃຫ້ບໍລິການປະຊາກອນທີ່ເຈັບປ່ວຍ ແລະ ທຸກຍາກກວ່າຮັບກັບຫຼາຍຂຶ້ນດ້ວຍເຫດຜົນທີ່ບໍ່ມີແອັບໃດແກ້ໄດ້ — ປັບຄວາມສ່ຽງກ່ອນປຽບທຽບ.
