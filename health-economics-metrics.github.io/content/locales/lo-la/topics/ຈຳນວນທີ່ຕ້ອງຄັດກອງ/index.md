# ຈຳນວນທີ່ຕ້ອງຄັດກອງ (NNS)

NNS ແມ່ນຈຳນວນຄົນທີ່ຕ້ອງຖືກຄັດກອງ — ບໍ່ແມ່ນພຽງແຕ່ຮັກສາ — ເພື່ອປ້ອງກັນຜົນລັບທາງລົບ **ໜຶ່ງ** ກໍລະນີ ໃນໄລຍະຕິດຕາມທີ່ກຳນົດ, ໂດຍຂຶ້ນກັບຄວາມສ່ຽງພື້ນຖານຂອງປະຊາກອນ ແລະ ການຫຼຸດຄວາມສ່ຽງສຳພັດທີ່ການກວດພົບແຕ່ເນີ່ນໆ ແລະ ການຮັກສາບັນລຸ. ມັນເປັນຄູ່ທຽບລະດັບໂຄງການຄັດກອງຂອງ NNT: NNT ຖາມວ່າຕ້ອງ *ຮັກສາ* ຈັກຄົນເພື່ອປ້ອງກັນໜຶ່ງຜົນລັບ; NNS ຖາມວ່າຕ້ອງໃຫ້ຈັກຄົນຜ່ານເສັ້ນທາງ *ຄັດກອງແລ້ວຮັກສາ* ທັງໝົດເພື່ອໄປເຖິງບ່ອນນັ້ນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

Rembold ແນະນຳ NNS ໃນປີ 1998 ໂດຍສະເພາະເພື່ອໃຫ້ໂຄງການຄັດກອງປຽບທຽບກັນໄດ້ຢູ່ພື້ນຖານດຽວກັບການຮັກສາ, ເພາະການຫຼຸດຄວາມສ່ຽງສຳພັດຫົວຂ່າວຂອງການທົດສອບຄັດກອງເຊື່ອງສອງຢ່າງທີ່ການຮັກສາບໍ່ເຊື່ອງ: ຄວາມສ່ຽງພື້ນຖານຂອງປະຊາກອນທີ່ຖືກເຊີນຄັດກອງຈິງ, ແລະ ຂໍ້ທີ່ວ່າທຸກຄົນທີ່ຖືກຄັດກອງແບກຕົ້ນທຶນຂອງການທົດສອບ ແລະ ພາລະຜົນບວກປອມ, ບໍ່ແມ່ນສະເພາະກຸ່ມນ້ອຍທີ່ໄດ້ປະໂຫຍດ. ປະຕູຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນຂອງຄະນະກຳມະການຄັດກອງແຫ່ງຊາດຂອງສະຫະລາຊະອານາຈັກ (ເບິ່ງ [ເສດຖະສາດການຄັດກອງ](../ເສດຖະສາດການຄັດກອງ/)) ຖືກສ້າງຕາມຄວາມແຕກຕ່າງນີ້ພໍດີ — ໂຄງການຄັດກອງທີ່ມີການຫຼຸດຄວາມສ່ຽງສຳພັດໜ້າປະທັບໃຈໃນປະຊາກອນທີ່ມີຄວາມສ່ຽງພື້ນຖານຕ່ຳ ຍັງອາດມີ NNS ເປັນຫຼາຍພັນ, ເມື່ອນັ້ນຕົ້ນທຶນໂຄງການຕໍ່ຜົນລັບທີ່ປ້ອງກັນໄດ້ກາຍເປັນຄຳຖາມແທ້.

## ຄະນິດສາດ

```
NNS = 1 / (baseline_risk × relative_risk_reduction)

baseline_risk           = probability of the outcome in the screened
                           population over the follow-up period (0–1)
relative_risk_reduction = proportional risk reduction achieved by
                           screening-enabled early treatment (0–1)

Program cost per outcome prevented = NNS × cost_per_screen
```

ປຽບທຽບໂດຍກົງກັບ [NNT](../ຈຳນວນທີ່ຕ້ອງຮັກສາ/): NNS ຮວມປະສິດທິຜົນຂອງທໍ່ຄັດກອງ → ວິນິດໄສ → ຮັກສາທັງໝົດເປັນຕົວເລກດຽວ, ໃນຂະນະທີ່ NNT ສົມມຸດແລ້ວວ່າຜູ້ປ່ວຍຖືກວິນິດໄສ ແລະ ເລີ່ມຮັກສາ.

## ຕົວຢ່າງການຄິດໄລ່

ປະຊາກອນເປົ້າໝາຍຂອງໂຄງການຄັດກອງມີຄວາມສ່ຽງເຫດການພື້ນຖານ 2% ຕະຫຼອດໄລຍະການສຶກສາ (`baseline_risk = 0.02`), ແລະ ການກວດພົບແຕ່ເນີ່ນໆບັນລຸການຫຼຸດຄວາມສ່ຽງສຳພັດ 25% (`relative_risk_reduction = 0.25`):

```
NNS = 1 / (0.02 × 0.25) = 1 / 0.005 = 200

200 people must be screened to prevent one outcome.

At £50 per screen:
Programme cost per outcome prevented = 200 × £50 = £10,000
```

ຕົວເລກ £10,000 ນັ້ນແມ່ນສິ່ງທີ່ຄວນຊັ່ງທຽບກັບຕົ້ນທຶນຂອງຜົນລັບເອງ ແລະ QALY ທີ່ມັນຈະເຮັດໃຫ້ສູນເສຍ — ການປຽບທຽບດຽວກັນທີ່ [ເສດຖະສາດການປ້ອງກັນ](../ເສດຖະສາດການປ້ອງກັນ/) ເຮັດສຳລັບໂຄງການປ້ອງກັນໂດຍທົ່ວໄປ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

NNS ແມ່ນ "ຈຳນວນຜູ້ໃຊ້, ເຫດການ ຫຼື ຄຳຮ້ອງຂໍທີ່ຕ້ອງຜ່ານການກວດພົບ ຫຼື ການຄັດແຍກເພື່ອຈັບໜຶ່ງຜົນບວກຈິງທີ່ຄຸ້ມຄ່າທີ່ຈະດຳເນີນການ" — ກ່ຽວຂ້ອງໂດຍກົງກັບການຕິດຕາມ ແລະ ລະບົບຄັດແຍກທີ່ອີງການແຈ້ງເຕືອນ, ບ່ອນທີ່ເງື່ອນໄຂເປົ້າໝາຍທີ່ມີຄວາມຊຸກຊຸມຕ່ຳເຮັດໃຫ້ NNS ພອງຕົວແບບດຽວກັບທີ່ມັນເຮັດໃຫ້ຄ່າທຳນາຍບວກລົ້ມລົງ (ເບິ່ງ [ເສດຖະສາດການຄັດກອງ](../ເສດຖະສາດການຄັດກອງ/) ແລະ [ການປະເມີນ AI ທາງຄລີນິກ](../ການປະເມີນ-ai-ທາງຄລີນິກ/)). ກົດການຕິດຕາມທີ່ຕ້ອງປະມວນຜົນ 200 ເຫດການຕໍ່ການຈັບຈິງໜຶ່ງຄັ້ງຄຸ້ມຄ່າທີ່ຈະຣັນກໍຕໍ່ເມື່ອການຈັບນັ້ນມີຄ່າຢ່າງໜ້ອຍ 200 ເທົ່າຂອງຕົ້ນທຶນຄັດແຍກຕໍ່ເຫດການ — ເລກຄະນິດດຽວກັນກັບຕົວຢ່າງດ້ານສຸຂະພາບຂ້າງເທິງ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ເມີນເສີຍການຂຶ້ນກັບຄວາມສ່ຽງພື້ນຖານ**: ການທົດສອບ ຫຼື ໂຄງການຄັດກອງດຽວກັນມີ NNS — ແລະ ຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ — ແຕກຕ່າງຫຼາຍໃນປະຊາກອນສ່ຽງສູງ ທຽບກັບສ່ຽງຕ່ຳ. ຢ່າອ້າງ NNS ໂດຍບໍ່ລະບຸປະຊາກອນທີ່ມັນຖືກຄິດໄລ່.
- **ນັບຕົວຫານຜິດ**: NNS ນັບຄົນທີ່ *ຖືກຄັດກອງ*, ບໍ່ແມ່ນຄົນທີ່ຜົນບວກ ຫຼື ເລີ່ມຮັກສາ — ມັນຝັງປະສິດທິຜົນຂອງທໍ່ທັງໝົດແລ້ວ, ຈຶ່ງບໍ່ຄວນປຽບທຽບກັບຕົວຊີ້ວັດທີ່ນັບສະເພາະຜົນບວກ.
- **ປຽບທຽບຂ້າມໄລຍະຕິດຕາມ**: ໄລຍະຕິດຕາມທີ່ສັ້ນກວ່າໂດຍທົ່ວໄປເຮັດໃຫ້ NNS ພອງຕົວ, ເພາະສັງເກດເຫດການໜ້ອຍກວ່າໃນໜ້າຕ່າງ. ຕົວເລກ NNS ປຽບທຽບກັນໄດ້ກໍຕໍ່ເມື່ອຄິດໄລ່ໃນໄລຍະຕິດຕາມດຽວກັນ.
