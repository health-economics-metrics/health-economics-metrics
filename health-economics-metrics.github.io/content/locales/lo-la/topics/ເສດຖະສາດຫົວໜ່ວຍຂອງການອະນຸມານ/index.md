# ເສດຖະສາດຫົວໜ່ວຍຂອງການອະນຸມານ (Inference)

ເສດຖະສາດຫົວໜ່ວຍຂອງການອະນຸມານຕັ້ງລາຄາຄຸນສົມບັດ AI ຕາມການຄິດໄລ່ສ່ວນເພີ່ມ: **ຕົ້ນທຶນຕໍ່ໂທເຄັນ**, ລວມເປັນຕົ້ນທຶນຕໍ່ທຸລະກຳ, ຕໍ່ຜູ້ໃຊ້, ຕໍ່ຕອນການຮັກສາທາງຄລີນິກ. ພະລະວັດທີ່ກຳນົດມັນ: ລາຄາ LLM ຫຼຸດລົງປະມານ **ໜຶ່ງລຳດັບຂະໜາດທຸກໆ 1–2 ປີ** ໃນຂີດຄວາມສາມາດຄົງທີ່ — ອັດຕາເງິນເຟີ້ຕ່ຳທີ່ບໍ່ເຄີຍມີມາກ່ອນໃນການຄິດຕົ້ນທຶນເຕັກໂນໂລຢີສຸຂະພາບ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ການລົ້ມລະລາຍຂອງລາຄານຳມາສອງຜົນຕາມມາ. ດ້ານການຄ້າ, ຄຸນສົມບັດ AI ທີ່ຢູ່ຂອບເຂດມື້ນີ້ອາດມີກຳໄລຢ່າງງ່າຍດາຍໃນ 18 ເດືອນ — ແລະ ຄູ່ແຂ່ງທີ່ຕັ້ງລາຄາຕາມຕົ້ນທຶນມື້ນີ້ຈະຖືກຕັດລາຄາ. ສຳລັບການປະເມີນເສດຖະກິດ, ແບບຈຳລອງຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນຂອງບໍລິການຄລີນິກທີ່ໃຊ້ AI ທີ່ແຊ່ແຂງລາຄາອະນຸມານປີ 2024 **ຄາດເກີນຕົ້ນທຶນຕໍ່ເນື່ອງຢ່າງມີນັຍສຳຄັນ** — ການວິເຄາະຕ້ອງມີສະຖານະການລາຄາຫຼຸດລົງ ຄືກັບທີ່ແບບຈຳລອງຢາຈັດການກັບສິດທິບັດໝົດອາຍຸ ແລະ ການເຂົ້າຂອງຢາສາມັນ. (ຈຸດອ້າງອີງຈາກການຄົ້ນຄວ້າ: ໂທເຄັນຜົນອອກຂອງແບບຊັ້ນນຳ ~$15–75/M ໃນກາງປີ 2026, ແບບຊັ້ນກາງຖືກກວ່າໜຶ່ງລຳດັບ, ຄວາມສາມາດລະດັບ GPT-4 ຫຼຸດຈາກ ~$20/M ໃນປີ 2022 ເປັນ ~$0.40/M; Epoch AI ວັດການຫຼຸດລົງ 9×–900×/ປີ ຂຶ້ນກັບຂີດໝາຍຄວາມສາມາດ.)

## ຄະນິດສາດ

```
Cost per call     = input tokens × input rate + output tokens × output rate
Cost per unit     = Σ calls per unit of business output (per triage episode,
                    per drafted letter, per consultation summary)

Blended reality   = base call + retries + RAG context (input-heavy)
                    + evaluation/guardrail calls (often 20–50% overhead)

Price-decline scenario for multi-year models:
  cost_t = cost_0 × d^t, test d ∈ {0.3, 0.5, 0.7}/year in sensitivity analysis
```

## ຕົວຢ່າງການຄິດໄລ່

ບໍລິການ AI ສະຫຼຸບການອອກໂຮງໝໍ: ສະຫຼຸບສະເລ່ຍໃຊ້ໂທເຄັນເຂົ້າ 12,000 (ບໍລິບົດບັນທຶກ) + ອອກ 1,200, ບວກຂັ້ນຕອນກວດສອບ (ເຂົ້າ 6,000 / ອອກ 300). ທີ່ $3/M ເຂົ້າ, $15/M ອອກ:

```
Draft:   12,000 × 3/1M + 1,200 × 15/1M  = $0.036 + $0.018 = $0.054
Verify:   6,000 × 3/1M +   300 × 15/1M  = $0.018 + $0.0045 ≈ $0.023
Per summary ≈ $0.077 → per 100,000 summaries/year ≈ $7,700

Against ~20 clinician-minutes saved per summary (≈ £25), inference is
0.25% of the value created — the economics are dominated by everything
EXCEPT the tokens: integration, evaluation, governance, adoption.
```

ບົດສະຫຼຸບນັ້ນ — ຕົ້ນທຶນການອະນຸມານບໍ່ຄ່ອຍເປັນຂໍ້ຈຳກັດທີ່ຜູກມັດ ທີ່ລາຄາປັດຈຸບັນ ສຳລັບວຽກຄລີນິກມູນຄ່າສູງ — ແມ່ນຜົນການຄົ້ນພົບທີ່ຄວນນຳເຂົ້າກອງປະຊຸມຕັ້ງລາຄາ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ນີ້ແມ່ນ [ເສດຖະສາດຫົວໜ່ວຍຂອງຄລາວ](../ເສດຖະສາດຫົວໜ່ວຍຂອງຄລາວ/) ທີ່ຊຳນານສຳລັບ AI, ພ້ອມສາມຂໍ້ສັງເກດການປະຕິບັດ: **ວັດຕໍ່ຫົວໜ່ວຍທຸລະກິດ**, ບໍ່ແມ່ນຕໍ່ການເອີ້ນ API, ເພື່ອໃຫ້ຕົວເລກເຊື່ອມເຂົ້າແບບຈຳລອງ [ICER](../ອັດຕາສ່ວນຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນສ່ວນເພີ່ມ/)/[ຜົນກະທົບຕໍ່ງົບປະມານ](../ການວິເຄາະຜົນກະທົບຕໍ່ງົບປະມານ/) ໂດຍກົງ; **ເຝົ້າຄວາມບໍ່ສົມມາດຂອງເຂົ້າ/ອອກ** (ປົກກະຕິລາຄາອອກ ~4× ລາຄາເຂົ້າ; ສະຖາປັດຕະຍະກຳ RAG ໜັກດ້ານເຂົ້າ — ການເລືອກສະຖາປັດຕະຍະກຳແມ່ນການເລືອກລາຄາ); ແລະ **ກຳນົດເສັ້ນທາງຕາມລະດັບງານ** — ຈັບຄູ່ຄວາມສາມາດຂອງແບບກັບຄວາມຍາກຂອງງານ (ແບບຖືກສຳລັບການຈັດປະເພດ, ແບບຊັ້ນນຳສຳລັບການສັງເຄາະ) ມັກຫຼຸດຕົ້ນທຶນລວມ 5–10× ທີ່ຄຸນນະພາບເທົ່າກັນ, ເປັນຮຸ່ນຊອບແວຂອງການໃຊ້ການແຊກແຊງທີ່ໄດ້ຜົນຖືກທີ່ສຸດ ([ຕົ້ນທຶນຕ່ຳສຸດ](../ການວິເຄາະຕົ້ນທຶນຕ່ຳສຸດ/), ມີຫຼັກຖານຄວາມເທົ່າທຽມ).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ແບບຈຳລອງຫຼາຍປີທີ່ແຊ່ແຂງລາຄາ** — ຄາດຕົ້ນທຶນເກີນ; ແຕ່ກໍມີ **ແບບຈຳລອງລາຍຮັບທີ່ສົມມຸດເງິນເຟີ້ຕ່ຳ** — ສົງຄາມລາຄາບໍ່ແມ່ນສັນຍາ; ເຮັດສະຖານະການທັງສອງ.
- **ເມີນເສີຍພາລະການປະເມີນ**: guardrail, ຜູ້ຕັດສິນ ແລະ ການລອງໃໝ່ແມ່ນໂທເຄັນຈິງ, ມັກເປັນສ່ວນໃຫຍ່ໃນສະພາບແວດລ້ອມທີ່ມີການຄວບຄຸມ.
- **ສາຍຕາສັ້ນຕໍ່ໂທເຄັນ**: ຄວາມຊັກຊ້າ, ຂີດຈຳກັດອັດຕາ ແລະ ຂໍ້ຈຳກັດໜ້າຕ່າງບໍລິບົດມີຕົ້ນທຶນທີ່ລາຄາໂທເຄັນບໍ່ໄດ້ຈັບ.
