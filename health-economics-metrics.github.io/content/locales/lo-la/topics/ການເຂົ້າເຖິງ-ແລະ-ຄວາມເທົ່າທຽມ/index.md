# ການເຂົ້າເຖິງ ແລະ ຄວາມເທົ່າທຽມ

RE-AIM — Reach (ການເຂົ້າເຖິງ), Effectiveness (ປະສິດທິຜົນ), Adoption (ການຮັບເອົາ), Implementation (ການນຳໃຊ້), Maintenance (ການຮັກສາ) — ແມ່ນກອບມາດຕະຖານສຳລັບການຕັດສິນຜົນກະທົບຕໍ່ *ປະຊາກອນ* ຂອງການແຊກແຊງ. ເລກຄະນິດຫຼັກ: **ຜົນກະທົບດ້ານສາທາລະນະສຸກ ≈ ການເຂົ້າເຖິງ × ປະສິດທິຜົນ**. ເຄື່ອງມືດິຈິຕອນເພີ່ມມິຕິຄວາມເທົ່າທຽມ: ຊ່ອງຫວ່າງດິຈິຕອນເຮັດໃຫ້ການເຂົ້າເຖິງບໍ່ເທົ່າທຽມຢ່າງເປັນລະບົບ, ແລະ ການສົ່ງມອບແບບດິຈິຕອນກ່ອນສາມາດຂະຫຍາຍຊ່ອງຫວ່າງສຸຂະພາບທີ່ມັນຕັ້ງໃຈປິດ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ການທົບທວນຢ່າງເປັນລະບົບທີ່ນຳໃຊ້ RE-AIM ກັບ mHealth ພົບລາຍເຊັນທີ່ສອດຄ່ອງ: ການເຂົ້າເຖິງ ແລະ ການຮັບເອົາແຂງແຮງ, **ປະສິດທິຜົນ ແລະ ການຮັກສາອ່ອນ** — ແອັບແຜ່ຂະຫຍາຍງ່າຍ ແລະ ຈາງໄປໄວ. ສຳລັບບໍລິການສຸຂະພາບແຫ່ງຊາດ, ນີ້ໝາຍຄວາມວ່າຜະລິດຕະພັນຕໍ່ຜູ້ໃຊ້ທີ່ໜ້າປະທັບໃຈອາດເປັນການລົງທຶນປະຊາກອນທີ່ບໍ່ດີ, ແລະ ກົງກັນຂ້າມ: ເຄື່ອງມືທີ່ມີປະສິດທິຜົນປານກາງແຕ່ເຂົ້າເຖິງຫຼາຍລ້ານຄົນສາມາດຜະລິດໄດ້ຫຼາຍກວ່າເຄື່ອງມືທີ່ເລີດເລີດແຕ່ເຂົ້າເຖິງຫຼາຍພັນຄົນ (ເບິ່ງເລກ [HALE](../ອາຍຸຂັ້ຍທີ່ປັບດ້ວຍສຸຂະພາບ/)). ຄວາມເທົ່າທຽມບໍ່ແມ່ນຂໍ້ຈຳກັດຂ້າງຄຽງແຕ່ເປັນຕົວຂັບເຄື່ອນມູນຄ່າ: ການຖືກຍົກເວັ້ນດິຈິຕອນຕິດຕາມອາຍຸ, ຄວາມຂັດສົນ, ຄວາມພິການ ແລະ ພາສາ — ແມ່ນກຸ່ມປະຊາກອນທີ່ແບກພາລະທີ່ຮັກສາໄດ້ຫຼາຍທີ່ສຸດ — ດັ່ງນັ້ນຜູ້ໃຊ້ສ່ວນເພີ່ມທີ່ຖືກຍົກເວັ້ນມັກມີປະໂຫຍດທີ່ເປັນໄປໄດ້ *ສູງກວ່າສະເລ່ຍ*. ສຳລັບມາດຕະການສະຖິຕິທາງການຂອງຄວາມບໍ່ເທົ່າທຽມດ້ານສຸຂະພາບທີ່ກ່ຽວກັບສັງຄົມ-ເສດຖະກິດ, ເບິ່ງ [ດັດຊະນີຄວາມເຂັ້ມຂຸ້ນ](../ດັດຊະນີຄວາມເຂັ້ມຂຸ້ນ/).

## ຄະນິດສາດ

```
Population impact ≈ reach × effectiveness
  reach         = participants / eligible population (see activation-and-uptake.md)
  effectiveness = real-world effect among participants (retention-weighted —
                  see retention-and-churn.md)

Equity-stratified version:
  impact_group_g = reach_g × effectiveness_g, reported per deprivation
  quintile / age band / language group
  equity gap = impact_top quintile − impact_bottom quintile

Distributional cost-effectiveness: apply equity weights to QALYs by
recipient group — a QALY to the worst-off counts more (an increasingly
mainstream HTA extension).
```

## ຕົວຢ່າງການຄິດໄລ່

ໂຄງການປ້ອງກັນເບົາຫວານດິຈິຕອນ, ລາຍງານສອງແບບ:

```
Aggregate: reach 12%, effect 0.02 QALYs/participant → 0.0024 QALYs/eligible person

Stratified (deprivation quintiles):
  Q1 (least deprived): reach 22%, effect 0.02 → 0.0044
  Q5 (most deprived):  reach 4%,  effect 0.025 → 0.0010

The programme delivers 4.4× more health to the least deprived —
while Q5's per-participant effect is HIGHER (more headroom). An
assisted-digital arm (phone coaching + community access) costing 20%
more per Q5 participant that lifts Q5 reach to 12% triples Q5 impact
and improves the aggregate — the equity investment IS the efficiency
investment here.
```

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ການເຂົ້າເຖິງສ່ວນໃຫຍ່ແມ່ນຜະລິດຕະພັນຂອງວິສະວະກຳ: ຄວາມຕ້ອງການຂັ້ນຕ່ຳຂອງອຸປະກອນ ແລະ OS, ສົມມຸດຖານແບນວິດ, ການຮອງຮັບພາສາ, ການປະຕິບັດຕາມການເຂົ້າເຖິງໄດ້ (WCAG), ອຸປະສັກການຢືນຢັນຕົວຕົນ ແລະ ການແຈກຢາຍສະເພາະ app store ແຕ່ລະອັນຕັດປະຊາກອນອອກຈາກຕົວຫານ — ປົກກະຕິແບບເບິ່ງບໍ່ເຫັນ, ເພາະຜູ້ໃຊ້ທີ່ຖືກຍົກເວັ້ນບໍ່ເຄີຍປາກົດໃນການວິເຄາະ. ການປະຕິບັດວິສະວະກຳທີ່ເຄື່ອນຄວາມເທົ່າທຽມ: ວັດ *ຕົວຫານ* (ຕິດເຄື່ອງມືກັບປະຊາກອນທີ່ມີສິດ, ບໍ່ແມ່ນພຽງຜູ້ໃຊ້); ຈັດງົບປະສິດທິພາບສຳລັບອຸປະກອນເກົ່າ ແລະ ການເຊື່ອມຕໍ່ທີ່ບໍ່ດີ; ສົ່ງເສັ້ນທາງດິຈິຕອນທີ່ມີຜູ້ຊ່ວຍ (ໂທລະສັບ, SMS, ຕູ້ບໍລິການ) ເປັນຂັ້ນຕອນຊັ້ນໜຶ່ງ ແທນຊ່ອງທາງທີ່ໜ້າອາຍ; ແລະ ແບ່ງຊັ້ນທຸກຕົວຊີ້ວັດແດຊບອດຕາມມິຕິຄວາມເທົ່າທຽມ — ຄ່າສະເລ່ຍທີ່ບໍ່ແບ່ງຊັ້ນແມ່ນບ່ອນທີ່ຄວາມບໍ່ເທົ່າທຽມຫຼົບຢູ່ ([ການຮັບເອົາ GDS](../ຕົວຊີ້ວັດບໍລິການ-gds/) ມີຄຳເຕືອນດຽວກັນ).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ລາຍງານປະສິດທິຜົນຈາກຜູ້ທີ່ເຮັດສຳເລັດ, ອ້າງຜົນກະທົບຕໍ່ປະຊາກອນ** — ຕົວແປການເຂົ້າເຖິງຫາຍໄປຢ່າງງຽບໆ.
- **ຄວາມເທົ່າທຽມເປັນການກວດສອບພາຍຫຼັງ** ແທນປັດໄຈການອອກແບບ; ການເພີ່ມການເຂົ້າເຖິງພາຍຫຼັງແພງກວ່າການອອກແບບໄວ້ຫຼາຍ.
- **ລືມການຮັກສາ**: ມິຕິທີ່ອ່ອນທີ່ສຸດຂອງ RE-AIM ໃນ mHealth — ການອ້າງຜົນກະທົບເກີນຂອບເຂດເວລາຂອງຫຼັກຖານ.
- **ການປະຢັດຊ່ອງທາງດິຈິຕອນຢ່າງດຽວ** ທີ່ຍ້າຍຕົ້ນທຶນໄປໃສ່ຜູ້ໃຊ້ທີ່ຖືກຍົກເວັ້ນ ແລະ ພະນັກງານແຖວໜ້າ (ເບິ່ງ [ຕົວຊີ້ວັດບໍລິການ GDS](../ຕົວຊີ້ວັດບໍລິການ-gds/)).
