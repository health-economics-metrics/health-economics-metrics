# ມູນຄ່າຂອງຊີວິດທາງສະຖິຕິ (VSL)

ມູນຄ່າຂອງຊີວິດທາງສະຖິຕິ (VSL) — ເອີ້ນວ່າ "ມູນຄ່າຂອງການເສຍຊີວິດທີ່ປ້ອງກັນໄດ້" (VPF) ໃນການໃຊ້ຂອງສະຫະລາຊະອານາຈັກ — ແມ່ນຈຳນວນທີ່ *ປະຊາກອນ* ເຕັມໃຈຈ່າຍລວມກັນເພື່ອຫຼຸດຄວາມສ່ຽງຂອງການເສຍຊີວິດທາງສະຖິຕິໜຶ່ງຄັ້ງ, ໄດ້ມາຈາກການສຶກສາການແລກປ່ຽນຄ່າຈ້າງ-ຄວາມສ່ຽງ (ຄົນງານຮຽກຮ້ອງຄ່າຈ້າງເພີ່ມເທົ່າໃດສຳລັບວຽກສ່ຽງກວ່າ) ແລະ ການສຳຫຼວດຄວາມມັກທີ່ລະບຸ. ມັນບໍ່ແມ່ນລາຄາຂອງຊີວິດບຸກຄົນທີ່ລະບຸຕົວໃດ; ມັນແມ່ນການສ້າງແນວຄິດຄວາມສ່ຽງຂອງປະຊາກອນ, ແລະ ວິສະວະກອນຊອບແວທີ່ສ້າງລະບົບຫຼຸດຄວາມສ່ຽງ — ອັລກໍຣິທຶມຄັດແຍກ, ການສົ່ງລົດພະຍາບານ, ການຕິດຕາມຄວາມປອດໄພ — ຕ້ອງຮູ້ວ່າມັນມາຈາກປະເພນີທິດສະດີທີ່ແຕກຕ່າງຈາກ [ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ](../ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ/).

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

VSL/VPF ແມ່ນເຄື່ອງມືມາດຕະຖານໃນການແປງການຫຼຸດຄວາມສ່ຽງການເສຍຊີວິດເປັນເງິນໃນການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດດ້ານກົດລະບຽບ: ຄວາມປອດໄພການຂົນສົ່ງ, ກົດລະບຽບສິ່ງແວດລ້ອມ ແລະ ການແຊກແຊງສາທາລະນະສຸກບາງອັນ ລ້ວນນຳ business case ຜ່ານມັນ. Green Book ຂອງ HM Treasury ເຜີຍແຜ່ຕົວເລກ VPF ທີ່ໄດ້ຈາກຫຼັກຖານຕະຫຼາດແຮງງານ ແລະ ການສຳຫຼວດຂອງສະຫະລາຊະອານາຈັກ, ແລະ ກະຊວງຄົມມະນາຄົມໃຊ້ມັນໂດຍກົງໃນການປະເມີນຄວາມປອດໄພຖະໜົນ. ນີ້ແມ່ນປະເພນີການປະເມີນທີ່ແຕກຕ່າງແທ້ຈາກວິທີ QALY × ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ: ວິທີເກນປະເມີນຜົນໄດ້ຮັບດ້ານສຸຂະພາບທຽບກັບສິ່ງທີ່ *ງົບ* ສຸຂະພາບຜະລິດທີ່ຂອບໃນປັດຈຸບັນ, ໃນຂະນະທີ່ VSL/VPF ປະເມີນການຫຼຸດຄວາມສ່ຽງທຽບກັບສິ່ງທີ່ຄົນໃນຕະຫຼາດແຮງງານ ຫຼື ການສຳຫຼວດເປີດເຜີຍວ່າເຂົາຈະຈ່າຍ. ສອງກອບບໍ່ຈຳເປັນຕ້ອງປະສານກັນໄດ້ສະເໝີ, ແລະ ການໃຊ້ທັງສອງໃນກໍລະນີດຽວກັນໂດຍບໍ່ຮັບຮູ້ເປັນຂໍ້ຜິດພາດການວິເຄາະທົ່ວໄປ.

## ຄະນິດສາດ

```
Deaths averted = population × risk_reduction_per_person
  (risk_reduction_per_person is a probability, e.g. 0.000001 = 1-in-a-million
   reduction in annual mortality risk)

Monetized mortality benefit = deaths_averted × value_of_prevented_fatality
```

## ຕົວຢ່າງການຄິດໄລ່

ພາກພື້ນທີ່ມີ 800,000 ຄົນໄດ້ປະໂຫຍດຈາກການແຊກແຊງການສົ່ງ/ຄັດແຍກດິຈິຕອນດ້ານຄວາມປອດໄພຖະໜົນທີ່ຫຼຸດຄວາມສ່ຽງການເສຍຊີວິດປະຈຳປີຂອງແຕ່ລະຄົນ 1 ໃນລ້ານ (0.000001):

```
Deaths averted = 800,000 × 0.000001 = 0.8
```

ໃຊ້ມູນຄ່າຂອງການເສຍຊີວິດທີ່ປ້ອງກັນໄດ້ຂອງສະຫະລາຊະອານາຈັກ, £2,180,000 (ຕົວເລກ HM Treasury/DfT, ລາຄາ 2023/24 — Green Book ປັບປຸງປະຈຳປີ, ກວດຄືນກ່ອນອ້າງໃນການວິເຄາະຈິງ):

```
Monetized mortality benefit = 0.8 × £2,180,000 = £1,744,000/year
```

ເກືອບ £1.75 ລ້ານຕໍ່ປີຂອງຜົນປະໂຫຍດການເສຍຊີວິດທີ່ແປງເປັນເງິນ, ຈາກການຫຼຸດຄວາມສ່ຽງທີ່ປະຊາກອນທີ່ໄດ້ຮັບຜົນກະທົບສ່ວນໃຫຍ່ຈະບໍ່ສັງເກດເປັນລາຍບຸກຄົນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ທີມຊອບແວທີ່ສຳຄັນດ້ານຄວາມປອດໄພ — ເຟີມແວອຸປະກອນການແພດ, ຊອບແວຍານພາຫະນະອັດຕະໂນມັດ, ລະບົບຄວບຄຸມອຸດສາຫະກຳ — ປະເຊີນບັນຫາການຕັ້ງລາຄາຢ່າງແນ່ນອນເມື່ອສ້າງກໍລະນີຕົ້ນທຶນ-ຜົນປະໂຫຍດສຳລັບການລົງທຶນດ້ານຄວາມປອດໄພ: ຈະຕັ້ງລາຄາ "ປ້ອງກັນຄວາມລົ້ມເຫຼວຮ້າຍແຮງໜຶ່ງຄັ້ງ" ແນວໃດເມື່ອຄວາມລົ້ມເຫຼວຫາຍາກ, ຮຸນແຮງ ແລະ ກະຈາຍໃນຜູ້ໃຊ້ຈຳນວນຫຼາຍ? VSL/VPF ແມ່ນແບບຢ່າງໃນໂລກຈິງທີ່ມີເອກະສານສາທາລະນະມາຫຼາຍທົດສະວັດ ສຳລັບການໃສ່ຕົວເລກໃຫ້ການຫຼຸດຄວາມສ່ຽງລະດັບປະຊາກອນທີ່ຫາຍາກ ແລະ ຮຸນແຮງ — ຮູບຮ່າງຂໍ້ໂຕ້ແຍ້ງດຽວກັນກັບການຕັ້ງລາຄາການລົງທຶນ SRE ທຽບກັບການລົ້ມຮ້າຍແຮງທີ່ຫາຍາກ, ພຽງແຕ່ດ້ວຍຜົນລັບການເສຍຊີວິດແທນເວລາຢຸດ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຖື VSL ເປັນ "ລາຄາຂອງຊີວິດທີ່ລະບຸຕົວ"**: ບໍ່ແມ່ນ. VSL/VPF ແມ່ນການສ້າງແນວຄິດທາງສະຖິຕິຂອງປະຊາກອນທີ່ໄດ້ຈາກການແລກປ່ຽນການຫຼຸດຄວາມສ່ຽງຂ້າມຫຼາຍຄົນ, ບໍ່ແມ່ນການປະເມີນຊີວິດ ຫຼື ຄວາມຕາຍຂອງບຸກຄົນສະເພາະ.
- **ນັບຊ້ຳກັບການຄິດໄລ່ຜົນປະໂຫຍດເປັນເງິນສຸດທິອີງ QALY**: ການໃຊ້ຕົວເລກ VSL/VPF ແລະ ການຄິດໄລ່ QALY × ເກນແຍກໃນກໍລະນີດຽວກັນ, ໂດຍບໍ່ປະສານ, ນັບຄຸນຄ່າຂອງການເສຍຊີວິດທີ່ຫຼີກລ່ຽງໄດ້ດຽວກັນຊ້ຳຢ່າງງຽບໆ. ເລືອກກອບດຽວຕໍ່ກໍລະນີ.
- **ຍ້າຍການຄາດຄະເນ VSL ຂ້າມບໍລິບົດໂດຍບໍ່ປັບ**: VSL ທີ່ໄດ້ຈາກຕະຫຼາດແຮງງານຂອງປະເທດໜຶ່ງ, ຫຼື ຈາກຂໍ້ມູນຄ່າຈ້າງ-ຄວາມສ່ຽງວັຍເຮັດວຽກ, ທີ່ນຳໃຊ້ໂດຍບໍ່ປັບກັບບໍລິບົດລາຍໄດ້ຕ່າງກັນ ຫຼື ປະຊາກອນຕ່າງກັນ (ເດັກ, ຜູ້ສູງອາຍຸ) ແມ່ນບັນຫາວິທີການທີ່ຖົກຖຽງກັນມາດົນ — ບໍ່ແມ່ນບັນຫາທີ່ແກ້ແລ້ວ.
