# ຄວາມເໜືອກວ່າ ແລະ ຂອບເຂດປະສິດທິພາບ

ທາງເລືອກໜຶ່ງຖືກ**ເໜືອກວ່າ (dominated)** ຖ້າອີກທາງເລືອກໜຶ່ງມີຕົ້ນທຶນໜ້ອຍກວ່າ *ແລະ* ໃຫ້ຜົນຫຼາຍກວ່າ. **ຂອບເຂດປະສິດທິພາບ (efficiency frontier)** ແມ່ນສິ່ງທີ່ເຫຼືອຫຼັງຕັດທາງເລືອກທີ່ຖືກເໜືອກວ່າອອກ: ຊຸດຂອງທາງເລືອກທີ່ການໄດ້ຫຼາຍຂຶ້ນຕ້ອງຈ່າຍຫຼາຍຂຶ້ນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ກ່ອນການໂຕ້ວາທີເລື່ອງເກນຫຼືງົບປະມານໃດໆ ການປະເມີນເຕັກໂນໂລຢີສຸຂະພາບຕັດທາງເລືອກທີ່ບໍ່ມີໃຜຄວນເລືອກອອກກ່ອນ. ການພລອດທຸກທາງເລືອກເທິງແຜນຕົ້ນທຶນ-ທຽບ-ຜົນ ແລະ ລາກຂອບເຂດແມ່ນການອອກກຳລັງຫ້ານາທີທີ່ຂ້າເຄິ່ງໜຶ່ງຂອງລາຍຊື່ສັ້ນເປັນປະຈຳ. ການປຽບທຽບສ່ວນເພີ່ມ ([ICER](../ອັດຕາສ່ວນຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນສ່ວນເພີ່ມ/)) ຈຶ່ງຄິດໄລ່ສະເພາະ*ຕາມຂອບເຂດ* ແຕ່ລະທາງເລືອກທຽບກັບທາງເລືອກທີ່ຖືກທີ່ສຸດຖັດໄປທີ່ບໍ່ຖືກເໜືອກວ່າ — ບໍ່ເຄີຍທຽບກັບ "ບໍ່ເຮັດຫຍັງ" ເມື່ອມີທາງເລືອກກາງທີ່ດີກວ່າ.

## ຄະນິດສາດ

```
Strict dominance:   A dominates B if Cost_A ≤ Cost_B and Effect_A ≥ Effect_B
                    (with at least one strict inequality)

Extended dominance: B is ruled out if a mix of A and C achieves more effect
                    per pound — detected when ICERs decrease as you move up
                    the frontier. Valid frontier ICERs must be increasing.
```

ຂັ້ນຕອນ: ຈັດລຽງທາງເລືອກຕາມຜົນ; ເອົາອອກອັນທີ່ຖືກເໜືອກວ່າຢ່າງເຄັ່ງ; ຄິດໄລ່ ICER ເປັນຄູ່ລະຫວ່າງເພື່ອນບ້ານ; ເອົາອອກທາງເລືອກໃດທີ່ ICER ເກີນຂອງທາງເລືອກທີ່ມີຜົນຫຼາຍກວ່າຖັດໄປ (ຄວາມເໜືອກວ່າແບບຂະຫຍາຍ); ເຮັດຊ້ຳຈົນ ICER ເພີ່ມຂຶ້ນແບບຕໍ່ເນື່ອງ.

## ຕົວຢ່າງການຄິດໄລ່

ສີ່ທາງເລືອກໃນການຫຼຸດການນັດທີ່ພາດ (ຜົນ = ການນັດທີ່ເອົາຄືນ/ປີ):

```
Option          Cost/yr    Recovered
Do nothing      £0         0
SMS reminders   £20,000    2,000
Phone calls     £120,000   2,200
SMS + AI triage £90,000    3,500
```

ການໂທຖືກ**ເໜືອກວ່າຢ່າງເຄັ່ງ**ໂດຍ SMS + AI triage (ແພງກວ່າ, ເອົາຄືນໄດ້ໜ້ອຍກວ່າ). ຂອບເຂດ: ບໍ່ມີ → SMS → SMS + AI.

```
ICER(SMS vs nothing)   = 20,000 / 2,000  = £10 per appointment recovered
ICER(SMS+AI vs SMS)    = (90,000 − 20,000) / (3,500 − 2,000) = £46.67 per appointment
```

ICER ເພີ່ມຂຶ້ນ → ຂອບເຂດຖືກຕ້ອງ. ທີ່ ~£160 ທີ່ປະຢັດຕໍ່ການນັດໂຮງໝໍທີ່ເອົາຄືນ (ເບິ່ງ[ອັດຕາການບໍ່ມາຕາມນັດ](../ອັດຕາການບໍ່ມາຕາມນັດ/)) ທັງສອງຂັ້ນຂອງຂອບເຂດຄຸ້ມຄ່າທີ່ຈະເຮັດ; ຂໍ້ສະເໜີສູນໂທລະສັບບໍ່ຄວນໄປຮອດຄະນະກຳມະການເລີຍ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ສ້າງແຜນພາບດຽວກັນສຳລັບການຕັດສິນໃຈເຄື່ອງມືໃດໆ: ຕົ້ນທຶນຕໍ່ປີໃນແກນໜຶ່ງ, ຜົນລັບທີ່ວັດໄດ້ (ຊົ່ວໂມງທີ່ປະຢັດ, ເຫດການທີ່ຫຼີກລ່ຽງ, ການນຳໃຊ້ທີ່ເປີດໃຊ້) ໃນອີກແກນ. ຈຸດທີ່ຢູ່ເທິງ-ຊ້າຍຂອງຂອບເຂດຖືກກຳຈັດກ່ອນໃຜຈະໂຕ້ແຍ້ງເລື່ອງງົບປະມານ. ນີ້ປັບການເລືອກຜູ້ຂາຍຈາກການໂຕ້ວາທີລາຍການຄຸນສົມບັດໄປເປັນ "ເຈົ້າຖືກເໜືອກວ່າ; ການປະຊຸມຈົບແລ້ວ." ມັນຍັງເປີດໂປງຮູບແບບວິສາຫະກິດທົ່ວໄປຂອງການຊື້ທາງເລືອກທີ່ແພງທີ່ສຸດເພື່ອກຳໄລນ້ອຍນິດ — ຖືກຕ້ອງສະເພາະເມື່ອລາຄາສ່ວນເພີ່ມຕໍ່ຫົວໜ່ວຍສ່ວນເພີ່ມແມ່ນສິ່ງທີ່ອົງກອນຍອມຈ່າຍຢ່າງຮູ້ຕົວ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ປຽບທຽບທຸກຢ່າງກັບພື້ນຖານ** ແທນທາງເລືອກຖັດໄປໃນຂອບເຂດ — ເຮັດໃຫ້ທາງເລືອກແພງເບິ່ງດີໂດຍເຊື່ອງອັນທີ່ຖືກກວ່າແລະເກືອບທຽບເທົ່າ.
- **ຄະແນນຜົນມິຕິດຽວ** ທີ່ເຊື່ອງສິ່ງສຳຄັນ; ຖ້າສອງຜົນລັບນັບ ໃຫ້ລວມຢ່າງປ້ອງກັນໄດ້ (ເບິ່ງ[ການວິເຄາະຕົ້ນທຶນ-ອຣະຖະປະໂຫຍດ](../ການວິເຄາະຕົ້ນທຶນ-ອຣະຖະປະໂຫຍດ/)) ຫຼື ສະແດງສອງຂອບເຂດ.
- **ລືມຄວາມບໍ່ແນ່ນອນ**: ທາງເລືອກໃກ້ຂອບເຂດອາດສະຫຼັບທີ່ກັນພາຍໃຕ້[ການວິເຄາະຄວາມອ່ອນໄຫວ](../ການວິເຄາະຄວາມອ່ອນໄຫວ/).
