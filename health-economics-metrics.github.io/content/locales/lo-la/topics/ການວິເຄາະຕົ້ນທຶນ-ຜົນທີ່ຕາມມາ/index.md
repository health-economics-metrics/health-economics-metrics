# ການວິເຄາະຕົ້ນທຶນ-ຜົນທີ່ຕາມມາ (CCA)

CCA ນຳສະເໜີຕົ້ນທຶນຄຽງຄູ່**ຕາຕະລາງແຍກສ່ວນຂອງຜົນລັບທັງໝົດ** — ທາງຄລີນິກ, ການດຳເນີນງານ, ປະສົບການ — ໂດຍບໍ່ບີບອັດເປັນອັດຕາສ່ວນ ຫຼື ຄະແນນດຽວ. ຜູ້ຕັດສິນໃຈຊັ່ງນ້ຳໜັກການແລກປ່ຽນຢ່າງຊັດເຈນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

CCA ແມ່ນ**ຮູບແບບເສດຖະກິດທີ່ NICE ຕ້ອງການສຳລັບເຕັກໂນໂລຢີສຸຂະພາບດິຈິຕອນສ່ວນໃຫຍ່** ພາຍໃຕ້ Evidence Standards Framework. ຜະລິດຕະພັນດິຈິຕອນສ້າງຜົນທີ່ຫຼາກຫຼາຍ (ເວລາທີ່ປະຢັດ, ຄວາມພໍໃຈ, ການຫຼຸດ DNA, ຜົນທາງຄລີນິກເລັກນ້ອຍ) ທີ່ຕ້ານການລວມຢ່າງຊື່ສັດເປັນຕົວເລກ QALY ດຽວ. ແທນທີ່ຈະບັງຄັບຄະແນນປະສົມທີ່ເປາະບາງ CCA ສະແດງບັນຊີເຕັມ. ສຳລັບກໍລະນີທຸລະກິດຊອບແວສ່ວນໃຫຍ່ ມັນເປັນທັງຮູບແບບທີ່ຊື່ສັດທີ່ສຸດ ແລະ ຊັກຊວນທີ່ສຸດ ເພາະທຸກຜູ້ມີສ່ວນໄດ້ເສຍຫາແຖວທີ່ກ່ຽວຂ້ອງກັບການຕັດສິນໃຈຂອງຕົນເອງ.

## ຄະນິດສາດ

ຕັ້ງໃຈບໍ່ມີສູດລວມ. ຜົນຜະລິດແມ່ນຕາຕະລາງ:

```
                          Intervention   Comparator   Difference
Costs (annual)            £X             £Y           ΔC
Outcome 1 (natural units) …              …            Δ1
Outcome 2                 …              …            Δ2
Qualitative outcomes      described, not scored
```

ແຕ່ລະແຖວຮັກສາຫົວໜ່ວຍຂອງຕົນ. ກົດ: ທຸກຜົນທີ່ຕາມມາກຳນົດລ່ວງໜ້າ (ບໍ່ເລືອກສະເພາະອັນທີ່ດີຫຼັງເຫັນຜົນ); [ມຸມມອງ](../ມຸມມອງຂອງການວິເຄາະ/)ແລະ[ຂອບເຂດເວລາ](../ຂອບເຂດເວລາ/)ດຽວກັນຕະຫຼອດ; ຄວາມບໍ່ແນ່ນອນຕໍ່ແຖວ.

## ຕົວຢ່າງການຄິດໄລ່

ແພລດຟອມການປະເມີນກ່ອນຜ່າຕັດດິຈິຕອນ ທຽບກັບຂະບວນການທາງໂທລະສັບ, ຕໍ່ປີ, ໜຶ່ງ trust:

```
                              Digital      Phone       Difference
Running cost                  £180,000     £95,000     +£85,000
Nurse hours on assessments    6,200        11,800      −5,600 hrs
On-day surgery cancellations  92           174         −82
Patient satisfaction (CSAT)   4.5/5        3.9/5       +0.6
Assessments lost/incomplete   1.2%         4.8%        −3.6 pp
```

ບໍ່ມີຄະແນນດຽວ — ແຕ່ການຕັດສິນໃຈຄິດໄດ້ງ່າຍ: £85,000 ຊື້ຊົ່ວໂມງພະຍາບານ 5,600 ຊົ່ວໂມງ (≈ £15/ຊົ່ວໂມງ ຕ່ຳກວ່າຕົ້ນທຶນບຸກຄະລາກອນໃດໆຫຼາຍ), ການຍົກເລີກທີ່ຫຼີກລ່ຽງ 82 ຄັ້ງ (ແຕ່ລະຄັ້ງເສຍຊ່ອງຫ້ອງຜ່າຕັດທີ່ມີຄ່າ ~£1,200), ແລະ ປະສົບການທີ່ດີຂຶ້ນ. ຄະນະກຳມະການຍັງເຫັນຢ່າງຊັດເຈນສິ່ງທີ່ມັນ*ບໍ່*ໄດ້: ບໍ່ມີຜົນ QALY ຫຼື ອັດຕາການຕາຍທີ່ອ້າງ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

CCA ແມ່ນສະບັບທາງການຂອງ balanced scorecard ທີ່ຂໍ້ສະເໜີແພລດຟອມທີ່ດີໃຊ້ຢູ່ແລ້ວ: ຕົ້ນທຶນຄຽງຄູ່ຕົວຊີ້ວັດ DORA, ຄະແນນ DevEx, ຈຳນວນເຫດການ — ບໍ່ລວມ. ລະບຽບວິໄນເສດຖະສາດສຸຂະພາບທີ່ຄວນເພີ່ມ: **ກຳນົດແຖວລ່ວງໜ້າ** (ຕັດສິນວ່າອັນໃດນັບກ່ອນການທົດລອງ ເພື່ອບໍ່ໃຫ້ງຽບໆຖິ້ມຕົວຊີ້ວັດທີ່ແຍ່ລົງ), ແລະ **ສະແດງແຖວທີ່ບໍ່ເອື້ອອຳນວຍ** — CCA ທີ່ມີແຕ່ຂ່າວດີແມ່ນການໂຄສະນາ. ໃຊ້ CCA ເມື່ອບໍ່ມີຄະແນນປະສົມທີ່ປ້ອງກັນໄດ້ ເຊິ່ງສຳລັບເຄື່ອງມືນັກພັດທະນາແມ່ນເກືອບສະເໝີ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ເລືອກສະເພາະຜົນທີ່ຕາມມາທີ່ດີ** — ຄວາມສົມບູນຂອງຮູບແບບຂຶ້ນກັບການກຳນົດລ່ວງໜ້າ.
- **ການລວມທີ່ແອບແຝງ**: ການໃສ່ສີ ຫຼື "ຄະແນນລວມ" ນຳນ້ຳໜັກຕາມໃຈຊອບທີ່ CCA ມີຢູ່ເພື່ອຫຼີກລ່ຽງກັບຄືນມາ.
- **ການຕັດສິນໃຈເປັນອຳມະພາດ**: CCA ຕ້ອງການຜູ້ຕັດສິນໃຈທີ່ເຕັມໃຈຊັ່ງນ້ຳໜັກການແລກປ່ຽນ; ຈັບຄູ່ກັບຂໍ້ແນະນຳແລະເຫດຜົນ.
