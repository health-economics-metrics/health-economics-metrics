# ຕົ້ນທຶນຕໍ່ເນື່ອງທີ່ຫຼີກລ່ຽງໄດ້

ຕົ້ນທຶນຕໍ່ເນື່ອງທີ່ຫຼີກລ່ຽງໄດ້ (ການຫັກລ້າງຕົ້ນທຶນ, cost offsets) ແມ່ນລາຍຈ່າຍການປິ່ນປົວໃນອະນາຄົດທີ່ຖືກປ້ອງກັນໂດຍການກະທຳທີ່ເຮັດໄວກວ່າ ຫຼື ດີກວ່າ ແລ້ວຫັກລົບກັບຕົ້ນທຶນຂອງການແຊກແຊງເອງ. ການຫັກລ້າງແມ່ນກົນໄກທີ່ການແຊກແຊງສາມາດກາຍເປັນ*ເໜືອກວ່າ (dominant)* — ຖືກກວ່າ **ແລະ** ດີກວ່າ — ແລະ ມັນຍັງເປັນແຖວທີ່ຖືກນັບຊ້ຳ ແລະ ອ້າງເກີນຈິງຫຼາຍທີ່ສຸດໃນເສດຖະສາດສຸຂະພາບ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ເກືອບທຸກຂໍ້ສະເໜີຄຸນຄ່າຂອງສຸຂະພາບດິຈິຕອນມີຂໍ້ອ້າງການຫັກລ້າງ: "ແອັບຂອງພວກເຮົາປ້ອງກັນການຮັບເຂົ້າໂຮງໝໍ," "ການແຈ້ງເຕືອນຂອງພວກເຮົາປ້ອງກັນອາການຊຸດໂຊມ," "ແພລດຟອມຂອງພວກເຮົາຫຼີກລ່ຽງການກວດຊ້ຳ." ເມື່ອການຫັກລ້າງເປັນຈິງ ມັນປ່ຽນເສດຖະສາດ (ເບິ່ງຕົວຢ່າງ[ICER](../ອັດຕາສ່ວນຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນສ່ວນເພີ່ມ/) ທີ່ການຫັກລ້າງ £600k ເຮັດໃຫ້ກໍລະນີສຳເລັດ). ຜູ້ຈ່າຍເງິນຮູ້ເລື່ອງນີ້ — ດັ່ງນັ້ນຂໍ້ອ້າງການຫັກລ້າງຈຶ່ງຖືກກວດສອບໜັກທີ່ສຸດໃນທຸກການປະເມີນ. ກົດຄວາມໜ້າເຊື່ອຖືຂ້າງລຸ່ມແຍກແບບຈຳລອງທີ່ໃຫ້ທຶນໄດ້ ອອກຈາກການໂຄສະນາ.

## ຄະນິດສາດ

```
Net cost = intervention cost − Σ offsets

A valid offset must be:
  Attributable — causally linked to the intervention (comparator evidence)
  Marginal     — the money actually stops being spent, at marginal not
                 average cost (see marginal-vs-average-cost.md)
  Probability- — weighted by P(the downstream event would have occurred)
  weighted
  Discounted   — future avoided costs at present value
  Unique       — counted once, in one benefit line
```

## ຕົວຢ່າງການຄິດໄລ່

"ຂໍ້ອ້າງຄວາມສ່ຽງຈາກການຍ້າຍ ທີ່ເຮັດຖືກຕ້ອງ": ແອັບຕິດຕາມບາດແຜສຳລັບຄົນເຈັບຫຼັງຜ່າຕັດ 5,000 ຄົນ ອ້າງວ່າຫຼີກລ່ຽງການກັບເຂົ້າໂຮງໝໍຊ້ຳຍ້ອນຕິດເຊື້ອ.

```
Baseline readmission for infection: 4.0% ; with app (RCT): 3.1%
Attributable events avoided = 5,000 × 0.009 = 45/year
Cost per readmission spell (marginal, this trust): £3,200
Offset = 45 × 3,200 = £144,000/year
App cost = 5,000 × £20 = £100,000/year
Net cost = −£44,000 → genuinely cost-saving, with:
  attribution from an RCT ✓  marginal costing ✓  probability from trial data ✓
```

ຂໍ້ອ້າງດຽວກັນທີ່ສ້າງຈາກ "ການກັບເຂົ້າໂຮງໝໍຊ້ຳມີຕົ້ນທຶນສະເລ່ຍ £5,800, ພວກເຮົາຈະປ້ອງກັນໄດ້ຫຼາຍ" ລົ້ມເຫຼວທັງສີ່ການທົດສອບ ແລະ ສົມຄວນຖືກປະຕິເສດ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

"ການຍ້າຍລະບົບນີ້ຫຼີກລ່ຽງການຂຽນໃໝ່ໃນອະນາຄົດ" ແມ່ນຂໍ້ອ້າງການຫັກລ້າງ ແລະ ກົດຂອງເສດຖະສາດສຸຂະພາບເຮັດໃຫ້ມັນຊື່ສັດ:

- **ຕົ້ນທຶນທຽບເຄິ່ງຈິງ (counterfactual)**: ການຂຽນໃໝ່ຈະມີຕົ້ນທຶນເທົ່າໃດແທ້ ແລະ ມີຫຼັກຖານແນວໃດ?
- **ຄວາມນ່າຈະເປັນ**: ອະນາຄົດນັ້ນເກີດຂຶ້ນໄດ້ປານໃດ? (ບໍ່ແມ່ນ 100% — ຜະລິດຕະພັນຖືກຍົກເລີກ, ບູລິມະສິດປ່ຽນ.)
- **ການຫຼຸດມູນຄ່າ**: ການຂຽນໃໝ່ທີ່ຫຼີກລ່ຽງໃນປີທີ 4 ທີ່ອັດຕາຫຼຸດ 3.5–10% ມີຄ່າໜ້ອຍກວ່າມູນຄ່າໜ້າຕົວຫຼາຍ.
- **ຄວາມເປັນເອກະລັກ**: ຢ່າອ້າງການຫຼີກລ່ຽງການຂຽນໃໝ່ດຽວກັນທັງໃນແຖວໜີ້ທາງເຕັກນິກ ແລະ ແຖວການຮັກສາຜູ້ໃຊ້.

`Offset value = P(future event) × counterfactual cost × discount factor` — ຂຽນແຖວນັ້ນໃນຂໍ້ສະເໜີ ແລ້ວເບິ່ງການຄາດຄະເນກາຍເປັນສິ່ງທີ່ໂຕ້ແຍ້ງໄດ້ ເຊິ່ງແມ່ນຈຸດປະສົງ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການນັບຊ້ຳ** — ການຮັບເຂົ້າໂຮງໝໍທີ່ຫຼີກລ່ຽງຄັ້ງດຽວຖືກອ້າງເປັນການຫັກລ້າງ, ວັນນອນໂຮງໝໍ, ແລະ QALY ທີ່ແນບຕົ້ນທຶນ.
- **ການຫັກລ້າງຕາມຕົ້ນທຶນສະເລ່ຍ** ສຳລັບເຫດການທີ່ຕົ້ນທຶນຄົງທີ່ຍັງດຳເນີນຕໍ່ໄປບໍ່ວ່າທາງໃດ.
- **ຄວາມນ່າຈະເປັນ 100% ແບບງຽບໆ** ຕໍ່ເຫດການຕໍ່ເນື່ອງທີ່ພຽງແຕ່ອາດເກີດຂຶ້ນ.
- **ການຫັກລ້າງຕໍ່ງົບປະມານອື່ນ** ທີ່ນຳສະເໜີເປັນເງິນປະຢັດຂອງຜູ້ຈ່າຍເງິນທີ່ຖືກຂໍໃຫ້ຈ່າຍ — ເບິ່ງ[ມຸມມອງຂອງການວິເຄາະ](../ມຸມມອງຂອງການວິເຄາະ/).
