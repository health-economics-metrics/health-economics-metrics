# ຈຳນວນທີ່ຕ້ອງຮັກສາ (NNT)

NNT ແມ່ນຈຳນວນຜູ້ປ່ວຍທີ່ຕ້ອງໄດ້ຮັບການແຊກແຊງເພື່ອໃຫ້ຜູ້ປ່ວຍ **ໜຶ່ງ** ຄົນເພີ່ມເຕີມໄດ້ປະໂຫຍດ, ໃນກອບເວລາທີ່ລະບຸ. ມັນແປງການຫຼຸດຄວາມສ່ຽງເປັນເປີເຊັນ — ທີ່ເຮັດໃຫ້ເຂົ້າໃຈຜິດ — ເປັນຫົວໜ່ວຍຄວາມພະຍາຍາມຕໍ່ຜົນປະໂຫຍດທີ່ໃຜກໍໃຊ້ເຫດຜົນໄດ້.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

"ຫຼຸດການເປັນໂຣກຫົວໃຈວາຍ 25%!" ຟັງເບິ່ງແນ່ນອນ. ຖ້າຄວາມສ່ຽງພື້ນຖານແມ່ນ 4% ໃນ 5 ປີ, ການຫຼຸດສົມບູນແມ່ນ 1 ຈຸດເປີເຊັນ, ດັ່ງນັ້ນ **ຕ້ອງມີ 100 ຄົນກິນຢາ 5 ປີເພື່ອໃຫ້ 1 ຄົນໄດ້ປະໂຫຍດ** — ແລະ ທັງ 100 ຄົນຈ່າຍຕົ້ນທຶນ ແລະ ຮັບຜົນຂ້າງຄຽງ. NNT ແມ່ນຢາແກ້ການຕະຫຼາດຄວາມສ່ຽງສຳພັດ, ເຊິ່ງເປັນເຫດຜົນທີ່ການແພດອີງຫຼັກຖານນຳດ້ວຍມັນ. Statin ສຳລັບການປ້ອງກັນຂັ້ນຕົ້ນ: NNT ≈ 50–100 ໃນ 5 ປີຕໍ່ການເປັນໂຣກຫົວໃຈວາຍທີ່ຫຼີກລ່ຽງໄດ້. ຄູ່ກະຈົກຂອງມັນ, **NNH** (ຈຳນວນທີ່ຕ້ອງເປັນອັນຕະລາຍ), ນັບຈຳນວນທີ່ຮັກສາຕໍ່ຜູ້ທີ່ໄດ້ຮັບອັນຕະລາຍ.

## ຄະນິດສາດ

```
ARR = control event rate − treatment event rate   (absolute risk reduction)
NNT = 1 / ARR

NNH = 1 / (harm rate_treatment − harm rate_control)

Economic bridge:
cost per event prevented = NNT × cost per treatment course
```

ລະບຸກອບເວລາ ແລະ ປະຊາກອນພື້ນຖານສະເໝີ — NNT ບໍ່ມີຄວາມໝາຍຖ້າບໍ່ມີທັງສອງ.

## ຕົວຢ່າງການຄິດໄລ່

ລະບົບທຳນາຍການຕົກໃນໂຮງໝໍຕິດທຸງຜູ້ປ່ວຍສ່ຽງສູງສຳລັບການແຊກແຊງ (ເຊັນເຊີຕຽງ, ການທົບທວນ, ການເບິ່ງແຍງ). ການທົດລອງ: ການຕົກທີ່ບາດເຈັບຫຼຸດຈາກ 3.2% ເປັນ 2.4% ຂອງການຮັບເຂົ້າ.

```
ARR = 0.8 percentage points → NNT = 1/0.008 = 125
   (125 patients must get the intervention bundle to prevent 1 injurious fall)

Intervention cost ≈ £40/patient → cost per fall prevented = 125 × 40 = £5,000
Cost of an injurious inpatient fall (extra stay, imaging, litigation) ≈ £12,000
Net: prevention pays ~2.4:1 — and the QALY gain is on top.
```

ສັງເກດວ່າ NNT ຮັກສາການອ້າງໃຫ້ຊື່ສັດແນວໃດ: "ຫຼຸດການຕົກ 25%" ແລະ "ປ້ອງກັນການຕົກໜຶ່ງຄັ້ງຕໍ່ 125 ຜູ້ປ່ວຍທີ່ຮັກສາ" ແມ່ນຜົນດຽວກັນ, ແຕ່ຊັກຊວນຕ່າງກັນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

NNT ແມ່ນຫົວໜ່ວຍທີ່ຖືກຕ້ອງສຳລັບປະຕູ ຫຼື ການກວດໃດກໍຕາມທີ່ກະທຳຕໍ່ຫຼາຍລາຍການເພື່ອຈັບໜ້ອຍລາຍການ: **"ຈຳນວນ PR ທີ່ຕ້ອງຜ່ານປະຕູທົບທວນ AI ເພື່ອຈັບໜຶ່ງຂໍ້ບົກພ່ອງທີ່ກຳລັງໄປຫາການຜະລິດ."** ຖ້າປະຕູທົບທວນ 400 PR ຕໍ່ການຈັບຈິງ (NNT = 400) ທີ່ຄວາມສົນໃຈນັກພັດທະນາ 4 ນາທີຕໍ່ອັນ, ການຈັບໜຶ່ງຄັ້ງມີຕົ້ນທຶນ ~27 ຊົ່ວໂມງນັກພັດທະນາ — ຈາກນັ້ນປຽບທຽບກັບຕົ້ນທຶນເຫດການທີ່ມັນປ້ອງກັນ. NNH ແປງເປັນຜົນບວກປອມ: ຈຳນວນ PR ຕໍ່ການຕິດທຸງ *ປອມ* ໜຶ່ງຄັ້ງ, ແລະ ແຕ່ລະອັນມີຕົ້ນທຶນເທົ່າໃດໃນຄວາມສົນໃຈ ແລະ ຄວາມໄວ້ວາງໃຈ? ເຄື່ອງມືແບບຄັດກອງ (linter, ເຄື່ອງສະແກນຄວາມປອດໄພ, ການກວດຈັບຄວາມຜິດປົກກະຕິ) ຄວນມາພ້ອມເລກ NNT/NNH — ເບິ່ງ [ເສດຖະສາດການຄັດກອງ](../ເສດຖະສາດການຄັດກອງ/) ວ່າເປັນຫຍັງຄວາມຊຸກຊຸມຕ່ຳເຮັດໃຫ້ຕົວເລກເຫຼົ່ານີ້ໂຫດຮ້າຍ. [ຈຳນວນທີ່ຕ້ອງຄັດກອງ](../ຈຳນວນທີ່ຕ້ອງຄັດກອງ/) ແມ່ນຕົວເລກທຽບເທົ່າຢູ່ສູງຂຶ້ນໜຶ່ງລະດັບ, ສຳລັບໂຄງການຄັດກອງແລ້ວຮັກສາທັງໝົດ ແທນການຮັກສາຢ່າງດຽວ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ບໍ່ມີກອບເວລາ**: "NNT = 50" ບໍ່ມີຄວາມໝາຍ; "NNT = 50 ໃນ 5 ປີ" ຄືການອ້າງ.
- **ການຍ້າຍຄວາມສ່ຽງພື້ນຖານ**: NNT ທີ່ຄິດໄລ່ໃນປະຊາກອນທົດລອງສ່ຽງສູງລົ້ມລົງໃນປະຊາກອນນຳໃຊ້ສ່ຽງຕ່ຳ.
- **ເມີນເສີຍ NNH** — ປະຕູທີ່ມີ NNT 400 ແລະ NNH 3 ແມ່ນຕົວສ້າງຄວາມລຳຄານ, ບໍ່ແມ່ນລະບົບຄວາມປອດໄພ.
