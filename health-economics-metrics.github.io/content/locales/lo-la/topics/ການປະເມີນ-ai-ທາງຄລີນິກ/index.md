# ການປະເມີນ AI ທາງຄລີນິກ

ສະຖິຕິຫຼັກສຳລັບການປະເມີນ AI ທາງຄລີນິກ ຫຼື ແບບຈຳລອງວິນິດໄສ: ຄວາມອ່ອນໄຫວ (sensitivity), ຄວາມຈຳເພາະ (specificity), AUROC, ຄ່າພະຍາກອນ, ແລະ ຈຳນວນທີ່ຕ້ອງຄັດກອງ. ບົດຮຽນທາງເສດຖະກິດຫຼັກ: **AUROC ທີ່ດີເລີດບໍ່ໄດ້ເຮັດໃຫ້ການນຳໃຊ້ຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ** — ຄຸນຄ່າຂຶ້ນກັບຈຸດປະຕິບັດການ, ອັດຕາຊຸກຊຸມ, ແລະ ສິ່ງທີ່ເກີດຂຶ້ນຕໍ່ໄປຫຼັງທຸກຜົນບວກ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຜູ້ກຳກັບດູແລ (FDA, MHRA) ອະນຸຍາດ AI ທາງຄລີນິກທີ່**ຈຸດປະຕິບັດການທີ່ລັອກ** — ຄູ່ຄວາມອ່ອນໄຫວ/ຄວາມຈຳເພາະສະເພາະ (ເຊັ່ນ ລະບົບອັດຕະໂນມັດສຳລັບໂຣກຈອປະສາດຕາຈາກເບົາຫວານທຳອິດທີ່ FDA ອະນຸຍາດ: ຄວາມອ່ອນໄຫວ 87.2%, ຄວາມຈຳເພາະ 90.7% ໃນການທົດລອງສຳຄັນ). ນັກເສດຖະສາດສຸຂະພາບຈຶ່ງຖາມຄຳຖາມທີ່ຕົວຊີ້ວັດຄວາມຖືກຕ້ອງຕອບບໍ່ໄດ້: ທີ່ອັດຕາຊຸກຊຸມຂອງປະຊາກອນນຳໃຊ້ຂອງທ່ານ ການກວດພົບແຕ່ລະຄັ້ງ*ມີຕົ້ນທຶນ*ເທົ່າໃດ ແລະ ການປະຕິບັດຕາມມັນຄຸ້ມຄ່າບໍ? ການປະເມີນທາງເສດຖະກິດຂອງ AI ຄັດກອງໂຣກຈອປະສາດຕາ (npj Digital Medicine 2024) ສະແດງວ່າຄວາມຖືກຕ້ອງທີ່ສູງກວ່າພຽງຢ່າງດຽວບໍ່ຮັບປະກັນຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນເມື່ອນັບຕົ້ນທຶນການສົ່ງຕໍ່.

## ຄະນິດສາດ

```
Sensitivity = TP / (TP + FN)        — of the truly positive, share caught
Specificity = TN / (TN + FP)        — of the truly negative, share cleared
AUROC       = P(model ranks a random positive above a random negative)
              0.5 chance … 1.0 perfect; threshold-independent — and therefore
              deployment-decision-insufficient

PPV = TP / (TP + FP)   ← prevalence-dependent (Bayes); collapses when rare
NPV = TN / (TN + FN)

NNS  ≈ 1 / (prevalence × sensitivity)       — screened per true case found
Cost per true case = programme cost / TP      — the economic bottom line
```

## ຕົວຢ່າງການຄິດໄລ່

ແບບຈຳລອງດຽວກັນ ສອງສະພາບແວດລ້ອມ — ຄວາມອ່ອນໄຫວ 90%, ຄວາມຈຳເພາະ 93%:

```
Specialist clinic (prevalence 20%):
  PPV = (0.9×0.2)/(0.9×0.2 + 0.07×0.8) = 0.18/0.236 ≈ 76%  → 3 in 4 alerts real

Primary care (prevalence 1%):
  PPV = (0.9×0.01)/(0.9×0.01 + 0.07×0.99) = 0.009/0.0783 ≈ 11.5%
  → 8 in 9 alerts false; workup at £350 each:
  cost per true case = (0.009 + 0.0693) × 350 / 0.009 ≈ £3,045 per case found
```

ແບບຈຳລອງດຽວກັນ ເສດຖະສາດແຕກຕ່າງຢ່າງຫຼວງຫຼາຍ — ນັ້ນຄືເຫດຜົນທີ່ການປະເມີນສະເພາະສະຖານທີ່ເປັນຫົວຂໍ້ຂອງກົດລະບຽບ ແລະ ເປັນເຫດທີ່ "ແບບຈຳລອງຂອງພວກເຮົາມີ AUROC 0.95" ແມ່ນການເລີ່ມຕົ້ນຂອງກໍລະນີທາງເສດຖະກິດ ບໍ່ແມ່ນຈຸດຈົບ. ເບິ່ງ[ເສດຖະສາດການຄັດກອງ](../ເສດຖະສາດການຄັດກອງ/) ສຳລັບຄະນິດສາດຂອງໂຄງການທັງໝົດ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ສຳລັບວິສະວະກອນທີ່ສ້າງ ຫຼື ຊື້ AI ທາງຄລີນິກ: **ສົ່ງມອບເມທຣິກຊ໌ຄວາມສັບສົນ (confusion matrix) ທີ່ອັດຕາຊຸກຊຸມຂອງການນຳໃຊ້** ບໍ່ແມ່ນສະເພາະເສັ້ນໂຄ້ງ ROC; **ໃຫ້ເກນເປັນການຕັດສິນໃຈທາງເສດຖະກິດ** — ການແລກປ່ຽນ sens/spec ຄວນຫຼຸດຕົ້ນທຶນທີ່ຄາດໄວ້ (ກໍລະນີທີ່ພາດ × ຕົ້ນທຶນການພາດ ທຽບກັບ ສັນຍານຜິດ × ຕົ້ນທຶນການກວດຕໍ່) ບໍ່ແມ່ນເພີ່ມສະຖິຕິເກນທຽບໃຫ້ສູງສຸດ; ແລະ ຮັບຮູ້ຄະນິດສາດດຽວກັນໃນເຄື່ອງມືຂອງທ່ານເອງ — ລະບົບແຈ້ງເຕືອນ, ຕົວກວດຈັບຄວາມຜິດປົກກະຕິ, ແລະ ເຄື່ອງສະແກນຄວາມປອດໄພແມ່ນການທົດສອບວິນິດໄສຕໍ່ສາຍເຫດການທີ່ມີອັດຕາຊຸກຊຸມຕ່ຳ ໂດຍຄວາມເມື່ອຍລ້າຈາກການແຈ້ງເຕືອນແມ່ນ[NNH](../ຈຳນວນທີ່ຕ້ອງຮັກສາ/). ການອັບເດດແບບຈຳລອງທີ່ຍ້າຍຈຸດປະຕິບັດການຈະເປີດເສດຖະສາດຄືນໃໝ່ (ແລະ ການອະນຸຍາດຂອງກົດລະບຽບ — ເບິ່ງ[ການປະເມີນດ້ານກົດລະບຽບຂອງ AI](../ການປະເມີນດ້ານກົດລະບຽບຂອງ-ai/)).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການເລືອກຊື້ AUROC**: ປຽບທຽບແບບຈຳລອງດ້ວຍ AUROC ທັງທີ່ມັນຈະເຮັດວຽກທີ່ເກນດຽວ — ໃຫ້ປຽບທຽບທີ່ຈຸດປະຕິບັດການ.
- **ອ້າງ PPV ຂອງອັດຕາຊຸກຊຸມໃນການທົດລອງສຳລັບການນຳໃຊ້ຈິງ** — ຄລາສສິກ; ຄິດໄລ່ໃໝ່ທີ່ອັດຕາຊຸກຊຸມທ້ອງຖິ່ນສະເໝີ.
- **ຄວາມລຳອຽງຂອງສະເປກຕຣຳ**: ແບບຈຳລອງທີ່ຢືນຢັນດ້ວຍກໍລະນີຊັດເຈນທຽບກັບຄົນສຸຂະພາບດີ ເຮັດວຽກເກີນຈິງໃນສ່ວນກາງທີ່ຄຸມເຄືອທີ່ຄອບງຳການປະຕິບັດຈິງ.
- **ບໍ່ຄິດຕົ້ນທຶນເສັ້ນທາງຕໍ່ເນື່ອງ**: ທຸກຜົນບວກກະຕຸ້ນການກວດຕໍ່; ແບບຈຳລອງແມ່ນການແຊກແຊງຕໍ່ເສດຖະສາດຂອງ*ເສັ້ນທາງທັງໝົດ*.
