# ຈຸດສິ້ນສຸດດິຈິຕອນ ແລະ ໄບໂອມາກເກີ

ໄບໂອມາກເກີດິຈິຕອນແມ່ນມາດຕະການທາງສະລີລະວິທະຍາ ຫຼື ພຶດຕິກຳທີ່ເປັນວັດຖຸວິໄສ ເກັບດ້ວຍເຊັນເຊີ (ຄວາມໄວການຍ່າງຈາກໂທລະສັບ, ການນອນຈາກອຸປະກອນສວມໃສ່, ອາການສັ່ນຈາກເຄື່ອງວັດຄວາມເລັ່ງ). ຈຸດສິ້ນສຸດດິຈິຕອນແມ່ນມາດຕະການດັ່ງກ່າວທີ່ຍົກຂຶ້ນເປັນ**ຜົນລັບຂອງການທົດລອງ** — ໃຊ້ສະແດງຜົນການປິ່ນປົວ. ການເລື່ອນຈາກ "ຂໍ້ມູນທີ່ອຸປະກອນປ່ອຍອອກ" ເປັນ "ຫຼັກຖານທີ່ຜູ້ກຳກັບດູແລຍອມຮັບ" ຜ່ານບັນໄດການກວດສອບທີ່ກຳນົດໄວ້.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຈຸດສິ້ນສຸດຂອງການທົດລອງແບບດັ້ງເດີມເປັນຊ່ວງໆ (ມາຄລີນິກທຸກ 3 ເດືອນ) ແລະ ແພງ; ຈຸດສິ້ນສຸດດິຈິຕອນຕໍ່ເນື່ອງ, ແບບນິເວດ (ຊີວິດຈິງ ບໍ່ແມ່ນການປະຕິບັດໃນຄລີນິກ), ແລະ ຖືກຕໍ່ການສັງເກດ — ມັນສາມາດຫຍໍ້ການທົດລອງ, ກວດພົບຜົນໄວຂຶ້ນ, ແລະ ເປີດໃຫ້ມີການສຶກສາແບບກະຈາຍສູນ. ຂໍ້ຈຳກັດແມ່ນການກວດສອບ: ກອບທີ່ຍອມຮັບ (ສອດຄ່ອງກັບ FDA, ສາມເສົາ) ຕ້ອງການ**ການກວດຢັ້ງຢືນ/ການກວດສອບດ້ານການວິເຄາະ** (ເຊັນເຊີວັດປະລິມານທາງກາຍະພາບຢ່າງຖືກຕ້ອງ), **ການກວດສອບທາງຄລີນິກ** (ມາດຕະການສະທ້ອນສະພາບຄລີນິກທີ່ອ້າງ), ແລະ **ດ້ານສຳຄັນຂອງສຸຂະພາບ**ທີ່ສະແດງໄດ້ (ຄົນເຈັບໃສ່ໃຈສິ່ງທີ່ມັນຈັບ). ຈຸດສິ້ນສຸດທີ່ບໍ່ມີທັງສາມແມ່ນເທເລເມທຣີ ບໍ່ແມ່ນຫຼັກຖານ.

## ຄະນິດສາດ

```
Analytical validation: agreement with reference (see wearable-validation.md —
                       MAPE, CCC, Bland-Altman)
Clinical validation:   correlation/discrimination against clinical anchors
                       (known-groups validity, responsiveness to change)
Endpoint economics:
  events detected per patient-year (continuous) vs per-visit sampling
  trial power: continuous measures cut sample size when between-visit
  variance dominates — N ∝ σ²/Δ², and σ² falls with dense sampling
```

## ຕົວຢ່າງການຄິດໄລ່

ການທົດລອງໂຣກພາກິນສັນພິຈາລະນາຄວາມໄວການຍ່າງຈາກເຊັນເຊີທີ່ຂໍ້ມື ທຽບກັບຄະແນນທີ່ແພດປະເມີນລາຍໄຕມາດ:

```
Clinic endpoint:  4 measurements/patient/year, high day-to-day noise
Digital endpoint: ~200 passive measurements/patient/year

Variance of the annual-change estimate falls ~5× with dense sampling →
detectable effect size at fixed power improves ~√5 ≈ 2.2×, or
equivalently sample size shrinks ~40–60% for the same hypothesis.
At £25,000 per enrolled patient, cutting 200 patients ≈ £5M saved
per trial — the commercial case for the validation investment
(itself perhaps £1–2M) across a sponsor's pipeline.
```

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ຈຸດສິ້ນສຸດດິຈິຕອນແມ່ນວິໄນວິສະວະກຳຂໍ້ມູນທີ່ແຕ່ງຕົວແບບຄລີນິກ: **ທີ່ມາແລະການຄວບຄຸມເວີຊັນ** (ການອັບເດດອັນກໍຣິທຶມກາງການສຶກສາຄຸກຄາມການປຽບທຽບໄດ້ — ບັນຫາ[PCCP](../ການປະເມີນດ້ານກົດລະບຽບຂອງ-ai/)ໃນຮູບການທົດລອງ; ລັອກເວີຊັນແລະກວດສອບຂົວຕໍ່); **ການອອກແບບຂໍ້ມູນທີ່ຂາດ** (ຊ່ອງຫວ່າງເວລາສວມໃສ່ມີຂໍ້ມູນ ບໍ່ແມ່ນສຸ່ມ — ເບິ່ງ[ການກວດສອບອຸປະກອນສວມໃສ່](../ການຢືນຢັນອຸປະກອນສວມໃສ່/); ທາງເລືອກການເຕີມຄ່າເປັນຂໍ້ອ້າງທາງວິທະຍາສາດ); ແລະ **ການຕັດສິນໃຈແບ່ງ edge/cloud** ທີ່ປ່ຽນວ່າສັນຍານດິບໃດຍັງກູ້ຄືນໄດ້ໃນພາຍຫຼັງ. ທີມທີ່ຖືທໍ່ການວັດເປັນຊອບແວທີ່ມີການຄວບຄຸມຕັ້ງແຕ່ມື້ທຳອິດ — ທົດສອບ, ມີເວີຊັນ, ມີເອກະສານ — ຊື້ຄວາມໜ້າເຊື່ອຖືຂອງຈຸດສິ້ນສຸດໃນລາຄາຖືກ; ການເພີ່ມການກວດສອບໃສ່ທໍ່ທີ່ເຄື່ອນໄວເກີນໄປຄືບ່ອນທີ່ໂຄງການຈຸດສິ້ນສຸດດິຈິຕອນຕາຍ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ສຳພັນກັບຄລີນິກເປັນການກວດສອບເຕັມ**: ກົງກັບມາດຕະການຄລີນິກທີ່ມີຂໍ້ບົກພ່ອງພິສູດການສືບທອດ ບໍ່ແມ່ນຄວາມຈິງ; ກວດສອບທຽບກັບດ້ານສຸຂະພາບທີ່ມີຄວາມໝາຍ.
- **ຄວາມສ່ຽງດ້ານກົດລະບຽບຂອງຈຸດສິ້ນສຸດໃໝ່**: ຈຸດສິ້ນສຸດທີ່ບໍ່ເຄີຍມີມາກ່ອນອາດດີກວ່າທາງວິທະຍາສາດແຕ່ຍັງເຮັດໃຫ້ການຍື່ນລົ້ມ — ຕິດຕໍ່ຜູ້ກຳກັບດູແລແຕ່ຕົ້ນ (ມີໂຄງການ qualification).
- **ເຊັນເຊີບໍ່ກົງກັບປະຊາກອນ**: ກວດສອບໃນຂໍ້ມືຂອງຄົນໜຸ່ມສຸຂະພາບດີ, ນຳໃຊ້ໃນຄົນເຈັບສູງອາຍຸທີ່ມີອາການສັ່ນແລະຄວາມແຕກຕ່າງຂອງເມລານິນທີ່ PPG ບໍ່ເຄີຍເຫັນ.
- **feature ລອຍ**: ຝຶກອັນກໍຣິທຶມການຍ່າງໃໝ່ດ້ວຍຂໍ້ມູນໃໝ່ ນິຍາມຈຸດສິ້ນສຸດໃໝ່ກາງການສຶກສາຢ່າງງຽບໆ.
