# ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດ ທຽບກັບ ທີ່ບໍ່ປົດປ່ອຍເງິນສົດ

ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດ (cash-releasing) ຫຼຸດລາຍຈ່າຍຈິງ — ແຖວງົບປະມານນ້ອຍລົງ. ການປະຢັດທີ່ບໍ່ປົດປ່ອຍເງິນສົດ (non-cash-releasing) ປົດປ່ອຍເວລາ ຫຼື ຄວາມສາມາດທີ່ຖືກ*ນຳກັບມາໃຊ້ຊ້ຳ*ແທນທີ່ຈະເກັບເປັນເງິນ. ຜູ້ອຳນວຍການການເງິນຂອງລະບົບສຸຂະພາບຖືສອງຢ່າງນີ້ເປັນຄົນລະຊະນິດ ແລະ ທ່ານກໍຄວນເຊັ່ນກັນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ນີ້ແມ່ນການທົດສອບຄວາມຊື່ສັດທີ່ແຫຼມທີ່ສຸດທີ່ນຳໃຊ້ກັບກໍລະນີທຸລະກິດດິຈິຕອນໃດໆໃນບໍລິການສຸຂະພາບແຫ່ງຊາດ. ກອບຜົນປະໂຫຍດຂອງ NHS ຈັດປະເພດທຸກຜົນປະໂຫຍດທີ່ອ້າງຢ່າງຊັດເຈນວ່າເປັນ ປົດປ່ອຍເງິນສົດ, ບໍ່ປົດປ່ອຍເງິນສົດ, ຫຼື ດ້ານຄຸນນະພາບ. "ເງິນປະຢັດ" ດ້ານສຸຂະພາບດິຈິຕອນສ່ວນໃຫຍ່ — ນາທີຂອງແພດທີ່ປະຢັດຕໍ່ຄົນເຈັບ, ການບັນທຶກເອກະສານທີ່ໄວຂຶ້ນ — ແມ່ນບໍ່ປົດປ່ອຍເງິນສົດ: ມີຄຸນຄ່າ ແຕ່ບໍ່ຫຼຸດຂາດດຸນ. CFO ຂອງ trust ທີ່ປະເຊີນກັບຊ່ອງຫວ່າງເງິນທຶນໃຊ້ໄດ້ສະເພາະເງິນສົດ. ເບິ່ງ[ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດຢ່າງແທ້ຈິງ](../ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດຢ່າງແທ້ຈິງ/)ນຳ.

## ຄະນິດສາດ

```
Cash-releasing saving   = budget line before − budget line after
                          (must be extractable: a cancelled contract, closed ward,
                           reduced agency spend, avoided purchase)

Non-cash-releasing value = time released × unit cost of that time
                          (valued at opportunity cost; the money is NOT extractable)
```

ເຫດການທາງກາຍະພາບດຽວກັນ (ໜຶ່ງຊົ່ວໂມງທີ່ປະຢັດ) ຕົກຢູ່ໃນໝວດໜຶ່ງຫຼືອີກໝວດ ຂຶ້ນກັບສິ່ງທີ່ເກີດຂຶ້ນຕໍ່ໄປ:

```
hour saved → overtime/agency shift cancelled        → cash-releasing
hour saved → clinician sees one more waiting patient → non-cash-releasing (capacity)
hour saved → absorbed into slack, nothing changes    → no benefit at all
```

## ຕົວຢ່າງການຄິດໄລ່

ຊອບແວປະຢັດພະຍາບານ 100 ຄົນ ຄົນລະ 30 ນາທີຕໍ່ເວນ. ນັ້ນແມ່ນ 100 × 0.5 × 5 ເວນ/ອາທິດ × 46 ອາທິດ ≈ 11,500 ຊົ່ວໂມງ/ປີ. ທີ່ຕົ້ນທຶນນາຍຈ້າງ Band 5 ~£25/ຊົ່ວໂມງ ຫົວຂໍ້ຂ່າວທີ່ຫຼອກລວງແມ່ນ £287,500/ປີ.

ການແບ່ງທີ່ຊື່ສັດ:

- 20% ຂອງເວລາຕົກຢູ່ບ່ອນທີ່ຫວອດຈ່າຍສ່ວນເພີ່ມບຸກຄະລາກອນສຳຮອງ/ຈ້າງຊົ່ວຄາວເພື່ອກວມການເຮັດເອກະສານເກີນເວລາ: 2,300 ຊົ່ວໂມງ × ອັດຕາຈ້າງຊົ່ວຄາວ £35 = **£80,500 ປົດປ່ອຍເງິນສົດ** (ເວນບໍ່ໄດ້ຈອງຈິງ).
- 60% ຖືກຍ້າຍໄປດູແລຄົນເຈັບໂດຍກົງ: 6,900 ຊົ່ວໂມງ × £25 = **£172,500 ຄວາມສາມາດທີ່ບໍ່ປົດປ່ອຍເງິນສົດ** — ຄຸນຄ່າຈິງ, ລາຍງານແຍກ, ບໍ່ເຄີຍເອີ້ນວ່າ "ເງິນປະຢັດ."
- 20% ສູນຫາຍໄປກັບເວລາພັກແລະການຖືກລົບກວນ: **£0**. ການອ້າງມັນແມ່ນນິຍາຍ.

ກໍລະນີທຸລະກິດທີ່ນຳສະເໜີເງິນສົດ £80.5k + ຄວາມສາມາດ £172.5k ໜ້າເຊື່ອຖື. ອັນທີ່ນຳສະເໜີ "ເງິນປະຢັດ" £287.5k ຖືກປະຕິເສດໂດຍນັກບັນຊີຄົນທຳອິດທີ່ອ່ານ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ຕັກກະດຽວກັນຄວບຄຸມ ROI ຂອງຜູ້ຊ່ວຍຂຽນໂຄດດ້ວຍ AI: "30 ນາທີຕໍ່ນັກພັດທະນາຕໍ່ມື້" ແມ່ນຄວາມສາມາດທີ່ບໍ່ປົດປ່ອຍເງິນສົດ ເວັ້ນແຕ່ຈຳນວນພະນັກງານ, ລາຍຈ່າຍຜູ້ຮັບເໝົາ, ຫຼື ຕົ້ນທຶນຄລາວຫຼຸດລົງຈິງ. ລາຍງານປະເພດແຍກກັນ:

- ປົດປ່ອຍເງິນສົດ: ຍົກເລີກການວ່າຈ້າງຜູ້ຮັບເໝົາ, ຢຸດໃບອະນຸຍາດເຄື່ອງມື, ຫຼຸດລາຍຈ່າຍຄລາວ.
- ຄວາມສາມາດ: ຄຸນສົມບັດທີ່ສົ່ງມອບໄວຂຶ້ນ (ຄຸນຄ່າຜ່ານ[ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ](../ຕົ້ນທຶນຂອງຄວາມລ່າຊ້າ/)), backlog ທີ່ຫຼຸດລົງ.
- ບໍ່ມີຫຍັງ: ນາທີທີ່ປະຢັດແຕ່ແຕກກະຈາຍໄປກັບການສະຫຼັບບໍລິບົດ.

ຍັງຕ້ອງຕິດຕາມ*ເວລາທີ່ປົດປ່ອຍໄປບ່ອນໃດແທ້* — ການເຮັດໃຫ້ຜົນປະໂຫຍດເກີດຂຶ້ນຈິງ ([benefits-realization.md](../ການເຮັດໃຫ້ຜົນປະໂຫຍດເກີດຂຶ້ນຈິງ/)) ມີຢູ່ເພາະການເພີ່ມຂຶ້ນຂອງຄວາມສາມາດທີ່ອ້າງມັກລະເຫີຍເມື່ອກວດສອບ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຄູນນາທີດ້ວຍເງິນເດືອນແລ້ວເອີ້ນວ່າເງິນປະຢັດ** — ບາບຄລາສສິກ.
- **ຕີມູນຄ່າເວລາທີ່ປົດປ່ອຍດ້ວຍຕົ້ນທຶນສະເລ່ຍທີ່ລວມຄ່າໃຊ້ຈ່າຍ** ເມື່ອການໃຊ້ສ່ວນເພີ່ມຂອງເວລານັ້ນມີຄຸນຄ່າຕ່ຳ — ເບິ່ງ[ຕົ້ນທຶນສ່ວນເພີ່ມເທິງຕົ້ນທຶນສະເລ່ຍ](../ຕົ້ນທຶນສ່ວນເພີ່ມ-ທຽບກັບ-ຕົ້ນທຶນສະເລ່ຍ/).
- **ນັບຊົ່ວໂມງດຽວກັນສອງເທື່ອ**: ເປັນເງິນສົດ (ເວນທີ່ຫຼີກລ່ຽງ) ແລະ ເປັນຄວາມສາມາດ (ເບິ່ງຄົນເຈັບເພີ່ມ).
