# ການວິເຄາະຕົ້ນທຶນ-ຜົນປະໂຫຍດ (CBA)

CBA ຕີມູນຄ່າທັງຕົ້ນທຶນ *ແລະ* ຜົນລັບເປັນເງິນ. ມັນເປັນປະເພດການວິເຄາະດຽວທີ່ຕອບໄດ້ວ່າ "ສິ່ງນີ້ຄຸ້ມຄ່າທີ່ຈະເຮັດເລີຍບໍ?" — ບໍ່ແມ່ນພຽງ "ທາງເລືອກໃດດີທີ່ສຸດ?" — ເພາະຜົນປະໂຫຍດທີ່ແປງເປັນເງິນປຽບທຽບກັບຕົ້ນທຶນໄດ້ໂດຍກົງ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

CBA ແມ່ນມາດຕະຖານຂອງ **Green Book** ຂອງ HM Treasury ອັງກິດ ສຳລັບການປະເມີນການໃຊ້ຈ່າຍສາທາລະນະທັງໝົດ ລວມສຸຂະພາບເມື່ອຜົນລັບແປງເປັນເງິນໄດ້. ບ່ອນທີ່ [CEA](../ການວິເຄາະຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນ/)/[CUA](../ການວິເຄາະຕົ້ນທຶນ-ອຣະຖະປະໂຫຍດ/) ຢຸດທີ່ "ຕົ້ນທຶນຕໍ່ຫົວໜ່ວຍສຸຂະພາບ" CBA ຕີລາຄາສຸຂະພາບເອງ (QALY × ມູນຄ່າເກນ) ແລະ ທຸກຢ່າງອື່ນ — ເວລາ, ການເດີນທາງ, ຄາບອນ — ແລ້ວລາຍງານຕົວເລກສຸດທິດຽວ. ທຸກກໍລະນີທຸລະກິດດິຈິຕອນຂອງ NHS ເຕັມຮູບແບບມີກໍລະນີເສດຖະກິດທີ່ມີຮູບຮ່າງຄື CBA.

## ຄະນິດສາດ

```
NPV (net present social value) = Σ_t [ (Benefits_t − Costs_t) / (1 + r)^t ]
BCR (benefit-cost ratio)       = PV(benefits) / PV(costs)

Adopt if NPV > 0 (equivalently BCR > 1); rank by NPV, not BCR.
r = 3.5% (Green Book social time preference rate)
```

ຜົນກະທົບດ້ານສຸຂະພາບເຂົ້າເປັນເງິນໄດ້ເປັນ QALY × λ (ເບິ່ງ[ເກນຄວາມເຕັມໃຈຈ່າຍ](../ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ/)). Green Book ຍັງບັງຄັບ**ການປັບ optimism-bias** — ເພີ່ມຄ່າຄາດການຕົ້ນທຶນແລະຫັກຜົນປະໂຫຍດດ້ວຍເປີເຊັນຈາກຫຼັກຖານ ເພາະການປະເມີນມັກເບິ່ງສົດໃສກວ່າຈິງຢ່າງເປັນລະບົບ.

## ຕົວຢ່າງການຄິດໄລ່

ລະບົບສົ່ງຕໍ່ອີເລັກໂທຣນິກ, ຂອບເຂດ 5 ປີ, ຫຼຸດມູນຄ່າ 3.5%:

```
Costs:    build £1.2M (year 0), run £300k/yr (years 1–5)
Benefits: admin savings £250k/yr, avoided duplicate diagnostics £280k/yr,
          patient time saved 40,000 hrs/yr × £15 = £600k/yr → £1,130k/yr

PV costs    = 1,200k + 300k × 4.515 (annuity factor) = £2,555k
PV benefits = 1,130k × 4.515                          = £5,102k

NPV = 5,102 − 2,555 = +£2,547k     BCR = 2.0
```

ນຳໃຊ້ optimism bias ຂອງ Green Book (ເຊັ່ນ +40% ຕໍ່ຕົ້ນທຶນສ້າງ, −20% ຕໍ່ຜົນປະໂຫຍດ): PV ຕົ້ນທຶນ ≈ £3,035k, PV ຜົນປະໂຫຍດ ≈ £4,082k, NPV ≈ **+£1,047k** — ຍັງເປັນບວກ ເຊິ່ງແມ່ນຈຸດປະສົງຂອງການປັບ: ກໍລະນີຄວນຢູ່ລອດຕໍ່ຄວາມຫວັງດີຂອງຕົນເອງ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ກໍລະນີທຸລະກິດດ້ານວິສະວະກຳແມ່ນ CBA ແບບບໍ່ເປັນທາງການ. ການຍົກລະດັບຂອງ Green Book ທີ່ຄວນຢືມ:

- **optimism bias ເປັນການເພີ່ມມາດຕະຖານ** — ວິສະວະກອນຄາດຕ່ຳຕົ້ນທຶນການຍ້າຍລະບົບຢ່າງສະໝ່ຳສະເໝີຄືກະຊວງຄາດຕ່ຳຕົ້ນທຶນໂຄງສ້າງພື້ນຖານ; ນຳໃຊ້ການເພີ່ມທີ່ລະບຸແທນການທຳທ່າວ່າເທື່ອນີ້ແຕກຕ່າງ.
- **ແປງຜົນປະໂຫຍດຫຼັກເປັນເງິນຢ່າງຊື່ສັດ ຫຼື ບໍ່ແປງເລີຍ** — ເວລາຂອງຄົນເຈັບ/ຜູ້ໃຊ້ແປງດ້ວຍອັດຕາທີ່ປ້ອງກັນໄດ້; "ມູນຄ່າແບຣນ" ບໍ່ແມ່ນ.
- **NPV ຈັດອັນດັບ, BCR ບໍ່ແມ່ນ**: ໂຄງການນ້ອຍທີ່ BCR 5 ອາດສຳຄັນໜ້ອຍກວ່າໂຄງການໃຫຍ່ທີ່ BCR 1.6.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ແປງສິ່ງທີ່ແປງບໍ່ໄດ້ເປັນເງິນ** ເພື່ອເພີ່ມຜົນປະໂຫຍດ (ຂວັນກຳລັງໃຈ, "ຄວາມສອດຄ່ອງດ້ານຍຸດທະສາດ") — ຮັກສາສິ່ງເຫຼົ່ານັ້ນເປັນດ້ານຄຸນນະພາບ ຕາມ[ການວິເຄາະຕົ້ນທຶນ-ຜົນຕາມມາ](../ການວິເຄາະຕົ້ນທຶນ-ຜົນທີ່ຕາມມາ/).
- **ນັບການໂອນເປັນຜົນປະໂຫຍດ**: ເງິນທີ່ຍ້າຍລະຫວ່າງໜ່ວຍງານລັດລວມເປັນສູນໃນ[ມຸມມອງ](../ມຸມມອງຂອງການວິເຄາະ/)ຂອງສັງຄົມ.
- **ບໍ່ມີກໍລະນີທຽບເຄິ່ງຈິງ**: ຜົນປະໂຫຍດວັດທຽບກັບທາງເລືອກທີ່ເຮັດໜ້ອຍສຸດ ບໍ່ແມ່ນທຽບກັບສູນ.
