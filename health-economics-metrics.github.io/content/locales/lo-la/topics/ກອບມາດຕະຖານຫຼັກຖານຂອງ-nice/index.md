# ກອບມາດຕະຖານຫຼັກຖານຂອງ NICE (ESF)

ESF ແມ່ນກອບຂອງ NICE ທີ່ລະບຸ **ເຕັກໂນໂລຢີສຸຂະພາບດິຈິຕອນຕ້ອງການຫຼັກຖານຫຼາຍປານໃດ, ສັດສ່ວນກັບຄວາມສ່ຽງ**. ມັນເປັນສິ່ງທີ່ໃກ້ຄຳຕອບທາງການທີ່ສຸດຕໍ່ "ເຮົາຕ້ອງພິສູດຫຍັງກ່ອນທີ່ NHS ຈະຊື້ແອັບຂອງເຮົາ?"

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ESF (ອອກຄັ້ງທຳອິດປີ 2019, ປັບປຸງປີ 2022 ໃຫ້ຄຸມ AI ແລະ ອັລກໍຣິທຶມປັບຕົວ) ຈັດປະເພດເຕັກໂນໂລຢີສຸຂະພາບດິຈິຕອນເປັນລະດັບຕາມໜ້າທີ່ທາງຄລີນິກ, ດ້ວຍມາດຕະຖານຫຼັກຖານ **ສະສົມ** — 21 ມາດຕະຖານໃນ 5 ກຸ່ມ (ປັດໄຈການອອກແບບ, ມູນຄ່າ, ປະສິດທິພາບ/ປະສິດທິຜົນ, ຜົນກະທົບດ້ານເສດຖະກິດ, ການນຳໃຊ້):

```
Tier A — system services, no direct patient outcome (e.g., e-rostering)
         → basic standards: credibility, data protection, technical assurance
Tier B — inform, simple monitoring, communication (e.g., symptom diary)
         → + evidence of user benefit, appropriate reliability
Tier C — treat, diagnose, or actively guide clinical management
         → + high-quality comparative effectiveness evidence (ideally RCT)
           and economic analysis
```

ສຳລັບຫຼັກຖານດ້ານເສດຖະກິດ, [ການວິເຄາະຕົ້ນທຶນ-ຜົນທີ່ຕາມມາ](../ການວິເຄາະຕົ້ນທຶນ-ຜົນທີ່ຕາມມາ/) ຍອມຮັບໄດ້ສຳລັບລະດັບສ່ວນໃຫຍ່; [ການວິເຄາະຕົ້ນທຶນ-ອຣະຖະປະໂຫຍດ](../ການວິເຄາະຕົ້ນທຶນ-ອຣະຖະປະໂຫຍດ/) ຖືກຄາດຫວັງທີ່ຄວາມສ່ຽງສູງສຸດ. ESF ກຳນົດ **ຕົ້ນທຶນຫຼັກຖານຂອງການເຂົ້າຕະຫຼາດ** ຂອງທ່ານ — ຈັດງົບມັນຄືກັບຕົ້ນທຶນການສ້າງອື່ນໆ.

## ຄະນິດສາດ

ບໍ່ມີສູດ — ເປັນຕາຕະລາງການຕັດສິນໃຈ. ການຄິດໄລ່ທີ່ໃຊ້ງານແມ່ນດ້ານການຄ້າ:

```
Evidence investment required = f(tier)
  Tier A: documentation + assurance ≈ £10k–50k
  Tier B: observational/comparative user-benefit study ≈ £50k–250k
  Tier C: RCT-grade comparative study + economic model ≈ £250k–£2M+

Position your product's claims deliberately: claiming "supports clinical
decisions" instead of "informs patients" moves you a tier and can 10× the bill.
```

## ຕົວຢ່າງການຄິດໄລ່

ຜູ້ສ້າງແອັບເຕືອນຢາພິຈາລະນາເພີ່ມຄຸນສົມບັດແນະນຳການປັບປະລິມານຢາ.

- ໃນຖານະແອັບເຕືອນ: **ລະດັບ B** — ການສຶກສາກຸ່ມທີ່ສະແດງການປັບປຸງການປະຕິບັດຕາມກໍພຽງພໍ.
- ພ້ອມຄຳແນະນຳປະລິມານ: **ລະດັບ C** — ຫຼັກຖານປະສິດທິຜົນປຽບທຽບ (ອາດເປັນ RCT ທຽບກັບການດູແລປົກກະຕິ) ບວກການວິເຄາະເສດຖະກິດ.

ຖ້າ RCT ມີຕົ້ນທຶນ £600k ແລະ ລາຍຮັບສ່ວນເພີ່ມຂອງຄຸນສົມບັດປະລິມານແມ່ນ £200k/ປີ, ຄຸນສົມບັດຕ້ອງຮັກສາມູນຄ່າ 3+ ປີກ່ອນຕົ້ນທຶນຫຼັກຖານຄຸ້ມທຶນ — ການຕັດສິນໃຈຜະລິດຕະພັນທີ່ເບິ່ງຕ່າງກັນຢ່າງສິ້ນເຊີງເມື່ອຄິດລາຄາລະດັບ ESF ແລ້ວ. ຫຼາຍທີມສົ່ງມອບຜະລິດຕະພັນລະດັບ B ແລະ ຈັດຂັ້ນການອ້າງລະດັບ C ໄວ້ຫຼັງການໄດ້ຮັບທຶນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ESF ແມ່ນແບບແຜນການກຳກັບດູແລທີ່ໂອນໄປໃຊ້ໄດ້ຫຼາຍທີ່ສຸດໃນບ່ອນເກັບນີ້: **ຄວາມຕ້ອງການຫຼັກຖານແບບແບ່ງລະດັບຕາມຄວາມສ່ຽງສຳລັບການຮັບເອົາເຄື່ອງມື**. ລຸ້ນພາຍໃນ: ຕົວຈັດຮູບແບບໂຄ້ດຕ້ອງການການສາທິດ (ລະດັບ A); ເຄື່ອງມືຜະລິດຕະພາບທີ່ອ້າງປະຢັດຊົ່ວໂມງຕ້ອງການໂຄງການທົດລອງທີ່ວັດແທກ (ລະດັບ B); ປະຕູ AI ທີ່ບລັອກ deploy ອັດຕະໂນມັດ ຫຼື ຂຽນໂຄ້ດຄລີນິກອັດຕະໂນມັດຕ້ອງການຫຼັກຖານລະດັບການທົດລອງຄວບຄຸມກ່ອນນຳໃຊ້ທົ່ວອົງກອນ (ລະດັບ C). ຫຼັກຖານທີ່ສັດສ່ວນຢຸດທັງສອງຮູບແບບຄວາມລົ້ມເຫຼວ — ລະບົບລາຊະການບີບຄໍເຄື່ອງມືທີ່ບໍ່ສຳຄັນ, ແລະ ຄວາມຮູ້ສຶກສົ່ງມອບສິ່ງທີ່ມີຜົນຕາມມາ. ເບິ່ງ [ເສັ້ນທາງລັດ DiGA](../ເສັ້ນທາງລັດ-diga-ຂອງເຢຍລະມັນ/) ສຳລັບສ່ວນເສີມ "ການຮັບເອົາຊົ່ວຄາວພ້ອມກຳນົດເວລາຫຼັກຖານ".

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຈັດລະດັບຜິດດ້ວຍຄວາມຫວັງ** — ຜູ້ຄວບຄຸມ ແລະ ຜູ້ຊື້ຈັດປະເພດຕາມສິ່ງທີ່ຜະລິດຕະພັນ *ເຮັດ*, ບໍ່ແມ່ນສິ່ງທີ່ການຕະຫຼາດເວົ້າ.
- **ສ້າງຫຼັກຖານຫຼັງຜະລິດຕະພັນ**: ການເພີ່ມ RCT ໃສ່ຜະລິດຕະພັນທີ່ສົ່ງມອບແລ້ວໂດຍບໍ່ມີເຄື່ອງມືວັດ ຫຼື equipoise ຊ້າ ແລະ ມັກເປັນໄປບໍ່ໄດ້.
- **ບັນລຸ ESF ແລ້ວລືມສ່ວນທີ່ເຫຼືອ**: ESF ຢູ່ຄຽງຂ້າງ DTAC (ຄວາມປອດໄພທາງຄລີນິກ, ການປົກປ້ອງຂໍ້ມູນ, ການເຮັດວຽກຮ່ວມກັນ) ແລະ ສຳລັບ AI, ການອະນຸມັດຕາມກົດລະບຽບ — ເບິ່ງ [ການປະເມີນດ້ານກົດລະບຽບຂອງ AI](../ການປະເມີນດ້ານກົດລະບຽບຂອງ-ai/).
