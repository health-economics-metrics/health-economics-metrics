# Ανάλυση κόστους-οφέλους (CBA)

Η CBA αποτιμά σε χρήμα τόσο τα κόστη *όσο* και τις εκβάσεις. Είναι το μόνο είδος ανάλυσης που μπορεί να απαντήσει «αξίζει να γίνει καθόλου;» — όχι απλώς «ποια επιλογή είναι η καλύτερη;» — επειδή τα νομισματοποιημένα οφέλη μπορούν να συγκριθούν άμεσα με τα κόστη.

## Γιατί έχει σημασία

Η CBA είναι το πρότυπο του **Green Book** του HM Treasury του ΗΒ για κάθε αξιολόγηση δημόσιας δαπάνης, συμπεριλαμβανομένης της υγείας όταν οι εκβάσεις μπορούν να νομισματοποιηθούν. Όπου η [CEA](../ανάλυση-κόστους-αποτελεσματικότητας/)/[CUA](../ανάλυση-κόστους-χρησιμότητας/) σταματούν στο «κόστος ανά μονάδα υγείας», η CBA τιμολογεί την ίδια την υγεία (QALY × τιμή κατωφλίου) και όλα τα άλλα — χρόνο, μετακινήσεις, άνθρακα — και αναφέρει ένα καθαρό μέγεθος. Κάθε πλήρης ψηφιακή επιχειρηματική περίπτωση του NHS περιέχει μια οικονομική περίπτωση σε μορφή CBA.

## Τα μαθηματικά

```
NPV (net present social value) = Σ_t [ (Benefits_t − Costs_t) / (1 + r)^t ]
BCR (benefit-cost ratio)       = PV(benefits) / PV(costs)

Adopt if NPV > 0 (equivalently BCR > 1); rank by NPV, not BCR.
r = 3.5% (Green Book social time preference rate)
```

Οι επιδράσεις στην υγεία μπορούν να εισέλθουν νομισματοποιημένες ως QALY × λ (βλ. [κατώφλια προθυμίας πληρωμής](../κατώφλια-προθυμίας-πληρωμής/)). Το Green Book επιβάλλει επίσης **προσαρμογές μεροληψίας αισιοδοξίας** — αύξηση των εκτιμήσεων κόστους και μείωση των οφελών κατά ποσοστά βάσει τεκμηρίων, επειδή οι αξιολογήσεις είναι συστηματικά ρόδινες.

## Αναλυτικό παράδειγμα

Ένα σύστημα ηλεκτρονικής παραπομπής, ορίζοντας 5 ετών, προεξόφληση 3,5%:

```
Costs:    build £1.2M (year 0), run £300k/yr (years 1–5)
Benefits: admin savings £250k/yr, avoided duplicate diagnostics £280k/yr,
          patient time saved 40,000 hrs/yr × £15 = £600k/yr → £1,130k/yr

PV costs    = 1,200k + 300k × 4.515 (annuity factor) = £2,555k
PV benefits = 1,130k × 4.515                          = £5,102k

NPV = 5,102 − 2,555 = +£2,547k     BCR = 2.0
```

Εφαρμόστε τη μεροληψία αισιοδοξίας του Green Book (ας πούμε +40% στο κόστος κατασκευής, −20% στα οφέλη): PV κόστους ≈ £3.035k, PV οφελών ≈ £4.082k, NPV ≈ **+£1.047k** — παραμένει θετικό, που είναι και το νόημα της προσαρμογής: οι περιπτώσεις πρέπει να επιβιώνουν της δικής τους αισιοδοξίας.

## Σύνδεση με τη μηχανική λογισμικού

Οι επιχειρηματικές περιπτώσεις μηχανικής είναι άτυπες CBA. Οι αναβαθμίσεις του Green Book που αξίζει να κλέψετε:

- **Μεροληψία αισιοδοξίας ως τυπική αύξηση** — οι μηχανικοί υποτιμούν το κόστος μετάβασης τόσο αξιόπιστα όσο τα υπουργεία το κόστος υποδομών· εφαρμόστε δηλωμένη αύξηση αντί να προσποιείστε ότι αυτή τη φορά είναι διαφορετικά.
- **Νομισματοποιήστε το κυρίαρχο όφελος έντιμα ή καθόλου** — ο χρόνος ασθενούς/χρήστη νομισματοποιείται με υπερασπίσιμες τιμές· η «αξία μάρκας» όχι.
- **Το NPV κατατάσσει, το BCR όχι**: ένα μικροσκοπικό έργο με BCR 5 μπορεί να μετράει λιγότερο από ένα μεγάλο με BCR 1,6.

## Παγίδες

- **Νομισματοποίηση του ανεκτίμητου** για φούσκωμα των οφελών (ηθικό, «στρατηγική ευθυγράμμιση») — κρατήστε τα ποιοτικά, σύμφωνα με την [ανάλυση κόστους-συνεπειών](../ανάλυση-κόστους-συνεπειών/).
- **Καταμέτρηση μεταβιβάσεων ως οφελών**: χρήματα που μετακινούνται μεταξύ δημόσιων φορέων συμψηφίζονται σε μηδέν στην κοινωνική [οπτική](../οπτική-της-ανάλυσης/).
- **Καμία αντιπαραδειγματική βάση**: τα οφέλη μετριούνται έναντι της επιλογής ελάχιστης παρέμβασης, όχι έναντι του μηδενός.
