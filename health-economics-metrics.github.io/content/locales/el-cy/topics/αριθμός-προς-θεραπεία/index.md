# Αριθμός προς θεραπεία (NNT)

Ο NNT είναι ο αριθμός των ασθενών που πρέπει να λάβουν μια παρέμβαση ώστε **ένας** επιπλέον ασθενής να ωφεληθεί, σε δηλωμένο χρονικό πλαίσιο. Μετατρέπει τις ποσοστιαίες μειώσεις κινδύνου — που παραπλανούν — σε μονάδες προσπάθειας-ανά-όφελος για τις οποίες μπορεί να συλλογιστεί ο καθένας.

## Γιατί έχει σημασία

Το «Μειώνει τα εμφράγματα κατά 25%!» ακούγεται καθοριστικό. Αν ο βασικός κίνδυνος είναι 4% σε 5 έτη, η απόλυτη μείωση είναι 1 ποσοστιαία μονάδα, οπότε **100 άτομα πρέπει να παίρνουν το φάρμακο για 5 έτη για να ωφεληθεί 1** — και και τα 100 πληρώνουν τα κόστη και τις παρενέργειες. Ο NNT είναι το αντίδοτο στο μάρκετινγκ σχετικού κινδύνου, γι' αυτό η ιατρική βασισμένη σε τεκμήρια ξεκινά με αυτόν. Στατίνες για πρωτογενή πρόληψη: NNT ≈ 50–100 σε 5 έτη ανά έμφραγμα που αποφεύγεται. Ο καθρέφτης του, ο **NNH** (αριθμός προς βλάβη), μετρά πόσοι θεραπευόμενοι ανά άτομο που βλάπτεται.

## Τα μαθηματικά

```
ARR = control event rate − treatment event rate   (absolute risk reduction)
NNT = 1 / ARR

NNH = 1 / (harm rate_treatment − harm rate_control)

Economic bridge:
cost per event prevented = NNT × cost per treatment course
```

Δηλώνετε πάντα το χρονικό πλαίσιο και τον βασικό πληθυσμό — ο NNT δεν έχει νόημα χωρίς και τα δύο.

## Αναλυτικό παράδειγμα

Ένα σύστημα πρόβλεψης πτώσεων σε νοσοκομείο επισημαίνει ασθενείς υψηλού κινδύνου για παρέμβαση (αισθητήρες κλίνης, ανασκόπηση, επίβλεψη). Δοκιμή: οι πτώσεις με τραυματισμό πέφτουν από 3,2% σε 2,4% των εισαγωγών.

```
ARR = 0.8 percentage points → NNT = 1/0.008 = 125
   (125 patients must get the intervention bundle to prevent 1 injurious fall)

Intervention cost ≈ £40/patient → cost per fall prevented = 125 × 40 = £5,000
Cost of an injurious inpatient fall (extra stay, imaging, litigation) ≈ £12,000
Net: prevention pays ~2.4:1 — and the QALY gain is on top.
```

Παρατηρήστε πώς ο NNT κρατά τον ισχυρισμό έντιμο: το «μειώνει τις πτώσεις κατά 25%» και το «αποτρέπει μία πτώση ανά 125 θεραπευόμενους ασθενείς» είναι το ίδιο αποτέλεσμα, διαφορετικά πειστικό.

## Σύνδεση με τη μηχανική λογισμικού

Ο NNT είναι η σωστή μονάδα για κάθε πύλη ή έλεγχο που ενεργεί σε πολλά αντικείμενα για να πιάσει λίγα: **«αριθμός PR που πρέπει να περάσουν από την πύλη ανασκόπησης AI για να πιαστεί ένα ελάττωμα που οδεύει προς παραγωγή».** Αν η πύλη ελέγχει 400 PR ανά πραγματικό εύρημα (NNT = 400) με 4 λεπτά προσοχής προγραμματιστή το καθένα, ένα εύρημα κοστίζει ~27 ώρες προγραμματιστή — τώρα συγκρίνετέ το με το κόστος συμβάντος που αποτρέπει. Ο NNH αντιστοιχεί σε ψευδώς θετικά: πόσα PR ανά *ψευδή* επισήμανση, και τι κοστίζει καθένα σε προσοχή και εμπιστοσύνη; Τα εργαλεία τύπου προσυμπτωματικού ελέγχου (linters, σαρωτές ασφάλειας, ανίχνευση ανωμαλιών) πρέπει να κυκλοφορούν με αριθμητική NNT/NNH — βλ. [οικονομική του προσυμπτωματικού ελέγχου](../οικονομία-προληπτικού-ελέγχου/) για το γιατί η χαμηλή συχνότητα κάνει αυτούς τους αριθμούς βάναυσους. Ο [αριθμός προς έλεγχο](../αριθμός-προς-έλεγχο/) είναι το ανάλογο μέγεθος ένα επίπεδο πάνω, για ολόκληρο πρόγραμμα ελέγχου-και-μετά-θεραπείας αντί για θεραπεία μόνη.

## Παγίδες

- **Χωρίς χρονικό πλαίσιο**: το «NNT = 50» δεν σημαίνει τίποτα· το «NNT = 50 σε 5 έτη» είναι ισχυρισμός.
- **Μεταφύτευση βασικού κινδύνου**: ο NNT που υπολογίζεται σε πληθυσμό δοκιμής υψηλού κινδύνου καταρρέει σε πληθυσμό ανάπτυξης χαμηλού κινδύνου.
- **Αγνόηση του NNH** — μια πύλη με NNT 400 και NNH 3 είναι γεννήτρια ενοχλήσεων, όχι σύστημα ασφάλειας.
