# Καθαρό Νομισματικό Όφελος (NMB)

Το NMB μετατρέπει ένα αποτέλεσμα κόστους-αποτελεσματικότητας σε μία ενιαία χρηματική αξία: το κέρδος υγείας τιμολογημένο στο όριο προθυμίας πληρωμής, μείον το κόστος. Το δίδυμό του, το Καθαρό Όφελος Υγείας (NHB), εκφράζει τον ίδιο κανόνα σε μονάδες υγείας.

## Γιατί έχει σημασία

Οι λόγοι ([ICER](../αυξητικός-λόγος-κόστους-αποτελεσματικότητας/)) είναι άβολοι: εκρήγνυνται κοντά στο μηδενικό αποτέλεσμα, δεν μπορούν να υπολογιστούν κατά μέσο όρο σε δείγματα αβεβαιότητας και δεν μπορούν να κατατάξουν καθαρά τρεις ή περισσότερες επιλογές. Το NMB τα διορθώνει όλα — είναι γραμμικό, οπότε μπορείτε να κατατάξετε επιλογές, να υπολογίσετε μέσο όρο δειγμάτων Monte Carlo και να αναλύσετε τις συνεισφορές. Είναι επίσης η μορφή μαθηματικών οικονομίας της υγείας που κάθε μηχανικός ήδη γνωρίζει: *αξία μείον κόστος*.

## Τα μαθηματικά

```
NMB = (ΔE × λ) − ΔC
NHB = ΔE − (ΔC / λ)

ΔE = αυξητικό αποτέλεσμα (π.χ. QALY)
ΔC = αυξητικό κόστος
λ  = όριο προθυμίας πληρωμής (βλ. willingness-to-pay-thresholds.md)

Κανόνας απόφασης: υιοθετήστε αν NMB > 0 (ισοδύναμα NHB > 0).
Μεταξύ εναλλακτικών: επιλέξτε το υψηλότερο NMB.
```

NMB > 0 ⇔ ICER < λ (όταν ΔE > 0), οπότε οι δύο κανόνες συμφωνούν — το NMB απλώς συμπεριφέρεται καλύτερα.

## Αναλυτικό παράδειγμα

Τρεις επιλογές για μια υπηρεσία διαβήτη, ανά 1,000 ασθενείς, λ = £20,000/QALY:

```
Επιλογή           ΔC          ΔE (QALY)    NMB = 20,000×ΔE − ΔC
Εφαρμογή + καθοδήγηση £400,000  30         600,000 − 400,000 = £200,000
Μόνο εφαρμογή     £150,000    12           240,000 − 150,000 = £90,000
Επιπλέον κλινικές £700,000    32           640,000 − 700,000 = −£60,000
```

Οι επιπλέον κλινικές κερδίζουν τα περισσότερα QALY αλλά καταστρέφουν αξία σε αυτό το όριο (NMB < 0). Η εφαρμογή + καθοδήγηση κερδίζει. Σημειώστε ότι το NMB σας επιτρέπει να *κατατάξετε και τις τρεις ταυτόχρονα* — τα ζευγαρωτά ICER θα χρειάζονταν τη διαδικασία του μετώπου στο [κυριαρχία και μέτωπο αποδοτικότητας](../κυριαρχία-και-μέτωπο-αποδοτικότητας/), και καταλήγουν στην ίδια απάντηση.

Όψη NHB του νικητή: 30 − 400,000/20,000 = 30 − 20 = **10 QALY καθαρά** — η υγεία που κερδήθηκε πέραν όσης θα παρήγαγαν τα ίδια χρήματα αλλού.

## Σύνδεση με τη μηχανική λογισμικού

Το `(ώρες που εξοικονομήθηκαν × φορτωμένη ωριαία τιμή) − κόστος εργαλείου` — η καθημερινή επιχειρηματική περίπτωση εργαλείων — είναι κυριολεκτικά υπολογισμός NMB με λ = φορτωμένο κόστος μηχανικού. Δύο αναβαθμίσεις που προσθέτει η οικονομία της υγείας:

- **Κάντε το λ μεταβλητή, όχι σταθερά.** Σχεδιάστε το NMB έναντι του λ («αξία μιας μηχανικο-ώρας») και δείξτε πού αντιστρέφεται η απόφαση· διαφορετικοί ενδιαφερόμενοι μπορούν τότε να εφαρμόσουν τη δική τους αποτίμηση χωρίς να ξαναφτιάξουν τα μαθηματικά σας.
- **Σκέψη NHB**: «αυτή η πλατφόρμα εξοικονομεί 5,000 μηχανικο-ώρες αλλά καταναλώνει προϋπολογισμό που θα αγόραζε 3,000 μηχανικο-ώρες χωρητικότητας εργολάβων — καθαρά 2,000 ώρες» επιβάλλει τη σύγκριση κόστους ευκαιρίας σε μονάδες χωρητικότητας. Βλ. [κόστος ευκαιρίας](../κόστος-ευκαιρίας/).

## Παγίδες

- **Απόκρυψη του ορίου**: ένα NMB δεν έχει νόημα χωρίς δήλωση του λ· αναφέρετε το NMB στα £20k και £30k, ή σχεδιάστε την καμπύλη.
- **Χρήση του NMB για νομιμοποίηση μικροσκοπικών αποτελεσμάτων**: ένας τεράστιος πληθυσμός επί αμελητέο αποτέλεσμα ανά άτομο μπορεί να παράγει μεγάλο NMB — αναφέρετε τα αποτελέσματα ανά άτομο παράλληλα.
- **Λήθη ότι το NMB κληρονομεί κάθε αβεβαιότητα** στα ΔC και ΔE — συνδυάστε με [πιθανοτική ανάλυση ευαισθησίας](../πιθανοτική-ανάλυση-ευαισθησίας/).
