# Οριακό έναντι Μέσου Κόστους

Το μέσο κόστος είναι το συνολικό κόστος διά των μονάδων που παράγονται. Το οριακό κόστος είναι το κόστος παραγωγής μίας *επιπλέον* μονάδας. Οι αποφάσεις πρέπει να λαμβάνονται με βάση το οριακό κόστος — αλλά τα δημοσιευμένα κόστη μονάδας είναι σχεδόν πάντα μέσοι όροι.

## Γιατί έχει σημασία

Το πιο συνηθισμένο σφάλμα στις επιχειρηματικές περιπτώσεις ψηφιακής υγείας είναι η αποτίμηση ενός εξοικονομημένου πόρου με το **μέσο** κόστος του όταν η πραγματική εξοικονόμηση είναι το **οριακό** κόστος. Μια ημέρα νοσηλείας έχει μέσο (πλήρως απορροφημένο) κόστος £400+, αλλά η αποδέσμευση μίας ημέρας νοσηλείας δεν εξοικονομεί £400 — το κτίριο, η θέρμανση και το μεγαλύτερο μέρος του κόστους στελέχωσης συνεχίζονται. Τα μετρητά που πράγματι αποδεσμεύονται μπορεί να είναι £50–£150 εκτός αν αποδεσμευτούν αρκετά κρεβάτια ώστε να κλείσει ένας θάλαμος.

## Τα μαθηματικά

```
Μέσο κόστος:    AC = TC / Q
Οριακό κόστος:  MC = dTC/dQ   (κόστος μίας επιπλέον/λιγότερης μονάδας)

TC = συνολικό κόστος, Q = ποσότητα
```

Τα πάγια κόστη κάνουν MC < AC για μειώσεις χωρητικότητας, και το MC μπορεί να πλησιάζει το μηδέν όταν υπάρχει αδρανής χωρητικότητα. Οι ισχυρισμοί εξοικονόμησης πρέπει να χρησιμοποιούν:

```
Πραγματική εξοικονόμηση = ΔQ × MC          (μικρές αλλαγές)
Πραγματική εξοικονόμηση = βηματική αλλαγή στο TC (μεγάλες αλλαγές που περνούν όριο χωρητικότητας, π.χ. κλείσιμο θαλάμου)
```

## Αναλυτικό παράδειγμα

Το λογισμικό σας μειώνει το μέσο μήκος παραμονής, αποδεσμεύοντας 1,000 ημέρες νοσηλείας/έτος σε ένα trust.

- **Αφελής ισχυρισμός**: 1,000 × £400 μέσο κόστος = **£400,000 εξοικονόμηση**. Λάθος.
- **Οριακός ισχυρισμός**: μεταβλητό κόστος ανά ημέρα νοσηλείας (φαγητό, πλυντήριο, αναλώσιμα, κάποια ευέλικτη νοσηλευτική) ≈ £120. Εξοικονόμηση = 1,000 × £120 = **£120,000**, *συν* την αξία της αποδεσμευμένης χωρητικότητας αν τα κρεβάτια ξαναγεμίσουν με ασθενείς προγραμματισμένων επεμβάσεων που περιμένουν (έσοδα υπό πληρωμή βάσει δραστηριότητας, ή μείωση λίστας αναμονής).
- **Ισχυρισμός βηματικής αλλαγής**: αν το trust αποδεσμεύσει 7,300 ημέρες νοσηλείας/έτος (θάλαμος 20 κρεβατιών) μπορεί πράγματι να κλείσει τον θάλαμο: στελέχωση + λειτουργία ≈ £1.5 εκατομμύριο/έτος πραγματικών μετρητών. Τώρα η αριθμητική μέσου κόστους είναι πιο κοντά στην αλήθεια.

Η ίδια παρέμβαση, τρεις υπερασπίσιμοι αριθμοί, ανάλογα με το αν η αλλαγή περνά ένα βήμα χωρητικότητας.

## Σύνδεση με τη μηχανική λογισμικού

Η οικονομία του cloud είναι εγγενώς πεδίο οριακού κόστους:

- Το οριακό κόστος μίας ακόμη εκτέλεσης CI σε ήδη δεσμευμένη χωρητικότητα είναι ≈ £0, ενώ το μέσο κόστος ανά εκτέλεση (συνολική δαπάνη πλατφόρμας ÷ εκτελέσεις) μπορεί να είναι λίρες. Τα συστήματα επιμερισμού που χρεώνουν μέσο κόστος οδηγούν τις ομάδες σε υποχρήση κοινής χωρητικότητας που στο περιθώριο είναι στην πραγματικότητα δωρεάν.
- Αντιστρόφως, το «εξοικονομήσαμε 30% υπολογιστικής ισχύος» αποδεσμεύει μετρητά μόνο αν τα instances πράγματι τερματιστούν ή οι δεσμεύσεις μειωθούν — η εκδοχή λογισμικού της παγίδας της ημέρας νοσηλείας. Βλ. [εξοικονομήσεις με αποδέσμευση μετρητών έναντι χωρίς αποδέσμευση](../ταμειακά-απελευθερώσιμες-έναντι-μη-ταμειακά-απελευθερώσιμων-εξοικονομήσεων/).

## Παγίδες

- **Αποτίμηση χωρητικότητας με μέσο κόστος** και παρουσίασή της ως μετρητά (το κλασικό).
- **Υπόθεση ότι το οριακό κόστος είναι σταθερό.** Κάνει βήματα στα όρια χωρητικότητας (κλεισίματα θαλάμων, βαθμίδες αδειών, δεσμεύσεις reserved-instance).
- **Χρήση οριακού κόστους για αποφάσεις επέκτασης αλλά μέσου για συρρίκνωση** στην ίδια περίπτωση — διαλέξτε σύμφωνα με την πραγματική απόφαση.
