# उपचारासाठी आवश्यक संख्या (NNT)

NNT म्हणजे निर्दिष्ट कालावधीत **एका** अतिरिक्त रुग्णाला लाभ मिळण्यासाठी हस्तक्षेप घ्यावा लागणाऱ्या रुग्णांची संख्या. ती दिशाभूल करणाऱ्या टक्केवारी जोखीम घटींचे रूपांतर कोणालाही समजू शकणाऱ्या प्रयत्न-प्रति-लाभ एककांत करते.

## हे का महत्त्वाचे आहे

"हृदयविकाराचे झटके 25% कमी करते!" निर्णायक वाटते. 5 वर्षांत मूलभूत धोका 4% असेल, तर निरपेक्ष घट 1 टक्केवारी बिंदू आहे, म्हणजे **1 जणाला लाभ मिळण्यासाठी 100 जणांना 5 वर्षे औषध घ्यावे लागते** — आणि सर्व 100 खर्च आणि दुष्परिणाम सोसतात. NNT हे सापेक्ष-जोखीम विपणनावरील उतारा आहे, म्हणूनच पुरावा-आधारित वैद्यकशास्त्र त्यापासून सुरुवात करते. प्राथमिक प्रतिबंधासाठी स्टॅटिन्स: टाळलेल्या प्रति हृदयविकार झटक्यासाठी 5 वर्षांत NNT ≈ 50–100. त्याचे प्रतिबिंब, **NNH** (हानीसाठी आवश्यक संख्या), एका व्यक्तीला हानी होण्यामागे किती उपचारित हे मोजते.

## गणित

```
ARR = control event rate − treatment event rate   (absolute risk reduction)
NNT = 1 / ARR

NNH = 1 / (harm rate_treatment − harm rate_control)

Economic bridge:
cost per event prevented = NNT × cost per treatment course
```

नेहमी कालावधी आणि मूलभूत लोकसंख्या नमूद करा — दोन्हीशिवाय NNT निरर्थक आहे.

## सोडवलेले उदाहरण

रुग्णालयातील पडण्याची-भविष्यवाणी प्रणाली उच्च-जोखीम रुग्णांना हस्तक्षेपासाठी (खाट सेन्सर्स, पुनरावलोकन, देखरेख) चिन्हांकित करते. चाचणी: दुखापतीसह पडणे दाखल्यांच्या 3.2% वरून 2.4% पर्यंत घटते.

```
ARR = 0.8 percentage points → NNT = 1/0.008 = 125
   (125 patients must get the intervention bundle to prevent 1 injurious fall)

Intervention cost ≈ £40/patient → cost per fall prevented = 125 × 40 = £5,000
Cost of an injurious inpatient fall (extra stay, imaging, litigation) ≈ £12,000
Net: prevention pays ~2.4:1 — and the QALY gain is on top.
```

NNT दावा कसा प्रामाणिक ठेवतो ते पहा: "पडणे 25% कमी करते" आणि "उपचारित प्रत्येक 125 रुग्णांमागे एक पडणे टाळते" हाच निकाल आहे, फक्त वेगळ्या प्रकारे पटवणारा.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

थोडे पकडण्यासाठी अनेक वस्तूंवर कृती करणाऱ्या कोणत्याही गेट किंवा तपासणीसाठी NNT हे योग्य एकक आहे: **"AI रिव्ह्यू गेटमधून उत्पादनाकडे जाणारा एक दोष पकडण्यासाठी किती PR जावे लागतात."** गेट प्रत्येक खऱ्या पकडीमागे 400 PR तपासत असेल (NNT = 400), प्रत्येकासाठी 4 मिनिटे डेव्हलपर लक्ष, तर एका पकडीचा खर्च ~27 डेव्हलपर-तास — आता ते त्या टाळलेल्या घटना खर्चाशी तुलना करा. NNH खोट्या सकारात्मकांशी जुळतो: प्रति *खोट्या* ध्वजामागे किती PR, आणि प्रत्येकाचा लक्ष आणि विश्वासातला खर्च काय? तपासणी-शैलीचे टूलिंग (linters, सुरक्षा स्कॅनर, विसंगती शोध) NNT/NNH गणितासह पाठवले पाहिजे — कमी प्रसार ही संख्या क्रूर का बनवतो यासाठी [तपासणी अर्थशास्त्र](../तपासणी-अर्थशास्त्र/) पहा. केवळ एका उपचारासाठी नव्हे तर संपूर्ण तपासणी-मग-उपचार कार्यक्रमासाठी, एक पातळी वरचा साधर्म्य आकडा म्हणजे [तपासणीसाठी आवश्यक संख्या](../तपासणीसाठी-आवश्यक-संख्या/).

## सामान्य चुका

- **कालावधी नाही**: "NNT = 50" काहीच सांगत नाही; "5 वर्षांत NNT = 50" हा दावा आहे.
- **मूलभूत-जोखीम पुनर्रोपण**: उच्च-जोखीम चाचणी लोकसंख्येत मोजलेला NNT कमी-जोखीम तैनाती लोकसंख्येत कोसळतो.
- **NNH कडे दुर्लक्ष** — NNT 400 आणि NNH 3 असलेले गेट हे उपद्रव निर्माण करणारे आहे, सुरक्षा प्रणाली नाही.
