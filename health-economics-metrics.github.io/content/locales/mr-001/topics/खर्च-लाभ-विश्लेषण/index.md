# खर्च-लाभ विश्लेषण (CBA)

CBA खर्च *आणि* परिणाम दोन्हींचे मूल्य पैशांत ठरवते. "हे करणे अजिबात योग्य आहे का?" — केवळ "कोणता पर्याय सर्वोत्तम?" नव्हे — या प्रश्नाचे उत्तर देऊ शकणारा हा एकमेव विश्लेषण प्रकार आहे, कारण पैशांत रूपांतरित लाभांची थेट खर्चाशी तुलना करता येते.

## हे का महत्त्वाचे आहे

CBA हे UK च्या HM Treasury **Green Book** चे सर्व सार्वजनिक खर्च मूल्यमापनासाठीचे मानक आहे, परिणाम पैशांत मोजता येत असल्यास आरोग्यासहित. जिथे [CEA](../खर्च-परिणामकारकता-विश्लेषण/)/[CUA](../खर्च-उपयुक्तता-विश्लेषण/) "प्रति एकक आरोग्य खर्च" वर थांबतात, तिथे CBA आरोग्याचीच किंमत ठरवते (QALY × थ्रेशोल्ड मूल्य) आणि बाकी सर्वाचीही — वेळ, प्रवास, कार्बन — आणि एकच निव्वळ आकडा नोंदवते. प्रत्येक पूर्ण NHS डिजिटल व्यवसाय प्रकरणात CBA-स्वरूपाचे आर्थिक प्रकरण असते.

## गणित

```
NPV (net present social value) = Σ_t [ (Benefits_t − Costs_t) / (1 + r)^t ]
BCR (benefit-cost ratio)       = PV(benefits) / PV(costs)

Adopt if NPV > 0 (equivalently BCR > 1); rank by NPV, not BCR.
r = 3.5% (Green Book social time preference rate)
```

आरोग्य परिणाम QALY × λ म्हणून पैशांत येऊ शकतात ([देण्याच्या तयारीच्या मर्यादा](../देण्याच्या-तयारीच्या-मर्यादा/) पहा). Green Book **आशावाद-पक्षपात समायोजन** देखील अनिवार्य करते — खर्च अंदाज वाढवणे आणि पुराव्यावर आधारित टक्केवारीने लाभ कमी करणे, कारण मूल्यमापने पद्धतशीरपणे गुलाबी असतात.

## सोडवलेले उदाहरण

ई-रेफरल प्रणाली, 5-वर्षांचे क्षितिज, 3.5% सवलत:

```
Costs:    build £1.2M (year 0), run £300k/yr (years 1–5)
Benefits: admin savings £250k/yr, avoided duplicate diagnostics £280k/yr,
          patient time saved 40,000 hrs/yr × £15 = £600k/yr → £1,130k/yr

PV costs    = 1,200k + 300k × 4.515 (annuity factor) = £2,555k
PV benefits = 1,130k × 4.515                          = £5,102k

NPV = 5,102 − 2,555 = +£2,547k     BCR = 2.0
```

Green Book आशावाद-पक्षपात लावा (म्हणजे बांधणी खर्चावर +40%, लाभांवर −20%): PV खर्च ≈ £3,035k, PV लाभ ≈ £4,082k, NPV ≈ **+£1,047k** — तरीही धन, आणि समायोजनाचा हाच हेतू आहे: प्रकरणे स्वतःच्या आशावादातून टिकली पाहिजेत.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

अभियांत्रिकी व्यवसाय प्रकरणे ही अनौपचारिक CBA असतात. Green Book मधील चोरण्यासारख्या सुधारणा:

- **आशावाद-पक्षपात प्रमाणित भार म्हणून** — मंत्रालये पायाभूत सुविधांचा खर्च जितक्या खात्रीने कमी लेखतात, तितक्याच खात्रीने अभियंते स्थलांतर खर्च कमी लेखतात; "यावेळी वेगळे आहे" असे भासवण्याऐवजी नमूद केलेला भार लावा.
- **प्रमुख लाभाचे प्रामाणिक मूल्य ठरवा किंवा अजिबात नाही** — रुग्ण/वापरकर्ता वेळ समर्थनीय दरांनी पैशांत मोजला जातो; "ब्रँड मूल्य" नाही.
- **NPV क्रम लावते, BCR नाही**: BCR 5 असलेला छोटा प्रकल्प BCR 1.6 असलेल्या मोठ्या प्रकल्पापेक्षा कमी महत्त्वाचा असू शकतो.

## सामान्य चुका

- **लाभ फुगवण्यासाठी न मोजता येणाऱ्याचे पैशांत मूल्य ठरवणे** (मनोबल, "धोरणात्मक संरेखन") — ते [खर्च-परिणाम विश्लेषण](../खर्च-परिणाम-विश्लेषण/) नुसार गुणात्मक ठेवा.
- **हस्तांतरणे लाभ म्हणून मोजणे**: सार्वजनिक संस्थांमध्ये फिरणारा पैसा सामाजिक [दृष्टिकोनातून](../विश्लेषण-दृष्टिकोन/) निव्वळ शून्य होतो.
- **प्रतितथ्य नसणे**: लाभ किमान-करा पर्यायाविरुद्ध मोजले जातात, शून्याविरुद्ध नाही.
