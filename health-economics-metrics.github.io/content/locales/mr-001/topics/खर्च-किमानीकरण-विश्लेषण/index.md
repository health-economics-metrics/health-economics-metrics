# खर्च-किमानीकरण विश्लेषण (CMA)

CMA फक्त खर्चांची तुलना करते आणि सर्वात स्वस्त पर्याय निवडते — पर्यायांचे परिणाम समतुल्य असल्याचे सिद्ध झाले असेल *तरच* हे वैध आहे.

## हे का महत्त्वाचे आहे

CMA हे सर्वात सोपे विश्लेषण आणि सर्वात जास्त गैरवापरले जाणारे आहे. समतुल्यतेचा दावा सर्व काम करतो: जर परिणाम खरोखर वेगळे नसतील (बायोसिमिलर विरुद्ध त्याचे मूळ औषध; समान विनिर्देश पूर्ण करणारे एकाच सेवेचे दोन पुरवठादार), तर खर्च हा एकमेव प्रश्न आहे आणि CMA योग्य आहे. काटेकोरपणा समतुल्यता आधी *सिद्ध करण्यात* आहे — सहसा आधी ठरवलेल्या मर्यादेसह non-inferiority अभ्यासाद्वारे — आणि खरेदीदार नेमकी हीच पायरी वगळतात.

## गणित

```
Given evidence that Effect_A ≈ Effect_B (within a pre-specified margin δ):
Choose min(Cost_A, Cost_B)

Costs measured from the same perspective, over the same horizon,
including switching/transition costs.
```

समतुल्यतेचा पुरावा देता येत नसेल, तर CMA अवैध आहे — त्याऐवजी [CEA](../खर्च-परिणामकारकता-विश्लेषण/)/[CUA](../खर्च-उपयुक्तता-विश्लेषण/) वापरा.

## सोडवलेले उदाहरण

एक ट्रस्ट दोन व्हिडिओ-सल्ला प्लॅटफॉर्ममधून निवड करतो. 3-महिन्यांच्या समांतर पायलटमध्ये पूर्णत्व दर 94.1% विरुद्ध 93.8%, रुग्ण समाधान 4.4 विरुद्ध 4.4 — फरक आधी ठरवलेल्या 2 टक्केवारी बिंदूंच्या δ च्या आत. परिणाम: समतुल्य. 3 वर्षांतील खर्च:

```
                     Platform A     Platform B
Licences             £360,000       £210,000
Integration          £80,000        £150,000
Training/support     £60,000        £90,000
Total                £500,000       £450,000
```

प्लॅटफॉर्म B £50,000 ने जिंकतो — त्याच्या जास्त एकत्रीकरण खर्चासहही. पायलटशिवाय समतुल्यतेचा दावा विक्रेत्यांच्या माहितीपत्रकांवर अवलंबून असता, आणि 1-बिंदू पूर्णत्व-दर फरक (≈ दरवर्षी हजारो अयशस्वी सल्ले) £50,000 पेक्षा कितीतरी मोठा ठरला असता.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

CMA हे कमोडिटी खरेदीचे औपचारिक रूप आहे: समान SLO पूर्ण करणारे दोन CI प्रदाते, समान टिकाऊपणा विनिर्देश असलेले दोन ऑब्जेक्ट स्टोअर. आरोग्य-अर्थशास्त्राचा धडा *कृतींचा क्रम* आहे: आधी समतुल्यतेचा पुरावा (तुमच्या वर्कलोडवर बेंचमार्क, तुमच्या SLO विरुद्ध पायलट, मर्यादा आधी ठरवून), मग स्थलांतरासह एकूण खर्चांची तुलना. पहिल्या पायरीशिवाय "ते मुळात सारखेच आहेत, B स्वस्त आहे" म्हणूनच संस्था 10% स्वस्त आणि 40% वाईट साधन विकत घेतात. उपसिद्धांत: विक्रेता किंमतीवर युक्तिवाद करतो तेव्हा त्याला समतुल्यता मान्य करायला लावा — ती दुसऱ्या दिशेनेही बंधनकारक असते.

## सामान्य चुका

- **गृहीत समतुल्यता** — परिभाषित पाप; फरकाच्या पुराव्याचा अभाव म्हणजे समतुल्यतेचा पुरावा नव्हे (अपुऱ्या सामर्थ्याचे पायलट फुकट समतुल्यता "दाखवतात").
- **स्विचिंग खर्च वगळणे** — स्थलांतर, पुनर्प्रशिक्षण आणि समांतर चालवणे खर्चाच्या बाजूला येतात.
- **चुकीच्या परिणामांवर समतुल्यता**: मोजलेल्या मेट्रिकवर समतुल्य, पण महत्त्वाच्या एखाद्यावर (प्रवेशयोग्यता, टेल लेटन्सी, डेटा एग्रेस) वेगळे.
