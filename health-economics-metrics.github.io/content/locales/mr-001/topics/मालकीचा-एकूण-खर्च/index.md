# मालकीचा एकूण खर्च (TCO)

TCO म्हणजे प्रणालीच्या आयुष्यातील संपूर्ण खर्च: संपादन किंवा बांधणी, एकत्रीकरण, चालन, देखभाल, समर्थन, प्रशिक्षण आणि सेवेतून काढणे. अस्वस्थ करणारी मूलरेषा: **देखभाल हे सॉफ्टवेअर TCO चा 50–80% आहे** — आयुष्यभराच्या खर्चापैकी सुमारे तीन-चतुर्थांश *लाँचनंतर* येतो.

## हे का महत्त्वाचे आहे

आरोग्य तंत्रज्ञान मूल्यमापन फार पूर्वीच शिकले की औषधाची किंमत म्हणजे त्याचा खर्च नाही — प्रशासन, देखरेख आणि दुष्परिणाम हाताळणे सर्व मॉडेलमध्ये येते. फक्त बांधणी/परवाना खर्च मोजणारी सॉफ्टवेअर व्यवसाय प्रकरणे औषधाच्या भोळ्या किंमतीची चूक पुन्हा करतात आणि ती ज्यांना पोसतात त्या प्रत्येक [ICER](../वाढीव-खर्च-परिणामकारकता-गुणोत्तर/) आणि [अंदाजपत्रक प्रभाव](../अंदाजपत्रक-प्रभाव-विश्लेषण/) चा खर्च पक्ष पद्धतशीरपणे कमी दाखवतात. NHS खरेदीसाठी, TCO शिस्त डिजिटल उत्पादनाचा खर्च-परिणामकारकता दावा प्रामाणिक बनवते — आणि तिथेच स्वस्त दिसणारे पर्याय हरतात.

## गणित

```
TCO = initial cost (build/licence + integration + data migration + training)
    + Σ_t [operations + maintenance + support + infrastructure + upgrades
           + compliance/assurance]_t / (1 + r)^t
    + decommissioning cost (exit, data extraction, parallel running)

Horizon: 3–5 years commercial, system-lifetime for clinical infrastructure
r: 3.5% public sector (Green Book), 8–12% commercial
Benchmarks: annual maintenance ≈ 15–20% of build cost; ~78% of lifetime
TCO post-launch; ignore decommissioning and vendor lock-in prices itself.
```

## सोडवलेले उदाहरण

ई-निरीक्षण प्रणालीचे दोन पर्याय, 5-वर्षांचे क्षितिज:

```
                        Vendor SaaS     In-house build
Year 0 (licence/build)  £250,000        £900,000
Integration + training  £180,000        £150,000
Annual run (yrs 1–5)    £120,000/yr     £190,000/yr  (hosting + 1.5 FTE maint.)
Exit/decommission       £60,000         £30,000

Undiscounted TCO        £1,090,000      £2,030,000
```

बांधणी पर्यायाचा अभियांत्रिकी अंदाज (£900k) त्याच्या खऱ्या TCO च्या फक्त 44% होता — आणि बांधणी अंदाज स्वतः सहसा 30–40% ओलांडतात ([बनवा विरुद्ध खरेदी करा](../बनवा-विरुद्ध-खरेदी-करा/) पहा). अंतर्गत पर्याय भौतिकदृष्ट्या वेगळे *परिणाम* देत नसेल तर [खर्च-किमानीकरण](../खर्च-किमानीकरण-विश्लेषण/) तर्क लागू होतो आणि SaaS ~£940k ने जिंकतो.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

बांधणीची वकिली करताना अभियंते स्वतःच्या क्षेत्रातील देखभाल डेटाला कमी भार देतात: वार्षिक देखभाल बांधणी खर्चाच्या 15–20% हा नियम म्हणजे प्रत्येक £1M प्रणाली शांतपणे £150–200k/वर्ष भावी क्षमता वचनबद्ध करते — [तांत्रिक कर्ज](../तांत्रिक-कर्ज/) सोबत एकाच मानसिक ताळेबंदावर यायला हवी अशी देयता. TCO हा या रेपॉझिटरीतील प्रत्येक मेट्रिकचा खर्च अर्धा भाग आहे: प्रति तैनाती खर्च, [क्लाउड एकक अर्थशास्त्र](../क्लाउड-एकक-अर्थशास्त्र/), आणि HTA औषध प्रायोजकांवर लादते ती भाजक शिस्त. तुमच्या उत्पादनाच्या किमतीला आव्हान दिले जाते तेव्हा, प्रस्थापित उत्पादनाच्या खऱ्या चालन खर्चासह TCO तुलना हा सहसा उपलब्ध सर्वात मजबूत पुनर्मांडणी असतो. वरीलसारखा बहु-वर्षीय TCO आकडा कालांतराने अनेक खर्च ओळींची बेरीज आहे — मॉडेलला पैशापर्यंत जुळावे लागते तेव्हा ती बेरीज फ्लोटिंग पॉइंटऐवजी अचूक-दशांश का असावी यासाठी [चलन-सुरक्षित खर्च एकत्रीकरण](../चलन-सुरक्षित-खर्च-एकत्रीकरण/) पहा, आणि TCO एकूण खर्च केंद्रांमध्ये पैसे न गमावता विभागण्यासाठी [अचूक-पैसे खर्च वाटप](../अचूक-पैसे-खर्च-वाटप/).

## सामान्य चुका

- **लाँच-खर्च अँकरिंग**: वर्ष-0 खर्चावर पर्यायांची तुलना जेव्हा क्रम वर्ष 3 पर्यंत उलटतो.
- **मोफत-अंतर्गत-श्रम चूक**: "संघाला आधीच पगार मिळतो" म्हणून अंतर्गत देखभाल शून्य खर्चाची — [संधी खर्च](../संधी-खर्च/) पहा.
- **निर्गमन खर्चाकडे दुर्लक्ष**: डेटा एग्रेस, करार समाप्ती आणि समांतर चालवणे हेच तिथे आहेत जिथे "स्वस्त" SaaS महाग होते.
- **समान-क्षितिज उल्लंघने**: 3-वर्षीय SaaS TCO ची 10-वर्षीय बांधणी अमॉर्टायझेशनशी तुलना ([कालावधी क्षितिज](../कालावधी-क्षितिज/) पहा).
