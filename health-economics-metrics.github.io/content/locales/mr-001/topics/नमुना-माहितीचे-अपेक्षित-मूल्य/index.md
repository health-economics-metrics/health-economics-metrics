# नमुना माहितीचे अपेक्षित मूल्य (EVSI)

EVSI म्हणजे *विशिष्ट प्रस्तावित अभ्यासाचे* — दिलेली रचना, दिलेला नमुना आकार — तो चालवण्यापूर्वीचे मूल्य, याच्या उलट [EVPI](../परिपूर्ण-माहितीचे-अपेक्षित-मूल्य/) सर्व अनिश्चितता पूर्णपणे दूर करण्याची किंमत ठरवते. संशोधन निधीदात्याला प्रत्यक्षात भेडसावणाऱ्या प्रश्नाचे EVSI उत्तर देते: "ही चाचणी, या आकारात, तिच्या खर्चाइतकी योग्य आहे का?"

## हे का महत्त्वाचे आहे

EVPI तुम्हाला सांगते की कोणत्याही संशोधनाचे मूल्य जास्तीत जास्त किती असू शकते; समोरील चाचणी ती पातळी ओलांडते का हे ते कधीच सांगत नाही. 50-रुग्णांचा पायलट आणि 500-रुग्णांची निर्णायक चाचणी यातून निवडणाऱ्या राष्ट्रीय संशोधन निधीदात्याला *प्रत्येक विशिष्ट रचनेचे* मूल्य किती हे माहीत हवे, केवळ सर्वज्ञतेचे मूल्य नाही. EVSI तो आकडा पुरवते, आणि ते नमुना आकारासोबत वाढत असल्याने, निधीदात्याला अंदाज करण्याऐवजी अपेक्षित निव्वळ लाभ कमाल करणारा नमुना आकार शोधता येतो.

म्हणूनच EVSI नेहमी EVPI पेक्षा कमी किंवा बरोबर असते: मर्यादित नमुना अनिश्चितता फक्त अंशतः सोडवू शकतो, आणि परिपूर्ण माहितीपेक्षा जास्त मोलाचा दिसणारा अभ्यास हे गणनेत चूक असल्याचे चिन्ह आहे, खरा निकाल नाही.

## गणित

```
General:
EVSI(n) = E_data[ max_d E_θ|data[NB(d,θ)] ]  −  max_d E_θ[NB(d,θ)]
  (nested expectation: outer over possible study results, inner over the
  posterior belief about θ after seeing that result — usually estimated by
  nested Monte Carlo / Bayesian updating over probabilistic sensitivity
  analysis draws)

Closed-form normal approximation (single uncertain parameter, conjugate
normal-normal model — a standard shortcut, not exact for every model):
EVSI(n) = EVPI × n / (n + n0)

n  = proposed study's sample size
n0 = "prior-equivalent sample size" — the size of an imaginary sample that
     would carry the same information as the current prior, derived from
     the ratio of data variance to prior variance
ENBS(n) = EVSI(n) − Cost(n)
Population EVSI = per-decision EVSI × decisions affected
```

सामान्य रूप हे नेस्टेड अपेक्षा आहे कारण अभ्यासाचा भावी निकालच अनिश्चित आहे: अभ्यास निर्माण करू शकणाऱ्या प्रत्येक संभाव्य डेटासेटवर तुम्हाला सरासरी काढावी लागते, आणि प्रत्येकासाठी अद्ययावत (पोस्टेरियर) विश्वासानुसार सर्वोत्तम निर्णय पुन्हा मोजावा लागतो. बंद-रूप सामान्य सन्निकटन ती गणन खर्च एकाच गुणोत्तराने बदलते, जेव्हा अनिश्चित पॅरामीटर आणि डेटा (अंदाजे) सामान्य आणि conjugate असतात तेव्हा वैध — सोय, सार्वत्रिक नियम नाही. ती गृहीतके लागू होत नाहीत तेव्हा पूर्ण नेस्टेड Monte Carlo ही सामान्य-उद्देश पद्धत आहे. EVSI सहसा ज्या PSA नमुन्यांवरून मोजले जाते त्यासाठी [संभाव्यताधारित संवेदनशीलता विश्लेषण](../संभाव्यताधारित-संवेदनशीलता-विश्लेषण/) पहा.

## सोडवलेले उदाहरण

[EVPI](../परिपूर्ण-माहितीचे-अपेक्षित-मूल्य/) च्या सोडवलेल्या उदाहरणावर आधारित — 5,000 वैद्यकांना AI दस्तऐवजीकरण सहाय्यक रोल-आउट करणे, जिथे EVPI £1.2M आढळले — तोच EVPI येथे पूर्ण पाउंडांत मांडा: **EVPI = £1,200,000**.

50 वैद्यकांचा प्रस्तावित पायलट अभ्यास समोर आहे. पूर्व विश्वासाच्या विचरणाचे आणि पायलटच्या मापन अचूकतेचे गुणोत्तर पाहता, पूर्व-समतुल्य नमुना आकार `n0 = 75` येतो:

```
EVSI(50) = 1,200,000 × 50 / (50 + 75)
         = 1,200,000 × 50 / 125
         = 1,200,000 × 0.4
         = £480,000
```

पायलटचा खर्च £120,000 आहे:

```
ENBS = EVSI − Cost = 480,000 − 120,000 = £360,000
```

स्पष्टपणे धन ENBS: पायलटला निधी द्या. तोच खरेदी निर्णय 3 सारख्या प्रादेशिक ट्रस्टमध्ये पुन्हा येत असेल, तर पायलटचे मूल्य वाढते:

```
Population EVSI = 480,000 × 3 = £1,440,000
```

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

EVSI हे पायलट किंवा A/B चाचणी चालवायची की नाही इतकेच नव्हे तर ती *किती मोठी* असावी याचे अर्थशास्त्र आहे:

- **गुंतवणूक म्हणून नमुना आकाराचा निर्णय.** 50-वापरकर्त्यांचा बीटा आणि 5,000-वापरकर्त्यांचा टप्प्याटप्प्याने रोलआउट हे वेगवेगळे EVSI आणि वेगळे खर्च असलेले वेगळे "अभ्यास" आहेत — "जास्त डेटा नेहमी चांगला" या डीफॉल्टऐवजी EVSI तुम्हाला त्यांची एकाच आधारावर तुलना करू देते.
- **कमिशनिंग चाचणी ENBS आहे, केवळ EVSI नाही.** उच्च EVSI पण बहुतांश खाऊन टाकणारा खर्च असलेला अभ्यास कमकुवत प्रस्ताव आहे; निर्णय नियम म्हणजे नमुना घेण्याचा अपेक्षित निव्वळ लाभ, जसे व्यवसाय प्रकरण फक्त लाभ नोंदवण्याऐवजी लाभ आणि खर्च निव्वळ करते.
- **घटते परतावे स्पष्ट आहेत.** EVSI(n) `n/(n+n0)` सोबत वाढत असल्याने, पायलटचा आकार दुप्पट केल्याने त्याचे मूल्य कधीच दुप्पट होत नाही — मोठ्या प्रयोगाचे सीमान्त माहिती मूल्य घटते या अभियांत्रिकी अंतःप्रेरणेची औपचारिक आवृत्ती.

## सामान्य चुका

- **सामान्य सन्निकटन त्याच्या गृहीतकांबाहेर लावणे.** ते फक्त जवळपास-conjugate, एक-पॅरामीटर अनिश्चिततेसाठी लागू आहे; खरोखर अरेषीय किंवा बहु-पॅरामीटर निर्णय मॉडेलला पूर्ण नेस्टेड Monte Carlo हवे, हा शॉर्टकट नाही.
- **EVSI ची तुलना फक्त रोख खर्चाशी.** EVSI चे वजन अभ्यासाच्या *पूर्ण* खर्चाविरुद्ध केले पाहिजे, त्याच्या स्वतःच्या निर्णय-विलंब खर्चासह — [विलंबाचा खर्च](../विलंबाचा-खर्च/) पहा — केवळ अभ्यासाच्या बीजकाविरुद्ध नाही.
- **EVSI > EVPI ला खरा निष्कर्ष मानणे.** रचनेनुसार EVSI कधीच EVPI पेक्षा जास्त असू शकत नाही; हे देणारी गणना मॉडेलिंग बग आहे, शोध नाही.
