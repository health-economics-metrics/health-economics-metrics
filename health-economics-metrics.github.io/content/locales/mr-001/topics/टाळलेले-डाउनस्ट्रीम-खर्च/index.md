# टाळलेले डाउनस्ट्रीम खर्च

टाळलेले डाउनस्ट्रीम खर्च (खर्च-समायोजन) म्हणजे लवकर किंवा चांगल्या कृतीने टळलेले भविष्यातील उपचार खर्च, जे हस्तक्षेपाच्या स्वतःच्या खर्चातून वजा केले जातात. समायोजन ही अशी यंत्रणा आहे ज्यामुळे हस्तक्षेप *वर्चस्वी* (dominant) ठरू शकतो — स्वस्त **आणि** चांगला — आणि आरोग्य अर्थशास्त्रातील सर्वाधिक दुहेरी-मोजलेली, अतिरंजित केलेली ओळही तीच आहे.

## हे का महत्त्वाचे आहे

जवळजवळ प्रत्येक डिजिटल आरोग्य मूल्य-प्रस्तावात समायोजनाचा दावा असतो: "आमचे अ‍ॅप दाखले टाळते," "आमचे अलर्ट प्रकृती बिघडणे टाळतात," "आमचा प्लॅटफॉर्म दुहेरी चाचण्या टाळतो." समायोजन खरे असतात तेव्हा ते अर्थशास्त्र बदलून टाकतात ([ICER](../वाढीव-खर्च-परिणामकारकता-गुणोत्तर/) चे सोडवलेले उदाहरण पहा, जिथे £600k चे समायोजन प्रकरण जिंकवते). पेअरना हे माहीत आहे — म्हणून कोणत्याही मूल्यमापनात समायोजनाच्या दाव्यांची सर्वात कठोर छाननी होते. खालील विश्वासार्हता नियम निधी मिळण्याजोगे मॉडेल आणि विपणन यांच्यात फरक करतात.

## गणित

```
Net cost = intervention cost − Σ offsets

A valid offset must be:
  Attributable — causally linked to the intervention (comparator evidence)
  Marginal     — the money actually stops being spent, at marginal not
                 average cost (see marginal-vs-average-cost.md)
  Probability- — weighted by P(the downstream event would have occurred)
  weighted
  Discounted   — future avoided costs at present value
  Unique       — counted once, in one benefit line
```

## सोडवलेले उदाहरण

"हा स्थलांतर-जोखमीचा दावा, योग्य पद्धतीने": 5,000 शस्त्रक्रियेनंतरच्या रुग्णांसाठी जखम-देखरेख अ‍ॅप संसर्गामुळे होणारे पुनर्दाखले टाळण्याचा दावा करते.

```
Baseline readmission for infection: 4.0% ; with app (RCT): 3.1%
Attributable events avoided = 5,000 × 0.009 = 45/year
Cost per readmission spell (marginal, this trust): £3,200
Offset = 45 × 3,200 = £144,000/year
App cost = 5,000 × £20 = £100,000/year
Net cost = −£44,000 → genuinely cost-saving, with:
  attribution from an RCT ✓  marginal costing ✓  probability from trial data ✓
```

"पुनर्दाखल सरासरी £5,800 ला पडते, आम्ही भरपूर टाळू" यावर आधारित तोच दावा चारही चाचण्यांत अपयशी ठरतो आणि त्याला मिळणारा नकार योग्यच आहे.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

"हे स्थलांतर भविष्यातील पुनर्लेखन टाळते" हा समायोजनाचा दावा आहे, आणि आरोग्य अर्थशास्त्राचे नियम त्याला प्रामाणिक करतात:

- **प्रतितथ्य खर्च**: पुनर्लेखनाला प्रत्यक्षात किती खर्च येईल, कोणत्या पुराव्याने?
- **शक्यता**: ते भविष्य किती संभाव्य आहे? (100% नाही — उत्पादने बंद पडतात, प्राधान्ये बदलतात.)
- **सवलत**: चौथ्या वर्षी टळलेल्या पुनर्लेखनाचे 3.5–10% सवलत दराने मूल्य दर्शनी किमतीपेक्षा खूपच कमी असते.
- **अद्वितीयता**: तोच टाळलेला पुनर्लेखन तांत्रिक-कर्ज ओळीत आणि टिकवणूक ओळीत दोन्हीकडे मांडू नका.

`Offset value = P(future event) × counterfactual cost × discount factor` — ही ओळ प्रस्तावात लिहा आणि अंदाज चर्चायोग्य होताना पहा, हाच तर उद्देश आहे.

## सामान्य चुका

- **दुहेरी मोजणी** — तोच टाळलेला दाखला समायोजन, खाट-दिवस आणि खर्च जोडलेले QALY अशा तिन्ही ठिकाणी मांडणे.
- **सरासरी-खर्च समायोजन** अशा घटनांसाठी ज्यांचे स्थिर खर्च कोणत्याही परिस्थितीत चालू राहतात.
- **केवळ शक्य असलेल्या डाउनस्ट्रीम घटनांवर मूकपणे 100% शक्यता** लावणे.
- **इतर अंदाजपत्रकांना होणारी समायोजने** ज्यांना पैसे देण्यास सांगितले जात आहे त्या पेअरची बचत म्हणून मांडणे — [विश्लेषण दृष्टिकोन](../विश्लेषण-दृष्टिकोन/) पहा.
