# WSJF आणि CD3

CD3 (Cost of Delay Divided by Duration) आणि WSJF (Weighted Shortest Job First) हे प्राधान्यक्रम नियम आहेत जे **मूल्य घनतेनुसार** काम शेड्यूल करतात: वापरलेल्या प्रति एकक दुर्मिळ क्षमतेमागे किती विलंब खर्च काढून टाकला जातो. सामायिक, निश्चित क्षमतेखाली, एकूण विलंब खर्च कमी करण्यासाठी सर्वाधिक-CD3-प्रथम हा गणितीयदृष्ट्या इष्टतम क्रम आहे.

## हे का महत्त्वाचे आहे

प्रत्येक बॅकलॉग रेशनिंग समस्या आहे: अनेक योग्य वस्तू, एक पाइपलाइन. आरोग्य अर्थशास्त्राने आरोग्य अंदाजपत्रकांसाठी तीच समस्या खर्च-परिणामकारकता क्रमवारी तक्त्यांनी सोडवली: हस्तक्षेपांना प्रति पाउंड मिळवलेल्या आरोग्यानुसार क्रम द्या, अंदाजपत्रक संपेपर्यंत यादीत खाली निधी द्या. CD3 हाच तर्क वितरण क्षमतेसाठी आहे: *बंधित संसाधनाच्या* प्रति एकक लाभ, क्रमानुसार निधीकृत. क्रम बरोबर ठेवणे म्हणजे फुकट पैसा: तेच काम, तीच क्षमता, कमी एकूण विलंब खर्च.

## गणित

```
CD3  = Cost of Delay (£/week) / Duration (weeks)      — real units (Black Swan Farming)

WSJF = (user-business value + time criticality + risk reduction/opportunity
        enablement) / job size                         — SAFe's relative-scale proxy,
                                                        modified-Fibonacci scores
```

खऱ्या चलनासह CD3 ([विलंबाचा खर्च](../विलंबाचा-खर्च/)) WSJF च्या एकक-रहित गुणांपेक्षा काटेकोरपणे मजबूत आहे — WSJF आणि CD3 मधील संबंध म्हणजे बहु-निकष गुणांकन आणि पूर्ण [खर्च-उपयुक्तता विश्लेषण](../खर्च-उपयुक्तता-विश्लेषण/) यातील संबंध: पैशात रूपांतर अव्यवहार्य असताना उपयोगी, गुणांना अँकर नसताना हेराफेरीयोग्य.

## सोडवलेले उदाहरण

तीन वैशिष्ट्ये, एक संघ:

```
Feature   CoD (£/wk)   Duration   CD3
A         30,000       10 wks     3,000
B         12,000       2 wks      6,000
C         5,000        1 wk       5,000
```

CD3 क्रम: B, C, A. "सर्वात मोठा CoD प्रथम" (A, B, C) शी एकूण विलंब खर्चाची तुलना करा:

```
CD3 order  (B,C,A): A waits 3 wks, C waits 2 → 30k×3 + 5k×2  = £100k delay cost
CoD order  (A,B,C): B waits 10, C waits 12   → 12k×10 + 5k×12 = £180k
```

तीच वैशिष्ट्ये, तोच संघ — केवळ क्रमवारीने £80,000 वाचतात. अंतःप्रेरणा: लहान, तातडीच्या वस्तू आधी जातात कारण त्या आपला विलंब खर्च स्वस्तात मोकळा करतात; मोठी वस्तू थोडा वेळ थांबल्याने फारसे गमावत नाही.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

आरोग्य-सेवा सॉफ्टवेअर पोर्टफोलिओसाठी, CoD या रेपॉझिटरी शिकवत असलेल्या एककांत मांडा: QALY/आठवडा × थ्रेशोल्ड + कार्यात्मक £/आठवडा, आणि बॅकलॉग आरोग्य प्रणाली इतर सर्व विकत घेत असलेल्याला कसा क्रम देते त्याच्याशी थेट तुलनीय होतो. दोन सराव टिपा: (1) कालावधी म्हणजे *बंधन व्यापणारा कॅलेंडर वेळ*, प्रयत्न नव्हे — अडथळा संघाचे 2 दिवस लागणारी 2-आठवड्यांची वस्तू दिसते त्यापेक्षा स्वस्त आहे ([डाउनस्ट्रीम संसाधन इष्टतमीकरण](../डाउनस्ट्रीम-संसाधन-इष्टतमीकरण/) पहा); (2) रुग्णालये थिएटर याद्या तातडी-भारित थ्रूपुटनुसार क्रमवारी लावतात तेव्हा तोच नियम अप्रत्यक्षपणे चालवतात — क्लिनिकल प्राधान्य श्रेणी म्हणजे तीव्रता-भारित CD3 ([QALY तूट आणि तीव्रता सुधारक](../qaly-तूट-आणि-तीव्रता-सुधारक/) पहा).

## सामान्य चुका

- **WSJF गुण नाटक**: एकक-रहित Fibonacci चर्चा सर्वात मोठ्याने बोलणाऱ्याकडे एकवटतात; किमान बॅकलॉगच्या शीर्षस्थ वस्तू खऱ्या CoD मध्ये अँकर करा.
- **कालावधी हेराफेरी**: CD3 क्रम फुगवण्यासाठी वस्तू विभागणे — विभाजने स्वतंत्रपणे मूल्य देतात तेव्हा ठीक, देत नाहीत तेव्हा फसवणूक.
- **तातडी प्रोफाइलकडे दुर्लक्ष**: मुदत-आकाराचा CoD (नियामक तारखा) स्थिर-दर गृहीतक मोडतो; त्यांना तारीख व्यवहार्यतेनुसार शेड्यूल करा, मग बाकीच्यांना CD3.
- **पुन्हा-क्रमवारी खळबळ**: CD3 वचनबद्धतेच्या वेळी क्रम ठरवण्यासाठी आहे, चालू कामाच्या रोजच्या फेरबदलासाठी नाही (WIP वर [फ्लो मेट्रिक्स](../फ्लो-मेट्रिक्स/) पहा).
