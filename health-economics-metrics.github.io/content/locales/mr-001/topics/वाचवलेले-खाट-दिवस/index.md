# वाचवलेले खाट-दिवस

खाट-दिवस म्हणजे एक रुग्ण एका दिवसासाठी एक रुग्णालय खाट व्यापतो. लवकर सुट्टी, दाखले टाळणे किंवा आभासी वॉर्डद्वारे "वाचवलेले खाट-दिवस" हा NHS डिजिटल व्यवसाय प्रकरणांचा मुख्य लाभ आहे, आणि सर्वात जास्त वेळा अतिमूल्यित केला जाणारा.

## हे का महत्त्वाचे आहे

खाटा हा तीव्र काळजीचा बंधनकारक अडथळा आहे: खाटा भरल्या की निवडक शस्त्रक्रिया रद्द होतात, रुग्णवाहिका रांगेत उभ्या राहतात आणि आपत्कालीन विभाग तुंबतो. म्हणून खाट-दिवस मोकळे करणाऱ्या हस्तक्षेपांना खरे मूल्य असते — पण मूल्याचा *प्रकार* मोकळ्या झालेल्या खाटेचे काय होते यावर पूर्णपणे अवलंबून असतो. वित्त संचालकांनी भोळ्या खाट-दिवस दाव्यांवर मोठी सूट द्यायला शिकले आहे; हे अंकगणित बरोबर करणे ही विश्वासार्हतेची चाचणी आहे.

## गणित

```
Bed days saved = patients affected × Δ length of stay (or admissions avoided × avg LOS)

Value depends on the use of the freed capacity:
  refilled with elective activity → value = activity income or waiting-list benefit
  ward closed / flexed down      → value = staffing + running cost released (cash)
  absorbed as slack              → value ≈ marginal (hotel) cost only, £50–£150/day
```

तीव्र खाट-दिवसाचा सरासरी पूर्ण-आत्मसात खर्च अनेकदा £400+ सांगितला जातो (National Cost Collection मध्ये अतिरिक्त खाट-दिवसांसाठी ऐतिहासिकदृष्ट्या ~£350) — पण [सीमान्त विरुद्ध सरासरी खर्च](../सीमान्त-विरुद्ध-सरासरी-खर्च/) पहा: सरासरी हीच बचत क्वचितच असते.

## सोडवलेले उदाहरण

दूरस्थ-देखरेख "आभासी वॉर्ड" 600 रुग्णांना दरवर्षी 2 दिवस लवकर घरी जाऊ देतो: 1,200 खाट-दिवस वाचतात.

- **भोळा दावा**: 1,200 × £400 = £480,000. वॉर्ड बंद झाल्याशिवाय चुकीचा.
- **प्रामाणिक दावा**: ट्रस्ट त्या खाटा निवडक अस्थिरोग रुग्णांनी भरतो. 1,200 खाट-दिवस ÷ 3-दिवसांचा सरासरी मुक्काम = 400 अतिरिक्त निवडक रुग्ण-सत्रे, प्रत्येकी ~£6,000 उत्पन्न (क्रियाकलाप-आधारित देयकानुसार) = **£2.4M अतिरिक्त निधी-प्राप्त क्रियाकलाप** (त्या रुग्णांवर उपचार करण्याचा सीमान्त खर्च वजा), *शिवाय* 400 रुग्ण प्रतीक्षा यादीतून बाहेर. आभासी वॉर्डचा चालन खर्च (£350,000) यातून वजा होतो.

*पुन्हा वापरली* जाणारी मोकळी क्षमता अनेकदा भोळ्या रोख दाव्यापेक्षा जास्त मोलाची असते — पण तो वेगळ्या प्रकारचा लाभ आहे आणि त्याला तसेच लेबल लावले पाहिजे ([रोख-मुक्त करणारी विरुद्ध रोख-मुक्त न करणारी बचत](../रोख-मुक्त-करणारी-विरुद्ध-रोख-मुक्त-न-करणारी-बचत/)).

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

"वाचवलेले सर्व्हर-दिवस" अगदी तसेच वागतात. नेहमी चालू वातावरणे बंद केल्याने रोख फक्त तेव्हाच मोकळी होते जेव्हा इन्स्टन्स टर्मिनेट होतात किंवा आरक्षणे संपतात; पूलमध्ये परत शोषली गेलेली क्षमता तिच्या सीमान्त खर्चाइतकीच मोलाची (वचनबद्ध खर्चावर ~0). समांतर शिस्त: प्रत्येक दावा केलेल्या बचतीसाठी *यंत्रणा* सांगा — टर्मिनेट केले, मौल्यवान कामाने पुन्हा भरले किंवा उडून गेले. रुग्णालयातील मुक्काम कमी करणाऱ्या सॉफ्टवेअरने (सुट्टी समन्वय, दूरस्थ देखरेख, निदान चाचण्यांचा वेळ) तिन्ही परिस्थितींचे मॉडेलिंग करावे आणि प्रत्येक वॉर्डनुसार ट्रस्टला निवडू द्यावे.

## सामान्य चुका

- **सीमान्त क्षमतेचे सरासरी-खर्चाने मूल्यमापन** — सर्वसाधारण चूक.
- **दुहेरी मोजणी**: एकाच मोकळ्या खाटेपासून खाट-दिवस वाचले *आणि* दाखले टळले *आणि* प्रतीक्षा यादी कमी झाली असे सर्व मोजणे.
- **वाचलेले दिवस महागडे दिवस आहेत असे गृहीत धरणे**: मुक्कामाच्या शेवटी वाचलेले दिवस सर्वात स्वस्त (कमी तीव्रतेचे) दिवस असतात.
