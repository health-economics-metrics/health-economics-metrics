# देण्याच्या तयारीच्या मर्यादा

देण्याच्या तयारीची (WTP) मर्यादा म्हणजे निर्णयकर्ता प्रति एकक आरोग्य लाभासाठी देण्यास तयार असलेली कमाल रक्कम — [ICER](../वाढीव-खर्च-परिणामकारकता-गुणोत्तर/) चे स्वीकार/नकार निर्णयात रूपांतर करणारी रेषा.

## हे का महत्त्वाचे आहे

थ्रेशोल्ड हे ठिकाण आहे जिथे आरोग्य अर्थशास्त्र मोजमाप न राहता धोरण बनते. प्रत्येक राष्ट्रीय प्रणालीकडे एक आहे, स्पष्ट किंवा अप्रत्यक्ष, आणि स्थानिक संख्या जाणणे आरोग्य-मूल्य दाव्याची किंमत नेमकी कशी ठरवायची ते सांगते:

| संस्था | थ्रेशोल्ड (संशोधनानुसार, 2024–2025) |
|---|---|
| NICE (इंग्लंड) | £20,000–£30,000 प्रति QALY; अनुभवजन्य सरासरी निर्णय थ्रेशोल्ड ≈ £24,400 (2022–24); तीव्रता सुधारक प्रभावी कमाल मर्यादा ~£36k–£51k पर्यंत वाढवतात; अत्यंत विशेष तंत्रज्ञान £100k+ पर्यंत |
| ICER (US, अ-सरकारी) | $100,000–$150,000 प्रति QALY/evLYG किंमत बेंचमार्क; $50k–$200k श्रेणी नोंदवते |
| कॅनडा (CADTH / CDA-AMC) | ≈ CAD$50,000 प्रति QALY कार्यरत थ्रेशोल्ड |
| WHO-CHOICE (ऐतिहासिक, जागतिक) | टाळलेल्या प्रति DALY 1–3× दरडोई GDP (आता खूप बोथट म्हणून परावृत्त) |
| अनुभवजन्य UK पुरवठा बाजू (Claxton et al.) | NHS सीमेवर प्रत्यक्षात विस्थापित प्रति QALY ≈ £13,000 |

## गणित

थ्रेशोल्ड λ प्रत्येक निर्णय नियमात येतो:

```
Adopt if ICER = ΔC/ΔE < λ
Equivalently: adopt if NMB = λ×ΔE − ΔC > 0
```

λ *काय आहे* याचे दोन सिद्धांत:

- **मागणी बाजू**: समाज आरोग्यासाठी काय देण्यास तयार आहे (मूल्य निर्णय).
- **पुरवठा बाजू**: अंदाजपत्रक सध्या सीमेवर जे आरोग्य निर्माण करते (अनुभवजन्य राशी — Claxton चे ~£13k/QALY). निर्णयांसाठी वापरलेला λ पुरवठा-बाजू दरापेक्षा जास्त असेल, तर नवीन तंत्रज्ञान मंजूर करणे ते जोडते त्यापेक्षा जास्त आरोग्य विस्थापित करते.

## सोडवलेले उदाहरण

तुमची डिजिटल उपचार पद्धती £800 निव्वळ खर्चात (किंमत उणे प्रतिसंतुलन) प्रति उपचारित रुग्ण 0.05 QALY देते.

```
ICER = 800 / 0.05 = £16,000 per QALY
```

- इंग्लंड: £20k खाली → निधीयोग्य. कमाल समर्थनीय किंमत: λ = £20,000 वर, price_max = 0.05 × 20,000 + प्रतिसंतुलने = £1,000 + प्रतिसंतुलने.
- $150k/QALY वर US व्यावसायिक मांडणी: मूल्य-आधारित किंमत खूपच जास्त.
- $4,000 दरडोई-GDP थ्रेशोल्डचा देश: तेच उत्पादन निव्वळ ~$200 खाली असले पाहिजे.

तेच उत्पादन, तीन बाजार, तीन किमती — थ्रेशोल्ड *हेच* किंमत मॉडेल आहे. हे मूल्य-आधारित किंमत आहे, λ पासून उलट चालवलेले.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

प्रत्येक अभियांत्रिकी संस्थेकडे अप्रत्यक्ष λ असतो: प्रति वाचवलेल्या अभियंता-तास टूलिंगला निधी देण्याचा अडथळा. तो स्पष्ट करणे — "आम्ही प्रति विश्वासार्ह वाचवलेल्या अभियंता-तास £40 खालील कशालाही निधी देतो" — प्लॅटफॉर्म गुंतवणुकींची क्रमवारी-तक्ता तुलना शक्य करते, अगदी जसे प्रति-QALY-खर्च क्रमवारी तक्ते आरोग्य खर्चाला क्रम देतात. पुरवठा-बाजू धडाही हस्तांतरित होतो: तुमचा खरा अंतर्गत λ म्हणजे तुमचा *सध्याचा* बॅकलॉग सीमेवर जे निर्माण करतो, नेतृत्व वेळेचे मूल्य काय म्हणते ते नाही.

## सामान्य चुका

- **अधिकारक्षेत्रांमध्ये थ्रेशोल्ड खरेदी** किंवा सामान्य उत्पादनासाठी HST कमाल मर्यादा उद्धृत करणे.
- **λ ला किंमत किमान मर्यादा मानणे**: थ्रेशोल्ड पार करणे आवश्यक आहे, पुरेसे नाही — [अंदाजपत्रक प्रभाव](../अंदाजपत्रक-प्रभाव-विश्लेषण/) तरीही प्रति-एकक परवडणारे उत्पादन बुडवू शकतो.
- **थ्रेशोल्ड हलतात हे विसरणे**: NICE चे तीव्रता सुधारक (2022) आणि नियतकालिक पुनरावलोकने प्रभावी λ बदलतात; दाव्यांना दिनांक द्या.
- **आधी रूपांतर न करता वेगळ्या चलनातील थ्रेशोल्डशी ICER ची तुलना**: [आंतर-चलन ICER तुलना](../आंतर-चलन-icer-तुलना/) पहा — रूपांतरण पद्धत (क्रयशक्ती समता विरुद्ध बाजार विनिमय दर) पद्धतीदृष्ट्या परिणामकारक आहे, पूर्णांकन तपशील नाही.
- **λ-आधारित मूल्यमापनाला श्रम-बाजार VSL/VPF परंपरेशी गल्लत करणे**: त्या वेगळ्या सैद्धांतिक परंपरांतून येतात (आरोग्य-अंदाजपत्रक-बंधित पद्धती विरुद्ध वेतन-जोखीम तडजोडींमधील प्रकट पसंती) आणि नेहमी जुळवता येत नाहीत — जीवनाचे मूल्य ठरवण्याच्या पर्यायी प्रकट-पसंती दृष्टिकोनासाठी [सांख्यिकीय जीवनाचे मूल्य](../सांख्यिकीय-जीवनाचे-मूल्य/) पहा.
