# उपस्थित न राहण्याचा (DNA) दर

DNA दर म्हणजे ठरवलेल्या भेटींपैकी ज्यात रुग्ण ना उपस्थित राहतो ना रद्द करतो अशा भेटींची टक्केवारी. डॉक्टर, खोली आणि वेळ यांचा खर्च झालेला असतो; पण काहीच घडत नाही. आरोग्यसेवेतील हा सर्वात शुद्ध अपव्यय मेट्रिक आहे — आणि सॉफ्टवेअरने सर्वात जास्त सुधारता येणाऱ्यांपैकी एक.

## हे का महत्त्वाचे आहे

NHS England चे आकडे (2019): चुकलेल्या GP भेटी दरवर्षी 15 दशलक्षांपेक्षा जास्त, प्रत्येकी ~£30 — **£216M/वर्ष** पेक्षा जास्त — आणि रुग्णालयातील बाह्यरुग्ण DNA दरवर्षी ~8M (भेटींचे ~6.4%), प्रति चुकलेला स्लॉट सरासरी ~**£160**. स्मरणपत्राचा सीमान्त खर्च काही पैशांचा आणि वसूल झालेले मूल्य पूर्ण कर्मचारी असलेला क्लिनिकल स्लॉट असल्याने, DNA घटीचे ROI गणित डिजिटल आरोग्यातील सर्वोत्तम गणितांपैकी आहे, म्हणूनच SMS स्मरणपत्रे, सोपी पुनर्बुकिंग आणि भविष्यसूचक अतिबुकिंग हे डिजिटल आरोग्याच्या पहिल्या सिद्ध यशांमध्ये होते.

## गणित

```
DNA rate = DNAs / booked appointments × 100

Value of reduction = appointments × ΔDNA rate × value per recovered slot

value per recovered slot: the slot is refilled (activity value / waiting-list
reduction) or it is not (staff time partially reusable) — mechanism matters,
as with bed-days-saved.md.
```

## सोडवलेले उदाहरण

एक बाह्यरुग्ण विभाग: दरवर्षी 200,000 भेटी, DNA दर 8%. स्मरणपत्र-अधिक-पुनर्बुकिंग सेवा (एका-स्पर्श पुनर्बुकिंगसह SMS, वाहतूक माहिती, प्रवेशयोग्य स्वरूपे) DNA 5.5% पर्यंत कमी करते.

```
Recovered slots = 200,000 × 0.025 = 5,000/year
Refilled from the waiting list at ~£160 average outpatient value:
  5,000 × £160 = £800,000/year of recovered activity
Service cost: 200,000 × £0.40 = £80,000/year

Return ≈ 10:1, plus 5,000 waiting-list patients seen sooner
(see waiting-list-impact.md and referral-to-treatment.md).
```

परिणाम आकार (2.5 बिंदू) वास्तववादी आहे: स्मरणपत्र RCT सातत्याने 25–40% सापेक्ष DNA घट दाखवतात.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

- **ही शेड्युलिंग-प्रणालींची समस्या आहे**: स्मरणपत्रे, स्वयं-सेवा पुनर्बुकिंग, रद्दीकरणांमधून प्रतीक्षा-यादी स्वयं-भरणा, आणि लक्ष्यित अतिबुकिंग चालवणारी no-show भाकीत मॉडेल. प्रत्येक सामान्य सॉफ्टवेअर अभियांत्रिकी आहे ज्याला असामान्यपणे स्पष्ट आर्थिक प्रकरण आहे.
- **अभियांत्रिकी साधर्म्य**: राखीव क्षमतेसाठी no-show — बुक केलेले पण निष्क्रिय CI स्लॉट, राखीव क्लाउड क्षमता, बैठक खोल्या, मुलाखत पॅनेल. अर्थशास्त्र हस्तांतरित होते: स्वस्त स्वयंचलित धक्का (किंवा न वापरलेल्या आरक्षणांचे स्वयं-मुक्तीकरण) महागडी वचनबद्ध क्षमता परत मिळवते.
- **भाकीत नैतिकतेची झलक**: उपस्थिती डेटावर प्रशिक्षित no-show मॉडेल वंचितता आणि प्रवेश अडथळे आपल्यात सामावून घेतात; संभाव्य गैरहजर राहणाऱ्यांना *कमी प्राधान्य* देण्यासाठी त्यांचा वापर विषमता वाढवतो, उपस्थितीला *आधार* देण्यासाठी (वाहतूक मदत, टेलिफोन पर्याय) वापर ती कमी करतो. [पोहोच आणि समानता](../पोहोच-आणि-समानता/) पहा.

## सामान्य चुका

- **रद्द करून पुन्हा बुक केलेल्या भेटीचे वसूल झालेले मूल्य दोनदा मोजणे.**
- **पुन्हा न भरल्या जाणाऱ्या वसूल स्लॉटचे मूल्यमापन** — स्मरणपत्र पाठवूनही रिकामा स्लॉट रिकामाच असतो.
- **DNA शून्यावर आणण्याचा पाठलाग**: DNA चे शेवटचे बिंदू म्हणजे खऱ्या अडथळ्यांना सामोरे जाणारे रुग्ण; दंडात्मक दृष्टिकोन (N DNA नंतर सुट्टी) रुग्णांना सोडून देऊन मेट्रिक कमी करतात.
