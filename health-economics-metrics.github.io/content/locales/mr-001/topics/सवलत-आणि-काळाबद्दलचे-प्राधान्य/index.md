# सवलत आणि काळाबद्दलचे प्राधान्य

सवलत भविष्यातील खर्च आणि लाभांचे वर्तमान मूल्यात रूपांतर करते, कारण आजचा लाभ पाच वर्षांनंतरच्या त्याच लाभापेक्षा जास्त मोलाचा असतो.

## हे का महत्त्वाचे आहे

प्रत्येक आरोग्य-अर्थशास्त्र मूल्यमापन आणि प्रत्येक गंभीर सार्वजनिक-क्षेत्र व्यवसाय प्रकरण बहु-वर्षीय प्रवाहांना सवलत देते. UK च्या HM Treasury Green Book ने 3.5% वार्षिक सामाजिक काळ-प्राधान्य दर अनिवार्य केला आहे; NICE चे संदर्भ प्रकरण खर्च आणि आरोग्य परिणाम दोन्हींना दरवर्षी 3.5% सवलत देते (30+ वर्षांचे लाभ असलेल्या जवळपास-बरे करणाऱ्या उपचारांसाठी 1.5% चा नॉन-रेफरन्स-केस दर). तुमचे सॉफ्टवेअर व्यवसाय प्रकरण "10 वर्षांत £5 दशलक्ष बचत" असा दावा करत असेल, तर वित्त परीक्षक लगेच सवलत दिलेला आकडा मागेल.

## गणित

भविष्यातील रकमेचे वर्तमान मूल्य:

```
PV = FV / (1 + r)^t

PV = present value
FV = future value in year t
r  = discount rate (NICE/Green Book: 0.035)
t  = years from now
```

n वर्षांसाठी स्थिर वार्षिक लाभ B (annuity) साठी:

```
PV = B × [1 − (1 + r)^(−n)] / r
```

## सोडवलेले उदाहरण

तुमचे सॉफ्टवेअर गो-लाइव्हनंतर एका वर्षाने सुरू होऊन 5 वर्षे दरवर्षी एका NHS ट्रस्टचे £100,000 वाचवते.

सवलत न दिलेली एकूण रक्कम: £500,000.

3.5% सवलत दिल्यावर:

```
Year 1: 100,000 / 1.035^1 = £96,618
Year 2: 100,000 / 1.035^2 = £93,351
Year 3: 100,000 / 1.035^3 = £90,194
Year 4: 100,000 / 1.035^4 = £87,144
Year 5: 100,000 / 1.035^5 = £84,197

Total PV ≈ £451,505
```

प्रामाणिक मथळा सुमारे £451,000 आहे, भोळ्या बेरजेपेक्षा सुमारे 10% कमी. आता समजा वितरण एका वर्षाने घसरले: प्रत्येक पद एक वर्ष पुढे सरकते आणि PV सुमारे £436,000 पर्यंत घसरते — [विलंबाचा खर्च](../विलंबाचा-खर्च/) याचे सवलतीचे रूप.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

- **तांत्रिक कर्ज फेड आणि प्लॅटफॉर्म स्थलांतरे** वर्षांनंतर येणाऱ्या लाभ प्रवाहांचे वचन देतात; या तिमाहीत परतावा देणाऱ्या कामाशी तुलना करण्यापूर्वी त्यांना सवलत द्या.
- **आधी खर्च, नंतर लाभ** हा स्थलांतराचा प्रमाणित आकार आहे. सवलत त्या आकाराला दंड देते, योग्यच: ती नंतरच्या मूल्यासाठी आज क्षमता वचनबद्ध करण्याचे जोखीममुक्त काळ-मूल्य ठरवते.
- **"5 व्या वर्षातील बचत"** दाव्यांबद्दल दुप्पट संशय हवा — ते जोरदार सवलत दिलेले आणि अत्यंत अनिश्चित दोन्ही असतात ([संवेदनशीलता विश्लेषण](../संवेदनशीलता-विश्लेषण/) पहा).

## सामान्य चुका

- **खर्चांना सवलत पण लाभांना नाही** (किंवा उलट) — संदर्भ प्रकरण दोन्हींना समान दराने सवलत देते.
- **सार्वजनिक-क्षेत्र प्रकरणात व्यावसायिक दर (8–12%) वापरणे**, किंवा व्हेंचर-समर्थित प्रकरणात 3.5%. दर निर्णयकर्त्याशी जुळवा.
- **सवलत आणि महागाईची गल्लत.** सवलत *वास्तविक* (महागाई-समायोजित) मूल्यांना लागू होते; दोन्ही अप्रत्यक्षपणे करू नका.
