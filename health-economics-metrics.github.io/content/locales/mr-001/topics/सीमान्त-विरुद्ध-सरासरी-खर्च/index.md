# सीमान्त विरुद्ध सरासरी खर्च

सरासरी खर्च म्हणजे एकूण खर्च भागिले उत्पादित एकके. सीमान्त खर्च म्हणजे एक *अतिरिक्त* एकक उत्पादित करण्याचा खर्च. निर्णय सीमान्त खर्चावर घेतले पाहिजेत — पण प्रकाशित एकक खर्च जवळजवळ नेहमीच सरासरी असतात.

## हे का महत्त्वाचे आहे

डिजिटल आरोग्य व्यवसाय प्रकरणांमधील सर्वात सामान्य चूक म्हणजे वाचलेल्या संसाधनाचे मूल्य त्याच्या **सरासरी** खर्चाने ठरवणे, जेव्हा खरी बचत **सीमान्त** खर्च असते. रुग्णालयातील एका खाट-दिवसाचा सरासरी (पूर्ण-आत्मसात) खर्च £400+ असतो, पण एक खाट-दिवस मोकळा केल्याने £400 वाचत नाहीत — इमारत, गरम करणे आणि बहुतेक कर्मचारी खर्च चालू राहतात. वॉर्ड बंद करण्याइतक्या खाटा मोकळ्या झाल्याशिवाय प्रत्यक्षात मोकळी होणारी रोख £50–£150 असू शकते.

## गणित

```
Average cost:  AC = TC / Q
Marginal cost: MC = dTC/dQ   (cost of one more/one fewer unit)

TC = total cost, Q = quantity
```

स्थिर खर्चांमुळे क्षमता कपातीसाठी MC < AC असतो, आणि अतिरिक्त क्षमता असताना MC शून्याच्या जवळ जाऊ शकतो. बचतीचे दावे हे वापरावेत:

```
True saving = ΔQ × MC          (small changes)
True saving = step change in TC (large changes that cross a capacity threshold, e.g. closing a ward)
```

## सोडवलेले उदाहरण

तुमचे सॉफ्टवेअर सरासरी मुक्काम कमी करते, ट्रस्टमध्ये दरवर्षी 1,000 खाट-दिवस मोकळे करते.

- **भोळा दावा**: 1,000 × £400 सरासरी खर्च = **£400,000 वाचले**. चुकीचे.
- **सीमान्त दावा**: प्रति खाट-दिवस चल खर्च (अन्न, धुलाई, उपभोग्य वस्तू, काही परिचारिका लवचिकता) ≈ £120. बचत = 1,000 × £120 = **£120,000**, *अधिक* मोकळ्या झालेल्या क्षमतेचे मूल्य जर खाटा प्रतीक्षा करणाऱ्या निवडक रुग्णांनी पुन्हा भरल्या (क्रियाकलाप-आधारित देयकांतर्गत उत्पन्न, किंवा प्रतीक्षा-यादी घट).
- **पायरी-बदल दावा**: ट्रस्टने दरवर्षी 7,300 खाट-दिवस (20-खाटांचा वॉर्ड) मोकळे केले तर तो वॉर्ड प्रत्यक्षात बंद करू शकतो: कर्मचारी + चालन ≈ £1.5 दशलक्ष/वर्ष खरी रोख. आता सरासरी-खर्च गणित सत्याच्या जवळ आहे.

तोच हस्तक्षेप, तीन समर्थनीय आकडे, बदल क्षमतेची पायरी ओलांडतो की नाही यावर अवलंबून.

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

क्लाउड अर्थशास्त्र हा मूळचा सीमान्त-खर्च प्रदेश आहे:

- आधीच-राखीव क्षमतेवर आणखी एक CI रनचा सीमान्त खर्च ≈ £0 असतो, तर प्रति रन सरासरी खर्च (एकूण प्लॅटफॉर्म खर्च ÷ रन) पाउंडांमध्ये असू शकतो. सरासरी खर्चाने बिल करणाऱ्या चार्जबॅक प्रणाली संघांना सीमेवर प्रत्यक्षात मोफत असलेली सामायिक क्षमता कमी वापरायला लावतात.
- उलट, "आम्ही 30% कंप्यूट वाचवले" हे रोख तेव्हाच मोकळी करते जेव्हा इन्स्टन्स प्रत्यक्षात बंद केले जातात किंवा आरक्षणे कमी केली जातात — खाट-दिवस सापळ्याची सॉफ्टवेअर आवृत्ती. [रोख-मुक्त करणारी विरुद्ध रोख-मुक्त न करणारी बचत](../रोख-मुक्त-करणारी-विरुद्ध-रोख-मुक्त-न-करणारी-बचत/) पहा.

## सामान्य चुका

- **क्षमतेचे सरासरी खर्चाने मूल्यमापन** आणि ते रोख म्हणून मांडणे (नेहमीची).
- **सीमान्त खर्च स्थिर असल्याचे गृहीत धरणे.** तो क्षमता सीमांवर (वॉर्ड बंद, परवाना स्तर, राखीव-इन्स्टन्स वचनबद्धता) पायऱ्या घेतो.
- **एकाच प्रकरणात विस्ताराच्या निर्णयांसाठी सीमान्त पण आकुंचनासाठी सरासरी खर्च वापरणे** — प्रत्यक्ष निर्णयानुसार निवडा.
