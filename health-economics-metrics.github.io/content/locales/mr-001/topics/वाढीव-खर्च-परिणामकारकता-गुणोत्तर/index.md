# वाढीव खर्च-परिणामकारकता गुणोत्तर (ICER)

ICER म्हणजे पुढच्या-सर्वोत्तम पर्यायाऐवजी एक पर्याय निवडल्यास प्रति अतिरिक्त एकक आरोग्य परिणामाचा अतिरिक्त खर्च. हा आरोग्य तंत्रज्ञान मूल्यमापनाचा मथळा आकडा आहे. (परिणाम एकक QALY असेल तेव्हा त्याला वाढीव खर्च-उपयुक्तता गुणोत्तर, ICUR, असेही म्हणतात.)

## हे का महत्त्वाचे आहे

आरोग्य प्रणाली तंत्रज्ञानाचे मूल्यमापन कधीही एकट्याने करत नाहीत — नेहमी *वाढीव* पद्धतीने, अन्यथा जे केले गेले असते त्याविरुद्ध. NICE तंत्रज्ञानाचा ICER आपल्या **£20,000–£30,000 प्रति QALY** थ्रेशोल्डशी तुलना करते; US ICER संस्था $50,000–$200,000/QALY वर नोंदवते; कॅनडा अंदाजे CAD$50,000/QALY वर काम करतो. तुमचे उत्पादन राष्ट्रीय आरोग्य सेवेसाठी "योग्य" आहे का हे औपचारिकपणे त्याचा ICER स्थानिक थ्रेशोल्ड ओलांडतो का यावर अवलंबून आहे. [देण्याच्या तयारीच्या मर्यादा](../देण्याच्या-तयारीच्या-मर्यादा/) पहा.

## गणित

```
ICER = (Cost_new − Cost_comparator) / (Effect_new − Effect_comparator)
     = ΔC / ΔE
```

अर्थ लावण्याचे नियम:

- ΔC < 0, ΔE > 0: नवीन पर्याय **वर्चस्व** गाजवतो — स्वस्त आणि चांगला; गुणोत्तराची गरज नाही.
- ΔC > 0, ΔE > 0: ICER काढा, थ्रेशोल्ड λ शी तुलना करा; ICER < λ असेल तर स्वीकारा.
- ΔC > 0, ΔE < 0: नवीन पर्याय वर्चस्वित आहे — नाकारा.
- ΔE = 0 जवळ गुणोत्तरे वाईट वागतात — क्रम लावण्यासाठी [निव्वळ आर्थिक लाभ](../निव्वळ-आर्थिक-लाभ/) पसंत करा.

तुलनात्मक *पुढचा-सर्वोत्तम अ-वर्चस्वित पर्याय* असला पाहिजे, "काही न करणे" नाही — [वर्चस्व आणि कार्यक्षमता सीमा](../वर्चस्व-आणि-कार्यक्षमता-सीमा/) पहा.

## सोडवलेले उदाहरण

हृदयविकार रुग्णांसाठी दूरस्थ-देखरेख सेवा, प्रति 1,000 रुग्ण/वर्ष, नेहमीच्या काळजी विरुद्ध:

```
Costs:   service £900,000; admissions avoided save £600,000
         ΔC = 900,000 − 600,000 = £300,000
Effects: earlier intervention gains 25 QALYs
         ΔE = 25

ICER = 300,000 / 25 = £12,000 per QALY
```

£12,000/QALY हे NICE च्या £20,000 थ्रेशोल्डच्या सहज खाली आहे — मजबूत प्रकरण. *निव्वळ* खर्च कसा महत्त्वाचा आहे ते पहा: £600,000 च्या प्रतिसंतुलनाशिवाय ICER £36,000/QALY असता आणि प्रकरण बहुधा अपयशी ठरले असते. खर्च प्रतिसंतुलने आणि त्यांच्या पुराव्याची गुणवत्ता हेच ठिकाण आहे जिथे हे विश्लेषण जिंकले किंवा हरले जाते ([टाळलेले डाउनस्ट्रीम खर्च](../टाळलेले-डाउनस्ट्रीम-खर्च/) पहा).

## सॉफ्टवेअर अभियांत्रिकीशी संबंध

ICER शिस्त अभियांत्रिकी निर्णयांना संपूर्णपणे हस्तांतरित होते:

```
(cost of option B − cost of option A) / (outcome B − outcome A)
```

— प्रति अतिरिक्त तैनाती, प्रति वाचवलेला अभियंता-तास, प्रति टाळलेली घटना वाढीव खर्च — नेहमी पुढच्या-सर्वोत्तम पर्यायाविरुद्ध, काही न करण्याविरुद्ध नाही. चोरण्यासारख्या दोन सवयी: (1) *तुलनात्मक स्पष्टपणे नाव द्या*; बहुतेक टूल ROI दावे गुपचूप पुतळ्याशी तुलना करतात; (2) *आधी खर्च निव्वळ करा* — £100k खर्च असलेले पण £80k विद्यमान खर्च विस्थापित करणारे टूल ΔC = £20k आहे.

## सामान्य चुका

- **स्पष्ट रूपांतरण पायरीशिवाय चलनांमध्ये ICER ची तुलना**: एका देशाच्या चलनात मोजलेला ICER दुसऱ्या देशाच्या थ्रेशोल्डशी तुलना करण्यापूर्वी नमूद पद्धतीने रूपांतरित केला पाहिजे — रूपांतरण घटकाची निवड (क्रयशक्ती समता विरुद्ध बाजार विनिमय दर) स्वतः स्वीकाराचा निर्णय कसा उलटवू शकते यासाठी [आंतर-चलन ICER तुलना](../आंतर-चलन-icer-तुलना/) पहा.
- **तुलनात्मक हेराफेरी**: अप्रचलित किंवा कृत्रिमरीत्या वाईट मूलरेषेशी तुलना ΔE फुगवते आणि ICER ची खुशामत करते.
- **वाढीऐवजी सरासरी**: संपूर्ण कार्यक्रमाचा प्रति QALY खर्च म्हणजे त्याचा विस्तार किंवा स्वीकार करण्याचा ICER नाही.
- **बिंदू-अंदाज पूजा**: ICER हे दोन अनिश्चित फरकांचे गुणोत्तर आहेत; अनिश्चितता [PSA आणि CEAC](../संभाव्यताधारित-संवेदनशीलता-विश्लेषण/) द्वारे नोंदवा.
- **ऋण ICER संदिग्ध असतात** (स्वस्त-आणि-चांगला विरुद्ध महाग-आणि-वाईट यांचे चिन्ह सारखेच) — कोणत्या चतुर्थांशात आहे हे सांगितल्याशिवाय कधीही ऋण ICER नोंदवू नका.
