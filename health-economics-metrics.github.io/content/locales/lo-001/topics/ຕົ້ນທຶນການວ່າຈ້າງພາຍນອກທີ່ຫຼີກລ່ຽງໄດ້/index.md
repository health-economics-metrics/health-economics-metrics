# ຕົ້ນທຶນການວ່າຈ້າງພາຍນອກທີ່ຫຼີກລ່ຽງໄດ້

ເມື່ອໂຮງໝໍ trust ບໍ່ສາມາດບັນລຸເປົ້າໝາຍດ້ວຍຄວາມສາມາດພາຍໃນ ມັນຊື້ຄວາມສາມາດໃນອັດຕາພິເສດ: ເຮັດວຽກລ່ວງເວລາທ້າຍອາທິດຂອງບຸກຄະລາກອນຕົນເອງ ຫຼື ວ່າຈ້າງພາຍນອກໃຫ້ຜູ້ໃຫ້ບໍລິການເອກະຊົນເຮັດການຜ່າຕັດ. ມູນຄ່າທາງເສດຖະກິດຂອງຊອບແວທີ່ປົດປ່ອຍຄວາມສາມາດລວມ**ຕົ້ນທຶນທີ່ຫຼີກລ່ຽງໄດ້ຂອງວຽກອັດຕາພິເສດນັ້ນ**.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ພາຍໃຕ້ຄວາມກົດດັນຂອງການຟື້ນຟູການຜ່າຕັດນັດໝາຍ ໂຮງໝໍ trust ຈ່າຍລາຄາຕະຫຼາດຈຸດຂອງພາກເອກະຊົນເປັນປະຈຳ (ມັກ 1.2–1.5 ເທົ່າຂອງລາຄາໃນແຜນ NHS) ຫຼື ອັດຕາ waiting-list-initiative ພິເສດໃຫ້ແພດທີ່ປຶກສາຂອງຕົນເອງສຳລັບລາຍການທ້າຍອາທິດ. ບໍ່ຄືກັບການອ້າງຄວາມສາມາດທົ່ວໄປ ການຫຼີກລ່ຽງການວ່າຈ້າງພາຍນອກ**ປົດປ່ອຍເງິນສົດ**: ໃບແຈ້ງໜີ້ຈາກຜູ້ໃຫ້ບໍລິການເອກະຊົນບໍ່ຖືກອອກຈິງໆ. ນັ້ນເຮັດໃຫ້ມັນເປັນໜຶ່ງໃນແຖວຜົນປະໂຫຍດທີ່ແຂງແຮງທີ່ສຸດສຳລັບຊອບແວທີ່ເພີ່ມປະລິມານງານພາຍໃນ — ແລະ ເປັນໜຶ່ງໃນອັນທີ່ສະແດງຫຼັກຖານໄດ້ງ່າຍທີ່ສຸດ ເພາະລາຍຈ່າຍວ່າຈ້າງພາຍນອກເປັນແຖວງົບປະມານທີ່ເຫັນໄດ້ຢູ່ແລ້ວ.

## ຄະນິດສາດ

```
Avoidable outsourcing cost = activity moved in-house × (outsourced unit price
                             − internal marginal cost per case)

Internal marginal cost: consumables + variable staffing for the extra activity
— the fixed estate is already paid for (see marginal-vs-average-cost.md).
```

ການອ້າງຕ້ອງການໃຫ້ຄວາມສາມາດພາຍໃນທີ່ປົດປ່ອຍອອກມາຮອງຮັບກິດຈະກຳໄດ້ຈິງ: ຫ້ອງຜ່າຕັດ, ຕຽງ, ແລະ ບຸກຄະລາກອນຕ້ອງພ້ອມທັງໝົດ (ຂໍ້ຈຳກັດທີ່ຜູກມັດເປັນຜູ້ຄວບຄຸມ — ທິດສະດີຂໍ້ຈຳກັດອີກຄັ້ງ).

## ຕົວຢ່າງການຄິດໄລ່

ໂຮງໝໍ trust ວ່າຈ້າງພາຍນອກຜ່າຕັດຕາຂາວ 800 ຄັ້ງ/ປີ ລາຄາຄັ້ງລະ £900: ລາຍຈ່າຍພາຍນອກ £720,000/ປີ ທຽບກັບລາຄາຕາມແຜນ ~£750.

ຊອບແວຈັດຕາຕະລາງຫ້ອງຜ່າຕັດ (ການປັບລາຍການໃຫ້ເໝາະສົມ, ການເຕີມຊ່ອງວ່າງຈາກການຍົກເລີກ, ການຕິດຕາມເວລາປ່ຽນຮອບ) ເພີ່ມການນຳໃຊ້ຫ້ອງຜ່າຕັດພາຍໃນພໍທີ່ຈະນຳກັບຄືນ 500 ຄັ້ງ:

```
Internal marginal cost per case ≈ £350 (consumables + sessional staffing)
Saving = 500 × (900 − 350) = £275,000/year — cash-releasing
Remaining outsourcing: 300 × £900 = £270,000 (was £720,000)
```

ຕົ້ນທຶນຊອບແວ £90,000/ປີ → ສຸດທິ ≈ **+£185,000/ປີ ເປັນເງິນສົດທີ່ເກັບໄດ້ຈິງ** ບວກຜົນປະໂຫຍດດ້ານຄຸນນະພາບພາຍໃນ ແລະ ການຝຶກອົບຮົມຈາກການເກັບວຽກໄວ້ພາຍໃນ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ສິ່ງທີ່ຄ້າຍກັນໂດຍກົງແມ່ນ**ສ່ວນເພີ່ມພິເສດຂອງຜູ້ຮັບເໝົາ ແລະ ທີ່ປຶກສາ**: ເມື່ອຄວາມສາມາດດ້ານວິສະວະກຳພາຍໃນບໍ່ພໍບັນລຸພັນທະ ອົງກອນຊື້ຄວາມສາມາດພາຍນອກທີ່ 1.5–3 ເທົ່າຂອງອັດຕາພາຍໃນທີ່ລວມຄ່າໃຊ້ຈ່າຍ. ການລົງທຶນດ້ານແພລດຟອມ ແລະ ຜະລິດຕະພາບທີ່ເພີ່ມປະລິມານງານພາຍໃນຄວນອ້າງການຫຼີກລ່ຽງລາຍຈ່າຍຜູ້ຮັບເໝົາຕາມນີ້ຢ່າງແນ່ນອນ — ອັດຕາຕໍ່ວັນພາຍນອກ ລົບ ຕົ້ນທຶນສ່ວນເພີ່ມພາຍໃນ ຄູນ ວຽກທີ່ນຳກັບຄືນ — ເພາະມັນເປັນໜຶ່ງໃນແຖວທີ່ປົດປ່ອຍເງິນສົດຈິງໆໜ້ອຍແຖວໃນກໍລະນີທຸລະກິດຜະລິດຕະພາບນັກພັດທະນາ. ຂໍ້ຄວນລະວັງດຽວກັນນຳໃຊ້: ຄວາມສາມາດພາຍໃນຕ້ອງມີຢູ່ຈິງ ແລະ ຖືກຈັດຕາຕະລາງໃຫ້ວຽກທີ່ນຳກັບຄືນ ບໍ່ດັ່ງນັ້ນການອ້າງແມ່ນນິຍາຍ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ອ້າງການນຳກັບຄືນໂດຍບໍ່ມີຕ່ອງໂສ້ຄວາມສາມາດຄົບ** — ສັນຍະແພດຖືກປົດປ່ອຍແຕ່ບໍ່ມີຊ່ອງຫ້ອງຜ່າຕັດ (ຫຼື ວິສະວະກອນຖືກປົດປ່ອຍແຕ່ບໍ່ມີແບນວິດການຈັດການຜະລິດຕະພັນ) ກໍບໍ່ໄດ້ນຳກັບຄືນຫຍັງ.
- **ປຽບທຽບລາຄາວ່າຈ້າງພາຍນອກກັບຕົ້ນທຶນສະເລ່ຍພາຍໃນ** ແທນຕົ້ນທຶນສ່ວນເພີ່ມ — ເຮັດໃຫ້ເງິນປະຢັດຕ່ຳກວ່າຈິງ ເຊິ່ງແປກ; ຕົ້ນທຶນຄົງທີ່ເກີດຂຶ້ນບໍ່ວ່າທາງໃດ.
- **ຄວາມບໍ່ສົມມາດຂອງຄຸນນະພາບ/ຄວາມຊັບຊ້ອນ**: ກໍລະນີທີ່ວ່າຈ້າງພາຍນອກມັກເປັນກໍລະນີງ່າຍ; ການນຳກັບຄືນປ່ຽນສ່ວນປະສົມກໍລະນີພາຍໃນ ແລະ ຕົ້ນທຶນຕໍ່ຫົວໜ່ວຍ.
