# ດັດຊະນີຄວາມເຂັ້ມຂຸ້ນ

ດັດຊະນີຄວາມເຂັ້ມຂຸ້ນ (Concentration Index; Wagstaff, Paci, van Doorslaer, 1991) ແມ່ນມາດຕະການສະຖິຕິມາດຕະຖານຂອງຄວາມບໍ່ເທົ່າທຽມທີ່ກ່ຽວຂ້ອງກັບເສດຖະກິດ-ສັງຄົມໃນຕົວແປດ້ານສຸຂະພາບ ມີຄ່າຕັ້ງແຕ່ -1 ຫາ 1. ຄ່າລົບໝາຍຄວາມວ່າຕົວແປສຸຂະພາບກະຈຸກຢູ່ໃນກຸ່ມທີ່ເສຍປຽບທາງເສດຖະກິດ-ສັງຄົມ, ຄ່າບວກໝາຍຄວາມວ່າກະຈຸກຢູ່ໃນກຸ່ມທີ່ມີຖານະດີກວ່າ, ແລະ ສູນໝາຍຄວາມວ່າບໍ່ມີລະດັບຊັ້ນທາງເສດຖະກິດ-ສັງຄົມທີ່ສອດຄ່ອງ — ມັນປ່ຽນຄວາມສົງໄສກ່ຽວກັບການແຈກຢາຍທີ່ບໍ່ເທົ່າທຽມໃຫ້ເປັນຕົວເລກດຽວທີ່ປຽບທຽບໄດ້.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ໂຄງການອາດເບິ່ງມີປະສິດທິຜົນໂດຍລວມ ແຕ່ຍັງສົ່ງມອບຜົນປະໂຫຍດເກືອບທັງໝົດໃຫ້ຄົນທີ່ມີຖານະດີຢູ່ແລ້ວ. ຄວາມກັງວົນດ້ານການແຈກຢາຍແບບນີ້ແມ່ນສິ່ງທີ່[ການເຂົ້າເຖິງ ແລະ ຄວາມເທົ່າທຽມ](../ການເຂົ້າເຖິງ-ແລະ-ຄວາມເທົ່າທຽມ/)ຕິດຕາມແບບບັນຍາຍ — ການເຂົ້າເຖິງແຍກຕາມຫ້າສ່ວນຂອງຄວາມທຸກຍາກ, ຊ່ອງຫວ່າງຄວາມເທົ່າທຽມລະຫວ່າງກຸ່ມເທິງແລະລຸ່ມ — ແຕ່ຕາຕະລາງແຍກຊັ້ນບໍ່ບີບອັດເປັນເສັ້ນແນວໂນ້ມດຽວ ແລະ ປຽບທຽບຂ້າມສອງການແຊກແຊງທີ່ແຕກຕ່າງກັນທັງໝົດທີ່ວັດດ້ວຍມາດຕາສ່ວນຕ່າງກັນໄດ້ຍາກ. ດັດຊະນີຄວາມເຂັ້ມຂຸ້ນແກ້ທັງສອງບັນຫາ: ຄິດໄລ່ແບບດຽວກັນສຳລັບຕົວແປສຸຂະພາບໃດກໍໄດ້ຕໍ່ການຈັດອັນດັບເສດຖະກິດ-ສັງຄົມໃດກໍໄດ້ ດັ່ງນັ້ນບໍລິການສຸຂະພາບແຫ່ງຊາດສາມາດຕິດຕາມວ່າຄວາມບໍ່ເທົ່າທຽມຂອງບໍລິການດິຈິຕອນສະເພາະກວ້າງຂຶ້ນ ຫຼື ແຄບລົງລະຫວ່າງເວີຊັນ, ແລະ ປຽບທຽບຄວາມຍຸຕິທຳດ້ານການແຈກຢາຍຂອງການນຳໃຊ້ແອັບກັບ, ຕົວຢ່າງ, ໂຄງການຄັດກອງ, ໃນມາດຕາສ່ວນທີ່ເປັນມາດຕະຖານດຽວກັນ.

## ຄະນິດສາດ

```
CI = (2 / mean(health_values)) × Cov(health_values, socioeconomic_ranks)

Cov(X, Y) = mean(X × Y) − mean(X) × mean(Y)   (population covariance)

socioeconomic_ranks: each person's fractional rank in the socioeconomic
distribution, in [0, 1] (0 = most disadvantaged, 1 = most advantaged;
for grouped/banded data, conventionally the midpoint rank of each group)
```

ນີ້ແມ່ນ "ສູດໂຄແວຣຽນຊ໌ທີ່ສະດວກ" (O'Donnell, van Doorslaer, Wagstaff, Lindelow, World Bank 2008) — ທາງລັດມາດຕະຖານຂອງຜູ້ປະຕິບັດໃນການຄິດໄລ່ດັດຊະນີຄວາມເຂັ້ມຂຸ້ນໂດຍກົງຈາກຂໍ້ມູນສັງເກດເປັນຄູ່ ໂດຍບໍ່ຕ້ອງລາກແລະອິນທິເກຣດໃຕ້ເສັ້ນໂຄ້ງຄວາມເຂັ້ມຂຸ້ນກ່ອນ.

## ຕົວຢ່າງການຄິດໄລ່

ຄະແນນສຸຂະພາບດີທີ່ລາຍງານເອງ (1 = ຮ້າຍທີ່ສຸດ, 4 = ດີທີ່ສຸດ) ທີ່ສັງເກດຂ້າມສີ່ຄວອຕາຍເສດຖະກິດ-ສັງຄົມຂະໜາດເທົ່າກັນ ແຕ່ລະອັນແທນດ້ວຍອັນດັບຈຸດກາງຂອງຄວອຕາຍ:

```
health_values        = [1.0, 2.0, 3.0, 4.0]
socioeconomic_ranks  = [0.125, 0.375, 0.625, 0.875]

mean(health_values)        = 2.5
mean(health × rank)        = mean([0.125, 0.75, 1.875, 3.5]) = 1.5625
mean(socioeconomic_ranks)  = 0.5

Cov = 1.5625 − 2.5 × 0.5 = 0.3125

CI = 2 × 0.3125 / 2.5 = 0.25
```

`0.25` ທີ່ເປັນບວກໝາຍຄວາມວ່າຄະແນນສຸຂະພາບນີ້ກະຈຸກຢູ່ໃນກຸ່ມທີ່ມີຖານະດີທາງເສດຖະກິດ-ສັງຄົມ — ຜູ້ຕອບທີ່ໄດ້ຄະແນນສູງເອີ້ນໄປທາງສ່ວນທີ່ມີຖານະດີຂອງການຈັດອັນດັບ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ນີ້ແມ່ນການວັດຄວາມບໍ່ເທົ່າທຽມແບບອີງໂຄແວຣຽນຊ໌ດຽວກັນທີ່ໃຊ້ໃນເສດຖະສາດທົ່ວໄປ (ຍາດພີ່ນ້ອງຂອງສຳປະສິດ Gini), ແລະ ນຳມາໃຊ້ວັດວ່າຜົນປະໂຫຍດຂອງຜະລິດຕະພັນຊອບແວກະຈຸກຢູ່ໃນກຸ່ມຜູ້ໃຊ້ທີ່ມີຖານະດີຢູ່ແລ້ວ ແທນທີ່ຈະກະຈາຍຢ່າງເທົ່າທຽມ — ການຂະຫຍາຍໂດຍກົງຂອງ[ການເຂົ້າເຖິງ ແລະ ຄວາມເທົ່າທຽມ](../ການເຂົ້າເຖິງ-ແລະ-ຄວາມເທົ່າທຽມ/) (ມິຕິ "reach" ຂອງ RE-AIM) ໄປເປັນມາດຕະການສະຖິຕິທາງການ ແທນຊ່ອງຫວ່າງທີ່ບັນຍາຍ. ບ່ອນທີ່ reach-and-equity ລາຍງານຜົນກະທົບຕໍ່ຊັ້ນ ດັດຊະນີຄວາມເຂັ້ມຂຸ້ນບີບອັດການແຈກຢາຍທັງໝົດເປັນຕົວເລກມີເຄື່ອງໝາຍດຽວ ເໝາະເປັນ KPI ດຽວທີ່ຕິດຕາມຂ້າມເວີຊັນ — ໃຊ້ໄດ້ຈິງສຳລັບແດຊບອດ ບ່ອນທີ່ການແຍກຊັ້ນເຕັມບໍ່ເໝາະ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການເລື່ອນຂອງຂໍ້ຕົກລົງເລື່ອງເຄື່ອງໝາຍ**: ເຄື່ອງໝາຍຂຶ້ນກັບວ່າຕົວແປສຸຂະພາບແລະອັນດັບຖືກນິຍາມແນວໃດ — ປ່ຽນອັນໃດອັນໜຶ່ງກໍກັບເຄື່ອງໝາຍ ດັ່ງນັ້ນຕ້ອງລະບຸຂໍ້ຕົກລົງທີ່ໃຊ້ຢ່າງຊັດເຈນຄຽງຄູ່ຄ່າທີ່ລາຍງານສະເໝີ.
- **ອັນດັບຂອບແທນອັນດັບຈຸດກາງ**: ຂໍ້ມູນເສດຖະກິດ-ສັງຄົມທີ່ແບ່ງກຸ່ມ (ເຊັ່ນ ຫ້າສ່ວນ) ຕ້ອງໃຊ້ອັນດັບສ່ວນຂອງແຕ່ລະກຸ່ມທີ່*ຈຸດກາງ* ບໍ່ແມ່ນຂອບ ບໍ່ດັ່ງນັ້ນດັດຊະນີມີຄວາມລຳອຽງ.
- **ອ່ານ "ໃກ້ສູນ" ວ່າ "ບໍ່ມີຄວາມບໍ່ເທົ່າທຽມ"**: ດັດຊະນີຄວາມເຂັ້ມຂຸ້ນໃກ້ສູນໝາຍເຖິງ "ບໍ່ມີລະດັບຊັ້ນເສດຖະກິດ-ສັງຄົມທີ່ສອດຄ່ອງ" ບໍ່ແມ່ນ "ບໍ່ມີຄວາມບໍ່ເທົ່າທຽມ" ໃນຄວາມໝາຍສົມບູນ — ຄວາມບໍ່ເທົ່າທຽມທີ່ຊົດເຊີຍກັນໃນທິດທາງຕ່າງກັນອາດຫັກລ້າງກັນ.
