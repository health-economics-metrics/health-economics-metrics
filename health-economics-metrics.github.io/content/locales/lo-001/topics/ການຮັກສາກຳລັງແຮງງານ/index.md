# ການຮັກສາກຳລັງແຮງງານ

ເສດຖະສາດການຮັກສາກຳລັງແຮງງານວັດປະລິມານວ່າການລາອອກຂອງພະນັກງານມີຕົ້ນທຶນຕໍ່ລະບົບສຸຂະພາບເທົ່າໃດ — ການຮັບສະໝັກ, ການປະຖົມນິເທດ, ການຄຸ້ມຄອງຕຳແໜ່ງວ່າງ — ແລະ ດັ່ງນັ້ນຊອບແວທີ່ຫຼຸດຄວາມເມື່ອຍລ້າດ້ານບໍລິຫານມີຄ່າເທົ່າໃດ. ຄວາມເມື່ອຍລ້າຈາກງານຂໍ້ມູນບໍລິຫານທີ່ຊ້ຳໆແມ່ນຕົວຂັບເຄື່ອນຫຼັກຂອງການລາອອກຂອງພະນັກງານ ແລະ ການຂາດງານຍ້ອນເຈັບປ່ວຍໃນ NHS.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ເມື່ອແພດລາອອກ, ທຣັສຈ່າຍສາມຄັ້ງ: ເພື່ອຮັບສະໝັກຄົນແທນ (ໂຄສະນາ, ຄ່າທຳນຽມຕົວແທນ, ການສຳພາດ), ເພື່ອປະຖົມນິເທດເຂົາ (ຫຼາຍເດືອນຂອງຜະລິດຕະພາບຫຼຸດ, ການເບິ່ງແຍງ), ແລະ ເພື່ອຄຸ້ມຄອງຕຳແໜ່ງວ່າງລະຫວ່າງນັ້ນ — ປົກກະຕິດ້ວຍພະນັກງານຕົວແທນ ຫຼື ຊົ່ວຄາວທີ່ 2–3× ອັດຕາ Agenda for Change ຫຼັກ (ເບິ່ງ [ຕົ້ນທຶນການວ່າຈ້າງພາຍນອກທີ່ຫຼີກລ່ຽງໄດ້](../ຕົ້ນທຶນການວ່າຈ້າງພາຍນອກທີ່ຫຼີກລ່ຽງໄດ້/) ແລະ [ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດຢ່າງແທ້ຈິງ](../ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດຢ່າງແທ້ຈິງ/)). ເພາະຕົ້ນທຶນການລາອອກເປັນເງິນສົດຈິງ, ການປັບປຸງການຮັກສາແມ່ນໜຶ່ງໃນຜົນປະໂຫຍດດ້ານກຳລັງແຮງງານໜ້ອຍອັນທີ່ຜູ້ອຳນວຍການການເງິນເກັບເງິນໄດ້. ຄວາມຂັດຂ້ອງດ້ານບໍລິຫານຢູ່ໃນບັນດາຕົວຂັບເຄື່ອນທີ່ຖືກອ້າງສູງສຸດຂອງຄວາມເມື່ອຍລ້າທາງຄລີນິກຢ່າງສອດຄ່ອງ, ເຊິ່ງເຮັດໃຫ້ມັນເປັນຕົ້ນທຶນທີ່ຊອບແວແກ້ໄຂໄດ້.

## ຄະນິດສາດ

```
Cost per leaver = recruitment cost + onboarding/productivity-ramp cost
                + vacancy cover premium × vacancy duration

Annual turnover cost = headcount × turnover rate × cost per leaver

Value of software  = headcount × Δturnover rate × cost per leaver
                   + sickness-absence reduction × cover cost/day
```

ຕ່ອງໂສ້ສາເຫດມີສອງຂໍ້ທີ່ຄາດຄະເນ — ຊອບແວ → ຄວາມເມື່ອຍລ້າ/ຄວາມຂັດຂ້ອງ, ແລະ ຄວາມເມື່ອຍລ້າ → ການລາອອກ — ດັ່ງນັ້ນໃຫ້ຫຼັກຖານທັງສອງ (ການສຳຫຼວດພະນັກງານກ່ອນ/ຫຼັງ; ການສຳພັນຄວາມເມື່ອຍລ້າ-ການລາອອກທີ່ເຜີຍແຜ່) ແລະ ຮັກສາ Δ ທີ່ອ້າງໃຫ້ປານກາງ.

## ຕົວຢ່າງການຄິດໄລ່

ທຣັສຈ້າງພະຍາບານ 1,200 ຄົນ; ການລາອອກ 11%/ປີ. ຕົ້ນທຶນຕໍ່ຜູ້ລາອອກ:

```
Recruitment ≈ £4,500;  onboarding/ramp ≈ £6,000
Vacancy cover: 4 months × 0.6 WTE covered by agency premium ≈ £8,000
Total ≈ £18,500 per leaver
Baseline turnover cost = 1,200 × 0.11 × 18,500 ≈ £2.44M/year
```

ຊອບແວຫຼຸດພາລະເອກະສານ (ການປະເມີນທີ່ຖືກເຕີມອັດຕະໂນມັດ, single sign-on, ການບອກໃຫ້ຂຽນ) ເຄື່ອນການລາອອກໄດ້ 1 ຈຸດເປີເຊັນຢ່າງສົມເຫດສົມຜົນ:

```
Value = 1,200 × 0.01 × 18,500 = £222,000/year cash-relevant
```

ການອ້າງ 1 ຈຸດທີ່ມີຄະແນນຄວາມຂັດຂ້ອງຂອງການສຳຫຼວດພະນັກງານສະໜັບສະໜູນໜ້າເຊື່ອຖື; ການອ້າງ 4 ຈຸດບໍ່. ຣັນ [tornado](../ການວິເຄາະຄວາມອ່ອນໄຫວ/) ກັບ Δturnover: ມັນຄອບງຳທຸກຢ່າງອື່ນໃນແບບຈຳລອງ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ເລກການຮັກສາວິສະວະກຳຄືກັນ ແລະ ມີເອກະສານໜ້ອຍກວ່າ: ການທົດແທນວິສະວະກອນອາວຸໂສມີຕົ້ນທຶນ 6–12 ເດືອນຂອງເງິນເດືອນເຕັມ (ການຮັບສະໝັກ, ການປັບຕົວ, ບໍລິບົດທີ່ສູນເສຍ), ດັ່ງນັ້ນອົງກອນ 200 ຄົນທີ່ມີການລາອອກ 15% ເຜົາຫຼາຍລ້ານຕໍ່ປີກັບການຫຼຸດຫາຍ. ການລົງທຶນປະສົບການນັກພັດທະນາ ([SPACE ແລະ DevEx](../space-ແລະ-devex/)) ແມ່ນຕົວທຽບເທົ່າໂດຍກົງຂອງການບັນເທົາພາລະເອກະສານສຳລັບພະຍາບານ — ແລະ ຄວນໃຫ້ເຫດຜົນແບບດຽວກັນ: ຄະແນນຄວາມຂັດຂ້ອງທີ່ວັດ, ຜົນກະທົບທີ່ອ້າງປານກາງຕໍ່ການລາອອກ, ຕົ້ນທຶນຕໍ່ຜູ້ລາອອກຈາກຂໍ້ມູນການເງິນຂອງທ່ານເອງ. ວິໄນເສດຖະສາດສຸຂະພາບທີ່ຄວນລອກແມ່ນ *ການຄິດຕົ້ນທຶນຜູ້ລາອອກຢ່າງຊື່ສັດ* ແທນການໂຕ້ຖຽງວ່າຄົນ "ລາອອກຈິງ" ຍ້ອນເຄື່ອງມືຫຼືບໍ່.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຖືວ່າທຸກການເຄື່ອນໄຫວຂອງການລາອອກເກີດຈາກການແຊກແຊງຂອງທ່ານ** — ຕະຫຼາດແຮງງານເຄື່ອນການລາອອກຫຼາຍກວ່າຊອບແວຫຼາຍ; ໃຊ້ກຸ່ມຄວບຄຸມ ຫຼື ຢ່າງໜ້ອຍການປັບແນວໂນ້ມຂອງຂະແໜງ.
- **ນັບຊ້ຳ**: ການປະຢັດການຮັກສາ ແລະ ການປະຢັດລາຍຈ່າຍຕົວແທນຊ້ອນກັນ (ການຄຸ້ມຄອງຕຳແໜ່ງວ່າງ *ແມ່ນ* ລາຍຈ່າຍຕົວແທນ); ປະສານບັນທັດ.
- **ເມີນເສີຍຄວາມລ່າຊ້າ**: ການລາອອກທີ່ຂັບດ້ວຍຄວາມເມື່ອຍລ້າຕອບສະໜອງຕໍ່ການປ່ຽນຄວາມຂັດຂ້ອງໃນ 1–2 ປີ, ບໍ່ແມ່ນໄຕມາດຖັດໄປ.
