# ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ

ເກນຄວາມເຕັມໃຈທີ່ຈະຈ່າຍ (WTP) ແມ່ນຈຳນວນສູງສຸດທີ່ຜູ້ຕັດສິນໃຈຈະຈ່າຍຕໍ່ໜຶ່ງຫົວໜ່ວຍຜົນໄດ້ຮັບດ້ານສຸຂະພາບ — ເສັ້ນທີ່ປ່ຽນ [ICER](../ອັດຕາສ່ວນຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນສ່ວນເພີ່ມ/) ເປັນການຕັດສິນໃຈຮັບເອົາ/ປະຕິເສດ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ເກນແມ່ນບ່ອນທີ່ເສດຖະສາດສຸຂະພາບຢຸດເປັນການວັດ ແລະ ກາຍເປັນນະໂຍບາຍ. ທຸກລະບົບແຫ່ງຊາດມີອັນໜຶ່ງ, ຊັດເຈນ ຫຼື ແອບແຝງ, ແລະ ການຮູ້ຕົວເລກໃນທ້ອງຖິ່ນບອກທ່ານຢ່າງແນ່ນອນວ່າຈະຕັ້ງລາຄາການອ້າງມູນຄ່າສຸຂະພາບແນວໃດ:

| ອົງກອນ | ເກນ (ຕາມການຄົ້ນຄວ້າ, 2024–2025) |
|---|---|
| NICE (England) | £20,000–£30,000 per QALY; empirical average decision threshold ≈ £24,400 (2022–24); severity modifiers raise effective ceiling to ~£36k–£51k; highly specialized technologies up to £100k+ |
| ICER (US, non-governmental) | $100,000–$150,000 per QALY/evLYG price benchmarks; reports $50k–$200k range |
| Canada (CADTH / CDA-AMC) | ≈ CAD$50,000 per QALY working threshold |
| WHO-CHOICE (historical, global) | 1–3× GDP per capita per DALY averted (now discouraged as too blunt) |
| Empirical UK supply side (Claxton et al.) | ≈ £13,000 per QALY actually displaced at the NHS margin |

## ຄະນິດສາດ

ເກນ λ ເຂົ້າທຸກກົດການຕັດສິນໃຈ:

```
Adopt if ICER = ΔC/ΔE < λ
Equivalently: adopt if NMB = λ×ΔE − ΔC > 0
```

ສອງທິດສະດີວ່າ λ *ແມ່ນຫຍັງ*:

- **ດ້ານຄວາມຕ້ອງການ**: ສິ່ງທີ່ສັງຄົມເຕັມໃຈຈ່າຍສຳລັບສຸຂະພາບ (ການຕັດສິນຄຸນຄ່າ).
- **ດ້ານການສະໜອງ**: ສຸຂະພາບທີ່ງົບຜະລິດໃນປັດຈຸບັນທີ່ຂອບ (ປະລິມານຈາກຫຼັກຖານ — ~£13k/QALY ຂອງ Claxton). ຖ້າ λ ທີ່ໃຊ້ຕັດສິນເກີນອັດຕາດ້ານການສະໜອງ, ການອະນຸມັດເຕັກໂນໂລຢີໃໝ່ແທນທີ່ສຸຂະພາບຫຼາຍກວ່າທີ່ມັນເພີ່ມ.

## ຕົວຢ່າງການຄິດໄລ່

ຢາດິຈິຕອນຂອງທ່ານໃຫ້ 0.05 QALY ຕໍ່ຜູ້ປ່ວຍທີ່ຮັກສາ ດ້ວຍຕົ້ນທຶນສຸດທິ (ລາຄາລົບການຫັກລົບ) £800.

```
ICER = 800 / 0.05 = £16,000 per QALY
```

- ອັງກິດ: ຕ່ຳກວ່າ £20k → ໄດ້ທຶນ. ລາຄາສູງສຸດທີ່ປົກປ້ອງໄດ້: ທີ່ λ = £20,000, price_max = 0.05 × 20,000 + offsets = £1,000 + offsets.
- ກອບການຄ້າສະຫະລັດທີ່ $150k/QALY: ລາຄາຕາມມູນຄ່າສູງກວ່າຫຼາຍ.
- ເກນປະເທດ GDP ຕໍ່ຫົວຄົນ $4,000: ຜະລິດຕະພັນດຽວກັນຕ້ອງມີຕົ້ນທຶນສຸດທິຕ່ຳກວ່າ ~$200.

ຜະລິດຕະພັນດຽວກັນ, ສາມຕະຫຼາດ, ສາມລາຄາ — ເກນ *ແມ່ນ* ແບບຈຳລອງການຕັ້ງລາຄາ. ນີ້ແມ່ນການຕັ້ງລາຄາຕາມມູນຄ່າ, ຣັນຍ້ອນຈາກ λ.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ທຸກອົງກອນວິສະວະກຳມີ λ ແອບແຝງ: ອຸປະສັກທີ່ມັນໃຫ້ທຶນເຄື່ອງມືຕໍ່ຊົ່ວໂມງວິສະວະກອນທີ່ປະຢັດ. ການເຮັດໃຫ້ມັນຊັດເຈນ — "ເຮົາໃຫ້ທຶນທຸກຢ່າງຕ່ຳກວ່າ £40 ຕໍ່ຊົ່ວໂມງວິສະວະກອນທີ່ປະຢັດໄດ້ຢ່າງໜ້າເຊື່ອຖື" — ເປີດໃຫ້ປຽບທຽບຕາຕະລາງລີກຂອງການລົງທຶນແພລດຟອມ, ຄືກັບທີ່ຕາຕະລາງລີກຕົ້ນທຶນຕໍ່ QALY ຈັດອັນດັບລາຍຈ່າຍສຸຂະພາບ. ບົດຮຽນດ້ານການສະໜອງກໍໂອນ: λ ພາຍໃນທີ່ແທ້ຈິງຂອງທ່ານແມ່ນສິ່ງທີ່ backlog *ປັດຈຸບັນ* ຂອງທ່ານຜະລິດທີ່ຂອບ, ບໍ່ແມ່ນສິ່ງທີ່ຜູ້ນຳເວົ້າວ່າເວລາມີຄ່າ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການເລືອກເກນ** ຂ້າມເຂດອຳນາດ ຫຼື ອ້າງເພດານ HST ສຳລັບຜະລິດຕະພັນທົ່ວໄປ.
- **ຖື λ ເປັນພື້ນລາຄາ**: ຜ່ານເກນແມ່ນຈຳເປັນ, ບໍ່ແມ່ນພຽງພໍ — [ຜົນກະທົບຕໍ່ງົບປະມານ](../ການວິເຄາະຜົນກະທົບຕໍ່ງົບປະມານ/) ຍັງສາມາດຈົມຜະລິດຕະພັນທີ່ຈ່າຍໄດ້ຕໍ່ຫົວໜ່ວຍ.
- **ເມີນເສີຍວ່າເກນເຄື່ອນ**: ຕົວປັບຄວາມຮຸນແຮງຂອງ NICE (2022) ແລະ ການທົບທວນເປັນໄລຍະປ່ຽນ λ ປະສິດທິຜົນ; ໃສ່ວັນທີການອ້າງຂອງທ່ານ.
- **ປຽບທຽບ ICER ກັບເກນໃນສະກຸນເງິນອື່ນໂດຍບໍ່ແປງກ່ອນ**: ເບິ່ງ [ການປຽບທຽບ ICER ຂ້າມສະກຸນເງິນ](../ການປຽບທຽບ-icer-ຂ້າມສະກຸນເງິນ/) — ວິທີແປງ (ຄວາມສະເໝີພາບຂອງອຳນາດຊື້ ທຽບກັບ ອັດຕາແລກປ່ຽນຕະຫຼາດ) ມີຜົນຕາມມາທາງວິທີການ, ບໍ່ແມ່ນລາຍລະອຽດການປັດເສດ.
- **ສັບສົນການປະເມີນອີງ λ ກັບປະເພນີ VSL/VPF ຕະຫຼາດແຮງງານ**: ສອງຢ່າງມາຈາກປະເພນີທິດສະດີຕ່າງກັນ (ວິທີການຖືກຈຳກັດດ້ວຍງົບສຸຂະພາບ ທຽບກັບ ຄວາມມັກທີ່ເປີດເຜີຍຈາກການແລກປ່ຽນຄ່າຈ້າງ-ຄວາມສ່ຽງ) ແລະ ບໍ່ສະເໝີໄປປະສານກັນໄດ້ — ສຳລັບວິທີຄວາມມັກທີ່ເປີດເຜີຍທາງເລືອກໃນການປະເມີນຊີວິດ, ເບິ່ງ [ມູນຄ່າຂອງຊີວິດທາງສະຖິຕິ](../ມູນຄ່າຂອງຊີວິດທາງສະຖິຕິ/).
