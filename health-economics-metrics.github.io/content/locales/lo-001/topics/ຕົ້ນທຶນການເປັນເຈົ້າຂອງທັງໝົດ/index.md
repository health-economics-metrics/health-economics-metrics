# ຕົ້ນທຶນການເປັນເຈົ້າຂອງທັງໝົດ (TCO)

TCO ແມ່ນຕົ້ນທຶນເຕັມຂອງລະບົບຕະຫຼອດອາຍຸ: ການຈັດຫາ ຫຼື ການສ້າງ, ການເຊື່ອມໂຍງ, ການດຳເນີນງານ, ການບຳລຸງຮັກສາ, ການສະໜັບສະໜູນ, ການຝຶກອົບຮົມ ແລະ ການຍົກເລີກ. ເສັ້ນຖານທີ່ບໍ່ສະບາຍ: **ການບຳລຸງຮັກສາແມ່ນ 50–80% ຂອງ TCO ຊອບແວ** — ປະມານສາມສ່ວນສີ່ຂອງຕົ້ນທຶນຕະຫຼອດອາຍຸມາ *ຫຼັງ* ການເປີດໂຕ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ການປະເມີນເຕັກໂນໂລຢີສຸຂະພາບຮຽນຮູ້ມາດົນແລ້ວວ່າລາຄາຢາບໍ່ແມ່ນຕົ້ນທຶນຂອງມັນ — ການໃຫ້ຢາ, ການຕິດຕາມ ແລະ ການຈັດການຜົນຂ້າງຄຽງທັງໝົດຢູ່ໃນແບບຈຳລອງ. business case ຊອບແວທີ່ນັບສະເພາະຕົ້ນທຶນການສ້າງ/ໃບອະນຸຍາດຊ້ຳຂໍ້ຜິດພາດລາຄາຢາແບບໄຮ້ດຽງສາ, ແລະ ປະເມີນດ້ານຕົ້ນທຶນຂອງທຸກ [ICER](../ອັດຕາສ່ວນຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນສ່ວນເພີ່ມ/) ແລະ [ຜົນກະທົບຕໍ່ງົບປະມານ](../ການວິເຄາະຜົນກະທົບຕໍ່ງົບປະມານ/) ທີ່ມັນປ້ອນຕ່ຳເກີນໄປຢ່າງເປັນລະບົບ. ສຳລັບການຈັດຊື້ NHS, ວິໄນ TCO ແມ່ນສິ່ງທີ່ເຮັດໃຫ້ການອ້າງຄວາມຄຸ້ມຄ່າດ້ານຕົ້ນທຶນຂອງຜະລິດຕະພັນດິຈິຕອນຊື່ສັດ — ແລະ ເປັນບ່ອນທີ່ທາງເລືອກທີ່ເບິ່ງຖືກແພ້.

## ຄະນິດສາດ

```
TCO = initial cost (build/licence + integration + data migration + training)
    + Σ_t [operations + maintenance + support + infrastructure + upgrades
           + compliance/assurance]_t / (1 + r)^t
    + decommissioning cost (exit, data extraction, parallel running)

Horizon: 3–5 years commercial, system-lifetime for clinical infrastructure
r: 3.5% public sector (Green Book), 8–12% commercial
Benchmarks: annual maintenance ≈ 15–20% of build cost; ~78% of lifetime
TCO post-launch; ignore decommissioning and vendor lock-in prices itself.
```

## ຕົວຢ່າງການຄິດໄລ່

ສອງທາງເລືອກສຳລັບລະບົບບັນທຶກສັນຍານຊີບເອເລັກໂຕຣນິກ, ຂອບເຂດ 5 ປີ:

```
                        Vendor SaaS     In-house build
Year 0 (licence/build)  £250,000        £900,000
Integration + training  £180,000        £150,000
Annual run (yrs 1–5)    £120,000/yr     £190,000/yr  (hosting + 1.5 FTE maint.)
Exit/decommission       £60,000         £30,000

Undiscounted TCO        £1,090,000      £2,030,000
```

ການຄາດຄະເນວິສະວະກຳຂອງທາງເລືອກສ້າງ (£900k) ເປັນພຽງ 44% ຂອງ TCO ແທ້ — ແລະ ການຄາດຄະເນການສ້າງເອງໂດຍທົ່ວໄປເກີນ 30–40% (ເບິ່ງ [ສ້າງເອງ ທຽບກັບ ຊື້](../ສ້າງເອງ-ທຽບກັບ-ຊື້/)). ເວັ້ນເສຍແຕ່ທາງເລືອກພາຍໃນໃຫ້ *ຜົນລັບ* ທີ່ແຕກຕ່າງຢ່າງມີນັຍສຳຄັນ, ຕັກກະ [ຕົ້ນທຶນຕ່ຳສຸດ](../ການວິເຄາະຕົ້ນທຶນຕ່ຳສຸດ/) ນຳໃຊ້ ແລະ SaaS ຊະນະປະມານ £940k.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

ວິສະວະກອນໃຫ້ນ້ຳໜັກຂໍ້ມູນການບຳລຸງຮັກສາຂອງສາຂາຕົນເອງຕ່ຳເມື່ອສະໜັບສະໜູນການສ້າງ: ກົດການບຳລຸງຮັກສາປະຈຳປີ 15–20% ຂອງຕົ້ນທຶນການສ້າງໝາຍຄວາມວ່າທຸກລະບົບ £1M ຜູກມັດຄວາມຈຸອະນາຄົດ £150–200k/ປີຢ່າງງຽບໆ — ໜີ້ສິນທີ່ຢູ່ໃນໃບດຸນພາຍໃນຫົວດຽວກັບ [ໜີ້ສິນດ້ານເຕັກນິກ](../ໜີ້ສິນດ້ານເຕັກນິກ/). TCO ຍັງເປັນຄຶ່ງຕົ້ນທຶນຂອງທຸກຕົວຊີ້ວັດໃນບ່ອນເກັບນີ້: ຕົ້ນທຶນຕໍ່ການ deploy, [ເສດຖະສາດຫົວໜ່ວຍຂອງຄລາວ](../ເສດຖະສາດຫົວໜ່ວຍຂອງຄລາວ/), ແລະ ວິໄນຕົວຫານທີ່ HTA ບັງຄັບຜູ້ສະໜັບສະໜູນຢາ. ເມື່ອລາຄາຜະລິດຕະພັນຂອງທ່ານຖືກທ້າທາຍ, ການປຽບທຽບ TCO ລວມຕົ້ນທຶນດຳເນີນງານແທ້ຂອງຄູ່ແຂ່ງເດີມມັກເປັນການຈັດກອບໃໝ່ທີ່ແຂງແຮງທີ່ສຸດ. ຕົວເລກ TCO ຫຼາຍປີຄືຂ້າງເທິງແມ່ນຜົນລວມຂອງລາຍການຕົ້ນທຶນຫຼາຍອັນຕາມເວລາ — ເບິ່ງ [ການລວມຕົ້ນທຶນທີ່ປອດໄພດ້ານສະກຸນເງິນ](../ການລວມຕົ້ນທຶນທີ່ປອດໄພດ້ານສະກຸນເງິນ/) ວ່າເປັນຫຍັງຜົນລວມນັ້ນຄວນເປັນທົດສະນິຍົມແນ່ນອນແທນຈຸດລອຍເມື່ອແບບຈຳລອງຕ້ອງກົງກັບເງິນເປັນເພັນນີ, ແລະ [ການຈັດສັນຕົ້ນທຶນແບບເຊັນຖືກຕ້ອງ](../ການຈັດສັນຕົ້ນທຶນແບບເຊັນຖືກຕ້ອງ/) ສຳລັບການແບ່ງຍອດ TCO ຂ້າມສູນຕົ້ນທຶນໂດຍບໍ່ເສຍເພັນນີ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ຍຶດຕົ້ນທຶນເປີດໂຕ**: ປຽບທຽບທາງເລືອກທີ່ຕົ້ນທຶນປີ 0 ໃນຂະນະທີ່ອັນດັບກັບກັນພາຍໃນປີ 3.
- **ຄວາມເຂົ້າໃຈຜິດແຮງງານພາຍໃນຟຣີ**: ການບຳລຸງຮັກສາພາຍໃນຄິດຕົ້ນທຶນເປັນສູນເພາະ "ທີມໄດ້ຮັບຄ່າຈ້າງແລ້ວ" — ເບິ່ງ [ຕົ້ນທຶນຄວາມເສຍໂອກາດ](../ຕົ້ນທຶນຄວາມເສຍໂອກາດ/).
- **ເມີນເສີຍຕົ້ນທຶນອອກ**: ການດຶງຂໍ້ມູນອອກ, ການຢຸດສັນຍາ ແລະ ການດຳເນີນຂະໜານແມ່ນບ່ອນທີ່ SaaS "ຖືກ" ກາຍເປັນແພງ.
- **ການລະເມີດຂອບເຂດດຽວກັນ**: ປຽບທຽບ TCO SaaS 3 ປີກັບການຕັດຈຳໜ່າຍການສ້າງ 10 ປີ (ເບິ່ງ [ຂອບເຂດເວລາ](../ຂອບເຂດເວລາ/)).
