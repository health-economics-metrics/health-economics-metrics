# ວັນນອນໂຮງໝໍທີ່ປະຢັດໄດ້

ວັນນອນໂຮງໝໍ (bed day) ແມ່ນຄົນເຈັບໜຶ່ງຄົນຄອບຄອງຕຽງໂຮງໝໍໜຶ່ງຕຽງໜຶ່ງມື້. "ວັນນອນໂຮງໝໍທີ່ປະຢັດໄດ້" — ຜ່ານການອອກໂຮງໝໍໄວຂຶ້ນ, ການຫຼີກລ່ຽງການຮັບເຂົ້າ, ຫຼື ຫວອດສະເໝືອນ — ແມ່ນຜົນປະໂຫຍດຫຼັກຂອງກໍລະນີທຸລະກິດດິຈິຕອນຂອງ NHS ແລະ ເປັນສິ່ງທີ່ຖືກຕີມູນຄ່າສູງເກີນຈິງທົ່ວໄປທີ່ສຸດ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຕຽງແມ່ນຂໍ້ຈຳກັດທີ່ຜູກມັດຂອງການດູແລສຸກເສີນ: ເມື່ອຕຽງເຕັມ ການຜ່າຕັດນັດໝາຍຖືກຍົກເລີກ, ລົດຄູ່ສຸກເສີນຕໍ່ແຖວ, ແລະ ພະແນກສຸກເສີນແອອັດ. ການແຊກແຊງທີ່ປົດປ່ອຍວັນນອນໂຮງໝໍຈຶ່ງມີຄຸນຄ່າຈິງ — ແຕ່*ປະເພດ*ຂອງຄຸນຄ່າຂຶ້ນກັບສິ່ງທີ່ເກີດຂຶ້ນກັບຕຽງທີ່ປົດປ່ອຍທັງໝົດ. ຜູ້ອຳນວຍການການເງິນໄດ້ຮຽນຮູ້ທີ່ຈະຫຼຸດມູນຄ່າຂໍ້ອ້າງວັນນອນໂຮງໝໍແບບງ່າຍໆຢ່າງຫຼວງຫຼາຍ; ການເຮັດເລກນີ້ໃຫ້ຖືກຕ້ອງແມ່ນການທົດສອບຄວາມໜ້າເຊື່ອຖື.

## ຄະນິດສາດ

```
Bed days saved = patients affected × Δ length of stay (or admissions avoided × avg LOS)

Value depends on the use of the freed capacity:
  refilled with elective activity → value = activity income or waiting-list benefit
  ward closed / flexed down      → value = staffing + running cost released (cash)
  absorbed as slack              → value ≈ marginal (hotel) cost only, £50–£150/day
```

ຕົ້ນທຶນສະເລ່ຍທີ່ຖືກດູດຊຶມເຕັມຂອງວັນນອນໂຮງໝໍສຸກເສີນມັກຖືກອ້າງວ່າ £400+ (National Cost Collection ໃນອະດີດ ~£350 ສຳລັບວັນນອນເກີນ) — ແຕ່ເບິ່ງ[ຕົ້ນທຶນສ່ວນເພີ່ມເທິງຕົ້ນທຶນສະເລ່ຍ](../ຕົ້ນທຶນສ່ວນເພີ່ມ-ທຽບກັບ-ຕົ້ນທຶນສະເລ່ຍ/): ຄ່າສະເລ່ຍເກືອບບໍ່ເຄີຍເປັນເງິນປະຢັດ.

## ຕົວຢ່າງການຄິດໄລ່

"ຫວອດສະເໝືອນ" ດ້ວຍການຕິດຕາມທາງໄກ ໃຫ້ຄົນເຈັບ 600 ຄົນ/ປີ ກັບບ້ານໄວຂຶ້ນ 2 ມື້: ປະຢັດ 1,200 ວັນນອນໂຮງໝໍ.

- **ຂໍ້ອ້າງແບບງ່າຍ**: 1,200 × £400 = £480,000. ຜິດ ເວັ້ນແຕ່ຫວອດຖືກປິດ.
- **ຂໍ້ອ້າງທີ່ຊື່ສັດ**: ໂຮງໝໍ trust ເຕີມຕຽງດ້ວຍຄົນເຈັບກະດູກນັດໝາຍ. 1,200 ວັນນອນ ÷ ເວລາພັກສະເລ່ຍ 3 ມື້ = 400 ຄັ້ງຜ່າຕັດນັດໝາຍເພີ່ມ ທີ່ລາຍຮັບ ~£6,000 ຕໍ່ຄັ້ງພາຍໃຕ້ການຈ່າຍຕາມກິດຈະກຳ = **ກິດຈະກຳທີ່ໄດ້ຮັບທຶນເພີ່ມ £2.4M** (ລົບຕົ້ນທຶນສ່ວນເພີ່ມຂອງການປິ່ນປົວຄົນເຈັບເຫຼົ່ານັ້ນ) *ບວກ* ຄົນເຈັບ 400 ຄົນອອກຈາກລາຍຊື່ລໍຖ້າ. ຕົ້ນທຶນດຳເນີນງານຫວອດສະເໝືອນ (£350,000) ຫັກລົບກັບຈຳນວນນີ້.

ຄວາມສາມາດທີ່ປົດປ່ອຍແລ້ວ*ນຳກັບມາໃຊ້ໃໝ່*ມັກມີຄ່າຫຼາຍກວ່າຂໍ້ອ້າງເງິນສົດແບບງ່າຍ — ແຕ່ມັນເປັນຄຸນຄ່າຄົນລະປະເພດ ແລະ ຕ້ອງຕິດປ້າຍຕາມນັ້ນ ([ປົດປ່ອຍເງິນສົດ ທຽບກັບ ບໍ່ປົດປ່ອຍເງິນສົດ](../ການປະຢັດທີ່ປົດປ່ອຍເງິນສົດ-ທຽບກັບ-ທີ່ບໍ່ປົດປ່ອຍເງິນສົດ/)).

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

"ວັນເຊີບເວີທີ່ປະຢັດໄດ້" ປະພຶດຕົວຄືກັນທຸກຢ່າງ. ການຢຸດໃຊ້ສະພາບແວດລ້ອມທີ່ເປີດຕະຫຼອດຈະປົດປ່ອຍເງິນສົດກໍຕໍ່ເມື່ອອິນສະແຕນຖືກຢຸດ ຫຼື ການຈອງໝົດອາຍຸ; ຄວາມສາມາດທີ່ຖືກດູດກັບຄືນເຂົ້າສະລອຍມີຄ່າເທົ່າຕົ້ນທຶນສ່ວນເພີ່ມ (~0 ໃນລາຍຈ່າຍທີ່ຜູກມັດ). ລະບຽບວິໄນຄູ່ຂະໜານ: ທຸກເງິນປະຢັດທີ່ອ້າງ ໃຫ້ລະບຸ*ກົນໄກ* — ຢຸດ, ເຕີມດ້ວຍວຽກທີ່ມີຄຸນຄ່າ, ຫຼື ລະເຫີຍໄປ. ຊອບແວທີ່ຫຼຸດໄລຍະການນອນໂຮງໝໍ (ການປະສານການອອກໂຮງໝໍ, ການຕິດຕາມທາງໄກ, ເວລາຜົນວິນິດໄສ) ຄວນສ້າງແບບຈຳລອງທັງສາມສະຖານະການ ແລ້ວໃຫ້ໂຮງໝໍ trust ເລືອກຕໍ່ຫວອດ.

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ການຕີມູນຄ່າດ້ວຍຕົ້ນທຶນສະເລ່ຍ** ຂອງຄວາມສາມາດສ່ວນເພີ່ມ — ຂໍ້ຜິດພາດແບບຄລາສສິກ.
- **ການນັບຊ້ຳ**: ວັນນອນໂຮງໝໍທີ່ປະຢັດ *ແລະ* ການຮັບເຂົ້າທີ່ຫຼີກລ່ຽງ *ແລະ* ລາຍຊື່ລໍຖ້າທີ່ຫຼຸດ ຈາກຕຽງທີ່ປົດປ່ອຍອັນດຽວກັນ.
- **ສົມມຸດວ່າວັນທີ່ປະຢັດແມ່ນວັນທີ່ແພງ**: ວັນທີ່ປະຢັດໄດ້ຕອນທ້າຍຂອງການພັກຮັກສາແມ່ນວັນທີ່ຖືກທີ່ສຸດ (ຄວາມຮຸນແຮງຕ່ຳ).
