# ອັດຕາການບໍ່ມາຕາມນັດ (DNA)

ອັດຕາ DNA ແມ່ນເປີເຊັນຂອງການນັດໝາຍທີ່ຈອງໄວ້ ທີ່ຄົນເຈັບບໍ່ມາແລະບໍ່ຍົກເລີກ. ແພດ, ຫ້ອງ, ແລະ ຊ່ອງເວລາຖືກຈ່າຍເງິນແລ້ວ; ແຕ່ບໍ່ມີຫຍັງເກີດຂຶ້ນ. ມັນເປັນຕົວຊີ້ວັດຂອງເສຍເປົ່າທີ່ບໍລິສຸດທີ່ສຸດໃນການດູແລສຸຂະພາບ — ແລະ ເປັນໜຶ່ງໃນສິ່ງທີ່ຊອບແວແກ້ໄດ້ງ່າຍທີ່ສຸດ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຕົວເລກຂອງ NHS England (2019): ການນັດ GP ທີ່ພາດເກີນ 15 ລ້ານຄັ້ງ/ປີ ປະມານ £30 ຕໍ່ຄັ້ງ — ເກີນ **£216M/ປີ** — ແລະ DNA ຜູ້ປ່ວຍນອກຂອງໂຮງໝໍແມ່ນ ~8M/ປີ (~6.4% ຂອງການນັດ) ສະເລ່ຍ ~**£160** ຕໍ່ຊ່ອງທີ່ພາດ. ເພາະຕົ້ນທຶນສ່ວນເພີ່ມຂອງການເຕືອນມີພຽງເປັນເພນນີ ແລະ ມູນຄ່າທີ່ເອົາຄືນແມ່ນຊ່ອງຄລີນິກທີ່ມີບຸກຄະລາກອນເຕັມ ການຫຼຸດ DNA ຈຶ່ງມີເລກຄະນິດ ROI ທີ່ດີທີ່ສຸດຢ່າງໜຶ່ງໃນສຸຂະພາບດິຈິຕອນ ເຊິ່ງເປັນເຫດຜົນທີ່ SMS ເຕືອນ, ການນັດໃໝ່ງ່າຍ, ແລະ ການຈອງເກີນແບບພະຍາກອນຢູ່ໃນບັນດາຜົນສຳເລັດທຳອິດທີ່ພິສູດແລ້ວຂອງສຸຂະພາບດິຈິຕອນ.

## ຄະນິດສາດ

```
DNA rate = DNAs / booked appointments × 100

Value of reduction = appointments × ΔDNA rate × value per recovered slot

value per recovered slot: the slot is refilled (activity value / waiting-list
reduction) or it is not (staff time partially reusable) — mechanism matters,
as with bed-days-saved.md.
```

## ຕົວຢ່າງການຄິດໄລ່

ພະແນກຜູ້ປ່ວຍນອກ: 200,000 ການນັດ/ປີ, ອັດຕາ DNA 8%. ບໍລິການເຕືອນພ້ອມນັດໃໝ່ (SMS ທີ່ນັດໃໝ່ດ້ວຍການແຕະດຽວ, ຂໍ້ມູນການຂົນສົ່ງ, ຮູບແບບທີ່ເຂົ້າເຖິງໄດ້) ຫຼຸດ DNA ເປັນ 5.5%.

```
Recovered slots = 200,000 × 0.025 = 5,000/year
Refilled from the waiting list at ~£160 average outpatient value:
  5,000 × £160 = £800,000/year of recovered activity
Service cost: 200,000 × £0.40 = £80,000/year

Return ≈ 10:1, plus 5,000 waiting-list patients seen sooner
(see waiting-list-impact.md and referral-to-treatment.md).
```

ຂະໜາດຜົນ (2.5 ຈຸດ) ເປັນຈິງ: RCT ການເຕືອນສະແດງຢ່າງສະໝ່ຳສະເໝີວ່າ DNA ຫຼຸດລົງສຳພັນ 25–40%.

## ຄວາມເຊື່ອມໂຍງກັບວິສະວະກຳຊອບແວ

- **ນີ້ແມ່ນບັນຫາລະບົບຈັດຕາຕະລາງ**: ການເຕືອນ, ການນັດໃໝ່ດ້ວຍຕົນເອງ, ການເຕີມຊ່ອງວ່າງອັດຕະໂນມັດຈາກລາຍຊື່ລໍຖ້າເມື່ອມີການຍົກເລີກ, ແລະ ແບບຈຳລອງພະຍາກອນການບໍ່ມາທີ່ຂັບເຄື່ອນການຈອງຊ້ອນເປົ້າໝາຍ. ແຕ່ລະອັນແມ່ນວິສະວະກຳຊອບແວທຳມະດາທີ່ມີກໍລະນີທາງເສດຖະກິດຄົມຊັດຜິດປົກກະຕິ.
- **ສິ່ງທຽບເທົ່າດ້ານວິສະວະກຳ**: ການບໍ່ມາສຳລັບຄວາມສາມາດທີ່ຈອງໄວ້ — ຊ່ອງ CI ທີ່ຈອງແຕ່ວ່າງ, ຄວາມສາມາດຄລາວທີ່ຈອງໄວ້, ຫ້ອງປະຊຸມ, ຄະນະສຳພາດ. ເສດຖະສາດຖ່າຍທອດໄດ້: ການກະຕຸ້ນອັດຕະໂນມັດລາຄາຖືກ (ຫຼື ປ່ອຍການຈອງທີ່ບໍ່ໃຊ້ອັດຕະໂນມັດ) ເອົາຄວາມສາມາດທີ່ຜູກມັດແພງຄືນ.
- **ຕົວຢ່າງຈັນຍາບັນການພະຍາກອນ**: ແບບຈຳລອງການບໍ່ມາທີ່ຝຶກດ້ວຍຂໍ້ມູນການມາເຂົ້າລະຫັດຄວາມທຸກຍາກແລະອຸປະສັກການເຂົ້າເຖິງ; ການໃຊ້ມັນເພື່ອ*ຫຼຸດບູລິມະສິດ*ຄົນທີ່ອາດບໍ່ມາເພີ່ມຄວາມບໍ່ເທົ່າທຽມ, ການໃຊ້ມັນເພື່ອ*ສະໜັບສະໜູນ*ການມາ (ຊ່ວຍການຂົນສົ່ງ, ທາງເລືອກທາງໂທລະສັບ) ຫຼຸດມັນ. ເບິ່ງ[ການເຂົ້າເຖິງ ແລະ ຄວາມເທົ່າທຽມ](../ການເຂົ້າເຖິງ-ແລະ-ຄວາມເທົ່າທຽມ/).

## ຂໍ້ຜິດພາດທີ່ພົບເລື້ອຍ

- **ນັບການຍົກເລີກແລ້ວນັດໃໝ່ເປັນມູນຄ່າທີ່ເອົາຄືນສອງເທື່ອ.**
- **ຕີມູນຄ່າຊ່ອງທີ່ເອົາຄືນແຕ່ບໍ່ໄດ້ເຕີມ** — ຊ່ອງວ່າງທີ່ສົ່ງການເຕືອນແລ້ວກໍຍັງວ່າງ.
- **ໄລ່ DNA ໃຫ້ເປັນສູນ**: ຈຸດສຸດທ້າຍຂອງ DNA ແມ່ນຄົນເຈັບທີ່ປະເຊີນອຸປະສັກຈິງ; ວິທີລົງໂທດ (ປົດອອກຫຼັງ DNA N ຄັ້ງ) ຫຼຸດຕົວຊີ້ວັດໂດຍການປະຖິ້ມຄົນເຈັບ.
