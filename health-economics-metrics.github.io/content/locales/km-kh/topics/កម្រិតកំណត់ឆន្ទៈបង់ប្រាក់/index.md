# កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់

កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់ (WTP) គឺជាចំនួនអតិបរមាដែលអ្នកធ្វើការសម្រេចចិត្តនឹងបង់ក្នុងមួយឯកតានៃការទទួលបានសុខភាព — បន្ទាត់ដែលបម្លែង [ICER](../សមាមាត្រប្រសិទ្ធភាពថ្លៃដើមបន្ថែម/) ទៅជាការសម្រេចចិត្តទទួលយក/បដិសេធ។

## ហេតុអ្វីបានជាសំខាន់

កម្រិតកំណត់គឺជាកន្លែងដែលសេដ្ឋកិច្ចសុខភាពឈប់ជាការវាស់វែង ហើយក្លាយជាគោលនយោបាយ។ រាល់ប្រព័ន្ធជាតិមានមួយ ច្បាស់លាស់ ឬបង្កប់ ហើយការដឹងលេខក្នុងស្រុកប្រាប់អ្នកយ៉ាងពិតប្រាកដពីរបៀបកំណត់តម្លៃការអះអាងតម្លៃសុខភាព៖

| ស្ថាប័ន | កម្រិតកំណត់ (តាមការស្រាវជ្រាវ 2024–2025) |
|---|---|
| NICE (អង់គ្លេស) | £20,000–£30,000 ក្នុងមួយ QALY; កម្រិតកំណត់ការសម្រេចចិត្តមធ្យមជាក់ស្តែង ≈ £24,400 (2022–24); កត្តាកែតម្រូវភាពធ្ងន់ធ្ងរបង្កើនដំបូលមានប្រសិទ្ធភាពដល់ ~£36k–£51k; បច្ចេកវិទ្យាឯកទេសខ្ពស់រហូតដល់ £100k+ |
| ICER (សហរដ្ឋអាមេរិក មិនមែនរដ្ឋាភិបាល) | ស្តង់ដារតម្លៃ $100,000–$150,000 ក្នុងមួយ QALY/evLYG; រាយការណ៍ជួរ $50k–$200k |
| កាណាដា (CADTH / CDA-AMC) | កម្រិតកំណត់ប្រតិបត្តិ ≈ CAD$50,000 ក្នុងមួយ QALY |
| WHO-CHOICE (ប្រវត្តិសាស្ត្រ សកល) | 1–3× GDP ក្នុងមនុស្សម្នាក់ ក្នុងមួយ DALY ដែលបានជៀសវាង (ឥឡូវមិនលើកទឹកចិត្ត ព្រោះគ្មានភាពជាក់លាក់) |
| ផ្នែកផ្គត់ផ្គង់អង់គ្លេសជាក់ស្តែង (Claxton et al.) | ≈ £13,000 ក្នុងមួយ QALY ដែលត្រូវបានជំនួសពិតប្រាកដនៅគែម NHS |

## គណិតវិទ្យា

កម្រិតកំណត់ λ ចូលក្នុងរាល់ច្បាប់ការសម្រេចចិត្ត៖

```
Adopt if ICER = ΔC/ΔE < λ
Equivalently: adopt if NMB = λ×ΔE − ΔC > 0
```

ទ្រឹស្តីពីរអំពីអ្វីដែល λ *ជា*៖

- **ផ្នែកតម្រូវការ**៖ អ្វីដែលសង្គមមានឆន្ទៈបង់សម្រាប់សុខភាព (ការវិនិច្ឆ័យតម្លៃ)។
- **ផ្នែកផ្គត់ផ្គង់**៖ សុខភាពដែលថវិកាផលិតបច្ចុប្បន្ននៅគែម (បរិមាណជាក់ស្តែង — ~£13k/QALY របស់ Claxton)។ ប្រសិនបើ λ ដែលប្រើសម្រាប់ការសម្រេចចិត្តលើសអត្រាផ្នែកផ្គត់ផ្គង់ ការអនុម័តបច្ចេកវិទ្យាថ្មីជំនួសសុខភាពច្រើនជាងដែលវាបន្ថែម។

## ឧទាហរណ៍ដែលបានគណនា

ការព្យាបាលឌីជីថលរបស់អ្នកផ្តល់ 0.05 QALY ក្នុងមួយអ្នកជំងឺដែលបានព្យាបាល ក្នុងថ្លៃដើមសុទ្ធ (តម្លៃដកការទូទាត់) £800។

```
ICER = 800 / 0.05 = £16,000 per QALY
```

- អង់គ្លេស៖ ក្រោម £20k → អាចផ្តល់មូលនិធិ។ តម្លៃអតិបរមាដែលអាចការពារបាន៖ នៅ λ = £20,000, price_max = 0.05 × 20,000 + offsets = £1,000 + offsets។
- ក្របខ័ណ្ឌពាណិជ្ជកម្មអាមេរិកនៅ $150k/QALY៖ តម្លៃផ្អែកលើតម្លៃខ្ពស់ជាងឆ្ងាយ។
- កម្រិតកំណត់ប្រទេស GDP ក្នុងមួយប្រជាជន $4,000៖ ផលិតផលដដែលត្រូវតែមានតម្លៃសុទ្ធក្រោមប្រហែល $200។

ផលិតផលតែមួយ បីទីផ្សារ បីតម្លៃ — កម្រិតកំណត់ *គឺជា* ម៉ូដែលកំណត់តម្លៃ។ នេះគឺជាការកំណត់តម្លៃតាមតម្លៃ ដំណើរការបញ្ច្រាសពី λ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

រាល់អង្គការវិស្វកម្មមាន λ បង្កប់៖ របាំងដែលវាផ្តល់មូលនិធិឧបករណ៍ក្នុងមួយម៉ោងវិស្វករដែលបានសន្សំ។ ការធ្វើឱ្យវាច្បាស់លាស់ — "យើងផ្តល់មូលនិធិអ្វីក៏ដោយក្រោម £40 ក្នុងមួយម៉ោងវិស្វករដែលបានសន្សំគួរឱ្យជឿ" — អនុញ្ញាតការប្រៀបធៀបតារាងចំណាត់ថ្នាក់នៃការវិនិយោគវេទិកា ដូចតារាងថ្លៃដើមក្នុងមួយ QALY ចាត់ថ្នាក់ការចំណាយសុខភាព។ មេរៀនផ្នែកផ្គត់ផ្គង់ក៏ផ្ទេរដែរ៖ λ ផ្ទៃក្នុងពិតរបស់អ្នកគឺអ្វីដែលបញ្ជីការងារ *បច្ចុប្បន្ន* របស់អ្នកផលិតនៅគែម មិនមែនអ្វីដែលថ្នាក់ដឹកនាំនិយាយថាពេលវេលាមានតម្លៃ។

## ចំណុចងាយធ្លាក់

- **ការជ្រើសកម្រិតកំណត់** ឆ្លងយុត្តាធិការ ឬការដកស្រង់ដំបូល HST សម្រាប់ផលិតផលធម្មតា។
- **ការចាត់ទុក λ ជាជាន់តម្លៃ**៖ ការឆ្លងកម្រិតកំណត់ចាំបាច់ មិនគ្រប់គ្រាន់ទេ — [ផលប៉ះពាល់ថវិកា](../ការវិភាគផលប៉ះពាល់ថវិកា/) នៅតែអាចធ្វើឱ្យផលិតផលដែលអាចទទួលបានក្នុងមួយឯកតាលិចលង់។
- **ការមិនអើពើថាកម្រិតកំណត់ផ្លាស់ប្តូរ**៖ កត្តាកែតម្រូវភាពធ្ងន់ធ្ងររបស់ NICE (2022) និងការពិនិត្យតាមកាលកំណត់ផ្លាស់ប្តូរ λ មានប្រសិទ្ធភាព; ចុះកាលបរិច្ឆេទការអះអាងរបស់អ្នក។
- **ការប្រៀបធៀប ICER ជាមួយកម្រិតកំណត់ក្នុងរូបិយប័ណ្ណផ្សេងដោយមិនបម្លែងមុន**៖ សូមមើល[ការប្រៀបធៀប ICER ឆ្លងរូបិយប័ណ្ណ](../ការប្រៀបធៀប-icer-ឆ្លងរូបិយប័ណ្ណ/) — វិធីបម្លែង (សមភាពអំណាចទិញ ធៀបនឹងអត្រាប្តូរប្រាក់ទីផ្សារ) មានផលវិធីសាស្ត្រ មិនមែនព័ត៌មានលម្អិតនៃការបង្គត់ទេ។
- **ការលាយបញ្ចូលការកំណត់តម្លៃផ្អែក λ ជាមួយប្រពៃណី VSL/VPF ទីផ្សារពលកម្ម**៖ ទាំងនេះមកពីប្រពៃណីទ្រឹស្តីខុសគ្នា (វិធីសាស្ត្រដែលត្រូវបានដាក់កម្រិតដោយថវិកាសុខភាព ធៀបនឹងចំណូលចិត្តបង្ហាញពីការដោះដូរប្រាក់ឈ្នួល-ហានិភ័យ) ហើយមិនតែងតែផ្សះផ្សាបាន — សម្រាប់វិធីសាស្ត្រចំណូលចិត្តបង្ហាញជំនួសក្នុងការកំណត់តម្លៃជីវិត សូមមើល[តម្លៃនៃជីវិតស្ថិតិ](../តម្លៃនៃជីវិតស្ថិតិ/)។
