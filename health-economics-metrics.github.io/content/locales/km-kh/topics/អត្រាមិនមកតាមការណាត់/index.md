# អត្រាមិនមកតាមការណាត់ (DNA)

អត្រា DNA គឺជាភាគរយនៃការណាត់ជួបដែលបានកក់ ដែលអ្នកជំងឺមិនមក ហើយក៏មិនលុបចោល។ គ្លីនិកករ បន្ទប់ និងម៉ោងត្រូវបានបង់ប្រាក់; គ្មានអ្វីកើតឡើង។ វាជារង្វាស់ការខ្ជះខ្ជាយសុទ្ធបំផុតក្នុងការថែទាំសុខភាព — និងជាមួយក្នុងចំណោមរង្វាស់ដែលអាចជួសជុលដោយកម្មវិធីបានច្រើនបំផុត។

## ហេតុអ្វីបានជាសំខាន់

តួលេខ NHS England (2019)៖ ការណាត់ជួបវេជ្ជបណ្ឌិតទូទៅដែលខកខានលើស 15 លាន/ឆ្នាំ ក្នុងតម្លៃ ~£30 ម្នាក់ — លើស **£216M/ឆ្នាំ** — ហើយ DNA អ្នកជំងឺក្រៅមន្ទីរពេទ្យដំណើរការ ~8M/ឆ្នាំ (~6.4% នៃការណាត់ជួប) ក្នុងមធ្យម ~**£160** ក្នុងមួយម៉ោងដែលខកខាន។ ដោយសារថ្លៃដើមរឹតបន្តឹងនៃការរំលឹកគឺប៉ុន្មានសេន ហើយតម្លៃដែលទទួលបានវិញគឺជាម៉ោងគ្លីនិកដែលមានបុគ្គលិកពេញលេញ ការកាត់បន្ថយ DNA មានគណិតវិទ្យា ROI ល្អបំផុតមួយក្នុងសុខភាពឌីជីថល ដែលជាមូលហេតុដែលការរំលឹក SMS ការកក់ឡើងវិញងាយស្រួល និងការកក់លើសតាមការព្យាករណ៍ស្ថិតក្នុងចំណោមជ័យជម្នះសុខភាពឌីជីថលដែលបានបញ្ជាក់ដំបូងបំផុត។

## គណិតវិទ្យា

```
DNA rate = DNAs / booked appointments × 100

Value of reduction = appointments × ΔDNA rate × value per recovered slot

value per recovered slot: the slot is refilled (activity value / waiting-list
reduction) or it is not (staff time partially reusable) — mechanism matters,
as with bed-days-saved.md.
```

## ឧទាហរណ៍ដែលបានគណនា

នាយកដ្ឋានអ្នកជំងឺក្រៅ៖ 200,000 ការណាត់ជួប/ឆ្នាំ អត្រា DNA 8%។ សេវារំលឹក-បូក-កក់ឡើងវិញ (SMS ដែលមានការកក់ឡើងវិញមួយប៉ះ ព័ត៌មានដឹកជញ្ជូន ទម្រង់អាចចូលប្រើបាន) កាត់បន្ថយ DNA ទៅ 5.5%។

```
Recovered slots = 200,000 × 0.025 = 5,000/year
Refilled from the waiting list at ~£160 average outpatient value:
  5,000 × £160 = £800,000/year of recovered activity
Service cost: 200,000 × £0.40 = £80,000/year

Return ≈ 10:1, plus 5,000 waiting-list patients seen sooner
(see waiting-list-impact.md and referral-to-treatment.md).
```

ទំហំឥទ្ធិពល (2.5 ចំណុច) ប្រាកដនិយម៖ RCT ការរំលឹកបង្ហាញជាប់លាប់ការកាត់បន្ថយ DNA ដែលទាក់ទង 25–40%។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

- **នេះជាបញ្ហាប្រព័ន្ធកំណត់ពេល**៖ ការរំលឹក ការកក់ឡើងវិញដោយខ្លួនឯង ការបំពេញបញ្ជីរង់ចាំស្វ័យប្រវត្តិពីការលុបចោល និងម៉ូដែលព្យាករណ៍អ្នកមិនមកដែលជំរុញការកក់ទ្វេដងគោលដៅ។ ម្នាក់ៗគឺជាវិស្វកម្មកម្មវិធីធម្មតាដែលមានករណីសេដ្ឋកិច្ចច្បាស់ខុសពីធម្មតា។
- **ភាពស្រដៀងវិស្វកម្ម**៖ អ្នកមិនមកសម្រាប់សមត្ថភាពដែលបានកក់ — រន្ធ CI ដែលបានកក់ប៉ុន្តែទំនេរ សមត្ថភាពពពកដែលបានកក់ បន្ទប់ប្រជុំ ក្រុមសម្ភាសន៍។ សេដ្ឋកិច្ចផ្ទេរ៖ ការរំលឹកស្វ័យប្រវត្តិថោក (ឬការបញ្ចេញស្វ័យប្រវត្តិនៃការកក់ដែលមិនប្រើ) ទទួលបានសមត្ថភាពដែលបានសន្យាថ្លៃមកវិញ។
- **ការមើលជាមុនអំពីក្រមសីលធម៌ព្យាករណ៍**៖ ម៉ូដែលអ្នកមិនមកដែលបណ្តុះបណ្តាលលើទិន្នន័យការចូលរួមអ៊ិនកូដភាពខ្វះខាត និងឧបសគ្គការចូលប្រើ; ការប្រើពួកវាដើម្បី *បន្ថយអាទិភាព* អ្នកទំនងមិនមកពង្រីកវិសមភាព ការប្រើពួកវាដើម្បី *គាំទ្រ* ការចូលរួម (ជំនួយដឹកជញ្ជូន ជម្រើសទូរស័ព្ទ) កាត់បន្ថយវា។ សូមមើល[ការឈានដល់ និងសមធម៌](../ការឈានដល់-និងសមធម៌/)។

## កំហុសដែលត្រូវជៀសវាង

- **រាប់ការលុបចោល-ហើយ-កក់ឡើងវិញជាតម្លៃដែលទទួលបានវិញពីរដង។**
- **វាយតម្លៃម៉ោងដែលទទួលបានវិញដែលមិនត្រូវបានបំពេញឡើងវិញ** — ម៉ោងទំនេរដែលបានផ្ញើការរំលឹកនៅតែទំនេរ។
- **ដេញ DNA ទៅសូន្យ**៖ ចំណុចចុងក្រោយនៃ DNA គឺជាអ្នកជំងឺដែលប្រឈមនឹងឧបសគ្គពិត; វិធីសាស្ត្រដាក់ទណ្ឌកម្ម (ឈប់ព្យាបាលបន្ទាប់ពី N DNAs) កាត់បន្ថយរង្វាស់ដោយបោះបង់អ្នកជំងឺ។
