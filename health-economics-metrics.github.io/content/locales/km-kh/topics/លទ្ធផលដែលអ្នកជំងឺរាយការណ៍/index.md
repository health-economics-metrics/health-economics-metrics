# លទ្ធផលដែលអ្នកជំងឺរាយការណ៍ (PROM, PREM, MCID)

PROM គឺជាឧបករណ៍ស្តង់ដារដែលអ្នកជំងឺរាយការណ៍ស្ថានភាពសុខភាពរបស់ខ្លួនផ្ទាល់ (រោគសញ្ញា មុខងារ គុណភាពជីវិត); PREM ចាប់យក *បទពិសោធន៍* នៃការថែទាំ។ **MCID** — ភាពខុសគ្នាតូចបំផុតដែលសំខាន់ផ្នែកគ្លីនិក — គឺជាការផ្លាស់ប្តូរពិន្ទុតូចបំផុតដែលអ្នកជំងឺយល់ឃើញជាក់ស្តែងថាមានអត្ថប្រយោជន៍៖ របារដែលរាល់ការអះអាងអំពីភាពប្រសើរឡើងត្រូវតែឆ្លងកាត់។

## ហេតុអ្វីបានជាសំខាន់

PROM គឺជារូបិយប័ណ្ណប្រសិទ្ធភាពចម្បងសម្រាប់សុខភាពឌីជីថល៖ កម្មវិធីកម្រផ្លាស់ប្តូរមរណភាព ប៉ុន្តែអាចផ្លាស់ប្តូរពិន្ទុរោគសញ្ញាដែលបានបញ្ជាក់ត្រឹមត្រូវបានយ៉ាងគួរឱ្យជឿ។ ឧបករណ៍ដែលសំខាន់មានតិច និងមានស្តង់ដារ — **PHQ-9** (ជំងឺបាក់ទឹកចិត្ត 0–27; ក្រុមធ្ងន់ធ្ងរនៅ 5/10/15/20), **GAD-7** (ការថប់បារម្ភ 0–21; ក្រុមនៅ 5/10/15), **EQ-5D** (ឧបយោគសម្រាប់[QALY](../ឆ្នាំជីវិតដែលកែតម្រូវតាមគុណភាព/)) — ហើយអ្នកគ្រប់គ្រង ស្ថាប័ន HTA និងអ្នកបង់ប្រាក់ទទួលយកពួកវា ពីព្រោះពួកវាអាចប្រៀបធៀបបានឆ្លងកាត់ផលិតផល និងការសាកល្បង។ MCID គឺជាច្រកភាពស្មោះត្រង់៖ PHQ-9 MCID ≈ 5 ពិន្ទុ, GAD-7 ≈ 4, សន្ទស្សន៍ EQ-5D ជាទូទៅ ~0.03–0.08 — ការផ្លាស់ប្តូរ PHQ-9 1.5 ពិន្ទុដែលមានសារៈសំខាន់ផ្នែកស្ថិតិលើគំរូធំ គឺ *ពិត ប៉ុន្តែគ្មានន័យផ្នែកគ្លីនិក* ហើយអ្នកពិនិត្យភស្តុតាងនឹងនិយាយដូច្នេះ។

## គណិតវិទ្យា

```
PROM scoring: instrument-specific sums (e.g., PHQ-9 = Σ 9 items × 0–3)

MCID estimation:
  anchor-based:      score change among patients who report "somewhat better"
  distribution-based: ≈ 0.5 × SD of baseline scores (rough heuristic)

Response rate framing (for trials and dossiers):
  responder = patient improving ≥ MCID (or ≥50% for PHQ-9 convention)
  NNT = 1 / (responder rate_treatment − responder rate_control)
  — see number-needed-to-treat.md
```

## ឧទាហរណ៍ដែលបានគណនា

កម្មវិធីគាំទ្រជំងឺបាក់ទឹកចិត្ត RCT ធៀបនឹងបញ្ជីរង់ចាំ 12 សប្តាហ៍៖

```
PHQ-9 change: app −6.2 points, control −2.1 → adjusted difference −4.1
MCID check: 4.1 < 5 → mean difference below MCID; report responders instead:
  responders (≥5-point drop): app 48%, control 22% → ARR 26%
  NNT = 1/0.26 ≈ 4 — four users treated per additional clinical response

Economic bridge: responders' EQ-5D gain 0.06 sustained 6 months
  = 0.03 QALYs; per 1,000 users: 260 extra responders × 0.03 = 7.8 QALYs
  ≈ £156,000–£234,000 of health value at NICE thresholds
```

ការបង្ហាញជាអ្នកឆ្លើយតប/NNT នៅតែឆ្លងកាត់ការពិនិត្យ ខណៈដែលភាពខុសគ្នាមធ្យមក្រោម MCID នឹងត្រូវបានច្រានចោល។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

PROM គឺជាបញ្ហាប្រមូលទិន្នន័យដែលកម្មវិធីស័ក្តិសមពិសេសក្នុងការដោះស្រាយ៖ ឧបករណ៍ក្នុងកម្មវិធីទទួលបានអត្រាបញ្ចប់ និងដង់ស៊ីតេរយៈពេលវែងដែលក្រដាសមិនដែលសម្រេចបាន ដោយបម្លែងទិន្នន័យតេឡេមេទ្រីផលិតផលធម្មតាទៅជាភស្តុតាងកម្រិត HTA ([EQ-5D](../eq-5d/) មានតែប្រាំអេក្រង់)។ ច្បាប់វិស្វកម្ម៖ ប្រើឧបករណ៍ដែលបានបញ្ជាក់ត្រឹមត្រូវ *ពាក្យតាមពាក្យ* (ការសរសេរពាក្យឡើងវិញធ្វើឱ្យវាអស់សុពលភាព — អាជ្ញាប័ណ្ណអនុវត្ត); កំណត់ពេលវាស់វែងតាមពិធីការ មិនមែនតាមភាពងាយស្រួលនៃការចូលរួមទេ (ការវាស់តែអ្នកប្រើសកម្មគឺជាភាពលំអៀងអ្នករស់រាន — សូមមើល[ការរក្សា](../ការរក្សា-និងការបោះបង់/)); និងចាក់សោកំណែទិន្នន័យឧបករណ៍ដូចគ្រោងណាមួយ — ការផ្លាស់ប្តូរពាក្យកណ្តាលការសិក្សាគឺជាការខូចទិន្នន័យ។ PREM ត្រូវនឹងឧបករណ៍ប្រភេទ CSAT/NPS ហើយមេរៀនដដែលអនុវត្ត៖ ស្តង់ដារឈ្នះផលិតខ្លួនឯង នៅទីណាដែលទស្សនិកជនជាអ្នកបង់ប្រាក់។ សម្រាប់ឧបករណ៍ជាក់លាក់ផលិតភាពការងារ សូមមើល [WPAI](../ផលិតភាពការងារ-និងការចុះខ្សោយសកម្មភាព/)។

## ចំណុចងាយធ្លាក់

- **សារៈសំខាន់ស្ថិតិក្រោម MCID** ដែលបង្ហាញជាអត្ថប្រយោជន៍គ្លីនិក — ការបំផ្លើសទូទៅបំផុតក្នុងវិស័យនេះ។
- **ការត្រឡប់ទៅរកមធ្យម**៖ អ្នកប្រើចុះឈ្មោះនៅកំពូលរោគសញ្ញា; ការមុន/ក្រោយក្រុមតែមួយបំផ្លើសខ្លាំង — អ្នកប្រៀបធៀបគឺមិនអាចចរចាបាន។
- **ការជ្រើសឧបករណ៍**៖ ដំណើរការ PHQ-9, GAD-7 និង WHO-5 រួចរាយការណ៍ណាដែលផ្លាស់ប្តូរ — ចុះបញ្ជីមុននូវចម្បង។
- **សម្ពាធស្ទង់មតិយល់ព្រមឌីជីថល**៖ ការជំរុញអ្នកប្រើឱ្យឆ្លើយតបអំណោយផលធ្វើឱ្យឧបករណ៍ខូច (ហើយអ្នកពិនិត្យដឹងអត្រាមូលដ្ឋាន)។
