# ផលចំណេញលើការវិនិយោគ (ROI)

ROI គឺជាសមាមាត្រនៃចំណេញសុទ្ធទៅនឹងប្រាក់ដែលបានវិនិយោគ។ វាគឺជារង្វាស់ដែលវិស្វកម្ម និងហិរញ្ញវត្ថុចែករំលែករួចហើយ — សេដ្ឋកិច្ចសុខភាពបន្ថែមវិន័យដែលធ្វើឱ្យការអះអាង ROI ឆ្លងកាត់ការត្រួតពិនិត្យ៖ ទស្សនៈ អ្នកប្រៀបធៀប ព្រំដែនពេលវេលា និងប្រភេទអត្ថប្រយោជន៍ដែលបានប្រកាស។

## ហេតុអ្វីបានជាសំខាន់

ROI គឺជាភាសាកណ្តាលរបស់អ្នកកាន់ថវិកា ហើយសុខភាពសាធារណៈក៏ប្រើវាដែរ៖ ការពិនិត្យសញ្ញាសម្គាល់របស់ Masters et al. រកឃើញ **ROI មធ្យម 14.3:1** សម្រាប់អន្តរាគមន៍សុខភាពសាធារណៈ (រាល់ £1 ត្រឡប់ ~£14 ទៅសេដ្ឋកិច្ចទូលំទូលាយ និងប្រព័ន្ធសុខាភិបាល) — លេខដែលប្រើយ៉ាងទូលំទូលាយដើម្បីតស៊ូមតិការចំណាយបង្ការ។ ប៉ុន្តែ 14:1 នោះគឺជាតួលេខ *សង្គម រយៈពេលវែង*; ROI របស់ CFO មន្ទីរពេទ្យគឺទស្សនៈអ្នកបង់ប្រាក់ និង 1–3 ឆ្នាំ។ ជម្លោះ ROI ភាគច្រើនពិតជាជម្លោះទស្សនៈដែលមិនបានប្រកាស។

## គណិតវិទ្យា

```
ROI = (Benefits − Costs) / Costs      (often × 100%)

Payback period = Costs / annual net benefit
```

ការអះអាង ROI មិនបានកំណត់គ្រប់គ្រាន់ ដោយគ្មានការប្រកាសបួន៖

1. **ទស្សនៈ** — អត្ថប្រយោជន៍របស់នរណាដែលរាប់? (សូមមើល[ទស្សនៈនៃការវិភាគ](../ទស្សនៈនៃការវិភាគ/))
2. **អ្នកប្រៀបធៀប** — ធៀបនឹងជម្រើសផ្សេងអ្វី? (សូមមើល[ថ្លៃដើមឱកាស](../ថ្លៃដើមឱកាស/))
3. **ព្រំដែនពេលវេលា** — ក្នុងរយៈពេលប៉ុន្មាន និង[បានបញ្ចុះតម្លៃ](../ការបញ្ចុះតម្លៃ-និងចំណូលចិត្តពេលវេលា/)?
4. **ថ្នាក់អត្ថប្រយោជន៍** — បញ្ចេញសាច់ប្រាក់ សមត្ថភាព ឬគុណភាព? (សូមមើល[ការសន្សំដែលបញ្ចេញសាច់ប្រាក់ ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់](../ការសន្សំដែលបញ្ចេញសាច់ប្រាក់-ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់/))

## ឧទាហរណ៍ដែលបានគណនា

ប្រព័ន្ធរៀបចំតារាងការងារអេឡិចត្រូនិក ថ្លៃដើម £500,000 ក្នុងរយៈពេល 3 ឆ្នាំ។

```
Cash-releasing:  agency shift reduction        £450,000
Capacity:        ward-manager admin time freed £600,000 (valued, not banked)
Qualitative:     staff satisfaction, safety    not monetized

Strict financial ROI  = (450,000 − 500,000)/500,000 = −10%
Economic ROI          = (1,050,000 − 500,000)/500,000 = +110%
```

លេខទាំងពីរពិត។ អ្នកលក់ដែលដកស្រង់ "+110% ROI" ជូន CFO ដែលអាចរក្សាបានតែ £450k នឹងបាត់បង់ទំនុកចិត្ត; ការបង្ហាញទាំងពីរ ដោយមានស្លាក នឹងឈ្នះវា។ ការបំបែកដូចគ្នាការពារអ្នកតស៊ូមតិផ្ទៃក្នុង នៅពេលហិរញ្ញវត្ថុធ្វើសវនកម្មអត្ថប្រយោជន៍ពីរឆ្នាំក្រោយ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

រាល់សំណើឧបករណ៍មានស្លាយ ROI; ស្ទើរតែគ្មានមួយណាប្រកាសប៉ារ៉ាម៉ែត្របួនទេ។ ការបរាជ័យទូទៅបំផុតគឺការលាយប្រភេទ៖ ការទទួលបានសមត្ថភាព (នាទីអ្នកអភិវឌ្ឍន៍) ដែលបង្ហាញជាផលចំណេញហិរញ្ញវត្ថុ។ រៀបចំ ROI របស់ AI/វេទិកាដូចឧទាហរណ៍ខាងលើ — បន្ទាត់សាច់ប្រាក់ បន្ទាត់សមត្ថភាព បន្ទាត់គុណភាព — ហើយបន្ថែម[ការវិភាគភាពរសើប](../ការវិភាគភាពរសើប/) លើលេខទន់។ សម្រាប់ការត្រួតពិនិត្យការពិត P&L លើ ROI របស់ AI ជាពិសេស សូមមើល[ផលចំណេញលើការវិនិយោគ AI](../ផលចំណេញលើការវិនិយោគ-ai/)។

## ចំណុចងាយធ្លាក់

- **ការលាងសម្អាតទស្សនៈ**៖ អត្ថប្រយោជន៍សង្គមមួយទសវត្សរ៍ដែលដកស្រង់ជូនអ្នកកាន់ថវិកាដែលមានព្រំដែន 12 ខែ។
- **សរុបជំនួសសុទ្ធ**៖ "ត្រឡប់ £3M" លើការចំណាយ £2M គឺ ROI 50% មិនមែន 300% ទេ។
- **ការបង្កើនសមាមាត្រអតិបរមា**៖ ភាគបែងតូចផលិត ROI គួរឱ្យភ្ញាក់ផ្អើលលើការវិនិយោគតូចតាច; ចាត់ចំណាត់ថ្នាក់ផលប័ត្រតាម NPV ឬ[អត្ថប្រយោជន៍ជាប្រាក់សុទ្ធ](../អត្ថប្រយោជន៍រូបិយវត្ថុសុទ្ធ/) ប្រើ ROI ជាតម្រង។
- **គ្មានសវនកម្មអត្ថប្រយោជន៍**៖ ROI ព្យាករណ៍ដោយគ្មានការតាមដាន[ការសម្រេចអត្ថប្រយោជន៍](../ការសម្រេចអត្ថប្រយោជន៍/) គឺជាការសន្យា មិនមែនលទ្ធផលទេ។
