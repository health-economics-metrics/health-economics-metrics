# ថ្លៃដើមឱកាស

ថ្លៃដើមឱកាសគឺជាតម្លៃនៃជម្រើសផ្សេងល្អបំផុតដែលអ្នកបោះបង់នៅពេលអ្នកប្តេជ្ញាធនធានមួយ។ ក្នុងប្រព័ន្ធសុខាភិបាលដែលមានថវិកាថេរ ការចំណាយ £1 លានលើរឿងមួយ មានន័យថា សុខភាពតម្លៃ £1 លាន *មិនត្រូវបានផលិត* នៅកន្លែងផ្សេង។

## ហេតុអ្វីបានជាសំខាន់

ថ្លៃដើមឱកាសគឺជាគំនិតដ៏ជ្រៅបំផុតក្នុងសេដ្ឋកិច្ចសុខភាព ហើយជាគំនិតដែលវិស្វករកម្មវិធីរំលងញឹកញាប់បំផុត។ ថវិកាសុខភាពមានកំណត់ថេរក្នុងមួយឆ្នាំណាមួយ ដូច្នេះបច្ចេកវិទ្យាថ្មីមិនដែលត្រូវបានផ្តល់មូលនិធិពីប្រាក់ "បន្ថែម" ទេ — វាជំនួសអ្វីមួយ។ សំណួរដែលអ្នកបង់ប្រាក់សួរពិតប្រាកដមិនមែន "តើនេះល្អទេ?" ទេ ប៉ុន្តែ "តើនេះប្រសើរជាងអ្វីដែលប្រាក់ដដែលទិញបានបច្ចុប្បន្នទេ?"

នេះជាមូលហេតុដែលមានកម្រិតកំណត់ប្រសិទ្ធភាពថ្លៃដើម៖ កម្រិតកំណត់គឺជាការប៉ាន់ស្មាននៃសុខភាពដែលប្រាក់ទិញបាននៅគែមនៃប្រព័ន្ធបច្ចុប្បន្ន។ សូមមើល[កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់](../កម្រិតកំណត់ឆន្ទៈបង់ប្រាក់/)។

## គណិតវិទ្យា

គ្មានរូបមន្តតែមួយទេ; ថ្លៃដើមឱកាសគឺជាវិន័យប្រៀបធៀប៖

```
Opportunity cost of choosing A = value of best forgone alternative B
Net gain from A = value(A) − value(B)
```

ស្តង់ដារជាក់ស្តែង៖ Claxton et al. (2015) បានប៉ាន់ស្មានថា NHS ផលិត QALY មួយក្នុងតម្លៃប្រហែល **£13,000** នៅគែម។ ដូច្នេះ £13,000 ដែលចំណាយលើបច្ចេកវិទ្យាដែលផលិតតិចជាង QALY មួយ ធ្វើឱ្យប្រជាជាតិ *មានសុខភាពអន់ជាង* ទោះបីបច្ចេកវិទ្យា "ដំណើរការ" ក៏ដោយ។

## ឧទាហរណ៍ដែលបានគណនា

ថវិកាបំប្លែងរបស់ NHS trust មួយអាចផ្តល់មូលនិធិបានតែមួយក្នុងចំណោម៖

- **ជម្រើស A**៖ កម្មវិធីរៀបចំតារាងការងារអេឡិចត្រូនិក — សន្សំ £400,000/ឆ្នាំលើការចំណាយបុគ្គលិកភ្នាក់ងារ។
- **ជម្រើស B**៖ កម្មវិធីសម្របសម្រួលការចេញពីមន្ទីរពេទ្យ — សន្សំ 2,000 ថ្ងៃគ្រែ/ឆ្នាំ។ ក្នុងថ្លៃដើមប្រៀបធៀបប្រហែល £150 ក្នុងមួយថ្ងៃគ្រែដែលដោះលែងបានពិត នោះគឺ £300,000/ឆ្នាំ បូកនឹងការព្យាបាលឆាប់ជាងសម្រាប់អ្នកជំងឺកំពុងរង់ចាំ។

ការផ្តល់មូលនិធិឱ្យ A មានន័យថាបោះបង់ B។ ថ្លៃដើមឱកាសរបស់ A គឺ £300,000 របស់ B + អត្ថប្រយោជន៍អ្នកជំងឺ; ករណី *សុទ្ធ* សម្រាប់ A គឺគ្រាន់តែជាភាពខុសគ្នា មិនមែន £400,000 ក្បាលព័ត៌មានរបស់ A ទេ។ ករណីអាជីវកម្មណាមួយដែលប្រៀបធៀបសំណើជាមួយ "មិនធ្វើអ្វី" ជំនួសឱ្យជម្រើសជំនួសល្អបំផុត បំផ្លើសតម្លៃរបស់វា។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

សមត្ថភាពវិស្វកម្មក៏ជាថវិកាថេរដែរ — ចន្លោះផែនទីបង្ហាញផ្លូវ មិនមែនផោនទេ។ ក្រុមវេទិកាដែលផ្តល់មូលនិធិឱ្យឧបករណ៍ A ដែលសន្សំម៉ោងវិស្វករក្នុងតម្លៃ £500/ម៉ោង ខណៈដែលឧបករណ៍ B ផ្តល់ដូចគ្នាក្នុងតម្លៃ £200/ម៉ោង គឺកំពុងបំផ្លាញសមត្ថភាព ដូចប្រព័ន្ធសុខាភិបាលដែលផ្តល់មូលនិធិថ្នាំ £40,000/QALY ជំនួសការថែទាំ £13,000/QALY។ វិន័យនេះផ្ទេរបានដោយផ្ទាល់៖

- តែងតែដាក់ឈ្មោះអ្នកប្រៀបធៀប ("ធៀបនឹងអ្វី?")។
- វាយតម្លៃពេលវេលាវិស្វករតាមអ្វីដែលវានឹងផលិតបើមិនដូច្នេះ មិនមែនតាមប្រាក់ខែតែម្យ៉ាងទេ។
- ចាត់ទុក "យើងនៅសល់ថវិកា" ជាការចាប់ផ្តើមនៃការវិភាគ មិនមែនចុងបញ្ចប់ទេ។

## ចំណុចងាយធ្លាក់

- **ការប្រៀបធៀបនឹងអ្វីទាំងអស់។** អ្នកប្រៀបធៀបត្រឹមត្រូវគឺការប្រើប្រាស់ប្រាក់ល្អបំផុតបន្ទាប់ ដែលកម្រជា "មិនធ្វើអ្វី"។
- **ការសន្មត់ថាពេលវេលាដែលសន្សំមានថ្លៃដើមឱកាសសូន្យ។** ពេលវេលាដែលសន្សំមានតម្លៃតែនៅពេលដែលវាត្រូវបានប្រើឡើងវិញលើអ្វីដែលមានតម្លៃ — សូមមើល[ការសន្សំដែលបញ្ចេញសាច់ប្រាក់ ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់](../ការសន្សំដែលបញ្ចេញសាច់ប្រាក់-ធៀបនឹងមិនបញ្ចេញសាច់ប្រាក់/)។
- **ការមិនអើពើការជំនួស។** "ថវិកានឹងពង្រីកឱ្យសមស្រប" ស្ទើរតែមិនដែលពិតក្នុងសេវាសុខភាពជាតិក្នុងឆ្នាំបច្ចុប្បន្ន។
- **ការមិនអើពើថាវិធីសាស្ត្រណាកំណត់តម្លៃធនធានដែលត្រូវបានជំនួស។** សម្រាប់ផលិតភាពដែលបាត់បង់ជាពិសេស — ពីជំងឺ ពិការភាព ឬនិយោជិតចាកចេញ — សូមមើល[វិធីសាស្ត្រមូលធនមនុស្ស ធៀបនឹងវិធីសាស្ត្រថ្លៃដើមកកិត](../វិធីសាស្ត្រមូលធនមនុស្ស-ធៀបនឹងវិធីសាស្ត្រថ្លៃដើមកកិត/) ដែលជាកំណែនៃគំនិតនេះសម្រាប់ថ្លៃដើមផលិតភាពជាក់លាក់។
