# ការវិភាគកាត់បន្ថយថ្លៃដើម (CMA)

CMA ប្រៀបធៀបតែថ្លៃដើម ហើយជ្រើសជម្រើសថោកបំផុត — ស្របច្បាប់ *តែ* នៅពេលលទ្ធផលនៃជម្រើសត្រូវបានបង្ហាញថាស្មើគ្នា។

## ហេតុអ្វីបានជាសំខាន់

CMA គឺជាការវិភាគសាមញ្ញបំផុត និងត្រូវបានប្រើខុសច្រើនបំផុត។ ការអះអាងសមមូលធ្វើការទាំងអស់៖ ប្រសិនបើលទ្ធផលពិតជាមិនខុសគ្នា (ជីវសមមូលធៀបនឹងដើម; អ្នកផ្គត់ផ្គង់ពីរនៃសេវាដូចគ្នាបំពេញលក្ខណៈបច្ចេកទេសដូចគ្នា) នោះថ្លៃដើមគឺជាសំណួរតែមួយគត់ ហើយ CMA ត្រឹមត្រូវ។ ភាពម៉ត់ចត់ស្ថិតនៅក្នុងការ *បញ្ជាក់* សមមូលជាមុន — ជាធម្មតាតាមរយៈការសិក្សាមិនអន់ជាង (non-inferiority) ជាមួយរឹមដែលកំណត់ជាមុន — ដែលពិតជាជំហានដែលអ្នកទិញជាទូទៅរំលង។

## គណិតវិទ្យា

```
Given evidence that Effect_A ≈ Effect_B (within a pre-specified margin δ):
Choose min(Cost_A, Cost_B)

Costs measured from the same perspective, over the same horizon,
including switching/transition costs.
```

ប្រសិនបើមិនអាចបង្ហាញភស្តុតាងសមមូល CMA មិនមានសុពលភាព — ប្រើ [CEA](../ការវិភាគប្រសិទ្ធភាពថ្លៃដើម/)/[CUA](../ការវិភាគថ្លៃដើម-ឧបយោគ/) ជំនួស។

## ឧទាហរណ៍ដែលបានគណនា

ទុនជ្រើសរវាងវេទិកាពិគ្រោះវីដេអូពីរ។ ការសាកល្បងស្របគ្នា 3 ខែបង្ហាញអត្រាបញ្ចប់ 94.1% ធៀបនឹង 93.8% ការពេញចិត្តអ្នកជំងឺ 4.4 ធៀបនឹង 4.4 — ភាពខុសគ្នាក្នុង δ ដែលបានយល់ព្រមជាមុន 2 ចំណុចភាគរយ។ លទ្ធផល៖ ស្មើគ្នា។ ថ្លៃដើមលើសពី 3 ឆ្នាំ៖

```
                     Platform A     Platform B
Licences             £360,000       £210,000
Integration          £80,000        £150,000
Training/support     £60,000        £90,000
Total                £500,000       £450,000
```

វេទិកា B ឈ្នះ £50,000 — *រួមទាំង* ថ្លៃរួមបញ្ចូលខ្ពស់ជាង។ បើគ្មានការសាកល្បង ការអះអាងសមមូលនឹងផ្អែកលើខិត្តប័ណ្ណអ្នកលក់ ហើយភាពខុសគ្នាអត្រាបញ្ចប់ 1 ចំណុច (≈ ការពិគ្រោះបរាជ័យរាប់ពាន់ក្នុងមួយឆ្នាំ) នឹងលើសពី £50,000។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

CMA គឺជាទម្រង់ផ្លូវការនៃការទិញទំនិញធម្មតា៖ អ្នកផ្តល់ CI ពីរបំពេញ SLO ដូចគ្នា ឃ្លាំងវត្ថុពីរដែលមានលក្ខណៈបច្ចេកទេសភាពធន់ដូចគ្នា។ មេរៀនសេដ្ឋកិច្ចសុខាភិបាលគឺ *លំដាប់នៃប្រតិបត្តិការ*៖ ដំបូងបង្ហាញភស្តុតាងសមមូល (ស្តង់ដារធៀបនឹងបន្ទុកការងាររបស់អ្នក សាកល្បងធៀបនឹង SLO របស់អ្នក ដោយរឹមយល់ព្រមជាមុន) បន្ទាប់មកប្រៀបធៀបថ្លៃដើមសរុបរួមទាំងការធ្វើចំណាកស្រុក។ "ពួកវាស្ទើរតែដូចគ្នា B ថោកជាង" ដោយគ្មានជំហានទីមួយគឺជារបៀបដែលអង្គការទិញឧបករណ៍ដែលថោក 10% ហើយអាក្រក់ 40%។ លទ្ធផលតាម៖ នៅពេលអ្នកលក់ជជែកតម្លៃ ឱ្យពួកគេតាមឆ្លងសមមូល — វាចងផ្លូវម្ខាងទៀតផងដែរ។

## កំហុសដែលត្រូវជៀសវាង

- **សមមូលដែលសន្មត** — អំពើបាបកំណត់; អវត្តមាននៃភស្តុតាងនៃភាពខុសគ្នាមិនមែនជាភស្តុតាងនៃសមមូលទេ (ការសាកល្បងអំណាចទាប "បង្ហាញ" សមមូលដោយឥតគិតថ្លៃ)។
- **ការដកថ្លៃផ្លាស់ប្តូរចេញ** — ការធ្វើចំណាកស្រុក ការបណ្តុះបណ្តាលឡើងវិញ និងការដំណើរការស្របគ្នា ជាកម្មសិទ្ធិនៃផ្នែកថ្លៃដើម។
- **សមមូលលើលទ្ធផលខុស**៖ សមមូលលើរង្វាស់ដែលបានវាស់ ខុសគ្នាលើរង្វាស់ដែលសំខាន់ (ភាពអាចចូលប្រើបាន ភាពយឺតកន្ទុយ ការបញ្ចេញទិន្នន័យ)។
