# ការសម្រេចអត្ថប្រយោជន៍

ការគ្រប់គ្រងការសម្រេចអត្ថប្រយោជន៍ (BRM) គឺជាវិន័យនៃការកំណត់អត្តសញ្ញាណ ការកំណត់មូលដ្ឋាន ការតាមដាន និង *ការបង្ហាញភស្តុតាង* ថាអត្ថប្រយោជន៍ដែលបានសន្យាក្នុងករណីអាជីវកម្មពិតជាបានកើតឡើងបន្ទាប់ពីការផ្តល់ជូន។ ក្នុងការវិនិយោគសាធារណៈអង់គ្លេស វាស្ថិតក្នុង **គំរូប្រាំករណី (Five Case Model)** នៃ Green Book របស់ HM Treasury; ក្នុងវេជ្ជសាស្ត្រ ញាតិរបស់វាគឺការឃ្លាំមើលក្រោយទីផ្សារ។

## ហេតុអ្វីបានជាសំខាន់

ករណីអាជីវកម្មគឺជាការសន្យា; ការសម្រេចអត្ថប្រយោជន៍គឺជាសវនកម្ម។ ការវាយតម្លៃកម្មវិធីឌីជីថលធំៗរបស់ NHS បានរកឃើញម្តងហើយម្តងទៀតនូវអត្ថប្រយោជន៍ព្យាករណ៍ដែលមិនដែលកើតឡើង — ហើយនៅពេលអត្ថប្រយោជន៍មិនបញ្ចេញសាច់ប្រាក់ វាមិនធ្វើអ្វីសម្រាប់បន្ទាត់ខាងក្រោមរបស់ទុនទេ។ ការឆ្លើយតបរបស់ Green Book៖ រាល់ករណីចំណាយត្រូវតែឆ្លងកាត់ **ប្រាំករណី** (យុទ្ធសាស្ត្រ សេដ្ឋកិច្ច ពាណិជ្ជកម្ម ហិរញ្ញវត្ថុ ការគ្រប់គ្រង) ដោយមានការគ្រោងការសម្រេចអត្ថប្រយោជន៍ក្នុងករណីគ្រប់គ្រង *មុនពេលអនុម័ត* — ដាក់ឈ្មោះម្ចាស់ ចាប់យកមូលដ្ឋាន កំណត់កាលបរិច្ឆេទវាស់។ បើគ្មានវា "កម្មវិធីបានសន្សំ 30 នាទីក្នុងមួយគិលានុបដ្ឋាយិកា" នៅតែជារឿងប្រឌិតរបស់អ្នកលក់ជារៀងរហូត។

## គណិតវិទ្យា

```
Realization rate = benefits realized / benefits forecast   (per benefit, per period)

Mechanics that make it computable:
  baseline captured BEFORE go-live (else the delta is unmeasurable)
  each benefit: owner, metric, data source, measurement schedule
  forecast adjusted for optimism bias at appraisal (Green Book mandate)
  benefits classed cash / non-cash / qualitative and tracked separately
  (see cash-releasing-vs-non-cash-releasing.md)
```

## ឧទាហរណ៍ដែលបានគណនា

ករណីអាជីវកម្មកំណត់ពេលបុគ្គលិកអេឡិចត្រូនិកបានសន្យា ក្នុងមួយឆ្នាំ៖ ការកាត់បន្ថយចំណាយភ្នាក់ងារ £450k (សាច់ប្រាក់) ម៉ោងអ្នកគ្រប់គ្រងវួដ 8,000 (សមត្ថភាព) ការអនុលោមភាពអត្រាបំពេញប្រសើរឡើង (គុណភាព)។ 12 ខែក្រោយដាក់ឱ្យប្រើ៖

```
Benefit           Forecast    Realized    Rate   Evidence
Agency spend      £450,000    £287,000    64%    ledger vs baseline year
Manager hours     8,000       5,100       64%    time-motion sample
Fill compliance   +10pp       +12pp       120%   rostering system data

Actions from the review (the point of BRM):
agency shortfall traced to two wards never onboarded → onboard them;
forecast model's 30%-optimism error logged → applied to the next case.
```

ការសម្រេច 64% មិនមែនជាការបរាជ័យទេ — វាជា *ចំណេះដឹង*។ ករណីដែលមិនបានវាស់អះអាង 100% ជារៀងរហូត។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

អង្គការវិស្វកម្មអនុម័តការវិនិយោគវេទិកាលើអត្ថប្រយោជន៍ព្យាករណ៍ ហើយស្ទើរតែមិនដែលធ្វើសវនកម្មវា — រោគសាស្ត្រដែល BRM ជួសជុល។ ការនាំចូលស្រាល៖ រាល់សំណើលើសពីកម្រិតដាក់ឈ្មោះម្ចាស់អត្ថប្រយោជន៍ រង្វាស់មូលដ្ឋាន និងកាលបរិច្ឆេទពិនិត្យ T+6 ខែ; អត្រាសម្រេចត្រឡប់ទៅប្រាប់អំពីរបៀបដែលអង្គការបញ្ចុះការព្យាករណ៍បន្ទាប់របស់ក្រុមនោះ (ឬអ្នកលក់)។ នេះក៏ជាចម្លើយចំពោះការសង្ស័យឧបករណ៍ AI៖ [ការរកឃើញរបស់ MIT ថា ~95% នៃការសាកល្បង GenAI មិនបង្ហាញផលចំណេញ P&L ដែលអាចវាស់បាន](../ផលចំណេញលើការវិនិយោគ-ai/) គឺជាលទ្ធផលការសម្រេចអត្ថប្រយោជន៍ — ការសាកល្បងដែល *បាន* ផលចំណេញមានបន្ទាត់អត្ថប្រយោជន៍ដែលអាចតាមដាន និងមានម្ចាស់។ ព្យាករណ៍ → វាស់ → ក្រិតឡើងវិញ គឺជាវដ្តដូចគ្នានឹងការសាកល្បងដែលកំណត់តម្លៃដោយ [EVPI](../តម្លៃរំពឹងទុកនៃព័ត៌មានល្អឥតខ្ចោះ/) ដំណើរការនៅមាត្រដ្ឋានផលប័ត្រ។

## កំហុសដែលត្រូវជៀសវាង

- **គ្មានមូលដ្ឋានមុនដាក់ឱ្យប្រើ** — ការខកខានដ៏ស្លាប់ ដែលមិនអាចជួសជុលបាន។
- **អត្ថប្រយោជន៍កំព្រា**៖ គ្មានម្ចាស់ដាក់ឈ្មោះ មានន័យថាគ្មាននរណាប្រមូលទិន្នន័យ ហើយរាល់ការពិនិត្យនិយាយថា "ជាទូទៅដំណើរការតាមផែនការ"។
- **អត្ថប្រយោជន៍រាប់ស្ទួនឆ្លងកម្មវិធី** អះអាងសមត្ថភាពដែលបានដោះលែងដូចគ្នា — រក្សាបញ្ជីអត្ថប្រយោជន៍ទូទាំងផលប័ត្រ។
- **ល្ខោនការសម្រេច**៖ វាស់ជ័យជម្នះគុណភាពងាយៗ ខណៈបន្ទាត់សាច់ប្រាក់មិនត្រូវបានពិនិត្យស្ងាត់ៗ។
