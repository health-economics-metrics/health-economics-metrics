# ភាពលេចធ្លោ និងព្រំដែនប្រសិទ្ធភាព

ជម្រើសមួយ **ត្រូវបានលេចធ្លោ (dominated)** ប្រសិនបើជម្រើសមួយទៀតថោកជាង *និង* ផ្តល់ច្រើនជាង។ **ព្រំដែនប្រសិទ្ធភាព** គឺជាអ្វីដែលនៅសល់បន្ទាប់ពីលុបជម្រើសដែលត្រូវបានលេចធ្លោ៖ សំណុំនៃជម្រើសដែលការទទួលបានច្រើនជាងតម្រូវឱ្យបង់ច្រើនជាង។

## ហេតុអ្វីបានជាសំខាន់

មុនការជជែកណាមួយអំពីកម្រិត ឬថវិកា ការវាយតម្លៃបច្ចេកវិទ្យាសុខភាពលុបជម្រើសដែលគ្មាននរណាគួរជ្រើសជាមុន។ ការគូសរាល់ជម្រើសលើយន្តហោះថ្លៃដើមធៀបនឹងឥទ្ធិពល ហើយគូសព្រំដែនគឺជាលំហាត់ប្រាំនាទីដែលជាប្រចាំសម្លាប់ពាក់កណ្តាលនៃបញ្ជីខ្លី។ បន្ទាប់មកការប្រៀបធៀបបន្ថែម ([ICERs](../សមាមាត្រប្រសិទ្ធភាពថ្លៃដើមបន្ថែម/)) ត្រូវបានគណនាតែ *តាមព្រំដែន* ជម្រើសនីមួយៗធៀបនឹងជម្រើសមិនលេចធ្លោថោកបន្ទាប់ — មិនដែលធៀបនឹង "មិនធ្វើអ្វី" នៅពេលមានជម្រើសកណ្តាលល្អជាង។

## គណិតវិទ្យា

```
Strict dominance:   A dominates B if Cost_A ≤ Cost_B and Effect_A ≥ Effect_B
                    (with at least one strict inequality)

Extended dominance: B is ruled out if a mix of A and C achieves more effect
                    per pound — detected when ICERs decrease as you move up
                    the frontier. Valid frontier ICERs must be increasing.
```

នីតិវិធី៖ តម្រៀបជម្រើសតាមឥទ្ធិពល; លុបជម្រើសដែលត្រូវបានលេចធ្លោយ៉ាងតឹងរ៉ឹង; គណនា ICERs ជាគូរវាងអ្នកជិតខាង; លុបជម្រើសណាដែល ICER លើស ICER នៃជម្រើសមានឥទ្ធិពលខ្លាំងជាងបន្ទាប់ (ភាពលេចធ្លោពង្រីក); ធ្វើម្តងទៀតរហូតដល់ ICERs កើនឡើងឯកតា។

## ឧទាហរណ៍ដែលបានគណនា

បួនជម្រើសសម្រាប់កាត់បន្ថយការណាត់ជួបដែលខកខាន (ឥទ្ធិពល = ការណាត់ជួបដែលទទួលបានវិញ/ឆ្នាំ)៖

```
Option          Cost/yr    Recovered
Do nothing      £0         0
SMS reminders   £20,000    2,000
Phone calls     £120,000   2,200
SMS + AI triage £90,000    3,500
```

ការហៅទូរស័ព្ទ **ត្រូវបានលេចធ្លោយ៉ាងតឹងរ៉ឹង** ដោយ SMS + AI triage (ថ្លៃជាង ទទួលបានវិញតិចជាង)។ ព្រំដែន៖ គ្មាន → SMS → SMS + AI។

```
ICER(SMS vs nothing)   = 20,000 / 2,000  = £10 per appointment recovered
ICER(SMS+AI vs SMS)    = (90,000 − 20,000) / (3,500 − 2,000) = £46.67 per appointment
```

ICERs កើនឡើង → ព្រំដែនមានសុពលភាព។ នៅ ~£160 សន្សំក្នុងមួយការណាត់ជួបមន្ទីរពេទ្យដែលទទួលបានវិញ (សូមមើល[អត្រាមិនមកតាមការណាត់](../អត្រាមិនមកតាមការណាត់/)) ទាំងពីរជំហានព្រំដែនសមនឹងធ្វើ; សំណើ phone-bank មិនគួរទៅដល់គណៈកម្មការឡើយ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

បង្កើតតារាងដូចគ្នាសម្រាប់ការសម្រេចចិត្តឧបករណ៍ណាមួយ៖ ថ្លៃដើមក្នុងមួយឆ្នាំលើអ័ក្សមួយ លទ្ធផលដែលបានវាស់ (ម៉ោងដែលបានសន្សំ ឧប្បត្តិហេតុដែលបានជៀសវាង ការដាក់ឱ្យប្រើដែលអាចធ្វើបាន) លើអ័ក្សម្ខាងទៀត។ ចំណុចខាងលើ-ឆ្វេងនៃព្រំដែនត្រូវបានលុបមុននរណាជជែកអំពីថវិកា។ នេះបង្វិលការជ្រើសអ្នកលក់ពីការជជែកបញ្ជីលក្ខណៈពិសេស ទៅ "អ្នកត្រូវបានលេចធ្លោ; កិច្ចប្រជុំចប់ហើយ"។ វាក៏លាតត្រដាងគំរូសហគ្រាសទូទៅនៃការទិញជម្រើសថ្លៃបំផុតសម្រាប់ផលចំណេញបន្តិចបន្តួច — ស្របច្បាប់តែបើតម្លៃបន្ថែមក្នុងមួយឯកតាបន្ថែមគឺជាតម្លៃដែលអង្គការនឹងបង់ដោយដឹងខ្លួន។

## កំហុសដែលត្រូវជៀសវាង

- **ការប្រៀបធៀបអ្វីៗទៅនឹងមូលដ្ឋាន** ជំនួសឱ្យជម្រើសបន្ទាប់នៅលើព្រំដែន — នេះបញ្ជោរជម្រើសថ្លៃដោយលាក់ជម្រើសស្ទើរតែស្មើគ្នាថោកជាង។
- **ពិន្ទុឥទ្ធិពលវិមាត្រតែមួយ** ដែលលាក់អ្វីដែលសំខាន់; ប្រសិនបើលទ្ធផលពីររាប់ សូមបញ្ចូលវាដោយការពារបាន (សូមមើល[ការវិភាគថ្លៃដើម-ឧបយោគ](../ការវិភាគថ្លៃដើម-ឧបយោគ/)) ឬបង្ហាញព្រំដែនពីរ។
- **ភ្លេចភាពមិនប្រាកដប្រជា**៖ ជម្រើសជិតព្រំដែនអាចប្តូរកន្លែងក្រោម[ការវិភាគភាពប្រកាន់អារម្មណ៍](../ការវិភាគភាពរសើប/)។
