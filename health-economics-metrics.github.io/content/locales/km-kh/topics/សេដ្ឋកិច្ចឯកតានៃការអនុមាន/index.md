# សេដ្ឋកិច្ចឯកតានៃការអនុមាន

សេដ្ឋកិច្ចឯកតានៃការអនុមាន (inference unit economics) កំណត់តម្លៃមុខងារ AI តាមការគណនាបន្ថែម (marginal compute) របស់វា៖ **ថ្លៃដើមក្នុងមួយ token** បូកសរុបទៅជាថ្លៃដើមក្នុងមួយប្រតិបត្តិការ ក្នុងមួយអ្នកប្រើ ក្នុងមួយវគ្គព្យាបាល។ ឌីណាមិកកំណត់៖ តម្លៃ LLM បានធ្លាក់ចុះប្រហែល **មួយលំដាប់ទំហំរៀងរាល់ 1–2 ឆ្នាំ** នៅសមត្ថភាពថេរ — អត្រាបរិយាកាសធ្លាក់ថ្លៃដែលមិនធ្លាប់មានពីមុនក្នុងការគិតថ្លៃបច្ចេកវិទ្យាសុខភាព។

## ហេតុអ្វីបានជាសំខាន់

ផលវិបាកពីរកើតចេញពីការដួលតម្លៃ។ ផ្នែកពាណិជ្ជកម្ម មុខងារ AI ដែលនៅមានរឹមតិចថ្ងៃនេះ អាចរកប្រាក់ចំណេញយ៉ាងងាយក្នុង 18 ខែ — ហើយដៃគូប្រកួតប្រជែងដែលកំណត់តម្លៃលើថ្លៃដើមថ្ងៃនេះនឹងត្រូវគេកាត់តម្លៃ។ សម្រាប់ការវាយតម្លៃសេដ្ឋកិច្ច គំរូប្រសិទ្ធភាពថ្លៃដើមណាមួយសម្រាប់សេវាព្យាបាលដែលប្រើ AI ដែលបង្កកតម្លៃអនុមាននៃឆ្នាំ 2024 **ប៉ាន់ស្មានថ្លៃដើមបន្តហួសខ្លាំង** — ការវិភាគត្រូវការសេណារីយ៉ូធ្លាក់តម្លៃ ដូចគំរូថ្នាំដោះស្រាយការផុតកំណត់ប៉ាតង់ និងការចូលរបស់ថ្នាំហ្សែណេរិក។ (ចំណុចយោងពីការស្រាវជ្រាវ៖ token ទិន្នផលព្រំដែន ~$15–75/M នៅពាក់កណ្តាលឆ្នាំ 2026 គំរូកម្រិតកណ្តាលថោកជាងមួយលំដាប់ សមត្ថភាពកម្រិត GPT-4 ធ្លាក់ពី ~$20/M ក្នុងឆ្នាំ 2022 មក ~$0.40/M; Epoch AI បានវាស់ការធ្លាក់ 9×–900×/ឆ្នាំ អាស្រ័យលើដំណាក់កាលសមត្ថភាព។)

## គណិតវិទ្យា

```
Cost per call     = input tokens × input rate + output tokens × output rate
Cost per unit     = Σ calls per unit of business output (per triage episode,
                    per drafted letter, per consultation summary)

Blended reality   = base call + retries + RAG context (input-heavy)
                    + evaluation/guardrail calls (often 20–50% overhead)

Price-decline scenario for multi-year models:
  cost_t = cost_0 × d^t, test d ∈ {0.3, 0.5, 0.7}/year in sensitivity analysis
```

## ឧទាហរណ៍ដែលបានគណនា

សេវាសង្ខេបការចេញពីមន្ទីរពេទ្យដោយ AI៖ សង្ខេបជាមធ្យមប្រើ input token 12,000 (បរិបទកំណត់ត្រា) + output 1,200 បូកជំហានផ្ទៀងផ្ទាត់ (6,000 in / 300 out)។ ក្នុងតម្លៃ $3/M in, $15/M out៖

```
Draft:   12,000 × 3/1M + 1,200 × 15/1M  = $0.036 + $0.018 = $0.054
Verify:   6,000 × 3/1M +   300 × 15/1M  = $0.018 + $0.0045 ≈ $0.023
Per summary ≈ $0.077 → per 100,000 summaries/year ≈ $7,700

Against ~20 clinician-minutes saved per summary (≈ £25), inference is
0.25% of the value created — the economics are dominated by everything
EXCEPT the tokens: integration, evaluation, governance, adoption.
```

សេចក្តីសន្និដ្ឋាននោះ — ថ្លៃដើមអនុមានកម្រិតតិចតួចជាឧបសគ្គចងកាតព្វកិច្ច ក្នុងតម្លៃបច្ចុប្បន្ន សម្រាប់កិច្ចការគ្លីនិកតម្លៃខ្ពស់ — ខ្លួនវាផ្ទាល់ជាការរកឃើញដែលគួរយកទៅកិច្ចប្រជុំកំណត់តម្លៃ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

នេះគឺ[សេដ្ឋកិច្ចឯកតាពពក](../សេដ្ឋកិច្ចឯកតាពពក/)ដែលឯកទេសសម្រាប់ AI ជាមួយកំណត់ចំណាំអនុវត្តបី៖ **វាស់តាមឯកតាអាជីវកម្ម** មិនមែនតាមការហៅ API ទេ ដើម្បីឱ្យលេខភ្ជាប់ត្រង់ទៅគំរូ [ICER](../សមាមាត្រប្រសិទ្ធភាពថ្លៃដើមបន្ថែម/)/[ផលប៉ះពាល់ថវិកា](../ការវិភាគផលប៉ះពាល់ថវិកា/); **ប្រុងប្រយ័ត្នភាពមិនស៊ីមេទ្រីរវាង input/output** (ទិន្នផលជាទូទៅថ្លៃជាង input ~4×; ស្ថាបត្យកម្ម RAG ធ្ងន់លើ input — ជម្រើសស្ថាបត្យកម្មគឺជាជម្រើសតម្លៃ); និង **ដឹកតាមថ្នាក់កិច្ចការ** — ផ្គូផ្គងសមត្ថភាពគំរូនឹងភាពលំបាកនៃកិច្ចការ (គំរូថោកសម្រាប់ការចាត់ថ្នាក់ គំរូព្រំដែនសម្រាប់ការសំយោគ) កាត់បន្ថយថ្លៃដើមលាយ 5–10× ជាប្រចាំនៅគុណភាពស្មើគ្នា ជាកំណែកម្មវិធីនៃការប្រើអន្តរាគមន៍មានប្រសិទ្ធភាពថោកបំផុត ([ការវិភាគកាត់បន្ថយថ្លៃដើម](../ការវិភាគកាត់បន្ថយថ្លៃដើម/) ដោយមានភស្តុតាងសមមូល)។

## កំហុសដែលត្រូវជៀសវាង

- **គំរូច្រើនឆ្នាំតម្លៃបង្កក** — ប៉ាន់ស្មានថ្លៃដើមហួស; ប៉ុន្តែក៏មាន **គំរូចំណូលដែលសន្មតការធ្លាក់ថ្លៃ** — សង្គ្រាមតម្លៃមិនមែនជាកិច្ចសន្យាទេ; ធ្វើសេណារីយ៉ូទាំងពីរ។
- **មិនអើពើនឹងថ្លៃវាយតម្លៃ**: guardrail, judge និង retry គឺជា token ពិតប្រាកដ ជារឿយៗជាភាគច្រើនក្នុងបរិយាកាសដែលមានបទប្បញ្ញត្តិ។
- **ភាពមើលឃើញខ្លីលើ token**: ភាពយឺត ដែនកំណត់អត្រា និងដែនកំណត់បង្អួចបរិបទ មានថ្លៃដើមដែលតម្លៃ token មិនចាប់បាន។
