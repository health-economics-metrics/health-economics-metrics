# ការខ្វះខាត QALY និងកត្តាកែតម្រូវភាពធ្ងន់ធ្ងរ

ការខ្វះខាត QALY វាស់ថាជំងឺមួយយកសុខភាពអនាគតប៉ុន្មានពីអ្នកជំងឺ បើប្រៀបធៀបនឹងប្រជាជនទូទៅ។ NICE ប្រើវាដើម្បីអនុវត្ត **កត្តាកែតម្រូវភាពធ្ងន់ធ្ងរ**៖ ប្រជាជនកាន់តែឈឺ QALY នីមួយៗដែលទទួលបានកាន់តែមានតម្លៃ — ដល់ទៅ 1.7× នៃកម្រិតកំណត់ស្តង់ដារ។

## ហេតុអ្វីបានជាសំខាន់

តាំងពីសៀវភៅណែនាំ NICE ឆ្នាំ 2022 ភាពធ្ងន់ធ្ងរគឺជាមេគុណច្បាស់លាស់លើតម្លៃនៃការទទួលបានសុខភាព ជំនួសប្រាក់រង្វាន់ចុងជីវិតចាស់។ បច្ចេកវិទ្យាសម្រាប់ស្ថានភាពធ្ងន់ធ្ងរត្រូវបានវិនិច្ឆ័យធៀបនឹងកម្រិតកំណត់មានប្រសិទ្ធភាពដល់ទៅ ~£51,000/QALY ជំនួស £30,000។ ប្រសិនបើកម្មវិធីរបស់អ្នកបម្រើប្រជាជនរងផលប៉ះពាល់ធ្ងន់ធ្ងរ (ខ្សោយបេះដូងកម្រិតខ្ពស់ ជំងឺផ្លូវចិត្តធ្ងន់ធ្ងរ) កត្តាកែតម្រូវភាពធ្ងន់ធ្ងរអាចជាភាពខុសគ្នារវាងករណីសេដ្ឋកិច្ចដែលអាចផ្តល់មូលនិធិ និងមិនអាច — ហើយអ្នកត្រូវការគណិតវិទ្យាការខ្វះខាតដើម្បីអះអាងវា។

## គណិតវិទ្យា

រង្វាស់ពីរ គណនាលើអាយុជីវិតដែលនៅសល់ជាមួយការថែទាំស្តង់ដារបច្ចុប្បន្ន៖

```
Absolute shortfall     = QALYs_general_population − QALYs_with_condition
Proportional shortfall = Absolute shortfall / QALYs_general_population
```

ទម្ងន់ NICE 2022 (រង្វាស់ណាដែលផ្តល់ទម្ងន់ខ្ពស់ជាងអនុវត្ត)៖

```
Weight ×1.0: absolute < 12 and proportional < 0.85
Weight ×1.2: absolute ≥ 12 or proportional ≥ 0.85
Weight ×1.7: absolute ≥ 18 or proportional ≥ 0.95
```

ទម្ងន់គុណនឹង ΔE (ឬស្មើគ្នា កម្រិតកំណត់)៖ λ មានប្រសិទ្ធភាពក្លាយជា £24k–£36k នៅ ×1.2 និង £34k–£51k នៅ ×1.7។

## ឧទាហរណ៍ដែលបានគណនា

អ្នកជំងឺដែលមានស្ថានភាពឈ្លានពាន អាយុមធ្យម 60។ ប្រជាជនទូទៅអាយុ 60 រំពឹង 14.2 QALY ដែលបានបញ្ចុះតម្លៃ; ជាមួយស្ថានភាពនេះក្រោមការថែទាំបច្ចុប្បន្ន 2.1។

```
Absolute shortfall     = 14.2 − 2.1 = 12.1  (≥ 12 → qualifies for ×1.2)
Proportional shortfall = 12.1 / 14.2 = 0.852 (≥ 0.85 → also ×1.2)
```

ICER នៃវេទិកាត្រួតពិនិត្យរបស់អ្នកគឺ £26,000/QALY — លើសពីការវិនិច្ឆ័យចំណុចកណ្តាលស្តង់ដារ £20k–£30k គឺនៅព្រំដែន។ ជាមួយទម្ងន់ ×1.2៖ ICER មានប្រសិទ្ធភាព = 26,000 / 1.2 ≈ **£21,700/QALY** — អាចផ្តល់មូលនិធិបានយ៉ាងងាយស្រួល។ ការគណនាការខ្វះខាតទើបតែផ្លាស់ប្តូរការសម្រេចចិត្ត។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ការផ្តល់ទម្ងន់ភាពធ្ងន់ធ្ងរគឺជាកំណែផ្លូវការនៃអ្វីដែលអង្គការវិស្វកម្មធ្វើតាមវិចារណញាណ៖ ចំណាយច្រើនក្នុងមួយឯកតាភាពប្រសើរឡើងលើប្រព័ន្ធដែលអាក្រក់បំផុត។ គំរូដែលអាចផ្ទេរបាន — គណនា "ការខ្វះខាត SLO" នៃសេវានីមួយៗ (ទាបជាងមូលដ្ឋានមានសុខភាពល្អដែលរំពឹងប៉ុន្មាន ទាំងដាច់ខាត និងសមាមាត្រ) ហើយផ្តល់ទម្ងន់តម្លៃនៃការជួសជុលតាមនោះ។ នេះបង្ហាញជាមួយនព្វន្ធជំនួសអំណះអំណាង ថាហេតុអ្វីប្រព័ន្ធមរតកដែលកំពុងឆេះទទួលការវិនិយោគច្រើនជាងក្នុងមួយម៉ោងដែលសន្សំ ជាងប្រព័ន្ធដែលមានសុខភាពល្អ។ វាក៏ផ្ទុកមេរៀនអភិបាលកិច្ចដដែល៖ ផ្សព្វផ្សាយទម្ងន់ *មុន* កិច្ចប្រជុំផ្តល់អាទិភាព បើមិនដូច្នោះទេរាល់ក្រុមអះអាងភាពធ្ងន់ធ្ងរ។

## ចំណុចងាយធ្លាក់

- **ការគណនាការខ្វះខាតធៀបនឹងមូលដ្ឋានខុស**៖ វាត្រូវបានវាស់ក្រោម *ការថែទាំស្តង់ដារបច្ចុប្បន្ន* មិនមែនប្រវត្តិធម្មជាតិដែលមិនបានព្យាបាលទេ។
- **ភាពរសើបអាយុ**៖ ការខ្វះខាតអាស្រ័យខ្លាំងលើអាយុប្រជាជន (អ្នកជំងឺក្មេងមាន QALY ច្រើនជាងដើម្បីបាត់បង់ → ការខ្វះខាតដាច់ខាតខ្ពស់ជាង); ប្រើការចែកចាយអាយុពិតប្រាកដនៃប្រជាជនដែលត្រូវបានព្យាបាល។
- **ការសន្មត់ថាកត្តាកែតម្រូវអនុវត្តនៅកន្លែងផ្សេង** — វាជាយន្តការ NICE (អង់គ្លេស); ស្ថាប័ន HTA ផ្សេងទៀតដោះស្រាយភាពធ្ងន់ធ្ងរខុសគ្នា (ឬមិនធ្វើសោះ)។
