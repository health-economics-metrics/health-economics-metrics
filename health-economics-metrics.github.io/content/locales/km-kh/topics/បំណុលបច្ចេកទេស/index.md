# បំណុលបច្ចេកទេស

បំណុលបច្ចេកទេសគឺជាថ្លៃដើមអនាគតដោយប្រយោលនៃការសម្រេចចិត្តបែបងាយស្រួលក្នុងអតីតកាលនៅក្នុងមូលដ្ឋានកូដ៖ ការងារជួសជុលដែលជំពាក់ (**ដើមទុន**) និងការទប់ទល់ជាប់រហូតលើការបញ្ជូន (**ការប្រាក់**)។ វិធីសាស្ត្របរិមាណដូចជា SQALE បម្លែងវាពីពាក្យប្រៀបធៀបទៅជាបំណុលដែលមានថ្លៃដើម។

## ហេតុអ្វីបានជាសំខាន់

បើមិនកំណត់បរិមាណ បំណុលបច្ចេកទេសគឺជាការត្អូញត្អែរ; បើកំណត់បរិមាណ វាគឺជាករណីអាជីវកម្ម។ មូលដ្ឋានឧស្សាហកម្ម (CAST Appmarq កម្មវិធី 1,400 / 550M LOC)៖ តាមប្រវត្តិសាស្ត្រ ≈ **ដើមទុនបំណុលបច្ចេកទេស $3.61 ក្នុងមួយបន្ទាត់កូដ** ដោយមូលដ្ឋានកូដធម្មតាផ្ទុកសមាមាត្របំណុល 15–20% នៃថ្លៃដើមសាងសង់ឡើងវិញ ធៀបនឹងរបារសុខភាពដែលប្រើទូទៅ ≤5% (ថ្នាក់ "A" របស់ SonarQube)។ ក្របខ័ណ្ឌសេដ្ឋកិច្ចសុខភាពសមស្របយ៉ាងពិតប្រាកដ៖ បំណុលគឺជា *ជំងឺរ៉ាំរ៉ៃ* — មិនបានព្យាបាល វារីកចម្រើន "ការប្រាក់" របស់វាកើនជាការបញ្ជូនយឺតជាង និងអត្រាកំហុសខ្ពស់ជាង ហើយការជួសជុលប្រកួតប្រជែងសមត្ថភាពជាមួយការងារលក្ខណៈពិសេស ដូចការបង្ការប្រកួតប្រជែងជាមួយការព្យាបាល។

## គណិតវិទ្យា

```
SQALE principal   = Σ over violations (remediation time) × developer cost rate
Technical debt ratio (TDR) = remediation cost / redevelopment cost × 100
                    (SonarQube grades: A ≤ 5%, B ≤ 10%, C ≤ 20%, D ≤ 50%)

Interest (the number that justifies paydown):
  interest/year = Δ delivery velocity × value per unit velocity
                + Δ defect rate × cost per defect
Paydown case  = PV(interest avoided over horizon) − remediation cost
                (discounted — see discounting-and-time-preference.md)
```

ដើមទុនបញ្ជាក់បំណុល; **ការប្រាក់** បង្កើតករណីវិនិយោគ។ ការបង់ដើមទុន £500k ដើម្បីជៀសវាងការប្រាក់ £40k/ឆ្នាំ គឺជាការដោះដូរមិនល្អ; ដើម្បីជៀសវាង £400k/ឆ្នាំ គឺល្អឥតខ្ចោះ។

## ឧទាហរណ៍ដែលបានគណនា

ស្រទាប់សមាហរណកម្មកំណត់ត្រាគ្លីនិក 400k-LOC៖ ដើមទុន SQALE 3,800 ម៉ោង × £75 = **£285k**; TDR ≈ 12% (ថ្នាក់ C)។ ការប្រាក់ដែលបានវាស់៖ ក្រុមដែលប៉ះស្រទាប់នេះបង្ហាញពេលវេលាវដ្តយូរជាង 40% និងអត្រាបរាជ័យផ្លាស់ប្តូរ 2× ធៀបនឹងមូលដ្ឋានសំណង់។ ស្រទាប់ស្រូប 6,000 ម៉ោងអ្នកអភិវឌ្ឍន៍/ឆ្នាំ៖

```
Interest ≈ 6,000 × 0.40 × £75      = £180,000/year (velocity drag)
         + 12 extra failures × £8,000 = £96,000/year (rework/incidents)
         ≈ £276,000/year

Remediate the worst 30% of principal (£85k) targeting hotspots → modelled
interest reduction 60%: saves ~£166k/year. Payback ≈ 6 months.
```

ការកំណត់គោលដៅចំណុចក្តៅមានសារៈសំខាន់៖ ការប្រាក់បំណុលប្រមូលផ្តុំនៅកន្លែងដែលប្រេកង់ផ្លាស់ប្តូរ × ដង់ស៊ីតេបំណុលខ្ពស់បំផុត — ការជួសជុលបំណុលដែលកម្រប៉ះមិនទិញអ្វីទេ ដូចការព្យាបាលស្ថានភាពដែលនឹងមិនដែលរីកចម្រើន ([សេដ្ឋកិច្ចនៃការបង្ការ](../សេដ្ឋកិច្ចនៃការបង្ការ/))។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

ការនាំចូលសេដ្ឋកិច្ចសុខភាពដែលលើកកម្ពស់អំណះអំណាងបំណុលបច្ចេកទេស៖ បង្ហាញសំណង់ជា **បញ្ជីបន្ទុក** (បែប [DALY](../ឆ្នាំជីវិតដែលកែតម្រូវតាមពិការភាព/) — តើឆ្នាំវិស្វកម្មមានសុខភាពល្អដែលបាត់បង់នៅឯណា?); បង្ហាញហេតុផលការបង់បំណុលដោយគណិតវិទ្យារីកចម្រើនដោយស្មោះត្រង់ (ជាធម្មតាមានប្រសិទ្ធភាពថ្លៃដើម មិនមែនសន្សំថ្លៃដើមទេ); ផ្តល់ទម្ងន់ការជួសជុលប្រព័ន្ធអាក្រក់បំផុតតាម[ការខ្វះខាតភាពធ្ងន់ធ្ងរ](../ការខ្វះខាត-qaly-និងកត្តាកែតម្រូវភាពធ្ងន់ធ្ងរ/); ហើយដាក់សំណើជួសជុលធំៗជាមួយការវិភាគទូទាត់ដែលរួចផុតពីច្បាប់[ថ្លៃដើមបន្ទាប់ដែលបានជៀសវាង](../ថ្លៃដើមបន្ទាប់ដែលបានជៀសវាង/) — ថ្លឹងតាមប្រូបាប៊ីលីតេ បានបញ្ចុះតម្លៃ រាប់តែម្តង។

## ចំណុចងាយធ្លាក់

- **ការរាយការណ៍តែដើមទុន**៖ លេខធំគួរឱ្យខ្លាចដោយគ្មានការប៉ាន់ស្មានការប្រាក់មិនបញ្ជាក់អ្វីទេ។
- **តួលេខបំណុលដែលបង្កើតដោយឧបករណ៍យកតាមព្យញ្ជនៈ**៖ SQALE រាប់ការរំលោភច្បាប់; វាខកខានបំណុលស្ថាបត្យកម្ម (ប្រភេទថ្លៃ) ហើយរាប់រឿងតូចតាច។
- **ឧត្តមគតិបំណុលសូន្យ**៖ កម្រិតបំណុលល្អបំផុតមិនមែនសូន្យទេ — បំណុលគឺជាអានុភាព; សំណួរគឺអត្រាការប្រាក់។
- **"ការសរសេរឡើងវិញជៀសវាងទាំងអស់"**៖ សំណើសរសេរឡើងវិញត្រូវតែឆ្លងកាត់ច្បាប់ទូទាត់ដូចគ្នា — ថ្លៃដើមប្រឆាំងការពិត ប្រូបាប៊ីលីតេ ការបញ្ចុះតម្លៃ។
