# រង្វាស់លំហូរ

រង្វាស់លំហូរវាស់ថាតើការងារផ្លាស់ទីតាមប្រព័ន្ធផ្តល់ជូនយ៉ាងដូចម្តេច៖ ពេលវេលាវដ្ត ពេលវេលាដឹកនាំ ទិន្នផល ការងារកំពុងដំណើរការ (WIP) និងប្រសិទ្ធភាពលំហូរ។ ពួកវាត្រូវបានគ្រប់គ្រងដោយច្បាប់ Little — គណិតវិទ្យាជួរដូចគ្នាដែលគ្រប់គ្រងគ្រែមន្ទីរពេទ្យ និងបញ្ជីរង់ចាំ។

## ហេតុអ្វីបានជាសំខាន់

ពេលវេលាផ្តល់ជូនភាគច្រើនមិនមែនជាការងារទេ — វាគឺជាការរង់ចាំ។ ការសិក្សាប្រសិទ្ធភាពលំហូរនៃការងារចំណេះដឹងរកឃើញជាប្រចាំថាធាតុត្រូវបានធ្វើការសកម្មតែ **5–15%** នៃពេលវេលាកន្លងផុតរបស់វា; ដែលនៅសល់គឺជាជួរ។ នោះមានន័យថាការបង្កើនល្បឿនថោកបំផុតគឺការលុបជួរ មិនមែនការជួលទេ — ពិតជាការយល់ដឹងដែលកម្មវិធីលំហូរអ្នកជំងឺមន្ទីរពេទ្យបានរកឃើញអំពីគ្រែ។ សម្រាប់អ្វីដែលមាន[ថ្លៃដើមនៃការពន្យារ](../ថ្លៃដើមនៃការពន្យារ/) រង្វាស់លំហូរកំណត់ទីតាំងដែលថ្លៃពន្យារកើនឡើង។

## គណិតវិទ្យា

```
Cycle time      = t(finished) − t(started)
Lead time       = t(delivered) − t(requested)     (includes pre-work queue)
Throughput      = items completed / period
WIP             = items started but unfinished
Flow efficiency = active time / (active + wait time) × 100

Little's Law:  average WIP = throughput × average cycle time
               (equivalently: cycle time = WIP / throughput)
```

ច្បាប់ Little គឺជាដងថ្លឹង៖ នៅទិន្នផលថេរ ការកាត់បន្ថយ WIP កាត់បន្ថយពេលវេលាវដ្តសមាមាត្រ។ វាក៏គ្រប់គ្រងមន្ទីរពេទ្យ៖ `beds occupied = admissions/day × length of stay`។

## ឧទាហរណ៍ដែលបានគណនា

ក្រុមមានធាតុកំពុងដំណើរការ 40 ហើយបញ្ចប់ 10/សប្តាហ៍៖ ពេលវេលាវដ្ត = 40/10 = 4 សប្តាហ៍។ ពួកគេដាក់ដែនកំណត់ WIP កាត់បន្ថយ WIP ទៅ 15៖ ពេលវេលាវដ្ត = 15/10 = **1.5 សប្តាហ៍** — មនុស្សដូចគ្នា ទិន្នផលដូចគ្នា ផ្តល់ជូនលឿនជាង 62% ទាំងស្រុងពីវិន័យជួរ។

កំណត់តម្លៃដោយ CoD៖ ប្រសិនបើធាតុមានថ្លៃពន្យារមធ្យម £3,000/សប្តាហ៍ ធាតុនីមួយៗឥឡូវចំណាយ 2.5 សប្តាហ៍តិចជាងក្នុងជួរ៖ 10 ធាតុ/សប្តាហ៍ × 2.5 × 3,000 = **£75,000/សប្តាហ៍នៃថ្លៃពន្យារដែលបានលុបបំបាត់** — ពីការផ្លាស់ប្តូរគោលនយោបាយដែលមិនចំណាយអ្វី។

កញ្ចក់មន្ទីរពេទ្យ៖ 40 ការចូលសម្រាក/ថ្ងៃ × 6.0 ថ្ងៃ LOS = 240 គ្រែ; កាត់បន្ថយការរង់ចាំមិនមែនគ្លីនិកក្នុង LOS ទៅ 5.6 ថ្ងៃ ហើយ 16 គ្រែត្រូវបានដោះលែង ([រយៈពេលស្នាក់នៅ](../រយៈពេលស្នាក់នៅមន្ទីរពេទ្យ/)) — ច្បាប់ដូចគ្នា ដងថ្លឹងដូចគ្នា។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

រង្វាស់លំហូរគឺជាភាសាចែករំលែករវាងវិស្វកម្មផ្តល់ជូន និងប្រតិបត្តិការសុខាភិបាល៖

- **ស្តង់ដារដំណាក់កាលរងរបស់ PR** (LinearB ~8M PRs)៖ ពេលរើស elite < 7h ពិនិត្យ < 6h វដ្តសរុប < ~26h — ពេលរើសគឺជាជួរសុទ្ធ ជាអ្វីដំបូងដែលត្រូវវាយប្រហារ។
- **[បញ្ជីរង់ចាំ](../ផលប៉ះពាល់បញ្ជីរង់ចាំ/)** គឺជាការនៅជំពាក់; **[RTT](../ពីការបញ្ជូនទៅការព្យាបាល/)** គឺជាពេលវេលាដឹកនាំ; **[ការកាន់កាប់គ្រែ](../ថ្ងៃគ្រែដែលបានសន្សំ/)** គឺជា WIP។ ការកែលម្អផ្ទេរទាំងពីរទិស៖ ដែនកំណត់ WIP ↔ ការធ្វើឱ្យរលូនការចូលសម្រាក; ឧបករណ៍វាស់ពេលជួរ ↔ ការតាមដានដំណាក់កាលផ្លូវ។
- ប្រសិទ្ធភាពលំហូរក្រោម 15% គឺធម្មតាក្នុងទាំងពីរដែន ហើយទាំងពីរលាក់វា ព្រោះ *មនុស្ស* រវល់ ខណៈ *ការងារ* រង់ចាំ — វាស់នាឡិកាការងារ មិនមែននាឡិកាអ្នកធ្វើការទេ។

## កំហុសដែលត្រូវជៀសវាង

- **ការគោរពការប្រើប្រាស់**៖ ការជំរុញការប្រើប្រាស់អ្នកធ្វើការឆ្ពោះទៅ 100% ផ្ទុះពេលជួរមិនលីនេអ៊ែរ (M/M/1: ការរង់ចាំ ∝ ρ/(1−ρ)) — មូលហេតុដែលមន្ទីរពេទ្យកាន់កាប់ 95% ស្ទះ ហើយក្រុមបែងចែក 95% ជាប់គាំង។
- **មធ្យមលើការចែកចាយរេ**៖ ពេលវេលាវដ្តមានកន្ទុយធ្ងន់; ព្យាករណ៍ដោយភាគរយ (p85) មិនមែនមធ្យមទេ។
- **ការកាត់បន្ថយ WIP ដោយបដិសេធការងារខាងលើ** ហើយហៅវាថាការកែលម្អលំហូរ — តម្រូវការមិនបាត់ទេ វាតម្រង់ជួរនៅក្រៅព្រំដែនវាស់ (កំណែមន្ទីរពេទ្យ៖ ឡានពេទ្យរង់ចាំខាងក្រៅ ED)។
