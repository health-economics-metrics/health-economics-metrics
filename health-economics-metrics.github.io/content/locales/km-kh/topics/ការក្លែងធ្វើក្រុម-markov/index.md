# ការក្លែងធ្វើក្រុម Markov

គំរូក្រុម Markov (Markov cohort model) គឺជាបច្ចេកទេសធ្វើគំរូ HTA ស្តង់ដារសម្រាប់អន្តរាគមន៍ដែលផលរបស់វាលាតត្រដាងក្នុងរយៈពេលច្រើន (វដ្ត) មិនមែនក្នុងមួយជំហានទេ។ ក្រុមសម្មតិកម្មមួយចាប់ផ្តើមទាំងស្រុងក្នុងស្ថានភាពសុខភាពមួយ ហើយរាល់វដ្ត សំណុំប្រូបាប៊ីលីតេផ្លាស់ប្តូរថេរផ្លាស់ទីប្រភាគនៃក្រុមរវាងស្ថានភាព; ថ្លៃដើម និង QALY កកើតរាល់វដ្តសមាមាត្រនឹងចំនួនក្រុមដែលស្ថិតក្នុងស្ថានភាពនីមួយៗ ហើយត្រូវបានបញ្ចុះតម្លៃមកតម្លៃបច្ចុប្បន្ន។ វិស្វករកម្មវិធីណាដែលធ្វើគំរូករណីអាជីវកម្មសុខភាពឌីជីថលច្រើនឆ្នាំ — ដែលអ្នកប្រើ ឬអ្នកជំងឺផ្លាស់ប្តូររវាងស្ថានភាពដូចជា "ចូលរួម" "ឈប់" ឬ "churn" តាមពេលវេលា — កំពុងសាងសង់រចនាសម្ព័ន្ធដូចគ្នា។

## ហេតុអ្វីបានជាសំខាន់

ការសម្រេចចិត្តបច្ចេកវិទ្យាសុខភាពពិតភាគច្រើនមិនមែនជាការប្រៀបធៀបមួយជំហាននៃថ្លៃដើម និងលទ្ធផលរបស់រយៈពេលតែមួយទេ។ ស្ថានភាពរ៉ាំរ៉ៃវិវត្ត កើតឡើងវិញ ឆ្លើយតបនឹងការព្យាបាល ឬបណ្តាលការស្លាប់ ក្នុងរយៈពេលច្រើនឆ្នាំ — ហើយ[ការវិភាគប្រសិទ្ធភាពថ្លៃដើម](../ការវិភាគប្រសិទ្ធភាពថ្លៃដើម/)រយៈពេលតែមួយមិនអាចតំណាងវាបានទេ។ ការដាក់ស្នើ NICE, ICER និង CADTH សម្រាប់អន្តរាគមន៍ជំងឺរ៉ាំរ៉ៃ ដែលត្រូវបានវាយតម្លៃតាម[ការវាយតម្លៃបច្ចេកវិទ្យាសុខភាព](../ការវាយតម្លៃបច្ចេកវិទ្យាសុខភាព/) ស្ទើរតែតែងតែសាងសង់ជាគំរូក្រុម Markov ដែលមានជើងមេឃពេលវេលាពេញមួយជីវិត ពីព្រោះជម្រើសផ្សេង — ការធ្វើគំរូគ្រប់ផ្លូវអ្នកជំងឺបុគ្គលដែលអាចមាន — មិនអាចដោះស្រាយបានក្នុងមាត្រដ្ឋាន។ គំរូ Markov កម្រិតក្រុមដោះដូរភាពប្រាកដនិយមកម្រិតបុគ្គលខ្លះ (វាមិនអាចតំណាងការចងចាំស្ថានភាពអតីតកាលបានងាយទេ ដូច្នេះហៅថា "Markov"៖ អនាគតអាស្រ័យតែលើស្ថានភាពបច្ចុប្បន្ន) ដើម្បីបានគំរូដែលមានតម្លាភាព អាចសវនកម្មបាន និងលឿនគ្រប់គ្រាន់ដើម្បីរត់រាប់ពាន់ដងក្នុង[ការវិភាគភាពរសើបប្រូបាប៊ីលីស្ទិក](../ការវិភាគភាពរសើបប្រូបាប៊ីលីស្ទិក/)។

## គណិតវិទ្យា

```
One cycle's cohort update (row-vector x transition matrix):
  new_state[j] = sum_i state[i] * transition_matrix[i][j]

One cycle's cost:
  cycle_cost = sum_s state[s] * cost_per_cycle[s]

One cycle's QALYs:
  cycle_qalys = sum_s state[s] * utility[s] * cycle_length_years

Full simulation over `cycles` cycles, discounted at `discount_rate`:
  total_discounted_cost  = sum_{t=0}^{cycles-1} cycle_cost(state_t)  / (1 + discount_rate)^t
  total_discounted_qalys = sum_{t=0}^{cycles-1} cycle_qalys(state_t) / (1 + discount_rate)^t
  where state_0 = initial_distribution, state_{t+1} = advance_cohort(state_t, transition_matrix)
```

ការបញ្ចុះតម្លៃរាល់វដ្តមកតម្លៃបច្ចុប្បន្នប្រើរូបមន្ត[ការបញ្ចុះតម្លៃ និងចំណូលចិត្តពេលវេលា](../ការបញ្ចុះតម្លៃ-និងចំណូលចិត្តពេលវេលា/)ដូចគ្នាបេះបិទ ដោយអនុវត្តវដ្តទល់វដ្តជំនួសឱ្យឆ្នាំទល់ឆ្នាំ។

## ឧទាហរណ៍ដែលបានគណនា

**គ្លីនិក**: គំរូ 2 ស្ថានភាព — `Well` និង `Dead` — ដែល 10% នៃក្រុមស្លាប់រាល់វដ្ត ហើយ `Dead` ជាស្ថានភាពស្រូប (ប្រូបាប៊ីលីតេផ្លាស់ប្តូរខ្លួនឯងរបស់វាគឺ 1.0; ការលុបរង្វិលខ្លួនឯងនោះនឹងធ្វើឱ្យម៉ាស់ក្រុមរលាយបាត់បន្ទាប់ពីមួយវដ្តក្នុង `Dead`)។ ក្រុមចាប់ផ្តើមទាំងស្រុង `Well` ថ្លៃដើម £1,000 ក្នុងមួយវដ្តខណៈ `Well` (£0 នៅពេល `Dead`) ហើយទទួលបាន 0.8 QALY ក្នុងមួយឆ្នាំខណៈ `Well`។ ក្លែងធ្វើ 3 វដ្តប្រចាំឆ្នាំ នៅអត្រាបញ្ចុះតម្លៃ 3.5% របស់ NICE៖

```
Cycle 0: state = [1.00, 0.00] (100% Well)
  cost = £1,000.00, qalys = 0.800, discount factor = 1.000000
  discounted: cost = £1,000.00, qalys = 0.8000

Cycle 1: state = [0.90, 0.10] (90% Well, 10% Dead)
  cost = £900.00, qalys = 0.720, discount factor = 0.966184
  discounted: cost = £869.57, qalys = 0.6957

Cycle 2: state = [0.81, 0.19] (81% Well, 19% Dead)
  cost = £810.00, qalys = 0.648, discount factor = 0.933511
  discounted: cost = £756.14, qalys = 0.6049

Total discounted cost  ≈ £2,625.71
Total discounted QALYs ≈ 2.1006
```

ស្ថានភាពរាល់វដ្តគឺស្ថានភាពវដ្តមុនដែលឆ្លងកាត់ម៉ាទ្រីសផ្លាស់ប្តូរ — 90% នៃ 90% ដែលនៅ `Well` នៅវដ្ត 1 នៅតែ `Well` នៅវដ្ត 2 (0.9 × 0.9 = 0.81) ខណៈ 19% ផ្សេងទៀតបានស្លាប់ហើយ (0.9 × 0.1 + 0.1 × 1.0 = 0.19)។ សូមកត់សម្គាល់ថាក្រុមមិនដែលបង្ហូរ `Well` ទាំងស្រុងទេ៖ ជាមួយអត្រាមរណភាព 10% ក្នុងមួយវដ្តថេរ និងគ្មានការចូលឡើងវិញ ប្រភាគ `Well` ថយចុះតាមធរណីមាត្រ ជាជាងសូន្យនៅចំនួនវដ្តកំណត់ណាមួយ។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

សម្រាប់របៀបដែលគំរូ HTA ច្រើនវដ្តត្រូវបានប្រើក្នុងការវាយតម្លៃពិតប្រាកដ សូមមើល [ការវាយតម្លៃបច្ចេកវិទ្យាសុខភាព](../ការវាយតម្លៃបច្ចេកវិទ្យាសុខភាព/) — ករណីយោងដែលគ្រប់គ្រងអត្រាបញ្ចុះតម្លៃ ប្រភពឧបយោគ និងជើងមេឃពេលវេលា ដែលគំរូ Markov ដែលបានដាក់ស្នើត្រូវប្រើ។

គំរូក្រុម Markov ខាងរចនាសម្ព័ន្ធគឺជាម៉ាស៊ីនស្ថានភាពដែលមានការផ្លាស់ប្តូរប្រូបាប៊ីលីស្ទិក រត់ក្នុងចំនួន tick ថេរ ដោយបញ្ចុះតម្លៃតម្លៃរបស់ tick នីមួយៗ។ រូបរាងដូចគ្នាក្លែងធ្វើការរក្សា/ការផ្លាស់ប្តូរស្ថានភាពរបស់ក្រុមអ្នកប្រើតាមពេលវេលា — សូមមើល [រង្វាស់ DORA](../រង្វាស់-dora/) សម្រាប់កំណែភាពអាចទុកចិត្តបានប្រតិបត្តិការនៃ "ប្រភាគណានៃប្រព័ន្ធស្ថិតក្នុងស្ថានភាពរិចរឹលក្នុងរយៈពេលនេះ ហើយវាមានតម្លៃប៉ុន្មាន"។ ជាក់ស្តែង៖

- **ការធ្វើគំរូការរក្សា/churn** គឺជាគំរូក្រុម Markov ដែលមានស្ថានភាពដូចជា "សកម្ម" "ប្រថុយ" "churned"៖ ម៉ាទ្រីសផ្លាស់ប្តូររាល់ខែថេរ រត់ 12 ឬ 24 វដ្តប្រចាំខែ ប្រាប់អ្នកពីចំនួនអ្នកប្រើសកម្មដែលរំពឹង (និងចំណូល) នៅខែអនាគតណាមួយ ដូចគ្នានឹង `Well`/`Dead` ប្រាប់ពីអ្នកនៅរស់ដែលរំពឹង។
- **សេដ្ឋកិច្ចភាពអាចទុកចិត្តបាន និងឧប្បត្តិហេតុ**: ស្ថានភាពរបស់ប្រព័ន្ធ (ល្អ រិចរឹល ធ្លាក់) អាចត្រូវបានធ្វើគំរូតាមរបៀបដូចគ្នា ជាមួយ "ថ្លៃដើមក្នុងមួយវដ្ត" នៃគ្រោះថ្នាក់ពេលធ្លាក់ដែលកកើតខណៈប្រព័ន្ធស្ថិតក្នុងស្ថានភាពរិចរឹល/ធ្លាក់ — បំប្លែងអាគុយម៉ង់ប្រេកង់ឧប្បត្តិហេតុទៅជាអាគុយម៉ង់ថ្លៃដើមបញ្ចុះតម្លៃ ដែលអាចប្រៀបធៀបនឹងថ្លៃដើមនៃការងារភាពអាចទុកចិត្តបានដែលនឹងផ្លាស់ប្តូរប្រូបាប៊ីលីតេផ្លាស់ប្តូរ។
- **ស្ថានភាពស្រូបជាស្ថានភាពចុងក្រោយ**: `Dead` ក្នុងគំរូគ្លីនិកគឺពិតជា "ការជាវដែលបានលុបចោល" ឬ "ក្រៅបណ្តាញជាអចិន្ត្រៃយ៍" ក្នុងគំរូកម្មវិធី — ទាំងពីរត្រូវការប្រូបាប៊ីលីតេផ្លាស់ប្តូរខ្លួនឯងច្បាស់លាស់ 1.0 បើមិនដូច្នោះការក្លែងធ្វើបាត់បង់ម៉ាស់ដោយស្ងាត់។

## កំហុសដែលត្រូវជៀសវាង

- **ប្រូបាប៊ីលីតេផ្លាស់ប្តូរដែលមិនបូកស្មើ 1 ក្នុងមួយជួរ។** ជួរដែលបូកច្រើន ឬតិចជាង 1 ធ្វើឱ្យក្រុម "លេច" ឬ "កើន" ម៉ាស់ដោយស្ងាត់រាល់វដ្ត — ត្រូវពិនិត្យផលបូកជួរជានិច្ចមុនទុកចិត្តទិន្នផលគំរូ ព្រោះគ្មានអ្វីនៅរចនាសម្ព័ន្ធគំរូខ្លួនឯងបង្ហាញកំហុសទេ។
- **ប្រវែងវដ្តរដុបពេកសម្រាប់ឌីណាមិកពិតនៃជំងឺ។** វដ្តប្រចាំឆ្នាំសម្រាប់ស្ថានភាពដែលផ្លាស់ប្តូរយ៉ាងសំខាន់ក្នុងរយៈពេលប៉ុន្មានសប្តាហ៍ ប៉ាន់ស្មានទាបការផ្លាស់ប្តូរដែលកើតឡើងពាក់កណ្តាលវដ្ត; ជ្រើសរើសប្រវែងវដ្តខ្លីធៀបនឹងល្បឿនដែលដំណើរការដែលធ្វើគំរូពិតជាផ្លាស់ទី។
- **ភ្លេចរង្វិលខ្លួនឯងនៃស្ថានភាពស្រូប។** ស្ថានភាពស្រូប (ការស្លាប់ ការឈប់អចិន្ត្រៃយ៍) ត្រូវការប្រូបាប៊ីលីតេផ្លាស់ប្តូរខ្លួនឯងពិតប្រាកដ 1.0។ ប្រសិនបើលុបវា ម៉ាស់ក្រុមក្នុងស្ថានភាពនោះហួតបន្ទាប់ពីមួយវដ្ត ប៉ាន់ស្មានទាបថ្លៃដើមបូកសរុប ឬការបាត់បង់ QALY។
- **ចាត់ទុកគំរូថាបានសុពលភាពព្រោះវារត់។** គំរូក្រុម Markov ដែលមានប្រូបាប៊ីលីតេផ្លាស់ប្តូរមើលទៅសមហេតុផលនៅតែអាចខុសខាងរចនាសម្ព័ន្ធ (ខ្វះស្ថានភាព អាកប្បកិរិយាស្រូបខុស); ផ្ទៀងផ្ទាត់នឹងស្តង់ដារជំងឺរាតត្បាតដែលដឹង (ឧ. តើការរស់រានមានជីវិត 5 ឆ្នាំដែលបានធ្វើគំរូត្រូវនឹងខ្សែកោងរស់រានមានជីវិតដែលបានបោះពុម្ពឬអត់) មុនទុកចិត្តទិន្នផល។
