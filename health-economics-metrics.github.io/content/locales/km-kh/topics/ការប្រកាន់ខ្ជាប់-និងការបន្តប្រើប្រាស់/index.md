# ការប្រកាន់ខ្ជាប់ និងការបន្តប្រើប្រាស់

ការប្រកាន់ខ្ជាប់ (adherence) គឺជាកម្រិតដែលការប្រើប្រាស់ជាក់ស្តែងស្របតាមការប្រើប្រាស់ដែលបានចេញវេជ្ជបញ្ជា (អាំងតង់ស៊ីតេ); ការបន្តប្រើប្រាស់ (persistence) គឺជារយៈពេលដែលការប្រើប្រាស់បន្តមុនពេលបញ្ឈប់ (រយៈពេល)។ ឱសថស្ថានមានរង្វាស់ស្តង់ដារ — **MPR** និង **PDC** ដោយ ≥80% ជាកម្រិត "ប្រកាន់ខ្ជាប់" តាមទម្លាប់ — ហើយការព្យាបាលឌីជីថលទទួលមរតកទាំងគំនិត និងបញ្ហា៖ ការប្រកាន់ខ្ជាប់គឺជាមេគុណរវាងប្រសិទ្ធភាព និងតម្លៃដែលសម្រេចបាន។

## ហេតុអ្វីបានជាសំខាន់

អ្នកបង់ប្រាក់ (payer) ដំណើរការលើលេខទាំងនេះរួចហើយ៖ PDC ≥80% ចូលក្នុងការវាយតម្លៃផ្កាយ Medicare របស់សហរដ្ឋអាមេរិក ដែលផ្លាស់ប្តូរចំណូលអ្នកបង់ប្រាក់ពិតប្រាកដ — ការប្រកាន់ខ្ជាប់គឺជាហេដ្ឋារចនាសម្ព័ន្ធមានទម្ងន់ផ្នែកហិរញ្ញវត្ថុ មិនមែនជារង្វាស់ទន់ៗទេ។ សម្រាប់ការព្យាបាលឌីជីថល គំរូដដែលៗកើតឡើង៖ ទិន្នន័យ DiGA បង្ហាញបរិមាណវេជ្ជបញ្ជាខ្លាំង ប៉ុន្តែការប្រកាន់ខ្ជាប់ប្រកបដោយនិរន្តរភាពខ្សោយ ហើយការកំណត់តម្លៃ DTx ផ្អែកលើលទ្ធផល (មកដល់អាល្លឺម៉ង់ពីឆ្នាំ 2026) នឹងបង់ប្រាក់តាមលទ្ធផលដែលកំណត់ដោយការប្រកាន់ខ្ជាប់។ ការលើកកម្រិតគំនិតពីការស្រាវជ្រាវសុខភាពឌីជីថល៖ **ការចូលរួមប្រកបដោយប្រសិទ្ធភាព** (effective engagement) — ការចូលរួម *គ្រប់គ្រាន់* ដើម្បីសម្រេចលទ្ធផលដែលបានមានបំណង — និងលទ្ធផលតាមរបស់វា គឺ **កម្រិតថ្នាំអប្បបរមាប្រកបដោយប្រសិទ្ធភាព** ដែលកំណត់តាមបទពិសោធន៍សម្រាប់អន្តរាគមន៍នីមួយៗ ជាជាងសន្មតថា "កាន់តែច្រើនកាន់តែល្អ"។

## គណិតវិទ្យា

```
MPR = Σ days' supply dispensed / days in period × 100   (can exceed 100%;
      overestimates via early refills)
PDC = days covered by supply / days in period × 100     (capped at 100%;
      the conservative, CMS-preferred estimator)
Digital adherence = actual usage events / prescribed usage events × 100
Persistence       = days from initiation to discontinuation
                    (report % persistent at N months; survival methods)

Value gating: realized outcome ≈ efficacy × g(adherence)
  where g is the dose-response function; below the minimum effective
  dose, g ≈ 0 — cost incurred, benefit forfeited
```

## ឧទាហរណ៍ដែលបានគណនា

ផលិតផល CBT ឌីជីថលសម្រាប់ជំងឺគេងមិនលក់ ដែលបានចេញវេជ្ជបញ្ជាជា 6 ម៉ូឌុលក្នុង 6 សប្តាហ៍; ប្រសិទ្ធភាពតាមការសាកល្បង 0.025 QALYs ក្នុងចំណោមអ្នកដែលបំពេញ ≥4 ម៉ូឌុល (កម្រិតថ្នាំអប្បបរមាប្រកបដោយប្រសិទ្ធភាពដែលបានកំណត់តាមបទពិសោធន៍)៖

```
1,000 prescriptions at £250 → £250,000 payer spend
Module completion: ≥4 modules 38%; 1–3 modules 34%; zero modules 28%

QALYs realized = 1,000 × 0.38 × 0.025 = 9.5
Cost per QALY  = 250,000 / 9.5 ≈ £26,300 — marginal at NICE thresholds

Adherence engineering (reminders redesign, session shortening) lifts
≥4-module completion to 50%: 12.5 QALYs → £20,000/QALY. The product
crossed the funding threshold without touching the therapy content.
```

ក្រោមការកំណត់តម្លៃតាមសមត្ថភាពបែប 2026 ការផ្លាស់ប្តូរដូចគ្នាប៉ះពាល់ *ចំណូល* ដោយផ្ទាល់ — វិស្វកម្មការប្រកាន់ខ្ជាប់ក្លាយជាផែនទីបង្ហាញផ្លូវពាណិជ្ជកម្ម។

## ទំនាក់ទំនងជាមួយវិស្វកម្មកម្មវិធី

វាក្យសព្ទពីរមកបញ្ចូលគ្នាលើគំនិតមួយ៖ ការវិភាគកម្មវិធី ([ការធ្វើឱ្យសកម្ម](../ការធ្វើឱ្យសកម្ម-និងការទទួលយក/), [ភាពស្អិត](../រង្វាស់ការចូលរួម/), [ការរក្សា](../ការរក្សា-និងការបោះបង់/)) និងឱសថស្ថានគ្លីនិក (MPR, PDC, ការបន្តប្រើប្រាស់) សុទ្ធតែវាស់ការប៉ះពាល់នឹងអន្តរាគមន៍ — ផ្គូផ្គងព្រឹត្តិការណ៍ផលិតផលរបស់អ្នកទៅនឹងវាក្យសព្ទគ្លីនិក នោះអ្នកបង់ប្រាក់អាចអានផ្ទាំងគ្រប់គ្រងរបស់អ្នកបាន។ វិស្វកម្មជាម្ចាស់នៃដងថ្លឹងការប្រកាន់ខ្ជាប់៖ តក្កវិជ្ជាការរំលឹក (ការរំលឹកប្រចាំថ្ងៃដ៏ល្ងង់ បង្ហាត់ឱ្យបដិសេធ; ពេលវេលាបត់បែនមិនបង្ហាត់បែបនោះទេ) ថ្លៃដើមនៃសម័យប្រជុំ (ម៉ូឌុល 20 នាទីបញ្ចប់តិចជាង 3 ម៉ូឌុល 7 នាទី) និងទិន្នន័យផ្ទាល់នៃការកកស្ទះដែលកំណត់ទីតាំង *កន្លែងណា* ក្នុងពិធីការដែលអ្នកប្រើបោះបង់។ ដាក់ឧបករណ៍វាស់ការឆ្លើយតបតាមកម្រិតថ្នាំតាំងពីថ្ងៃដំបូង — ការវិភាគកម្រិតថ្នាំអប្បបរមាប្រកបដោយប្រសិទ្ធភាពដែលកំណត់គំរូសេដ្ឋកិច្ចទាំងមូលត្រូវការទិន្នន័យការប្រើប្រាស់ភ្ជាប់នឹងលទ្ធផល ដែលមានតែផលិតផលទេដែលអាចប្រមូលបាន។

## កំហុសដែលត្រូវជៀសវាង

- **ការច្រឡំ MPR/PDC**៖ MPR ធ្វើឱ្យប៉ោង; ចង្អុលបង្ហាញថាប្រើអ្នកប៉ាន់ស្មានមួយណា ហើយប្រើ PDC សម្រាប់អ្វីដែលប្រឈមមុខនឹងអ្នកបង់ប្រាក់។
- **ការប្រកាន់ខ្ជាប់នឹងរង្វាស់ មិនមែនការព្យាបាល**៖ ការបើកកម្មវិធីត្រូវបានរាប់ជាកម្រិតថ្នាំ (សូមមើល[រង្វាស់ការចូលរួម](../រង្វាស់ការចូលរួម/))។
- **គោលដៅចូលរួម "កាន់តែច្រើនកាន់តែល្អ"** ដែលអន្តរាគមន៍មានកម្រិតថ្នាំកំណត់ — ការបញ្ចប់ការសិក្សាគឺជាជោគជ័យ ការប្រើប្រាស់ជាអចិន្ត្រៃយ៍មិនមែនទេ។
- **ការអះអាងប្រសិទ្ធភាពផ្អែកលើអ្នករួចជីវិត**៖ លទ្ធផលក្នុងចំណោមអ្នកប្រកាន់ខ្ជាប់រួមមានឥទ្ធិពលជ្រើសរើស (អ្នកប្រកាន់ខ្ជាប់ខុសពីអ្នកដទៃ); ការប៉ាន់ស្មានមូលហេតុដោយស្មោះត្រង់ត្រូវការការចាប់ឆ្នោត ឬការកែតម្រូវដោយប្រុងប្រយ័ត្ន។
