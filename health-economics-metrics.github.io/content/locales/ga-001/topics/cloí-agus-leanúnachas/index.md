# Cloí agus leanúnachas

Is éard é cloí an méid a mheaitseálann an úsáid iarbhír an úsáid a ordaíodh (déine); is éard é leanúnachas cá fhad a leanann an úsáid sula scoirtear di (fad). Tá bearta caighdeánaithe ag an bhfarmaclann — **MPR** agus **PDC**, agus ≥80% mar an tairseach choinbhinsiúnach “cloíteach” — agus faigheann teiripe digití an dá choincheap agus an fhadhb araon: is é an cloí an t-iolraitheoir idir éifeachtacht agus luach réadaithe.

## Cén fáth a bhfuil tábhacht leis

Oibríonn íocóirí cheana féin ar na huimhreacha seo: cothaíonn PDC ≥80% Rátálacha Réalta Medicare SAM, a bhogann ioncam íocóra fíor — is bonneagar ualaithe go hairgeadúil é an cloí, ní méadrach bog. I gcás teiripe digití, athfhillean an patrún: léiríonn sonraí DiGA méideanna oidis láidre ach cloí inbhuanaithe lag, agus íocfaidh praghsáil DTx bunaithe ar thorthaí (ag teacht sa Ghearmáin ó 2026) ar thorthaí atá ceangailte le cloí. An t-uasghrádú coincheapúil ó thaighde sláinte digití: **rannpháirtíocht éifeachtach** — rannpháirtíocht *leordhóthanach* chun an toradh beartaithe a bhaint amach — agus a corollary, an **dáileog éifeachtach íosta**, a bhunaítear go heimpíreach do gach idirghabháil seachas glacadh leis gurb é “níos mó” an freagra.

## An mhatamaitic

```
MPR = Σ laethanta soláthair a dháiltear / laethanta sa tréimhse × 100   (is féidir
      go sáródh sé 100%; sármeastar é trí athlíonadh luath)
PDC = laethanta clúdaithe ag soláthar / laethanta sa tréimhse × 100     (teorainn
      100%; an t-eisíocóir coimeádach, rogha CMS)
Cloí digiteach = imeachtaí úsáide iarbhír / imeachtaí úsáide ordaithe × 100
Leanúnachas    = laethanta ó thús go scor
                 (tuairiscigh % leanúnach ag N míonna; modhanna marthanais)

Geatáil luacha: toradh réadaithe ≈ éifeachtacht × g(cloí)
  áit arb é g an fheidhm dáileog-freagra; faoi bhun na dáileoige
  éifeachtaí íosta, g ≈ 0 — tabhaítear costas, caillfear sochar
```

## Sampla oibrithe

Táirge CBT digiteach don insomnia, ordaithe mar 6 mhodúl thar 6 seachtaine; éifeachtacht trialach 0.025 QALY i measc na ndaoine a chríochnaigh ≥4 mhodúl (an dáileog éifeachtach íosta a bunaíodh go heimpíreach):

```
1,000 oideas ag £250 → £250,000 caiteachas íocóra
Críochnú modúl: ≥4 mhodúl 38%; 1–3 modúl 34%; nialas modúl 28%

QALYanna réadaithe = 1,000 × 0.38 × 0.025 = 9.5
Costas in aghaidh an QALY = 250,000 / 9.5 ≈ £26,300 — ar an imeall ag tairseacha NICE

Ardaíonn innealtóireacht cloí (athdhearadh meabhrúchán, seisiúin níos giorra)
críochnú ≥4 mhodúl go 50%: 12.5 QALY → £20,000/QALY. Chuaigh an táirge
thar tairseach an mhaoinithe gan teagmháil le hábhar na teiripe.
```

Faoi phraghsáil feidhmíochta de stíl 2026, bogann an t-athrú céanna an *t-ioncam* go díreach — éiríonn innealtóireacht cloí ina treochlár tráchtála.

## An nasc le hinnealtóireacht bogearraí

Tagann dhá fhoclóir le chéile ar choincheap amháin: tomhaiseann anailísíocht bogearraí ([gníomhachtú](../gníomhachtú-agus-glacadh/), [greamaitheacht](../méadracha-rannpháirtíochta/), [coinneáil](../coinneáil-agus-scoite/)) agus cógaslann chliniciúil (MPR, PDC, leanúnachas) araon nochtadh d’idirghabháil — mapáil d’imeachtaí táirge ar an bhfoclóir cliniciúil agus is féidir le híocóirí do dhaiseanna a léamh. Is leis an innealtóireacht na luamháin cloí: loighic meabhrúchán (traenálann pingeanna laethúla neamhchliste diúltú; ní dhéanann am oiriúnaitheach), costas seisiúin (críochnaítear modúl 20 nóiméad níos lú ná 3 × 7 nóiméad), agus telemeitreacht frithchuimilte a aimsíonn *cén áit* sa phrótacal a thiteann úsáideoirí as. Cuir uirlisí dáileog-freagra i bhfeidhm ón gcéad lá — teastaíonn sonraí úsáide-nasctha-le-toradh ón anailís dáileoige éifeachtaí íosta a gheatálann an tsamhail eacnamaíoch ar fad, agus ní féidir ach leis an táirge iad a bhailiú.

## Gaistí

- **Mearbhall MPR/PDC**: sármheasann MPR; luaigh cén t-eisíocóir agus úsáid PDC d’aon rud atá os comhair íocóra.
- **Cloí leis an méadrach, ní leis an teiripe**: oscailtí a áirítear mar dháileoga (féach [méadracha rannpháirtíochta](../méadracha-rannpháirtíochta/)).
- **Spriocanna rannpháirtíochta “is fearr níos mó”** nuair a bhfuil dáileog theoranta ag an idirghabháil — is rath é céimniú, ní rath é úsáid shíoraí.
- **Éilimh éifeachtachta bunaithe ar mharthanóirí**: cuimsíonn torthaí i measc na gcloíteach éifeachtaí roghnúcháin (tá daoine cloíteacha difriúil); teastaíonn randamú nó coigeartú cúramach don mheastachán cúiseach macánta.
