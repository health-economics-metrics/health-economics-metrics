# Ráta nár fhreastail (DNA)

Is é an ráta DNA an céatadán de choinní áirithe nach bhfreastalaíonn an t-othar orthu ná nach gcuireann sé ar ceal. Íoctar as an gcliniceoir, an seomra, agus an sliotán; ní tharlaíonn aon rud. Is é an méadrach dramhaíola is íonaí sa chúram sláinte — agus ceann de na cinn is inleigheasta ó thaobh bogearraí.

## Cén fáth a bhfuil tábhacht leis

Figiúirí NHS England (2019): sáraíonn coinní dochtúra teaghlaigh caillte 15 milliún/bliain ag ~£30 an ceann — os cionn **£216M/bliain** — agus ritheann DNAnna eachtracha ospidéil ~8M/bliain (~6.4% de choinní) ag meán ~**£160** in aghaidh an tsliotáin chaillte. Toisc gur pinginí costas imeallach meabhrúcháin agus gur sliotán cliniciúil lán-fhoirne an luach aisghafa, tá cuid de na huimhríochtaí ROI is fearr sa tsláinte dhigiteach ag laghdú DNA, rud is cúis gurbh iad meabhrúcháin SMS, athchlárú éasca, agus ró-chlárú tuartha ina measc na chéad bhuaite sláinte digití cruthaithe.

## An mhatamaitic

```
Ráta DNA = DNAnna / coinní áirithe × 100

Luach laghdaithe = coinní × ΔRáta DNA × luach in aghaidh an tsliotáin aisghafa

luach in aghaidh an tsliotáin aisghafa: athlíontar an sliotán (luach gníomhaíochta / laghdú
liosta feithimh) nó ní athlíontar (am foirne in-athúsáidte go páirteach) — tá an mheicníocht
tábhachtach, mar a tharlaíonn le bed-days-saved.md.
```

## Sampla oibrithe

Roinn othar eachtrach: 200,000 coinne/bliain, ráta DNA 8%. Laghdaíonn seirbhís meabhrúcháin-móide-athchláraithe (SMS le hathchlárú aon-bhuille, eolas iompair, formáidí inrochtana) DNAnna go 5.5%.

```
Sliotáin aisghafa = 200,000 × 0.025 = 5,000/bliain
Athlíonta ón liosta feithimh ag ~£160 meánluach othar eachtrach:
  5,000 × £160 = £800,000/bliain de ghníomhaíocht aisghafa
Costas seirbhíse: 200,000 × £0.40 = £80,000/bliain

Toradh ≈ 10:1, móide 5,000 othar liosta feithimh feicthe níos luaithe
(féach waiting-list-impact.md agus referral-to-treatment.md).
```

Tá méid na héifeachta (2.5 pointe) réalaíoch: léiríonn RCTanna meabhrúcháin go seasta laghdú coibhneasta DNA 25–40%.

## An nasc le hinnealtóireacht bogearraí

- **Is fadhb chóras sceidealaithe í seo**: meabhrúcháin, athchlárú féinseirbhíse, uathlíonadh liosta feithimh ó chealuithe, agus samhlacha tuartha neamh-fhreastail a thiomáineann ró-chlárú spriocdhírithe. Is gnáth-innealtóireacht bogearraí gach ceann acu le cás eacnamaíoch thar a bheith géar.
- **An analach innealtóireachta**: neamh-fhreastail do chumas curtha in áirithe — sliotáin CI áirithe-ach-díomhaoin, cumas scamall curtha in áirithe, seomraí cruinnithe, painéil agallaimh. Aistríonn an eacnamaíocht: aisghabhann bogadh saor uathoibrithe (nó scaoileadh uathoibrithe áirithintí gan úsáid) cumas daor tiomanta.
- **Réamhamharc eitice tuartha**: ionchódaíonn samhlacha neamh-fhreastail a oiliúnadh ar shonraí freastail díothacht agus bacainní rochtana; má úsáidtear iad chun daoine dóchúla nach bhfreastalóidh a *dhíthosaíocht* méadaíonn sé éagothroime, má úsáidtear iad chun freastal a *thacú* (cabhair iompair, malairtí teileafóin) laghdaíonn sé í. Féach [sroicheadh agus cothromas](../sroicheadh-agus-cothromaíocht/).

## Gaistí

- **Cealuithe-agus-athchláraithe a chomhaireamh mar luach aisghafa faoi dhó.**
- **Sliotáin aisghafa nach n-athlíontar a luacháil** — tá sliotán folamh le meabhrúchán seolta folamh fós.
- **DNA a ruaigeadh go nialas**: is othair le fíor-bhacainní iad na pointí deiridh DNA; ní ghearrann cur chuige pionósach (scaoileadh tar éis N DNA) an méadrach ach trí na hothair a thréigean.
