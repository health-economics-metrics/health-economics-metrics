# ימי מיטה שנחסכו

יום מיטה הוא מטופל אחד שתופס מיטת בית חולים אחת ליום אחד. "ימי מיטה שנחסכו" — באמצעות שחרור מוקדם, מניעת אשפוז או מחלקות וירטואליות — היא התועלת הראשית בתיקים עסקיים דיגיטליים של ה-NHS, והנפוצה ביותר להערכת-יתר.

## למה זה חשוב

מיטות הן האילוץ המחייב של טיפול חריף: כשהמיטות מתמלאות, ניתוחים אלקטיביים מבוטלים, אמבולנסים ממתינים בתור ומיון מתגודד. התערבויות ששוחררות ימי מיטה נושאות אפוא ערך אמיתי — אך *סוג* הערך תלוי כולו במה שקורה למיטה שהתפנתה. מנהלי כספים למדו להפחית משמעותית טענות נאיביות של ימי מיטה; דיוק בחשבון הזה הוא מבחן אמינות.

## המתמטיקה

```
Bed days saved = patients affected × Δ length of stay (or admissions avoided × avg LOS)

Value depends on the use of the freed capacity:
  refilled with elective activity → value = activity income or waiting-list benefit
  ward closed / flexed down      → value = staffing + running cost released (cash)
  absorbed as slack              → value ≈ marginal (hotel) cost only, £50–£150/day
```

העלות הממוצעת המלאה של יום מיטה חריף מצוטטת לעיתים קרובות ב-£400 ומעלה (באוסף העלויות הלאומי היסטורית ~£350 לימי מיטה עודפים) — אך ראו [עלות שולית מול ממוצעת](../עלות-שולית-מול-עלות-ממוצעת/): הממוצע כמעט אף פעם אינו החיסכון.

## דוגמה מחושבת

"מחלקה וירטואלית" עם ניטור מרחוק מאפשרת ל-600 מטופלים בשנה ללכת הביתה יומיים מוקדם: 1,200 ימי מיטה שנחסכו.

- **טענה נאיבית**: 1,200 × £400 = £480,000. שגויה, אלא אם מחלקה נסגרת.
- **טענה כנה**: הנאמנות ממלאת את המיטות בחולי אורתופדיה אלקטיבית. 1,200 ימי מיטה ÷ שהייה ממוצעת של 3 ימים = 400 אשפוזים אלקטיביים נוספים ב-~£6,000 הכנסה כל אחד תחת תשלום מבוסס פעילות = **£2.4M של פעילות ממומנת נוספת** (בניכוי העלות השולית לטיפול באותם מטופלים), *בנוסף* ל-400 מטופלים שירדו מרשימת ההמתנה. עלות ההפעלה של המחלקה הווירטואלית (£350,000) מקוזזת מזה.

קיבולת ששוחררה ו*נעשה בה שימוש חוזר* שווה לעיתים קרובות יותר מהטענה הנאיבית במזומן — אך זה סוג אחר של ערך וחייבים לסמן אותו ככזה ([משחרר מזומן לעומת שאינו משחרר מזומן](../חיסכון-משחרר-מזומן-לעומת-חיסכון-שאינו-משחרר-מזומן/)).

## הקשר להנדסת תוכנה

"ימי שרת שנחסכו" מתנהגים באופן זהה. הוצאה משימוש של סביבות פעילות תמיד משחררת מזומן רק כשמופעים מסתיימים או הזמנות פוקעות; קיבולת שנספגת חזרה למאגר שווה את עלותה השולית (~0 בהוצאה מחויבת). הדיסציפלינה המקבילה: לכל חיסכון נטען, נקבו את ה*מנגנון* — הופסק, מולא בעבודה בעלת ערך, או התאדה. תוכנה שמקצרת שהייה בבית חולים (תיאום שחרור, ניטור מרחוק, קיצור זמני אבחון) צריכה למדל את שלושת התרחישים ולתת לנאמנות לבחור לכל מחלקה.

## מלכודות נפוצות

- **הערכה לפי עלות ממוצעת** של קיבולת שולית — הטעות הקלאסית.
- **ספירה כפולה**: ימי מיטה שנחסכו *וגם* אשפוזים שנמנעו *וגם* צמצום רשימת המתנה מאותה מיטה שהתפנתה.
- **הנחה שהימים שנחסכו הם הימים היקרים**: הימים שנחסכים בסוף האשפוז הם הזולים ביותר (חומרה נמוכה).
