# דומיננטיות וגבול היעילות

אפשרות היא **נשלטת** אם אפשרות אחרת עולה פחות *וגם* מספקת יותר. **גבול היעילות** הוא מה שנשאר לאחר סילוק אפשרויות נשלטות: קבוצת הבחירות שבהן קבלת יותר דורשת תשלום יותר.

## למה זה חשוב

לפני כל ויכוח על ספים או תקציבים, הערכת טכנולוגיות בריאות מסלקת קודם אפשרויות שאיש לא צריך לבחור לעולם. שרטוט כל אפשרות במישור עלות מול אפקט וציור הגבול הוא תרגיל של חמש דקות שהורג באופן שגרתי מחצית מרשימה קצרה. השוואות מצטברות ([ICERs](../יחס-עלות-אפקטיביות-מצטבר/)) מחושבות אז רק *לאורך הגבול*, כל אפשרות מול הזולה הבאה שאינה נשלטת — לעולם לא מול "אל תעשה דבר" כשקיימות אפשרויות ביניים טובות יותר.

## המתמטיקה

```
Strict dominance:   A dominates B if Cost_A ≤ Cost_B and Effect_A ≥ Effect_B
                    (with at least one strict inequality)

Extended dominance: B is ruled out if a mix of A and C achieves more effect
                    per pound — detected when ICERs decrease as you move up
                    the frontier. Valid frontier ICERs must be increasing.
```

הליך: מיינו אפשרויות לפי אפקט; הסירו נשלטות לחלוטין; חשבו ICER זוגיים בין שכנות; הסירו כל אפשרות שה-ICER שלה עולה על זה של האפשרות הבאה היעילה יותר (דומיננטיות מורחבת); חזרו עד שה-ICER עולים באופן מונוטוני.

## דוגמה מחושבת

ארבע אפשרויות להפחתת תורים שהוחמצו (אפקט = תורים שהוחזרו בשנה):

```
Option          Cost/yr    Recovered
Do nothing      £0         0
SMS reminders   £20,000    2,000
Phone calls     £120,000   2,200
SMS + AI triage £90,000    3,500
```

שיחות טלפון **נשלטות לחלוטין** על ידי SMS + מיון בינה מלאכותית (עולות יותר, מחזירות פחות). הגבול: כלום → SMS → SMS + בינה מלאכותית.

```
ICER(SMS vs nothing)   = 20,000 / 2,000  = £10 per appointment recovered
ICER(SMS+AI vs SMS)    = (90,000 − 20,000) / (3,500 − 2,000) = £46.67 per appointment
```

ICER עולים → גבול תקף. ב-~£160 שנחסכו לכל תור בית חולים שהוחזר (ראו [שיעור אי-הגעה](../שיעור-אי-הגעה/)), שני צעדי הגבול כדאי לנקוט; הצעת מוקד הטלפונים לעולם לא הייתה צריכה להגיע לוועדה.

## הקשר להנדסת תוכנה

בנו את אותו תרשים לכל החלטת כלים: עלות בשנה על ציר אחד, תוצאה נמדדת (שעות שנחסכו, תקריות שנמנעו, פריסות שאפשרו) על השני. נקודות למעלה-ושמאלה מהגבול מסולקות לפני שמישהו מתווכח על תקציב. זה ממסגר מחדש בחירת ספק מוויכוחי רשימת תכונות ל"אתה נשלט; הפגישה נגמרה". הוא גם חושף את דפוס הארגונים הנפוץ של קניית האפשרות היקרה ביותר עבור רווח שולי — לגיטימי רק אם המחיר המצטבר ליחידה מצטברת הוא כזה שהארגון היה משלם ביודעין.

## מלכודות נפוצות

- **השוואת הכול לקו הבסיס** במקום לאפשרות הבאה בגבול — מחמיא לאפשרויות יקרות בהסתרת כמעט-שקולות זולות יותר.
- **ציוני אפקט חד-ממדיים** שמסתירים את מה שחשוב; אם שתי תוצאות נחשבות, או שלבו אותן באופן הניתן להגנה (ראו [ניתוח עלות-תועלתנות](../ניתוח-עלות-תועלתנות/)) או הציגו שני גבולות.
- **שכחת אי-ודאות**: אפשרויות ליד הגבול עלולות להחליף מקומות תחת [ניתוח רגישות](../ניתוח-רגישות/).
