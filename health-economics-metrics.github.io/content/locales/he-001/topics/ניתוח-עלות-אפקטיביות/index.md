# ניתוח עלות-אפקטיביות (CEA)

CEA משווה את עלויות ההתערבויות החלופיות מול תוצאה אחת הנמדדת ב**יחידות טבעיות** — שנות חיים, מקרים שזוהו, אשפוזים שנמנעו, מ"מ כספית של הורדת לחץ דם. תוצרו הוא עלות ליחידת תוצאה.

## למה זה חשוב

CEA הוא סוס העבודה של ההשוואה כשכל האפשרויות מכוונות לאותה תוצאה. הוא עונה "איזו מבין הדרכים להשגת X היא השימוש הטוב ביותר בכסף?" — אך *לא* "האם X בכלל שווה להשיג?" (לזה נדרש [ניתוח עלות-תועלת](../ניתוח-עלות-תועלת/)) ו*לא* "איך X משתווה לעדיפויות לא קשורות?" (לזה נדרשים [ניתוח עלות-תועלתנות](../ניתוח-עלות-תועלתנות/) ותוצאה גנרית כמו QALY).

## המתמטיקה

סטטיסטיקת ההשוואה היא ה-[ICER](../יחס-עלות-אפקטיביות-מצטבר/) ביחידות טבעיות:

```
ICER = (Cost_A − Cost_B) / (Effect_A − Effect_B)
     = £ per additional case detected / admission avoided / etc.
```

הליך: הגדירו את יחידת התוצאה; תמחרו כל אפשרות מאותה [נקודת מבט](../נקודת-מבט-הניתוח/) על פני אותו [אופק זמן](../אופק-זמן/); סלקו אפשרויות נשלטות ([גבול היעילות](../דומיננטיות-וגבול-היעילות/)); חשבו יחסים מצטברים לאורך הגבול.

## דוגמה מחושבת

שלוש דרכים לאתר פרפור פרוזדורים שלא אובחן באוכלוסייה של 100,000:

```
Option                    Cost        Cases found
Opportunistic pulse checks £150,000       300
Pharmacy screening events  £400,000       520
Wearable-based screening   £900,000       610

ICER pharmacy vs pulse:  (400k−150k)/(520−300) = £1,136 per additional case
ICER wearable vs pharmacy:(900k−400k)/(610−520) = £5,556 per additional case
```

האם £5,556 למקרה נוסף "שווה את זה" תלוי בערכו של מקרה שנמצא (מניעת שבץ במורד הזרם) — CEA מדרג את האפשרויות אך החלטת האימוץ דורשת את ההערכה החיצונית הזו. שימו לב שהעלות *הממוצעת* למקרה של אפשרות הציוד הלביש (900k/610 = £1,475) נראית בסדר; ה-£5,556 *המצטבר* הוא המספר הכן להחלטת ההרחבה.

## הקשר להנדסת תוכנה

CEA הוא התבנית הנכונה בכל פעם שלאפשרויות יש תוצאה משותפת אחת: עלות לבדיקה חלשה שסולקה על פני שלוש גישות תיקון; עלות לתקרית שנמנעה על פני ספקי observability; עלות לפריסה מוצלחת על פני ארכיטקטורות CI. הדיסציפלינה שהוא כופה — יחידת תוצאה מוצהרת אחת, יחסים מצטברים (לא ממוצעים), אפשרויות נשלטות מסולקות קודם — הורגת את רוב השוואות הספקים הגרועות לפני שדיון התמחור מתחיל.

## מלכודות נפוצות

- **השוואת אפשרויות עם תוצאות שונות** ("מקרים שנמצאו" מול "שביעות רצון") ב-CEA אחד — לזה נדרש [ניתוח עלות-השלכות](../ניתוח-עלות-השלכות/) או תוצאה גנרית.
- **יחסי עלות-אפקטיביות ממוצעים** המוצגים במקום שנדרשים מצטברים (דוגמת הלביש לעיל).
- **יחידות תוצאה שנבחרו להחנפה**: "התראות שנוצרו" הוא פלט, לא תוצאה; התעקשו על יחידות שנושאות ערך.
