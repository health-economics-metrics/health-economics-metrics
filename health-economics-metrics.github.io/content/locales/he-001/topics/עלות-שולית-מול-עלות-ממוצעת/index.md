# עלות שולית מול עלות ממוצעת

עלות ממוצעת היא העלות הכוללת מחולקת ביחידות שיוצרו. עלות שולית היא העלות של ייצור יחידה *נוספת* אחת. החלטות צריכות להתקבל לפי עלות שולית — אך עלויות יחידה מפורסמות הן כמעט תמיד ממוצעים.

## למה זה חשוב

השגיאה הנפוצה ביותר בתיקים עסקיים של בריאות דיגיטלית היא הערכת משאב שנחסך לפי עלותו ה**ממוצעת** כשהחיסכון האמיתי הוא העלות ה**שולית**. ליום מיטה בבית חולים יש עלות ממוצעת (נטמעת מלאה) של £400+, אך שחרור יום מיטה אחד אינו חוסך £400 — הבניין, החימום ורוב עלויות כוח האדם נמשכים. המזומן ששוחרר בפועל עשוי להיות £50–£150 אלא אם מתפנות מספיק מיטות כדי לסגור מחלקה.

## המתמטיקה

```
Average cost:  AC = TC / Q
Marginal cost: MC = dTC/dQ   (cost of one more/one fewer unit)

TC = total cost, Q = quantity
```

עלויות קבועות גורמות ל-MC < AC להפחתות קיבולת, ו-MC יכולה להתקרב לאפס כשקיימת קיבולת פנויה. טענות חיסכון צריכות להשתמש ב:

```
True saving = ΔQ × MC          (small changes)
True saving = step change in TC (large changes that cross a capacity threshold, e.g. closing a ward)
```

## דוגמה מחושבת

התוכנה שלכם מקצרת את אורך השהייה הממוצע, ומשחררת 1,000 ימי מיטה בשנה בנאמנות.

- **טענה נאיבית**: 1,000 × £400 עלות ממוצעת = **£400,000 נחסכו**. שגוי.
- **טענה שולית**: עלות משתנה ליום מיטה (אוכל, כביסה, חומרים מתכלים, גמישות סיעודית מסוימת) ≈ £120. חיסכון = 1,000 × £120 = **£120,000**, *בנוסף* לערך הקיבולת ששוחררה אם המיטות מתמלאות מחדש בחולים אלקטיביים ממתינים (הכנסה תחת תשלום מבוסס פעילות, או צמצום רשימת המתנה).
- **טענת שינוי מדרגה**: אם הנאמנות משחררת 7,300 ימי מיטה בשנה (מחלקה של 20 מיטות) היא יכולה באמת לסגור את המחלקה: כוח אדם + הפעלה ≈ £1.5 מיליון בשנה של מזומן אמיתי. כעת חשבון העלות הממוצעת קרוב יותר לאמת.

אותה התערבות, שלושה מספרים בני-הגנה, תלוי אם השינוי חוצה מדרגת קיבולת.

## הקשר להנדסת תוכנה

כלכלת ענן היא טריטוריה מקורית של עלות שולית:

- העלות השולית של הרצת CI אחת נוספת על קיבולת שכבר הוזמנה היא ≈ £0, בעוד העלות הממוצעת להרצה (הוצאת פלטפורמה כוללת ÷ הרצות) עשויה להיות לירות. מערכות חיוב-חוזר שמחייבות עלות ממוצעת מניעות צוותים לנצל פחות קיבולת משותפת שהיא למעשה חופשית בשוליים.
- לעומת זאת, "חסכנו 30% מהמחשוב" משחרר מזומן רק אם מופעים באמת מסתיימים או הזמנות מצטמצמות — גרסת התוכנה של מלכודת יום המיטה. ראו [חיסכון משחרר מזומן לעומת שאינו משחרר מזומן](../חיסכון-משחרר-מזומן-לעומת-חיסכון-שאינו-משחרר-מזומן/).

## מלכודות נפוצות

- **הערכת קיבולת לפי עלות ממוצעת** והצגתה כמזומן (הקלאסיקה).
- **הנחה שעלות שולית קבועה.** היא קופצת בגבולות קיבולת (סגירת מחלקות, דרגות רישוי, התחייבויות מופעים שמורים).
- **שימוש בעלות שולית להחלטות הרחבה אך בממוצעת להתכווצות** באותו תיק — בחרו לפי ההחלטה בפועל.
