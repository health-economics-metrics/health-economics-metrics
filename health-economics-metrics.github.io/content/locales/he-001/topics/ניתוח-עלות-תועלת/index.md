# ניתוח עלות-תועלת (CBA)

CBA מעריך בכסף גם עלויות *וגם* תוצאות. זהו סוג הניתוח היחיד שיכול לענות "האם זה בכלל שווה לעשות?" — ולא רק "איזו אפשרות הטובה ביותר?" — כי תועלות שהומרו לכסף ניתנות להשוואה ישירה לעלויות.

## למה זה חשוב

CBA הוא התקן של **Green Book** של משרד האוצר הבריטי להערכת כל הוצאה ציבורית, כולל בריאות כשאפשר להמיר תוצאות לכסף. בעוד ש-[CEA](../ניתוח-עלות-אפקטיביות/)/[CUA](../ניתוח-עלות-תועלתנות/) נעצרים ב"עלות ליחידת בריאות", CBA מתמחר את הבריאות עצמה (QALY × ערך סף) ואת כל השאר — זמן, נסיעות, פחמן — ומדווח על נתון נטו אחד. כל תיק עסקי דיגיטלי מלא של ה-NHS מכיל תיק כלכלי בצורת CBA.

## המתמטיקה

```
NPV (net present social value) = Σ_t [ (Benefits_t − Costs_t) / (1 + r)^t ]
BCR (benefit-cost ratio)       = PV(benefits) / PV(costs)

Adopt if NPV > 0 (equivalently BCR > 1); rank by NPV, not BCR.
r = 3.5% (Green Book social time preference rate)
```

השפעות בריאותיות יכולות להיכנס כשהן מומרות לכסף כ-QALY × λ (ראו [ספי נכונות לשלם](../ספי-נכונות-לשלם/)). ה-Green Book גם מחייב **התאמות הטיית אופטימיות** — העלאת אומדני עלות והורדת תועלות באחוזים מבוססי ראיות, כי הערכות ורודות באופן שיטתי.

## דוגמה מחושבת

מערכת הפניות אלקטרונית, אופק 5 שנים, היוון 3.5%:

```
Costs:    build £1.2M (year 0), run £300k/yr (years 1–5)
Benefits: admin savings £250k/yr, avoided duplicate diagnostics £280k/yr,
          patient time saved 40,000 hrs/yr × £15 = £600k/yr → £1,130k/yr

PV costs    = 1,200k + 300k × 4.515 (annuity factor) = £2,555k
PV benefits = 1,130k × 4.515                          = £5,102k

NPV = 5,102 − 2,555 = +£2,547k     BCR = 2.0
```

יישמו הטיית אופטימיות של Green Book (נניח +40% על עלות הבנייה, −20% על תועלות): PV עלויות ≈ £3,035k, PV תועלות ≈ £4,082k, NPV ≈ **+£1,047k** — עדיין חיובי, וזו מטרת ההתאמה: תיקים צריכים לשרוד את האופטימיות של עצמם.

## הקשר להנדסת תוכנה

תיקים עסקיים הנדסיים הם CBA לא פורמליים. שדרוגי ה-Green Book ששווה לגנוב:

- **הטיית אופטימיות כתוספת סטנדרטית** — מהנדסים מעריכים בחסר עלות הגירה באמינות כמו שמשרדי ממשלה מעריכים בחסר עלות תשתית; יישמו תוספת מוצהרת במקום להעמיד פנים שהפעם שונה.
- **המירו לכסף את התועלת הדומיננטית ביושר או לא בכלל** — זמן מטופלים/משתמשים מומר בתעריפים הניתנים להגנה; "ערך מותג" לא.
- **NPV מדרג, BCR לא**: פרויקט זעיר עם BCR 5 יכול להיות פחות חשוב מגדול עם BCR 1.6.

## מלכודות נפוצות

- **המרה לכסף של מה שאינו ניתן להמרה** כדי לנפח תועלות (מורל, "יישור אסטרטגי") — השאירו אותם איכותיים, לפי [ניתוח עלות-השלכות](../ניתוח-עלות-השלכות/).
- **ספירת העברות כתועלות**: כסף שעובר בין גופים ציבוריים מתאפס ב[נקודת המבט](../נקודת-מבט-הניתוח/) החברתית.
- **אין עובדה נגדית**: תועלות נמדדות מול אפשרות המינימום, לא מול אפס.
