# ערך צפוי של מידע מדגמי (EVSI)

EVSI הוא ערכו של *מחקר ספציפי מוצע* — תכנון נתון, גודל מדגם נתון — לפני שהוא מורץ, בניגוד ל-[EVPI](../ערך-צפוי-של-מידע-מושלם/), שמתמחר ביטול מוחלט של כל אי-הוודאות. EVSI עונה על השאלה שמממן מחקר מתמודד איתה בפועל: "האם הניסוי *הזה*, בגודל *הזה*, שווה את עלותו?"

## למה זה חשוב

EVPI אומר לכם את התקרה לכמה כל מחקר יכול להיות שווה; הוא לעולם אינו אומר אם הניסוי שלפניכם עובר את הרף. מממן מחקר לאומי שבוחר בין פיילוט של 50 מטופלים לניסוי מכריע של 500 מטופלים צריך לדעת כמה שווה *כל תכנון ספציפי*, לא רק את ערך כל-יודעות. EVSI מספק את המספר הזה, ומכיוון שהוא גדל עם גודל המדגם, הוא מאפשר למממן למצוא את גודל המדגם שממקסם תועלת נטו צפויה במקום לנחש.

זו גם הסיבה ש-EVSI תמיד קטן או שווה ל-EVPI: מדגם סופי יכול רק לפתור חלקית אי-ודאות, ומחקר שנראה שווה יותר ממידע מושלם הוא סימן שהחישוב שגוי, לא תוצאה אמיתית.

## המתמטיקה

```
General:
EVSI(n) = E_data[ max_d E_θ|data[NB(d,θ)] ]  −  max_d E_θ[NB(d,θ)]
  (nested expectation: outer over possible study results, inner over the
  posterior belief about θ after seeing that result — usually estimated by
  nested Monte Carlo / Bayesian updating over probabilistic sensitivity
  analysis draws)

Closed-form normal approximation (single uncertain parameter, conjugate
normal-normal model — a standard shortcut, not exact for every model):
EVSI(n) = EVPI × n / (n + n0)

n  = proposed study's sample size
n0 = "prior-equivalent sample size" — the size of an imaginary sample that
     would carry the same information as the current prior, derived from
     the ratio of data variance to prior variance
ENBS(n) = EVSI(n) − Cost(n)
Population EVSI = per-decision EVSI × decisions affected
```

הצורה הכללית היא ציפייה מקוננת כי תוצאתו העתידית של מחקר היא בעצמה לא ודאית: יש לעשות ממוצע על כל מערך נתונים אפשרי שהמחקר יכול לייצר, ולכל אחד לחשב מחדש את ההחלטה הטובה ביותר בהינתן האמונה המעודכנת (האחורית). קירוב הנורמלי בצורה סגורה מחליף את העלות החישובית הזו ביחס יחיד, תקף כשהפרמטר הלא ודאי והנתונים מתפלגים (בקירוב) נורמלית וקונג'וגטית — נוחות, לא חוק אוניברסלי. Monte Carlo מקונן מלא הוא השיטה הכללית כשההנחה אינה מתקיימת. ראו [ניתוח רגישות הסתברותי](../ניתוח-רגישות-הסתברותי/) להגרלות ה-PSA שמהן EVSI מוערך בדרך כלל.

## דוגמה מחושבת

בהמשך לדוגמה המחושבת של [EVPI](../ערך-צפוי-של-מידע-מושלם/) — פריסת עוזר תיעוד בינה מלאכותית ל-5,000 קלינאים, שבה נמצא EVPI של £1.2M — בטאו את אותו EVPI כאן בלירות שלמות: **EVPI = £1,200,000**.

פיילוט מוצע של 50 קלינאים על הפרק. מהיחס בין שונות האמונה הקודמת לדיוק המדידה של הפיילוט, גודל המדגם השקול לקודם מתברר כ-`n0 = 75`:

```
EVSI(50) = 1,200,000 × 50 / (50 + 75)
         = 1,200,000 × 50 / 125
         = 1,200,000 × 0.4
         = £480,000
```

הפיילוט עולה £120,000:

```
ENBS = EVSI − Cost = 480,000 − 120,000 = £360,000
```

ENBS חיובי בבירור: מממנים את הפיילוט. אם אותה החלטת רכש חוזרת על פני 3 נאמנויות אזוריות דומות, ערך הפיילוט גדל:

```
Population EVSI = 480,000 × 3 = £1,440,000
```

## הקשר להנדסת תוכנה

EVSI הוא הכלכלה של בחירת *כמה גדול* צריך להיות פיילוט או מבחן A/B, לא רק אם להריץ אחד בכלל:

- **גודל מדגם כהחלטת השקעה.** בטא של 50 משתמשים ופריסה מדורגת של 5,000 משתמשים הם "מחקרים" שונים עם EVSI ועלויות שונים — EVSI מאפשר להשוות ביניהם על אותו בסיס במקום ברירת המחדל של "יותר נתונים זה תמיד טוב יותר".
- **ENBS, לא EVSI לבדו, הוא מבחן ההזמנה.** מחקר עם EVSI גבוה אך עלות שאוכלת את רובו הוא הצעה חלשה; כלל ההחלטה הוא תועלת נטו צפויה של דגימה, בדיוק כפי שתיק עסקי מנטרל תועלת מול עלות במקום לדווח על תועלת בלבד.
- **תשואות פוחתות מפורשות.** מכיוון ש-EVSI(n) עולה עם `n/(n+n0)`, הכפלת גודל פיילוט לעולם אינה מכפילה את ערכו — גרסה פורמלית של האינסטינקט ההנדסי שלניסוי גדול יותר יש ערך מידע שולי פוחת.

## מלכודות נפוצות

- **יישום קירוב הנורמלי מחוץ להנחותיו.** הוא תקף רק לאי-ודאות כמעט קונג'וגטית של פרמטר יחיד; מודל החלטה לא ליניארי או רב-פרמטרי באמת דורש Monte Carlo מקונן מלא, לא קיצור הדרך הזה.
- **השוואת EVSI לעלות מזומן בלבד.** EVSI חייב להישקל מול העלות *המלאה* של המחקר, כולל עלות עיכוב ההחלטה שלו — ראו [עלות עיכוב](../עלות-עיכוב/) — לא רק חשבונית המחקר.
- **התייחסות ל-EVSI > EVPI כממצא אמיתי.** EVSI לעולם אינו יכול לחרוג מ-EVPI מעצם בנייתו; חישוב שמייצר זאת הוא באג מידול, לא גילוי.
