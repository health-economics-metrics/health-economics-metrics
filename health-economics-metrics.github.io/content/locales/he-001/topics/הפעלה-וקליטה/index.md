# הפעלה וקליטה

שיעור ההפעלה הוא חלקם של הנרשמים שמגיעים לערך המשמעותי הראשון (פעולת ה"אהה" — קריאה ראשונה שנרשמה, שיעור ראשון שהושלם). קליטה היא הגרסה האוכלוסייתית: חלקה של האוכלוסייה *הזכאית* שמאמצת את הפתרון בכלל. יחד הם שערי הכניסה של משפך הערך: רכישה → קליטה → הפעלה → [שימור](../שימור-ונטישה/) → תוצאה.

## למה זה חשוב

משתמשים שלא הופעלו הם עלות טהורה: הוצאות רכישה, אספקה, משטח תמיכה — ללא ערך קליני כלל. מדדי ייחוס מציבים את שיעור ההפעלה בתוכנה לבריאות *מתחת* לממוצע הבין-תעשייתי (≈24% לעומת ≈37% להפעלת משתמשים חדשים בקבוצת מדדי SaaS אחת; השלמת רשימת קליטה ~20%), בשל קליטה כבדה יותר (זהות, הסכמה, בטיחות קלינית). לקליטה יש משמעות אוכלוסייתית: ב[מסגרת RE-AIM](../טווח-הגעה-ושוויון/), ההשפעה על בריאות הציבור ≈ טווח הגעה × אפקטיביות — אפליקציה מצוינת שאומצה על ידי 3% מהאוכלוסייה הזכאית מזיזה את מחוג האוכלוסייה בשיעור של 3% בלבד. בטיפולים דיגיטליים שנרשמים במרשם, שער הקליטה נראה בנתונים לאומיים: **כ-81% ממרשמי DiGA הגרמניים מופעלים** — אחד מכל חמישה טיפולים שנרשמו ושולמו אינו מתחיל לעולם (ראו [המסלול המהיר של DiGA](../המסלול-המהיר-diga-של-גרמניה/)).

## המתמטיקה

```
Activation rate = users completing key action within window / sign-ups × 100
Uptake rate     = adopters / eligible population × 100
DTx fill rate   = activated prescription codes / issued prescriptions × 100

Funnel value model:
  eligible × uptake × activation × retention-weighted benefit = population value
  — four multiplications; improving the smallest factor usually
  dominates (theory-of-constraints for funnels)
```

## דוגמה מחושבת

גוף מזמין מציע אפליקציה למניעת סוכרת ל-80,000 תושבים זכאים:

```
Invited → registered:  80,000 → 12,000  (uptake 15%)
Registered → activated (first session + goal set, 7 days): 12,000 → 5,400 (45%)
Activated → completed 6-month programme: 5,400 → 1,600 (30%)

Programme effect (trial, completers): 0.03 QALYs + £180 avoided costs
Population value = 1,600 × (0.03 × £20,000 + £180) ≈ £1.25M
Per-eligible-person value = £15.6 — versus £780 if every eligible person completed.

Where to invest? Doubling uptake (15→30%) doubles value; raising
activation 45→65% adds ~44%; both beat further polishing the programme
content the 1,600 already complete.
```

## הקשר להנדסת תוכנה

ההפעלה היא השלב הנוח ביותר להתערבות הנדסית במשפך: חיכוך באימות זהות, תהליכי הסכמה, עיצוב מצב ריק וזמן עד ערך ראשון הם קוד, לא מדיניות (זמן חציוני עד ערך בבריאות ≈ יום ו-7 שעות בנתוני ייחוס — כל שעה ממנו היא חשיפה לנטישה). קליטה היא בעיה של מערכות הפצה: שילוב במסלולי הפניה (רגע כתיבת המרשם), הזמנות בהמלצת רופא המשפחה (האמון עובר הלאה) ונגישות (שפה, מיומנות דיגיטלית — ראו [טווח הגעה ושוויון](../טווח-הגעה-ושוויון/)). מודל ערך המשפך שלעיל הוא מחולל התיק העסקי לשניהם: כפלו את הגורמים, מצאו את צוואר הבקבוק, ותמחרו את התיקון מול ערך האוכלוסייה שהוא משחרר.

## מלכודות נפוצות

- **הפעלה שהוגדרה כנוחות** (דוא"ל אומת) ולא כמשמעות קלינית (פעולה טיפולית ראשונה) — מנפחת את המדד ושוברת את שרשרת הערך.
- **משחקי מכנה בקליטה**: "מבין מי שביקר באתר" לעומת האוכלוסייה הזכאית באמת — המזמינים מתעניינים בזו האחרונה.
- **אפקטי בחירה**: משתמשים שקל להפעיל הם החולים הכי פחות והמקופחים הכי פחות; שיפורי משפך עלולים להרחיב פערי שוויון תוך שיפור הממוצעים.
