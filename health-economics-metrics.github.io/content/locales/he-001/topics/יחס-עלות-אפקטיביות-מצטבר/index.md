# יחס עלות-אפקטיביות מצטבר (ICER)

ה-ICER הוא העלות הנוספת ליחידת אפקט בריאותי נוספת כשבוחרים באפשרות אחת על פני החלופה הטובה הבאה. זהו המספר הראשי של הערכת טכנולוגיות בריאות. (כשיחידת האפקט היא QALY, הוא נקרא גם יחס עלות-תועלתנות מצטבר, ICUR.)

## למה זה חשוב

מערכות בריאות לעולם אינן מעריכות טכנולוגיה בבידוד — תמיד *באופן מצטבר*, מול מה שהיה נעשה אחרת. NICE משווה את ה-ICER של טכנולוגיה לסף של **£20,000–£30,000 ל-QALY**; מכון ICER האמריקאי מדווח על פני $50,000–$200,000/QALY; קנדה פועלת בערך ב-CAD$50,000/QALY. האם המוצר שלכם "שווה" לשירות בריאות לאומי הוא, באופן פורמלי, האם ה-ICER שלו עובר את הסף המקומי. ראו [ספי נכונות לשלם](../ספי-נכונות-לשלם/).

## המתמטיקה

```
ICER = (Cost_new − Cost_comparator) / (Effect_new − Effect_comparator)
     = ΔC / ΔE
```

כללי פרשנות:

- ΔC < 0, ΔE > 0: האפשרות החדשה **שולטת** — זולה וטובה יותר; אין צורך ביחס.
- ΔC > 0, ΔE > 0: חשבו ICER, השוו לסף λ; אמצו אם ICER < λ.
- ΔC > 0, ΔE < 0: האפשרות החדשה נשלטת — דחו.
- יחסים מתנהגים רע ליד ΔE = 0 — העדיפו [תועלת כספית נטו](../תועלת-כספית-נטו/) לדירוג.

קבוצת ההשוואה חייבת להיות *האפשרות הטובה הבאה שאינה נשלטת*, לא "אל תעשה דבר" — ראו [דומיננטיות וגבול היעילות](../דומיננטיות-וגבול-היעילות/).

## דוגמה מחושבת

שירות ניטור מרחוק לחולי אי-ספיקת לב, לכל 1,000 מטופלים בשנה, מול טיפול רגיל:

```
Costs:   service £900,000; admissions avoided save £600,000
         ΔC = 900,000 − 600,000 = £300,000
Effects: earlier intervention gains 25 QALYs
         ΔE = 25

ICER = 300,000 / 25 = £12,000 per QALY
```

£12,000/QALY נמוך בנוחות מסף £20,000 של NICE — תיק חזק. שימו לב כיצד העלות *נטו* חשובה: בלי קיזוז £600,000 ה-ICER היה £36,000/QALY והתיק כנראה היה נכשל. קיזוזי עלות ואיכות הראיות שלהם הם המקום שבו ניתוחים אלה נוצחים ומופסדים (ראו [עלויות במורד הזרם שנמנעו](../עלויות-במורד-הזרם-שנמנעו/)).

## הקשר להנדסת תוכנה

דיסציפלינת ה-ICER עוברת כלשונה להחלטות הנדסיות:

```
(cost of option B − cost of option A) / (outcome B − outcome A)
```

— עלות מצטברת לכל פריסה נוספת, לכל שעת מהנדס שנחסכה, לכל תקרית שנמנעה — תמיד מול החלופה הטובה הבאה, לא מול אי-עשיית דבר. שני ההרגלים ששווה לגנוב: (1) *נקבו את קבוצת ההשוואה במפורש*; רוב טענות ה-ROI של כלים משוות בסתר מול איש קש; (2) *נטו קודם את העלויות* — כלי שעולה £100k אך מסיט £80k של הוצאה קיימת יש לו ΔC = £20k.

## מלכודות נפוצות

- **השוואת ICER בין מטבעות בלי שלב המרה מפורש**: ICER שחושב במטבע של מדינה אחת חייב להיות מומר בשיטה מוצהרת לפני השוואתו לסף של מדינה אחרת — ראו [השוואת ICER בין מטבעות](../השוואת-icer-בין-מטבעות/) לכך שבחירת גורם ההמרה (שוויון כוח קנייה מול שער חליפין שוק) יכולה בעצמה להפוך את החלטת האימוץ.
- **משחקי קבוצת השוואה**: השוואה מול קו בסיס מיושן או גרוע באופן מלאכותי מנפחת ΔE ומחמיאה ל-ICER.
- **ממוצעים במקום מצטברים**: עלות ל-QALY של תוכנית שלמה אינה ה-ICER של הרחבתה או אימוצה.
- **פולחן אומד נקודתי**: ICER הם יחסים של שני הפרשים לא ודאיים; דווחו אי-ודאות באמצעות [PSA ו-CEAC](../ניתוח-רגישות-הסתברותי/).
- **ICER שליליים אינם חד-משמעיים** (זול-וטוב יותר לעומת יקר-וגרוע יותר נותנים אותו סימן) — לעולם אל תדווחו ICER שלילי בלי לומר באיזה רביע הוא.
