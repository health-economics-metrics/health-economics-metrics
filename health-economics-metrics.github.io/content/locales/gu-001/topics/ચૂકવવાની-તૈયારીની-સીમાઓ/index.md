# ચૂકવવાની તૈયારીની સીમાઓ

ચૂકવવાની-તૈયારી (WTP) સીમા એ આરોગ્ય લાભના એકમ દીઠ નિર્ણયકર્તા વધુમાં વધુ જે ચૂકવશે તે છે — તે રેખા જે [ICER](../વૃદ્ધિશીલ-ખર્ચ-અસરકારકતા-ગુણોત્તર/) ને અપનાવો/નકારો નિર્ણયમાં ફેરવે છે.

## આ શા માટે મહત્ત્વનું છે

સીમા એ છે જ્યાં આરોગ્ય અર્થશાસ્ત્ર માપન મટીને નીતિ બને છે. દરેક રાષ્ટ્રીય તંત્ર પાસે એક હોય છે, સ્પષ્ટ અથવા ગર્ભિત, અને સ્થાનિક આંકડો જાણવાથી આરોગ્ય-મૂલ્ય દાવાનો ભાવ કેવી રીતે નક્કી કરવો તે બરાબર ખબર પડે છે:

| સંસ્થા | સીમા (સંશોધિત, 2024–2025) |
|---|---|
| NICE (England) | £20,000–£30,000 per QALY; empirical average decision threshold ≈ £24,400 (2022–24); severity modifiers raise effective ceiling to ~£36k–£51k; highly specialized technologies up to £100k+ |
| ICER (US, non-governmental) | $100,000–$150,000 per QALY/evLYG price benchmarks; reports $50k–$200k range |
| Canada (CADTH / CDA-AMC) | ≈ CAD$50,000 per QALY working threshold |
| WHO-CHOICE (historical, global) | 1–3× GDP per capita per DALY averted (now discouraged as too blunt) |
| Empirical UK supply side (Claxton et al.) | ≈ £13,000 per QALY actually displaced at the NHS margin |

## ગણિત

સીમા λ દરેક નિર્ણય નિયમમાં આવે છે:

```
Adopt if ICER = ΔC/ΔE < λ
Equivalently: adopt if NMB = λ×ΔE − ΔC > 0
```

λ *શું છે* તેના બે સિદ્ધાંતો:

- **માંગ બાજુ**: આરોગ્ય માટે સમાજ ચૂકવવા શું તૈયાર છે (મૂલ્ય નિર્ણય).
- **પુરવઠા બાજુ**: બજેટ હાલમાં સીમાંત પર જે આરોગ્ય ઉત્પન્ન કરે છે (પ્રાયોગિક રાશિ — Claxton નું ~£13k/QALY). જો નિર્ણયો માટે વપરાતો λ પુરવઠા-બાજુ દર કરતાં વધે, તો નવી ટેકને મંજૂર કરવાથી તે ઉમેરે છે તેના કરતાં વધુ આરોગ્ય વિસ્થાપિત થાય છે.

## ઉકેલેલું ઉદાહરણ

તમારું ડિજિટલ થેરાપ્યુટિક સારવાર પામેલા દર્દી દીઠ 0.05 QALY £800 ચોખ્ખા ખર્ચે (ભાવ બાદ સરભર) આપે છે.

```
ICER = 800 / 0.05 = £16,000 per QALY
```

- England: £20k થી નીચે → ભંડોળપાત્ર. મહત્તમ બચાવપાત્ર ભાવ: λ = £20,000 પર, price_max = 0.05 × 20,000 + સરભર = £1,000 + સરભર.
- $150k/QALY પર યુએસ વ્યાપારી ફ્રેમિંગ: મૂલ્ય-આધારિત ભાવ ઘણો ઊંચો.
- $4,000 ના માથાદીઠ-GDP દેશ સીમા: એ જ ઉત્પાદન ચોખ્ખું ~$200 થી ઓછું હોવું જોઈએ.

એ જ ઉત્પાદન, ત્રણ બજાર, ત્રણ ભાવ — સીમા *એ જ* ભાવ-નિર્ધારણ મૉડેલ છે. આ મૂલ્ય-આધારિત ભાવ નિર્ધારણ છે, λ થી ઊલટું ચલાવેલું.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

દરેક એન્જિનિયરિંગ સંસ્થા પાસે ગર્ભિત λ હોય છે: બચેલા એન્જિનિયર-કલાક દીઠ ટૂલિંગને ભંડોળ આપવાની અડચણ. તેને સ્પષ્ટ કરવાથી — "દર વિશ્વસનીય બચેલા એન્જિનિયર-કલાક દીઠ £40 થી ઓછા કંઈ પણને અમે ભંડોળ આપીએ છીએ" — પ્લૅટફૉર્મ રોકાણોની લીગ-ટેબલ સરખામણી શક્ય બને છે, બરાબર જેમ ખર્ચ-પ્રતિ-QALY લીગ ટેબલ આરોગ્ય ખર્ચને ક્રમ આપે છે. પુરવઠા-બાજુનો પાઠ પણ ટ્રાન્સફર થાય છે: તમારો સાચો આંતરિક λ એ છે જે તમારો *હાલનો* બૅકલૉગ સીમાંત પર ઉત્પન્ન કરે છે, નેતૃત્વ સમયનું જે મૂલ્ય કહે છે તે નહીં.

## સામાન્ય ભૂલો

- અધિકારક્ષેત્રો વચ્ચે **સીમા ખરીદી** અથવા સામાન્ય ઉત્પાદન માટે HST ટોચમર્યાદા ટાંકવી.
- **λ ને ભાવ તળિયું ગણવું**: સીમા પાર કરવી જરૂરી છે, પૂરતી નથી — [બજેટ અસર](../બજેટ-અસર-વિશ્લેષણ/) હજી પણ એકમ-દીઠ પરવડતા ઉત્પાદનને ડુબાડી શકે છે.
- **સીમાઓ બદલાય છે તે અવગણવું**: NICE ના ગંભીરતા સંશોધકો (2022) અને સમયાંતરે સમીક્ષાઓ અસરકારક λ બદલે છે; તમારા દાવાઓને તારીખ આપો.
- **ચલણ બદલ્યા વગર અલગ ચલણમાં ICER ને સીમા સામે સરખાવવો**: [આંતર-ચલણ ICER સરખામણી](../આંતર-ચલણ-icer-સરખામણી/) જુઓ — રૂપાંતર પદ્ધતિ (ખરીદ શક્તિ સમાનતા વિરુદ્ધ બજાર વિનિમય દર) પદ્ધતિગત રીતે પરિણામકારક છે, ગોળ કરવાની વિગત નથી.
- **λ-આધારિત મૂલ્યાંકનને શ્રમ-બજાર VSL/VPF પરંપરા સાથે ગૂંચવવું**: આ જુદી સૈદ્ધાંતિક પરંપરાઓમાંથી આવે છે (આરોગ્ય-બજેટ-મર્યાદિત પદ્ધતિ વિરુદ્ધ વેતન-જોખમ વિનિમયમાંથી પ્રગટ પસંદગી) અને હંમેશાં સમાધાનપાત્ર નથી — જીવનનું મૂલ્ય આંકવાના વૈકલ્પિક પ્રગટ-પસંદગી અભિગમ માટે [આંકડાકીય જીવનનું મૂલ્ય](../આંકડાકીય-જીવનનું-મૂલ્ય/) જુઓ.
