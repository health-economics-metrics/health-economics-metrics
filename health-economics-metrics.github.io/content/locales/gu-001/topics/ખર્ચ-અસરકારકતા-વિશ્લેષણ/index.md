# ખર્ચ-અસરકારકતા વિશ્લેષણ (CEA)

CEA વૈકલ્પિક હસ્તક્ષેપોના ખર્ચની **કુદરતી એકમો**માં માપેલા એક જ પરિણામ સામે સરખામણી કરે છે — જીવન-વર્ષો, શોધાયેલા કેસ, ટાળેલા દાખલ, ઘટાડેલા બ્લડ પ્રેશરના mmHg. તેનું આઉટપુટ પરિણામના એકમ દીઠ ખર્ચ છે.

## આ શા માટે મહત્ત્વનું છે

જ્યારે બધા વિકલ્પો એ જ પરિણામને લક્ષ્ય બનાવે ત્યારે CEA મુખ્ય સરખામણી છે. તે "X સિદ્ધ કરવાની આમાંથી કઈ રીત નાણાંનો શ્રેષ્ઠ ઉપયોગ છે?" નો જવાબ આપે છે — પરંતુ "X સિદ્ધ કરવા જેવું છે જ?" નો *નહીં* (તેને [ખર્ચ-લાભ વિશ્લેષણ](../ખર્ચ-લાભ-વિશ્લેષણ/) જોઈએ) અને "X ની અસંબંધિત પ્રાથમિકતાઓ સાથે સરખામણી કેવી?" નો *નહીં* (તેને [ખર્ચ-ઉપયોગિતા વિશ્લેષણ](../ખર્ચ-ઉપયોગિતા-વિશ્લેષણ/) અને QALY જેવું સામાન્ય પરિણામ જોઈએ).

## ગણિત

સરખામણી આંકડો કુદરતી એકમોમાં [ICER](../વૃદ્ધિશીલ-ખર્ચ-અસરકારકતા-ગુણોત્તર/) છે:

```
ICER = (Cost_A − Cost_B) / (Effect_A − Effect_B)
     = £ per additional case detected / admission avoided / etc.
```

પ્રક્રિયા: પરિણામ એકમ વ્યાખ્યાયિત કરો; દરેક વિકલ્પનો ખર્ચ એ જ [દૃષ્ટિકોણ](../વિશ્લેષણ-દૃષ્ટિકોણ/) થી એ જ [સમય ક્ષિતિજ](../સમય-ક્ષિતિજ/) પર આંકો; પ્રભાવિત વિકલ્પો દૂર કરો ([કાર્યક્ષમતા સીમા](../પ્રભુત્વ-અને-કાર્યક્ષમતા-સીમા/)); સીમા સાથે વૃદ્ધિશીલ ગુણોત્તર ગણો.

## ઉકેલેલું ઉદાહરણ

1,00,000 ની વસ્તીમાં નિદાન ન થયેલ ઍટ્રિયલ ફાઇબ્રિલેશન શોધવાની ત્રણ રીતો:

```
Option                    Cost        Cases found
Opportunistic pulse checks £150,000       300
Pharmacy screening events  £400,000       520
Wearable-based screening   £900,000       610

ICER pharmacy vs pulse:  (400k−150k)/(520−300) = £1,136 per additional case
ICER wearable vs pharmacy:(900k−400k)/(610−520) = £5,556 per additional case
```

વધારાના કેસ દીઠ £5,556 "યોગ્ય" છે કે નહીં તે શોધાયેલા કેસના મૂલ્ય (ડાઉનસ્ટ્રીમ સ્ટ્રોક નિવારણ) પર આધારિત છે — CEA વિકલ્પોને ક્રમ આપે છે પરંતુ અપનાવવાના નિર્ણયને એ બાહ્ય મૂલ્યાંકન જોઈએ. નોંધો કે વેરેબલ વિકલ્પનો *સરેરાશ* ખર્ચ પ્રતિ કેસ (900k/610 = £1,475) સારો લાગે છે; વિસ્તરણ નિર્ણય માટે *વૃદ્ધિશીલ* £5,556 પ્રામાણિક સંખ્યા છે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

જ્યારે વિકલ્પો એક પરિણામ વહેંચે ત્યારે CEA યોગ્ય નમૂનો છે: ત્રણ સુધારણા અભિગમોમાં દૂર કરેલા flaky ટેસ્ટ દીઠ ખર્ચ; ઑબ્ઝર્વેબિલિટી વેન્ડર્સમાં ટાળેલી ઘટના દીઠ ખર્ચ; CI આર્કિટેક્ચરોમાં સફળ ડિપ્લોયમેન્ટ દીઠ ખર્ચ. તે જે શિસ્ત લાગુ કરે છે — એક જાહેર પરિણામ એકમ, વૃદ્ધિશીલ (સરેરાશ નહીં) ગુણોત્તર, પ્રભાવિત વિકલ્પો પહેલા દૂર — કિંમત ચર્ચા શરૂ થાય તે પહેલાં મોટાભાગની ખરાબ વેન્ડર સરખામણીઓને મારી નાખે છે.

## સામાન્ય ભૂલો

- **અલગ પરિણામો ધરાવતા વિકલ્પોની** ("શોધાયેલા કેસ" વિરુદ્ધ "સંતોષ") એક CEA માં સરખામણી — તેને [ખર્ચ-પરિણામ વિશ્લેષણ](../ખર્ચ-પરિણામ-વિશ્લેષણ/) કે સામાન્ય પરિણામ જોઈએ.
- **સરેરાશ ખર્ચ-અસરકારકતા ગુણોત્તર** જ્યાં વૃદ્ધિશીલ જોઈએ ત્યાં રજૂ કરવા (ઉપરનું વેરેબલ ઉદાહરણ).
- **ખુશામત માટે પસંદ કરેલા પરિણામ એકમો**: "ઉત્પન્ન થયેલી ચેતવણીઓ" આઉટપુટ છે, પરિણામ નહીં; મૂલ્ય વહન કરતા એકમોનો આગ્રહ રાખો.
