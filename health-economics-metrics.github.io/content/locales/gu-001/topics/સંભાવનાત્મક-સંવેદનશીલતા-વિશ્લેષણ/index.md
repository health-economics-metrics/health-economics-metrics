# સંભાવનાત્મક સંવેદનશીલતા વિશ્લેષણ (PSA)

PSA દરેક અનિશ્ચિત પરિમાણને સંભાવના વિતરણ સોંપે છે, તે બધાનું એકસાથે હજારો વાર નમૂનાકરણ કરે છે (મોન્ટે કાર્લો), અને એક જ બિંદુ-અંદાજને બદલે વિકલ્પ શ્રેષ્ઠ પસંદગી હોવાની *સંભાવના* અહેવાલ કરે છે.

## આ શા માટે મહત્ત્વનું છે

NICE નો સંદર્ભ કેસ PSA *જરૂરી* ગણે છે. નિર્ધારક વિશ્લેષણ "જો એક ઇનપુટ ખોટું હોય તો?" નો જવાબ આપે છે; PSA "આપણે જે કંઈ એકસાથે નથી જાણતા તે જોતાં, આપણે સાચો નિર્ણય લઈ રહ્યા હોવાની કેટલી સંભાવના છે?" નો જવાબ આપે છે. તેનું સહી આઉટપુટ, **ખર્ચ-અસરકારકતા સ્વીકાર્યતા વક્ર (CEAC)**, વિકલ્પ ખર્ચ-અસરકારક હોવાની સંભાવનાને ચૂકવવાની-તૈયારી સીમા સામે આલેખે છે — "ICER £24,000/QALY છે" ને "£30,000/QALY પર આ સાચી પસંદગી હોવાની 78% સંભાવના છે" માં ફેરવે છે.

## ગણિત

```
For each of N draws (N ≈ 10,000):
  sample every parameter θ from its distribution
    (costs ~ Gamma, probabilities ~ Beta, utilities ~ Beta, effects ~ Normal/logNormal)
  compute NMB_j(θ) = λ × Effect_j(θ) − Cost_j(θ) for each option j

CEAC_j(λ) = fraction of draws in which option j has the highest NMB at threshold λ
```

NMB માટે [ચોખ્ખો નાણાકીય લાભ](../ચોખ્ખો-નાણાકીય-લાભ/) અને λ માટે [ચૂકવવાની તૈયારીની સીમાઓ](../ચૂકવવાની-તૈયારીની-સીમાઓ/) જુઓ.

## ઉકેલેલું ઉદાહરણ

પ્લૅટફૉર્મ માઇગ્રેશન બિઝનેસ કેસ. ત્રણ અનિશ્ચિત ઇનપુટ:

```
Migration cost      ~ Gamma,  mean £800k, sd £200k
Annual benefit      ~ Normal, mean £350k, sd £150k
Benefit duration    ~ Uniform, 3–6 years
```

10,000 ડ્રૉ દરેક માટે ચોખ્ખો લાભ = સમયગાળો × વાર્ષિક − ખર્ચ ગણો (સ્પષ્ટતા માટે ડિસ્કાઉન્ટ બાકાત). સચિત્ર પરિણામો:

```
Mean net benefit:      £775k
Probability net > 0:   0.86
5th–95th percentile:  −£180k … +£1.9M
```

બિંદુ-અંદાજે કહ્યું "દેખીતી રીતે હા." PSA કહે છે "86% હા, વાસ્તવિક પૂંછડી સાથે જ્યાં આપણે £180k+ ગુમાવીએ" — જે પોર્ટફોલિયો માલિકને ખરેખર જોઈએ છે, અને તે પહેલાં ડિસ્કવરી સ્પાઇક ચલાવવાના કેસની કિંમત આંકે છે ([EVPI](../સંપૂર્ણ-માહિતીનું-અપેક્ષિત-મૂલ્ય/) જુઓ).

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

એન્જિનિયરો ડિલિવરી આગાહી માટે પહેલેથી મોન્ટે કાર્લો પર ભરોસો કરે છે (થ્રુપુટ નમૂનાકરણ બિંદુ અંદાજોને હરાવે છે). એ જ મશીનરી નાણાં સુધી વિસ્તારો: અપનાવવા, બચેલા સમય અને પગાર પર વિતરણો, પછી ખોટી-ચોકસાઈ ROI ને બદલે "આ પ્લૅટફૉર્મ રોકાણ ચોખ્ખું-હકારાત્મક હોવાની સંભાવના" અહેવાલ કરો. CEAC-શૈલીનો વક્ર — સંસ્થા એન્જિનિયર-કલાકનું મૂલ્ય કેવી રીતે આંકે તેના કાર્ય તરીકે શ્રેષ્ઠ વિકલ્પ હોવાની સંભાવના — ભંડોળ સમિતિ માટે કોઈપણ એક સંખ્યા કરતાં ખરેખર સારી કૃતિ છે.

## સામાન્ય ભૂલો

- **કચરા વિતરણો**: બનાવટી પ્રમાણભૂત વિચલન સાથે PSA એ લૅબ કોટ પહેરેલું નિર્ધારક વિશ્લેષણ છે. ફેલાવો ડેટા કે માળખાગત નિષ્ણાત મેળવણી પર આધારિત કરો.
- **પરિમાણો વચ્ચે સહસંબંધની અવગણના** (ઊંચું અપનાવવું સામાન્ય રીતે ઊંચા બચેલા-સમય સાથે સંબંધિત); સ્વતંત્ર નમૂનાકરણ પૂંછડી જોખમ ઓછું આંકે છે.
- **સિમ્યુલેશનની ફક્ત સરેરાશ અહેવાલ કરવી** — આખો મુદ્દો વિતરણ અને નિર્ણય સંભાવના છે.
