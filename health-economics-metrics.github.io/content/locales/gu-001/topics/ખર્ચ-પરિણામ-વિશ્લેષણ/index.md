# ખર્ચ-પરિણામ વિશ્લેષણ (CCA)

CCA ખર્ચને **બધા પરિણામોના વિઘટિત કોષ્ટક** સાથે રજૂ કરે છે — ક્લિનિકલ, સંચાલન, અનુભવાત્મક — તેમને એક જ ગુણોત્તર કે ગુણાંકમાં સંકોચ્યા વિના. નિર્ણયકર્તા સમાધાનોને સ્પષ્ટપણે તોલે છે.

## આ શા માટે મહત્ત્વનું છે

CCA એ Evidence Standards Framework હેઠળ **મોટાભાગની ડિજિટલ આરોગ્ય ટેકનોલોજી માટે NICE નું પસંદગીનું આર્થિક સ્વરૂપ** છે. ડિજિટલ ઉત્પાદનો વિષમ અસરો (બચેલો સમય, સંતોષ, DNA ઘટાડો, નાના ક્લિનિકલ લાભ) પેદા કરે છે જે એક QALY સંખ્યામાં પ્રામાણિક રીતે એકત્ર થવાનો પ્રતિકાર કરે છે. નાજુક સંયુક્ત બળજબરીથી બનાવવાને બદલે, CCA સંપૂર્ણ ખાતાવહી બતાવે છે. મોટાભાગના સૉફ્ટવેર બિઝનેસ કેસ માટે, તે સૌથી પ્રામાણિક અને સૌથી પ્રેરક સ્વરૂપ બંને છે, કારણ કે દરેક હિતધારક પોતાની નિર્ણય-સંબંધિત પંક્તિ શોધી શકે છે.

## ગણિત

ઇરાદાપૂર્વક કોઈ એકત્રીકરણ સૂત્ર નથી. આઉટપુટ કોષ્ટક છે:

```
                          Intervention   Comparator   Difference
Costs (annual)            £X             £Y           ΔC
Outcome 1 (natural units) …              …            Δ1
Outcome 2                 …              …            Δ2
Qualitative outcomes      described, not scored
```

દરેક પંક્તિ પોતાના એકમો રાખે છે. નિયમો: દરેક પરિણામ પૂર્વ-નિર્દિષ્ટ (પરિણામો પછી ચૂંટી-ચૂંટીને નહીં); સમગ્ર એ જ [દૃષ્ટિકોણ](../વિશ્લેષણ-દૃષ્ટિકોણ/) અને [ક્ષિતિજ](../સમય-ક્ષિતિજ/); દરેક પંક્તિ દીઠ અનિશ્ચિતતા.

## ઉકેલેલું ઉદાહરણ

ડિજિટલ પ્રી-ઑપરેટિવ મૂલ્યાંકન પ્લૅટફૉર્મ વિરુદ્ધ ફોન-આધારિત પ્રક્રિયા, વર્ષ દીઠ, એક ટ્રસ્ટ:

```
                              Digital      Phone       Difference
Running cost                  £180,000     £95,000     +£85,000
Nurse hours on assessments    6,200        11,800      −5,600 hrs
On-day surgery cancellations  92           174         −82
Patient satisfaction (CSAT)   4.5/5        3.9/5       +0.6
Assessments lost/incomplete   1.2%         4.8%        −3.6 pp
```

કોઈ એક ગુણાંક નથી — પણ નિર્ણય વિશે તર્ક કરવો સરળ છે: £85,000 5,600 નર્સ-કલાક ખરીદે છે (≈ £15/કલાક, કોઈપણ સ્ટાફિંગ ખર્ચથી ઘણો નીચે), 82 ટાળેલા રદ્દીકરણ (દરેક ~£1,200 ના થિયેટર સ્લોટનો બગાડ), અને સારો અનુભવ. સમિતિ એ પણ બરાબર જોઈ શકે છે કે તેને *શું નથી* મળતું: કોઈ દાવો કરેલ QALY કે મૃત્યુદર અસર નહીં.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

CCA એ સંતુલિત સ્કોરકાર્ડનું ઔપચારિક સ્વરૂપ છે જે સારી પ્લૅટફૉર્મ દરખાસ્ત પહેલેથી વાપરે છે: ખર્ચ DORA મેટ્રિક્સ, DevEx ગુણાંક, ઘટના સંખ્યાની બાજુમાં — એકત્ર કર્યા વિના. ઉમેરવાની આરોગ્ય-અર્થશાસ્ત્ર શિસ્ત: **પંક્તિઓ પૂર્વ-નિર્દિષ્ટ કરો** (પાયલટ પહેલાં શું ગણાશે તે નક્કી કરો, જેથી ખરાબ થયેલું મેટ્રિક શાંતિથી છોડી ન શકાય), અને **પ્રતિકૂળ પંક્તિઓ બતાવો** — ફક્ત સારા સમાચારવાળું CCA માર્કેટિંગ છે. જ્યારે કોઈ બચાવી શકાય તેવો સંયુક્ત ન હોય ત્યારે CCA વાપરો, જે ડેવલપર ટૂલિંગ માટે લગભગ હંમેશા હોય છે.

## સામાન્ય ભૂલો

- **ચૂંટેલા પરિણામો** — સ્વરૂપની અખંડિતતા પૂર્વ-નિર્દિષ્ટતા પર આધારિત છે.
- **છુપાયેલું એકત્રીકરણ**: રંગ-કોડિંગ કે "એકંદર ગુણાંક" CCA જે મનસ્વી ભારથી બચવા અસ્તિત્વમાં છે તેને પાછા દાખલ કરે છે.
- **નિર્ણય લકવો**: CCA ને સમાધાનો તોલવા તૈયાર નિર્ણયકર્તા જોઈએ; તેને ભલામણ અને તર્ક સાથે જોડો.
