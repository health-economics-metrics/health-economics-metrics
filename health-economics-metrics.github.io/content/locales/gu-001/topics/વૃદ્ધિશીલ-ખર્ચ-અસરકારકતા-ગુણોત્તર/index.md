# વૃદ્ધિશીલ ખર્ચ-અસરકારકતા ગુણોત્તર (ICER)

ICER એ એક વિકલ્પને આગામી-શ્રેષ્ઠ વિકલ્પ પર પસંદ કરતાં આરોગ્ય અસરના વધારાના એકમ દીઠ વધારાનો ખર્ચ છે. તે આરોગ્ય ટેકનોલોજી મૂલ્યાંકનની હેડલાઇન સંખ્યા છે. (જ્યારે અસર એકમ QALY હોય, ત્યારે તેને વૃદ્ધિશીલ ખર્ચ-ઉપયોગિતા ગુણોત્તર, ICUR, પણ કહેવાય છે.)

## આ શા માટે મહત્ત્વનું છે

આરોગ્ય પ્રણાલીઓ ક્યારેય ટેકનોલોજીનું એકલતામાં મૂલ્યાંકન કરતી નથી — હંમેશા *વૃદ્ધિશીલ* રીતે, અન્યથા જે થાય તેની સામે. NICE ટેકનોલોજીના ICER ની તેની **£20,000–£30,000 પ્રતિ QALY** સીમા સાથે સરખામણી કરે છે; US ICER સંસ્થા $50,000–$200,000/QALY પર અહેવાલ કરે છે; કેનેડા આશરે CAD$50,000/QALY પર કામ કરે છે. તમારું ઉત્પાદન રાષ્ટ્રીય આરોગ્ય સેવા માટે "યોગ્ય" છે કે નહીં, ઔપચારિક રીતે, તે છે કે તેનો ICER સ્થાનિક સીમા પાર કરે છે કે નહીં. જુઓ [ચૂકવવાની તૈયારીની સીમાઓ](../ચૂકવવાની-તૈયારીની-સીમાઓ/).

## ગણિત

```
ICER = (Cost_new − Cost_comparator) / (Effect_new − Effect_comparator)
     = ΔC / ΔE
```

અર્થઘટનના નિયમો:

- ΔC < 0, ΔE > 0: નવો વિકલ્પ **પ્રભાવી** છે — સસ્તો અને વધુ સારો; ગુણોત્તરની જરૂર નથી.
- ΔC > 0, ΔE > 0: ICER ગણો, સીમા λ સાથે સરખાવો; ICER < λ હોય તો અપનાવો.
- ΔC > 0, ΔE < 0: નવો વિકલ્પ પ્રભાવિત છે — નકારો.
- ΔE = 0 ની નજીક ગુણોત્તર ખરાબ વર્તે છે — ક્રમ આપવા માટે [ચોખ્ખો નાણાકીય લાભ](../ચોખ્ખો-નાણાકીય-લાભ/) પસંદ કરો.

તુલનાકાર *આગામી-શ્રેષ્ઠ અપ્રભાવિત વિકલ્પ* હોવો જોઈએ, "કંઈ ન કરવું" નહીં — જુઓ [પ્રભુત્વ અને કાર્યક્ષમતા સીમા](../પ્રભુત્વ-અને-કાર્યક્ષમતા-સીમા/).

## ઉકેલેલું ઉદાહરણ

હૃદય-નિષ્ફળતાના દર્દીઓ માટે રિમોટ-મૉનિટરિંગ સેવા, 1,000 દર્દી/વર્ષ દીઠ, સામાન્ય સંભાળ સામે:

```
Costs:   service £900,000; admissions avoided save £600,000
         ΔC = 900,000 − 600,000 = £300,000
Effects: earlier intervention gains 25 QALYs
         ΔE = 25

ICER = 300,000 / 25 = £12,000 per QALY
```

£12,000/QALY NICE ની £20,000 સીમાથી આરામથી નીચે છે — મજબૂત કેસ. નોંધો કે *ચોખ્ખો* ખર્ચ કેવી રીતે મહત્ત્વનો છે: £600,000 ઑફસેટ વિના ICER £36,000/QALY હોત અને કેસ કદાચ નિષ્ફળ જાત. આ વિશ્લેષણો ઑફસેટ અને તેમની પુરાવા ગુણવત્તામાં જીતાય કે હારાય છે ([ટાળેલા ડાઉનસ્ટ્રીમ ખર્ચ](../ટાળેલા-ડાઉનસ્ટ્રીમ-ખર્ચ/) જુઓ).

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

ICER શિસ્ત એન્જિનિયરિંગ નિર્ણયો પર સંપૂર્ણ રીતે સ્થાનાંતરિત થાય છે:

```
(cost of option B − cost of option A) / (outcome B − outcome A)
```

— વધારાના ડિપ્લોય દીઠ, બચેલા એન્જિનિયર-કલાક દીઠ, ટાળેલી ઘટના દીઠ વૃદ્ધિશીલ ખર્ચ — હંમેશા આગામી-શ્રેષ્ઠ વિકલ્પ સામે, કંઈ ન કરવા સામે નહીં. ચોરવા જેવી બે ટેવો: (1) *તુલનાકારનું સ્પષ્ટ નામ આપો*; મોટાભાગના ટૂલ ROI દાવા ગુપ્ત રીતે ભૂસા-માણસ સામે સરખાવે છે; (2) *પહેલાં ખર્ચ ચોખ્ખો કરો* — £100k નો ખર્ચ કરતું પણ £80k ના હાલના ખર્ચને વિસ્થાપિત કરતું ટૂલ ΔC = £20k ધરાવે છે.

## સામાન્ય ભૂલો

- **સ્પષ્ટ રૂપાંતરણ પગલા વિના ચલણો વચ્ચે ICER ની સરખામણી**: એક દેશના ચલણમાં ગણેલા ICER ને બીજા દેશની સીમા સાથે સરખાવતા પહેલાં જણાવેલી પદ્ધતિથી રૂપાંતરિત કરવો જોઈએ — રૂપાંતરણ ગુણકની પસંદગી (ખરીદ શક્તિ સમતા વિરુદ્ધ બજાર વિનિમય દર) પોતે અપનાવવાનો નિર્ણય કેમ પલટાવી શકે તે માટે [આંતર-ચલણ ICER સરખામણી](../આંતર-ચલણ-icer-સરખામણી/) જુઓ.
- **તુલનાકાર સાથે રમત**: અપ્રચલિત કે કૃત્રિમ રીતે ખરાબ આધારરેખા સામે સરખામણી ΔE ફુલાવે છે અને ICER ની ખુશામત કરે છે.
- **વૃદ્ધિને બદલે સરેરાશ**: સમગ્ર કાર્યક્રમનો QALY દીઠ ખર્ચ તેને વિસ્તારવા કે અપનાવવાનો ICER નથી.
- **બિંદુ-અંદાજ પૂજા**: ICER બે અનિશ્ચિત તફાવતોના ગુણોત્તર છે; [PSA અને CEAC](../સંભાવનાત્મક-સંવેદનશીલતા-વિશ્લેષણ/) દ્વારા અનિશ્ચિતતા અહેવાલ કરો.
- **ઋણ ICER અસ્પષ્ટ છે** (સસ્તો-અને-વધુ-સારો વિરુદ્ધ મોંઘો-અને-ખરાબ સમાન ચિહ્ન આપે છે) — કયો ચતુર્થાંશ છે તે કહ્યા વિના ક્યારેય ઋણ ICER અહેવાલ ન કરો.
