# માલિકીનો કુલ ખર્ચ (TCO)

TCO એ સિસ્ટમના જીવનકાળ દરમિયાનનો સંપૂર્ણ ખર્ચ છે: સંપાદન અથવા નિર્માણ, ઇન્ટિગ્રેશન, સંચાલન, જાળવણી, સપોર્ટ, તાલીમ અને નિવૃત્તિ. અસુખદ આધારરેખા: **જાળવણી સૉફ્ટવેર TCO ના 50–80% છે** — જીવનકાળ ખર્ચનો લગભગ ત્રણ-ચતુર્થાંશ ભાગ લૉન્ચ *પછી* આવે છે.

## આ શા માટે મહત્ત્વનું છે

આરોગ્ય ટેક્નોલૉજી મૂલ્યાંકન ઘણા સમય પહેલાં શીખ્યું કે દવાની કિંમત તેનો ખર્ચ નથી — વહીવટ, નિરીક્ષણ અને આડઅસરોનું સંચાલન બધું મૉડેલમાં હોવું જોઈએ. જે સૉફ્ટવેર બિઝનેસ કેસ ફક્ત બિલ્ડ/લાઇસન્સ ખર્ચ ગણે છે તે નિષ્કપટ-દવા-ભાવની ભૂલ પુનરાવર્તિત કરે છે અને તે જે દરેક [ICER](../વૃદ્ધિશીલ-ખર્ચ-અસરકારકતા-ગુણોત્તર/) અને [બજેટ અસર](../બજેટ-અસર-વિશ્લેષણ/) ને ખવડાવે છે તેના ખર્ચ બાજુને વ્યવસ્થિત રીતે ઓછી આંકે છે. NHS ખરીદીમાં, TCO શિસ્ત ડિજિટલ ઉત્પાદનના ખર્ચ-અસરકારકતા દાવાને પ્રામાણિક બનાવે છે — અને ત્યાં જ સસ્તા દેખાતા વિકલ્પો હારે છે.

## ગણિત

```
TCO = initial cost (build/licence + integration + data migration + training)
    + Σ_t [operations + maintenance + support + infrastructure + upgrades
           + compliance/assurance]_t / (1 + r)^t
    + decommissioning cost (exit, data extraction, parallel running)

Horizon: 3–5 years commercial, system-lifetime for clinical infrastructure
r: 3.5% public sector (Green Book), 8–12% commercial
Benchmarks: annual maintenance ≈ 15–20% of build cost; ~78% of lifetime
TCO post-launch; ignore decommissioning and vendor lock-in prices itself.
```

## ઉકેલેલું ઉદાહરણ

ઇ-ઑબ્ઝર્વેશન સિસ્ટમ માટે બે વિકલ્પો, 5-વર્ષ ક્ષિતિજ:

```
                        Vendor SaaS     In-house build
Year 0 (licence/build)  £250,000        £900,000
Integration + training  £180,000        £150,000
Annual run (yrs 1–5)    £120,000/yr     £190,000/yr  (hosting + 1.5 FTE maint.)
Exit/decommission       £60,000         £30,000

Undiscounted TCO        £1,090,000      £2,030,000
```

બિલ્ડ વિકલ્પનો એન્જિનિયરિંગ અંદાજ (£900k) તેના સાચા TCO નો ફક્ત 44% હતો — અને બિલ્ડ અંદાજો પોતે સામાન્ય રીતે 30–40% વટાવે છે ([બિલ્ડ વિરુદ્ધ ખરીદ](../બનાવો-વિરુદ્ધ-ખરીદો/) જુઓ). જ્યાં સુધી ઇન-હાઉસ વિકલ્પ સારી રીતે જુદા *પરિણામો* ન આપે, [ખર્ચ-લઘુતમીકરણ](../ખર્ચ-લઘુતમીકરણ-વિશ્લેષણ/) તર્ક લાગુ પડે છે અને SaaS લગભગ £940k થી જીતે છે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

બિલ્ડની તરફેણ કરતી વખતે એન્જિનિયરો પોતાના ક્ષેત્રના જાળવણી ડેટાને ઓછું વજન આપે છે: બિલ્ડ ખર્ચના 15–20% વાર્ષિક જાળવણી નિયમનો અર્થ છે કે દરેક £1M સિસ્ટમ શાંતિથી £150–200k/વર્ષ ભાવિ ક્ષમતાની પ્રતિબદ્ધતા કરે છે — એવી જવાબદારી જે [ટેકનિકલ ડેટ](../ટેકનિકલ-ડેટ/) જેવી જ માનસિક બૅલન્સ શીટ પર છે. TCO આ રિપોઝિટરીના દરેક મેટ્રિકનો ખર્ચ અડધો ભાગ પણ છે: ડિપ્લોયમેન્ટ દીઠ ખર્ચ, [ક્લાઉડ યુનિટ ઇકોનોમિક્સ](../ક્લાઉડ-યુનિટ-ઇકોનોમિક્સ/), અને છેદ શિસ્ત જે HTA દવા પ્રાયોજકો પર લાગુ કરે છે. જ્યારે તમારા ઉત્પાદનના ભાવને પડકાર મળે, ત્યારે પ્રસ્થાપિતના સાચા ચાલુ ખર્ચ સહિતની TCO સરખામણી સામાન્ય રીતે ઉપલબ્ધ સૌથી મજબૂત પુનઃફ્રેમિંગ છે. ઉપર જેવો બહુ-વર્ષીય TCO આંકડો સમય પર અનેક ખર્ચ લાઇન આઇટમનો સરવાળો છે — એકવાર મૉડેલને પેની સુધી મેળ ખાવો પડે ત્યારે તે સરવાળો ફ્લોટિંગ પૉઇન્ટને બદલે ચોક્કસ-દશાંશ કેમ હોવો જોઈએ તે માટે [ચલણ-સુરક્ષિત ખર્ચ રોલઅપ](../ચલણ-સુરક્ષિત-ખર્ચ-રોલઅપ/) જુઓ, અને પેની ગુમાવ્યા વગર TCO કુલને ખર્ચ કેન્દ્રો વચ્ચે વહેંચવા [ચોક્કસ-સેન્ટ ખર્ચ ફાળવણી](../ચોક્કસ-સેન્ટ-ખર્ચ-ફાળવણી/) જુઓ.

## સામાન્ય ભૂલો

- **લૉન્ચ-ખર્ચ ઍન્કરિંગ**: વર્ષ-0 ખર્ચે વિકલ્પો સરખાવવા જ્યારે ક્રમ વર્ષ 3 સુધીમાં ઊલટો થાય છે.
- **મફત-આંતરિક-શ્રમ ભ્રમ**: ઇન-હાઉસ જાળવણીને શૂન્ય ખર્ચ ગણવી કારણ કે "ટીમને પહેલેથી પગાર મળે છે" — [તકની કિંમત](../તકની-કિંમત/) જુઓ.
- **નિર્ગમ ખર્ચ અવગણવા**: ડેટા ઇગ્રેસ, કરાર સમાપ્તિ અને સમાંતર ચલાવવું ત્યાં છે જ્યાં "સસ્તું" SaaS મોંઘું બને છે.
- **સમાન-ક્ષિતિજ ઉલ્લંઘન**: 3-વર્ષના SaaS TCO ને 10-વર્ષના બિલ્ડ અવમૂલ્યન સામે સરખાવવું ([સમય-ક્ષિતિજ](../સમય-ક્ષિતિજ/) જુઓ).
