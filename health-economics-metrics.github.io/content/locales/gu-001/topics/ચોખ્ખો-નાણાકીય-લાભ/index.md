# ચોખ્ખો નાણાકીય લાભ (NMB)

NMB ખર્ચ-અસરકારકતા પરિણામને એક જ નાણા મૂલ્યમાં ફેરવે છે: ચૂકવવાની-તૈયારી સીમા પર કિંમત આંકેલો આરોગ્ય લાભ, ઓછા ખર્ચ. તેનું જોડિયું, ચોખ્ખો આરોગ્ય લાભ (NHB), એ જ નિયમ આરોગ્ય એકમોમાં વ્યક્ત કરે છે.

## આ શા માટે મહત્ત્વનું છે

ગુણોત્તર ([ICER](../વૃદ્ધિશીલ-ખર્ચ-અસરકારકતા-ગુણોત્તર/)) અટપટા છે: તે શૂન્ય અસરની નજીક વિસ્ફોટે છે, અનિશ્ચિતતા ડ્રૉ પર સરેરાશ લઈ શકાતા નથી, અને ત્રણ કે વધુ વિકલ્પોને સ્વચ્છ રીતે ક્રમ આપી શકતા નથી. NMB તે બધું ઠીક કરે છે — તે રેખીય છે, તેથી તમે વિકલ્પોને ક્રમ આપી શકો, મોન્ટે કાર્લો ડ્રૉની સરેરાશ લઈ શકો, અને ફાળાઓનું વિઘટન કરી શકો. તે દરેક એન્જિનિયર પહેલેથી જાણે છે તેવા આરોગ્ય-આર્થિક ગણિતનું સ્વરૂપ પણ છે: *મૂલ્ય ઓછા ખર્ચ*.

## ગણિત

```
NMB = (ΔE × λ) − ΔC
NHB = ΔE − (ΔC / λ)

ΔE = incremental effect (e.g., QALYs)
ΔC = incremental cost
λ  = willingness-to-pay threshold (see willingness-to-pay-thresholds.md)

Decision rule: adopt if NMB > 0 (equivalently NHB > 0).
Among alternatives: choose the highest NMB.
```

NMB > 0 ⇔ ICER < λ (જ્યારે ΔE > 0), તેથી બંને નિયમો સંમત છે — NMB ફક્ત વધુ સારી રીતે વર્તે છે.

## ઉકેલેલું ઉદાહરણ

ડાયાબિટીસ સેવા માટેના ત્રણ વિકલ્પો, 1,000 દર્દી દીઠ, λ = £20,000/QALY:

```
Option           ΔC          ΔE (QALYs)   NMB = 20,000×ΔE − ΔC
App + coaching   £400,000    30           600,000 − 400,000 = £200,000
App only         £150,000    12           240,000 − 150,000 = £90,000
Extra clinics    £700,000    32           640,000 − 700,000 = −£60,000
```

વધારાની ક્લિનિક્સ સૌથી વધુ QALY મેળવે છે પણ આ સીમા પર મૂલ્ય નષ્ટ કરે છે (NMB < 0). ઍપ + કોચિંગ જીતે છે. નોંધો કે NMB તમને ત્રણેયને *એકસાથે ક્રમ* આપવા દે છે — જોડીવાર ICER ને [પ્રભુત્વ અને કાર્યક્ષમતા સીમા](../પ્રભુત્વ-અને-કાર્યક્ષમતા-સીમા/) માંની સીમા પ્રક્રિયા જોઈએ, અને એ જ જવાબ પર પહોંચે.

વિજેતાનું NHB દૃશ્ય: 30 − 400,000/20,000 = 30 − 20 = **10 QALY ચોખ્ખું** — એ જ નાણાંએ બીજે જે ઉત્પન્ન કર્યું હોત તેનાથી વધુ મેળવેલો આરોગ્ય.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

`(hours saved × loaded hourly rate) − tool cost` — રોજિંદો ટૂલિંગ બિઝનેસ કેસ — શાબ્દિક રીતે λ = લોડેડ એન્જિનિયર ખર્ચ સાથેની NMB ગણતરી છે. આરોગ્ય અર્થશાસ્ત્ર બે સુધારા ઉમેરે છે:

- **λ ને અચળ નહીં, ચલ બનાવો.** NMB ને λ ("એન્જિનિયર-કલાકનું મૂલ્ય") સામે આલેખો અને બતાવો કે નિર્ણય ક્યાં પલટાય છે; જુદા હિતધારકો પછી તમારું ગણિત ફરી કર્યા વિના પોતાનું મૂલ્યાંકન લાગુ કરી શકે.
- **NHB વિચાર**: "આ પ્લૅટફૉર્મ 5,000 એન્જિનિયર-કલાક બચાવે છે પણ એવું બજેટ વાપરે છે જેણે 3,000 એન્જિનિયર-કલાક કૉન્ટ્રાક્ટર ક્ષમતા ખરીદી હોત — ચોખ્ખા 2,000 કલાક" તકની કિંમતની સરખામણી ક્ષમતા એકમોમાં ફરજિયાત કરે છે. જુઓ [તકની કિંમત](../તકની-કિંમત/).

## સામાન્ય ભૂલો

- **સીમા છુપાવવી**: λ જણાવ્યા વિના NMB અર્થહીન છે; NMB £20k અને £30k પર અહેવાલ કરો, અથવા વક્ર આલેખો.
- **નાની અસરો ધોવા NMB વાપરવો**: વિશાળ વસ્તી ગુણ નગણ્ય પ્રતિ-વ્યક્તિ અસર મોટો NMB આપી શકે; પ્રતિ-વ્યક્તિ અસરો સાથે અહેવાલ કરો.
- **NMB ΔC અને ΔE ની દરેક અનિશ્ચિતતા વારસામાં મેળવે છે તે ભૂલવું** — [સંભાવનાત્મક સંવેદનશીલતા વિશ્લેષણ](../સંભાવનાત્મક-સંવેદનશીલતા-વિશ્લેષણ/) સાથે જોડો.
