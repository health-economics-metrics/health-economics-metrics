# સારવાર માટે જરૂરી સંખ્યા (NNT)

NNT એ દર્દીઓની સંખ્યા છે જેમણે હસ્તક્ષેપ મેળવવો જોઈએ જેથી જણાવેલ સમયગાળામાં **એક** વધારાના દર્દીને લાભ થાય. તે ટકાવારી જોખમ ઘટાડા — જે ગેરમાર્ગે દોરે છે — ને પ્રયાસ-દીઠ-લાભ એકમોમાં ફેરવે છે જેના વિશે કોઈપણ તર્ક કરી શકે.

## આ શા માટે મહત્ત્વનું છે

"હાર્ટ એટેક 25% ઘટાડે છે!" નિર્ણાયક લાગે છે. જો આધારરેખા જોખમ 5 વર્ષમાં 4% હોય, તો નિરપેક્ષ ઘટાડો 1 ટકા-બિંદુ છે, તેથી **1 ને લાભ થવા 100 લોકોએ 5 વર્ષ દવા લેવી પડે** — અને તમામ 100 ખર્ચ અને આડઅસરો ચૂકવે છે. NNT સાપેક્ષ-જોખમ માર્કેટિંગનો મારણ છે, એટલે જ પુરાવા-આધારિત દવા તેનાથી શરૂ કરે છે. પ્રાથમિક નિવારણ માટે સ્ટેટિન્સ: ટાળેલા હાર્ટ એટેક દીઠ 5 વર્ષમાં NNT ≈ 50–100. તેનું પ્રતિબિંબ, **NNH** (નુકસાન માટે જરૂરી સંખ્યા), ગણે છે કે એક વ્યક્તિને નુકસાન થવા દીઠ કેટલાની સારવાર થઈ.

## ગણિત

```
ARR = control event rate − treatment event rate   (absolute risk reduction)
NNT = 1 / ARR

NNH = 1 / (harm rate_treatment − harm rate_control)

Economic bridge:
cost per event prevented = NNT × cost per treatment course
```

સમયગાળો અને આધારરેખા વસ્તી હંમેશા જણાવો — બંને વિના NNT અર્થહીન છે.

## ઉકેલેલું ઉદાહરણ

હૉસ્પિટલમાં પડવાની-આગાહી પ્રણાલી ઉચ્ચ-જોખમ દર્દીઓને હસ્તક્ષેપ (બેડ સેન્સર, સમીક્ષા, દેખરેખ) માટે ફ્લૅગ કરે છે. ટ્રાયલ: ઈજા સાથે પડવું દાખલના 3.2% થી 2.4% થાય છે.

```
ARR = 0.8 percentage points → NNT = 1/0.008 = 125
   (125 patients must get the intervention bundle to prevent 1 injurious fall)

Intervention cost ≈ £40/patient → cost per fall prevented = 125 × 40 = £5,000
Cost of an injurious inpatient fall (extra stay, imaging, litigation) ≈ £12,000
Net: prevention pays ~2.4:1 — and the QALY gain is on top.
```

નોંધો કે NNT દાવાને કેવી રીતે પ્રામાણિક રાખે છે: "પડવું 25% ઘટાડે છે" અને "સારવાર થયેલા દર 125 દર્દી દીઠ એક પડવું અટકાવો" એ જ પરિણામ છે, અલગ રીતે પ્રેરક.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

NNT એ કોઈપણ દ્વાર કે તપાસ માટે યોગ્ય એકમ છે જે થોડા પકડવા ઘણી વસ્તુઓ પર કામ કરે: **"ઉત્પાદન-તરફ-જતો એક ખામી પકડવા AI રિવ્યૂ દ્વારમાંથી કેટલા PR પસાર થવા જોઈએ."** જો દ્વાર દરેક સાચા પકડ દીઠ 400 PR રિવ્યૂ કરે (NNT = 400) દરેક પર 4 મિનિટ ડેવલપર ધ્યાન સાથે, તો એક પકડનો ખર્ચ ~27 ડેવલપર-કલાક — હવે તેની સરખામણી તે અટકાવતી ઘટનાના ખર્ચ સાથે કરો. NNH ખોટા હકારાત્મકો સાથે મેપ થાય છે: *ખોટા* ફ્લૅગ દીઠ કેટલા PR, અને દરેકનો ધ્યાન અને વિશ્વાસમાં ખર્ચ શું? સ્ક્રીનિંગ-શૈલી ટૂલિંગ (લિન્ટર, સુરક્ષા સ્કૅનર, વિસંગતતા શોધ) NNT/NNH અંકગણિત સાથે મોકલવું જોઈએ — નીચો વ્યાપ આ સંખ્યાઓને કેમ ક્રૂર બનાવે છે તે માટે [સ્ક્રીનિંગ અર્થશાસ્ત્ર](../સ્ક્રીનિંગ-અર્થશાસ્ત્ર/) જુઓ. [સ્ક્રીનિંગ માટે જરૂરી સંખ્યા](../સ્ક્રીનિંગ-માટે-જરૂરી-સંખ્યા/) એક સ્તર ઉપરનો સમાન આંકડો છે, ફક્ત સારવાર નહીં પણ આખા સ્ક્રીન-પછી-સારવાર કાર્યક્રમ માટે.

## સામાન્ય ભૂલો

- **સમયગાળો નહીં**: "NNT = 50" નો કોઈ અર્થ નથી; "5 વર્ષમાં NNT = 50" દાવો છે.
- **આધારરેખા-જોખમનું પ્રત્યારોપણ**: ઉચ્ચ-જોખમ ટ્રાયલ વસ્તીમાં ગણેલો NNT નીચા-જોખમ ડિપ્લોયમેન્ટ વસ્તીમાં તૂટી પડે છે.
- **NNH ની અવગણના** — NNT 400 અને NNH 3 ધરાવતો દ્વાર ખલેલ જનરેટર છે, સલામતી પ્રણાલી નહીં.
