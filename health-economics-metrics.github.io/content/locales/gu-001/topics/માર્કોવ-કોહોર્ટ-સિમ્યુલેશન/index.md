# માર્કોવ કોહોર્ટ સિમ્યુલેશન

માર્કોવ કોહોર્ટ મૉડેલ એ એવા હસ્તક્ષેપો માટેની પ્રમાણભૂત HTA મૉડેલિંગ તકનીક છે જેમની અસરો એક જ વારમાં નહીં, પણ અનેક સમય ગાળા (ચક્ર)માં ખુલે છે. કાલ્પનિક કોહોર્ટ સંપૂર્ણપણે એક આરોગ્ય અવસ્થામાં શરૂ થાય છે, અને દરેક ચક્રમાં સંક્રમણ સંભાવનાઓનો નિશ્ચિત સમૂહ કોહોર્ટના અપૂર્ણાંકોને અવસ્થાઓ વચ્ચે ખસેડે છે; દરેક અવસ્થા કોહોર્ટનો કેટલો ભાગ રોકે છે તેના પ્રમાણમાં ખર્ચ અને QALY દરેક ચક્રમાં જમા થાય છે, અને વર્તમાન મૂલ્ય સુધી ડિસ્કાઉન્ટ થાય છે. બહુ-વર્ષીય ડિજિટલ-આરોગ્ય બિઝનેસ કેસનું મૉડેલિંગ કરતો કોઈપણ સૉફ્ટવેર એન્જિનિયર — જ્યાં વપરાશકર્તાઓ કે દર્દીઓ સમય સાથે "જોડાયેલા", "ચૂકી ગયેલા" કે "છોડી ગયેલા" જેવી અવસ્થાઓ વચ્ચે ખસે છે — એ જ માળખું બનાવી રહ્યો છે.

## આ શા માટે મહત્ત્વનું છે

મોટાભાગના વાસ્તવિક આરોગ્ય-ટેકનોલોજી નિર્ણયો એક જ સમયગાળાના ખર્ચ અને પરિણામની એક-વારની સરખામણી નથી. લાંબો રોગ વર્ષો દરમ્યાન આગળ વધે છે, ફરી ઉથલો મારે છે, સારવારનો પ્રતિભાવ આપે છે, કે જીવ લે છે — અને એક-સમયગાળાનું [ખર્ચ-અસરકારકતા વિશ્લેષણ](../ખર્ચ-અસરકારકતા-વિશ્લેષણ/) તે રજૂ કરી શકતું નથી. [આરોગ્ય ટેકનોલોજી મૂલ્યાંકન](../આરોગ્ય-ટેકનોલોજી-મૂલ્યાંકન/) દ્વારા મૂલ્યાંકિત લાંબા-રોગ હસ્તક્ષેપો માટે NICE, ICER અને CADTH સબમિશન લગભગ હંમેશા આજીવન સમય ક્ષિતિજ સાથે માર્કોવ કોહોર્ટ મૉડેલ તરીકે બનાવાય છે, કારણ કે વિકલ્પ — દરેક સંભવિત વ્યક્તિગત દર્દી માર્ગનું મૉડેલિંગ — સ્કેલ પર અશક્ય છે. કોહોર્ટ-સ્તરનું માર્કોવ મૉડેલ થોડી વ્યક્તિગત-સ્તરની વાસ્તવિકતા છોડે છે (તે ભૂતકાળની અવસ્થાઓની સ્મૃતિ સરળતાથી રજૂ કરી શકતું નથી, તેથી "માર્કોવ": ભવિષ્ય ફક્ત વર્તમાન અવસ્થા પર આધાર રાખે છે) તેના બદલે પારદર્શક, ઑડિટ કરી શકાય તેવું અને [સંભાવનાત્મક સંવેદનશીલતા વિશ્લેષણ](../સંભાવનાત્મક-સંવેદનશીલતા-વિશ્લેષણ/) માં હજારો વાર ચલાવવા જેટલું ઝડપી મૉડેલ મળે છે.

## ગણિત

```
One cycle's cohort update (row-vector x transition matrix):
  new_state[j] = sum_i state[i] * transition_matrix[i][j]

One cycle's cost:
  cycle_cost = sum_s state[s] * cost_per_cycle[s]

One cycle's QALYs:
  cycle_qalys = sum_s state[s] * utility[s] * cycle_length_years

Full simulation over `cycles` cycles, discounted at `discount_rate`:
  total_discounted_cost  = sum_{t=0}^{cycles-1} cycle_cost(state_t)  / (1 + discount_rate)^t
  total_discounted_qalys = sum_{t=0}^{cycles-1} cycle_qalys(state_t) / (1 + discount_rate)^t
  where state_0 = initial_distribution, state_{t+1} = advance_cohort(state_t, transition_matrix)
```

દરેક ચક્રને વર્તમાન મૂલ્યમાં પાછું ડિસ્કાઉન્ટ કરવું બરાબર [ડિસ્કાઉન્ટિંગ અને સમય-પસંદગી](../ડિસ્કાઉન્ટિંગ-અને-સમય-પસંદગી/) સૂત્ર વાપરે છે, વર્ષ-દર-વર્ષને બદલે ચક્ર-દર-ચક્ર લાગુ.

## ઉકેલેલું ઉદાહરણ

**ક્લિનિકલ**: 2-અવસ્થા મૉડેલ — `Well` અને `Dead` — જ્યાં કોહોર્ટનો 10% દરેક ચક્રમાં મૃત્યુ પામે છે અને `Dead` શોષક છે (તેની સ્વ-સંક્રમણ સંભાવના 1.0 છે; તે સ્વ-લૂપ છોડવાથી `Dead` માં એક ચક્ર પછી કોહોર્ટ દળ અદૃશ્ય થઈ જાય). કોહોર્ટ સંપૂર્ણપણે `Well` થી શરૂ થાય છે, `Well` હોય ત્યારે ચક્ર દીઠ £1,000 ખર્ચ કરે છે (`Dead` થયા પછી £0), અને `Well` હોય ત્યારે વર્ષે 0.8 QALY મેળવે છે. NICE ના 3.5% ડિસ્કાઉન્ટ દરે 3 વાર્ષિક ચક્ર માટે સિમ્યુલેટ:

```
Cycle 0: state = [1.00, 0.00] (100% Well)
  cost = £1,000.00, qalys = 0.800, discount factor = 1.000000
  discounted: cost = £1,000.00, qalys = 0.8000

Cycle 1: state = [0.90, 0.10] (90% Well, 10% Dead)
  cost = £900.00, qalys = 0.720, discount factor = 0.966184
  discounted: cost = £869.57, qalys = 0.6957

Cycle 2: state = [0.81, 0.19] (81% Well, 19% Dead)
  cost = £810.00, qalys = 0.648, discount factor = 0.933511
  discounted: cost = £756.14, qalys = 0.6049

Total discounted cost  ≈ £2,625.71
Total discounted QALYs ≈ 2.1006
```

દરેક ચક્રની અવસ્થા ગયા ચક્રની અવસ્થા સંક્રમણ મૅટ્રિક્સ દ્વારા આગળ લઈ જવાયેલી છે — ચક્ર 1 માં હજુ `Well` રહેલા 90% માંથી 90% ચક્ર 2 માં `Well` રહે છે (0.9 × 0.9 = 0.81), જ્યારે બાકીના 19% હવે મૃત્યુ પામ્યા (0.9 × 0.1 + 0.1 × 1.0 = 0.19). નોંધો કે કોહોર્ટ ક્યારેય `Well` સંપૂર્ણ ખાલી કરતો નથી: સ્થિર 10% પ્રતિ-ચક્ર મૃત્યુદર અને પુનઃપ્રવેશ વિના, `Well` અપૂર્ણાંક કોઈ મર્યાદિત ચક્ર સંખ્યાએ શૂન્ય થવાને બદલે ભૌમિતિક રીતે ક્ષીણ થાય છે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

બહુ-ચક્ર HTA મૉડેલ વાસ્તવિક મૂલ્યાંકનમાં કેવી રીતે વપરાય છે તે માટે, [આરોગ્ય ટેકનોલોજી મૂલ્યાંકન](../આરોગ્ય-ટેકનોલોજી-મૂલ્યાંકન/) જુઓ — સંદર્ભ કેસ જે નક્કી કરે છે કે સબમિટ થયેલા માર્કોવ મૉડેલે કયો ડિસ્કાઉન્ટ દર, ઉપયોગિતા સ્રોત અને સમય ક્ષિતિજ વાપરવા.

માર્કોવ કોહોર્ટ મૉડેલ રચનાત્મક રીતે સંભાવનાત્મક સંક્રમણો ધરાવતું સ્ટેટ મશીન છે, નિશ્ચિત સંખ્યાની ટિક માટે ચલાવાય છે, દરેક ટિકના મૂલ્યને ડિસ્કાઉન્ટ કરે છે. એ જ આકાર સમય સાથે વપરાશકર્તા કોહોર્ટની જાળવણી/અવસ્થા સંક્રમણોનું સિમ્યુલેશન કરે છે — "આ સમયગાળામાં પ્રણાલીનો કેટલો અપૂર્ણાંક ઘટેલી અવસ્થામાં છે, અને તેનો ખર્ચ શું" ના સંચાલન-વિશ્વસનીયતા સંસ્કરણ માટે [DORA મેટ્રિક્સ](../dora-મેટ્રિક્સ/) જુઓ. નક્કર રીતે:

- **જાળવણી/છોડી-જવાનું મૉડેલિંગ** એ "સક્રિય", "જોખમમાં", "છોડી ગયેલા" જેવી અવસ્થાઓ સાથેનું માર્કોવ કોહોર્ટ મૉડેલ છે: નિશ્ચિત માસિક સંક્રમણ મૅટ્રિક્સ, 12 કે 24 માસિક ચક્ર માટે ચલાવાય, તમને કોઈપણ ભવિષ્યના મહિને અપેક્ષિત સક્રિય-વપરાશકર્તા સંખ્યા (અને આવક) કહે છે, જેમ `Well`/`Dead` અપેક્ષિત ટકી રહેનારા કહે છે.
- **વિશ્વસનીયતા અને ઘટના અર્થશાસ્ત્ર**: પ્રણાલીની અવસ્થાઓ (સ્વસ્થ, ઘટેલી, ડાઉન) એ જ રીતે મૉડેલ થઈ શકે, જ્યાં પ્રણાલી ઘટેલી/ડાઉન અવસ્થાઓમાં હોય ત્યારે ડાઉનટાઇમ નુકસાનનો "ચક્ર દીઠ ખર્ચ" જમા થાય — ઘટના-આવૃત્તિ દલીલને ડિસ્કાઉન્ટેડ-ખર્ચ દલીલમાં ફેરવે છે જે સંક્રમણ સંભાવનાઓ બદલતા વિશ્વસનીયતા કામના ખર્ચ સાથે તુલનાત્મક છે.
- **અંતિમ અવસ્થાઓ તરીકે શોષક અવસ્થાઓ**: ક્લિનિકલ મૉડેલમાં `Dead` બરાબર સૉફ્ટવેર મૉડેલમાં "રદ કરેલું સબ્સ્ક્રિપ્શન" કે "કાયમી ઑફલાઇન" અવસ્થા છે — બંનેને 1.0 ની સ્પષ્ટ સ્વ-સંક્રમણ સંભાવના જોઈએ, નહીં તો સિમ્યુલેશન શાંતિથી દળ ગુમાવે છે.

## સામાન્ય ભૂલો

- **પંક્તિ દીઠ 1 સુધી સરવાળે ન થતી સંક્રમણ સંભાવનાઓ.** 1 થી વધુ કે ઓછા સરવાળાવાળી પંક્તિ શાંતિથી કોહોર્ટને દરેક ચક્રે દળ "ટપકાવે" કે "વધારે" છે — મૉડેલ આઉટપુટ પર વિશ્વાસ કરતાં પહેલાં હંમેશા પંક્તિ સરવાળા તપાસો, કારણ કે મૉડેલ રચના પોતે ભૂલને ફ્લૅગ કરતી નથી.
- **રોગની વાસ્તવિક ગતિશીલતા માટે ચક્ર લંબાઈ બહુ સ્થૂળ.** અઠવાડિયામાં અર્થપૂર્ણ રીતે અવસ્થા બદલતી સ્થિતિ માટે વાર્ષિક ચક્ર ચક્ર-મધ્યે થતા સંક્રમણોને ઓછા આંકે છે; મૉડેલ કરેલી પ્રક્રિયા ખરેખર કેટલી ઝડપથી ખસે છે તેની સરખામણીમાં ટૂંકી ચક્ર લંબાઈ પસંદ કરો.
- **શોષક અવસ્થાના સ્વ-લૂપને ભૂલવું.** શોષક અવસ્થા (મૃત્યુ, કાયમી બંધ કરવું)ને બરાબર 1.0 ની સ્વ-સંક્રમણ સંભાવના જોઈએ. તે છોડો અને તે અવસ્થામાં કોહોર્ટનું દળ એક ચક્ર પછી ઉડી જાય છે, સંચિત ખર્ચ કે QALY નુકસાન ઓછું આંકે છે.
- **ચાલે છે એટલે મૉડેલ માન્ય છે એમ ગણવું.** વિશ્વસનીય-દેખાતી સંક્રમણ સંભાવનાઓ ધરાવતું માર્કોવ કોહોર્ટ મૉડેલ હજુ રચનાત્મક રીતે ખોટું હોઈ શકે (ગુમ અવસ્થાઓ, ખોટું શોષક વર્તન); આઉટપુટ પર વિશ્વાસ કરતાં પહેલાં જાણીતા રોગચાળાશાસ્ત્રીય બેન્ચમાર્ક સામે માન્ય કરો (દા.ત. 5 વર્ષે મૉડેલ કરેલું અસ્તિત્વ પ્રકાશિત અસ્તિત્વ વક્રો સાથે મેળ ખાય છે?).
