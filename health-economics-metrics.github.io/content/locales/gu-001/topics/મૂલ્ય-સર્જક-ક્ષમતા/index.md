# મૂલ્ય-સર્જક ક્ષમતા (સંચાલન સુધારણા)

મૂલ્ય-સર્જક ક્ષમતા એ મુક્ત થયેલા સમયનો "તક લાભ" છે: તમારું સૉફ્ટવેર જે કલાકો મુક્ત કરે છે તેનાથી હૉસ્પિટલ હવે શું *સિદ્ધ* કરી શકે છે. આ તે મેટ્રિક છે જે મુખ્ય સંચાલન અધિકારીઓ અને તબીબી નિયામકો માટે સૌથી વધુ મહત્ત્વનું છે, કારણ કે તે તેમના મૂલ્યાંકન થાય છે તે ચલણમાં બોલે છે — પ્રવૃત્તિ, લક્ષ્યો અને સુધારણા.

## આ શા માટે મહત્ત્વનું છે

NHS પાસે વિશાળ રેફરલ-ટુ-ટ્રીટમેન્ટ બૅકલૉગ છે, અને જે ટ્રસ્ટ રાષ્ટ્રીય પ્રતીક્ષા-સમય ધોરણો ચૂકે છે તેમને નિયમનકારી તપાસ અને હસ્તક્ષેપનો સામનો કરવો પડે છે ([રેફરલ-ટુ-ટ્રીટમેન્ટ](../રેફરલથી-સારવાર/) જુઓ). ભરતી ધીમી અને મર્યાદિત છે; મકાનો નિશ્ચિત છે. એકમાત્ર ઝડપી લીવર એ છે કે હાલના સ્ટાફ અને જગ્યામાંથી વધુ મૂલ્ય-સર્જક પ્રવૃત્તિ મેળવવી. જે સૉફ્ટવેર નિષ્ણાતનો સમય પાછો મેળવે છે તે ફક્ત "પૈસા બચાવતું" નથી — તે *ક્ષમતા ટંકશાળે છે*: ભરતી કે બાંધકામ વગર એવા ક્લિનિક જે અસ્તિત્વમાં ન હોઈ શકત, એવા મૂલ્યાંકનો જે શેડ્યૂલ ન થઈ શકત.

## ગણિત

```
Hidden capacity created = time released → activity units enabled × scheme value

Activity units: outpatient attendances, pre-op assessments, monitoring reviews
Scheme value:   national tariff / NHS Payment Scheme prices
                (see national-tariff-and-unit-costs.md)
```

આ [પ્રૅક્ટિશનર સમય](../પ્રૅક્ટિશનરનો-સમય/) નું આઉટપુટ-આધારિત મૂલ્યાંકન છે, સેવા લાઇન સુધી માપેલું અને ઑપરેશન્સ ટીમ પહેલેથી જે પ્રવૃત્તિ એકમોમાં આયોજન કરે છે તેમાં વ્યક્ત કરેલું.

## ઉકેલેલું ઉદાહરણ

બૅન્ડ 6 નિષ્ણાત નર્સો પ્રી-ઑપરેટિવ મૂલ્યાંકન ક્લિનિક ચલાવે છે. દસ્તાવેજીકરણ સ્વચાલન 25 નર્સો દરેક માટે દિવસ દીઠ 1 કલાક પાછો મેળવે છે; દરેક કલાકમાં 2 મૂલ્યાંકન બંધ બેસે છે.

```
Extra assessments = 25 nurses × 2/day × 250 days = 12,500/year
At ~£120 scheme value per pre-op assessment:
  12,500 × £120 = £1.5M/year of care capacity created
```

— એક પણ નર્સની ભરતી કે એક પણ ઓરડો બાંધ્યા વગર. (આ સ્ટબે મૂળ જે વ્યાપકપણે ટાંકાતું મૉડેલ ટાંક્યું હતું તેણે નાના સમૂહ માટે આંકડો £766,920/વર્ષ મૂક્યો હતો; ગણિતની પેટર્ન સમાન છે — આંકડો નર્સો × સત્રો × ટૅરિફ સાથે માપાય છે.) COO માટે સંચાલન ફ્રેમિંગ: પ્રી-ઑપ મૂલ્યાંકન થિયેટર લિસ્ટ પરની બાધા બનવાનું બંધ કરે છે — દિવસે-રદ થતી શસ્ત્રક્રિયાઓ ઘટે છે, અને થિયેટર ઉપયોગ વધે છે, જ્યાંથી *આગલી* લાભ લાઇન શરૂ થાય છે ([ડાઉનસ્ટ્રીમ સંસાધન ઑપ્ટિમાઇઝેશન](../ડાઉનસ્ટ્રીમ-સંસાધન-ઑપ્ટિમાઇઝેશન/) જુઓ).

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

આ જ પુનઃફ્રેમિંગ ડેવલપર-ઉત્પાદકતા દાવાઓને વેતન ગણિતમાંથી બચાવે છે: મુક્ત થયેલ એન્જિનિયરિંગ સમય, *સંસ્થા અન્યથા પરવડી ન શકે તેવી શિપ થયેલી ક્ષમતા* — ફીચર, માઇગ્રેશન, વિશ્વસનીયતા કાર્ય — તરીકે વ્યક્ત, જે સંસ્થા સીમાંત પર આવી ક્ષમતા માટે જે ચૂકવે છે (કૉન્ટ્રૅક્ટર દરો, અથવા મુલતવી-ભરતી સમકક્ષ) તે પ્રમાણે મૂલવાયેલું. COO ફ્રેમિંગ પ્લૅટફૉર્મ કાર્ય પિચ કરવા વિશે પણ કંઈક શીખવે છે: લાભને તે એકમોમાં વ્યક્ત કરો જેમાં શ્રોતાનું મૂલ્યાંકન થાય છે. ઑપ્સ નેતાઓ પ્રવૃત્તિ અને લક્ષ્યોમાં વિચારે છે, અમૂર્ત કલાકોમાં નહીં; એન્જિનિયરિંગ નેતાઓ રોડમૅપ આઇટમ અને હેડકાઉન્ટમાં વિચારે છે, બચેલી મિનિટોમાં નહીં.

## સામાન્ય ભૂલો

- **માંગ વગર ક્ષમતા દાવા**: 12,500 વધારાના મૂલ્યાંકન સ્લૉટ ત્યારે જ મહત્ત્વના છે જ્યારે શસ્ત્રક્રિયા પાઇપલાઇન તેમને ભરે — ડાઉનસ્ટ્રીમ બાધા તપાસો.
- **ચુકવણી પદ્ધતિ વગર ટૅરિફ મૂલ્ય**: મિશ્ર ચુકવણી હેઠળ, વધારાની પ્રવૃત્તિ વધારાની આવક ન લાવે; મૂલ્ય તેના બદલે પ્રતીક્ષા-યાદી ઘટાડો હોઈ શકે ([પ્રતીક્ષા યાદી અસર](../પ્રતીક્ષા-યાદી-અસર/) જુઓ).
- **ક્ષમતાને રોકડ તરીકે રજૂ કરવી** — આ મુખ્ય બિન-રોકડ-મુક્તિકર લાભ છે; તેને લેબલ કરો ([રોકડ-મુક્તિકર વિરુદ્ધ બિન-રોકડ-મુક્તિકર](../રોકડ-મુક્તિકારક-વિરુદ્ધ-બિન-રોકડ-મુક્તિકારક-બચત/) જુઓ).
