# સંવેદનશીલતા વિશ્લેષણ

નિર્ધારક સંવેદનશીલતા વિશ્લેષણ (DSA) એક સમયે એક ધારણાને વાજબી શ્રેણીમાં બદલે છે, એ જોવા કે નિષ્કર્ષ ટકે છે કે નહીં. પ્રમાણભૂત દૃશ્ય-રજૂઆત ટૉર્નેડો આકૃતિ છે: પરિણામને કેટલું ઝુલાવે છે તે પ્રમાણે ક્રમિત પરિમાણો.

## આ શા માટે મહત્ત્વનું છે

દરેક આર્થિક મૉડેલ અંદાજો પર બનેલું છે — બચેલો સમય, સ્વીકાર, એકમ ખર્ચ. આરોગ્ય ટેક્નોલૉજી મૂલ્યાંકન બિંદુ-અંદાજ ("ROI 340% છે") ત્યાં સુધી સ્વીકારતું નથી જ્યાં સુધી પુરાવો ન હોય કે નિષ્કર્ષ ઇનપુટ પરના વાજબી મતભેદ સામે ટકાઉ છે. ટૉર્નેડો આકૃતિ નિર્ણયકર્તાને કહે છે કે *કઈ ધારણાની ઊલટતપાસ કરવી*: જો કેસ ત્યારે જ ચાલે જ્યારે સૌથી વિવાદાસ્પદ પરિમાણ આશાવાદી છેડે હોય, તો બધા તરત જોઈ શકે છે.

આરોગ્ય અર્થશાસ્ત્રથી સૉફ્ટવેર બિઝનેસ કેસમાં સૌથી વધુ ટ્રાન્સફર થતી ટેવ આ છે.

## ગણિત

શ્રેણી [p_low, p_high] ધરાવતા દરેક પરિમાણ p માટે:

```
Result_low  = model(p = p_low,  all others at base case)
Result_high = model(p = p_high, all others at base case)
Swing(p)    = |Result_high − Result_low|
```

પરિમાણોને ઝુલાવ પ્રમાણે ક્રમ આપો; આધારરેખા પરિણામ આસપાસ આડી પટ્ટીઓ દોરો. પ્રકારો: દ્વિ-માર્ગી DSA (બે પરિમાણોને ગ્રિડ પર બદલો), સીમા વિશ્લેષણ (નિર્ણય પલટાય તે પરિમાણ મૂલ્ય શોધો).

## ઉકેલેલું ઉદાહરણ

200 ડેવલપર્સ માટે AI કોડિંગ સહાયક. આધારરેખા: £39/ડેવ/મહિનો લાઇસન્સ; 30 મિનિટ/ડેવ/દિવસ બચત; લોડેડ ખર્ચ £60/કલાક; 220 કાર્ય દિવસો.

```
Base-case annual benefit = 200 × 0.5h × 220 × £60 = £1,320,000
Annual cost              = 200 × £39 × 12         = £93,600
Base-case net            = £1,226,400
```

ટૉર્નેડો (એક સમયે એક પરિમાણ):

```
Time saved 0.1–1.0 h/day: net = £170,400 … £2,546,400   (swing £2.38M) ← dominates
Loaded cost £40–£80/h:    net = £786,400 … £1,666,400   (swing £0.88M)
Working days 200–240:     net = £1,106,400 … £1,346,400 (swing £0.24M)
Licence £30–£50/mo:       net = £1,248,000 … £1,200,000 (swing £48k)
```

સીમા વિશ્લેષણ: ચોખ્ખો લાભ લગભગ **2.1 મિનિટ/દિવસ** બચતે શૂન્ય થાય છે. નિર્ણય લાઇસન્સ ભાવ પ્રત્યે અસંવેદનશીલ છે અને સંપૂર્ણપણે બચેલા-સમયના અંદાજ પર ટકે છે — તેથી તે માપો, બાકીનું નહીં. (અને યાદ રાખો કે પરિણામ ક્ષમતા છે, રોકડ નહીં — [રોકડ-મુક્તિકર વિરુદ્ધ બિન-રોકડ-મુક્તિકર](../રોકડ-મુક્તિકારક-વિરુદ્ધ-બિન-રોકડ-મુક્તિકારક-બચત/) જુઓ.)

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

એન્જિનિયરો આ વૃત્તિ "X વિશે આપણે ખોટા હોઈએ તો?" તરીકે પહેલેથી કરે છે — DSA તેને વ્યવસ્થિત અને દૃશ્યમાન બનાવે છે. દરેક ટૂલિંગ દરખાસ્ત, ક્ષમતા યોજના અને બિલ્ડ-વિરુદ્ધ-ખરીદ વિશ્લેષણમાં ટૉર્નેડો આકૃતિ મૂકો. તે કોનો અંતઃસ્ફુરણા સાચો તેની દલીલોને કયું પરિમાણ માપવા જવું તેના કરારમાં ફેરવે છે — ઘણીવાર પાઇલટ દ્વારા, જેનું મૂલ્ય પોતે ભાવિત કરી શકાય ([સંપૂર્ણ માહિતીનું અપેક્ષિત મૂલ્ય](../સંપૂર્ણ-માહિતીનું-અપેક્ષિત-મૂલ્ય/) જુઓ).

## સામાન્ય ભૂલો

- **ખુશામતી શ્રેણીઓ**: વાસ્તવિક અનિશ્ચિતતા ગમે તે હોય, દરેક ઇનપુટ આસપાસ ±10%. બચેલા-સમયના અંદાજ ±80% ને લાયક છે; લાઇસન્સ ભાવ ±10%.
- **એક-સમયે-એક પારસ્પરિક અસરો ચૂકે છે** — સહસંબંધિત પરિમાણો (સ્વીકાર અને બચેલો સમય) ને દ્વિ-માર્ગી વિશ્લેષણ અથવા સંપૂર્ણ [સંભાવનાત્મક સંવેદનશીલતા વિશ્લેષણ](../સંભાવનાત્મક-સંવેદનશીલતા-વિશ્લેષણ/) જોઈએ.
- **વિશ્લેષણ કરીને અવગણવું**: જો ટૉર્નેડો કહે કે કેસ એક નરમ આંકડા પર ટકે છે, તો આગળનું પગલું માપન છે, મંજૂરી નહીં.
