# આરોગ્ય ટેકનોલોજી મૂલ્યાંકન (HTA)

HTA એ ઔપચારિક, સંસ્થાકીય પ્રક્રિયા છે જેના દ્વારા આરોગ્ય પ્રણાલીઓ નક્કી કરે છે કે ટેકનોલોજી — દવા, ઉપકરણ કે સૉફ્ટવેર — ચૂકવવા યોગ્ય છે કે નહીં. તે પ્રકાશિત, ફરજિયાત પદ્ધતિ હેઠળ ક્લિનિકલ-અસરકારકતા પુરાવાને આર્થિક મૂલ્યાંકન સાથે જોડે છે.

## આ શા માટે મહત્ત્વનું છે

જો તમે રાષ્ટ્રીય આરોગ્ય સેવાને વેચો, તો HTA સંસ્થા શાબ્દિક રીતે તમારી બજાર પહોંચ નક્કી કરી શકે. સ્થાનિક પ્રક્રિયા જાણવી એટલે તમારા સાચા મૂલ્ય-નિયામકને જાણવું:

- **NICE (ઇંગ્લેન્ડ)**: નિર્ધારિત *સંદર્ભ કેસ* હેઠળ વૈધાનિક મૂલ્યાંકનો — [EQ-5D](../eq-5d/) માંથી QALY, NHS+PSS [દૃષ્ટિકોણ](../વિશ્લેષણ-દૃષ્ટિકોણ/), 3.5% [ડિસ્કાઉન્ટિંગ](../ડિસ્કાઉન્ટિંગ-અને-સમય-પસંદગી/), [PSA](../સંભાવનાત્મક-સંવેદનશીલતા-વિશ્લેષણ/) જરૂરી — [ગંભીરતા સંશોધકો](../qaly-ઘટ-અને-ગંભીરતા-સંશોધકો/) સાથે £20k–£30k/QALY સામે નક્કી; અત્યંત વિશિષ્ટ ટેકનોલોજી ભારણ સાથે £100k+ સુધી.
- **ICER (US, બિન-સરકારી)**: *આરોગ્ય-લાભ ભાવ બેન્ચમાર્ક* સાથે પુરાવા અહેવાલો — ઉત્પાદન $100k–$150k પ્રતિ QALY/evLYG પર ખર્ચ-અસરકારક બને તે ભાવ — વાટાઘાટના લિવરેજ તરીકે વપરાય; ઉપરાંત બજેટ-અસર "પોસાણક્ષમતા ચેતવણીઓ."
- **કેનેડા (CADTH → CDA-AMC)**: ≈CAD$50k/QALY પર ભરપાઈ સમીક્ષાઓ; ઐતિહાસિક રીતે ~95% સબમિશનમાં ભાવ ઘટાડાની વિનંતી કરી.

## ગણિત

HTA ની શક્તિ સૂત્ર નથી પણ **ફરજિયાત પદ્ધતિ** છે: દરેક સબમિશન એ જ સંદર્ભ-કેસ નિયમો હેઠળ એ જ [ICER](../વૃદ્ધિશીલ-ખર્ચ-અસરકારકતા-ગુણોત્તર/) ગણે છે, તેથી પરિણામો ઉત્પાદનો અને વર્ષો વચ્ચે તુલનાત્મક છે. સંદર્ભ કેસ પરિણામ માપ, ઉપયોગિતા સાધન, દૃષ્ટિકોણ, તુલનાકાર પસંદગી, ડિસ્કાઉન્ટ દર, સમય ક્ષિતિજ અને અનિશ્ચિતતા વિશ્લેષણ નિર્દિષ્ટ કરે છે — સ્પૉન્સર રમત કરી શકે તેવી દરેક સ્વતંત્રતા દૂર કરે છે.

## ઉકેલેલું ઉદાહરણ

એક ડિજિટલ થેરાપ્યુટિક NICE-શૈલી મૂલ્યાંકનમાં સબમિટ કરે છે:

```
Model: ΔC = +£450/patient, ΔE = +0.03 QALYs → ICER = £15,000/QALY ✓ under £20k
Reference-case checks:
  utilities from EQ-5D-5L with UK value set              ✓
  comparator = current care pathway (not "no treatment") ✓
  PSA: 71% probability cost-effective at £20k            ✓ (reported)
  severity modifier: shortfall below ×1.2 bounds         — none claimed
Recommendation: routine commissioning, with real-world data collection.
```

સ્પૉન્સરના પોતાના પસંદગીના વિશ્લેષણે £9,000/QALY બતાવ્યું; સંદર્ભ કેસે પ્રામાણિક તુલનાકાર ફરજિયાત કરીને તેને £15,000 પર ધકેલ્યું. એ અંતર *જ* કારણ છે કે સંદર્ભ કેસ અસ્તિત્વમાં છે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

સ્થાનાંતરિત કરી શકાય તેવી કૃતિ **આંતરિક સંદર્ભ કેસ** છે: બધા ટૂલિંગ/પ્લૅટફૉર્મ બિઝનેસ કેસ માટે એક ફરજિયાત પદ્ધતિ — જાહેર તુલનાકાર, પ્રમાણભૂત એકમ ખર્ચ (પૅટર્ન માટે [રાષ્ટ્રીય ટૅરિફ અને એકમ ખર્ચ](../રાષ્ટ્રીય-ટૅરિફ-અને-એકમ-ખર્ચ/) જુઓ), નિશ્ચિત ડિસ્કાઉન્ટ દર, જરૂરી સંવેદનશીલતા વિશ્લેષણ, પ્રમાણભૂત નમૂનો. પ્લૅટફૉર્મ કાઉન્સિલને સબમિટ કરેલ "ટૂલ્સ માટે AMCP-ડોસિયર" દરખાસ્તોને તુલનાત્મક અને રમતને દેખીતી બનાવે છે, બરાબર જેમ HTA દવા માટે કરે છે. NICE કરતાં નાનાથી શરૂ કરો: બે-પાનાનો નમૂનો વત્તા પ્રકાશિત ભાવ-પુસ્તિકા કોઈ ધોરણ ન હોવા કરતાં સારી.

બહુ-ચક્ર HTA મૉડેલ ખરેખર કોહોર્ટ-દર-ચક્ર કેવી રીતે સિમ્યુલેટ થાય છે તે માટે, [માર્કોવ કોહોર્ટ સિમ્યુલેશન](../માર્કોવ-કોહોર્ટ-સિમ્યુલેશન/) જુઓ.

## સામાન્ય ભૂલો

- **નિયામક ક્લિયરન્સ પછી HTA ને ઔપચારિકતા ગણવી** — CE/UKCA/FDA ક્લિયરન્સ કહે છે કે ઉત્પાદન સલામત છે; HTA નક્કી કરે છે કે તે *ખરીદવા યોગ્ય* છે કે નહીં. અલગ અવરોધ, અલગ પુરાવા.
- **ટ્રાયલ પછી આર્થિક મૉડેલ બનાવવું** — પુરાવા નિર્માણ સંદર્ભ કેસની જરૂરિયાતોથી પાછળની તરફ ડિઝાઇન થવું જોઈએ.
- **અધિકારક્ષેત્ર તફાવતોની અવગણના**: US માં $120k/QALY પર ભંડોળ-યોગ્ય ICER NICE પર £30k એ નિષ્ફળ જાય છે; બજાર દીઠ પુરાવા અને ભાવનું આયોજન કરો.
