# નમૂના માહિતીનું અપેક્ષિત મૂલ્ય (EVSI)

EVSI એ *ચોક્કસ સૂચિત અભ્યાસ*નું મૂલ્ય છે — આપેલી ડિઝાઇન, આપેલું નમૂના કદ — તે ચલાવાય તે પહેલાં, [EVPI](../સંપૂર્ણ-માહિતીનું-અપેક્ષિત-મૂલ્ય/) ની વિરુદ્ધ, જે બધી અનિશ્ચિતતા સંપૂર્ણપણે દૂર કરવાની કિંમત આંકે છે. EVSI એ પ્રશ્નનો જવાબ આપે છે જેનો સંશોધન ભંડોળદાતા ખરેખર સામનો કરે છે: "શું *આ* ટ્રાયલ, *આ* કદે, તેના ખર્ચને યોગ્ય છે?"

## આ શા માટે મહત્ત્વનું છે

EVPI તમને કહે છે કે કોઈપણ સંશોધનનું મૂલ્ય વધુમાં વધુ કેટલું હોઈ શકે; તે ક્યારેય નથી કહેતું કે તમારી સામેની ટ્રાયલ માપદંડ પાર કરે છે કે નહીં. 50-દર્દી પાયલટ અને 500-દર્દી નિર્ણાયક ટ્રાયલ વચ્ચે પસંદગી કરતા રાષ્ટ્રીય સંશોધન ભંડોળદાતાને જાણવું જરૂરી છે કે *દરેક ચોક્કસ ડિઝાઇન*નું મૂલ્ય કેટલું છે, માત્ર સર્વજ્ઞતાનું મૂલ્ય નહીં. EVSI તે સંખ્યા આપે છે, અને કારણ કે તે નમૂના કદ સાથે સ્કેલ થાય છે, તે ભંડોળદાતાને અંદાજ લગાવવાને બદલે અપેક્ષિત ચોખ્ખો લાભ મહત્તમ કરતું નમૂના કદ શોધવા દે છે.

એટલે જ EVSI હંમેશા EVPI કરતાં ઓછું અથવા સમાન હોય છે: મર્યાદિત નમૂનો અનિશ્ચિતતાને ફક્ત આંશિક રીતે ઉકેલી શકે, અને જે અભ્યાસ સંપૂર્ણ માહિતી કરતાં વધુ મૂલ્યવાન દેખાય તે ગણતરી ખોટી હોવાની નિશાની છે, વાસ્તવિક પરિણામ નહીં.

## ગણિત

```
General:
EVSI(n) = E_data[ max_d E_θ|data[NB(d,θ)] ]  −  max_d E_θ[NB(d,θ)]
  (nested expectation: outer over possible study results, inner over the
  posterior belief about θ after seeing that result — usually estimated by
  nested Monte Carlo / Bayesian updating over probabilistic sensitivity
  analysis draws)

Closed-form normal approximation (single uncertain parameter, conjugate
normal-normal model — a standard shortcut, not exact for every model):
EVSI(n) = EVPI × n / (n + n0)

n  = proposed study's sample size
n0 = "prior-equivalent sample size" — the size of an imaginary sample that
     would carry the same information as the current prior, derived from
     the ratio of data variance to prior variance
ENBS(n) = EVSI(n) − Cost(n)
Population EVSI = per-decision EVSI × decisions affected
```

સામાન્ય સ્વરૂપ નેસ્ટેડ અપેક્ષા છે કારણ કે અભ્યાસનું ભવિષ્યનું પરિણામ પોતે અનિશ્ચિત છે: તમારે અભ્યાસ ઉત્પન્ન કરી શકે તેવા દરેક સંભવિત ડેટાસેટ પર સરેરાશ લેવી પડે, અને દરેક માટે અપડેટ થયેલી (posterior) માન્યતા આપેલી શ્રેષ્ઠ નિર્ણય ફરી ગણવો પડે. બંધ-સ્વરૂપ સામાન્ય અંદાજ તે ગણતરી ખર્ચને એક ગુણોત્તર સાથે બદલે છે, જે ત્યારે માન્ય છે જ્યારે અનિશ્ચિત પરિમાણ અને ડેટા (લગભગ) સામાન્ય રીતે વિતરિત અને conjugate હોય — સગવડ, સાર્વત્રિક નિયમ નહીં. જ્યારે તે ધારણા ન ટકે ત્યારે સંપૂર્ણ નેસ્ટેડ મોન્ટે કાર્લો સામાન્ય-હેતુ પદ્ધતિ છે. EVSI સામાન્ય રીતે જેમાંથી અંદાજાય છે તે PSA ડ્રૉ માટે [સંભાવનાત્મક સંવેદનશીલતા વિશ્લેષણ](../સંભાવનાત્મક-સંવેદનશીલતા-વિશ્લેષણ/) જુઓ.

## ઉકેલેલું ઉદાહરણ

[EVPI](../સંપૂર્ણ-માહિતીનું-અપેક્ષિત-મૂલ્ય/) ના ઉકેલેલા ઉદાહરણ પર નિર્માણ — 5,000 ક્લિનિશિયનો માટે AI દસ્તાવેજીકરણ સહાયક રોલઆઉટ, જ્યાં EVPI £1.2M મળ્યું — એ જ EVPI અહીં સંપૂર્ણ પાઉન્ડમાં વ્યક્ત કરો: **EVPI = £1,200,000**.

50 ક્લિનિશિયનોનો સૂચિત પાયલટ અભ્યાસ ટેબલ પર છે. પૂર્વ માન્યતાના વિચરણ અને પાયલટની માપન ચોકસાઈના ગુણોત્તરથી, પૂર્વ-સમકક્ષ નમૂના કદ `n0 = 75` થાય છે:

```
EVSI(50) = 1,200,000 × 50 / (50 + 75)
         = 1,200,000 × 50 / 125
         = 1,200,000 × 0.4
         = £480,000
```

પાયલટનો ખર્ચ £120,000 છે:

```
ENBS = EVSI − Cost = 480,000 − 120,000 = £360,000
```

સ્પષ્ટપણે હકારાત્મક ENBS: પાયલટને ભંડોળ આપો. જો એ જ પ્રાપ્તિ નિર્ણય 3 સમાન પ્રાદેશિક ટ્રસ્ટોમાં પુનરાવર્તિત થાય, તો પાયલટનું મૂલ્ય સ્કેલ થાય છે:

```
Population EVSI = 480,000 × 3 = £1,440,000
```

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

EVSI એ પાયલટ કે A/B ટેસ્ટ *કેટલો મોટો* હોવો જોઈએ તે પસંદ કરવાનું અર્થશાસ્ત્ર છે, માત્ર ચલાવવો કે નહીં તે નહીં:

- **નમૂના-કદ-રોકાણ તરીકેનો નિર્ણય.** 50-વપરાશકર્તા બીટા અને 5,000-વપરાશકર્તા તબક્કાવાર રોલઆઉટ અલગ EVSI અને અલગ ખર્ચવાળા અલગ "અભ્યાસો" છે — EVSI તમને "વધુ ડેટા હંમેશા સારો" ડિફૉલ્ટ કરવાને બદલે તેમને એ જ આધાર પર સરખાવવા દે છે.
- **કમિશનિંગ કસોટી ENBS છે, એકલું EVSI નહીં.** ઊંચું EVSI પણ તેનો મોટો ભાગ ખાઈ જતો ખર્ચ ધરાવતો અભ્યાસ નબળી દરખાસ્ત છે; નિર્ણય નિયમ નમૂનાનો અપેક્ષિત ચોખ્ખો લાભ છે, બરાબર જેમ બિઝનેસ કેસ ફક્ત લાભ અહેવાલ કરવાને બદલે ખર્ચ સામે લાભ ચોખ્ખો કરે છે.
- **ઘટતું વળતર સ્પષ્ટ છે.** કારણ કે EVSI(n) `n/(n+n0)` સાથે વધે છે, પાયલટનું કદ બમણું કરવાથી તેનું મૂલ્ય ક્યારેય બમણું થતું નથી — એન્જિનિયરિંગ સહજવૃત્તિનું ઔપચારિક સંસ્કરણ કે મોટા પ્રયોગનું સીમાંત માહિતી મૂલ્ય ઘટતું જાય છે.

## સામાન્ય ભૂલો

- **સામાન્ય અંદાજને તેની ધારણાઓની બહાર લાગુ કરવો.** તે ફક્ત લગભગ-conjugate, એક-પરિમાણ અનિશ્ચિતતા માટે ટકે છે; ખરેખર અરેખીય કે બહુ-પરિમાણ નિર્ણય મૉડેલને આ શૉર્ટકટ નહીં, સંપૂર્ણ નેસ્ટેડ મોન્ટે કાર્લો જોઈએ.
- **EVSI ની સરખામણી ફક્ત રોકડ ખર્ચ સાથે કરવી.** EVSI ને અભ્યાસના *સંપૂર્ણ* ખર્ચ સામે તોલવું જોઈએ, તેના પોતાના નિર્ણય-વિલંબ ખર્ચ સહિત — જુઓ [વિલંબની કિંમત](../વિલંબની-કિંમત/) — માત્ર અભ્યાસના ઇનવૉઇસ સામે નહીં.
- **EVSI > EVPI ને વાસ્તવિક તારણ ગણવું.** રચના મુજબ EVSI ક્યારેય EVPI થી વધી શકે નહીં; જે ગણતરી આ પેદા કરે તે મૉડેલિંગ બગ છે, શોધ નહીં.
