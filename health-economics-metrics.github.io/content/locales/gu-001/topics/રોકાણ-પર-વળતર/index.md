# રોકાણ પર વળતર (ROI)

ROI એટલે ચોખ્ખા લાભ અને રોકાયેલા નાણાંનો ગુણોત્તર. આ એવું મેટ્રિક છે જે એન્જિનિયરિંગ અને નાણાં પહેલેથી વહેંચે છે — આરોગ્ય અર્થશાસ્ત્ર એ શિસ્ત ઉમેરે છે જે ROI દાવાને તપાસમાં ટકાવે છે: જાહેર કરેલો દૃષ્ટિકોણ, તુલનાત્મક વિકલ્પ, ક્ષિતિજ અને લાભ શ્રેણીઓ.

## આ શા માટે મહત્ત્વનું છે

ROI બજેટ ધારકોની સામાન્ય ભાષા છે, અને જાહેર આરોગ્ય પણ તેનો ઉપયોગ કરે છે: Masters et al. ની ઐતિહાસિક સમીક્ષામાં જાહેર-આરોગ્ય હસ્તક્ષેપો માટે **મધ્યક ROI 14.3:1** મળ્યો (દર £1 વ્યાપક અર્થતંત્ર અને આરોગ્ય તંત્રને ~£14 પાછા આપે છે) — નિવારણ ખર્ચ માટે દલીલ કરવા વ્યાપકપણે વપરાતો આંકડો. પરંતુ તે 14:1 *સામાજિક, લાંબી-ક્ષિતિજ* આકૃતિ છે; હૉસ્પિટલ CFO નો ROI પેયર-દૃષ્ટિકોણ અને 1–3 વર્ષનો હોય છે. મોટાભાગના ROI ઝઘડા ખરેખર અઘોષિત-દૃષ્ટિકોણના ઝઘડા હોય છે.

## ગણિત

```
ROI = (Benefits − Costs) / Costs      (often × 100%)

Payback period = Costs / annual net benefit
```

ચાર ઘોષણાઓ વગર ROI દાવો અધૂરો છે:

1. **દૃષ્ટિકોણ** — કોના લાભ ગણાય? ([વિશ્લેષણ દૃષ્ટિકોણ](../વિશ્લેષણ-દૃષ્ટિકોણ/) જુઓ)
2. **તુલનાત્મક વિકલ્પ** — કયા વિકલ્પની સામે? ([તકની કિંમત](../તકની-કિંમત/) જુઓ)
3. **ક્ષિતિજ** — કેટલા સમય માટે, અને [ડિસ્કાઉન્ટ](../ડિસ્કાઉન્ટિંગ-અને-સમય-પસંદગી/) સાથે?
4. **લાભ વર્ગ** — રોકડ-મુક્તિકર, ક્ષમતા, કે ગુણાત્મક? ([રોકડ-મુક્તિકર વિરુદ્ધ બિન-રોકડ-મુક્તિકર](../રોકડ-મુક્તિકારક-વિરુદ્ધ-બિન-રોકડ-મુક્તિકારક-બચત/) જુઓ)

## ઉકેલેલું ઉદાહરણ

ઇ-રોસ્ટરિંગ સિસ્ટમ, 3 વર્ષમાં ખર્ચ £500,000.

```
Cash-releasing:  agency shift reduction        £450,000
Capacity:        ward-manager admin time freed £600,000 (valued, not banked)
Qualitative:     staff satisfaction, safety    not monetized

Strict financial ROI  = (450,000 − 500,000)/500,000 = −10%
Economic ROI          = (1,050,000 − 500,000)/500,000 = +110%
```

બંને આંકડા સાચા છે. જે CFO ફક્ત £450k બૅન્કમાં લઈ શકે છે તેને "+110% ROI" કહેનાર વિક્રેતા વિશ્વાસ ગુમાવશે; બંને, લેબલ સાથે, રજૂ કરવાથી જીતાશે. આ જ વિભાજન આંતરિક સમર્થકને પણ બચાવે છે જ્યારે નાણાં વિભાગ બે વર્ષ પછી લાભોનું ઑડિટ કરે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

દરેક ટૂલિંગ દરખાસ્તમાં ROI સ્લાઇડ હોય છે; લગભગ કોઈ ચાર પરિમાણ જાહેર કરતી નથી. સૌથી સામાન્ય નિષ્ફળતા શ્રેણી-મિશ્રણ છે: ક્ષમતા લાભ (ડેવલપર મિનિટો) ને નાણાકીય વળતર તરીકે રજૂ કરવા. AI/પ્લૅટફૉર્મ ROI ને ઉપરના ઉકેલેલા ઉદાહરણની જેમ ગોઠવો — રોકડ લાઇન, ક્ષમતા લાઇન, ગુણાત્મક લાઇન — અને નરમ આંકડાઓ પર [સંવેદનશીલતા વિશ્લેષણ](../સંવેદનશીલતા-વિશ્લેષણ/) ઉમેરો. ખાસ કરીને AI ROI ની P&L વાસ્તવિકતા તપાસ માટે [AI રોકાણ પર વળતર](../ai-રોકાણ-પર-વળતર/) જુઓ.

## સામાન્ય ભૂલો

- **દૃષ્ટિકોણ ધોવાણ**: દાયકાભરના સામાજિક લાભ 12-મહિનાની ક્ષિતિજ ધરાવતા બજેટ ધારકને ટાંકવા.
- **ચોખ્ખાને બદલે કુલ**: £2M ખર્ચ પર "£3M પાછા" એ 50% ROI છે, 300% નહીં.
- **ગુણોત્તર મહત્તમીકરણ**: નાના છેદ નજીવા રોકાણો પર અદભુત ROI આપે છે; પોર્ટફોલિયોને NPV અથવા [ચોખ્ખા નાણાકીય લાભ](../ચોખ્ખો-નાણાકીય-લાભ/) થી ક્રમ આપો, ROI ને ચાળણી તરીકે વાપરો.
- **લાભ ઑડિટ નહીં**: [લાભ સાકારીકરણ](../લાભ-સાકારીકરણ/) ટ્રૅકિંગ વગરનો અનુમાનિત ROI વચન છે, પરિણામ નહીં.
