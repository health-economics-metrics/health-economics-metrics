# QALY ઘટ અને ગંભીરતા સંશોધકો

QALY ઘટ માપે છે કે રોગ સામાન્ય વસ્તીની સરખામણીમાં દર્દીઓ પાસેથી કેટલું ભવિષ્યનું આરોગ્ય લઈ લે છે. NICE તેનો ઉપયોગ **ગંભીરતા સંશોધકો** લાગુ કરવા કરે છે: વસ્તી જેટલી વધુ બીમાર, તેટલું દરેક મેળવેલા QALY નું મૂલ્ય વધુ — પ્રમાણભૂત સીમાના 1.7× સુધી.

## આ શા માટે મહત્ત્વનું છે

NICE ની 2022 માર્ગદર્શિકાથી, ગંભીરતા એ આરોગ્ય લાભના મૂલ્ય પર સ્પષ્ટ ગુણક છે, જૂના જીવન-અંતના પ્રીમિયમનું સ્થાન લે છે. ગંભીર સ્થિતિ માટેની ટેકનોલોજી £30,000 ને બદલે ~£51,000/QALY સુધીની અસરકારક સીમા સામે નક્કી થાય છે. જો તમારું સૉફ્ટવેર ગંભીર રીતે અસરગ્રસ્ત વસ્તીને સેવા આપે (અદ્યતન હૃદય નિષ્ફળતા, ગંભીર માનસિક બીમારી), તો ગંભીરતા સંશોધક ભંડોળ-યોગ્ય અને ભંડોળ-અયોગ્ય આર્થિક કેસ વચ્ચેનો તફાવત હોઈ શકે — અને તેનો દાવો કરવા તમને ઘટનું ગણિત જોઈએ.

## ગણિત

બે માપ, વર્તમાન પ્રમાણભૂત સંભાળ સાથે બાકીના આયુષ્ય પર ગણાયેલા:

```
Absolute shortfall     = QALYs_general_population − QALYs_with_condition
Proportional shortfall = Absolute shortfall / QALYs_general_population
```

NICE 2022 ભાર (જે માપ ઊંચો ભાર આપે તે લાગુ):

```
Weight ×1.0: absolute < 12 and proportional < 0.85
Weight ×1.2: absolute ≥ 12 or proportional ≥ 0.85
Weight ×1.7: absolute ≥ 18 or proportional ≥ 0.95
```

ભાર ΔE ને (અથવા સમકક્ષ રીતે સીમાને) ગુણે છે: અસરકારક λ ×1.2 પર £24k–£36k અને ×1.7 પર £34k–£51k બને છે.

## ઉકેલેલું ઉદાહરણ

આક્રમક સ્થિતિવાળા દર્દીઓ, સરેરાશ ઉંમર 60. 60 પર સામાન્ય વસ્તી 14.2 ડિસ્કાઉન્ટેડ QALY ની અપેક્ષા રાખે છે; વર્તમાન સંભાળ હેઠળ સ્થિતિ સાથે, 2.1.

```
Absolute shortfall     = 14.2 − 2.1 = 12.1  (≥ 12 → qualifies for ×1.2)
Proportional shortfall = 12.1 / 14.2 = 0.852 (≥ 0.85 → also ×1.2)
```

તમારા મૉનિટરિંગ પ્લૅટફૉર્મનો ICER £26,000/QALY છે — પ્રમાણભૂત £20k–£30k મધ્યબિંદુ નિર્ણયથી ઉપર, સીમારેખા. ×1.2 ભાર સાથે: અસરકારક ICER = 26,000 / 1.2 ≈ **£21,700/QALY** — આરામથી ભંડોળ-યોગ્ય. ઘટની ગણતરીએ હમણાં જ નિર્ણય ખસેડ્યો.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

ગંભીરતા ભારણ એ એવી વસ્તુનું ઔપચારિક સંસ્કરણ છે જે એન્જિનિયરિંગ સંસ્થાઓ સહજવૃત્તિથી કરે છે: સૌથી ખરાબ-સ્થિતિવાળી પ્રણાલીઓ પર સુધારાના એકમ દીઠ વધુ ખર્ચ કરવો. સ્થાનાંતરિત પૅટર્ન — દરેક સેવાની "SLO ઘટ" ગણો (તે તેની અપેક્ષિત સ્વસ્થ આધારરેખાથી કેટલી નીચે ચાલે છે, નિરપેક્ષ અને પ્રમાણસર), અને તે મુજબ સુધારણા મૂલ્યને ભારિત કરો. આ દલીલોને બદલે અંકગણિત સાથે ન્યાયી ઠેરવે છે કે બળતી લેગસી પ્રણાલીને સ્વસ્થ પ્રણાલી કરતાં બચેલા કલાક દીઠ વધુ રોકાણ કેમ મળે. તે એ જ ગવર્નન્સ પાઠ પણ વહન કરે છે: ભાર પ્રાથમિકતા બેઠક *પહેલાં* પ્રકાશિત કરો, નહીં તો દરેક ટીમ ગંભીરતાનો દાવો કરે છે.

## સામાન્ય ભૂલો

- **ખોટી આધારરેખા સામે ઘટ ગણવી**: તે *વર્તમાન પ્રમાણભૂત સંભાળ* હેઠળ માપાય છે, સારવાર ન થયેલા કુદરતી ઇતિહાસ સામે નહીં.
- **ઉંમર સંવેદનશીલતા**: ઘટ વસ્તીની ઉંમર પર ભારે આધાર રાખે છે (યુવાન દર્દીઓ પાસે ગુમાવવા વધુ QALY → ઊંચી નિરપેક્ષ ઘટ); સારવાર થયેલી વસ્તીનું વાસ્તવિક ઉંમર વિતરણ વાપરો.
- **સંશોધક બીજે લાગુ પડે છે એમ માનવું** — તે NICE (ઇંગ્લેન્ડ) પદ્ધતિ છે; અન્ય HTA સંસ્થાઓ ગંભીરતાને અલગ રીતે સંભાળે છે (અથવા બિલકુલ નહીં).
