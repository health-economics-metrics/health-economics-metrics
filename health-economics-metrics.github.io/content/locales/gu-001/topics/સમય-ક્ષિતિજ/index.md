# સમય-ક્ષિતિજ

સમય-ક્ષિતિજ એ સમયગાળો છે જેમાં વિશ્લેષણ ખર્ચ અને અસરો ગણે છે. તે સરખાવાતા વિકલ્પો વચ્ચેના બધા અર્થપૂર્ણ તફાવતો પકડવા પૂરતો લાંબો હોવો જોઈએ.

## આ શા માટે મહત્ત્વનું છે

ટૂંકી ક્ષિતિજ પસંદ કરો તો મોડા લાભ (નિવારણ) અને મોડા ખર્ચ (જાળવણી) ચૂકી જશો. અતિ-લાંબી ક્ષિતિજ પસંદ કરો તો બધું અનિશ્ચિતતામાં ડૂબી જાય છે. આરોગ્ય ટેક્નોલૉજી મૂલ્યાંકન ઘણીવાર મૃત્યુ-અસરવાળી સારવાર માટે **આજીવન** ક્ષિતિજ વાપરે છે; [બજેટ અસર વિશ્લેષણ](../બજેટ-અસર-વિશ્લેષણ/) જાણીજોઈને ટૂંકી **1–5 વર્ષ** ક્ષિતિજ વાપરે છે કારણ કે તેનો પ્રશ્ન પરવડવાનો છે, મૂલ્યનો નહીં. ક્ષિતિજ ઘોષિત મૉડેલિંગ પસંદગી છે, અને અસંગત ક્ષિતિજો સરખામણી સાથે રમત કરવાની ક્લાસિક રીત છે.

## ગણિત

ક્ષિતિજ કોઈ પણ મૂલ્યાંકનમાં સરવાળાની ઉપલી મર્યાદા છે:

```
Net present value = Σ (t = 0 … T) [ (Benefits_t − Costs_t) / (1 + r)^t ]

T = time horizon (years)
r = discount rate (see discounting-and-time-preference.md)
```

પરિણામો ક્ષિતિજ જણાવીને અને આદર્શ રીતે અનેક ક્ષિતિજે બતાવીને રજૂ કરવા જોઈએ.

## ઉકેલેલું ઉદાહરણ

ઇલેક્ટ્રોનિક પ્રિસ્ક્રાઇબિંગ સિસ્ટમ અમલમાં મૂકવાનો ખર્ચ £2 મિલિયન અને ચલાવવાનો £200,000/વર્ષ છે. તે £600,000/વર્ષના મૂલ્યની દવા-ભૂલો અટકાવે છે (ટાળેલા નુકસાનનો સારવાર ખર્ચ).

ક્ષિતિજ પ્રમાણે ચોખ્ખો લાભ (સ્પષ્ટતા માટે ડિસ્કાઉન્ટ વગર):

```
Horizon 1 year:  −2,000,000 − 200,000 + 600,000  = −£1,600,000
Horizon 3 years: −2,000,000 + 3 × 400,000        = −£800,000
Horizon 5 years: −2,000,000 + 5 × 400,000        =  £0
Horizon 10 years:−2,000,000 + 10 × 400,000       = +£2,000,000
```

સિસ્ટમ 5 વર્ષથી ઓછી કોઈ પણ ક્ષિતિજે "નિષ્ફળ" અને 10 વર્ષે "સફળ" થાય છે. બેમાંથી કોઈ સાચો જવાબ નથી; પ્રામાણિક અહેવાલ બ્રેક-ઇવન બિંદુ જણાવે છે અને ક્ષિતિજને સિસ્ટમના આયુષ્ય (બદલાતા પહેલાં કેટલો સમય?) થી વાજબી ઠેરવે છે.

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

- **એક સ્પ્રિન્ટ પર માપેલા ટૂલ મૂલ્યાંકન** શીખવાના-વક્રનો ઘટાડો (ખર્ચ આગળ-ભારિત) અને લાંબા ગાળાની જાળવણી (ખર્ચ પાછળ-ભારિત) વ્યવસ્થિત રીતે ચૂકે છે. અઠવાડિયું-2 માં માપેલા AI કોડિંગ-સહાયક પાઇલટ ટકાઉ સ્થિતિ નહીં, નવીનતાની ટોચ પકડે છે.
- **કરારની લંબાઈ ≠ લાભ ક્ષિતિજ.** 1-વર્ષનો SaaS કરાર પણ 5 વર્ષ પર મૂલવી શકાય જો તમે વાસ્તવિક રીતે નવીનીકરણની અપેક્ષા રાખો — પણ તે જણાવો.
- **લેગસી બદલવાના કેસ** જૂની સિસ્ટમના વિશ્વસનીય આયુષ્યાંત સુધી ચલાવવા જોઈએ, મનસ્વી ગોળ આંકડા સુધી નહીં.

## સામાન્ય ભૂલો

- **ક્ષિતિજ ખરીદી**: જે ક્ષિતિજ તમારા વિકલ્પને જીતાડે તે પસંદ કરવી. પરિણામ ગણતાં પહેલાં ક્ષિતિજ પૂર્વ-નોંધો.
- એક જ સરખામણીમાં **જુદા વિકલ્પો માટે જુદી ક્ષિતિજ**.
- **ડિસ્કાઉન્ટિંગ કે અનિશ્ચિતતા વિશ્લેષણ વગર આજીવન ક્ષિતિજ** — વર્ષ-30 ના લાભ મૂળ કિંમતે કાલ્પનિક છે. લાંબી ક્ષિતિજોને [સંવેદનશીલતા વિશ્લેષણ](../સંવેદનશીલતા-વિશ્લેષણ/) સાથે જોડો.
