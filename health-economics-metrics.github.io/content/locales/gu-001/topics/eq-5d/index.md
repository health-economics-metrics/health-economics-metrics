# EQ-5D

EQ-5D એ આરોગ્ય-સંબંધિત જીવનની ગુણવત્તા માપવા માટે EuroQol જૂથની પ્રમાણિત પ્રશ્નાવલી છે. તે સાધન છે જે મોટાભાગની [QALY](../ગુણવત્તા-સમાયોજિત-જીવન-વર્ષ/) ગણતરીઓની અંદરના ઉપયોગિતા ભારાંક પેદા કરે છે — NICE નો સંદર્ભ કેસ તેને પુખ્ત વયના લોકો માટે પસંદગીનું માપ નામ આપે છે.

## આ શા માટે મહત્ત્વનું છે

QALY નો દાવો કરવા માંગતા કોઈપણ ડિજિટલ આરોગ્ય ઉત્પાદનને માન્ય સાધનમાંથી ઉપયોગિતાઓ જોઈએ, અને EQ-5D UK અને મોટાભાગના યુરોપમાં ડિફૉલ્ટ છે. તે ઍપમાં જડવા જેટલું ટૂંકું છે (5 પ્રશ્નો + દૃશ્ય માપ), એટલે સૉફ્ટવેર ઉત્પાદનો સામાન્ય ઉપયોગની આડઅસર તરીકે HTA-કક્ષાનો પરિણામ ડેટા એકત્ર કરી શકે છે — દવાઓ પર માળખાકીય લાભ, જેને સમર્પિત અભ્યાસો જોઈએ.

## ગણિત

EQ-5D-5L **5 પરિમાણો**માંના દરેકમાં એક પ્રશ્ન પૂછે છે — ગતિશીલતા, સ્વ-સંભાળ, રોજિંદી પ્રવૃત્તિઓ, પીડા/અસ્વસ્થતા, ચિંતા/ડિપ્રેશન — દરેકનો જવાબ **5 સ્તરે** (કોઈ સમસ્યા નહીં … અત્યંત સમસ્યાઓ), ઉપરાંત 0–100 દૃશ્ય એનાલોગ માપ (EQ VAS).

```
Health state = 5-digit profile, e.g. "21221"
Utility index = value_set(profile)

The value set is country-specific, derived from time-trade-off /
discrete-choice surveys of the general public. Anchors: 1 = full health,
0 = dead; states worse than death are negative (UK 3L set floor: −0.594).
```

QALY અંકગણિત પછી `duration × utility` તરીકે આગળ વધે છે.

## ઉકેલેલું ઉદાહરણ

એક મસ્ક્યુલોસ્કેલેટલ રિહૅબ ઍપ 1,000 પૂર્ણ કરનારા વપરાશકર્તાઓ માટે ઑનબોર્ડિંગ અને 6 મહિને EQ-5D-5L માપે છે.

```
Mean utility at baseline:  0.62
Mean utility at 6 months:  0.71
Gain sustained (assume) 1 year: (0.71 − 0.62) × 1.0 = 0.09 QALYs per user
```

નિયંત્રણ-જૂથ ફેરફાર 0.03 (કુદરતી પુનઃપ્રાપ્તિ) સામે, આભારી લાભ 0.06 QALY/વપરાશકર્તા છે. £20,000–£30,000/QALY પર નાણાંકીય મૂલ્ય: **પૂર્ણ કરનાર વપરાશકર્તા દીઠ £1,200–£1,800 આરોગ્ય મૂલ્ય** — ચુકવણીકાર સાથે ઍપની ભાવ વાટાઘાટને લંગર કરતી સંખ્યા. (EQ-5D સૂચકાંક માટે લઘુતમ ક્લિનિકલી મહત્ત્વના તફાવતો સામાન્ય રીતે 0.03–0.08 ની રેન્જમાં છે, તેથી 0.06 વિશ્વસનીય છે પણ નિયંત્રણ સરખામણી પાર કરવી જોઈએ; જુઓ [દર્દી-નોંધિત પરિણામો](../દર્દી-નોંધિત-પરિણામો/).)

## સૉફ્ટવેર એન્જિનિયરિંગ સાથે સંબંધ

- **તેને ઇન્સ્ટ્રુમેન્ટ કરો.** સાઇનઅપ અને ફૉલો-અપ અંતરાલે EQ-5D એ UI ની થોડી સ્ક્રીન છે; વળતર HTA-કક્ષાનો પુરાવો છે. EuroQol પાસેથી લાઇસન્સ મેળવો (જરૂરી, કેટલાક ઉપયોગો માટે મફત).
- **ડિપ્લોયમેન્ટ દેશ માટે યોગ્ય વૅલ્યુ સેટ વાપરો** — એ જ જવાબો UK વિરુદ્ધ જર્મની વિરુદ્ધ જાપાનમાં અલગ રીતે સ્કોર થાય છે.
- **ડિઝાઇન પાઠ**: EQ-5D બતાવે છે કે નાનું પ્રમાણિત સર્વે વત્તા પ્રકાશિત સ્કોરિંગ ફંક્શન તુલનાત્મક એક સૂચકાંક કેવી રીતે આપે છે. કોઈપણ વિશ્વસનીય ડેવલપર-અનુભવ સૂચકાંક માટે પણ એ જ પૅટર્ન છે — પ્રમાણિત સાધન, પ્રકાશિત ભારાંક, તદર્થ અનુભૂતિ નહીં. જુઓ [SPACE અને DevEx](../space-અને-devex/).

## સામાન્ય ભૂલો

- **તુલનાકાર વિના પહેલાં/પછી** — સરેરાશ તરફ પાછા ફરવું અને કુદરતી પુનઃપ્રાપ્તિ ભોળા લાભ ફુલાવે છે.
- **ટકી રહેનાર પૂર્વગ્રહ**: ફક્ત જોડાયેલા રહેલા વપરાશકર્તાઓને માપવા ([જાળવણી અને છોડી જવું](../જાળવણી-અને-છોડી-જવું/) જુઓ).
- **અભ્યાસો વચ્ચે 3L અને 5L સંસ્કરણો કે વૅલ્યુ સેટ ભેળવવા** — વ્યવસ્થિત રીતે અલગ સંખ્યાઓ.
- **હળવી અસરગ્રસ્ત વસ્તીમાં સીલિંગ અસરો**: ઘણા વપરાશકર્તાઓ આધારરેખા પર 1.0 ની નજીક સ્કોર કરે છે, લાભ દર્શાવવા માટે કોઈ જગ્યા છોડતા નથી.
- **વૅલ્યુ સેટને સ્વ-ન્યાયી ગણવો**: વૅલ્યુ સેટ જે ઉપયોગિતા સંખ્યાઓ પાછી આપે છે તે પોતે જનતા પાસેથી સમય-વિનિમય (કે સંબંધિત પસંદગી-આધારિત) સર્વે દ્વારા મેળવાઈ હતી — કેવી રીતે તે માટે [સમય-વિનિમય (TTO) ઉપયોગિતા નિષ્કર્ષણ](../સમય-વિનિમય-tto-ઉપયોગિતા-નિષ્કર્ષણ/) જુઓ.
