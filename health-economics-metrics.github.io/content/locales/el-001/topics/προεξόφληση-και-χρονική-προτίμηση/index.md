# Προεξόφληση και Χρονική Προτίμηση

Η προεξόφληση μετατρέπει μελλοντικά κόστη και οφέλη σε παρούσες αξίες, επειδή ένα όφελος σήμερα αξίζει περισσότερο από το ίδιο όφελος σε πέντε χρόνια.

## Γιατί έχει σημασία

Κάθε αξιολόγηση οικονομίας της υγείας και κάθε σοβαρή επιχειρηματική περίπτωση του δημόσιου τομέα προεξοφλεί πολυετείς ροές. Το Green Book του HM Treasury του Ηνωμένου Βασιλείου επιβάλλει ετήσιο κοινωνικό επιτόκιο χρονικής προτίμησης 3.5%· η περίπτωση αναφοράς του NICE προεξοφλεί τόσο το κόστος όσο και τα αποτελέσματα υγείας με 3.5% ετησίως (με επιτόκιο 1.5% εκτός περίπτωσης αναφοράς για θεραπείες που πλησιάζουν τη θεραπεία με οφέλη σε 30+ έτη). Αν η επιχειρηματική σας περίπτωση λογισμικού ισχυρίζεται «εξοικονόμηση £5 εκατομμυρίων σε 10 έτη», ένας οικονομικός αξιολογητής θα ζητήσει αμέσως το προεξοφλημένο μέγεθος.

## Τα μαθηματικά

Παρούσα αξία ενός μελλοντικού ποσού:

```
PV = FV / (1 + r)^t

PV = παρούσα αξία
FV = μελλοντική αξία στο έτος t
r  = επιτόκιο προεξόφλησης (NICE/Green Book: 0.035)
t  = έτη από τώρα
```

Για σταθερό ετήσιο όφελος B σε n έτη (πάγια ετήσια καταβολή):

```
PV = B × [1 − (1 + r)^(−n)] / r
```

## Αναλυτικό παράδειγμα

Το λογισμικό σας εξοικονομεί σε ένα trust του NHS £100,000 ετησίως για 5 έτη, ξεκινώντας ένα έτος μετά το go-live.

Μη προεξοφλημένο σύνολο: £500,000.

Προεξοφλημένο με 3.5%:

```
Έτος 1: 100,000 / 1.035^1 = £96,618
Έτος 2: 100,000 / 1.035^2 = £93,351
Έτος 3: 100,000 / 1.035^3 = £90,194
Έτος 4: 100,000 / 1.035^4 = £87,144
Έτος 5: 100,000 / 1.035^5 = £84,197

Συνολική PV ≈ £451,505
```

Ο έντιμος τίτλος είναι περίπου £451,000, περίπου 10% λιγότερο από το αφελές άθροισμα. Υποθέστε τώρα ότι η παράδοση καθυστερεί ένα έτος: κάθε όρος μετατοπίζεται ένα έτος αργότερα και η PV πέφτει στα περίπου £436,000 — η οπτική της προεξόφλησης στο [κόστος καθυστέρησης](../κόστος-καθυστέρησης/).

## Σύνδεση με τη μηχανική λογισμικού

- Η **αποπληρωμή τεχνικού χρέους και οι μετεγκαταστάσεις πλατφορμών** υπόσχονται ροές οφέλους σε χρόνια μακριά· προεξοφλήστε τις πριν τις συγκρίνετε με εργασία που αποδίδει αυτό το τρίμηνο.
- Το **μπροστινά φορτωμένο κόστος, πίσω φορτωμένα οφέλη** είναι το τυπικό σχήμα μιας μετεγκατάστασης. Η προεξόφληση τιμωρεί αυτό το σχήμα, σωστά: τιμολογεί την άνευ κινδύνου χρονική αξία της δέσμευσης χωρητικότητας τώρα για αξία αργότερα.
- Οι ισχυρισμοί **«εξοικονόμηση στο έτος 5»** αξίζουν διπλό σκεπτικισμό — είναι και έντονα προεξοφλημένοι και υψηλής αβεβαιότητας (βλ. [ανάλυση ευαισθησίας](../ανάλυση-ευαισθησίας/)).

## Παγίδες

- **Προεξόφληση κόστους αλλά όχι οφελών** (ή αντίστροφα) — η περίπτωση αναφοράς προεξοφλεί και τα δύο, με το ίδιο επιτόκιο.
- **Χρήση εμπορικού επιτοκίου (8–12%) σε περίπτωση δημόσιου τομέα**, ή 3.5% σε περίπτωση που χρηματοδοτείται από επιχειρηματικά κεφάλαια. Ταιριάξτε το επιτόκιο με τον φορέα απόφασης.
- **Σύγχυση προεξόφλησης με πληθωρισμό.** Η προεξόφληση εφαρμόζεται σε *πραγματικές* (προσαρμοσμένες για τον πληθωρισμό) αξίες· μην κάνετε και τα δύο σιωπηρά.
