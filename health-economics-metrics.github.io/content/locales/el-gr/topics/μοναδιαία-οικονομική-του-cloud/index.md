# Μοναδιαία οικονομική του cloud (FinOps)

Η μοναδιαία οικονομική του cloud μετατρέπει τη ακατέργαστη δαπάνη cloud σε **κόστος ανά μονάδα παραγωγής** — ανά πελάτη, ανά συναλλαγή, ανά επιλυμένο περιστατικό, ανά token. Είναι η δυνατότητα FinOps που μετατρέπει το «ο λογαριασμός μας στο AWS είναι £400k/μήνα» σε «η εξυπηρέτηση ενός ασθενούς κοστίζει £0,83».

## Γιατί έχει σημασία

Τα συνολικά ποσά δαπάνης δεν μπορούν να απαντήσουν στα ερωτήματα που μετράνε: γίνεται το προϊόν περισσότερο ή λιγότερο αποδοτικό; Η ανάπτυξη βελτιώνει ή καταστρέφει το περιθώριο; Τι πρέπει να χρεώνουμε; Τα μοναδιαία κόστη απαντούν και στα τρία. Για την ψηφιακή υγεία ειδικά, το «κόστος ανά επιλυμένο περιστατικό» *είναι* μοναδιαίο κόστος υπηρεσίας υγείας — άμεσα συγκρίσιμο με τα μεγέθη του [National Cost Collection](../εθνικό-τιμολόγιο-και-κόστη-μονάδας/) που χρησιμοποιεί ένας φορέας ανάθεσης για κάθε άλλη υπηρεσία, κάτι που την καθιστά τη φυσική γλώσσα για την τιμολόγηση ψηφιακών διαδρομών έναντι των παραδοσιακών.

## Τα μαθηματικά

```
Unit cost = total allocated cost (incl. shared/platform costs) / units delivered

Two families:
  resource-efficiency units: cost/GB stored, cost/vCPU-hour, cost/token,
                             cost/build-minute
  business units:            cost/customer, cost/transaction, cost/consultation,
                             cost/case-resolved

Marginal vs average discipline applies (marginal-vs-average-cost.md):
committed/reserved spend makes marginal unit cost ≈ 0 until the next
commitment step — price expansion decisions at marginal, efficiency
trends at average.
```

## Αναλυτικό παράδειγμα

Μια ψηφιακή υπηρεσία διαλογής (triage): δαπάνη cloud £62.000/μήνα (υπολογιστική £30k, δεδομένα £18k, κατανομή κοινής πλατφόρμας £14k), που διαχειρίζεται 380.000 επεισόδια διαλογής/μήνα:

```
Average cost per episode = 62,000 / 380,000 ≈ £0.163

Commissioner comparison: telephone triage ≈ £8–12/call, GP consultation ≈ £42
→ digital episode runs at ~2% of the cheapest human alternative — the
channel-shift economics of gds-service-metrics.md, from the cost side.

Trend check: last year £0.21/episode at 240k episodes → improving scale
economics (fixed platform costs amortizing), worth a headline in the QBR.
```

## Σύνδεση με τη μηχανική λογισμικού

Η μοναδιαία οικονομική είναι το σημείο όπου οι επιλογές μηχανικής γίνονται αναγνώσιμες από τα οικονομικά: μια αρχιτεκτονική που υποδιπλασιάζει το κόστος ανά επεισόδιο είναι πλεονέκτημα τιμολόγησης· μια που κλιμακώνεται υπεργραμμικά είναι χρονοβόμβα ορατή μόνο σε αυτόν τον δείκτη. Πρακτικές που μεταφέρονται από την κοστολόγηση υγείας: **δημοσιεύστε τους κανόνες κατανομής** (τα κοινά κόστη διέστρεφαν τα ανά μονάδα μεγέθη έως ότου το PLICS τυποποίησε την κοστολόγηση σε επίπεδο ασθενή — η κατανομή κόστους πλατφόρμας σας χρειάζεται την ίδια αυστηρότητα)· **επιλέξτε μονάδες στις οποίες σκέφτεται ο αγοραστής** (οι φορείς ανάθεσης αγοράζουν επεισόδια, όχι vCPU)· και τροφοδοτήστε τα μοναδιαία κόστη σε κάθε μοντέλο [ICER](../αυξητικός-λόγος-κόστους-αποτελεσματικότητας/) και [επίπτωσης στον προϋπολογισμό](../ανάλυση-επίπτωσης-στον-προϋπολογισμό/) ως τον κανονιστικό παρονομαστή κόστους. Για λειτουργίες AI, η μονάδα είναι το token — βλ. [οικονομική μονάδας εξαγωγής συμπερασμάτων](../οικονομία-μονάδας-συμπερασμού/).

## Παγίδες

- **Αγνόηση των κοινών κοστών**: τα μοναδιαία κόστη που εξαιρούν κατανομές πλατφόρμας/ασφάλειας/on-call υποεκτιμούν κατά 30–50% και καταρρέουν στον έλεγχο.
- **Ματαιόδοξοι παρονομαστές**: το «κόστος ανά κλήση API» κολακεύει· το «κόστος ανά ολοκληρωμένο επεισόδιο ασθενούς» ενημερώνει.
- **Τιμολόγηση οριακών αποφάσεων με μέσο κόστος**: η χρέωση των ομάδων με το μέσο μοναδιαίο κόστος για χρήση που είναι οριακά δωρεάν οδηγεί σε θέατρο αποφυγής σπατάλης (βλ. [εθνικό τιμολόγιο](../εθνικό-τιμολόγιο-και-κόστη-μονάδας/) για την εκδοχή του NHS αυτού του σφάλματος κινήτρων).
