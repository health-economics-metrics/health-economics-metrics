# Ανάλυση Κόστους-Συνεπειών (CCA)

Η CCA παρουσιάζει το κόστος δίπλα σε έναν **αποσυναθροισμένο πίνακα όλων των αποτελεσμάτων** — κλινικών, λειτουργικών, βιωματικών — χωρίς να τα συμπτύσσει σε έναν ενιαίο λόγο ή βαθμό. Ο φορέας λήψης αποφάσεων σταθμίζει ρητά τους συμβιβασμούς.

## Γιατί έχει σημασία

Η CCA είναι η **προτιμώμενη οικονομική μορφή του NICE για τις περισσότερες ψηφιακές τεχνολογίες υγείας** στο πλαίσιο του Evidence Standards Framework. Τα ψηφιακά προϊόντα παράγουν ετερογενή αποτελέσματα (εξοικονόμηση χρόνου, ικανοποίηση, μείωση DNA, μικρά κλινικά οφέλη) που δύσκολα συναθροίζονται έντιμα σε έναν αριθμό QALY. Αντί να επιβάλει ένα εύθραυστο σύνθετο μέγεθος, η CCA δείχνει ολόκληρο το καθολικό. Για τις περισσότερες επιχειρηματικές περιπτώσεις λογισμικού είναι τόσο η πιο έντιμη όσο και η πιο πειστική μορφή, επειδή κάθε ενδιαφερόμενος μπορεί να βρει τη δική του γραμμή που αφορά την απόφασή του.

## Τα μαθηματικά

Σκόπιμα δεν υπάρχει τύπος συνάθροισης. Το αποτέλεσμα είναι ένας πίνακας:

```
                          Παρέμβαση      Σύγκριση     Διαφορά
Κόστος (ετήσιο)           £X             £Y           ΔC
Αποτέλεσμα 1 (φυσ. μονάδες) …            …            Δ1
Αποτέλεσμα 2              …              …            Δ2
Ποιοτικά αποτελέσματα     περιγράφονται, δεν βαθμολογούνται
```

Κάθε γραμμή διατηρεί τις δικές της μονάδες. Κανόνες: κάθε συνέπεια προκαθορίζεται (χωρίς επιλεκτική επιλογή μετά τα αποτελέσματα)· ίδια [οπτική ανάλυσης](../οπτική-της-ανάλυσης/) και ίδιος [χρονικός ορίζοντας](../χρονικός-ορίζοντας/) παντού· αβεβαιότητα ανά γραμμή.

## Αναλυτικό παράδειγμα

Ψηφιακή πλατφόρμα προεγχειρητικής εκτίμησης έναντι τηλεφωνικής διαδικασίας, ανά έτος, ένα trust:

```
                              Ψηφιακή      Τηλεφωνική  Διαφορά
Λειτουργικό κόστος            £180,000     £95,000     +£85,000
Ώρες νοσηλευτών σε εκτιμήσεις 6,200        11,800      −5,600 ώρες
Ακυρώσεις χειρουργείων ημέρας 92           174         −82
Ικανοποίηση ασθενών (CSAT)    4.5/5        3.9/5       +0.6
Χαμένες/ελλιπείς εκτιμήσεις   1.2%         4.8%        −3.6 pp
```

Κανένας ενιαίος βαθμός — όμως η απόφαση είναι εύκολο να τεκμηριωθεί: τα £85,000 αγοράζουν 5,600 ώρες νοσηλευτών (≈ £15/ώρα, πολύ κάτω από οποιοδήποτε κόστος στελέχωσης), 82 αποφευχθείσες ακυρώσεις (καθεμία σπαταλά μια θέση χειρουργείου αξίας ~£1,200) και καλύτερη εμπειρία. Μια επιτροπή βλέπει επίσης ακριβώς τι *δεν* παίρνει: κανένα διακηρυγμένο όφελος σε QALY ή θνησιμότητα.

## Σύνδεση με τη μηχανική λογισμικού

Η CCA είναι η τυπική εκδοχή της ισορροπημένης κάρτας βαθμολόγησης που ήδη χρησιμοποιεί μια καλή πρόταση πλατφόρμας: κόστος δίπλα σε μετρικές DORA, βαθμολογίες DevEx, αριθμούς περιστατικών — χωρίς συνάθροιση. Η πειθαρχία της οικονομίας της υγείας που προστίθεται: **προκαθορίστε τις γραμμές** (αποφασίστε τι μετράει πριν από το πιλοτικό, ώστε να μην μπορείτε να παραλείψετε αθόρυβα τη μετρική που χειροτέρεψε) και **δείξτε τις δυσμενείς γραμμές** — μια CCA με μόνο καλά νέα είναι μάρκετινγκ. Χρησιμοποιήστε την CCA όταν δεν υπάρχει υπερασπίσιμο σύνθετο μέγεθος, κάτι που για τα εργαλεία προγραμματιστών ισχύει σχεδόν πάντα.

## Παγίδες

- **Επιλεκτικές συνέπειες** — η ακεραιότητα της μορφής εξαρτάται από την προκαθορισμένη επιλογή.
- **Λαθραία συνάθροιση**: ο χρωματικός κώδικας ή οι «συνολικές βαθμολογίες» επανεισάγουν τα αυθαίρετα βάρη που η CCA υπάρχει για να αποφεύγει.
- **Παράλυση αποφάσεων**: η CCA απαιτεί φορέα απόφασης πρόθυμο να σταθμίσει συμβιβασμούς· συνοδεύστε την με σύσταση και τη σχετική αιτιολόγηση.
