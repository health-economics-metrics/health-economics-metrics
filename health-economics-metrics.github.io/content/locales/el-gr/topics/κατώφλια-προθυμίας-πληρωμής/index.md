# Κατώφλια προθυμίας πληρωμής

Ένα κατώφλι προθυμίας πληρωμής (WTP) είναι το μέγιστο που ένας υπεύθυνος λήψης αποφάσεων θα πληρώσει ανά μονάδα οφέλους υγείας — η γραμμή που μετατρέπει ένα [ICER](../αυξητικός-λόγος-κόστους-αποτελεσματικότητας/) σε απόφαση υιοθέτησης/απόρριψης.

## Γιατί έχει σημασία

Το κατώφλι είναι το σημείο όπου η οικονομική της υγείας παύει να είναι μέτρηση και γίνεται πολιτική. Κάθε εθνικό σύστημα έχει ένα, ρητό ή σιωπηρό, και η γνώση του τοπικού αριθμού σας λέει ακριβώς πώς να τιμολογήσετε έναν ισχυρισμό αξίας υγείας:

| Φορέας | Κατώφλι (όπως ερευνήθηκε, 2024–2025) |
|---|---|
| NICE (England) | £20,000–£30,000 per QALY; empirical average decision threshold ≈ £24,400 (2022–24); severity modifiers raise effective ceiling to ~£36k–£51k; highly specialized technologies up to £100k+ |
| ICER (US, non-governmental) | $100,000–$150,000 per QALY/evLYG price benchmarks; reports $50k–$200k range |
| Canada (CADTH / CDA-AMC) | ≈ CAD$50,000 per QALY working threshold |
| WHO-CHOICE (historical, global) | 1–3× GDP per capita per DALY averted (now discouraged as too blunt) |
| Empirical UK supply side (Claxton et al.) | ≈ £13,000 per QALY actually displaced at the NHS margin |

## Τα μαθηματικά

Το κατώφλι λ εισέρχεται σε κάθε κανόνα απόφασης:

```
Adopt if ICER = ΔC/ΔE < λ
Equivalently: adopt if NMB = λ×ΔE − ΔC > 0
```

Δύο θεωρίες για το τι *είναι* το λ:

- **Πλευρά ζήτησης**: τι είναι διατεθειμένη να πληρώσει η κοινωνία για υγεία (αξιακή κρίση).
- **Πλευρά προσφοράς**: η υγεία που παράγει σήμερα ο προϋπολογισμός στο περιθώριο (εμπειρικό μέγεθος — τα ~£13k/QALY του Claxton). Αν το λ που χρησιμοποιείται για αποφάσεις υπερβαίνει τον ρυθμό της πλευράς προσφοράς, η έγκριση νέας τεχνολογίας εκτοπίζει περισσότερη υγεία από όση προσθέτει.

## Αναλυτικό παράδειγμα

Η ψηφιακή θεραπευτική σας αποδίδει 0,05 QALY ανά θεραπευόμενο ασθενή με καθαρό κόστος (τιμή μείον αντισταθμίσεις) £800.

```
ICER = 800 / 0.05 = £16,000 per QALY
```

- Αγγλία: κάτω από £20k → χρηματοδοτήσιμο. Μέγιστη υπερασπίσιμη τιμή: στο λ = £20.000, price_max = 0,05 × 20.000 + αντισταθμίσεις = £1.000 + αντισταθμίσεις.
- Αμερικανική εμπορική πλαισίωση στα $150k/QALY: η τιμή βάσει αξίας είναι πολύ υψηλότερη.
- Κατώφλι χώρας με ΑΕΠ κατά κεφαλήν $4.000: το ίδιο προϊόν πρέπει να κοστίζει καθαρά κάτω από ~$200.

Ίδιο προϊόν, τρεις αγορές, τρεις τιμές — το κατώφλι *είναι* το μοντέλο τιμολόγησης. Αυτή είναι τιμολόγηση βάσει αξίας, τρεγμένη ανάποδα από το λ.

## Σύνδεση με τη μηχανική λογισμικού

Κάθε οργανισμός μηχανικών έχει ένα σιωπηρό λ: το όριο στο οποίο χρηματοδοτεί εργαλεία ανά ώρα μηχανικού που εξοικονομείται. Η ρητή διατύπωσή του — «χρηματοδοτούμε οτιδήποτε κάτω από £40 ανά αξιόπιστη ώρα μηχανικού που εξοικονομείται» — επιτρέπει σύγκριση τύπου πίνακα κατάταξης επενδύσεων πλατφόρμας, ακριβώς όπως οι πίνακες κόστους-ανά-QALY κατατάσσουν τις δαπάνες υγείας. Το δίδαγμα της πλευράς προσφοράς μεταφέρεται επίσης: το πραγματικό εσωτερικό σας λ είναι ό,τι παράγει το *τρέχον* backlog σας στο περιθώριο, όχι ό,τι λέει η ηγεσία ότι αξίζει ο χρόνος.

## Παγίδες

- **Αγορά κατωφλίου** μεταξύ δικαιοδοσιών ή παράθεση του ανώτατου ορίου HST για ένα συνηθισμένο προϊόν.
- **Αντιμετώπιση του λ ως κατώτατης τιμής**: η υπέρβαση του κατωφλίου είναι αναγκαία, όχι επαρκής — η [επίπτωση στον προϋπολογισμό](../ανάλυση-επίπτωσης-στον-προϋπολογισμό/) μπορεί και πάλι να βυθίσει ένα προϊόν προσιτό ανά μονάδα.
- **Αγνόηση ότι τα κατώφλια κινούνται**: οι τροποποιητές σοβαρότητας του NICE (2022) και οι περιοδικές αναθεωρήσεις αλλάζουν το πραγματικό λ· χρονολογήστε τους ισχυρισμούς σας.
- **Σύγκριση ενός ICER με κατώφλι σε διαφορετικό νόμισμα χωρίς πρότερη μετατροπή**: βλ. [σύγκριση ICER μεταξύ νομισμάτων](../σύγκριση-icer-μεταξύ-νομισμάτων/) — η μέθοδος μετατροπής (ισοτιμία αγοραστικής δύναμης έναντι συναλλαγματικής ισοτιμίας αγοράς) έχει μεθοδολογικές συνέπειες, δεν είναι λεπτομέρεια στρογγυλοποίησης.
- **Σύγχυση αποτίμησης βάσει λ με την παράδοση VSL/VPF της αγοράς εργασίας**: προέρχονται από διαφορετικές θεωρητικές παραδόσεις (μεθοδολογία περιορισμένη από τον προϋπολογισμό υγείας έναντι αποκαλυπτόμενης προτίμησης από ανταλλαγές μισθού-κινδύνου) και δεν συμβιβάζονται πάντα — για την εναλλακτική προσέγγιση αποκαλυπτόμενης προτίμησης στην αποτίμηση της ζωής, βλ. [Αξία μιας στατιστικής ζωής](../αξία-μιας-στατιστικής-ζωής/).
